## Describe System Behaviors / Describe Activity Diagrams

- Initial Node — Official summary: Dispatch control token at beginning of activity (Since R2024a) **metadata only; full English and Chinese documents pending**
- Action Node — Official summary: Process object tokens through MATLAB function or nested activity diagram (Since R2024a) **metadata only; full English and Chinese documents pending**
- Pin — Official summary: Direct tokens into or out of an action node (Since R2024a) **metadata only; full English and Chinese documents pending**
- Parameter Node — Official summary: Process tokens through a nested activity diagram (Since R2024a) **metadata only; full English and Chinese documents pending**
- Decision or Merge Node — Official summary: Route input tokens based on evaluation of MATLAB expressions, or merge multiple input tokens onto one output flow (Since R2024a) **metadata only; full English and Chinese documents pending**
- Join or Fork Node — Official summary: Synchronize multiple input tokens into one output, or replicate one input token on all output flows (Since R2024a) **metadata only; full English and Chinese documents pending**
- Flow Final Node — Official summary: Terminate one object or control flow (Since R2024a) **metadata only; full English and Chinese documents pending**
- Activity Final Node — Official summary: Terminate entire activity (Since R2024a) **metadata only; full English and Chinese documents pending**
