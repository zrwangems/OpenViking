## 描述

用于设置两个节点之间初始温差的热元件

Infinite Thermal Resistance 模块表示一个无限大的热阻，没有热量流过它。使用此模块可以在不影响模型方程的情况下设置两个热节点之间的初始温差。

**Variables** 选项卡允许你在仿真前为 **Temperature difference** 变量设置优先级和初始目标值。有关详细信息，请参阅 Set Priority and Initial Target for Block Variables。
