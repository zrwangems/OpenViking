## 描述

用于设置两个节点之间初始电压差的电气元件

Infinite Resistance 模块表示一个不消耗电流的无限大电阻。使用此模块可以在不影响模型方程的情况下设置两个电气节点之间的初始电压差。

**Variables** 选项卡允许您在仿真前为 **Voltage difference** 变量设置优先级和初始目标值。有关详细信息，请参阅 Set Priority and Initial Target for Block Variables。
