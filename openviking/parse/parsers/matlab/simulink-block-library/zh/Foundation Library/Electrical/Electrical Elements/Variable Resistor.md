# Variable Resistor

## 端口

### 输入

### **R** — 电阻控制信号，单位为欧姆 物理信号

用于指定电阻值的输入物理信号。
### 守恒

### **+** — 正极端子 电气

与电阻器正极端子相关联的电气守恒端口。

### **-** — 负极端子 电气

与电阻器负极端子相关联的电气守恒端口。

### **H** — 热端口 热

提供电阻器温度的热守恒端口。

#### 依赖关系

要启用此端口，请选中**添加热端口**复选框。

## 参数

### **最小电阻 R>=0** — 最小可接受电阻 `0 Ohm` (默认) | 非负标量

最小电阻值。如果输入信号低于此级别（例如变为负值），则使用此最小电阻值。参数值必须为非负值。

### **添加热端口** — 控制热端口可见性 **关闭** (默认) | **打开**

选中此复选框会公开热端口 **H**，可让您将电阻器连接到热网络。选中此复选框还会启用**热质量**参数，并将**温度**变量添加到**初始目标**和**标称值**部分。

### **热质量** — 电阻器的热质量 `1 J/K` (默认) | 非负标量

电阻器的热质量。

#### 依赖关系

要启用此参数，请选中**添加热端口**复选框。

## 描述

电气系统中的线性可变电阻器

Variable Resistor 模块对一个线性可变电阻器进行建模，用以下方程描述：

V=I·R

其中：

- *V* 是电压。
- *I* 是电流。
- *R* 是电阻，即控制端口处的信号值。

连接端 **+** 和 **-** 是分别对应于电阻器的正极端子和负极端子的守恒电气端口。**R** 是控制电阻值的物理信号输入端口。如果电流从正极流向负极，则电流为正，电阻器两端的电压等于正极端子电压与负极端子电压之差，即 *V*(+) – *V*(–)。

可选热端口 **H** 可让您将电阻器连接到热网络。要公开热端口，请选中**添加热端口**复选框，然后使用**热质量**参数指定电阻器的热质量。您还可以指定**温度**变量的初始目标值。该模块没有对其他效应进行建模，例如基于温度的电阻变化。

### 变量

要在仿真之前设置模块变量的优先级和初始目标值，请使用模块对话框或属性检查器中的**初始目标**部分。有关详细信息，请参阅设置模块变量的优先级和初始目标值。

标称值提供了一种指定模型中变量的预期模的方法。使用基于标称值的系统缩放可提高仿真的稳健性。标称值可以来自不同的来源，其中之一是模块对话框或属性检查器中的的**标称值**部分。有关详细信息，请参阅Modify Nominal Values for a Block Variable。
