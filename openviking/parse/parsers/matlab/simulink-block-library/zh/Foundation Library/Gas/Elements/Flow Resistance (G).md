# Flow Resistance (G)

## 端口

### 守恒

### **A** — 入口或出口气体

与流阻的入口或出口关联的气体守恒端口。此模块没有固有方向性。

### **B** — 入口或出口气体

与流阻的入口或出口关联的气体守恒端口。此模块没有固有方向性。

## 参数

### **标称压降** — 已知工作条件下的压降 `0.001 MPa`（默认）

已知工作条件下从入口到出口的压降。此模块使用标称参数计算压降与质量流量之间的比例常数。

### **标称质量流量** — 已知工作条件下的质量流量 `0.1 kg/s`（默认）

已知工作条件下通过部件的质量流量。此模块使用标称参数计算压降与质量流量之间的比例常数。

### **标称密度** — 已知工作条件下的密度 `0 m^3/kg`（默认）

已知工作条件下流阻内部的质量密度。此模块使用标称参数计算压降与质量流量之间的比例常数。将此参数设置为零，以忽略压降对流体密度的依赖性。

### **端口 A 和 B 处的横截面积** — 流阻端口处的流通面积 `0.01 m^2`（默认）

流阻端口处的流通面积。假定这些端口尺寸相同。

### **层流对应的标称质量流量分数** — 阈值质量流量与标称质量流量的比值 `1e-3`（默认）

阈值质量流量与标称质量流量的比值。此模块使用此参数计算阈值质量流量——并最终设置压降线性化的极限。

## 描述

气体分支中的一般阻力

Flow Resistance (G) 模块对气体网络分支中的一般压降进行建模。压降与质量流量的平方以及气体密度成正比。比例常数由模块对话框中指定的标称工作条件确定。

当可用于某个部件的唯一数据是其压降随质量流量变化的函数时，请使用此模块。将此模块与其他模块组合，以创建能更准确捕捉其所引起压降的自定义部件——例如，基于腔室模块的热交换器。

### 质量平衡

假定流阻内部的气体体积可忽略不计。那么，通过一个端口流入的质量流量必须精确等于通过另一个端口流出的质量流量：

m˙A+m˙B=0,

其中 m˙A 和 m˙B 分别定义为通过端口 **A** 和 **B** 进入部件的质量流量。

### 能量平衡

能量只能通过气体守恒端口进入和离开流阻。壁面与环境之间不发生热交换。此外，不对流体做功，流体也不对外做功。那么，通过一个端口流入的能量流率必须精确等于通过另一个端口流出的能量流率：

ϕA+ϕB=0,

其中 *ϕ*A 和 *ϕ*B 是通过端口 **A** 和 **B** 进入流阻的能量流率。

### 动量平衡

流体上相关的外力包括由于端口处压力产生的外力以及由于部件壁面处黏性摩擦产生的外力。重力被忽略，其他体积力也被忽略。将摩擦力表示为损失系数 *ξ* 的函数，得到半经验表达式：

Δp=ξm˙22ρS2,

其中：

- *Δp* 是从端口 **A** 到端口 **B** 的压降——即 *p*A + *p*B。
- *ξ* 是损失系数。
- *ρ* 是流体密度。
- *S* 是流通面积。

压降方程通过两项修改实现。首先，为了在流动方向反转时允许符号变化，将其重写为：

Δp=ξm˙|m˙|2ρS2,

其中仅当质量流量也为正时，压降才为正。其次，为了消除由流动反转导致的奇异性——这可能在仿真期间给数值求解器带来挑战——在接近零流量的小区域内对其进行线性化：

Δp=ξm˙m˙2+​m˙Th22ρS2,

其中 m˙Th 是阈值质量流量，低于该值时压降被线性化。该图显示了修改后的压降与局部质量流量的关系（曲线 **I**）：

- 高于 m˙Th 时，压降近似于原始方程（曲线 **II**）所表达的值，并且随 m˙2 变化。这种依赖性与在湍流中观察到的依赖性相当。
- 低于 m˙Th 时，压降近似为一条直线，其斜率部分取决于 m˙Th（曲线 **III**），并且随 m˙ 变化。这种依赖性与在层流中观察到的依赖性相当。

为便于建模，损失系数 *ξ* 不需要作为模块参数。相反，它会根据模块对话框中指定的标称条件自动计算：

ξ2S2=ρ\*Δp\*m˙\*2,

其中星号 (\*) 表示标称工作条件下的值。所有这些计算的基础是假设阈值质量流量 m˙Th 远小于标称值 m˙\*。将压降表达式中的分数 *ξ*/(2S2) 替换后得到：

Δp=ρ\*Δp\*ρm˙\*2(m˙m˙2+m˙Th2).

或者，等价地：

Δp=Cm˙ρm˙2+m˙Th2,

其中 *C* 是流阻两端压降与局部质量流量之间的比例常数。其定义为：

C=ρ\*Δp\*m˙\*2.

如果假设流体密度不变，则其标称值和实际值必须始终相等。当在模块对话框中将标称值指定为 `0` 时就是这种情况——`0` 是一个特殊值，用于向模块指示流体密度为常量。此时两者的比值为 `1`，分数 *C*/*ρ* 简化为：

Cρ=Δp\*m˙\*2.
