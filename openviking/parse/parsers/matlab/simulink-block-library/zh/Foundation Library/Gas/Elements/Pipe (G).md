# Pipe (G)

## 端口

### 守恒

### **A** — 入口或出口气体

与管道入口或出口关联的气体守恒端口。该模块没有固有方向性。

### **B** — 入口或出口气体

与管道入口或出口关联的气体守恒端口。该模块没有固有方向性。

### **H** — 管壁温度（热）

与管壁温度关联的热守恒端口。该温度可能不同于气体体积的温度。

## 参数

### 几何

### **管道长度** — 管道长度 `5 m`（默认）

管道沿流动方向的长度。

### **横截面积** — 管道内部面积 `0.01 m^2`（默认）

管道垂直于流动方向的内部面积。

### **水力直径** — 具有相同横截面积的等效圆柱形管道的直径 `0.1 m`（默认）

具有相同横截面积的等效圆柱形管道的直径。

### 摩擦与传热

### **局部阻力的总等效长度** — 管道中所有局部阻力的组合长度 `0.1 m`（默认）

管道中所有局部阻力的组合长度。局部阻力包括弯头、管件、附件以及管道入口和出口。局部阻力的作用是增加管段的有效长度。该长度仅在摩擦计算中加到管道几何长度上。气体体积仅取决于由 **管道长度** 参数定义的管道几何长度。

### **内表面绝对粗糙度** — 管道内表面上所有表面缺陷的平均深度 `15e-6 m`（默认）

管道内表面上所有表面缺陷的平均深度，这会影响湍流流态下的压力损失。

### **层流上限雷诺数限制** — 流动开始从层流过渡到湍流时的雷诺数 `2000`（默认）

流动开始从层流过渡到湍流时的雷诺数。该数值等于对应于充分发展层流的最大雷诺数。

### **湍流下限雷诺数限制** — 流动开始从湍流过渡到层流时的雷诺数 `4000`（默认）

流动开始从湍流过渡到层流时的雷诺数。该数值等于对应于充分发展湍流的最小雷诺数。

### **层流黏性摩擦的形状因子** — 管道几何形状对黏性摩擦损失的影响 `64`（默认）

无量纲因子，用于表示管道横截面几何形状对层流流态下黏性摩擦损失的影响。典型值为：圆形横截面为 64，方形横截面为 57，长宽比为 2 的矩形横截面为 62，薄环形横截面为 96 [1]。

### **层流换热的努塞尔数** — 对流传热与导热传热之比 `3.66`（默认）

层流流态下对流传热与导热传热之比。其值取决于管道横截面几何形状和管壁热边界条件，例如恒定温度或恒定热通量。典型值为 3.66，适用于具有恒定壁温的圆形横截面 [2]。

### 效应与初始条件

### **启用动态可压缩性** — 选择是否对气体压力动态建模 `On`（默认）| `Off`

选择是否考虑气体的动态可压缩性。动态可压缩性使气体密度依赖于压力，从而影响系统在小时间尺度上的瞬态响应。如果您希望在仿真期间快速达到稳态或简化模型初始化，请禁用动态可压缩性。

### **启用流体惯性** — 选择是否对气体惯性建模 `Off`（默认）| `On`

选择是否考虑气体流动惯性。流动惯性提供对质量流量变化的阻力。

## 描述

用于气体流动的刚性导管

Pipe (G) 模块对气体网络中的管道流动动态进行建模。该模块考虑黏性摩擦损失以及与管壁的对流传热。管道包含恒定体积的气体。压力和温度基于该气体体积的可压缩性和热容量演化。当出口达到声速条件时会发生阻塞。

**注意**

通过该模块的气体流动可能发生阻塞。如果连接到 Pipe (G) 模块的 Mass Flow Rate Source (G) 模块或 Controlled Mass Flow Rate Source (G) 模块指定的质量流量大于可能的阻塞质量流量，则会出现仿真错误。有关更多信息，请参阅 Choked Flow。

### 质量平衡

质量守恒将质量流量与表示气体体积的内部节点的压力和温度动态联系起来。当您选中 **启用动态可压缩性** 时，质量平衡为

∂M∂p⋅dpIdt+∂M∂T⋅dTIdt=m˙A+m˙B

其中：

- ∂M∂p 是气体体积的质量相对于压力在恒定温度和体积下的偏导数。
- ∂M∂T 是气体体积的质量相对于温度在恒定压力和体积下的偏导数。
- *p*I 是气体体积的压力。
- *T*I 是气体体积的温度。
- *t* 是时间。
- m˙A 和 m˙B 分别是端口 A 和 B 的质量流量。与端口关联的流量在流入模块时为正。

当您清除 **启用动态可压缩性** 复选框时，流入管道的质量流量等于流出管道的质量流量

m˙A+m˙B=0

### 能量平衡

能量守恒将能量和热流量与表示气体体积的内部节点的压力和温度动态联系起来。当您选中 **启用动态可压缩性** 时，能量平衡为

∂U∂p⋅dpIdt+∂U∂T⋅dTIdt=ΦA+ΦB+QH

其中：

- ∂U∂p 是气体体积的内能相对于压力在恒定温度和体积下的偏导数。
- ∂U∂T 是气体体积的内能相对于温度在恒定压力和体积下的偏导数。
- *Φ*A 和 *Φ*B 分别是端口 **A** 和 **B** 的能量流量。
- *Q*H 是端口 **H** 的热流量。

当您清除 **启用动态可压缩性** 复选框时，能量平衡为

ρ0⋅cp⋅V⋅dTdt=ΦA+ΦB+QH

其中：

- *cp* 是气体比热。
- *V* 是管道体积。
- *ρ0* 是气体密度。该模块从 **标称液体温度** 和 **标称液体压力** 参数计算此常数值。

### 完全气体和半完全气体模型的偏导数

气体体积的质量 *M* 和内能 *U* 相对于压力和在恒定体积下的温度的偏导数取决于气体属性模型。对于完全气体和半完全气体模型，方程为：

∂M∂p=VρIpI∂M∂T=−VρITI∂U∂p=V(hIZRTI−1)∂U∂T=VρI(cpI−hITI)

其中：

- *ρ*I 是气体体积的密度。
- *V* 是气体体积。
- *h*I 是气体体积的比焓。
- *Z* 是可压缩性因子。
- *R* 是比气体常数。
- *c*pI 是气体体积的定压比热。

### 真实气体模型的偏导数

对于真实气体模型，气体体积的质量 *M* 和内能 *U* 相对于压力和在恒定体积下的温度的偏导数为：

∂M∂p=VρIβI∂M∂T=−VρIαI∂U∂p=V(ρIhIβI−TIαI)∂U∂T=VρI(cpI−hIαI)

其中：

- *β* 是气体体积的等温体积模量。
- *α* 是气体体积的等压热膨胀系数。

### 动量平衡

管道每一半的动量平衡对由动量通量和黏性摩擦引起的压降进行建模。如果管道不对流体惯性建模，则管道每一半的动量平衡为

pA−pI=(m˙AS)2⋅(1ρI−1ρA)+ΔpAIpB−pI=(m˙BS)2⋅(1ρI−1ρB)+ΔpBI

其中：

- *p* 是端口 **A**、端口 **B** 或内部节点 I 处的气体压力，如下标所示。
- *ρ* 是端口 **A**、端口 **B** 或内部节点 I 处的密度，如下标所示。
- *S* 是管道的横截面积。
- *Δp*AI 和 *Δp*BI 是由黏性摩擦引起的压力损失。

当您选中 **启用流体惯性** 时，管道每一半的动量平衡有一个附加的惯性项

pA−pI=(m˙AS)2⋅(1ρI−1ρA)+ΔpAI+inertiaApB−pI=(m˙BS)2⋅(1ρI−1ρB)+ΔpBI+inertiaB

inertiaA=L2S⋅dm˙AdtinertiaB=L2S⋅dm˙Bdt

其中 *L* 是管道长度。

通过端口 **H** 与管壁交换的热量通过能量守恒方程（见能量平衡）添加到由内部节点表示的气体体积的能量中。因此，管道每一半的动量平衡（在端口 **A** 与内部节点之间以及在端口 **B** 与内部节点之间）被假定为绝热过程。绝热关系为：

hA+12(m˙AρAS)2=hI+12(m˙AρIS)2hB+12(m˙BρBS)2=hI+12(m˙BρIS)2

其中 *h* 是端口 **A**、端口 **B** 或内部节点 I 处的比焓，如下标所示。

由黏性摩擦引起的压力损失 *Δp*AI 和 *Δp*BI 取决于流态。管道每一半的雷诺数定义为：

ReA=|m˙A|⋅DhS⋅μIReB=|m˙B|⋅DhS⋅μI

其中：

- *D*h 是管道的水力直径。
- *μ*I 是内部节点处的动力黏度。

如果雷诺数小于 **层流上限雷诺数限制** 参数值，则流动处于层流流态。如果雷诺数大于 **湍流下限雷诺数限制** 参数值，则流动处于湍流流态。

在层流流态下，由黏性摩擦引起的压力损失为：

ΔpAIlam=fshapem˙A⋅μI2ρI⋅Dh2⋅S⋅L+Leqv2ΔpBIlam=fshapem˙B⋅μI2ρI⋅Dh2⋅S⋅L+Leqv2

其中：

- *f*shape 是 **层流黏性摩擦的形状因子** 参数值。
- *L*eqv 是 **局部阻力的总等效长度** 参数值。

在湍流流态下，由黏性摩擦引起的压力损失为：

ΔpAItur=fDarcyAm˙A⋅|m˙A|2ρI⋅Dh⋅S2⋅L+Leqv2ΔpBItur=fDarcyBm˙B⋅|m˙B|2ρI⋅Dh⋅S2⋅L+Leqv2

其中 *f*Darcy 是端口 **A** 或 **B** 处的 Darcy 摩擦因子，如下标所示。

Darcy 摩擦因子由 Haaland 关联式计算：

fDarcyA=[−1.8log10(6.9ReA+(εrough3.7Dh)1.11)]−2fDarcyB=[−1.8log10(6.9ReB+(εrough3.7Dh)1.11)]−2

其中 *ε*rough 是 **内表面绝对粗糙度** 参数值。

当雷诺数介于 **层流上限雷诺数限制** 和 **湍流下限雷诺数限制** 参数值之间时，流动处于层流与湍流之间的过渡状态。过渡区域中由黏性摩擦引起的压力损失在层流流态和湍流流态之间平滑连接。

QH=Qconv+kISsurfDh(TH−TI)

*S*surf 是管道表面积，
*S*surf =
4*S**L*/*D*h。

Qconv=|m˙avg|cpavg(TH−Tin)(1−exp(−hcoeffSsurf|m˙avg|cpavg))

其中：

- *T*in 是入口温度，取决于

- m˙avg=(m˙A−m˙B)/2 是从端口 **A** 到

- cpavg 是在平均温度下计算的比热。

换热系数 *h*coeff 取决于 Nusselt 数：

hcoeff=NukavgDh

Nutur=fDarcy8(Reavg−1000)Pravg1+12.7fDarcy8(Pravg2/3−1)

其中 *Pr*avg 是在平均温度下计算的 Prandtl 数。平均 Reynolds 数为

### 假设与限制

- 管壁完全刚性。
- 流动充分发展。摩擦损失和换热不包含入口效应。
- 重力影响可忽略。
- 此模块不对超声速流动建模。
