# Flow Resistance (MA)

## 端口

### 守恒

### **A** — 入口或出口湿空气

与流阻的入口或出口关联的湿空气守恒端口。此模块没有固有方向性。

### **B** — 入口或出口湿空气

与流阻的入口或出口关联的湿空气守恒端口。此模块没有固有方向性。

## 参数

### **标称压降** — 已知工作条件下的压降 `0.001 MPa`（默认）

在已知工作条件下从入口到出口的压降。该模块使用标称参数计算压降与质量流量之间的比例常数。

### **标称混合物质量流量** — 已知工作条件下的质量流量 `0.1 kg/s`（默认）

在已知工作条件下穿过模块的空气混合物质量流量。该模块使用标称参数计算压降与质量流量之间的比例常数。

### **标称混合物密度** — 已知工作条件下的密度 `0 kg/m^3`（默认）

在已知工作条件下流阻内部湿空气混合物的质量密度。该模块使用标称参数计算压降与质量流量之间的比例常数。将此参数设置为零可忽略压降对空气混合物密度的依赖性。

### **端口 A 和 B 处的横截面积** — 流阻端口处的流通面积 `0.01 m^2`（默认）

流阻端口处的流通面积。假定这些端口的尺寸相同。

### **用于层流过渡的标称混合物质量流量分数** — 阈值与标称质量流量的比值 `1e-3`（默认）

空气混合物的阈值质量流量与标称质量流量的比值。该模块使用此参数设置压降线性化的阈值。

## 描述

湿空气支路中的通用阻力

Flow Resistance (MA) 模块对湿空气网络分支中的通用压降进行建模。压降与混合物质量流量的平方成正比，并与混合物密度成反比。比例常数根据模块对话框中指定的标称工作条件确定。将 **标称混合物密度** 参数设置为零可忽略密度依赖性。

当有通过组件的压力损失和流量的经验数据，但详细几何信息不可用时，请使用此模块。

该模块方程使用以下符号。

|  |  |
| --- | --- |
| m˙ | 质量流量 |
| *Φ* | 能量流量 |
| *p* | 压力 |
| *ρ* | 密度 |
| *R* | 比气体常数 |
| *S* | 横截面积 |
| *K* | 比例常数 |
| *h* | 比焓 |
| *T* | 温度 |

下标 `a`、`w`、`d` 和 `g` 分别表示干空气、水蒸气、水滴和痕量气体的属性。下标 `A` 和 `B` 表示相应的端口。

质量平衡：

m˙A+m˙B=0m˙wA+m˙wB=0m˙gA+m˙gB=0m˙dA+m˙dB=0

能量平衡：

ΦA+ΦB=0

如果 **标称混合物密度** 参数值 *ρ*nom 大于零，则该模块按如下方式计算压降

pA−pB=K1m˙Am˙A2+(flamm˙nom)2RTinpin

其中：

- *f*lam 是用于层流过渡的标称混合物质量流量分数。
- *p*in 是入口压力（*p*A 或 *p*B，取决于流动方向）。
- *T*in 是入口温度（*T*A 或 *T*B，取决于流动方向）。

比例常数根据标称流动条件计算如下

K1=Δpnomρnomm˙nom2

如果 **标称混合物密度** 参数设置为零，则该模块按如下方式计算压降

pA−pB=K2m˙Am˙A2+(flamm˙nom)2

其中比例常数根据标称流动条件计算如下

K2=Δpnomm˙nom2

假定流阻是绝热的，因此混合物的比总焓相等

hA+12(m˙ARTASpA)2=hB+12(m˙BRTBSpB)2

### 假设和限制

- 该流阻是绝热的。它不与环境交换热量。
- 假定压降与混合物质量流量的平方成正比，与混合物密度成反比。
