# PS Lookup Table (4D)

## 端口

### 输入

### **x1** — 沿第一个轴的输入查询点或查询点的 N 维数组，untyped physical signal

沿第一个轴的输入查询点或查询点。信号大小可以是标量（用于单个查询点），也可以是表示沿第一个轴的查询点坐标的 N 维数组。

### **x2** — 沿第二个轴的输入查询点或查询点的 N 维数组，untyped physical signal

沿第二个轴的输入查询点或查询点。信号大小必须与沿第一个轴的信号大小匹配。

### **x3** — 沿第三个轴的输入查询点或查询点的 N 维数组，untyped physical signal

沿第三个轴的输入查询点或查询点。信号大小必须与沿第一个轴的信号大小匹配。

### **x4** — 沿第四个轴的输入查询点或查询点的 N 维数组，untyped physical signal

沿第四个轴的输入查询点或查询点。信号大小必须与沿第一个轴的信号大小匹配。

### 输出

### **f** — 输出函数值，untyped physical signal

输出函数值，基于将查找表应用于四个输入值。输出信号大小与沿第一个轴的输入信号大小匹配。输出信号单位由 **4D array of table values** 参数的单位决定。

## 参数

### **Table grid vector 1** — 沿第一个轴的数据值向量 `[1, 2, 3]`（默认）

将沿第一个轴的数据值向量指定为 1×`m` 数组。该向量必须严格单调，递增或递减。值可以是非均匀间隔的。对于平滑插值，向量必须至少包含三个值。对于线性插值，两个值就足够。

参数单位必须与端口 **x1** 处输入信号的单位一致。默认情况下，单位为 `1`（无单位）。您可以从下拉列表中选择其他单位，或键入所需的单位名称（如 `rpm`）或有效表达式（如 `rad/s`）。有关详细信息和单位缩写列表，请参阅《如何在模块对话框中指定单位》和《单位定义》。

### **Table grid vector 2** — 沿第二个轴的数据值向量 `[1, 2, 3, 4]`（默认）

将沿第二个轴的数据值向量指定为 1×`n` 数组。该向量必须严格单调，递增或递减。值可以是非均匀间隔的。对于平滑插值，向量必须至少包含三个值。对于线性插值，两个值就足够。

参数单位必须与端口 **x2** 处输入信号的单位一致。默认情况下，单位为 `1`（无单位）。您可以从下拉列表中选择其他单位，或键入所需的单位名称（如 `rpm`）或有效表达式（如 `rad/s`）。有关详细信息和单位缩写列表，请参阅《如何在模块对话框中指定单位》和《单位定义》。

### **Table grid vector 3** — 沿第三个轴的数据值向量 `[1, 2, 3]`（默认）

将沿第三个轴的数据值向量指定为 1×`p` 数组。该向量必须严格单调，递增或递减。值可以是非均匀间隔的。对于平滑插值，向量必须至少包含三个值。对于线性插值，两个值就足够。

参数单位必须与端口 **x3** 处输入信号的单位一致。默认情况下，单位为 `1`（无单位）。您可以从下拉列表中选择其他单位，或键入所需的单位名称（如 `rpm`）或有效表达式（如 `rad/s`）。有关详细信息和单位缩写列表，请参阅《如何在模块对话框中指定单位》和《单位定义》。

### **Table grid vector 4** — 沿第四个轴的数据值向量 `[1, 2, 3, 4, 5]`（默认）

将沿第四个轴的数据值向量指定为 1×`q` 数组。该向量必须严格单调，递增或递减。值可以是非均匀间隔的。对于平滑插值，向量必须至少包含三个值。对于线性插值，两个值就足够。

参数单位必须与端口 **x4** 处输入信号的单位一致。默认情况下，单位为 `1`（无单位）。您可以从下拉列表中选择其他单位，或键入所需的单位名称（如 `rpm`）或有效表达式（如 `rad/s`）。有关详细信息和单位缩写列表，请参阅《如何在模块对话框中指定单位》和《单位定义》。

### **4D array of table values** — 表网格顶点处函数值的四维数组 `ones(3, 4, 3, 5)`（默认）

将输出值指定为 `m`×`n`×`p`×`q` 数组，用于定义数据网格顶点处的函数值。数组大小必须与数据向量定义的维度匹配。

参数单位决定端口 **f** 处输出信号的单位。默认情况下，单位为 `1`（无单位）。您可以从下拉列表中选择其他单位，或键入所需的单位名称（如 `rpm`）或有效表达式（如 `rad/s`）。有关详细信息和单位缩写列表，请参阅《如何在模块对话框中指定单位》和《单位定义》。

### **Interpolation method** — 选择插值方法 `Linear`（默认） | `Smooth`

选择以下插值方法之一，用于在输入值位于两个连续网格点之间时逼近输出值：

- `Linear` — 使用多维插值的线性算法扩展。该方法先沿 *`x1`* 方向进行线性插值，然后沿 *`x2`* 方向，然后沿 *`x3`* 方向，再沿 *`x4`* 方向。选择此选项可获得最佳性能。
- `Smooth` — 使用改进的 Akima 插值算法。有关详细信息，请参阅 `tablelookup`。选择此选项可生成具有连续一阶导数的连续曲面。

### **Extrapolation method** — 选择外插方法 `Linear`（默认） | `Nearest` | `Error`

选择以下外插方法之一，用于在输入值位于参数列表指定范围之外时确定输出值：

- `Linear` — 从插值区域边缘进行线性延伸。线性外插的斜率等于插值区域边缘处插值曲面的斜率。
- `Nearest` — 从插值区域边缘按常量延伸。最近外插的值等于插值区域边缘处插值曲面的值。选择此选项可生成不会高于数据中最高点或低于数据中最低点的外插。
- `Error` — 如果任何输入信号超出表范围，则发出错误。当您希望数据位于表范围内时，选择此选项可避免进入外插模式。

## 描述

使用指定的查找方法逼近四维函数

PS Lookup Table (4D) 模块通过将输入查询点坐标与四维查找表进行插值，计算对某个函数 `f=f(x1,x2,x3,x4)` 的近似值。

您可以通过指定 **Table grid vector 1** 参数（沿第一个轴的数据点向量）、**Table grid vector 2** 参数（沿第二个轴的数据点向量）、**Table grid vector 3** 参数（沿第三个轴的数据点向量）、**Table grid vector 4** 参数（沿第四个轴的数据点向量）以及 **4D array of table values** 参数（输出值数组）来定义查找表。

表网格数据向量必须严格单调，递增或递减。制表函数值的数组大小必须与数据向量定义的维度匹配。也就是说，如果四个数据向量的大小分别为 1×`m`、1×`n`、1×`p` 和 1×`q`，则提供输出函数值的 `m`×`n`×`p`×`q` 数组。

模块的四个输入和输出是大小匹配的物理信号。模块基于输入查询和表网格查找，使用选定的插值和外插方法生成输出。您可以选择两种插值方法和两种外插方法。您还可以选择让模块在任何输入信号值超出相应表网格向量范围时发出错误。
