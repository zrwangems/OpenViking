# PS Lookup Table (1D)

## 端口

### 输入

### **x** — 沿 *x* 轴的输入查询点或 N 维查询点数组，untyped physical signal

沿 *x* 轴的输入查询点。信号大小要么是标量（表示单个查询点），要么是表示沿 *x* 轴查询点坐标的 N 维数组。

### 输出

### **f** — 输出函数值，untyped physical signal

输出函数值，基于将查找表应用于输入查询。输出信号大小与输入信号大小匹配。输出信号单位由 **表值** 参数的单位决定。

## 参数

### **表网格向量** — 沿 *x* 轴的数据点向量 `[1, 2, 3, 4, 5] 1`（默认）

指定沿 *x* 轴的数据点向量。该向量必须严格单调，即递增或递减。这些值可以非均匀间隔。对于平滑插值，该向量必须至少包含三个值。对于线性插值，两个值就足够了。

参数单位必须与端口 **x** 处输入信号的单位一致。默认情况下，单位为 `1`（无单位）。您可以从下拉列表中选择其他单位，也可以键入所需的单位名称（例如 `rpm`）或有效表达式（例如 `rad/s`）。有关更多信息以及单位缩写列表，请参阅如何在模块对话框中指定单位和单位定义。

### **表值** — 沿 *f* 轴的输出值向量 `[0, 1, 2, 3, 4] 1`（默认）

指定输出函数值的向量。函数值向量的大小必须与数据点向量的大小相同。

参数单位决定端口 **f** 处输出信号的单位。默认情况下，单位为 `1`（无单位）。您可以从下拉列表中选择其他单位，也可以键入所需的单位名称（例如 `rpm`）或有效表达式（例如 `rad/s`）。有关更多信息以及单位缩写列表，请参阅如何在模块对话框中指定单位和单位定义。

### **插值方法** — 选择插值方法 `Linear`（默认） | `Smooth`

当输入值位于两个连续网格点之间时，选择以下插值方法之一来逼近输出值：

- `Linear` — 使用线性函数。选择此选项可获得最佳性能。
- `Smooth` — 使用修改后的 Akima 插值算法。有关详细信息，请参阅 `tablelookup`。选择此选项可生成具有连续一阶导数的连续曲线。

### **外插方法** — 选择外插方法 `Linear`（默认） | `Nearest` | `Error`

当输入值超出自变量列表中指定的范围时，选择以下外插方法之一来确定输出值：

- `Linear` — 从插值区域的边缘进行线性延伸。线性外插的斜率等于插值区域边缘处插值曲线的斜率。
- `Nearest` — 从插值区域的边缘以常数方式延伸。最近外插的值等于插值区域边缘处插值曲线的值。选择此选项可生成不会高于数据中最高点或低于数据中最低点的外插。
- `Error` — 如果输入信号超出表的范围，则发出错误。当您希望数据位于表范围内时，选择此选项可避免进入外插模式。

## 描述

使用指定的查找方法逼近一维函数

PS Lookup Table (1D) 模块通过将输入查询点坐标与一维查找表进行插值，计算某个函数 `f=f(x)` 的近似值。

您通过指定 **表网格向量** 参数（沿 *x* 轴的数据点向量）和 **表值** 参数（对应函数值向量）来定义查找表。这两个向量的长度必须匹配。此外，`x` 数据向量必须严格单调，即递增或递减。

模块的输入和输出是大小匹配的物理信号。模块基于输入查询和表网格查找，使用选定的插值和外插方法生成输出。您可以选择两种插值方法和两种外插方法。您还可以选择让模块在输入信号值超出表网格向量范围时发出错误。

### 绘制表数据

绘制查找表可让您在仿真模型之前可视化数据，以确保表正确。绘图反映为模块指定的表格数据，以及选定的插值和外插选项。

要绘制数据，请在模型中右键单击该模块，然后从上下文菜单中选择 **Foundation Library** > **Plot Table**。有关更多信息，请参阅绘制查找表。
