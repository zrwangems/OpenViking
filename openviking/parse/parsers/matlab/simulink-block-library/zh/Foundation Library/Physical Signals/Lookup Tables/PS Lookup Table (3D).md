# PS Lookup Table (3D)

## 端口

### 输入

### **x1** — 沿第一轴的输入查询点或查询点 N 维数组，无类型物理信号

沿第一轴的输入查询点。信号大小要么是标量（用于单个查询点），要么是表示查询点沿第一轴坐标的 N 维数组。

### **x2** — 沿第二轴的输入查询点或查询点 N 维数组，无类型物理信号

沿第二轴的输入查询点。信号大小必须与沿第一轴的信号大小匹配。

### **x3** — 沿第三轴的输入查询点或查询点 N 维数组，无类型物理信号

沿第三轴的输入查询点。信号大小必须与沿第一轴的信号大小匹配。

### 输出

### **f** — 输出函数值，无类型物理信号

输出函数值，基于将查找表应用于三个输入值。输出信号大小与沿第一轴的输入信号大小匹配。输出信号单位由 **3D array of table values** 参数的单位确定。

## 参数

### **Table grid vector 1** — 沿第一轴的数据值向量 `[1, 2, 3] 1`（默认）

将沿第一轴的数据值向量指定为 1×`m` 数组。该向量必须严格单调，即递增或递减。这些值可以非均匀间隔。对于平滑插值，该向量必须至少包含三个值。对于线性插值，两个值就足够了。

参数单位必须与端口 **x1** 处输入信号的单位一致。默认情况下，单位为 `1`（无单位）。您可以从下拉列表中选择不同的单位，或键入所需的单位名称（如 `rpm`）或有效表达式（如 `rad/s`）。有关详细信息和单位缩写列表，请参阅如何在模块对话框中指定单位和单位定义。

### **Table grid vector 2** — 沿第二轴的数据值向量 `[1, 2, 3, 4] 1`（默认）

将沿第二轴的数据值向量指定为 1×`n` 数组。该向量必须严格单调，即递增或递减。这些值可以非均匀间隔。对于平滑插值，该向量必须至少包含三个值。对于线性插值，两个值就足够了。

参数单位必须与端口 **x2** 处输入信号的单位一致。默认情况下，单位为 `1`（无单位）。您可以从下拉列表中选择不同的单位，或键入所需的单位名称（如 `rpm`）或有效表达式（如 `rad/s`）。有关详细信息和单位缩写列表，请参阅如何在模块对话框中指定单位和单位定义。

### **Table grid vector 3** — 沿第三轴的数据值向量 `[1, 2, 3]` 1（默认）

将沿第三轴的数据值向量指定为 1×`p` 数组。该向量必须严格单调，即递增或递减。这些值可以非均匀间隔。对于平滑插值，该向量必须至少包含三个值。对于线性插值，两个值就足够了。

参数单位必须与端口 **x3** 处输入信号的单位一致。默认情况下，单位为 `1`（无单位）。您可以从下拉列表中选择不同的单位，或键入所需的单位名称（如 `rpm`）或有效表达式（如 `rad/s`）。有关详细信息和单位缩写列表，请参阅如何在模块对话框中指定单位和单位定义。

### **3D array of table values** — 表网格顶点处的函数值三维数组 `ones(3, 4, 3)` 1（默认）

将输出值指定为 `m`×`n`×`p` 数组，用于定义数据网格顶点处的函数值。数组大小必须与数据向量定义的维度匹配。

参数单位决定端口 **f** 处输出信号的单位。默认情况下，单位为 `1`（无单位）。您可以从下拉列表中选择不同的单位，或键入所需的单位名称（如 `rpm`）或有效表达式（如 `rad/s`）。有关详细信息和单位缩写列表，请参阅如何在模块对话框中指定单位和单位定义。

### **Interpolation method** — 选择插值方法 `Linear`（默认）| `Smooth`

选择以下插值方法之一，用于在输入值位于两个连续网格点之间时逼近输出值：

- `Linear` — 使用多维插值的线性算法扩展。该方法先沿 *`x1`* 方向、然后沿 *`x2`* 方向、再沿 *`x3`* 方向执行线性插值。选择此选项可获得最佳性能。
- `Smooth` — 使用修改的 Akima 插值算法。有关详细信息，请参阅 `tablelookup`。选择此选项可生成具有连续一阶导数的连续曲面。

### **Extrapolation method** — 选择外推方法 `Linear`（默认）| `Nearest` | `Error`

选择以下外推方法之一，用于在输入值位于参数列表中指定的范围之外时确定输出值：

- `Linear` — 从插值区域的边缘线性延伸。线性外推的斜率等于插值曲面在插值区域边缘处的斜率。
- `Nearest` — 从插值区域的边缘作为常数延伸。最近邻外推的值等于插值曲面在插值区域边缘处的值。选择此选项可生成不会高于数据中最高点或低于数据中最低点的外推。
- `Error` — 如果任何输入信号超出表的范围，则发出错误。当您希望数据位于表范围内时，选择此选项可避免进入外推模式。

## 描述

使用指定的查找方法逼近三维函数

PS Lookup Table (3D) 模块通过针对三维查找表对输入查询点坐标进行插值，计算某个函数 `f=f(x1,x2,x3)` 的近似值。

您通过指定 **Table grid vector 1** 参数（沿第一轴的数据点向量）、**Table grid vector 2** 参数（沿第二轴的数据点向量）、**Table grid vector 3** 参数（沿第三轴的数据点向量）以及 **3D array of table values** 参数（输出值数组）来定义查找表。

表网格数据向量必须严格单调，即递增或递减。制表函数值的数组大小必须与数据向量定义的维度匹配。也就是说，如果三个数据向量的大小分别为 1×`m`、1×`n` 和 1×`p`，则提供输出函数值的 `m`×`n`×`p` 数组。

模块的三个输入和输出是大小匹配的物理信号。模块基于输入查询和表网格查找，使用所选的插值方法和外推方法生成输出。您可以选择两种插值方法和两种外推方法。您还可以选择让模块在任何输入信号值超出相应的表网格向量范围时发出错误。
