# PS Scattered Lookup Table (2D)

## 端口

### 输入

### **x1** — 沿第一个方向的输入查询点或查询点的 N 维数组，无类型物理信号

沿第一个方向的查询输入值，指定为标量或 N 维数组。

### **x2** — 沿第二个方向的输入查询点或查询点的 N 维数组，无类型物理信号

沿第二个方向的查询输入值，指定为标量或 N 维数组。信号大小必须与沿第一个方向的信号大小匹配。

### 输出

### **f** — 输出函数值，无类型物理信号

输出函数值，基于将散点查找方法应用于两个输入值。输出信号大小与沿第一个方向的输入信号大小匹配。输出信号单位由 **数据点函数值** 参数的单位决定。

## 参数

### **数据点坐标 1** — 沿第一个方向的输入值数据集 `[1, 2, 3, 4, 5] 1`（默认值）

沿第一个方向的输入值数据集，指定为一维数组。至少指定三个值。

参数单位必须与端口 **x1** 处输入信号的单位一致。默认情况下，单位为 `1`（无单位）。可以从下拉列表中选择其他单位，或键入所需的单位名称（如 `rpm`），或键入有效的表达式（如 `rad/s`）。有关更多信息和单位缩写列表，请参阅如何在模块对话框中指定单位和单位定义。

### **数据点坐标 2** — 沿第二个方向的输入值数据集 `[7, 6, 3, 2, 9] 1`（默认值）

沿第二个方向的输入值数据集，指定为与 **数据点坐标 1** 大小相同的一维数组。

参数单位必须与端口 **x2** 处输入信号的单位一致。默认情况下，单位为 `1`（无单位）。可以从下拉列表中选择其他单位，或键入所需的单位名称（如 `rpm`），或键入有效的表达式（如 `rad/s`）。有关更多信息和单位缩写列表，请参阅如何在模块对话框中指定单位和单位定义。

### **数据点函数值** — 查找的数据点函数值集 `[1, 2, 3, 4, 5] 1`（默认值）

用于查找的数据点函数值集，指定为与 **数据点坐标 1** 大小相同的一维数组。

参数单位决定端口 **f** 处输出信号的单位。默认情况下，单位为 `1`（无单位）。可以从下拉列表中选择其他单位，或键入所需的单位名称（如 `rpm`），或键入有效的表达式（如 `rad/s`）。有关更多信息和单位缩写列表，请参阅如何在模块对话框中指定单位和单位定义。

### **外插方法** — 选择外插方法 `Linear`（默认值） | `Nearest`

当输入值位于数据集的凸包之外时，选择用于计算输出值的近似方法：

- `Linear` — 基于边界梯度的
  线性外插。
- `Nearest` — 最近邻外插。
  此方法求值为边界上最近邻的值。

## 描述

使用散点数据查找近似二维函数

PS Scattered Lookup Table (2D) 模块在给定二维空间中散点输入数据点集的坐标以及每个数据点处的函数值时，计算对某个函数 `f=f(x1,x2)` 的近似值。两个输入和输出都是物理信号。输入指定查询点在两个方向上的坐标。输出是对应于输入查询点的计算所得函数值。

该模块使用 Delaunay 三角剖分将查询输入值与一个非结构化（即散点）数据点集进行插值，从而计算输出值。通过指定 **数据点坐标 1** 参数（沿第一个方向的数据点坐标向量）、**数据点坐标 2** 参数（这些相同数据点沿第二个方向的坐标向量）以及 **数据点函数值**（对应于每个数据点的函数值向量）来定义查找表。所有三个向量的大小必须相同。
