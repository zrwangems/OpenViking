# Rotational Mechanical Converter (2P)

## 端口
```yaml
ports: []
```

该模块具有以下端口：

`A`
:   与转换器入口相关联的两相流体守恒端口。

`H`
:   表示转换器表面的热守恒端口，通过该表面进行热交换。

`R`
:   与转换器转子相关联的机械旋转守恒端口。

`C`
:   与转换器壳体相关联的机械旋转守恒端口。

`P`
:   物理信号输入端口，用于传递来自 Simscape™ Multibody™ 关节的位置信息。将此端口连接到关节的位置传感端口 **q**。有关详细信息，请参阅 Connecting Simscape Networks to Simscape Multibody Joints。要启用此端口，请将 **Interface rotation** 参数设置为 `Provide input signal from Multibody joint`。

### 参数选项卡

**机械方向**
:   运动界面相对于转换器中流体体积的对齐方式：

    - `A 处压力导致 R 相对于 C 正向旋转` — 流体体积增加导致端口 **R** 相对于端口 **C** 正向旋转。
    - `A 处压力导致 R 相对于 C 负向旋转` — 流体体积增加导致端口 **R** 相对于端口 **C** 负向旋转。

**界面旋转**
:   选择确定端口 **R** 相对于端口 **C** 旋转的方法：

    - `根据端口 R 相对于端口 C 的速度计算` — 基于模块方程，从相对端口速度计算旋转。这是默认方法。
    - `从 Multibody 关节提供输入信号` — 启用输入物理信号端口 **q**，以传递来自 Multibody 关节的旋转信息。仅当使用 Rotational Multibody Interface 模块将转换器连接到 Multibody 关节时，才使用此方法。有关详细信息，请参阅如何传递位置信息。

**初始界面旋转**
:   仿真开始时运动界面的角度。零角度对应于转换器中的总流体体积等于指定的死区体积。默认值为 `0` rad。

    - 如果 **机械方向** 为 `A 处压力导致 R 相对于 C 正向旋转`，则参数值必须大于或等于 0。
    - 如果 **机械方向** 为 `A 处压力导致 R 相对于 C 负向旋转`，则参数值必须小于或等于 0。

    当 **界面旋转** 设置为 `根据端口 R 相对于端口 C 的速度计算` 时，此参数启用。

**界面体积排量**
:   运动界面每单位旋转所排出的流体体积。默认值为 `0.01 m^3`/rad。

**死区体积**
:   当界面角度为零时，转换器中剩余的流体体积。死区体积使模块即使在界面角度为零时也能考虑转换器中的质量和能量存储。默认值为 `1e-5` m^3。

**端口 A 处的横截面积**
:   转换器入口的流通面积，由端口 **A** 表示。忽略由于转换器内部流通面积变化引起的压力损失。默认值为 `0.01` m^2。

**环境压力设定**
:   周围环境的压力特性。选择 `大气压力` 将环境压力设置为 Two-Phase Fluid Properties (2P) 模块中指定的大气压力。选择 `指定压力` 将环境压力设置为不同的值。默认设置为 `大气压力`。

**环境压力**
:   周围环境的绝对压力。环境压力作用于转换器的内部压力，并影响转换器轴的运动。仅当 **环境压力设定** 参数设置为 `指定压力` 时，此参数才激活。默认值 `0.101325` MPa 对应于平均海平面的大气压力。

### 效应和初始条件选项卡

**初始流体能量设定**
:   用于定义组件初始条件的热力学变量。默认设置为 `Temperature`。

**初始压力**
:   仿真开始时腔室内的压力，相对于绝对零压指定。默认值为 `0.101325` MPa。

**初始温度**
:   仿真开始时腔室内的温度，相对于绝对零度指定。当**初始流体能量设定**选项设置为 `Temperature` 时，此参数处于激活状态。默认值为 `293.15` K。

**初始蒸汽干度**
:   仿真开始时腔室内蒸汽的质量分数。当**初始流体能量设定**选项设置为 `Vapor quality` 时，此参数处于激活状态。默认值为 `0.5`。

**初始蒸汽空隙率**
:   仿真开始时腔室内蒸汽的体积分数。当**初始流体能量设定**选项设置为 `Vapor void fraction` 时，此参数处于激活状态。默认值为 `0.5`。

**初始比焓**
:   仿真开始时腔室内流体的比焓。当**初始流体能量设定**选项设置为 `Specific enthalpy` 时，此参数处于激活状态。默认值为 `1500` kJ/kg。

**初始比内能**
:   仿真开始时腔室内流体的比内能。当**初始流体能量设定**选项设置为 `Specific internal energy` 时，此参数处于激活状态。默认值为 `1500` kJ/kg。

**相变时间常数**
:   相变事件的持续时间特征值。该常数在相之间的过渡中引入时间滞后。默认值为 `0.1` s。

## 描述

两相流体与机械旋转网络之间的接口

Rotational Mechanical Converter (2P) 模块建模两相流体与机械旋转网络之间的接口。该接口将流体网络中的压力转换为机械旋转网络中的扭矩，反之亦然。

该模块使您能够建模由两相流体系统驱动的旋转执行器。然而，它不考虑旋转执行器中常见的惯性、摩擦或硬限位。您可以使用 Simscape 模块（如 Inertia、Rotational Friction 和 Rotational Hard Stop）单独建模这些效应。

端口 A 表示流体进入和离开转换器的入口。端口 C 和 R 分别表示转换器壳体和运动接口。端口 H 表示转换器与其周围环境进行热交换的壁面。

### 扭矩方向

扭矩方向取决于转换器的机械方向。如果 **Mechanical Orientation** 参数为正，则通过入口的正流量倾向于使运动接口相对于转换器壳体沿正方向旋转。

**正机械方向**

如果 **Mechanical Orientation** 参数为负，则通过入口的正质量流量倾向于使运动接口相对于转换器壳体沿负方向旋转。

### 流动阻力和热阻

端口 A 与转换器内部之间的流动阻力假定可忽略不计。两者之间的压力损失近似为零。因此，端口 A 处的压力等于转换器内的压力：

pA=pI，

其中：

- *p*A 是端口 A 处的压力。
- *p*I 是转换器内的压力。

类似地，端口 H 与转换器内部之间的热阻假定可忽略不计。两者之间的温度梯度近似为零。因此，端口 H 处的温度等于转换器内的温度：

TH=TI，

其中：

- *T*H 是端口 H 处的温度。
- *T*I 是转换器内的温度。

### 流体体积

转换器中的流体体积是死区流体体积与排量流体体积之和。死区体积是当接口角为零时留在转换器中的流体量。该体积使您即使在接口处于零位时也能对动态可压缩性和热容效应进行建模。

排量体积是由于运动接口的旋转而添加到转换器中的流体量。该体积随接口角增大而增加。转换器中作为接口角函数的总体积为

V=Vdead+Dvolθintϵor，

其中：

- *V* 是转换器中流体的总体积。
- *V*dead 是转换器的死区体积。
- *D*vol 是接口每单位旋转的排量流体体积。
- *θ*int 是运动接口的旋转角。
- *∊*or 是转换器的机械方向（如果流体压力增加导致 R 相对于 C 正向旋转，则为 `1`；如果流体压力增加导致 R 相对于 C 负向旋转，则为 `-1`）。

如果将转换器连接到 Multibody 关节，请使用物理信号输入端口 **q** 来指定端口 **R** 相对于端口 **C** 的旋转。否则，模块将根据模块方程从相对端口角速度计算接口旋转。当流体体积等于死区体积时，接口旋转为零。然后，根据 **Mechanical orientation** 参数值：

- 如果为 `Pressure at A causes positive rotation of R relative to C`，则当流体体积从死区体积增加时，接口旋转增大。
- 如果为 `Pressure at A causes negative rotation of R relative to C`，则当流体体积从死区体积增加时，接口旋转减小。

### 力平衡

在平衡状态下，转换器中的内部压力抵消其周围环境的外部压力以及机械网络施加在运动接口上的扭矩。该扭矩与流体网络施加的扭矩方向相反。因此，转换器中的扭矩平衡为

pIDvol=patmDvol−tintϵor，

其中：

- *p*atm 是转换器外部的环境压力。
- *t*int 是流体网络施加在运动接口上的扭矩大小。

### 能量平衡

转换器中的总能量可能因通过入口的能量流、通过转换器壁的热流以及作用在机械网络上的功而变化。因此，由能量守恒方程给出的能量流率为

E˙=ϕA+ϕH−pIDvolθ˙intϵor，

其中：

- E 是转换器中流体的总能量。
- *ϕ*A 是通过端口 A 流入转换器的能量流率。
- *ϕ*H 是通过端口 H 流入转换器的热流率。

将转换器中的流体动能视为可忽略不计，流体的总能量简化为：

E=MuI，

其中：

- *M* 是转换器中的流体质量。
- *u*I 是转换器中流体的比内能。

### Mass Balance

转换器中的流体质量会因通过入口（由端口 A 表示）的流动而发生变化。因此，由质量守恒方程给出的质量流量为

M˙=m˙A，

其中：

- m˙A 是通过端口 A 流入转换器的质量流量。

流体质量的变化可能伴随流体体积的变化，这是由于运动界面的旋转所致。它也可能伴随质量密度的变化，这是由于转换器中压力或比内能的演变所致。转换器中的质量变化率为

M˙=[(∂ρ∂p)up˙I+(∂ρ∂u)pu˙I]V+Dvolθ˙intϵorvI，

其中：

- (∂ρ∂p)u 是在比内能恒定时密度对压力的偏导数。
- (∂ρ∂u)p 是在压力恒定时密度对比内能的偏导数。
- *v*I 是转换器中流体的比体积。

该模块使用三次多项式函数混合各域的密度偏导数。在蒸汽干度为 0–0.1 时，该函数混合过冷液体域和两相混合物域的导数。在蒸汽干度为 0.9–1 时，它混合两相混合物域和过热蒸汽域的导数。

平滑后的密度偏导数会在原始质量守恒方程中引入不良的数值误差。为修正这些误差，该模块添加修正项

ϵM=M−V/vIτ，

其中：

- *∊*M 是修正项。
- *τ* 是相变时间常数——相变事件的特征持续时间。该常数确保相变不会瞬时发生，从而在每次相变发生时有效地引入时间滞后。

质量守恒方程的最终形式为

[(∂ρ∂p)up˙I+(∂ρ∂u)pu˙I]V+Dvolθ˙intϵorvI=m˙A+ϵM。

该模块使用此方程，根据通过入口的质量流量计算转换器中的内部压力。
