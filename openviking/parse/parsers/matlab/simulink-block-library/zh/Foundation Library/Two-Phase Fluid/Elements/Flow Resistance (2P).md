# Flow Resistance (2P)

## 端口

### 守恒

### **A** — 流动阻力两相流体端口

两相流体通过该端口进入或离开流动阻力。

### **B** — 流动阻力两相流体端口

两相流体通过该端口进入或离开流动阻力。

## 参数

### **标称压降** — 已知工作条件下的压降 0.001 MPa（默认值）| 具有压力单位的标量

已知工作条件下从入口到出口的压降。该模块使用标称参数计算压降与质量流量之间的比例常数。

### **标称质量流量** — 已知工作条件下的质量流量 0.1 kg/s（默认值）| 具有质量/时间单位的标量

已知工作条件下通过组件的质量流量。该模块使用标称参数计算压降与质量流量之间的比例常数。

### **标称比容** — 已知工作条件下的比容 0 m^3/kg（默认值）| 具有体积/质量单位的标量

已知工作条件下流动阻力内部的比容。该模块使用标称参数计算压降与质量流量之间的比例常数。将此参数设置为零可忽略压降对比容的依赖性。

### **端口 A 和 B 处的横截面积** — 流动阻力端口处的流通面积 0.01 m^2（默认值）| 具有面积单位的标量

流动阻力端口处的流通面积。假设这些端口的尺寸相同。

### **层流的标称质量流量分数** — 阈值与标称质量流量的比率 1e-3（默认值）| 无量纲标量

阈值质量流量与标称质量流量的比率。该模块使用此参数计算阈值质量流量，并最终设置压降的线性化限值。

### 变量

### **Mass flow rate into port A** — 通过端口 A 进入流动阻力的质量流量 293.15 K（默认值）| 具有温度单位的正标量

## 描述

两相流体支路中的一般阻力

Flow Resistance (2P) 模块对两相流体网络支路中的一般压降进行建模。压降与质量流量的平方以及两相流体的密度成正比。比例常数由模块对话框中指定的标称工作条件确定。

当组件唯一可用的数据是其压降随质量流量变化的函数时，请使用此模块。将此模块与其他模块组合，以创建更准确地捕获其引起的压降的自定义组件——例如，基于腔室模块的热交换器。

### 质量平衡

假设流动阻力内部的流体体积可忽略不计。则通过一个端口流入的质量流量必须恰好等于通过另一个端口流出的质量流量：

m˙A+m˙B=0,

其中 m˙A 和 m˙B 分别定义为通过端口 **A** 和 **B** 进入组件的质量流量。

### 能量平衡

能量只能通过两相流体端口进入和离开流动阻力。壁面与环境之间不发生热交换。此外，不对流体做功，流体也不对外做功。则通过一个端口流入的能量流率必须恰好等于通过另一个端口流出的能量流率：

ϕA+ϕB=0,

其中 *ϕ*A 和 *ϕ*B 是通过端口 **A** 和 **B** 进入流动阻力的能量流率。

### 动量平衡

流体上相关的外部力包括由端口处压力引起的力以及由组件壁面处粘性摩擦引起的力。重力以及其他体积力均被忽略。用损失因子 *ξ* 表示摩擦力，可得到以下半经验表达式：

Δp=ξνm˙22S2,

其中：

- *Δp* 是从端口 **A** 到端口 **B** 的压降——即 *p*A +
  *p*B。
- *ξ* 是损失因子。
- *ν* 是比容，即质量密度 *ρ* 的倒数——即 *1/**ρ*。
- *S* 是流通面积。

压降方程的实现进行了两项修改。首先，为了在流动方向反转时允许符号变化，将其重写为：

Δp=ξνm˙|m˙|2S2,

其中压降仅在质量流量也为正时才为正。其次，为消除由流动反转引起的奇异性——这些奇异性可能在仿真期间给数值求解器带来挑战——在接近零流量的一个小区域内将其线性化：

Δp=ξνm˙m˙2+​m˙Th22S2,

其中 m˙Th 是阈值质量流量，低于该值时压降被线性化。图中显示了修改后的压降随局部质量流量的变化（曲线 **I**）：

- 高于 m˙Th 时，压降近似于原始方程所表达的值（曲线 **II**），并且随 m˙2 变化。这种依赖性与湍流中观察到的一致。
- 低于 m˙Th 时，压降近似为一条直线，其斜率部分取决于 m˙Th（曲线 **III**），并且随 m˙ 变化。这种依赖性与层流中观察到的一致。

为便于建模，不需要将损失因子 *ξ* 作为模块参数。相反，它会根据模块对话框中指定的标称条件自动计算：

ξ2S2=Δp\*ν\*m˙\*2,

其中星号 (\*) 表示标称工作条件下的值。所有这些计算的基础都是假设阈值质量流量 m˙Th 远小于标称值 m˙\*。将压降表达式中的分数 *ξ*/(2S2) 替换后得到：

Δp=νΔp\*ν\*m˙\*2(m˙m˙2+m˙Th2).

或等价地：

Δp=Cνm˙m˙2+m˙Th2,

其中 *C* 是流动阻力两端压降与局部质量流量之间的比例常数。其定义为：

C=Δp\*ν\*m˙\*2.

如果假设比容——因而质量密度——不变，则其标称值和实际值必须始终相等。当在模块对话框中将标称值指定为 `0` 时就是这种情况——`0` 是一个特殊值，用于向模块表明比容为常数。此时两者之比为 `1`，乘积 *C**ν* 简化为：

Cν=Δp\*m˙\*2.
