# Local Restriction (2P)

## 端口
```yaml
ports:
- name: AR
  summary: 节流面积控制信号，m^2 物理信号
  direction: input
- name: A
  summary: 入口或出口两相流体
  direction: input
- name: B
  summary: 入口或出口两相流体
  direction: input
```

### 输入

### **AR** — 节流面积控制信号，m^2 物理信号

控制节流面积的输入物理信号。当该信号的值超出**最小节流面积**和**最大节流面积**参数指定的节流面积上下限时，信号将饱和。

#### 依赖关系

要启用此端口，请将**节流类型**参数设置为 `Variable`。
### 守恒

### **A** — 入口或出口两相流体

与局部节流入口或出口相关联的两相流体守恒端口。该模块没有固有方向性。

### **B** — 入口或出口两相流体

与局部节流入口或出口相关联的两相流体守恒端口。该模块没有固有方向性。

### **节流类型** — 节流面积是否可以在仿真过程中变化 `Variable`（默认）| `Fixed`

节流面积是否可以在仿真过程中变化：

- `Variable` — 端口 **AR** 处的输入物理信号指定节流面积，该面积可以在仿真过程中变化。**最小节流面积**和**最大节流面积**参数指定节流面积的上下限。
- `Fixed` — 由**节流面积**模块参数值指定的节流面积在仿真过程中保持恒定。

### **最小节流面积** — 节流横截面积的下限 `1e-10 m^2`（默认）| 正标量

节流横截面积的下限。您可以使用此参数表示泄漏面积。端口 **AR** 处的输入信号在该值处饱和，以防止节流面积进一步减小。

#### 依赖关系

要启用此参数，请将**节流类型**设置为 `Variable`。

### **最大节流面积** — 节流横截面积的上限 `0.005 m^2`（默认）| 正标量

节流横截面积的上限。端口 **AR** 处的输入信号在该值处饱和，以防止节流面积进一步增大。

#### 依赖关系

要启用此参数，请将**节流类型**设置为 `Variable`。

### **节流面积** — 节流处垂直于流动路径的面积 `1e-3 m^2`（默认）| 正标量

节流处垂直于流动路径的面积。

#### 依赖关系

要启用此参数，请将**节流类型**设置为 `Fixed`。

### **压力损失模型** — 动量平衡计算是否假设均匀流体密度 `Bernoulli`（默认）| `Control volume`

用于动量平衡计算的方程：

- `Bernoulli` — 该模块使用伯努利方程，假设从入口到出口密度均匀。此选项有时不如 `Control volume` 方法精确，但更稳健且仿真速度更快。
- `Control volume` — 该模块使用控制体分析，不假设密度均匀。它将从入口到节流处的流动建模为流动收缩，将从节流处到出口的流动建模为流动膨胀。

### **端口 A 和 B 处的横截面积** — 端口处垂直于流动路径的面积 `0.01 m^2`（默认）| 正标量

端口 **A** 和 **B** 处垂直于流动路径的面积。假设两个端口的该面积相同。

### **流量系数** — 通过节流的实际质量流量与理论质量流量之比 `0.64`（默认）| 0 到 1 之间的无量纲标量

流量系数是一种半经验参数，通常用于表征孔口的流通能力。该参数表示通过孔口的实际质量流量与理想质量流量之比。

### **Laminar flow pressure ratio** — 用于在层流和湍流状态之间切换的压力比 `0.999`（默认值）| 0 到 1 之间的无量纲标量

出口压力与入口端口压力之比，在该比值下假定流态从层流切换为湍流。当前流态决定仿真中使用的方程。如果流动为层流，则通过限流口的压降与质量流量成线性关系。如果流动为湍流，则通过限流口的压降与质量流量成二次关系。

## 版本历史

**在 R2015b 中引入**

### R2024a：使用伯努利方程计算压力损失

Local Restriction (2P) 模块现在具有 **Pressure loss model** 参数，可让您在两种压力损失模型之间进行选择。`Control volume` 选项是以前版本中可用的功能，在某些场景下更准确。新的 `Bernoulli` 选项假定从入口到出口的流体密度均匀，更稳健，并且提供更快的仿真。

此更改没有兼容性影响。`Bernoulli` 选项是新模块的默认设置，但当您打开现有模型时，其中的 Local Restriction (2P) 模块会自动将 **Pressure loss model** 参数设置为 `Control volume`。

### R2022b：对固定面积和可变面积限流口建模

Local Restriction (2P) 模块现在具有 **Restriction type** 参数，可让您在固定面积和可变面积限流口建模之间切换。该模块使用 **Restriction area** 参数或输入物理信号端口 **AR** 来指定局部限流口的面积。

在以前的版本中，该模块仅对固定限流口建模。Two-Phase Fluid 库还包含一个单独的 Variable Local Restriction (2P) 模块，该模块已不再可用。此更改没有兼容性影响。当您打开现有模型时，其中的所有 Variable Local Restriction (2P) 模块都会自动替换为具有暴露控制端口 **AR** 的 Local Restriction (2P) 模块。

## 描述

两相流体网络中的流通面积限制

Local Restriction (2P) 模块用于对两相流体网络中因流通面积局部缩小（例如阀门或孔板）而产生的压降进行建模。

端口 **A** 和 **B** 分别表示限制的入口和出口。端口 **AR** 处的输入物理信号用于指定限制面积。或者，您也可以将固定限制面积指定为模块参数。

模块图标会根据 **Restriction type** 参数的值而变化。

| 限制类型 | 模块图标 |
| --- | --- |
| `Variable` | Variable Local Restriction (2P) 模块图标 |
| `Fixed` | Fixed Local Restriction (2P) 模块图标 |

该限制是绝热的。它不与环境交换热量。

该限制由一次收缩以及随后的流通面积突然扩张组成。

**局部限制示意图**

流体流过局部限制

流体在收缩期间加速，这会导致压力下降。在通过限制并伴随一定动量损失后，流体膨胀并在朝向出口的方向上减速，使压力在限制之后略有回升。该压力损失模型对应于 **Pressure loss model** 参数的 `Control volume` 选项。它提供更好的精度，但相比默认的 `Bernoulli` 选项鲁棒性和效率更低，后者假设限制入口与出口之间流体密度均匀。

在以下情况下使用 `Bernoulli` 选项：

- 局部限制在完全过冷液体状态下运行。流体近似不可压缩，均匀密度假设是合适的。
- 局部限制用作制冷循环中的膨胀阀。入口处的流体是从冷凝器出来的过冷液体，因此均匀密度假设是合适的。
- 局部限制在完全过热蒸汽状态下运行，但流速为低声速，这通常是 HVAC 系统中的情况。在这种情况下，密度也不会发生太大变化，均匀密度假设是合适的。

对于所有其他情况，您也可以使用 `Bernoulli` 选项，以精度换取更快、更鲁棒的仿真。

### 质量平衡

质量平衡方程为

m˙A+m˙B=0，

其中：

- m˙A 和 m˙B 是分别通过端口 **A** 和端口 **B** 流入限制的质量流量。

### 能量平衡

能量平衡方程为

ϕA+ϕB=0，

其中 *ϕ*A 和 *ϕ*B 是分别通过端口 **A** 和端口 **B** 流入限制的能量流量。

假设局部限制是绝热的，因此比总焓的变化为零。在端口 **A** 处，

uA+pAνA+wA22=uR+pRνR+wR22，

而在端口 **B** 处，

uB+pBνB+wB22=uR+pRνR+wR22，

其中：

- *u*A、*u*B 和 *u*R 分别是端口 **A**、端口 **B** 和限制孔口处的比内能。
- *p*A、*p*B 和 *p*R 分别是端口 **A**、端口 **B** 和限制孔口处的压力。
- *ν*A、*ν*B 和 *ν*R 分别是端口 **A**、端口 **B** 和限制孔口处的比体积。
- *w*A、*w*B 和 *w*R 分别是端口 **A**、端口 **B** 和限制孔口处的理想流速。

该模块计算理想流速如下：

在端口 **A** 处为

wA=m˙idealνAS，

在端口 **B** 处为

wB=m˙idealνBS，

在限制内部为

wR=m˙idealνRSR，

其中：

- m˙ideal 是通过限制的理想质量流量。
- *S* 是端口 **A** 和端口 **B** 处的流通面积。
- *S*R 是限制孔口的流通面积。

该模块计算通过限制的理想质量流量如下：

m˙ideal=m˙ACD，

其中 *C*D 是局部限制的流量排放系数。

### 使用伯努利方程时的动量平衡

从端口 **A** 到端口 **B** 的质量流量为：

m˙A=CdSRΔp(Δp+Δplam2)1/42νinPRloss(1−(SRS)2),Δp=pA−pB,

其中：

- *Δp*lam 是阈值压降，在该压降下流动开始在层流和湍流之间平滑过渡。
- *v*in 是入口比容。哪个端口作为入口、哪个端口作为出口取决于节流口两侧的压差。如果端口 **A** 处的压力大于端口 **B** 处的压力，则端口 **A** 是入口；如果端口 **B** 处的压力更大，则端口 **B** 是入口。
- *PR*loss 是压力损失比。

压力损失比 *PR*loss 是入口与出口之间的压差与入口与节流口之间的压差之比。它是一个用于考虑节流口后流动膨胀过程中压力恢复的项：

PRloss=1−(SRS)2(1−Cd2)−CdSRS1−(SRS)2(1−Cd2)+CdSRS。

### 使用控制体分析时的动量平衡

对于湍流，从端口 **A** 到端口 **B** 的质量流量为：

m˙A=CdSRΔp2|Δp|νRKT。

*K*T 定义为：

KT=(1+SRS)(1−νinνRSRS)−2SRS(1−νoutνRSRS),

其中下标 `in` 表示入口端口，下标 `out` 表示出口端口。哪个端口作为入口、哪个端口作为出口取决于节流口两侧的压差。如果端口 **A** 处的压力大于端口 **B** 处的压力，则端口 **A** 是入口；如果端口 **B** 处的压力更大，则端口 **B** 是入口。

对于层流，从端口 **A** 到端口 **B** 的质量流量为：

m˙A=CdSRΔp2ΔplamνR(1−SRS)2。

*Δp*lam 表示阈值压降，在该压降下流动开始在层流和湍流之间平滑过渡：

Δplam=(pA+pB2)(1−Blam),

其中 *B*lam 是 **Laminar flow pressure ratio** 参数。如果从端口 **A** 到端口 **B** 的压降低于阈值，则流动为层流；否则，流动为湍流。

节流口面积处的压力 *p*R 也取决于流态。当流动为湍流时：

pR,T=pin−νR2(m˙ACdSR)2(1+SRS)(1−νinνRSRS)。

当流动为层流时：

pR,L=pA+pB2。

### 假设和限制

- 节流口是绝热的。它不与周围环境交换热量。
- `Bernoulli` 压力损失模型假设节流口入口和出口之间的流体密度均匀。
