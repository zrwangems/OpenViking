# Translational Mechanical Converter (2P)

## 端口
```yaml
ports: []
```

该模块具有以下端口：

`A`
:   与转换器入口相关联的两相流体守恒端口。

`H`
:   表示转换器表面的热守恒端口，通过该表面进行热交换。

`R`
:   与转换器杆相关联的机械平移守恒端口。

`C`
:   与转换器壳体相关联的机械平移守恒端口。

`P`
:   物理信号输入端口，用于传递来自 Simscape Multibody™ 关节的位置信息。将此端口连接到关节的位置传感端口 **p**。有关详细信息，请参阅 Connecting Simscape Networks to Simscape Multibody Joints。要启用此端口，请将 **Interface displacement** 参数设置为 `Provide input signal from Multibody joint`。

### 参数选项卡

**机械方向**
:   运动界面相对于转换器中流体体积的对齐方式：

    - `A 处压力导致 R 相对于 C 产生正位移` — 流体体积增加导致端口 **R** 相对于端口 **C** 产生正位移。这是默认值。
    - `A 处压力导致 R 相对于 C 产生负位移` — 流体体积增加导致端口 **R** 相对于端口 **C** 产生负位移。

**界面位移**
:   选择确定端口 **R** 相对于端口 **C** 位移的方法：

    - `根据端口 R 相对于端口 C 的速度计算` — 基于模块方程，根据相对端口速度计算位移。这是默认方法。
    - `从 Multibody joint 提供输入信号` — 启用输入物理信号端口 **p**，以传递来自 Multibody joint 的位移信息。仅当使用 Translational Multibody Interface 模块将转换器连接到 Multibody joint 时，才使用此方法。有关详细信息，请参阅 How to Pass Position Information。

**初始界面位移**
:   仿真开始时运动界面的平移偏移量。零位移对应于转换器中的总流体体积等于指定的死区体积。默认值为 `0` m。

    - 如果 **机械方向** 为 `A 处压力导致 R 相对于 C 产生正位移`，则参数值必须大于或等于 0。
    - 如果 **机械方向** 为 `A 处压力导致 R 相对于 C 产生负位移`，则参数值必须小于或等于 0。

    当 **界面位移** 设置为 `根据端口 R 相对于端口 C 的速度计算` 时，此参数启用。

**界面横截面积**
:   转换器入口处垂直于流动方向的面积。此面积不必与入口面积相同。转换器内部因流动面积变化引起的压力损失忽略不计。默认值为 `0.01` m^2。

**死区体积**
:   当界面位移为零时，转换器中剩余的流体体积。死区体积使模块即使在界面位移为零时也能考虑转换器中的质量和能量存储。默认值为 `1e-5` m^3。

**端口 A 处的横截面积**
:   由端口 **A** 表示的转换器入口的流动面积。此面积不必与界面横截面积相同。转换器内部因流动面积变化引起的压力损失忽略不计。默认值为 `0.01` m^2。

**环境压力设定**
:   周围环境的压力特性。选择 `大气压力` 将环境压力设置为 Two-Phase Fluid Properties (2P) 模块中指定的大气压力。选择 `指定压力` 将环境压力设置为不同的值。默认设置为 `大气压力`。

**环境压力**
:   周围环境的绝对压力。环境压力作用于转换器的内部压力并影响转换器轴的运动。仅当 **环境压力设定** 参数设置为 `指定压力` 时，此参数才激活。默认值 `0.101325` MPa 对应于平均海平面处的大气压力。

### 效应和初始条件选项卡

**初始流体能量设定**
:   用于定义组件初始条件的热力学变量。默认设置为 `Temperature`。

**初始压力**
:   仿真开始时腔室内的压力，相对于绝对零度指定。默认值为 `0.101325` MPa。

**初始温度**
:   仿真开始时腔室内的温度，相对于绝对零度指定。当**初始流体能量设定**选项设置为 `Temperature` 时，此参数处于激活状态。默认值为 `293.15` K。

**初始蒸汽干度**
:   仿真开始时腔室内蒸汽的质量分数。当**初始流体能量设定**选项设置为 `Vapor quality` 时，此参数处于激活状态。默认值为 `0.5`。

**初始蒸汽空隙率**
:   仿真开始时腔室内蒸汽的体积分数。当**初始流体能量设定**选项设置为 `Vapor void fraction` 时，此参数处于激活状态。默认值为 `0.5`。

**初始比焓**
:   仿真开始时腔室内流体的比焓。当**初始流体能量设定**选项设置为 `Specific enthalpy` 时，此参数处于激活状态。默认值为 `1500` kJ/kg。

**初始比内能**
:   仿真开始时腔室内流体的比内能。当**初始流体能量设定**选项设置为 `Specific internal energy` 时，此参数处于激活状态。默认值为 `1500` kJ/kg。

**相变时间常数**
:   相变事件的特性持续时间。此常数在相之间的过渡中引入时间滞后。默认值为 `0.1` s。

## 描述

两相流体与机械平移网络之间的接口

Translational Mechanical Converter (2P) 模块对两相流体与机械平移网络之间的接口进行建模。该接口将流体网络中的压力转换为机械平移网络中的力，反之亦然。

此模块使您能够对由两相流体系统驱动的线性执行器进行建模。然而，它不考虑线性执行器中常见的质量、摩擦或硬限位。您可以使用 Simscape™ 模块（如 Mass、Translational Friction 和 Translational Hard Stop）单独对这些效应进行建模。

端口 A 表示流体进入和离开转换器的入口。端口 C 和 R 分别表示转换器外壳和移动接口。端口 H 表示转换器与其周围环境进行热交换的壁面。

### Force Direction

力的方向取决于转换器的机械方向。如果 **Mechanical Orientation** 参数设置为正值，则通过入口的正流量倾向于使运动界面相对于转换器壳体沿正方向平移。

**Positive Mechanical Orientation**

如果 **Mechanical Orientation** 参数设置为负值，则通过入口的正质量流量倾向于使运动界面相对于转换器壳体沿负方向平移。

**Negative Mechanical Orientation**

端口 A 与转换器内部之间的流动阻力假定可忽略不计。两者之间的压力损失近似为零。因此，端口 A 处的压力等于转换器内部的压力：

pA=pI，

其中：

- *p*A 是端口 A 处的压力。
- *p*I 是转换器内部的压力。

类似地，端口 H 与转换器内部之间的热阻假定可忽略不计。两者之间的温度梯度近似为零。因此，端口 H 处的温度等于转换器内部的温度：

TH=TI，

其中：

- *T*H 是端口 H 处的温度。
- *T*I 是转换器内部的温度。

### Fluid Volume

转换器中的流体体积是死区流体体积与排量流体体积之和。死区体积是界面位移为零时留在转换器中的流体量。即使界面处于零位，该体积也允许您对动态可压缩性和热容效应进行建模。

排量体积是由于运动界面平移而添加到转换器中的流体量。该体积随界面位移增加而增加。作为界面位移函数的转换器总体积为

V=Vdead+Sintxintϵor，

其中：

- *V* 是转换器中流体的总体积。
- *V*dead 是转换器的死区体积。
- *S*int 是界面的横截面积，假定等于入口的横截面积。
- *x*int 是运动界面的位移。
- ∊or 是转换器的机械方向（如果流体压力增加导致 R 相对于 C 产生正位移，则为 `1`；如果流体压力增加导致 R 相对于 C 产生负位移，则为 `-1`）。

如果将转换器连接到 Multibody 关节，请使用物理信号输入端口 **p** 来指定端口 **R** 相对于端口 **C** 的位移。否则，模块将根据模块方程从相对端口速度计算界面位移。当流体体积等于死区体积时，界面位移为零。然后，取决于 **Mechanical orientation** 参数值：

- 如果为 `Pressure at A causes positive displacement of R relative to C`，则当流体体积从死区体积增加时，界面位移增加。
- 如果为 `Pressure at A causes negative displacement of R relative to C`，则当流体体积从死区体积增加时，界面位移减小。

### Force Balance

在平衡状态下，转换器中的内部压力抵消其周围环境的外部压力以及机械网络施加在运动界面上的力。该力与流体网络施加的力相反。因此，转换器中的力平衡为

pISint=patmSint−Fintϵor，

其中：

- *p*atm 是转换器外部的环境压力。
- *F*int 是流体网络施加在运动界面上的力的大小。

### Energy Balance

转换器中的总能量可能因通过入口的能量流、通过转换器壁的热流以及流体网络对机械网络所做的功而发生变化。因此，由能量守恒方程给出的能量流率为

E˙=ϕA+ϕH−pISintx˙intϵor,

其中：

- E 是转换器中流体的总能量。
- *ϕ*A 是通过端口 A 进入转换器的能量流率。
- *ϕ*H 是通过端口 H 进入转换器的热流率。

取转换器中流体动能为可忽略，流体的总能量简化为：

E=MuI,

其中：

- *M* 是转换器中的流体质量。
- *u*I 是转换器中流体的比内能。

### Mass Balance

转换器中的流体质量可能因通过入口的流动而发生变化，该入口由端口 A 表示。因此，由质量守恒方程给出的质量流率为

M˙=m˙A,

其中：

- m˙A 是通过端口 A 进入转换器的质量流率。

流体质量的变化可能伴随流体体积的变化，这是由于运动界面的平移所致。它也可能伴随质量密度的变化，这是由于转换器中压力或比内能的演化所致。转换器中的质量变化率则为

M˙=[(∂ρ∂p)up˙I+(∂ρ∂u)pu˙I]V+Sintx˙intϵorvI,

其中：

- (∂ρ∂p)u 是在恒定比内能下密度对压力的偏导数。
- (∂ρ∂u)p 是在恒定压力下密度对比内能的偏导数。
- *v*I 是转换器中流体的比体积。

该模块使用三次多项式函数混合各域的密度偏导数。在蒸汽干度为 0–0.1 时，该函数混合过冷液体和两相混合物域的导数。在蒸汽干度为 0.9–1 时，它混合两相混合物和过热蒸汽域的导数。

平滑后的密度偏导数会在原始质量守恒方程中引入不良的数值误差。为校正这些误差，该模块添加校正项

ϵM=M−V/vIτ,

其中：

- *∊*M 是校正项。
- *τ* 是相变时间常数——相变事件的特性持续时间。该常数确保相变不会瞬时发生，从而在相变发生时有效地引入时间滞后。

质量守恒方程的最终形式为

[(∂ρ∂p)up˙I+(∂ρ∂u)pu˙I]V+Dvolθ˙intϵorvI=m˙A+ϵM.

该模块使用此方程，根据通过入口的质量流率计算转换器中的内部压力。
