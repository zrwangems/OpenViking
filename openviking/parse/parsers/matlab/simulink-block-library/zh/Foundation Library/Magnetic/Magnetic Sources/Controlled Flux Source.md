## 描述

由输入信号驱动的理想磁通源

Controlled Flux Source 模块表示理想的磁通源，无论源两端的 mmf 多大，它都能将通过的磁通保持在指定值。

输出磁通为 *PHI = PHIs*，其中 *PHIs* 是在物理信号端口处呈现的数值。

箭头指示磁通流动的正方向。
