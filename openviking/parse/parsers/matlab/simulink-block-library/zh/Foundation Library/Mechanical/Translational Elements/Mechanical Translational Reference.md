## 描述

机械平移端口的参考连接

Mechanical Translational Reference 模块表示机械平移端口的一个参考点（也称为“坐标系”）。所有牢牢固定到坐标系的平移端口都必须连接到一个 Mechanical Translational Reference 模块。有关详细信息，请参阅Grounding Rules。
