## 描述

机械旋转端口的参考连接

Mechanical Rotational Reference 模块表示机械旋转端口的参考点或参考坐标系。所有刚性固定到该坐标系的旋转端口都必须连接到 Mechanical Rotational Reference 模块。有关详细信息，请参阅接地规则。
