# Compound Motor

## 端口

### 守恒

### **+** — 正端子电气

与 Compound Motor 正端子相关联的电气守恒端口。

### **-** — 负端子电气

与 Compound Motor 负端子相关联的电气守恒端口。

### **C** — 电机机壳机械

与 Compound Motor 机壳相关联的机械旋转守恒端口。

### **R** — 电机转子机械

与 Compound Motor 转子相关联的机械旋转守恒端口。

### **Hs** — 串励磁场绕组热端口 热

与串励磁场绕组相关联的热守恒端口。有关详细信息，请参阅热效应建模。

#### 依赖项

要启用此端口，请将 **建模选项** 设置为 `Show thermal port`。

### **Hp** — 并励磁场绕组热端口 热

与并励磁场绕组相关联的热守恒端口。有关详细信息，请参阅热效应建模。

#### 依赖项

要启用此端口，请将 **建模选项** 设置为 `Show thermal port`。

### **Ha** — 电枢热端口 热

与电枢相关联的热守恒端口。有关详细信息，请参阅热效应建模。

#### 依赖项

要启用此端口，请将 **建模选项** 设置为 `Show thermal port`。

### **触发类型** — 触发类型 `Always on` (默认值) | `Timed` | `Behavioral` | `Additional triggers` | `Conditional` | `Manual`

触发类型，指定为以下选项之一：

- `Always On` — 故障在仿真开始时注入。
- `Timed` — 当仿真时间达到为 **触发故障时间** 参数指定的值时，故障注入。
- `Behavioral` — 故障在仿真期间根据故障参数值注入。将 **触发类型** 设置为 `Behavioral` 会启用定义故障条件的模块参数。
- `Additional triggers` — 故障因模块对话框中不可用的附加触发器而注入。选择此选项，并单击 **打开故障属性** 超链接，在属性检查器中将 **触发类型** 设置为以下值之一：

  - `Conditional` — 故障因反映与信号关联的行为的条件而注入。条件在每个时间步计算 **条件** 参数中的布尔表达式。要对不可逆故障建模，请在属性检查器中选择 **触发激活后保持开启** 参数。当触发条件首次变为 true 时，模块进入故障状态，并在仿真剩余时间内保持故障状态。要对可逆故障建模，请清除 **触发激活后保持开启** 参数。当触发条件为 true 时，模块进入故障状态；当触发条件为 false 时，模块进入无故障状态。要了解详细信息，请参阅创建和管理条件。
  - `Manual` — 当您在 **故障仪表板** 窗格中切换状态时，故障注入或清除。要了解详细信息，请参阅在模型中手动触发故障。

#### 依赖项

要启用此参数，请单击 **电枢绕组故障** 参数的 **添加故障** 超链接。

### 故障
要在 Compound Motor 模块中对故障建模，请在 **故障** 部分中，单击要建模的故障旁边的 **添加故障**。有关故障建模的更多信息，请参阅故障行为建模和故障触发。

Compound Motor 模块允许您对三种类型的故障建模：

- 电枢绕组故障 — 电枢绕组发生故障并变为开路。
- 串联磁场绕组故障 — 串联磁场绕组发生故障并变为开路。
- 并励磁场绕组故障 — 并励磁场绕组发生故障并变为开路。

当电枢发生故障时，连接到该模块的电压源会在总电机转数的某一比例内观察到开路，该比例由 **电枢处于开路状态期间的转数比例** 参数指定。下图说明了在一个转数周期内的电路状态行为和开路状态（`rev_faulted`）：

**故障触发**

您可以使用 **触发类型** 参数指定故障发生的方式和时间。

如果将 **触发类型** 设置为 `Behavioral`，则当绕组电流连续超过阈值的时间长于特定时间间隔时，Compound Motor 模块会触发故障：

- 当绕组电流连续超过 **最大允许电枢绕组电流** 参数值，且持续时间长于 **超过电枢绕组电流时发生故障的时间** 参数值时，会发生电枢绕组故障。
- 当绕组电流超过 **最大允许串联磁场绕组电流** 参数值，且持续时间长于 **超过串联磁场绕组电流时发生故障的时间** 参数值时，会发生串联磁场绕组故障。
- 当绕组电流超过 **最大允许并励磁场绕组电流** 参数值，且持续时间长于 **超过并励磁场绕组电流时发生故障的时间** 参数值时，会发生并励磁场绕组故障。

如果将 **触发类型** 设置为 `Conditional`，您可以选择 Compound Motor 模块中的故障是否可逆 *（自 R2025a 起）*。要对不可逆故障建模，请单击 **打开故障属性** 以打开属性检查器，并选中 **触发激活后保持开启** 参数。当触发条件首次变为 true 时，模块进入故障状态，并在仿真的剩余时间内保持故障状态。要对可逆故障建模，请清除 **触发激活后保持开启** 参数。当触发条件为 true 时，模块进入故障状态；当触发条件为 false 时，模块进入无故障状态。

有关向模块添加故障和指定故障触发的更多信息，请参阅 Simscape 故障简介。

### 对热效应建模
您可以公开热端口，以对将功率转换为热量的损耗效应建模。要公开热端口，请将 **建模选项** 参数设置为以下任一值：

- `No thermal port` — 模块不包含热端口。
- `Show thermal port` — 模块包含用于串联磁场绕组、并励磁场绕组和电枢的热守恒端口。

有关在致动器模块中使用热端口的更多信息，请参阅仿真旋转和平移致动器中的热效应。
