# Busbar

## 端口

### 输出

### **Vt** — 电压 物理信号

与电压测量相关联的物理信号端口。该值以标么值报告，即等于相间均方根电压除以**额定母排电压(相间 RMS)**。

#### 依赖关系

仅当在**参数**设置中将**测量端口**参数设置为**是**时，才会显示该端口。

### **ph** — 相位 物理信号

与电压相位测量相关联的物理信号端口。

#### 依赖关系

仅当在**参数**设置中将**测量端口**参数设置为**是**时，才会显示该端口。

### **P** — 有功功率 物理信号

与有功（实际）功率测量相关联的物理信号端口。

#### 依赖关系

仅当在**参数**设置中将**连接数**参数设置为 **2**、**3** 或 **4** 并且将**测量端口**参数设置为**是**时，才会显示该端口。

### **Q** — 无功功率 物理信号

与无功（虚）功率测量相关联的物理信号端口。

#### 依赖关系

仅当在**参数**设置中将**连接数**参数设置为 **2**、**3** 或 **4** 并且将**测量端口**参数设置为**是**时，才会显示该端口。
### 守恒

### **~1** — 三相连接 1 电气

与第一个三相连接相关联的复合三相电气守恒端口。

### **~2** — 三相连接 2 电气

与第二个三相连接相关联的复合三相电气守恒端口。

#### 依赖关系

仅当在**参数**设置中将**连接数**参数设置为 **2**、**3** 或 **4** 时，才会显示该端口。

### **~3** — 三相连接 3 电气

与第三个三相连接相关联的复合三相电气守恒端口。

#### 依赖关系

仅当在**参数**设置中将**连接数**参数设置为 **3** 或 **4** 时，才会显示该端口。

### **~4** — 三相连接 4 电气

与第四个三相连接相关联的复合三相电气守恒端口。

#### 依赖关系

仅当在**参数**设置中将**连接数**参数设置为 **4** 时，才会显示该端口。

## 参数

### **连接数** — 端口连接的数量 **2** (默认) | **1** | **3** | **4**

模块上暴露的端口连接的数量。

模块上暴露的端口的数量与该参数相关。

### **额定母排电压(相间 RMS)** — 母排额定电压 `sqrt(3) * 100 / sqrt(2)` **V** (默认)

母排的额定相间均方根电压。

### **网络频率** — 网络频率 `60` **Hz** (默认)

所连接网络的频率。

### **测量端口** — 测量端口暴露 **否** (默认) | **是**

电压、相位、有功功率和无功功率物理信号输出测量端口的可见性。

#### 依赖关系

仅当将该参数设置为**是**时，才会显示端口 **Vt** 和 **ph**。

仅当将该参数设置为**是**，并且在**参数**设置中将**连接数**参数设置为 **2**、**3** 或 **4** 时，才会显示端口 **P** 和 **Q**。

## 描述

潮流分析母排连接器

Busbar 模块是用于潮流分析的连接器。该模块用于与频率-时间仿真模式兼容的三相 Simscape™ Electrical™ 网络。完成仿真后，该模块会添加一个注解，显示仿真启动时其每个三相电气守恒端口的电压、相位、有功功率和无功功率。对于要添加的注解，必须启用 Simscape 记录。

该模块将在基于时间的仿真模式下进行仿真，但除非网络与频率-时间仿真模式兼容并且您在 Solver Configuration 模块上选中了**从稳态开始仿真**，否则不会在初始潮流结果中添加注解。不过，当使用基于时间的仿真模式时，该模块会计算电压、相位、有功功率和无功功率的近似值。您可以在 Simscape 记录中查看这些值，或者通过暴露该模块上的可选测量端口来进行查看。近似水平取决于系统的平衡程度和当前谐波水平。
