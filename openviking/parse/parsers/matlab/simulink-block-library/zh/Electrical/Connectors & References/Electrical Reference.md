## 描述

电气接地连接

Electrical Reference 表示电气接地。所有模块直接接地的电气守恒端口都必须连接到一个 Electrical Reference 模块。带有电气元件的模型必须包含至少一个 Electrical Reference 模块。有关详细信息，请参阅Grounding Rules。
