# SM AC4C

## 端口

### 输入

### **V\_REF** — 电压参考标量

电压调节器参考设定点，以标幺值表示，指定为标量。

**数据类型：** `single` | `double`

### **V\_S** — 来自稳定器的输入标量

来自电力系统稳定器的输入，以标幺值表示，指定为标量。

**数据类型：** `single` | `double`

以标幺值表示的端电压幅值，指定为标量。

## 描述

离散时间或连续时间同步电机 AC4C 励磁系统，包括自动电压调节器和励磁机

SM AC4C 模块实现了符合 IEEE 421.5-2016[1] 的同步电机 AC4C 型励磁系统模型。

使用此模块可对使用交流旋转励磁机作为发电机运行的同步电机的磁场电压进行控制和调节建模。

您可以使用 **采样时间（-1 表示继承）** 参数在模块的连续实现和离散实现之间切换。要将积分器配置为连续时间，请将 **采样时间（-1 表示继承）** 属性设置为 `0`。要将积分器配置为离散时间，请将 **采样时间（-1 表示继承）** 属性设置为正的非零值，或设置为 `-1` 以从上游模块继承采样时间。

SM AC4C 模块由四个主要组件组成：

- 电流补偿器根据端电流修改测量的端电压。
- 电压测量传感器使用低通滤波器模拟端电压传感器的动态特性。
- 励磁控制元件组件将电压传感器输出与端电压参考进行比较以产生电压误差。然后，该电压误差通过电压调节器以产生励磁机磁场电压。
- 交流旋转励磁机对交流旋转励磁机建模，该励磁机产生施加到受控同步电机的磁场电压。该模块还将励磁机励磁电流（标准符号为 *VFE*）反馈回励磁系统。

此图显示了 AC4C 励磁系统模型的整体结构：

在图中：

- *VT* 和 *IT* 是同步电机的测量端电压和电流。
- *VC1* 是电流补偿后的端电压。
- *VC* 是滤波后的电流补偿端电压。
- *VREF* 是参考端电压。
- *VS* 是电力系统稳定器电压。
- *EFE* 和 *VFE* 分别是励磁机磁场电压和电流。
- *EFD* 和 *IFD* 分别是磁场电压和电流。

以下各节详细描述了模块的每个主要部分。

### 电流补偿器和电压测量传感器

电流补偿器建模为：

VC1=VT+ITRC2+XC2，

其中：

- *RC* 是负载补偿电阻。
- *XC* 是负载补偿电抗。

电压测量传感器实现为时间常数为 *TR* 的低通滤波器模块。有关离散和连续实现，请参阅此模块的文档。

### 励磁控制元件

此图说明了励磁控制元件的整体结构：

与其他交流励磁模型不同，SM AC4C 模块包括一个完整的晶闸管桥，用于对励磁机输出电路建模，以及一个控制晶闸管桥触发的电压调节器。励磁系统稳定不是通过速率反馈实现的，而是通过超前-滞后网络和低通滤波器实现的。

在图中：

- 求和点逻辑子系统对过励限制器 (OEL)、欠励限制器 (UEL) 和定子电流限制器 (SCL) 电压的求和点输入位置建模。有关在此模块中使用限制器的详细信息，请参阅磁场电流限制器。
- 超前-滞后模块对与电压调节器相关的附加动态建模。此处，*TC* 是超前时间常数，*TB* 是滞后时间常数。有关离散和连续实现，请参阅超前-滞后模块的文档。
- 接管逻辑子系统对 OEL、UEL 和 SCL 电压的接管点输入位置建模。有关在此模块中使用限制器的详细信息，请参阅磁场电流限制器。
- 低通滤波器模块对电压调节器的主要动态建模。此处，*KA* 是调节器增益，*TA* 是调节器的主要时间常数。该模块的最小和最大抗积分饱和限值分别为 *VRmin* 和 *VRmax*。
- 图的底部部分对基于 *Ifd* 的限制建模。
- **initialOffset** 常量模块确保仿真可以从稳态开始。SM AC4C 模块使用最大和最小调节器输出值、调节器输出增益、与换相电抗成正比的整流器负载系数以及初始磁场电压来计算此值。

### 磁场电流限制器

您可以使用各种磁场电流限制器在不安全的运行条件下修改电压调节器的输出：

- 使用过励限制器防止因过大的磁场电流需求导致磁场绕组过热。
- 使用欠励限制器在磁场励磁过低时提升励磁，因为过低有失步风险。
- 使用定子电流限制器防止因过大电流导致定子绕组过热。

将任何这些限制器的输出连接到以下点之一：

- 求和点，作为自动电压调节器 (AVR) 反馈回路的一部分
- 接管点，以覆盖 AVR 的通常行为

如果在求和点使用定子电流限制器，请使用单个输入 *VSCLsum*。如果在接管点使用定子电流限制器，请同时使用过励输入 *VOELscl* 和欠励输入 *VUELscl*。
