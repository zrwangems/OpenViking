# SM AC5C

## 端口

### 输入

### **V\_REF** — 电压参考标量

电压调节器参考设定点，以标幺值表示，指定为标量。

**数据类型：** `single` | `double`

### **V\_S** — 来自稳定器的输入标量

来自电力系统稳定器的输入，以标幺值表示，指定为标量。

**数据类型：** `single` | `double`

### **V\_T** — 机端电压标量

机端电压幅值，以标幺值表示，指定为标量。

**数据类型：** `single` | `double`

### **I\_T** — 机端电流标量

机端电流幅值，以标幺值表示，指定为标量。

**数据类型：** `single` | `double`

### **V\_OEL** — 过励限制信号标量

来自过励限制器的输入，以标幺值表示，指定为标量。

#### 依赖关系

- 要忽略来自过励限制器的输入，将 **备用 OEL 输入位置 (V\_OEL)** 设置为 `Unused`。
- 要在求和点使用来自过励限制器的输入，将 **备用 OEL 输入位置 (V\_OEL)** 设置为 `Summation point`。
- 要在接管点使用来自过励限制器的输入，将 **备用 OEL 输入位置 (V\_OEL)** 设置为 `Take-over`。

**数据类型：** `single` | `double`

### **V\_UEL** — 欠励限制信号标量

来自欠励限制器的输入，以标幺值表示，指定为标量。

#### 依赖关系

- 要忽略来自欠励限制器的输入，将 **备用 UEL 输入位置 (V\_UEL)** 设置为 `Unused`。
- 要在求和点使用来自欠励限制器的输入，将 **备用 UEL 输入位置 (V\_UEL)** 设置为 `Summation point`。
- 要在接管点使用来自欠励限制器的输入，将 **备用 UEL 输入位置 (V\_UEL)** 设置为 `Take-over`。

**数据类型：** `single` | `double`

### **V\_SCLsum** — 求和点定子电流限制信号标量

使用求和点时来自定子电流限制器的输入，以标幺值表示，指定为标量。

#### 依赖关系

- 要忽略来自定子电流限制器的输入，将 **备用 SCL 输入位置 (V\_SCL)** 设置为 `Unused`。
- 要在求和点使用来自定子电流限制器的输入，将 **备用 SCL 输入位置 (V\_SCL)** 设置为 `Summation point`。

**数据类型：** `single` | `double`

### **V\_SCLoel** — 用于过励限制器的接管定子电流限制标量

使用接管点时来自定子电流限制器的输入，用于防止磁场过励，以标幺值表示，指定为标量。

#### 依赖关系

- 要忽略来自定子电流限制器的输入，将 **备用 SCL 输入位置 (V\_SCL)** 设置为 `Unused`。
- 要在接管点使用来自定子电流限制器的输入，将 **备用 SCL 输入位置 (V\_SCL)** 设置为 `Take-over`。

**数据类型：** `single` | `double`

### **V\_SCLuel** — 用于欠励限制器的接管定子电流限制标量

使用接管点时来自定子电流限制器的输入，用于防止磁场欠励，以标幺值表示，指定为标量。

#### 依赖关系

- 要忽略来自定子电流限制器的输入，将 **备用 SCL 输入位置 (V\_SCL)** 设置为 `Unused`。
- 要在接管点使用来自定子电流限制器的输入，将 **备用 SCL 输入位置 (V\_SCL)** 设置为 `Take-over`。

**数据类型：** `single` | `double`

### **Ifd\_pu** — 测量的励磁电流标量

同步电机的测量标幺励磁电流，指定为标量。

**数据类型：** `single` | `double`
### 输出

### **Efd\_pu** — 励磁电压标量

施加到同步电机励磁电路的标幺励磁电压，返回为标量。

**数据类型：** `single` | `double`

## 描述

离散时间或连续时间同步电机 AC5C 励磁系统，包括自动电压调节器和励磁机

SM AC5C 模块实现符合 IEEE 421.5-2016[1] 的同步电机 AC5C 型励磁系统模型。

使用此模块对作为发电机运行并使用交流旋转励磁机的同步电机的励磁电压的控制和调节进行建模。

可以通过 **采样时间（-1 表示继承）** 参数在模块的连续实现和离散实现之间切换。要将积分器配置为连续时间，请将 **采样时间（-1 表示继承）** 属性设置为 `0`。要将积分器配置为离散时间，请将 **采样时间（-1 表示继承）** 属性设置为正的非零值，或设置为 `-1` 以从上游模块继承采样时间。

SM AC5C 模块由四个主要组件组成：

- Current Compensator 根据机端电流修改测量的机端电压。
- Voltage Measurement Transducer 使用 Low-Pass Filter 模块模拟机端电压变送器的动态特性。
- Excitation Control Elements 组件将电压变送器输出与机端电压参考进行比较以产生电压误差。然后，该电压误差经过电压调节器以产生励磁机磁场电压。
- AC Rotating Exciter 对交流旋转励磁机进行建模，该励磁机产生施加到受控同步电机的励磁电压。该模块还将励磁机磁场电流（标准符号为 *VFE*）反馈到励磁系统。

以下各节详细描述该模块的每个主要部分。

### Current Compensator 和 Voltage Measurement Transducer

电流补偿器建模为：

VC1=VT+ITRC2+XC2,

其中：

- *RC* 是负载补偿电阻。
- *XC* 是负载补偿电抗。

Voltage Measurement Transducer 通过时间常数为 *TR* 的 Low-Pass Filter 模块实现。有关离散和连续实现，请参阅此模块的文档。

### Excitation Control Elements

此图说明 Excitation Control Elements 的总体结构：

图中：

- Summation Point Logic 子系统对过励限制器 (OEL)、欠励限制器 (UEL) 和定子电流限制器 (SCL) 电压的求和点输入位置进行建模。有关将限制器与此模块一起使用的详细信息，请参阅励磁电流限制器。
- Low-Pass Filter 模块对电压调节器的主要动态特性进行建模。这里，*KA* 是调节器增益，*TA* 是调节器的主要时间常数。该模块的最小和最大抗积分饱和饱和限值分别为 *VAmin* 和 *VAmax*。
- Filtered Derivative 和 Lead-Lag 模块对用于稳定励磁系统的速率反馈路径进行建模。这里，*KF* 是该系统的增益，*TF1*、*TF2* 和 *TF3* 是其时间常数。有关离散和连续实现，请参阅 Filtered Derivative 模块的文档。
- Take-over Logic 子系统对 OEL、UEL 和 SCL 电压的接管点输入位置进行建模。有关将限制器与此模块一起使用的详细信息，请参阅励磁电流限制器。
- **initialOffset** Constant 模块确保仿真可以从稳态启动。SM AC5C 模块通过使用饱和和励磁机参数（包括初始励磁电压和调节器输出增益）计算此值。

### 励磁电流限制器

您可以使用各种励磁电流限制器在不安全运行条件下修改电压调节器的输出：

- 使用过励限制器防止因励磁电流需求过大而导致励磁绕组过热。
- 使用欠励限制器在励磁过低时提升励磁，因为励磁过低会有失步风险。
- 使用定子电流限制器防止因电流过大而导致定子绕组过热。

将任何这些限制器的输出连接在以下点之一：

- 求和点，作为自动电压调节器 (AVR) 反馈回路的一部分
- 接管点，以覆盖 AVR 的通常行为

如果在求和点使用定子电流限制器，请使用单个输入 *VSCLsum*。如果在接管点使用定子电流限制器，请同时使用过励输入 *VSCLoel* 和欠励输入 *VSCLuel*。
