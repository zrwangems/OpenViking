# SM PSS2C

## 端口

### 输入

### **V\_SI1** — 速度、频率或功率标量

标幺值速度、终端母线电压频率、补偿频率或电功率，指定为标量。

**数据类型：** `single` | `double`

### **V\_SI2** — 电功率标量

标幺值电功率，指定为标量。

**数据类型：** `single` | `double`
### 输出

### **V\_ST** — 稳定速度、频率或功率标量

自动电压调节器输入稳定信号，受 *VST\_min* 和 *VST\_max* 限制，返回为标量。

**数据类型：** `single` | `double`

## 描述

离散时间或连续时间单输入 PSS2C 电力系统稳定器

SM PSS2C 模块实现双输入 PSS2C 电力系统稳定器 (PSS)，该稳定器按照 IEEE 421.5-2016[1] 维持同步电机 (SM) 的转子角稳定性。通常，您使用 PSS 通过励磁控制来增强电力系统振荡的阻尼。

您可以使用同一模型表示两种不同类型的双输入电力系统稳定器：

- 一种稳定器，它使用电功率和速度（或频率）信号来计算加速功率的积分。这使计算得到的稳定器信号对机械变化不敏感。
- 一种稳定器，它使用电功率与速度或频率的组合。为实现所需的稳定信号整形，系统直接使用速度，而不进行相位超前补偿，并加上一个与电功率成比例的信号。

您可以使用 **采样时间（继承时为 -1）** 参数在模块的连续和离散实现之间切换。要将积分器配置为连续时间，请将 **采样时间（继承时为 -1）** 属性设置为 `0`。要将积分器配置为离散时间，请将 **采样时间（继承时为 -1）** 属性设置为正的非零值，或设置为 `-1` 以从上游模块继承采样时间。

下图说明了 PSS2C 电力系统稳定器的整体结构：

图中：

- *V\_SI1* 和 *V\_SI2* 是两个电力系统稳定器输入。常用输入为速度、频率或功率。
- 每个稳定器输入表示两个 Washout (Discrete or Continuous) 模块，其时间常数为 *TW1* 到 *TW4*，以及一个由 Low-Pass Filter (Discrete or Continuous) 表示的变送器，其时间常数为 *T6* 和 *T7*。
- 为允许斜坡跟踪滤波器特性，Ramp Tracking Filter 子系统对串联的超前-滞后和低通滤波器模块网络进行建模。
- 为提供相位补偿，Lead-Lag (Discrete or Continuous) 网络对与电力系统稳定器相关的附加动态进行建模，表示四个超前-滞后补偿级，其时间常数为 *T1* 到 *T4* 以及 *T10* 到 *T13*。
- PSS output logic 子系统允许表示与发电机有功功率输出相关的 PSS 输出逻辑。*PPSSon* 和 *PPSSoff* 是用于定义滞环的阈值。
