# SM ST1C

## 端口

### 输入

### **V\_REF** — 电压参考标量

电压调节器参考设定点，采用标幺值表示，指定为标量。

**数据类型：** `single` | `double`

### **V\_S** — 来自稳定器的输入标量

来自电力系统稳定器的输入，采用标幺值表示，指定为标量。

**数据类型：** `single` | `double`

### **V\_T** — 端电压标量

采用标幺值表示的端电压幅值，指定为标量。

**数据类型：** `single` | `double`

### **I\_T** — 端电流标量

采用标幺值表示的端电流幅值，指定为标量。

**数据类型：** `single` | `double`

### **V\_OEL** — 过励限制信号标量

来自过励限制器的输入，采用标幺值表示，指定为标量。

#### 依赖关系

- 要忽略来自过励限制器的输入，请将 **备用 OEL 输入位置 (V\_OEL)** 设置为 `Unused`。
- 要在求和点使用来自过励限制器的输入，请将 **备用 OEL 输入位置 (V\_OEL)** 设置为 `Summation point`。
- 要在接管点使用来自过励限制器的输入，请将 **备用 OEL 输入位置 (V\_OEL)** 设置为 `Take-over`。

**数据类型：** `single` | `double`

### **V\_UEL** — 欠励限制信号标量

来自欠励限制器的输入，采用标幺值表示，指定为标量。

#### 依赖关系

- 要忽略来自欠励限制器的输入，请将 **备用 UEL 输入位置 (V\_UEL)** 设置为 `Unused`。
- 要在求和点使用来自欠励限制器的输入，请将 **备用 UEL 输入位置 (V\_UEL)** 设置为 `Summation point`。
- 要在接管点使用来自欠励限制器的输入，请将 **备用 UEL 输入位置 (V\_UEL)** 设置为 `Take-over`。

**数据类型：** `single` | `double`

### **V\_SCLsum** — 求和点定子电流限制信号标量

使用求和点时来自定子电流限制器的输入，采用标幺值表示，指定为标量。

#### 依赖关系

- 要忽略来自定子电流限制器的输入，请将 **备用 SCL 输入位置 (V\_SCL)** 设置为 `Unused`。
- 要在求和点使用来自定子电流限制器的输入，请将 **备用 SCL 输入位置** 设置为 `Summation point`。

**数据类型：** `single` | `double`

### **V\_SCLoel** — 接管定子电流限制 (OEL) 标量

使用接管点时，来自定子电流限制器的、防止励磁过励的输入，采用标幺值表示，指定为标量。

#### 依赖关系

- 要忽略来自定子电流限制器的输入，请将 **备用 SCL 输入位置 (V\_SCL)** 设置为 `Unused`。
- 要在接管点使用来自定子电流限制器的输入，请将 **备用 SCL 输入位置 (V\_SCL)** 设置为 `Take-over`。

**数据类型：** `single` | `double`

### **V\_SCLuel** — 接管定子电流限制 (UEL) 标量

使用接管点时，来自定子电流限制器的、防止励磁欠励的输入，采用标幺值表示，指定为标量。

#### 依赖关系

- 要忽略来自定子电流限制器的输入，请将 **备用 SCL 输入位置 (V\_SCL)** 设置为 `Unused`。
- 要在接管点使用来自定子电流限制器的输入，请将 **备用 SCL 输入位置 (V\_SCL)** 设置为 `Take-over`。

**数据类型：** `single` | `double`

### **Ifd\_pu** — 测量的励磁电流标量

同步电机的测量标幺励磁电流，指定为标量。

**数据类型：** `single` | `double`

### **Efd\_pu** — 励磁电压标量

**数据类型：** `single` | `double`

## 描述

具有自动电压调节器的离散时间或连续时间同步电机 ST1C 静止励磁系统

SM ST1C 模块实现符合 IEEE 421.5-2016[1] 的同步电机型 ST1C 静止励磁系统模型。

使用此模块对同步电机的励磁电压的控制和调节进行建模。

通过使用 **采样时间（-1 表示继承）** 参数，可以在模块的连续实现和离散实现之间切换。要将积分器配置为连续时间，请将 **采样时间（-1 表示继承）** 属性设置为 `0`。要将积分器配置为离散时间，请将 **采样时间（-1 表示继承）** 属性设置为正的、非零值，或设置为 `-1` 以从上游模块继承采样时间。

SM ST1C 模块包含三个主要组件：

- Current Compensator 根据端电流修改测量的端电压。
- Voltage Measurement Transducer 使用低通滤波器模拟端电压传感器的动态。
- Excitation Control Elements 组件将电压传感器输出与端电压参考值进行比较以产生电压误差。然后，该电压误差通过电压调节器以产生励磁电压。

此图展示了 ST1C 励磁系统模型的整体结构：

图中：

- *VT* 和 *IT* 是同步电机的测量端电压和端电流。
- *VC1* 是经电流补偿的端电压。
- *VC* 是经过滤波、电流补偿的端电压。
- *VREF* 是参考端电压。
- *VS* 是电力系统稳定器电压。
- *EFD* 和 *IFD* 分别是励磁电压和励磁电流。

以下各节详细描述该模块的各个主要部分。

### Current Compensator 和 Voltage Measurement Transducer

电流补偿器建模为：

VC1=VT+ITRC2+XC2,

其中：

- *RC* 是负载补偿电阻。
- *XC* 是负载补偿电抗。

电压测量传感器实现为具有时间常数 *TR* 的 Low-Pass Filter 模块。有关离散和连续实现，请参阅 Low-Pass Filter 模块的文档。

### Excitation Control Elements

此图展示了励磁控制元件的整体结构：

图中：

- Summation Point Logic 子系统对过励限制器 (OEL)、欠励限制器 (UEL)、定子电流限制器 (SCL) 和电力系统稳定器 (V\_S) 电压的求和点输入位置进行建模。有关将限制器与该模块一起使用的详细信息，请参阅励磁电流限制器。
- 有两个 Take-over Logic 子系统。这些子系统对 OEL、UEL、SCL 和 PSS 电压的接管点输入位置进行建模。有关将限制器与该模块一起使用的详细信息，请参阅励磁电流限制器。
- 两个 Lead-Lag 模块对与电压调节器相关的附加动态进行建模。前者表示暂态增益降低，其中 *TC* 是超前时间常数，*TB* 是滞后时间常数。后者允许表示暂态增益增加，其中 *TC1* 是超前时间常数，*TB1* 是滞后时间常数。有关离散和连续实现，请参阅 Lead-Lag 模块的文档。
- Low-Pass Filter 模块对电压调节器的主要动态进行建模。这里，*KA* 是调节器增益，*TA* 是调节器的主要时间常数。该模块的最小和最大抗积分饱和饱和限值分别为 *VAmin* 和 *VAmax*。
- Filtered Derivative 模块对用于稳定励磁系统的速率反馈路径进行建模。这里，*KF* 和 *TF* 分别是该系统的增益和时间常数。有关离散和连续实现，请参阅 Filtered Derivative 模块的文档。
- 由于强励能力非常高，该模型采用励磁电流限制器来保护发电机转子和励磁机。初始阈值和增益分别由 *ILR* 和 *KLR* 定义。如果使用显式 OEL 模型，请将增益 *KLR* 设置为 `0` 以禁用此励磁电流限制器。

### Field Current Limiters

在不安全运行条件下，你可以使用各种励磁电流限制器来修改电压调节器的输出：

- 使用过励限制器，防止因过大的励磁电流需求导致励磁绕组过热。
- 使用欠励限制器，在励磁过低且有失步风险时提升励磁。
- 使用定子电流限制器，防止因过大的电流导致定子绕组过热。

将上述任一限制器的输出连接到以下任一位置：

- 求和点，作为自动电压调节器 (AVR) 反馈回路的一部分
- 接管点，以覆盖 AVR 的常规行为

如果你在求和点使用定子电流限制器，使用单输入 *VSCLsum*。如果你在接管点使用定子电流限制器，同时使用过励输入 *VSCLoel* 和欠励输入 *VSCLuel*。
