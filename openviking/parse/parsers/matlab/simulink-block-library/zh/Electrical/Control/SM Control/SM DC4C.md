# SM DC4C

## 端口

### 输入

### **V\_REF** — 电压参考标量

电压调节器参考设定点，采用标幺值表示，指定为标量。

**数据类型：** `single` | `double`

### **V\_S** — 稳定器输入标量

来自电力系统稳定器的输入，采用标幺值表示，指定为标量。

**数据类型：** `single` | `double`

### **V\_T** — 机端电压标量

机端电压幅值，采用标幺值表示，指定为标量。

**数据类型：** `single` | `double`

### **I\_T** — 机端电流标量

机端电流幅值，采用标幺值表示，指定为标量。

**数据类型：** `single` | `double`

### **V\_OEL** — 过励限制信号标量

来自过励限制器的输入，采用标幺值表示，指定为标量。

- 要忽略来自过励限制器的输入，请将 **备用 OEL 输入位置 (V\_OEL)** 设置为 `Unused`。
- 要在求和点使用来自过励限制器的输入，请将 **备用 OEL 输入位置 (V\_OEL)** 设置为 `Summation point`。
- 要在接管点使用来自过励限制器的输入，请将 **备用 OEL 输入位置 (V\_OEL)** 设置为 `Take-over`。

**数据类型：** `single` | `double`

### **V\_UEL** — 欠励限制信号标量

来自欠励限制器的输入，采用标幺值表示，指定为标量。

- 要忽略来自欠励限制器的输入，请将 **备用 UEL 输入位置 (V\_UEL)** 设置为 `Unused`。
- 要在求和点使用来自欠励限制器的输入，请将 **备用 UEL 输入位置 (V\_UEL)** 设置为 `Summation point`。
- 要在接管点使用来自欠励限制器的输入，请将 **备用 UEL 输入位置 (V\_UEL)** 设置为 `Take-over`。

**数据类型：** `single` | `double`

### **V\_SCLsum** — 求和点定子电流限制信号标量

使用求和点时来自定子电流限制器的输入，采用标幺值表示，指定为标量。

- 要忽略来自定子电流限制器的输入，请将 **备用 SCL 输入位置 (V\_SCL)** 设置为 `Unused`。
- 要在求和点使用来自定子电流限制器的输入，请将 **备用 SCL 输入位置 (V\_SCL)** 设置为 `Summation point`。

**数据类型：** `single` | `double`

### **V\_OELscl** — 接管定子电流限制 (OEL) 标量

使用接管点时来自定子电流限制器的输入，用于防止磁场过励，采用标幺值表示，指定为标量。

- 要忽略来自定子电流限制器的输入，请将 **备用 SCL 输入位置 (V\_SCL)** 设置为 `Unused`。
- 要在接管点使用来自定子电流限制器的输入，请将 **备用 SCL 输入位置 (V\_SCL)** 设置为 `Take-over`。

**数据类型：** `single` | `double`

### **V\_UELscl** — 接管定子电流限制 (UEL) 标量

使用接管点时来自定子电流限制器的输入，用于防止磁场欠励，采用标幺值表示，指定为标量。

- 要忽略来自定子电流限制器的输入，请将 **备用 SCL 输入位置 (V\_SCL)** 设置为 `Unused`。
- 要在接管点使用来自定子电流限制器的输入，请将 **备用 SCL 输入位置 (V\_SCL)** 设置为 `Take-over`。

**数据类型：** `single` | `double`

### 输出

### **Efd\_pu** — 励磁电压标量

要施加到同步电机励磁绕组的标幺励磁电压，返回为标量。

**数据类型：** `single` | `double`

## 描述

离散时间或连续时间同步电机 DC4C 励磁系统，包括自动电压调节器和励磁机

SM DC4C 模块对符合 IEEE 421.5-2016[1] 的同步电机 DC4C 型励磁系统进行建模。使用此模块可对作为发电机运行、使用 DC 换向器旋转励磁机的同步电机的励磁电压进行建模、控制和调节。

您可以使用 **采样时间（-1 表示继承）** 参数在模块的连续实现和离散实现之间切换。要将模块配置为连续时间，请将 **采样时间（-1 表示继承）** 属性设置为 `0`。要将模块配置为离散时间，请将 **采样时间（-1 表示继承）** 属性设置为正非零值，或设置为 `-1` 以从上游模块继承采样时间。

SM DC4C 模块由五个主要组件组成：

- 电流补偿器根据机端电流修改测得的机端电压。
- 电压测量传感器通过使用低通滤波器模拟机端电压传感器的动态特性。
- 励磁控制元件组件将电压传感器输出与机端电压参考进行比较，以产生电压误差。然后，该电压误差通过电压调节器，以产生励磁机励磁电压。
- DC 旋转励磁机对 DC 换向器旋转励磁机进行建模，该励磁机产生并向受控同步电机施加励磁电压。该模块还将励磁电压反馈到励磁系统。
- 电源对受控整流器的电源与机端电压的依赖性进行建模。

此图显示了 DC4C 励磁系统模型的总体结构：

图中：

- *VT* 和 *IT* 是同步电机的测得的机端电压和电流。
- *VC1* 是电流补偿后的机端电压。
- *VC* 是经过滤波的电流补偿后机端电压。
- *VREF* 是参考机端电压。
- *VS* 是电力系统稳定器电压。
- *SW1* 是用户选择的受控整流器电源开关。
- *VB* 是励磁机励磁电压。
- *EFE* 和 *VFE* 分别是励磁机励磁电压和电流。
- *EFD* 是励磁电压。

### 电流补偿器和电压测量传感器

电流补偿器建模为：

VC1=VT+ITRC2+XC2,

其中：

- *RC* 是负载补偿电阻。
- *XC* 是负载补偿电抗。

电压测量传感器实现为 `Low-Pass Filter` 模块，时间常数为 *TR*。要查看确切的离散和连续实现，请参阅 Low-Pass Filter。

### Excitation Control Elements

此图说明了励磁控制元件的总体结构：

在图中：

- Summation Point Logic 子系统对过励限制器（OEL）、欠励限制器（UEL）和定子电流限制器（SCL）电压的求和点输入位置进行建模。有关将此模块与限幅器配合使用的更多信息，请参阅励磁电流限幅器。
- Low-Pass Filter 模块对电压调节器的主要动态进行建模。这里，*KA* 是调节器增益，*TA* 是调节器的主要时间常数。该模块的最小和最大抗积分饱和限幅分别为 *VRmin* 和 *VRmax*。
- PID\_R 子系统对用作自动电压调节器控制结构的 PID 控制器进行建模。该模块的最小和最大抗积分饱和限幅分别为 *VRmax / KA* 和 *VRmin / KA*。
- Take-over Logic 子系统对 OEL、UEL 和 SCL 电压的接管点输入位置进行建模。有关将此模块与限幅器配合使用的更多信息，请参阅励磁电流限幅器。
- Filtered Derivative 模块对用于稳定励磁系统的速率反馈路径进行建模。这里，*KF* 和 *TF* 分别是该系统的增益和时间常数。要查看确切的离散和连续实现，请参阅 Filtered Derivative。

### 励磁电流限幅器

可使用各种励磁电流限幅器在不安全运行条件下修改电压调节器的输出：

- 使用过励限制器防止因过大的励磁电流需求而导致励磁绕组过热。
- 使用欠励限制器在励磁过低时提升励磁，否则可能存在失步风险。
- 使用定子电流限制器防止因过大的电流而导致定子绕组过热。

将上述任一限幅器的输出连接到以下任一位置：

- 求和点，作为自动电压调节器（AVR）反馈回路的一部分
- 接管点，以覆盖 AVR 的通常行为

如果在求和点使用定子电流限制器，请使用单输入 **V\_SCLsum**。如果在接管点使用定子电流限制器，请同时使用过励输入 **V\_OELscl** 和欠励输入 **V\_UELscl**。

### DC Rotating Exciter

此图说明了直流换向器旋转励磁机的总体结构：

在图中：

- 励磁机励磁电流 *VFE* 是两个信号之和：

  - 非线性函数 *Vx* 对励磁机输出电压的饱和进行建模。
  - 比例项 *KE* 对励磁机输出电压与励磁机励磁电流之间的线性关系进行建模。
- Integrator 子系统对 *EFE* 与 *VFE* 之间的差值进行积分，以生成输出励磁电压 *Efd*。*TE* 是该过程的时间常数。

### 电源

可使用 **Logical switch 1** 参数更改可控整流器的电源表示。可控整流器的电源可以源自端电压（`Position A: power source derived from terminal voltage`），也可以独立于端电压（`Position B: power source independent from the terminal conditions`）。
