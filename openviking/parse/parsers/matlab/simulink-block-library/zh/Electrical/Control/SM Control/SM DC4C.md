## 描述

离散时间或连续时间同步电机 DC4C 励磁系统，包括自动电压调节器和励磁机

SM DC4C 模块对符合 IEEE 421.5-2016[1] 的同步电机 DC4C 型励磁系统进行建模。
使用此模块可对作为发电机运行并使用直流换向器旋转励磁机的同步电机的励磁电压进行建模和控制与调节。

您可以使用
**采样时间（-1 表示继承）** 参数在模块的连续实现和离散实现之间切换。要将
模块配置为连续时间，请将 **采样时间（-1 表示继承）**
属性设置为 `0`。要将模块配置为离散时间，请将
**采样时间（-1 表示继承）** 属性设置为正的非零
值，或设置为 `-1` 以从上游
模块继承采样时间。

SM DC4C 模块由五个主要组件组成：

- 电流补偿器根据机端电流修改测量的机端电压。
- 电压测量传感器通过使用低通滤波器模拟机端
  电压传感器的动态特性。
- 励磁控制元件组件将电压传感器
  输出与机端电压参考进行比较以产生电压误差。该
  电压误差随后通过电压调节器以产生
  励磁机励磁电压。
- 直流旋转励磁机对直流换向器旋转励磁机进行建模，该励磁机
  产生励磁电压并将其施加到受控同步电机。该模块还将励磁电压
  反馈到励磁系统。
- 电源对受控整流器的电源与机端电压的
  依赖性进行建模。

### 电流补偿器和电压测量传感器

电流补偿器建模为：

VC1=VT+ITRC2+XC2，

其中：

- *RC* 是负载补偿
  电阻。
- *XC* 是负载补偿
  电抗。

电压测量传感器实现为具有时间
常数 *TR* 的低通滤波器模块。要查看确切的离散和
连续实现，请参阅低通
滤波器。

### Excitation Control Elements

此图展示了励磁控制元件的整体结构：

图中：

- Summation Point Logic 子系统为过励限制器（OEL）、欠励限制器（UEL）和定子电流限制器（SCL）电压建模了求和点输入位置。有关将此模块与限制器配合使用的详细信息，请参阅 Field Current Limiters。
- Low-Pass Filter 模块为电压调节器的主要动态特性建模。此处，*KA* 为调节器增益，*TA* 为调节器的主要时间常数。该模块的最小和最大抗积分饱和限幅分别为 *VRmin* 和 *VRmax*。
- PID\_R 子系统为用作自动电压调节器控制结构的 PID 控制器建模。该模块的最小和最大抗积分饱和限幅分别为 *VRmax / KA* 和 *VRmin / KA*。
- Take-over Logic 子系统为 OEL、UEL 和 SCL 电压建模了接管点输入位置。有关将此模块与限制器配合使用的详细信息，请参阅 Field Current Limiters。
- Filtered Derivative 模块为用于稳定励磁系统的速率反馈路径建模。此处，*KF* 和 *TF* 分别为该系统的增益和时间常数。要查看精确的离散和连续实现，请参阅 Filtered Derivative。

### Field Current Limiters

您可以使用各种励磁电流限制器在不安全运行条件下修改电压调节器的输出：

- 使用过励限制器防止因励磁电流需求过大而导致励磁绕组过热。
- 使用欠励限制器在励磁过低时提升励磁，因为励磁过低可能导致失步。
- 使用定子电流限制器防止因电流过大而导致定子绕组过热。

将上述任一限制器的输出连接到以下任一位置：

- 求和点，作为自动电压调节器（AVR）反馈回路的一部分
- 接管点，以覆盖 AVR 的常规行为

如果在求和点使用定子电流限制器，请使用单输入 **V\_SCLsum**。如果在接管点使用定子电流限制器，请同时使用过励输入 **V\_OELscl** 和欠励输入 **V\_UELscl**。

### DC Rotating Exciter

此图展示了直流换向器旋转励磁机的整体结构：

图中：

- 励磁机励磁电流 *VFE* 是两个信号之和：

  - 非线性函数 *Vx* 为励磁机输出电压的饱和建模。

### Power Source

您可以使用 **Logical switch 1** 参数更改受控整流器的电源表示。受控整流器的电源既可以来自端电压（`Position A: power source derived from terminal voltage`），也可以独立于端电压（`Position B: power source independent from the terminal conditions`）。
