# Model Reference Adaptive Controller

## 端口

### 输入

### **r** — 被控对象参考，*r* 标量

被控对象系统参考信号。

**数据类型：** `single` | `double`

### **y** — 被控对象输出，*y* 标量

被控对象系统输出信号。

**数据类型：** `single` | `double`

### **Reset** — 积分器复位标量

积分器的外部复位信号（上升沿）。

**数据类型：** `Boolean`
### 输出

### **u** — 控制器调整后输出，*u* 标量

调整后的控制信号。

**数据类型：** `single` | `double`

## 参数

### 控制器参数

### **比例增益** — 控制器比例增益，*Kp* `1`（默认）| 正标量

控制器的比例增益，*Kp*。

### **积分增益** — 控制器积分增益，*Ki* `1`（默认）| 正标量

控制器的积分增益，*Ki*。

### **微分增益** — 控制器微分增益，*Kd* `0`（默认）

控制器的微分增益，*Kd*。

### **抗积分饱和增益** — 控制器抗积分饱和增益 `1`（默认）| 正标量

控制器的抗积分饱和增益。

### **使用滤波微分** — 滤波选项 `on`（默认）| off

选择是否对参考信号使用滤波器系数。

#### 依赖关系

仅当选中 **使用滤波微分** 复选框时，**滤波器系数** 参数才可见。

### **滤波器系数** — 参考信号滤波器系数 `100`（默认）

参考信号的滤波器系数。

#### 依赖关系

仅当选中 **使用滤波微分** 复选框时，此参数才可见。

### **控制作用上限** — 控制信号上限，*upid\_max* `5`（默认）

控制信号的上界。

### **控制作用下限** — 控制信号下限，*upid\_min* `-5`（默认）

控制信号的下界。

### **采样时间（-1 表示继承）** — 模块采样时间 `-1`（默认）| 正标量

连续模块执行之间的时间，以 s 为单位。执行期间，模块产生输出，并在适当时更新其内部状态。有关详细信息，请参阅 What Is Sample Time? 和 Specify Sample Time。

如果此模块位于触发子系统内，请将此参数设置为 `-1` 以继承采样时间。如果此模块位于连续可变步长模型中，请使用正标量显式指定采样时间。

#### 依赖关系

如果将 **采样时间（-1 表示继承）** 设置为 `-1`，并在 **参考模型** 设置中将 **模型参数化** 设置为 `Continuous-time`，则 **离散化采样时间** 参数将在 **参考模型** 设置中可见。

### 参考模型

### **模型参数化** — 离散或连续模型选项 `Discrete-time`（默认）| `Continuous-time`

控制器的数学模型。

#### 依赖关系

选择：

- `Discrete-time` 会使离散时间参数可见。
- `Continuous-time` 会使连续时间参数可见。此外，在 **控制器参数** 设置中，如果 **采样时间（-1 表示继承）** 设置为 `-1`，选择此选项会使 **离散化采样时间** 参数在 **参考模型** 设置中可见。

### **离散时间分子** — 离散时间传递函数分子 `[0.01 -0.0099]`（默认）

离散时间传递函数的分子。

#### 依赖关系

为 **模型参数化** 选择 `Discrete-time` 会使此参数可见。

### **离散时间分母** — 离散时间传递函数分母 `[1 -1.9801 0.9802]`（默认）| 向量

离散时间传递函数的分母。

#### 依赖关系

为 **模型参数化** 选择 `Discrete-time` 会使此参数可见。

### **离散化采样时间** — 离散化采样时间 `0.01`（默认）| `-1` 或正数

连续离散化之间的时间，以 seconds 为单位。如果模块采样时间继承，请显式指定离散化采样时间。

#### 依赖关系

仅当满足以下两个条件时，此参数才可见：

- 在 **控制参数** 设置中，**采样时间（-1 表示继承）** 设置为 `-1`。
- 在 **参考模型** 设置中，**模型参数化** 设置为 `Continuous-time`。

### **连续时间分子** — 连续时间传递函数分子 `[1 1]`（默认）| 向量

连续时间传递函数的分子。

#### 依赖关系

为 **模型参数化** 选择 `Continuous-time` 会使此参数可见。

### **连续时间分母** — 连续时间传递函数分母 `[1 2 1]`（默认）| 向量

连续时间传递函数的分母。

#### 依赖关系

为 **模型参数化** 选择 `Continuous-time` 会使此参数可见。

### 调整机制

### **学习率** — *γ* `0.5`（默认）

对被控对象变化的调整速率。

## 描述

基于离散时间 PID 的模型参考自适应控制

Model Reference Adaptive Controller 模块实现离散时间比例-积分-微分（PID）模型参考自适应控制（MRAC）。MRAC 系统的三个主要组成部分是参考模型、调整机制和控制器。

### 方程

控制方程为

upid(k)=[Kp+KiTszz−1+Kdz−1Tsz]e(k),

其中：

- *upid* 是控制器输出。
- *Kp* 是比例增益。
- *Ki* 是积分增益。
- *Kd* 是微分增益。
- *Ts* 是采样时间。
- *e* 是误差。

参考模型是闭环系统的传递函数。该模型体现闭环系统的期望行为。它实现为离散时间传递函数

Gm(z)=B(z)A(z).

调整机制根据被控对象输出与参考模型输出之间的误差，按下式调整控制作用

θ=(y−ym)ym−γTszz−1,

其中：

- *θ* 是自适应参数。
- *y* 是被控对象输出。
- *ym* 是参考模型输出。
- *γ* 是学习率。

增大 *γ* 的值会使对被控对象变化的适应更快。

调整后的控制信号 *u* 为

u(k)=upid(k)θ(k).
