# SPDT Relay

## 端口

### 输入

### **PS** — 物理信号控制物理信号

使继电器通电和断电的物理信号输入端口。

#### 依赖关系

要启用此端口，请在 **主设置** 中，将 **控制端口** 参数设置为 `PS`。

### 输出

### **x** — 继电器状态物理信号

以 **C**–**S1** 和 **C**–**S2** 连接表示的继电器状态：

- 1 — 闭合连接
- 0 — 断开连接

#### 依赖关系

要启用此端口，请在 **主设置** 中，将 **状态端口** 参数设置为 `Visible`。

### 守恒

### **S1** — 常闭触点电气

与常闭触点关联的电气守恒端口。

### **C** — 公共触点电气

与公共触点关联的电气守恒端口。

### **S2** — 常开触点电气

与常开触点关联的电气守恒端口。

### **+** — 绕组正极端子电气

与绕组正电压端子关联的电气守恒端口。通过绕组的电流控制继电器状态。

#### 依赖关系

要启用此端口，请在 **主设置** 中，将 **控制端口** 参数设置为 `Electrical`。

### **-** — 绕组负极端子电气

与绕组负电压端子关联的电气守恒端口。通过绕组的电流控制继电器状态。

#### 依赖关系

要启用此端口，请在 **主设置** 中，将 **控制端口** 参数设置为 `Electrical`。

## 描述

带延迟和故障的单刀双掷继电器

SPDT Relay 模块对单刀双掷继电器进行建模。该模块具有三种可能状态：

- 未激励 — 公共触点 **C** 连接到常闭触点 **S1**。
- 激励 — 公共触点 **C** 连接到常开触点 **S2**。
- 开路 — 继电器断开。公共触点 **C** 未连接到常闭触点 **S1** 或常开触点 **S2**。

您可以：

- 使用物理信号输入端口或电气守恒端口控制继电器状态。
- 输出继电器状态。
- 延迟一个或两个连接的断开和闭合。
- 引入行为故障或时间故障，导致连接卡住、开路或触点电阻退化。

### 继电器状态控制

该模块有两种控制变体：

- 物理信号 (PS) 控制 — 继电器状态取决于输入物理信号的值与继电器阈值的比较结果。继电器阈值 *th* 是您为 **阈值** 参数指定的值。
- 电气控制 — 继电器状态取决于流过正负电气守恒端口的电流与继电器上、下阈值的比较结果，这些端口表示继电器绕组。上、下阈值取决于您在 **绕组** 设置中为参数指定的值。

对于 PS 控制变体，在仿真开始时：

- 如果输入信号 *PS* 小于或等于 *th*，则继电器未激励，公共触点 **C** 连接到常闭触点 **S1**。
- 如果输入信号 *PS* 大于 *th*，则继电器激励，**C** 连接到常开触点 **S2**。

仿真开始后，如果 *PS* 升至 *th* 以上，则模块从未激励状态进入激励状态：

- **C**–**S1** 连接在 **C-S1 连接断开时间** 中指定的延迟后断开。
- **C**–**S2** 连接在 **C-S2 连接闭合时间** 中指定的延迟后闭合。

如果模块从激励状态进入未激励状态，即 *PS* 降至 *th* 或以下：

- **C**–**S2** 连接在 **C-S2 连接断开时间** 中指定的延迟后断开。
- **C**–**S1** 连接在 **C-S1 连接闭合时间** 中指定的延迟后闭合。

对于电气控制变体，上、下阈值取决于 **额定电压**、**吸合额定电压百分比**、**释放额定电压百分比** 和 **绕组串联电阻** 参数的指定值。额定电流为：

irated=Vratedrcoil.

上电流阈值 *ienergized* 的方程为：

ienergized\_current=Rated Voltage\*Percent rated voltage to energizeWinding series resistance .

下电流阈值 *ide-energized* 的方程为：

ide−energized\_current=Rated Voltage\*Percent rated voltage to de−energizeWinding series resistance .

在仿真开始时：

- 如果控制电流小于 *ienergized*，则公共触点 **C** 连接到常闭触点 **S1**。
- 如果控制电流大于 *ienergized*，则继电器激励，**C** 连接到常开触点 **S2**。

仿真开始后，如果电流升至 *ienergized* 以上，则模块从未激励状态进入激励状态：

- **C**–**S1** 连接在 **C-S1 连接断开时间** 中指定的延迟后断开。
- **C**–**S2** 连接在 **C-S2 连接闭合时间** 中指定的延迟后闭合。

如果电流降至 *ide-energized* 以下，则模块从激励状态进入未激励状态：

- **C**–**S2** 连接在 **C-S2 连接断开时间** 中指定的延迟后断开。
- **C**–**S1** 连接在 **C-S1 连接闭合时间** 中指定的延迟后闭合。

### 故障

要对 SPDT Relay 模块中的故障建模，请在 **Faults** 部分中，单击要建模故障旁边的 **Add fault**。有关故障建模的详细信息，请参阅故障行为建模和故障触发。

可以将开关故障或开路故障添加到绕组。如果添加开关故障，可以将 **Switch fault** 参数设置为：

- `C-S1 stuck closed`
- `C-S2 stuck closed`
- `C open circuit (no path to S1 or S2)`
- `Degraded contact resistance`

可以使用 **Trigger type** 参数指定故障的发生方式和时间。

有关向模块添加故障和指定故障触发的详细信息，请参阅 Simscape 故障简介。

****C**–**S1** 卡闭故障**

如果公共触点 **C** 机械地、电气地或化学地卡在常闭触点 **S1** 上，则发生 **C**–**S1** 卡闭故障。此类故障的原因包括：

- 触点熔焊，可能是由于浪涌电流或分断电流超过额定值或负载短路。
- 机械损坏。
- 绝缘劣化。
- 感性电压。

下表显示了 **C**–**S1** 卡闭故障的故障状态。

| 连接 | 状态 |
| --- | --- |
| **C**–**S1** | 1 |
| **C**–**S2** | 0 |

仅当负载电流超过电流阈值的时间超过行为触发时间阈值时，才会发生 **C**–**S1** 卡闭行为故障。也就是说，仅当以下条件成立时，行为故障才会发生：

iload>ith,

并且

ti>i\_th>tth\_b,

其中：

- *iload* 是负载电流。
- *ith* 是 **Maximum permissible load current** 参数的值。
- *ti>i\_th* 是超过电流阈值的时间。
- *tth\_b* 是 **Time to fail when exceeding current** 参数的值。

当故障发生时，如果 **C**–**S1** 为：

- 闭合 — **C**–**S1** 在仿真的剩余时间内保持闭合。
- 断开 — **C**–**S1** 故障不会生效，除非继电器失电并且 **C**–**S1** 连接闭合。一旦闭合，**C**–**S1** 连接在仿真的剩余时间内保持闭合。

****C**–**S2** 卡闭故障**

如果公共触点 **C** 机械地、电气地或化学地卡在常闭触点 **S2** 上，则发生 **C**–**S2** 卡闭故障。此类故障的原因包括：

- 触点熔焊，可能是由于浪涌电流或分断电流超过额定值或负载短路。
- 机械损坏。
- 绝缘劣化。

下表显示了 **C**–**S2** 卡闭故障的故障状态。

| 连接 | 状态 |
| --- | --- |
| **C**–**S1** | 0 |
| **C**–**S2** | 1 |

仅当负载电流超过电流阈值的时间超过行为触发时间阈值时，才会发生 **C**–**S2** 卡闭行为故障。也就是说，仅当以下条件成立时，行为故障才会发生：

iload>ith,

并且

ti>i\_th>tth\_b,

其中：

- *iload* 是负载电流。
- *ith* 是 **Maximum permissible load current** 参数的指定值。
- *ti>i\_th* 是超过电流阈值的时间。
- *tth\_b* 是 **Time to fail when exceeding current** 参数的指定值。

当故障发生时，如果 **C**–**S2** 为：

- 闭合 — **C**–**S2** 在仿真的剩余时间内保持闭合。
- 断开 — **C**–**S2** 故障不会生效，除非继电器得电并且 **C**–**S2** 连接闭合。一旦闭合，**C**–**S2** 连接在仿真的剩余时间内保持闭合。

****C** 开路（无路径到 **S1** 或 **S2**）故障**

如果公共触点 **C** 机械地卡在断开位置，则发生 **C** 开路（无路径到 **S1** 或 **S2**）故障。如果出现以下情况，可能发生此类故障：

- 存在触点损坏或劣化。
- 开关连接器机械地卡在继电器中间。

下表显示了 **C** 开路（无路径到 **S1** 或 **S2**）故障的故障状态。

| 连接 | 状态 |
| --- | --- |
| **C**–**S1** | 0 |
| **C**–**S2** | 0 |

仅当负载电流超过电流阈值的时间超过行为触发时间阈值时，才会发生 **C** 开路行为故障。也就是说，仅当以下条件成立时，行为故障才会发生：

iload>ith,

并且

ti>i\_th>tth\_b,

其中：

- *iload* 是负载电流。
- *ith* 是 **Maximum permissible load current** 参数的值。
- *ti>i\_th* 是超过电流阈值的时间段。
- *tth\_b* 是 **Time to fail when exceeding current** 参数的值。

当超过时间故障阈值时，如果：

- 继电器处于开路状态，即一个连接已断开，而另一个连接尚未接通，则继电器在仿真的剩余时间内保持断开。
- **C**–**S1** 或 **C**–**S2** 连接闭合，则故障不会生效，除非继电器得电或失电并且该闭合连接断开。如果该连接断开，则继电器变为开路，并在仿真的剩余时间内保持开路。

当超过行为故障阈值时，如果：

- 继电器处于开路状态，即一个连接已断开，而另一个连接尚未接通，则继电器在仿真的剩余时间内保持断开。
- **C**–**S1** 或 **C**–**S2** 连接闭合，则继电器状态立即变为开路，并在仿真的剩余时间内保持开路。

**接触电阻退化故障**

接触电阻退化故障的原因包括：

- 过度使用引起的过载条件。高浪涌电流和电压可引起过载条件，继电器的过度切换也可引起过载条件。过载条件最终触发电弧，产生热量使触点材料退化。
- 化学污染干扰继电器触点的操作。污染物可能包括氧化膜或异物颗粒，往往会产生高或不稳定的接触电阻读数。
- 继电器寿命终止。

下表显示了接触电阻退化故障的故障状态。

| 连接 | 状态 |
| --- | --- |
| **C**–**S1** | 0 或 1。接触电阻已退化。 |
| **C**–**S2** | 0 或 1。接触电阻已退化。 |

当发生时间故障时，**S1** 和 **S2** 的退化接触电阻为：

rcontact\_s1(t)=rcontact\_fault\_s1−(rcontact\_fault\_s1−rcontact)sech(t−tth\_tτ),

rcontact\_s2(t)=rcontact\_fault\_s2−(rcontact\_fault\_s2−rcontact)sech(t−tth\_tτ),

其中：

- *rcontact\_fault\_s1* 是故障 **S1** 接触电阻的最终值。
- *rcontact\_fault\_s2* 是故障 **S2** 接触电阻的最终值。
- *rcontact* 是未故障 **S1** 和 **S2** 接触电阻。

仅当负载电流超过电流阈值的时间超过行为触发时间阈值时，才会发生接触电阻退化行为故障。也就是说，仅当以下条件成立时，行为故障才会发生：

iS1−C>ith,

并且

ti1>i\_th>tth\_b,

其中：

- *iload* 是负载电流。
- *ith* 是 **Maximum permissible load current** 参数的值。
- *ti1>i\_th* 是连接 **C-S1** 的电流阈值被超过的时间段。
- *tth\_b* 是 **Time to fail when exceeding current** 参数的值。

对于行为触发的故障，如果 iS1−C>ith 在时间区间 *tth\_b* 内连续成立，

rcontact\_s1(t)=rcontact\_fault\_s1−(rcontact\_fault\_s1−rcontact)sech(ti1>i\_th−tth\_bτ),

其中：

- *iS1-C* 是公共触点至常闭触点 **C**–**S1** 的电流。
- *ith* 是 **Maximum permissible load current** 参数的指定值。
- *tth\_b* 是 **Time to fail when exceeding current** 参数的指定值。
- *rcontact\_fault\_s1* 是故障 **S1** 接触电阻的最终值。
- *rcontact* 是未故障 **S1** 接触电阻。
- *τ* 是 **Time constant for degraded contact resistance** 参数的指定值。

同样，对于 **C**–**S2** 连接，如果

iS2−C>ith

并且

ti2>i\_th>tth\_b,

则退化接触电阻为：

rcontact\_s2(t)=rcontact\_fault\_s2−(rcontact\_fault\_s2−rcontact)sech(ti2>i\_th−tth\_bτ),

其中：

- *iS2-C* 是公共触点至常闭触点 **C**–**S2** 的电流。
- *rcontact\_fault\_s2* 是故障 **S2** 接触电阻的最终值

当超过时间故障阈值时，对于 **C**–**S1** 和 **C**–**S2** 两个连接，接触电阻立即退化，并在仿真的剩余时间内保持退化。

当 **C**–**S1** 的行为故障阈值被超过时，以 *iS1-C* 表示，**C**–**S1** 连接的电阻在 **Time to fail when exceeding current** 参数的指定值之后退化，并在仿真的剩余时间内保持退化。

当 **C**–**S2** 的行为故障阈值被超过时，以 *iS2-C* 表示，**C**–**S2** 连接的电阻在 **Time to fail when exceeding current** 参数的指定值之后退化，并在仿真的剩余时间内保持退化。

**绕组失效开路**

开路绕组故障仅适用于电气控制变体。绕组线圈中的开路可导致此类故障。

下表显示了绕组失效开路故障的故障状态。

| 连接 | 状态 |
| --- | --- |
| **C**–**S1** | 1 |
| **C**–**S2** | 0 |

对于定时故障，模块将绕组电流近似为：

Ldidt+Ri=vwinding\*sech(t−tth\_tτ),

其中：

- *L* 是绕组电感。
- *R* 是绕组电阻。
- *i* 是绕组电流。
- *vwinding* 是绕组两端的电压。
- *tth\_t* 是 **Trigger fault at time** 参数的值。
- *τ* 是 **Time constant for winding open circuit transition** 参数的值。

仅当满足以下条件之一时，才会发生绕组失效开路行为故障：

- 绕组电流超过电流阈值的时间超过行为触发时间阈值。
- 绕组电压超过电压阈值的次数超过电压过载次数阈值。

也就是说，仅当以下条件成立时，行为故障才会发生：

iwinding>ith

然后

ti>i\_th>tth\_b,

其中：

- *iwinding* 是绕组电流。
- *ith* 是 **Maximum permissible winding current** 参数的指定值。
- *ti>i\_th* 是超过电流阈值的时间。
- *tth\_b* 是 **Time to fail when exceeding current** 参数的指定值。

或者如果：

vwinding>vth,

然后

Nv>v\_th>Nth,

其中：

- *vwinding* 是绕组电压。
- *vth* 是 **Maximum permissible winding voltage** 参数的指定值。
- *Nv>v\_th* 是超过电压阈值的次数。
- *Nth* 是 **Number of events to fail when exceeding voltage** 参数的指定值。

一旦故障触发，**C**–**S1** 在仿真的剩余时间内保持闭合。
