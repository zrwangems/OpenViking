# Supercapacitor

## 端口

### 守恒

### **+** — 正极端子 electrical

与正极端子关联的电气守恒端口。

### **-** — 负极端子 electrical

与负极端子关联的电气守恒端口。

## 参数

#### 单元特性

### **固定电阻，[R1 R2 R3]** — 每条支路的固定电阻值 `[0.2, 90.0, 1000.0]` `Ohm`（默认）

以数组形式指定超级电容器各条支路中固定电阻器的电阻值。

### **固定电容，[C1 C2 C3]** — 每条支路的固定电容值 `[2.5, 1.5, 4.0]` `F`（默认）

以数组形式指定超级电容器中固定电容器的各个电容值。

### **电压相关电容器增益** — 第一条支路的可变电容系数 `0.95` `F/V`（默认）

指定超级电容器第一条支路中电压相关电容器的可变电容系数 *Kv*。有关确定可变电容系数的信息，请参阅 [1]。

### **自放电电阻** — 自放电电阻 `inf`（默认）

指定连接在两个端子之间的超级电容器自放电电阻。

#### 配置

### **串联单元数** — 串联的超级电容器单元数 `1`（默认）

指定超级电容器中采用串联配置的单元数。

### **并联单元数** — 并联的超级电容器单元数 `1`（默认）

指定超级电容器中采用并联配置的单元数。

#### 变量

### **起始值** — 初始目标值 `0`（默认）

在仿真之前，使用 **变量** 选项卡设置模块变量的优先级和初始目标值。有关详细信息，请参阅 Set Priority and Initial Target for Block Variables。

## 描述

电化学双电层电容器

Supercapacitor 模块表示电化学双电层电容器（ELDC），通常称为超级电容器或超大容量电容器。超级电容器的电容值比普通电容器大若干个数量级。超级电容器可以快速充电和放电，因此能够提供能量脉冲。

使用单个 Supercapacitor 模块，你可以对任意数量串联或并联的超级电容器单元建模。为此，将相关参数（即 **串联单元数** 或 **并联单元数**）设置为大于 `1` 的值。在内部，该模块仅对单个超级电容器单元的方程进行仿真，但会计算：

- 根据串联连接的单元数计算输出电压
- 根据并联连接的单元数计算电流

与逐个单元仿真方程相比，基于单个单元的输出计算多单元超级电容器的输出更高效。

该图显示了 Supercapacitor 模块中单个单元的等效电路。该电路是常用于对超级电容器行为建模的电阻器与电容器网络。

电容器 *C1*、*C2* 和 *C3* 具有固定电容。电容器 *Cv* 的电容取决于其两端电压。电阻器 *R1*、*R2* 和 *R3* 具有固定电阻。Supercapacitor 模块中各个固定电容器两端的电压按下式计算：

Vcn=vNseries−inRn,

其中：

- *v* 是模块两端的电压。
- *Nseries* 是串联单元数。
- *n* 是支路编号。*n* = [1, 2, 3]。
- *in* 是第 *n* 条支路中的电流。
- *Rn* 是第 *n* 条支路中的电阻。
- *Vcn* 是第 *n* 条支路中电容器两端的电压。

超级电容器第一条支路中电流的方程取决于该支路中电容器两端的电压。如果电容器两端电压为正，即

Vc1>0,

则

i1=(C1+KvVc1)dVc1dt,

否则

i1=C1dVc1dt,

其中：

- *Vc1* 是第一条支路中电容器两端的电压。
- *C1* 是第一条支路中固定电容器的电容。
- *Kv* 是电压相关电容增益。
- *i1* 是第一条支路中的电流。

对于其余支路，电流定义为

in=CndVcndt,

其中：

- *n* 是支路编号。*n* =[2, 3]。
- *Cn* 是第 *n* 条支路的电容。

通过 Supercapacitor 模块的总电流为

i=Nparallel(i1+i2+i3+vRdischarge),

其中：

- *Nparallel* 是并联单元数。
- *Rdischarge* 是超级电容器的自放电电阻。
- *i* 是通过超级电容器的电流。
