# Constant Power Load (Three-Phase)

## 端口

### 守恒

### **~** — 三相电压电气

与三相电压相关联的复合三相端口。

#### 依赖项

要启用此端口，请将 **电气连接** 设置为 `Composite three-phase ports`。

### **a** — A 相电压电气

与 A 相电压相关联的扩展三相端口。

#### 依赖项

要启用此端口，请将 **电气连接** 设置为 `Expanded three-phase ports`。

### **b** — B 相电压电气

与 B 相电压相关联的扩展三相端口。

#### 依赖项

要启用此端口，请将 **电气连接** 设置为 `Expanded three-phase ports`。

### **c** — C 相电压电气

与 C 相电压相关联的扩展三相端口。

#### 依赖项

要启用此端口，请将 **电气连接** 设置为 `Expanded three-phase ports`。

## 参数

### 主要

### **电气连接** — 电气连接 `Composite three-phase ports`（默认）| `Expanded three-phase ports`

是对方模复合三相端口还是扩展三相端口进行建模。

复合三相端口使用单个模块端口表示三个独立的电气守恒端口。你可以使用复合三相端口构建对应于三相电气系统单线图的模型。

扩展三相端口使用三个独立的电气守恒端口表示三相系统的各个相。

### **额定电气频率** — 额定电气频率 `60` `Hz`（默认）| 正标量

*自 R2023a 起*

额定电气频率。

### **消耗的有功功率** — 消耗的有功功率 `1` `kW`（默认）| 标量

模块消耗的有功功率。

### **消耗的无功功率** — 消耗的无功功率 `0` `A*kV`（默认）| 标量

模块消耗的无功功率。

### **最小电源电压（相间 RMS）** — 最小电源电压 `100` `V`（默认）| 正标量

电源为使模块作为恒功率负载运行所需的最小电压，以相间 RMS 表示。

### **电压时间常数** — 电压动态时间常数 `0.01` `s`（默认）| 正标量

*自 R2023a 起*

与端子电压测量的瞬态相关联的时间常数。

### **初始电源电压（相间 RMS）** — 初始端子电压 `200` `V`（默认）| 正标量

*自 R2023a 起*

时间零点的端子电压，以相间 RMS 表示。

### **初始电源电压角度** — 时间零点的 A 相端子电压角度 `0` `deg`（默认）| 标量

*自 R2023a 起*

时间零点的 A 相端子电压角度。

### **对电气参考的寄生电导** — 对电气参考的寄生电导 `1e-6` `S`（默认）| 非负标量

*自 R2023a 起*

对电气参考的寄生电导。

### 故障

### **开路故障** — 添加开路故障的选项 `Add fault`（默认）

在 Constant Power Load (Three-Phase) 模块中添加开路故障的选项。

要添加故障，请单击 **添加故障** 超链接。

### **开路电导** — 开路电导 `1e-4` `S`（默认）| 标量

开路状态期间的电导。

#### 依赖项

要启用此参数，请通过单击 **开路故障** 参数中的 **添加故障** 超链接，向 Constant Power Load (Three-Phase) 模块添加故障。

创建故障后，可以在 **故障检查器** 窗口中更改属性。打开包含故障的模块时，将显示 **打开故障检查器** 超链接，而不是 **添加故障** 超链接。有关展示如何包含故障的示例，请参阅分析直流电枢绕组故障。

### **触发故障的时间** — 进入故障状态前的时间 `0` `s`（默认）| 非负标量

模块进入故障状态时的仿真时间。

#### 依赖项

要启用此参数，请将 **触发类型** 设置为 `Timed`。

### R2023a：改进了对感性节点的支持

在 R2023a 之前，要将 Constant Power Load (Three-Phase) 模块连接到感性节点，必须提供较大的寄生电阻。从 R2023a 开始，可以通过指定 **额定电气频率**、**电压时间常数**、**初始电源电压（相间 RMS）**、**初始电源电压角度** 和 **对电气参考的寄生电导** 参数，将此模块连接到感性节点。如果保存于较早版本中的模型包含此模块，则必须为这些参数设置适当的值。

此外，该模块的 **建模选项** 参数已重命名为 **电气连接**，并已移至 **主要** 部分。

## 描述

三相恒功率负载

Constant Power Load (Three-Phase) 模块为三相电源实现恒功率负载。

只要来自三相电源的电压等于或大于 **最小电源电压（相间 RMS）** 参数指定的值，该模块就输出标称额定功率。

当来自三相电源的电压降至 **最小电源电压（相间 RMS）** 的值以下时，负载行为会发生变化，该模块将对具有恒定阻抗的负载进行建模。

### 方程

当来自三相电源的电压大于 **最小电源电压（相间 RMS）** 参数指定的值时，该模块以恒定 PQ 模式运行。

有功功率和无功功率定义为：

P=32VpkIpkcos(φV−φI)Q=32VpkIpksin(φV−φI)

其中：

- *Vpk* 是电压峰值幅值。
- φI=φV−atan(QP) 是电流的相位。
- Ipk=23PVpkcos(φV−φI) 是电流峰值幅值。

在第一个周期内，峰值电流等于 0 A。

当来自三相电源的电压小于或等于 **最小电源电压（相间 RMS）** 参数指定的值时，该模块以恒定 Z 模式运行。

有功功率和无功功率定义为：

P=32Vpk2RR2+X2Q=32Vpk2XR2+X2

其中：

- R=V2line RMSminPP2+Q2 是恒定电阻。
- X=V2line RMSminQP2+Q2 是恒定电抗。
- *Vline
  RMSmin* 是
  **最小电源电压（相间
  RMS）**。

### 潮流分析

如果该模块位于与频率-时间仿真模式兼容的网络中，则可以对该网络执行潮流分析。潮流分析提供稳态值，可用于初始化电机。

有关详细信息，请参阅使用 Simscape Electrical 和频率与时间仿真模式执行潮流分析。

### 故障

要对 Constant Power Load (Three-Phase) 模块中的故障进行建模，请在 **故障** 部分中，单击要建模的故障旁边的 **添加故障**。有关故障建模的详细信息，请参阅故障行为建模和故障触发。

Constant Power Load (Three-Phase) 模块允许将电气故障建模为开路。该模块可以在特定时间触发故障事件。
