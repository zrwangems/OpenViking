# Variable Gap Capacitor

## 端口

### 守恒

### **+** — 正极端子电气

与电容器正极端子关联的电气守恒端口。

### **-** — 负极端子电气

与电容器负极端子关联的电气守恒端口。

### **R** — 随动板机械平移

与随动板关联的机械平移守恒端口。

### **C** — 基板机械平移

与基板关联的机械平移守恒端口。

## 参数

### **电容器极板面积** — 电容器极板面积 `1e-3` `m^2` (默认) | positive scalar

极板面积。

### **电介质厚度** — 电介质厚度 `1e-4` `m` (默认) | positive scalar

电介质的厚度。

### **指定电介质属性** — 用于指定电介质属性的选项 `Off` (默认) | `On`

用于指定电介质属性的选项。如果清除此参数，模块假定电介质为真空，并且弹性力为零。

### **电介质相对介电常数** — 电介质的相对介电常数 `1.0` (默认) | positive scalar

电介质相对于真空介电常数的介电常数。

#### 依赖关系

要启用此参数，请选择 **指定电介质属性** 参数。

### **电介质材料的杨氏模量** — 电介质材料的杨氏模量 `0` `Pa` (默认) | nonnegative scalar

电介质材料的杨氏模量。

#### 依赖关系

要启用此参数，请选择 **指定电介质属性** 参数。

## 描述

具有平行极板和可变间隙的电容器

Variable Gap Capacitor 模块对具有平行极板和可变间隙的电容器进行建模。当向该模块施加电压时，该电压会在极板之间产生电场，从而产生静电吸引力。

您可以通过选择 **指定电介质属性** 参数来指定电介质的属性。如果指定电介质材料的杨氏模量，则极板之间的位移会使电介质变形，从而产生弹性力。如果不指定电介质的属性，则该模块假定电介质为真空，并且位移不会产生弹性力。

当电容器充电时，平移力也会影响电容器的电容、电流和电压。

### 方程

电容由以下方程定义：

C=ε0εAd+x,

其中：

- ε0 是真空的介电常数。
- *ε* 是 **电介质相对介电常数** 参数。
- *A* 是 **电容器极板面积** 参数。
- *d* 是 **电介质厚度** 参数。
- *x* 是极板的位移。

静电吸引力由以下方程给出：

F=C2V22Aε0ε,

其中 *V* 是电容器两端的电压。

弹性力由以下方程给出：

Fdef=EAxd,

其中 *E* 是 **电介质材料的杨氏模量** 参数。

通过该模块的总力是静电吸引力与弹性力之和。
