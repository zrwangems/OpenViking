# Diffusion Resistor

## 端口

### 守恒

### **+** — 正端子电气

与电阻正端子关联的电气守恒端口。

### **-** — 负端子电气

与电阻负端子关联的电气守恒端口。

表示电阻热质量的热守恒端口。

## 参数

### **建模选项** — 是否启用热端口 `No thermal port`（默认） | `Show thermal port`

是否启用模块的热端口，并指定电阻值如何随温度变化以及设置热质量。

### 主要

### **电阻** — 标称零偏置电阻 `1` `Ohm`（默认）

零偏置电阻，用作标称电阻值。电阻值必须大于零。如果将 **建模选项** 设置为 `Show thermal port`，则这是在热部分中 **测量温度** 参数所对应温度下的零偏置电阻。

### **容差 (%)** — 电阻容差，以百分比表示 `5`（默认）

根据制造商数据手册定义的电阻容差。

### **容差应用** — 选择仿真期间如何应用容差 `None — use nominal value`（默认） | `Random tolerance` | `Apply maximum tolerance value` | `Apply minimum tolerance value`

选择仿真期间如何应用容差：

- `None — use nominal value` — 模块不应用容差，使用标称电阻值。
- `Random tolerance` — 模块在容差值限制内对电阻值应用随机偏移。可以使用 **容差分布** 参数选择 Uniform 或 Gaussian 分布来计算随机数。
- `Apply maximum tolerance value` — 电阻增加指定的容差百分比值。
- `Apply minimum tolerance value` — 电阻减小指定的容差百分比值。

### **容差分布** — 选择分布类型 `Uniform`（默认） | `Gaussian`

选择随机容差的分布类型：

- `Uniform` — 均匀分布
- `Gaussian` — 高斯分布

## 描述

具有速度饱和以及可选容差、工作限值、故障行为和噪声的电阻模型

Diffusion Resistor 模块表示一个具有速度饱和的电阻，同时允许您对以下效应建模：

- 容差
- 工作限值
- 故障
- 热噪声
- 模型热效应

您可以相互独立地打开和关闭这些建模选项。

在其最简单的形式中，Diffusion Resistor 模块的电阻为：

R=R0(1−p2−p3+p21+(θ2vpn)2+p31+|θ3vpn|33)

其中：

- *R0* 是零偏置电阻。
- *p2* 和
  *p*3 分别是二次和线性
  电压系数。
- *θ2* 和
  *θ*3 分别是二次和线性电压激活的反向电压。
- *vpn* 是施加在电阻两端的电压。

在低偏置下，

R≈R0(1+p2θ22vpn22)

因此 *p2* 和
*θ2* 决定了电阻的低偏置二次行为。

在高偏置下，

R≈R0(1−p2−p3+|vpn|(p2θ2+p3θ3))

因此 *p3* 和
*θ3* 仅影响电阻的高偏置线性行为。

您可以使用电阻的电压依赖性来对扩散电阻中的速度饱和建模。对于足够高的电压，

isat=1R0(p2θ2+p3θ3)

其中 *isat* 是饱和电流。

### 简化参数化

简化参数化模型假设二次和线性系数相同。这是 Compact Model Coalition 为 r2\_cmc 模型提供的推荐假设之一，可作为执行参数提取时合理的初始猜测。使用此假设，可以定义两个新参数，**Critical voltage** 和 **Corner voltage**，它们提供了一种更简单的模型参数化方法：

p2=p3=vco/(2vcrit)
θ2=θ3=1/(2vco)

其中：

- *vcrit* 是 critical voltage。
- *vco* 是 corner voltage。

在高电压下，

dR/dvpn≈R0/vcrit

因此，critical voltage 是 *R*/*R0* 随电压增大的斜率的倒数。

使用此参数化，饱和电流为

isat=vcrit/R0

### 容差

可以对为 **Resistance** 参数提供的标称值应用容差。数据手册通常会为给定电阻器类型提供容差百分比。下表显示了模块如何根据所选的 **Tolerance application** 选项应用容差并计算电阻。

| 选项 | 电阻值 |
| --- | --- |
| `None — use nominal value` | *R*0 |
| `Random tolerance` | 均匀分布：*R0* · (1 – *tol* + 2· *tol*· `rand`)  高斯分布：*R0* · (1 + *tol* · `randn` / *nSigma*) |
| `Apply maximum tolerance value` | *R0* · (1 + *tol* ) |
| `Apply minimum tolerance value` | *R0* · (1 – *tol* ) |

表中，

- *R*0 是 **Resistance** 参数值，即标称零偏置电阻。
- *tol* 是小数容差，**Tolerance (%)** /100。
- *nSigma* 是为 **Number of standard deviations for quoted tolerance** 参数提供的值。
- `rand` 和 `randn` 是用于生成均匀分布和正态分布随机数的标准 MATLAB® 函数。

**注意**

如果选择 `Random tolerance` 选项且处于 "Fast Restart" 模式，则只要小数容差 *tol* 或 **Number of standard deviations for quoted tolerance** *nSigma* 中至少有一个设置为 Run-time 并使用变量定义（即使不修改该变量），每次仿真都会更新随机容差值。

### 工作限值

可以按功率和最大工作电压指定工作限值。如果将 **Modeling option** 参数设置为 `Show thermal port`（参见 Model Thermal Effects），还可以按温度指定工作限值。

当超过工作限值时，模块可以生成警告，也可以因错误停止仿真。有关详细信息，请参阅 Operating Limits parameters 部分。

### 故障

要对 Diffusion Resistor 模块中的故障建模，请在 **Faults** 部分中，单击要建模的故障旁边的 **Add fault**。有关故障建模的详细信息，请参阅 Fault Behavior Modeling 和 Fault Triggering。

Diffusion Resistor 模块允许将电气故障建模为电阻的瞬时变化。模块可以触发故障事件：

- 在特定时间。
- 当电流超过最大允许值的时间超过特定时间间隔时。

如果要在特定时间触发故障，请在 **Fault Inspector** 窗口中将 **Trigger type** 设置为 `Timed`。如果要确定系统是否发生故障以及何时发生故障，请在 **Fault Inspector** 窗口中将 **Trigger type** 设置为 `Behavioral`。

当电阻器发生故障时，其电阻将更改为为 **Faulted zero-voltage resistance** 参数指定的值。

### 热噪声

Diffusion Resistor 模块可以生成热噪声电流。如果将 **Noise mode** 参数设置为 `Enabled`，则模块包含一个与扩散电阻器并联的噪声电流源。

如果采样时间为 *h*，则热噪声由下式给出：

iN=sqrt(2kT/R) N(0,1)/sqrt(h)

其中：

- *k* 是 Boltzmann 常数，1.3806504e-23 J/K。
- *T* 是温度。
- *R* 是电阻。
- *N* 是均值为零、标准差为一的高斯随机数。
- *2kT/R* 是双边热噪声功率分布（单边等效为 *4kT/R*）。

模块通过使用 Simscape™ Foundation 库中的 PS Random Number 源生成高斯噪声。可以通过设置 **Repeatability** 参数来控制随机数种子：

- `Not repeatable` — 每次仿真模型时，模块使用 MATLAB 随机数生成器重置随机种子：

  ```
  seed = randi(2^32-1);
  ```
- `Repeatable` — 模块自动生成种子值并将其存储在模块内部，以便始终使用相同的随机数开始仿真。当从模块库中将 Diffusion Resistor 模块添加到模型时，会设置此自动生成的种子值。当从模型中的现有 Diffusion Resistor 模块创建新副本时，会生成新的种子值。模块使用上面显示的 MATLAB 随机数生成器命令设置该值。
- `Specify seed` — 如果选择此选项，则附加的 **Seed** 参数允许直接指定随机数种子值。

### 热效应建模

可以暴露热端口，以指定电阻值如何随温度变化并设置热质量。要暴露热端口，请将 **Modeling option** 参数设置为以下任一值：

- `No thermal port` — 模块不包含热端口。
- `Show thermal port` — 模块包含一个热守恒端口。

使用 **Variables** 设置来设置初始温度目标。

如果将 **Modeling option** 参数设置为 `Show thermal port`，则电阻的定义方程会增加额外的温度缩放：

R=R0(1+TC1effΔT+TC2eff(ΔT)2)(1−p2−p3+p21+(θ2vpn)2+p31+|θ3vpn|33)

其中 TC1eff 和 TC2eff 分别是线性温度缩放系数和二次温度缩放系数。

ΔT=Tsim−Tmeas

其中：

- *T*sim 是仿真温度。
- *T*meas 是测量温度。

暴露热端口后，生成的噪声在确定瞬时噪声值时使用热端口处的温度。暴露热端口还会按如下方式扩展 **Operating Limits** 选项卡上的选项：

- **Power rating** 参数变为与温度相关。需要定义一个温度，最高到该温度时可用完整额定功率，再定义一个更高的温度，在该温度下额定功率降至零。假定额定功率在这两个温度之间随温度线性下降。
- 附加参数 **Operating temperature range, [Tmin Tmax]** 允许定义模块运行的有效温度范围。

### 变量

要在仿真前设置模块变量的优先级和初始目标值，请使用模块对话框或 Property Inspector 中的 **Initial Targets** 部分。有关详细信息，请参阅 Set Priority and Initial Target for Block Variables。

使用标称值来指定模型中变量的预期量级。使用基于标称值的系统缩放可提高仿真稳健性。标称值可以来自不同来源。其中一个来源是模块对话框或 Property Inspector 中的 **Nominal Values** 部分。有关详细信息，请参阅 System Scaling by Nominal Values。

本节仅对暴露热端口的模块出现。**Temperature** 变量允许为仿真开始时的温度指定高优先级目标。

### 基本假设和限制

启用噪声进行仿真会减慢仿真速度。选择采样时间 (*h*)，使噪声仅在关注的频率上生成，而不会在更高频率上生成。
