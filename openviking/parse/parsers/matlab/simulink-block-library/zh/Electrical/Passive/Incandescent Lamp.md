# Incandescent Lamp

## 端口

### 守恒

### **+** — 正端子电气

与灯正电压关联的电气守恒端口。

### **-** — 负端子电气

与灯负电压关联的电气守恒端口。

## 参数

### 电阻

### **参数化** — 模块参数化 `Specify resistance values directly`（默认）| `Specify currents`

选择以下模块参数化方法之一：

- `Specify resistance values
  directly` — 提供灯丝在开启时和导通稳态时的电阻值。模块基于这些值确定传热系数的值。这是默认选项。
- `Specify currents` —
  提供灯丝在开启时和导通稳态时的电流值。模块基于这些值确定传热系数的值。

### **开启时的初始电阻** — 开启时的初始电阻 `0.15` `Ohm`（默认）

灯最初开启时外部电路看到的电阻。

#### 依赖关系

仅当为 **参数化** 参数选择 `Specify resistance values directly` 时，此参数才可见。

### **导通时的稳态电阻** — 导通时的稳态电阻 `1` `Ohm`（默认）

灯导通并处于稳态时外部电路看到的电阻。此电阻应大于 **开启时的初始电阻**。

#### 依赖关系

仅当为 **参数化** 参数选择 `Specify resistance values directly` 时，此参数才可见。

### **开启时的浪涌电流** — 开启时的浪涌电流 `70` `A`（默认）

灯最初开启时流过灯的电流。

#### 依赖关系

仅当为 **参数化** 参数选择 `Specify currents` 时，此参数才可见。

### **导通时的稳态电流** — 导通时的稳态电流 `10` `A`（默认）

灯导通并处于稳态时流过灯的电流。此电流应小于 **开启时的浪涌电流**。

#### 依赖关系

仅当为 **参数化** 参数选择 `Specify currents` 时，此参数才可见。

### **额定电压** — 灯额定电压 `12` `V`（默认）

灯的额定电压，以及导通状态和开启状态下提供电阻或电流值所对应的电压值。

### **电阻温度系数** — 电阻温度系数 `0.004` `1/K`（默认）

每单位温度升高对应的电阻分数增量。

### 动态

### **热时间常数** — 热时间常数 `25` `ms`（默认）

灯开启或关闭时灯丝温度的一阶热时间常数。

### **初始灯状态** — 初始灯状态 `Off`（默认）| `On`

在 `On` 和 `Off` 之间选择。

### 故障

### **开路故障** — 添加开路故障的选项 `Add fault`（默认）

用于在 Incandescent Lamp 模块中添加开路故障的选项。

要添加故障，请单击 **Add fault** 超链接。

### **开路电阻** — 开路电阻 `1e6` `Ohm`（默认）

当灯变为开路时灯丝电阻的值。

#### 依赖关系

要启用此参数，请通过单击 **开路故障** 参数中的 **Add fault** 超链接，向 Incandescent Lamp 模块添加故障。

创建故障后，您可以在 **故障检查器** 窗口中更改属性。当您打开存在故障的模块时，将显示 **打开故障检查器** 超链接，而不是 **Add fault** 超链接。有关如何包含故障的示例，请参阅分析直流电枢绕组故障。

### **在指定时间触发故障** — 进入故障状态之前的时间 `0` `s`（默认）| 非负标量

对于大于此参数值的仿真时间，灯丝电阻将等于 **开路电阻**。为此参数指定有限值可让您模拟灯泡烧坏时的故障动态。

#### 依赖关系

要启用此参数，请将 **触发类型** 设置为 `Timed`。

## 描述

具有温度相关电阻的白炽灯

Incandescent Lamp 模块对白炽灯建模，其主要特性是电阻随着灯丝变热而增加。

在简化假设下，即灯丝的热损失率与环境温差成正比，灯丝温度由下式决定

ktcdTdt=i2R−kT

并且灯丝电阻由以下方程决定

R=R0(1+αT)

其中：

- *R0* 是开启时的初始电阻（当灯丝处于环境温度时）。
- *T* 是相对于环境温度的灯丝温度。
- α 是电阻温度系数。
- *tc* 是热时间常数。
- *k* 是传热系数。
- *R* 是灯丝电阻。
- *i* 是灯丝电流。

有两种参数化选项：

- 如果选择 `Specify resistance values directly`，模块会使用您提供的导通时和开启时的灯丝电阻值来确定传热系数的值。
- 如果选择 `Specify currents`，模块会使用您提供的导通时和开启时的灯丝电流值来确定传热系数的值。

### 故障

要在 Incandescent Lamp 模块中对故障建模，请在 **故障** 部分中，单击要建模的故障旁边的 **Add fault**。有关故障建模的更多信息，请参阅故障行为建模和故障触发。

Incandescence Lamp 模块允许您将电气故障建模为开路电阻。该模块可以在特定时间触发故障事件。当处于开路状态时，灯电阻被设置为 **开路电阻** 参数的值。
