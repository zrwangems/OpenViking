# Resistor

## 端口

### 守恒

### **+** — 正端子电气

与电阻正端子关联的电气守恒端口。

### **-** — 负端子电气

与电阻负端子关联的电气守恒端口。

### **H** — 电阻热质量热

表示电阻热质量的热守恒端口。

#### 依赖项

要启用此端口，请将 **建模选项** 设置为 `Show thermal port`。

## 参数

### **建模选项** — 是否启用热端口 `No thermal port`（默认） | `Show thermal port`

是否启用模块的热端口，以及指定电阻值如何随温度变化和设置热质量。

### 主要

### **电阻** — 标称电阻值 `1` `Ohm`（默认）

标称电阻值。电阻值必须大于零。

### **容差 (%)** — 电阻容差，以百分比表示 `5`（默认）

制造商数据表中定义的电阻容差。

### **容差应用** — 选择仿真期间如何应用容差 `None — use nominal value`（默认） | `Random tolerance` | `Apply maximum tolerance value` | `Apply minimum tolerance value`

选择仿真期间如何应用容差：

- `None — use nominal value`
  — 模块不应用容差。模块使用标称电阻值。
- `Random tolerance` — 模块在容差值限制内对电阻值应用随机偏移。您可以使用 **容差分布** 参数选择 Uniform 或 Gaussian 分布来计算随机数。
- `Apply maximum tolerance value`
  — 电阻按指定的容差百分比值增加。
- `Apply minimum tolerance value`
  — 电阻按指定的容差百分比值减小。

### **容差分布** — 选择分布类型 `Uniform`（默认） | `Gaussian`

选择随机容差的分布类型：

- `Uniform` — Uniform 分布
- `Gaussian` — Gaussian 分布

#### 依赖项

要启用此参数，请将 **容差应用** 设置为 `Random tolerance`。

### **标称容差的标准差数** — 用于计算高斯随机数 `4`（默认）

用于计算高斯随机数的标准差数。

#### 依赖项

要启用此参数，请将 **容差分布** 设置为 `Gaussian`。

### 工作限制

### **启用工作限制** — 选择 `Yes` 以在超出工作限制时启用报告 `No`（默认） | `Yes`

选择 `Yes` 以在超出工作限制时启用报告。**工作限制** 部分中的关联参数将变为可见，以便您选择报告方法并以功率和最大工作电压指定工作限制。以温度指定工作限制的参数仅对暴露热端口的模块可见（请参阅对热效应建模）。默认值为 `No`。

### **超出工作限制时的报告** — 选择报告方法 `Warn`（默认） | `Error`

选择超出工作限制时发生的情况：

- `Warn` — 模块发出警告。
- `Error` — 仿真停止并报错。

#### 依赖项

要启用此参数，请将 **启用工作限制** 设置为 `Yes`。

### **最大工作电压** — 正常运行模块所允许的最大电压 `100` `V`（默认）

正常运行模块所允许的最大电压幅度。

#### 依赖项

要启用此参数，请将 **启用工作限制** 设置为 `Yes`。

### **额定功率** — 正常运行模块所允许的最大功率 `1` `W`（默认）

正常运行模块所允许的最大功率。

如果暴露模块的热端口，此参数将变得与温度相关。您为 **额定功率** 参数指定的值适用于 **低于该温度时可用全额定功率** 参数值所指定的温度。然后额定功率随温度线性下降，直到在 **高于该温度时额定功率降至零** 参数值所指定的温度处变为 0。

#### 依赖项

要启用此参数，请将 **启用工作限制** 设置为 `Yes`。

### **低于该温度时可用全额定功率** — 全额定功率仍然适用的最高温度 `70` `degC`（默认）

**额定功率** 参数值所指定的全额定功率仍然适用的最高温度。

#### 依赖项

要启用此参数，请将 **建模选项** 设置为 `Show thermal port`。

#### 依赖项

要启用此参数，请将 **建模选项** 设置为 `Show thermal port`。

长度为 2 的行向量，指定正常运行模块所允许的最低和最高温度值。第一个元素是最低允许工作温度，第二个元素是最高允许工作温度。

## 版本历史

**在 R2009a 中引入**

### R2025a: 对瞬态条件故障建模

现在，您可以通过清除 **触发激活后保持开启** 参数来在 Resistor 模块中对可逆条件故障建模。当触发条件为 true 时，模块进入故障状态；当触发条件为 false 时，模块进入非故障状态。

在 R2025a 之前，当触发条件第一次变为 true 时，模块进入故障状态，并在仿真的剩余时间内保持故障状态。

如果您在 R2025a 之前创建模型并在 Resistor 模块中启用条件故障，则为了向后兼容，模块现在默认选择 **触发激活后保持开启** 参数。

### R2023a: 使用单个参数实现故障的时间或行为触发器

**启用时间触发器** 和 **启用行为触发器** 参数已删除，并替换为 **故障触发器** 参数。您可以将 **故障触发器** 参数设置为 `Temporal` 或 `Behavioral`。您只能启用一个触发器。

如果您在较早版本中创建模型并同时启用了时间触发器和行为触发器，现在仅启用时间触发器。因此，如果行为触发器在您的模型中导致故障，仿真结果会有所不同。

如果要在特定时间触发故障，请将 **故障触发器** 参数设置为 `Temporal`。如果要确定系统是否失效以及何时失效，请将 **故障触发器** 参数设置为 `Behavioral`。

## 描述

包含可选容差、工作限制、故障行为和噪声的 Resistor

Resistor 模块表示线性电阻，同时允许您对以下效应建模：

- 容差
- 工作限制
- 故障
- 热噪声
- 对热效应建模

您可以相互独立地打开和关闭这些建模选项。当所有附加选项都关闭时，组件行为与 Simscape™ Foundation 库的 Resistor 模块完全相同。

在其最简单的形式中，Resistor 模块对线性电阻建模，由以下方程描述：

i=v/R

其中：

- *i* 是电流。
- *v* 是电压。
- *R* 是电阻。

如果您将 **噪声模式** 参数设置为 `Enabled`，则定义方程会增加一个离散变量 *i*N 来表示热噪声，如热噪声中所述。

### 容差

您可以对为 **Resistance** 参数提供的标称值应用容差。数据手册通常会为给定电阻类型提供容差百分比。该表显示模块如何根据所选的 **Tolerance application** 选项应用容差并计算阻值。

| 选项 | 阻值 |
| --- | --- |
| `None — use nominal value` | *R* |
| `Random tolerance` | 均匀分布：*R* · (1 – *tol* + 2· *tol*· `rand`)  高斯分布：*R* · (1 + *tol* · `randn` / *nSigma*) |
| `Apply maximum tolerance value` | *R* · (1 + *tol* ) |
| `Apply minimum tolerance value` | *R* · (1 – *tol* ) |

在表中，

- *R* 是 **Resistance** 参数值，即标称阻值。
- *tol* 是分数容差，由基于百分比的 **Tolerance (%)** 参数计算得到。
- *nSigma* 是您为 **Number of standard deviations for quoted tolerance** 参数提供的值。
- `rand` 和 `randn` 是用于生成均匀分布和正态分布随机数的标准 MATLAB® 函数。

**注意**

如果您选择 `Random tolerance` 选项且处于 "Fast Restart" 模式，则只要分数容差 *tol* 或 **Number of standard deviations for quoted tolerance** 中的 *nSigma* 至少有一个设置为 Run-time 并使用变量定义（即使您不修改该变量），随机容差值就会在每次仿真时更新。

### 工作限制

您可以按功率和最大工作电压指定工作限制。如果您将 **Modeling option** 参数设置为 `Show thermal port`（请参阅对热效应建模），则还可以按温度指定工作限制。

当超出工作限制时，模块可以生成警告，也可以因错误而停止仿真。有关详细信息，请参阅 Operating Limits parameters 部分。

### 故障

要对 Resistor 模块中的故障建模，请在 **Faults** 部分中，单击要建模的故障旁边的 **Add fault**。有关故障建模的详细信息，请参阅 Fault Behavior Modeling 和 Fault Triggering。

当电阻发生故障时，其阻值会变为您为 **Faulted resistance** 参数指定的值。

**故障触发**

您可以使用 **Trigger type** 参数指定故障发生的方式和时间。

如果您将 **Trigger type** 设置为 `Behavioral`，则当电流持续超过 **Maximum permissible current** 参数值的时间长于 **Time to fail when exceeding maximum permissible current** 参数值时，Resistor 模块会触发故障事件。

如果您将 **Trigger type** 设置为 `Conditional`，则可以选择 Resistor 模块中的故障是否可逆 *(since R2025a)*。要对不可逆故障建模，请单击 **Open fault properties** 打开 Property Inspector，然后选择 **Trigger stays on once activated** 参数。当触发条件第一次变为 true 时，模块进入故障状态，并在仿真剩余时间内保持故障状态。要对可逆故障建模，请清除 **Trigger stays on once activated** 参数。当触发条件为 true 时，模块进入故障状态；当触发条件为 false 时，模块进入未故障状态。

有关向模块添加故障和指定故障触发的详细信息，请参阅 Introduction to Simscape Faults。

### 热噪声

Resistor 模块可以生成热噪声电流。如果您将 **Noise mode** 参数设置为 `Enabled`，则定义方程会增加一个离散变量 *i*N 来表示热噪声：

i=v/R+iN

如果采样时间为 *h*，则热噪声由下式给出：

iN=2kT/RN(0,1)h

其中：

- *k* 是 Boltzmann 常数，1.3806504e-23 J/K。
- *T* 是温度。
- *R* 是阻值。
- *N* 是均值为零、标准差为 1 的高斯随机数。
- *2kT/R* 是双边热噪声功率分布（单边等效值为 *4kT/R*）。

模块通过使用 Simscape Foundation 库中的 PS Random Number 源生成高斯噪声。您可以通过设置 **Repeatability** 参数控制随机数种子：

- `Not repeatable` — 每次对模型进行仿真时，模块都会使用 MATLAB 随机数生成器重置随机种子：

  ```
  seed = randi(2^32-1);
  ```
- `Repeatable` — 模块自动生成一个种子值并将其存储在模块内部，以便始终使用相同的随机数开始仿真。当您从模块库向模型添加 Resistor 模块时，会设置此自动生成的种子值。当您从模型中的现有 Resistor 模块创建新副本时，会生成新的种子值。模块使用上面显示的 MATLAB 随机数生成器命令设置该值。
- `Specify seed` — 如果选择此选项，则额外的 **Seed** 参数允许您直接指定随机数种子值。

### 对热效应建模

您可以公开热端口，以指定阻值如何随温度变化并设置热质量。要公开热端口，请将 **Modeling option** 参数设置为以下任一项：

- `No thermal port` — 模块不包含热端口。
- `Show thermal port` — 模块包含一个热守恒端口。

使用 **Variables** 选项卡设置初始温度目标。

公开热端口后，生成的噪声在确定瞬时噪声值时会使用热端口处的温度。公开热端口还会扩展 **Operating Limits** 选项卡上的选项，如下所示：

- **Power rating** 参数变为与温度相关。您需要定义一个温度，在该温度及以下可获得完整功率额定值；再定义一个更高的温度，在该温度下功率额定值降为零。假设功率额定值在这两个值之间随温度线性下降。
- 额外参数 **Operating temperature range, [Tmin Tmax]** 允许您定义模块运行的有效温度范围。

### 绘图和显示选项

如果公开热端口，您可以使用模块上下文菜单上的 **Electrical** 菜单执行绘图和显示操作。

右键单击该模块，然后从 **Electrical** 菜单中选择 **Basic characteristics**，以使用当前电阻参数在 MATLAB 图窗中绘制以 SI 单位表示的阻值。

### 变量

要在仿真前设置模块变量的优先级和初始目标值，请使用模块对话框或 Property Inspector 中的 **Initial Targets** 部分。有关详细信息，请参阅 Set Priority and Initial Target for Block Variables。

使用标称值指定模型中变量的预期量级。使用基于标称值的系统缩放可提高仿真稳健性。标称值可以来自不同来源。其中一个来源是模块对话框或 Property Inspector 中的 **Nominal Values** 部分。有关详细信息，请参阅 System Scaling by Nominal Values。

此部分仅适用于公开热端口的模块。**Temperature** 变量允许您为仿真开始时的温度指定高优先级目标。

### 假设和限制

启用噪声进行仿真会减慢仿真速度。请选择采样时间 (*h*)，使噪声仅在关注的频率处生成，而不要在更高频率处生成。
