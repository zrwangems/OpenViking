# Dynamic Load

## 端口

### 输入

### **P** — 有功功率，W 物理信号

与有功功率关联的物理信号端口，指定为标量。

### **Q** — 无功功率，V\*A 物理信号

与无功功率关联的物理信号端口，指定为标量。
### 守恒

### **+** — 正端子 电气

与 Dynamic Load 正端子关联的电气守恒端口。

### **-** — 负端子 电气

与 Dynamic Load 负端子关联的电气守恒端口。

## 参数

### 主要

### **负载类型** — 负载类型 `DC`（默认） | `AC`

负载类型。选择 `DC` 以将此负载用于直流电源，或选择 `AC` 以将此负载用于交流电源。

### **最小电源电压** — 最小直流电源电压 `20` `V`（默认） | 标量

直流电源为使该模块作为恒功率负载运行所需提供的最小电压。

#### 依赖关系

要启用此参数，请将 **负载类型** 设置为 `DC`。

### **最小消耗功率** — 最小消耗功率 `1e-3` `W`（默认） | 标量

该模块消耗的最小功率量。

#### 依赖关系

要启用此参数，请将 **负载类型** 设置为 `DC`。

### **反向电导** — 反向电导 `1e-6` `S`（默认） | 标量

电源电压变为负值时的反向电导值。

#### 依赖关系

要启用此参数，请将 **负载类型** 设置为 `DC`。

### **过渡电压宽度** — 过渡电压宽度 `1e-3` `V`（默认） | 标量

过渡电压宽度。当电源电压降到 **最小电源电压** 以下或变为负值时，此值用于确保模块行为之间的平滑过渡。

#### 依赖关系

要启用此参数，请将 **负载类型** 设置为 `DC`。

### **额定频率** — 额定频率 `60` `Hz`（默认） | 标量

额定频率。

#### 依赖关系

要启用此参数，请将 **负载类型** 设置为 `AC`。

### **最小电源电压 (RMS)** — 最小交流电源电压 `200` `V`（默认） | 标量

交流电源为使该模块作为动态负载运行所需提供的最小电压（RMS）。

#### 依赖关系

要启用此参数，请将 **负载类型** 设置为 `AC`。

### **电压时间常数** — 电压动态的时间常数 `0.01` `s`（默认） | 正标量

*自 R2024a 起*

与端子电压测量的瞬态关联的时间常数。

#### 依赖关系

要启用此参数，请将 **负载类型** 设置为 `AC`。

### **初始电源电压 (RMS)** — 初始端子电压 `300` `V`（默认） | 正标量

*自 R2024a 起*

时间为零时的端子电压（RMS）。

#### 依赖关系

要启用此参数，请将 **负载类型** 设置为 `AC`。

### **初始电源电压角度** — 端子电压的初始角度 `0` `deg`（默认） | 标量

*自 R2024a 起*

时间为零时的端子电压角度。

#### 依赖关系

要启用此参数，请将 **负载类型** 设置为 `AC`。

### 故障

### **开路故障** — 添加开路故障的选项 `Add fault`（默认）

在 Dynamic Load 模块中添加开路故障的选项。

要添加故障，请单击 **Add fault** 超链接。

### **开路电导** — 开路电导 `1e-4` `S`（默认） | 标量

开路状态期间的电导。

#### 依赖关系

要启用此参数，请通过单击 **开路故障** 参数中的 **Add fault** 超链接向 Dynamic Load 模块添加故障。

创建故障后，可以在 **Fault Inspector** 窗口中更改属性。打开包含故障的模块时，将显示 **Open Fault Inspector** 超链接，而不是 **Add fault** 超链接。有关如何包含故障的示例，请参阅分析直流电枢绕组故障。

### **在时间触发故障** — 进入故障状态之前的时间 `0` `s`（默认） | 非负标量

模块进入故障状态时的仿真时间。

#### 依赖关系

要启用此参数，请将 **触发类型** 设置为 `Timed`。

## 版本历史

**在 R2020b 中引入**

### R2024a: 改进了对感性节点和双向有功功率输入的支持

在 R2024a 之前，要将 Dynamic Load 模块连接到感性节点，必须提供较大的寄生电阻。从 R2024a 开始，如果将 **负载类型** 参数设置为 `AC`，则可以通过指定 **电压时间常数**、**初始电源电压 (RMS)** 和 **初始电源电压角度** 参数将此模块连接到感性节点。由于此更改，**最小有功功率** 参数已被移除。如果您的模型保存在较早版本中且包含此模块，则必须为新参数设置适当的值。

Dynamic Load 模块现在还根据输入有功功率 *Pin* 的极性消耗或生成有功功率。如果 *Pin* 大于 0，则该模块消耗有功功率。如果 *Pin* 小于 0，则该模块生成有功功率。

## 描述

用于直流或交流电源的动态负载

Dynamic Load 模块实现用于直流或交流电源的动态负载。

如果将 **负载类型** 参数设置为 `DC`：

- 只要该模块消耗的功率大于 **最小消耗功率** 参数的值，且直流电源的电压等于或大于为 **最小电源电压** 参数指定的值，该模块的消耗功率就等于 **P** 端口。
- 当直流电源的电压降至 **最小电源电压** 以下时，负载行为会发生变化，该模块表现为电阻性负载。如果电源电压变为负值，则该模块表现为开路电导。

为确保这些行为之间的平滑过渡，该模块使用具有连续导数的三阶多项式样条。您可以使用 **过渡电压宽度** 参数指定此过渡的宽度。

如果将 **负载类型** 参数设置为 `AC`，下表显示了该模块如何基于电源电压 *V* 计算消耗的有功功率和无功功率。

| *V* 值的范围 | 消耗的有功功率和无功功率 |
| --- | --- |
| V>Vmin | Pactual=PinQactual=Qin |
| V<Vmin | 该模块将负载建模为阻抗等于：R=Vmin2PinPin2+Qin2X=Vmin2QinPin2+Qin2Z=R2+X2 |

在这些方程中：

- *Vmin* 是 **最小电源电压 (RMS)** 参数的值。
- *Pin* 是 Dynamic Load 模块的输入有功功率，由外部输入端口 **P** 确定。
- *Pactual* 是 Dynamic Load 模块消耗的有功功率。
- *Qin* 是 Dynamic Load 模块的输入无功功率，由外部输入端口 **Q** 确定。
- *Qactual* 是 Dynamic Load 模块消耗的无功功率。

Dynamic Load 模块根据输入有功功率 *Pin* 的极性消耗或生成有功功率。如果 *Pin* 大于 0，则该模块消耗有功功率。如果 *Pin* 小于 0，则该模块生成有功功率。

### 故障

要在 Dynamic Load 模块中建模故障，请在 **故障** 部分中，单击要建模的故障旁边的 **Add fault**。有关故障建模的详细信息，请参阅故障行为建模和故障触发。

Dynamic Load 模块允许您将电气故障建模为开路。该模块可以在特定时间触发故障事件。

### 潮流分析

如果该模块位于与频率-时间仿真模式兼容的网络中，您可以对该网络执行潮流分析。潮流分析提供稳态值，您可以使用这些值来初始化电机。

有关详细信息，请参阅使用 Simscape Electrical 执行潮流分析以及频率和时间仿真模式。
