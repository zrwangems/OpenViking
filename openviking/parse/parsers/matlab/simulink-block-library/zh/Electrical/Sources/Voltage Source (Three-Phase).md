# Voltage Source (Three-Phase)

## 端口

### 守恒

### **~** — 三相端口电气

可扩展三相端口，与三相 *a*、*b* 和 *c* 关联。

### **n** — 星形中心电气

与星形中心关联的电气守恒端口。

## 参数

### **建模选项** — 是否对复合或展开式三相端口建模 `Composite three-phase ports`（默认）| `Expanded three-phase ports`

是否对复合或展开式三相端口建模。

复合三相端口使用单个模块端口表示三个独立的电气守恒端口。您可以使用复合三相端口构建与三相电力系统单线图对应的模型。

展开式三相端口使用三个独立的电气守恒端口表示三相系统的各相。

### 主要

### **额定电压（相间 RMS）** — RMS 线电压 `sqrt(3) * 100 / sqrt(2)` `V`（默认）

RMS 相间电压，或线电压。

### **相移** — 相移 `0` `deg`（默认）

以角度单位表示的相移。

### **频率** — 电压频率 `60` `Hz`（默认）

电压频率，以 Hz 或可直接转换为 Hz 的单位指定（其中 Hz 定义为 1/s）。例如，`kHz` 和 `MHz` 是有效单位，但 `rad/s` 不是。

### **源阻抗** — 源阻抗方法 `X/R Ratio`（默认）| `None` | `Series R` | `Series L` | `Series RL`

选择用于指定源阻抗的方法。默认选项为 `X/R Ratio`。选择任何其他选项将启用其他参数。选项包括：

- `None`
- `X/R Ratio`
- `Series R`
- `Series L`
- `Series RL`

### **短路功率水平** — 短路功率水平 `1e6` `V*A`（默认）

短路功率水平。

#### 依赖关系

仅当为 **源阻抗** 参数选择 `X/R Ratio` 时，此参数才可见。

### **源 X/R 比** — 电抗与电阻之比 `15`（默认）

复数阻抗，即电抗与电阻之比。

#### 依赖关系

仅当为 **源阻抗** 参数选择 `X/R Ratio` 时，此参数才可见。

### **源电阻** — 源电阻 `0.01` `Ohm`（默认）

源电阻。

#### 依赖关系

仅当为 **源阻抗** 参数选择 `Series R` 或 `Series RL` 时，此参数才可见。

### **源电感** — 源电感 `3.97e-4` `H`（默认）

源电感。

#### 依赖关系

仅当为 **源阻抗** 参数选择 `Series L` 或 `Series RL` 时，此参数才可见。

### 谐波

### **源谐波** — 源谐波 `None`（默认）| `Generate harmonics`

在 `None` 和 `Generate harmonics` 之间选择。默认值为 `None`。

### **谐波次数** — 谐波次数 `[5, 7, 11, 13]`（默认）

一个行向量，包含用于生成谐波的附加整数谐波次数。

#### 依赖关系

仅当为 **源表示形式** 参数选择 `Generate harmonics` 时，此参数才可见。

### **谐波幅值与峰值幅值之比** — 谐波幅值与峰值幅值之比 `[.1, .1, .1, .1]`（默认）

一个行向量，包含相对于基波幅值的谐波幅值比值。

#### 依赖关系

仅当为 **源表示形式** 参数选择 `Generate harmonics` 时，此参数才可见。

### 寄生参数

### **源阻抗寄生并联电导** — 源阻抗寄生并联电导 `0` `1/Ohm`（默认）

源阻抗寄生并联电导。

#### 依赖关系

仅当为 **源阻抗** 参数选择 `X/R Ratio`、`Series L` 或 `Series RL` 时，此参数才可见。

## 描述

具有可选谐波的理想三相电压源

Voltage Source (Three-Phase) 模块对理想三相电压源或具有谐波的三相电压源进行建模。使用源表示形式参数指定配置。

当为 **源阻抗** 参数选择 `None` 时，Voltage Source 模块会对理想三相电压源进行建模，该电压源在其端子间保持指定幅值的正弦电压，与流过源的电流无关。

该源采用星形配置，端口 **n** 提供与星形中心的连接。端口 **~** 是表示三相 *a*、*b* 和 *c* 的可扩展三相端口。如果电流从星形中心流向正端子，则电流为正，并且每相两端的电压等于正端子处电压与星形中心处电压之差，*V*(+) – *V*n。

### 方程

Voltage Source 模块的输出电压由以下方程定义：

v=vDC+vACsin(2πft+ϕ)+vN

va=V0sin(2πft+φ)

vN=Pv/2N(0,1)h

vc=V0sin(2πft+φ+120∘),

其中：

- *V0* 是峰值相电压。
- *vline\_rms* 是均方根 (RMS) 相间电压。
- *va*、*vb*、*vc* 分别是各相电压。
- *f* 是频率。
- *φ* 是相移。
- *t* 是时间。

当指定具有谐波表示形式的三相电压源时，Voltage Source 模块的输出电压由以下方程定义：

V0=23vline\_rmsHratios

va=V0sin((2πft+φ)Horders')

vb=V0sin((2πft+φ−θ)Horders'​)

vc=V0sin((2πft+φ+θ)Horders'),

其中：

- *V0* 是一个行向量，包含基波和各次谐波正弦量的峰值电压。
- *vline\_rms* 是 RMS 相间电压。
- *Hratios* 是谐波比值的行向量。第一个元素为 1，表示基波。
- *Horders* 是谐波次数的行向量。第一个元素为 1，表示基波。
- *va*、*v*b、*v*c 分别是各相电压。
- *f* 是谐波频率的列向量。第一个元素是基波频率。
- *φ* 是谐波相移的列向量。第一个元素是基波相移。
- *θ* 是谐波相位偏移的列向量。第一个元素是 `120°`。
- *t* 是时间。

当为 **源阻抗** 参数选择 `X/R ratio` 时，源阻抗方程为：

R=vline\_rms2Ssc1+ϕ2

X=Rϕ

L=X2πf,

其中：

- *Ssc* 是您指定的 **短路功率水平**。
- *ϕ* 是您指定的 **源 X/R 比**。
- *R* 是计算得到的源电阻。
- *X* 是计算得到的源电抗。
- *L* 是计算得到的源电感。
