# Programmable Voltage Source (Three-Phase)

## 端口

### 输入

### **F** — 频率物理信号

与频率关联的物理信号输入。

### **M** — 幅值物理信号

与幅值关联的物理信号输入。

### **Phi** — 相移物理信号

与相移关联的物理信号输入。

### 守恒

### **n** — 中性点电气

与中性点关联的电气守恒端口。

### **~** — 三相交流电压电气

与交流电压关联的可扩展电气守恒三相端口。

## 参数

### **建模选项** — 是对复合三相端口还是扩展三相端口建模 `Composite three-phase ports`（默认）| `Expanded three-phase ports`

是对复合三相端口还是扩展三相端口建模。

复合三相端口使用单个模块端口表示三个独立的电气守恒端口。您可以使用复合三相端口构建对应于三相电力系统单线图的模型。

扩展三相端口使用三个独立的电气守恒端口表示三相系统的各相。

## 描述

具有可选可编程交流幅值、频率和相移的三相电压源

Programmable Voltage Source (Three-Phase) 模块对具有可编程交流幅值、频率和相移的三相电压源进行建模。选择外部模式可通过物理输入信号 **M**、**F** 和 **Phi** 指定这些量。您可以将谐波和内部阻抗添加到电压源。

有关相关方程，请参阅 Voltage Source (Three-Phase) 模块。

### 变量

要在仿真前设置模块变量的优先级和初始目标值，请使用模块对话框或属性检查器中的 **初始目标** 部分。有关详细信息，请参阅《设置模块变量的优先级和初始目标》。

标称值提供了一种在模型中指定变量预期幅值的方法。使用基于标称值的系统缩放可提高仿真稳健性。您可以使用不同来源指定标称值，包括模块对话框或属性检查器中的 **标称值** 部分。有关详细信息，请参阅《通过标称值进行系统缩放》。
