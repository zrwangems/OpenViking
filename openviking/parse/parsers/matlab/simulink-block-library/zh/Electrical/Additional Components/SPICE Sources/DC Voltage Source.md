# DC Voltage Source

## 端口

### 守恒

### **+** — 正电压 电气

与 DC 电流源正电压相关联的电气守恒端口

### **-** — 负电压 电气

与 DC 电流源负电压相关联的电气守恒端口

## 参数

### **常数值，DC** — DC 输出电压 `0` **V** (默认)

DC 输出电压值，单位为 V。

## 描述

恒定电压源

DC Voltage Source 模块表示输出电压值与流经电压源的电流无关的恒定电压源。
