# DC Voltage Source

## 端口

### 守恒端口

### **+** — 正电压电气端口

与直流电流源正电压相关联的电气守恒端口

### **-** — 负电压电气端口

与直流电流源负电压相关联的电气守恒端口

## 参数

### **Constant value, DC** — 直流输出电压 `0` `V`（默认值）

直流输出电压的值，单位为 V。

## 描述

恒定电压源

DC Voltage Source 模块表示一个恒定电压源，其输出电压值与流过该源的电流无关。
