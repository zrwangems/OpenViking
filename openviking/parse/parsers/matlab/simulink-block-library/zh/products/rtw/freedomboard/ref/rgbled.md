## 描述

将 RGB LED 设置为所需颜色

通过为红色、绿色和蓝色 LED（分别标注为 R、G 和 B）提供输入，将 RGB LED 设置为所需颜色。模块输入接受 0 到 255 范围内的值。

例如，要输出红色，请将 R 输入值设置为大于 0 的值，G 和 B 设置为 0。

在没有硬件的仿真期间，此模块不执行任何操作。
