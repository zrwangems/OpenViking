### R2020a: 现有模型自动将此模块更新为当前版本

从 R2020a 开始，Simulink® 不再允许您使用 R2015b 之前可用的 Walsh Code Generator 模块版本。

现有模型会自动更新，以加载在“Source blocks output frames of contiguous time samples but do not use frame attribute”中宣布的 Walsh Code Generator 模块版本。有关模块转发的详细信息，请参阅《使用转发表维护库模块的兼容性 (Simulink)》。
