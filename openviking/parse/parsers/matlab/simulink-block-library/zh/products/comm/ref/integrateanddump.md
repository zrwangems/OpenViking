## 参数

**积分周期**
:   两次复位之间的输入样本数。

**偏移量**
:   非负整数向量或标量，指定仿真开始时从输入数据的每一列中丢弃的输入样本数。

**输出中间值**
:   确定模块是否输出连续两次复位之间的中间累积和。

### 定点属性

仅当模块输入为定点信号时，以下参数的设置才适用。

**舍入模式**
:   使用此参数指定当定点计算结果无法精确映射为存储该结果的数据类型和定标所能表示的数值时要使用的舍入方法。

    有关详细信息，请参阅“舍入模式”或“舍入模式：最简单”（Fixed-Point Designer）。

**整数溢出时饱和**
:   使用此参数指定在定点计算结果的幅值超出存储该结果的数据类型和定标所能表示的范围时要使用的方法：

    - Saturate 将正溢出表示为所用范围内的最大正数，并将负溢出表示为所用范围内绝对值最大的负数。
    - Wrap 使用模运算将溢出值转换回数据类型的可表示范围。有关详细信息，请参阅“模运算”（Fixed-Point Designer）。

**累加器—模式**
:   使用 **累加器—模式** 参数指定如何设置累加器的字长和小数长度：

    - 选择 `Inherit via internal rule` 时，模块会自动计算累加器输出的字长和小数长度。
    - 选择 `Same as input` 时，这些特性与模块输入的相应特性一致。
    - 选择 `Binary point scaling` 时，可以输入累加器的字长和小数长度（以 bits 为单位）。
    - 选择 `Slope and bias scaling` 时，可以输入累加器的字长（以 bits 为单位）和斜率。

**输出**
:   使用 **输出** 参数选择如何指定模块输出的字长和小数长度：

    - 选择 `Same as accumulator` 时，这些特性与累加器的相应特性一致。
    - 选择 `Same as input` 时，这些特性与模块输入的相应特性一致。
    - 选择 `Binary point scaling` 时，输入模块输出的字长和小数长度（以 bits 为单位）。
    - 选择 `Slope and bias scaling` 时，输入模块输出的字长（以 bits 为单位）和斜率。

有关定点应用相关参数的更多信息，请参阅“为模块指定定点属性”。

## 描述

对离散时间信号进行积分，并定期复位为零

Integrate and Dump 模块对离散时间输入信号求累积和，并按照固定时序将累积和复位为零。仿真开始时，模块会丢弃 **偏移量** 参数所指定数量的样本。经过这一初始阶段后，模块按列对输入信号求和，并每 *N* 个输入样本将累积和复位为零，其中 *N* 是 **积分周期** 参数的值。复位发生在模块于该时间步生成输出之后。

当系统的发射机使用简单的方脉冲模型时，接收机模型通常采用积分-清零操作。光纤通信以及 CDMA（码分多址）应用等扩频通信系统也采用此操作。

此模块接受标量、列向量或矩阵输入信号。当输入信号不是标量值时，对于某个正整数 *k*，输入必须包含 *k*·*N* 行。对于这些输入信号，模块会独立处理每一列。

选择 **输出中间值** 会按如下方式影响输出的内容、维度和采样时间：

- 如果清除该复选框，模块会在每个复位时刻输出累积和。

  - 如果输入是标量值，则输出采样时间是输入采样时间的 *N* 倍，并且模块会产生一个持续时间为一个输出采样周期的延迟。在这种情况下，输出维度与输入维度一致。
  - 如果输入是 (*k*·*N*)×*n* 矩阵，则输出为 *k*×*n* 矩阵。在这种情况下，模块不存在延迟，并且输出周期与输入周期一致。
- 如果选中该复选框，模块会在每个时间步输出累积和。输出具有与输入相同的采样时间和矩阵维度。

### 瞬态和延迟

**偏移量** 参数中的非零值会使模块在丢弃输入样本的初始阶段输出一个或多个零。如果输入是具有 *n* 列的矩阵，并且 **偏移量** 参数是长度为 *n* 的向量，则 **偏移量** 向量的第 *m* 个元素是数据第 *m* 列的偏移量。如果 **偏移量** 是标量，则模块对数据的每一列应用相同的偏移量。由非零 **偏移量** 值导致的初始零输出是一种瞬态效应，而不是持续延迟。

清除 **输出中间值** 后，在整个仿真过程中，模块输出相对于输入都会存在延迟：

- 如果输入是标量值，则在任何瞬态效应结束后，输出会延迟一个样本。也就是说，从输入和输出中去除瞬态后，可以在索引为 m+1 的输出样本中看到第 *m* 个积分周期的结果。
- 如果输入是列向量或矩阵，并且 **偏移量** 参数非零，那么在瞬态效应结束后，每个积分周期的结果会出现在与该积分周期的*最后一个*输入样本对应的输出帧中。当积分周期跨越两个输入帧时，该输出帧比与这一积分周期第一个输入样本对应的输出帧晚一帧。有关这种情况的示例，请参阅“瞬态和延迟示例”。
