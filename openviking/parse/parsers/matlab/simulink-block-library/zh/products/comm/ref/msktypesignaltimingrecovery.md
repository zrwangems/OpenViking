# MSK-Type Signal Timing Recovery

## 端口

R2025b 中未提供相关文档。

## 参数

**调制类型**
:   系统中的调制类型。可选值为
    `MSK` 和 `GMSK`。

**每符号采样数**
:   输入信号中表示每个符号的采样数 N。此值必须大于 1。

**误差更新增益**
:   一个正实数，表示模块逐次更新相位估计时使用的步长。通常，此数值小于
    1/N，这对应于缓慢变化的相位。

    此参数在正常模式、加速模式和快速加速模式下可调。如果您使用 Simulink®
    Coder™ 快速仿真 (RSIM) 目标构建 RSIM 可执行文件，则无需重新编译模型即可调节此参数。有关详细信息，请参阅可调参数 (Simulink)。

**重置**
:   确定模块是否重新启动相位估计过程以及在何种情况下重新启动。可选值为 `None`、
    `Every frame` 和 `On nonzero input via port`。最后一个选项会使模块具有第二个输入端口，标签为 `Rst`。

## 描述

使用四阶非线性方法恢复符号定时相位

MSK-Type Signal Timing Recovery 模块使用四阶非线性方法恢复输入信号的符号定时相位。此模块实现了一种通用的非数据辅助反馈方法，该方法独立于载波相位恢复，但需要预先补偿载波频率偏移。此模块适用于采用基带最小频移键控 (MSK) 调制或高斯最小频移键控 (GMSK) 调制的系统。

### 输入

默认情况下，此模块有一个输入端口。输入信号可以是（但并非必须是）与发送脉冲形状匹配的接收滤波器的输出，也可以是用于限制进入此模块的噪声量的低通滤波器的输出。

此模块接受标量或列向量输入信号。输入使用 *N* 个采样表示每个符号，其中 *N* > 1 为 **每符号采样数** 参数。

- 对于列向量输入信号，模块以单速率处理模式运行。在此模式下，输出信号继承输入信号的采样率。输入长度必须是 *N* 的整数倍。
- 对于标量输入信号，模块以多速率处理模式运行。在此模式下，输入和输出信号具有不同的采样率。输出采样率等于输入采样率的 *N* 倍。
- 此模块接受 Double 或 Single 类型的输入信号

如果将 **重置** 参数设置为 `On nonzero input via port`，则模块具有第二个输入端口，标签为 `Rst`。`Rst` 输入确定何时重新开始定时估计过程，且必须为标量。

- 如果输入信号是标量值，则 `Rst` 输入的采样时间等于符号周期
- 如果输入信号是列向量，则 `Rst` 输入的采样时间等于输入端口的采样时间
- 此模块接受 Double 或 Boolean 类型的重置信号

### 输出

模块有两个输出端口，标签分别为 `Sym` 和 `Ph`：

- `Sym` 输出是将估计的相位校正应用于输入信号后得到的结果。此输出为每个符号的信号值，可用于判决。`Sym` 输出中的值以符号速率出现：

  - 对于长度为 *N*\**R* 的列向量输入信号，`Sym` 输出是长度为 *R* 的列向量，其采样率与输入信号相同。
  - 对于标量输入信号，`Sym` 输出的采样率等于输入采样率的 *N* 倍。
- `Ph` 输出给出输入中每个符号的相位估计。

  `Ph` 输出包含小于 *N* 的非负实数。相位估计的非整数值对应于位于输入信号两个值之间的插值。`Ph` 输出的采样时间与 `Sym` 输出的采样时间相同。

  **注意**

  如果 `Ph` 输出非常接近零或 **每符号采样数** 参数的值，或者输入信号中的实际定时相位偏移非常接近零，则模块的精度可能会受到少量噪声或抖动的影响。当定时相位偏移明显而不是非常接近零时，模块的工作效果良好。
- 输出信号继承输入信号的数据类型。

### 延迟

当输入信号为向量时，此模块会产生两个符号的延迟。当输入信号为标量时，此模块会产生三个符号的延迟。
