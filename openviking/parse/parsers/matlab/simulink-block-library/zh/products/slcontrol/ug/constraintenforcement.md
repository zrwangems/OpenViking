# Constraint Enforcement

## 端口

### 输入

### **u0** — 控制动作 标量 | 向量

未修改的控制动作，指定为标量或向量。

如果 **动作数量** 参数为 `1`，
将 **u0** 连接到标量信号。否则，将
**u0** 连接到长度等于 **动作数量** 的向量信号。

### **fx** — 约束函数偏移系数 标量 | 向量

以下约束方程中的偏移系数 *fx*。

fx+gxu≤c

如果 **约束数量** 参数为
`1`，将 **fx** 连接到标量信号。否则，
将 **fx** 连接到长度等于
**约束数量** 的向量信号。

### **gx** — 约束函数线性系数 标量 | 向量 | 矩阵

以下约束方程中的线性系数 *gx*。

fx+gxu≤c

将 **gx** 连接到
*Nc*×*Nu*
信号，其中 *Nc* 等于
**约束数量** 参数，并且
*Nu* 等于 **动作数量**
参数。

### **c** — 约束边界 标量 | 向量

以下约束函数中的运行时约束边界 *c*。

fx+gxu≤c

如果 **约束数量** 参数为
`1`，将 **c** 连接到标量信号。否则，
将 **c** 连接到长度等于
**约束数量** 的向量信号。

如果此端口被禁用，模块将使用通过 **约束边界** 参数指定的常量约束边界。

#### 依赖关系

要启用此输入端口，请选择 **使用外部源**
参数。

### **umax** — 动作信号上限 标量 | 向量

要为动作信号指定运行时上限，请启用此输入端口。如果
此端口被禁用，模块不会对控制动作应用任何上限。

如果 **动作数量** 参数为 `1`，
将 **umax** 连接到标量信号。否则，将
**umax** 连接到长度等于 **动作数量**
的向量信号。

#### 依赖关系

要启用此输入端口，请选择 **使用外部源设定上限**
参数。

### **umin** — 动作信号下限 标量 | 向量

要为动作信号指定运行时下限，请启用此输入端口。如果
此端口被禁用，模块不会对控制动作应用任何下限。

如果 **动作数量** 参数为 `1`，
将 **umin** 连接到标量信号。否则，将
**umin** 连接到长度等于 **动作数量**
的向量信号。

#### 依赖关系

要启用此输入端口，请选择 **使用外部源设定下限**
参数。
### 输出

### **u\*** — 修改后的控制动作 标量 | 向量

由 QP 求解器返回的修改后的控制动作。

如果求解器在达到最大迭代次数之前找到解，
**u\*** 将输出此最优解。

如果求解器达到最大迭代次数，优化停止，并且
**u\*** 输出次优解。

如果初始优化问题不可行，返回的控制动作取决于模块是否配置为忽略约束或动作边界。
有关详细信息，请参阅 **exitflag** 参数。

如果 **动作数量** 参数为 `1`，
**u\*** 输出标量信号。否则，**u\***
输出长度等于 **动作数量**
的向量信号。

### **exitflag** — 优化状态 `1` | `2` | `3` | `4` | `0` | 负整数

QP 求解器的优化状态。下表显示了可能的状态值。

| 退出标志 | 描述 |
| --- | --- |
| `1` | 求解器收敛到最优解，所有约束和边界均处于活动状态。在这种情况下，**u\*** 输出最优控制动作。 |
| `2` | 初始优化问题不可行，且模块配置为忽略所有约束和边界。在这种情况下，**u\*** 输出未修改的控制动作 **u0**。 |
| `3` | 初始优化问题不可行。模块忽略动作边界重新运行优化，并找到了可行解，该解由模块在 **u\*** 中输出。 |
| `4` | 初始优化问题不可行。模块忽略约束边界重新运行优化，并找到了可行解，该解由模块在 **u\*** 中输出。 |
| `0` | 求解器达到最大迭代次数。**u\*** 中输出的控制动作可能是次优的。 |
| 负整数 | 初始优化问题不可行，且适用以下情况之一。  - 在没有动作边界的情况下重新运行优化未产生可行解。 - 在没有约束边界的情况下重新运行优化未产生可行解。 - 模块配置为不忽略约束和动作边界。  在这种情况下，**u\*** 中输出的控制动作为零。 |

#### 依赖关系

要启用此输出端口，请选择 **优化状态**
参数。

## 描述

修改控制动作以满足约束和动作边界

Constraint Enforcement 模块计算在满足约束和动作边界的情况下最接近指定控制动作的修改后控制动作。

该模块使用二次规划 (QP) 求解器来寻找使函数 |u−u0|2 最小化的控制动作 *u*。这里，*u*0 是未修改的控制动作。

求解器将以下约束应用于优化问题。

fx+gxu≤cumin≤u≤umax

这里：

- *fx* 和
  *gx* 是约束函数的系数。
- *c* 是约束函数的边界。
- *u*min 是控制动作的下界。
- *u*max 是控制动作的上界。

Constraint Enforcement 模块需要 Optimization Toolbox™ 软件。

有关约束执行的详细信息，请参阅 Constraint Enforcement for Control Design。
