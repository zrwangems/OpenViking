## 描述

终止整个活动

活动最终节点由一个白色圆圈围成的灰色实心圆圈表示。

当控制令牌进入 Activity Final Node 模块时，整个活动图终止。活动最终节点没有任何输出流。

### 创建 Activity Final Node

您可以将 Activity Final Node 模块从左边的调色板拖放到画布上的任意位置，从而创建一个活动最终节点。
