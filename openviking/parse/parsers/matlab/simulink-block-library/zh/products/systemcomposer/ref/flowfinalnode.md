## 描述

终止一个对象或控制流

流量最终节点由一个圆圈内的灰色十字表示。

当控制令牌进入 Flow Final Node 模块时，相应的对象或控制流会终止，但整个活动图不会终止。流最终节点没有任何输出。

### 创建 Flow Final Node

您可以将 Flow Final Node 模块从左边的调色板拖放到画布上的任意位置，从而创建一个流最终节点。
