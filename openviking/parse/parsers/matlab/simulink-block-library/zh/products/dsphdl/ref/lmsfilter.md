# LMS Filter

## 端口

### 输入

### **data** — 输入数据，实数或复数值的标量或列向量

输入数据，指定为实数或复数值的标量或列向量。输入向量大小必须在 [2, 64] 范围内，且必须小于滤波器长度。该模块仅支持最高 32 bits 的输入字长。

您可以使用 `double` 和 `single` 数据类型进行仿真，但不能用于 HDL 代码生成。对于 HDL 代码生成，输入数据类型必须为 `signed fixed point`。

**数据类型：** `single` | `double` | `fixed point`
**复数支持：** Yes

### **desired** — 期望输入数据，实数或复数值的标量或列向量

期望输入数据，指定为实数或复数值的标量或列向量。输入向量大小必须在 [2, 64] 范围内，且必须小于滤波器长度。**desired** 端口必须与输入 **data** 端口具有相同的数据类型、复/实性和维度。

**数据类型：** `single` | `double` | `fixed point`
**复数支持：** Yes

### **valid** — 指示有效的输入数据，标量

指示输入数据是否有效的控制信号。当 **valid** 为 `1` (`true`) 时，模块从输入端口 **data** 和 **desired** 捕获值。当 **valid** 为 `0` (`false`) 时，模块忽略来自输入端口 **data** 和 **desired** 的值。

**数据类型：** `Boolean`

### **stepSize** — 滤波器的收敛性和稳定性，实数标量

指定步长以控制滤波器的收敛性和稳定性。建议的步长必须小于 1/(2 x *Input power* x *Filter length*)。

您可以使用 `double` 和 `single` 数据类型进行仿真，但不能用于 HDL 代码生成。对于 HDL 代码生成，输入数据类型必须为 `unsigned fixed point`。

#### 依赖关系

要启用此端口，请在 **主** 选项卡上，将 **步长来源** 参数设置为 `Input port`。

**数据类型：** `double` | `single` | `fixed point`

### **adapt** — 更新滤波器权重，标量

当 **adapt** 为 `1` (`true`) 且输入 **valid** 为 `1` (`true`) 时，对于每个输入 **valid**，模块都会适应新的滤波器权重。当 **adapt** 为 `0` (`false`) 且输入 **valid** 为 `1` (`true`) 或 `0` (`false`) 时，模块保持其先前的滤波器权重。

#### 依赖关系

要启用此端口，请在 **主** 选项卡上，选择 **启用 adapt 输入端口** 参数。

**数据类型：** `Boolean`

### **reset** — 清除内部状态，标量

清除内部状态的控制信号。当 **reset** 为 `1` (`true`) 时，模块停止当前计算，清除内部状态，并设置为模块掩码上指定的滤波器权重初始值。当 **reset** 为 `0` (`false`) 且输入 **valid** 为 `1` (`true`) 时，模块捕获数据以进行处理。

有关更多复位注意事项，请参阅硬件控制信号页面上的复位信号部分。

#### 依赖关系

要启用此端口，请在 **控制端口** 选项卡上，选择 **启用 reset 输入端口** 参数。

**数据类型：** `Boolean`

### 输出

### **data** — 滤波后的输出数据，实数或复数值的标量或列向量

滤波后的输出数据，以实数或复数值的标量或列向量形式返回。输出的维度与输入的维度匹配。

当输入数据为浮点类型时，输出数据继承输入数据的数据类型。当输入数据为定点类型时，输出数据为定点类型，其字长和小数长度均增加 1。

**数据类型：** `single` | `double` | `fixed point`
**复数支持：** Yes

### **valid** — 指示有效的输出数据，标量

指示来自输出 **data** 端口的数据是否有效的控制信号。当 **valid** 为 `1` (`true`) 时，模块从输出 **data** 端口返回有效数据。当 **valid** 为 `0` (`false`) 时，来自输出 **data** 端口的值无效。

**数据类型：** `Boolean`

### **error** — 输出信号与期望信号之间的误差，实数或复数标量或列向量

当输出 **valid** 为 `1` (`true`) 时，输出从期望信号中减去滤波后的输出信号的结果。

如果输入 **data** 和 **desired** 是标量或列向量，则误差信号具有与输入数据相同的维度和复/实性。当输入数据为浮点类型时，输出数据继承输入数据的数据类型。当输入数据为定点类型时，输出数据为定点类型，其字长增加 2，小数长度增加 1。

#### 依赖关系

要启用此端口，请在 **主** 选项卡上，选择 **启用滤波器误差输出端口** 参数。

**数据类型：** `Boolean`

### **weights** — 更新后的滤波器权重，行向量

对于每次迭代，当输出 **valid** 为 `1` (`true`) 时，模块从此端口输出当前更新后的滤波器权重。

对于浮点输入，权重数据类型必须与输入类型匹配。对于定点信号，输入必须与 **权重** 参数所设置的数据类型匹配。

#### 依赖关系

要启用此端口，请在 **主** 选项卡上，选择 **启用滤波器权重输出端口** 参数。

**数据类型：** `Boolean`

## 参数

### 主

### **滤波器长度** — 滤波器长度 `32` (默认) | 小于或等于 2048 的正整数

将 LMS 滤波器的长度指定为小于或等于 2048 的正整数。

### **步长来源** — 步长来源 `Property` (默认) | `Input port`

选择模块是通过属性还是输入端口指定步长。

- `Property` — 使用 **步长 (mu)** 参数指定步长。
- `Input port` — 使用 **stepSize** 端口指定步长。

### **步长 (mu)** — 步长 `0.01` (默认) | 正标量数值

将步长指定为正标量数值。建议的步长必须小于 1/(2 x *Input power* x *Filter length*)。

#### 依赖关系

要启用此参数，请将 **步长来源** 参数设置为 `Property`。

### **滤波器权重的初始值** — 滤波器权重的初始值 `0` (默认) | 标量 | 行向量

输入初始滤波器权重，形式为大小等于滤波器长度的标量或行向量。

当您指定标量值时，模块会将其视为等效于指定标量值的行向量。

### **启用 adapt 输入端口** — 启用 adapt 输入端口的选项 `off` (默认) | on

选择此参数以启用 **adapt** 输入端口。

### **启用滤波器权重输出端口** — 启用 weights 输出端口的选项 `on` (默认) | off

选择此参数以启用 **weights** 输出端口。

对于每次迭代，模块从此端口输出当前更新后的滤波器权重。

### **启用滤波器误差输出端口** — 启用 error 输出端口的选项 `off` (默认) | on

选择此参数以启用 **error** 输出端口。

### 数据类型

### **舍入模式** — 用于对输出进行类型转换的舍入模式 `Floor` (默认) | `Ceiling` | `Convergent` | `Nearest` | `Round` | `Zero`

用于将输出类型转换为 **输出** 参数所指定数据类型的舍入模式。当输入数据类型为浮点时，模块会忽略此参数。有关更多详细信息，请参阅舍入模式。

### **整数溢出时饱和** — 用于对输出进行类型转换的溢出处理 `off` (默认) | `on`

用于将输出类型转换为 **输出** 参数所指定数据类型的溢出处理。当输入数据类型为浮点时，模块会忽略此参数。有关更多详细信息，请参阅溢出处理。

### **步长** — 步长类型 `Inherit: Same word length as input` (默认) | `fixdt(0,16,16)` | `<data type expression>`

指定步长数据类型。

#### 依赖关系

要启用此参数，请将 **步长来源** 参数设置为 `Property`。

### **权重** — 滤波器权重类型 `fixdt(1,16,15)` (默认) | `Inherit: Same as input` | `<data type expression>`

指定滤波器权重的数据类型。

### **步长误差乘积** — 步长误差乘积类型 `Inherit: Same word length as input` (默认) | `Inherit: Inherit via internal rule` | `fixdt(1,16,15)` | `<data type expression>`

指定步长误差乘积。

### 控制端口

### **启用 reset 输入端口** — 启用 reset 输入端口的选项 `off` (默认) | `on`

选中此复选框以启用 **reset** 输入端口。reset 信号实现数据路径寄存器的本地同步复位。

有关更多复位注意事项，请参阅硬件控制信号页面上的复位信号部分。

### **使用 HDL 全局复位** — 将数据路径寄存器连接到生成的 HDL 全局复位信号的选项 `off` (默认) | `on`

选中此复选框以将生成的 HDL 全局复位信号连接到数据路径寄存器。此参数不会更改模块的外观，也不会修改 Simulink 中的仿真行为。当您清除此复选框时，生成的 HDL 全局复位仅清除控制路径寄存器。生成的 HDL 全局复位可以是同步或异步的，具体取决于模型配置参数中的 **HDL Code Generation** > **Global Settings** > **Reset type** 参数。

有关更多复位注意事项，请参阅硬件控制信号页面上的复位信号部分。

## 描述

最小化观测信号与期望信号之间的误差

LMS Filter 模块使用均方误差 (MSE) 准则估计滤波器权重，并最小化期望信号与观测信号之间的误差。该模块调整其权重，直到数据与期望数据之间的误差最小。该模块接受实数和复数类型的标量及向量输入。

您可以将此模块用于各种应用，例如噪声消除、系统辨识和逆系统建模。该模块提供了适合 HDL 代码生成和硬件部署的架构。

**注意**

您还可以使用 DSP HDL IP Designer 应用为这种硬件优化算法生成 HDL 代码，而无需创建 Simulink® 模型。该应用提供与 Simulink 模块相同的接口和配置选项。
