# Flow Coefficient Parameterized Valve (TL)

## 端口

### 输入

### **L** — 阀门控制信号，`unitless` 物理信号

用于指定控制阀门开度的信号的端口（在某些阀门类型中与 *行程* 或 *升程百分比* 相关）。
当值为 `0` 时阀门完全关闭，当值为 `1` 时阀门完全打开。
### 守恒

### **A** — 热液体流道

流体可通过该开口进入或离开流阻。
哪个端口用作入口、哪个用作出口取决于流动方向。

### **B** — 热液体流道

流体可通过该开口进入或离开流阻。
哪个端口用作入口、哪个用作出口取决于流动方向。

## 参数

### **流量系数规格** — 用于指定阀门流量系数的参数化方式 `Cv coefficient (USG/min)` (默认) | `Kv coefficient (m^3/h)`

选择要指定的流量系数。
*C*v 和 *K*v 在测量时的物理条件以及表达时使用的物理单位上有所不同。通常，制造商提供的产品数据表中至少会报告其中一项。请选择有可用数据的选项。

### **最大流量下的 Cv 系数** — 以英制单位表示的最大程度打开阀门的流量系数 `1` (默认) | 单位为 USG/min 的正标量

以英制单位表示的、阀门全开时的流量系数。当制造商提供 *C*v 系数时，这就是阀门数据表中报告的值。

### **最大流量下的 Kv 系数** — 以 SI 单位表示的最大程度打开阀门的流量系数 `1` (默认) | 单位为 m^3/h 的正标量

以 SI 单位表示的、阀门全开时的流量系数。当制造商提供 *K*v 系数时，这就是阀门数据表中报告的值。

### **最小流量下的 Cv 系数** — 以英制单位表示的最大程度关闭阀门的流量系数 `1e-4` (默认) | 单位为 USG/min 的正标量

以英制单位表示的、紧密关闭且除端口 **A** 和端口 **B** 之间内部泄漏引起的流量外没有任何流量的阀门的流量系数。该参数的主要目的是确保仿真期间模型的数值稳健性。其精确值不如其为一个大于零的非常小的数重要。

### **最小流量下的 Kv 系数** — 以 SI 单位表示的最大程度关闭阀门的流量系数 `1e-4` (默认) | 单位为 m^3/h 的正标量

以 SI 单位表示的、紧密关闭且除端口 **A** 和端口 **B** 之间内部泄漏引起的流量外没有任何流量的阀门的流量系数。该参数的主要目的是确保仿真期间模型的数值稳健性。其精确值不如其为一个大于零的非常小的数重要。

### **阀门开度特性** — 用于计算阀门开度分数的参数化方式 `Linear` (默认) | `Quick opening``Equal percentages`

仿真期间使用的阀门开度曲线的选择。此处所做的选择决定端口 **L** 处指定的控制信号如何转换为阀门开度分数（以及开度面积）。有关开度参数化的详细信息，请参阅模块描述。

### **指数数值** — `Quick opening` 参数化中指数的分母 2 (默认) | 正的 unitless 标量

在 `Quick opening` 参数化的控制方程中用于除以指数的数。要获得真正的快速开启曲线（对应于从完全关闭位置快速开启、但随着接近最大开启位置而逐渐变慢的阀门），请使用大于 `1` 的值。

### **阀门可调比** — `Equal percentages` 参数化中指数的底数 `50` (默认) | 正的 unitless 标量

在 `Equal percentages` 参数化的控制方程中，将指数应用于其上的数。该数是流经阀门的最大流量与最小流量之比（前者对应于阀门最大开启时，后者对应于阀门最大关闭时）。典型值范围为 `20` 到 `50`。

### **端口 A 和 B 处的横截面积** — 阀门入口和出口处的流通面积 `0.01 m^2` (默认) | 单位为面积的正标量

每个端口处垂直于流动路径的面积。假定各端口尺寸相等。此处指定的流通面积应与阀门所连接组件的入口流通面积相匹配。

### **临界雷诺数** — 流动在层流和湍流之间切换时的雷诺数 `150` (默认) | 正的 unitless 标量

阀门内流体预期在层流和湍流流态之间切换时的雷诺数。假定该切换立即发生：通常存在于两种流态之间的过渡区域被忽略。

## 描述

以 Cv 或 Kv 流量系数对流通面积建模的阀门

Flow Coefficient Parameterized Valve (TL) 模块使用流量系数来关联通过端口的流量与端口间的压降，从而对阀门的流动特性进行建模。流量系数参数化适用于阀门内部几何形状已知信息很少的情况，或者流量系数是表征阀门的首选方式的情况。该阀门模型的假设足够通用，可应用于多种阀门；此模块不假定任何单一阀门类型。

### 流量系数参数化

流量系数衡量的是由压差驱动的流体通过阀门的难易程度。它是阀门选型中的一个重要参数，也是在模型中表征阀门的一种便捷方式。在此作用上，它尤其有用，因为它用单个数值量化了阀门流道中产生的所有损失。流量系数通常由阀门制造商测量，并在随阀门提供的数据表中报告。

严格来说，常用的流量系数有两种：*C*v 和 *K*v。它们描述的是本质相同的量：在阀门开到最大并设定为某些标准运行条件时，通过阀门的水的体积流量。这些流量系数仅在测量期间设定的温度和压降（运行条件）以及表达时使用的物理单位上有所不同：

- *C*v 在普遍接受的温度 `60 °F` 和压降 `1 PSI` 下测量；它以英制单位 `US gpm` 表示。当 **流量系数规格** 模块参数设置为 `Cv coefficient (USG/min)` 时，这就是模型中所使用的流量系数 [1]。
- *K*v 在普遍接受的温度 `15 °C` 和压降 `1 bar` 下测量；它以公制单位 `m3/h` 表示。当 **流量系数规格** 模块参数设置为 `Kv coefficient (m^3/h)` 时，这就是模型中所使用的流量系数。[2]。

流量系数需要两个值：*最大* 值和 *最小* 值。最大值对应于阀门全开时；这是阀门数据表中经常报告的值。最小值对应于阀门紧密关闭时，此时仅剩泄漏流量（如果有的话）。施加在流量系数上的这个下界主要用于确保模型的数值稳健性。其精确值不如其为一个（通常非常小的）大于零的数重要。

### 阀门开度参数化

阀门开度分数（阀门开度面积与其最大值之比）在仿真期间根据端口 **L** 处指定的输入确定。该输入是 *控制信号*，在某些阀门中它与 *行程* 或 *升程百分比* 相关。控制信号的取值范围可以为 `0` 到 `1`。如果指定了更小或更大的值，则会将其调整到两个极限值中最近的一个。换句话说，该信号在 `0` 和 `1` 处被 *饱和*。

从控制信号到开度分数的转换取决于模块中选择的 **阀门开度特性** 参数化方式。当控制信号为 `0` 或 `1` 时，所有参数化方式的计算结果都相同：端口 **L** 处的值 `0` 始终表示最大程度（但不一定 *完全*）关闭的阀门；值 `1` 始终表示最大程度打开的阀门。在中间值处，开度分数有所不同：

- `Linear` — 阀门开度分数（在图中表示为 *f*(*L*)）等于端口 **L** 处的控制信号。两者同步变化，直到控制信号降到零以下（阀门完全关闭）或升到其最大值以上（阀门完全打开）。开度分数范围为 `0` 到 `1`（此陈述并不适用于所有阀门开度参数化）。

  f(L)=L.
- `Quick opening` — 阀门开度分数 *f*(*L*) 是端口 **L** 处控制信号的幂函数。当控制信号接近 `0` 时，开度分数随控制信号快速上升；当控制信号接近 `1` 时，上升缓慢。计算中的指数 (*α*) 决定开度速率如何随控制信号变化。开度分数范围为 `0` 到 `1`。

  f(L)=L1α,    α>1.
- `Equal percentage` — 阀门开度分数是端口 **L** 处控制信号的指数函数。当控制信号接近 `0` 时，开度分数随控制信号缓慢上升；当控制信号接近 `1` 时，快速上升。指数的底数 (*R*，即阀门的 *可调比*，通过端口的最大流量与最小流量之比）决定开度速率如何随控制信号变化。开度分数范围从一个很小的分数（对于典型可调比值 `20`–`50`，为 `0.02`–`0.05`）到 `1`。

  f(L)=RL−1−1R1−1R,    R≈20−50.

### 质量平衡

假定阀门内部流体的体积（以及因此其质量）非常小，并且出于建模目的将其忽略。因此，那里不能积聚任何量的流体。根据质量守恒原理，通过一个端口流入阀门的质量流量必须等于通过另一个端口流出阀门的质量流量：

m˙A+m˙B=0,

其中 m˙ 定义为通过下标（**A** 或 **B**）所指示的端口 *流入* 阀门的质量流量。

### 动量平衡

阀门流道中产生的那些压力损失的原因在模块中被忽略。无论其性质如何——突然的面积变化、流道扭曲——仿真期间只考虑它们的累积效应。正是这种累积效应使阀门的流量系数能够让模块在模型中加以捕获。该常数通过阀门的有效开度面积 (*S*) *间接* 计入阀门的动量平衡：

pA−pB=m˙m˙2+m˙crρavgS2,

其中：

- *p* 是通过下标（**A** 或 **B**）所指示的端口处的压力。
- *ρ*avg 是各端口处流体密度的算术平均值。
- m˙ 是某一端口处的质量流量。
- m˙cr 是临界质量流量，即假定流动在层流和湍流流态之间切换时的质量流量：

  m˙cr=Recrμavgπ4S,

  其中 *Re*cr 是转变点处的雷诺数，*μ*avg 是各端口处动力粘度的平均值。

有效开度面积 (*S*) 是阀门最大开度面积按开度分数 (*f*(*L*)) 缩放后的乘积。该计算对开度面积施加了一个下界，低于该下界时仅剩泄漏流量：

S(L)={Smaxf(L),if Smaxf(L)>SminSmin,else,

其中下标 `max` 和 `min` 分别指阀门处于完全打开和最大程度关闭位置；函数 *f*(*L*) 是根据端口 **L** 处指定的控制信号计算出的开度分数：

f(L)={L,Linear parameterizationL1/α,Quick opening parameterizationRL−1,Equal percentages parameterization,

其中 *α* 从 **指数数值** 模块参数获得，*R* 从 **阀门可调比** 参数获得。最大开度面积通过将（最大）流量系数乘以适当的转换因子获得：

SMax={λCCv,max,if Cv is usedλKKv,max,if Kv is used,

其中：

- *λ*C 是英制单位最大流量系数 (*C*v,max) 与最大开度面积之间的转换因子：`2.4015e-5 m^2`。
- *λ*K 是 SI 单位最大流量系数 (*K*v,max) 与最大开度面积之间的转换因子：`2.7765e-5 m^2`。

最小开度面积则通过将最大开度面积乘以最小流量系数与最大流量系数之比获得：

SMin={Cv,minCv,maxSmax,if Cv is usedKv,minKv,maxSmax,if Kv is used.

### 能量平衡

阀门被建模为绝热组件。流体与其周围壁面之间不会发生热交换。流体从入口流到出口时，不对流体做功，也不由流体做功。在这些假设下，能量只能通过对流通过端口 **A** 和 **B** 流动。根据能量守恒原理，端口能量流之和必须始终等于零：

ϕA+ϕB=0,

其中 *ϕ* 定义为通过其中一个端口（**A** 或 **B**）*流入* 阀门的能量流量。
