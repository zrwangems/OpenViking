# Memory Allocate

## 端口

未在 R2025b 中记录。

## 参数

### 内存

为存储变量分配内存。指定数据类型和大小。

### **变量名称** — 变量的名称 myVariable（默认）| string | character vector

指定要为其分配内存的变量的名称。该变量在生成的代码中分配。

### **指定变量对齐** — 变量对齐标志 off（默认）| on

如果目标处理器需要，请选择此参数，以指示编译器将新变量对齐到 byte 对齐边界。

#### 参数依赖关系

如果选择此参数，请使用参数 **内存对齐边界** 设置 byte 对齐边界。

### **内存对齐边界** — 变量的内存对齐 4（默认）| 1 | 2 | 8

指定变量数据类型的对齐边界，以 bytes 为单位。对齐可以发生在 1、2、4 或 8-byte 边界上。如果变量包含多个值（如向量或数组），模块将根据编译器应用的规则对齐元素。

#### 参数依赖关系

要启用此参数，请选择 **指定变量对齐**。

### **数据类型** — 变量的数据类型 uint32（默认）| double | single | int8 | uint8 | int16 | uint16 | int32 | int64 | uint64 | boolean

指定变量的数据类型。

### **指定数据类型限定符** — 数据类型限定符标志 off（默认）| on

选择此参数以指定要应用于变量的数据类型限定符。

#### 参数依赖关系

如果选择此参数，请使用参数 **数据类型限定符** 设置要应用于变量的数据类型限定符。

### **数据类型限定符** — 变量的数据类型限定符 volatile（默认）| sting | character vectory

指定要应用于生成代码中变量的数据类型限定符，以 string 或 character vector 形式给出。常见限定符有 `volatile`、`const`、`static` 和 `register`。模块不检查你输入的值是否为有效限定符。

### **数据维度** — 变量数据类型的元素数 64（默认）| 正整数

将变量的指定数据类型的元素数指定为正整数。

### **初始化内存** — 内存初始化标志 off（默认）| on

选择此参数以指定变量的初始值。

#### 参数依赖关系

如果选择此参数，请使用参数 **初始值** 设置初始值。

### **初始值** — 变量的初始值 0（默认）| scalar | vector | matrix

指定变量的初始值。在运行时，模块将该内存位置设置为该值。

#### 参数依赖关系

要启用此参数，请选择 **初始化内存**。

### 段

指定要在其中为变量分配内存的内存段。

### **指定内存段** — 内存段标志 off（默认）| on

选择此参数以指定用于在内存中为变量分配空间的内存段。

#### 参数依赖关系

如果选择此参数，请使用参数 **内存段**、**绑定内存段**、**段起始地址** 指定内存段详细信息。

### **内存段** — 变量的内存段 mySEC1（默认）| string | character vector

指定用于为变量分配内存的内存段名称，以 string 或 character vector 形式给出。指定标准内存段或在代码其他位置声明的自定义内存段。

验证该内存段是否有足够空间存储该变量。

#### 参数依赖关系

- 要启用此参数，请选择 **指定内存段**。
- 要将指定的内存段绑定到内存中的特定起始地址，请选择 **绑定内存段**，并通过为 **段起始地址** 输入值来指定地址。

### **绑定内存段** — 将内存段绑定到起始地址标志 off（默认）| on

选择此参数以将为此变量新建的内存段绑定到特定起始地址。

当选择此参数时，将为 **内存段** 指定的新内存段定义。

#### 参数依赖关系

- 选择此参数以启用参数 **段起始地址**。
- 如果要将变量与现有内存段关联，请不要选择此参数。

### **段起始地址** — 变量的内存段起始地址 hex2dec('8000')（默认）| 十进制或十六进制形式的内存地址

以十进制形式或十六进制形式（如默认值 `hex2dec('8000')` 所示转换为十进制）指定要将变量的内存段绑定到的起始地址。模块不验证该地址。请验证指定的地址存在并且可以包含指定的内存段。

#### 参数依赖关系

- 通过选择参数 **绑定内存段** 来启用此参数。
- 如果要将变量与现有内存段关联，请不要为此参数指定值。

## 描述

为新变量分配内存

Memory Allocate 模块在 C2xxx 处理器上指示 TI 编译器为新变量分配内存位置。模块参数指定变量名称、变量在内存中的对齐、变量的数据类型以及其他可完整定义所需内存的特性。

模块不验证变量的参数设置是否有效，例如检查变量名称、数据类型或段。你必须检查参数设置是否有效。

不要将 Memory Allocation 模块连接到模型中的其他模块。
