# F2838x-M4 TCP Send

## 端口

### 输入

### **Port\_1** — 输入数据向量

该模块接受指定为 *N*×1 数组的数据。该模块通过 TCP/IP 网络将此数据发送到接收主机。

**数据类型：** `int8` | `uint8` | `int16` | `uint16` | `int32` | `uint32` | `single` | `double` | `Boolean`

### **Length** — 接收数据长度标量

接收到的可变输入消息的长度。

#### 依赖项

要启用此端口，请选择 **启用可变长度** 参数。

**数据类型：** `uint32`
### 输出

### **Status** — 给定时间步传输的数据标量

如果数据在给定时间步传输，则该端口输出 `0`。否则，它输出一个非零值，指示数据传输不成功。

#### 依赖项

此参数仅在启用 **输出传输状态** 参数时出现。

**数据类型：** `uint8`

## 参数

### **连接模式** — 将模块设置为服务器或客户端 `Server`（默认）| `Client`

将模块设置为 TCP/IP 服务器或客户端。

当您将连接模式参数设置为 `Server` 时，请提供 **本地 IP 端口**。本地端口充当 TCP/IP 服务器上的侦听端口。

当您将连接模式参数设置为 `Client` 时，请提供要将数据发送到的 TCP/IP 服务器的 **服务器 IP 地址** 和 **服务器 IP 端口**。

### **服务器 IP 地址** — 要将数据发送到的服务器的远程 IP 地址 `192.168.1.10`（默认）| `any valid IP address`

指定数据发送到的接收服务器的远程 IP 地址。

#### 依赖项

此参数仅在 **连接模式** 参数设置为 `Client` 时出现。

### **服务器 IP 端口** — 数据发送到的服务器上的远程 IP 端口 `25002`（默认）| [1,65535] 范围内的正整数

指定数据发送到的接收服务器上的端口号。

#### 依赖项

此参数仅在 **连接模式** 参数设置为 `Client` 时出现。

### **本地 IP 端口** — 发送主机上用于发送数据的 IP 端口 `25000`（默认）| [1,65535] 范围内的正整数

指定从中发送数据的应用程序的端口号。此本地端口充当 TCP/IP 服务器的侦听端口。

### **启用可变长度** — 启用以接收可变数据长度 `off`（默认）| `on`

当您选择 **启用可变长度** 参数时，模块会配置一个输入端口 **Length**。

### **等待直到上一数据包传输完成** — 等待直到上一时间步接收的数据发送完成 `off`（默认）| `on`

- `on` — 选择此参数时，发送操作以阻塞模式运行。在此模式下，如果模块仍在传输上一时间步接收的数据包，则模块会保留当前时间步输入端口处的数据并等待发送。

  如果目标硬件在计划开始下一次发送操作时仍在等待所请求的数据发送，则会发生任务超限。要修复超限，请使用 **采样时间** 参数增大时间步。
- `off` — 清除此参数时，发送操作以非阻塞模式运行。在此模式下，如果模块仍在传输上一时间步接收的数据包，则当前时间步输入端口处的数据将被丢弃。

  在任一模式下，如果模块尚未建立发送和接收主机之间的连接，或者连接丢失，则输入端口处的数据将被丢弃。

### **输出传输状态** — 用于在数据传输期间显示传输状态的选项 `off`（默认）| `on`

选择此选项以在数据传输期间显示传输状态。

当您选择输出传输状态参数时，模块会配置一个输出端口。模块上的该端口标记为 Status，指示模块在输出端口处输出传输操作的状态。

## 描述

通过 TCP/IP 网络将数据发送到远程主机

TCP Send 模块通过 TCP/IP 网络将数据发送到远程主机或另一硬件板。在将包含 TCP Send 模块的模型部署到目标之前，服务器必须已启动并正在运行。

该模块以阻塞模式或非阻塞模式发送数据。在阻塞模式下，模型在等待数据完全发送期间会阻止执行。在非阻塞模式下，模型会连续运行。要将模块设置为阻塞模式，请选择 **等待直到上一数据包传输完成** 选项。

**注意**

- 您的防病毒软件或防火墙可能会阻止 TCP 流量。请配置该软件以允许来自特定 IP 端口号的流量。
- 由于 F2838x (ARM Cortex-M4) 上的 RAM 内存限制，此模块不支持将应用程序加载到 RAM。
- F2838x Arm Cortex-M 内核（Connectivity Manager）的 CPU Timer 2 为 lwIP 协议栈提供时基。它配置为每 1 ms 触发一次中断。如果模型中使用了 Ethernet 模块，则不应重新配置此定时器。如果通过 Hardware Interrupt 模块使能了相应中断，它将每 1 ms 运行一次中断处理程序。
- 在 TI C2000 与 Raspberry Pi 等其他目标之间建立 TCP 通信时，请将 TCP Send 和 TCP Receive 模块配置为同时为客户端或同时为服务器，以成功建立通信。不支持混合配置。
