# C2000 Integer part IQN

IQ 数的整数部分

此模块返回 IQ 数的整数部分。返回值为 long integer。

**注意**

此模块的实现不会在代码生成期间调用对应的 Texas Instruments® 库函数。TI 函数使用全局 Q 设置，而此模块使用的 MathWorks® 代码会基于模块输入动态调整 Q 格式。有关详细信息，请参阅 Using the IQmath Library。
