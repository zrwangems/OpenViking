# AD9361 Tx

## 端口

### 输入

### **txDataIn** — 发射数据复数矩阵

发射数据，指定为复数矩阵。矩阵中的列数取决于正在使用的通道数。每列对应于通过一个通道发送的复数数据的一个通道。在单通道模式下，一列中的元素数必须为偶数。

此端口支持具有以下数据类型的复数值：

- 16-bit signed integers — 由于 AD9361 RF 芯片具有 12-bit DAC，仅使用 I 和 Q 采样的 12 个最高有效位。
- Single-precision floating point — [–1, 1] 范围内的复数值。由于 AD9361 RF 芯片具有 12-bit DAC，幅值小于 0.0625 的数会丢失。
- Double-precision floating point — [–1, 1] 范围内的复数值。由于 AD9361 RF 芯片具有 12-bit DAC，幅值小于 0.0625 的数会丢失。

**数据类型：** `int16` | `single` | `double`
**复数支持：** 是

### **txValid** — 发射数据的有效性 `Boolean` 标量

发射数据的有效性，指定为 Boolean 标量。当 **txValid** 为 `1` 时，模块会捕获来自 **txDataIn** 端口的输入数据。当 **txValid** 为 `0` 时，模块会将输入数据视为无效，并且不会捕获它。
### 输出

### **txDataOut** — 发射数据复数矩阵

通过模块传递的发射数据，以复数矩阵形式返回。矩阵中的列数取决于正在使用的通道数。每列对应于在一个通道上接收的复数数据的一个通道。

此端口支持具有以下数据类型的复数值：

- 16-bit signed integers — 由于 AD9361 RF 芯片具有 12-bit DAC，仅使用 I 和 Q 采样的 12 个最高有效位。
- Single-precision floating point — [–1, 1] 范围内的复数值。由于 AD9361 RF 芯片具有 12-bit DAC，幅值小于 0.0625 的数会丢失。
- Double-precision floating point — [–1, 1] 范围内的复数值。由于 AD9361 RF 芯片具有 12-bit DAC，幅值小于 0.0625 的数会丢失。

#### 依赖项

要启用此端口，请将 **将仿真输入发送到** 参数设置为 `Output port`。

**数据类型：** `int16` | `single` | `double`
**复数支持：** 是

## 参数

### **启用通道 1** — 用于启用通道 1 的选项 `on`（默认）| `off`

选择此参数以启用发射通道 1。

### **启用通道 2** — 用于启用通道 2 的选项 `off`（默认）| `on`

选择此参数以启用发射通道 2。

### **将仿真输入发送到** — 仿真行为 `Data file`（默认）| `Output port` | `Terminator`

仿真行为，指定为以下值之一：

- `Data file` –– 将来自 **txDataIn** 端口的有效数据导出到文件，使用 **数据集名称** 和 **源名称** 参数。
- `Output port` –– 直通来自输入端口的数据。
- `Terminator` –– 将 **txValidIn** 端口连接到模块内部的终止器。

### **数据集名称** — 记录文件的名称 `rf_tx_data.tgz`（默认）| 文件路径

记录文件的名称，指定为主机上的文件路径，或者浏览并选择主机上的文件。此模块仅支持使用 SoC Blockset 数据记录 API 创建的 TGZ 文件。默认值是从 Packet-Based ADS-B Transceiver 示例中记录的数据集。

### **源名称** — 数据集名称 `RF data Ch-1`（默认）| character vector

记录数据集文件中可用数据集的名称，指定为 character vector。该数据集必须存在于 **数据集名称** 参数指定的文件中。您可以在 **源名称** 框中键入名称，或点击 **选择** 以查看记录数据文件中可用的源列表并检查其属性。默认值是从 Packet-Based ADS-B Transceiver 示例中记录的数据集。

## 描述

将硬件逻辑连接到基于 AD9361 的 Zynq 发射器

AD9361 Tx 模块将您的硬件逻辑连接到 AD9361 发射器硬件。在仿真中，此模块会将数据返回到文件或输出端口。它不会从仿真连接到无线电硬件。

此模块支持最多两个通道来发送数据。
