# Drive Cycle Source

## 端口

### 输入

### **VelFdbk** — 车辆纵向速度 `scalar`

车辆纵向速度。

#### 依赖关系

要启用此端口，在 **故障跟踪** 选项卡上，选择 **启用故障跟踪**。将 **速度反馈单位, inUnit** 参数设置为 `VelFdbk` 输入端口信号单位。
### 输出

### **Info** — 总线信号 bus

包含这些模块计算的总线信号。

| 信号 | | 描述 |
| --- | --- | --- |
| `Reference Speed` | | 车辆参考速度 |
| `Reference Accel` | | 车辆参考加速度 |
| `Gear` | | 车辆挡位 |
| `Fault` | `UpprBnd` | 允许车辆速度范围的上限。 |
| `LowerBnd` | 允许车辆速度范围的下限。 |
| `Fault` | 指示故障条件的布尔值：  - 1 — 故障 - 0 — 无故障    如果车辆速度不在允许速度范围内，模块将设置故障条件。 |
| `FaultCnt` | 故障数量。 |
| `CumFaultTime` | 处于故障条件的累计时间。 |
| `SnglFaultTime` | 单次故障花费的时间。 |
| `Fail` | 指示故障失败的布尔值：  - 1 — 失败 - 0 — 无失败    如果故障条件超过最大故障数量、最大单次故障时间或最大总故障时间，模块将设置故障失败。 |

#### 依赖关系

要启用此端口，在 **故障跟踪** 选项卡上，选择 **启用故障跟踪**。

### **RefSpd** — 车辆参考速度 `scalar`

车辆参考速度，采用你指定的单位。要指定单位，使用 **输出速度单位** 参数。

### **RefAcc** — 车辆参考加速度 `scalar`

为计算加速度，模块使用二阶多项式和三点采样点滤波器实现 Savitzky-Golay 微分。

#### 依赖关系

要创建输出加速度端口，选择 **输出加速度**。选择 **输出加速度** 会启用 **输出加速度单位** 参数。

### **Gear** — 车辆挡位 `scalar`

#### 依赖关系

要启用此端口：

1. 首先指定包含换挡时间表的驱动循环。可以使用：

   - 支持包来安装包含换挡时间表的标准驱动循环，例如 `JC08` 和 `CUEDC`。
   - 工作区变量。
   - .`mat`、.`xls`、.`xlsx` 或 .`txt` 文件。
2. 选择 **输出换挡数据**。

## 参数

### 循环设置

#### 设置

### **驱动循环源** — 选择驱动循环源 `FTP75`（默认）| `Wide Open Throttle (WOT)` | `Workspace variable` | `.mat, .xls, .xlsx or .txt file`

- `FTP75` — 从 .`mat` 文件将 FTP75 驱动循环加载到 1-D Lookup Table 模块中。FTP75 表示城市驱动循环，可用于确定乘用车的尾气排放和燃油经济性。

  要从支持包安装其他驱动循环，请参阅 Install Drive Cycle Data。
- `Wide Open Throttle (WOT)` — 使用 WOT 参数指定用于性能测试的驱动循环。
- `Workspace variable` — 将时间、速度以及可选的挡位数据指定为结构体、二维数组或时间序列对象。
- `.mat, .xls, .xlsx or .txt file` — 指定包含列格式的时间、速度以及可选的挡位数据的文件。

安装其他循环后，可以使用 `set_param` 设置驱动循环。例如，要使用驱动循环 `US06`：

```
set_param([gcs '/Drive Cycle Source'],'cycleVar','US06')
```

### **来自工作区** — 工作区 `variable`

工作区变量，包含单调递增时间向量、速度向量以及可选的挡位数据向量。可以使用结构体、二维数组或时间序列对象。在 **源速度单位** 参数字段中输入速度单位。

每个对应时间值必须存在有效点。不能指定 `inf`、`empty` 或 `NaN`。

下表提供了使用工作区变量创建自己的驱动循环的示例。

| 工作区变量 | 源速度单位 | 输出速度单位 | 驱动循环图 |
| --- | --- | --- | --- |
| 不带换挡时间表的结构体，**来自工作区** 设置为 `myCycleS`。  ``` t = 0:1:100; xdot = 5.*sin(t)+10; myCycleS.time = t'; myCycleS.signals.values = xdot'; ``` | `m/s` | `mph` | 显示正弦波的速度-时间图 |
| 带换挡时间表的结构体，**来自工作区** 设置为 `myCycleS`。  ``` gears=[0, 1, 2, 3, 3, 4, 4, 4, 4, 4, 4]; t=0:1:10; xdot=[0,5,10,15,20,25,30,30,30,30,30]; myCycleS.time=t'; myCycleS.signals.values=[xdot',gears']; ``` | `m/s` | `mph` | 显示从 0 秒时 0 mph 线性增加到 6 秒时 70 mph 的速度-时间图。6 秒后，速度保持恒定在 70 mph。 |
| 不带换挡时间表的二维数组，**来自工作区** 设置为 `myCycleA`。  ``` t = 0:1:100; xdot = 5.*sin(t)+5; myCycleA = [t',xdot']; ``` | `m/s` | `mph` | 显示正弦波的速度-时间图 |
| 带换挡时间表的二维数组，**来自工作区** 设置为 `myCycleA`。  ``` gears=[0, 1, 2, 3, 4, 4, 4, 5, 5, 5, 5]; t=0:1:10; xdot=[0,5,10,15,20,25,30,40,50,60,60]; myCycleA=[t',xdot',gears']; ``` | `mph` | `mph` | 显示从 0 秒时 0 mph 线性增加到 6 秒时 30 mph，再到 9 秒时 60 mph 的速度-时间图。9 秒后，速度保持恒定在 60 mph。 |
| 不带换挡时间表的时间序列对象，**来自工作区** 设置为 `myCycleT`。  ``` myCycleT = timeseries; t = 0:1:100; xdot = 5.*sin(t)+20; myCycleT.Data = xdot'; myCycleT.Time = t'; ``` | `m/s` | `mph` | 显示正弦波的速度-时间图 |
| 不带换挡时间表的时间序列对象，**来自工作区** 设置为 `myCycleT`。  ``` myCycleT = timeseries; gears=[0, 1, 2, 3, 4, 4, 4, 5, 5, 5, 5]; t=0:1:10; xdot=[0,10,20,30,32,33,34,40,50,60,60]; myCycleT.Data = [xdot',gears']; myCycleT.Time = t'; ``` | `mph` | `mph` | 显示 mph 线性增加的速度-时间图。9 秒后，速度保持恒定在 60 mph。 |

#### 依赖关系

要启用此参数，从 **驱动循环源** 中选择 `Workspace variable`。

### **驱动循环源文件** — 文件名 `.mat, .xls, .xlsx or .txt`

包含单调递增时间数据、速度数据以及可选的列格式或逗号分隔格式挡位数据的文件。模块忽略文件中的单位。在 **源速度单位** 参数字段中输入源速度单位。

| 文件 | 源速度单位 | 输出速度单位 | 驱动循环图 |
| --- | --- | --- | --- |
| 包含与文件名同名矩阵的 .`mat` 文件。该矩阵包含第 1 列中的时间和第 2 列中的速度。它可以选择性地包含第 3 列中的挡位选择。  ``` sampcyc =           0         0     0.5000    0.7000     1.0000    2.0000      1.5000    3.6000     2.0000    5.6000     2.5000    7.9000      3.0000   10.3000     3.5000   13.0000      4.0000   16.0000     4.5000   19.0000     5.0000   22.3000     5.5000   25.7000     6.0000   29.3000 ``` | `m/s` | `m/s` | 速度-时间图 |
| 第 A 列中为时间、第 B 列中为速度的 .`xls` 或 .`xlsx` 文件。  11 行，第 A 列中为时间，第 B 列中为速度 | `mph` | `mph` | 速度-时间图 |
| 第 A 列中为时间、第 B 列中为速度、第 C 列中为挡位的 .`xls` 或 .`xlsx` 文件。模块：  - 忽略文件中的表头和单位。 - 将挡位信息转换为整数：  - N 到 0   - D 到 2    12 行，第 A 列中为以 sec 为单位的时间，第 B 列中为以 mph 为单位的速度，第 C 列中为挡位 | `mph` | `mph` | 速度-时间图 |
| 第 1 列中为时间、第 2 列中为速度的 .`txt` 文件。模块忽略表头和单位信息。  20 行，第 A 列中为以 sec 为单位的时间，第 B 列中为以 mph 为单位的速度 | `mph` | `mph` | 速度-时间图 |

可以从外部源导入标准驱动循环文件。例如，可以按照 WTMC 上的说明导入全球统一摩托车排放认证和测试程序（WMTC）循环。具体来说：

1. 下载换挡表和说明。
2. 按照说明根据您的输入计算换挡数据。
3. 速度单位是 `km/hr`。使用换算系数 1000/3600 将速度转换为 `m/s`。
4. 将数据复制并保存到新的 .`xls` 或 .`xlsx` 文件中，以用作源文件。

如果使用 **P**、**R**、**N**、**D**、**L**、**OD** 提供挡位时间表，模块会将挡位映射为整数。

| 挡位 | 整数 |
| --- | --- |
| P | `80` |
| R | `-1` |
| N | `0` |
| L | `1` |
| D | `2` |
| OD | 最高指定挡位之后的下一个整数。 |

例如，模块将挡位时间表 `P P N L D 3 4 5 6 5 4 5 6 7 OD 7` 转换为 `80 80 0 1 2 3 4 5 6 5 4 5 6 7 8 7`。

### 故障跟踪

#### 故障设置

### **启用故障跟踪** — 启用故障跟踪 `off`（默认）| `on`

- **时间容差, timeBnd**

### **速度容差, velBnd** — 驱动循环速度容差 `2.0`（默认）| `scalar`

标准化测试指定要使用的速度容差。以下是两个示例：

- EPA 测功机驾驶时间表 — `2.0`
- WLTP 测试 — `2.0`

## 描述

标准或指定的纵向驱动循环

Drive Cycle Source 模块生成标准或用户指定的纵向驱动循环。模块输出是作为时间函数的车辆纵向参考速度，以及适用时的换挡时间表。可以使用驱动循环来：

- 预测车辆在给定换挡时间表下遵循指定速度曲线所需的发动机扭矩和燃油消耗。
- 为车辆控制和被控对象模型的闭环加速和制动命令生成真实的速度和换挡时间表。
- 在研究、调整和优化车辆控制、系统性能以及覆盖多个驱动循环时的系统鲁棒性。
- 识别超出标准化测试指定容差的故障。这些包括：

  - EPA 测功机驾驶时间表1
  - 全球统一轻型车辆测试程序（WLTP）实验室测试2

要生成驱动循环，可以使用：

- 来自预定义源的驱动循环。模块默认包含 `FTP–75` 驱动循环，并且可以从支持包加载其他循环。

  要从支持包安装其他驱动循环，请参阅 Install Drive Cycle Data。某些驱动循环包括换挡时间表，例如 `JC08` 和 `CUEDC`。
- 定义您自己的驱动循环的工作区变量。
- .`mat`、.`xls`、.`xlsx` 或 .`txt` 文件。这允许您加载其他标准驱动循环，或您构建的驱动循环。
- 节气门全开（WOT）参数。设置初始和标称参考速度以产生参考速度的突然大幅变化，从而在车辆中引发 WOT 条件。

要实现下表所列目标，请使用指定的 Drive Cycle Source 模块参数选项。

| 目标 | 操作 |
| --- | --- |
| 如果仿真运行时间超过驱动循环长度，则重复驱动循环。 | 选择 **循环重复**。 |

### 故障和故障失败跟踪

在 **故障跟踪** 选项卡上，使用这些参数指定故障容差。如果车辆速度不在给定参考时间的允许范围内，模块将设置故障条件。此处显示了 EPA 和 WLTP 循环的示例：

| 参数 | 描述 | 设置 | |
| --- | --- | --- | --- |
| EPA 标准1 | WLTP 测试2 |
| **速度容差** | 在时间容差内，高于驱动循环速度轨迹最高点和低于最低点的速度容差。 | 2.0 mph | 2.0 km/h |
| **时间容差** | 模块用于确定允许速度范围的时间。 | 1.0 s | 1.0 s |
| **最大故障数量** | 驱动循环期间允许的最大故障数量，超过该数量将导致故障失败。 | *未指定* | 10 |

### 使用工作区变量创建驱动循环
