# Data Input

## 端口

### 输出

### **Port\_1** — 在数据输入字段中输入的值 `1.0`（默认）| 向量

该模块输出您通过在设备键盘上键入而在数据输入字段中输入的值。

**数据类型：** `uint8` | `int8` | `uint16` | `int16` | `uint32` | `int32` | `single` | `double`

## 参数

### **字符向量输入** — 用于指定输入数据是否为字符向量数据的选项 off（默认）

选择此选项可启用在数据输入字段中输入字符向量数据。

- 当您选择**字符向量输入**选项时，Android 设备上的键盘布局将变为 QWERTY。数据输入字段接受 QWERTY 键盘支持的任何值。

  该模块输出一个 1×*N* 向量，其中包含与数据输入字段中输入字符的 ASCII 值相对应的 `uint8` 值。*N* 是在**字符数**参数中指定的长度。
- 当您清除**字符向量输入**选项时，键盘布局保持为数字键盘。数据输入字段仅接受与**数据类型**参数中指定的类型相符的值。

  | 当输入为字符向量时 | 当输入为数值时 |
  | --- | --- |
  |  |  |

### **初始值** — 数据输入字段的默认值 `0.1`（默认）| 当前数据类型的任何有效值

- 对于数值输入，该模块会将初始值转换为**数据类型**参数中指定的类型，然后将其显示在数据输入字段中。例如，如果**初始值**指定为 `1`，并且**数据类型**参数设置为 `double`，则数据输入字段中显示的值是 `1.0000000000000`。
- 对于字符向量输入，请确保**初始值**参数中字符向量的长度不超过**字符数**参数中指定的值。

### **字符数** — 字符向量的最大长度 `100`（默认）| 小于 256 的任何正整数

指定可在数据输入字段中输入的最大字符数。数据输入字段不接受超过**字符数**参数中指定长度的任何输入。

如果字符向量中的字符数小于**字符数**参数中指定的长度，则该模块会用零填充输出数组中的空位。

下表以文本 `Hello` 为例，展示了当数据输入字段中输入的字符向量长度小于、等于或大于**字符数**参数中指定的长度时的模块输出。

| 数据输入字段中的数据长度 < 字符数 | 数据输入字段中的数据长度 = 字符数 | 数据输入字段中的数据长度 > 字符数 |
| --- | --- | --- |
| **字符数** = `8` | **字符数** = `5` | **字符数** = `2` |
|  |  |  |

#### 依赖关系

当您选择**字符向量输入**选项时，将显示**字符数**参数。

### **数据类型** — 输入数据的数据类型 `double`（默认）| `uint8` | `int8` | `uint16` | `int16` | `uint32` | `int32` | `single`

指定在数据输入字段中输入的数据的类型。数据输入字段仅接受在**数据类型**参数中指定的范围内的输入。例如，如果将**数据类型**设置为 `int8`，则数据输入字段不接受超出 −128 到 127 范围的任何值。

**注意**

您可能会观察到，在数据输入字段中输入的 `single` 或 `double` 数据的浮点计算并不像您预期的那样精确。遵循 IEEE standard 754，Simulink® 以有限精度表示数字。有关浮点数据计算的详细信息，请参阅浮点数。

#### 依赖关系

当您清除**字符向量输入**选项时，将显示**数据类型**参数。

### **采样时间** — 该模块读取数据的频率 `0.1`（默认）| `-1` | 任何正整数

指定该模块从数据输入字段读取数据的频率，以 seconds 为单位。当您将此参数指定为 `-1` 时，Simulink 会根据模型中的模块上下文确定该模块的最佳采样时间。

## 描述

在设备屏幕上生成数据输入字段

Data Input 模块在 Android™ 设备屏幕上生成一个数据输入字段。数据输入字段是一个编辑框，可通过在设备键盘上键入来输入或修改数据。**模块参数**对话框中的**数据类型**参数指定可在数据输入字段中输入的数据类型。

该模块输出您在数据输入字段中输入的值。对于字符向量输入，该模块输出相应的 ASCII 值。

**注意**

在没有硬件的仿真期间，此模块输出零。有关详细信息，请参阅模块在仿真中产生零或不执行任何操作。
