# Ultrasonic Sensor

## 端口

### 输出

### **Port\_1** — 超声波传感器与传感器前方最近物体之间的距离 标量

该端口输出连接到硬件的超声波传感器与传感器前方最近物体之间的距离。该模块以 meters 为单位输出距离。如果物体放置在传感器检测范围之外，则该端口输出 `0`。

**数据类型：** `double`

## 参数

### **信号引脚数** — 超声波传感器上的信号引脚数量 `1`（默认） | `2`

选择超声波传感器上用于发送和接收声波的信号引脚数量。

- `1` — 如果超声波传感器只有一个信号引脚 SIG，则选择 `1`。
- `2` — 如果超声波传感器有两个单独的信号引脚 Trig 和 Echo，则选择 `2`。

### **触发引脚** — 连接到 Trig 引脚的数字引脚 `4`（默认） | 任何有效的引脚编号

选择硬件上超声波传感器的 Trig 引脚所连接的数字引脚。有关硬件上数字引脚编号的信息，请单击 **查看引脚映射**。

要了解如何为该模块分配引脚，请参阅 Arduino 定时器无关模块的引脚映射。

#### 依赖关系

仅当您将 **信号引脚数** 参数设置为 `2` 时，**触发引脚** 参数才会出现。

### **回波引脚** — 连接到 Echo 引脚的数字引脚 `5`（默认） | 任何有效的引脚编号

选择硬件上超声波传感器的 Echo 引脚所连接的数字引脚。有关硬件上数字引脚编号的信息，请单击 **查看引脚映射**。

要了解如何为该模块分配引脚，请参阅 Arduino 定时器无关模块的引脚映射。

#### 依赖关系

仅当您将 **信号引脚数** 参数设置为 `2` 时，**回波引脚** 参数才会出现。

### **信号引脚** — 连接到 SIG 引脚的数字引脚 `3`（默认） | 任何有效的引脚编号

选择硬件上超声波传感器的 SIG 引脚所连接的数字引脚。有关硬件上数字引脚编号的信息，请单击 **查看引脚映射**。

要了解如何为该模块分配引脚，请参阅 Arduino 定时器无关模块的引脚映射。

#### 依赖关系

仅当您将 **信号引脚数** 参数设置为 `1` 时，**信号引脚** 参数才会出现。

### **采样时间** — 使用超声波传感器读取距离的间隔 `0.1`（默认） | `-1` | 任何非负值

指定该模块使用超声波传感器读取距离的频率，以 seconds 为单位。

指定 **采样时间** 时，请验证以下设置以避免任务超限：

1. **采样时间** 参数必须等于模型基础速率。要查看模型基础速率，请在模型工具栏上选择 **显示** > **采样时间** > **全部**。在采样时间图例对话框中，红色框对应的值就是模型的基础速率。
2. **采样时间** 参数和模型基础速率必须大于传感器发送和接收声波所需的总时间。例如，如果物体放置在距离传感器 0.1 meters 处，则指定的 **采样时间** 参数必须大于 `0.000301` seconds。

   有关如何计算声波传播时间的信息，请参阅计算声波传播时间。

## 描述

测量超声波传感器与物体之间的距离

Ultrasonic Sensor 模块输出连接到硬件的超声波传感器与传感器前方最近物体之间的距离。该模块以 meters 为单位将距离输出为 double-precision 值。如果物体放置在传感器检测范围之外，则该模块输出 `0`。

如果在未连接硬件的情况下对包含 Ultrasonic Sensor 模块的模型进行仿真，则该模块输出零。有关详细信息，请参阅模块在仿真中产生零或不执行任何操作。
