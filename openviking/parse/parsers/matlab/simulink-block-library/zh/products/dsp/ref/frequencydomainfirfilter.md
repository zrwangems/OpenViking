# Frequency-Domain FIR Filter

## 端口

### 输入

### **x** — 数据输入 向量 | 矩阵

数据输入，指定为大小为 *L*-by-*T* 的向量或矩阵。此模块支持可变大小输入信号，也就是说，即使在调用算法之后，也可以更改输入帧大小（行数）。但是，通道数（列数）必须保持不变。

在选择 **从输入端口指定系数** 参数之前，此端口未命名。

**数据类型：** `single` | `double`
**复数支持：** 是

### **Num** — 时域 FIR 滤波器系数 行向量 | 矩阵 *（自 R2024a 起）*

将时域 FIR 滤波器系数指定为大小为 *F*-by-*NumLen* 的行向量（单个滤波器）或矩阵（多个滤波器）*（自 R2024a 起）*，其中 *F* 是滤波器数，*NumLen* 是滤波器长度。如果 *F* 大于 1，则其值必须是输入通道数（列数）*T* 与通过 **传播路径数** 参数指定的路径数 *P* 的乘积的倍数。乘数因子决定输出通道数 *R*，且等于 *F*/(*T* × *P*)。

系数值可以在仿真期间更改，但分子的大小必须保持不变。

#### 依赖关系

要启用此端口，请将 **分子域** 设置为 `Time`，并选中 **从输入端口指定系数** 参数。

**数据类型：** `single` | `double` | `int8` | `int16` | `int32` | `uint8` | `uint16` | `uint32`
**复数支持：** 是

### **NumFFT** — 频域 FIR 滤波器系数 行向量 | 矩阵 | 三维数组 *（自 R2024a 起）*

将频域 FIR 滤波器系数指定为行向量、矩阵或三维数组 *（自 R2024a 起）*。

当清除 **对分子进行分区以降低延迟** 参数时，此端口输入的系数可以是行向量或大小为 *F*-by-*FFTLength* 的矩阵。FFT 长度等于向量输入的长度。如果 *F* 大于 1（多个滤波器）*（自 R2024a 起）*，则其值必须是输入通道数（列数）*T* 与通过 **传播路径数** 参数指定的路径数 *P* 的乘积的倍数。乘数因子决定输出通道数 *R*，且等于 *F*/(*T* × *P*)。

当选中 **对分子进行分区以降低延迟** 参数时，**频率响应** 必须为大小为 2*PL*-by-*N* 的矩阵以表示单个滤波器，或为大小为 2*PL*-by-*N*-by-*F* 的三维数组 *（自 R2024a 起）* 以表示多个滤波器，其中 *PL* 是分区大小，*N* 是分区数，*F* 是滤波器数。

#### 依赖关系

要启用此端口，请将 **分子域** 设置为 `Frequency`，并选中 **从输入端口指定频率响应** 参数。

**数据类型：** `single` | `double` | `int8` | `int16` | `int32` | `uint8` | `uint16` | `uint32`
**复数支持：** 是

### 输出参数

### **output** — 滤波后输出 向量 | 矩阵 | 三维数组 *（自 R2024a 起）*

滤波后输出，返回为向量、矩阵或三维数组 *（自 R2024a 起）*。

当滤波器数 *F* 大于 1 且选中 **对所有输入通道的滤波输出贡献求和** 参数时，模块将来自每个输入通道的滤波后输出相加，生成 *L*-by-*R* 输出矩阵，其中 *L* 是输入帧大小（输入行数），*R* 是输出通道数。*R* 等于 *F*/(*T* x *P*)，其中 *F* 是滤波器数，*T* 是输入通道数，*P* 是在 **传播路径数** 参数中指定的值。*（自 R2024a 起）*

当清除 **对所有输入通道的滤波输出贡献求和** 参数时，模块不会对所有输入通道的滤波输出贡献求和。输出是 *L*-by-*R*-by-*T* 数组。`output(:,j,k)` 表示第 *k* 个输入通道对第 *j* 个输出通道的输出。例如，`output(:,3,2)` 表示第二个输入通道在第三个输出通道上的输出。*（自 R2024a 起）*

有关对象如何计算输出的更多信息，请参阅算法。

输出的数据类型和复数属性与输入信号相同。

在选择 **输出滤波器延迟** 参数并点击 **应用** 之前，此端口未命名。

**数据类型：** `single` | `double`
**复数支持：** 是

### **latency** — 滤波器延迟 正整数

滤波器延迟，返回为标量。此延迟是 overlap-add 和 overlap-save 方法固有的，不包括滤波器的群延迟。仅当选中 **输出滤波器延迟** 复选框时，此端口才会出现。

在选择 **输出滤波器延迟** 复选框并点击 **应用** 之前，此端口未命名。

**数据类型：** `uint32`

## 参数

### **频域滤波方法** — 频域中的滤波方法 `Overlap-save`（默认）| `Overlap-add`

将频域中的滤波方法指定为 `Overlap-save` 或 `Overlap-add`。有关这两种方法的更多详细信息，请参阅算法。

### **分子域** — 分子域 `Time`（默认）| `Frequency`

将滤波器系数的域指定为以下之一：

- `Time` –– 在 **滤波器系数** 参数中或通过 **Num** 输入端口指定时域滤波器系数。
- `Frequency` –– 在 **频率响应** 参数中或通过 **NumFFT** 输入端口指定滤波器的频率响应。

### **从输入端口指定系数** — 用于指定时域 FIR 滤波器系数的标志 `off`（默认）| `on`

选中此复选框时，时域 FIR 滤波器系数通过端口 **Num** 输入。清除此复选框时，系数通过 **滤波器系数** 参数在模块对话框中指定。

要查看滤波器响应，请清除此复选框，在模块对话框中指定系数，然后点击 **查看滤波器响应** 按钮。

#### 依赖关系

要启用此参数，请将 **分子域** 设置为 `Time`。

将时域 FIR 滤波器系数指定为大小为 *F*-by-*NumLen* 的行向量（单个滤波器）或矩阵（多个滤波器）*（自 R2024a 起）*，其中 *F* 是滤波器数，*NumLen* 是滤波器长度。如果 *F* 大于 1，则其值必须是输入通道数（列数）*T* 与通过 **传播路径数** 参数指定的路径数 *P* 的乘积的倍数。乘数因子决定输出通道数 *R*，且等于 *F*/(*T* × *P*)。

系数值可以在仿真期间更改，但分子的大小必须保持不变。

要启用此参数，请将 **分子域** 设置为 `Time`，并清除 **从输入端口指定系数** 参数。

**数据类型：** `single` | `double` | `int8` | `int16` | `int32` | `int64` | `uint8` | `uint16` | `uint32` | `uint64`
**复数支持：** 是

### **从输入端口指定频率响应** — 用于指定频域滤波器系数的标志 off（默认）| on

选中此复选框时，频域中的 FIR 滤波器系数通过端口 **NumFFT** 输入。清除此复选框时，系数通过 **频率响应** 参数在模块对话框中指定。

### **传播路径数** — 每个输入通道和输出通道对之间的传播路径数 `1`（默认）| 正整数

*自 R2024a 起*

有关示例，请参阅 Filter Input Signal Using 1-by-2 SIMO System。

**数据类型：** `single` | `double`

### **对分子进行分区以降低延迟** — 用于对分子进行分区以降低延迟的选项 `off`（默认）| `on`

## 描述

在频域中对输入信号进行滤波

Frequency-Domain FIR Filter 模块实现基于频域快速傅里叶变换 (FFT) 的滤波，以对流式输入信号进行滤波。在时域中，滤波操作涉及输入与有限脉冲响应 (FIR) 滤波器的脉冲响应之间的卷积。在频域中，滤波操作涉及输入的傅里叶变换与脉冲响应的傅里叶变换的乘积。随着脉冲响应变长，频域滤波比时域滤波更高效。通过将 **分子域** 设置为 `Frequency`，可以直接在频域中指定滤波器系数。

此模块使用 overlap-save 和 overlap-add 方法执行频域滤波。对于脉冲响应长度较长的滤波器，这两种方法固有的延迟可能很大。为了减轻此延迟，Frequency-Domain FIR Filter 模块将脉冲响应划分为较短的块，并在这些较短的块上实现 overlap-save 和 overlap-add 方法。要对脉冲响应进行分区，请选中 **对分子进行分区以降低延迟** 复选框。有关这两种方法以及通过脉冲响应分区降低延迟的更多详细信息，请参阅算法。

Frequency-Domain FIR Filter 模块可以通过在时域和频域中支持多个滤波器，对单输入多输出 (SIMO) 和多输入多输出 (MIMO) 系统建模。有关展示如何对此类系统建模的示例，请参阅 Filter Input Signal Using 1-by-2 SIMO System 和 Filter Input Signal Using 3-by-2 MIMO System。还可以使用 **传播路径数** 参数指定每个输入通道和输出通道对之间的多条路径。有关对 MIMO 系统建模的更多信息，请参阅 Modeling MIMO System with Multiple Propagation Paths。*（自 R2024a 起）*
