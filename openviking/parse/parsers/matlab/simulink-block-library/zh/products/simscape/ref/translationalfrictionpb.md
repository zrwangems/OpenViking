# Translational Friction (PB)

## 端口

### 输入

### **N** — 法向力控制信号，N 物理信号

用于指定法向力的控制信号的物理信号输入端口。
如果信号变为负值，模块会将输入值饱和到 0。

#### 依赖关系

要启用此端口，请将 **法向力指定** 参数设置为 `Variable`。
### 守恒

### **B** — 基座端口，基于位置的机械平移

表示基座连接的基于位置的机械平移守恒端口。

### **F** — 从动端口，基于位置的机械平移

表示从动连接的基于位置的机械平移守恒端口。对于正长度，端口 **F** 的位置比端口 **B** 更正。

## 参数

### **法向力指定** — 法向力是常量还是变量 `Constant`（默认）| `Variable`

选择施加到模块上的法向力是常量还是变量：

- `Constant` — 使用 **法向力** 参数值指定法向力。
- `Variable` — 使用端口 **N** 处的物理信号指定法向力。

### **法向力** — 垂直于运动的力 `10 N`（默认）| 非负标量

沿垂直于运动方向施加到模块上的力。模块基于此值和比例系数 **分离摩擦系数** 与 **库仑摩擦系数** 计算分离摩擦力和库仑摩擦力。

#### 依赖关系

要启用此参数，请将 **法向力指定** 设置为 `Constant`。

### **分离摩擦系数** — 法向力与分离摩擦力之间的比例系数 `2.5`（默认）| 正标量

用于基于法向力计算分离摩擦力的系数，该力是库仑摩擦与静摩擦之和。参数值必须大于或等于 **库仑摩擦系数** 的值。

### **分离摩擦速度** — Stribeck 摩擦的峰值速度 `0.1 m/s`（默认）| 正标量

Stribeck 摩擦达到峰值时的速度。此时，Stribeck 摩擦与库仑摩擦之和为分离摩擦力。此参数指定速度阈值，它会影响仿真精度与速度之间的权衡。

### **库仑摩擦系数** — 法向力与阻碍运动的摩擦之间的比例系数 `2`（默认）| 非负标量

用于基于法向力计算库仑摩擦力的系数，库仑摩擦力是阻碍运动的摩擦。

### **粘性摩擦系数** — 粘性损耗比例系数 `0 N/(m/s)`（默认）| 非负标量

摩擦力与相对速度之间的比例系数。粘性损耗不依赖于法向力。

## 描述

基于位置的机械平移系统中表面之间的阻力摩擦接触

Translational Friction (PB) 模块表示表面之间的阻力摩擦接触。

摩擦力是相对速度的函数，并假定为 Stribeck、库仑和粘性分量之和，如图所示。

摩擦力示意图

Stribeck 摩擦，*F*S，是在低速时出现的负斜率特性 [1]。库仑摩擦，*F*C，在任何速度下都会产生恒定力。粘性摩擦，*F*V，阻碍运动，其力与相对速度成正比。在零速度附近，库仑摩擦与 Stribeck 摩擦之和即为分离摩擦，*F*brk。

您指定法向力，*F*N，它沿垂直于导轨（即垂直于运动方向）的方向作用于模块。模块基于法向力以及您也指定的比例系数计算分离摩擦力和库仑摩擦力。法向力可以是常量或变量。

摩擦力用以下方程近似：

ffriction=−2e(Fbrk−FC)⋅exp(−(vvSt)2)⋅vvSt−FC⋅tanh(vvCoul)−fvv

Fbrk=FN⋅Kbrk

FC=FN⋅KC

vSt=vbrk2

vCoul=vbrk/10

v=vF−vB

length=xF−xB

power\_dissipated=−ffriction⋅v

其中：

- *f*friction 是摩擦力。
- *F*N 是法向力，它沿垂直于导轨（即垂直于运动方向）的方向作用于模块。
- *F*C 是库仑摩擦。
- *K*C 是库仑摩擦系数。
- *F*brk 是分离摩擦。
- *K*brk 是分离摩擦系数。
- *f*v 是粘性摩擦系数。
- *v*brk 是分离摩擦速度。
- *v*St 是 Stribeck 速度阈值。
- *v*Coul 是库仑速度阈值。
- *v* 是相对速度。
- *v*B 和 *v*F 分别是端口 **B** 和 **F** 的绝对速度。
- *length* 是摩擦长度。
- *x*B 和 *x*F 分别是端口 **B** 和 **F** 的绝对位置。
- *power\_dissipated* 是通过摩擦耗散的功率。

第一个方程中的负号反映了基于位置的机械平移域中使用的力流约定。除非端口已反转，否则 *f*friction 的正值表示模块处于压缩状态，*f*friction 的负值表示模块处于拉伸状态。有关详细信息，请参阅双端口模块方向和力流约定。

力方程的 Stribeck 部分中使用的指数函数是连续的，并且在速度幅值大于分离摩擦速度时会衰减。

力方程的库仑部分中使用的双曲正切函数确保方程在 *v* = 0 处平滑且连续，但在非零速度下会迅速达到其完整值。

连接 **B** 和 **F** 是基于位置的机械平移守恒端口。摩擦力从端口 **B** 作用到端口 **F**。正的摩擦力沿正方向驱动端口 **F**。您可以使用 **法向力** 参数或使用物理信号端口 **N** 来指定法向力。
