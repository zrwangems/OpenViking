### **Select input coordinate frame** — 输入坐标框架 `NED`（默认） | `Fixed-frame` | `ICRF`

选择输入坐标框架以相对于 north-east-down (NED)、fixed-frame (Fixed-frame) 或 International Celestial Reference Frame (ICRF) 定位航空航天飞行器。

如果模型包含关联的 Simulation 3D Scene Configuration 模块，Simulation 3D Custom Pack 模块将使用 Simulation 3D Scene Configuration 的坐标框架。在这种情况下，**Select input coordinate frame** 可能被禁用。有关 Simulation 3D Custom Pack 模块坐标框架的更多信息，请参阅 Algorithms。

## 版本历史

**在 R2023b 中引入**

### R2025a: Simulation 3D Custom Pack 模块现在与 Simulation 3D Scene Configuration 模块同步坐标框架

Simulation 3D Custom Pack 模块有以下更改：

- **Geospatial** 选项卡已重命名为 **Input** 选项卡。
- 在 **Input** 选项卡上，**Select input coordinate frame** 窗格现在包含以下坐标框架按钮：

  - **Fixed-frame** — Fixed-frame 坐标框架。选择此坐标框架时，注释 `Fixed-frame` 会出现在 pack 模块图标下方。
  - **ICRF** — International Celestial Reference Frame 坐标框架。选择此坐标框架时，注释 `ICRF` 会出现在 pack 模块图标下方。
  - **NED** — North-east-down 坐标框架。选择此坐标框架时，注释 `NED` 会出现在 pack 模块图标下方。

  如果模型包含 Simulation 3D pack 模块和关联的 Simulation 3D Scene Configuration 模块，Simulation 3D Custom Pack 的 **Input** 选项卡选项可能被禁用。在这种情况下，Simulation 3D Custom Pack 会与 Simulation 3D Scene Configuration 模块同步坐标系。
- 坐标系在模块下方显示为注释。
- **Enable geospatial correction** 和 **Direction of x-axis (degrees clockwise from north)** 参数已删除。

### R2024a: Simulation 3D Custom Pack 模块现在支持 Earth-centered Earth-fixed (ECEF) 输入坐标框架

为了为平移输入启用 ECEF 坐标系，Simulation 3D Custom Pack 模块已更新。将这些参数与 Simulation 3D Scene Configuration 模块中的 **Use Earth center as origin (ECEF)** 参数一起使用。

- **Select input coordinate frame**

  - **ECEF** — ECEF 输入坐标框架。选择此坐标框架时，注释 `Origin: Earth center (ECEF)` 会出现在 pack 模块图标下方。
  - **NED** — NED 坐标框架。在 R2024a 之前，NED 是唯一支持的坐标框架。
- **Direction of x-axis (degrees clockwise from north)** — *x* 轴方向。选中 **Enable geospatial correction** 复选框时，此参数启用。

## 描述

为自定义飞机生成平移和旋转信息

Simulation 3D Custom Pack 模块为 **Type** 设置为 `Custom` 的 Simulation 3D Aircraft 模块创建平移和旋转信息。使用 Simulation 3D Custom Pack 模块将平移和旋转信息提供给 Simulation 3D Aircraft 模块的 **Translation** 和 **Rotation** 输入端口。
