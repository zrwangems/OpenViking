# C2000 IQN to Float

将 IQ 数转换为浮点数

此模块将 IQ 输入转换为等效的浮点数。输出为单个浮点数。

**注意**

此模块的实现不会在代码生成期间调用相应的 Texas Instruments® 库函数。TI 函数使用全局 Q 设置，而此模块使用的 MathWorks® 代码会根据模块输入动态调整 Q 格式。有关详细信息，请参阅 Using the IQmath Library。
