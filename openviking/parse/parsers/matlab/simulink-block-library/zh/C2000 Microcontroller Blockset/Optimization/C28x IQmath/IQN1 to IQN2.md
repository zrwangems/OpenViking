# C2000 IQN1 to IQN2

将 IQ 数值转换为不同的 Q 格式

此模块将特定 Q 格式的 IQ 数值转换为不同的 Q 格式。

**注意**

在代码生成期间，此模块的实现不会调用对应的 Texas Instruments® 库函数。TI 函数使用全局 Q 设置，而此模块使用的 MathWorks® 代码会根据模块输入动态调整 Q 格式。有关详细信息，请参阅 Using the IQmath Library。
