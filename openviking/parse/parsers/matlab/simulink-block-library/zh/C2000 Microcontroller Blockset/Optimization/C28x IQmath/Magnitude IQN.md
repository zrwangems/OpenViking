# C2000 Magnitude IQN

两个正交 IQ 数的幅值

此模块使用以下公式计算两个 IQ 数的幅值

a2+b2

输出是与输入具有相同 Q 格式的 IQ 数。

**注意**

此模块的实现不会在代码生成期间调用相应的 Texas Instruments® 库函数。TI 函数使用全局 Q
设置，而此模块使用的 MathWorks® 代码会根据模块输入动态调整 Q 格式。有关更多信息，请参阅 Using the IQmath Library。
