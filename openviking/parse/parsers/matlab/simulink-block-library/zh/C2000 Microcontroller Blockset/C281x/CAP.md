## 参数

### 数据格式窗格

**模块**
:   选择要使用的事件管理器 (EV) 模块：

    - `A` — 使用 CAP 1、2 和 3。
    - `B` — 使用 CAP 4、5 和 6。

**输出溢出状态标志**
:   选择以输出 FIFO 中元素的状态。状态 flag 的数据类型为 uint16。

**输出数据格式**
:   要输出的数据类型：

    - `Send 2 elements (FIFO Buffer)` — 发送最新的两个值。当 FIFO 中有两个元素时更新输出，这由发送位 13 或 11 或 9 指示（CAP x FIFO）。如果在捕获的元素少于两个时轮询 CAP，则会重复旧值。CAP 寄存器的读取方式如下：

      1. 读取 CAP x FIFO 状态位，并将该值存储在状态 flag 中。
      2. 读取 FIFO 的顶部值，并将其存储在输出的索引 0 处。
      3. 读取 FIFO 的新顶部值（先前存储的底部堆栈值），并将其存储在输出的索引 1 处。

    - `Send 1 element (oldest)` — 发送两个最近值中较旧的值。当 FIFO 中至少有一个元素时更新输出，这由发送位 13:12、或 11:10、或 9:8 指示。CAP 寄存器的读取方式如下：

      1. 读取 CAP x FIFO 状态位，并将该值存储在状态 flag 中。
      2. 读取 FIFO 的顶部值，并将其存储在输出中。

    - `Send 1 element (latest)` — 发送最近的值。当 FIFO 中至少有一个元素时更新输出，这由发送位 13:12、或 11:10、或 9:8 指示。CAP 寄存器的读取方式如下：

      1. 读取 CAP x FIFO 状态位，并将该值存储在状态 flag 中。
      2. 如果 FIFO 缓冲区包含两个条目，则读取底部值并将其存储在输出中。如果 FIFO 缓冲区包含一个条目，则读取顶部值并将其存储在输出中。

**采样时间**
:   FIFO 输出之间的时间。如果没有新数据可用，则发送先前数据。

**数据类型**
:   输出数据的数据类型。可用选项为 `auto`、`double`、`single`、`int8`、`uint8`、`int16`、`uint16`、`int32`、`uint32` 和 `boolean`。`auto` 选项使用向此模块输出数据的已连接模块的数据类型。如果此模块不接收输入，则 `auto` 将数据类型设置为 `double`。

    **注意**

    C281x CAP 模块的输出可以向量化。

### CAP 窗格

CAP 窗格为各个 CAP 设置参数。受 CAP 窗格影响的特定 CAP 取决于您选择的 EV 模块：

- **CAP1** 对于 EV 模块 A 或 B，分别控制 CAP 1 或 CAP 4。
- **CAP2** 对于 EV 模块 A 或 B，分别控制 CAP 2 或 CAP 5。
- **CAP3** 对于 EV 模块 A 或 B，分别控制 CAP 3 或 CAP 6。

**使能 CAP**
:   选择以使用指定的捕获单元引脚。

**边沿检测**
:   要用于此 CAP 的跳变检测类型。可用类型为 `Rising Edge`、`Falling Edge`、`Both Edges` 和 `No transition`。

**时基**
:   选择 CAP 用作时基的目标板 GP 定时器。CAP 1、2 和 3 可以使用 `Timer 1` 或 `Timer 2`。CAP 4、5 和 6 可以使用 `Timer 3` 或 `Timer 4`。

**时钟源**
:   此选项仅适用于 CAP 3 窗格。您可以选择 `Internal` 以使用内部时基。还需为内部时基配置 **计数模式**、**定时器预分频器** 和 **定时器周期源**。

    选择 `QEP circuit` 以从正交编码器脉冲 (QEP) 子模块生成输入时钟。

**计数模式**
:   选择 `Up` 以生成非对称波形输出，或选择 `Up-down` 以生成对称波形输出，如下图所示。

    计数模式用于内部定时器设置。

    当您将 **计数模式** 指定为 `Up`（非对称）时，波形：

    - 从低电平开始
    - 当上升周期计数器值与 **比较值** 匹配时变为高电平
    - 在周期结束时变为低电平

    当您将 **计数模式** 指定为 `Up-down`（对称）时，波形：

    - 从低电平开始
    - 当递增周期计数器值与 **比较值** 匹配时变为高电平
    - 当递减周期计数器值与 **比较值** 匹配时变为低电平

    当您将 **时钟源** 设置为 `QEP circuit` 时，**计数模式** 变为不可用。

**定时器预分频器**
:   用于对所选 GP 定时器进行预分频以产生所需定时器计数速率的时钟分频因子。可用选项为 `none`、`1/2`、`1/4`、`1/8`、`1/16`、`1/32`、`1/64` 和 `1/128`。下表显示了选择每个选项所得到的速率。

    | 缩放 | 生成速率 (µs) |
    | --- | --- |
    | none | 0.01334 |
    | 1/2 | 0.02668 |
    | 1/4 | 0.05336 |
    | 1/8 | 0.10672 |
    | 1/16 | 0.21344 |
    | 1/32 | 0.42688 |
    | 1/64 | 0.85376 |
    | 1/128 | 1.70752 |

    **注意**

    这些速率假设输入时钟为 75 MHz。

**定时器周期源**
:   选择 `Specify via dialog` 以启用 **定时器周期** 参数。选择 `Input port` 以创建模块输入 **T1**，其接受定时器周期值。

**定时器周期**
:   以时钟周期为单位设置定时器周期的长度。输入 `0` 到 `65535` 之间的值。该值默认为 `65535`。

    如果您知道一个时钟周期的长度，就可以轻松计算出要为定时器周期设置多少个时钟周期。以下计算确定一个时钟周期的长度：

    Sysclk(150MHz)→HISPCLK(1/2)→InputClockPrescaler(1/128)

    在此计算中，将 150 MHz 的系统时钟频率除以高速时钟预分频器 2。然后，将结果值除以定时器控制输入时钟预分频器 128。所得频率为 0.586 MHz。因此，一个时钟周期为 1/.586 MHz，即 1.706 µs。

**在 CAP 上发布中断**
:   选中此复选框以在 CAP 上发布异步中断。

# C281x CAP

接收并记录捕获输入引脚跳变

C281x CAP 模块为外部事件精确定时非常重要的系统提供输入捕获功能。C281x CAP 模块为事件管理器 (EV) 模块的捕获单元 (CAP) 设置参数。捕获单元通过将输入信号跳变的时间记录到两级深 FIFO 堆栈中，来记录在捕获单元引脚上检测到的跳变。您可以将捕获单元引脚设置为检测上升沿、下降沿、任一类型跳变或不跳变。该模块的 cnt 输出给出 EV 运行定时器的捕获值。

C281x 芯片有六个捕获单元——每个 EV 模块关联三个。捕获单元 1、2 和 3 与 EVA 关联，捕获单元 4、5 和 6 与 EVB 关联。每个捕获单元与一个捕获输入引脚关联。

每组 EV 模块捕获单元可以使用目标板上的两个通用 (GP) 定时器之一。EVA 捕获单元可以使用 GP 定时器 1 或 2。EVB 捕获单元可以使用 GP 定时器 3 或 4。当发生跳变时，该模块将所选定时器的值存储在两级深 FIFO 堆栈中。

C281x CAP 模块与其他 C281 模块共享 GP 定时器。有关共享定时器的更多信息和指导，请参阅在 C281x 外设之间共享通用定时器。

**注意**

一个模型中最多可以有两个 C281x CAP 模块——每个 EV 模块一个模块。

### 输出

该模块最多有两个输出：一个 `cnt` (count) 输出和一个可选的 FIFO 状态 `flag` 输出。`cnt` 输出保存检测到的跳变期间捕获的 EV 定时器值。`cnt` 输出根据 **输出数据格式** 参数中设置的值给出运行计数器的捕获值。状态 flag 输出为：

- `0` — FIFO 为空。要么尚未发生捕获，要么先前存储的捕获已从堆栈读出。（此 flag 的二进制版本为 `00`。）
- `1` — FIFO 在堆栈顶部寄存器中有一个条目。（此 flag 的二进制版本为 `01`。）
- `2` — FIFO 在堆栈寄存器中有两个条目。（此 flag 的二进制版本为 `10`。）
- `3` — FIFO 在堆栈寄存器中有两个条目，并且一个或多个捕获值已丢失。发生这种情况是因为在读取 FIFO 堆栈之前发生了另一次捕获。这意味着当您按照调度方案执行该模块时读取 FIFO 堆栈：如果使用采样时间，则同步读取；如果由中断或空闲任务触发，则异步读取。新值被放入底部寄存器。底部寄存器值被推入堆栈顶部，顶部值被推出堆栈。（此 flag 的二进制版本为 `11`。）
