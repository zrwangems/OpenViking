# BME280

## 端口
```yaml
ports:
- name: Pressure
  summary: BME280 传感器测量的气压 标量
  direction: output
  data_types: double
- name: Temperature
  summary: BME280 传感器测量的温度 标量
  direction: output
  data_types: double
- name: Humidity
  summary: BME280 传感器测量的相对湿度 标量
  direction: output
  data_types: double
- name: Status
  summary: 读取值的状态 0 | 1
  direction: output
  data_types: uint8
```

### 输出

### **Pressure** — BME280 传感器测量的气压 标量

由连接到 C2000 板的 BME280 传感器测量的气压（单位为帕斯卡 (Pa)）。

#### 依赖关系

仅当您选择 **Pressure (Pa)** 参数时，此输出端口才会出现。

**数据类型：** `double`

### **Temperature** — BME280 传感器测量的温度 标量

由连接到 C2000 板的 BME280 传感器测量的温度（单位为 ℃）。

#### 依赖关系

仅当您选择 **Temperature (℃)** 参数时，此输出端口才会出现。

**数据类型：** `double`

### **Humidity** — BME280 传感器测量的相对湿度 标量

由连接到 C2000 板的 BME280 传感器测量的相对湿度（单位为 %）。

#### 依赖关系

仅当您选择 **Humidity (%)** 参数时，此输出端口才会出现。

**数据类型：** `double`

### **Status** — 读取值的状态 `0` | `1`

从 BME280 传感器读取的值的状态，用于指示读取的数据是否为新值。**Status** 值为 `0` 表示读取的数据是新值，`1` 表示读取的数据不是新值。

#### 依赖关系

仅当您选择 **Status** 参数时，此输出端口才会出现。

**数据类型：** `uint8`

### **I2C module** — 用于通信的模块 `I2C_A`（默认值）

用于与 BME280 传感器通信的 I2C 模块。不同 C2000 处理器支持的 I2C 模块数量各不相同。您可以通过打开配置参数对话框并查看 **Target hardware resources** 下的 I2C 特定选项卡，找到与处理器（您在 Simulink 模型的 Hardware Board 参数中选择的处理器）对应的受支持 I2C 模块。

### **I2C address** — BME280 传感器的 I2C 地址 `0x77`（默认值） | `0x76`

BME280 传感器与 C2000 处理器通信时使用的 I2C 地址。默认参数值 (`0x77`) 对应于 BOOSTXL-SENSORS BoosterPackTM Plug-in Module User's Guide 的 `Schematics` 部分中提到的值。

### **Pressure (Pa)** — 设置用于读取气压的输出端口 `on`（默认值） | `off`

选择此参数可将 **Pressure** 设置为输出端口之一。

### **Temperature (℃)** — 设置用于读取温度的输出端口 `on`（默认值） | `off`

选择此参数可将 **Temperature** 设置为输出端口之一。

### **Humidity (%)** — 设置用于读取湿度的输出端口 `on`（默认值） | `off`

选择此参数可将 **Humidity** 设置为输出端口之一。

### **Status** — 设置用于获取读取值状态的输出端口 `off`（默认值） | `on`

选择此参数可将 **Status** 设置为输出端口之一。

### **Filter coefficient** — IIR 滤波器的滤波器系数 `0`（默认值） | `2` | `4` | `8` | `16`

指定从 BME280 传感器读取气压和温度值时 IIR 滤波器的滤波器系数。为滤波器系数选择非零值有助于改善阶跃响应并消除测量值中的短期波动。

### **Stand by time** — 读取值的待机时间 `0.5`（默认值） | `10` | `20` | `62.5` | `125` | `250` | `500` | `1000`

指定从 BME280 传感器读取值时处理器保持空闲（非活动持续时间）的待机时间（单位为 ms）。此值的选择会影响总循环时间。

### **Pressure oversampling factor** — 测量气压值的过采样因子 `1`（默认值） | `2` | `4` | `8` | `16`

指定过采样因子以减少从 BME280 传感器读取的气压值的噪声。此值是一个乘法因子，会影响测量速率和电流消耗。

### **Humidity oversampling factor** — 测量湿度值的过采样因子 `1`（默认值） | `2` | `4` | `8` | `16`

指定过采样因子以减少从 BME280 传感器读取的湿度值的噪声。此值是一个乘法因子，会影响测量速率和电流消耗。

### **Temperature oversampling factor** — 测量湿度值的过采样因子 `1`（默认值） | `2` | `4` | `8` | `16`

指定过采样因子以减少从 BME280 传感器读取的温度值的噪声。此值是一个乘法因子，会影响测量速率和电流消耗。

### **Data type** — BME280 传感器值的输出数据类型 `single`（默认值） | `double`

指定从 BME280 传感器读取的值的输出数据类型。TI 的 C2000™ 处理器的默认数据类型为 `single`。如有需要，可使用此参数将值更改为 `double`。

### **Sample time** — 读取数据的时间间隔 `-1`（默认值） | 正整数

指定此模块从 BME280 传感器读取数据的频率。当您将此参数设置为 -1 时，Simulink 会根据模型中的模块上下文确定该模块的最佳采样时间。

## 描述

从 BME280 传感器测量气压、相对湿度和温度

BME280 模块输出由连接到 C2000 板的 BME280 传感器测量的气压和相对湿度值。该模块还输出 BME280 传感器读取的温度。
