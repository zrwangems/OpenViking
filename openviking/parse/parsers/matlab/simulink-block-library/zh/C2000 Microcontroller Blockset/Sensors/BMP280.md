# BMP280 Pressure Sensor

## 端口
```yaml
ports:
- name: Pressure
  summary: 大气压强标量
  direction: output
  data_types: double
- name: Temperature
  summary: 环境温度标量
  direction: output
  data_types: double
- name: Status
  summary: 压强和温度读取值的状态 0 | 1
  direction: output
  data_types: uint8
```

### 输出

### **Pressure** — 大气压强标量

该模块输出大气压强，单位为帕斯卡 (Pa)。

#### 依赖关系

此输出端口仅在您选择 **Pressure (Pa)** 参数时出现。

**数据类型：** `double`

### **Temperature** — 环境温度标量

该模块输出环境温度，单位为 ℃。

#### 依赖关系

此输出端口仅在您选择 **Temperature (℃)** 参数时出现。

**数据类型：** `double`

### **Status** — 压强和温度读取值的状态 `0` | `1`

该模块输出大气压强和环境温度测量的状态。`0` 表示读取的数据是新数据，`1` 表示读取的数据不是新数据。

#### 依赖关系

此输出端口仅在您选择 **Status** 参数时出现。

**数据类型：** `uint8`

### **I2C Module** — 用于 I2C 通信的特定模块 `I2C_A`（默认值）

指定您所使用板上用于 I2C 通信的模块。

### **I2C address** — 与 BMP280 传感器通信的 I2C 地址 `0x76`（默认值） | `0x77`

与 BMP280 传感器上的外设进行通信的 I2C 地址由硬件板上 SDO 引脚的状态决定。此表提供了与引脚及其状态对应的 I2C 地址。

| 引脚名称 | 引脚状态 | I2C 地址 |
| --- | --- | --- |
| SDO | 0 | 0x76 |
| 1 | 0x77 |

### **Pressure (Pa)** — 设置用于读取压强的输出端口 `on`（默认值） | `off`

选择此参数可将 **Pressure** 设置为输出端口之一。

### **Temperature (℃)** — 设置用于读取温度的输出端口 `on`（默认值） | `off`

选择此参数可将 **Temperature** 设置为输出端口之一。

### **Status** — 设置用于获取所选输出状态的输出端口 `on`（默认值） | `off`

选择此参数可将 **Status** 设置为输出端口之一。

### **Data type** — BMP280 传感器值的输出数据类型 `single`（默认值） | `double` | `uint32`

选择模块从中读取值的传感器数据类型。

指定从 BMP280 传感器读取的值的输出数据类型。C2000 硬件的默认数据类型为 `single`。如有需要，可使用此参数将值更改为 `double` 或 `uint32`。

### **Sample time** — 读取数据的时间间隔 `-1`（默认值） | 正整数

指定此模块从 BMP280 传感器读取数据的频率。当您将此参数设置为 -1 时，Simulink 会根据模型中的模块上下文确定该模块的最佳采样时间。

### IIR filter settings

### **Filter coeffiecient** — 滤波器系数值 `0`（默认值） | `2` | `4` | `8` | `16`

选择传感器的滤波器系数值，这有助于降低输出信号的带宽。

C2000 硬件的默认滤波器系数值为 `0`。如有需要，可使用此参数更改该值。

### Sensitivity

### **Pressure sensitivity factor (Pa)** — 压强灵敏度因子 `2.62`（默认值） | `1.31` | `0.66` | `0.33` | `0.16`

选择压强灵敏度因子，传感器在气压变化时使用该因子读取值。

C2000 硬件的默认数据类型为 `2.62`。如有需要，可使用此参数更改该值。

当滤波器启用时，传感器使用此公式获取最新的测量计算结果。

`dt = (dadc / f) +
dt-1 (1 - 1 / f)`，其中 `dt` 是当前数据，`dt-1` 是先前数据，`dadc` 是预滤波数据，`f` 是滤波器系数。

### **Temperature sensitivity factor (℃)** — 温度灵敏度因子 `0.005`（默认值） | `0.0025`

选择温度灵敏度因子，传感器在温度变化条件下使用该因子读取值。

C2000 硬件的默认数据类型为 `0.005`。如有需要，可使用此参数更改该值。

## 描述

从 BMP280 传感器测量大气压强和环境温度

BMP280 Pressure Sensor 模块使用与 C2000 板接口连接的 BMP280 压强传感器测量大气压强和环境温度。
