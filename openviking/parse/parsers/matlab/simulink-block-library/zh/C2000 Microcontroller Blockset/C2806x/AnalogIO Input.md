## 参数

**参数（输入引脚）**
:   选择要采样的输入引脚。

**采样时间**
:   指定采样之间的时间间隔。要从上游模块继承采样时间，请将此参数设置为 -1。

**数据类型**
:   选择数字输出数据的数据类型。如果选择
    `auto`，该模块会自动为您的模型选择
    数据类型。您也可以手动选择数据类型。您
    可以从以下选项中选择：`double`、
    `single`、`int8`、
    `uint8`、`int16`、
    `uint16`、`int32`
