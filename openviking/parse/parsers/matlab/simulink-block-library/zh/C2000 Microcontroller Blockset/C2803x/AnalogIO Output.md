# C2802x/C2803x/C2806x/F28M3x AnalogIO Output

配置模拟 I/O，使其在特定引脚上输出模拟信号。

使用此模块驱动模拟 I/O 引脚的输出电压。

在常规模式下，当模块输入端的值为 True 时，模拟 IO 引脚会拉高；当值为 False 时，该引脚会接地。

在切换模式下，当模块输入端的值为 True 时，会切换模拟 IO 引脚的实际输出电平；而当值为 False 时，则不会改变模拟 IO 引脚的输出电平。

- C2802x/C2803x/C2806x/F28M3x AnalogIO Output block
