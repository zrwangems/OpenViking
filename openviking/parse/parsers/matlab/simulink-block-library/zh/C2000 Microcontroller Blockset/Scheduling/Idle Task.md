# Idle Task

## 端口

### 输入

### **Port\_1** — 仅仿真端口标量

将一个或多个仿真中断源连接到仿真输入。

#### 依赖关系

当 **启用仿真端口** 参数启用时，此端口才会出现。

**数据类型：** `SoCData`
### 输出

### **data** — Idle Task 数据向量

Idle Task 的输出是 uint16 值的向量。

**数据类型：** `single` | `double` | `int8` | `int16` | `int32` | `int64` | `uint8` | `uint16` | `uint32` | `uint64` | `Boolean` | `bus`

## 参数

### **任务编号** — 按编号标识创建的任务 `double`（默认）| `single` | `int8` | `int16` | `int32` | `int64` | `int64` | `uint8` | `uint16` | `uint32` | `uint64` | `uint64` | `Boolean` | `bus`

按编号标识创建的任务。通过输入整数向量，可以输入所需数量的任务。默认值为 [1,2]，表示下游子系统有两个函数。

您输入的值决定下游子系统中函数的执行顺序，而输入值的数量对应于下游子系统中函数的数量。

输入一个向量，其元素数量与下游子系统中函数的数量相同。此向量最多可包含 16 个元素，且值必须为 0 到 15（含 0 和 15）。

向量中第一个元素的值决定子系统中第一个函数的执行顺序，第二个元素的值决定子系统中第二个函数的执行顺序，依此类推。

例如，在此字段中输入 [2,3,1] 表示有三个要执行的函数，并且第三个函数最先执行，第一个函数第二个执行，第二个函数第三个执行。函数执行完后，Idle Task 模块会循环回来，并按相同顺序重复执行这些函数。

### **抢占标志** — 存储缓冲区数量 `1`（默认）| 正整数

较高优先级中断可以抢占优先级较低的中断。为了允许您控制抢占，请使用抢占标志指定中断是否可以被抢占。

输入 `1` 表示该中断可以被抢占。输入 `0` 表示该中断不能被抢占。当 **任务编号** 包含多个任务时，您可以通过输入标志值向量为每个任务分配不同的抢占标志，这些标志值对应于 **任务编号** 中任务的顺序。如果 **任务编号** 包含多个任务，而您在此处只输入一个标志值，则该状态适用于这些任务。

在默认设置 `[0 1]` 中，**任务编号** 中优先级为 `1` 的任务不可被抢占，而优先级为 `2` 的任务可以被抢占。

### **启用仿真端口** — 为模块启用外设仿真端口 `off`（默认）| `on`

选择此选项时，Simulink 软件会向 Idle Task 模块添加一个输入端口。此端口仅用于仿真。将一个或多个仿真中断源连接到仿真输入。

**注意**

选中此复选框以在 Simulink 软件中测试异步中断处理行为。

## 描述

创建自由运行任务

Idle Task 模块以及连接到它的子系统指定一个或多个要作为后台任务执行的函数。通过 Idle Task 模块执行的任务具有最低优先级，低于基础速率任务的优先级。

### 向量化输出

模块输出包含一组向量——任务编号向量和抢占标志向量（一个或多个）。除非抢占标志向量只有一个元素，否则抢占标志向量必须与任务数量向量长度相同。抢占标志的值决定给定中断（和任务）是否可抢占。抢占会覆盖优先级排序。较低优先级的不可抢占任务可以抢占较高优先级的可抢占任务。

当抢占标志向量只有一个元素时，该元素值适用于下游子系统中的函数，这些函数由任务编号向量中的任务编号定义。如果抢占标志向量与任务编号向量具有相同数量的元素，则任务编号向量中定义的每个任务都具有一个抢占状态，该状态由抢占标志向量中对应元素的值定义。
