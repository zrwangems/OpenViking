# TCP Receive

## 端口

### 输出

### **Data** — 输出数据向量

在每个时间步，该端口输出一个数据向量，其大小由 **Data size (N)** 参数指定。有关详细信息，请参阅 Receive TCP Data。

**数据类型：** `int8` | `uint8` | `int16` | `uint16` | `int32` | `uint32` | `single` | `double` | `Boolean`

### **Status** — 在给定时间步是否接收到请求的数据 `0` | `1`

在每个时间步，当接收到的数据长度大于或等于 **Data size (N)** 参数中指定的长度时，该端口输出 `0`。否则，输出 `1`，表示未接收到新数据。

有关详细信息，请参阅 Receive TCP Data。

**数据类型：** `uint16`

## 参数

#### 主

### **Connection mode** — 将模块设置为服务器或客户端 `Server`（默认）| `Client`

将模块设置为 TCP/IP 服务器或客户端。

当您将此参数设置为 `Server` 时，必须提供 **Local IP Port**。本地端口用作 TCP/IP 服务器的监听端口。

当您将此参数设置为 `Client` 时，必须提供要从中接收数据的 TCP/IP 服务器的 **Remote IP Address** 和 **Remote IP Port**。

### **Local IP Port** — 接收主机的 IP 端口，数据从该端口接收 `25001`（默认）| [1 到 65,535]

此本地端口号用作接收主机的监听端口。将本地端口号与发送主机的远程端口号匹配。

### **Remote IP Address** — 要从中接收数据的服务器的远程 IP 地址 `192.168.1.2`（默认）| 任何有效的 IP 地址

指定要从中接收数据的服务器的 IP 地址。

#### 依赖关系

此参数仅在将 **Connection mode** 参数设置为 `Client` 时显示。

### **Remote IP Port** — 要从中接收数据的服务器的远程 IP 端口 `25000`（默认）| [1 到 65,535]

指定要从中接收数据的服务器的端口号。

#### 依赖关系

此参数仅在将 **Connection mode** 设置为 `Client` 时显示。

### **Data type** — 接收数据的数据类型 `uint8`（默认）| `double` | `single` | `int8` | `int16` | `uint16` | `int32` | `uint32` | `boolean`

指定模块从发送主机接收的数据的类型。每个元素的大小取决于其数据类型。

### **Data size (N)** — 接收数据中的字节数 `1`（默认）| 任何正整数

每个时间步要接收的字节数。

### **Sample time** — 模块从发送主机读取数据的时间间隔 `0.1`（默认）| 任何非负值

当您将此参数设置为 `-1` 时，Simulink® 会根据模型中的模块上下文确定该模块的最佳采样时间。

#### 高级

### **Wait until data received** — 等待直到请求的数据可用 on（默认）| off

- 当您选择此选项时，读取操作以阻塞模式运行。在等待请求的数据可用期间，读取操作被阻塞。读取时，如果数据不可用，模块会等待 **Timeout in seconds** 参数中指定的时间。有关阻塞模式下输出端口值的详细信息，请参阅 Receive TCP Data。

  如果当下一次读取操作计划开始时，目标硬件仍在等待数据可用，则会发生任务超限。

  要修复超限：

  - 使用 **Sample time** 参数增加时间步。
  - 使用 **Data size (N)** 参数减少请求的数据长度。
- 当您清除此选项时，读取操作以非阻塞模式运行。在此模式下，模块不会等待请求的数据可用。有关非阻塞模式下输出端口值的详细信息，请参阅 Receive TCP Data。

### **Timeout in seconds** — 等待接收数据的时间 `0.1`（默认）| `Inf` | 任何非负值

指定模块在每个时间步等待数据可用的时间量。如果发生超时，读取操作将被中止。

#### 依赖关系

此参数仅在您选择 **Wait until data received** 参数时可用。

### Receive TCP Data

本节说明在阻塞和非阻塞模式下输出端口的值，其中以下模块参数指定为：

| 模块参数 | 值 |
| --- | --- |
| **数据类型** | `uint8` |
| **Data size (N)** | `4` |

输出端口的值因接收到的数据长度小于、大于或等于请求的数据长度而有所不同。

- 接收到的数据长度 = Data size (N)：**Data** 端口输出一个数据向量，其大小由 **Data size (N)** 参数指定。**Status** 端口输出 `0`，表示已接收到请求的数据。

  假设接收到的数据长度为 4。在这种情况下，**Data** 端口输出一个大小为 4 的数据向量，其中填充了接收到的数据字节。**Status** 端口输出 `0`。
- 接收到的数据长度 < Data size (N)：在阻塞模式下，模块会等待数据可用，最长等待 **Timeout in seconds** 秒。如果数据在 **Timeout in seconds** 秒内变为可用，**Data** 端口输出一个数据向量，其大小由 **Data size (N)** 参数指定。**Status** 端口输出 `0`，表示已接收到新数据。如果等待时间超过 **Timeout in seconds**，**Data** 端口输出一个数据向量，其大小由 **Data size (N)** 参数指定，并填充零。**Status** 端口输出 `1`，表示未接收到新数据。

  在非阻塞模式下，模块不会等待请求的数据可用。**Data** 端口输出一个数据向量，其大小由 **Data size (N)** 参数指定，并填充零。**Status** 端口输出 `1`，表示未接收到新数据。
- 接收到的数据长度 > Data size (N)：**Data** 端口输出一个数据向量，其大小由 **Data size (N)** 参数指定。该向量仅包含数据中的前 *N* 个字节。其余字节将在下一个时间步与数据字节一起发出。**Status** 端口输出 `0`，表示已接收到请求的数据。

  假设接收到的数据长度为 5 字节。在这种情况下，**Data** 端口输出一个大小为 4 的数据向量。该向量仅包含接收数据中的前 4 个字节。第五个字节将在下一个时间步与数据字节一起发出。**Status** 端口输出 `0`。

## 描述

通过 TCP/IP 网络从远程主机接收数据

TCP Receive 模块通过有线网络从远程主机或其他目标硬件接收数据。当您将 **Connection mode** 设置为 `Server` 时，必须提供 **Local IP Port**。**Local IP Port** 用作 TCP/IP 服务器的监听端口。当您将 **Connection mode** 设置为 `Client` 时，必须提供要从中接收数据的服务器的 **Remote IP Address** 和 **remote IP Port**。

该模块有两个输出端口：**Data** 和 **Status**。在每个采样时间，**Data** 端口输出一个数据向量，其大小由 **Data size (N)** 参数指定。

当接收到的数据长度大于或等于 **Data size (N)** 参数中指定的长度时，**Status** 端口输出 `0`。否则，输出 `1`，表示没有新数据可用。

在没有硬件的仿真期间，该模块输出零。

**注意**

在某些情况下，防病毒软件或防火墙可能会阻止 TCP 流量。如果是这样，请配置防病毒软件或防火墙以允许特定 IP 端口号的流量。

该模块以阻塞模式或非阻塞模式接收数据。

在阻塞模式下，模型在等待请求的数据可用时阻塞执行。

阻塞模式

在时间步 1，模块请求四个数据值，TCP/IP 接收缓冲区获得四个数据值。执行继续运行。

在时间步 2，模块再次请求数据，但 TCP/IP 接收缓冲区仅获得三个数据值。执行暂停，直到缓冲区接收到第四个数据值或超时值过去。然后，执行恢复。

在时间步 3，模块请求数据，缓冲区接收到五个数据值。模块返回前四个数据值，其余数据值将在下一个接收周期中使用。

在非阻塞模式下，模型连续运行。

非阻塞模式

在时间步 1，模块请求数据，缓冲区获得四个数据值。模块将 **Status** 端口值更改为 0，表示新的请求数据可用。此时 **Data** 端口包含新接收的数据值。模块将 **Data** 端口值重置为 0。

在时间步 2，模块再次请求数据，但缓冲区仅获得三个值。由于数据大小指定为 4，模块无法返回值为 3 的结果。因此，模块将 **Status** 端口值设置为 1，表示没有新数据。**Data** 端口上的所有值变为 0。此时缓冲区有三个数据值。但是，在此阶段，与阻塞模式不同，执行不会停止。

在时间步 3，缓冲区有五个数据值，模块按接收顺序返回前四个数据值，并将 **Status** 端口值更改为 0。其余数据值将在下一个接收周期中使用。
