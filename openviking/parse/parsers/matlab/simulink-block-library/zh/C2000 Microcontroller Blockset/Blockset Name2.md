# C2000 Microcontroller Blockset

了解 C2000 Microcontroller Blockset 的基础知识

为 Texas Instruments C2000 微控制器设计、仿真和实现应用

C2000™ Microcontroller Blockset 使您能够为 TI C2000 微控制器（MCU）建模数字电源转换和电机控制应用。该模块集包含外设模块，例如 digital IO、ADC 和 ePWM，用于在使用 C2000 MCU 的工业和汽车应用中执行需要 ADC-PWM 同步的控制算法仿真。

该模块集使您能够通过处理器间数据通信（IPC）和协处理器（Control Law Accelerator）模块对算法进行多核执行分区。您可以将 Simulink® 模型直接连接到支持的硬件，以实现实时 I/O 数据交换以进行快速原型开发。

您可以为 C2000 MCU 生成优化代码，使用 IQ Math 和相关优化例程进行实时和中断驱动的代码执行，并执行实时信号监控、参数调优和处理器在环（PIL）测试（使用 Embedded Coder®）。该模块集包含参考示例，帮助您在 C2000 MCU 上构建和部署电机控制应用（使用 Motor Control Blockset™ 和 Embedded Coder）。

C2000TM 是 Texas Instruments® 的商标。
