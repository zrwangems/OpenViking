# Digital Output

## 端口

### 输入

### **Digital Data** — 要写入输出通道向量的数字数据

输入值的数据类型和范围取决于板卡的能力。

**数据类型：** `single` | `double` | `int8` | `uint8` | `int16` | `uint16` | `int32` | `uint32`
### 输出

### **Missed Ticks** — 丢失的滴答计数（可选）double

在 **Connected IO** 模式下，返回模型落后于实时内核的定时器滴答数。当模型落后超过 **最大丢失滴答数** 时，软件会报告错误并停止仿真。

#### 依赖关系

当您选择 **显示“Missed Ticks”端口** 时，此端口可见。

**数据类型：** `double`

## 参数

### **安装新板卡** — 注册板卡 `< no board selected >` (默认)

当您点击 **安装新板卡** 时，软件会显示支持的板卡制造商列表。当您选择制造商时，软件会显示该制造商提供的板卡列表。当您选择板卡时，软件会将板卡添加到已注册板卡列表，并将该板卡设为当前板卡。

默认情况下，已注册板卡列表中的初始选择为 `< no board selected >`。

有关 I/O 板卡的驱动程序支持的详细信息，请参阅 Hardware Support from Simulink Desktop Real-Time。

#### 依赖关系

当您在已注册板卡列表中选择一个板卡时，**删除当前板卡** 和 **板卡设置** 按钮可用。

### **采样时间** — 模块的采样时间 `0.1` (默认) | double

输入一个值，以 seconds 为单位，表示您希望模块执行并与 I/O 硬件交互的频率。模块会以此采样率将模型与实时时钟同步。

如果您使用的是固定步长求解器，请输入您在 **固定步长** 配置参数中输入的值，或该值的整数倍。

#### 编程使用

|  |
| --- |
| **模块参数：** `SampleTime` |

### **最大丢失滴答数** — 模型可以落后内核的定时器滴答数 `10` (默认) | integer

在 **Connected IO** 模式下，输入模型可以落后实时内核的定时器滴答数。当模型落后此数量或更少的定时器滴答时，软件假定该滞后是暂时的。它允许模型追赶，即使模型丢失了一些滴答。当模型落后超过此数量时，软件会报告错误并停止仿真。

在 **Run in Kernel** 模式下，软件忽略此值。

#### 编程使用

|  |
| --- |
| **模块参数：** `MaxMissedTicks` |

### **显示“Missed Ticks”端口** — 将丢失的滴答数发送到端口 `Missed Ticks` `'off'` (默认) | `'on'`

在 **Connected IO** 模式下，选中此复选框以将丢失的滴答数发送到输出端口 `Missed Ticks`。

在 **Run in Kernel** 模式下，`Missed Ticks` 端口为零。

#### 编程使用

|  |
| --- |
| **模块参数：** `ShowMissedTicks` |

### **等待时让出 CPU** — 内核等待硬件时让出 CPU `'off'` (默认) | `'on'`

在 **Connected IO** 模式下，选中此复选框以在内核等待硬件响应时授予其他程序更多 CPU 时间。

在 **Run in Kernel** 模式下，软件忽略此值。

#### 编程使用

|  |
| --- |
| **模块参数：** `YieldWhenWaiting` |

### **输出通道** — 选择数字输出通道向量

输入一个通道向量，用于选择您在此板卡上使用的数字输出通道。该向量可以是任何有效的 MATLAB® 向量形式。例如，要选择前八个数字输出通道，请输入：

```
[1,2,3,4,5,6,7,8]
```

或

```
[1:8]
```

如果您想使用前四个数字输出线，请输入：

```
[1,2,3,4]
```

如果您有一个 8 位数字通道，请输入 `[1]`。如果您有两个 8 位数字通道，请输入 `[1 9]`，然后从 **通道模式** 列表中选择 `Byte`。

#### 编程使用

|  |
| --- |
| **模块参数：** `Channels` |

### **通道模式** — 表示输出线的模式 `Bit` (默认) | `Byte`

从列表中选择以下之一：

- `Bit` — 期望值为 `0` 或 `1`。
- `Byte` — 期望值为 `0–255`，该值会转换为一个由八条数字线组成的数字通道。

#### 编程使用

|  |
| --- |
| **模块参数：** `BitMode` |

### **初始值** — 输出通道向量的初始值

为每个数字输出线或通道输入初始值，这些线或通道是您在 **输出通道** 参数中输入的。例如，如果您输入了 `[1,2,3,4]`，并且您希望初始值为 `0` 和 `1`，请输入：

```
[0,0,1,1]
```

如果您从 **通道模式** 列表中选择 `Byte`，请为每个数字输出通道输入一个 `0` 到 `255` 之间的值。例如，对于 1 字节（八条数字线），初始值为 `25`，请输入 `[25]`。对于 2 字节（16 条数字线），初始值为 `25` 和 `50`，请输入 `[25 50]`。

#### 编程使用

|  |
| --- |
| **模块参数：** `InitialValue` |

### **最终值** — 输出通道向量的最终值

为每个数字输出通道输入最终值，这些通道是您在 **输出通道** 参数中输入的。例如，如果您输入了 `[1,2,3,4]`，并且您希望最终值为 `0`，请输入：

```
[0,0,0,0]
```

如果您从 **通道模式** 列表中选择 `Byte`，请为每个数字输出通道输入一个 `0` 到 `255` 之间的值。

#### 编程使用

|  |
| --- |
| **模块参数：** `FinalValue` |

## 描述

写入一个或多个数字输出通道

Digital Output 模块从您的 Simulink® 模型连接并写入特定的数字线或通道。在将 Digital Output 模块添加到模型后，您可以输入其 I/O 驱动程序的参数。
