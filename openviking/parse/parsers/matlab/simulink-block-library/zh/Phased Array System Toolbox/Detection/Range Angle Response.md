# Range Angle Response

## 端口

### 输入

### **X** — 输入信号数据立方体 复数值 *K*-by-*N* 矩阵 | 复数值 *K*-by-*N*-by-*L* 数组

输入信号立方体，指定为复数值 *K*-by-*N* 矩阵或复数值 *K*-by-*N*-by-*L* 数组。数据立方体的内容取决于不同语法指定的距离-角度处理类型。

- *K* 是快时间或距离样本数。
- *N* 是独立空间通道数，例如传感器或方向。
- *L* 是慢时间维度，对应于输入信号中的脉冲或扫频数。

输入矩阵第一个维度的大小可以变化，以仿真变化的信号长度。例如，在具有可变脉冲重复频率的脉冲波形情况下，可能会发生大小变化。

### **PRF** — 脉冲重复频率 正标量

脉冲重复频率

#### 依赖关系

要启用此输入参量，请将 **距离处理方法** 的值设置为 `FFT`，并不要选中 **对输入信号去斜** 复选框。

**数据类型：** `double`

### **Xref** — 用于去斜的参考信号 复数值 *K*-by-1 列向量

用于去斜的参考信号，指定为复数值 *K*-by-1 列向量。行数必须等于 `X` 快时间维度的长度。

#### 依赖关系

要启用此输入参量，请将 **距离处理方法** 的值设置为 `FFT`，并选中 **对输入信号去斜** 复选框。

**数据类型：** `double`
**复数支持：** Yes

### **Coeff** — 匹配滤波器系数 复数值 *P*-by-1 列向量

匹配滤波器系数，指定为复数值 *P*-by-1 列向量。*P* 必须小于或等于 *K*。*K* 是快时间或距离样本数。

#### 依赖关系

要启用此输入参量，请将 **距离处理方法** 的值设置为 `Matched filter`。

**数据类型：** `double`
**复数支持：** Yes

### **El** — 俯仰角 标量

响应的俯仰角，指定为 –90° 到 +90° 之间的标量。针对此俯仰角计算距离-角度响应。单位为度。

#### 依赖关系

要启用此参量，请将 **俯仰角来源** 参数设置为 `Input port`。

**数据类型：** `double`

### 输出

### **Resp** — 距离响应数据立方体 复数值 *M* 元素列向量 | 复数值 *M*-by-*L* 矩阵 | 复数值 *M*-by-*N*-by-*L* 数组

距离响应数据立方体，返回为以下之一：

- 复数值 *M* 元素列向量
- 复数值 *M*-by-*L* 矩阵
- 复数值 *M*-by-*N*-by-*L* 数组

*M* 的值取决于处理类型

| 距离处理方法 | *M* 的值 |
| --- | --- |
| `FFT` | 如果将 **距离处理中的 FFT 长度来源** 参数设置为 `Auto`，则 *M = K*，即 `X` 快时间维度的长度。否则，*M* 等于距离处理中的 FFT 长度参数的值。 |
| `Matched filter` | *M = K*，即 `X` 快时间维度的长度。 |

**数据类型：** `double`
**复数支持：** Yes

### **Range** — 沿距离维度的距离值 实数值 *M*-by-1 列向量

沿距离维度的距离值，返回为实数值 *M*-by-1 列向量。此向量定义对应于 `RESP` 输出数据立方体快时间维度的距离。*M* 是 `RESP` 快时间维度的长度。距离值单调递增且等间距。单位为米。

**数据类型：** `double`

### **Ang** — 沿角度方向的角度值 *P*-by-1 实数值向量

对应于沿角度方向样本的角度值，返回为 *P*-by-1 实数值向量。单位为度。

**数据类型：** `double`

## 参数

#### 主选项卡

### **信号传播速度 (m/s)** — 信号传播速度 `physconst('LightSpeed')`（默认）| 实数值正标量

信号传播速度，指定为实数值正标量。光速的默认值是 `physconst('LightSpeed')` 返回的值。单位为米每秒。

**示例：** `3e8`

**数据类型：** `double`

### **工作频率 (Hz)** — 系统工作频率 `3e8`（默认）| 正实数标量

系统工作频率，指定为正标量。单位为 Hz。

### **测量模式** — 测量模式 `Monostatic`（默认）| `Bistatic`

测量模式，指定为 `Monostatic` 或 `Bistatic`。设置为 `Monostatic` 时，距离测量为单基地距离。设置为 `Bistatic` 时，距离测量为双基地距离。

**示例：** `Bistatic`

**数据类型：** `char` | `string`

### **距离处理方法** — 距离处理方法 `Matched filter`（默认）| `FFT`

距离处理方法，指定为 `Matched filter` 或 `FFT`。

- `Matched filter` — 对象对输入信号进行匹配滤波。此方法通常用于脉冲信号，其中匹配滤波器是发射信号的时间反转。
- `FFT` — 对象对输入信号应用 FFT。此方法通常用于啁啾信号，例如 FMCW 和线性 FM 脉冲信号。

**数据类型：** `char`

### **继承采样率** — 从上流模块继承采样率 on（默认）| off

选择此参数以从上流模块继承采样率。否则，使用 **采样率 (Hz)** 参数指定采样率。

**数据类型：** `Boolean`

### **采样率 (Hz)** — 信号采样率 `1e6`（默认）| 正实数值标量

将信号采样率指定为正标量。单位为 Hz。

#### 依赖关系

要启用此参数，请清除 **继承采样率** 复选框。

**数据类型：** `double`

### **FM 扫频斜率 (Hz/s)** — 线性 FM 扫频斜率 `1.0e9`（默认）| 标量

线性 FM 扫频斜率，指定为标量。`X` 输入端的快时间维度必须对应于具有此斜率的扫频。

**示例：** `1.5e9`

#### 依赖关系

要启用此参数，请将 **距离处理方法** 参数设置为 `FFT`。

**数据类型：** `double`

### **对输入信号去斜** — 启用对输入信号去斜 `on`（默认）| `off`

启用对输入信号去斜的选项，指定为 `on` 或 `off`。不选中此复选框表示输入信号已经去斜，无需进行去斜操作。当输入信号需要去斜时，选中此复选框。

#### 依赖关系

要启用此参数，请将 **距离处理方法** 参数设置为 `FFT`。

**数据类型：** `Boolean`

### **距离中的 FFT 长度来源** — 用于对去斜信号进行距离处理的 FFT 长度来源 `Auto`（默认）| `Property`

用于对去斜信号进行距离处理的 FFT 长度来源，指定为 `Auto` 或 `Property`。

- `Auto` — FFT 长度等于输入数据立方体快时间维度的长度。
- `Property` — 使用 **距离处理中的 FFT 长度** 参数指定 FFT 长度。

#### 依赖关系

要启用此参数，请将 **距离处理方法** 参数设置为 `FFT`。

**数据类型：** `char`

### **距离处理中的 FFT 长度** — 用于距离处理的 FFT 长度 `1024`（默认）| 正整数

用于距离处理的 FFT 长度，指定为正整数。

#### 依赖关系

要启用此参数，请将 **距离处理方法** 参数设置为 `FFT`，并将 **距离处理中的 FFT 长度来源** 参数设置为 `Property`。

**数据类型：** `double`

### **距离处理窗** — 用于距离处理的 FFT 加权窗 `None`（默认）| `Hamming` | `Chebyshev` | `Hann` | `Kaiser` | `Taylor`

用于距离处理的 FFT 加权窗，指定为 `None`、`Hamming`、`Chebyshev`、`Hann`、`Kaiser` 或 `Taylor`。

如果将此参数设置为 `Taylor`，则生成的 Taylor 窗在主瓣旁边具有四个几乎恒定的旁瓣。

#### 依赖关系

要启用此参数，请将 **距离处理方法** 参数设置为 `FFT`。

**数据类型：** `char`

### **距离旁瓣衰减电平** — 用于距离处理的旁瓣衰减 `30`（默认）| 标量

用于距离处理的旁瓣衰减，指定为正标量。此衰减仅应用于 Kaiser、Chebyshev 或 Taylor 窗。单位为 dB。

#### 依赖关系

要启用此参数，请将 **距离处理方法** 参数设置为 `FFT`，并将 **距离处理窗** 参数设置为 `Kaiser`、`Chebyshev` 或 `Kaiser`。

### **将参考距离设置在中心** — 将参考距离设置在距离网格中心 `on`（默认）| `off`

将参考距离设置在距离网格中心，指定为 `on` 或 `off`。选中此复选框可将参考距离设置在距离网格中心。否则，参考距离对应于距离网格的起始位置。

#### 依赖关系

要启用此参数，请将 **距离处理方法** 设置为 `FFT`。

**数据类型：** `Boolean`

### **参考距离 (m)** — 距离网格的参考距离 `0.0`（默认）| 非负标量

距离网格的参考距离，指定为非负标量。

- 如果将 **距离处理方法** 参数设置为 `'Matched filter'`，则参考距离设置为距离网格的起始位置。
- 如果将 **距离处理方法** 参数设置为 `FFT`，则参考距离由 **将参考距离设置在中心** 参数确定。

  - 选中 **将参考距离设置在中心** 复选框时，参考距离设置为距离网格的中心。
  - 否则，参考距离设置为距离网格的起始位置。

  单位为米。

**示例：** `1000.0`

**数据类型：** `double`

### **俯仰角来源** — 俯仰角来源 `Property`（默认）| **Input port**

俯仰角来源，指定为 `Property` 或 **Input port**。

|  |  |
| --- | --- |
| `Property` | 俯仰角来自 **俯仰角 (deg)** 参数。 |
| `Input port` | 俯仰角来自输入端口。 |

### **俯仰角 (deg)** — 用于计算距离-角度响应的俯仰角 `0`（默认）| 标量

用于计算距离-角度响应的俯仰角，指定为标量。角度必须介于 --90 和 90 度之间。当将 ElevationAngleSource 属性设置为 `'Property'` 时，此属性适用。此属性的默认值为 0。

### **角度跨度 (deg)** — 角度响应跨度 `[-90 90]`（默认）| 实数值 1-by-2 向量

角度响应跨度，指定为实数值 2-by-1 向量。对象在角度范围 `[min_angle max_angle]` 内计算距离-角度响应。

**示例：** `[-45 45]`

**数据类型：** `` 12wqqqq` `` | `qdouble`

### **角度 bin 数** — 角度跨度中的样本数 大于二的正整数

用于计算距离-角度响应的角度跨度中的样本数，指定为大于二的正整数。

**示例：** `[256]`

**数据类型：** `double`

#### 阵元参数

### **阵元类型** — 阵列阵元类型 `Isotropic Antenna`（默认）| `Cosine Antenna` | `Custom Antenna` | `Omni Microphone` | `Custom Microphone`

天线或麦克风类型，指定为以下之一：

### **工作频率范围 (Hz)** — 天线或麦克风阵元的工作频率范围 `[0,1e20]`（默认）| 实数值 1-by-2 行向量

将天线或麦克风阵元的工作频率范围指定为 `[LowerBound,UpperBound]` 形式的 1-by-2 行向量。阵元在此频率范围之外没有响应。频率单位为 Hz。

### **工作频率向量 (Hz)** — 自定义天线或麦克风阵元的工作频率范围 `[0,1e20]`（默认）| 实数值行向量

将用于设置天线和麦克风频率响应的频率指定为 1-by-*L* 行向量，其元素为递增实数值。天线或麦克风阵元在此向量最小和最大元素指定的频率范围之外没有响应。频率单位为 Hz。

### **遮挡阵元背面** — 将 `Isotropic Antenna` 阵元或 `Omni Microphone` 阵元的背面响应设置为零 off（默认）| on

选中此复选框以遮挡阵元的背面响应。当背面被遮挡时，与侧射方向成 ±90° 以外的所有方位角处的响应均设置为零。侧射方向定义为 0° 方位角和 0° 俯仰角。

#### 依赖关系

要启用此复选框，请将 **阵元类型** 设置为 `Isotropic Antenna` 或 `Omni Microphone`。

将余弦方向图的指数指定为非负标量或由非负值组成的实值 1×2 矩阵。当 **余弦方向图指数** 为 1×2 向量时，第一个元素是方位角方向上的指数，第二个元素是俯仰角方向上的指数。当您将此参数设置为标量时，方位角方向和俯仰角方向余弦方向图都会以相同的幂次进行运算。

#### 依赖关系

要启用此参数，请将 **阵元类型** 设置为 `Cosine Antenna`。

### **频率响应 (dB)** — 天线和麦克风频率响应 `[0,0]`（默认）| 实值行向量

自定义天线或自定义麦克风在由 **工作频率向量 (Hz)** 参数定义的频率处的频率响应。**频率响应 (dB)** 的维度必须与 **工作频率向量 (Hz)** 参数指定的向量的维度匹配。

#### 依赖关系

要启用此参数，请将 **阵元类型** 设置为 `Custom Antenna` 或 `Custom Microphone`。

### **输入方向图坐标系** — 自定义天线方向图的坐标系 `az-el`（默认）| `phi-theta`

自定义天线方向图的坐标系，指定为 `az-el` 或 `phi-theta`。指定 `az-el` 时，使用 **方位角 (deg)** 和 **俯仰角 (deg)** 参数指定方向图点的坐标。指定 `phi-theta` 时，使用 **Phi 角 (deg)** 和 **Theta 角 (deg)** 参数指定方向图点的坐标。

#### 依赖关系

要启用此参数，请将 **阵元类型** 设置为 `Custom Antenna`。

### **方位角 (deg)** — 天线辐射方向图的方位角 `[-180:180]`（默认）| 实值行向量

将计算天线辐射方向图时所用的方位角指定为 1×*P* 行向量。*P* 必须大于 2。方位角必须介于 –180° 和 180° 之间（包含两端），并且必须严格递增。

#### 依赖关系

要启用此参数，请将 **阵元类型** 参数设置为 `Custom Antenna`，并将 **输入方向图坐标系** 参数设置为 `az-el`。

### **俯仰角 (deg)** — 天线辐射方向图的俯仰角 `[-90:90]`（默认）| 实值行向量

将计算辐射方向图时所用的俯仰角指定为 1×*Q* 向量。*Q* 必须大于 2。角度单位为度。俯仰角必须介于 –90° 和 90° 之间（包含两端），并且必须严格递增。

#### 依赖关系

要启用此参数，请将 **阵元类型** 参数设置为 `Custom Antenna`，并将 **输入方向图坐标系** 参数设置为 `az-el`。

### **Phi 角 (deg)** — 自定义天线辐射方向图的 Phi 角坐标 `0:360` | 实值 1×*P* 行向量

指定天线辐射方向图时所使用的点的 Phi 角，指定为实值 1×*P* 行向量。*P* 必须大于 2。角度单位为度。Phi 角必须介于 0° 和 360° 之间，并且必须严格递增。

#### 依赖关系

要启用此参数，请将 **阵元类型** 参数设置为 `Custom Antenna`，并将 **输入方向图坐标系** 参数设置为 `phi-theta`。

### **Theta 角 (deg)** — 自定义天线辐射方向图的 Theta 角坐标 `0:180` | 实值 1×*Q* 行向量

指定天线辐射方向图时所使用的点的 Theta 角，指定为实值 1×*Q* 行向量。*Q* 必须大于 2。角度单位为度。Theta 角必须介于 0° 和 360° 之间，并且必须严格递增。

#### 依赖关系

要启用此参数，请将 **阵元类型** 参数设置为 `Custom Antenna`，并将 **输入方向图坐标系** 参数设置为 `phi-theta`。
