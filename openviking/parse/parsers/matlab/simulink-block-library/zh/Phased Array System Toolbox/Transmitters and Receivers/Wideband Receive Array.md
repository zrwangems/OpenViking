# Wideband Receive Array

## 端口

**注意**

模块的输入和输出端口对应于底层 System 对象的 `step` 方法中描述的输入和输出参数。请参阅本页底部的链接。

| 端口 | 描述 | 支持的数据类型 |
| --- | --- | --- |
| `X` | 到达信号输入端口。输入矩阵第一个维度的大小可以变化，以模拟不断变化的信号长度。例如，在脉冲重复频率可变的脉冲波形情况下，可能会发生这种大小变化。 | Double-precision floating point |
| `Ang` | 信号入射方向输入端口。 | Double-precision floating point |
| `W` | 阵列或子阵权重输入端口。要启用此端口，请选中 **启用权重输入** 复选框。 | Double-precision floating point |
| `WS` | 子阵阵元权重输入端口。要启用此端口，请从 **子阵导向方法** 下拉菜单中选择 `Custom`。 |  |
| `Steer` | 导向角输入端口。要启用此端口，请从 **子阵导向方法** 下拉菜单中选择 `Phase` 或 `Time`。 | Double-precision floating point |
| `Out` | 收集的信号 | Double-precision floating point |

## 参数

**信号传播速度 (m/s)**
:   将信号的传播速度指定为正标量，单位为米/秒。您可以使用函数 `physconst` 指定光速。

**继承采样率**
:   选中此复选框可从上游模块继承采样率。否则，请使用 **采样率 (Hz)** 参数指定采样率。

**采样率 (Hz)**
:   将信号采样率（以赫兹为单位）指定为正标量。仅当未选中 **继承采样率** 参数时，才会显示此参数。

**假设调制输入**
:   选中此复选框以指示输入信号已在载波频率处解调。

**载波频率**
:   选中 **假设调制输入** 复选框时，会显示此参数。该参数将载波频率指定为正标量，单位为赫兹。

**子带数量**
:   处理子带的数量，指定为正整数。

**传感器增益度量**
:   传感器增益度量，指定为 `dB` 或 `dBi`。

    - 当将此参数设置为 `dB` 时，输入信号功率会按相应方向上的传感器功率方向图（以 dB 为单位）进行缩放，然后再进行合成。
    - 当将此参数设置为 `dBi` 时，输入信号功率会按相应方向上的方向性图（以 dBi 为单位）进行缩放，然后再进行合成。当您希望将结果与雷达方程计算的值进行比较时，此选项很有用；该雷达方程使用 dBi 指定天线增益。使用 `dBi` 选项的计算开销很大，因为需要在所有方向上积分，以计算传感器的总辐射功率。默认值为 `dB`。

**启用权重输入**
:   选中此复选框可使用输入端口 `W` 指定阵列权重。仅当选中此复选框时，才会显示该输入端口。

**仿真方式**
:   模块仿真方法，指定为 `Interpreted Execution` 或 `Code Generation`。如果希望模块使用 MATLAB® 解释器，请选择 `Interpreted Execution`。如果希望模块作为编译后的代码运行，请选择 `Code Generation`。编译后的代码需要时间来编译，但通常运行速度更快。

    在开发和调优模型时，解释执行非常有用。模块在 MATLAB 中运行底层 System 对象™。您可以快速更改并执行模型。对结果满意后，即可使用 `Code Generation` 运行模块。长时间仿真的运行速度比在解释执行时更快。您无需重新编译即可重复执行。但是，如果更改任何模块参数，模块会在执行前自动重新编译。

    设置此参数时，必须考虑模型的整体仿真模式。下表显示了 **仿真方式** 参数与整体仿真模式的交互方式。

    当 Simulink® 模型处于 `Accelerator` 模式时，通过 **仿真方式** 指定的模块模式将覆盖该仿真模式。

    **加速模式**

    |  |  |  |  |
    | --- | --- | --- | --- |
    | 模块仿真 | 仿真行为 | | |
    | `Normal` | `Accelerator` | `Rapid Accelerator` |
    | `Interpreted Execution` | 模块使用 MATLAB 解释器执行。 | 模块使用 MATLAB 解释器执行。 | 根据模型创建独立可执行文件。 |
    | `Code Generation` | 模块将被编译。 | 模型中的所有模块都将被编译。 |

    有关详细信息，请参阅 Choosing a Simulation Mode (Simulink)。

### 阵列参数

**将传感器阵列指定为**
:   指定传感器阵元或传感器阵列。传感器阵列也可以包含子阵列，也可以是分区阵列。此参数还可以表示为 MATLAB 表达式。

    **类型**

    |  |
    | --- |
    | `Single element` |
    | `Array (no subarrays)` |
    | `Partitioned array` |
    | `Replicated subarray` |
    | `MATLAB expression` |

**几何结构**
:   将阵列几何结构指定为以下之一：

    - `ULA` — 均匀线性阵列
    - `URA` — 均匀矩形阵列
    - `UCA` — 均匀圆形阵列
    - `Conformal Array` — 任意阵元位置

**阵元数量**
:   阵列阵元的数量。

    阵列阵元的数量，指定为正整数。当 **几何结构** 设置为 `ULA` 或 `UCA` 时，会显示此参数。如果 **传感器阵列** 选择了 `Replicated subarray` 选项，则此参数应用于子阵列。

**阵列大小**
:   当 **几何结构** 设置为 `URA` 时，会显示此参数。当 **传感器阵列** 设置为 `Replicated subarray` 时，此参数应用于子阵列。

    将阵列大小指定为正整数或由正整数组成的 1-by-2 向量。

    - 如果 **阵列大小** 是 1-by-2 向量，则该向量的形式为 `[NumberOfArrayRows,NumberOfArrayColumns]`。
    - 如果 **阵列大小** 是整数，则阵列具有相同的行数和列数。

    对于 URA，阵元沿列从上到下编索引，并从左到右继续对后续各列编索引。在此图中，**阵列大小** 为 `[3,2]` 会生成一个三行两列的阵列。

**阵元间距 (m)**
:   当 **几何结构** 设置为 `ULA` 或 `URA` 时，会显示此参数。当 **传感器阵列** 选择了 `Replicated subarray` 选项时，此参数应用于子阵列。

    - 对于 `ULA`，将阵列中两个相邻阵元之间的间距指定为标量，单位为米。
    - 对于 `URA`，将阵列的阵元间距指定为 1-by-2 向量或标量，单位为米。如果 **阵元间距** 是 1-by-2 向量，则该向量的形式为 `[SpacingBetweenRows,SpacingBetweenColumns]`。有关这些量的讨论，请参阅 `phased.URA`。如果 **阵元间距** 是标量，则行间距和列间距相等。

**阵列轴**
:   当 **几何结构** 参数设置为 `ULA` 或模块仅支持 ULA 阵列几何结构时，会显示此参数。将阵列轴指定为 `x`、`y` 或 `z`。所有 ULA 阵列阵元在局部阵列坐标系中沿此轴均匀间隔。

**阵列法向**,
:   当您将 **几何结构** 设置为 `URA` 或 `UCA` 时，会显示此参数。将 **阵列法向** 指定为 `x`、`y` 或 `z`。所有 URA 和 UCA 阵列阵元分别位于阵列坐标系的 *yz*、*zx* 或 *xy* 平面中。

**UCA 半径 (m)**
:   均匀圆形阵列的半径，指定为正标量。单位为米。

    当 **几何结构** 设置为 `UCA` 时，会显示此参数。

**锥削**
:   锥削（也称为*阵元权重*）应用于阵列中的传感器阵元。锥削用于修改发射或接收数据的幅度和相位。

    此参数适用于所有阵列类型，但当您将 **传感器阵列** 设置为 `Replicated subarray` 时，此参数应用于子阵列。

    - 对于 `ULA` 或 `UCA`，将阵元锥削指定为复值标量或复值 1-by-*N* 行向量。在此向量中，*N* 表示阵列中的阵元数量。如果 **锥削** 是标量，则对每个阵元应用相同的权重。如果 **锥削** 是向量，则将向量中的权重应用于相应的传感器阵元。必须为传感器阵列中的每个阵元应用权重。
    - 对于 `URA`，将阵元锥削指定为复值标量或复值 *M*-by-*N* 矩阵。在此矩阵中，*M* 是沿 *z* 轴的阵元数量，*N* 是沿 *y* 轴的阵元数量。*M* 和 *N* 对应于 **阵列大小** 矩阵中 `[NumberofArrayRows,NumberOfArrayColumns]` 的值。如果 `Taper` 是标量，则对每个阵元应用相同的权重。如果 **锥削** 是矩阵，则将矩阵中的权重应用于相应的传感器阵元。必须为传感器阵列中的每个阵元应用权重。
    - 对于 `Conformal Array`，将阵元锥削指定为复值标量或复值 1-by-*N* 向量。在此向量中，*N* 是由 **阵元位置** 向量的大小确定的阵列阵元数量。如果 **锥削** 是标量，则对每个阵元应用相同的权重。如果 **锥削** 的值是向量，则将向量中的权重应用于相应的传感器阵元。必须为传感器阵列中的每个阵元应用权重。

**阵元点阵**
:   当 **几何结构** 设置为 `URA` 时，会显示此参数。当 **传感器阵列** 设置为 `Replicated subarray` 时，此参数应用于子阵列。

    将阵元点阵指定为 `Rectangular` 或 `Triangular`

    - `Rectangular` — 使所有阵元沿行和列方向对齐。
    - `Triangular`— 将矩形点阵的偶数行阵元向正行轴方向移动。位移为沿行维度阵元间距的一半。

**阵元位置 (m)**
:   当 **几何结构** 设置为 `Conformal Array` 时，会显示此参数。当 **传感器阵列** 设置为 `Replicated subarray` 时，此参数应用于子阵列。

    将共形阵列阵元的位置指定为 3-by-*N* 矩阵，其中 *N* 是共形阵列中的阵元数量。**阵元位置 (m)** 的每一列表示单个阵元在阵列局部坐标系中的位置，形式为 `[x;y;z]`。局部坐标系的原点位于任意点。单位为米。

**阵元法向 (deg)**
:   当 **几何结构** 设置为 `Conformal Array` 时，会显示此参数。当 **传感器阵列** 设置为 `Replicated subarray` 时，此参数应用于子阵列。

    将共形阵列中阵元的法线方向指定为以度为单位的 2-by-*N* 矩阵或 2-by-1 列向量。变量 *N* 表示阵列中的阵元数量。如果 **阵元法向 (deg)** 是矩阵，则每列以 `[azimuth;elevation]` 形式指定相应阵元相对于局部坐标系的法线方向。局部坐标系的正 *x* 轴与共形阵列的法线方向对齐。如果 **阵元法向 (deg)** 是 2-by-1 列向量，则该向量为阵列中的所有阵元指定相同的指向方向。

    您可以使用 **阵元位置 (m)** 和 **阵元法向 (deg)** 参数来表示任意阵元布置，其中各对阵元之间可相差特定变换。您可以组合平移、方位角旋转和仰角旋转变换。但是，不能使用需要绕法线旋转的变换。

**子阵列定义矩阵**
:   当 **将传感器阵列指定为** 设置为 `Partitioned array` 时，会显示此参数。

    将子阵列选择指定为 *M*-by-*N* 矩阵。*M* 是子阵列的数量，*N* 是阵列中阵元的总数量。矩阵的每一行对应一个子阵列，行中的每个元素指示某个阵元是否属于该子阵列。当元素为零时，该阵元不属于此子阵列。非零元素表示应用于相应阵元的复值权重。每行必须至少包含一个非零元素。

    每个子阵列的相位中心是其几何中心。**子阵列定义矩阵** 和 **几何结构** 决定该几何中心。

**子阵列转向方法**
:   当 **将传感器阵列指定为** 参数设置为 `Partitioned array` 或 `Replicated subarray` 时，会显示此参数。

    将子阵列转向方法指定为

    - `None`
    - `Phase`
    - `Time`
    - `Custom`

    选择 `Phase` 或 `Time` 会在 Narrowband Receive Array、Narrowband Transmit Array、Wideband Receive Array、Wideband Transmit Array 模块以及 Constant Gamma Clutter 和 GPU Constant Gamma Clutter 模块上打开 `Steer` 输入端口。

    选择 `Custom` 会在 Narrowband Receive Array、Narrowband Transmit Array、Wideband Receive Array、Wideband Transmit Array 模块以及 Constant Gamma Clutter 和 GPU Constant Gamma Clutter 模块上打开 `WS` 输入端口。

**移相器频率 (Hz)**
:   当您将 **传感器阵列** 设置为 `Partitioned array` 或 `Replicated subarray`，并将 **子阵列转向方法** 设置为 `Phase` 时，会显示此参数。

    将用于执行子阵列转向的移相器的工作频率指定为正标量，单位为赫兹。

**移相器位数**
:   当您将 **传感器阵列** 设置为 `Partitioned array` 或 `Replicated subarray`，并将 **子阵列转向方法** 设置为 `Phase` 时，会显示此参数。

    用于量化波束形成器或导向矢量权重的相移分量的位数。将位数指定为非负整数。值为零表示不执行量化。

**子阵列布局**
:   当您将 **传感器阵列** 设置为 `Replicated subarray` 时，会显示此参数。

    将复制子阵列的布局指定为 `Rectangular` 或 `Custom`。

**网格大小**
:   当您将 **传感器阵列** 设置为 `Replicated subarray`，并将 **子阵列布局** 设置为 `Rectangular` 时，会显示此参数。

    矩形子阵列网格大小，指定为单个正整数或由正整数值组成的 1-by-2 行向量。

    如果 **网格大小** 是整数标量，则阵列在每行和每列中具有相同数量的子阵列。如果 **网格大小** 是形式为 `[NumberOfRows, NumberOfColumns]` 的 1-by-2 向量，则第一个元素是沿每列的子阵列数量。第二个元素是每行中的子阵列数量。行沿局部 *y* 轴，列沿局部 *z* 轴。此处的图显示了如何使用 `[1,2]` 的 **网格大小** 复制一个 3-by-2 URA 子阵列。

**网格间距**
:   当您将 **传感器阵列** 设置为 `Replicated subarray`，并将 **子阵列布局** 设置为 `Rectangular` 时，会显示此参数。

    将子阵列的矩形网格间距指定为实值正标量、1-by-2 行向量或 `Auto`。网格间距的单位为米。

    - 如果 **网格间距** 是标量，则沿行的间距与沿列的间距相同。
    - 如果 **网格间距** 是 1-by-2 行向量，则该向量的形式为 `[SpacingBetweenRows,SpacingBetweenColumn]`。第一个元素指定沿列的行间距。第二个元素指定沿行的列间距。
    - 如果 **网格间距** 设置为 `Auto`，则在构建完整阵列时，复制过程会同时保留子阵列在行和列方向上的阵元间距。仅当您将 **几何结构** 指定为 `ULA` 或 `URA` 时，此选项才可用。

**子阵列位置 (m)**
:   当您将 **传感器阵列** 设置为 `Replicated subarray`，并将 **子阵列布局** 设置为 `Custom` 时，会显示此参数。

    将自定义网格中子阵列的位置指定为 3-by-*N* 矩阵，其中 *N* 是阵列中的子阵列数量。矩阵的每一列表示单个子阵列在阵列局部坐标系中的位置，单位为米。坐标以 `[x; y; z]` 形式表示。

**子阵列法向**
:   当您将 **传感器阵列** 参数设置为 `Replicated subarray`，并将 **子阵列布局** 设置为 `Custom` 时，会显示此参数。

    指定阵列中子阵列的法线方向。此参数值为 2-by-*N* 矩阵，其中 *N* 是阵列中的子阵列数量。矩阵的每一列以 `[azimuth; elevation]` 形式指定相应子阵列的法线方向。每个角度均以度为单位，并在局部坐标系中定义。

    您可以使用 **子阵列位置** 和 **子阵列法向** 参数来表示任意子阵列布置，其中各对子阵列之间可相差特定变换。这些变换可以组合平移、方位角旋转和仰角旋转。但是，不能使用需要绕法线旋转的变换。

**表达式**
:   包含阵列构造函数的有效 MATLAB 表达式，例如 `phased.URA`。

### 传感器阵列选项卡：阵元参数

**阵元类型**
:   将天线或麦克风类型指定为

    - `Isotropic Antenna`
    - `Cosine Antenna`
    - `Custom Antenna`
    - `Omni Microphone`
    - `Custom Microphone`

**余弦方向图指数**
:   当将 **阵元类型** 设置为 `Cosine Antenna` 时，会显示此参数。

    将余弦方向图的指数指定为标量或 1-by-2 向量。所有值都必须指定为非负实数。当将 **余弦方向图指数** 设置为标量时，方位角方向余弦方向图和仰角方向余弦方向图均提升到指定次幂。当将 **余弦方向图指数** 设置为 1-by-2 向量时，第一个元素是方位角方向余弦方向图的指数，第二个元素是仰角方向余弦方向图的指数。

**工作频率范围 (Hz)**
:   当 **阵元类型** 设置为 `Isotropic Antenna`、`Cosine Antenna` 或 `Omni Microphone` 时，会显示此参数。

    将天线阵元的工作频率范围指定为 `[LowerBound,UpperBound]` 形式的 1-by-2 行向量，单位为赫兹。天线阵元在指定频率范围之外无响应。

**工作频率向量 (Hz)**
:   当 **阵元类型** 设置为 `Custom Antenna` 或 `Custom Microphone` 时，会显示此参数。

    将用于设置天线和麦克风频率响应的频率指定为值递增的 1-by-*L* 行向量，单位为 Hz。使用 **频率响应** 设置频率响应。天线或麦克风阵元在由 **工作频率向量 (Hz)** 的最小元素和最大元素指定的频率范围之外无响应。

**频率响应 (dB)**
:   当 **阵元类型** 设置为 `Custom Antenna` 或 `Custom Microphone` 时，会显示此参数。

    对于由 **工作频率向量 (Hz)** 定义的频率，将此参数指定为天线或麦克风的频率响应，单位为分贝。将 **频率响应 (dB)** 指定为 1-by-*L* 向量，其维度与 **工作频率向量 (Hz)** 中指定的向量相匹配。

**输入方向图坐标系**
:   自定义天线方向图的坐标系，指定为 `az-el` 或 `phi-theta`。当指定 `az-el` 时，使用 **方位角 (deg)** 和 **仰角 (deg)** 参数指定方向图点的坐标。当指定 `phi-theta` 时，使用 **Phi 角 (deg)** 和 **Theta 角 (deg)** 参数指定方向图点的坐标。

**方位角 (deg)**
:   当 **阵元类型** 设置为 `Custom Antenna` 且 **输入方向图坐标系** 参数设置为 `az-el` 时，会显示此参数。

    将用于计算天线辐射方向图的方位角指定为 1-by-*P* 行向量。*P* 必须大于 2。角度单位为度。方位角必须介于 –180° 和 180° 之间，并严格递增。

**仰角 (deg)**
:   当 **阵元类型** 设置为 `Custom Antenna` 且 **输入方向图坐标系** 参数设置为 `az-el` 时，会显示此参数。

    将用于计算辐射方向图的仰角指定为 1-by-*Q* 向量。*Q* 必须大于 2。角度单位为度。仰角必须介于 –90° 和 90° 之间，并严格递增。

**Phi 角 (deg)**
:   当 **阵元类型** 设置为 `Custom Antenna` 且 **输入方向图坐标系** 参数设置为 `phi-theta` 时，会显示此参数。

    将用于指定天线辐射方向图的各点的 Phi 角指定为 1-by-*P* 行向量。*P* 必须大于 2。角度单位为度。Phi 角必须介于 0° 和 360° 之间，并严格递增。

**Theta 角 (deg)**
:   当 **阵元类型** 设置为 `Custom Antenna` 且 **输入方向图坐标系** 参数设置为 `phi-theta` 时，会显示此参数。

    将用于指定天线辐射方向图的各点的 Theta 角指定为 1-by-*Q* 行向量。*Q* 必须大于 2。角度单位为度。Theta 角必须介于 0° 和 180° 之间，并严格递增。

**幅值方向图 (dB)**
:   当 **阵元类型** 设置为 `Custom Antenna` 时，会显示此参数。

    组合天线辐射方向图的幅值，指定为 *Q*-by-*P* 矩阵或 *Q*-by-*P*-by-*L* 数组。

    - 当 **输入方向图坐标系** 参数设置为 `az-el` 时，*Q* 等于 **仰角 (deg)** 参数所指定向量的长度，*P* 等于 **方位角 (deg)** 参数所指定向量的长度。
    - 当 **输入方向图坐标系** 参数设置为 `phi-theta` 时，*Q* 等于 **Theta 角 (deg)** 参数所指定向量的长度，*P* 等于 **Phi 角 (deg)** 参数所指定向量的长度。

    量 *L* 等于 **工作频率向量 (Hz)** 的长度。

    - 如果此参数为 *Q*-by-*P* 矩阵，则同一方向图应用于 **工作频率向量 (Hz)** 参数中指定的 *所有* 频率。
    - 如果该值为 *Q*-by-*P*-by-*L* 数组，则数组的每个 *Q*-by-*P* 页为 **工作频率向量 (Hz)** 参数中指定的 *相应* 频率指定一个方向图。

**相位方向图 (dB)**
:   当 **阵元类型** 设置为 `Custom Antenna` 时，会显示此参数。

    组合天线辐射方向图的相位，指定为 *Q*-by-*P* 矩阵或 *Q*-by-*P*-by-*L* 数组。

    - 当 **输入方向图坐标系** 参数设置为 `az-el` 时，*Q* 等于 **仰角 (deg)** 参数所指定向量的长度，*P* 等于 **方位角 (deg)** 参数所指定向量的长度。
    - 当 **输入方向图坐标系** 参数设置为 `phi-theta` 时，*Q* 等于 **Theta 角 (deg)** 参数所指定向量的长度，*P* 等于 **Phi 角 (deg)** 参数所指定向量的长度。

    量 *L* 等于 **工作频率向量 (Hz)** 的长度。

    - 如果此参数为 *Q*-by-*P* 矩阵，则同一方向图应用于 **工作频率向量 (Hz)** 参数中指定的 *所有* 频率。
    - 如果该值为 *Q*-by-*P*-by-*L* 数组，则数组的每个 *Q*-by-*P* 页为 **工作频率向量 (Hz)** 参数中指定的 *相应* 频率指定一个方向图。

    - 如果此参数为 *Q*-by-*P* 矩阵，则同一方向图应用于 **工作频率向量 (Hz)** 参数中指定的 *所有* 频率。
    - 如果该值为 *Q*-by-*P*-by-*L* 数组，则数组的每个 *Q*-by-*P* 页为 **工作频率向量 (Hz)** 参数中指定的 *相应* 频率指定一个方向图。

**MatchArrayNormal**
:   当 **阵元类型** 设置为 `Custom Antenna` 时，会显示此参数。

    选中此复选框可旋转天线阵元方向图，使其与阵列法线对齐。未选中时，不旋转阵元方向图。

    当天线用于天线阵列且 **输入方向图坐标系** 参数为 `az-el` 时，选中此复选框会旋转方向图，使阵元坐标系的 *x* 轴指向阵列法线方向。未选中时，使用未经旋转的阵元方向图。

    当天线用于天线阵列且 **输入方向图坐标系** 设置为 `phi-theta` 时，选中此复选框会旋转方向图，使阵元坐标系的 *z* 轴指向阵列法线方向。

    将此参数与 `URA` 和 `UCA` 阵列的 **阵列法线** 参数结合使用。

**极坐标方向图频率 (Hz)**
:   当 **阵元类型** 设置为 `Custom Microphone` 时，会显示此参数。

    将极坐标方向图的测量频率指定为 1-by-*M* 向量。测量频率位于 **工作频率向量 (Hz)** 参数指定的频率范围内。频率单位为 Hz。

**极坐标方向图角度 (deg)**
:   当 **阵元类型** 设置为 `Custom Microphone` 时，会显示此参数。

    将极坐标方向图的测量角度指定为 1-by-*N* 向量。角度从麦克风的中心拾音轴开始测量，必须介于 –180° 和 180° 之间（含端点）。

**极坐标方向图 (dB)**
:   当 **阵元类型** 设置为 `Custom Microphone` 时，会显示此参数。

    将麦克风阵元极坐标方向图的幅值指定为 *M*-by-*N* 矩阵。*M* 是 **极坐标方向图频率 (Hz)** 中指定的测量频率数量。*N* 是 **极坐标方向图角度 (deg)** 中指定的测量角度数量。矩阵的每一行表示在 **极坐标方向图频率 (Hz)** 中指定的相应频率以及 **极坐标方向图角度 (deg)** 中指定的所有角度下测得的极坐标方向图幅值。假设方向图在方位角平面内测量。在方位角平面内，仰角为 0°，中心拾音轴位于方位角 0°、仰角 0°。假设极坐标方向图围绕中心轴对称。可以根据极坐标方向图构建麦克风在 3-D 空间中的响应方向图。

**在阵元背面设置挡板**
:   仅当 **阵元类型** 参数设置为 `Isotropic Antenna` 或 `Omni Microphone` 时，才会显示此复选框。

    选中此复选框可在天线阵元背面设置挡板。在这种情况下，天线对相对于 *正侧向* 超出 ±90° 的所有方位角的响应均设为零。将正侧向定义为方位角 0°、仰角 0° 的方向。

## 描述

宽带接收阵列

Wideband Receive Array 模块接收入射到传感器阵列各阵元的宽带平面波。该模块将输入信号划分为多个子带，然后根据入射方向在每个子带中施加相移。随后将得到的子带信号组合起来，形成输出。
