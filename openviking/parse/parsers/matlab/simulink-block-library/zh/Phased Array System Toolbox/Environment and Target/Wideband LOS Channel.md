# Wideband LOS Channel

## 端口

### 输入

### **X** — 辐射信号 复值 *M*-by-1 向量 | 复值 *M*-by-*N* 矩阵

辐射信号，指定为复值 *M*-by-1 向量或复值 *M*-by-*N* 矩阵。*M* 是信号的长度，*N* 是阵元的数量（或支持子阵列时为子阵列的数量）。

**X 的维度**

| 维度 | 信号 |
| --- | --- |
| *M*-by-1 向量 | 所有阵元（或支持子阵列时的所有子阵列）辐射相同的信号。 |
| `M-by-N matrix` | 每一列对应于相应阵元（或支持子阵列时的相应子阵列）辐射的信号。 |

输入矩阵第一维的大小可以变化，以模拟变化的信号长度。例如，在具有可变脉冲重复频率的脉冲波形情况下，可能会发生大小变化。

**数据类型:** `double`
**复数支持:** Yes

### **Pos1** — 信号起点的位置 3-by-1 实值列向量 | 3-by-*N* 实值矩阵

信号起点的位置，指定为实值 3-by-1 列向量或 3-by-*N* 实值矩阵。数量 *N* 是源位置的数量。源位置的示例包括发射器、阵元位置或子阵列位置。位置单位是 meters。

如果 **Pos1** 是列向量，则其形式为 `[x;y;z]`。如果 **Pos1** 是矩阵，则每一列指定不同的信号起点，并采用 `[x;y;z]` 形式。

如果 **Pos1** 有多于一列，则 **Pos2** 只能有一列。不能将 **Pos1** 和 **Pos2** 同时指定为矩阵。

**示例:** `[1000;100;500]`

**数据类型:** `double`

### **Pos2** — 信号终点 3-by-1 实值列向量 | 3-by-*N* 实值矩阵

信号终点的位置，指定为实值 3-by-1 列向量或 3-by-*N* 实值矩阵。数量 *N* 是终点的数量，例如阵元位置或子阵列位置。位置单位是 meters。

如果 **Pos2** 是列向量，则其形式为 `[x;y;z]`。如果 **Pos2** 是矩阵，则每一列指定不同的信号终点。每一行采用 `[x;y;z]` 形式。位置单位是 meters。

如果 **Pos2** 有多于一列，则 **Pos1** 只能有一列。不能将 **Pos2** 和 **Pos1** 同时指定为矩阵。

**示例:** `[1000;100;500]`

**数据类型:** `double`

### **Vel1** — 源速度 3-by-1 实值列向量 | 3-by-*N* 实值矩阵 | *N*-by-3 实值矩阵

源速度，指定为与 **Pos1** 大小相同的实值向量或矩阵。

**示例:** `[20;20;50]`

**数据类型:** `double`

### **Vel2** — 终点速度 3-by-1 实值列向量 | 3-by-*N* 实值矩阵 | *N*-by-3 实值矩阵

终点速度，指定为与 **Pos2** 大小相同的实值向量或矩阵。

**示例:** `[0;0;100]`

**数据类型:** `double`
### 输出

### **Port\_1** — 传播后的信号 复值 *M*-by-1 向量 | 复值 *M*-by-*N* 矩阵

传播后的信号，返回为复值 *M*-by-1 向量或复值 *M*-by-*N* 矩阵。**Port\_1** 与输入端口 **X** 的大小相同。*M* 是信号的长度，*N* 是信号的数量。

**数据类型:** `double`

## 参数

### **传播速度 (m/s)** — 信号传播速度 `physconst('LightSpeed')`（默认）| 正标量

信号传播速度，指定为实值正标量。光速的默认值是由 `physconst('LightSpeed')` 返回的值。

**数据类型:** `double`

### **信号载波频率 (Hz)** — 信号载波频率 `3e8`（默认）| 正标量

信号载波频率，指定为正标量。单位是 Hz。

**数据类型:** `double`

### **子带数量** — 处理子带数量 `64`（默认）| 正整数

处理子带数量，指定为正整数。

**示例:** `128`

### **指定大气参数** — 启用大气衰减模型 off（默认）| on

选中此复选框可启用大气衰减建模。

### **温度 (degrees Celsius)** — 环境温度 `15` | 实值标量

将环境大气温度指定为实值标量。单位是 degrees Celsius。

#### 依赖项

当您选中 **指定大气参数** 复选框时，此参数会出现。

### **干空气压力 (Pa)** — 大气干空气压力 `101325` | 正实值标量

将大气干空气压力指定为正实值标量。单位是 Pascals (Pa)。此属性的值 101325 对应一个标准大气压。

#### 依赖项

当您选中 **指定大气参数** 复选框时，此参数会出现。

### **水汽密度 (g/m^3)** — 大气水汽密度 `7.5` | 正实值标量

将大气水汽密度指定为正实值标量。单位是 gm/m3。

#### 依赖项

当您选中 **指定大气参数** 复选框时，此参数会出现。

### **液态水密度 (g/m^3)** — 液态水密度 `0` | 非负实值标量

将雾或云的液态水密度指定为非负实值标量。单位是 gm/m3。液态水密度的典型值为中等雾 0.05 和浓雾 0.5。

#### 依赖项

当您选中 **指定大气参数** 复选框时，此参数会出现。

### **降雨率 (mm/hr)** — 降雨率 `0` | 非负实值标量

将降雨率指定为非负实值标量。单位是 mm/hour。

#### 依赖项

当您选中 **指定大气参数** 复选框时，此参数会出现。

### **执行双向传播** — 启用双向传播 off（默认）| on

选中此复选框可执行起点和终点之间的往返传播。否则，模块执行从起点到终点的单向传播。

### **继承采样率** — 从上游模块继承采样率 on（默认）| off

选择此参数以从上游模块继承采样率。否则，使用 **采样率 (Hz)** 参数指定采样率。

**数据类型:** `Boolean`

### **采样率 (Hz)** — 信号采样率 `1e6`（默认）| 正实值标量

将信号采样率指定为正标量。单位是 Hz。

#### 依赖项

要启用此参数，请清除 **继承采样率** 复选框。

**数据类型:** `double`

### **最大单向传播距离 (m)** — 最大单向传播距离 `10e3`（默认）| 正实值标量

将信号起点和终点之间的最大距离指定为正标量。单位是 meters。任何传播超过此距离的信号的幅度将被设置为零。

### **仿真方式** — 模块仿真方法 `Interpreted Execution`（默认）| `Code Generation`

模块仿真，指定为 `Interpreted Execution` 或 `Code Generation`。如果您希望您的模块使用 MATLAB® 解释器，请选择 `Interpreted Execution`。如果您希望您的模块作为编译代码运行，请选择 `Code Generation`。编译代码需要时间编译，但通常运行更快。

解释执行在开发和调整模型时很有用。模块在 MATLAB 中运行底层 System object™。您可以快速更改并执行模型。当您对结果满意时，随后可以使用 `Code Generation` 运行模块。长时间仿真使用生成的代码比解释执行运行得更快。您可以重复执行而无需重新编译，但如果您更改任何模块参数，模块会在执行前自动重新编译。

此表显示 **仿真方式** 参数如何影响整体仿真行为。

当 Simulink® 模型处于 `Accelerator` 模式时，使用 **仿真方式** 指定的模块模式将覆盖仿真模式。

**加速模式**

|  |  |  |  |
| --- | --- | --- | --- |
| 模块仿真 | 仿真行为 | | |
| `Normal` | `Accelerator` | `Rapid Accelerator` |
| `Interpreted Execution` | 模块使用 MATLAB 解释器执行。 | 模块使用 MATLAB 解释器执行。 | 从模型创建独立可执行文件。 |
| `Code Generation` | 模块被编译。 | 模型中的所有模块都被编译。 |

有关详细信息，请参阅 Choosing a Simulation Mode (Simulink)。

## 描述

宽带视距传播信道

Wideband LOS Channel 模块通过视距 (LOS) 信道将信号从空间中的一个点传播到多个点，或从多个点传播回一个点。该模块对传播时间、自由空间传播损耗、多普勒频移以及大气和天气损耗进行建模。该模块假设传播速度远大于目标速度，在这种情况下 stop-and-hop 模型有效。

当在 LOS 信道中将信号传播到目标并返回时，您可以使用单个模块计算双向 LOS 信道传播延迟，或使用两个模块在每个方向上执行单向传播延迟。由于 LOS 信道传播延迟不一定是采样间隔的整数倍，因此当您使用双向传播模块时，以采样表示的总往返延迟可能与使用两个单向传播模块时的以采样表示的延迟不同。因此，建议尽可能使用单个双向传播模块。
