# CFAR Detector

## 端口

### 输入

### **X** — 单元矩阵，实值 *M*×1 列向量 | 实值 *M*×*N* 矩阵

单元矩阵，指定为实值 *M*×1 列向量或实值 *M*×*N* 矩阵。

输入矩阵第一个维度的大小可以变化，以模拟变化的信号长度。例如，在具有可变脉冲重复频率的脉冲波形情况下，可能会发生大小变化。

**数据类型：** `single` | `double`

### **Idx** — 被测单元索引，实值长度为 *D* 的向量

被测单元 (CUT)，指定为实值长度为 *D* 的向量。索引指定要对其执行检测处理的输入元素或被测单元。当 `X` 是向量时，`Idx` 指定元素。当 `X` 是矩阵时，`Idx` 指定元素的行。同一索引应用于矩阵的所有列。对于 `Idx` 中指定的索引，检测沿 `Xww` 的每一列独立执行。

**数据类型：** `double`

### **K** — 阈值因子，正标量

用于计算检测阈值的阈值因子，指定为正标量。

#### 依赖关系

要启用此端口，请将 **阈值因子方法** 参数设置为 `Input port`。

**数据类型：** `double`

### 输出

### **Y** — 检测结果 *D*×1 向量 | *D*×*N* 矩阵 | *1*×*L* | 2×*L* 矩阵

`Y` 的格式取决于 **输出格式** 属性。

- 当 **输出格式** 为 `'Cut result'` 时，`Y` 是 *D*×1 向量或 *D*×*N* 矩阵，包含逻辑检测结果。*D* 是 `Idx` 的长度，*N* 是 `X` 的列数。`Y` 的行对应于 `Idx` 中的行。对于每一行，如果 `X` 的对应列中存在检测，则 `Y` 在相应列中包含 `1`。否则，`Y` 包含 `0`。
- 当 **输出格式** 为 `'Detection report'` 时，`Y` 是 1×*L* 向量或 2×*L* 矩阵，包含检测索引。*L* 是输入数据中找到的检测数量。当 `X` 是列向量时，`Y` 包含 `X` 中每个检测的索引。当 `X` 是矩阵时，`Y` 包含 `X` 中每个检测的行索引和列索引。`Y` 的每一列具有形式 `[detrow;detcol]`。当 **检测数量来源** 属性设置为 `'Property'` 时，*L* 等于 **最大检测数量** 参数的值。如果实际检测数量小于此值，则无检测的列设置为 `NaN`。

**数据类型：** `double`

### **Th** — 检测阈值标量

应用于被测单元的检测阈值，以标量形式返回。

- 当 **输出格式** 为 `'CUT result'` 时，`Th` 端口在 `Y` 的元素为 `1` 时输出检测阈值，并在 `Y` 的元素为 `0` 时输出 `NaN`。`Th` 的输出与 `Y` 大小相同。
- 当 **输出格式** 为 `'Detection index'` 时，`Th` 端口为 `Y` 中的每个对应检测输出检测阈值。当 **检测数量来源** 参数设置为 `'Property'` 时，检测数量由 **最大检测数量** 参数设置。如果实际检测数量小于此值，则无检测的列设置为 `NaN`。

#### 依赖关系

要启用此端口，请选中 **输出检测阈值** 复选框。

**数据类型：** `double`

### **N** — 估计噪声功率正标量

每个检测到的被测单元的估计噪声功率，以正标量形式返回。

- 当 **输出格式** 为 `'CUT result'` 时，`N` 在 `Y` 为 `1` 时返回噪声功率估计，并在 `Y` 为零时返回 `NaN`。端口 `N` 的输出与 `Y` 大小相同。
- 当 **输出格式** 为 `'Detection index'` 时，`M` 为 `Y` 中的每个对应检测返回噪声功率估计。当 **检测数量来源** 属性设置为 `'Property'` 时，*L* 等于 **最大检测数量** 参数的值。如果实际检测数量小于此值，则无检测的列设置为 `NaN`。

#### 依赖关系

要启用此端口，请选中 **输出估计噪声功率** 复选框。

**数据类型：** `double`

## 参数

### **CFAR 算法** — CFAR 算法 `CA` (default) | `GOCA` | `SOCA` | `OS`

使用以下值之一指定 CFAR 检测算法

|  |  |
| --- | --- |
| `CA` | 单元平均 |
| `GOCA` | 最大单元平均 |
| `OS` | 有序统计 |
| `SOCA` | 最小单元平均 |

### **保护单元数** — 保护单元数 `2` (default)

将训练中使用的保护单元数指定为偶数整数。此参数指定被测单元两侧的单元总数。

### **训练单元数** — 训练单元数 `2` (default)

将训练中使用的训练单元数指定为偶数整数。在可能的情况下，训练单元在被测单元前后等分。

### **有序统计量秩** — 有序统计量秩 `1` (default)

将有序统计量的秩指定为正整数标量。该值必须小于或等于 **训练单元数** 的值。

#### 依赖关系

当 **CFAR 算法** 设置为 `OS` 时，此参数出现。

### **阈值因子方法** — 获取阈值因子的方法 `Auto` (default) | `Input port` | `Custom`

指定阈值因子是来自自动计算、**自定义阈值因子** 参数，还是来自输入参数。此参数的值包括：

|  |  |
| --- | --- |
| `Auto` | 应用程序根据 **虚警概率** 参数中指定的期望虚警概率自动计算阈值因子。该计算假设输入中的每个独立信号是来自平方律检测器的单个脉冲，且没有脉冲积累。该计算还假设噪声为高斯白噪声。 |
| `Custom` | **自定义阈值因子** 参数指定阈值因子。 |
| `Input port` | 阈值因子使用输入端口 `K` 设置。仅当 **阈值因子方法** 设置为 `Input port` 时，此端口才会出现。 |

### **虚警概率** — 期望虚警概率 `0.1` (default)

将期望虚警概率指定为 0 到 1 之间（不含 0 和 1）的标量。

#### 依赖关系

仅当将 **阈值因子方法** 设置为 `Auto` 时，此参数才会出现。

### **自定义阈值因子** — 自定义阈值因子 `1` (default)

将自定义阈值因子指定为正标量。

#### 依赖关系

仅当将 **阈值因子方法** 设置为 `Custom` 时，此参数才会出现。

### **输出格式** — 检测结果格式 `CUT result` (default) | `Detection index`

将输出端口 `Y` 中返回的检测结果格式指定为 `CUT result` 或 `Detection index`。

- 当设置为 `CUT result` 时，结果为每个被测单元的逻辑检测值（`1` 或 `0`）。`1` 表示被测单元的值超过检测阈值。
- 当设置为 `Detection index` 时，结果形成包含超过检测阈值的被测单元索引的向量或矩阵。

### **输出检测阈值** — 输出检测阈值 off (default) | on

选中此复选框可创建包含检测阈值的输出端口 `Th`。

### **输出估计噪声功率** — 输出估计噪声功率 off (default) | on

选中此复选框可创建包含估计噪声的输出端口 `N`。

### **检测数量来源** — 检测数量来源 `Auto` (default) | `Property`

将检测数量的来源指定为 `Auto` 或 `Property`。当选择 `Auto` 时，报告的检测索引数是具有检测的被测单元总数。如果选择 `Property`，报告的检测数量由 **最大检测数量** 参数的值确定。

#### 依赖关系

要启用此参数，请将 **输出格式** 参数设置为 `Detection index`。

### **最大检测数量** — 要报告的最大检测数量 `1` (default)

将要报告的检测索引最大数量指定为正整数。

#### 依赖关系

要启用此参数，请将 **输出格式** 参数设置为 `Detection index`，并将 **检测数量来源** 参数设置为 `Property`。

## 描述

恒虚警率 (CFAR) 检测器

CFAR Detector 模块实现一维恒虚警率 (CFAR) 检测器。检测处理对输入数据的选定元素（称为单元）执行。当图像单元值超过阈值时，即声明检测。为保持恒虚警率，阈值设置为图像噪声功率的倍数。检测器使用三种单元平均方法之一或有序统计方法，从周围单元估计被测单元 *(CUT)* 的噪声功率。单元平均方法包括单元平均 (CA)、最大单元平均 (GOCA) 或最小单元平均 (SOCA)。

有关 CFAR 检测器的详细信息，请参阅 [1]。

对于每个测试单元，检测器：

1. 根据 CUT 单元周围训练带中的单元值估计噪声统计量。
2. 通过将噪声估计乘以阈值因子来计算阈值。
3. 将 CUT 单元值与阈值进行比较，以确定目标存在还是不存在。如果该值大于阈值，则目标存在。
