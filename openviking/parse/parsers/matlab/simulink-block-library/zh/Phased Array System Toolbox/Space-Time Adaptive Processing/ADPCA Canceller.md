# ADPCA Canceller

## 端口

### 输入

### **X** — 输入信号 *M*×*N*×*P* 复数值矩阵

输入信号，指定为
*M*×*N*×*P*
复数值数组。*M* 是距离样本数，*N* 是通道数，*P* 是脉冲数。

输入矩阵第一维的大小可以变化，以模拟变化的信号长度。例如，在具有可变脉冲重复频率的脉冲波形情况下，可能会发生大小变化。

**数据类型：** `double`
**复数支持：** 是

### **Idx** — 距离单元索引 正整数

用于计算处理权重的距离单元索引。

**示例：** `1`

**数据类型：** `double`

### **PRF** — 脉冲重复频率 正标量

当前脉冲的脉冲重复频率，指定为正标量。

#### 依赖关系

要启用此端口，请将 **将 PRF 指定为** 参数设置为 `Input port`。

**数据类型：** `double`

### **Ang** — 目标方向 `2`×`1` 实数值向量

目标方向，指定为
`2`×`1` 实数值向量。向量形式为
`[AzimuthAngle;ElevationAngle]`。角度单位为度（degrees）。方位角必须介于 –180° 和 180° 之间（含端点），俯仰角必须介于 –90° 和 90° 之间（含端点）。角度相对于阵列的局部坐标系定义。

#### 依赖关系

要启用此端口，请将 **将方向指定为** 参数设置为 `Input port`。

**数据类型：** `double`

### **Dop** — 目标 Doppler 频率 标量

当前脉冲的目标 Doppler 频率，指定为
标量。

#### 依赖关系

当清除 **输出 Doppler 前结果** 复选框且 **将目标 Doppler 指定为** 参数设置为 `Input port` 时，此端口出现。

**数据类型：** `double`
### 输出

### **Y** — 波束形成输出 *M*×1 复数值向量

处理输出，返回为
*M*×*1* 复数值向量。
量 *M* 是输入端口 `X` 中的距离样本数。

**数据类型：** `double`
**复数支持：** 是

### **W** — 处理权重 长度为 *N*\**P* 的复数值向量

处理权重，返回为长度为
*N*\**P* 的复数值向量。量 *N* 是通道数，*P* 是脉冲数。当 **将传感器阵列指定为** 参数设置为 `Partitioned array` 或 `Replicated subarray` 时，*N* 表示子阵数。*L* 是在 `Ang` 输入端口或 **波束形成方向 (deg)** 参数中指定的所需波束形成方向数。每个波束形成方向有一组权重。

#### 依赖关系

要启用此端口，请选中 **启用权重输出** 复选框。

**数据类型：** `double`
**复数支持：** 是

#### 依赖项

要启用此参数，请将 **元素类型** 设置为 `Custom Antenna`。

量 *L* 等于 **工作频率向量 (Hz)** 的长度。

- 如果此参数是 *Q*-by-*P* 矩阵，则同一方向图应用于 **工作频率向量 (Hz)** 参数中指定的 *所有* 频率。

### **MatchArrayNormal** — 将天线元素旋转到阵列法线 `on`（默认）| `off`

选中此复选框可将天线元素方向图旋转以与阵列法线对齐。未选中时，元素方向图不旋转。

当天线用于天线阵列且 **输入方向图坐标系** 参数为 `az-el` 时，选中此复选框会旋转方向图，使元素坐标系的 *x* 轴沿阵列法线指向。不选中则使用未经旋转的元素方向图。

当天线用于天线阵列且 **输入方向图坐标系** 设置为 `phi-theta` 时，选中此复选框会旋转方向图，使元素坐标系的 *z* 轴沿阵列法线指向。

将此参数与 `URA` 和 `UCA` 阵列的 **阵列法线** 参数结合使用。

#### 依赖项

要启用此参数，请将 **元素类型** 设置为 `Custom Antenna`。

极坐标方向图麦克风响应频率，指定为实标量或实值 1-by-*L* 向量。响应频率位于 **工作频率向量 (Hz)** 向量指定的频率范围内。

#### 依赖项

要启用此参数，请将 **元素类型** 设置为 `Custom Microphone`。

### **极坐标方向图角度 (deg)** — 极坐标方向图响应角度 `[-180:180]`（默认）| 实值 -by-*P* 行向量

指定极坐标方向图响应角度，为 1-by-*P* 向量。角度从麦克风的中心拾音轴测量，必须介于 –180° 和 180° 之间（含端点）。

#### 依赖项

要启用此参数，请将 **元素类型** 设置为 `Custom Microphone`。

### **极坐标方向图 (dB)** — 自定义麦克风极坐标响应 `zeros(1,361)`（默认）| 实值 *L*-by-*P* 矩阵

将自定义麦克风元素极坐标方向图的幅度指定为 *L*-by-*P* 矩阵。*L* 是 **极坐标方向图频率 (Hz)** 中指定的频率数。*P* 是 **极坐标方向图角度 (deg)** 中指定的角度数。矩阵的每一行表示在 **极坐标方向图频率 (Hz)** 中指定的对应频率以及 **极坐标方向图角度 (deg)** 中指定的所有角度处测得的极坐标方向图幅度。该方向图在方位平面中测量。在方位平面中，仰角为 0°，中心拾音轴为 0° degrees 方位角和 0° degrees 仰角。极坐标方向图绕中心轴对称。您可以从极坐标方向图构造 3-D 空间中的麦克风响应方向图。

#### 依赖项

要启用此参数，请将 **元素类型** 设置为 `Custom Microphone`。

### 阵列参数

### **将传感器阵列指定为** — 阵列类型 `Array (no subarrays)`（默认）| `MATLAB expression`

直接指定 ULA 传感器阵列，或通过使用 MATLAB 表达式指定。

**类型**

|  |
| --- |
| `Array (no subarrays)` |
| `MATLAB expression` |

### **元素数** — U 中的阵列元素数 `2`（默认）| 大于或等于二的正整数

ULA 阵列的阵列元素数，指定为大于或等于二的整数。

**示例：** `11`

**数据类型：** `double`

### **元素间距** — ULA 元素之间的距离 `0.5`（默认）| 正标量

相邻 ULA 元素之间的距离，指定为正标量。单位为 meters。

**示例：** `1.5`

### **阵列轴** — ULA 的线性轴方向 `y`（默认）| `x` | `z`

ULA 的线性轴方向，指定为 `y`、`x` 或 `z`。所有 ULA 阵列元素在局部阵列坐标系中沿此轴均匀间隔。

#### 依赖项

- 要启用此参数，请将 **几何结构** 设置为 `ULA`。
- 当模块仅支持 ULA 阵列时，也会启用此参数。

### **锥削** — ULA 阵列锥削 `1`（默认）| 复值向量

锥削（也称为 *元素权重*）应用于阵列中的传感器元素。锥削用于修改发射或接收数据的幅度和相位。

将元素锥削指定为复值标量或复值 1-by-*N* 行向量。在此向量中，*N* 表示阵列中的元素数。如果 **锥削** 是标量，则对每个元素应用相同的权重。如果 **锥削** 是向量，则将向量中的权重应用于对应的传感器元素。必须对传感器阵列中的每个元素应用权重。

**示例：** [0.5;1;0.5]

**数据类型：** `double`
**复数支持：** Yes

### **表达式** — 用于创建 Phased Array System Toolbox 阵列 System object 的 MATLAB 表达式

用于创建 ULA 阵列的 MATLAB 表达式，指定为有效的 Phased Array System Toolbox 阵列 System object。

**示例：** `phased.ULA('NumElements',13)`

#### 依赖项

要启用此参数，请将 **将传感器阵列指定为** 设置为 `MATLAB expression`。
