# ULA Beamscan Spectrum

## 端口

### 输入

### **Port 1** — 接收信号 *M*×*N* 复数值矩阵

接收信号，指定为 *M*×*N* 复数值矩阵。量 *M* 是信号中包含的样本值（快照）数，*N* 是阵列中的传感器阵元数。

输入矩阵第一维的大小可以变化，以模拟变化的信号长度。例如，在具有可变脉冲重复频率的脉冲波形情况下，可能发生大小变化。

**数据类型：** `double`
**复数支持：** Yes

### 输出

### **Y** — Beamscan 空间谱 非负实值列向量

Beamscan 空间谱，返回为非负实值列向量，表示估计的 beamscan 空间谱的幅度。每个条目对应由 **扫描角度 (deg)** 参数指定的角度。

**数据类型：** `double`

### **Ang** — 到达方向 非负实值列向量

信号的到达方向，返回为实值行向量。到达角是源方向与阵列轴之间的侧射角。角度单位为度。向量长度为 **信号数量** 参数指定的信号数。如果对象无法识别频谱中的峰值，它将返回 `NaN`。

#### 依赖关系

要启用此输出端口，请选中 **启用 DOA 输出** 复选框。

**数据类型：** `double`

## 参数

### **信号传播速度 (m/s)** — 信号传播速度 `physconst('LightSpeed')` (默认) | 实值正标量

信号传播速度，指定为实值正标量。光速的默认值是 `physconst('LightSpeed')` 返回的值。单位是米每秒。

**示例：** `3e8`

**数据类型：** `double`

### **工作频率 (Hz)** — 系统工作频率 `3e8` (默认) | 正实标量

系统工作频率，指定为正标量。单位是 Hz。

### **移相器中的位数** — 移相器相位量化位数 `0` (默认) | 非负整数

用于量化波束形成器或导向矢量权重的相移分量的位数。将位数指定为非负整数。值为零表示不执行量化。

### **前向-后向平均** — 启用前向-后向平均 off (默认) | on

选中此参数可使用前向-后向平均来估计具有共轭对称阵列流形结构的传感器阵列的协方差矩阵。

### **空间平滑** — 启用空间平滑 `0` (默认) | 非负整数

将空间平滑用于估计协方差矩阵的平均量指定为非负整数。平滑每增加一次，可处理一个额外的相干源，但会将有效阵元数减少一个。此参数的最大值为 *N* – 2，其中 *N* 是 ULA 中的传感器数。

### **扫描角度 (deg)** — 频谱峰值的搜索角度 `-90:90` (默认) | 实值行向量

以度为单位将扫描角度指定为实值行向量。这些角度是阵列侧射角，必须介于 –90° 和 90° 之间（包括端值）。必须按递增顺序指定角度。

### **启用 DOA 输出** — 通过输出端口输出到达方向 off (默认) | on

选中此参数可通过 **Ang** 输出端口输出信号的到达方向 (DOA)。

### **信号数量** — 预期到达信号数 `1` (默认) | 正整数

将 DOA 估计的预期信号数指定为正标量整数。

#### 依赖关系

要启用此参数，请选中 **启用 DOA 输出** 复选框。

**数据类型：** `double`

### **仿真方式** — 模块仿真方法 `Interpreted Execution` (默认) | `Code Generation`

模块仿真，指定为 `Interpreted Execution` 或 `Code Generation`。如果希望模块使用 MATLAB® 解释器，请选择 `Interpreted Execution`。如果希望模块作为编译代码运行，请选择 `Code Generation`。编译代码需要时间编译，但通常运行更快。

在开发和调整模型时，解释执行很有用。模块在 MATLAB 中运行底层 System object™。您可以快速更改和执行模型。当对结果满意时，可以使用 `Code Generation` 运行模块。长时间仿真使用生成的代码比解释执行运行更快。可以重复执行而无需重新编译，但如果更改任何模块参数，则模块会在执行前自动重新编译。

此表显示 **仿真方式** 参数如何影响整体仿真行为。

当 Simulink® 模型处于 `Accelerator` 模式时，使用 **仿真方式** 指定的模块模式会覆盖仿真模式。

#### 传感器阵列选项卡

### **指定传感器阵列方式为** — 指定阵列的方法 `Array (no subarrays)` (默认) | `MATLAB expression`

指定阵列的方法，指定为 `Array (no subarrays)` 或 `MATLAB expression`。

- `Array (no subarrays)` — 使用模块参数指定阵列。
- `MATLAB expression` — 使用 MATLAB 表达式创建阵列。

### **表达式** — 用于创建阵列的 MATLAB 表达式 Phased Array System Toolbox™ 阵列 System object

用于创建阵列的 MATLAB 表达式，指定为有效的 Phased Array System Toolbox 阵列 System object。

**示例：** `phased.URA('Size',[5,3])`

#### 依赖关系

要启用此参数，请将 **指定传感器阵列方式为** 设置为 `MATLAB expression`。

#### 阵元参数

### **阵元类型** — 阵列阵元类型 `Isotropic Antenna` (默认) | `Cosine Antenna` | `Custom Antenna` | `Omni Microphone` | `Custom Microphone`

天线或麦克风类型，指定为以下之一：

- `Isotropic Antenna`
- `Cosine Antenna`
- `Custom Antenna`
- `Omni Microphone`
- `Custom Microphone`

### **工作频率范围 (Hz)** — 天线或麦克风阵元的工作频率范围 `[0,1e20]` (默认) | 实值 1×2 行向量

将天线或麦克风阵元的工作频率范围指定为 `[LowerBound,UpperBound]` 形式的 1×2 行向量。阵元在此频率范围之外没有响应。频率单位是 Hz。

#### 依赖关系

要启用此参数，请将 **阵元类型** 设置为 `Isotropic Antenna`、`Cosine Antenna` 或 `Omni Microphone`。

### **工作频率向量 (Hz)** — 自定义天线或麦克风阵元的工作频率范围 `[0,1e20]` (默认) | 实值行向量

将用于设置天线和麦克风频率响应的频率指定为递增实数值的 1×*L* 行向量。天线或麦克风阵元在此向量最小和最大元素指定的频率范围之外没有响应。频率单位是 Hz。

#### 依赖关系

要启用此参数，请将 **阵元类型** 设置为 `Custom Antenna` 或 `Custom Microphone`。使用 **频率响应 (dB)** 设置这些频率处的响应。

### **对元件背面加障板** — 将 `Isotropic Antenna` 阵元或 `Omni Microphone` 阵元的背面响应设置为零 off (默认) | on

选中此复选框可对元件的背面响应加障板。背面加障板后，所有偏离侧射方向 ±90° 以外的方位角处的响应设置为零。侧射方向定义为 0° 方位角和 0° 俯仰角。

#### 依赖关系

要启用此复选框，请将 **阵元类型** 设置为 `Isotropic Antenna` 或 `Omni Microphone`。

### **余弦方向图指数** — 方位角和俯仰角余弦方向图的指数 `[1.5 1.5]` (默认) | 非负标量 | 由非负值组成的实值 1×2 矩阵

将余弦方向图的指数指定为非负标量或由非负值组成的实值 1×2 矩阵。当 **余弦方向图指数** 是 1×2 向量时，第一个元素是方位方向的指数，第二个元素是俯仰方向的指数。将此参数设置为标量时，方位方向和俯仰方向余弦方向图都升到相同幂次。

#### 依赖关系

要启用此参数，请将 **阵元类型** 设置为 `Cosine Antenna`。

### **频率响应 (dB)** — 天线和麦克风频率响应 `[0,0]` (默认) | 实值行向量

自定义天线或自定义麦克风在 **工作频率向量 (Hz)** 参数定义的频率处的频率响应。**频率响应 (dB)** 的维度必须与 **工作频率向量 (Hz)** 参数指定的向量维度匹配。

#### 依赖关系

要启用此参数，请将 **阵元类型** 设置为 `Custom Antenna` 或 `Custom Microphone`。

### **输入方向图坐标系** — 自定义天线方向图的坐标系 `az-el` (默认) | `phi-theta`

自定义天线方向图的坐标系，指定为 `az-el` 或 `phi-theta`。指定 `az-el` 时，使用 **方位角 (deg)** 和 **俯仰角 (deg)** 参数指定方向图点的坐标。指定 `phi-theta` 时，使用 **Phi 角 (deg)** 和 **Theta 角 (deg)** 参数指定方向图点的坐标。

#### 依赖关系

要启用此参数，请将 **阵元类型** 设置为 `Custom Antenna`。

### **方位角 (deg)** — 天线辐射方向图的方位角 `[-180:180]` (默认) | 实值行向量

将用于计算天线辐射方向图的方位角指定为 1×*P* 行向量。*P* 必须大于 2。方位角必须介于 –180° 和 180° 之间（包括端值），并且严格递增。

#### 依赖关系

要启用此参数，请将 **阵元类型** 参数设置为 `Custom Antenna`，并将 **输入方向图坐标系** 参数设置为 `az-el`。

### **俯仰角 (deg)** — 天线辐射方向图的俯仰角 `[-90:90]` (默认) | 实值行向量

将用于计算辐射方向图的俯仰角指定为 1×*Q* 向量。*Q* 必须大于 2。角度单位为度。俯仰角必须介于 –90° 和 90° 之间（包括端值），并且严格递增。

#### 依赖关系

要启用此参数，请将 **阵元类型** 参数设置为 `Custom Antenna`，并将 **输入方向图坐标系** 参数设置为 `az-el`。

### **Phi 角 (deg)** — 自定义天线辐射方向图的 Phi 角坐标 `0:360` | 实值 1×*P* 行向量

用于指定天线辐射方向图的点的 Phi 角，指定为实值 1×*P* 行向量。*P* 必须大于 2。角度单位为度。Phi 角必须介于 0° 和 360° 之间，并且严格递增。

#### 依赖关系

要启用此参数，请将 **阵元类型** 参数设置为 `Custom Antenna`，并将 **输入方向图坐标系** 参数设置为 `phi-theta`。

### **Theta 角 (deg)** — 自定义天线辐射方向图的 Theta 角坐标 `0:180` | 实值 1×*Q* 行向量

用于指定天线辐射方向图的点的 Theta 角，指定为实值 1×*Q* 行向量。*Q* 必须大于 2。角度单位为度。Theta 角必须介于 0° 和 360° 之间，并且严格递增。

#### 依赖关系

要启用此参数，请将 **阵元类型** 参数设置为 `Custom Antenna`，并将 **输入方向图坐标系** 参数设置为 `phi-theta`。

### **辐射方向图 (dB)** — 自定义天线辐射方向图 `zeros(181,361)` | 复数值矩阵 | 复数值 MATLAB 数组

组合极化天线辐射方向图的幅度，指定为 *Q*×*P* 矩阵或 *Q*×*P*×*L* 数组。*Q* 的值必须等于 **俯仰角 (deg)** 指定的 *Q* 值。*P* 的值必须等于 **方位角 (deg)** 指定的 *P* 值。*L* 的值必须等于 **工作频率向量 (Hz)** 指定的 *L* 值。

#### 依赖关系

要启用此参数，请将 **阵元类型** 设置为 `Custom Antenna`。

### **极坐标方向图频率 (Hz)** — 极坐标方向图麦克风响应频率 1e3 (默认) | 实标量 | 实值 1×*L* 行向量

极坐标方向图麦克风响应频率，指定为实标量或实值 1×*L* 向量。响应频率位于 **工作频率向量 (Hz)** 向量指定的频率范围内。

#### 依赖关系

要启用此参数，请将 **阵元类型** 设置为 `Custom Microphone`。

### **极坐标方向图角度 (deg)** — 极坐标方向图响应角度 `[-180:180]` (默认) | 实值 1×*P* 行向量

将极坐标方向图响应角度指定为 1×*P* 向量。这些角度从麦克风的中心拾取轴测量，必须介于 –180° 和 180° 之间（包括端值）。

#### 依赖关系

要启用此参数，请将 **阵元类型** 设置为 `Custom Microphone`。

### **极坐标方向图 (dB)** — 自定义麦克风极坐标响应 `zeros(1,361)` (默认) | 实值 *L*×*P* 矩阵

将自定义麦克风阵元极坐标方向图的幅度指定为 *L*×*P* 矩阵。*L* 是 **极坐标方向图频率 (Hz)** 中指定的频率数。*P* 是 **极坐标方向图角度 (deg)** 中指定的角度数。矩阵的每一行表示在 **极坐标方向图频率 (Hz)** 中指定的对应频率以及 **极坐标方向图角度 (deg)** 中指定的所有角度处测得的极坐标方向图幅度。方向图在方位平面中测量。在方位平面中，俯仰角为 0°，中心拾取轴为 0° 方位角和 0° 俯仰角。极坐标方向图围绕中心轴对称。您可以根据极坐标方向图构建 3-D 空间中的麦克风响应方向图。

#### 依赖关系

要启用此参数，请将 **阵元类型** 设置为 `Custom Microphone`。

#### 阵列参数

### **阵元数量** — ULA 中的阵列阵元数量 `2` (默认) | 大于或等于二的正整数

ULA 阵列的阵列阵元数量，指定为大于或等于二的整数。

**示例：** `11`

**数据类型：** `double`

### **阵元间距** — ULA 阵元之间的距离 `0.5` (默认) | 正标量

相邻 ULA 阵元之间的距离，指定为正标量。单位是米。

**示例：** `1.5`

### **阵列轴** — ULA 的线性轴方向 `y` (默认) | `x` | `z`

ULA 的线性轴方向，指定为 `y`、`x` 或 `z`。然后，所有 ULA 阵列阵元在局部阵列坐标系中沿此轴均匀间隔。

### **Taper** — 阵列阵元锥削 1（默认） | complex scalar | complex-valued row vector

将阵元锥削指定为 complex-valued scalar 或 complex-valued 1-by-*N* row vector。在此向量中，*N* 表示阵列中的阵元数量。

也称为 *element weights*，锥削会与阵列阵元响应相乘。锥削会修改响应的幅度和相位，以降低旁瓣或控制主响应轴的指向。

如果 **Taper** 是标量，则对每个阵元应用相同权重。如果 **Taper** 是向量，则将向量中的一个权重应用于对应的传感器阵元。权重数量必须与阵列的阵元数量匹配。

**数据类型：** `double`

## 描述

用于 ULA 的 Beamscan 空间谱估计器

ULA Beamscan Spectrum 模块通过使用应用于均匀线阵的窄带常规波束形成器扫描宽边角区域，估计入射窄带信号的空间谱。该模块可选地通过估计频谱峰值来计算指定数量信号的到达方向。
