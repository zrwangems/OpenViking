# Beamscan Spectrum

## 端口

### 输入

### **X** — 接收信号 *M*×*N* 复值矩阵

接收信号，指定为 *M*×*N* 复值矩阵。量 *M* 是信号的长度，即信号中包含的采样值数量。量 *N* 是阵列中传感器元素的数量。

输入矩阵第一个维度的大小可以变化，以模拟信号长度的变化。例如，对于具有可变脉冲重复频率的脉冲波形，可能会发生这种大小变化。

**数据类型：** `double`

### 输出

### **Y** — Beamscan 二维空间谱 非负实值 *P*×*Q* 矩阵

估计的二维空间谱的幅度，以非负实值 *P*×*Q* 矩阵形式返回。每个元素表示估计的 MUSIC 空间谱的幅度。每个元素对应于由 **方位扫描角 (deg)** 和 **仰角扫描角 (deg)** 参数指定的角度。*P* 等于 **方位扫描角 (deg)** 中指定的向量的长度，*Q* 等于 **仰角扫描角 (deg)** 中指定的向量的长度。

**数据类型：** `double`

### **Ang** — 到达方向 非负实值 2×*L* 矩阵

信号的到达方向，以实值 2×*L* 矩阵形式返回。*L* 是由 **信号数量** 参数指定的信号数量。到达方向角由信源相对于阵列局部坐标系的方位角和仰角定义。矩阵的第一行包含方位角，第二行包含仰角。如果对象无法识别空间谱中的峰值，将返回 `NaN`。角度单位为度。

#### 依赖关系

要启用此输出端口，请选中 **启用 DOA 输出** 复选框。

**数据类型：** `double`

## 参数

### **信号传播速度 (m/s)** — 信号传播速度 `physconst('LightSpeed')`（默认值）| 正实数标量

信号传播速度，指定为正实数标量。光速的默认值是 `physconst('LightSpeed')` 返回的值。单位为 m/s。

**示例：** `3e8`

**数据类型：** `double`

### **工作频率 (Hz)** — 系统工作频率 `3e8`（默认值）| 正实数标量

系统工作频率，指定为正标量。单位为 Hz。

### **移相器中的位数** — 相移量化位数 `0`（默认值）| 非负整数

用于量化波束形成器或导向矢量权值中相移分量的位数。将位数指定为非负整数。值为零表示不执行量化。

### **前后向平均** — 启用前后向平均 off（默认值）| on

选择此参数可使用前后向平均来估计具有共轭对称阵列流形结构的传感器阵列的协方差矩阵。

### **方位扫描角 (deg)** — 方位方向上的扫描角 `-180:180`（默认值）| 实值向量

方位方向上的扫描角，指定为实值向量。角度必须介于 –180° 和 180° 之间（含边界）。必须按升序指定角度。单位为度。

**数据类型：** `double`

### **仰角扫描角 (deg)** — 仰角方向上的扫描角 `-90:90`（默认值）| 实值向量

仰角方向上的扫描角，指定为实值向量。角度必须介于 –90° 和 90° 之间（含边界）。必须按升序指定角度。单位为度。

**数据类型：** `double`

### **启用 DOA 输出** — 通过输出端口输出到达方向 off（默认值）| on

选择此参数可通过 **Ang** 输出端口输出信号的到达方向 (DOA)。

### **信号数量** — 预期到达信号数 `1`（默认值）| 正整数

将用于 DOA 估计的预期信号数量指定为正整数标量。

#### 依赖关系

要启用此参数，请选中 **启用 DOA 输出** 复选框。

**数据类型：** `double`

### **仿真方式** — 模块仿真方法 `Interpreted Execution`（默认值）| `Code Generation`

模块仿真方式，指定为 `Interpreted Execution` 或 `Code Generation`。如果希望模块使用 MATLAB® 解释器，请选择 `Interpreted Execution`。如果希望模块作为编译代码运行，请选择 `Code Generation`。编译代码需要编译时间，但通常运行速度更快。

解释执行在开发和调优模型时很有用。模块在 MATLAB 中运行底层 System object™。您可以快速更改和执行模型。对结果满意后，可以使用 `Code Generation` 运行模块。与解释执行相比，使用生成的代码进行长时间仿真时运行速度更快。您无需重新编译即可重复运行，但如果更改任何模块参数，模块会在执行前自动重新编译。

#### 传感器阵列选项卡

### **传感器阵列指定方式** — 指定阵列的方法 `Array (no subarrays)`（默认值）| `MATLAB expression`

指定阵列的方法，指定为 `Array (no subarrays)` 或 `MATLAB expression`。

- `Array (no subarrays)` — 使用模块参数指定阵列。
- `MATLAB expression` — 使用 MATLAB 表达式创建阵列。

### **表达式** — 用于创建阵列的 MATLAB 表达式 Phased Array System Toolbox™ 阵列 System object

用于创建阵列的 MATLAB 表达式，指定为有效的 Phased Array System Toolbox 阵列 System object。

**示例：** `phased.URA('Size',[5,3])`

#### 依赖关系

要启用此参数，请将 **传感器阵列指定方式** 设置为 `MATLAB expression`。

#### 阵列参数

### **几何结构** — 阵列几何结构 `ULA`（默认值）| `URA` | `UCA` | `Conformal Array`

阵列几何结构，指定为以下值之一：

- `ULA` — 均匀线性阵列
- `URA` — 均匀矩形阵列
- `UCA` — 均匀圆形阵列
- `Conformal Array` — 任意元素位置

### **元素数量** — 阵列元素数量 `2`（用于 ULA 阵列）和 `5`（用于 UCA 阵列）（默认值）| 大于或等于 2 的整数

ULA 或 UCA 阵列的阵列元素数量，指定为大于或等于 2 的整数。

#### 依赖关系

要启用此参数，请将 **几何结构** 设置为 `ULA` 或 `UCA`。

### **元素间距 (m)** — 阵列元素之间的间距 `0.5`（用于 ULA 阵列）和 `[0.5,0.5]`（用于 URA 阵列）（默认值）| ULA 或 URA 阵列的正标量 | URA 阵列的由正值组成的二元素向量

相邻阵列元素之间的间距：

- ULA — 将阵列中两个相邻元素之间的间距指定为正标量。
- URA — 将间距指定为正标量或由正值组成的 1×2 向量。如果 **元素间距 (m)** 是标量，则行间距和列间距相等。如果 **元素间距 (m)** 是向量，则该向量的形式为 `[SpacingBetweenArrayRows,SpacingBetweenArrayColumns]`。

#### 依赖关系

要启用此参数，请将 **几何结构** 设置为 `ULA` 或 `URA`。

### **阵列轴** — ULA 的线性轴方向 `y`（默认值）| `x` | `z`

ULA 的线性轴方向，指定为 `y`、`x` 或 `z`。在阵列局部坐标系中，所有 ULA 阵列元素沿此轴均匀分布。

#### 依赖关系

- 要启用此参数，请将 **几何结构** 设置为 `ULA`。
- 当模块仅支持 ULA 阵列时，也会启用此参数。

### **阵列大小** — URA 阵列的维度 `[2,2]`（默认值）| 正整数 | 由正整数组成的 1×2 向量

URA 阵列的维度，指定为正整数或由正整数组成的 1×2 向量。

- 如果 **阵列大小** 是 1×2 向量，则该向量的形式为 `[NumberOfArrayRows,NumberOfArrayColumns]`。
- 如果 **阵列大小** 是整数，则阵列的每行和每列具有相同数量的元素。

对于 URA，阵列元素沿最左侧阵列列从上到下进行索引，然后从左到右依次对后续各列继续索引。在此图中，**阵列大小** 值 `[3,2]` 创建一个三行两列的阵列。

#### 依赖关系

要启用此参数，请将 **几何结构** 设置为 `URA`。

### **元素点阵** — URA 元素位置的点阵 `Rectangular`（默认值）| `Triangular`

URA 元素位置的点阵，指定为 `Rectangular` 或 `Triangular`。

- `Rectangular` — 将所有元素沿行和列方向对齐。
- `Triangular` — 将矩形点阵中偶数行的元素沿行轴正方向移动。位移为沿行维度元素间距的一半。

#### 依赖关系

要启用此参数，请将 **几何结构** 设置为 `URA`。

### **阵列法向** — 阵列法向方向 `x`（用于 URA 阵列）或 `z`（用于 UCA 阵列）（默认值）| `y`

阵列法向方向，指定为 `x`、`y` 或 `z`。

平面阵列的元素位于与所选阵列法向方向正交的平面内。元素视轴方向沿阵列法向方向。

| 阵列法向参数值 | 元素位置和视轴方向 |
| --- | --- |
| `x` | 阵列元素位于 *yz* 平面内。所有元素视轴向量均沿 *x* 轴方向。 |
| `y` | 阵列元素位于 *zx* 平面内。所有元素视轴向量均沿 *y* 轴方向。 |
| `z` | 阵列元素位于 *xy* 平面内。所有元素视轴向量均沿 *z* 轴方向。 |

#### 依赖关系

要启用此参数，请将 **几何结构** 设置为 `URA` 或 `UCA`。

### **UCA 半径 (m)** — UCA 阵列半径 0.5（默认值）| 正标量

UCA 阵列的半径，指定为正标量。

#### 依赖关系

要启用此参数，请将 **几何结构** 设置为 `UCA`。

### **元素位置 (m)** — 共形阵列元素的位置 `[0;0;0]`（默认值）| 实值 3×*N* 矩阵

共形阵列中元素的位置，指定为实值 3×*N* 矩阵，其中 *N* 是共形阵列中的元素数量。此矩阵的每一列表示阵列元素在阵列局部坐标系中的位置 `[x;y;z]`。局部坐标系的原点为 *(0,0,0)*。单位为米。

#### 依赖关系

要启用此参数，请将 **几何结构** 设置为 `Conformal Array`。

**数据类型：** `double`

### **元素法向 (deg)** — 共形阵列元素法向量的方向 `[0;0]` | 2×1 列向量 | 2×*N* 矩阵

共形阵列中元素法向量的方向，指定为 2×1 列向量或 2×*N* 矩阵。*N* 表示阵列中的元素数量。如果参数值是矩阵，则每一列以 `[azimuth;elevation]` 的形式指定相应元素相对于局部坐标系的法向方向。局部坐标系将正 *x* 轴与共形阵列的法向方向对齐。如果参数值是 2×1 列向量，则所有阵列元素使用相同的指向。

您可以使用 **元素位置 (m)** 和 **元素法向 (deg)** 参数来表示元素对之间存在特定变换关系的任意布置。这些变换可以组合平移、方位旋转和仰角旋转。但是，不能使用需要绕法向方向旋转的变换。

要启用此参数，请将 **几何结构** 设置为 `Conformal Array`。

**数据类型：** `double`

### **锥削** — 阵列元素锥削 1（默认值）| 复数标量 | 复值行向量

将元素锥削指定为复值标量或复值 1×*N* 行向量。在此向量中，*N* 表示阵列中的元素数量。

锥削也称为*元素权值*，会与阵列元素响应相乘。锥削会修改响应的幅度和相位，以降低旁瓣或控制主响应轴的方向。

如果 **锥削** 是标量，则对每个元素应用相同的权值。如果 **锥削** 是向量，则将该向量中的权值应用于相应的传感器元素。权值数量必须与阵列的元素数量一致。

**数据类型：** `double`

## 描述

Beamscan 空间谱估计器

Beamscan Spectrum 模块通过使用窄带常规波束形成器扫描一定范围的方位角和仰角，估计入射窄带信号的二维空间谱。该模块还可选择通过定位空间谱的峰值来计算指定数量信号的到达方向。
