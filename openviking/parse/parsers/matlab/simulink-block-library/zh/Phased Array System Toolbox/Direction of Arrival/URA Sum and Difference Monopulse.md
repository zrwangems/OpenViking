# URA Sum and Difference Monopulse

## 端口

**注意**

模块的输入和输出端口对应于底层 System object 的 `step` 方法中描述的输入和输出参数。请参阅本页底部的链接。

| 端口 | 描述 | 支持的数据类型 |
| --- | --- | --- |
| `X` | 输入信号。输入矩阵第一个维度的大小可以变化，以仿真不断变化的信号长度。例如，在具有可变脉冲重复频率的脉冲波形情况下，可能会发生大小变化。 | Double-precision floating point |
| `Steer` | 到达方向的初始估计。 | Double-precision floating point |
| `Ang` | 到达方向的估计。 | Double-precision floating point |

## 参数

**信号传播速度 (m/s)**
:   将信号的传播速度指定为正标量，单位为米/秒。您可以使用函数 `physconst` 指定光速。

**工作频率 (Hz)**
:   将系统的工作频率指定为正标量，单位为赫兹。

**移相器中的位数**
:   用于量化波束形成器权重或导向矢量权重中相移分量的位数。将位数指定为非负整数。值为零表示不执行量化。

**仿真方式**
:   模块仿真方法，指定为 `Interpreted Execution` 或 `Code Generation`。如果希望模块使用 MATLAB® 解释器，请选择 `Interpreted Execution`。如果希望模块作为编译后的代码运行，请选择 `Code Generation`。编译后的代码需要编译时间，但通常运行速度更快。

    在开发和调优模型时，解释执行非常有用。该模块在 MATLAB 中运行底层 System object™。您可以快速更改和执行模型。当您对结果满意时，可以使用 `Code Generation` 运行模块。长时间仿真的运行速度比解释执行时更快。您可以在不重新编译的情况下重复运行。但是，如果更改任何模块参数，模块会在执行前自动重新编译。

    设置此参数时，必须考虑模型的整体仿真模式。下表显示了 **仿真方式** 参数与整体仿真模式的交互方式。

    当 Simulink® 模型处于 `Accelerator` 模式时，使用 **仿真方式** 指定的模块模式会覆盖仿真模式。

    **加速模式**

    |  |  |  |  |
    | --- | --- | --- | --- |
    | 模块仿真 | 仿真行为 | | |
    | `Normal` | `Accelerator` | `Rapid Accelerator` |

### 阵列参数

**传感器阵列指定方式**
:   直接指定 ULA 传感器阵列，或使用 MATLAB 表达式指定。

    **类型**

    |  |
    | --- |
    | `Array (no subarrays)` |
    | `MATLAB expression` |

**阵列大小**
:   将阵列大小指定为正整数或由正整数组成的 1×2 向量。

    - 如果 **阵列大小** 是 1×2 向量，则该向量的形式为 `[NumberOfArrayRows,NumberOfArrayColumns]`。
    - 如果 **阵列大小** 是整数，则阵列的行数和列数相同。

    阵元沿列从上到下进行索引，并从左到右依次继续索引后续各列。在此图中，**阵列大小** 为 `[3,2]` 时，会生成一个三行两列的阵列。

**阵元间距**
:   将阵列的阵元间距指定为 1×2 向量或标量，单位为米。如果 **阵元间距** 是 1×2 向量，则该向量的形式为 `[SpacingBetweenRows,SpacingBetweenColumns]`。有关这些量的讨论，请参阅 `phased.URA`。如果 **阵元间距** 是标量，则行间距和列间距相等。

**阵元栅格**
:   将阵元栅格指定为 `Rectangular` 或 `Triangular`。

    - `Rectangular` — 将所有阵元沿行和列方向对齐。
    - `Triangular` — 将矩形栅格中偶数行的阵元向行轴正方向移动。阵元沿行方向移动半个阵元间距的距离。

**阵列法向**
:   当您将 **几何结构** 设置为 `URA` 或 `UCA` 时，会显示此参数。将 **阵列法向** 指定为 `x`、`y` 或 `z`。所有 URA 和 UCA 阵列的阵元分别放置在阵列坐标系的 *yz*、*zx* 或 *xy* 平面中。

**锥削**
:   锥削（也称为*阵元权重*）应用于阵列中的传感器阵元。锥削用于修改发射或接收数据的幅度和相位。

    将阵元锥削指定为复值标量或复值 *M*×*N* 矩阵。在该矩阵中，*M* 是沿 *z* 轴的阵元数量，*N* 是沿 *y* 轴的阵元数量。*M* 和 *N* 对应于 **阵列大小** 矩阵中的 `[NumberofRows, NumberOfColumns]` 值。如果 `Taper` 是标量，则对每个阵元应用相同的权重。如果 **锥削** 的值为矩阵，则将矩阵中的权重应用于对应的传感器阵元。必须对传感器阵列中的每个阵元应用权重。

**表达式**
:   有效的 MATLAB 表达式，其中包含均匀矩形阵列的构造函数，例如 `phased.URA`。

### 传感器阵列选项卡：阵元参数

**阵元类型**
:   将天线或麦克风类型指定为

    - `Isotropic Antenna`
    - `Cosine Antenna`
    - `Custom Antenna`
    - `Omni Microphone`
    - `Custom Microphone`

**余弦方向图指数**
:   当将**阵元类型**设置为 `Cosine Antenna` 时，会显示此参数。

    将余弦方向图的指数指定为标量或 1-by-2 向量。所有值都必须指定为非负实数。当将**余弦方向图指数**设置为标量时，方位方向余弦方向图和仰角方向余弦方向图均取指定次幂。当将**余弦方向图指数**设置为 1-by-2 向量时，第一个元素是方位方向余弦方向图的指数，第二个元素是仰角方向余弦方向图的指数。

**工作频率范围 (Hz)**
:   当**阵元类型**设置为 `Isotropic Antenna`、`Cosine Antenna` 或 `Omni Microphone` 时，会显示此参数。

    将天线阵元的工作频率范围指定为形如 `[LowerBound,UpperBound]` 的 1-by-2 行向量，以赫兹为单位。天线阵元在指定频率范围之外无响应。

**工作频率向量 (Hz)**
:   当**阵元类型**设置为 `Custom Antenna` 或 `Custom Microphone` 时，会显示此参数。

    将用于设置天线和麦克风频率响应的频率指定为由递增值组成的 1-by-*L* 行向量，单位为 Hz。使用**频率响应 (dB)**设置频率响应。天线或麦克风阵元在由**工作频率向量 (Hz)**的最小元素和最大元素指定的频率范围之外无响应。

**频率响应 (dB)**
:   当**阵元类型**设置为 `Custom Antenna` 或 `Custom Microphone` 时，会显示此参数。

    对于由**工作频率向量 (Hz)**定义的频率，将此参数指定为天线或麦克风的频率响应，以分贝为单位。将**频率响应 (dB)**指定为 1-by-*L* 向量，其维度与**工作频率向量 (Hz)**中指定的向量相匹配。

**输入方向图坐标系**
:   自定义天线方向图的坐标系，指定为 `az-el` 或 `phi-theta`。当指定 `az-el` 时，使用**方位角 (deg)**和**仰角 (deg)**参数指定方向图点的坐标。当指定 `phi-theta` 时，使用**Phi 角 (deg)**和**Theta 角 (deg)**参数指定方向图点的坐标。

**方位角 (deg)**
:   当**阵元类型**设置为 `Custom Antenna` 且**输入方向图坐标系**参数设置为 `az-el` 时，会显示此参数。

    将用于计算天线辐射方向图的方位角指定为 1-by-*P* 行向量。*P* 必须大于 2。角度单位为度。方位角必须介于 –180° 和 180° 之间，并严格递增。

**仰角 (deg)**
:   当**阵元类型**设置为 `Custom Antenna` 且**输入方向图坐标系**参数设置为 `az-el` 时，会显示此参数。

    将用于计算辐射方向图的仰角指定为 1-by-*Q* 向量。*Q* 必须大于 2。角度单位为度。仰角必须介于 –90° 和 90° 之间，并严格递增。

**Phi 角 (deg)**
:   当**阵元类型**设置为 `Custom Antenna` 且**输入方向图坐标系**参数设置为 `phi-theta` 时，会显示此参数。

    将用于指定天线辐射方向图的各点的 Phi 角指定为 1-by-*P* 行向量。*P* 必须大于 2。角度单位为度。Phi 角必须介于 0° 和 360° 之间，并严格递增。

**Theta 角 (deg)**
:   当**阵元类型**设置为 `Custom Antenna` 且**输入方向图坐标系**参数设置为 `phi-theta` 时，会显示此参数。

    将用于指定天线辐射方向图的各点的 Theta 角指定为 1-by-*Q* 行向量。*Q* 必须大于 2。角度单位为度。Theta 角必须介于 0° 和 180° 之间，并严格递增。

**幅度方向图 (dB)**
:   当**阵元类型**设置为 `Custom Antenna` 时，会显示此参数。

    组合天线辐射方向图的幅度，指定为 *Q*-by-*P* 矩阵或 *Q*-by-*P*-by-*L* 数组。

    - 当**输入方向图坐标系**参数设置为 `az-el` 时，*Q* 等于**仰角 (deg)**参数所指定向量的长度，*P* 等于**方位角 (deg)**参数所指定向量的长度。
    - 当**输入方向图坐标系**参数设置为 `phi-theta` 时，*Q* 等于**Theta 角 (deg)**参数所指定向量的长度，*P* 等于**Phi 角 (deg)**参数所指定向量的长度。

    *L* 等于**工作频率向量 (Hz)**的长度。

    - 如果此参数为 *Q*-by-*P* 矩阵，则将相同方向图应用于**工作频率向量 (Hz)**参数中指定的*所有*频率。
    - 如果该值为 *Q*-by-*P*-by-*L* 数组，则数组的每个 *Q*-by-*P* 页为**工作频率向量 (Hz)**参数中指定的*相应*频率指定一个方向图。

**相位方向图 (dB)**
:   当**阵元类型**设置为 `Custom Antenna` 时，会显示此参数。

    组合天线辐射方向图的相位，指定为 *Q*-by-*P* 矩阵或 *Q*-by-*P*-by-*L* 数组。

    - 当**输入方向图坐标系**参数设置为 `az-el` 时，*Q* 等于**仰角 (deg)**参数所指定向量的长度，*P* 等于**方位角 (deg)**参数所指定向量的长度。
    - 当**输入方向图坐标系**参数设置为 `phi-theta` 时，*Q* 等于**Theta 角 (deg)**参数所指定向量的长度，*P* 等于**Phi 角 (deg)**参数所指定向量的长度。

    *L* 等于**工作频率向量 (Hz)**的长度。

    - 如果此参数为 *Q*-by-*P* 矩阵，则将相同方向图应用于**工作频率向量 (Hz)**参数中指定的*所有*频率。
    - 如果该值为 *Q*-by-*P*-by-*L* 数组，则数组的每个 *Q*-by-*P* 页为**工作频率向量 (Hz)**参数中指定的*相应*频率指定一个方向图。

    - 如果此参数为 *Q*-by-*P* 矩阵，则将相同方向图应用于**工作频率向量 (Hz)**参数中指定的*所有*频率。
    - 如果该值为 *Q*-by-*P*-by-*L* 数组，则数组的每个 *Q*-by-*P* 页为**工作频率向量 (Hz)**参数中指定的*相应*频率指定一个方向图。

**MatchArrayNormal**
:   当**阵元类型**设置为 `Custom Antenna` 时，会显示此参数。

    选中此复选框可旋转天线阵元方向图，使其与阵列法线对齐。未选中时，不旋转阵元方向图。

    当天线用于天线阵列且**输入方向图坐标系**参数为 `az-el` 时，选中此复选框会旋转方向图，使阵元坐标系的 *x* 轴指向阵列法线方向。未选中时，使用未经旋转的阵元方向图。

    当天线用于天线阵列且**输入方向图坐标系**设置为 `phi-theta` 时，选中此复选框会旋转方向图，使阵元坐标系的 *z* 轴指向阵列法线方向。

    将此参数与 `URA` 和 `UCA` 阵列的**阵列法线**参数结合使用。

**极坐标方向图频率 (Hz)**
:   当**阵元类型**设置为 `Custom Microphone` 时，会显示此参数。

    将极坐标方向图的测量频率指定为 1-by-*M* 向量。测量频率位于**工作频率向量 (Hz)**参数指定的频率范围内。频率单位为 Hz。

**极坐标方向图角度 (deg)**
:   当**阵元类型**设置为 `Custom Microphone` 时，会显示此参数。

    将极坐标方向图的测量角度指定为 1-by-*N* 向量。角度从麦克风的中心拾音轴开始测量，且必须介于 –180° 和 180° 之间（含端点）。

**极坐标方向图 (dB)**
:   当**阵元类型**设置为 `Custom Microphone` 时，会显示此参数。

    将麦克风阵元极坐标方向图的幅度指定为 *M*-by-*N* 矩阵。*M* 是**极坐标方向图频率 (Hz)**中指定的测量频率数量。*N* 是**极坐标方向图角度 (deg)**中指定的测量角度数量。矩阵的每一行表示在**极坐标方向图频率 (Hz)**中指定的相应频率以及**极坐标方向图角度 (deg)**中指定的所有角度下测得的极坐标方向图幅度。假设方向图是在方位平面内测量的。在方位平面内，仰角为 0°，中心拾音轴位于方位角 0°、仰角 0° 方向。假设极坐标方向图绕中心轴对称。可以根据极坐标方向图构建麦克风在 3-D 空间中的响应方向图。

**在阵元背面加挡板**
:   仅当**阵元类型**参数设置为 `Isotropic Antenna` 或 `Omni Microphone` 时，才会显示此复选框。

    选中此复选框可在天线阵元背面加挡板。在这种情况下，对于相对于*宽边*方向超出 ±90° 的所有方位角，天线响应均设置为零。将宽边方向定义为方位角 0°、仰角 0°。

## 描述

用于 URA 的和差单脉冲

URA Sum-and-Difference Monopulse 模块基于初始估计，采用和差单脉冲算法，估计入射到均匀矩形阵列 (URA) 的窄带信号的到达方向。该模块通过对和导向矢量的后半部分进行相位反转，获得差导向矢量。
