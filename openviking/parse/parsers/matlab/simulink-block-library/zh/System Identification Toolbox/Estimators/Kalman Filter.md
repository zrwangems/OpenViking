# Kalman Filter

## 端口

### 输入

### **u** — 已知输入 标量 | 向量

已知输入 `u(t)` 或 `u[k]`。

#### 依赖关系

要启用此端口，请选择 **添加输入端口 u** 参数。此参数默认选中。

### **y** — 测量输出 标量 | 向量

用于更新估计状态的测量输出 `y[n]`。

### **A** — 状态矩阵 实矩阵

*n*-by-*n* 状态（或系统）矩阵。

#### 依赖关系

要启用此端口，请将 **模型来源** 参数设置为 **Input Port**。

### **B** — 输入矩阵 实矩阵

*n*-by-*p* 输入矩阵。

#### 依赖关系

要启用此端口，请将 **模型来源** 参数设置为 **Input Port** 并选择 **添加输入端口 u** 参数。

### **C** — 输出矩阵 实矩阵

*q*-by-*p* 输出矩阵。

#### 依赖关系

要启用此端口，请将 **模型来源** 参数设置为 **Input Port**。

### **D** — 直通矩阵 实矩阵

*q*-by-*p* 直通（或前馈）矩阵。在系统模型没有直接直通的情况下，**D** 是零矩阵。

#### 依赖关系

要启用此端口，请将 **模型来源** 参数设置为 **Input Port** 并选择 **添加输入端口 u** 参数。

### **G** — 测量输出 实矩阵

状态空间方程中的噪声变换。

#### 依赖关系

要启用此端口，请选择 **使用 G 和 H 矩阵（默认 G=I 和 H=0）** 参数。

### **H** — 测量输出 实矩阵

状态空间方程中的噪声变换。

#### 依赖关系

要启用此端口，请选择 **使用 G 和 H 矩阵（默认 G=I 和 H=0）** 参数。

### **Q** — 过程噪声协方差矩阵 标量 | 向量 | 矩阵

过程噪声协方差矩阵，指定为以下之一：

- 实数非负标量。**Q** 是一个 *Nw*-by-*Nw* 对角矩阵，标量在对角线上。*Nw* 是模型中过程噪声输入的数量。
- 实数非负标量向量。**Q** 是一个 *Nw*-by-*Nw* 对角矩阵，向量的元素位于 **Q** 的对角线上。
- *Nw*-by-*Nw* 半正定矩阵。

#### 依赖关系

要启用此端口，请取消选择 **时不变 Q** 参数。

### **R** — 测量噪声协方差矩阵 标量 | 向量 | 矩阵

测量噪声协方差矩阵，指定为以下之一：

- 实数正标量。**R** 是一个 *Ny*-by-*Ny* 对角矩阵，标量在对角线上。*Ny* 是模型中测量输出的数量。
- 实数正标量向量。**R** 是一个 *Ny*-by-*Ny* 对角矩阵，向量的元素位于 **R** 的对角线上。
- *Ny*-by-*Ny* 正定矩阵。

#### 依赖关系

要启用此端口，请取消选择 **时不变 R** 参数。

### **N** — 过程噪声和测量噪声互协方差矩阵 标量 | 向量 | 矩阵

过程噪声和测量噪声互协方差矩阵，指定为 *Nw*-by-*Ny* 矩阵。矩阵 [Q N; NT R] 必须为正定。

#### 依赖关系

要启用此端口，请取消选择 **时不变 N** 参数。

### **P0** — 初始状态估计误差协方差 标量 | 向量 | 矩阵

初始时刻的 **P** 矩阵。

#### 依赖关系

要启用此端口，请将 **模型来源** 参数设置为 **Input Port** 并将 **来源** 参数设置为 **Input Port**。

### **X0** — 初始状态估计 标量 | 向量

初始时刻的估计状态。

#### 依赖关系

要启用此端口，请将 **来源** 参数设置为 **Input Port**。

### **Enable** — 用于启用测量更新的控制信号 标量

此端口控制测量更新并接受标量信号。

#### 依赖关系

要启用此端口，请选择 **添加输入端口 Enable 以控制测量更新** 参数。

### **Reset** — 用于重置状态估计的控制信号 标量

用于使用指定初始值重置估计状态和参数协方差矩阵的控制信号。有关何时触发重置的更多信息，请参阅外部重置。

#### 依赖关系

要启用此端口，请将 **外部重置** 参数设置为 **None** 以外的任何值。

### 输出

### **xhat** — 估计状态 标量 | 向量

线性系统的估计状态。

### **yhat** — 估计输出 标量 | 向量

线性系统的估计输出。

#### 依赖关系

要启用此端口，请选择 **输出估计的模型输出 y** 参数。

### **Z** — 状态估计误差协方差矩阵

将 **Z** 输出端口添加到模块。

要启用此端口，请选择 **输出状态估计误差协方差 Z** 参数。

#### 依赖关系

要启用此端口，请将 **时域** 参数设置为 **Discrete-Time** 并选择 **使用当前测量 y[n] 改进 xhat[n]** 参数。

### **P** — 状态估计误差协方差矩阵

将 **P** 输出端口添加到模块。

要启用此端口，请选择 **输出状态估计误差协方差 P** 参数。

#### 依赖关系

要启用此端口，请将 **时域** 参数设置为 **Continuous-Time**，或将 **时域** 参数设置为 **Discrete-Time** 并取消选择 **使用当前测量 y[n] 改进 xhat[n]** 参数。

**注意**

- 除 **Enable** 和 **Reset** 之外的所有输入端口必须具有相同的数据类型（single 或 double）。
- **Enable** 和 **Reset** 端口支持 `single`、`double`、`int8`、`uint8`、`int16`、`uint16`、`int32`、`uint32` 和 boolean 数据类型。

## 参数

### 滤波器设置

### **时域** — 指定估计连续时间状态还是离散时间状态 `Discrete-Time`（默认） | `Continuous-Time`

- `Discrete-Time`（默认）— 模块估计离散时间状态。
- `Continuous-Time` — 模块估计连续时间状态。

  当 Kalman Filter 模块处于具有同步状态控制的模型中（请参阅 State Control (HDL Coder) 模块）时，不能选择 **Continuous-Time**。

#### 程序化使用

|  |
| --- |
| **模块参数：** `TimeDomain` |
| **类型：** string, character vector |
| **值：** `"Discrete-Time"` | `"Continuous-Time"` |
| **默认值：** `"Discrete-Time"` |

### **使用当前测量 y[n] 改进 xhat[n]** — 使用测量输出更新输出状态估计 `on`（默认） | `off`

使用离散时间 Kalman 滤波器的当前估计器变体。未选择此参数时，使用延迟估计器（变体）。

此参数仅在 **时域** 为 **Discrete-Time** 时可用。

#### 程序化使用

|  |
| --- |
| **模块参数：** `UseCurrentEstimator` |
| **类型：** string, character vector |
| **值：** `"off"` | `"on"` |
| **默认值：** `"on"` |

### **采样时间** — 模块采样时间 `-1`（默认） | `非负标量`

模块采样时间，指定为 `-1` 或正标量。

默认值为 `-1`，这意味着模块根据模型上下文中模块的上下文继承其采样时间。所有模块输入端口必须具有相同的采样时间。

#### 依赖关系

此参数仅在 **时域** 为 **Discrete-Time** 且 **模型来源** 为 **Individual A, B, C, D matrices** 或 **Input port** 时可用。当 **模型来源** 为 **LTI State-Space Variable** 时，模块从 LTI 状态空间变量获取其采样时间。

#### 程序化使用

|  |
| --- |
| **模块参数：** `Ts` |
| **类型：** string, character vector |
| **值：** `"-1"` | scalar |
| **默认值：** `"-1"` |

### 模型参数

#### 系统模型

### **模型来源** — 指定如何将 A、B、C、D 矩阵提供给模块 `LTI State-Space Variable`（默认） | `Individual A, B, C, D matrices` | `Input port`

- `LTI State-Space Variable` — 使用 **Variable** 中指定的模型。默认值为 `ss(0.95,1,1,0)`。模型的采样时间必须与 **时域** 参数匹配；也就是说，如果 **时域** 为离散时间，则模型必须是离散时间。
- `Individual A, B, C, D matrices` — 在模块参数中指定 **A**、**B**、**C** 和 **D**。
- `Input port` — 将 **A**、**B**、**C**、**D** 矩阵指定为 Kalman Filter 模块的输入信号。如果选择此选项，模块将包含额外的输入端口 **A**、**B**、**C**、**D**。您还必须在模块参数中指定 **Number of states**、**Number of inputs** 和 **Number of outputs**。

#### 程序化使用

|  |
| --- |
| **模块参数：** `ModelSource` |
| **类型：** string, character vector |
| **值：** `"LTI State-Space Variable"` | `"Individual A, B, C, D matrices"` | `"Input port"` |
| **默认值：** `"LTI State-Space Variable"` |

#### 噪声特性

## 描述

估计离散时间或连续时间线性系统的状态

使用 Kalman Filter 模块，根据过程和测量噪声协方差数据估计状态空间被控对象模型的状态。状态空间模型可以是时变的。如果状态空间模型和噪声协方差矩阵全部为时不变，则使用稳态 Kalman 滤波器实现；否则使用时变 Kalman 滤波器。

Kalman 滤波器为连续时间估计和离散时间估计中的连续或离散估计问题提供最优解。

Kalman Filter 模块与 `kalman` (Control System Toolbox) 命令在以下方面不同：

- 当您调用 `kalman(sys,...)` 时，它假设
  `sys` 包含 `G` 和
  `H` 矩阵。具体而言，`sys.B` 的
  形式为 `[B G]`，`sys.D` 的形式为
  `[D H]`。当您向
  Kalman Filter 模块提供 LTI 变量时，它不会假设所提供的 LTI 变量
  包含 `G` 和 `H`。它们是
  可选且独立的。
- 由 `kalman` 命令创建的滤波器默认
  输出 `[yhat;xhat]`。该模块默认仅输出
  `xhat`。
- `Kalman` 命令可以为离散时间系统输出 `P`
  和 `Z` 协方差矩阵两者。对于此类系统，该
  模块只能输出 `P` 或 `Z`。
