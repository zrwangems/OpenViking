# PMSM Rs Estimator

## 端口

### 输入

### **Iabc** — 三相电流响应 矢量

电流传感器测量的电机三相电流响应（以安培为单位）。

**注意**

提供 *c* 相电流输入是可选的。如果不提供 *c* 相电流输入，模块功能不会受到影响。

**数据类型:** `single`

### **Vdc** — DC 母线电压 标量

提供给逆变器的 DC 总线电压（以伏特为单位）。

**数据类型:** `single`

### **StartStop** — 用于 *Rs* 估计的控制信号 逻辑值

用于启动或停止 *Rs* 估计的信号：

- `1`（脉冲的上升沿）- 此信号会启动 *Rs* 估计过程。
- `0`（脉冲的下降沿）- 此信号会立即停止 *Rs* 估计过程。如果在估计过程完成前突然中断，该模块不会计算或输出 *Rs* 值。

**数据类型:** `Boolean`

### 输出

### **Vabc** — *a*、*b* 和 *c* 轴定子参考电压分量 矢量

沿 *abc* 参考系的 *a*、*b* 和 *c* 轴的定子参考电压分量。每个电压分量的范围在 `-1` 到 `1` 之间。

**数据类型:** `single`

### **Rs** — 估计定子电阻 标量

估计的 PMSM 的定子电阻（以 ohm 为单位）。

**数据类型:** `single`

## 参数

### **最大电流限值(A)** — 测试时允许的最大电流 `15` (默认) | `scalar`

测试期间允许的最大电流（安培）。

### **注入电压斜升步长(标幺)** — 注入电压上升过程中的步长 `0.0001` (默认) | `scalar`

注入电压上升过程中的步长（采用标幺单位）。

### **最大电压斜升时间限值(秒)** — 最大电压斜升持续时间 `0.25` (默认) | `scalar`

注入电压斜升的最大允许持续时间（以秒为单位）。

### **每次电压注入的电压和电流采样数** — 用于估算 Rs 的电压和电流采样数 `1000` (默认) | `scalar`

每次电压注入用于估算 Rs 的电压和电流采样数。

### **电压注入之间的驻留时间(秒)** — 电压注入之间的等待时间 `0.25` (默认) | `scalar`

连续电压注入之间的等待时间（以秒为单位）。

### **相电阻不平衡判断阈值(0,1)** — 确定相间电阻不平衡的阈值 `0.2` (默认) | `scalar`

阈值（指定为介于 `0` 到 `1` 之间的值），用于判定相间电阻是否失衡。

## 描述

估计永磁同步电机 (PMSM) 的定子电阻 ( R s )

PMSM Rs Estimator 模块使用相电流、穿过电机的 DC 电压和测试配置元素来估计 PMSM 的定子电阻。

该模块为每个相注入两个电压 *V1* 和 *V2*，并测量相应的电流响应 *I1* 和 *I2*，从而估算每相电阻。随后通过计算三相电阻的平均值来估算电机电阻。
