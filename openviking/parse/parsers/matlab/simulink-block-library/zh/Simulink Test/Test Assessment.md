## 描述

评估并验证被测系统的行为

以表格化的步骤序列定义测试评估。与 Test Sequence 模块类似，Test Assessment 模块使用 MATLAB® 作为动作语言。

双击 Test Assessment 模块以打开 Test Sequence Editor。默认情况下，Test Assessment 模块包含一个测试步骤 Run，配置为 When 分解序列。要将转换类型更改为标准转换，请右键单击顶层步骤并清除 **When decomposition**。有关详细信息，请参阅 Test Sequence Editor。
