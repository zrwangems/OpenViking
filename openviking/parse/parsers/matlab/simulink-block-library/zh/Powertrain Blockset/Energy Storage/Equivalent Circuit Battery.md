# Equivalent Circuit Battery

## 端口

### 输入

### **CapInit** — 电池容量 `scalar`

额定电池容量（在标称温度下），
*Capbatt*，单位为 Ah。

#### 依赖项

要创建此端口，请为 **初始电池容量** 参数选择 `External
Input`。

### **BattCurr** — 电池网络电流 `scalar`

从电池网络流出的合并电流，
*Iin*，单位为 A。

### **BattTemp** — 电池温度 `scalar`

电池温度，*T*，单位为 K。

### 输出

### **Info** — 总线信号 bus

包含这些模块计算的总线信号。

| 信号 | | | 描述 | 变量 | 单位 |
| --- | --- | --- | --- | --- | --- |
| `BattCurr` | | | 从电池网络流出的合并电流 | *Ibatt* | A |
| `BattAmpHr` | | | 电池能量 | *LdAmpHr* | A\*h |
| `BattSoc` | | | 荷电状态容量 | *SOC* | NA |
| `BattVolt` | | | 电池网络的合并电压 | *Vout* | V |
| `BattPwr` | | | 电池功率 | *Pbatt* | W |
| `PwrInfo` | `PwrTrnsfrd` | `PwrLdBatt` | 电池网络功率 | *PLdBatt* | W |
| `PwrNotTrnsfrd` | `PwrLossBatt` | 电池网络功率损耗 | *PLossBatt* | W |
| `PwrStored` | `PwrStoredBatt` | 电池网络存储功率 | *PStoredBatt* | W |
| `HystState` | | | 迟滞状态变量 | *Hstate* | 1 |
| `HystVolt` | | | 迟滞电压 | *Vhyst* | V |
| `EntropicPwr` | | | 熵可逆损耗 | *Pentropic* | W |

### **BattVolt** — 电池输出电压 `scalar`

电池网络的合并电压，*Vout*，
单位为 V。

### **包含迟滞** — 添加迟滞电压 `off` (default) | `on`

选择此参数可添加迟滞电压。

迟滞电压在电池电流从充电变为放电时，为非线性的
电压偏移添加状态估计器。要计算带迟滞的
电池网络合并电压，请选择 **包含
迟滞**。该模块使用以下方程。

Hstate=∫(−Hstate•abs(Ibatt)−Ibatt)•HystRateCbattVHyst=Hstate•MaxHystVolt−InstHystVolt•sign(Ibatt)VT=VHyst+Em−IbattRo−∑1nVn
