# IM Controller

## 端口

### 输入

### **SpdReq** — 转子机械速度命令 `scalar`

转子机械速度命令，*ω\*m*，单位为 rad/s。

#### 依赖关系

要创建此端口，请为 **Control Type** 参数选择 `Speed Control`。

### **TrqCmd** — 转矩命令 `scalar`

转矩命令，*T\**，单位为 N·m。

#### 依赖关系

要创建此端口，请为 **Control Type** 参数选择 `Torque Control`。

### **BusVolt** — 直流母线电压 `scalar`

直流母线电压 *vbus*，单位为 V。

### **PhaseCurrA** — 电流 `scalar`

定子电流 a 相，*ia*，单位为 A。

### **PhaseCurrB** — 电流 `scalar`

定子电流 b 相，*ib*，单位为 A。

### **SpdFdbk** — 转子机械速度 `scalar`

转子机械速度，*ωm*，单位为 rad/s。
### 输出

### **Info** — Bus signal bus

包含这些模块计算的 Bus signal。

| 信号 | 描述 | 单位 |
| --- | --- | --- |
| `SrcPwr` | 源功率 | W |
| `LdPwr` | 负载功率 | W |
| `PwrLoss` | 功率损耗 | W |
| `MtrTrqEst` | 估计的电机转矩 | N·m |

### **BusCurr** — 母线电流 `scalar`

估计的直流母线电流，*ibus*，单位为 A。

### **PhaseVolt** — 定子端电压 `array`

定子端电压，*Va*、*Vb* 和 *Vc*，单位为 V。

## 描述

用于感应电机的基于内部转矩的磁场定向控制器，带可选外环速度控制器

IM Controller 模块实现用于感应电机 (IM) 的基于内部转矩的磁场定向控制器，并带有可选外环速度控制器。转矩控制实现控制电机磁通的策略。您可以指定速度控制或转矩控制。

IM Controller 实现速度控制、转矩确定、调节器、变换和电机的方程。

### 速度控制器

要实现速度控制器，请选择 **Control Type** 参数 `Speed Control`。如果选择 **Control Type** 参数 `Torque Control`，该模块不实现速度控制器。

速度控制器通过实现状态滤波器并计算前馈和反馈命令来确定转矩命令。如果不实现速度控制器，请向 IM Controller 模块输入转矩命令。

**状态滤波器**

状态滤波器是一个低通滤波器，它基于速度命令生成加速度命令。在 **Speed Controller** 选项卡上：

- 要使速度命令滞后时间可忽略，请指定 **Bandwidth of the state filter** 参数。
- 要基于状态滤波器带宽计算 **Speed regulation time constant, Ksf** 增益，请选择 **Calculate Speed Regulator Gains**。

特征方程的离散形式为：

z+KsfTsm−1

滤波器使用以下方程计算增益。

Ksf=1−exp(−Tsm2πEVsf)Tsm

该方程使用以下变量。

|  |  |
| --- | --- |
| *EVsf* | 速度命令滤波器带宽 |
| *Tsm* | 运动控制器采样时间 |
| *Ksf* | 速度调节器时间常数 |

**状态反馈**

为生成状态反馈转矩，该模块使用来自状态滤波器的滤波后速度误差信号。反馈转矩计算还需要速度调节器增益。

在 **Speed Controller** 选项卡上，选择 **Calculate Speed Regulator Gains** 以计算：

- **Proportional gain, ba**
- **Angular gain, Ksa**
- **Rotational gain, Kisa**

对于增益计算，该模块使用 **Motor Parameter** 选项卡上 **Physical inertia, viscous damping, static friction** 参数值中的惯量。

### 电气损耗

要指定电气损耗，请在 **Electrical Losses** 选项卡上，为 **Parameterize losses by** 选择以下选项之一。

| 设置 | 模块实现 |
| --- | --- |
| `Single efficiency measurement` | 使用逆变器效率常数值计算电气损耗。 |
| `Tabulated loss data` | 电气损耗作为电机速度和负载转矩的函数计算。 |
| `Tabulated efficiency data` | 使用作为电机速度和负载转矩函数的逆变器效率计算电气损耗。    - 将您提供的效率值转换为损耗，并使用表格化损耗进行仿真。 - 忽略您为零速度或零转矩提供的效率值。当转矩或速度为零时，假设损耗为零。 - 使用线性插值确定损耗。根据需要为低速和低转矩提供表格化数据，以获得低功率条件下所需的精度水平。 - 不对超出表范围的速度和转矩幅值外推损耗值。 |

最佳实践是使用 `Tabulated loss data` 而不是 `Tabulated efficiency data`：

- 对于零速度或零转矩，效率变得定义不清。
- 您可以考虑零速度或转矩时仍然存在的固定损耗。
