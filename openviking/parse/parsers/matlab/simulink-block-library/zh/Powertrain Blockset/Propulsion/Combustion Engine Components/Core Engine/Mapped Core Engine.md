# Mapped Core Engine

## 端口

### 输入

### ***`<TrqCmd>`*** — 发动机负载 `TrqCmd`（默认）

发动机负载，*L*。发动机负载示例包括：

- 指令扭矩

- 发动机气缸中的指令指示平均有效压力 (IMEP)

- 归一化气缸空气质量

- 喷射燃料质量

#### 依赖关系

要指定发动机负载端口名称，请在 **配置** 选项卡上的 **负载输入端口名称** 参数字段中输入名称。

### ***`<EngSpd>`*** — 发动机转速 `EngSpd`（默认）

发动机转速，*N*。

#### 依赖关系

要指定发动机负载端口名称，请在 **配置** 选项卡上的 **转速输入端口名称** 参数字段中输入名称。

### ***`<EngTemp>`*** — 发动机温度 `EngTemp`（默认）

发动机温度，*T*。

#### 依赖关系

要创建发动机温度输入端口名称，请选择 **输入发动机温度** 参数字段。

要指定发动机负载端口名称，请在 **配置** 选项卡上的 **温度输入端口名称** 参数字段中输入名称。

## 描述

使用查找表的稳态核心发动机模型

Mapped Core Engine 模块使用功率、空气质量流量、燃料流量、排气温度、效率和排放性能查找表实现稳态核心发动机模型。您可以将该模块用于：

- 硬件在环 (HIL) 发动机控制设计。
- 车辆级燃油经济性和性能仿真。

该模块允许您为这些发动机特性指定查找表。查找表是发动机负载 *L* 和发动机转速 *N* 的函数。如果您选择 **输入发动机温度**，则查找表也是发动机温度 *T* 的函数。

- 功率
- 空气
- 燃料
- 温度
- 效率
- 排放

  - 碳氢化合物 (HC)
  - 一氧化碳 (CO)
  - 一氧化氮和二氧化氮 (NOx)
  - 二氧化碳 (CO2)
  - 颗粒物 (PM) 排放

为限制 Mapped Core Engine 模块输出，该模块不会外插查找表数据。
