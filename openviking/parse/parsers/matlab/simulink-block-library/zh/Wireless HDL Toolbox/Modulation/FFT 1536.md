# FFT 1536

## 端口

### 输入

### **data** — 实数或复数值的输入数据标量

输入数据，指定为实数或复数值的标量。

仿真支持 `double` 和 `single` 数据类型，但 HDL 代码生成不支持。

输入字长中提供的小数位数越多，输出中获得的精度越高。

**数据类型：** `double` | `single` | `int8` | `int16` | `int32` | `fixed point`
**复数支持：** 是

### **valid** — 指示有效输入数据标量

指示输入数据是否有效。当输入 **valid** 为 `1`（true）时，模块捕获输入 **data** 端口上的值。当输入 **valid** 为 `0`（false）时，模块忽略输入 **data** 采样。

**数据类型：** `Boolean`

### **reset** — 复位控制信号标量

当该值为 `1`（true）时，模块停止当前计算并清除所有内部状态。

#### 依赖关系

要启用此端口，请选择 **Enable reset input port** 参数。

**数据类型：** `Boolean`
### 输出

### **data** — 实数或复数值的频率通道输出数据标量

频率通道输出数据，以实数或复数值的标量形式返回。

当输入为 `fixed point` 数据类型时，输出数据类型与输入数据类型相同。当输入为整数类型时，输出数据类型为 `fixed point` 类型。

**数据类型：** `double` | `single` | `int8` | `int16` | `int32` | `fixed point`
**复数支持：** 是

### **ctrl** — 伴随样本流的控制信号 `samplecontrol` 总线

伴随样本流的控制信号，以 `samplecontrol` 总线形式返回。该总线包含 `start`、`end` 和 `valid` 控制信号，用于指示帧的边界和样本的有效性。

- `start` — 指示输出帧的起始
- `end` — 指示输出帧的结束
- `valid` — 指示输出 **data** 端口上的数据有效

有关更多详细信息，请参阅 Sample Control Bus。

**数据类型：** `bus`

## 参数

### 主

### **Complex multiplication** — HDL 实现 `Use 3 multipliers and 5 adders`（默认）| `Use 4 multipliers and 2 adders`

指定 HDL 实现的复数乘法器类型。每次乘法使用 `Use 3 multipliers and 5 adders` 或 `Use 4 multipliers and 2 adders` 实现。实现速度取决于所使用的综合工具和目标器件。

### **Rounding method** — 内部定点计算的舍入模式 `Floor`（默认）| `Ceiling` | `Convergent` | `Nearest` | `Round` | `Zero`

指定内部定点计算的舍入方法类型。有关舍入方法的更多信息，请参阅 Rounding Modes。当输入为任何整数或定点数据类型时，此模块使用定点算术进行内部计算。当输入数据为 `single` 或 `double` 时，此参数不适用。

### **Normalize butterfly output** — 输出归一化 `off`（默认）| `on`

选择此参数时，模块将输出除以 1536。当您希望模块的输出保持与其输入相同的幅度范围时，此选项很有用。当输入为 `fixed point` 类型时，需要此选项。

选择此参数时，输出字长增加 2 位；清除此参数时，输出字长增加 11 位。

### 控制端口

### **Enable reset input port** — 可选复位信号 `off`（默认）| `on`

选择此参数以启用 **reset** 端口。

## 扩展功能

### C/C++ 代码生成 使用 Simulink® Coder™ 生成 C 和 C++ 代码。

此模块支持用于 Simulink® 加速器和快速加速器模式以及 DPI 组件生成的 C/C++ 代码生成。

### HDL 代码生成 使用 HDL Coder™ 为 FPGA 和 ASIC 设计生成 VHDL、Verilog 和 SystemVerilog 代码。

HDL Coder™ 提供影响 HDL 实现和综合逻辑的额外配置选项。

**HDL 架构**

此模块有一个默认 HDL 架构。

**HDL 模块属性**

|  |  |
| --- | --- |
| **ConstrainedOutputPipeline** | 通过在设计内移动现有延迟来在输出端放置的寄存器数量。分布式流水线不会重新分配这些寄存器。默认值为 `0`。有关更多详细信息，请参阅 ConstrainedOutputPipeline (HDL Coder)。 |
| **InputPipeline** | 在生成代码中插入的输入流水线级数。分布式流水线和受约束输出流水线可以移动这些寄存器。默认值为 `0`。有关更多详细信息，请参阅 InputPipeline (HDL Coder)。 |
| **OutputPipeline** | 在生成代码中插入的输出流水线级数。分布式流水线和受约束输出流水线可以移动这些寄存器。默认值为 `0`。有关更多详细信息，请参阅 OutputPipeline (HDL Coder)。 |

**限制**

无法为可复位同步子系统 (HDL Coder) 内的此模块生成 HDL。

## 描述

计算 LTE 标准传输带宽 15 MHz 的快速傅里叶变换 (FFT)

FFT 1536 模块旨在支持 LTE 标准传输带宽 15 MHz。此模块用于 LTE OFDM 解调器模块操作。该模块接受输入数据以及有效控制信号，并输出带有 `samplecontrol` 总线的流式数据。

该模块提供适用于 HDL 代码生成和硬件部署的架构。
