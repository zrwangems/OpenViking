- **快照时间** 中指定的确切快照时间。

  如下图所示，启用过零检测后，变步长 Simulink 求解器会在快照时间 `Tsnap` 对模型进行仿真。`Tsnap` 可能位于求解器自动选择的仿真时间步 `Tn-1` 和 `Tn` 之间。

  如下图所示，启用过零检测后，变步长 Simulink 求解器会在检测到触发信号的时间 `Ttrig` 对模型进行仿真。`Ttrig` 可能位于求解器自动选择的仿真时间步 `Tn-1` 和 `Tn` 之间。

### 线性系统采样时间

仿真期间计算的线性系统的采样时间。

使用此参数可以：

- 从连续时间系统计算具有特定采样时间的离散时间系统
- 以不同的采样时间对离散时间系统重新采样
- 从离散时间系统计算连续时间系统

在连续时间系统与离散时间系统之间相互转换时，软件使用 **采样时间速率转换方法** 中指定的转换方法。

**设置**

**默认值：** `auto`

`auto`。采样时间计算如下：
:   - 对于连续时间模型，为 0。
    - 对于包含具有不同采样时间的模块的模型（多速率模型），为各采样时间的最小公倍数。例如，如果混合使用连续时间和离散时间模块，且采样时间分别为 0、0.2 和 0.3，则线性模型的采样时间为 0.6。

正的有限值。用于计算：
:   - 从连续时间系统得到离散时间线性系统。
    - 从另一个具有不同采样时间的离散时间系统得到离散时间线性系统。

`0`
:   用于从离散时间模型计算连续时间线性系统。

**命令行信息**

|  |
| --- |
| **参数：** `SampleTime` |
| **类型：** character vector |
| **值：** `'auto'` | 正的有限值 | `'0'` |
| **默认值：** `'auto'` |

### 采样时间速率转换方法

用于转换单速率或多速率模型采样时间的方法。

仅当 **线性系统采样时间** 的值不是 `auto` 时，才使用此参数。

**设置**

**默认：** `Zero-Order Hold`

`Zero-Order Hold`
:   零阶保持，其中假定控制输入在采样时间 `Ts` 内分段恒定。有关详细信息，请参阅 Zero-Order Hold。

    此方法通常在时域中表现更好。

`Tustin (bilinear)`
:   不进行频率预扭曲的双线性 (Tustin) 近似。软件将小数时间延迟舍入到最接近的采样时间整数倍。有关详细信息，请参阅 Tustin 近似。

    此方法通常在频域中表现更好。

`Tustin with Prewarping`
:   带频率预扭曲的双线性 (Tustin) 近似。还需在 **预扭曲频率 (rad/s)** 中指定预扭曲频率。有关详细信息，请参阅 Tustin 近似。

    此方法通常在频域中表现更好。使用此方法可确保在感兴趣的频率区域内匹配。

`Upsampling when possible, Zero-Order Hold otherwise`
:   尽可能对离散时间系统进行上采样，否则使用 `Zero-Order Hold`。

    仅当将离散时间系统转换为新的、更快的采样时间，且该采样时间是原系统采样时间的整数倍时，才能进行上采样。

`Upsampling when possible, Tustin otherwise`
:   尽可能对离散时间系统进行上采样，否则使用 `Tustin (bilinear)`。

    仅当将离散时间系统转换为新的、更快的采样时间，且该采样时间是原系统采样时间的整数倍时，才能进行上采样。

`Upsampling when possible, Tustin with Prewarping otherwise`
:   尽可能对离散时间系统进行上采样，否则使用 `Tustin with Prewarping`。还需在 **预扭曲频率 (rad/s)** 中指定预扭曲频率。

    仅当将离散时间系统转换为新的、更快的采样时间，且该采样时间是原系统采样时间的整数倍时，才能进行上采样。

## 描述

从非线性 Simulink 模型近似得到的线性系统的零极点图

除了 **Bounds** 选项卡中的默认参数设置不同外，此模块与 Check Pole-Zero Characteristics 模块相同。

根据 Simulink 模型计算线性系统，并在零极点图上绘制极点和零点。

在仿真期间，软件会对指定线性化输入和输出之间的模型部分进行线性化，并绘制该线性系统的极点和零点。

Simulink 模型可以是连续时间、离散时间或多速率模型，并且可以包含时延。由于在此模块中只能指定一对线性化输入/输出，因此该线性系统为单输入单输出 (SISO) 系统。

您可以指定多个根据二阶特性近似得到的极点位置边界，并在绘图中查看这些边界。您还可以在仿真期间检查是否满足这些边界：

- 如果所有边界都得到满足，模块不执行任何操作。
- 如果某个边界未得到满足，模块将触发断言，并在 MATLAB® 命令行窗口中显示警告消息。您还可以指定模块执行以下操作：

  - 对 MATLAB 表达式求值。
  - 停止仿真，并将焦点移至该模块。

在仿真期间，模块还可以输出逻辑断言信号。

- 如果所有边界都得到满足，该信号为 true (`1`)。
- 如果任何边界未得到满足，该信号为 false (`0`)。

您可以添加多个 Pole-Zero Plot 模块，以计算并绘制模型不同部分的极点和零点。

您可以将线性系统保存为 MATLAB 工作区中的变量。

此模块不支持代码生成，只能在 `Normal` 仿真模式下使用。
