# Closed-Loop PID Autotuner

## 端口

### 输入

### **u** — 来自控制器的信号 标量

将模块插入系统中，使此端口接受来自信号源的控制信号。通常，此端口接受来自系统中 PID 控制器的信号。

**数据类型：** `single` | `double`

### **y** — 被控对象输出 标量

将此端口连接到被控对象输出。

**数据类型：** `single` | `double`

### **start/stop** — 启动和停止自整定实验 标量

要启动和停止自整定过程，请在 `start/stop` 端口提供信号。当该信号的值从以下情况变化时：

- 负值或零变为正值，实验启动
- 正值变为负值或零，实验停止

当实验未运行时，模块将信号从 **u** 原样传递到 **u+Δu**。在此状态下，模块对被控对象或控制器的行为没有影响。

通常，可以使用从 0 变为 1 的信号启动实验，使用从 1 变为 0 的信号停止实验。配置 **start/stop** 信号时需要考虑以下几点：

- 在被控对象处于期望的平衡工作点时启动实验。使用初始控制器将被控对象驱动到该工作点。如果没有初始控制器（仅开环整定），可以使用连接到 **u** 的信号源模块将被控对象驱动到该工作点。
- 在实验期间避免对被控对象施加任何负载扰动。负载扰动会扭曲被控对象输出，并降低频率响应估计的精度。
- 让实验运行足够长的时间，以便算法在其探测的所有频率上收集足够的数据来获得良好的估计。

  对于 **Sinestream** 和 **Superposition** 模式，有两种方法可以确定何时停止实验：

  - 提前确定实验时长。在 superposition 实验模式下，实验时长的保守估计为 200/*ωc*；在 sinestream 实验模式下为 550/*ωc*，其中 *ωc* 是您的目标带宽。
  - 观察 `% conv` 输出处的信号，当信号稳定在接近 100% 时停止实验。

  对于 **PRBS** 模式，根据指定的 **目标带宽** 和 **控制器采样时间** 值，模块对话框会在 **实验** 选项卡的 **描述** 部分显示推荐的实验时长。过早停止实验可能会导致不正确的整定结果。*(自 R2023b 起)*
- 当停止实验时，模块会计算整定后的 PID 增益，并更新 `pid gains` 端口处的信号。

您可以配置任何适合您应用的逻辑来控制实验的启动和停止时间。

**数据类型：** `single` | `double`

### **bandwidth** — 用于整定的目标带宽 标量

为 `Target bandwidth (rad/sec)` 参数提供值。有关详细信息，请参阅该参数。

#### 依赖关系

要启用此端口，请在整定选项卡中，在 `Target bandwidth (rad/sec)` 旁边选择 **使用外部源**。

**数据类型：** `single` | `double`

### **target PM** — 用于整定的目标相位裕度 标量

为 `Target phase margin (degrees)` 参数提供值。有关详细信息，请参阅该参数。

#### 依赖关系

要启用此端口，请在整定选项卡中，在 `Target phase margin (degrees)` 旁边选择 **使用外部源**。

**数据类型：** `single` | `double`

### **signal Amp** — 注入扰动信号的幅值 标量 | 向量

为 `Signal Amplitudes` 参数提供值。有关详细信息，请参阅该参数。

#### 依赖关系

要启用此端口，请在实验选项卡中，在 `Signal Amplitudes` 旁边选择 **使用外部源**。

**数据类型：** `single` | `double`

### **isExpGood** — 禁用扰动和整定 标量

*自 R2025a 起*

当您在此输入提供值 1 (true) 时，Closed-Loop PID Autotuner 模块会照常输出实验（扰动）。如果该值为 0 (false)，模块会将扰动设置为零，并且不执行整定。为了再次允许扰动和整定，您必须先将 **start/stop** 信号设置为 0，然后再设置回 1，并启动新的实验。**isExpGood** 端口在其值为 false 时会锁存该值，直到触发新的实验。

如果您的被控对象在 Closed-Loop PID Autotuner 模块下游存在信号限幅，由于扰动可能饱和，估计实验可能不准确。类似地，系统中的任何故障也可能导致实验不准确。您可以使用 **isExpGood** 提供禁用扰动和整定的信号。有关示例，请参阅"在下游信号限幅存在时禁用 PID 自整定"。

#### 依赖关系

要启用此端口，请在 **模块** 选项卡上选择 **使用 isExpGood 端口禁用扰动和整定**。

**数据类型：** `single` | `double`
### 输出

### **u+Δu** — 用于被控对象输入的信号 标量

将模块插入系统中，使此端口向被控对象馈送输入信号。

- 当实验正在运行时（`start/stop` 为正值），模块会在此端口向被控对象注入测试信号。如果您有任何保护被控对象的饱和或速率限制，请将 **u+Δu** 的信号馈入其中。
- 当实验未运行时（`start/stop` 为零或负值），模块将信号从 **u** 原样传递到 **u+Δu**。

#### 依赖关系

要启用此端口，请在 **输出信号配置** 中选择 **control + perturbation**。

**数据类型：** `single` | `double`

### **Δu** — 被控对象输入扰动 标量

模块会在此端口生成扰动信号。通常，您通过求和模块从此端口注入扰动，如下图所示。

- 当实验正在运行时（**start/stop** 为正值），模块会在此端口生成扰动信号。
- 当实验未运行时（**start/stop** 为零或负值），此端口处的信号为零。在此状态下，模块对被控对象没有影响。

#### 依赖关系

要启用此端口，请在 **输出信号配置** 中选择 **perturbation only**。

**数据类型：** `single` | `double`

### **% conv** — 实验期间 FRD 估计的收敛度 标量

当实验正在运行时（`start/stop` 为正值），模块会向被控对象注入测试信号，并在 `y` 处测量被控对象响应。它使用这些信号估计被控对象在用于整定的目标带宽附近的若干频率处的频率响应。对于 sinestream 和 superposition 信号，`% conv` 表示被控对象频率响应估计的完成接近程度。通常，该值在实验开始后会迅速上升到约 90%，然后逐渐收敛到更高的值。当它在接近 100% 处趋于平稳时，停止实验。

对于 **PRBS** 实验模式，此端口处的信号仅在估计实验完成后才更新。*(自 R2023b 起)*

**数据类型：** `single` | `double`

### **pid gains** — 整定后的 PID 系数 总线

此 4 元素总线信号包含整定后的 PID 增益 *P*、*I*、*D* 以及滤波器系数 *N*。这些值对应于 `Form` 参数中给出的表达式里的 `P`、`I`、`D` 和 `N` 参数。初始时，这些值分别为 0、0、0 和 100。模块在实验结束时更新这些值。即使您整定的不是 PIDF 控制器，此总线信号也始终包含四个元素。

如果您有关联到此模块的 PID 控制器，可以在实验结束后使用这些值更新该控制器。为此，请在模块选项卡中点击 **Update PID Block**。

**数据类型：** `single` | `double`

### **estimated PM** — 使用整定后控制器达到的估计相位裕度 标量

此端口输出整定后的控制器所达到的估计相位裕度（以度为单位）。模块在整定实验结束时更新此值。估计相位裕度由 *G*(*jωc*)*C*(*jωc*) 的相角计算得出，其中 *G* 是估计的被控对象，*C* 是整定后的控制器，*ωc* 是穿越频率（带宽）。估计相位裕度可能与 `Target phase margin (degrees)` 参数指定的目标相位裕度不同。它是整定后系统所达到的鲁棒性和稳定性的指标。

- 通常，估计相位裕度接近目标相位裕度。一般而言，该值越大，整定后系统越鲁棒，超调越小。
- 负相位裕度表示闭环系统可能不稳定。

#### 依赖关系

要启用此端口，请在整定选项卡中选择 **输出整定后控制器达到的估计相位裕度**。

### **frd** — 估计的频率响应 向量

此端口输出由实验估计出的频率响应数据。初始时，`frd` 处的值为 [0, 0, 0, 0, 0]。在实验期间，模块在频率 [1/10, 1/3, 1, 3, 10]*ωc* 处注入信号，其中 *ωc* 是目标带宽。在实验期间的每个采样时间，模块会用包含这些频率处复数频率响应的向量相应地更新 `frd`。对于 sinestream 和 superposition 信号，您可以使用响应的进展来替代 `% conv`，以检查估计的收敛情况。当实验停止时，模块会用用于计算 PID 增益的最终估计频率响应更新 `frd`。

对于 **PRBS** 实验模式，此端口处的信号仅在估计实验完成后才更新。*(自 R2023b 起)*

#### 依赖关系

要启用此端口，请在实验选项卡中选择 **带宽附近的被控对象频率响应**。

### **nominal** — 标称工作点处的被控对象输入和输出 向量

此端口输出一个向量，其中包含实验开始时的被控对象输入（**u+Δu**）和被控对象输出（**y**）。这些值是模块执行实验所在的标称工作点处的被控对象输入和输出。

#### 依赖关系

要启用此端口，请在实验选项卡中选择 **被控对象标称输入和输出**。

## 参数

#### 整定选项卡

### **类型** — PID 控制器作用 `PI`（默认）| `PID` | `PIDF` | ...

指定系统中 PID 控制器的类型。控制器类型指示控制器中存在哪些作用。以下控制器类型可用于 PID 自整定：

- `P` — 仅比例
- `I` — 仅积分
- `PI` — 比例和积分
- `PD` — 比例和微分
- `PDF` — 带微分滤波器的比例和微分
- `PID` — 比例、积分和微分
- `PIDF` — 带微分滤波器的比例、积分和微分

当您使用整定后的参数值更新 PID Controller 模块或自定义 PID 控制器时，请确保控制器类型匹配。

**可调：**是

| --- |
| **模块参数：**`PIDType` |
| **类型：**字符向量 |
| **取值：**`'P'` | `'I'` | `'PI'` | `'PD'` | `'PDF'` | `'PID'` | `'PIDF'` |
| **默认值：**`'PI'` |

### **形式** — PID 控制器形式 `Parallel`（默认）| `Ideal`

指定控制器形式。控制器形式决定了 PID 系数 *P*、*I*、*D* 和 *N* 的解释方式。

- `Parallel` — 在 `Parallel` 形式下，离散时间 PIDF 控制器的传递函数为：

  C=P+IFi(z)+D[N1+NFd(z)],

  其中 *Fi*(*z*) 和 *Fd*(*z*) 是积分器和滤波器公式（请参阅 `Integrator method` 和 `Filter method`）。连续时间并联形式 PIDF 控制器的传递函数为：

  C=P+I(1s)+D(Nss+N).

  其他控制器作用相当于将 *P*、*I* 或 *D* 设置为零。
- `Ideal` — 在 `Ideal` 形式下，离散时间 PIDF 控制器的传递函数为：

  C=P[1+IFi(z)+D(N1+NFd(z))].

  连续时间理想形式 PIDF 控制器的传递函数为：

  C=P[1+I(1s)+D(Nss+N)].

  其他控制器作用相当于将 *D* 设置为零，或将 *I* 设置为 `Inf`。（在理想形式下，控制器必须具有比例作用。）

当您使用整定后的参数值更新 PID Controller 模块或自定义 PID 控制器时，请确保控制器形式匹配。

| **类型：**字符向量 |
| **取值：**`'Parallel'` | `'Ideal'` |

### **控制器采样时间 (sec)** — PID 控制器的采样时间 0.1（默认）| 正标量 | –1

以秒为单位指定 PID 控制器的采样时间。此值还会设置模块所执行实验的采样时间。

要执行 PID 整定，模块会测量高达目标带宽 10 倍频率的频率响应信息。为确保该频率低于 Nyquist 频率，目标带宽 *ωc* 必须满足 *ωc**Ts* ≤ 0.3，其中 *Ts* *ωc* 是您使用 **控制器采样时间 (sec)** 参数指定的控制器采样时间。

当您使用整定后的参数值更新 PID Controller 模块或自定义 PID 控制器时，请确保控制器采样时间匹配。

#### 提示

#### 依赖关系

要启用此参数，请将 **时域** 设置为 `discrete-time`。

### **积分器方法** — 积分器项的离散积分公式 `Forward Euler`（默认） | `Backward Euler` | `Trapezoidal`

指定控制器中积分器项的离散积分公式。在离散时间中，模块假定的 PID 控制器传递函数为：

C=P+IFi(z)+D[N1+NFd(z)],

采用并联形式，或采用理想形式，

C=P[1+IFi(z)+D(N1+NFd(z))].

对于控制器采样时间 *Ts*，`Integrator method` 参数按如下方式确定公式 *Fi*：

| 积分器方法 | *Fi* |
| --- | --- |
| `Forward Euler` | Tsz−1 |
| `Backward Euler` | Tszz−1 |
| `Trapezoidal` | Ts2z+1z−1 |

有关每种方法相对优势的详细信息，请参阅 Discrete PID Controller 模块参考页。

使用整定后的参数值更新 PID Controller 模块或自定义 PID 控制器时，请确保积分器方法匹配。

### **目标带宽 (rad/sec)** — 整定响应的目标穿越频率 1（默认） | positive scalar

目标带宽以 rad/sec 为单位指定，是整定后开环响应 *CP* 的 0-dB 增益穿越频率的目标值，其中 *P* 是被控对象响应，*C* 是控制器响应。此穿越频率大致设定控制带宽。对于上升时间 *τ* seconds，目标带宽的良好估计值为 2/*τ* rad/sec。

为执行 PID 整定，自整定模块测量的频率响应信息最高可达目标带宽的 10 倍频率。为确保该频率低于 Nyquist 频率，目标带宽 *ωc* 必须满足 *ωc**Ts* ≤ 0.3，其中 *Ts* 是使用 **控制器采样时间 (sec)** 参数指定的控制器采样时间。由于此条件，可为整定实施的最快上升时间约为 6.67*Ts*。如果此上升时间不满足设计目标，请考虑减小 *Ts*。

为获得闭环整定的最佳结果，请使用与初始 PID 控制器带宽相差约不超过 10 倍的目标带宽。要为带宽的较大变化整定控制器，请使用较小变化逐步整定。

要通过输入端口提供目标带宽，请选择 **使用外部源**。

### **目标相位裕度 (degrees)** — 开环响应的目标最小相位裕度 60（默认） | scalar in range 0–90

指定整定后开环响应在穿越频率处的目标最小相位裕度。目标相位裕度反映整定系统的期望鲁棒性。通常，选择约 45°–60° 范围内的值。一般来说，较高的相位裕度可改善超调，但可能限制响应速度。默认值 60° 倾向于平衡性能和鲁棒性，根据被控对象特性，产生约 5–10% 的超调。

#### 实验选项卡

### **实验模式** — 扰动信号类型 **Superposition**（默认） | **Sinestream** | **PRBS** *(since R2023b)*

指定每个频率处的扰动是按顺序正弦（**Sinestream**）、同时正弦（**Superposition**）还是伪随机二进制序列（**PRBS**）施加。

- **Sinestream** — 在此模式下，模块分别在各频率处施加扰动。有关用于估计的 sinestream 信号的详细信息，请参阅 Sinestream Input Signals。
- **Superposition** — 在此模式下，扰动信号一次包含所有指定频率。对于在频率向量 *ω* = [*ω*1, … , *ωN*] 处、幅值为 *A* = [*A*1, … , *AN*] 的频率响应估计，扰动信号为：

  Δu=∑iAisin(ωit).
- **PRBS** — 一种在两个值之间切换且具有类似白噪声特性的确定性伪随机二进制序列。与使用 sinestream 输入信号相比，PRBS 信号可减少总估计时间，同时产生相当的估计结果。PRBS 信号可用于估计通信和电力电子系统的频率响应。有关详细信息，请参阅 PRBS Input Signals。*(since R2023b)*

**Sinestream** 模式可以更准确，也可以侵入性更低，因为扰动的总大小永远不会大于 **信号幅值** 参数指定的值。但是，由于 sinestream 扰动的顺序特性，每增加一个频率点都会增加建议的实验时间（有关详细信息，请参阅 **start/stop** 输入端口）。因此，在 **Superposition** 模式下，估计实验通常快得多，且结果令人满意。

与 superposition 输入信号相比，sinestream 信号可减少执行时间，但估计频率响应也需要更长时间。当处理能力有限且希望减少执行时间时，使用 sinestream 信号进行频率响应估计很有用。

为覆盖相似的频率范围，**PRBS** 模式下的实验长度通常比其他两种模式短得多。但是，需要在结果速度和质量之间进行权衡。*(since R2023b)*

### **信号幅值** — 扰动的幅值 1（默认） | scalar | vector of length 5

在实验期间，模块以频率 [1/10, 1/3, 1, 3, 10]*ωc* 向被控对象注入扰动信号，其中 *ωc* 是整定的目标带宽。使用 **信号幅值** 指定每个注入信号的幅值。指定：

- scalar value，用于在每个频率注入相同幅值
- vector of length 5，用于在 [1/10, 1/3, 1, 3, 10]*ωc* 的每个频率指定不同幅值

在具有典型目标带宽的典型被控对象中，实验频率处的被控对象响应幅值变化不大。在这种情况下，可以使用 scalar value 在所有频率施加相同幅值的扰动。但是，如果知道响应在频率范围内急剧衰减，请考虑减小较低频率输入的幅值并增大较高频率输入的幅值。当所有被控对象响应具有可比幅值时，估计实验在数值上会更好。

扰动幅值必须满足：

- 足够大，使扰动克服被控对象执行器中的任何死区，并产生高于噪声水平的响应
- 足够小，使被控对象在标称工作点附近的近似线性区域内运行，并避免使被控对象输入或输出饱和

当 **实验模式** 为 **Superposition** 时，正弦信号会叠加。因此，扰动至少可能与所有幅值之和一样大。确保最大可能的扰动在被控对象执行器的范围内。使执行器饱和会向估计的频率响应中引入误差。

要通过输入端口提供信号幅值，请选择 **使用外部源**。

**可调：** Yes

#### 模块选项卡

### **减少内存并避免任务超限（仅外部模式）** — 仅部署整定算法 `off`（默认） | `on`

该模块包含两个模块，一个执行实时频率响应估计，另一个使用所得的估计响应来整定 PID 增益。当在外部仿真模式下运行包含该模块的 Simulink 模型时，默认情况下会部署这两个模块。您可以仅部署估计模块以节省目标硬件上的内存（请参阅 Control Real-Time PID Autotuning in Simulink）。在这种情况下，整定算法在 Simulink 主机上运行，而不是在目标硬件上运行。选择此选项时，所部署算法使用的内存约为清除该选项时的三分之一。

PID 增益计算比频率响应估计需要更大的计算负载。对于较快的控制器采样时间，某些硬件可能无法在一个执行周期内完成增益计算。因此，在使用计算能力有限的硬件时，选择此选项可让您整定具有较快采样时间的 PID 控制器。

此外，启用此选项时，从整定实验结束到新的 PID 增益到达 **pid gains** 输出端口之间可能会有几个采样周期的延迟。在将增益推送到控制器之前，请先在 **pid gains** 输出端口确认变化，而不是使用 **start/stop** 信号作为更新的触发。

如果您打算在不使用外部仿真模式的情况下部署该模块并执行 PID 整定，请不要选择此选项。

## 描述

基于从闭环实验实时估计的被控对象频率响应自动调优 PID 增益

Closed-Loop PID Autotuner 模块允许你针对物理被控对象实时调优 PID 控制器，前提是你有一个初始 PID 控制器，且该控制器能形成稳定闭环。在整个自动调优过程中，被控对象始终处于初始 PID 控制器的闭环控制下。该模块可以在没有参数化被控对象模型的情况下调优 PID 控制器，以达到指定的带宽和相位裕度。如果你有代码生成产品，例如 Simulink® Coder™，则可以生成在硬件上实现调优算法的代码，让你可以在使用或不使用 Simulink 管理自动调优过程的情况下实时调优。

如果你有在 Simulink 中建模的被控对象和初始 PID 控制器，则可以针对建模的被控对象执行闭环 PID 自动调优。这样做可以让你在实时调优控制器之前预览被控对象响应并调整 PID 自动调优的设置。

为实现无模型调优，Closed-Loop PID Autotuner 模块：

1. 向被控对象注入测试信号，以收集被控对象输入输出数据并实时估计频率响应。该测试信号是在被控对象输入之上叠加的扰动信号的组合。
2. 在实验结束时，基于目标带宽附近估计的被控对象频率响应调优 PID 控制器参数。
3. 使用调优后的参数更新 PID Controller 模块或自定义 PID 控制器，使你能够实时验证闭环性能。

与 Open-Loop PID Autotuner 模块不同，整个实验过程中闭环保持闭合。保持闭环有助于在估计实验期间维持被控对象的安全运行。

你可以使用 Closed-Loop PID Autotuner 模块为以下对象调优 PID 控制器：

- 任何稳定被控对象
- 任何具有一个或多个积分器（极点在 *s* = 0）或虚轴上的一对或多对复极点的连续时间被控对象
- 任何具有一个或多个积分器（极点在 *z* = –1）或单位圆 |*z*| = 1 上的一对或多对复极点的离散时间被控对象

如果你没有初始 PID 控制器，可以使用 Open-Loop PID Autotuner 模块获得一个。然后，你可以切换到闭环 PID 自动调优以进行细化或重新调优。

该模块支持使用 Simulink Coder、Embedded Coder® 和 Simulink PLC Coder™ 进行代码生成。它不支持使用 HDL Coder™ 进行代码生成。

有关使用 Closed-Loop PID Autotuner 模块的详细信息，请参阅：

- 在 Simulink 中建模的被控对象的 PID 自动调优
- 实时 PID 自动调优

有关 PID 自动调优的更多一般信息以及闭环和开环方法的比较，请参阅何时使用 PID 自动调优。
