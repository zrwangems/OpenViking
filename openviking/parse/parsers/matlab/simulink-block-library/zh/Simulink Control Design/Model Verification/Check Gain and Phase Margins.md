# Gain and Phase Margin Plot

## 端口

### 输入

### **Trigger** — 外部触发信号 标量

使用此输入端口（由 External trigger 图标指示）连接外部触发信号，以计算模型线性化。要指定要检测的触发信号类型，请使用 **触发类型** 参数。

#### 依赖关系

要启用此端口，请将 **线性化时机** 参数设置为 `External trigger`。

### 输出

### **z–1** — 断言信号 `1` | `0`

将断言信号的值作为逻辑值输出。如果违反 **边界** 选项卡上指定的任何边界，则断言信号为 false（`0`）。否则，此信号为 true（`1`）。

默认情况下，输出信号的数据类型为 double。要将输出数据类型设置为 Boolean，请在 Simulink 模型中，在“配置参数”对话框中，选择 **将逻辑信号实现为 Boolean 数据** 参数。此设置适用于模型中生成逻辑信号的所有模块。

您可以使用断言信号设计复杂的断言逻辑。有关示例，请参阅使用 Simulink Control Design 和 Simulink Verification Blocks 验证模型。

#### 依赖关系

要启用此端口，请选择 **输出断言信号** 参数。

要指定要线性化的模型部分以及其他线性化设置，请使用 **线性化** 选项卡上的参数。此选项卡上的默认设置对于 Gaind and Phase Margin Plot 和 Check Gain and Phase Margins 模块相同。

要指定要线性化的模型部分，请从 Simulink 模型中选择信号，并将其添加为线性化输入或输出。

在 **配置** 列中，从以下类型中选择线性分析点的类型。有关线性分析点的详细信息，请参阅指定要线性化的模型部分。

- `Open-loop Input` — 指定回路断开后的线性化输入点
- `Open-loop Output` — 指定回路断开前的线性化输出点
- `Loop Transfer` — 指定回路断开前的输出点，后跟一个输入

### **线性化时机** — 何时计算线性模型 `Simulation snapshots`（默认） | `External trigger`

使用此参数指定何时计算线性模型。

要在指定的仿真快照时间计算线性模型，请将此参数设置为 `Simulation snapshots`。使用 **快照时间** 参数指定快照时间。

在以下情况下使用仿真快照：

- 知道模型处于稳态工作点的一个或多个时间
- 希望在特定时间计算线性系统

要在基于触发的仿真事件中计算线性模型，请将此参数设置为 `External trigger`。选择此选项会向模块添加一个触发输入端口，您可以将外部触发信号连接到该端口。要指定要检测的触发类型，请使用 **触发类型** 参数。

当仿真期间生成的信号指示模型处于感兴趣的稳态条件时，请使用外部触发。例如，对于飞机模型，您可能希望在燃料质量达到最大燃料质量的给定分数时计算线性系统。

### **启用过零检测** — 启用过零检测 `on`（默认） | `off`

选择此选项以启用过零检测。

当您将 **线性化时机** 参数设置为 `Simulation snapshots` 时，启用过零检测可确保软件在 **快照时间** 参数中指定的确切快照时间计算线性模型。

当您将 **线性化时机** 参数设置为 `External trigger` 时，启用过零检测可确保软件在检测到外部触发的确切时间计算线性模型。要指定触发类型，请使用 **触发类型** 参数。

如果清除此选项，软件将在可变步长 Simulink 求解器选择的仿真时间计算线性系统，这些时间可能不对应于确切的快照时间或检测到触发信号的确切时间。

例如，考虑可变步长求解器选择仿真时间 *T**n*–1 和 *Tn* 的情况。如下图所示，指定的快照时间 *Tsnap* 可以位于所选仿真时间之间。如果启用过零检测，求解器还会在时间 *Tsnap* 仿真模型，并在此点计算线性模型。

类似地，外部触发可能在所选仿真时间之间的时间 *Ttrig* 被检测到。如果启用过零检测，求解器还会在时间 *Ttrig* 仿真模型，并在此点计算线性模型。

在这两种情况下，如果未启用过零检测，软件将在 *T**n*–1 或 *Tn* 处计算线性模型。

有关过零检测的详细信息，请参阅过零检测。

#### 依赖关系

当您使用固定步长 Simulink 求解器时，将忽略此参数。

### **采样时间速率转换方法** — 速率转换方法 `Zero-Order Hold`（默认）| `Tustin (bilinear)` | `Tustin with Prewarping` | ...

用于在线性化期间转换采样时间的方法，指定为以下值之一。

- `Zero-Order Hold` — 零阶保持，其中控制输入假设在采样时间 `Ts` 内分段恒定。此方法通常在时域中表现更好。
- `Tustin (bilinear)` — 不带频率预扭曲的双线性（Tustin）近似。软件将分数时间延迟舍入到采样时间的最接近倍数。此方法通常在频域中表现更好。
- `Tustin with Prewarping` — 带频率预扭曲的双线性（Tustin）近似。使用 **预扭曲频率** 参数指定预扭曲频率。此方法通常在频域中表现更好。使用此方法可确保在感兴趣的频率区域内匹配。
- `Upsampling when possible, Zero-Order Hold otherwise` — 在可能时对离散时间系统进行上采样；否则，使用零阶保持。
- `Upsampling when possible, Tustin otherwise` — 在可能时对离散时间系统进行上采样；否则，使用 Tustin 近似。
- `Upsampling when possible, Tustin with Prewarping otherwise` — 在可能时对离散时间系统进行上采样；否则，使用带频率预扭曲的 Tustin 近似。

仅当您将离散时间系统转换为新的更快采样时间，且该采样时间是原始系统采样时间的整数倍时，才能进行上采样。

有关多速率模型的速率转换和线性化的详细信息，请参阅：

- 多速率线性化算法
- 使用不同速率转换方法对模型进行线性化
- 连续-离散转换方法

**注意**

如果您使用的速率转换方法不是 `Zero-Order Hold`，则转换后的状态不再具有与原始状态相同的物理含义。因此，生成的 LTI 系统中的状态名称将变为 `'?'`。

## 描述

从非线性 Simulink 模型近似得到的线性系统的增益裕度和相位裕度

Gain and Phase Margin Plot 和 Check Gain and Phase Margins 模块从非线性 Simulink® 模型计算线性系统，并在仿真期间显示增益裕度和相位裕度。除 **Bounds** 选项卡上的默认设置外，这些模块完全相同。

- Gain and Phase Margin Plot 不定义默认边界。
- Check Gain and Phase Margins 模块定义默认边界，并为断言启用这些边界。

您可以在表格中或 Bode、Nichols 或 Nyquist 图上查看裕度。

有关线性系统频域分析的详细信息，请参阅 Frequency-Domain Responses。

在仿真期间，软件对指定的线性化输入和输出之间的模型部分进行线性化，然后绘制线性系统的响应。您还可以将线性系统作为变量保存到 MATLAB® 工作区中。

Simulink 模型可以是连续时间或离散时间，也可以是多速率，并且可以具有时滞。由于在此模块中只能指定一个线性化输入/输出对，因此该线性系统为 Single-Input Single-Output (SISO)。

您可以为增益裕度和相位裕度分别指定一个最小边界，并在选定的图或表格中查看它们。您还可以在仿真期间检查这些边界是否满足。

- 如果满足所有边界，则该模块不执行任何操作。
- 如果某个边界不满足，则该模块进行断言，并且警告消息会出现在 MATLAB Command Window 中。您还可以指定该模块：

  - 计算 MATLAB 表达式。
  - 停止仿真并使该模块获得焦点。

在仿真期间，该模块还可以输出逻辑断言信号。

- 如果满足所有边界，则信号为 true（`1`）。
- 如果任何边界不满足，则信号为 false（`0`）。

要计算并绘制模型各个部分的增益裕度和相位裕度，您可以添加多个 Gain and Phase Margin Plot 和 Check Gain and Phase Margins 模块。

这些模块不支持代码生成，并且只能在 `Normal` 仿真模式下使用。
