### Linearization inputs/outputs

线性化输入和输出，用于定义非线性 Simulink 模型中要线性化的部分。

如果已在 Simulink 模型中定义线性化输入和输出，模块会自动检测这些点，并将其显示在 **Linearization inputs/outputs** 区域中。随时单击 ，即可使用模型中的 I/O 更新 **Linearization inputs/outputs** 表。要添加其他分析点，请执行以下操作：

1. 单击 。

   对话框将展开，显示 **Click a signal in the model to select it** 区域和一个新的  按钮。
2. 在 Simulink 编辑器中选择一个或多个信号。

   所选信号将显示在 **Click a signal in the model to select it** 区域中的 **Model signal** 下。
3. （可选）对于总线，展开总线信号以选择各个元素。

   **提示**

   对于大型总线或其他大型信号列表，可以在 **Filter by name** 编辑框中输入搜索文本来筛选元素名称。名称匹配区分大小写。此外，还可以输入 MATLAB 正则表达式。

   要修改筛选选项，请单击 。要隐藏筛选选项，请单击 。

    筛选选项

   - Enable regular expression
   - Show filtered results as a flat list
4. 单击 ，将所选信号添加到 **Linearization inputs/outputs** 表中。

   要从 **Linearization inputs/outputs** 表中删除信号，请选择该信号并单击 。

   **提示**

   要查找 Simulink 模型中与 **Linearization inputs/outputs** 表中某个信号对应的位置，请在表中选择该信号并单击 。

该表显示有关所选信号的以下信息：

|  |  |
| --- | --- |
| **Block : Port : Bus Element** | 与输入/输出关联的模块名称。模块名称旁边的数字是所选总线信号所在的端口号。最后一项是所选总线元素的名称。 |
| **Configuration** | 线性化点的类型：  - `Open-loop Input` — 指定环路断点之后的线性化输入点。 - `Open-loop Output` — 指定环路断点之前的线性化输出点。 - `Loop Transfer` — 指定环路断点之前的输出点，其后跟随一个输入点。 - `Input Perturbation` — 指定信号的加性输入。 - `Output Measurement` — 在信号处进行测量。 - `Loop Break` — 指定环路断点。 - `Sensitivity` — 指定一个加性输入，后接输出测量。 - `Complementary Sensitivity` — 指定一个输出，后接一个加性输入。 |

### Linearize on

指定在仿真期间何时计算线性系统。

**设置**

**默认值：**`Simulation snapshots`

`Simulation snapshots`
:   特定仿真时间，在 **Snapshot times** 中指定。

    在以下情况下使用：

    - 知道模型处于稳态工作点的一个或多个时刻
    - 要在特定时刻计算线性系统

`External trigger`
:   基于触发的仿真事件。在 **Trigger type** 中指定触发类型。

    当仿真期间生成的信号指示稳态工作点时使用。

    选择此选项会向模块添加一个触发端口。使用此端口将模块连接到触发信号。

    例如，对于飞机模型，您可能希望在燃油质量为最大燃油质量的某一比例时计算线性系统。在这种情况下，请将此条件建模为外部触发。

**依赖关系**

- 将此参数设置为 `Simulation snapshots` 可启用 **Snapshot times**。
- 将此参数设置为 `External trigger` 可启用 **Trigger type**。

- 在 **Snapshot times** 中指定的准确快照时间。

  如下图所示，启用过零检测后，变步长 Simulink 求解器会在快照时间 `Tsnap` 对模型进行仿真。`Tsnap` 可能位于求解器自动选择的仿真时间步 `Tn-1` 和 `Tn` 之间。
- 检测到外部触发的准确时刻，在 **Trigger type** 中指定。

  如下图所示，启用过零检测后，变步长 Simulink 求解器会在检测到触发信号的时刻 `Ttrig` 对模型进行仿真。`Ttrig` 可能位于求解器自动选择的仿真时间步 `Tn-1` 和 `Tn` 之间。

### Linear system sample time

仿真期间计算的线性系统的采样时间。

使用此参数可以：

- 从连续时间系统计算具有特定采样时间的离散时间系统
- 以不同的采样时间对离散时间系统重新采样
- 从离散时间系统计算连续时间系统

在从连续时间系统计算离散时间系统以及执行反向计算时，软件使用 **Sample time rate conversion method** 中指定的转换方法。

**设置**

**默认值：**`auto`

`auto`。采样时间计算如下：
:   - 对于连续时间模型，为 0。
    - 对于包含具有不同采样时间的模块的模型（多速率模型），采样时间为各采样时间的最小公倍数。例如，如果连续时间和离散时间模块混用，采样时间分别为 0、0.2 和 0.3，则线性模型的采样时间为 0.6。

正有限值。用于计算：
:   - 从连续时间系统计算离散时间线性系统。
    - 从另一个具有不同采样时间的离散时间系统计算离散时间线性系统。

`0`
:   用于从离散时间模型计算连续时间线性系统。

**命令行信息**

|  |
| --- |
| **参数：**`SampleTime` |
| **类型：**character vector |
| **值：**`'auto'` | 正有限值 | `'0'` |
| **默认值：**`'auto'` |

### 采样时间速率转换方法

用于转换单速率或多速率模型采样时间的方法。

仅当 **线性系统采样时间** 的值不为 `auto` 时，才使用此参数。

**设置**

**默认值：** `Zero-Order
Hold`

`Zero-Order Hold`
:   零阶保持，其中假定控制输入在采样时间 `Ts` 内分段恒定。有关详细信息，请参阅 Zero-Order Hold。

    此方法通常在时域中表现更好。

`Tustin (bilinear)`
:   不带频率预扭曲的双线性 (Tustin) 近似。软件将小数时间延迟舍入为最接近的采样时间整数倍。有关详细信息，请参阅 Tustin Approximation。

    此方法通常在频域中表现更好。

`Tustin with Prewarping`
:   带频率预扭曲的双线性 (Tustin) 近似。还需在 **预扭曲频率 (rad/s)** 中指定预扭曲频率。有关详细信息，请参阅 Tustin Approximation。

    此方法通常在频域中表现更好。使用此方法可确保在感兴趣的频率区域实现匹配。

`Upsampling when possible, Zero-Order Hold otherwise`
:   尽可能对离散时间系统进行上采样，否则使用 `Zero-Order
    Hold`。

    仅当将离散时间系统转换为新的更快采样时间，且该采样时间是原系统采样时间的整数倍时，才能进行上采样。

`Upsampling when possible, Tustin otherwise`
:   尽可能对离散时间系统进行上采样，否则使用 `Tustin
    (bilinear)`。

    仅当将离散时间系统转换为新的更快采样时间，且该采样时间是原系统采样时间的整数倍时，才能进行上采样。

`Upsampling when possible, Tustin with Prewarping otherwise`
:   尽可能对离散时间系统进行上采样，否则使用 `Tustin
    with Prewarping`。还需在 **预扭曲频率 (rad/s)** 中指定预扭曲频率。

    仅当将离散时间系统转换为新的更快采样时间，且该采样时间是原系统采样时间的整数倍时，才能进行上采样。

## 描述

根据非线性 Simulink 模型近似得到的线性系统的 Nichols 图

除 **Bounds** 选项卡中的默认参数设置不同外，此模块与 Check Nichols Characteristics 模块相同。

根据非线性 Simulink 模型计算线性系统，并在 Nichols 图上绘制该线性系统。

在仿真过程中，软件对指定的线性化输入和输出之间的模型部分进行线性化，并绘制线性系统的开环增益和相位。

Simulink 模型可以是连续时间、离散时间或多速率模型，并且可以包含时延。由于在此模块中只能指定一个线性化输入/输出对，因此线性系统是单输入单输出 (SISO) 系统。

您可以指定多个开环和闭环增益及相位边界，并在 Nichols 图上查看这些边界。您还可以在仿真过程中检查是否满足这些边界：

- 如果满足所有边界，模块不执行任何操作。
- 如果某个边界不满足，模块将触发断言，并且 MATLAB® 命令行窗口中会出现一条警告消息。您还可以指定该模块执行以下操作：

  - 对 MATLAB 表达式求值。
  - 停止仿真并将焦点移至该模块。

在仿真过程中，该模块还可以输出逻辑断言信号。

- 如果满足所有边界，则信号为 true (`1`)。
- 如果有任何边界不满足，则信号为 false (`0`)。

您可以添加多个 Nichols Plot 模块，以计算并绘制模型各个部分的增益和相位。

您可以将线性系统作为变量保存到 MATLAB 工作区中。

该模块不支持代码生成，只能在 `Normal` 仿真模式下使用。
