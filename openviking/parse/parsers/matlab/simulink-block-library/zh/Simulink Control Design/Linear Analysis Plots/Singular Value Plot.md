### Linearize on

**设置**

**默认值：** `Simulation snapshots`

`Simulation snapshots`
:   特定仿真时间，在 **Snapshot times** 中指定。

    在以下情况下使用：

    - 知道模型处于稳态工作点的一个或多个时间
    - 希望在特定时间计算线性系统

`External trigger`
:   基于触发器的仿真事件。在 **Trigger type** 中指定触发器类型。

    当仿真期间生成的信号指示稳态工作点时使用。

    选择此选项会向模块添加一个触发端口。使用此端口将模块连接到触发信号。

    例如，对于飞机模型，您可能希望在燃油质量为最大燃油质量的某个比例时计算线性系统。在这种情况下，请将此条件建模为外部触发器。

**依赖关系**

- 将此参数设置为 `Simulation snapshots` 会启用 **Snapshot times**。
- 将此参数设置为 `External trigger` 会启用 **Trigger type**。

### Linear system sample time

仿真期间计算的线性系统的采样时间。

使用此参数可以：

- 根据连续时间系统计算具有特定采样时间的离散时间系统
- 以不同的采样时间对离散时间系统重新采样
- 根据离散时间系统计算连续时间系统

从连续时间系统计算离散时间系统（反之亦然）时，软件使用 **Sample time rate conversion method** 中指定的转换方法。

**设置**

**默认值：** `auto`

`auto`。采样时间计算如下：
:   - 对于连续时间模型，为 0。
    - 对于包含不同采样时间模块的模型（多速率模型），为各采样时间的最小公倍数。例如，如果混合使用连续时间和离散时间模块，采样时间分别为 0、0.2 和 0.3，则线性模型的采样时间为 0.6。

正有限值。用于计算：
:   - 根据连续时间系统计算离散时间线性系统。
    - 根据另一个具有不同采样时间的离散时间系统计算离散时间线性系统。

`0`
:   用于根据离散时间模型计算连续时间线性系统。

**命令行信息**

| --- |
| **参数：** `SampleTime` |
| **类型：** character vector |

### 采样时间速率转换方法

转换单速率或多速率模型采样时间的方法。

仅当**线性系统采样时间**的值不为 `auto` 时，才使用此参数。

**设置**

**默认值：** `Zero-Order Hold`

`Zero-Order Hold`
:   零阶保持，其中假定控制输入在采样时间 `Ts` 内分段恒定。有关详细信息，请参阅 Zero-Order Hold。

    此方法通常在时域中表现更好。

`Tustin (bilinear)`
:   不带频率预扭曲的双线性 (Tustin) 近似。软件将小数时延舍入为最接近采样时间的整数倍。有关详细信息，请参阅 Tustin 近似。

    此方法通常在频域中表现更好。

`Tustin with Prewarping`
:   带频率预扭曲的双线性 (Tustin) 近似。还需在**预扭曲频率 (rad/s)** 中指定预扭曲频率。有关详细信息，请参阅 Tustin 近似。

    此方法通常在频域中表现更好。使用此方法可确保在感兴趣的频率区域内实现匹配。

`Upsampling when possible, Zero-Order Hold otherwise`
:   尽可能对离散时间系统进行上采样，否则使用 `Zero-Order Hold`。

    仅当将离散时间系统转换为新的更快采样时间，且该采样时间是原系统采样时间的整数倍时，才能进行上采样。

`Upsampling when possible, Tustin otherwise`
:   尽可能对离散时间系统进行上采样，否则使用 `Tustin (bilinear)`。

    仅当将离散时间系统转换为新的更快采样时间，且该采样时间是原系统采样时间的整数倍时，才能进行上采样。

`Upsampling when possible, Tustin with Prewarping otherwise`
:   尽可能对离散时间系统进行上采样，否则使用 `Tustin with Prewarping`。还需在**预扭曲频率 (rad/s)** 中指定预扭曲频率。

    仅当将离散时间系统转换为新的更快采样时间，且该采样时间是原系统采样时间的整数倍时，才能进行上采样。

## 描述

根据非线性 Simulink 模型近似得到的线性系统的奇异值图

此模块与 Check Singular Value Characteristics 模块相同，只是 **Bounds** 选项卡中的默认参数设置不同。

从非线性 Simulink 模型计算线性系统，并在奇异值图上绘制该线性系统。

在仿真期间，软件对模型中位于指定线性化输入和输出之间的部分进行线性化，并绘制线性系统的奇异值。

Simulink 模型可以是连续时间、离散时间或多速率模型，并且可以包含时延。线性系统可以是单输入单输出 (SISO) 系统或多输入多输出 (MIMO) 系统。对于 MIMO 系统，模块会显示所有输入/输出组合的图。

您可以指定分段线性且与频率相关的奇异值上界和下界，并在图上查看这些边界。您还可以检查在仿真期间是否满足这些边界：

- 如果满足所有边界，模块不执行任何操作。
- 如果不满足某个边界，模块会触发断言，并在 MATLAB® 命令行窗口中显示警告消息。您还可以指定模块：

  - 计算 MATLAB 表达式。
  - 停止仿真，并将焦点置于该模块。

在仿真期间，模块还可以输出逻辑断言信号。

- 如果满足所有边界，信号为 true (`1`)。
- 如果不满足任何边界，信号为 false (`0`)。

对于 MIMO 系统，这些边界适用于针对所有输入/输出组合计算得到的线性系统的奇异值。

您可以添加多个 Singular Value Plot 模块，以计算并绘制模型各个部分的奇异值。

您可以将线性系统保存为 MATLAB 工作区中的变量。

该模块不支持代码生成，并且只能在 `Normal` 仿真模式下使用。
