# Bode Plot

## 端口

### 输入

### **Trigger** — 外部触发信号标量

使用此输入端口（由 External trigger 图标指示）连接外部触发信号，以计算模型线性化。要指定要检测的触发信号类型，请使用 **触发类型** 参数。

#### 依赖关系

要启用此端口，请将 **何时线性化** 参数设置为 `External trigger`。

### 输出

### **z–1** — 断言信号 `1` | `0`

将断言信号的值作为逻辑值输出。如果违反 **边界** 选项卡上指定的任何边界，则断言信号为 false（`0`）。否则，此信号为 true（`1`）。

默认情况下，输出信号的数据类型为 double。要将输出数据类型设置为 Boolean，请在 Simulink 模型中，在配置参数对话框中，选择 **将逻辑信号实现为 Boolean 数据** 参数。此设置适用于模型中生成逻辑信号的所有模块。

您可以使用断言信号设计复杂的断言逻辑。有关示例，请参阅使用 Simulink Control Design 和 Simulink Verification Blocks 验证模型。

#### 依赖关系

要启用此端口，请选择 **输出断言信号** 参数。

## 参数

### **显示绘图** — 打开绘图按钮

要在仿真期间查看计算得到的 Bode 图，请在开始仿真前单击此按钮。如果您在 **边界** 选项卡上指定了边界，这些边界也会显示在图上。

要在打开模块时显示绘图，请选择 **打开模块时显示绘图** 参数。

有关使用绘图的详细信息，请参阅使用绘图。

### **打开模块时显示绘图** — 打开模块时打开绘图 `off`（默认） | `on`

选择此参数可在打开模块时打开绘图。然后，您可以在绘图窗口中执行任务，例如添加或修改边界，而无需使用模块参数。要从绘图窗口访问模块参数，请选择 **编辑** 或单击参数图标。

有关使用绘图的详细信息，请参阅使用绘图。

### 线性化

要指定要线性化的模型部分和其他线性化设置，请使用 **线性化** 选项卡上的参数。此选项卡上的默认设置对于 Bode Plot 和 Check Bode Characteristics 模块相同。

### **线性化输入/输出** — 指定要线性化的模型部分线性分析点

要指定要线性化的模型部分，请从 Simulink 模型中选择信号，并将它们添加为线性化输入或输出。

线性化输入和输出表

在表中，**模块:端口:总线元素** 列显示每个信号的以下信息。

- 源模块
- 信号连接到的源模块的输出端口
- 总线元素名称（如果信号位于总线中）

在 **配置** 列中，从以下类型中选择线性分析点的类型。有关线性分析点的详细信息，请参阅指定要线性化的模型部分。

- `Open-loop Input` — 指定回路开环后的线性化输入点
- `Open-loop Output` — 指定回路开环前的线性化输出点
- `Loop Transfer` — 指定回路开环前的输出点，后跟一个输入
- `Input Perturbation` — 指定信号上的加性输入
- `Output Measurement` — 在信号处进行测量
- `Loop Break` — 指定回路开环
- `Sensitivity` — 指定加性输入，后跟输出测量
- `Complementary Sensitivity` — 指定输出，后跟加性输入

**注意**

如果在未指定线性化输入或输出的情况下仿真模型，软件将在 MATLAB 命令窗口中生成警告，并且不会计算线性系统。

### **何时线性化** — 何时计算线性模型 `Simulation snapshots`（默认） | `External trigger`

使用此参数指定您希望何时计算线性模型。

要在指定的仿真快照时间计算线性模型，请将此参数设置为 `Simulation snapshots`。使用 **快照时间** 参数指定快照时间。

在以下情况下使用仿真快照：

- 知道模型处于稳态工作点的一个或多个时间
- 想要在特定时间计算线性系统

要在基于触发的仿真事件中计算线性模型，请将此参数设置为 `External trigger`。选择此选项会向模块添加一个触发输入端口，您将外部触发信号连接到该端口。要指定要检测的触发类型，请使用 **触发类型** 参数。

当仿真期间生成的信号指示模型处于感兴趣的稳态条件时，请使用外部触发。例如，对于飞机模型，您可能希望每当燃料质量达到最大燃料质量的给定比例时计算线性系统。

### **启用过零检测** — 启用过零检测 `on`（默认） | `off`

选择此选项以启用过零检测。

当您将 **何时线性化** 参数设置为 `Simulation snapshots` 时，启用过零检测可确保软件在 **快照时间** 参数中指定的确切快照时间计算线性模型。

当您将 **何时线性化** 参数设置为 `External trigger` 时，启用过零检测可确保软件在检测到外部触发的确切时间计算线性模型。要指定触发类型，请使用 **触发类型** 参数。

如果清除此选项，软件将在变步长 Simulink 求解器选择的仿真时间计算线性系统，这可能不对应于确切的快照时间或检测到触发信号的确切时间。

例如，考虑变步长求解器选择仿真时间 *T**n*–1 和 *Tn* 的情况。如下图所示，指定的快照时间 *Tsnap* 可能位于所选仿真时间之间。如果启用过零检测，求解器还会在时间 *Tsnap* 仿真模型，并在该点计算线性模型。

类似地，外部触发可能在介于所选仿真时间之间的时间 *Ttrig* 被检测到。如果启用过零检测，求解器还会在时间 *Ttrig* 仿真模型，并在该点计算线性模型。

在两种情况下，如果未启用过零检测，软件将在 *T**n*–1 或 *Tn* 处计算线性模型。

有关过零检测的详细信息，请参阅过零检测。

#### 依赖关系

当您使用定步长 Simulink 求解器时，将忽略此参数。

### **线性系统采样时间** — 线性系统的采样时间 `'auto'`（默认） | 正有限值 | `0`

要使用指定的采样时间计算线性系统，软件将使用您在 **采样时间速率转换方法** 参数中指定的方法转换模型中的采样时间。

您可以将采样时间设置为以下值之一。

- `auto` — 如果模型中的所有模块都是连续时间，则使用采样时间 `0`。否则，将采样时间设置为模型中非零采样时间的最小公倍数。
- 正有限值 — 创建具有指定采样时间的离散时间模型。
- `0` — 创建连续时间模型。

### **采样时间速率转换方法** — 速率转换方法 `Zero-Order Hold`（默认） | `Tustin (bilinear)` | `Tustin with Prewarping` | ...

在线性化期间转换采样时间的方法，指定为以下值之一。

- `Zero-Order Hold` — 零阶保持，其中控制输入在采样时间 `Ts` 内假定为分段常数。此方法通常在时域中表现更好。
- `Tustin (bilinear)` — 不带频率预畸变的双线性（Tustin）近似。软件将分数时间延迟舍入到采样时间的最接近倍数。此方法通常在频域中表现更好。
- `Tustin with Prewarping` — 带频率预畸变的双线性（Tustin）近似。使用 **预畸变频率** 参数指定预畸变频率。此方法通常在频域中表现更好。使用此方法可确保在感兴趣的频率区域内匹配。
- `Upsampling when possible, Zero-Order Hold otherwise` — 在可能时对离散时间系统进行上采样；否则，使用零阶保持。
- `Upsampling when possible, Tustin otherwise` — 在可能时对离散时间系统进行上采样；否则，使用 Tustin 近似。
- `Upsampling when possible, Tustin with Prewarping otherwise` — 在可能时对离散时间系统进行上采样；否则，使用带频率预畸变的 Tustin 近似。

仅当将离散时间系统转换为新的更快采样时间（该采样时间是原始系统采样时间的整数倍）时，才能进行上采样。

有关多速率模型的速率转换和线性化的详细信息，请参阅：

- 多速率线性化算法
- 使用不同速率转换方法对模型进行线性化
- 连续-离散转换方法

**注意**

如果使用 `Zero-Order Hold` 以外的速率转换方法，则转换后的状态不再具有与原始状态相同的物理意义。因此，生成的 LTI 系统中的状态名称将更改为 `'?'`。

### **频率** — 上限幅值边界段的频率 vector | matrix | cell array

要定义 Bode 图的上限，请以 radians per second 为单位指定每个边界段的起始和结束频率。要指定无上限，请将此参数设置为 `[]`。

## 描述

从非线性 Simulink 模型计算得到的线性系统的 Bode 图

Bode Plot 和 Check Bode Characteristics 模块会从非线性 Simulink® 模型计算线性系统，并在仿真期间在 Bode 图上绘制该线性系统。除了 **边界**选项卡上的默认设置外，这些模块完全相同。

- Bode Plot 不定义默认边界。
- Check Bode Characteristics 模块定义默认边界并为断言启用这些边界。

有关线性系统频域分析的详细信息，请参阅频域响应。

在仿真期间，软件会在指定的线性化输入和输出之间对模型的一部分进行线性化，然后绘制该线性系统的幅值和相位。你还可以将该线性系统保存为 MATLAB® 工作区中的变量。

Simulink 模型可以是连续时间、离散时间或多速率模型，并且可以具有时间延迟。线性系统可以是单输入单输出 (SISO) 或多输入多输出 (MIMO)。对于 MIMO 系统，模块会显示所有输入/输出组合的图。

你可以指定分段线性的、频率相关的幅值上界和下界，并在 Bode 图上查看它们。你还可以在仿真期间检查是否满足这些边界。

- 如果满足所有边界，则模块不执行任何操作。
- 如果不满足某个边界，则模块会触发断言，并且警告消息会出现在 MATLAB 命令窗口中。你还可以指定该模块：

  - 计算一个 MATLAB 表达式。
  - 停止仿真并将该模块置于焦点。

在仿真期间，模块还可以输出逻辑断言信号。

- 如果满足所有边界，则该信号为 true (`1`)。
- 如果任何边界不满足，则该信号为 false (`0`)。

要计算并绘制模型各个部分的幅值和相位，你可以添加多个 Bode Plot 和 Check Bode Characteristics 模块。

这些模块不支持代码生成，并且只能在 `Normal` 仿真模式下使用。
