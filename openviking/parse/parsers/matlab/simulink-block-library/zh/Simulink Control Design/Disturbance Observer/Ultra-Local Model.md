# Ultra Local Model

## 端口

### 输入

### **u** — 被控对象输入标量

在此端口指定被控对象输入。

**数据类型：** `single` | `double`

### **y** — 被控对象输出标量

在此端口指定测量的被控对象输出。

**数据类型：** `single` | `double`

### 输出

### **Fhat** — 估计的扰动和未建模动态标量

模型中估计的扰动。该模块使用代数估计方法在一个小积分窗口上计算这些扰动。这些扰动可以同时包括未建模动态和外部扰动。

**数据类型：** `single` | `double`

### **yhat** — 估计输出标量

基于估计的 F^，在时间 *t*+*Ts* 对被控对象输出 *y* 的一步预测。

#### 依赖关系

要启用此端口，请选择 **Output estimated yhat**。

**数据类型：** `single` | `double`

## 参数

要以交互方式编辑模块参数，请使用 Property Inspector。在 Simulink® 工具条的 **Simulation** 选项卡上，在 **Prepare** 库中，选择 **Property Inspector**。

### **输入增益 (α)** — 输入增益 `1`（默认） | 非零有限标量

输入增益，指定为非零有限标量值。为使 ULM 正常工作，您不需要对输入增益 *α* 进行精确猜测。该模块要求您选择 *α* ∈ R，以近似平衡三个量 *y(n)*、*F(t)* 和 *αu(t)* 的幅值。估计的 F^ 会捕获 *α* 与真实被控对象值之间的任何失配。

#### 编程用法

要以编程方式设置模块参数值，请使用 `set_param` 函数。

|  |  |
| --- | --- |
| **参数：** | `alpha` |
| **值：** | `"1"`（默认） \| 用引号括起的非零有限标量 |

**示例：** `set_param(gcb,"alpha","2");`

### **模型阶数** — 超局部模型阶数 `1`（默认） | `2`

超局部模型的阶数，指定为一阶或二阶模型。

- 一阶 — y˙=F+αu
- 二阶 — y¨=F+αu

通常，ULM 模型阶数可以小于或等于真实被控对象阶数。此外，当您将 ULM 用作无模型控制结构的一部分以提供扰动补偿时，ULM 模型阶数的选择还取决于标称控制器的选择。例如，如果标称控制律是纯比例 (P) 或比例积分 (PI)，一阶 ULM 就足够。然而，如果标称控制律是比例微分 (PD) 或比例积分微分 (PID)，则需要二阶 ULM。

#### 编程用法

要以编程方式设置模块参数值，请使用 `set_param` 函数。

|  |  |
| --- | --- |
| **参数：** | `modelOrder` |
| **值：** | `"1"`（默认） \| `"2"` |

**示例：** `set_param(gcb,"modelOrder","2");`

### **估计器采样时间** — 估计器采样时间 `0.01`（默认）

估计器采样时间 *Ts* 是 ULM 更新其对 F^ 的估计的时间。更快的采样时间意味着用于估计的收集运行时数据更接近局部工作条件，从而提高估计精度。由于 ULM 的典型应用通常涉及将 F^ 作为控制律的一部分，因此它只需按控制器要求的速率运行。

#### 编程用法

要以编程方式设置模块参数值，请使用 `set_param` 函数。

|  |  |
| --- | --- |
| **参数：** | `Ts` |
| **值：** | `"0.01"`（默认） \| 用引号括起的正标量 |

**示例：** `set_param(gcb,"Ts","0.02");`

### **积分窗口（步数）** — 积分窗口 `3`（默认） | 大于 3 的正整数

积分窗口，指定为大于 3 的正整数。该模块使用代数估计算法估计 *F(t)*。为计算 F^，该算法在从时间 *t* − *N*×*Ts* 到当前时间 *t* 的积分窗口期间收集被控对象输入和输出信号。这里，*N* 是您可以在 ULM 模块中指定的*积分窗口*。该模块要求参数 *N* 至少为 3 才能正常工作。通常，*N* 不能太小，因为太小的 *N* 会降低数值积分精度和对测量噪声的鲁棒性。相反，*N* 不能太大，因为太大的 *N* 使用更多历史数据，这可能会阻止 F^ 准确反映局部被控对象行为。

#### 编程用法

要以编程方式设置模块参数值，请使用 `set_param` 函数。

|  |  |
| --- | --- |
| **参数：** | `numIntegrationSteps` |
| **值：** | `"3"`（默认） \| 用引号括起的大于 3 的正整数 |

**示例：** `set_param(gcb,"numIntegrationSteps","5");`

### **包含当前时刻输入以进行 F 估计** — 包含当前时刻输入以进行估计 `off`（默认） | `on`

用于估计 *F* 时包含当前被控对象输入和输出步长的标志。

- `off` — 仅使用被控对象数据 *u*(*t*) 和 *y*(*t*) 的过去 *N* 步来估计 *F*，其中 *N* 是积分窗口。
- `on` — 包含当前时间步的 *u*(*t*) 和 *y*(*t*) 数据来估计 *F*。积分窗口大小随后变为 *N*+1。

#### 编程用法

要以编程方式设置模块参数值，请使用 `set_param` 函数。

|  |  |
| --- | --- |
| **参数：** | `useCurrentdata` |
| **值：** | `"off"`（默认） \| `"on"` |

**示例：** `set_param(gcb,"useCurrentdata","on");`

### **输出估计的 yhat** — 输出的一步估计 `off`（默认） | `on`

启用此选项可在输出端口 **yhat** 返回基于估计的 F^ 在时间 *t*+*Ts* 对被控对象输出 *y* 的一步预测。该模块按如下方式计算：

- 一阶 — y^(t+Ts)=y^(t)+∫tt+Tsy^˙(τ)dτ,y^˙=F^+αu+L(y−y^)
- 二阶 — y^(t+Ts)=y^(t)+∫∫tt+Tsy^¨(τ)dτ,y^¨=F^+αu+L(y−y^)

#### 编程用法

要以编程方式设置模块参数值，请使用 `set_param` 函数。

|  |  |
| --- | --- |
| **参数：** | `enableYhatport` |
| **值：** | `"off"`（默认） \| `"on"` |

**示例：** `set_param(gcb,"enableYhatport","on");`

### **观测器增益 (L)** — 观测器增益 `0`（默认） | 非负标量

观测器增益，指定为非负标量。指定观测器增益有助于产生更准确的 **yhat** 估计。

#### 依赖关系

## 描述

将非线性被控对象估计为具有捕获未知动态和扰动的仿射项的单积分器或双积分器系统

超局部模型 (ULM) 是一种估计技术，允许您将非线性被控对象近似为具有捕获未知动态和扰动的仿射项的单积分器或双积分器系统。估计模型仅在短时间内对局部工作点有效。您可以使用 Ultra-Local Model 模块进行基于 ULM 的估计。使用此模块，您可以估计以下形式的一阶和二阶局部被控对象动态：

- 一阶 — y˙=F+αu
- 二阶 — y¨=F+αu

这里，*α* 是用于调优的输入增益，*F* 是组合不确定动态和外部扰动的仿射项。

您既可以将此模块用作独立估计器，以进行扰动估计和输出预测，也可以使用其扰动估计能力来提高标称控制器性能。

有关基于 ULM 的估计的详细信息，请参阅 Ultra-Local Model for Disturbance Estimation and Compensation。
