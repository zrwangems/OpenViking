# Varying State Space

## 端口

### 输入

### **u** — 系统输入 标量 | 向量

系统输入信号。

### **A** — 状态矩阵 矩阵

维度为 *Nx*×*Nx* 的状态矩阵，其中 *Nx* 是系统状态的数量。

### **B** — 输入矩阵 矩阵

维度为 *Nx*×*Nu* 的输入矩阵，其中 *Nu* 是系统输入的数量。

### **C** — 输出矩阵 矩阵

维度为 *Ny*×*Nx* 的输出矩阵，其中 *Ny* 是系统输出的数量。

### **D** — 前馈矩阵 矩阵

维度为 *Ny*×*Nu* 的前馈矩阵。

对于零直通状态空间模型，清除 **启用直通** 复选框。清除此复选框将禁用 **D** 输入端口。*（自 R2023a 起）*

### **dx0** — 状态导数偏移 矩阵

*自 R2024a 起*

维度为 *Nx*×1 的状态导数偏移，其中 *Nx* 是系统状态的数量。

#### 依赖项

要启用此端口，请选择 **启用状态导数偏移 dx0**。

### **x0** — 状态偏移 矩阵

*自 R2024a 起*

维度为 *Nx*×1 的状态偏移，其中 *Nx* 是系统状态的数量。

#### 依赖项

要启用此端口，请选择 **启用状态偏移 x0**。

### **u0** — 输入偏移 矩阵

*自 R2024a 起*

维度为 *Nu*×1 的输入偏移，其中 *Nu* 是系统输入的数量。

#### 依赖项

要启用此端口，请选择 **启用输入偏移 u0**。

### **y0** — 输出偏移 矩阵

*自 R2024a 起*

维度为 *Ny*×1 的输出偏移，其中 *Ny* 是系统输出的数量。

#### 依赖项

要启用此端口，请选择 **启用输出偏移 y0**。

### **IC** — 初始条件 向量

*自 R2024b 起*

用于启动仿真时与局部模型一起使用的初始条件，指定为长度等于模型状态数量的向量。

#### 依赖项

要启用此端口，请将 **初始条件来源** 设置为 `external`。

### 输出

### **y** — 系统输出 标量 | 向量

系统输出信号。

### **x** — 当前状态向量 向量

当前状态值。

#### 依赖项

要启用此端口，请选择 **输出状态** 参数。

### **dx** — 状态导数 向量

**x** 中对应状态的当前导数。

#### 依赖项

要启用此端口，请选择 **输出状态导数** 参数。

### R2024a：支持指定偏移

使用模块参数的 **偏移** 选项卡启用输入端口，以指定可变偏移的瞬时值。

### R2023a：添加了启用直通复选框

对于零直通状态空间模型，清除 **启用直通** 复选框。清除此复选框将禁用 **D** 输入端口。对于零直通模型，禁用该端口比向端口馈入零常数在数值上更可靠。

## 描述

具有可变矩阵值的状态空间模型

使用此模块实现具有可变矩阵的连续时间状态空间模型。将状态矩阵 *A*、输入矩阵 *B*、输出矩阵 *C* 和前馈矩阵 *D* 的瞬时值馈入相应的输入端口。系统响应由以下给出：

dx=Ax+Bu
y=Cx+Du

其中 *u* 是系统输入，*y* 是系统输出，*x* 和 *dx* 分别是状态向量和状态导数。

该模块还允许您指定可变偏移 *（自 R2024a 起）*。然后，系统响应由以下给出：

dx=dx0+A(x−x0)+B(u−u0)
y=y0+C(x−x0)+D(u−u0)

其中 *u*0 是输入偏移，*y*0 是输出偏移，*x*0 和 *dx*0 分别是状态偏移和状态导数偏移。

使用此模块以及 Linear Parameter Varying 库中的其他模块，通过可变参数或系数实现常见控制元素。有关详细信息，请参阅 Model Gain-Scheduled Control Systems in Simulink。

**注意**

避免使 **C** 和 **D** 矩阵依赖系统输出 **y**。如果存在这种依赖，则得到的状态空间方程 *y* = *C*(*y*)*x* + *D*(*y*)*u* 会产生代数环，因为计算输出值 *y* 需要知道输出值。这种代数环容易导致不稳定和发散。相反，尝试用时间 *t*、模块输入 **u** 和状态输出 **x** 表示 **C** 和 **D**。

出于类似原因，避免使 **A** 和 **B** 依赖 **dx** 输出。请注意，当 **y** 是状态和输入的固定组合时（换言之，当 *y* = *C**x* + *D**u*，其中 *C* 和 *D* 是常数矩阵时），**A** 和 **B** 依赖 **y** 是安全的。
