# Ideal Ground Truth Sensor

## 端口

### 输出

### **Object Detections** — 包含 MATLAB® 结构的对象检测 Simulink 总线

对象检测，以包含 MATLAB 结构的 Simulink 总线形式返回。有关总线的更多详细信息，请参阅 Create Nonvirtual Buses (Simulink)。

检测结构采用以下形式：

| 字段 | 描述 | 类型 |
| --- | --- | --- |
| `NumDetections` | 检测数 | Integer |
| `IsValidTime` | 当在模块调用间隔之间的时间请求更新时为 False | Boolean |
| `Detections` | 对象检测 | 由 **Maximum number of object detections reported** 参数设置长度的对象检测结构数组。其中只有 `NumDetections` 个检测是实际检测。 |

对象检测结构包含以下属性。

| 属性 | 定义 |
| --- | --- |
| `Time` | 测量时间 |
| `Measurement` | 对象测量值 |
| `MeasurementNoise` | 测量噪声协方差矩阵 |
| `SensorIndex` | 传感器的唯一 ID |
| `ObjectClassID` | 对象分类 |
| `MeasurementParameters` | 非线性 Kalman 跟踪滤波器的初始化函数所使用的参数 |
| `ObjectAttributes` | 传递给跟踪器的附加信息 |

`Measurement` 字段报告在 **Coordinate system used to report objects** 指定的坐标系中测量的位置和速度。此字段为形式为 [*x*; *y*; *z*; *vx*; *vy*; *vz*] 的实值列向量。单位为 meters per second。

`MeasurementNoise` 字段是一个 6×6 矩阵，报告 `Measurement` 字段中每个坐标的测量噪声协方差。

`MeasurementParameters` 字段是一个结构体，包含以下字段。

| 参数 | 定义 |
| --- | --- |
| `Frame` | 指示用于报告测量的坐标系的枚举类型。Ideal Ground Truth Sensor 模块以自车和传感器笛卡尔坐标系报告检测，二者均为直角坐标系。因此，对于此模块，`Frame` 始终设置为 `'rectangular'`。 |
| `OriginPosition` | 传感器原点相对于自车原点的 3-D 向量偏移。该向量派生自模块的 **Sensor's (x,y,z) position (m)** 参数。 |
| `Orientation` | 传感器坐标系相对于自车坐标系的姿态。该姿态派生自模块的 **Yaw angle of sensor mounted on ego vehicle (deg)**、**Pitch angle of sensor mounted on ego vehicle (deg)** 和 **Roll angle of sensor mounted on ego vehicle (deg)** 参数。 |
| `HasVelocity` | 指示测量是否包含速度。 |

每个检测的 `ObjectAttributes` 属性是一个结构体，包含以下字段。

| 字段 | 定义 |
| --- | --- |
| `TargetIndex` | 生成该检测的参与者（actor）的标识符 `ActorID`。对于虚警，此值为负数。 |

#### 依赖关系

要启用此输出端口，请设置以下选项：

- **Types of detections generated by sensor** 参数必须为 `Objects only` 或 `Objects and Lanes`
- **Output format of reported targets** 必须为 `Object Detections`。

### **Tracks** — 包含 MATLAB 结构的对象航迹 Simulink 总线

对象航迹，以包含 MATLAB 结构的 Simulink 总线形式返回。请参阅 Create Nonvirtual Buses (Simulink)。

下表显示了结构体字段。

| 字段 | 描述 |
| --- | --- |
| `NumTracks` | 航迹数 |
| `Tracks` | 由 **Maximum number of tracks** 参数设置长度的航迹结构数组。其中只有前 `NumTracks` 个是实际航迹。 |

下表显示了每个航迹结构体的字段。

| 字段 | 定义 |
| --- | --- |
| `TrackID` | 用于区分多个航迹的唯一航迹标识符。 |
| `BranchID` | 用于区分多个航迹分支的唯一航迹分支标识符。 |
| `SourceIndex` | 用于在多跟踪器环境中区分跟踪源的唯一源索引。 |
| `UpdateTime` | 航迹更新时间。单位为 seconds。 |
| `Age` | 航迹更新的次数。 |
| `State` | 更新时的状态向量值。 |
| `StateCovariance` | 不确定性协方差矩阵。 |
| `ObjectClassID` | 表示对象分类的整数值。值 `0` 表示未知分类。非零分类仅适用于已确认的航迹。 |
| `TrackLogic` | 确认和删除逻辑类型。对于雷达传感器，此值始终为 `'History'`，表示基于历史的逻辑。 |
| `TrackLogicState` | 航迹逻辑类型的当前状态，以 1×*K* 逻辑数组返回。*K* 是记录的最新航迹逻辑状态数。在数组中，`1` 表示命中，`0` 表示未命中。 |
| `IsConfirmed` | 确认状态。如果航迹被确认是真实目标，则此字段为 `true`。 |
| `IsCoasted` | 外推状态。如果航迹在没有新检测的情况下更新，则此字段为 `true`。 |
| `IsSelfReported` | 指示航迹是否由跟踪器报告。此字段用于航迹融合环境。默认返回 `true`。 |
| `ObjectAttributes` | 有关航迹的附加信息。 |

有关这些字段的更多详细信息，请参阅 `objectTrack`。

该模块为每个目标参与者输出一条航迹。

#### 依赖关系

要启用此端口，请在 **Parameters** 选项卡上，将 **Output format of reported targets** 参数设置为 `Tracks`。

### **Target Poses** — 包含 MATLAB 结构的目标位姿 Simulink 总线

目标位姿，以包含 MATLAB 结构的 Simulink 总线形式返回。

一个*目标位姿*定义目标在自车坐标系中的位置、速度和姿态。目标位姿还包括参与者位置和姿态的变化率。

该结构体包含以下字段：

| 字段 | 描述 |
| --- | --- |
| `ActorID` | 场景定义的参与者标识符，指定为正整数。 |
| `ClassID` | 分类标识符，指定为非负整数。`0` 表示未知或未分配类别的对象。 |
| `Position` | 参与者的位置，指定为形式为 [*x* *y* *z*] 的实值向量。单位为 meters。 |
| `Velocity` | 参与者在 *x*、*y* 和 *z* 方向上的速度 (*v*)，指定为形式为 [*v**x* *v**y* *v**z*] 的实值向量。单位为 meters per second。 |
| `Roll` | 参与者的横滚角，指定为实标量。单位为 degrees。 |
| `Pitch` | 参与者的俯仰角，指定为实标量。单位为 degrees。 |
| `Yaw` | 参与者的偏航角，指定为实标量。单位为 degrees。 |
| `AngularVelocity` | 参与者在 *x*、*y* 和 *z* 方向上的角速度 (*ω*)，指定为形式为 [*ω**x* *ω**y* *ω**z*] 的实值向量。单位为 degrees per second。 |

#### 依赖关系

要启用此端口，请在 **Parameters** 选项卡上，将 **Output format of reported targets** 参数设置为 `Target Poses`。

### **Lane Boundaries** — 包含 MATLAB 结构的车道边界检测 Simulink 总线

车道边界检测，以包含 MATLAB 结构的 Simulink 总线形式返回。该结构体包含以下字段：

|  |  |
| --- | --- |
| **字段** | **描述** |
| `Coordinates` | 车道边界坐标，以实值 *N*×3 矩阵返回，其中 *N* 是车道边界坐标的数量。车道边界坐标定义在沿道路中心、距自车纵向距离处边界上点的位置。该矩阵还包括距自车零距离处的边界坐标。这些坐标位于自车原点的左侧和右侧，自车原点位于后轴中心下方。单位为 meters。 |
| `Curvature` | `Coordinates` 矩阵每一行处的车道边界曲率，以实值 *N*×1 向量返回。*N* 是车道边界坐标的数量。单位为 radians per meter。 |
| `CurvatureDerivative` | `Coordinates` 矩阵每一行处的车道边界曲率导数，以实值 *N*×1 向量返回。*N* 是车道边界坐标的数量。单位为 radians per square meter。 |
| `HeadingAngle` | 初始车道边界航向角，以实标量返回。车道边界的航向角相对于自车航向。单位为 degrees。 |
| `LateralOffset` | 自车位置相对于车道边界的横向偏移，以实标量返回。自车左侧车道边界的偏移为正。自车右侧的偏移为负。单位为 meters。在此图中，自车与左侧车道偏移 1.5 米，与右侧车道偏移 2.1 米。 自车在行驶车道中 |
| `BoundaryType` | 车道边界标线类型，返回为以下值之一：  - `'Unmarked'` — 不存在物理车道标记 - `'Solid'`  — 单条连续线 - `'Dashed'` — 单条虚线车道标记 - `'DoubleSolid'` — 两条连续线 - `'DoubleDashed'` — 两条虚线 - `'SolidDashed'` — 左侧实线，右侧虚线 - `'DashedSolid'` — 左侧虚线，右侧实线 |
| `Strength` | 车道边界标线的饱和度强度，以 0 到 1 的实标量返回。值 `0` 对应颜色完全不饱和的标线。该标线为灰色。值 `1` 对应颜色完全饱和的标线。 |
| `Width` | 车道边界宽度，以正实标量返回。在双线车道标记中，两条线以及线间空间使用相同宽度。单位为 meters。 |
| `Length` | 虚线中虚线的长度，以正实标量返回。在双线车道标记中，两条线使用相同长度。 |
| `Space` | 虚线中虚线之间的间隔长度，以正实标量返回。在虚线双线车道标记中，两条线使用相同间隔。 |

#### 依赖关系

要启用此输出端口，请将 **Types of detections generated by sensor** 参数设置为 `Objects and Lanes`。

## 参数

要交互式编辑模块参数，请使用 Property Inspector。在 Simulink 工具条的 **Simulation** 选项卡上，在 **Prepare** 库中，选择 **Property Inspector**。

### **Unique identifier of sensor** — 唯一传感器标识符，正整数

唯一传感器标识符，指定为正整数。此参数用于区分多传感器系统中来自不同传感器的检测。

**示例：** `5`

**数据类型：** `double`

### **Types of detections generated by sensor** — 选择由传感器生成的检测类型 `Objects Only`（默认） | `Objects and Lanes`

由传感器生成的检测类型，指定为 `Objects Only` 或 `Objects and Lanes`。

- 设置为 `Objects Only` 时，仅检测参与者。
- 设置为 `Objects and Lanes` 时，传感器同时生成对象检测和未被遮挡的车道检测。

### **Required interval between sensor updates (s)** — 传感器更新之间的必需时间间隔 `0.1` | 正实标量

传感器更新之间的必需时间间隔，指定为正实标量。`drivingScenario` 对象按固定时间间隔调用 Ideal Ground Truth Sensor。传感器按此参数定义的间隔生成新检测，该间隔必须是仿真时间间隔的整数倍。在更新间隔之间从传感器请求的更新不包含检测。单位为 seconds。

**示例：** `5`

**数据类型：** `double`

#### 传感器外参和测量

### **Sensor's (x,y,z) position (m)** — 自车上的传感器安装位置 `[1.9 0 0.2]`（默认） | 形式为 [*x* *y* *z*] 的 1×3 实值向量

自车上的传感器安装位置，指定为形式为 [*x* *y* *z*] 的 1×3 实值向量。此参数定义传感器相对于自车原点沿 *x*、*y* 和 *z* 轴的坐标，单位为 meters，其中：

- *x* 轴从车辆向前指向。
- *y* 轴指向车辆左侧。
- *z* 轴从地面向上指向。

默认值定义了一个安装在轿车前格栅中心的传感器。

有关自车坐标系的更多详细信息，请参阅 Coordinate Systems in Automated Driving Toolbox。

**数据类型：** `double`

### **Yaw angle of sensor mounted on ego vehicle (deg)** — 传感器的偏航角 `0`（默认） | 实标量

传感器的偏航角，指定为实标量。偏航角是自车中心线与传感器下视距离轴之间的角度。正偏航角对应于沿自车坐标系 *z* 轴正方向观察时的顺时针旋转。单位为 degrees。

**示例：** `-4`

**数据类型：** `double`

### **Pitch angle of sensor mounted on ego vehicle (deg)** — 传感器的俯仰角 `0`（默认） | 实标量

传感器的俯仰角，指定为实标量。俯仰角是传感器下视距离轴与自车坐标系 *x-y* 平面之间的角度。正俯仰角对应于沿自车坐标系 *y* 轴正方向观察时的顺时针旋转。单位为 degrees。

**示例：** `3`

**数据类型：** `double`

### **Roll angle of sensor mounted on ego vehicle (deg)** — 传感器的横滚角 `0`（默认） | 实标量

传感器的横滚角，指定为实标量。横滚角是传感器下视距离轴绕自车坐标系 *x* 轴旋转的角度。正横滚角对应于沿坐标系 *x* 轴正方向观察时的顺时针旋转。单位为 degrees。

**示例：** `-4`

**数据类型：** `double`

### **Field of view [Azimuth, Elevation] (deg)** — 传感器的角度视场 `[120 30]`（默认） | 正值的 1×2 实值向量

传感器的角度视场，指定为形式为 `[azfov,elfov]` 的正值 1×2 实值向量。视场定义传感器图像的方位角和俯仰角范围。每个分量必须位于 0 度到 180 度的区间内。传感器角度视场外的目标不会被检测。单位为 degrees。

**数据类型：** `double`

### **Maximum detection range (m)** — 传感器的最大检测距离 `50`（默认） | 正实标量

传感器的最大检测距离，指定为正实标量。传感器无法检测超出此距离的目标。单位为 meters。

**示例：** `200`

**数据类型：** `double`

#### 检测报告

### **Coordinate system used to report objects** — 报告检测所使用的坐标系 `Host Coordinates`（默认） | `Sensor Coordinates`

报告检测的坐标系，指定为以下选项之一：

- `Host Coordinates` — 检测在自车笛卡尔坐标系中报告。
- `Sensor Coordinates` — 检测在传感器笛卡尔坐标系中报告。

### **Point on target used to report position** — 用于报告位置的目标上的点 `Origin Point`（默认） | `Closest Point` | `Rear Center`

用于报告地面真值位置的目标参与者上的点，指定为以下选项之一：

- `Origin Point` — 传感器报告目标参与者局部坐标系的原点。对于 driving scenario 车辆参与者，原点是其后轴中心。对于 RoadRunner Scenario 车辆参与者，原点是其几何中心。
- `Closest Point` — 传感器报告目标参与者上最接近传感器的点。
- `Rear Center` — 传感器报告目标参与者的后部中心。

### **Output format of reported targets** — 传感器报告目标参与者的格式 `Object detections`（默认） | `Tracks` | `Target Poses`

传感器报告目标参与者的格式，指定为以下选项之一：

- `Object detections` — 传感器生成目标报告作为 **Object Detections** 输出端口中描述的对象检测。
- `Tracks` — 传感器生成目标报告作为*航迹*，即已经过跟踪滤波器处理的聚类检测。传感器按 **Tracks** 输出端口中所述返回航迹。
- `Target Poses` — 传感器生成目标位姿，如 **Target Poses** 输出端口中所述。

### **Maximum number of object detections reported** — 传感器报告的最大对象检测数 `300`（默认） | 正整数

传感器报告的最大对象检测数，指定为正整数。报告最接近传感器的检测。

**数据类型：** `double`

### **Lane boundaries reported by sensor** — 传感器报告的车道边界 `Ego Lane`（默认） | `Ego and Adjacent Lanes` | `All Lanes`

传感器报告的车道边界，指定为以下选项之一：

- `Ego Lane` — 传感器返回主车参与者所行驶车道的边界。
- `Ego and Adjacent Lanes` — 传感器返回相邻左、右车道以及主车参与者所行驶车道的边界。
- `All Lanes` — 传感器返回道路上所有车道的边界。

#### 依赖关系

要启用此参数，请先将 **Types of detections generated by sensor** 参数设置为 `Objects and Lanes`。

### **Maximum number of lane boundary detections reported** — 报告的最大车道边界检测数 `300`（默认） | 正整数

报告的最大车道数，指定为正整数。

#### 依赖关系

要启用此参数，请先将 **Types of detections generated by sensor** 参数设置为 `Objects and Lanes`。

**数据类型：** `double`

## 描述

从 driving scenario 或 RoadRunner Scenario 生成地面真值测量，作为传感器检测或航迹报告

Ideal Ground Truth Sensor 模块为视场内目标参与者的地面真值测量生成检测或航迹报告。它还将地面真值车道边界生成为车道检测。使用此模块可从包含参与者和轨迹的 driving scenario 生成地面真值数据作为传感器检测，您可以从 Scenario Reader 模块读取这些数据。在 driving scenario 中使用时，该模块仅为场景中的车辆参与者生成检测。

您可以在 RoadRunner Scenario 仿真中将该模块与车辆参与者一起使用。在 RoadRunner Scenario 仿真中使用时，该模块为车辆参与者以及其他静态参与者（如建筑物、交通锥等）生成地面真值检测。有关更多信息，请参阅 Add Sensors to RoadRunner Scenario Using Simulink example。
