# Ideal Ground Truth Sensor

## 端口

### 输出

### **Object Detections** — 目标检测，返回为包含 MATLAB® 结构的 Simulink 总线

目标检测，返回为包含 MATLAB 结构的 Simulink 总线。有关总线的更多详细信息，请参阅 Create Nonvirtual Buses (Simulink)。

检测结构具有以下形式：

| 字段 | 描述 | 类型 |
| --- | --- | --- |
| `NumDetections` | 检测数量 | 整数 |
| `IsValidTime` | 当在模块调用间隔之间的时间请求更新时为 False | 布尔值 |
| `Detections` | 目标检测 | 目标检测结构的数组，其长度由 **Maximum number of object detections reported** 参数设置。这些检测中只有 `NumDetections` 个是实际检测。 |

目标检测结构包含以下属性。

| 属性 | 定义 |
| --- | --- |
| `Time` | 测量时间 |
| `Measurement` | 目标测量值 |
| `MeasurementNoise` | 测量噪声协方差矩阵 |
| `SensorIndex` | 传感器的唯一 ID |
| `ObjectClassID` | 目标分类 |
| `MeasurementParameters` | 非线性卡尔曼跟踪滤波器初始化函数使用的参数 |
| `ObjectAttributes` | 传递给跟踪器的附加信息 |

`Measurement` 字段报告测量值在 **Coordinate system used to report objects** 指定的坐标系中的位置和速度。该字段为实数-valued 列向量，形式为 [*x*; *y*; *z*; *vx*; *vy*; *vz*]。单位为米每秒。

`MeasurementNoise` 字段是一个 6×6 矩阵，报告 `Measurement` 字段中每个坐标的测量噪声协方差。

`MeasurementParameters` 字段是一个结构体，包含以下字段。

| 参数 | 定义 |
| --- | --- |
| `Frame` | 枚举类型，指示用于报告测量值的坐标系框架。Ideal Ground Truth Sensor 模块以自车和传感器笛卡尔坐标报告检测，两者均为矩形坐标系框架。因此，对于此模块，`Frame` 始终设置为 `'rectangular'`。 |
| `OriginPosition` | 传感器原点相对于自车原点的 3-D 向量偏移。该向量派生自模块的 **Sensor's (x,y,z) position (m)** 参数。 |
| `Orientation` | 传感器坐标系相对于自车坐标系的方向。该方向派生自模块的 **Yaw angle of sensor mounted on ego vehicle (deg)**、**Pitch angle of sensor mounted on ego vehicle (deg)** 和 **Roll angle of sensor mounted on ego vehicle (deg)** 参数。 |
| `HasVelocity` | 指示测量值是否包含速度。 |

每个检测的 `ObjectAttributes` 属性是一个结构体，包含以下字段。

| 字段 | 定义 |
| --- | --- |
| `TargetIndex` | 生成该检测的参与者 `ActorID` 的标识符。对于虚警，此值为负数。 |

#### 依赖关系

要启用此输出端口，请设置以下选项：

- **Types of detections generated by sensor** 参数必须为 `Objects only` 或 `Objects and Lanes`
- **Output format of reported targets** 必须为 `Object Detections`。

### **Tracks** — 目标航迹，返回为包含 MATLAB 结构的 Simulink 总线

目标航迹，返回为包含 MATLAB 结构的 Simulink 总线。请参阅 Create Nonvirtual Buses (Simulink)。

下表显示了结构体字段。

| 字段 | 描述 |
| --- | --- |
| `NumTracks` | 航迹数量 |
| `Tracks` | 航迹结构的数组，其长度由 **Maximum number of tracks** 参数设置。其中只有前 `NumTracks` 个是实际航迹。 |

下表显示了每个航迹结构的字段。

| 字段 | 定义 |
| --- | --- |
| `TrackID` | 用于区分多个航迹的唯一航迹标识符。 |
| `BranchID` | 用于区分多个航迹分支的唯一航迹分支标识符。 |
| `SourceIndex` | 用于在多跟踪器环境中区分跟踪源的唯一源索引。 |
| `UpdateTime` | 航迹更新的时间。单位为秒。 |
| `Age` | 航迹更新的次数。 |
| `State` | 更新时刻的状态向量值。 |
| `StateCovariance` | 不确定性协方差矩阵。 |
| `ObjectClassID` | 表示目标分类的整数值。值 `0` 表示未知分类。非零分类仅适用于已确认的航迹。 |
| `TrackLogic` | 确认和删除逻辑类型。对于雷达传感器，此值始终为 `'History'`，表示基于历史的逻辑。 |
| `TrackLogicState` | 航迹逻辑类型的当前状态，返回为 1×*K* 逻辑数组。*K* 是记录的最新航迹逻辑状态的数量。在数组中，`1` 表示命中，`0` 表示未命中。 |
| `IsConfirmed` | 确认状态。如果航迹被确认为真实目标，此字段为 `true`。 |
| `IsCoasted` | 滑行状态。如果航迹在没有新检测的情况下更新，此字段为 `true`。 |
| `IsSelfReported` | 指示航迹是否由跟踪器报告。此字段用于航迹融合环境。默认返回 `true`。 |
| `ObjectAttributes` | 关于航迹的附加信息。 |

有关这些字段的更多详细信息，请参阅 `objectTrack`。

该模块为每个目标参与者输出一条航迹。

#### 依赖关系

要启用此端口，请在 **Parameters** 选项卡上，将 **Output format of reported targets** 参数设置为 `Tracks`。

### **Target Poses** — 目标位姿，返回为包含 MATLAB 结构的 Simulink 总线

目标位姿，返回为包含 MATLAB 结构的 Simulink 总线。

*目标位姿* 定义了目标在自车坐标系中的位置、速度和方向。目标位姿还包括参与者位置和方向的变化率。

该结构体包含以下字段：

| 字段 | 描述 |
| --- | --- |
| `ActorID` | 场景定义的参与者标识符，指定为正整数。 |
| `ClassID` | 分类标识符，指定为非负整数。`0` 表示未知或未分配类别的目标。 |
| `Position` | 参与者的位置，指定为形式为 [*x* *y* *z*] 的实数值向量。单位为米。 |
| `Velocity` | 参与者在 *x*、*y* 和 *z* 方向上的速度 (*v*)，指定为形式为 [*v**x* *v**y* *v**z*] 的实数值向量。单位为米每秒。 |
| `Roll` | 参与者的横滚角，指定为实数标量。单位为度。 |
| `Pitch` | 参与者的俯仰角，指定为实数标量。单位为度。 |
| `Yaw` | 参与者的偏航角，指定为实数标量。单位为度。 |
| `AngularVelocity` | 参与者在 *x*、*y* 和 *z* 方向上的角速度 (*ω*)，指定为形式为 [*ω**x* *ω**y* *ω**z*] 的实数值向量。单位为度每秒。 |

#### 依赖关系

要启用此端口，请在 **Parameters** 选项卡上，将 **Output format of reported targets** 参数设置为 `Target Poses`。

### **Lane Boundaries** — 车道边界检测，返回为包含 MATLAB 结构的 Simulink 总线

车道边界检测，返回为包含 MATLAB 结构的 Simulink 总线。该结构体包含以下字段：

|  |  |
| --- | --- |
| **字段** | **描述** |
| `Coordinates` | 车道边界坐标，返回为实数 *N*×3 矩阵，其中 *N* 是车道边界坐标的数量。车道边界坐标定义了边界上各点的位置，这些点位于沿道路中心距自车的返回纵向距离处。该矩阵还包括距自车零距离处的边界坐标。这些坐标位于自车原点的左侧和右侧，自车原点位于后轴中心下方。单位为米。 |
| `Curvature` | `Coordinates` 矩阵每一行处的车道边界曲率，返回为实数 *N*×1 向量。*N* 是车道边界坐标的数量。单位为弧度每米。 |
| `CurvatureDerivative` | `Coordinates` 矩阵每一行处的车道边界曲率导数，返回为实数 *N*×1 向量。*N* 是车道边界坐标的数量。单位为弧度每平方米。 |
| `HeadingAngle` | 初始车道边界航向角，返回为实数标量。车道边界的航向角相对于自车航向。单位为度。 |
| `LateralOffset` | 自车位置相对于车道边界的横向偏移，返回为实数标量。自车左侧车道边界的偏移为正。自车右侧的偏移为负。单位为米。在此图中，自车距左侧车道偏移 1.5 米，距右侧车道偏移 2.1 米。 自车在行驶车道中 |
| `BoundaryType` | 车道边界标线类型，返回为以下值之一：  - `'Unmarked'` — 不存在物理车道标记 - `'Solid'` — 单条不间断线 - `'Dashed'` — 单条虚线车道标记线 - `'DoubleSolid'` — 两条不间断线 - `'DoubleDashed'` — 两条虚线 - `'SolidDashed'` — 左侧为实线，右侧为虚线 - `'DashedSolid'` — 左侧为虚线，右侧为实线 |
| `Strength` | 车道边界标线的饱和度强度，返回为 0 到 1 之间的实数标量。值 `0` 对应于颜色完全不饱和的标线。标线为灰色。值 `1` 对应于颜色完全饱和的标线。 |
| `Width` | 车道边界宽度，返回为正实数标量。在双线车道标记中，两条线以及线之间的间隔使用相同的宽度。单位为米。 |
| `Length` | 虚线中虚线的长度，返回为正实数标量。在双线车道标记中，两条线使用相同的长度。 |
| `Space` | 虚线中虚线之间的间隔长度，返回为正实数标量。在虚线双线车道标记中，两条线使用相同的间隔。 |

#### 依赖关系

要启用此输出端口，请将 **Types of detections generated by sensor** 参数设置为 `Objects and Lanes`。

## 参数

要以交互方式编辑模块参数，请使用 Property Inspector。在 Simulink Toolstrip 中，在 **Simulation** 选项卡上，在 **Prepare** 库中，选择 **Property Inspector**。

### **Unique identifier of sensor** — 唯一传感器标识符，正整数

唯一传感器标识符，指定为正整数。此参数用于区分多传感器系统中来自不同传感器的检测。

**示例：** `5`

**数据类型：** `double`

### **Types of detections generated by sensor** — 选择传感器生成的检测类型 `Objects Only`（默认）| `Objects and Lanes`

传感器生成的检测类型，指定为 `Objects Only` 或 `Objects and Lanes`。

- 设置为 `Objects Only` 时，仅检测参与者。
- 设置为 `Objects and Lanes` 时，传感器同时生成目标检测和未遮挡的车道检测。

### **Required interval between sensor updates (s)** — 传感器更新之间的所需时间间隔 `0.1` | 正实数标量

传感器更新之间的所需时间间隔，指定为正实数标量。`drivingScenario` 对象以固定时间间隔调用理想真值传感器。传感器以此参数定义的间隔生成新检测，该参数必须是仿真时间间隔的整数倍。在更新间隔之间从传感器请求的更新不包含检测。单位为秒。

**示例：** `5`

**数据类型：** `double`

#### 传感器外参和测量

### **Sensor's (x,y,z) position (m)** — 传感器在自车上的安装位置 `[1.9 0 0.2]`（默认）| 形式为 [*x* *y* *z*] 的 1×3 实数值向量

传感器在自车上的安装位置，指定为形式为 [*x* *y* *z*] 的 1×3 实数值向量。此参数定义了传感器相对于自车原点沿 *x*、*y* 和 *z* 轴的坐标（以米为单位），其中：

- *x* 轴指向车辆前方。
- *y* 轴指向车辆左侧。
- *z* 轴从地面指向上方。

默认值定义了一个安装在轿车前格栅中心的传感器。

有关自车坐标系的更多详细信息，请参阅 Coordinate Systems in Automated Driving Toolbox。

**数据类型：** `double`

### **Yaw angle of sensor mounted on ego vehicle (deg)** — 传感器偏航角 `0`（默认）| 实数标量

传感器的偏航角，指定为实数标量。偏航角是自车中心线与传感器下视距离轴之间的角度。正偏航角对应于沿自车坐标系 *z* 轴正方向观察时的顺时针旋转。单位为度。

**示例：** `-4`

**数据类型：** `double`

### **Pitch angle of sensor mounted on ego vehicle (deg)** — 传感器俯仰角 `0`（默认）| 实数标量

传感器的俯仰角，指定为实数标量。俯仰角是传感器下视距离轴与自车坐标系 *x-y* 平面之间的角度。正俯仰角对应于沿自车坐标系 *y* 轴正方向观察时的顺时针旋转。单位为度。

**示例：** `3`

**数据类型：** `double`

### **Roll angle of sensor mounted on ego vehicle (deg)** — 传感器横滚角 `0`（默认）| 实数标量

传感器的横滚角，指定为实数标量。横滚角是传感器下视距离轴绕自车坐标系 *x* 轴旋转的角度。正横滚角对应于沿坐标系 *x* 轴正方向观察时的顺时针旋转。单位为度。

**示例：** `-4`

**数据类型：** `double`

### **Field of view [Azimuth, Elevation] (deg)** — 传感器的角度视场 `[120 30]`（默认）| 正实数值 1×2 向量

传感器的角度视场，指定为正实数值 1×2 向量 `[azfov,elfov]`。视场定义了传感器图像的方位角和俯仰角范围。每个分量必须位于 0 度到 180 度的区间内。位于传感器角度视场之外的目标不会被检测到。单位为度。

**数据类型：** `double`

### **Maximum detection range (m)** — 传感器的最大检测距离 `50`（默认）| 正实数标量

传感器的最大检测距离，指定为正实数标量。传感器无法检测超出此距离的目标。单位为米。

**示例：** `200`

**数据类型：** `double`

#### 检测报告

### **Coordinate system used to report objects** — 报告检测的坐标系 `Host Coordinates`（默认）| `Sensor Coordinates`

报告检测的坐标系，指定为以下选项之一：

- `Host Coordinates` — 检测以自车笛卡尔坐标系报告。
- `Sensor Coordinates` — 检测以传感器笛卡尔坐标系报告。

### **Point on target used to report position** — 用于报告位置的目标上的点 `Origin Point`（默认）| `Closest Point` | `Rear Center`

用于报告真值位置的目标上的点，指定为以下选项之一：

- `Origin Point` — 传感器报告目标 actor 的局部坐标系原点。对于 driving scenario 车辆 actor，原点为其后轴中心。对于 RoadRunner Scenario 车辆 actor，原点为其几何中心。
- `Closest Point` — 传感器报告目标 actor 上距离传感器最近的点。
- `Rear Center` — 传感器报告目标 actor 的后部中心。

### **Output format of reported targets** — 传感器报告目标 actor 的格式 `Object detections`（默认）| `Tracks` | `Target Poses`

传感器报告目标 actor 的格式，指定为以下选项之一：

- `Object detections` — 传感器生成目标报告作为 **Object Detections** 输出端口中所描述的目标检测。
- `Tracks` — 传感器生成目标报告作为 *tracks*，即经过跟踪滤波器处理的聚类检测。传感器按照 **Tracks** 输出端口中的描述返回 tracks。
- `Target Poses` — 传感器按照 **Target Poses** 输出端口中的描述生成目标位姿。

### **Maximum number of object detections reported** — 传感器报告的最大目标检测数 `300`（默认）| 正整数

传感器报告的最大目标检测数，指定为正整数。报告距离传感器最近的检测。

**Data Types:** `double`

### **Lane boundaries reported by sensor** — 传感器报告的车道边界 `Ego Lane`（默认）| `Ego and Adjacent Lanes` | `All Lanes`

传感器报告的车道边界，指定为以下选项之一：

- `Ego Lane` — 传感器返回主车 actor 所行驶车道的边界。
- `Ego and Adjacent Lanes` — 传感器返回主车 actor 所行驶车道以及相邻左右车道的边界。
- `All Lanes` — 传感器返回道路上所有车道的边界。

#### 依赖关系

要启用此参数，请先将 **Types of detections generated by sensor** 参数设置为 `Objects and Lanes`。

### **Maximum number of lane boundary detections reported** — 报告的最大车道数 `300`（默认）| 正整数

报告的最大车道数，指定为正整数。

#### 依赖关系

要启用此参数，请先将 **Types of detections generated by sensor** 参数设置为 `Objects and Lanes`。

**Data Types:** `double`

- `Auto` — 模块自动创建总线名称。

### **Specify an output object bus name** — 输出目标总线名称 `BusSSFGroundTruthObjects`（默认）| 有效总线名称

车道检测总线名称的来源，指定为以下选项之一：

- `Auto` — 模块自动创建总线名称。
- `Property` — 使用 **Specify an output lane bus name** 参数指定总线名称。

### **Specify an output lane bus name** — 输出目标总线名称 `BusSSFGroundTruthLaneBoundaries`（默认）| 有效总线名称

指定 **Lane Boundaries** 输出端口中返回的目标检测总线的名称。

## 描述

从 driving scenario 或 RoadRunner Scenario 生成真值测量作为传感器检测或跟踪报告

Ideal Ground Truth Sensor 模块针对视场中目标 actor 的真值测量生成检测或跟踪报告。它还将真值车道边界生成为车道检测。使用此模块可从包含 actor 和轨迹的 driving scenario 生成真值数据作为传感器检测，这些数据可从 Scenario Reader 模块读取。在 driving scenario 中使用时，该模块仅为场景中的车辆 actor 生成检测。

您可以将该模块与 RoadRunner Scenario 仿真中的车辆 actor 一起使用。在 RoadRunner Scenario 仿真中使用时，该模块会为车辆 actor 以及建筑物、交通锥等其他静态 actor 生成真值检测。有关详细信息，请参阅 Add Sensors to RoadRunner Scenario Using Simulink 示例。
