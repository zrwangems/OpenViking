# Vision Detection Generator

## 端口
```yaml
ports:
- name: Actors
  summary: 场景参与者位姿 包含 MATLAB® 结构的 Simulink 总线
  direction: input
- name: Lane Boundaries
  summary: 车道边界 包含 MATLAB 结构的 Simulink 总线
  direction: input
- name: Object Detections
  summary: 目标检测 包含 MATLAB 结构的 Simulink 总线
  direction: output
- name: Lane Detections
  summary: 车道边界检测 包含 MATLAB 结构的 Simulink 总线
  direction: output
```

### 输入

### **Actors** — 场景参与者位姿 包含 MATLAB® 结构的 Simulink 总线

自车坐标系中的场景参与者位姿，指定为包含 MATLAB 结构的 Simulink 总线。

该结构必须包含以下字段。

| 字段 | 描述 | 类型 |
| --- | --- | --- |
| `NumActors` | 参与者数量 | 非负整数 |
| `Time` | 当前仿真时间 | 实值标量 |
| `Actors` | 参与者位姿 | 长度为 `NumActors` 的参与者位姿结构体数组 |

`Actors` 中的每个参与者位姿结构体必须包含以下字段。

| 字段 | 描述 |
| --- | --- |
| `ActorID` | 场景定义的参与者标识符，指定为正整数。 |
| *在 R2024b 中：* `FrontAxlePosition` | 车辆的前轴位置，指定为三元素行向量，形式为 [*x* *y* *z*]。单位为米。 **注意** 如果驾驶场景中至少有一辆车不包含前轴轨迹，则 `ActorPoses` 结构体不包含此字段。 |
| `Position` | 参与者的位置，指定为实值向量，形式为 [*x* *y* *z*]。单位为米。 |
| `Velocity` | 参与者在 *x*、*y* 和 *z* 方向上的速度 (*v*)，指定为实值向量，形式为 [*v**x* *v**y* *v**z*]。单位为米每秒。 |
| `Roll` | 参与者的横滚角，指定为实值标量。单位为度。 |
| `Pitch` | 参与者的俯仰角，指定为实值标量。单位为度。 |
| `Yaw` | 参与者的偏航角，指定为实值标量。单位为度。 |
| `AngularVelocity` | 参与者在 *x*、*y* 和 *z* 方向上的角速度 (*ω*)，指定为实值向量，形式为 [*ω**x* *ω**y* *ω**z*]。单位为度每秒。 |

#### 依赖关系

要启用此输入端口，请将 **Types of detections generated by sensor** 参数设置为 `Objects only`、`Lanes with occlusion` 或 `Lanes and objects`。

### **Lane Boundaries** — 车道边界 包含 MATLAB 结构的 Simulink 总线

自车坐标系中的车道边界，指定为包含 MATLAB 结构的 Simulink 总线。

该结构必须包含以下字段。

| 字段 | 描述 | 类型 |
| --- | --- | --- |
| `NumLaneBoundaries` | 车道边界数量 | 非负整数 |
| `Time` | 当前仿真时间 | 实值标量 |
| `LaneBoundaries` | 从相对于自车的最左侧车道开始的车道边界。 | 长度为 `NumLaneBoundaries` 的车道边界结构体数组 |

`LaneBoundaries` 中的每个车道边界结构体必须包含以下字段。

|  |  |
| --- | --- |
| **字段** | **描述** |
| `Coordinates` | 车道边界坐标，指定为实值 *N*×3 矩阵，其中 *N* 是车道边界坐标的数量。车道边界坐标定义了沿道路中心、距自车指定纵向距离处边界上点的位置。 - 在 MATLAB 中，使用 `laneBoundaries` 函数的 `'XDistance'` 名称-值对参数指定这些距离。 - 在 Simulink 中，使用 Scenario Reader 模块的 **Distances from ego vehicle for computing boundaries (m)** 参数或 Simulation 3D Vision Detection Generator 模块的 **Distance from parent for computing lane boundaries** 参数指定这些距离。 此矩阵还包含距自车零距离处的边界坐标。这些坐标位于自车原点的左侧和右侧，自车原点位于后轴中心下方。单位为米。 |
| `Curvature` | `Coordinates` 矩阵每一行处的车道边界曲率，指定为实值 *N*×1 向量。*N* 是车道边界坐标的数量。单位为弧度每米。 |
| `CurvatureDerivative` | `Coordinates` 矩阵每一行处的车道边界曲率导数，指定为实值 *N*×1 向量。*N* 是车道边界坐标的数量。单位为弧度每平方米。 |
| `HeadingAngle` | 初始车道边界航向角，指定为实值标量。车道边界的航向角相对于自车航向。单位为度。 |
| `LateralOffset` | 自车位置相对于车道边界的横向偏移，指定为实值标量。自车左侧车道边界的偏移为正值。自车右侧的偏移为负值。单位为米。在此图中，自车距左侧车道偏移 1.5 米，距右侧车道偏移 2.1 米。 行驶车道中的自车 |
| `BoundaryType` | 车道边界标线类型，指定为以下值之一： - `'Unmarked'` — 不存在物理车道标记 - `'Solid'` — 单条不间断线 - `'Dashed'` — 单条虚线车道标记线 - `'DoubleSolid'` — 两条不间断线 - `'DoubleDashed'` — 两条虚线 - `'SolidDashed'` — 左侧为实线，右侧为虚线 - `'DashedSolid'` — 左侧为虚线，右侧为实线 |
| `Strength` | 车道边界标线的饱和度强度，指定为 0 到 1 之间的实值标量。值为 `0` 对应于标记颜色完全不饱和。标记为灰色。值为 `1` 对应于标记颜色完全饱和。 |
| `Width` | 车道边界宽度，指定为正实值标量。在双线车道标记中，两条线及线间间隔使用相同的宽度。单位为米。 |
| `Length` | 虚线中虚线的长度，指定为正实值标量。在双线车道标记中，两条线使用相同的长度。 |
| `Space` | 虚线中虚线之间的间隔长度，指定为正实值标量。在虚线双线车道标记中，两条线使用相同的间隔。 |

#### 依赖关系

要启用此输入端口，请将 **Types of detections generated by sensor** 参数设置为 `Lanes only`、`Lanes only`、`Lanes with occlusion` 或 `Lanes and objects`。
### 输出

### **Object Detections** — 目标检测 包含 MATLAB 结构的 Simulink 总线

目标检测，返回为包含 MATLAB 结构的 Simulink 总线。有关总线的更多详细信息，请参阅 Create Nonvirtual Buses (Simulink)。

您可以将来自这些传感器和其他传感器的目标检测传递给跟踪器（例如 Multi-Object Tracker 模块），并生成航迹。

检测结构体具有以下形式：

| 字段 | 描述 | 类型 |
| --- | --- | --- |
| `NumDetections` | 检测数量 | 整数 |
| `IsValidTime` | 当在模块调用间隔之间的时间请求更新时为 false | 布尔值 |
| `Detections` | 目标检测 | 目标检测结构体数组，长度由 **Maximum number of reported detections** 参数设置。其中只有 `NumDetections` 个检测是实际检测。 |

目标检测结构体包含以下属性。

| 属性 | 定义 |
| --- | --- |
| `Time` | 测量时间 |
| `Measurement` | 目标测量值 |
| `MeasurementNoise` | 测量噪声协方差矩阵 |
| `SensorIndex` | 传感器的唯一 ID |
| `ObjectClassID` | 目标分类 |
| `MeasurementParameters` | 非线性卡尔曼跟踪滤波器初始化函数使用的参数 |
| `ObjectAttributes` | 传递给跟踪器的附加信息 |

`Measurement` 字段报告测量值在 **Coordinate system used to report detections** 指定的坐标系中的位置和速度。此字段为实值列向量，形式为 [*x*; *y*; *z*; *vx*; *vy*; *vz*]。单位为米每秒。

`MeasurementNoise` 字段是一个 6×6 矩阵，报告 `Measurement` 字段中每个坐标的测量噪声协方差。

`MeasurementParameters` 字段是一个结构体，包含以下字段。

| 参数 | 定义 |
| --- | --- |
| `Frame` | 枚举类型，指示用于报告测量值的坐标系。Vision Detection Generator 模块在自车坐标系和传感器笛卡尔坐标系中报告检测，二者均为直角坐标系。因此，对于此模块，`Frame` 始终设置为 `'rectangular'`。 |
| `OriginPosition` | 传感器原点相对于自车原点的三维向量偏移。该向量由模块的 **Sensor's (x,y) position (m)** 和 **Sensor's height (m)** 参数导出。 |
| `Orientation` | 视觉传感器坐标系相对于自车坐标系的姿态。该姿态由模块的 **Yaw angle of sensor mounted on ego vehicle (deg)**、**Pitch angle of sensor mounted on ego vehicle (deg)** 和 **Roll angle of sensor mounted on ego vehicle (deg)** 参数导出。 |
| `HasVelocity` | 指示测量值是否包含速度。 |

每个检测的 `ObjectAttributes` 属性是一个结构体，包含以下字段。

| 字段 | 定义 |
| --- | --- |
| `TargetIndex` | 生成该检测的参与者的标识符 `ActorID`。对于虚警，此值为负数。 |

#### 依赖关系

要启用此输出端口，请将 **Types of detections generated by sensor** 参数设置为 `Objects only`、`Lanes with occlusion` 或 `Lanes and objects`。

### **Lane Detections** — 车道边界检测 包含 MATLAB 结构的 Simulink 总线

车道边界检测，返回为包含 MATLAB 结构的 Simulink 总线。该结构体具有以下字段：

| 字段 | 描述 | 类型 |
| --- | --- | --- |
| `Time` | 车道检测时间 | 实值标量 |
| `IsValidTime` | 当在模块调用间隔之间的时间请求更新时为 false | 布尔值 |
| `SensorIndex` | 传感器的唯一标识符 | 正整数 |
| `NumLaneBoundaries` | 车道边界检测数量 | 非负整数 |
| `LaneBoundaries` | 车道边界检测 | `clothoidLaneBoundary` 对象数组 |

#### 依赖关系

要启用此输出端口，请将 **Types of detections generated by sensor** 参数设置为 `Lanes only`、`Lanes with occlusion` 或 `Lanes and objects`。

### 参数

#### 传感器标识

### **Unique identifier of sensor** — 唯一传感器标识符 `1`（默认）| 正整数

唯一传感器标识符，指定为正整数。传感器标识符用于区分多传感器系统中来自不同传感器的检测。如果模型包含多个具有相同传感器标识符的传感器模块，Bird's-Eye Scope 将显示错误。

**示例：** `5`

### **Types of detections generated by sensor** — 选择检测类型 `Objects only`（默认）| `Lanes only` | `Lanes with occlusion` | `Lanes and objects`

传感器生成的检测类型，指定为 `Objects only`、`Lanes only`、`Lanes with occlusion` 或 `Lanes and objects`。

- 设置为 `Objects only` 时，不使用道路信息来遮挡参与者。
- 设置为 `Lanes only` 时，不使用参与者信息来检测车道。
- 设置为 `Lanes with occlusion` 时，相机视场中的参与者可能削弱传感器检测车道的能力。
- 设置为 `Lanes and objects` 时，传感器同时生成目标检测和被遮挡的车道检测。

### **Required interval between sensor updates (s)** — 所需时间间隔 `0.1`（默认）| 正实值标量

传感器更新之间的所需时间间隔，指定为正实值标量。此参数的值必须是 **Actors** 输入端口数据间隔的整数倍。在更新间隔之间向传感器请求的更新不包含任何检测。单位为秒。

### **Required interval between lane detections updates (s)** — 车道检测更新之间的时间间隔 0.1（默认）| 正实值标量

车道检测更新之间的所需时间间隔，指定为正实值标量。视觉检测生成器以固定时间间隔被调用。视觉检测器按此参数定义的间隔生成新的车道检测，该间隔必须是仿真时间间隔的整数倍。在更新间隔之间向传感器请求的更新不包含任何车道检测。单位为秒。

#### 传感器外参

### **Sensor's (x,y) position (m)** — 视觉传感器中心的位置 `[3.4 0]`（默认）| 实值 1×2 向量

视觉传感器中心的位置，指定为实值 1×2 向量。**Sensor's (x,y) position (m)** 和 **Sensor's height (m)** 参数定义了视觉传感器相对于自车坐标系的坐标。默认值对应于安装在轿车仪表板上的前向视觉传感器。单位为米。

### **Sensor's height (m)** — 视觉传感器离地高度 `0.2`（默认）| 正实值标量

从驾驶场景或 RoadRunner Scenario 中的视觉测量中检测对象和车道

Vision Detection Generator 模块根据安装在自车上的视觉传感器所采集的相机测量结果生成检测。

该模块根据仿真参与者的位姿推导检测结果，并以等于传感器更新间隔的间隔生成这些检测结果。默认情况下，检测结果参考自车的坐标系。该模块可以仿真带有附加随机噪声的真实检测，还可以生成误检。统计模型生成测量噪声、真实检测和误检。要控制统计模型生成的随机数，请使用模块 **Measurements** 选项卡上的随机数生成器设置。

您可以在 Driving Scenario 和 RoadRunner Scenario 仿真中将该模块与车辆参与者一起使用。有关更多信息，请参阅 Add Sensors to RoadRunner Scenario Using Simulink 示例。

您可以使用 Vision Detection Generator 为 Multi-Object Tracker 模块创建输入。在使用 Driving Scenario Designer 应用构建场景和传感器模型时，导出到 Simulink® 的相机传感器会输出为 Vision Detection Generator 模块。
