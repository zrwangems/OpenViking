# Bicycle Model

## 端口

### 输入

### **WhlAngF** — 车轮转角 `scalar`

前轮转角，单位为 rad。

### **FxF** — 力输入：前轴上的总纵向力 `scalar`

前轴上的纵向力，*FxF*，沿车辆固定 `x` 轴，单位为 N。

Bicycle Model - Force Input 模块输入端口。

### **FxR** — 力输入：后轴上的总纵向力 `scalar`

后轴上的纵向力，*FxR*，沿车辆固定 `x` 轴，单位为 N。

Bicycle Model - Force Input 模块输入端口。

### **xdotin** — 速度输入：纵向速度 `scalar`

车辆 CG 沿车辆固定 *x* 轴的速度，单位为 m/s。

Bicycle Model - Velocity Input 模块输入端口。

## 参数

#### 纵向

### **前轴车轮数量, NF** — 前轮数量 `2` (默认) | `scalar`

前轴车轮数量，*NF*。该值无量纲。

### **后轴车轮数量, NR** — 后轮数量 `2` (默认) | `scalar`

后轴车轮数量，*NR*。该值无量纲。

### **车辆质量, m** — 车辆质量 `2000` (默认) | `scalar`

车辆质量，*m*，单位为 kg。

### **从质心到前轴的纵向距离, a** — 前轴距离 `1.4` (默认) | `scalar`

从车辆 CG 到前轮轴的水平距离 *a*，单位为 m。

### **从质心到后轴的纵向距离, b** — 后轴距离 `1.6` (默认) | `scalar`

从车辆 CG 到后轮轴的水平距离 *b*，单位为 m。

### **从质心到车轴平面的垂直距离, h** — 高度 `0.35` (默认) | `scalar`

车辆 CG 高于车轴的高度，*h*，单位为 m。

### **初始惯性坐标系纵向位置, X\_o** — 位置 `0` (默认) | `scalar`

初始车辆 CG 沿大地固定 *X* 轴的位移，单位为 m。

### **初始纵向速度, xdot\_o** — 速度 `0` (默认) | `scalar`

初始车辆 CG 沿车辆固定 *x* 轴的速度，单位为 m/s。

#### 横向

### **前轮胎侧偏刚度, Cy\_f** — 刚度 `12e3` (默认) | `scalar`

前轮胎侧偏刚度，*Cyf*，单位为 N/rad。

### **后轮胎侧偏刚度, Cy\_r** — 刚度 `11e3` (默认) | `scalar`

后轮胎侧偏刚度，*Cyr*，单位为 N/rad。

### **初始惯性坐标系横向位移, Y\_o** — 位置 `0` (默认) | `scalar`

初始车辆 CG 沿大地固定 *Y* 轴的位移，单位为 m。

### **初始横向速度, ydot\_o** — 速度 `0` (默认) | `scalar`

初始车辆 CG 沿车辆固定 *y* 轴的速度，单位为 m/s。

#### 横摆

### **横摆极惯性, Izz** — 惯性 `4000` (默认) | `scalar`

横摆极惯性，单位为 kg\*m^2。

### **初始横摆角, psi\_o** — Psi 旋转 `0` (默认) | `scalar`

车辆固定坐标系绕大地固定 *Z* 轴的旋转（横摆），单位为 rad。

### **初始横摆角速度, r\_o** — 横摆角速度 `0` (default) | `scalar`

车辆绕车辆固定 *z* 轴的角速度（横摆角速度），单位为 rad/s。

## 描述

实现单轨 3DOF 刚性车身，以计算纵向、侧向和横摆运动

**注意**

使用 Bicycle Model 模块仿真模型需要 Simulink® 3D Animation™。

Bicycle Model 模块实现刚性双轴单轨车身模型，以计算纵向、侧向和横摆运动。该模块考虑车身质量、空气阻力以及由于加速和转向引起的车轴间重量分布。有两种类型的 Bicycle Model 模块。

| 模块 | 实现 |
| --- | --- |
| Bicycle Model - Velocity Input 具有速度输入端口 WhlAngF 和 xdotin 的 Bicycle Model 模块。 | - 模块假设外部纵向速度为准稳态，因此纵向加速度近似为零。 - 由于运动为准稳态，模块仅使用轮胎侧偏角和线性侧偏刚度计算侧向力。 |
| Bicycle Model - Force Input 具有力输入端口 WhlAngF、FxF 和 FxR 的 Bicycle Model 模块。 | - 模块使用外部纵向力来加速或制动车辆。 - 模块使用轮胎侧偏角和线性侧偏刚度计算侧向力。 |

为了计算前轴和后轴上的法向力，该模块使用刚体车辆运动、悬架系统力以及风力和阻力。该模块在刚性车身坐标系上分解力和力矩分量。
