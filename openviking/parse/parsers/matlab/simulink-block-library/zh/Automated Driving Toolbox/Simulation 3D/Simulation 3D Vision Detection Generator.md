# Simulation 3D Vision Detection Generator

## 端口

### 输出

### **Object Detections** — 包含 MATLAB® 结构的对象检测 Simulink bus

对象检测，以包含 MATLAB 结构的 Simulink bus 形式返回。有关 bus 的更多详细信息，请参阅 Create Nonvirtual Buses (Simulink)。
该结构具有此表中所示的形式。

| 字段 | 描述 | 类型 |
| --- | --- | --- |
| `NumDetections` | 检测数量 | Integer |
| `IsValidTime` | 当在模块调用间隔之间的时间请求更新时为 False | Boolean |
| `Detections` | 对象检测 | 长度为 **Maximum number of reported detections** 参数所设置值的对象检测结构体数组。这些检测中只有 `NumDetections` 个是实际检测。 |

对象检测结构体包含这些属性。

| 属性 | 定义 |
| --- | --- |
| `Time` | 测量时间 |
| `Measurement` | 对象测量 |
| `MeasurementNoise` | 测量噪声协方差矩阵 |
| `SensorIndex` | 传感器的唯一 ID |
| `ObjectClassID` | 对象分类 |
| `MeasurementParameters` | 非线性 Kalman 跟踪滤波器的初始化函数所使用的参数 |
| `ObjectAttributes` | 传递给跟踪器的附加信息 |

`Measurement` 字段报告测量在传感器坐标系中的位置和速度。此字段是形式为 [*x*; *y*; *z*; *vx*; *vy*; *vz*] 的 real-valued 列向量。`MeasurementNoise` 字段是一个 6-by-6 矩阵，报告 `Measurement` 字段中每个坐标的测量噪声协方差。

`MeasurementParameters` 字段是一个结构体，包含这些字段。

| 参数 | 定义 |
| --- | --- |
| `Frame` | 枚举类型，指示用于报告测量的坐标系。Simulation 3D Vision Detection Generator 模块以传感器 Cartesian 坐标报告检测，这是一个 rectangular 坐标系。因此，对于此模块，`Frame` 始终设置为 `'rectangular'`。 |
| `OriginPosition` | 传感器原点相对于 ego vehicle 原点的偏移，以 [*x*, *y*, *z*] 形式的向量返回。模块从传感器的 *x*、*y* 和 *z* 安装位置推导这些值。有关更多详细信息，请参阅此模块的 **Mounting** 参数。 |
| `Orientation` | 传感器坐标系相对于 ego vehicle 坐标系的方向，以 3-by-3 real-valued 正交矩阵返回。模块从传感器的 *yaw*、*pitch* 和 *roll* 安装方向推导这些值。有关更多详细信息，请参阅此模块的 **Mounting** 参数。 |
| `HasVelocity` | 指示测量是否包含速度。 |

### **Actor Truth** — 包含 MATLAB 结构的 actor 位姿真值 Simulink bus

仿真环境中 actor 位姿的真值，以包含 MATLAB 结构的 Simulink bus 形式返回。

该结构具有这些字段。

| 字段 | 描述 | 类型 |
| --- | --- | --- |
| `NumActors` | actor 数量 | Nonnegative integer |
| `Time` | 当前仿真时间 | Real-valued scalar |
| `Actors` | actor 位姿 | 长度为 `NumActors` 的 actor 位姿结构体数组 |

`Actors` 中的每个 actor 位姿结构体都具有这些字段。

| 字段 | 描述 |
| --- | --- |
| `ActorID` | 场景定义的 actor 标识符，指定为 positive integer。 |
| *In R2024b:* `FrontAxlePosition` | 车辆的前轴位置，指定为 [*x* *y* *z*] 形式的三元素行向量。单位是 meters。 **注意** 如果驾驶场景中至少有一辆车不包含前轴轨迹，则 `ActorPoses` 结构体不包含此字段。 |
| `Position` | actor 的位置，指定为 [*x* *y* *z*] 形式的 real-valued 向量。单位是 meters。 |
| `Velocity` | actor 在 *x*-、*y*- 和 *z*-方向上的速度 (*v*)，指定为 [*v**x* *v**y* *v**z*] 形式的 real-valued 向量。单位是 meters per second。 |
| `Roll` | actor 的 roll 角，指定为 real-valued scalar。单位是 degrees。 |
| `Pitch` | actor 的 pitch 角，指定为 real-valued scalar。单位是 degrees。 |
| `Yaw` | actor 的 yaw 角，指定为 real-valued scalar。单位是 degrees。 |
| `AngularVelocity` | actor 在 *x*-、*y*- 和 *z*-方向上的角速度 (*ω*)，指定为 [*ω**x* *ω**y* *ω**z*] 形式的 real-valued 向量。单位是 degrees per second。 |

ego vehicle 的位姿不包括在 `Actors` 数组中。

#### 依赖项

要启用此输出端口，请在 **Ground Truth** 选项卡上，选择 **Output actor truth** 参数。

### **Lane Truth** — 包含 MATLAB 结构的车道边界真值 Simulink bus

仿真环境中车道边界的真值，以包含 MATLAB 结构的 Simulink bus 形式返回。

该结构具有这些字段。

| 字段 | 描述 | 类型 |
| --- | --- | --- |
| `NumLaneBoundaries` | 车道边界数量 | Nonnegative integer |
| `Time` | 当前仿真时间 | Real scalar |
| `LaneBoundaries` | 车道边界，从相对于 ego vehicle 的最左侧车道开始。 | 长度为 `NumLaneBoundaries` 的车道边界结构体数组 |

`LaneBoundaries` 中的每个车道边界结构体都具有这些字段。

|  |  |
| --- | --- |
| **字段** | **描述** |
| `Coordinates` | 车道边界坐标，指定为 real-valued *N*-by-3 矩阵，其中 *N* 是车道边界坐标的数量。车道边界坐标定义边界上在指定纵向距离处、沿道路中心距 ego vehicle 的点的位置。 - 在 MATLAB 中，通过使用 `laneBoundaries` 函数的 `'XDistance'` 名称-值对组参数来指定这些距离。 - 在 Simulink 中，通过使用 Scenario Reader 模块的 **Distances from ego vehicle for computing boundaries (m)** 参数或 Simulation 3D Vision Detection Generator 模块的 **Distance from parent for computing lane boundaries** 参数来指定这些距离。 该矩阵还包括距 ego vehicle 零距离处的边界坐标。这些坐标位于 ego-vehicle 原点的左侧和右侧，该原点位于后轴中心下方。单位是 meters。 |
| `Curvature` | `Coordinates` 矩阵每一行处的车道边界曲率，指定为 real-valued *N*-by-1 向量。*N* 是车道边界坐标的数量。单位是 radians per meter。 |
| `CurvatureDerivative` | `Coordinates` 矩阵每一行处的车道边界曲率导数，指定为 real-valued *N*-by-1 向量。*N* 是车道边界坐标的数量。单位是 radians per square meter。 |
| `HeadingAngle` | 初始车道边界航向角，指定为 real scalar。车道边界的航向角相对于 ego vehicle 航向。单位是 degrees。 |
| `LateralOffset` | ego vehicle 位置与车道边界的横向偏移，指定为 real scalar。到 ego vehicle 左侧车道边界的偏移为正。到 ego vehicle 右侧的偏移为负。单位是 meters。在此图像中，ego vehicle 距左侧车道偏移 1.5 meters，距右侧车道偏移 2.1 meters。 Ego vehicle in a driving lane |
| `BoundaryType` | 车道边界标记类型，指定为以下值之一： - `'Unmarked'` — 不存在物理车道标记 - `'Solid'` — 单条不间断线 - `'Dashed'` — 单条虚线车道标记线 - `'DoubleSolid'` — 两条不间断线 - `'DoubleDashed'` — 两条虚线 - `'SolidDashed'` — 左侧为实线，右侧为虚线 - `'DashedSolid'` — 左侧为虚线，右侧为实线 |
| `Strength` | 车道边界标记的饱和度强度，指定为从 0 到 1 的 real scalar。值 `0` 对应于颜色完全未饱和的标记。该标记为灰色。值 `1` 对应于颜色完全饱和的标记。 |
| `Width` | 车道边界宽度，指定为 positive real scalar。在双线车道标记中，两条线以及线之间的空间使用相同宽度。单位是 meters。 |
| `Length` | 虚线中虚线的长度，指定为 positive real scalar。在双线车道标记中，两条线使用相同长度。 |
| `Space` | 虚线中虚线之间的空间长度，指定为 positive real scalar。在虚线双线车道标记中，两条线使用相同空间。 |

返回的车道边界结构体数量取决于 **Maximum number of reported lanes** 参数值。

#### 依赖项

要启用此输出端口，请在 **Ground Truth** 选项卡上，选择 **Output lane truth** 参数。

## 参数

### 安装

### **Sensor identifier** — 唯一传感器标识符 `1`（默认）| positive integer

指定传感器的唯一标识符。在多传感器系统中，传感器标识符使您能够区分传感器。当您将新的传感器模块添加到模型时，该模块的 **Sensor identifier** 为 *N* + 1，其中 *N* 是模型中现有传感器模块中最高的 **Sensor identifier** 值。

**示例：** `2`

### **Parent name** — 父级车辆名称 `Scene Origin`（默认）| vehicle name

传感器安装到的父级名称，指定为 `Scene Origin` 或模型中车辆的 name。您可以选择的车名对应于模型中 simulation 3D vehicle 模块的 **Name** 参数。如果选择 `Scene Origin`，模块会将传感器放置在场景原点。

**示例：** `SimulinkVehicle1`

### **Mounting location** — 传感器安装位置 `Origin`（默认）| `Front bumper` | `Rear bumper` | `Right mirror` | `Left mirror` | `Rearview mirror` | `Hood center` | `Roof center` | ...

传感器安装位置。默认情况下，模块根据 **Parent name** 参数将传感器放置在相对于场景或车辆原点的位置。

- 当 **Parent name** 为 `Scene Origin` 时，模块将传感器安装到场景原点。您只能将 **Mounting location** 设置为 `Origin`。在仿真期间，传感器保持静止。
- 当 **Parent name** 为车辆名称时，模块将传感器安装到表中所述的一个预定义安装位置。在仿真期间，传感器随车辆移动。

| 安装位置 | 描述 | 相对于车辆原点的方向 [Roll, Pitch, Yaw] (deg) |
| --- | --- | --- |
| `Origin` | 安装到车辆原点的前向传感器，原点位于地面上且位于车辆的几何中心（请参阅 Coordinate Systems for Unreal Engine Simulation in Automated Driving Toolbox）  Vehicle with sensor mounted at origin | [0, 0, 0] |
| `Front bumper`  `Front center` | 安装到前保险杠的前向传感器  Vehicle with sensor mounted at front bumper | [0, 0, 0] |
| `Rear bumper`  `Rear center` | 安装到后保险杠的后向传感器  Vehicle with sensor mounted at rear bumper | [0, 0, 180] |
| `Right mirror` | 安装到右侧后视镜的向下传感器  Vehicle with sensor mounted at right side-view mirror | [0, –90, 0] |
| `Left mirror` | 安装到左侧后视镜的向下传感器  Vehicle with sensor mounted at left side-view mirror | [0, –90, 0] |
| `Rearview mirror` | 安装到车内后视镜的前向传感器  Vehicle with sensor mounted at rearview mirror | [0, 0, 0] |
| `Hood center` | 安装到引擎盖中心的前向传感器  Vehicle with sensor mounted at hood center | [0, 0, 0] |
| `Roof center` | 安装到车顶中心的前向传感器  Vehicle with sensor mounted at roof center | [0, 0, 0] |

当沿着 *X* 轴、*Y* 轴和 *Z* 轴的正方向看时，roll、pitch 和 yaw 分别为顺时针正。当从上方看车辆时，yaw 角（方向角）为逆时针正，因为您是沿该轴的负方向看。

传感器相对于车辆的 *X*-*Y*-*Z* 安装位置取决于车辆类型。要指定车辆类型，请使用您将传感器安装到的 Simulation 3D Vehicle with Ground Following 的 **Type** 参数。要获取车辆类型的 *X*-*Y*-*Z* 安装位置，请参阅该车辆的参考页。

要确定传感器在世界坐标中的位置，请打开传感器模块。然后，在 **Ground Truth** 选项卡上，选择 **Output location (m) and orientation (rad)** 参数，并检查来自 **Translation** 输出端口的数据。

### **Specify offset** — 指定距安装位置的偏移 `off`（默认）| `on`

选择此参数以使用 **Relative translation [X, Y, Z] (m)** 和 **Relative rotation [Roll, Pitch, Yaw] (deg)** 参数指定距安装位置的偏移。

### **Relative translation [X, Y, Z] (m)** — 相对于安装位置的平移偏移 `[0, 0, 0]`（默认）| real-valued 1-by-3 vector

相对于传感器安装位置的平移偏移，指定为 [*X*, *Y*, *Z*] 形式的 real-valued 1-by-3 向量。单位是 meters。

如果您通过将 **Parent name** 设置为车辆名称来将传感器安装到车辆，则 *X*、*Y* 和 *Z* 位于车辆坐标系中，其中：

- *X* 轴从车辆向前指向。
- *Y* 轴指向车辆左侧（当沿车辆前方向看时）。
- *Z* 轴向上指向。

原点是在 **Mounting location** 参数中指定的安装位置。此原点不同于车辆原点，车辆原点是车辆的几何中心。

如果您通过将 **Parent name** 设置为 `Scene Origin` 来将传感器安装到场景原点，则 *X*、*Y* 和 *Z* 位于场景的世界坐标中。

有关车辆和世界坐标系的更多详细信息，请参阅 Coordinate Systems for Unreal Engine Simulation in Automated Driving Toolbox。

**示例：** `[0,0,0.01]`

#### 依赖项

要启用此参数，请选择 **Specify offset**。

### **Relative rotation [Roll, Pitch, Yaw] (deg)** — 相对于安装位置的旋转偏移 `[0, 0, 0]`（默认）| real-valued 1-by-3 vector

相对于传感器安装位置的旋转偏移，指定为 [*Roll*, *Pitch*, *Yaw*] 形式的 real-valued 1-by-3 向量。Roll、pitch 和 yaw 分别是围绕 *X*、*Y* 和 *Z* 轴的旋转角。单位是 degrees。

如果您通过将 **Parent name** 设置为车辆名称来将传感器安装到车辆，则 *X*、*Y* 和 *Z* 位于车辆坐标系中，其中：

- *X* 轴从车辆向前指向。
- *Y* 轴指向车辆左侧（当沿车辆前方向看时）。
- *Z* 轴向上指向。
- 当沿 *X* 轴、*Y* 轴和 *Z* 轴的前方向看时，roll、pitch 和 yaw 分别为顺时针正。如果您从 2D 俯视视角查看场景，则 yaw 角（也称为方向角）为逆时针正，因为您是沿 *Z* 轴的负方向查看场景。

原点是在 **Mounting location** 参数中指定的安装位置。此原点不同于车辆原点，车辆原点是车辆的几何中心。

如果您通过将 **Parent name** 设置为 `Scene Origin` 来将传感器安装到场景原点，则 *X*、*Y* 和 *Z* 位于场景的世界坐标中。

有关车辆和世界坐标系的更多详细信息，请参阅 Coordinate Systems for Unreal Engine Simulation in Automated Driving Toolbox。

**示例：** `[0,0,10]`

#### 依赖项

要启用此参数，请选择 **Specify offset**。

### **Sample time** — 采样时间 `-1`（默认）| positive scalar

模块的采样时间，以 seconds 为单位，指定为 positive scalar。3D 仿真环境帧速率是采样时间的倒数。

如果将采样时间设置为 `-1`，则模块从 Simulation 3D Scene Configuration 模块继承其采样时间。

### 参数

#### 检测报告

### **Types of detections generated by sensor** — 传感器生成的检测类型 `Lanes and objects`（默认）| `Objects only` | `Lanes only` | `Lanes with occlusion`

传感器生成的检测类型，指定为以下选项之一：

- `Lanes and objects` — 检测车道和对象。不使用道路信息遮挡 actor。
- `Objects only` — 仅检测对象。
- `Lanes only` — 仅检测车道。
- `Lanes with occlusion` — 检测车道和对象。相机视野中的对象可能削弱传感器检测车道的能力。

### **Maximum number of reported detections** — 最大报告检测数 `50`（默认）| positive integer

传感器报告的最大检测数，指定为 positive integer。检测按距传感器的距离递增顺序报告，直到达到最大数量。

**示例：** `100`

### **Maximum number of reported lanes** — 最大报告车道数 `30`（默认）| positive integer

报告的最大车道数，指定为 positive integer。

**示例：** `100`

### **Distance from parent for computing lane boundaries** — 用于计算车道边界的距父级距离 `0:0.5:9.5`（默认）| *N*-element real-valued vector

用于计算车道边界的距父级坐标系的距离，指定为 *N* 元素 real-valued 向量。*N* 是距离值的数量。*N* 不应超过 100。单位是 meters。

*parent* 是传感器安装到的坐标系，例如 ego vehicle。**Parent name** 参数确定父级坐标系。距离相对于父级坐标系的原点。

当从后向相机检测车道时，指定负距离。当从前向相机检测车道时，指定正距离。

默认情况下，模块在父级前方 0 到 9.5 meters 范围内每 0.5 meters 计算一次车道边界。

**示例：** `1:0.1:10` 在父级前方 1 到 10 meters 范围内每 0.1 meters 计算一次车道边界。

### 测量

### **Maximum detection range (m)** — 最大检测范围 `150`（默认）| positive real scalar

最大检测范围，指定为 positive real scalar。vision sensor 无法检测超出此范围的对象。单位是 meters。

**示例：** `250`

#### 目标检测器设置

### **Bounding box accuracy (pixels)** — 边界框精度 `5`（默认）| positive real scalar

边界框精度，指定为 positive real scalar。此量定义检测器可以将边界框与目标匹配的精度。单位是 pixels。

**示例：** `9`

### **Smoothing filter noise intensity (m/s^2)** — 用于过滤位置和速度测量的噪声强度 `5`（默认）| positive real scalar

用于过滤位置和速度测量的噪声强度，指定为 positive real scalar。噪声强度定义 vision sensor 中使用的内部 constant-velocity Kalman 滤波器的过程噪声标准差。滤波器使用 piecewise-constant white noise acceleration model 对过程噪声建模。噪声强度通常为目标预期的最大加速度量级。单位是 meters per second squared。

**示例：** `2`

### **Maximum detectable object speed (m/s)** — 最大可检测目标速度 `50`（默认）| nonnegative real scalar

最大可检测目标速度，指定为 nonnegative real scalar。单位是 meters per second。

**示例：** `20`

### **Maximum allowed occlusion for detector** — 对象的最大允许遮挡 `0.5`（默认）| real scalar in the range [0 1)

对象的最大允许遮挡，指定为范围 [0 1) 内的 real scalar。*Occlusion* 是对象对传感器不可见的总表面积比例。值 1 表示对象被完全遮挡。单位是无量纲。

**示例：** `0.2`

### **Minimum detectable image size of an object (pixels)** — 对象的最小高度和宽度 `[15,15]`（默认）| 1-by-2 vector of positive values

vision sensor 在图像中检测到的对象的最小高度和宽度，指定为正值 `[minHeight,minWidth]` 向量。对象的 2-D 投影高度必须大于或等于 `minHeight`。对象的投影宽度必须大于或等于 `minWidth`。单位是 pixels。

**示例：** `[25 20]`

### **Probability of detecting a target** — 检测概率 `0.9`（默认）| positive real scalar less than or equal to 1

检测目标的概率，指定为小于或等于 1 的 positive real scalar。此量定义传感器检测到可检测对象的概率。*可检测对象* 是满足最小可检测尺寸、最大范围、最大速度和最大允许遮挡约束的对象。

**示例：** `0.95`

### **Number of false positives per image** — vision sensor 每幅图像生成的误报检测数 `0.1`（默认）| nonnegative real scalar

vision sensor 每幅图像生成的误报检测数，指定为 nonnegative real scalar。

**示例：** `1.0`

### **Add noise to measurements** — 启用向 vision sensor 测量添加噪声 `on`（默认）| `off`

### **Select method to specify initial seed** — 指定随机数生成器种子的方法 `Repeatable`（默认）| `Specify seed` | `Not repeatable`

## 描述

从 3D 仿真环境中的测量检测对象和车道

**注意**

使用 Simulation 3D Vision Detection Generator 模块仿真模型需要 Simulink® 3D Animation™。

Simulation 3D Vision Detection Generator 模块从安装在 3D 仿真环境中 ego vehicle 上的 vision sensor 所拍摄的相机测量生成检测。此环境使用 Epic Games® 的 Unreal Engine® 渲染。模块从基于场景中 actor 的 cuboid（箱形）表示的仿真 actor 位姿推导检测。有关更多详细信息，请参阅 Algorithms。

模块以等于传感器更新间隔的间隔生成检测。检测参考传感器坐标系。模块可以仿真添加了随机噪声的真实检测，还可以生成误报检测。统计模型生成测量噪声、真实检测和误报。要控制统计模型生成的随机数，请使用模块的 **Measurements** 选项卡上的随机数生成器设置。

如果将 **Sample time** 设置为 `-1`，模块将使用 Simulation 3D Scene Configuration 模块中指定的采样时间。要使用此传感器，您必须在模型中包含 Simulation 3D Scene Configuration 模块。

**提示**

Simulation 3D Scene Configuration 模块必须在 Simulation 3D Vision Detection Generator 模块之前执行。这样，Unreal Engine 3D 可视化环境会在 Simulation 3D Vision Detection Generator 模块接收数据之前准备好数据。要检查模块执行顺序，请右键单击这些模块并选择 **Properties**。在 **General** 选项卡上，确认这些 **Priority** 设置：

- Simulation 3D Scene Configuration — `0`
- Simulation 3D Vision Detection Generator — `1`

有关执行顺序的更多信息，请参阅 How Unreal Engine Simulation for Automated Driving Works。
