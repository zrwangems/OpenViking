# Simulation 3D Vision Detection Generator

## 端口

### 输出

### **Object Detections** — 目标检测，返回为包含 MATLAB® 结构的 Simulink 总线

目标检测，返回为包含 MATLAB 结构的 Simulink 总线。有关总线的更多详细信息，请参阅 Create Nonvirtual Buses (Simulink)。
该结构具有下表所示的形式。

| 字段 | 描述 | 类型 |
| --- | --- | --- |
| `NumDetections` | 检测数量 | 整数 |
| `IsValidTime` | 当在模块调用间隔之间的时刻请求更新时为 false | 布尔值 |
| `Detections` | 目标检测 | 目标检测结构数组，长度由 **Maximum number of reported detections** 参数设置。其中只有 `NumDetections` 个检测是实际检测。 |

目标检测结构包含以下属性。

| 属性 | 定义 |
| --- | --- |
| `Time` | 测量时间 |
| `Measurement` | 目标测量值 |
| `MeasurementNoise` | 测量噪声协方差矩阵 |
| `SensorIndex` | 传感器的唯一 ID |
| `ObjectClassID` | 目标分类 |
| `MeasurementParameters` | 非线性卡尔曼跟踪滤波器初始化函数使用的参数 |
| `ObjectAttributes` | 传递给跟踪器的附加信息 |

`Measurement` 字段报告测量值在传感器坐标系中的位置和速度。该字段是形式为 [*x*; *y*; *z*;
*vx*; *vy*; *vz*] 的实值列向量。`MeasurementNoise` 字段是一个 6×6 矩阵，报告 `Measurement`
字段中每个坐标的测量噪声协方差。

`MeasurementParameters` 字段是一个结构，包含以下字段。

| 参数 | 定义 |
| --- | --- |
| `Frame` | 枚举类型，指示用于报告测量值的坐标系。Simulation 3D Vision Detection Generator 模块在传感器笛卡尔坐标系中报告检测，该坐标系为矩形坐标系。因此，对于此模块，`Frame` 始终设置为 `'rectangular'`。 |
| `OriginPosition` | 传感器原点相对于自车原点的偏移，返回为形式为 [*x*, *y*, *z*] 的向量。该模块从传感器的 *x*、*y* 和 *z* 安装位置推导这些值。有关更多详细信息，请参阅此模块的 **Mounting** 参数。 |
| `Orientation` | 传感器坐标系相对于自车坐标系的姿态，返回为 3×3 实值正交矩阵。该模块从传感器的 *yaw*、*pitch* 和 *roll* 安装姿态推导这些值。有关更多详细信息，请参阅此模块的 **Mounting** 参数。 |
| `HasVelocity` | 指示测量值是否包含速度。 |

## 参数

### Mounting

### **Sensor identifier** — 唯一传感器标识符 `1`（默认）| 正整数

指定传感器的唯一标识符。在多传感器系统中，传感器标识符
使您能够区分传感器。当您向模型中添加新的传感器模块时，该模块的 **Sensor identifier** 为 *N*
+ 1，其中 *N* 是模型中现有传感器模块中最高的 **Sensor identifier**
值。

**示例：** `2`

### **Parent name** — 父车辆名称 `Scene Origin`（默认）| 车辆名称

传感器安装到的父对象名称，指定为 `Scene
Origin` 或模型中车辆的名称。您可以选择
的车辆名称对应于模型中仿真 3D 车辆模块的 **Name** 参数。如果您选择 `Scene
Origin`，该模块将传感器放置在场景原点。

**示例：** `SimulinkVehicle1`

### **Mounting location** — 传感器安装位置 `Origin`（默认）| `Front bumper` | `Rear bumper` | `Right mirror` | `Left mirror` | `Rearview mirror` | `Hood center` | `Roof center` | ...

传感器安装位置。默认情况下，该模块根据 **Parent name** 参数将传感器相对于场景或车辆原点放置。

- 当 **Parent name** 为 `Scene Origin` 时，该模块将传感器安装到场景原点。您只能将 **Mounting location** 设置为 `Origin`。在仿真期间，传感器保持静止。
- 当 **Parent name** 为某个车辆的名称时，该模块将传感器安装到表中描述的某个预定义安装位置。在仿真期间，传感器随车辆移动。

| Mounting Location | Description | Orientation Relative to Vehicle Origin [Roll, Pitch, Yaw] (deg) |
| --- | --- | --- |
| `Origin` | 前向传感器，安装到车辆原点，该原点位于地面上且位于车辆的几何中心（参见 Automated Driving Toolbox 中 Unreal Engine 仿真的坐标系） 传感器安装在原点的车辆 | [0, 0, 0] |
| `Front bumper`  `Front center` | 前向传感器，安装到前保险杠 传感器安装在前保险杠的车辆 | [0, 0, 0] |
| `Rear bumper`  `Rear center` | 后向传感器，安装到后保险杠 传感器安装在后保险杠的车辆 | [0, 0, 180] |
| `Right mirror` | 向下传感器，安装到右侧后视镜 传感器安装在右侧后视镜的车辆 | [0, –90, 0] |
| `Left mirror` | 向下传感器，安装到左侧后视镜 传感器安装在左侧后视镜的车辆 | [0, –90, 0] |
| `Rearview mirror` | 前向传感器，安装到车内后视镜 传感器安装在车内后视镜的车辆 | [0, 0, 0] |
| `Hood center` | 前向传感器，安装到发动机罩中心 传感器安装在发动机罩中心的车辆 | [0, 0, 0] |
| `Roof center` | 前向传感器，安装到车顶中心 传感器安装在车顶中心的车辆 | [0, 0, 0] |

当分别沿 *X* 轴、*Y* 轴和 *Z* 轴的正方向观察时，横滚、俯仰和偏航为顺时针正方向。当从上方观察车辆时，偏航角（即朝向角）为逆时针正方向，因为您是沿该轴的负方向观察的。

传感器相对于车辆的 *X*-*Y*-*Z* 安装位置取决于车辆类型。要指定车辆类型，请使用您将传感器安装到的 Simulation 3D Vehicle with Ground Following 的 **Type** 参数。要获取某车辆类型的 *X*-*Y*-*Z* 安装位置，请参阅该车辆的参考页。

要确定传感器在世界坐标系中的位置，请打开传感器模块。然后，在 **Ground Truth** 选项卡上，选择 **Output location (m) and orientation (rad)** 参数，并检查 **Translation** 输出端口的数据。

### **Specify offset** — 指定相对于安装位置的偏移 `off`（默认）| `on`

选择此参数可通过 **Relative translation [X, Y, Z] (m)** 和 **Relative rotation [Roll, Pitch, Yaw] (deg)** 参数指定相对于安装位置的偏移。

### **Relative translation [X, Y, Z] (m)** — 相对于安装位置的平移偏移 `[0, 0, 0]`（默认）| 实值 1×3 向量

相对于传感器安装位置的平移偏移，指定为形式为 [*X*, *Y*, *Z*] 的实值 1×3 向量。单位为米。

如果您通过将 **Parent name** 设置为某车辆的名称来将传感器安装到该车辆，则 *X*、*Y* 和 *Z* 位于车辆坐标系中，其中：

- *X* 轴从车辆向前指向。
- *Y* 轴指向车辆左侧（当沿车辆前方方向观察时）。
- *Z* 轴向上指向。

原点是在 **Mounting location** 参数中指定的安装位置。该原点不同于车辆原点，车辆原点是车辆的几何中心。

如果您通过将 **Parent name** 设置为 `Scene Origin` 来将传感器安装到场景原点，则 *X*、*Y* 和 *Z* 位于场景的世界坐标系中。

有关车辆坐标系和世界坐标系的更多详细信息，请参见 Automated Driving Toolbox 中 Unreal Engine 仿真的坐标系。

**Example:** `[0,0,0.01]`

#### 依赖关系

要启用此参数，请选择 **Specify offset**。

### **Relative rotation [Roll, Pitch, Yaw] (deg)** — 相对于安装位置的旋转偏移 `[0, 0, 0]`（默认）| 实值 1×3 向量

相对于传感器安装位置的旋转偏移，指定为形式为 [*Roll*, *Pitch*, *Yaw*] 的实值 1×3 向量。横滚、俯仰和偏航分别是绕 *X* 轴、*Y* 轴和 *Z* 轴的旋转角。单位为度。

如果您通过将 **Parent name** 设置为某车辆的名称来将传感器安装到该车辆，则 *X*、*Y* 和 *Z* 位于车辆坐标系中，其中：

- *X* 轴从车辆向前指向。
- *Y* 轴指向车辆左侧（当沿车辆前方方向观察时）。
- *Z* 轴向上指向。
- 当分别沿 *X* 轴、*Y* 轴和 *Z* 轴的正方向观察时，横滚、俯仰和偏航为顺时针正方向。如果您从 2D 俯视视角观察场景，则偏航角（也称为朝向角）为逆时针正方向，因为您是沿 *Z* 轴的负方向观察场景的。

原点是在 **Mounting location** 参数中指定的安装位置。该原点不同于车辆原点，车辆原点是车辆的几何中心。

如果您通过将 **Parent name** 设置为 `Scene Origin` 来将传感器安装到场景原点，则 *X*、*Y* 和 *Z* 位于场景的世界坐标系中。

有关车辆坐标系和世界坐标系的更多详细信息，请参见 Automated Driving Toolbox 中 Unreal Engine 仿真的坐标系。

**Example:** `[0,0,10]`

#### 依赖关系

要启用此参数，请选择 **Specify offset**。

### **Sample time** — 采样时间 `-1`（默认）| 正标量

模块的采样时间，以秒为单位，指定为正标量。3D 仿真环境的帧率是采样时间的倒数。

如果将采样时间设置为 `-1`，则该模块从 Simulation 3D Scene Configuration 模块继承其采样时间。

### 参数

#### Detection Reporting

### **Types of detections generated by sensor** — 传感器生成的检测类型 `Lanes and objects`（默认）| `Objects only` | `Lanes only` | `Lanes with occlusion`

传感器生成的检测类型，指定为以下选项之一：

- `Lanes and objects` — 检测车道和目标。不使用道路信息来遮挡参与者。
- `Objects only` — 仅检测目标。
- `Lanes only` — 仅检测车道。
- `Lanes with occlusion` — 检测车道和目标。相机视场中的目标可能会削弱传感器检测车道的能力。

### **Maximum number of reported detections** — 报告的最大检测数 `50`（默认）| 正整数

传感器报告的最大检测数，指定为正整数。检测按距传感器的距离递增顺序报告，直到达到最大数量。

**Example:** `100`

### **Maximum number of reported lanes** — 报告的最大车道数 `30`（默认）| 正整数

报告的最大车道数，指定为正整数。

**Example:** `100`

### **Distance from parent for computing lane boundaries** — 用于计算车道边界的距父坐标系距离 `0:0.5:9.5`（默认）| *N* 元素实值向量

用于计算车道边界的距父坐标系距离，指定为 *N* 元素实值向量。*N* 是距离值的数量。*N* 不应超过 100。单位为米。

*父坐标系* 是传感器安装到的坐标系，例如自车。**Parent name** 参数决定父坐标系。距离相对于父坐标系的原点。

当从后向相机检测车道时，指定负距离。当前向相机检测车道时，指定正距离。

默认情况下，该模块在父坐标系前方 0 到 9.5 米范围内每 0.5 米计算一次车道边界。

**Example:** `1:0.1:10` 在父坐标系前方 1 到 10 米范围内每 0.1 米计算一次车道边界。

### Measurements

### **Maximum detection range (m)** — 最大检测范围 `150`（默认）| 正实标量

最大检测范围，指定为正实标量。视觉传感器无法检测超出此范围的目标。单位为米。

**Example:** `250`

#### Object Detector Settings

### **Bounding box accuracy (pixels)** — 边界框精度 `5`（默认）| 正实标量

边界框精度，指定为正实标量。该量定义检测器将边界框与目标匹配的精度。单位为像素。

**Example:** `9`

### **Smoothing filter noise intensity (m/s^2)** — 用于过滤位置和速度测量值的噪声强度 `5`（默认）| 正实标量

用于过滤位置和速度测量值的噪声强度，指定为正实标量。噪声强度定义视觉传感器中使用的内部匀速卡尔曼滤波器的过程噪声标准差。该滤波器使用分段常值白噪声加速度模型来建模过程噪声。噪声强度通常为目标预期最大加速度幅度的量级。单位为米每二次方秒。

**Example:** `2`

### **Maximum detectable object speed (m/s)** — 最大可检测目标速度 `50`（默认）| 非负实标量

最大可检测目标速度，指定为非负实标量。单位为米每秒。

**Example:** `20`

### **Maximum allowed occlusion for detector** — 目标的最大允许遮挡 `0.5`（默认）| 范围 [0 1) 内的实标量

目标的最大允许遮挡，指定为范围 [0 1) 内的实标量。*遮挡* 是目标总表面积中传感器不可见的部分所占比例。值 1 表示目标被完全遮挡。单位为无量纲。

**Example:** `0.2`

### **Minimum detectable image size of an object (pixels)** — 目标的最小高度和宽度 `[15,15]`（默认）| 正值的 1×2 向量

视觉传感器在图像中检测到的目标的最小高度和宽度，指定为 `[minHeight,minWidth]` 正值向量。目标的 2-D 投影高度必须大于或等于 `minHeight`。目标的投影宽度必须大于或等于 `minWidth`。单位为像素。

**Example:** `[25 20]`

### **Probability of detecting a target** — 检测概率 `0.9`（默认）| 小于或等于 1 的正实标量

检测目标的概率，指定为小于或等于 1 的正实标量。该量定义传感器检测到可检测目标的概率。*可检测目标* 是满足最小可检测尺寸、最大范围、最大速度和最大允许遮挡约束的目标。

**Example:** `0.95`

### **Number of false positives per image** — 视觉传感器每幅图像生成的误检测数 `0.1`（默认）| 非负实标量

视觉传感器每幅图像生成的误检测数，指定为非负实标量。

**Example:** `1.0`

## 描述

从 3D 仿真环境中的测量值检测对象和车道

**注意**

使用 Simulation 3D Vision Detection Generator 模块仿真模型需要 Simulink® 3D Animation™。

Simulation 3D Vision Detection Generator 模块根据安装在自车上的视觉传感器在 3D 仿真环境中获取的相机测量值生成检测结果。该环境使用 Epic Games® 的 Unreal Engine® 进行渲染。该模块从仿真参与者位姿中推导检测结果，这些位姿基于场景中参与者的长方体（箱形）表示。有关更多详细信息，请参阅算法。

该模块以等于传感器更新间隔的间隔生成检测结果。检测结果参考传感器坐标系。该模块可以仿真添加了随机噪声的真实检测结果，也可以生成误检。统计模型生成测量噪声、真实检测结果和误检。要控制统计模型生成的随机数，请使用模块 **Measurements** 选项卡上的随机数生成器设置。

如果将 **Sample time** 设置为 `-1`，则该模块使用 Simulation 3D Scene Configuration 模块中指定的采样时间。要使用此传感器，您必须在模型中包含 Simulation 3D Scene Configuration 模块。

**提示**

Simulation 3D Scene Configuration 模块必须在 Simulation 3D Vision Detection Generator 模块之前执行。这样，Unreal Engine 3D 可视化环境会在 Simulation 3D Vision Detection Generator 模块接收数据之前准备好数据。要检查模块执行顺序，请右键单击这些模块并选择 **Properties**。在 **General** 选项卡上，确认以下 **Priority** 设置：

- Simulation 3D Scene Configuration — `0`
- Simulation 3D Vision Detection Generator — `1`

有关执行顺序的更多信息，请参阅 How Unreal Engine Simulation for Automated Driving Works。
