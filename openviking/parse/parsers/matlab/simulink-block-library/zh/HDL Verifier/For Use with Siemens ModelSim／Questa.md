# HDL Verifier

了解 HDL Verifier 的基础知识

HDL Verifier™ 使您能够在 HDL 设计环境中重用系统级设计环境。您可以针对 MATLAB® 和 Simulink® 中的黄金参考模型测试和验证 RTL 设计，在仿真器或硬件中调试设计，并生成测试平台和验证 IP。

使用 HDL Verifier，您可以使用在 MATLAB 和 Simulink 中运行的测试平台以及在 HDL 仿真器中运行的 RTL 设计来验证 FPGA、ASIC 和 SoC 设计。您可以将这些测试平台与 AMD®、Altera® 和 Microchip FPGA 开发板一起重用来验证硬件实现并探测内部信号以调试设计。您还可以从 MATLAB 和 Simulink 生成 Universal Verification Methodology (UVM) 组件，以便在您的 SystemVerilog 验证环境中使用。所有这些功能都与现有 HDL 代码和 HDL Coder™ 生成的代码兼容。

工作流程图左侧显示 HDL Verifier，箭头指向三个工作流程：1. 算法验证，2. FPGA 调试，3. 验证 IP 导出
