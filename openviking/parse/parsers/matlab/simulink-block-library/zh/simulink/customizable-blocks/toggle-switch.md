# Toggle Switch

## 端口

R2025b 中未记录。

## 参数

使用属性检查器和模块参数对话框来指定模块参数的值。要设置仪表板模块的核心参数，请使用模块参数对话框或属性检查器中的**参数**选项卡。要自定义模块，请使用属性检查器中的**设计**选项卡。要打开模块的模块参数对话框，请双击该模块。要打开属性检查器，请在**建模**选项卡上的**设计**下，选择**属性检查器**。

### 参数

要设置仪表板模块的核心参数，请打开属性检查器，然后单击**参数**选项卡。

#### 连接

### **连接** — 用于连接参数值的模块参数值连接选项

仪表板模块不使用端口连接到模型元素。要将仪表板模块连接到模型中的参数值，请使用连接模式、Simulink 工具条或模块参数对话框中的**连接**表。要从属性检查器打开模块参数对话框，请在**连接到**右侧，单击**连接**或**更改**。您可以连接到具有标量值的参数，或连接到矩阵的元素。有关连接模式以及如何使用工具条进行连接的信息，请参阅 Connect Dashboard Blocks to Simulink Model。

要将控制模块连接到具有标量值的参数，或使用**连接**表更改控制模块与具有标量值的参数的连接：

1. 选择该模块。
2. 要连接该模块，请在属性检查器的**参数**选项卡上，单击**连接**。要更改该模块的连接，请改为单击**更改**。
3. 选择要将其参数值连接到的模块。
4. 在表中，选择要连接到的参数。
5. 单击**应用**。

在更新模型图之前，控制模块无法连接到由变量定义的参数。要在仿真未运行时连接到由变量定义的参数，或修改定义已连接参数值的变量的值，请按 **Ctrl+D** 更新模型图。

您还可以将仪表板模块连接到 Stateflow 图表。有关详细信息，请参阅 Connect Dashboard Blocks to Stateflow (Stateflow)。

#### 编程用法

要以编程方式将仪表板模块连接到可调参数，请使用 `Simulink.HMI.ParamSourceInfo` 对象。`Simulink.HMI.ParamSourceInfo` 对象包含四个属性。某些属性适用于将仪表板模块连接到由值定义的参数，某些属性适用于将仪表板模块连接到由变量定义的参数。并非所有字段都有连接值，因为给定的仪表板模块要么连接到由值定义的参数，要么连接到由变量定义的参数。

|  |
| --- |
| **模块参数：** `Binding` |
| **类型：** `Simulink.HMI.ParamSourceInfo` |
| **默认值：** `[]` |

#### 主要

### **标签** — 显示所连接元素名称的标签位置 `Hide` (默认) | `Bottom` | `Top`

您可以在位于模块顶部或底部的标签中显示仪表板模块所连接元素的名称，也可以隐藏标签。如果您希望标签可见，请指定标签的位置。如果您不希望标签可见，请选择 `Hide`。

**注意**

当仪表板模块未连接到元素时，标签为空白。

#### 编程用法

|  |
| --- |
| **模块参数：** `LabelPosition` |
| **类型：** character vector |
| **值：** `'Hide'` | `'Bottom'` | `'Top'` |
| **默认值：** `'Hide'` |

### **锁定纵横比** — 用于保持模块纵横比的选项 `on` (默认) | `off`

选择此参数可在 Simulink 画布中调整模块大小时保持纵横比。

当纵横比锁定时，添加新的背景图像会将模块的纵横比更改为与背景图像的纵横比匹配。当纵横比未锁定时，添加新的背景图像不会更改模块的纵横比，而是会更改背景图像的纵横比以适合模块的大小。

当纵横比锁定时，在调整模块大小时按下 **Shift** 键会临时解锁纵横比。当您释放 **Shift** 键时，纵横比会锁定。当纵横比未锁定时，在调整模块大小时按下 **Shift** 键会临时锁定纵横比。当您释放 **Shift** 键时，纵横比会解锁。

### **状态** — 值与标签的配对 scalar and character vector

每个状态将**状态值**与**状态标签**配对。当模块处于给定状态时，它将该状态的**状态值**赋给所连接的变量或参数。您可以使用**状态标签**在模块上显示赋给所连接变量或参数的值，或提供描述性文本标签。

默认情况下，开关有两个状态，分别对应每个开关位置：

- 在 `Off` 状态下，模块将所连接的变量或参数赋值为 `0`。
- 在 `On` 状态下，模块将所连接的变量或参数赋值为 `1`。

您可以使用可自定义的开关模块设计具有任意数量（大于或等于 1）状态的开关。要添加新状态，请单击 **+** 按钮。要删除当前状态，请单击 **-** 按钮。

**提示**

除了值和标签之外，您还可以在设计模式下为状态配置各种其他参数。例如，您可以选择当开关处于该状态时将出现在开关上的图像。要在设计模式下配置参数：

1. 选择开关模块。
2. 进入设计模式。在属性检查器的**设计**选项卡上，单击**编辑**按钮。
3. 在**设计**选项卡上，打开**状态**组件，展开**选择状态**部分，然后从下拉菜单中选择要配置的状态。
4. 使用模块上方的工具栏，或在属性检查器的**设计**选项卡上的**状态**组件中，配置所选状态的参数值。

#### 编程用法

要以编程方式配置模块的**状态**，请将 `States` 参数的值指定为包含两个元素的结构体数组，其字段为：

- `Value` — 状态的 Scalar double 值。
- `Label` — 用作开关位置标签的 String or character array。

```
leftState.Value = 0;
leftState.Label = 'Off';
rightState.Value = 1;
rightState.Label = 'On';
switchStates = [leftState rightState];
```

| **类型：** two element array of structures |

#### 开关

### **锁定纵横比** — 用于保持模块纵横比的选项 `on` (默认) | `off`

选择此参数可在 Simulink 画布中调整模块大小时保持纵横比。

#### 状态

### **选择状态** — 状态的管理和配置 scalar and character vector

每个状态将**状态值**与**状态标签**配对。当模块处于给定状态时，它将该状态的**状态值**赋给所连接的变量或参数。您可以使用**状态标签**在模块上显示赋给所连接变量或参数的值，或提供描述性文本标签。

默认情况下，开关有两个状态，分别对应每个开关位置：

- 在 `Off` 状态下，模块将所连接的变量或参数赋值为 `0`。
- 在 `On` 状态下，模块将所连接的变量或参数赋值为 `1`。

您可以使用可自定义的开关模块设计具有任意数量（大于或等于 1）状态的开关。要添加新状态，请单击 **+** 按钮。要删除当前状态，请单击 **X** 按钮。

要配置状态，请在**状态**组件中展开**选择状态**部分，然后选择该状态。

您可以在属性检查器的**设计**选项卡上的**状态**组件中配置所选状态的值、标签文本以及各种其他参数。例如，您可以选择当开关处于该状态时将出现在开关上的图像。

您在**状态**组件中对参数值所做的所有更改仅应用于所选状态。要配置其他状态，请在**选择状态**部分的下拉菜单中选择该状态。然后，在**状态**组件中配置该状态的参数值。

**提示**

或者，您可以：

- 使用设计模式下出现在开关模块上方的工具栏配置所选状态的参数
- 使用属性检查器中的**参数**选项卡配置模块状态的值和标签文本

### **标签 X 偏移量** — 文本中心相对于模块左边缘的水平偏移量 `scalar`

指定**状态标签**中心相对于模块左边缘的水平偏移量，以模块宽度的比例表示。相对于偏移量为 `0` 时文本的位置，负值偏移量将文本向左移动，正值偏移量将文本向右移动。

## 版本历史

**在 R2021b 中引入**

### R2025a: 在仿真期间选择 Dashboard 模块并打开模块参数对话框

当来自 Dashboard 或 Customizable Blocks 库的 Simulink 模块处于*活动*状态时，您可以与该模块所代表的小工具交互。例如，您可以按下按钮或拨动开关。当模块处于非活动状态时，您只能与该模块交互。例如，您可以移动该模块或调整其大小。默认情况下，来自 Dashboard 和 Customizable Blocks 库的所有模块在仿真期间均处于活动状态。提升到 Dashboard 面板的模块，当该面板在其自己的窗口中打开，或已停靠且未锁定时，也处于活动状态。如果通过按下按钮触发的回调中至少有一个具有非空值，则 Callback Button 模块始终处于活动状态。要与非活动模块所代表的小工具交互，您可以通过点击该模块来临时激活它。取消选择该模块后，该模块将再次变为非活动状态。

点击活动的 Callback Button 模块，或点击来自 Dashboard 或 Customizable Blocks 库且连接到参数或变量值的活动模块，会同时选择该模块并与该模块所代表的小工具交互。例如，点击未选中的活动且已连接的 Push Button 模块，会同时选择该模块并按下按钮。从 R2025a 开始，您可以通过按住 **Shift** 并点击该模块来选择模块而不与小工具交互。类似地，您可以通过按住 **Shift** 并双击该模块来打开模块参数对话框。

### R2024b: 使用键盘解锁 Dashboard 模块宽高比

如果来自 Dashboard 库的模块的宽高比已锁定，您可以通过按 **Shift** 临时解锁宽高比。释放 **Shift** 键后，宽高比会锁定。

如果宽高比已解锁，按 **Shift** 会临时锁定宽高比。释放 **Shift** 键后，宽高比会解锁。

### R2024a: 将 Dashboard 面板部署为 Web App 或独立桌面 App

借助 Simulink Compiler™ 许可证，您现在可以将 Dashboard 面板（连同该面板所连接的模型一起打包）部署为独立桌面 App 或 Web App。您可以使用该 App 操作面板上的控件并监视面板上的显示，而不依赖 Simulink。

要了解如何部署面板，请参阅将 Dashboard 面板部署为 App。

### R2024a: 停靠 Dashboard 面板

从 R2024a 开始，您可以将 Dashboard 面板停靠到 Simulink 编辑器窗口。您可以使用停靠的面板在仿真期间监视信号并控制参数，而不会遮挡画布中的模型图。

有关详细信息，请参阅停靠面板。

### R2023b: 在新窗口中打开面板

从 R2023b 开始，您可以在新窗口中打开 Dashboard 面板。为此，选择该面板，并暂停在出现的省略号上。在展开的操作菜单中，点击在新窗口中打开。

## 描述

使用具有可自定义外观的开关更改参数或变量值

使用 Toggle Switch 模块可在仿真之前或仿真期间更改所连接变量或参数的值。当您使用 Customizable Blocks 库中的 Toggle Switch 模块时，您可以自定义该模块的外观，使其看起来像您系统中的真实开关。您可以将该开关配置为具有任意数量的状态，以自定义行为。例如，您可以设计一个三路拨动开关或一个变速箱。将 Toggle Switch 模块与其他 Dashboard 模块一起使用，可为您的模型创建交互式 Dashboard。

真实拨动开关具有多个设置。Toggle Switch 模块将这些设置视为不同的状态。一个状态将状态值与图像、点击区域以及显示在点击区域上的状态标签配对。

要在仿真期间激活状态，请点击该状态的点击区域。要在仿真未运行时激活状态，请点击 Toggle Switch 模块以选择该模块，然后点击该状态的点击区域。当您激活该状态时，状态值会分配给 Toggle Switch 模块所连接的 Simulink® 模块图元素。

**注意**

- 在仿真期间或点击模块之后，双击已连接的 Toggle Switch 模块不会打开模块参数对话框。要打开模块参数对话框，请按 **Shift**，然后双击该模块。
- 在仿真期间点击已连接的 Toggle Switch 模块会同时选择该模块并移动开关。要在不移动开关的情况下选择该模块，请按 **Shift**，然后点击该模块。

### 自定义 Toggle Switch 模块

当您将 Toggle Switch 模块添加到模型时，该模块预配置有默认设计。您可以将该模块与默认设计一起使用，或自定义该模块的外观。

要自定义该模块的外观，请使用设计模式。选择该模块后，您可以通过以下三种方式之一进入设计模式：

- 在 Simulink 工具条中，在该模块特定的选项卡上，在 **设计** 下，点击 **编辑**。
- 在属性检查器中，在 **设计** 选项卡上，点击 **编辑**。
- 暂停在模块上方出现的省略号上，然后点击编辑自定义模块按钮。

在设计模式中，您可以使用模块上方的工具栏自定义滑块开关。要访问其他自定义选项或为设计设置输入精确值，请使用属性检查器中的 **设计** 选项卡。

处于设计模式的可自定义 Toggle Switch 模块，其中工具栏和属性检查器中的设计选项卡可见。

当您自定义 Slider Switch 模块时，您需要为每个状态配置模块外观。要选择要自定义的状态，请使用工具栏中的下拉列表。或者，在 **设计** 选项卡上，选择 **状态** 组件，然后从 **选择状态** 列表中选择。要添加状态，请在工具栏中点击添加状态按钮。要删除状态，请点击移除状态按钮。

**用于自定义所选状态的设计模式操作**

| 操作 | 在工具栏中可用 | 在 **设计** 选项卡中可用 |
| --- | --- | --- |
| 指定状态值。 | No | Yes |
| 指定状态标签文本和颜色。 | No | Yes |
| 添加或移除状态。 | Yes | Yes |
| 上传定义模块在该状态下外观的状态图像。 | Yes | Yes |
| 更改状态图像和点击区域的大小。 | No | Yes |
| 更改状态标签、状态图像和点击区域的位置。 | No | Yes |

除了使用工具栏和 **设计** 选项卡自定义模块设计之外，您还可以在画布中以交互方式调整组件大小并重新定位组件。要调整特定于某个状态的组件（例如状态图像）的大小，请在工具栏中选择该状态，然后调整该组件的大小或重新定位该组件。

**适用于所有状态的设计模式操作**

| 操作 | 在工具栏中可用 | 在 **设计** 选项卡中可用 |
| --- | --- | --- |
| 上传背景图像。 | No | Yes |
| 设置纯色背景颜色。 | No | Yes |
| 上传前景图像。 | No | Yes |

完成设计编辑后，要退出设计模式，请点击画布右上角的 **X**。

### 连接 Dashboard 模块

Dashboard 模块不使用端口连接到模型元素。要连接 Dashboard 模块，请使用连接模式。要在未连接的模块上进入连接模式，请暂停在要连接的模块上，然后点击连接按钮。要在已连接的模块上进入连接模式，请选择该模块，暂停在出现的省略号 (…) 上，然后在展开的操作菜单中点击连接按钮。

要将控制模块连接到模型中的参数，或更改控制模块的连接，请进入连接模式。选择要将其参数连接到的模块。在出现的列表中，选择要连接到的参数。然后，暂停在 Dashboard 模块上，并点击完成连接按钮。

在更新模型图之前，控制模块无法连接到由变量定义的参数。要在仿真未运行时连接到由变量定义的参数，或修改定义所连接参数值的变量值，请按 **Ctrl+D** 更新模型图。

您可以连接到具有标量值的参数，或连接到矩阵或结构体的元素。有关详细信息，请参阅将 Dashboard 模块连接到 Simulink 模型。

您还可以将 Dashboard 模块连接到 Stateflow® 图。有关详细信息，请参阅将 Dashboard 模块连接到 Stateflow (Stateflow)。

### 参数记录

连接到 Dashboard 模块的可调参数会记录到仿真数据检查器，您可以在其中查看参数值以及记录的信号数据。您可以通过使用 UI 或 `Simulink.sdi.exportRun` 函数从仿真数据检查器导出参数数据，从而在 MATLAB® 工作区中访问记录的参数数据。有关使用仿真数据检查器 UI 导出数据的详细信息，请参阅将数据导出到工作区或文件。参数数据存储在 `Simulink.SimulationData.Parameter` 对象中，可作为导出的 `Simulink.SimulationData.Dataset` 中的元素进行访问。
