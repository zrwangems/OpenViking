# Automated Manual Transmission

## 端口

### 输入

### **Gear** — 要接合的挡位号 `scalar`

要接合的挡位号的整数值。

### **CltchCmd** — 离合器命令 `scalar`

离合器压力命令。

#### 依赖关系

要创建此端口，请选择 **控制类型** 参数 `External control`。

### **EngTrq** — 施加的输入扭矩 `scalar`

施加的输入扭矩，*Ti*，通常来自发动机曲轴或双质量飞轮减振器，单位为 N·m。

### **DiffTrq** — 施加的负载扭矩 `scalar`

施加的负载扭矩，*Td*，通常来自差速器或传动轴，单位为 N·m。

### **Temp** — 油温 `scalar`

油温，单位为 K。为确定效率，模块使用 4D 查找表，该表是以下量的函数：

- 挡位
- 输入扭矩
- 输入速度
- 油温

#### 依赖关系

要创建此端口，请将 **效率因子** 设置为 `Gear, input torque, input speed, and temperature`。

### 输出

### **Info** — 总线信号 bus

总线信号包含以下模块计算。

| 信号 | | | 描述 | 变量 | 单位 |
| --- | --- | --- | --- | --- | --- |
| `Eng` | `EngTrq` | | 输入施加的扭矩 | *Ti* | N·m |
| `EngSpd` | | 输入驱动轴速度 | *ωi* | rad/s |
| `Diff` | `DiffTrq` | | 输出驱动轴扭矩 | *Tt* | N·m |
| `DiffSpd` | | 输出驱动轴速度 | *ωt* | rad/s |
| `Cltch` | `CltchForce` | | 施加的离合器力 | *Fc* | N |
| `CltchLocked` | | 离合器锁止状态，Boolean：  - 锁止 — `0` - 未锁止 —   `1` | N/A | N/A |
| `Trans` | `TransSpdRatio` | | 时间 *t* 处的速度比 | ϕ(t) | N/A |
| `TransEta` | | 输出功率与输入功率之比 | η | N/A |
| `TransGearCmd` | | 命令挡位 | *Ncmd* | N/A |
| `TransGear` | | 接合挡位 | *N* | N/A |
| `PwrInfo` | `PwrTrnsfrd` | `PwrEng` | 发动机功率 | *Peng* | W |
| `PwrDiffrntl` | 差速器功率 | *Pdiff* | W |
| `PwrNotTrnsfrd` | `PwrEffLoss` | 机械功率损失 | *Peffloss* | W |
| `PwrDampLoss` | 机械阻尼损失 | *Pdamploss* | W |
| `PwrCltchLoss` | 离合器功率损失 | *Pmech* | W |
| `PwrStored` | `PwrStoredTrans` | 旋转动能变化率 | *Pstr* | W |

### **EngSpd** — 角速度 `scalar`

施加的驱动轴角速度输入，*ωi*，单位为 rad/s。

### **DiffSpd** — 角速度 `scalar`

驱动轴角速度输出，*ωd*，单位为 rad/s。

## 参数

### **控制类型** — 指定控制类型 `Ideal integrated controller` (default) | `External control`

AMT 通过控制来自离合器的压力信号连续提供驱动轴扭矩。如果选择 **控制类型** 参数 `Ideal integrated controller`，模块将生成理想化的离合器压力信号。要使用您自己的离合器控制信号，请选择 **控制类型** 参数 `External control`。

| **数据类型：** | `character vector` |

## 描述

理想自动手动变速器

Automated Manual Transmission 模块实现理想自动变速器（AMT）。AMT 是一种手动变速器，带有附加执行器和电子控制单元（ECU），用于根据来自控制器的命令调节离合器和挡位选择。挡位数通过整数向量指定，并具有相应的挡位传动比、惯性、粘性阻尼和效率因子。离合器和同步接合速率是线性的且可调。

将此模块用于：

- 功率和扭矩容量选型
- 确定挡位传动比对燃油经济性和性能的影响

为确定旋转驱动轴速度和反作用扭矩，Automated Manual Transmission 模块计算：

- 离合器锁止和离合器摩擦
- 锁止旋转动力学
- 未锁止旋转动力学

要指定模块效率计算，对于 **效率因子**，选择以下任一选项。

| 设置 | 模块实现 |
| --- | --- |
| `Gear only` | 效率由作为挡位函数的 1D 查找表确定。 |
| `Gear, input torque, input speed, and temperature` | 效率由作为以下量的函数的 4D 查找表确定：  - 挡位 - 输入扭矩 - 输入速度 - 油温 |

### 离合器控制

AMT 通过控制来自离合器的压力信号连续提供驱动轴扭矩。如果选择 **控制类型** 参数 `Ideal integrated controller`，模块将生成理想化的离合器压力信号。要使用您自己的离合器控制信号，请选择 **控制类型** 参数 `External control`。
