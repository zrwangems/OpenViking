# CI Controller

## 端口

### 输入

### **TrqCmd** — 指令发动机扭矩 `scalar`

指令发动机扭矩，*Trqcmd,input*，
单位为 N·m。

### **EngSpd** — 测得发动机转速 `scalar`

测得发动机转速，*N*，单位为 rpm。

### **Map** — 测得进气歧管绝对压力 `scalar`

测得进气歧管绝对压力，*MAP*，
单位为 Pa。

### **Mat** — 测得进气歧管绝对温度 `scalar`

测得进气歧管绝对温度，*MAT*，
单位为 K。

### **AmbPrs** — 环境压力 `scalar`

绝对环境压力，PAmb，
单位为 Pa。

### **EgrVlvAreaPct** — EGR 阀面积百分比 `scalar`

测得 EGR 阀面积百分比，*EGRap*，单位为
%。

### **VgtPos** — VGT 速度 `scalar`

测得 VGT 齿条位置，
*VGTpos*。

### **VgtSpd** — VGT 速度 `scalar`

测得 VGT 速度，*Nvgt*，单位为
rpm。

### **Ect** — 发动机冷却温度 `scalar`

发动机冷却温度，
*Tcoolant*，单位为 K。

### **IgSw** — 点火开关 `Boolean`

车辆点火开关状态，无量纲。

#### 依赖项

要创建此端口，请在 **停止-启动** 选项卡上，选择 **启用发动机停止-启动**。

### **ESSEnable** — 发动机停止-启动使能 `Boolean`

启用或禁用停止-启动逻辑的命令，无量纲。

#### 依赖项

要创建此端口，请在 **停止-启动** 选项卡上，选择 **启用发动机停止-启动**。选择 **外部使能端口**。

## 描述

包括空气质量流量、扭矩和 EGR 估计的压燃式控制器

CI Controller 模块实现了一个压燃式 (CI) 控制器，具有空气
质量流量、扭矩、排气再循环 (EGR) 流量、排气背压和
排气温度估计。您可以在发动机控制设计或性能、燃油经济性和
排放权衡研究中使用 CI Controller 模块。
核心发动机模块需要 CI
Controller 模块输出的命令。

该模块使用指令扭矩和测得发动机转速
来确定以下开环执行器命令：

- 喷油器脉冲宽度
- 燃油喷射正时
- 可变几何涡轮增压器 (VGT) 齿条位置
- EGR 阀面积百分比

CI Controller 模块有两个子系统：

- `Controller` 子系统 —
  基于作为指令扭矩和测得发动机转速函数的表来确定命令。

  | 基于 | 确定的命令 |
  | --- | --- |
  | 指令扭矩  测得发动机转速 | 喷油器脉冲宽度  燃油喷射正时  VGT 齿条位置  EGR 阀面积百分比 |
- `Estimator` 子系统 —
  基于这些发动机属性确定估计值。

  | 基于 | 估计 |
  | --- | --- |
  | 测得发动机转速  燃油喷射正时  循环平均进气歧管压力和温度  燃油喷油器脉冲宽度  绝对环境压力  EGR 阀面积百分比  VGT 齿条位置  VGT 速度 | 空气质量流量  扭矩  排气温度  排气背压  EGR 阀气体质量流量 |

### 控制器

控制器通过指令
VGT 齿条位置、EGR 阀面积百分比、燃油喷射正时
和喷油器脉冲宽度来控制燃烧过程。作为
测得发动机转速和指令扭矩函数的前馈查找表确定控制
命令。

**空气**

控制器指令 EGR 阀面积百分比和 VGT 齿条
位置。更改 VGT 齿条位置会修改涡轮流量
特性。在低请求扭矩下，齿条位置可以降低
排气背压，导致较低的涡轮增压器转速和
增压压力。当指令燃油需要额外空气
质量流量时，齿条位置设置为关闭涡轮增压器叶片，从而提高
涡轮增压器转速和进气歧管增压压力。

可变几何涡轮增压器 (VGT) 齿条位置查找
表是指令扭矩和发动机转速的函数

RPcmd=fRPcmd(Trqcmd,N)

其中：

- *RPcmd* 是
  VGT 齿条位置指令，单位为百分比。
- *Trqcmd* 是
  指令发动机扭矩，单位为 N·m。
- *N* 是发动机转速，单位为 rpm。

齿条位置与指令扭矩和发动机转速的 3D 图

指令排气再循环
(EGR) 阀面积百分比查找表是指令扭矩
和发动机转速的函数

EGRcmd=fEGRcmd(Trqcmd,N)

其中：

- *EGRcmd* 是
  指令 EGR 阀面积百分比，单位为百分比。
- *Trqcmd* 是
  指令发动机扭矩，单位为 N·m。
- *N* 是发动机转速，单位为 rpm。

指令 EGR 阀面积百分比与指令扭矩和发动机转速的 3D 图

**燃油**

为引发燃烧，CI 发动机将燃油直接喷入
燃烧室。喷射后，燃油自燃，增加气缸压力。喷射
燃油的总质量和主喷射正时决定扭矩产生。

假设燃油轨压力恒定，CI 控制器基于
请求的总燃油质量指令喷油器脉冲宽度：

Pwinj=Fcmd, totSinj

该方程使用以下变量。

|  |  |
| --- | --- |
| Pwinj | 燃油喷油器脉冲宽度 |
| *Sinj* | 燃油喷油器斜率 |
| *Fcmd,tot* | 每次喷射的指令总燃油质量 |
| *MAINSOI* | 主喷油开始正时 |
| *N* | 发动机转速 |

指令的每次喷射总燃油质量
表是扭矩指令和发动机转速的函数

Fcmd,tot=fFcmd,tot(Trqcmd,N)

其中：

- *Fcmd,tot* = *F* 是
  指令的每次喷射总燃油质量，单位为 mg per cylinder。
- *Trqcmd* 是
  指令发动机扭矩，单位为 N·m。
- *N* 是发动机转速，单位为 rpm。

指令的每次喷射总燃油质量与指令扭矩和发动机转速的 3D 图

主喷油开始 (SOI) 正时
查找表是指令燃油质量和发动机转速的函数

MAINSOI=f(Fcmd,tot,N)

其中：

- *MAINSOI* 是主喷油开始正时，单位为上止点后曲轴
  转角（degATDC）。
- *Fcmd,tot* = *F* 是
  指令燃油质量，单位为 mg per injection。
- *N* 是发动机转速，单位为 rpm。

**怠速**

当指令扭矩低于阈值时，怠速
转速控制器调节发动机转速。

| 如果 | 怠速转速控制器 |
| --- | --- |
| *Trqcmd,input* < *Trqidlecmd,enable* | 启用 |
| *Trqidlecmd,enable* ≤ *Trqcmd,input* | 未启用 |

怠速转速控制器使用离散 PI 控制器，通过指令扭矩来调节
目标怠速转速。

PI 控制器使用以下传递函数：

Cidle(z)=Kp,idle+Ki,idletsz−1

怠速转速指令扭矩必须小于最大
指令扭矩：

0 ≤ *Trqidlecomd* ≤*Trqidlecmd,max*

在这些条件下，怠速转速控制激活。如果
指令输入扭矩降到启用怠速转速控制器的
阈值以下（*Trqcmd,input* < *Trqidlecmd,enable*），
则指令发动机扭矩由下式给出：

*Trqcmd* = max(*Trqcmd,input*,*Trqidlecmd*)。

这些方程使用以下变量。

|  |  |
| --- | --- |
| *Trqcmd* | 指令发动机扭矩 |
| *Trqcmd,input* | 输入指令发动机扭矩 |
| *Trqidlecmd,enable* | 启用怠速转速控制器的阈值 |
| *Trqidlecmd* | 怠速转速控制器指令扭矩 |
| *Trqidlecmd,max* | 最大指令扭矩 |
| *Nidle* | 基础怠速 |
| *Kp,idle* | 怠速转速控制器比例增益 |
| *Ki,idle* | 怠速转速控制器积分增益 |

**转速限制器**

为防止发动机超速，该模块实现发动机转速限制控制器，该控制器
将发动机转速限制为 **转速限制器转速
阈值** 参数在 **控制** > **怠速**
选项卡上指定的值。

如果发动机转速 *N* 超过发动机转速限制
*Nlim*，该模块将指令发动机
扭矩设置为 0。

为了在发动机转速接近转速
限制时将扭矩指令平滑过渡到 0，该模块实现一个查找表乘数。该查找表将
扭矩指令乘以一个值，该值范围从 0（发动机转速超过限制）到 1（发动机转速
未超过限制）。

### 估计器

使用 CI Core Engine 模块，CI
Controller 模块根据传感器反馈估计空气质量流量、EGR 阀
质量流量、排气背压、发动机扭矩、AFR 和排气
温度。`Info` 端口
提供估计值，但该模块不使用它们来确定
开环发动机执行器命令。

**空气质量流量**

为了计算空气质量流量，压燃式 (CI)
发动机使用 CI Engine Speed-Density Air Mass Flow Model。速度-密度
模型使用速度-密度方程计算发动机空气
质量流量，将发动机进气口质量流量与进气
歧管压力、进气歧管温度和发动机转速关联起来。

**EGR 阀质量流量**

为了计算估计的排气再循环 (EGR) 阀质量流量，该模块
计算在标准温度和压力条件下会发生的 EGR 流量，然后将流量修正到实际温度和压力
条件。该模块的 EGR 计算使用估计排气背压、
估计排气温度、标准温度和标准压力。

  压力比和 EGR 阀流通面积的函数
