# Display

## 端口

在 R2025b 中未记录。

## 参数

使用属性检查器和模块参数对话框指定模块参数的值。要设置仪表板模块的核心参数，请使用模块参数对话框或属性检查器中的 **参数** 选项卡。要自定义模块，请使用属性检查器中的 **设计** 选项卡。要打开模块的模块参数对话框，请双击该模块。要打开属性检查器，请在 **建模** 选项卡上，在 **设计** 下，选择 **属性检查器**。

### 参数

要设置仪表板模块的核心参数，请打开属性检查器，然后单击 **参数** 选项卡。

#### 信号

### **Connection** — 要连接的信号和显示信号连接选项

仪表板模块不使用端口连接到模型元素。要将仪表板模块连接到模型中的参数值，请使用连接模式、Simulink Toolstrip 或模块参数对话框中的 **Connection** 表。有关连接模式以及如何使用工具条进行连接的信息，请参阅 Connect Dashboard Blocks to Simulink Model。

要使用 **Connection** 表连接 Display 模块或更改 Display 模块的连接：

1. 选择该模块。
2. 要连接该模块，请在属性检查器中，在 **参数** 选项卡上单击 **连接**。要更改该模块的连接，请改为单击 **更改**。
3. 选择要连接到的信号线。
4. 在表中，选择要连接到的信号。
5. 单击 **应用**。

还可以将仪表板模块连接到 Stateflow 图。有关详细信息，请参阅 Connect Dashboard Blocks to Stateflow (Stateflow)。

#### 主要

### **Format** — 用于显示信号值的格式 `short`（默认） | `long` | `shortE` | `longE` | ...

指定用于显示信号值的格式。

| 如果选择... | 模块显示... |
| --- | --- |
| `short` | 缩放定点十进制格式，小数点后四位。 |
| `long` | 缩放定点十进制格式，对于 `double` 值小数点后十五位，对于 `single` 值小数点后七位。 |
| `shortE` | 科学计数法格式，四位数字。 |
| `longE` | 科学计数法格式，对于 `double` 值小数点后十五位，对于 `single` 值小数点后七位。 |
| `shortG` | 数据采用定点十进制或科学计数法中更紧凑的格式，总共五位数字。 |
| `longG` | 数据采用定点十进制或科学计数法中更紧凑的格式，对于 `double` 值总共十五位数字，对于 `single` 值七位数字。 |
| `shortEng` | 工程计数法，其中指数为三的倍数，小数点后四位。 |
| `longEng` | 工程计数法，其中指数为三的倍数，具有十五位有效数字。 |
| `+-` | 正/负格式。分别对正值、负值和零值显示 `+`、`-` 和空白字符。 |
| `bank` | 货币格式，小数点后两位。 |
| `hex` | 十六进制表示。 |
| `rat` | 比率。 |
| `Custom` | 自定义字符串格式。数据以使用 **Format String** 参数指定的自定义字符串显示。 |
| `Integer` | 数据舍入到最接近的整数。 |

当将 Display 模块连接到 String Constant 模块输出的信号时，无论 **Format** 参数的值如何，显示信号值的格式均为 `string`。类似地，当将 Display 模块连接到 Enumerated Constant 模块输出的信号时，无论 **Format** 参数的值如何，显示信号值的格式均为 `enum`。

### **Format String** — 用于格式化数据的自定义字符串 `'%d'`（默认） | string

指定用于格式化所显示信号数据的自定义字符串。格式字符串由文本和格式运算符组成，格式运算符以 `%` 符号开头，以转换字符结尾。在字符串中希望显示信号数据的位置使用格式运算符。有关支持的格式运算符的详细信息，请参阅 `compose` 函数的 `formatSpec` 输入。

**示例：** `The value of pi is %.2f` 在句子中显示所连接信号的值。

**示例：** `$%.2f` 显示所连接信号的值，并带有美元符号和两位小数。

#### 依赖关系

要启用此参数，请将 **Format** 设置为 `Custom`。

### **Label** — 显示所连接元素名称的标签位置 `Top`（默认） | `Bottom` | `Hide`

可以在位于模块顶部或底部的标签中显示仪表板模块所连接元素的名称，也可以隐藏标签。如果希望标签可见，请指定标签的位置。如果不希望标签可见，请指定 `Hide`。

**注意**

### **Lock Aspect Ratio** — 用于保持模块纵横比的选项 `on`（默认） | `off`

选择此参数可在 Simulink 画布中调整模块大小时保持纵横比。

当纵横比锁定时，添加新的背景图像会更改模块的纵横比，使其与背景图像的纵横比匹配。当纵横比未锁定时，添加新的背景图像不会更改模块的纵横比，而是更改背景图像的纵横比以适合模块的大小。

当纵横比锁定时，在调整模块大小时按 **Shift** 键会临时解锁纵横比。释放 **Shift** 键时，纵横比会锁定。当纵横比未锁定时，在调整模块大小时按 **Shift** 键会临时锁定纵横比。释放 **Shift** 键时，纵横比会解锁。

#### 显示

### **Lock Aspect Ratio** — 用于保持模块纵横比的选项 `on`（默认） | `off`

选择此参数可在 Simulink 画布中调整模块大小时保持纵横比。

当纵横比锁定时，添加新的背景图像会更改模块的纵横比，使其与背景图像的纵横比匹配。当纵横比未锁定时，添加新的背景图像不会更改模块的比例，而是拉伸或缩放背景图像以适合模块的大小。

当纵横比锁定时，在调整模块大小时按 **Shift** 键会解锁纵横比。释放 **Shift** 键时，纵横比会锁定。当纵横比未锁定时，在调整模块大小时按 **Shift** 键会锁定纵横比。释放 **Shift** 键时，纵横比会解锁。

#### 文本

### **Font** — 字体 `Courier Prime` | `DSEG7-Classic` | `Noto Sans` | `Noto Serif` | `Roboto` | `Ubuntu`

从在所有平台上看起来相同的 WYSIWYG（所见即所得）字体列表中选择。

### **Size** — 字体大小 scalar

从 `6` 到 `72` 之间的字体大小列表中选择。

### **Text Color** — 文本颜色 `[r g b]` vector

从标准颜色调色板中选择文本颜色，或指定自定义颜色。

### **X Offset** — 文本中心相对于模块中心的水平偏移 scalar

指定文本中心相对于模块中心的水平偏移，以模块宽度的比例表示。相对于偏移为 `0` 时的文本位置，负值偏移会将文本向左移动，正值偏移会将文本向右移动。

### **Y Offset** — 文本中心相对于模块中心的垂直偏移 scalar

指定文本中心相对于模块中心的垂直偏移，以模块高度的比例表示。相对于偏移为 `0` 时的文本位置，负值偏移会将文本向上移动，正值偏移会将文本向下移动。

### **Width** — 文本边界框的宽度 scalar

以模块宽度的比例指定文本边界框的宽度。

### **Height** — 文本边界框的高度 scalar

以模块高度的比例指定文本边界框的高度。

### **Lock Aspect Ratio** — 用于保持文本边界框纵横比的选项 `on`（默认） | `off`

选择此参数可在 Simulink 画布中调整文本边界框大小时保持纵横比。

#### 背景图像

### **Use Background Color** — 用于指定纯色模块背景颜色的选项 `off`（默认） | `on`

对于模块背景，可以提供背景图像或选择纯色。要选择纯色背景，请选择此参数。要提供背景图像，请清除此参数。

**注意**

使用 Simulink Toolstrip 的 **Format** 选项卡更改背景颜色会移除背景图像并启用 **Use Background Color** 参数。

**示例：** `on`

### **Color** — 模块背景颜色 `[r g b]` vector

要使用纯色背景，请选择 **Use Background Color** 参数。然后，从标准颜色调色板中选择背景颜色，或指定自定义颜色。

**提示**

还可以在 Simulink Toolstrip 的 **Format** 选项卡中指定 **Background Color**。

要指定模块文本的颜色，请使用 **Font Color** 参数。

将模块的 `BackgroundColor` 参数指定为 `1` 乘 `3` 的 `[r g b]` vector，其值介于 `0` 和 `1` 之间，并格式化为 string 或 character vector。

|  |

### **Opacity** — 模块背景不透明度 `1`（默认） | scalar

将模块背景不透明度指定为从 `0` 到 `1` 的 scalar 值。

### **Corner Radius** — 具有模块背景颜色的区域的圆角半径 scalar

以模块两个维度（宽度或高度）中较小者的一半的比例，指定由模块背景颜色覆盖的区域的圆角半径。

**示例：** `0.25`

#### 前景图像

### **X Offset** — 前景图像左边缘相对于模块左边缘的水平偏移 scalar

指定图像左边缘相对于模块左边缘的水平偏移，以模块宽度的比例表示。相对于偏移为 `0` 时的图像位置，负值偏移会将图像向左移动，正值偏移会将图像向右移动。

**示例：** `1`

### **Width** — 前景图像宽度 scalar

以模块宽度的比例指定前景图像的宽度。

**示例：** `0.5`

### **Height** — 前景图像高度 scalar

以模块高度的比例指定前景图像的高度。

**示例：** `0.5`

## 描述

在仿真期间以可自定义的外观显示信号值

Display 模块连接到模型中的信号，并在仿真期间显示信号值。Display 模块可以显示标量信号。在 Customizable Blocks 库中使用 Display 模块时，可以自定义模块的外观，使其看起来像系统中的真实显示器。将 Display 模块与其他仪表板模块一起使用，可为模型构建包含控件和指示器的交互式仪表板。

### 自定义 Display 模块

将 Display 模块添加到模型时，该模块已预配置为默认设计。您可以沿用默认设计使用该模块，也可以自定义模块的外观。

要自定义模块外观，请使用设计模式。选择模块后，可以通过以下三种方式之一进入设计模式：

- 在 Simulink® 工具条中，在模块特定的选项卡上，在
  **设计** 下，点击 **编辑**。
- 在属性检查器中，在 **设计** 选项卡上，点击
  **编辑**。
- 将鼠标暂停在模块上出现的省略号上，并点击编辑自定义模块
  按钮 。

在设计模式下，可以使用模块上方的工具栏自定义显示。要访问其他自定义选项或为设计设置输入精确值，请使用属性检查器中的 **设计** 选项卡。

处于设计模式的可自定义 Display 模块，其中工具栏和属性检查器中的设计选项卡可见。

**设计模式操作**

| 操作 | 在工具栏中可用 | 在 **设计** 选项卡中可用 |
| --- | --- | --- |
| 更改字体。从在所有平台上外观相同的 WYSIWYG（what you see is what you get）字体列表中选择。 | Yes | Yes |
| 更改字体大小。 | Yes | Yes |
| 更改文本颜色。 | Yes | Yes |
| 将文本设为粗体、斜体或带下划线。 | Yes | Yes |
| 上传背景图像。 | Yes | Yes |
| 设置纯色背景颜色。 | No | Yes |
| 上传前景图像。 | No | Yes |
| 更改文本在模块内的位置。 | No | Yes |

除了使用工具栏和 **设计** 选项卡自定义模块设计外，还可以在画布中以交互方式重新定位文本。

完成设计编辑后，要退出设计模式，请点击画布右上角的 **X**。

### 连接 Dashboard 模块

Dashboard 模块不使用端口连接到模型元素。要连接 Dashboard 模块，请使用连接模式。要在未连接的模块上进入连接模式，请将鼠标暂停在要连接的模块上，然后点击连接按钮。要在已连接的模块上进入连接模式，请选择该模块，将鼠标暂停在出现的省略号 (…) 上，然后在展开的操作菜单中点击连接按钮。

要将 Display 模块连接到模型中的信号，或更改 Display 模块的连接，请进入连接模式。选择要连接的信号线。从出现的列表中，选择要连接的信号。然后，将鼠标暂停在 Dashboard 模块上，并点击完成连接按钮。要查看 Dashboard 模块显示所连接模块的值，请运行仿真。

有关连接 Dashboard 模块的详细信息，请参阅将 Dashboard 模块连接到 Simulink 模型。

还可以将 Dashboard 模块连接到 Stateflow® 图。有关详细信息，请参阅将 Dashboard 模块连接到 Stateflow (Stateflow)。

未连接的 Display 模块连接到 Sine Wave 模块发送到 Outport 模块的信号。

未连接的 Half Gauge 模块连接到 Sine Wave 模块发送到 Display 模块的信号。
