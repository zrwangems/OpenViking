## 参数

使用属性检查器和模块参数对话框指定模块参数的值。要设置仪表板模块的核心参数，请使用模块参数对话框或属性检查器中的**参数**选项卡。要自定义模块，请使用属性检查器中的**设计**选项卡。要打开模块的模块参数对话框，请双击该模块。要打开属性检查器，请在**建模**选项卡的**设计**下，选择**属性检查器**。

### 参数

要设置仪表板模块的核心参数，请打开属性检查器并点击**参数**选项卡。

#### 连接

### **Connection** — 要连接的模块参数值 参数值连接选项

仪表板模块不使用端口连接到模型元素。要将仪表板模块连接到模型中的参数值，请使用连接模式、Simulink 工具条或模块参数对话框中的**连接**表。要从属性检查器打开模块参数对话框，请在**连接到**右侧，点击**连接**或**更改**。您可以连接到具有标量值的参数，或连接到矩阵的元素。有关连接模式以及如何使用工具条进行连接的信息，请参阅 Connect Dashboard Blocks to Simulink Model。

要使用**连接**表将控制模块连接到具有标量值的参数，或更改控制模块与具有标量值的参数的连接：

1. 选择该模块。
2. 要连接该模块，请在属性检查器的**参数**选项卡上，点击**连接**。要更改该模块的连接，请改为点击**更改**。
3. 选择要将其参数值连接到的模块。
4. 在表中，选择要连接到的参数。
5. 点击**应用**。

在更新模型图之前，控制模块无法连接到由变量定义的参数。要连接到由变量定义的参数，或在仿真未运行时修改定义已连接参数值的变量的值，请按 **Ctrl+D** 更新模型图。

您还可以将仪表板模块连接到 Stateflow 图。有关详细信息，请参阅 Connect Dashboard Blocks to Stateflow (Stateflow)。

#### 编程用法

要以编程方式将仪表板模块连接到可调参数，请使用 `Simulink.HMI.ParamSourceInfo` 对象。`Simulink.HMI.ParamSourceInfo` 对象包含四个属性。某些属性适用于将仪表板模块连接到由值定义的参数，某些属性适用于将仪表板模块连接到由变量定义的参数。并非所有字段都有连接的值，因为给定的仪表板模块要么连接到由值定义的参数，要么连接到由变量定义的参数。

### **Lock Aspect Ratio** — 保持模块宽高比的选项 `on`（默认）| `off`

选择此参数可在 Simulink 画布中调整模块大小时保持宽高比。

当宽高比锁定时，添加新的背景图像会将模块的宽高比更改为与背景图像的宽高比匹配。当宽高比未锁定时，添加新的背景图像不会更改模块的宽高比，而是更改背景图像的宽高比以适合模块的大小。

当宽高比锁定时，在调整模块大小时按下 **Shift** 键会临时解锁宽高比。当您释放 **Shift** 键时，宽高比锁定。当宽高比未锁定时，在调整模块大小时按下 **Shift** 键会临时锁定宽高比。当您释放 **Shift** 键时，宽高比解锁。

## 版本历史

**在 R2021a 中引入**

### R2025a：在仿真期间选择 dashboard 模块并打开模块参数对话框

当 Dashboard 或 Customizable Blocks 库中的 Simulink 模块处于*活动*状态时，您可以与该模块所代表的组件进行交互。例如，您可以按下按钮或拨动开关。当模块处于非活动状态时，您只能与模块本身进行交互。例如，您可以移动或调整模块大小。默认情况下，Dashboard 和 Customizable Blocks 库中的所有模块在仿真期间均处于活动状态。提升到 dashboard 面板的模块在面板于其自身窗口中打开或停靠且未锁定时也处于活动状态。Callback Button 模块中，由按下按钮触发的至少一个回调具有非空值时，该模块始终处于活动状态。要与非活动模块所代表的组件进行交互，您可以通过点击该模块来临时激活它。当您取消选择该模块时，该模块将再次变为非活动状态。

点击活动的 Callback Button 模块或连接到参数或变量值的 Dashboard 或 Customizable Blocks 库中的活动模块，既会选择该模块，也会与该模块所代表的组件进行交互。例如，点击未选中的活动已连接 Push Button 模块既会选择该模块，也会按下按钮。从 R2025a 开始，您可以通过按住 **Shift** 然后点击模块来选择模块而不与组件进行交互。同样，您可以通过按住 **Shift** 然后双击模块来打开模块参数对话框。

### R2024b：使用键盘解锁 dashboard 模块宽高比

如果 Dashboard 库中模块的宽高比已锁定，您可以通过按住 **Shift** 临时解锁宽高比。当您释放 **Shift** 键时，宽高比将锁定。

如果宽高比已解锁，按住 **Shift** 将临时锁定宽高比。当您释放 **Shift** 键时，宽高比将解锁。

## 描述

使用具有可自定义外观的水平滑块更改参数或变量值

使用 Horizontal Slider 模块在仿真期间调节变量或模块参数的值。您可以自定义 Horizontal Slider 模块的外观，使其看起来像真实系统中的控件。您可以调整刻度范围和刻度值，以适应要调节的值的所需范围。将 Horizontal Slider 模块与其他 dashboard 模块一起使用，以创建交互式 dashboard 来控制您的模型。

要在仿真运行时调节值，请使用指针将手柄拖动到要将所连接变量或模块参数设置为的刻度值。要在仿真未运行时调节值，请点击 Horizontal Slider 模块以选择该模块，然后将手柄拖动到要将所连接变量或模块参数设置为的刻度值。

**注意**

- 在仿真期间或点击模块后，双击已连接的 Horizontal Slider 模块不会打开模块参数对话框。要打开模块参数对话框，请按 **Shift**，然后双击该模块。
- 在仿真期间点击已连接的 Horizontal Slider 模块既会选择该模块，也会移动滑块手柄。要选择模块而不移动滑块手柄，请按 **Shift**，然后点击该模块。

### 自定义 Horizontal Slider 模块

当您将 Horizontal Slider 模块添加到模型时，该模块已预配置为默认设计。您可以使用默认设计的模块，也可以自定义模块的外观。

要自定义模块的外观，请使用设计模式。选择模块后，您可以通过以下三种方式之一进入设计模式：

- 在 Simulink® 工具条中，在模块特定选项卡上的 **Design** 下，点击 **Edit**。
- 在属性检查器中，在 **Design** 选项卡上，点击 **Edit**。
- 暂停在模块上方出现的省略号上，然后点击 Edit Custom Block 按钮 。

在设计模式中，您可以使用模块上方的工具栏来自定义圆形仪表。要访问其他自定义选项或为设计设置输入精确值，请使用属性检查器中的 **Design** 选项卡。

处于设计模式的 Horizontal Slider 模块，工具栏和属性检查器中的 Design 选项卡可见。

**设计模式操作**

| 操作 | 在工具栏中可用 | 在 **Design** 选项卡中可用 |
| --- | --- | --- |
| 上传手柄图像。 | 是 | 是 |
| 上传背景图像。 | 是 | 是 |
| 设置纯色背景颜色。 | 否 | 是 |
| 上传前景图像。 | 否 | 是 |
| 指定值条增长所依据的原点的位置。 | 否 | 是 |
| 更改刻度线、刻度标签或值条的颜色和不透明度。 | 是 | 是 |
| 将刻度方向指定为从左到右或从右到左。 | 否 | 是 |
| 更改刻度和手柄的大小。 | 否 | 是 |
| 更改刻度和手柄的位置。 | 否 | 是 |

要使用工具栏更改刻度线、刻度标签或值条的颜色和不透明度，请在工具栏从左数第二部分中，选择要更改颜色的组件。要更改颜色，请点击色轮。要更改不透明度，请移动滑块。

除了使用工具栏和 **Design** 选项卡自定义模块设计外，您还可以在画布中以交互方式调整组件大小和重新定位组件。

完成设计编辑后，要退出设计模式，请点击画布右上角的 **X**。

### 连接 Dashboard 模块

Dashboard 模块不使用端口连接到模型元素。要连接 dashboard 模块，请使用连接模式。要在未连接的模块上进入连接模式，请暂停在要连接的模块上，然后点击 Connect 按钮 。要在已连接的模块上进入连接模式，请选择该模块，暂停在出现的省略号 (…) 上，然后在展开的操作菜单中点击 Connect 按钮。

要将控制模块连接到模型中的参数，或更改控制模块的连接，请进入连接模式。选择要将其参数连接到的模块。在出现的列表中，选择要连接到的参数。然后，暂停在 dashboard 模块上，并点击 Done Connecting 按钮 。

在更新模型图之前，控制模块无法连接到由变量定义的参数。要在仿真未运行时连接到由变量定义的参数，或修改定义已连接参数值的变量值，请按 **Ctrl+D** 更新模型图。

您可以连接到具有标量值的参数，也可以连接到矩阵或结构的元素。有关详细信息，请参阅 Connect Dashboard Blocks to Simulink Model。

您还可以将 dashboard 模块连接到 Stateflow® 图。有关详细信息，请参阅 Connect Dashboard Blocks to Stateflow (Stateflow)。

### 参数记录

连接到 dashboard 模块的可调参数会记录到仿真数据检查器中，您可以在其中查看参数值以及记录的信号数据。您可以通过使用 UI 或 `Simulink.sdi.exportRun` 函数从仿真数据检查器导出参数数据，从而在 MATLAB® 工作区中访问记录的参数数据。有关使用仿真数据检查器 UI 导出数据的详细信息，请参阅 Export Data to Workspace or File。参数数据存储在 `Simulink.SimulationData.Parameter` 对象中，可作为导出的 `Simulink.SimulationData.Dataset` 中的元素访问。
