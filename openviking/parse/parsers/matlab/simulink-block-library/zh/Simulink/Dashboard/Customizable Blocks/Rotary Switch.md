## 参数

使用属性检查器和模块参数对话框指定模块参数的值。要设置仪表板模块的核心参数，请使用模块参数对话框或属性检查器中的 **参数** 选项卡。要自定义模块，请使用属性检查器中的 **设计** 选项卡。要打开某个模块的模块参数对话框，请双击该模块。要打开属性检查器，请在 **建模** 选项卡上的 **设计** 下，选择 **属性检查器**。

### 参数

要设置仪表板模块的核心参数，请打开属性检查器，然后单击 **参数** 选项卡。

#### 连接

### **连接** — 将模块参数值连接到参数值的连接选项

仪表板模块不使用端口连接到模型元素。要将仪表板模块连接到模型中的参数值，请使用连接模式、Simulink 工具条或模块参数对话框中的 **连接** 表。要从属性检查器打开模块参数对话框，请在 **连接到** 右侧单击 **连接** 或 **更改**。您可以连接到具有标量值的参数，也可以连接到矩阵的元素。有关连接模式以及如何使用工具条进行连接的信息，请参阅将仪表板模块连接到 Simulink 模型。

要使用 **连接** 表将控制模块连接到具有标量值的参数，或更改控制模块与具有标量值的参数的连接，请执行以下操作：

1. 选择该模块。
2. 要连接该模块，请在属性检查器的 **参数** 选项卡上，单击 **连接**。要更改该模块的连接，请改为单击 **更改**。
3. 选择要将其参数值连接到的模块。
4. 在表中，选择要连接到的参数。
5. 单击 **应用**。

在更新模型图之前，控制模块无法连接到由变量定义的参数。要在仿真未运行时连接到由变量定义的参数，或修改定义已连接参数值的变量的值，请按 **Ctrl+D** 更新模型图。

您还可以将仪表板模块连接到 Stateflow 图表。有关详细信息，请参阅将仪表板模块连接到 Stateflow (Stateflow)。

#### 编程用法

要以编程方式将仪表板模块连接到可调参数，请使用 `Simulink.HMI.ParamSourceInfo` 对象。`Simulink.HMI.ParamSourceInfo` 对象包含四个属性。有些属性适用于将仪表板模块连接到由值定义的参数，有些属性适用于将仪表板模块连接到由变量定义的参数。并非所有字段都有连接值，因为给定的仪表板模块要么连接到由值定义的参数，要么连接到由变量定义的参数。

|  |
| --- |
| **模块参数:** `Binding` |
| **类型:** `Simulink.HMI.ParamSourceInfo` |
| **默认值:** `[]` |

#### 主要

### **标签** — 显示所连接元素名称的标签位置 `Hide` (默认) | `Bottom` | `Top`

您可以在位于模块顶部或底部的标签中显示仪表板模块所连接元素的名称，也可以隐藏标签。如果您希望标签可见，请指定标签的位置。如果您不希望标签可见，请选择 `Hide`。

**注意**

当仪表板模块未连接到元素时，标签为空白。

| **默认值:** `'Hide'` |

### **锁定纵横比** — 保持模块纵横比的选项 `on` (默认) | `off`

在 Simulink 画布中调整模块大小时，选择此参数可保持纵横比。

锁定纵横比时，添加新的背景图像会将模块的纵横比更改为与背景图像的纵横比匹配。解锁纵横比时，添加新的背景图像不会更改模块的纵横比，而是更改背景图像的纵横比以适合模块的大小。

锁定纵横比时，在调整模块大小时按 **Shift** 键会临时解锁纵横比。释放 **Shift** 键后，纵横比将锁定。解锁纵横比时，在调整模块大小时按 **Shift** 键会临时锁定纵横比。释放 **Shift** 键后，纵横比将解锁。

### **枚举数据类型** — 使用枚举数据类型指定状态值和标签 `off` (默认) | `on`

您可以使用将数值与每个枚举配对的枚举数据类型来配置模块的状态值和标签。首先，选择 **枚举数据类型**。然后，在文本框中指定枚举数据类型的名称。指定的枚举数据类型的定义必须保存在 MATLAB 路径上或基础工作区中。

**注意**

您可以使用 `Simulink.defineIntEnumType` 函数定义枚举数据类型。例如，要为从一到五的一组罗马数字定义枚举数据类型 `myEnumType`，请使用以下命令。

```
Simulink.defineIntEnumType('myEnumType',...
    {'I','II','III','IV','V'}, [1 2 3 4 5]);
```

然后，在属性检查器的 **参数** 选项卡上的 **枚举数据类型** 字段中，输入 `myEnumType`。

#### 编程用法

### **状态** — 值与标签的配对 scalar 和 character vector

每个状态将 **状态值** 与 **状态标签** 配对。当模块处于给定状态时，它会将该状态的 **状态值** 赋给连接的变量或参数。您可以使用 **状态标签** 在模块上显示赋给连接的变量或参数的值，或提供描述性文本标签。

默认情况下，开关具有五个状态，每个状态对应一个开关位置。

| 状态值 | 状态标签 |
| --- | --- |
| `0` | `Off` |
| `1` | `Low` |
| `2` | `Medium` |
| `3` | `High` |
| `4` | `On` |

您可以使用可自定义的开关模块设计具有任意数量状态（大于或等于 1）的开关。要添加新状态，请单击 **+** 按钮。要删除当前状态，请单击 **-** 按钮。

**注意**

启用 **枚举数据类型** 时，无法添加或删除状态。

**提示**

您还可以在设计模式下配置状态的参数：

1. 选择开关模块。
2. 进入设计模式。在属性检查器的 **设计** 选项卡上，单击 **编辑**。
3. 在 **设计** 选项卡上，打开 **状态** 组件，展开 **选择状态** 部分，然后从下拉菜单中选择要配置的状态。
4. 使用模块上方的工具栏或属性检查器配置所选状态的参数值。

#### 编程用法

要以编程方式配置模块的 **状态**，请将 `States` 参数的值指定为包含两个元素的结构体数组，这些元素具有以下字段：

- `Value` — 状态的 Scalar double 值
- `Label` — 用作开关位置标签的 String 或 character array

```
firstState.Value = 0;
firstState.Label = 'Off';
secondState.Value = 1;
secondState.Label = 'On';
switchStates = [firstState secondState];
```

|  |
| --- |
| **模块参数:** `States` |
| **类型:** two element array of structures |

### **锁定纵横比** — 保持模块纵横比的选项 `on` (默认) | `off`

## 版本历史

**在 R2021b 中引入**

### R2025a：在仿真期间选择 dashboard 模块并打开模块参数对话框

当来自 Dashboard 或 Customizable Blocks 库的 Simulink 模块处于 *活动* 状态时，您可以与该模块表示的 gadget 交互。例如，您可以按下按钮或拨动开关。当模块处于非活动状态时，您只能与模块交互。例如，您可以移动或调整模块大小。默认情况下，来自 Dashboard 和 Customizable Blocks 库的所有模块在仿真期间均处于活动状态。提升到 dashboard 面板的模块在面板在其自己的窗口中打开或以停靠且未锁定状态打开时也处于活动状态。对于 Callback Button 模块，如果通过按下按钮触发的至少一个回调具有非空值，则这些模块始终处于活动状态。要与非活动模块表示的 gadget 交互，您可以通过点击模块临时激活该模块。当您取消选择该模块时，该模块再次变为非活动状态。

点击活动的 Callback Button 模块，或点击来自 Dashboard 或 Customizable Blocks 库、连接到参数或变量值且处于活动状态的模块，会同时选择该模块并与该模块表示的 gadget 交互。例如，点击未选择、处于活动状态且已连接的 Push Button 模块会同时选择该模块并按下按钮。从 R2025a 开始，您可以通过按住 **Shift** 并点击模块来选择该模块而不与 gadget 交互。类似地，您可以通过按住 **Shift** 并双击模块来打开模块参数对话框。

### R2024b：使用键盘解锁 dashboard 模块纵横比

如果来自 Dashboard 库的模块的纵横比已锁定，您可以通过按 **Shift** 临时解锁纵横比。释放 **Shift** 键时，纵横比会锁定。

如果纵横比未锁定，按 **Shift** 会临时锁定纵横比。释放 **Shift** 键时，纵横比会解锁。

## 描述

使用具有可自定义外观的旋转开关更改参数或变量值

使用 Rotary Switch 模块在仿真之前或期间更改所连接的变量或参数的值。当您使用 Customizable Blocks 库中的 Rotary Switch 模块时，可以自定义该模块的外观，使其看起来像您系统中的真实旋转开关。将 Rotary Switch 模块与其他 dashboard 模块一起使用，为您的模型创建交互式 dashboard。

真实的旋转开关具有多个设置。Rotary Switch 模块将这些设置视为不同的状态。一个状态将状态值与手柄方向、点击区域以及显示在点击区域上的状态标签配对。

要在仿真期间激活状态，请点击该状态的点击区域，或将手柄拖动到指向该点击区域。要在仿真未运行时激活状态，请点击 Rotary Switch 模块以选择该模块，然后点击点击区域或将手柄拖动到指向该点击区域。当您激活状态时，状态值会分配给 Rotary Switch 模块所连接的 Simulink® 框图元素。

状态点击区域总体上覆盖模块中手柄从第一个状态移动到最后一个状态时所经过的角度范围内的区域。状态标签在该范围上均匀分布，第一个标签位于范围的起点，最后一个标签位于范围的终点。该范围被细分为点击区域，使得相邻点击区域的边界平分标签之间的角度距离。

该图像显示了一个具有四种状态的自定义旋转开关。第一个状态和最后一个状态的标签相隔 150 degrees。状态标签（顺时针读取）为 A、B、C 和 D。点击区域以四种不同颜色显示。第一个和第四个状态的点击区域跨越的角度距离是其他每个状态跨越角度距离的一半。

**注意**

- 在仿真期间双击已连接的 Rotary Switch 模块，或在点击该模块后双击，不会打开模块参数对话框。要打开模块参数对话框，请按 **Shift**，然后双击该模块。
- 在仿真期间点击已连接的 Rotary Switch 模块会同时选择该模块并移动开关手柄。要选择模块而不移动开关手柄，请按 **Shift**，然后点击该模块。

### 自定义 Rotary Switch 模块

当您将 Rotary Switch 模块添加到模型时，该模块已预配置默认设计。您可以使用具有默认设计的模块，或自定义该模块的外观。

要自定义模块的外观，请使用设计模式。选择该模块后，您可以通过以下三种方式之一进入设计模式：

- 在 Simulink Toolstrip 中，在模块特定的选项卡上，在 **Design** 下，点击 **Edit**。
- 在 Property Inspector 中，在 **Design** 选项卡上，点击 **Edit**。
- 暂停在模块上方出现的省略号上，然后点击 Edit Custom Block 按钮。

在设计模式下，您可以使用模块上方的工具栏自定义旋转开关。要访问其他自定义选项或为设计设置输入精确值，请使用 Property Inspector 中的 **Design** 选项卡。

处于设计模式的可自定义 Rotary Switch 模块，其中工具栏和 Property Inspector 中的 Design 选项卡可见。

自定义 Rotary Switch 模块时，您会为每个状态配置模块外观。要选择要自定义的状态，请使用工具栏中的下拉列表。或者，在 **Design** 选项卡上，选择 **States** 组件，然后从 **Select State** 列表中选择。要添加状态，请在工具栏中点击 Add State 按钮。要删除状态，请点击 Remove State 按钮。

**用于自定义所选状态的设计模式操作**

| 操作 | 在工具栏中可用 | 在 **Design** 选项卡中可用 |
| --- | --- | --- |
| 指定状态值。 | No | Yes |
| 指定状态标签文本。 | No | Yes |
| 添加或移除状态。 | Yes | Yes |
| 上传手柄图像。 | Yes | Yes |
| 更改手柄大小。 | No | Yes |
| 更改手柄位置。 | No | Yes |

除了使用工具栏和 **Design** 选项卡自定义模块设计外，您还可以在画布中以交互方式调整组件大小并重新定位。手柄的移动限制在通过模块中心且位于 **Start Angle** 的线上。

要更改状态标签的颜色，请在 **Format** 选项卡上的 **Style** 下，点击 **Foreground** 按钮上的箭头并选择颜色。您可以从标准颜色调色板中选择，或点击 Custom Colors 按钮指定自定义颜色。

**适用于所有状态的设计模式操作**

| 操作 | 在工具栏中可用 | 在 **Design** 选项卡中可用 |
| --- | --- | --- |
| 更改状态标签跨越的弧长。 | No | Yes，在 **Rotary Switch** 组件中 |
| 更改弧的起始角度。 | No | Yes，在 **Rotary Switch** 组件中 |
| 更改标签半径。 | No | Yes，在 **Rotary Switch** 组件中 |
| 上传背景图像。 | Yes | Yes |
| 设置纯色背景。 | No | Yes |
| 上传前景图像。 | No | Yes |

完成设计编辑后，要退出设计模式，请点击画布右上角的 **X**。

### 连接 Dashboard 模块

Dashboard 模块不使用端口连接到模型元素。要连接 dashboard 模块，请使用连接模式。对于未连接的模块，要进入连接模式，请暂停在要连接的模块上，然后点击 Connect 按钮。对于已连接的模块，要进入连接模式，请选择该模块，暂停在出现的省略号 (…) 上，然后在展开的操作菜单中点击 Connect 按钮。

要将控制模块连接到模型中的参数，或更改控制模块的连接，请进入连接模式。选择要将其参数连接到的模块。从出现的列表中，选择要连接到的参数。然后，暂停在 dashboard 模块上，并点击 Done Connecting 按钮。

在更新模型图之前，控制模块无法连接到由变量定义的参数。要在仿真未运行时连接到由变量定义的参数，或修改定义所连接参数值的变量值，请按 **Ctrl+D** 更新模型图。

您可以连接到具有标量值的参数，或连接到矩阵或结构的元素。有关详细信息，请参阅 Connect Dashboard Blocks to Simulink Model。

您还可以将 dashboard 模块连接到 Stateflow® 图。有关详细信息，请参阅 Connect Dashboard Blocks to Stateflow (Stateflow)。

### 参数记录

连接到 dashboard 模块的可调参数会记录到 Simulation Data Inspector，您可以在其中查看参数值以及记录的信号数据。您可以通过使用 UI 或 `Simulink.sdi.exportRun` 函数从 Simulation Data Inspector 导出参数数据，从而在 MATLAB® 工作区中访问记录的参数数据。有关使用 Simulation Data Inspector UI 导出数据的详细信息，请参阅 Export Data to Workspace or File。参数数据存储在 `Simulink.SimulationData.Parameter` 对象中，可作为导出的 `Simulink.SimulationData.Dataset` 中的元素访问。
