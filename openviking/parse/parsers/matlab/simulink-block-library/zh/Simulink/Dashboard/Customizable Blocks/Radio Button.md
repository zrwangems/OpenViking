# Radio Button

## 端口

R2025b 中未记录。

## 参数

使用属性检查器和模块参数对话框来指定模块参数的值。要设置仪表板模块的核心参数，请使用模块参数对话框或属性检查器中的**参数**选项卡。要自定义模块，请使用属性检查器中的**设计**选项卡。要打开模块的模块参数对话框，请双击该模块。要打开属性检查器，请在**建模**选项卡上的**设计**下，选择**属性检查器**。

### 参数

要设置仪表板模块的核心参数，请打开属性检查器并点击**参数**选项卡。

#### 连接

### **Connection** — 用于连接参数值的模块参数值 连接选项

仪表板模块不使用端口连接到模型元素。要将仪表板模块连接到模型中的参数值，请使用连接模式、Simulink 工具条或模块参数对话框中的**连接**表。要从属性检查器打开模块参数对话框，请在**连接到**右侧，点击**连接**或**更改**。您可以连接到具有标量值的参数，或连接到矩阵的元素。有关连接模式以及如何使用工具条进行连接的信息，请参阅 Connect Dashboard Blocks to Simulink Model。

要使用**连接**表将控制模块连接到具有标量值的参数，或更改控制模块与具有标量值的参数的连接：

1. 选择该模块。
2. 要连接该模块，请在属性检查器的**参数**选项卡上，点击**连接**。要更改该模块的连接，请改为点击**更改**。
3. 选择要连接其参数值的模块。
4. 在表中，选择要连接到的参数。
5. 点击**应用**。

在您更新模型图之前，控制模块无法连接到由变量定义的参数。要连接到由变量定义的参数，或在仿真未运行时修改定义已连接参数值的变量的值，请按 **Ctrl+D** 更新模型图。

您还可以将仪表板模块连接到 Stateflow 图。有关详细信息，请参阅 Connect Dashboard Blocks to Stateflow (Stateflow)。

#### 编程用法

要以编程方式将仪表板模块连接到可调参数，请使用 `Simulink.HMI.ParamSourceInfo` 对象。`Simulink.HMI.ParamSourceInfo` 对象包含四个属性。某些属性适用于将仪表板模块连接到由值定义的参数，某些属性适用于将仪表板模块连接到由变量定义的参数。并非所有字段都有连接值，因为给定的仪表板模块要么连接到由值定义的参数，要么连接到由变量定义的参数。

|  |
| --- |
| **模块参数：** `Binding` |
| **类型：** `Simulink.HMI.ParamSourceInfo` |
| **默认值：** `[]` |

#### 主要

### **Label** — 显示所连接元素名称的标签位置 `Hide`（默认）| `Bottom` | `Top`

您可以在位于模块顶部或底部的标签中显示仪表板模块所连接元素的名称，也可以隐藏该标签。如果您希望标签可见，请指定标签的位置。如果您不希望标签可见，请选择 `Hide`。

**注意**

当仪表板模块未连接到元素时，标签为空白。

#### 编程用法

|  |
| --- |
| **模块参数：** `LabelPosition` |
| **类型：** 字符向量 |
| **值：** `'Hide'` | `'Bottom'` | `'Top'` |
| **默认值：** `'Hide'` |

### **Lock Aspect Ratio** — 用于保持模块宽高比的选项 `on`（默认）| `off`

选择此参数可在 Simulink 画布中调整模块大小时保持宽高比。

当宽高比锁定时，添加新的背景图像会将模块的宽高比更改为与背景图像的宽高比匹配。当宽高比未锁定时，添加新的背景图像不会更改模块的宽高比，而是更改背景图像的宽高比以适合模块的大小。

当宽高比锁定时，在调整模块大小时按 **Shift** 键会临时解锁宽高比。当您释放 **Shift** 键时，宽高比锁定。当宽高比未锁定时，在调整模块大小时按 **Shift** 键会临时锁定宽高比。当您释放 **Shift** 键时，宽高比解锁。

### **Enumerated Data Type** — 用于使用枚举数据类型指定状态值和标签的选项 `off`（默认）| `on`

要配置模块的状态标签和值，您可以使用将每个枚举与数值配对的枚举数据类型。首先，选择**枚举数据类型**。然后，在文本框中指定枚举数据类型的名称。指定的枚举数据类型的定义必须保存在 MATLAB 路径上或基础工作区中。

**注意**

您可以使用 `Simulink.defineIntEnumType` 函数定义枚举数据类型。例如，要为从一到五的一组罗马数字定义枚举数据类型 `myEnumType`，请使用此命令。

```
Simulink.defineIntEnumType('myEnumType',...
    {'I','II','III','IV','V'}, [1 2 3 4 5]);
```

然后，在属性检查器的**参数**选项卡上，在**枚举数据类型**文本框中，输入 `myEnumType`。

### **States** — 状态的管理和配置 标量和字符向量

每个单选按钮选项对应于 Radio Button 模块的一个状态。该状态具有标签和值。**状态标签**值是模块上标识该选项的文本。当您选择某个选项时，Radio Button 模块进入关联状态，并将**状态值**值分配给所连接的参数。

默认情况下，该模块具有三个单选按钮选项和三个对应的状态。

| 状态值 | 状态标签 |
| --- | --- |
| `0` | `Label1` |
| `1` | `Label2` |
| `2` | `Label3` |

您可以设计具有任意数量状态（大于或等于 1）的 Radio Button 模块。要添加新状态，请点击 **+** 按钮。要删除状态，请点击**状态标签**列中的标签文本或**状态值**列中的值，然后点击 **-** 按钮。

**注意**

当**枚举数据类型**打开时，您无法添加或删除状态。您可以在属性检查器的**参数**选项卡中关闭此选项。

要配置状态的标签文本或值，请点击**状态标签**列中的标签文本或**状态值**列中的值，删除当前值，输入新值，然后按 **Enter**。

**提示**

您还可以在设计模式下配置状态的参数：

1. 选择 Radio Button 模块。
2. 进入设计模式。在属性检查器的**设计**选项卡上，点击**编辑**。
3. 在**设计**选项卡上，打开**状态**组件，展开**选择状态**部分，然后从下拉菜单中，选择要配置的状态。
4. 在**文本**和**值**文本框中配置所选状态的标签文本和值。

### 设计

要自定义仪表板模块，请打开属性检查器，点击**设计**选项卡，然后点击**编辑**。您在本节中对参数值所做的更改将应用于所有单选按钮选项。

#### Radio Button

### **Lock Aspect Ratio** — 用于保持模块宽高比的选项 `on`（默认）| `off`

选择此参数可在 Simulink 画布中调整模块大小时保持宽高比。

当宽高比锁定时，添加新的背景图像会将模块的宽高比更改为与背景图像的宽高比匹配。当宽高比未锁定时，添加新的背景图像不会更改模块的比例，而是拉伸或缩放背景图像以适合模块的大小。

### **Group Title** — 单选按钮选项列表上方的标题 字符串 | 字符数组

您可以在单选按钮选项列表周围显示边框，并在列表上方显示标题。要显示边框和默认标题，请选择**显示组**选项。要更改标题，请在**组标题**文本框中输入新标题。将标题指定为字符串或字符数组。

### **Border Thickness** — 单选按钮选项列表周围边框的粗细 标量

您可以在单选按钮选项列表周围显示边框，并在列表上方显示标题。要显示边框和标题，请选择**显示组**选项。在**边框粗细**文本框中，以像素为单位指定边框粗细。输入大于或等于零的标量。

### **Border Color** — 单选按钮选项列表周围边框及列表上方标题的颜色 `[r g b]` 向量

您可以在单选按钮选项列表周围显示边框，并在列表上方显示标题。要显示边框和标题，请选择**显示组**选项。要更改边框和标题的颜色，请展开**边框颜色**菜单。从标准颜色调色板中选择一种颜色，或指定自定义颜色。

### **Placement** — 单选按钮图标相对于标签的位置 `Left`（默认）| `Top` | `Right` | `Bottom`

指定单选按钮图标相对于标签的位置。

**注意**

更改单选按钮图标位置不会更改偏移量。

### **Offset** — 图标相对于标签的位置 标量

以字体高度的比例指定图标相对于标签的位置，表示为大于或等于零的标量。

### **Width** — 图标宽度 标量

以标签文本字体高度的比例指定图标宽度。

**示例：** `0.5`

### **Height** — 图标高度 标量

以标签文本字体高度的比例指定图标高度。

**示例：** `0.5`

### **Lock Aspect Ratio** — 用于保持图标宽高比的选项 `on`（默认）| `off`

打开此选项可在调整单选按钮图标大小时保持宽高比。

### R2025a：在仿真期间选择仪表模块并打开模块参数对话框

当 Dashboard 或 Customizable Blocks 库中的 Simulink 模块处于*活动*状态时，您可以与该模块所代表的小工具进行交互。例如，您可以按下按钮或拨动开关。当模块处于非活动状态时，您只能与模块本身进行交互。例如，您可以移动或调整模块大小。默认情况下，Dashboard 和 Customizable Blocks 库中的所有模块在仿真期间均处于活动状态。提升到仪表面板的模块在面板于其自身窗口中打开或停靠且未锁定时也处于活动状态。对于 Callback Button 模块，只要按下按钮所触发的至少一个回调具有非空值，该模块就始终处于活动状态。要与非活动模块所代表的小工具进行交互，您可以通过点击该模块来临时激活它。当您取消选择该模块时，模块将再次变为非活动状态。

点击活动的 Callback Button 模块或连接到参数或变量值的 Dashboard 或 Customizable Blocks 库中的活动模块，会同时选择该模块并与该模块所代表的小工具进行交互。例如，点击未选中的活动已连接 Push Button 模块会同时选择该模块并按下按钮。从 R2025a 开始，您可以通过按住 **Shift** 然后点击模块来选择模块而不与小工具进行交互。类似地，您可以通过按住 **Shift** 然后双击模块来打开模块参数对话框。

## 描述

在仿真期间使用可自定义外观的单选按钮更改参数或变量值

使用 Radio Button 模块在仿真之前或仿真期间更改所连接参数或变量的值。当您在 Customizable Blocks 库中使用 Radio Button 模块时，您可以自定义模块的外观，例如，使模块看起来像您正在设计的数字用户界面中的单选按钮。将 Radio Button 模块与其他仪表模块一起使用，为您的模型构建交互式控件和指示器仪表板。

每个单选按钮选项对应 Radio Button 模块的一个状态。该状态具有一个标签和一个值。状态标签是模块上标识该选项的文本。当您选择一个选项时，Radio Button 模块进入关联状态，并将状态值赋给所连接的参数。要在仿真期间选择 Radio Button 模块上的选项，请点击您要选择的选项的单选按钮图标或标签文本。要在仿真未运行时选择选项，请点击 Radio Button 模块以选择该模块，然后点击选项图标或文本。

要自定义状态标签或值，请打开属性检查器的 **Parameters** 选项卡或模块参数对话框。

**注意**

- 在仿真期间双击已连接的 Radio Button 模块，或在点击该模块之后双击，不会打开模块参数对话框。要打开模块参数对话框，请按住 **Shift**，然后双击该模块。
- 在仿真期间点击已连接的 Radio Button 模块会同时选择该模块并选择一个单选按钮选项。要选择模块而不选择选项，请按住 **Shift**，然后点击该模块。

### 自定义 Radio Button 模块

当您将 Radio Button 模块添加到模型中时，该模块已预配置为默认设计。您可以使用默认设计使用该模块，也可以自定义模块的外观。

要自定义模块的外观，请使用设计模式。选择模块后，您可以通过以下三种方式之一进入设计模式：

- 在 Simulink® 工具条的模块特定选项卡上，在 **Design** 下，点击 **Edit**。
- 在属性检查器的 **Design** 选项卡上，点击 **Edit**。
- 暂停在模块上出现的省略号上，然后点击 Edit Custom Block 按钮 。

在设计模式下，您可以使用模块上方的工具栏来自定义单选按钮。要访问其他自定义选项或输入设计设置的精确值，请使用属性检查器中的 **Design** 选项卡。

处于设计模式的可自定义 Radio Button 模块，工具栏和属性检查器中的 Design 选项卡可见。

**设计模式操作**

| 操作 | 工具栏中可用 | **Design** 选项卡中可用 |
| --- | --- | --- |
| 更改每个选项赋给所连接参数的值。 | 否 | 是 |

### 连接仪表模块

仪表模块不使用端口连接到模型元素。要连接仪表模块，请使用连接模式。要在未连接的模块上进入连接模式，请暂停在要连接的模块上，然后点击 Connect 按钮 。要在已连接的模块上进入连接模式，请选择该模块，暂停在出现的省略号 (…) 上，然后在展开的操作菜单中点击 Connect 按钮。

要将控制模块连接到模型中的参数或更改控制模块的连接，请进入连接模式。选择要将其参数连接到的模块。在出现的列表中，选择要连接到的参数。然后，暂停在仪表模块上，并点击 Done Connecting 按钮 。

在更新模型图之前，控制模块无法连接到由变量定义的参数。要在仿真未运行时连接到由变量定义的参数或修改定义所连接参数值的变量值，请按 **Ctrl+D** 更新模型图。

您可以连接到具有标量值的参数，也可以连接到矩阵或结构的元素。有关详细信息，请参阅 Connect Dashboard Blocks to Simulink Model。

您还可以将仪表模块连接到 Stateflow® 图。有关详细信息，请参阅 Connect Dashboard Blocks to Stateflow (Stateflow)。

### 参数记录

连接到仪表模块的可调参数会记录到仿真数据检查器中，您可以在其中查看参数值以及记录的信号数据。您可以通过使用 UI 或 `Simulink.sdi.exportRun` 函数从仿真数据检查器导出参数数据，从而在 MATLAB® 工作区中访问记录的参数数据。有关使用仿真数据检查器 UI 导出数据的详细信息，请参阅 Export Data to Workspace or File。参数数据存储在 `Simulink.SimulationData.Parameter` 对象中，可作为导出的 `Simulink.SimulationData.Dataset` 中的元素进行访问。
