# Radio Button

## 端口

在 R2025b 中未记录。

## 参数

使用属性检查器和模块参数对话框指定模块参数的值。要设置仪表板模块的核心参数，请使用模块参数对话框或属性检查器中的**参数**选项卡。要自定义模块，请使用属性检查器中的**设计**选项卡。要为某个模块打开模块参数对话框，请双击该模块。要打开属性检查器，请在**建模**选项卡上的**设计**下，选择**属性检查器**。

### 参数

要设置仪表板模块的核心参数，请打开属性检查器并点击**参数**选项卡。

#### 连接

### **连接** — 用于将模块参数值连接到参数值的连接选项

仪表板模块不使用端口连接到模型元素。要将仪表板模块连接到模型中的参数值，请使用连接模式、Simulink 工具条或模块参数对话框中的**连接**表。要从属性检查器打开模块参数对话框，请在**连接到**右侧，点击**连接**或**更改**。您可以连接到具有标量值的参数，或连接到矩阵的元素。有关连接模式以及如何使用工具条进行连接的信息，请参阅将仪表板模块连接到 Simulink 模型。

要使用**连接**表将控制模块连接到具有标量值的参数，或更改控制模块到具有标量值的参数的连接：

1. 选择该模块。
2. 要连接该模块，请在属性检查器中的**参数**选项卡上，点击**连接**。要更改该模块的连接，请改为点击**更改**。
3. 选择要将其参数值连接到的模块。
4. 在表中，选择要连接到的参数。
5. 点击**应用**。

在更新模型图之前，控制模块无法连接到由变量定义的参数。要连接到由变量定义的参数，或在仿真未运行时修改定义所连接参数值的变量的值，请按 **Ctrl+D** 更新模型图。

您还可以将仪表板模块连接到 Stateflow 图。有关详细信息，请参阅将仪表板模块连接到 Stateflow (Stateflow)。

#### 编程使用

要以编程方式将仪表板模块连接到可调参数，请使用 `Simulink.HMI.ParamSourceInfo` 对象。`Simulink.HMI.ParamSourceInfo` 对象包含四个属性。某些属性适用于将仪表板模块连接到由值定义的参数，某些属性适用于将仪表板模块连接到由变量定义的参数。并非所有字段都有连接值，因为给定的仪表板模块要么连接到由值定义的参数，要么连接到由变量定义的参数。

|  |
| --- |
| **模块参数：** `Binding` |
| **类型：** `Simulink.HMI.ParamSourceInfo` |
| **默认值：** `[]` |

#### 主要

### **标签** — 显示所连接元素名称的标签位置 `Hide` (默认) | `Bottom` | `Top`

您可以在位于模块顶部或底部的标签中显示仪表板模块所连接元素的名称，也可以隐藏该标签。如果您希望标签可见，请指定标签的位置。如果您不希望标签可见，请选择 `Hide`。

**注意**

当仪表板模块未连接到元素时，标签为空白。

#### 编程使用

|  |
| --- |
| **模块参数：** `LabelPosition` |
| **类型：** character vector |
| **值：** `'Hide'` | `'Bottom'` | `'Top'` |
| **默认值：** `'Hide'` |

### **锁定纵横比** — 用于保持模块纵横比的选项 `on` (默认) | `off`

在 Simulink 画布中调整模块大小时，选择此参数以保持纵横比。

当纵横比锁定时，添加新的背景图像会更改模块的纵横比，使其与背景图像的纵横比匹配。当纵横比解锁时，添加新的背景图像不会更改模块的纵横比，而是更改背景图像的纵横比以适合模块的大小。

当纵横比锁定时，在调整模块大小时按下 **Shift** 键会临时解锁纵横比。当您释放 **Shift** 键时，纵横比会锁定。当纵横比解锁时，在调整模块大小时按下 **Shift** 键会临时锁定纵横比。当您释放 **Shift** 键时，纵横比会解锁。

### **Enumerated Data Type** — 用于使用 enumerated data type 指定状态值和标签的选项 `off` (默认) | `on`

要为模块配置状态标签和值，您可以使用将每个枚举与数值配对的 enumerated data type。首先，选择 **Enumerated Data Type**。然后，在文本框中指定 enumerated data type 的名称。指定的 enumerated data type 的定义必须保存在 MATLAB 路径上或基础工作区中。

**注意**

您可以使用 `Simulink.defineIntEnumType` 函数定义 enumerated data type。例如，要为从一到五的一组罗马数字定义 enumerated data type `myEnumType`，请使用以下命令。

```
Simulink.defineIntEnumType('myEnumType',...
    {'I','II','III','IV','V'}, [1 2 3 4 5]);
```

然后，在属性检查器中的**参数**选项卡上，在 **Enumerated Data Type** 文本框中，输入 `myEnumType`。

### **状态** — 状态的管理和配置 scalar 和 character vector

每个单选按钮选项对应于 Radio Button 模块的一个状态。状态具有标签和值。**状态标签**值是模块上标识该选项的文本。当您选择一个选项时，Radio Button 模块进入关联状态，并将**状态值**分配给所连接的参数。

默认情况下，模块具有三个单选按钮选项和三个对应状态。

| 状态值 | 状态标签 |
| --- | --- |
| `0` | `Label1` |
| `1` | `Label2` |
| `2` | `Label3` |

您可以将 Radio Button 模块设计为具有任意数量大于或等于 1 的状态。要添加新状态，请点击 **+** 按钮。要删除状态，请点击**状态标签**列中的标签文本或**状态值**列中的值，然后点击 **-** 按钮。

**注意**

当 **Enumerated Data Type** 打开时，您无法添加或删除状态。您可以在属性检查器的**参数**选项卡中关闭此选项。

要配置状态的标签文本或值，请点击**状态标签**列中的标签文本或**状态值**列中的值，删除当前值，输入新值，然后按 **Enter**。

**提示**

您也可以在设计模式下配置状态的参数：

1. 选择 Radio Button 模块。
2. 进入设计模式。在属性检查器中的**设计**选项卡上，点击**编辑**。
3. 在**设计**选项卡上，打开**状态**组件，展开**选择状态**部分，然后从下拉菜单中，选择要配置的状态。
4. 在**文本**和**值**文本框中配置所选状态的标签文本和值。

### 设计

要自定义仪表板模块，请打开属性检查器，点击**设计**选项卡，然后点击**编辑**。您在此部分对参数值所做的更改将应用于所有单选按钮选项。

#### Radio Button

### **锁定纵横比** — 用于保持模块纵横比的选项 `on` (默认) | `off`

在 Simulink 画布中调整模块大小时，选择此参数以保持纵横比。

当纵横比锁定时，添加新的背景图像会更改模块的纵横比，使其与背景图像的纵横比匹配。当纵横比解锁时，添加新的背景图像不会更改模块的比例，而是拉伸或缩放背景图像以适合模块的大小。

当纵横比锁定时，在调整模块大小时按下 **Shift** 键会解锁纵横比。当您释放 **Shift** 键时，纵横比会锁定。当纵横比解锁时，在调整模块大小时按下 **Shift** 键会锁定纵横比。当您释放 **Shift** 键时，纵横比会解锁。

### **显示组** — 用于在单选按钮选项列表周围显示边框的选项 `on` (默认) | `off`

选择此参数以在单选按钮选项列表周围显示边框，并在列表上方显示标题。要更改标题，请在**组标题**框中输入新标题。

### **组标题** — 单选按钮选项列表上方的标题 string | character array

您可以在单选按钮选项列表周围显示边框，并在列表上方显示标题。要显示边框和默认标题，请选择**显示组**选项。要更改标题，请在**组标题**文本框中输入新标题。将标题指定为 string 或 character array。

### **边框粗细** — 单选按钮选项列表周围边框的粗细 scalar

您可以在单选按钮选项列表周围显示边框，并在列表上方显示标题。要显示边框和标题，请选择**显示组**选项。在**边框粗细**文本框中，以 pixels 为单位指定边框粗细。输入大于或等于零的 scalar。

### **边框颜色** — 单选按钮选项列表周围边框以及列表上方标题的颜色 `[r g b]` vector

您可以在单选按钮选项列表周围显示边框，并在列表上方显示标题。要显示边框和标题，请选择**显示组**选项。要更改边框和标题的颜色，请展开**边框颜色**菜单。从标准颜色调色板中选择一种颜色，或指定自定义颜色。

### **放置** — 单选按钮图标相对于标签的放置 `Left` (默认) | `Top` | `Right` | `Bottom`

指定单选按钮图标相对于标签的放置。

**注意**

更改单选按钮图标放置不会更改偏移。

### **偏移** — 图标相对于标签的放置 scalar

以字体高度的比例指定图标相对于标签的放置，表示为大于或等于零的 scalar。

### **宽度** — 图标宽度 scalar

以标签文本字体高度的比例指定图标宽度。

**示例：** `0.5`

### **高度** — 图标高度 scalar

以标签文本字体高度的比例指定图标高度。

**示例：** `0.5`

### **锁定纵横比** — 用于保持图标纵横比的选项 `on` (默认) | `off`

打开此选项以在调整单选按钮图标大小时保持纵横比。

#### 前景图像

### **X 偏移** — 前景图像左边缘相对于模块左边缘的水平偏移 scalar

将图像左边缘相对于模块左边缘的水平偏移指定为模块宽度的比例。相对于偏移为 `0` 时的图像位置，负值偏移会将图像向左移动，正值偏移会将图像向右移动。

**示例：** `1`

### **Y 偏移** — 前景图像上边缘相对于模块上边缘的垂直偏移 scalar

将图像上边缘相对于模块上边缘的垂直偏移指定为模块高度的比例。相对于偏移为 `0` 时的图像位置，负值偏移会将图像向上移动，正值会将图像向下移动。

**示例：** `1`

### **宽度** — 前景图像宽度 scalar

将前景图像宽度指定为模块宽度的比例。

**示例：** `0.5`

### **高度** — 前景图像高度 scalar

将前景图像高度指定为模块高度的比例。

**示例：** `0.5`

当使用属性检查器调整图像大小时，选择此参数以保持纵横比。

## 版本历史

**Introduced in R2025a**

### R2025a: Select dashboard block and open Block Parameters dialog box during simulation

当 Dashboard 或 Customizable Blocks 库中的 Simulink 模块处于*活动*状态时，您可以与该模块表示的小工具交互。例如，您可以按下按钮或拨动开关。当模块处于非活动状态时，您只能与该模块交互。例如，您可以移动或调整该模块的大小。默认情况下，Dashboard 和 Customizable Blocks 库中的所有模块在仿真期间均处于活动状态。提升到 dashboard 面板的模块在该面板于其自己的窗口中打开，或停靠且未锁定时，也处于活动状态。对于通过按下按钮触发的回调中至少有一个具有非空值的 Callback Button 模块，这些模块始终处于活动状态。要与非活动模块表示的小工具交互，您可以通过点击该模块来临时激活模块。当您取消选择该模块时，该模块会再次变为非活动状态。

点击活动的 Callback Button 模块，或点击连接到参数或变量值的 Dashboard 或 Customizable Blocks 库中的活动模块，会同时选中该模块并与该模块表示的小工具交互。例如，点击未选中的活动且已连接的 Push Button 模块会同时选中该模块并按下按钮。从 R2025a 开始，您可以通过按 **Shift** 然后单击该模块来选中模块，而无需与小工具交互。类似地，您可以通过按 **Shift** 然后双击该模块来打开模块参数对话框。

## 描述

使用具有可自定义外观的单选按钮在仿真期间更改参数或变量值

使用 Radio Button 模块可在仿真之前或仿真期间更改所连接参数或变量的值。当您在 Customizable Blocks 库中使用 Radio Button 模块时，可以自定义该模块的外观，例如，使该模块看起来像您正在设计的数字用户界面中的单选按钮。将 Radio Button 模块与其他 Dashboard 模块一起使用，可为您的模型构建由控件和指示器组成的交互式仪表板。

每个单选按钮选项对应 Radio Button 模块的一个状态。该状态具有标签和值。状态标签是模块上标识该选项的文本。当您选择某个选项时，Radio Button 模块进入关联状态，并将状态值赋给所连接的参数。要在仿真期间选择 Radio Button 模块上的选项，请点击要选择的选项的单选按钮图标或标签文本。要在仿真未运行时选择选项，请点击 Radio Button 模块以选中该模块，然后点击选项图标或文本。

要自定义状态标签或值，请打开属性检查器的 **参数** 选项卡或模块参数对话框。

**注意**

- 在仿真期间双击已连接的 Radio Button 模块，或在点击该模块后双击，不会打开模块参数对话框。要打开模块参数对话框，请按 **Shift**，然后双击该模块。
- 在仿真期间点击已连接的 Radio Button 模块，会同时选中该模块并选择某个单选按钮选项。要在不选择选项的情况下选中模块，请按 **Shift**，然后单击该模块。

### 自定义 Radio Button 模块

当您将 Radio Button 模块添加到模型时，该模块会预配置默认设计。您可以按默认设计使用该模块，也可以自定义该模块的外观。

要自定义模块的外观，请使用设计模式。选中模块后，您可以通过以下三种方式之一进入设计模式：

- 在 Simulink® 工具条中的模块特定选项卡上，在 **设计** 下，点击 **编辑**。
- 在属性检查器中的 **设计** 选项卡上，点击 **编辑**。
- 将鼠标悬停在模块上方出现的省略号上，然后点击编辑自定义模块按钮。

在设计模式中，您可以使用模块上方的工具栏来自定义单选按钮。要访问其他自定义选项或为设计设置输入精确值，请使用属性检查器中的 **设计** 选项卡。

处于设计模式的 Customizable Radio Button 模块，工具栏和属性检查器中的设计选项卡可见。

**设计模式操作**

| 操作 | 在工具栏中可用 | 在 **设计** 选项卡中可用 |
| --- | --- | --- |

### 连接 Dashboard 模块

Dashboard 模块不使用端口连接到模型元素。要连接 Dashboard 模块，请使用连接模式。要在未连接的模块上进入连接模式，请将鼠标悬停在要连接的模块上，然后点击连接按钮。要在已连接的模块上进入连接模式，请选中该模块，将鼠标悬停在出现的省略号 (…) 上，然后在展开的操作菜单中点击连接按钮。

要将控制模块连接到模型中的参数，或更改控制模块的连接，请进入连接模式。选择要连接到其参数的模块。从出现的列表中，选择要连接到的参数。然后，将鼠标悬停在 Dashboard 模块上，并点击完成连接按钮。

在更新模型图之前，控制模块无法连接到由变量定义的参数。要连接到由变量定义的参数，或在仿真未运行时修改定义所连接参数值的变量的值，请按 **Ctrl+D** 更新模型图。

您可以连接到具有标量值的参数，或连接到矩阵或结构体的元素。有关详细信息，请参阅将 Dashboard 模块连接到 Simulink 模型。

您还可以将 Dashboard 模块连接到 Stateflow® 图。有关详细信息，请参阅将 Dashboard 模块连接到 Stateflow (Stateflow)。

### 参数记录

连接到 Dashboard 模块的可调参数会记录到仿真数据检查器中，您可以在其中查看参数值以及记录的信号数据。您可以使用 UI 或 `Simulink.sdi.exportRun` 函数从仿真数据检查器导出参数数据，从而在 MATLAB® 工作区中访问记录的参数数据。有关使用仿真数据检查器 UI 导出数据的详细信息，请参阅将数据导出到工作区或文件。参数数据存储在 `Simulink.SimulationData.Parameter` 对象中，可作为导出的 `Simulink.SimulationData.Dataset` 中的元素进行访问。
