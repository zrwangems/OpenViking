## 参数

使用属性检查器和模块参数对话框指定模块参数的值。要设置 Dashboard 模块的核心参数，请使用模块参数对话框或属性检查器中的 **参数** 选项卡。要自定义模块，请使用属性检查器中的 **设计** 选项卡。要打开某个模块的模块参数对话框，请双击该模块。要打开属性检查器，请在 **建模** 选项卡的 **设计** 下，选择 **属性检查器**。

### 参数

要设置 Dashboard 模块的核心参数，请打开属性检查器，然后单击 **参数** 选项卡。

#### 连接

### **连接** — 用于连接参数值的模块参数值连接选项

Dashboard 模块不使用端口连接到模型元素。要将 Dashboard 模块连接到模型中的参数值，请使用连接模式、Simulink 工具条或模块参数对话框中的 **连接** 表。要从属性检查器打开模块参数对话框，请在 **连接到** 右侧单击 **连接** 或 **更改**。您可以连接到具有标量值的参数，也可以连接到矩阵的元素。有关连接模式以及如何使用工具条进行连接的信息，请参阅将 Dashboard 模块连接到 Simulink 模型。

要使用 **连接** 表将控制模块连接到具有标量值的参数，或更改控制模块与具有标量值的参数的连接，请执行以下操作：

1. 选择该模块。
2. 要连接该模块，请在属性检查器的 **参数** 选项卡上单击 **连接**。要更改该模块的连接，请改为单击 **更改**。
3. 选择要将其参数值连接到的模块。
4. 在表中，选择要连接到的参数。
5. 单击 **应用**。

在更新模型图之前，控制模块无法连接到由变量定义的参数。要连接到由变量定义的参数，或在仿真未运行时修改定义已连接参数值的变量值，请按 **Ctrl+D** 更新模型图。

您还可以将 Dashboard 模块连接到 Stateflow 图。有关详细信息，请参阅将 Dashboard 模块连接到 Stateflow (Stateflow)。

#### 主要

### **按钮类型** — 按钮对点击的响应 `Momentary`（默认）| `Latch`

指定模块如何响应点击。

- `Momentary` — 仅在按下时按钮改变状态。当您释放点击时，按钮返回到其默认状态。
- `Latch` — 单击时按钮锁存状态变化。按钮保持按下状态，直到您再次单击它。

当您将 **按钮类型** 配置为 `Momentary` 时，模块具有以下状态：

- `Default` — 模块未按下时的默认状态
- `Pressed` — 模块按下时的模块状态

当您将 **按钮类型** 配置为 `Latch` 时，模块具有以下状态：

- `Default` — 模块未按下时的默认状态。
- `Pressed` — 当您在模块处于 `Default` 状态时按下按钮的过渡状态。当您释放点击时，模块转换到 `Latched` 状态。
- `Latched` — 模块未按下时的锁存状态。
- `Latched and Pressed` — 当您在模块处于 `Latched` 状态时按下按钮的过渡状态。当您释放点击时，模块转换到 `Default` 状态。

### **锁定纵横比** — 用于保持模块纵横比的选项 `on`（默认）| `off`

选择此参数可在 Simulink 画布中调整模块大小时保持纵横比。

当纵横比锁定时，添加新背景图像会更改模块的纵横比，以匹配背景图像的纵横比。当纵横比未锁定时，添加新背景图像不会更改模块的纵横比，而是更改背景图像的纵横比以适合模块的大小。

当纵横比锁定时，在调整模块大小时按 **Shift** 键会暂时解锁纵横比。当您释放 **Shift** 键时，纵横比锁定。当纵横比未锁定时，在调整模块大小时按 **Shift** 键会暂时锁定纵横比。当您释放 **Shift** 键时，纵横比解锁。

### **PressFcn** — 响应按下而执行的 MATLAB 代码 MATLAB code

响应按钮按下而执行的 MATLAB 代码。

当按钮处于按下状态时，`PressFcn` 代码会在 **按下延迟** 时间过后执行一次，并以每个 **重复间隔** 周期性地执行。

要为 `PressFcn` 指定代码，请从下拉菜单中选择 `PressFcn`。在菜单下方的文本框中输入代码。

如何按下按钮以执行 `PressFcn` 代码取决于 **按钮类型**。

- 如果 **按钮类型** 为 `Momentary`，请按住点击，持续您想要按下按钮的时间。
- 如果 **按钮类型** 为 `Latch`，请单击以按下按钮，但不要按住点击。按钮保持按下状态，直到您再次单击它。

**注意**

每次您单击按钮时，即使是在按下按钮的过程中这样做，`ClickFcn` 代码也会在您释放点击时执行一次。

**示例：** `1`

### **宽度** — 前景图像宽度 标量

将前景图像的宽度指定为模块宽度的比率。

**示例：** `0.5`

### **高度** — 前景图像高度 标量

将前景图像的高度指定为模块高度的比率。

**示例：** `0.5`

### **锁定纵横比** — 用于保持前景图像纵横比的选项 `on`（默认）| `off`

选中此参数可在使用属性检查器调整图像大小时保持纵横比。

## 描述

使用具有可自定义外观的按钮更改参数或变量值

Push Button 模块更改所连接变量或参数的值，并响应点击（立即释放指针）或按压（延迟释放指针）执行 MATLAB® 代码。您可以为点击指定与按压不同的代码。当您按下按钮时，代码要么在您指定的时间跨度后执行，要么按您指定的时间间隔执行。当您在 Customizable Blocks 库中使用 Push Button 模块时，可以修改模块外观，使其看起来像真实系统中的按钮。将 Push Button 模块与其他 dashboard 模块一起使用，以创建交互式 dashboard 来控制您的模型。

要在仿真期间按下虚拟按钮，请点击 Push Button 模块。要在仿真未运行时按下虚拟按钮，请点击 Push Button 以选择该模块，然后再次点击 Push Button 模块以按下按钮。当您为点击按下指针时，按钮被按下。当您释放指针时，您释放按钮。

您可以使用 callback 函数指定希望按钮执行的操作：

- `PressFcn` 函数在按钮被按下时运行。您可以将按钮配置为在按钮被按下时仅运行一次 `PressFcn` 函数，也可以指定重复间隔。要仅运行该函数一次，请指定重复间隔为 `0`。
- `ClickFcn` 函数在您释放按钮时运行。

您可以通过将 **Button Type** 设置为 `Latched`，将按钮配置为在您释放指针时保持按下。当您选择 latched 按钮类型时：

- 要锁存按钮，请点击按钮。
- 要解除锁存按钮，请再次点击按钮。

`PressFcn` 函数在按钮被锁存时运行。`ClickFcn` 函数在您锁存按钮时运行一次，并在您解除锁存按钮时运行一次。

您可以使用状态来指定当您与按钮交互时 Push Button 模块的外观如何变化：

- 当您按下按钮时，模块处于 `Pressed` 状态。
- 当按钮被锁存且您未按下它时，模块处于 `Latched` 状态。
- 当按钮被锁存且您正在按下它时，模块处于 `Latched and Pressed` 状态。
- 当模块不处于这三种状态中的任何一种时，它处于 `Default` 状态。

一个状态将指针操作与以下项配对：

- 状态标签
- 状态图标
- 状态图像

`Pressed`、`Latched` 和 `Latched and Pressed` 状态还将指针操作与 Push Button 模块的 **On Value** 配对。当您从默认状态进入这些状态之一时，**On Value** 被分配给 Push Button 模块所连接的 Simulink® 组件，并保持分配状态，直到按钮返回到 `Default` 状态。如果您在完整时间步过去之前释放按钮，**On Value** 会在后续时间步的持续时间内分配给该组件。

**注意**

- 在仿真期间或点击模块后双击已连接的 Push Button 模块不会打开 Block Parameters 对话框。要打开 Block Parameters 对话框，请按 **Shift**，然后双击该模块。
- 在仿真期间点击已连接的 Push Button 模块会同时选择该模块并按下按钮。要在不按下按钮的情况下选择模块，请按 **Shift**，然后点击该模块。

### 自定义 Push Button 模块

当您将 Push Button 模块添加到模型时，该模块预先配置了默认设计。您可以使用默认设计的模块，或自定义该模块的外观。

要自定义模块的外观，请使用设计模式。选择模块后，您可以通过以下三种方式之一进入设计模式：

- 在 Simulink Toolstrip 中，在模块特定的选项卡上，在 **Design** 下，点击 **Edit**。
- 在 Property Inspector 中，在 **Design** 选项卡上，点击 **Edit**。
- 将指针悬停在模块上出现的省略号上，然后点击 Edit Custom Block 按钮 。

在设计模式下，您可以使用模块上方的工具栏来自定义 push button。要访问其他自定义选项或为设计设置输入精确值，请使用 Property Inspector 中的 **Design** 选项卡。

处于设计模式下的 Customizable Push Button 模块，工具栏和 Property Inspector 中的 Design 选项卡可见。

当您自定义 Push Button 模块时，您为每个状态配置模块外观。当您将 **Block Type** 配置为 `Momentary` 时，模块有两个状态。当您将 **Block Type** 配置为 `Latch` 时，模块有四个。要选择要自定义的状态，请使用工具栏中的下拉列表。或者，在 **Design** 选项卡上，选择 **States** 组件，然后从 **Select State** 列表中选择。

**用于自定义所选状态的设计模式操作**

| 操作 | 在工具栏中可用 | 在 **Design** 选项卡中可用 |
| --- | --- | --- |
| 为 `Pressed`、`Latched` 和 `Latched and Pressed` 状态指定 **On Value**。 | No | Yes |
| 指定状态标签文本。 | No | Yes |
| 指定状态标签文本的颜色和不透明度。 | Yes | Yes |
| 上传状态图像。 | Yes | Yes |
| 上传状态图标。 | Yes | Yes |
| 更改状态图像和状态图标的大小。 | No | Yes |
| 更改状态标签、状态图像和状态图标的位置。 | No | Yes |

除了使用工具栏和 **Design** 选项卡自定义模块设计之外，您还可以在画布中以交互方式调整组件大小和重新定位组件。要调整特定于某个状态的组件（例如状态图像）的大小，请在工具栏中选择该状态，然后调整组件大小或重新定位组件。

**应用于所有状态的设计模式操作**

| 操作 | 在工具栏中可用 | 在 **Design** 选项卡中可用 |
| --- | --- | --- |
| 上传背景图像。 | No | Yes |
| 设置纯色背景色。 | No | Yes |
| 上传前景图像。 | No | Yes |

完成设计编辑后，要退出设计模式，请点击画布右上角的 **X**。

### 连接 Dashboard 模块

Dashboard 模块不使用端口连接到模型元素。要连接 dashboard 模块，请使用连接模式。要在未连接的模块上进入连接模式，请将指针悬停在要连接的模块上，然后点击 Connect 按钮 。要在已连接的模块上进入连接模式，请选择该模块，将指针悬停在出现的省略号 (…) 上，然后在展开的操作菜单中点击 Connect 按钮。
