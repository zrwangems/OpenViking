## 参数

使用属性检查器和模块参数对话框来指定模块参数的值。要设置 Dashboard 模块的核心参数，请使用模块参数对话框或属性检查器中的**参数**选项卡。要自定义模块，请使用属性检查器中的**设计**选项卡。要打开模块的模块参数对话框，请双击该模块。要打开属性检查器，请在**建模**选项卡上的**设计**下，选择**属性检查器**。

### 参数

要设置 Dashboard 模块的核心参数，请打开属性检查器，然后单击**参数**选项卡。

#### 连接

### **连接** — 用于将模块参数值连接到参数值的连接选项

Dashboard 模块不使用端口连接到模型元素。要将 Dashboard 模块连接到模型中的参数值，请使用连接模式、Simulink 工具条或模块参数对话框中的**连接**表。要从属性检查器打开模块参数对话框，请在**连接到**右侧，单击**连接**或**更改**。您可以连接到具有 scalar 值的参数，或连接到 matrix 的元素。有关连接模式以及如何使用工具条进行连接的信息，请参阅将 Dashboard 模块连接到 Simulink 模型。

要使用**连接**表将控制模块连接到具有 scalar 值的参数，或更改控制模块与具有 scalar 值的参数的连接，请执行以下操作：

1. 选择该模块。
2. 要连接该模块，请在属性检查器的**参数**选项卡上，单击**连接**。
   要更改该模块的连接，请改为单击**更改**。
3. 选择要将其参数值连接到的模块。
4. 在表中，选择要连接到的参数。
5. 单击**应用**。

在更新模型图之前，控制模块无法连接到由变量定义的参数。要在仿真未运行时连接到由变量定义的参数，或修改定义已连接参数值的变量的值，请按 **Ctrl+D** 更新模型图。

您还可以将 Dashboard 模块连接到 Stateflow 图。有关详细信息，请参阅将 Dashboard 模块连接到 Stateflow (Stateflow)。

#### 编程用法

要以编程方式将 Dashboard 模块连接到可调参数，请使用 `Simulink.HMI.ParamSourceInfo` 对象。`Simulink.HMI.ParamSourceInfo` 对象包含四个属性。某些属性适用于将 Dashboard 模块连接到由值定义的参数，某些属性适用于将 Dashboard 模块连接到由变量定义的参数。并非所有字段都有用于连接的值，因为给定的 Dashboard 模块连接到由值定义的参数或由变量定义的参数。

### **锁定纵横比** — 用于保持模块纵横比的选项 `on`（默认） | `off`

选择此参数可在 Simulink 画布中调整模块大小时保持纵横比。

当纵横比锁定时，添加新的背景图像会更改模块的纵横比，使其与背景图像的纵横比匹配。当纵横比未锁定时，添加新的背景图像不会更改模块的纵横比，而是更改背景图像的纵横比以适合模块的大小。

当纵横比锁定时，在调整模块大小时按 **Shift** 键会临时解锁纵横比。释放 **Shift** 键后，纵横比会锁定。当纵横比未锁定时，在调整模块大小时按 **Shift** 键会临时锁定纵横比。释放 **Shift** 键后，纵横比会解锁。

## 版本历史

**在 R2021a 中引入**

### R2025a：在仿真期间选择仪表板模块并打开模块参数对话框

当来自 Dashboard 或 Customizable Blocks 库的 Simulink 模块处于*活动*状态时，你可以与该模块表示的控件交互。例如，你可以按下按钮或拨动开关。当模块处于非活动状态时，你只能与该模块交互。例如，你可以移动或调整模块大小。默认情况下，来自 Dashboard 和 Customizable Blocks 库的所有模块在仿真期间都处于活动状态。提升到仪表板面板的模块在面板在其自己的窗口中打开，或停靠且未锁定时也处于活动状态。对于 Callback Button 模块，如果通过按下按钮触发的回调中至少有一个具有非空值，则该模块始终处于活动状态。要与由非活动模块表示的控件交互，你可以通过点击该模块临时激活它。取消选择该模块后，该模块会再次变为非活动状态。

点击活动的 Callback Button 模块，或点击来自 Dashboard 或 Customizable Blocks 库且连接到参数或变量值的活动模块，既会选择该模块，也会与该模块表示的控件交互。例如，点击未选择的、活动的、已连接的 Push Button 模块既会选择该模块，也会按下按钮。从 R2025a 开始，你可以通过按 **Shift** 然后点击模块来选择该模块，而无需与控件交互。类似地，你可以通过按 **Shift** 然后双击模块来打开模块参数对话框。

### R2024b：使用键盘解锁仪表板模块纵横比

如果来自 Dashboard 库的模块的纵横比已锁定，你可以通过按 **Shift** 临时解锁纵横比。释放 **Shift** 键时，纵横比会锁定。

如果纵横比未锁定，按 **Shift** 会临时锁定纵横比。释放 **Shift** 键时，纵横比会解锁。

## 描述

使用具有可自定义外观的垂直滑块更改参数或变量值

在仿真期间，使用 Vertical Slider 模块调节变量或模块参数的值。你可以自定义 Vertical Slider 模块的外观，使其看起来像真实系统中的控件。你可以调整刻度范围和刻度值，以适合你要调节的值所需的范围。将 Vertical Slider 模块与其他仪表板模块一起使用，以创建交互式仪表板来控制你的模型。

要在仿真运行时调节值，请使用指针将手柄拖到要将连接的变量或模块参数设置为的刻度值。要在仿真未运行时调节值，请点击 Vertical Slider 模块以选择该模块，然后将手柄拖到要将连接的变量或模块参数设置为的刻度值。

**注意**

- 在仿真期间或点击该模块后双击已连接的 Vertical Slider 模块不会打开模块参数对话框。要打开模块参数对话框，请按 **Shift**，然后双击该模块。
- 在仿真期间点击已连接的 Vertical Slider 模块既会选择该模块，也会移动滑块手柄。要在不移动滑块手柄的情况下选择该模块，请按 **Shift**，然后点击该模块。

### 自定义 Vertical Slider 模块

将 Vertical Slider 模块添加到模型时，该模块已预配置默认设计。你可以使用默认设计的模块，也可以自定义该模块的外观。

要自定义模块的外观，请使用设计模式。选择模块后，可以通过以下三种方式之一进入设计模式：

- 在 Simulink® Toolstrip 中，在模块特定的选项卡上的 **Design** 下，点击 **Edit**。
- 在属性检查器中，在 **Design** 选项卡上，点击 **Edit**。
- 悬停在模块上出现的省略号上，然后点击 Edit Custom Block 按钮。

在设计模式下，可以使用模块上方的工具栏自定义圆形仪表。要访问其他自定义选项或为设计设置输入精确值，请使用属性检查器中的 **Design** 选项卡。

处于设计模式的 Vertical Slider 模块，工具栏和属性检查器中的 Design 选项卡可见。

**设计模式操作**

| 操作 | 在工具栏中可用 | 在 **Design** 选项卡中可用 |
| --- | --- | --- |
| 上传手柄图像。 | Yes | Yes |
| 上传背景图像。 | Yes | Yes |
| 设置纯色背景颜色。 | No | Yes |
| 上传前景图像。 | No | Yes |
| 指定值条增长所依据的原点的位置。 | No | Yes |
| 更改刻度线、刻度标签或值条的颜色和不透明度。 | Yes | Yes |
| 将刻度方向指定为从左到右或从右到左。 | No | Yes |
| 更改刻度和手柄的大小。 | No | Yes |
| 更改刻度和手柄的位置。 | No | Yes |

要使用工具栏更改刻度线、刻度标签或值条的颜色和不透明度，请在工具栏从左数第二部分中选择要更改颜色的组件。要更改颜色，请点击色轮。要更改不透明度，请移动滑块。

除了使用工具栏和 **Design** 选项卡自定义模块设计外，你还可以在画布中以交互方式调整组件大小并重新定位组件。

完成设计编辑后，要退出设计模式，请点击画布右上角的 **X**。

### 连接仪表板模块

仪表板模块不使用端口连接到模型元素。要连接仪表板模块，请使用连接模式。要在未连接的模块上进入连接模式，请悬停在要连接的模块上，然后点击 Connect 按钮。要在已连接的模块上进入连接模式，请选择该模块，悬停在出现的省略号 (…) 上，然后在展开的操作菜单中点击 Connect 按钮。

要将控制模块连接到模型中的参数或更改控制模块的连接，请进入连接模式。选择要连接到其参数的模块。从出现的列表中，选择要连接到的参数。然后，悬停在仪表板模块上，并点击 Done Connecting 按钮。

在更新模型图之前，控制模块无法连接到由变量定义的参数。要在仿真未运行时连接到由变量定义的参数，或修改定义已连接参数值的变量的值，请按 **Ctrl+D** 更新模型图。

你可以连接到具有标量值的参数，也可以连接到矩阵或结构体的元素。有关详细信息，请参阅 Connect Dashboard Blocks to Simulink Model。

你还可以将仪表板模块连接到 Stateflow® 图。有关详细信息，请参阅 Connect Dashboard Blocks to Stateflow (Stateflow)。

### 参数记录

连接到仪表板模块的可调参数会记录到仿真数据检查器，你可以在其中查看参数值以及记录的信号数据。你可以通过使用 UI 或 `Simulink.sdi.exportRun` 函数从仿真数据检查器导出参数数据，从而在 MATLAB® 工作区中访问记录的参数数据。有关使用仿真数据检查器 UI 导出数据的详细信息，请参阅 Export Data to Workspace or File。参数数据存储在 `Simulink.SimulationData.Parameter` 对象中，可作为导出的 `Simulink.SimulationData.Dataset` 中的元素访问。
