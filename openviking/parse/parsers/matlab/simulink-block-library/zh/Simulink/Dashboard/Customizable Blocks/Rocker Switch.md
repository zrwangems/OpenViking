# Rocker Switch

## 端口

R2025b 中未记录。

## 参数

使用属性检查器和模块参数对话框指定模块参数的值。要设置仪表板模块的核心参数，请使用模块参数对话框或属性检查器中的 **参数** 选项卡。要自定义模块，请使用属性检查器中的 **设计** 选项卡。要打开某个模块的模块参数对话框，请双击该模块。要打开属性检查器，请在 **建模** 选项卡上的 **设计** 下，选择 **属性检查器**。

### 参数

要设置仪表板模块的核心参数，请打开属性检查器，然后单击 **参数** 选项卡。

#### 连接

### **连接** — 用于连接参数值的连接选项

仪表板模块不使用端口连接到模型元素。要将仪表板模块连接到模型中的参数值，请使用连接模式、Simulink 工具条或模块参数对话框中的 **连接** 表。要从属性检查器打开模块参数对话框，请在 **连接到** 的右侧，单击 **连接** 或 **更改**。你可以连接到具有 scalar 值的参数，或连接到矩阵的元素。有关连接模式以及如何使用工具条进行连接的信息，请参阅将仪表板模块连接到 Simulink 模型。

要使用 **连接** 表将控制模块连接到具有 scalar 值的参数，或更改控制模块与具有 scalar 值的参数的连接：

1. 选择该模块。
2. 要连接该模块，请在属性检查器的
   **参数** 选项卡上，单击 **连接**。
   要更改该模块的连接，请改为单击 **更改**。
3. 选择要连接其参数值的模块。
4. 在表中，选择要连接到的参数。
5. 单击 **应用**。

在你更新模型图之前，控制模块无法连接到由变量定义的参数。要在仿真未运行时连接到由变量定义的参数，或修改定义所连接参数值的变量的值，请按 **Ctrl+D** 更新模型图。

你还可以将仪表板模块连接到 Stateflow 图。有关详细信息，请参阅将仪表板模块连接到 Stateflow (Stateflow)。

#### 编程用法

要以编程方式将仪表板模块连接到可调参数，请使用 `Simulink.HMI.ParamSourceInfo` 对象。`Simulink.HMI.ParamSourceInfo` 对象包含四个属性。有些属性适用于将仪表板模块连接到由值定义的参数，有些属性适用于将仪表板模块连接到由变量定义的参数。并非所有字段都有连接值，因为给定仪表板模块要么连接到由值定义的参数，要么连接到由变量定义的参数。

|  |
| --- |
| **模块参数：** `Binding` |
| **类型：** `Simulink.HMI.ParamSourceInfo` |
| **默认值：** `[]` |

#### 主要

### **标签** — 显示所连接元素名称的标签位置 `Hide` (默认) | `Bottom` | `Top`

你可以在位于模块顶部或底部的标签中显示仪表板模块所连接元素的名称，也可以隐藏标签。如果希望标签可见，请指定标签的位置。如果不希望标签可见，请选择 `Hide`。

**注意**

当仪表板模块未连接到元素时，标签为空白。

#### 编程用法

|  |
| --- |
| **模块参数：** `LabelPosition` |
| **类型：** character vector |
| **值：** `'Hide'` | `'Bottom'` | `'Top'` |
| **默认值：** `'Hide'` |

### **锁定宽高比** — 用于保持模块宽高比的选项 `on` (默认) | `off`

选择此参数可在 Simulink 画布中调整模块大小时保持宽高比。

当宽高比锁定时，添加新的背景图像会将模块的宽高比更改为与背景图像的宽高比匹配。当宽高比未锁定时，添加新的背景图像不会更改模块的宽高比，而是更改背景图像的宽高比以适合模块的大小。

当宽高比锁定时，在调整模块大小时按 **Shift** 键会临时解锁宽高比。当你释放 **Shift** 键时，宽高比会锁定。当宽高比未锁定时，在调整模块大小时按 **Shift** 键会临时锁定宽高比。当你释放 **Shift** 键时，宽高比会解锁。

### **状态** — 值与标签的配对 scalar and character vector

每个状态将 **状态值** 与 **状态标签** 配对。当模块处于给定状态时，它会将该状态的 **状态值** 赋给所连接的变量或参数。你可以使用 **状态标签** 在模块上显示赋给所连接变量或参数的值，或提供描述性文本标签。

默认情况下，开关有两个状态，分别对应每个开关位置：

- 在 `Off` 状态下，模块将所连接的变量或参数赋值为 `0`。
- 在 `On` 状态下，模块将所连接的变量或参数赋值为 `1`。

你可以使用可自定义的开关模块设计具有大于或等于 1 的任意数量状态的开关。要添加新状态，请单击 **+** 按钮。要删除当前状态，请单击 **-** 按钮。

**提示**

在设计模式下，除了值和标签之外，你还可以为状态配置各种其他参数。例如，你可以选择当开关处于该状态时显示在开关上的图像。要在设计模式下配置参数：

1. 选择开关模块。
2. 进入设计模式。在属性检查器的
   **设计** 选项卡上，单击 **编辑**
   按钮。
3. 在 **设计** 选项卡上，打开
   **状态** 组件，展开 **选择
   状态** 部分，然后从下拉菜单中选择要
   配置的状态。
4. 使用模块上方的工具栏，或在属性检查器中
   **设计** 选项卡上的 **状态** 组件中，
   为所选状态配置参数值。

#### 编程用法

要以编程方式配置模块的 **状态**，请将 `States` 参数的值指定为包含两个元素的结构体数组，这些元素具有以下字段：

- `Value` — 状态的 Scalar double value。
- `Label` — 用作开关位置标签的 String or character array。

```
leftState.Value = 0;
leftState.Label = 'Off';
rightState.Value = 1;
rightState.Label = 'On';
switchStates = [leftState rightState];
```

| **模块参数：** `States` |
| **类型：** two element array of structures |

#### 开关

### **锁定宽高比** — 用于保持模块宽高比的选项 `on` (默认) | `off`

选择此参数可在 Simulink 画布中调整模块大小时保持宽高比。

当宽高比锁定时，添加新的背景图像会将模块的宽高比更改为与背景图像的宽高比匹配。当宽高比未锁定时，添加新的背景图像不会更改模块的比例，而是拉伸或缩放背景图像以适合模块的大小。

当宽高比锁定时，在调整模块大小时按 **Shift** 键会解锁宽高比。当你释放 **Shift** 键时，宽高比会锁定。当宽高比未锁定时，在调整模块大小时按 **Shift** 键会锁定宽高比。当你释放 **Shift** 键时，宽高比会解锁。

#### 状态

### **选择状态** — 状态的管理与配置 scalar and character vector

每个状态将 **状态值** 与 **状态标签** 配对。当模块处于给定状态时，它会将该状态的 **状态值** 赋给所连接的变量或参数。你可以使用 **状态标签** 在模块上显示赋给所连接变量或参数的值，或提供描述性文本标签。

默认情况下，开关有两个状态，分别对应每个开关位置：

- 在 `Off` 状态下，模块将所连接的变量或参数赋值为 `0`。
- 在 `On` 状态下，模块将所连接的变量或参数赋值为 `1`。

你可以使用可自定义的开关模块设计具有大于或等于 1 的任意数量状态的开关。要添加新状态，请单击 **+** 按钮。要删除当前状态，请单击 **X** 按钮。

要配置状态，请在 **状态** 组件中展开 **选择状态** 部分并选择该状态。

你可以在属性检查器中 **设计** 选项卡上的 **状态** 组件中，为所选状态配置值、标签文本以及各种其他参数。例如，你可以选择当开关处于该状态时显示在开关上的图像。

你在 **状态** 组件中对参数值所做的所有更改仅应用于所选状态。要配置其他状态，请在 **选择状态** 部分的下拉菜单中选择该状态。然后，在 **状态** 组件中配置该状态的参数值。

### **标签 X 偏移量** — 文本中心相对于模块左边缘的水平偏移量 `scalar`

将 **状态标签** 中心相对于模块左边缘的水平偏移量指定为模块宽度的比例。相对于偏移量为 `0` 时的文本位置，负值偏移量将文本向左移动，正值偏移量将文本向右移动。

## 版本历史

**在 R2021b 中引入**

### R2025a：在仿真期间选择仪表板模块并打开模块参数对话框

当 Dashboard 或 Customizable Blocks 库中的 Simulink 模块处于*活动*状态时，您可以与模块所代表的小工具交互。例如，您可以按下按钮或翻转开关。当模块处于非活动状态时，您只能与模块交互。例如，您可以移动或调整模块大小。默认情况下，Dashboard 和 Customizable Blocks 库中的所有模块在仿真期间均处于活动状态。提升到仪表板面板的模块，当面板在其自己的窗口中打开或已停靠且未锁定时，也处于活动状态。对于 Callback Button 模块，如果通过按下按钮触发的回调中至少有一个具有非空值，则该模块始终处于活动状态。要与非活动模块所代表的小工具交互，您可以通过点击模块临时激活它。取消选择该模块后，模块会再次变为非活动状态。

点击活动的 Callback Button 模块，或点击 Dashboard 或 Customizable Blocks 库中已连接到参数或变量值的活动模块，会同时选择该模块并与该模块所代表的小工具交互。例如，点击未选中的活动且已连接的 Push Button 模块，会同时选择该模块并按下按钮。从 R2025a 开始，您可以通过按 **Shift** 然后单击该模块来选择模块而不与小工具交互。类似地，您可以通过按 **Shift** 然后双击该模块来打开模块参数对话框。

### R2024b：使用键盘解锁仪表板模块宽高比

如果 Dashboard 库中模块的宽高比已锁定，您可以通过按 **Shift** 临时解锁宽高比。释放 **Shift** 键后，宽高比会锁定。

如果宽高比未锁定，按 **Shift** 会临时锁定宽高比。释放 **Shift** 键后，宽高比会解锁。

### R2024a：将仪表板面板部署为 Web 应用或独立桌面应用

拥有 Simulink Compiler™ 许可证后，您现在可以将仪表板面板与其所连接的模型一起打包，并部署为独立桌面应用或 Web 应用。您可以使用该应用独立于 Simulink 操作控件并监视面板上的显示内容。

要了解如何部署面板，请参阅 Deploy Dashboard Panel as App。

### R2024a：停靠仪表板面板

从 R2024a 开始，您可以将仪表板面板停靠到 Simulink Editor 窗口。您可以使用停靠的面板在仿真期间监视信号并控制参数，而不会遮盖画布中的模型图。

有关详细信息，请参阅 Dock Panels。

### R2023b：在新窗口中打开面板

从 R2023b 开始，您可以在新窗口中打开仪表板面板。为此，选择该面板并悬停在出现的省略号上。在展开的操作菜单中，点击 Open In New Window 。

您可以独立于模型窗口最小化和还原包含面板的新窗口。在面板窗口中，您可以运行、暂停、停止和单步执行仿真。在面板窗口中，您可以编辑面板及其包含的模块。

要将面板返回到模型画布，请在面板窗口工具条中点击 Open in canvas 。

## 描述

使用具有可自定义外观的开关更改参数或变量值

使用 Rocker Switch 模块在仿真前或仿真期间更改所连接的变量或参数的值。当您在 Customizable Blocks 库中使用 Rocker Switch 模块时，可以自定义模块的外观，使其看起来像系统中的真实开关。您可以将开关配置为具有任意数量的状态，以自定义行为。例如，您可以设计三向拨动开关或变速箱。将 Rocker Switch 模块与其他仪表板模块一起使用，为您的模型创建交互式仪表板。

真实的翘板开关具有多个设置。Rocker Switch 模块将这些设置视为不同的状态。一个状态将状态值与图像、点击区域以及显示在点击区域上的状态标签配对。

要在仿真期间激活某个状态，请点击该状态的点击区域。要在仿真未运行时激活某个状态，请点击 Rocker Switch 模块以选择该模块，然后点击该状态的点击区域。激活该状态后，状态值会赋给 Rocker Switch 模块所连接的 Simulink® 模块图元素。

**注意**

- 在仿真期间或点击已连接的 Rocker Switch 模块之后，双击该模块不会打开模块参数对话框。要打开模块参数对话框，请按 **Shift**，然后双击该模块。
- 在仿真期间点击已连接的 Rocker Switch 模块会同时选择该模块并移动开关。要选择模块而不移动开关，请按 **Shift**，然后点击该模块。

### 自定义 Rocker Switch 模块

将 Rocker Switch 模块添加到模型时，该模块会预配置为默认设计。您可以使用默认设计的模块，也可以自定义模块的外观。

要自定义模块外观，请使用设计模式。选择该模块后，您可以通过以下三种方式之一进入设计模式：

- 在 Simulink 工具条中，在模块特定选项卡上的 **设计** 下，点击 **编辑**。
- 在属性检查器中，在 **设计** 选项卡上，点击 **编辑**。
- 悬停在模块上方出现的省略号上，然后点击“编辑自定义模块”按钮。

在设计模式中，您可以使用模块上方的工具栏自定义翘板开关。要访问其他自定义选项或为设计设置输入精确值，请使用属性检查器中的 **设计** 选项卡。

设计模式中的可自定义 Rocker Switch 模块，其中工具栏和属性检查器中的设计选项卡可见。

自定义 Rocker Switch 模块时，您会为每个状态配置模块外观。要选择要自定义的状态，请使用工具栏中的下拉列表。或者，在 **设计** 选项卡上，选择 **状态** 组件，然后从 **选择状态** 列表中选择。要添加状态，请在工具栏中点击“添加状态”按钮。要删除状态，请点击“删除状态”按钮。

**自定义所选状态的设计模式操作**

| 操作 | 可在工具栏中使用 | 可在 **设计** 选项卡中使用 |
| --- | --- | --- |
| 指定状态值。 | No | Yes |
| 指定状态标签文本和颜色。 | No | Yes |
| 添加或删除状态。 | Yes | Yes |
| 上传定义模块在该状态下外观的状态图像。 | Yes | Yes |
| 更改状态图像和点击区域的大小。 | No | Yes |
| 更改状态标签、状态图像和点击区域的位置。 | No | Yes |

除了使用工具栏和 **设计** 选项卡自定义模块设计之外，您还可以在画布中以交互方式调整组件大小并重新定位组件。要调整特定于某个状态的组件（例如状态图像）的大小，请在工具栏中选择该状态，然后调整组件大小或重新定位组件。

**适用于所有状态的设计模式操作**

| 操作 | 可在工具栏中使用 | 可在 **设计** 选项卡中使用 |
| --- | --- | --- |
| 上传背景图像。 | No | Yes |
| 设置纯色背景色。 | No | Yes |
| 上传前景图像。 | No | Yes |

完成设计编辑后，要退出设计模式，请点击画布右上角的 **X**。

### 连接仪表板模块

仪表板模块不使用端口连接到模型元素。要连接仪表板模块，请使用连接模式。要在未连接的模块上进入连接模式，请悬停在要连接的模块上，然后点击连接按钮。要在已连接的模块上进入连接模式，请选择该模块，悬停在出现的省略号 (…) 上，然后在展开的操作菜单中点击连接按钮。

要将控制模块连接到模型中的参数，或更改控制模块的连接，请进入连接模式。选择要将其参数连接到的模块。从出现的列表中，选择要连接到的参数。然后，悬停在仪表板模块上，并点击完成连接按钮。

在更新模型图之前，控制模块无法连接到由变量定义的参数。要在仿真未运行时连接到由变量定义的参数，或修改定义所连接参数值的变量值，请按 **Ctrl+D** 更新模型图。

您可以连接到具有标量值的参数，或连接到矩阵或结构体的元素。有关详细信息，请参阅 Connect Dashboard Blocks to Simulink Model。

您还可以将仪表板模块连接到 Stateflow® 图。有关详细信息，请参阅 Connect Dashboard Blocks to Stateflow (Stateflow)。

### 参数记录

连接到仪表板模块的可调参数会记录到仿真数据检查器中，您可以在其中查看参数值以及记录的信号数据。您可以使用 UI 或 `Simulink.sdi.exportRun` 函数从仿真数据检查器导出参数数据，从而在 MATLAB® 工作区中访问记录的参数数据。有关使用仿真数据检查器 UI 导出数据的详细信息，请参阅 Export Data to Workspace or File。参数数据存储在 `Simulink.SimulationData.Parameter` 对象中，可作为导出的 `Simulink.SimulationData.Dataset` 中的元素进行访问。
