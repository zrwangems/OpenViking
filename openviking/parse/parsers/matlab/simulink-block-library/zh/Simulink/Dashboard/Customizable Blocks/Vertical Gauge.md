# Vertical Gauge

## 参数

使用属性检查器和模块参数对话框指定模块参数的值。要设置仪表板模块的核心参数，请使用模块参数对话框或属性检查器中的 **参数** 选项卡。要自定义模块，请使用属性检查器中的 **设计** 选项卡。要打开模块的模块参数对话框，请双击该模块。要打开属性检查器，请在 **建模** 选项卡上的 **设计** 下，选择 **属性检查器**。

### 参数

要设置仪表板模块的核心参数，请打开属性检查器，然后单击 **参数** 选项卡。

#### 信号

### **连接** — 要连接的信号，并显示信号连接选项

仪表板模块不使用端口连接到模型元素。要将仪表板模块连接到模型中的参数值，请使用连接模式、Simulink 工具条或模块参数对话框中的 **连接** 表。有关连接模式以及如何使用工具条进行连接的信息，请参阅将仪表板模块连接到 Simulink 模型。

要使用 **连接** 表连接显示模块或更改显示模块的连接，请执行以下操作：

1. 选择该模块。
2. 要连接该模块，请在属性检查器的 **参数** 选项卡上单击 **连接**。要更改该模块的连接，请改为单击 **更改**。
3. 选择要连接的信号线。
4. 在表中，选择要连接的信号。
5. 单击 **应用**。

您还可以将仪表板模块连接到 Stateflow 图。有关详细信息，请参阅将仪表板模块连接到 Stateflow (Stateflow)。

### **锁定纵横比** — 保持模块纵横比的选项 `on` (默认) | `off`

选择此参数可在 Simulink 画布中调整模块大小时保持纵横比。

当纵横比锁定时，添加新背景图像会更改模块的纵横比以匹配背景图像的纵横比。当纵横比未锁定时，添加新背景图像不会更改模块的纵横比，而是更改背景图像的纵横比以适合模块的大小。

当纵横比锁定时，调整模块大小时按住 **Shift** 键会临时解锁纵横比。释放 **Shift** 键时，纵横比锁定。当纵横比未锁定时，调整模块大小时按住 **Shift** 键会临时锁定纵横比。释放 **Shift** 键时，纵横比解锁。

### **刻度颜色** — 用于刻度范围的仪表刻度颜色指示

刻度上值范围的颜色规格。单击 **+** 按钮添加刻度颜色。对于添加的每种颜色，指定您要显示该颜色的范围的最小值和最大值。

#### 编程用法

要以编程方式指定 `Scale Colors` 参数，请使用包含以下字段的结构体数组：

- `Min` — 刻度上颜色范围的最小值
- `Max` — 刻度上颜色范围的最大值
- `Color` — 由 `0` 到 `1` 之间的 `double` 值组成的 `1`-by-`3` vector，以 `[r g b]` 形式指定该范围的颜色

为要指定颜色的每个刻度范围在数组中包含一个结构体。

    range1.Min = 0;
    range1.Max = 10;
    range1.Color = [0 0 1];
    range2.Min = 10;
    range2.Max = 15;
    range2.Color = [0 1 0];
    scaleRanges = [range1 range2];

|  |
| --- |
| **模块参数:** `ScaleColors` |
| **类型:** structure array |
| **默认:** `0x1` struct array |

## 版本历史

**在 R2020a 中引入**

### R2024b：使用键盘解锁 Dashboard 模块纵横比

如果 Dashboard 库中某个模块的纵横比已锁定，您可以通过按 **Shift** 临时解锁纵横比。当您释放 **Shift** 键时，纵横比会锁定。

如果纵横比已解锁，按 **Shift** 会临时锁定纵横比。当您释放 **Shift** 键时，纵横比会解锁。

### R2024a：将 Dashboard 面板部署为 Web 应用或独立桌面应用

拥有 Simulink Compiler™ 许可证后，您现在可以将 Dashboard 面板（与面板所连接的模型一起打包）部署为独立桌面应用或 Web 应用。您可以使用该应用独立于 Simulink 操作面板上的控件并监控面板上的显示内容。

要了解如何部署面板，请参阅将 Dashboard 面板部署为应用。

### R2024a：停靠 Dashboard 面板

从 R2024a 开始，您可以将 Dashboard 面板停靠到 Simulink 编辑器窗口。您可以使用停靠的面板在仿真期间监控信号和控制参数，而不会覆盖画布中的模型图。

有关详细信息，请参阅停靠面板。

### R2023b：在新窗口中打开面板

从 R2023b 开始，您可以在新窗口中打开 Dashboard 面板。为此，请选择该面板并暂停在出现的省略号上。在展开的操作菜单中，点击在新窗口中打开。

### 自定义 Vertical Gauge 模块

当您将 Vertical Gauge 模块添加到模型时，该模块会预配置为默认设计。您可以使用默认设计的模块，也可以自定义模块的外观。

要自定义模块的外观，请使用设计模式。选择模块后，您可以通过以下三种方式之一进入设计模式：

- 在 Simulink® 工具条中，在模块特定的选项卡上，在 **设计** 下，点击 **编辑**。
- 在属性检查器中，在 **设计** 选项卡上，点击 **编辑**。
- 暂停在模块上方出现的省略号上，然后点击编辑自定义模块按钮。

在设计模式中，您可以使用模块上方的工具条自定义圆形仪表。要访问其他自定义选项或输入设计设置的精确值，请使用属性检查器中的 **设计** 选项卡。

### 连接 Dashboard 模块

Dashboard 模块不使用端口连接到模型元素。要连接 Dashboard 模块，请使用连接模式。要在未连接的模块上进入连接模式，请暂停在要连接的模块上，然后点击连接按钮。要在已连接的模块上进入连接模式，请选择该模块，暂停在出现的省略号 (…) 上，然后在展开的操作菜单中点击连接按钮。

要将显示模块连接到模型中的信号或更改显示模块的连接，请进入连接模式。选择要连接到的信号线。从出现的列表中，选择要连接到的信号。然后，暂停在 Dashboard 模块上，并点击完成连接按钮。要查看 Dashboard 模块显示所连接模块的值，请运行仿真。

有关连接 Dashboard 模块的详细信息，请参阅将 Dashboard 模块连接到 Simulink 模型。

您还可以将 Dashboard 模块连接到 Stateflow® 图。有关详细信息，请参阅将 Dashboard 模块连接到 Stateflow (Stateflow)。
