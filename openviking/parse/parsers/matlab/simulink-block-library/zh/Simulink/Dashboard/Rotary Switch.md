## 参数

### **Connection** — 将模块参数值连接到参数值的连接选项

仪表板模块不使用端口连接到模型元素。要将仪表板模块连接到模型中的参数值，请使用连接模式、Simulink® 工具条或“模块参数”对话框中的 **Connection** 表。要从属性检查器打开“模块参数”对话框，请在 **连接到** 右侧点击 **连接** 或 **更改**。您可以连接到具有标量值的参数，或连接到矩阵的元素。有关连接模式以及如何使用工具条连接的信息，请参阅将仪表板模块连接到 Simulink 模型。

要使用 **Connection** 表将控制模块连接到具有标量值的参数，或更改控制模块与具有标量值的参数的连接：

1. 选择该模块。
2. 要连接该模块，请在属性检查器的 **参数** 选项卡上点击 **连接**。
   要更改该模块的连接，请改为点击 **更改**。
3. 选择要将其参数值连接到的模块。
4. 在表中，选择要连接到的参数。
5. 点击 **应用**。

在更新模型图之前，控制模块无法连接到由变量定义的参数。要在仿真未运行时连接到由变量定义的参数，或修改定义已连接参数值的变量的值，请按 **Ctrl+D** 更新模型图。

您还可以将仪表板模块连接到 Stateflow 图。有关详细信息，请参阅将仪表板模块连接到 Stateflow (Stateflow)。

#### 编程用法

要以编程方式将仪表板模块连接到可调参数，请使用 `Simulink.HMI.ParamSourceInfo` 对象。`Simulink.HMI.ParamSourceInfo` 对象包含四个属性。某些属性适用于将仪表板模块连接到由值定义的参数，某些适用于将仪表板模块连接到由变量定义的参数。并非所有字段都有连接值，因为给定仪表板模块要么连接到由值定义的参数，要么连接到由变量定义的参数。

|  |
| --- |
| **模块参数：** `Binding` |
| **类型：** `Simulink.HMI.ParamSourceInfo` |
| **默认值：** `[]` |

### **States** — 位置标签和值，标量和字符向量

分配给所连接变量或参数并与模块标签成对的数值。一个状态由 **State Value** 和 **State Label** 组成。

- **State Value** — 当 Rotary Switch 模块位于对应 **State Label** 时，分配给所连接变量或参数的值。
- **State Label** — 开关位置的标签。您可以使用 **State Label** 显示当 Rotary Switch 模块指向 **State Label** 时所连接变量或参数采用的值，也可以使用描述性文本标签。

点击 **+** 按钮以添加 **States**。

该模块的默认配置包括以下 **States**：

| State Value | State Label |
| --- | --- |
| `0` | `Off` |
| `1` | `Low` |
| `2` | `Medium` |
| `3` | `High` |

#### 编程用法

要以编程方式配置该模块的 **States**，请将 `States` 参数的值指定为具有以下字段的结构体数组：

- `Value` — 该状态的标量 double 值。
- `Label` — 用作开关位置标签的字符串或字符数组。

对于要为该模块指定的每个状态，在数组中包含一个结构体元素。

    state1.Value = 1;
    state1.Label = 'State 1';
    state2.Value = 2;
    state2.Label = 'State 2';
    states = [state1 state2];

|  |
| --- |
| **模块参数：** `States` |
| **类型：** structure array |

### **Enumerated Data Type** — 使用枚举数据类型指定状态值和标签 `off` (默认) | `on`

您可以使用为每个枚举值配对数值的枚举数据类型来配置模块的状态值和标签。要使用枚举数据类型指定模块的状态，请先选择 **Enumerated Data Type** 选项。然后，在文本框中指定枚举数据类型的名称。指定枚举数据类型的定义必须保存在 MATLAB 路径上或基础工作区中。

**示例：** `myEnumType`

#### 编程用法

要使用枚举数据类型以编程方式指定模块的状态标签和值，请为 `UseEnumeratedDataType` 参数指定 `'on'`，并为 `EnumeratedDataType` 参数指定枚举数据类型的名称。

|  |
| --- |
| **模块参数：** `UseEnumeratedDataType` |
| **类型：** string or character array |
| **值：** `'on'` | `'off'` |
| **默认值：** `'off'` |

|  |
| --- |
| **模块参数：** `EnumeratedDataType` |
| **类型：** string or character array |
| **默认值：** `''` |

### **Label** — 模块标签位置 `Top` (默认) | `Bottom` | `Hide`

模块标签的位置。当模块连接到模型中的元素时，标签为所连接元素的名称。

#### 编程用法

|  |
| --- |

| **类型：** character vector |
| **值：** `'Top'` | `'Bottom'` | `'Hide'` |
| **默认值：** `'Top'` |

## 版本历史

**在 R2015a 中引入**

### R2023b: 在新窗口中打开面板

从 R2023b 开始，您可以在新窗口中打开仪表板面板。为此，请选择面板并暂停在出现的省略号上。在展开的操作菜单中，点击 **在新窗口中打开** 按钮。

您可以单独于模型窗口最小化和还原包含该面板的新窗口。从面板窗口，您可以运行、暂停、停止和逐步执行仿真。在面板窗口中，您可以编辑面板及其包含的模块。

要将面板返回到模型画布，请在面板窗口工具条中点击 **在画布中打开**。

有关在新窗口中打开面板的详细信息，请参阅在新窗口中打开面板。

### R2023a: Simulink 工具条中的持久面板选项卡

当您将仪表板面板添加到模型时，**面板** 选项卡会出现在 Simulink 工具条中，并显示用于管理和编辑面板的选项。

以前，**面板** 选项卡仅在选中面板时可见。从 R2023a 开始，未选中任何面板时，**面板** 选项卡仍保持可见。

**面板** 选项卡还包含以下新选项：

- 您可以添加空面板。
- 您可以重命名所选面板。
- 您可以隐藏所选面板。

### R2022b: 对面板中可自定义仪表板模块的撤销和重做支持

从 R2022b 开始，您可以撤销和重做对面板中可自定义仪表板模块所做的更改。

要撤销或重做更改：

1. 点击面板或面板中的模块。
2. 按 **Ctrl+Z** 撤销更改，或按 **Ctrl+Y** 重做更改。

**注意**

键盘快捷键基于 Windows®。在 Mac 上，按 **command** (⌘) 而不是 **Ctrl**。

### R2022b: 工具条对面板的支持

从 R2022b 开始，您可以使用 Simulink 工具条管理和编辑面板及其包含的仪表板模块。

当您点击面板中的仪表板模块时，该模块的工具条选项卡会出现。例如，当您点击 Circular Gauge 模块时，**仪表** 选项卡会出现在工具条中。

当您点击面板时，**面板** 选项卡会出现在工具条中。该选项卡提供以下选项：

- 管理模型中面板的可见性。
- 使所有未隐藏的面板适合当前视图。
- 折叠所选面板。
- 自定义面板的大小和内容。
- 为所选面板设置自定义背景图像。
- 向所选面板添加新选项卡。

### R2021a: 使用仪表板模块调整矩阵和结构体元素

从 R2021a 开始，您可以将 Dashboard 库中的模块连接到定义可调模块参数值的矩阵或结构体的标量元素。当您将仪表板模块连接到可调参数时，首先选择一个或多个模块。然后，在对话框中选择要连接到的参数。当您选择具有非标量值的参数时，请使用对话框中的文本框指定要调整的元素。

### R2020b: Simulink 工具条对仪表板模块的支持

从 R2020b 开始，当您在模型中选择来自 Simulink 库中的 Dashboard 库或来自 Aerospace Blockset™ Flight Control Analysis 库中的 Flight Instruments 库的模块时，Simulink 工具条中的 **模块** 选项卡会变为特定于该模块的选项卡。您可以从工具条连接、断开连接和修改所选模块的连接。您可以跳转到连接到所选模块的模型元素，并且可以将所选模块添加到面板。

### R2019b: 增强的 Rotary Switch 模块和 Combo Box 模块的枚举数据类型支持

从 R2019b 开始，您可以使用枚举类为 Rotary Switch 模块和 Combo Box 模块的状态配置值和标签。

要使用枚举数据类型配置 Rotary Switch 或 Combo Box 模块的 **States**，请选择 **Enumerated Data Type**。在文本框中，输入要使用的枚举类的名称。

当您使用枚举类配置模块的状态时，无法从 **States** 表中手动编辑、添加或删除状态。

### R2019a: 以编程方式添加和配置仪表板模块

从 R2019a 开始，您可以使用 `add_block` 和 `set_param` 等函数在模型中创建和配置 Dashboard 库中的模块。

## 描述

用于在刻度盘上设置值的开关参数

Rotary Switch 模块在仿真期间将所连接模块参数的值更改为多个指定值。例如，您可以将 Rotary Switch 模块连接到模型中输入信号的幅值或频率，并在仿真期间更改其特性。将 Rotary Switch 模块与其他 Dashboard 模块一起使用，以创建交互式仪表板来控制您的模型。

在仿真期间以及选中该模块时，双击 Rotary Switch 模块不会打开其对话框。要编辑模块的参数，您可以使用 **属性检查器**，或者右键点击该模块，然后从上下文菜单中选择 **模块参数**。

### 连接仪表板模块

仪表板模块不使用端口连接到模型元素。要连接仪表板模块，请使用连接模式。要在未连接的模块上进入连接模式，请暂停在要连接的模块上，然后点击“连接”按钮。要在已连接的模块上进入连接模式，请选择该模块，暂停在出现的省略号 (…) 上，然后在展开的操作菜单中点击“连接”按钮。

要将控制模块连接到模型中的参数，或更改控制模块的连接，请进入连接模式。选择要将其参数连接到的模块。在出现的列表中，选择要连接到的参数。然后，暂停在仪表板模块上，然后点击“完成连接”按钮。

在更新模型图之前，控制模块无法连接到由变量定义的参数。要在仿真未运行时连接到由变量定义的参数，或修改定义已连接参数值的变量的值，请按 **Ctrl+D** 更新模型图。

您可以连接到具有标量值的参数，或连接到矩阵或结构体的元素。有关详细信息，请参阅将仪表板模块连接到 Simulink 模型。

您还可以将仪表板模块连接到 Stateflow® 图。有关详细信息，请参阅将仪表板模块连接到 Stateflow (Stateflow)。

### 参数记录

连接到仪表板模块的可调参数会记录到仿真数据检查器中，您可以在其中查看参数值以及已记录的信号数据。您可以通过使用 UI 或 `Simulink.sdi.exportRun` 函数从仿真数据检查器导出参数数据，从而在 MATLAB® 工作区中访问已记录的参数数据。有关使用仿真数据检查器 UI 导出数据的详细信息，请参阅将数据导出到工作区或文件。参数数据存储在 `Simulink.SimulationData.Parameter` 对象中，可作为导出的 `Simulink.SimulationData.Dataset` 中的元素访问。
