# Check Box

## 端口

R2025b 中未记录。

## 参数

使用属性检查器和模块参数对话框指定模块参数的值。要设置仪表板模块的核心参数，请使用模块参数对话框或属性检查器中的**参数**选项卡。要自定义模块，请使用属性检查器中的**设计**选项卡。要打开模块的模块参数对话框，请双击该模块。要打开属性检查器，请在**建模**选项卡的**设计**下，选择**属性检查器**。

### 参数

要设置仪表板模块的核心参数，请打开属性检查器并点击**参数**选项卡。

#### 连接

### **Connection** — 要连接的模块参数值 参数值连接选项

仪表板模块不使用端口连接到模型元素。要将仪表板模块连接到模型中的参数值，请使用连接模式、Simulink 工具条或模块参数对话框中的**Connection**表。要从属性检查器打开模块参数对话框，请在**Connected to**右侧点击**Connect**或**Change**。您可以连接到具有标量值的参数，或连接到矩阵的元素。有关连接模式以及如何使用工具条进行连接的信息，请参阅 Connect Dashboard Blocks to Simulink Model。

要使用**Connection**表将控制模块连接到具有标量值的参数，或更改控制模块与具有标量值的参数的连接：

1. 选择该模块。
2. 要连接该模块，请在属性检查器的**参数**选项卡中点击**Connect**。要更改该模块的连接，请改为点击**Change**。
3. 选择要连接其参数值的模块。
4. 在表中，选择要连接到的参数。
5. 点击**Apply**。

在更新模型图之前，控制模块无法连接到由变量定义的参数。要连接到由变量定义的参数，或在仿真未运行时修改定义已连接参数值的变量的值，请按**Ctrl+D**更新模型图。

您还可以将仪表板模块连接到 Stateflow 图表。有关详细信息，请参阅 Connect Dashboard Blocks to Stateflow (Stateflow)。

#### 编程使用

要以编程方式将仪表板模块连接到可调参数，请使用 `Simulink.HMI.ParamSourceInfo` 对象。`Simulink.HMI.ParamSourceInfo` 对象包含四个属性。某些属性适用于将仪表板模块连接到由值定义的参数，某些属性适用于将仪表板模块连接到由变量定义的参数。并非所有字段都有连接值，因为给定的仪表板模块要么连接到由值定义的参数，要么连接到由变量定义的参数。

|  |
| --- |
| **模块参数**：`Binding` |
| **类型**：`Simulink.HMI.ParamSourceInfo` |
| **默认值**：`[]` |

### **Lock Aspect Ratio** — 保持模块宽高比的选项 `on`（默认）| `off`

选择此参数以在 Simulink 画布中调整模块大小时保持宽高比。

当宽高比锁定时，添加新背景图像会更改模块的宽高比以匹配背景图像的宽高比。当宽高比解锁时，添加新背景图像不会更改模块的宽高比，而是更改背景图像的宽高比以适应模块的大小。

当宽高比锁定时，在调整模块大小时按 **Shift** 键会临时解锁宽高比。释放 **Shift** 键时，宽高比锁定。当宽高比解锁时，在调整模块大小时按 **Shift** 键会临时锁定宽高比。释放 **Shift** 键时，宽高比解锁。

#### 复选框

### **Lock Aspect Ratio** — 保持模块宽高比的选项 `on`（默认）| `off`

选择此参数以在 Simulink 画布中调整模块大小时保持宽高比。

当宽高比锁定时，添加新背景图像会更改模块的宽高比以匹配背景图像的宽高比。当宽高比解锁时，添加新背景图像不会更改模块的比例，而是拉伸或缩放背景图像以适应模块的大小。

当宽高比锁定时，在调整模块大小时按 **Shift** 键会解锁宽高比。释放 **Shift** 键时，宽高比锁定。当宽高比解锁时，在调整模块大小时按 **Shift** 键会锁定宽高比。释放 **Shift** 键时，宽高比解锁。

### **Horizontal Alignment** — 标签和图标对与模块的水平对齐方式 `Left`（默认）| `Center` | `Right`

设置标签和图标对在水平方向上的对齐方式。下表列出了当 **X Offset** 为零时标签和图标对的水平位置。非零的 **X Offset** 会将标签和图标对从表中列出的位置移动。

| Alignment | 标签和图标对的位置 |
| --- | --- |
| `Left` | 标签和图标对的左边缘位于模块的左边缘。 |
| `Center` | 标签和图标对的水平中点位于模块的水平中点。 |
| `Right` | 标签和图标对的右边缘位于模块的右边缘。 |

### **Icon and Label X Offset** — 图标和标签对相对于模块的水平偏移 `0`（默认）| 标量

**X Offset** 的测量方式取决于 **Horizontal Alignment** 的值。下表列出了每个 **Horizontal Alignment** 值的偏移测量方式。相对于偏移为 `0` 时的位置，负值偏移将文本向左移动，正值偏移将文本向右移动。

| **Horizontal Alignment** | 偏移 |
| --- | --- |
| `Left` | 将标签和图标对左边缘相对于模块左边缘的水平偏移指定为模块宽度的比例。 |
| `Center` | 将标签和图标对水平中点相对于模块水平中点的水平偏移指定为模块宽度的比例。 |
| `Right` | 将标签和图标对右边缘相对于模块右边缘的水平偏移指定为模块宽度的比例。 |

### **Icon and Label Y Offset** — 图标和标签对相对于模块的垂直偏移 `0`（默认）| `scalar`

将标签和图标对垂直中点相对于模块垂直中点的垂直偏移指定为模块高度的比例。相对于偏移为 `0` 时的位置，负值偏移将文本向上移动，正值偏移将文本向下移动。

### **Icon Placement** — 图标相对于标签的位置 `Left`（默认）| `Top` | `Right` | `Bottom`

## 版本历史

**在 R2024b 中引入**

### R2025a：在仿真期间选择仪表板模块并打开模块参数对话框

当来自 Dashboard 或 Customizable Blocks 库的 Simulink 模块处于*活动*状态时，您可以与该模块所代表的小工具进行交互。例如，您可以按下按钮或拨动开关。当模块处于非活动状态时，您只能与该模块进行交互。例如，您可以移动或调整模块大小。默认情况下，来自 Dashboard 和 Customizable Blocks 库的所有模块在仿真期间均处于活动状态。提升到仪表板面板的模块在面板于其自己的窗口中打开或停靠且未锁定时也处于活动状态。Callback Button 模块中至少有一个通过按下按钮触发的回调具有非空值时，该模块始终处于活动状态。要与非活动模块所代表的小工具进行交互，您可以通过点击该模块临时激活它。取消选择该模块后，模块再次变为非活动状态。

点击活动的 Callback Button 模块或来自 Dashboard 或 Customizable Blocks 库的已连接到参数或变量值的活动模块，会同时选择该模块并与该模块所代表的小工具进行交互。例如，点击未选中的活动已连接 Push Button 模块会同时选择该模块并按下按钮。从 R2025a 开始，您可以通过按 **Shift** 然后点击模块来选择模块而不与小工具交互。同样，您可以通过按 **Shift** 然后双击模块来打开模块参数对话框。

### R2024b：使用键盘解锁仪表板模块宽高比

如果来自 Dashboard 库的模块的宽高比已锁定，您可以通过按 **Shift** 临时解锁宽高比。释放 **Shift** 键时，宽高比锁定。

如果宽高比已解锁，按 **Shift** 会临时锁定宽高比。释放 **Shift** 键时，宽高比解锁。

## 描述

使用可自定义外观的复选框在仿真期间更改参数或变量的值

使用 Check Box 模块在仿真之前或仿真期间更改所连接变量或参数的值。当您在 Customizable Blocks 库中使用 Check Box 模块时，您可以自定义模块的外观，例如使模块看起来像您正在设计的数字用户界面中的复选框。将 Check Box 模块与其他仪表板模块一起使用，为您的模型构建交互式控件和指示器仪表板。

您可以通过将 Check Box 模块连接到参数，然后选中或清除复选框来更改参数的值。默认情况下，选中复选框将参数值设置为 `1`，清除复选框将值设置为 `0`。要自定义这些值，请打开属性检查器的 **Parameters** 选项卡或模块参数对话框，然后更改 **Cleared value** 和 **Checked value**。

要在仿真期间选中或清除复选框，请单击 Check Box 模块上的复选框图标。要在仿真未运行时选中或清除复选框，请单击 Check Box 模块以选中该模块，然后单击复选框图标。

**注意**

- 在仿真期间双击已连接的 Check Box 模块，或在单击该模块后双击，不会打开模块参数对话框。要打开模块参数对话框，请按 **Shift**，然后双击该模块。
- 在仿真期间单击已连接的 Check Box 模块会同时选中该模块并选中或取消选中复选框。要选中该模块而不选中或取消选中复选框，请按 **Shift**，然后单击该模块。

### 自定义 Check Box 模块

当您将 Check Box 模块添加到模型时，该模块预配置了默认设计。您可以使用默认设计使用该模块，也可以自定义模块的外观。

要自定义模块的外观，请使用设计模式。选中模块后，您可以通过以下三种方式之一进入设计模式：

- 在 Simulink® 工具条的模块特定选项卡上，在 **Design** 下，单击 **Edit**。
- 在属性检查器的 **Design** 选项卡上，单击 **Edit**。
- 暂停在模块上出现的省略号上，然后单击 Edit Custom Block 按钮 。

在设计模式下，您可以使用模块上方的工具栏自定义复选框。要访问其他自定义选项或输入设计设置的精确值，请使用属性检查器中的 **Design** 选项卡。

处于设计模式的可自定义 Check Box 模块，工具栏和属性检查器中的 Design 选项卡可见。

**设计模式操作**

| 操作 | 工具栏中可用 | **Design** 选项卡中可用 |
| --- | --- | --- |
| 更改标签文本。 | 否 | 是 |
| 更改标签字体颜色。 | 是 | 是 |
| 上传表示已选中复选框的图标。 | 是 | 是 |
| 上传表示已清除复选框的图标。 | 是 | 是 |
| 更改图标和标签在模块内的位置。 | 否 | 是 |
| 上传背景图像。 | 是 | 是 |
| 设置纯色背景颜色。 | 否 | 是 |
| 上传前景图像。 | 否 | 是 |

**注意**

您在 **Design** 选项卡中所做的所有更改——包括您在 **Label and Icon** 组件中所做的更改——都会同时应用于已清除复选框和已选中复选框。例如，当您更改图标宽度时，您会同时更改表示已清除复选框的图标宽度和表示已选中复选框的图标宽度。

除了使用工具栏和 **Design** 选项卡自定义模块设计外，您还可以在画布中以交互方式重新定位标签和图标。

完成设计编辑后，要退出设计模式，请单击画布右上角的 **X**。

### 连接仪表板模块

仪表板模块不使用端口连接到模型元素。要连接仪表板模块，请使用连接模式。要在未连接的模块上进入连接模式，请暂停在要连接的模块上，然后单击 Connect 按钮 。要在已连接的模块上进入连接模式，请选中该模块，暂停在出现的省略号 (…) 上，然后在展开的操作菜单中单击 Connect 按钮。

要将控制模块连接到模型中的参数或更改控制模块的连接，请进入连接模式。选择要将其参数连接到的模块。在出现的列表中，选择要连接到的参数。然后，暂停在仪表板模块上，并单击 Done Connecting 按钮 。

在您更新模型图之前，控制模块无法连接到由变量定义的参数。要连接到由变量定义的参数，或在仿真未运行时修改定义所连接参数值的变量值，请按 **Ctrl+D** 更新模型图。

您可以连接到具有标量值的参数，也可以连接到矩阵或结构的元素。有关详细信息，请参阅 Connect Dashboard Blocks to Simulink Model。

您还可以将仪表板模块连接到 Stateflow® 图。有关详细信息，请参阅 Connect Dashboard Blocks to Stateflow (Stateflow)。

### 参数记录

连接到仪表板模块的可调参数会记录到仿真数据检查器中，您可以在其中查看参数值以及记录的信号数据。您可以通过使用 UI 或 `Simulink.sdi.exportRun` 函数从仿真数据检查器导出参数数据，从而在 MATLAB® 工作区中访问记录的参数数据。有关使用仿真数据检查器 UI 导出数据的详细信息，请参阅 Export Data to Workspace or File。参数数据存储在 `Simulink.SimulationData.Parameter` 对象中，可作为导出的 `Simulink.SimulationData.Dataset` 中的元素访问。
