# Check Box

## 端口

R2025b 中未记录。

## 参数

使用属性检查器和模块参数对话框指定模块参数的值。要设置仪表板模块的核心参数，请使用模块参数对话框或属性检查器中的 **参数** 选项卡。要自定义模块，请使用属性检查器中的 **设计** 选项卡。要打开某个模块的模块参数对话框，请双击该模块。要打开属性检查器，请在 **建模** 选项卡上的 **设计** 下，选择 **属性检查器**。

### 参数

要设置仪表板模块的核心参数，请打开属性检查器，然后单击 **参数** 选项卡。

#### 连接

### **连接** — 用于将模块参数值连接到参数值的连接选项

仪表板模块不使用端口连接到模型元素。要将仪表板模块连接到模型中的参数值，请使用连接模式、Simulink 工具条或模块参数对话框中的 **连接** 表。要从属性检查器打开模块参数对话框，请在 **已连接到** 右侧单击 **连接** 或 **更改**。您可以连接到具有标量值的参数，或连接到矩阵的某个元素。有关连接模式以及如何使用工具条进行连接的信息，请参阅将仪表板模块连接到 Simulink 模型。

#### 编程用法

要以编程方式将仪表板模块连接到可调参数，请使用 `Simulink.HMI.ParamSourceInfo` 对象。`Simulink.HMI.ParamSourceInfo` 对象包含四个属性。有些属性适用于将仪表板模块连接到由值定义的参数，有些属性适用于将仪表板模块连接到由变量定义的参数。并非所有字段都有连接值，因为给定的仪表板模块要么连接到由值定义的参数，要么连接到由变量定义的参数。

|  |
| --- |
| **模块参数：** `Binding` |
| **类型：** `Simulink.HMI.ParamSourceInfo` |
| **默认：** `[]` |

### **标签** — 显示所连接元素名称的标签位置 `Hide`（默认） | `Bottom` | `Top`

您可以在位于模块顶部或底部的标签中显示仪表板模块所连接元素的名称，也可以隐藏该标签。如果要使标签可见，请指定标签的位置。如果不希望标签可见，请选择 `Hide`。

**注意**

当仪表板模块未连接到元素时，标签为空。

|  |
| --- |
| **模块参数：** `LabelPosition` |
| **类型：** character vector |
| **值：** `'Hide'` | `'Bottom'` | `'Top'` |
| **默认：** `'Hide'` |

### **锁定宽高比** — 用于保持模块宽高比的选项 `on`（默认） | `off`

选择此参数可在 Simulink 画布中调整模块大小时保持宽高比。

锁定宽高比时，添加新的背景图像会更改模块的宽高比，以匹配背景图像的宽高比。解锁宽高比时，添加新的背景图像不会更改模块的宽高比，而会更改背景图像的宽高比，以适应模块的大小。

锁定宽高比时，调整模块大小的同时按 **Shift** 键会临时解锁宽高比。释放 **Shift** 键时，宽高比锁定。解锁宽高比时，调整模块大小的同时按 **Shift** 键会临时锁定宽高比。释放 **Shift** 键时，宽高比解锁。

#### 复选框

### **锁定宽高比** — 用于保持模块宽高比的选项 `on`（默认） | `off`

选择此参数可在 Simulink 画布中调整模块大小时保持宽高比。

锁定宽高比时，添加新的背景图像会更改模块的宽高比，以匹配背景图像的宽高比。解锁宽高比时，添加新的背景图像不会更改模块的比例，而会拉伸或缩放背景图像，以适应模块的大小。

锁定宽高比时，调整模块大小的同时按 **Shift** 键会解锁宽高比。释放 **Shift** 键时，宽高比锁定。解锁宽高比时，调整模块大小的同时按 **Shift** 键会锁定宽高比。释放 **Shift** 键时，宽高比解锁。

### **颜色** — 标签字体颜色 `[0 0 0]`（默认） | `[r g b]` vector

从标准颜色调色板中选择标签文本的字体颜色，或指定自定义颜色。

### **水平对齐** — 标签和图标对相对于模块的水平对齐方式 `Left`（默认） | `Center` | `Right`

设置标签和图标对在水平方向上的对齐方式。下表列出了 **X 偏移量** 为零时标签和图标对的水平位置。非零 **X 偏移量** 会将标签和图标对从表中列出的位置移开。

| 对齐方式 | 标签和图标对的位置 |
| --- | --- |
| `Left` | 标签和图标对的左边缘位于模块的左边缘。 |
| `Center` | 标签和图标对的水平中点位于模块的水平中点。 |
| `Right` | 标签和图标对的右边缘位于模块的右边缘。 |

### **图标和标签 X 偏移量** — 图标和标签对相对于模块的水平偏移量 `0`（默认） | scalar

**X 偏移量** 的测量方式取决于 **水平对齐** 的值。下表列出了每个 **水平对齐** 值的偏移量测量方式。相对于偏移量为 `0` 时的位置，负偏移量会使文本左移，正偏移量会使文本右移。

| **水平对齐** | 偏移量 |
| --- | --- |
| `Left` | 将标签和图标对的左边缘相对于模块左边缘的水平偏移量指定为模块宽度的比率。 |
| `Center` | 将标签和图标对的水平中点相对于模块水平中点的水平偏移量指定为模块宽度的比率。 |
| `Right` | 将标签和图标对的右边缘相对于模块右边缘的水平偏移量指定为模块宽度的比率。 |

### **图标和标签 Y 偏移量** — 图标和标签对相对于模块的垂直偏移量 `0`（默认） | `scalar`

指定标签和图标对的垂直中点相对于模块垂直中点的垂直偏移量。相对于偏移量为 `0` 时的位置，负偏移量会使文本上移，正偏移量会使文本下移。

### **图标放置** — 图标相对于标签的放置位置 `Left`（默认） | `Top` | `Right` | `Bottom`

指定图标相对于标签的放置位置。

**注意**

更改图标放置位置会移动标签，但不会更改标签的偏移量或对齐方式。

### **图标偏移量** — 图标相对于标签的偏移量 scalar

当 **图标放置** 设置为 `Left` 或 `Right` 时，将图标相对于标签的偏移量指定为模块宽度的比率。

当 **图标放置** 设置为 `Top` 或 `Bottom` 时，将图标相对于标签的偏移量指定为模块高度的比率。

**示例：** `0.5`

### **图标宽度** — 图标宽度 scalar

将图标宽度指定为标签文本字体高度的比率。

**示例：** `0.5`

### **图标高度** — 图标高度 scalar

将图标高度指定为标签文本字体高度的比率。

**示例：** `0.5`

### **锁定宽高比** — 用于保持图标宽高比的选项 `on (default)` | `off`

选择此参数可在 Simulink 画布中调整图标大小时保持宽高比。

## 版本历史

**R2024b 中引入**

### R2025a：在仿真期间选择仪表板模块并打开模块参数对话框

当来自 Dashboard 或 Customizable Blocks 库的 Simulink 模块处于*活动*状态时，您可以与该模块所代表的控件交互。例如，您可以按下按钮或切换开关。当模块处于非活动状态时，您只能与该模块交互。例如，您可以移动或调整模块大小。默认情况下，来自 Dashboard 和 Customizable Blocks 库的所有模块在仿真期间都处于活动状态。提升到仪表板面板的模块在该面板在其自身窗口中打开或停靠且未锁定时也处于活动状态。只要通过按下按钮触发的至少一个回调具有非空值，Callback Button 模块就始终处于活动状态。要与非活动模块所代表的控件交互，您可以通过单击该模块来临时激活该模块。取消选择该模块后，该模块会再次变为非活动状态。

单击活动的 Callback Button 模块或来自 Dashboard 或 Customizable Blocks 库的、连接到参数或变量值的活动模块，会同时选择该模块并与该模块所代表的控件交互。例如，单击未选中的活动已连接 Push Button 模块会同时选择该模块并按下按钮。从 R2025a 开始，您可以通过按 **Shift** 并单击该模块来选择该模块，而不与控件交互。类似地，您可以通过按 **Shift** 并双击该模块来打开模块参数对话框。

### R2024b：使用键盘解锁仪表板模块宽高比

如果来自 Dashboard 库的模块的宽高比已锁定，您可以通过按 **Shift** 临时解锁宽高比。释放 **Shift** 键后，宽高比会锁定。

如果宽高比已解锁，按 **Shift** 会临时锁定宽高比。释放 **Shift** 键后，宽高比会解锁。

## 描述

使用具有可自定义外观的复选框在仿真期间更改参数或变量值

使用 Check Box 模块可在仿真前或仿真期间更改所连接变量或参数的值。当您在 Customizable Blocks 库中使用 Check Box 模块时，可以自定义模块的外观，例如使模块看起来像您正在设计的数字用户界面中的复选框。将 Check Box 模块与其他仪表板模块一起使用，可为您的模型构建包含控件和指示器的交互式仪表板。

您可以通过将 Check Box 模块连接到参数，然后选中或取消选中复选框来更改参数的值。默认情况下，选中复选框会将参数值设置为 `1`，取消选中复选框会将该值设置为 `0`。要自定义这些值，请打开属性检查器的 **参数** 选项卡或模块参数对话框，然后更改 **清除值** 和 **选中值**。

要在仿真期间选中或取消选中复选框，请点击 Check Box 模块上的复选框图标。要在仿真未运行时选中或取消选中复选框，请点击 Check Box 模块以选择该模块，然后点击复选框图标。

**注意**

- 在仿真期间双击已连接的 Check Box 模块，或在点击该模块后双击，不会打开模块参数对话框。要打开模块参数对话框，请按 **Shift**，然后双击该模块。
- 在仿真期间点击已连接的 Check Box 模块会同时选择该模块并选中或取消选中复选框。要选择该模块而不选中或取消选中复选框，请按 **Shift**，然后点击该模块。

### 自定义 Check Box 模块

将 Check Box 模块添加到模型时，该模块已预配置为默认设计。您可以使用默认设计下的该模块，也可以自定义该模块的外观。

要自定义模块的外观，请使用设计模式。选择该模块后，可以通过以下三种方式之一进入设计模式：

- 在 Simulink® 工具条中，在模块特定的选项卡上，于 **设计** 下点击 **编辑**。
- 在属性检查器中，在 **设计** 选项卡上点击 **编辑**。
- 将鼠标悬停在模块上出现的省略号上，然后点击编辑自定义模块按钮。

在设计模式下，您可以使用模块上方的工具栏自定义复选框。要访问更多自定义选项或为设计设置输入精确值，请使用属性检查器中的 **设计** 选项卡。

处于设计模式的 Customizable Check Box 模块，工具栏和属性检查器中的设计选项卡可见。

**设计模式操作**

| 操作 | 在工具栏中可用 | 在 **设计** 选项卡中可用 |
| --- | --- | --- |
| 更改标签文本。 | 否 | 是 |
| 更改标签字体颜色。 | 是 | 是 |
| 上传表示选中复选框的图标。 | 是 | 是 |
| 上传表示未选中复选框的图标。 | 是 | 是 |
| 更改图标和标签在模块内的位置。 | 否 | 是 |
| 上传背景图像。 | 是 | 是 |
| 设置纯色背景色。 | 否 | 是 |
| 上传前景图像。 | 否 | 是 |

**注意**

您在 **设计** 选项卡中所做的所有更改（包括在 **标签和图标** 组件中所做的更改）都会同时应用于未选中复选框和选中复选框。例如，当您更改图标宽度时，会同时更改表示未选中复选框的图标宽度和表示选中复选框的图标宽度。

除了使用工具栏和 **设计** 选项卡自定义模块设计之外，您还可以在画布中以交互方式重新定位标签和图标。

完成设计编辑后，要退出设计模式，请点击画布右上角的 **X**。

### 连接仪表板模块

仪表板模块不使用端口连接到模型元素。要连接仪表板模块，请使用连接模式。要在未连接的模块上进入连接模式，请将鼠标悬停在要连接的模块上，然后点击连接按钮。要在已连接的模块上进入连接模式，请选择该模块，将鼠标悬停在其上出现的省略号 (…) 上，然后在展开的操作菜单中点击连接按钮。

要将控制模块连接到模型中的参数或更改控制模块的连接，请进入连接模式。选择要将其参数连接到的模块。从出现的列表中，选择要连接到的参数。然后，将鼠标悬停在仪表板模块上，并点击完成连接按钮。

在更新模型图之前，控制模块无法连接到由变量定义的参数。要在仿真未运行时连接到由变量定义的参数，或修改定义所连接参数值的变量值，请按 **Ctrl+D** 更新模型图。

您可以连接到具有标量值的参数，或连接到矩阵或结构体的元素。有关详细信息，请参阅将仪表板模块连接到 Simulink 模型。

您还可以将仪表板模块连接到 Stateflow® 图。有关详细信息，请参阅将仪表板模块连接到 Stateflow (Stateflow)。

### 参数记录

连接到仪表板模块的可调参数会记录到仿真数据检查器，您可以在其中查看参数值以及记录的信号数据。您可以通过使用 UI 或 `Simulink.sdi.exportRun` 函数从仿真数据检查器导出参数数据，从而在 MATLAB® 工作区中访问记录的参数数据。有关使用仿真数据检查器 UI 导出数据的详细信息，请参阅将数据导出到工作区或文件。参数数据存储在 `Simulink.SimulationData.Parameter` 对象中，可作为导出的 `Simulink.SimulationData.Dataset` 中的元素进行访问。
