## 参数

使用属性检查器和模块参数对话框指定模块参数的值。要设置仪表板模块的核心参数，请使用模块参数对话框或属性检查器中的 **参数** 选项卡。要自定义模块，请使用属性检查器中的 **设计** 选项卡。要打开模块的模块参数对话框，请双击该模块。要打开属性检查器，请在 **建模** 选项卡上的 **设计** 下，选择 **属性检查器**。

### 参数

要设置仪表板模块的核心参数，请打开属性检查器，然后单击 **参数** 选项卡。

#### 主要

### **按钮类型** — 按钮对点击的响应 `Momentary`（默认）| `Latch`

指定模块如何响应点击。

- `Momentary` — 按钮仅在按下时更改状态。释放点击时，按钮返回其默认状态。
- `Latch` — 单击时按钮锁存状态更改。按钮保持按下状态，直到再次单击它。

将 **按钮类型** 配置为 `Momentary` 时，模块具有以下状态：

- `Default` — 模块未按下时的默认状态
- `Pressed` — 模块按下时的状态

将 **按钮类型** 配置为 `Latch` 时，模块具有以下状态：

- `Default` — 模块未按下时的默认状态。
- `Pressed` — 当按钮处于 `Default` 状态时按下按钮的过渡状态。释放点击时，模块转换到 `Latched` 状态。
- `Latched` — 模块未按下时的锁存状态。
- `Latched and Pressed` — 当按钮处于 `Latched` 状态时按下按钮的过渡状态。释放点击时，模块转换到 `Default` 状态。

### **锁定纵横比** — 用于保持模块纵横比的选项 `on`（默认）| `off`

选择此参数可在调整 Simulink 画布中模块大小时保持纵横比。

锁定纵横比时，添加新的背景图像会更改模块的纵横比以匹配背景图像的纵横比。解锁纵横比时，添加新的背景图像不会更改模块的纵横比，而是更改背景图像的纵横比以适合模块的大小。

锁定纵横比时，在调整模块大小期间按 **Shift** 键会临时解锁纵横比。释放 **Shift** 键时，纵横比锁定。解锁纵横比时，在调整模块大小期间按 **Shift** 键会临时锁定纵横比。释放 **Shift** 键时，纵横比解锁。

#### 回调

### **ClickFcn** — 为响应点击而执行的 MATLAB 代码 MATLAB code

为响应按钮点击而执行的 MATLAB 代码。

每次单击按钮时，`ClickFcn` 代码都会在释放点击的时刻执行一次。

要为 `ClickFcn` 指定代码，请从下拉菜单中选择 `ClickFcn`。在菜单下方的文本框中输入代码。

|  |
| --- |

| **类型:** character vector | string |
| **值:** MATLAB code |

### **PressFcn** — 为响应按下而执行的 MATLAB 代码 MATLAB code

为响应按钮按下而执行的 MATLAB 代码。

当按钮处于按下状态时，`PressFcn` 代码会在 **按下延迟** 时间过后执行一次，并在每个 **重复间隔** 周期性执行。

要为 `PressFcn` 指定代码，请从下拉菜单中选择 `PressFcn`。在菜单下方的文本框中输入代码。

如何按下按钮以执行 `PressFcn` 代码取决于 **按钮类型**。

- 如果 **按钮类型** 为 `Momentary`，请按住点击您希望按下按钮的持续时间。
- 如果 **按钮类型** 为 `Latch`，单击以按下按钮，但不要按住点击。按钮保持按下状态，直到再次单击它。

**注意**

每次单击按钮时，即使这是按下按钮过程的一部分，`ClickFcn` 代码也会在释放点击的时刻执行一次。

#### 按钮

### **锁定纵横比** — 用于保持模块纵横比的选项 `on`（默认）| `off`

选择此参数可在调整 Simulink 画布中模块大小时保持纵横比。

#### 状态

### **选择状态** — 要配置的状态选择 `Default`（默认）| `Pressed` | `Latched` | `Latched and Pressed`

从 **状态** 组件的 **选择状态** 部分的下拉菜单中选择要配置的状态。当 **按钮类型** 为 `Momentary` 时，可以选择以下状态：

- `Default` — 模块未按下时的默认状态
- `Pressed` — 模块按下时的状态

当 **按钮类型** 为 `Latch` 时，可以选择以下状态：

- `Default` — 模块未按下时的默认状态。
- `Pressed` — 当按钮处于 `Default` 状态时按下按钮的过渡状态。释放点击时，模块转换到 `Latched` 状态。
- `Latched` — 模块未按下时的锁存状态。
- `Latched and Pressed` — 当按钮处于 `Latched` 状态时按下按钮的过渡状态。释放点击时，模块转换到 `Default` 状态。

**注意**

可以为某个状态配置 **设计** 选项卡的 **状态** 组件中的所有参数。例如，可以选择当按钮处于该状态时显示在按钮上的图标。配置 **状态** 组件中的任何参数时，更改将应用于在 **状态** 组件的 **选择状态** 部分中所选的状态。

**示例:** `Pressed`

## 版本历史

**在 R2017b 中引入**

### R2025a: 仿真未运行时，单击一次而不是两次即可按下回调按钮

当来自 Dashboard 或 Customizable Blocks 库的 Simulink 模块处于*活动*状态时，您可以与该模块所代表的控件交互。例如，您可以按下按钮或翻转开关。当模块处于非活动状态时，您只能与模块本身交互。例如，您可以移动或调整模块大小。要在模块处于非活动状态时与控件交互，您可以通过单击模块来临时激活该模块。取消选择该模块后，该模块会再次变为非活动状态。

默认情况下，来自 Dashboard 和 Customizable Blocks 库的所有模块在仿真期间都处于活动状态。提升到 Dashboard 面板的模块在该面板在其自身窗口中打开或已停靠且未锁定时也处于活动状态。在以前的版本中，这些模块在所有其他情况下都处于非活动状态。具体而言，当仿真未运行时，模型画布中或面板中的 Callback Button 模块（该面板既未在其自身窗口中打开，也未停靠并解锁）处于非活动状态。要按下按钮，您必须单击模块两次：一次用于临时激活模块，一次用于按下按钮。

从 R2025a 开始，对于至少有一个由按下按钮触发的回调具有非空值的 Callback Button 模块，无论仿真是否正在运行，这些模块始终处于活动状态。此更改意味着当仿真未运行时，您可以通过单击一次来按下回调按钮。当仿真未运行时，您可以移动和调整活动的 Callback Button 模块的大小。

还有新的键盘快捷键可用于与活动模块交互。单击活动的 Callback Button 模块或来自 Dashboard 或 Customizable Blocks 库且连接到参数或变量值的活动模块时，会同时选择该模块并与该模块所代表的控件交互。例如，单击未选择的、活动的、已连接的 Push Button 模块会同时选择该模块并按下按钮。从 R2025a 开始，您可以通过按 **Shift** 再单击该模块来选择模块而不与控件交互。类似地，您可以通过按 **Shift** 再双击该模块来打开模块参数对话框。

### R2024b: 使用键盘解锁 Dashboard 模块纵横比

如果来自 Dashboard 库的模块的纵横比已锁定，您可以通过按 **Shift** 临时解锁纵横比。释放 **Shift** 键后，纵横比会锁定。

如果纵横比已解锁，按 **Shift** 会临时锁定纵横比。释放 **Shift** 键后，纵横比会解锁。

### R2024a: 停靠 Dashboard 面板

从 R2024a 开始，您可以将 Dashboard 面板停靠到 Simulink 编辑器窗口。您可以使用停靠的面板在仿真期间监测信号和控制参数，而不会覆盖画布中的模型图。

有关详细信息，请参阅停靠面板。

### R2023b: 在新窗口中打开面板

从 R2023b 开始，您可以在新窗口中打开 Dashboard 面板。为此，请选择该面板并暂停在出现的省略号上。在展开的操作菜单中，单击 **在新窗口中打开** 按钮 。

您可以单独最小化和还原包含该面板的新窗口，而不影响模型窗口。从面板窗口中，您可以运行、暂停、停止和单步执行仿真。在面板窗口中，您可以编辑该面板及其包含的模块。

要将面板返回到模型画布，请在面板窗口工具条中，单击 **在画布中打开** 。

有关在新窗口中打开面板的详细信息，请参阅在新窗口中打开面板。

### R2023a: Simulink 工具条中的持久面板选项卡

将 Dashboard 面板添加到模型时，Simulink 工具条中会出现 **面板** 选项卡，并显示用于管理和编辑面板的选项。

以前，**面板** 选项卡仅在选中面板时可见。从 R2023a 开始，未选择面板时，**面板** 选项卡仍保持可见。

### R2023a: Dashboard 库和 Customizable Blocks 库中的 Callback Button 模块具有相同的自定义设置

从 R2023a 开始，Dashboard 库中的 Callback Button 模块与 Customizable Blocks 库中的 Callback Button 模块具有相同的自定义选项。

### R2022b: 对面板中的可自定义 Dashboard 模块的撤消和重做支持

从 R2022b 开始，您可以撤消和重做对面板中的可自定义 Dashboard 模块所做的更改。

要撤消或重做更改：

1. 单击该面板或面板中的某个模块。
2. 按 **Ctrl+Z** 撤消更改，或按 **Ctrl+Y** 重做更改。

**注意**

### R2022b: 对面板的工具条支持

当您单击面板中的 Dashboard 模块时，该模块的工具条选项卡会出现。例如，当您单击 Circular Gauge 模块时，**仪表** 选项卡会出现在工具条中。

## 描述

使用按钮执行 MATLAB 代码

Callback Button 模块响应单击（立即释放指针）或按下（延迟释放指针）来运行 MATLAB® 代码。您可以为单击指定与按下不同的代码。当您按下按钮时，代码要么在某个时间跨度后执行，要么按您指定的时间间隔执行。您可以自定义 Callback Button 模块的外观，使其看起来像真实系统中的按钮。将 Callback Button 模块与其他 Dashboard 模块一起使用，可创建交互式仪表板来控制您的模型。

当 Callback Button 模块处于*活动*状态时，您可以与该模块所代表的控件交互。单击活动的 Callback Button 模块会按下虚拟按钮。当您按住指针时，按钮被按下。当您释放指针时，按钮被释放。当仿真正在运行、模块位于在其自身窗口中打开或已停靠且未锁定的面板中，或者由单击或按下触发的至少一个回调具有非空值时，Callback Button 模块处于活动状态。要选择活动的 Callback Button 模块而不按下按钮，请按 **Shift**，然后单击该模块。要打开活动的 Callback Button 模块的模块参数对话框，请按 **Shift**，然后双击该模块。

当模块处于非活动状态时，您只能与模块本身交互，例如执行调整模块大小或拖动模块等操作。要临时激活非活动的 Callback Button 模块，请单击该模块。取消选择 Callback Button 模块后，该模块会再次变为非活动状态。

使用回调函数指定按下按钮时要执行的操作：

- `PressFcn` 函数在按钮被按下期间运行。您可以将按钮配置为在按钮被按下期间仅运行一次 `PressFcn` 函数，也可以指定重复间隔。要仅运行一次该函数，请指定重复间隔为 `0`。
- `ClickFcn` 函数在您释放按钮时运行。

通过将 **按钮类型** 设置为 `Latched`，您可以配置按钮在释放指针后保持按下状态。当您选择锁存按钮类型时：

- 要锁存按钮，请单击该按钮。
- 要解除按钮锁存，请再次单击该按钮。

`PressFcn` 函数在按钮被锁存期间运行。`ClickFcn` 函数在您锁存按钮时运行一次，并在您解除按钮锁存时运行一次。

您可以使用状态来指定与按钮交互时 Callback Button 模块外观的变化方式：

- 当您按下按钮时，模块处于 `Pressed` 状态。
- 当按钮已锁存且您未按下它时，模块处于 `Latched` 状态。
- 当按钮已锁存且您正在按下它时，模块处于 `Latched and Pressed` 状态。
- 当模块不处于这三种状态中的任何一种时，它处于 `Default` 状态。

状态将指针操作与以下各项配对：

- 状态标签
- 状态图标
- 状态图像

### 自定义 Callback Button 模块

将 Callback Button 模块添加到模型时，该模块已预配置默认设计。您可以使用默认设计的模块，也可以自定义模块的外观。

要自定义模块的外观，请使用设计模式。选择模块后，您可以通过以下三种方式之一进入设计模式：

- 在 Simulink® 工具条中，在特定于模块的选项卡上的 **设计** 下，单击 **编辑**。
- 在属性检查器的 **设计** 选项卡上，单击 **编辑**。
- 暂停在模块上出现的省略号上，然后单击编辑自定义模块按钮 。

处于设计模式的 Callback Button 模块，其中工具栏和属性检查器中的设计选项卡可见。

设计 Callback Button 模块时，您需要为每个可能的状态配置模块外观。将 **模块类型** 配置为 `Momentary` 时，模块有两种状态。将 **模块类型** 配置为 `Latch` 时，模块有四种状态。

您可以使用模块上方的工具栏切换状态。对于每个状态，您可以：

- 上传状态图像。
- 上传状态图标，并指定图标相对于状态标签的位置。
- 指定状态标签文本、颜色、不透明度和位置。

您还可以上传前景或背景图像，或设置纯色背景。前景和背景适用于所有状态。

使用模块上方的工具栏配置图像、图标以及状态标签的颜色和不透明度。

您可以使用属性检查器中的 **设计** 选项卡来精细控制模块设计，并为设计设置输入精确值。

使用 **设计** 选项卡可以：

- 指定状态标签文本和位置。
- 指定图标位置。
- 上传前景图像。
- 上传背景图像。
- 设置纯色背景。

完成设计编辑后，要退出设计模式，请单击画布右上角的 **X**。
