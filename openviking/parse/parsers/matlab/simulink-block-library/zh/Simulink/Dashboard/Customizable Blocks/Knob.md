## 参数

使用属性检查器和模块参数对话框指定模块参数的值。要设置仪表板模块的核心参数，请使用模块参数对话框或属性检查器中的 **参数** 选项卡。要自定义该模块，请使用属性检查器中的 **设计** 选项卡。要打开模块的模块参数对话框，请双击该模块。要打开属性检查器，请在 **建模** 选项卡上的 **设计** 下，选择 **属性检查器**。

### 参数

要设置仪表板模块的核心参数，请打开属性检查器，然后单击 **参数** 选项卡。

#### 连接

### **Connection** — 用于将模块参数值连接到参数值的连接选项

仪表板模块不使用端口连接到模型元素。要将仪表板模块连接到模型中的参数值，请使用连接模式、Simulink Toolstrip 或模块参数对话框中的 **Connection** 表。要从属性检查器打开模块参数对话框，请在 **Connected to** 右侧单击 **Connect** 或 **Change**。您可以连接到具有 scalar 值的参数，或连接到矩阵的元素。有关连接模式以及如何使用工具条连接的信息，请参阅将仪表板模块连接到 Simulink 模型。

要使用 **Connection** 表将控制模块连接到具有 scalar 值的参数，或更改控制模块与具有 scalar 值的参数的连接：

1. 选择该模块。
2. 要连接该模块，请在属性检查器中的 **参数** 选项卡上单击 **Connect**。要更改该模块的连接，请改为单击 **Change**。
3. 选择要将其参数值连接到的模块。
4. 在表中，选择要连接到的参数。
5. 单击 **Apply**。

在对模型框图进行更新之前，控制模块无法连接到由变量定义的参数。若要连接到由变量定义的参数，或在仿真未运行时修改定义已连接参数值的变量的值，请按 **Ctrl+D** 更新模型框图。

您还可以将仪表板模块连接到 Stateflow 图。有关详细信息，请参阅将仪表板模块连接到 Stateflow (Stateflow)。

#### 编程用法

要以编程方式将仪表板模块连接到可调参数，请使用 `Simulink.HMI.ParamSourceInfo` 对象。`Simulink.HMI.ParamSourceInfo` 对象包含四个属性。有些属性适用于将仪表板模块连接到由值定义的参数，有些属性适用于将仪表板模块连接到由变量定义的参数。并非所有字段都有连接值，因为给定的仪表板模块要么连接到由值定义的参数，要么连接到由变量定义的参数。

|  |

| **模块参数：** `Binding` |

| **默认：** `[]` |

### **Lock Aspect Ratio** — 用于保持模块宽高比的选项 `on` (default) | `off`

选择此参数可在 Simulink 画布中调整模块大小时保持宽高比。

当宽高比锁定时，添加新的背景图像会更改模块的宽高比，以匹配背景图像的宽高比。当宽高比未锁定时，添加新的背景图像不会更改模块的宽高比，而是会更改背景图像的宽高比，以适合模块的大小。

当宽高比锁定时，调整模块大小期间按下 **Shift** 键会临时解锁宽高比。释放 **Shift** 键时，宽高比会锁定。当宽高比未锁定时，调整模块大小期间按下 **Shift** 键会临时锁定宽高比。释放 **Shift** 键时，宽高比会解锁。

## 版本历史

**在 R2021a 中引入**

### R2025a：在仿真期间选择 Dashboard 模块并打开模块参数对话框

当来自 Dashboard 或 Customizable Blocks 库的 Simulink 模块处于*活动*状态时，您可以与该模块所代表的控件交互。例如，您可以按下按钮或拨动开关。当模块处于非活动状态时，您只能与该模块交互。例如，您可以移动或调整模块大小。默认情况下，Dashboard 和 Customizable Blocks 库中的所有模块在仿真期间都处于活动状态。提升到仪表板面板的模块在该面板在其自己的窗口中打开或停靠且已解锁时也处于活动状态。对于 Callback Button 模块，如果按下按钮触发的至少一个回调具有非空值，则该模块始终处于活动状态。要与非活动模块所代表的控件交互，您可以通过点击该模块来临时激活它。取消选择该模块后，该模块会再次变为非活动状态。

点击活动的 Callback Button 模块或来自 Dashboard 或 Customizable Blocks 库、连接到参数或变量值的活动模块，会同时选择该模块并与该模块所代表的控件交互。例如，点击未选中的活动已连接 Push Button 模块会同时选择该模块并按下按钮。从 R2025a 开始，您可以通过按下 **Shift** 然后单击该模块来选择模块而不与控件交互。类似地，您可以通过按下 **Shift** 然后双击该模块来打开模块参数对话框。

### R2024b：使用键盘解锁 Dashboard 模块纵横比

如果来自 Dashboard 库的模块的纵横比已锁定，您可以通过按下 **Shift** 临时解锁纵横比。当您释放 **Shift** 键时，纵横比会锁定。

如果纵横比未锁定，按下 **Shift** 会临时锁定纵横比。当您释放 **Shift** 键时，纵横比会解锁。

## 描述

使用具有可自定义外观的旋钮更改参数或变量值

使用 Knob 模块在仿真期间调整变量或模块参数的值。当您使用 Customizable Blocks 库中的 Knob 模块时，可以自定义模块的外观，使其看起来像真实系统中的控件。您可以修改 Knob 模块上的范围和刻度值，以适合要调整的值的所需范围。将 Knob 模块与其他 Dashboard 模块一起使用，可创建交互式仪表板来控制模型。

要在仿真运行时调整值，请使用指针将手柄拖到要将所连接变量或模块参数设置到的刻度值。要在仿真未运行时调整值，请点击 Knob 模块以选择该模块，然后将手柄拖到要将所连接变量或模块参数设置到的刻度值。

**注意**

- 在仿真期间或点击模块后双击已连接的 Knob 模块不会打开模块参数对话框。要打开模块参数对话框，请按 **Shift**，然后双击该模块。
- 在仿真期间点击已连接的 Knob 模块会同时选择该模块并移动旋钮手柄。要选择模块而不移动旋钮手柄，请按 **Shift**，然后点击该模块。

### 自定义 Knob 模块

将 Knob 模块添加到模型时，该模块会预配置为默认设计。您可以使用默认设计的模块，也可以自定义模块的外观。

要自定义模块的外观，请使用设计模式。选择模块后，您可以通过以下三种方式之一进入设计模式：

- 在 Simulink® Toolstrip 中的模块特定选项卡上，在**设计**下，点击**编辑**。
- 在属性检查器中的**设计**选项卡上，点击**编辑**。
- 暂停在模块上出现的省略号上，然后点击编辑自定义模块按钮。

在设计模式下，您可以使用模块上方的工具条自定义圆形仪表。要访问其他自定义选项或为设计设置输入精确值，请使用属性检查器中的**设计**选项卡。

处于设计模式的 Customizable Knob 模块，其中工具条和属性检查器中的**设计**选项卡可见。

**设计模式操作**

| 操作 | 在工具条中可用 | 在**设计**选项卡中可用 |
| --- | --- | --- |
| 上传手柄图像。 | Yes | Yes |
| 上传背景图像。 | Yes | Yes |
| 设置纯色背景色。 | No | Yes |
| 上传前景图像。 | No | Yes |
| 更改刻度线、刻度标签或值条的颜色和不透明度。 | Yes | Yes |
| 更改刻度的弧长。 | No | Yes |
| 将刻度方向指定为顺时针或逆时针。 | No | Yes |
| 指定值条增长的起点位置。 | No | Yes |
| 更改刻度和手柄的大小。 | No | Yes |
| 更改刻度和手柄的位置。 | No | Yes |

要使用工具条更改刻度线、刻度标签或值条的颜色和不透明度，请在工具条从左数第二部分中选择要更改颜色的组件。要更改颜色，请点击色轮。要更改不透明度，请移动滑块。

除了使用工具条和**设计**选项卡自定义模块设计外，您还可以在画布中以交互方式调整组件大小和重新定位组件。手柄的移动被限制在穿过模块中心和刻度上最小值的线上。

完成设计编辑后，要退出设计模式，请点击画布右上角的 **X**。

### 连接 Dashboard 模块

Dashboard 模块不使用端口连接到模型元素。要连接 Dashboard 模块，请使用连接模式。要在未连接的模块上进入连接模式，请暂停在要连接的模块上，然后点击连接按钮。要在已连接的模块上进入连接模式，请选择该模块，暂停在出现的省略号 (…) 上，然后在展开的操作菜单中点击连接按钮。

要将控制模块连接到模型中的参数，或更改控制模块的连接，请进入连接模式。选择要连接到其参数的模块。在出现的列表中，选择要连接到的参数。然后，暂停在 Dashboard 模块上并点击完成连接按钮。

在更新模型图之前，控制模块无法连接到由变量定义的参数。要在仿真未运行时连接到由变量定义的参数，或修改定义已连接参数值的变量的值，请按 **Ctrl+D** 更新模型图。

您可以连接到具有标量值的参数，或连接到矩阵或结构体的元素。有关详细信息，请参阅将 Dashboard 模块连接到 Simulink 模型。

您还可以将 Dashboard 模块连接到 Stateflow® 图。有关详细信息，请参阅将 Dashboard 模块连接到 Stateflow (Stateflow)。

### 参数记录

连接到 Dashboard 模块的可调参数会记录到仿真数据检查器，您可以在其中查看参数值以及记录的信号数据。您可以使用 UI 或 `Simulink.sdi.exportRun` 函数从仿真数据检查器导出参数数据，从而在 MATLAB® 工作区中访问记录的参数数据。有关使用仿真数据检查器 UI 导出数据的更多信息，请参阅将数据导出到工作区或文件。参数数据存储在 `Simulink.SimulationData.Parameter` 对象中，可作为导出的 `Simulink.SimulationData.Dataset` 中的元素进行访问。
