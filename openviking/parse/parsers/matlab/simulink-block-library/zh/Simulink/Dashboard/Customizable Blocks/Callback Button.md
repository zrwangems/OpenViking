## 参数

使用“属性检查器”和“模块参数”对话框来指定模块参数的值。要设置仪表板模块的核心参数，请使用“模块参数”对话框或“属性检查器”中的 **参数** 选项卡。要自定义模块，请使用“属性检查器”中的 **设计** 选项卡。要打开模块的“模块参数”对话框，请双击该模块。要打开“属性检查器”，请在 **建模** 选项卡上的 **设计** 下，选择 **属性检查器**。

### 参数

要设置仪表板模块的核心参数，请打开“属性检查器”，然后单击 **参数** 选项卡。

#### 主要

### **按钮类型** — 按钮对点击的响应 `Momentary` (默认) | `Latch`

指定模块如何响应点击。

- `Momentary` — 按钮仅在按下时更改状态。释放点击后，按钮返回其默认状态。
- `Latch` — 按钮在点击时锁存状态更改。按钮保持按下状态，直到再次点击它。

当您将 **按钮类型** 配置为 `Momentary` 时，该模块具有以下状态：

- `Default` — 模块未按下时的默认状态
- `Pressed` — 模块按下时的模块状态

当您将 **按钮类型** 配置为 `Latch` 时，该模块具有以下状态：

- `Default` — 模块未按下时的默认状态。
- `Pressed` — 当按钮处于 `Default` 状态时按下按钮的过渡状态。释放点击后，模块转换到 `Latched` 状态。
- `Latched` — 模块未按下时的锁存状态。
- `Latched and Pressed` — 当按钮处于 `Latched` 状态时按下按钮的过渡状态。释放点击后，模块转换到 `Default` 状态。

|  |

| **类型：** character vector | string |

### **锁定宽高比** — 用于保持模块宽高比的选项 `on` (默认) | `off`

在 Simulink 画布中调整模块大小时，选择此参数以保持宽高比。

当宽高比锁定时，添加新的背景图像会更改模块的宽高比，以匹配背景图像的宽高比。当宽高比未锁定时，添加新的背景图像不会更改模块的宽高比，而是更改背景图像的宽高比，以适合模块的大小。

当宽高比锁定时，在调整模块大小时按下 **Shift** 键会临时解锁宽高比。释放 **Shift** 键时，宽高比会锁定。当宽高比未锁定时，在调整模块大小时按下 **Shift** 键会临时锁定宽高比。释放 **Shift** 键时，宽高比会解锁。

#### 回调

### **ClickFcn** — 响应点击而执行的 MATLAB 代码 MATLAB code

响应点击按钮而执行的 MATLAB 代码。

每次点击按钮时，`ClickFcn` 代码都会执行一次，执行时间点为释放点击时。

要为 `ClickFcn` 指定代码，请从下拉菜单中选择 `ClickFcn`。在菜单下方的文本框中输入代码。

#### 程序化使用

将模块的 `ClickFcn` 参数指定为格式化为 string 或 character vector 的 MATLAB code。

|  |
| --- |
| **模块参数：** `ClickFcn` |
| **类型：** character vector | string |
| **值：** MATLAB code |

### **PressFcn** — 响应按下而执行的 MATLAB 代码 MATLAB code

响应按下按钮而执行的 MATLAB 代码。

当按钮处于按下状态时，`PressFcn` 代码在 **按下延迟** 时间过后执行一次，然后每隔 **重复间隔** 周期性执行。

要为 `PressFcn` 指定代码，请从下拉菜单中选择 `PressFcn`。在菜单下方的文本框中输入代码。

您如何按下按钮以执行 `PressFcn` 代码取决于 **按钮类型**。

- 如果 **按钮类型** 为 `Momentary`，请按住点击，持续时间为您希望按下按钮的时间。
- 如果 **按钮类型** 为 `Latch`，点击以按下按钮，但不要按住点击。按钮保持按下状态，直到再次点击它。

**注意**

每次点击按钮时，即使这是按下按钮过程的一部分，`ClickFcn` 代码都会执行一次，执行时间点为释放点击时。

#### 程序化使用

将模块的 `PressFcn` 参数指定为格式化为 string 或 character vector 的 MATLAB code。

|  |
| --- |
| **模块参数：** `PressFcn` |
| **类型：** character vector | string |
| **值：** MATLAB code |

#### 按钮

### **锁定宽高比** — 用于保持模块宽高比的选项 `on` (默认) | `off`

在 Simulink 画布中调整模块大小时，选择此参数以保持宽高比。

当宽高比锁定时，在调整模块大小时按下 **Shift** 键会解锁宽高比。释放 **Shift** 键时，宽高比会锁定。当宽高比未锁定时，在调整模块大小时按下 **Shift** 键会锁定宽高比。释放 **Shift** 键时，宽高比会解锁。

#### 状态

### **选择状态** — 要配置的状态选择 `Default` (默认) | `Pressed` | `Latched` | `Latched and Pressed`

从 **状态** 组件中 **选择状态** 部分的下拉菜单中，选择要配置的状态。当 **按钮类型** 为 `Momentary` 时，您可以选择以下状态：

- `Default` — 模块未按下时的默认状态
- `Pressed` — 模块按下时的模块状态

当 **按钮类型** 为 `Latch` 时，您可以选择以下状态：

- `Default` — 模块未按下时的默认状态。
- `Pressed` — 当按钮处于 `Default` 状态时按下按钮的过渡状态。释放点击后，模块转换到 `Latched` 状态。
- `Latched` — 模块未按下时的锁存状态。
- `Latched and Pressed` — 当按钮处于 `Latched` 状态时按下按钮的过渡状态。释放点击后，模块转换到 `Default` 状态。

**注意**

您可以为某个状态配置 **设计** 选项卡的 **状态** 组件中的所有参数。例如，您可以选择当按钮处于该状态时显示在按钮上的图标。当您配置 **状态** 组件中的任何参数时，更改将应用于 **状态** 组件中 **选择状态** 部分所选的状态。

**示例：** `Pressed`

## 版本历史

**R2021b 中引入**

### R2025a: 仿真未运行时，单击一次而不是两次即可按下 Callback Button

当 Dashboard 或 Customizable Blocks 库中的 Simulink 模块处于*活动*状态时，您可以与模块所代表的小工具交互。例如，您可以按下按钮或翻转开关。当模块处于非活动状态时，您只能与模块本身交互。例如，您可以移动或调整模块大小。要在模块处于非活动状态时与小工具交互，您可以通过点击模块临时激活该模块。取消选择模块后，模块会再次变为非活动状态。

默认情况下，在仿真期间，Dashboard 和 Customizable Blocks 库中的所有模块都处于活动状态。提升到仪表板面板的模块在面板于其自身窗口中打开或停靠且未锁定时也处于活动状态。在以前的版本中，模块在所有其他情况下均处于非活动状态。具体而言，当仿真未运行时，模型画布中或既未在其自身窗口中打开也未停靠且未解锁的面板中的 Callback Button 模块处于非活动状态。要按下按钮，您必须点击模块两次：一次用于临时激活模块，一次用于按下按钮。

从 R2025a 开始，对于按下按钮所触发的至少一个回调具有非空值的 Callback Button 模块，无论仿真是否运行，它们始终处于活动状态。此更改意味着当仿真未运行时，您可以通过单击一次来按下回调按钮。当仿真未运行时，您可以移动和调整活动 Callback Button 模块的大小。

还有一个用于与活动模块交互的新键盘快捷方式。点击活动的 Callback Button 模块，或点击 Dashboard 或 Customizable Blocks 库中已连接到参数或变量值的活动模块，会同时选择该模块并与模块所代表的小工具交互。例如，点击未选中的活动已连接 Push Button 模块会同时选择该模块并按下按钮。从 R2025a 开始，您可以通过按下 **Shift** 并单击模块来选择模块而不与小工具交互。类似地，您可以通过按下 **Shift** 并双击模块来打开模块参数对话框。

### R2024b: 使用键盘解锁仪表板模块纵横比

如果 Dashboard 库中某个模块的纵横比已锁定，您可以通过按下 **Shift** 临时解锁纵横比。当您释放 **Shift** 键时，纵横比会重新锁定。

如果纵横比已解锁，按下 **Shift** 会临时锁定纵横比。当您释放 **Shift** 键时，纵横比会解锁。

### R2024a: 停靠仪表板面板

从 R2024a 开始，您可以将仪表板面板停靠到 Simulink 编辑器窗口。您可以使用停靠的面板在仿真期间监测信号和控制参数，而不会覆盖画布中的模型图。

有关详细信息，请参阅停靠面板。

### R2023b: 在新窗口中打开面板

从 R2023b 开始，您可以在新窗口中打开仪表板面板。为此，请选择面板并暂停在出现的省略号上。在展开的操作菜单中，点击“在新窗口中打开”。

您可以独立于模型窗口最小化和还原包含面板的新窗口。在面板窗口中，您可以运行、暂停、停止和单步执行仿真。在面板窗口中，您可以编辑面板及其包含的模块。

要将面板返回到模型画布，请在面板窗口工具条中点击“在画布中打开”。

有关在新窗口中打开面板的详细信息，请参阅“在新窗口中打开面板”。

### R2023a: Simulink 工具条中的持久面板选项卡

将仪表板面板添加到模型时，**面板** 选项卡会出现在 Simulink 工具条中，并显示用于管理和编辑面板的选项。

以前，**面板** 选项卡仅在选中面板时可见。从 R2023a 开始，当未选择面板时，**面板** 选项卡仍保持可见。

**面板** 选项卡还包含以下新选项：

- 您可以添加空面板。
- 您可以重命名所选面板。
- 您可以隐藏所选面板。

### R2022b: 支持对面板中的可自定义仪表板模块执行撤消和重做

从 R2022b 开始，您可以撤消和重做对面板中的可自定义仪表板模块所做的更改。

要撤消或重做更改：

1. 点击面板或面板中的模块。
2. 按 **Ctrl+Z** 撤消更改，或按 **Ctrl+Y** 重做更改。

**注意**

键盘快捷方式基于 Windows®。在 Mac 上，请按 **command** (⌘) 而不是 **Ctrl**。

### R2022b: 对面板的工具条支持

从 R2022b 开始，您可以使用 Simulink 工具条管理和编辑面板及其包含的仪表板模块。

当您在面板中点击仪表板模块时，该模块的工具条选项卡会出现。例如，当您点击 Circular Gauge 模块时，**仪表** 选项卡会出现在工具条中。

当您点击面板时，**面板** 选项卡会出现在工具条中。该选项卡提供以下选项：

- 管理模型中面板的可见性。
- 使所有未隐藏的面板适应当前视图。
- 折叠所选面板。
- 自定义面板的大小和内容。
- 为所选面板设置自定义背景图像。
- 为所选面板添加新选项卡。

### R2022a: 调整前景图像大小并重新定位

Customizable Blocks 库中的模块提供了将前景图像添加为模块设计一部分的选项。从 R2022a 开始，您可以在模块设计中旋转、调整大小和重新定位前景图像。

## 描述

使用具有可自定义外观的按钮执行 MATLAB 代码

Callback Button 模块响应点击（立即释放指针）或按下（延迟释放指针）来运行 MATLAB® 代码。您可以为点击指定与按下不同的代码。当您按下按钮时，代码会在您指定的时间跨度后执行，或按您指定的时间间隔执行。您可以自定义 Callback Button 模块的外观，使其看起来像真实系统中的按钮。将 Callback Button 模块与其他仪表板模块一起使用，以创建可控制模型的交互式仪表板。

当 Callback Button 模块处于*活动*状态时，您可以与模块所代表的小工具交互。点击活动的 Callback Button 模块会按下虚拟按钮。当您按住指针时，按钮被按下。当您释放指针时，按钮被释放。当仿真正在运行、模块位于在其自身窗口中打开或已停靠且未解锁的面板中，或者点击或按下所触发的至少一个回调具有非空值时，Callback Button 模块处于活动状态。要选择活动的 Callback Button 模块而不按下按钮，请按下 **Shift**，然后点击该模块。要打开活动的 Callback Button 模块的模块参数对话框，请按下 **Shift**，然后双击该模块。

当模块处于非活动状态时，您只能与模块本身交互，例如执行调整模块大小或拖动模块等操作。要临时激活非活动的 Callback Button 模块，请点击该模块。取消选择 Callback Button 模块后，模块会再次变为非活动状态。

使用回调函数指定您希望按下按钮执行的操作：

- `PressFcn` 函数在按钮被按下期间运行。您可以配置按钮，使其在按钮被按下期间仅运行一次 `PressFcn` 函数，也可以指定重复间隔。要仅运行该函数一次，请将重复间隔指定为 `0`。
- `ClickFcn` 函数在您释放按钮时运行。

您可以通过将 **按钮类型** 设置为 `Latched`，将按钮配置为在您释放指针时保持按下状态。当您选择锁存按钮类型时：

- 要锁存按钮，请点击按钮。
- 要取消锁存按钮，请再次点击按钮。

`PressFcn` 函数在按钮被锁存期间运行。`ClickFcn` 函数在您锁存按钮时运行一次，并在您取消锁存按钮时再运行一次。

您可以使用状态来指定当您与按钮交互时 Callback Button 模块的外观如何变化：

- 当您按下按钮时，模块处于 `Pressed` 状态。
- 当按钮已锁存且您未按下它时，模块处于 `Latched` 状态。
- 当按钮已锁存且您正在按下它时，模块处于 `Latched and Pressed` 状态。
- 当模块不处于这三种状态中的任何一种时，它处于 `Default` 状态。

状态将指针操作与以下项配对：

- 状态标签
- 状态图标
- 状态图像

### 自定义 Callback Button 模块

将 Callback Button 模块添加到模型时，该模块已预配置默认设计。您可以使用默认设计下的模块，也可以自定义模块的外观。

要自定义模块的外观，请使用设计模式。选择模块后，您可以通过以下三种方式之一进入设计模式：

- 在 Simulink® 工具条中，在模块特定选项卡上的 **设计** 下，点击 **编辑**。
- 在属性检查器中，在 **设计** 选项卡上，点击 **编辑**。
- 暂停在模块上方出现的省略号上，然后点击“编辑自定义模块”按钮。

在设计模式中，您可以使用模块上方的工具栏来自定义 callback button。要访问其他自定义选项或输入设计设置的精确值，请使用属性检查器中的 **设计** 选项卡。

处于设计模式的可自定义 Callback Button 模块，其中工具栏和属性检查器中的设计选项卡可见。

自定义 Callback Button 模块时，您需要为每个状态配置模块外观。当您将 **模块类型** 配置为 `Momentary` 时，模块有两个状态。当您将 **模块类型** 配置为 `Latch` 时，模块有四个状态。要选择要自定义的状态，请使用工具栏中的下拉列表。或者，在 **设计** 选项卡上，选择 **状态** 组件，然后从 **选择状态** 列表中选择。

**自定义所选状态的设计模式操作**

| 操作 | 在工具栏中可用 | 在 **设计** 选项卡中可用 |
| --- | --- | --- |
| 指定状态标签文本。 | No | Yes |
| 指定状态标签文本的颜色和不透明度。 | Yes | Yes |
| 上传状态图像。 | Yes | Yes |
| 上传状态图标。 | Yes | Yes |
| 更改状态图像和状态图标的大小。 | No | Yes |
| 更改状态标签、状态图像和状态图标的位置。 | No | Yes |

除了使用工具栏和 **设计** 选项卡自定义模块设计之外，您还可以在画布中以交互方式调整组件大小并重新定位组件。要调整特定于状态的组件（例如状态图像）的大小，请在工具栏中选择该状态，然后调整组件大小或重新定位组件。

**适用于所有状态的设计模式操作**

| 操作 | 在工具栏中可用 | 在 **设计** 选项卡中可用 |
| --- | --- | --- |
| 上传背景图像。 | No | Yes |
| 设置纯色背景颜色。 | No | Yes |
| 上传前景图像。 | No | Yes |

完成设计编辑后，要退出设计模式，请点击画布右上角的 **X**。
