# Enable

## 端口

### 输出

### **使能信号** — 子系统或模型的外部使能信号 标量

外部连接到已使能子系统模块外侧并传递到子系统内部的使能信号。
当您选中 **显示输出端口** 参数时，使能端口会添加一个使能信号端口。

**数据类型：** `single` | `double` | `int8` | `int16` | `int32` | `int64` | `uint8` | `uint16` | `uint32` | `uint64` | `Boolean` | `fixed point` | `expression`

## 参数

### **使能时的状态** — 选择子系统或模型禁用时的模块状态 `held`（默认）| `reset`

当子系统模块或模型模块被禁用时，选择子系统或模型内模块的模块状态会发生什么。

`held`
:   将模块状态保持在其先前值。

`reset`
:   将模块状态重置为其初始条件（如果未定义则为零）。

#### 程序化使用

|  |
| --- |
| **模块参数：** `StatesWhenEnabling` |
| **类型：** 字符向量 |
| **值：** `'held'` | `'reset'` |
| **默认：** `'held'` |

### **传播可变大小信号的尺寸** — 选择何时传播可变大小信号 `仅在使能时`（默认）| `执行期间`

选择何时传播可变大小信号。

`仅在使能时`
:   在重新使能包含使能端口模块的子系统模块或模型模块时传播可变大小信号。当您选择此选项时，采样时间必须为周期性。

`执行期间`
:   在每个时间步传播可变大小信号。

#### 程序化使用

|  |
| --- |
| **模块参数：** `PropagateVarSize` |
| **类型：** 字符向量 |
| **值：** `'Only when enabling'` | `'During execution'` |
| **默认：** `'Only when enabling'` |

### **显示输出端口** — 控制使能信号输出端口的显示 `off`（默认）| `on`

输出端口将外部连接到已使能子系统模块或已使能模型模块外侧的使能信号传递到内部。

off
:   移除使能端口模块上的输出端口。

on
:   在使能端口模块上显示输出端口。选择此选项允许子系统或模型处理使能信号。

#### 程序化使用

|  |
| --- |

| **类型：** 字符向量 |
| **值：** `'off'` | `'on'` |
| **默认：** `'off'` |

控制模型的过零检测。

on

off

### **端口维度** — 指定使能信号的维度 `1`（默认）| `[n]` | `[m n]`

指定外部连接到模型模块并传递到模块内部的使能信号的维度。

`1`
:   标量信号。

`[n]`
:   宽度为 `n` 的向量信号。

`[m n]`
:   具有 `m` 行和 `n` 列的矩阵信号。

### **数据类型** — 指定使能信号的输出数据类型 `double`（默认）| `single` | `int8` | `uint8` | `int16` | `uint16` | `int32` | `uint32` | `int64` | `uint64` | `boolean` | `fixdt(1,16)` | `fixdt(1,16,0)` | `fixdt(1,16,2^,0)` | `<data type expression>`

指定外部连接到模型模块并传递到模块内部的使能信号的数据类型。

`double`
:   双精度浮点。

`single`
:   单精度浮点。

`int8`
:   有符号 8 位整数。

`uint8`
:   无符号 8 位整数。

`int16`
:   有符号 16 位整数。

`uint16`
:   无符号 16 位整数。

`int32`
:   有符号 32 位整数。

`uint32`
:   无符号 32 位整数。

`int64`
:   有符号 64 位整数。

`uint64`
:   无符号 64 位整数。

`boolean`
:   值为 `true` 或 `false` 的布尔值。

`fixdt(1,16)`
:   有符号 16 位定点数，二进制点未定义。

:   有符号 16 位定点数，二进制点设置为零。

`fixdt(1,16,2^,0)`

## 描述

向子系统或模型添加使能端口

使能模块允许外部信号控制子系统或模型的执行。要启用此功能，请将该模块添加到子系统模块中，或添加到由模型模块引用的模型的根级别。

如果在模型的根级别使用使能端口：

- 对于多速率模型，将求解器设置为单任务。
- 对于具有固定步长的模型，模型中至少有一个模块必须以指定的固定步长速率运行。
