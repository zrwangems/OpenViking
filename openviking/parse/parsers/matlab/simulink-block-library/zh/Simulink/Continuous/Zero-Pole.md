# Zero-Pole

## 端口

### 输入

### **Port\_1** — 输入信号 标量

系统的标量时域输入信号。

**数据类型：** `double`
### 输出

### **Port\_1** — 输出信号 标量 | 向量

建模为零极点增益传递函数的系统输出，以标量或向量信号形式提供。

- 当建模单输出系统时，该模块产生标量时域信号。
- 当建模多输出系统时，该模块产生向量，其中向量的每个元素是系统的一个输出。

**数据类型：** `double`

## 参数

### **Zeros** — 零点矩阵 `[1]`（默认）| 向量 | 矩阵

定义零点矩阵。

- 对于单输出系统，输入一个向量作为传递函数的零点。
- 对于多输出系统，输入一个矩阵。该矩阵的每一列包含一个传递函数的零点，该传递函数将系统输入与输出向量的一个元素相关联。
- 要建模无零点的系统，输入 `[]`。

### **Poles** — 极点向量 `[0 -1]`（默认）| 向量

定义极点向量。

- 对于单输出系统，输入一个向量作为传递函数的极点。
- 对于多输出系统，输入一个向量作为系统所有传递函数共有的极点。

### **Gain** — 增益向量 `[1]`（默认）| 向量

定义增益向量。

- 对于单输出系统，输入一个 1×1 向量作为传递函数的增益。
- 对于多输出系统，输入一个增益向量。每个元素是零点矩阵中对应传递函数的增益。

### **Parameter tunability** — 代码中模块参数的可调表示 `Auto`（默认）| `Optimized` | `Unconstrained`

指定零点、极点和增益在加速器和快速加速器仿真中以及在使用 Simulink® Compiler™ 部署的仿真中是否可调。

- `Auto` — 软件确定参数可调性级别。
- `Optimized` — 软件为加速器、快速加速器和部署仿真生成零点、极点和增益的优化表示。优化表示中的零点、极点和增益值不可调。
- `Unconstrained` — **Zeros**、**Poles** 和 **Gain** 参数的值在加速器、快速加速器和部署仿真之间可调。

### **Absolute tolerance** — 计算模块状态的绝对容差 `auto`（默认）| 标量 | 向量

变步长求解器在选择步长时使用绝对容差和相对容差来确定状态计算中的误差是否可接受。

要从 **Absolute tolerance** 配置参数继承绝对容差，请将此参数值指定为 `auto` 或 `-1`。

要为该模块指定覆盖 **Absolute tolerance** 配置参数所指定值的绝对容差：

- 输入一个实正标量值，用于计算所有模块状态。
- 输入一个实向量，其维度与模块连续状态的维度匹配。

### **State Name (e.g., 'position')** — 为状态分配唯一名称的选项 `''`（默认）| 字符向量 | 字符向量元胞数组 | MATLAB® 变量 | ...

使用此参数可选地为该模块的状态分配名称。您分配的名称仅适用于该模块的状态。

- 要使用默认状态名称，请将此字段留空（`''`）。
- 要为单个状态分配单个名称，请在引号内输入名称。例如，要将单个状态命名为 `position`，请输入 `'position'`。
- 要为多个状态分配名称，请将此参数值指定为字符向量元胞数组。元胞数组中的每个名称必须唯一。例如，要分配名称 `a`、`b` 和 `c`，请输入 `{'a','b','c'}`。
- 要使用 MATLAB 变量指定名称，请输入变量名（不带引号）。例如，要使用变量 `names` 指定状态名称，请输入 `names`。

您可以指定的名称数量少于模块中的状态数量。在这种情况下，状态名称将用于多个状态，并且状态数量必须能整除状态名称数量。例如，当您为一个具有四个状态的模块指定两个名称时，第一个名称用于前两个状态，第二个名称用于后两个状态。

### C/C++ 代码生成 使用 Simulink® Coder™ 生成 C 和 C++ 代码。

不建议用于生产代码，因为嵌入式系统中常见的资源限制以及速度和内存限制。生成的代码可能包含：

- 内存的动态分配和释放
- 递归
- 额外的内存开销
- 变化较大的执行时间

虽然代码在功能上是有效的，并且在资源丰富的环境中可以接受，但较小的嵌入式目标通常无法支持此类代码。

对于 Second-Order Integrator 模块，Model Discretizer 生成近似离散化。

## 描述

使用零极点增益传递函数建模系统

Zero-Pole 模块通过指定拉普拉斯域传递函数的零点、极点和增益来建模系统。您可以使用此模块建模单输入单输出（SISO）和单输入多输出（SIMO）系统。

Zero-Pole 模块具有以下要求：

- 传递函数必须具有以下形式

  H(s)=KZ(s)P(s)=K(s−Z(1))(s−Z(2))…(s−Z(m))(s−P(1))(s−P(2))…(s−P(n)),

  其中 *Z* 表示零点，*P* 表示极点，*K* 表示传递函数的增益。
- 极点数必须大于或等于零点数。
- 复数极点和零点必须为共轭复数对。
- 对于多输出系统，所有传递函数必须具有相同的极点。零点值可以不同，但每个传递函数的零点数必须相同。

**提示**

要建模传递函数具有不同零点数或各有一个零点的多输出系统，请使用多个 Zero-Pole 模块。

### 建模单输出系统

单输出系统具有标量时域输入和输出信号。要建模此类系统：

1. 在 **Zeros** 字段中输入一个向量作为传递函数的零点。
2. 在 **Poles** 字段中输入一个向量作为传递函数的极点。
3. 在 **Gain** 字段中输入一个标量作为传递函数的增益。

### 建模多输出系统

多输出系统具有标量时域输入信号和向量时域输出信号。向量输出中的每个元素是系统的一个输出。要建模此类系统：

1. 在 **Zeros** 字段中输入零点矩阵。

   矩阵的每一列包含一个传递函数的零点，该传递函数将系统输入信号与输出信号中的一个元素相关联。
2. 在 **Poles** 字段中输入一个向量作为系统所有传递函数共有的极点。
3. 在 **Gain** 字段中输入增益向量。

   每个元素是零点矩阵中对应传递函数的增益。
