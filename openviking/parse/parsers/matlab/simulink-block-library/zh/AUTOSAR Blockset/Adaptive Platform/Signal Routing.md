AUTOSAR Blockset 提供各种 App 和模块，以支持使用 Simulink® 模型开发 AUTOSAR Classic 和 Adaptive 软件。您可以使用 AUTOSAR 组件设计器设计 Simulink 模型并将其映射到软件组件。您也可以借助该模块集，通过从 AUTOSAR XML (ARXML) 文件导入软件组件和组合描述，生成新的 Simulink AUTOSAR 模型。

AUTOSAR Blockset 提供了用于 AUTOSAR 库例程和基础软件 (BSW) 服务（包括 NVRAM 和诊断）的模块和构造。通过将 BSW 服务与应用软件模型一起进行仿真，您可以在不离开 Simulink 的情况下验证 AUTOSAR ECU 软件。

您可以使用 AUTOSAR Blockset 在 Simulink 中创建 AUTOSAR 架构模型（需要 System Composer™）。在 AUTOSAR 架构模型中，您可以编写软件组合和组件，其中包含接口、数据类型、配置文件和构造型。您可以添加仿真行为，包括 BSW 服务组件。您还可以通过 ARXML 文件双向处理（导入和导出）软件描述。

AUTOSAR Blockset 支持 C 和 C++ 产品级代码生成（使用 Embedded Coder®）。经过鉴定，它适用于 ISO 26262 标准（使用 IEC Certification Kit）。
