AUTOSAR Blockset 提供用于使用 Simulink® 模型开发 AUTOSAR Classic 和 Adaptive 软件的应用程序和模块。您可以使用 AUTOSAR Component Designer 应用程序设计 Simulink 模型并将其映射到软件组件。此外，该模块集允许您通过从 AUTOSAR XML (ARXML) 文件导入软件组件和组合描述，为 AUTOSAR 生成新的 Simulink 模型。

AUTOSAR Blockset 为 AUTOSAR 库例程和基础软件 (BSW) 服务提供模块和构造，包括 NVRAM 和诊断。通过将 BSW 服务与您的应用软件模型一起仿真，您可以在不离开 Simulink 的情况下验证您的 AUTOSAR ECU 软件。

AUTOSAR Blockset 允许您在 Simulink 中创建 AUTOSAR 架构模型（需要 System Composer™）。在 AUTOSAR 架构模型中，您可以编写软件组合、带接口的组件、数据类型、配置文件和构造型。您可以添加仿真行为，包括 BSW 服务组件。此外，您可以通过 ARXML 文件往返（导入和导出）软件描述。

AUTOSAR Blockset 支持 C 和 C++ 产品代码生成（配合 Embedded Coder®）。它已通过 ISO 26262 标准使用认证（配合 IEC Certification Kit）。
