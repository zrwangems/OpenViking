# Timing Measurement

## 端口

### 输入

### **reference** — 输入信号 标量

正在测量其时序指标的输入信号，指定为标量。

**数据类型：** `double`

### **test** — 测试信号 标量

用于测量输入信号延迟的测试信号，指定为标量。

#### 依赖关系

要启用此端口，请在**选择**选项卡中选择 **Delay** 作为测量选项。

**数据类型：** `double`
### 输出

### **period** — 输入信号的周期 标量

输入信号的周期，以标量形式返回。

**数据类型：** `double`

### **frequency** — 输入信号的频率 标量

输入信号的频率，以标量形式返回。

#### 依赖关系

要启用此端口，请在**选择**选项卡中选择 **Frequency** 作为测量选项。

**数据类型：** `double`

### **rise time** — 输入信号的上升时间 标量

输入信号的上升时间，以标量形式返回。

#### 依赖关系

要启用此端口，请在**选择**选项卡中选择 **Rise Time** 作为测量选项。

**数据类型：** `double`

### **fall time** — 输入信号的下降时间 标量

输入信号的下降时间，以标量形式返回。

#### 依赖关系

要启用此端口，请在**选择**选项卡中选择 **Fall time** 作为测量选项。

**数据类型：** `double`

### **duty cycle** — 输入信号的占空比 标量

输入信号的占空比，以标量形式返回。

#### 依赖关系

要启用此端口，请在**选择**选项卡中选择 **Duty Cycle** 作为测量选项。

**数据类型：** `double`

### **delay** — 输入信号的延迟 标量

输入信号的延迟，以标量形式返回。

#### 依赖关系

要启用此端口，请在**选择**选项卡中选择 **Delay** 作为测量选项。

**数据类型：** `double`

## 参数

### 选择

### **Period** — 测量输入信号的周期 on（默认）| off

选择以测量输入信号的周期。

周期定义为周期信号完成一个完整周期所需的时间，以秒为单位指定。

### **Frequency** — 测量输入信号的频率 off（默认）| on

选择以测量输入信号的频率。

频率定义为周期信号每单位时间完成的周期数，以赫兹为单位指定。它是 **Period** 的倒数。

### **Rise Time** — 测量输入信号的上升时间 off（默认）| on

选择以测量输入信号的上升时间。

上升时间定义为信号的上升沿从其稳态值的 10% 到 90%（或 20% 到 80%）所需的时间，以秒为单位指定。

### **Fall Time** — 测量输入信号的下降时间 off（默认）| on

选择以测量输入信号的下降时间。

下降时间定义为信号的下降沿从其稳态值的 90% 到 10%（或 80% 到 20%）所需的时间，以秒为单位指定。

### **Duty Cycle** — 测量输入信号的占空比 off（默认）| on

选择以测量输入信号的占空比。

占空比定义为正脉冲宽度与周期之比，以分数形式指定。

### **Delay** — 测量输入信号的延迟 off（默认）| on

选择以测量输入信号的延迟。

延迟定义为目标信号与测试信号之间阈值交叉点的时间差，以秒为单位指定。

### 配置

### **Use same reference threshold for all measurements** — 使用相同的参考阈值测量所有时序指标 on（默认）| off

选择以使用相同的参考阈值测量所有时序指标。

### **Reference threshold (V)** — 用于测量时序指标的参考阈值 `0`（默认）| 标量

用于测量所有时序指标的参考阈值电压，以伏特为单位指定为标量。

#### 依赖关系

要启用此参数，请在**配置**选项卡中选择**对所有测量使用相同的参考阈值**。

#### 编程用法

- 使用 `get_param(gcb,'SameRefThreshold')` 查看**参考阈值 (V)** 的当前值。
- 使用 `set_param(gcb,'SameRefThreshold',value)` 将**参考阈值 (V)** 设置为特定值。

#### 周期/频率

### **参考阈值 (V)** — 用于测量周期和/或频率的参考阈值电压 `0`（默认）| 标量

用于测量目标信号周期和/或频率的参考阈值电压，指定为以伏特为单位的标量。

#### 依赖关系

要启用此参数，请在**配置**选项卡中取消选择**对所有测量使用相同的参考阈值**，并在**选择**选项卡中选择**周期**和/或**频率**。

#### 编程用法

- 使用 `get_param(gcb,'PeriodRefThreshold')` 查看**参考阈值 (V)** 的当前值。
- 使用 `set_param(gcb,'PeriodRefThreshold',value)` 将**参考阈值 (V)** 设置为特定值。

#### 上升/下降时间

### **输入范围 (V)** — 输入信号的峰峰值 `[-1 1]`（默认）| 2 元素行向量

输入信号的峰峰值，指定为以伏特为单位的 2 元素行向量。第一个元素定义输入信号的谷值，第二个元素定义峰值。**输入范围 (V)** 用于计算上下阈值电平，以计算上升/下降时间。

#### 依赖关系

要启用此参数，请在**选择**选项卡中选择**上升时间**和/或**下降时间**。

#### 编程用法

- 使用 `get_param(gcb,'Range')` 查看**参考阈值 (V)** 的当前值。
- 使用 `set_param(gcb,'Range',value)` 将**参考阈值 (V)** 设置为特定值。

### **类型** — 用于测量上升/下降时间的输入阈值电平 `80%/20%`（默认）| `90%/10%`

确定用于测量上升/下降时间的输入阈值电平，指定为 `80%/20%` 或 `90%/10%`。

#### 依赖关系

要启用此参数，请在**选择**选项卡中选择**上升时间**和/或**下降时间**。

#### 编程用法

- 使用 `get_param(gcb,'MeasurementType')` 查看**参考阈值 (V)** 的当前值。
- 使用 `set_param(gcb,'MeasurementType',value)` 将**参考阈值 (V)** 设置为特定值。

#### 占空比

### **参考阈值 (V)** — 用于测量占空比的参考阈值电压 `0`（默认）| 标量

用于测量目标信号占空比的参考阈值电压，指定为以伏特为单位的标量。

#### 依赖关系

要启用此参数，请在**配置**选项卡中取消选择**对所有测量使用相同的参考阈值**，并在**选择**选项卡中选择**占空比**。

#### 编程用法

- 使用 `get_param(gcb,'DcRefThreshold')` 查看**参考阈值 (V)** 的当前值。
- 使用 `set_param(gcb,'DcRefThreshold',value)` 将**参考阈值 (V)** 设置为特定值。

#### 延迟

### **参考阈值 (V)** — 目标信号中用于测量延迟的阈值电压电平 `0`（默认）| 标量

正在测量其延迟的参考目标信号中的阈值电压电平，指定为以伏特为单位的标量。

#### 依赖关系

要启用此参数，请在**配置**选项卡中取消选择**对所有测量使用相同的参考阈值**，并在**选择**选项卡中选择**延迟**。

#### 编程用法

- 使用 `get_param(gcb,'DelayRefThreshold')` 查看**参考阈值 (V)** 的当前值。
- 使用 `set_param(gcb,'DelayRefThreshold',value)` 将**参考阈值 (V)** 设置为特定值。

### **Test threshold (V)** — 测试信号中用于测量延迟的阈值电压电平 `0`（默认）| 标量

测试信号中的阈值电压电平，用于测量参考信号的延迟，指定为以伏特为单位的标量。

#### 依赖关系

要启用此参数，请在**配置**选项卡中取消选择 **Use same reference threshold for all measurements**，并在**选择**选项卡中选择 **Delay**。

#### 程序化使用

- 使用 `get_param(gcb,'DelayTstThreshold')` 查看 **Reference threshold (V)** 的当前值。
- 使用 `set_param(gcb,'DelayTstThreshold',value)` 将 **Reference threshold (V)** 设置为特定值。
