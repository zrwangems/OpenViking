# Segmented DAC

## 端口

### 输入

### **digital** — 数字输入信号，整数

DAC 的数字输入信号，指定为整数。

如果 **输入极性** 参数设置为 `Bipolar`，则信号的允许范围为 [−2*NBits*-1, 2*NBits*-1]。

如果 **输入极性** 参数设置为 `Unipolar`，则信号的允许范围为 [0, 2*NBits*-1]。

**数据类型：** `single` | `double` | `int8` | `int16` | `int32` | `uint8` | `uint16` | `uint32` | `fixed point`

### **start** — 用于启动转换的外部时钟，标量

用于启动转换的外部时钟，指定为标量。数模转换过程在 **start** 端口处信号的上升沿启动。

#### 依赖关系

要启用此端口，请选择 **使用外部启动时钟**。

**数据类型：** `double`
### 输出

### **analog** — 转换后的模拟输出信号，标量

转换后的模拟输出信号，以标量形式返回。

**数据类型：** `double`

## 参数

### **输入极性** — 定义 DAC 输入数据极性 `Unipolar`（默认） | `Bipolar`

定义 DAC 输入数据的极性。将 **输入极性** 设置为：

- `Unipolar`：当数字输入只能为正时。
- `Bipolar`：当数字输入可以同时为正和负时。

#### 程序化使用

|  |
| --- |
| **模块参数：** `Polarity` |
| **类型：** 字符向量 |
| **值：** `Unipolar` | `Bipolar` |
| **默认值：** `Unipolar` |

### **使用外部启动时钟** — 连接到外部启动转换时钟 on（默认） | off

选择此项可连接到外部启动转换时钟。此选项默认处于选中状态。如果取消选择此选项，则使用 Segmented DAC 模块内部的 Sampling Clock Source 模块生成启动转换时钟。

### **转换启动频率 (Hz)** — 内部启动转换时钟的频率 `1e6`（默认） | 实数标量

内部启动转换时钟的频率，指定为以 Hz 为单位的实数标量。**转换启动频率** 参数确定转换启动时的转换速率。

#### 依赖关系

要启用此参数，请取消选择 **使用外部启动时钟**。

#### 程序化使用

|  |
| --- |
| **模块参数：** `StartFreq` |
| **类型：** 字符向量 |
| **值：** 实数标量 |
| **默认值：** `1e6` |

### **参考 (V)** — DAC 输出参考幅度 `0.5`（默认） | 实数标量

DAC 输出的参考幅度，指定为以 volts 为单位的实数标量。**参考 (V)** 比最大可实现输出高一个最低有效位 (LSB)。

#### 程序化使用

|  |

| **模块参数：** `Ref` |

### **偏置 (V)** — 代码零的模拟输出与模拟零之间的差 `0`（默认） | 实数标量

在未受损 DAC 中，代码零的模拟输出与模拟零之间的差，指定为以 volts 为单位的实数标量。

#### 程序化使用

|  |
| --- |
| **模块参数：** `Bias` |
| **类型：** 字符向量 |
| **值：** 实数标量 |

### **建立时间 (s)** — 输出建立所需的时间 `2e-7`（默认） | 非负实数标量

DAC 输出建立到其最终值的某个比例范围内所需的时间，指定为以 seconds 为单位的非负实数标量。

#### 程序化使用

|  |
| --- |
| **模块参数：** `SettlingTime` |
| **类型：** 字符向量 |
| **值：** 实数标量 |

### **建立时间容差 (LSB)** — 计算建立时间的容差 `0.5`（默认） | 正实数标量

允许用于计算建立时间的容差，指定为以 LSB 为单位的正实数标量。DAC 的输出必须在 **建立时间 (s)** 之前稳定到 **建立时间容差 (LSB)** 范围内。

#### 程序化使用

|  |

#### 段设置

### **位宽** — DAC 段的物理输入位数，大于或等于 2 的整数标量

DAC 段的物理输入位数，指定为大于或等于 2 的整数标量。对于前两个 DAC 段，**位宽** 的默认值为 `4`。对于后续段，默认值为 `2`。

### **位** — 每个段的位范围，向量

每个段的位范围，以向量形式返回。如果通过上移或下移来更改任何段的索引，该段的位范围会相应更改。此参数为只读。

### **拓扑** — 基础 DAC 段的拓扑 `Binary Weighted`（默认）

该段的基础 DAC 的拓扑。模块使用 `Binary Weighted` DAC。此参数为只读。

### **偏移误差** — 偏移量化步长 `0`（默认） | 实数标量

按您在 **偏移误差** 参数中提供的值偏移量化步长，指定为实数标量。

### **偏移误差单位** — 偏移误差的单位 `LSB`（默认） | `FS` | `%FS`

偏移误差的单位，指定为 `LSB`、满量程 (`FS`) 或满量程百分比 (`%FS`)。

**注意**

转换器的满量程范围定义为 +0.5 LSB 补偿传输曲线上最后一个代码与第一个代码之间的差。在 +0.5 LSB 补偿传输曲线中，第一个代码的宽度为 0.5 LSB，而最后一个代码的宽度为 1.5 LSB。输入值必须视为处于转换器的满量程范围内。

**注意**

LSB 由方程 LSB = Full scale range of converter2NBits 计算。

### **增益误差** — DAC 传输曲线斜率的误差 `0`（默认） | 实数标量

DAC 传输曲线斜率的误差，指定为实数标量。

### **增益误差单位** — 增益误差的单位 `LSB`（默认） | `FS` | `%FS`

增益误差的单位，指定为 `LSB`、满量程 (`FS`) 或满量程百分比 (`%FS`)。

**注意**

转换器的满量程范围定义为 +0.5 LSB 补偿传输曲线上最后一个代码与第一个代码之间的差。在 +0.5 LSB 补偿传输曲线中，第一个代码的宽度为 0.5 LSB，而最后一个代码的宽度为 1.5 LSB。输入值必须视为处于转换器的满量程范围内。

**注意**

LSB 由方程 LSB = Full scale range of converter2NBits 计算。

## 描述

使用较小 DAC 的排列将大数字输入转换为模拟信号

Segmented DAC 模块通过将大数字信号拆分到多个较小的 DAC 上，将其转换为模拟输出。Segmented DAC 模块最多支持五个二进制加权分段 DAC。
