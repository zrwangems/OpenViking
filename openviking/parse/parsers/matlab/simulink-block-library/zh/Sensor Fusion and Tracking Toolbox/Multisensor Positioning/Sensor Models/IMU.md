# IMU

## 端口

### 输入

### **Linear Acceleration** — IMU 在局部导航坐标系中的加速度 (m/s2) *N*×3 实标量矩阵

IMU 在局部导航坐标系中的加速度，指定为以米每二次方秒为单位的 *N*×3 实数标量矩阵。*N* 是当前帧中的样本数。不要在此输入中包含重力加速度，因为传感器默认会对重力加速度建模。

要指定 IMU 传感器机体坐标系相对于局部导航坐标系的姿态，请使用 **Orientation** 输入端口。

**数据类型：** `single` | `double`

### **Angular Velocity** — IMU 在局部导航坐标系中的角速度 (rad/s) *N*×3 实标量矩阵

IMU 传感器机体坐标系在局部导航坐标系中的角速度，指定为以弧度每秒为单位的 *N*×3 标量矩阵。*N* 是当前帧中的样本数。要指定 IMU 传感器机体坐标系相对于局部导航坐标系的姿态，请使用 **Orientation** 输入端口。

**数据类型：** `single` | `double`

### **Orientation** — IMU 在局部导航坐标系中的姿态 *N*×4 实标量数组 | 3×3×*N* 元素旋转矩阵

IMU 传感器机体坐标系相对于局部导航坐标系的姿态，指定为 *N*×4 实数标量数组或 3×3×*N* 旋转矩阵。假定 *N*×4 数组的每一行均为 `quaternion` 的四个元素。*N* 是当前帧中的样本数。

**数据类型：** `single` | `double`

### **Temperature** — IMU 的温度 (℃) *N*×1 实标量向量

IMU 的温度，指定为以摄氏度（℃）为单位的 *N*×1 实数标量向量。

#### 依赖关系

要启用此端口，请在**参数**选项卡中选中 **Specify temperature from input port**。

**数据类型：** `single` | `double`

### **Magnetic Field** — 局部导航坐标系中的磁场矢量 (μT) *N*×3 实标量矩阵

局部导航坐标系中的磁场矢量，指定为以微特斯拉为单位的 *N*×3 标量矩阵。

#### 依赖关系

要启用此端口，请在**参数**选项卡中选中 **Specify magnetic field from input port**。

**数据类型：** `single` | `double`

### 输出

### **Accel** — 传感器机体坐标系中 IMU 的加速度计测量值 (m/s2) *N*×3 实标量矩阵

传感器机体坐标系中 IMU 的加速度计测量值，返回为以米每二次方秒为单位的 *N*×3 实数标量矩阵。*N* 是当前帧中的样本数。

**数据类型：** `single` | `double`

### **Gyro** — 传感器机体坐标系中 IMU 的陀螺仪测量值 (rad/s) *N*×3 实标量矩阵

传感器机体坐标系中 IMU 的陀螺仪测量值，返回为以弧度每秒为单位的 *N*×3 实数标量矩阵。*N* 是当前帧中的样本数。

**数据类型：** `single` | `double`

### **Mag** — 传感器机体坐标系中 IMU 的磁力计测量值 (μT) *N*×3 实标量矩阵

传感器机体坐标系中 IMU 的磁力计测量值，返回为以微特斯拉为单位的 *N*×3 实数标量矩阵。*N* 是当前帧中的样本数。

**数据类型：** `single` | `double`

## 参数

#### 参数

### **Reference frame** — 导航参考坐标系 `NED` (默认) | `ENU`

导航参考坐标系，指定为 `NED`（北-东-下）或 `ENU`（东-北-上）。

**注意**

- 如果选择 NED 参考坐标系，请在 NED 参考坐标系中指定传感器输入。此外，传感器将重力加速度建模为 [0 0 9.81] m/s2。
- 如果选择 ENU 参考坐标系，请在 ENU 参考坐标系中指定传感器输入。此外，传感器将重力加速度建模为 [0 0 −9.81] m/s2。

### **Specify temperature from input port** — 从输入端口指定温度 off (默认) | on

选中此复选框可通过 **Temperature** 输入端口启用温度输入。

### **Temperature (oC)** — IMU 的工作温度 (oC) `25` (默认) | 实标量

IMU 的工作温度，以摄氏度为单位，指定为实标量。

当模块计算温度比例因子和环境漂移噪声时，将 25 oC 用作标称温度。

#### 依赖关系

要启用此参数，请清除 **Specify temperature from input port**。

**数据类型：** `single` | `double`

### **Specify magnetic field from input port** — 从输入端口指定磁场 off (默认) | on

选中此复选框可通过 **Magnetic field** 输入端口启用磁场输入。

### **Magnetic field (NED)** — 以 NED 导航坐标系表示的磁场矢量 (μT) `[27.5550, -2.4169, -16.0849]` (默认) | 1×3 标量向量

以 NED 导航坐标系表示的磁场矢量，指定为 1×3 标量向量。

默认磁场对应于纬度为零、经度为零且高度为零处的磁场。

#### 依赖关系

要启用此参数，请将 **Reference frame** 设置为 `NED`，并清除 **Specify magnetic field from input port**。

**数据类型：** `single` | `double`

### **MagneticField (ENU)** — 以 ENU 导航坐标系表示的磁场矢量 (μT) `[-2.4169, 27.5550, 16.0849]` (默认) | 1×3 标量向量

以 ENU 导航坐标系表示的磁场矢量，指定为 1×3 标量向量。

默认磁场对应于纬度为零、经度为零且高度为零处的磁场。

#### 依赖关系

要启用此参数，请将 **Reference frame** 设置为 `ENU`，并清除 **Specify magnetic field from input port**。

**数据类型：** `single` | `double`

### **Seed** — 随机化的初始种子 `67` (默认) | 非负整数

随机数生成器算法的初始种子，指定为非负整数。

**数据类型：** `single` | `double`

### **Simulate using** — 要运行的仿真类型 `Interpreted Execution` (默认) | `Code Generation`

- `Interpreted execution` — 使用 MATLAB® 解释器仿真模型。此选项可缩短启动时间。在 `Interpreted execution` 模式下，可以调试模块的源代码。
- `Code generation` — 使用生成的 C 代码仿真模型。首次运行仿真时，Simulink 会为模块生成 C 代码。如果模型未发生变化，则后续仿真会重用该 C 代码。此选项需要额外的启动时间。

**数据类型：** `single` | `double`

### **Axis skew (%)** — 传感器轴偏斜 (%) `diag([100 100 100])` (默认) | 标量 | 3 元素行向量 | 3×3 矩阵

传感器轴偏斜，以百分比为单位，指定为标量、3 元素行向量或 3×3 矩阵。矩阵的对角元素表示每个轴的未对准影响。非对角元素表示交叉轴未对准影响。测量状态 *v**measure* 通过未对准矩阵从真实状态 *v**true* 获得，如下所示：

vmeasure=1100M vtrue=1100[m11m12m13m21m22m23m31m32m33]vtrue

- 如果将属性指定为标量，则矩阵的所有非对角元素都采用指定标量的值，所有对角元素均为 100。
- 如果将属性指定为向量 [*a* *b* *c*]，则 *m*21 = *m*31 = *a*，*m*12 = *m*32 = *b*，且 *m*13 = *m*23 = *c*。所有对角元素均为 100。

**数据类型：** `single` | `double`

### **Velocity random walk (m/s2/√Hz)** — 速度随机游走 (m/s2/√Hz) `[0 0 0]` (默认) | 实标量 | 实 3 元素行向量

速度随机游走，以 (m/s2/√Hz) 为单位，指定为实标量或 3 元素行向量。此属性对应于传感器噪声的功率谱密度。任何标量输入都会转换为实 3 元素行向量，其中每个元素的值均为输入标量值。

**数据类型：** `single` | `double`
