# Grid-Based Multi Object Tracker

## 端口

### 输入

### **Sensor Data** — 传感器数据 Simulink® 总线，包含 MATLAB® 结构体

传感器数据，指定为包含 MATLAB 结构体的 Simulink 总线。该结构体包含以下字段：

| 字段 | 描述 |
| --- | --- |
| `NumSensors` | 传感器数量，指定为非负整数。 |
| `SensorData` | 传感器数据，指定为传感器数据结构体数组。数组的前 `NumSensors` 个元素是实际检测。 |

每个 `SensorData` 结构体包含以下字段：

| 字段 | 描述 |
| --- | --- |
| `Time` | 测量时间，指定为非负标量。 |
| `SensorIndex` | 传感器的唯一标识符，指定为正整数。 |
| `Measurement` | 目标测量，指定为 *K*×*M* 矩阵。*K* 是每个测量的维度，*M* 是测量数量。每个测量定义了在矩形或球面坐标系中检测的位置方面。 |
| `MeasurementParameters` | 测量参数，指定为描述从粒子状态到测量的变换的结构体。有关设置此字段的详细信息，请参阅 `objectDetection` 对象的 `MeasurementParameter` 属性。 |
| `NumMeasurements` | 测量数量或点云传感器检测中的点数，指定为正整数。 |

**注意**

每个结构体的 `Time` 字段必须小于或等于模块当前调用时间。该时间还必须大于模块上一次调用中指定的更新时间。

### **Prediction Time** — 跟踪更新时间 实数标量

跟踪更新时间，指定为以秒为单位的实数标量。跟踪器将所有跟踪更新到此时间。更新时间必须在每次调用模块时增加，并且必须至少与指定给 **Sensor Data** 输入端口的最大的 `Time` 一样大。

如果未启用此端口，则由 Simulink 管理的仿真时钟确定更新时间。

#### 依赖关系

要启用此端口，请在 **端口设置** 选项卡中，将 **预测时间源** 参数设置为 `Input port`。

### **Sensor Configurations** — 跟踪传感器的配置 包含 MATLAB 结构体的 Simulink 总线

跟踪传感器的配置，指定为包含 MATLAB 结构体的 Simulink 总线。该结构体包含以下字段：

| 字段 | 描述 |
| --- | --- |
| `NumConfigurations` | 传感器配置的数量，指定为正整数。 |
| `Configurations` | 传感器配置，指定为传感器配置结构体数组。数组的前 `NumConfigurations` 个元素是实际配置。字段名称和定义必须分别对应于 `trackingSensorConfiguration` 对象属性的名称和值。即使您在结构体中指定了 `FilterInitializationFcn`、`SensorTransformFcn` 和 `MaxNumDetsPerObject` 字段，跟踪器也会忽略它们。如果在跟踪系统中使用 Radar Data Generator (Radar Toolbox) 模块，则可以直接使用 Radar Data Generator (Radar Toolbox) 模块的 **Configuration** 输出来指定此值。 |

#### 依赖关系

要启用此端口，请在 **跟踪器配置** 选项卡中，选择 **随时间更新传感器配置** 参数。

### **State Parameters** — 跟踪状态参数 包含 MATLAB 结构体的 Simulink 总线

跟踪状态参数，指定为包含 MATLAB 结构体的 Simulink 总线。模块将此结构体用作生成跟踪的 `StateParameters` 字段的值。您可以使用这些参数来定义模块报告跟踪时所采用的参考坐标系，以及生成跟踪的其他所需属性。

例如，您可以使用包含以下字段的结构体来定义矩形参考坐标系，其原点位置为 `[10 10 0]` 米，原点速度为 `[2 -2 0]` 米/秒，相对于场景坐标系。

| 字段名称 | 值 |
| --- | --- |
| `Frame` | `"Rectangular"` |
| `Position` | `[10 10 0]` |
| `Velocity` | `[2 -2 0]` |

#### 依赖关系

要启用此端口，请在 **跟踪器配置** 选项卡中，选择 **随时间更新跟踪状态参数** 参数。

### 输出

### **Confirmed Tracks** — 确认跟踪 包含 MATLAB 结构体的 Simulink 总线

更新到当前时间的确认跟踪，返回为包含 MATLAB 结构体的 Simulink 总线。该结构体包含以下字段：

| 字段 | 描述 |
| --- | --- |
| `NumTracks` | 跟踪数量。 |
| `Tracks` | 跟踪结构体数组，其长度由 **最大跟踪数** 参数设置。只有数组的前 `NumTracks` 个元素是实际跟踪。 |

跟踪结构体的字段如跟踪结构体一节所示。每个跟踪的状态形式遵循 **用于跟踪的运动模型** 参数中指定的形式。

### **Tentative Tracks** — 暂定跟踪 包含 MATLAB 结构体的 Simulink 总线

更新到当前时间的暂定跟踪，返回为包含 MATLAB 结构体的 Simulink 总线。跟踪在确认之前为暂定跟踪。

该结构体包含以下字段：

| 字段 | 描述 |
| --- | --- |
| `NumTracks` | 跟踪数量 |
| `Tracks` | 跟踪结构体数组，其长度由 **最大跟踪数** 参数设置。只有数组的前 `NumTracks` 个元素是实际跟踪。 |

跟踪结构体的字段如跟踪结构体一节所示。每个跟踪的状态形式遵循 **用于跟踪的运动模型** 参数中指定的形式。

#### 依赖关系

要启用此端口，请在 **端口设置** 选项卡中，选择 **启用暂定跟踪输出**。

### **All Tracks** — 确认和暂定跟踪 包含 MATLAB 结构体的 Simulink 总线

更新到当前时间的确认和暂定跟踪的组合列表，返回为包含 MATLAB 结构体的 Simulink 总线。

该结构体包含以下字段：

| 字段 | 描述 |
| --- | --- |
| `NumTracks` | 跟踪数量 |
| `Tracks` | 跟踪结构体数组，其长度由 **最大跟踪数** 参数设置。只有数组的前 `NumTracks` 个元素是实际跟踪。 |

跟踪结构体的字段如跟踪结构体一节所示。每个跟踪的状态形式遵循 **用于跟踪的运动模型** 参数中指定的形式。

#### 依赖关系

要启用此端口，请在 **端口设置** 选项卡中，选择 **启用所有跟踪输出**。

## 参数

#### 跟踪器配置

### **跟踪器标识符** — 唯一跟踪器标识符 `0`（默认）| 非负整数

将唯一跟踪器标识符指定为非负整数。此参数作为跟踪器输出中的 `SourceIndex` 传递，并区分多跟踪器系统中来自不同跟踪器的跟踪。您必须将此属性指定为正整数，才能将跟踪输出用作 Track-To-Track Fuser 模块的输入。

**示例：** `1`

### **最大跟踪数** — 最大跟踪数 `100`（默认）| 正整数

模块可以维护的最大跟踪数，指定为正整数。

### **最大传感器数** — 最大传感器数 `20`（默认）| 正整数

将可连接到跟踪器的最大传感器数指定为正整数。`MaxNumSensors` 必须大于或等于用于更新模块的所有传感器数据中 `SensorIndex` 的最大值。

**数据类型：** `single` | `double`

### **传感器配置** — 跟踪传感器的配置 `struct('SensorIndex',1,'IsValidTime',true,'SensorLimits',[-180 180; 0 100])`（默认）| 结构体 | 结构体数组

将跟踪传感器的配置指定为结构体或结构体数组。此参数向跟踪器提供跟踪传感器配置信息，例如传感器检测限制和传感器分辨率。您必须为每个结构体指定以下字段：

| 字段名称 | 格式 |
| --- | --- |
| `SensorIndex` | 传感器的唯一标识符，指定为正整数。 |
| `IsValidTime` | 指示是否应使用传感器数据来更新跟踪，指定为 `true` 或 `false`。 |
| `SensorTransformParameters` | 传感器变换函数的参数，指定为 *p* 元素测量参数结构体数组。*p* 是传感器数量。每个结构体应包含与测量函数（例如 `cvmeas` 函数）中使用的测量参数同名的字段。第一个结构体必须描述从自主系统到传感器坐标系的变换。后续结构体描述从自主系统到跟踪坐标系的变换。如果只提供一个结构体，跟踪器假定在自主系统的坐标系中执行跟踪。 |
| `SensorLimits` | 传感器检测限制，指定为 2×2 矩阵。第一行指定方位角的下限和上限（以度为单位）。第二行指定检测距离的下限和上限（以米为单位）。 |

每个结构体的其他允许字段名称对应于 `trackingSensorConfiguration` 对象的属性名称。即使您在结构体中指定了 `FilterInitializationFcn`、`SensorTransformFcn` 和 `MaxNumDetsPerObject` 字段，跟踪器也会忽略它们。

在选择 **随时间更新传感器配置** 参数后，您可以使用 **Sensor configurations** 输入端口更新配置。

### **随时间更新传感器配置** — 随时间更新传感器配置 `off`（默认）| `on`

选择此参数以启用 **Sensor Configurations** 输入端口。这使您能够在仿真期间更新跟踪传感器配置。

### **跟踪状态参数** — 跟踪状态参考坐标系的参数 结构体

将跟踪状态参考坐标系的参数指定为结构体。模块将此参数的值传递给生成跟踪的 `StateParameters` 字段。您可以使用这些参数来定义模块报告跟踪时所采用的参考坐标系，以及生成跟踪的其他所需属性。

例如，您可以使用包含以下字段的结构体来定义矩形参考坐标系，其原点位置为 `[10 10 0]` 米，原点速度为 `[2 -2 0]` 米/秒，相对于场景坐标系。

| 字段名称 | 值 |
| --- | --- |
| `Frame` | `"Rectangular"` |
| `Position` | `[10 10 0]` |
| `Velocity` | `[2 -2 0]` |

您可以通过选择 **随时间更新跟踪状态参数** 参数，使用 **State Parameters** 输入端口更新跟踪状态参数。

**数据类型：** `struct`

### **随时间更新跟踪状态参数** — 随时间更新跟踪状态参数 `off`（默认）| `on`

选择此参数以启用通过 **State Parameters** 输入端口输入跟踪状态参数的端口。

### **启用 GPU 计算** — 启用 GPU 计算 `off`（默认）| `on`

选择此参数以启用使用 GPU 估计动态网格图。启用 GPU 计算需要 Parallel Computing Toolbox™。

### **网格的 X 维度** — 网格的 X 维度 `100`（默认）| 正标量

将本地坐标中网格的 x 维度指定为正标量，以米为单位。

### **网格的 Y 维度** — 网格的 Y 维度 `100`（默认）| 正标量

将本地坐标中网格的 y 维度指定为正标量，以米为单位。

### **网格分辨率** — 网格分辨率 `1`（默认）| 正标量

将网格的分辨率指定为正标量。分辨率表示网格在 x 和 y 两个方向上每米的单元格数。

### **网格原点** — 网格原点 `[-50 -50]`（默认）| 正标量

将本地坐标系中网格的原点指定为二元素标量向量，以米为单位。

### **仿真使用** — 要运行的仿真类型 `Interpreted Execution`（默认）| `Code Generation`

从以下选项中选择要运行的仿真类型：

- `Interpreted execution` — 使用 MATLAB 解释器仿真模型。此选项可缩短启动时间。在 `Interpreted execution` 模式下，您可以调试模块的源代码。
- `Code generation` — 使用生成的 C 代码仿真模型。首次运行仿真时，Simulink 会为模块生成 C 代码。只要模型不更改，C 代码就会在后续仿真中重复使用。此选项需要额外的启动时间。

#### 粒子滤波

### **用于跟踪的运动模型** — 用于跟踪的运动模型 `constant-velocity`（默认）| `constant-acceleration` | `constant-turnrate`

选择用于跟踪的运动模型，可选值为 `constant-velocity`、`constant-acceleration` 或 `constant-turnrate`。

每种运动模型的粒子状态和目标状态为：

| 运动模型 | 粒子状态 | 目标状态 |
| --- | --- | --- |
| `constant-velocity` | `[x; vx; y; vy]` | `[x; vx; y; vy; yaw; L; W]` |
| `constant-acceleration` | `[x; vx; ax; y; vy; ay]` | `[x; vx; ax; y; vy; ay; yaw; L; W]` |
| `constant-turn-rate` | `[x; vx; y; vy; w]` | `[x; vx; y; vy; w; yaw; L; W]` |

其中：

- `x` — 目标在本地跟踪坐标系 x 方向上的位置 (m)
- `y` — 目标在本地跟踪坐标系 y 方向上的位置 (m)
- `vx` — 目标在本地跟踪坐标系 x 方向上的速度 (m/s)
- `vy` — 目标在本地跟踪坐标系 y 方向上的速度 (m/s)
- `ax` — 目标在本地跟踪坐标系 x 方向上的加速度 (m/s2)
- `ay` — 目标在本地跟踪坐标系 y 方向上的加速度 (m/s2)
- `w` — 目标在本地跟踪坐标系中的偏航角速率 (deg/s)
- `yaw` — 目标在本地跟踪坐标系中的偏航角 (deg)
- `L` — 目标长度 (m)
- `W` — 目标宽度 (m)

### **目标的最小和最大速度 (m/s)** — 目标的最小和最大速度 (m/s) `[-10 10; -10 10]`（默认）| 2×2 标量矩阵

将目标的最小和最大速度指定为 2×2 标量矩阵，以 m/s 为单位。第一行指定 x 方向的速度下限和上限，第二行指定 y 方向的速度下限和上限。跟踪器使用这些限制在网格中使用均匀分布采样新粒子。

### **启用加性过程噪声** — 启用加性过程噪声 `false`（默认）| `true`

选择此参数以将过程噪声建模为加性。选中后，过程噪声直接添加到状态向量。否则，噪声将包含在运动模型中。

### **过程噪声协方差矩阵** — 过程噪声协方差矩阵 `eye(2)`（默认值）| *N*×*N* 矩阵

将过程噪声协方差指定为 *N*×*N* 矩阵。此参数指定粒子位置和目标几何中心的过程噪声。

- 如果选择 **启用加性过程噪声** 参数，则过程噪声会直接添加到预测模型。在这种情况下，*N* 等于 **用于跟踪的运动模型** 参数中粒子状态的维度。
- 如果不选择 **启用加性过程噪声** 参数，则根据所选的运动模型定义过程噪声。该模型会将过程噪声添加到高阶项，例如 `constant-velocity` 模型的加速度。

  | `MotionModel` | 加速度的项数 | 项的含义 |
  | --- | --- | --- |
  | `constant-velocity` | `2` | x 和 y 方向上的加速度 |
  | `constant-acceleration` | `2` | x 和 y 方向上的加加速度 |
  | `constant-turn-rate` | `3` | x 和 y 方向上的加速度，以及角加速度 |

**示例：** `[1.0 0.05; 0.05 2]`

### **持续粒子数** — 持续粒子数 `1e5`（默认值）| 正整数

将每个网格的持续粒子数指定为正整数。粒子数越多，可以提高估计质量，但会增加计算成本。

### **每步新生粒子数** — 每步新生粒子数 `1e4`（默认值）| 正标量

将每时间步新生（初始化）粒子数指定为正整数。跟踪器通过使用预测的和更新的占用信念质量之间的不匹配以及 **每步单元出生概率** 参数来确定这些新生粒子的位置。此参数的合理值约为 **持续粒子数** 参数指定粒子数的 10%。

### **每步单元出生概率** — 每步单元出生概率 `0.01`（默认值）| 范围 `[0, 1)` 内的标量

将每步单元中目标出生的概率指定为范围 `[0, 1)` 内的标量。出生概率控制在一个单元中生成新粒子的概率。

**示例：** `1e-4`

### **单位时间内目标死亡率** — 单位时间内目标死亡率 `1e-3`（默认值）| 正标量

将单位时间内目标死亡率指定为正标量。死亡率表示粒子或目标在每个时间步后消失的可能性。死亡率 (*P*d) 会影响组件在连续时间步内的生存概率 (*P*s)，如下所示：

Ps=(1−Pd)ΔT

其中 *Δ**T* 是时间步数。

**示例：** `1e-4`

### **自由空间预测置信度** — 自由空间预测置信度 `0.8`（默认值）| 标量

将自由空间预测置信度指定为标量。在跟踪器的预测阶段，此参数按如下方式降低单元处于“free”（未占用）状态的信念质量：

mk|k−1(F)=αΔTmk−1(F)

其中 *k* 是时间步索引，*m* 是信念质量，*α* 是表示自由空间预测置信度的因子，*Δ**T* 是时间步。

### **随机数生成** — 随机数种子生成方法 `Repeatable`（默认值）| `Not repeatable` | `Specify seed`

将随机数种子生成方法选择为 `Repeatable`、`Not repeatable` 或 `Specify seed`。

- `Repeatable` — 该模块每次使用相同的随机种子。
- `Not repeatable` — 该模块每次使用不同的随机种子。
- `Specify seed` — 使用 **初始种子** 参数为该模块指定随机种子。

### **初始种子** — 用于随机化的初始种子 `0`（默认值）| 非负整数

将该模块中用于随机化的初始种子指定为非负整数。

#### 依赖关系

要启用此参数，请将 **随机数生成** 参数选择为 `Specify seed`。

#### 航迹管理

### **新目标提取的聚类方法** — 新目标提取的聚类方法 `DBSCAN`（默认值）| `Custom`

将用于新目标提取的聚类方法指定为 `DBSCAN` 或 `Custom`。

- `DBSCAN` — 使用基于密度的带噪声应用空间聚类 (DBSCAN) 算法对未分配的动态网格单元进行聚类。您可以通过指定 **DBSCAN 聚类阈值** 和 **DBSCAN 每个簇的最小单元数** 参数来配置 DBSCAN 算法。
- `Custom` — 使用在 **'Custom' 聚类函数名称** 参数中指定的自定义聚类函数对未分配的动态网格单元进行聚类。

### **DBSCAN 聚类阈值** — DBSCAN 聚类阈值 `5`（默认值）| 正标量

将 DBSCAN 聚类阈值指定为正标量。

#### 依赖关系

要启用此参数，请将 **新目标提取的聚类方法** 参数选择为 `DBSCAN`。

### **DBSCAN 每个簇的最小单元数** — DBSCAN 每个簇的最小单元数 `2`（默认值）| 正整数

将 DBSCAN 每个簇的最小单元数指定为正整数。此参数会影响一个点是否为 DBSCAN 算法中的核心点。

#### 依赖关系

要启用此参数，请将 **新目标提取的聚类方法** 参数选择为 `DBSCAN`。

### **'Custom' 聚类函数名称** — 自定义聚类函数的名称，函数名称

将用于对未分配网格单元进行聚类的自定义函数名称指定为函数名称。该函数必须支持以下签名：


### **用于更新现有航迹的函数** — 用于更新现有航迹的函数 `trackerGridRFS.defaultTrackUpdate`（默认值）| 函数名称

### **用于将动态网格单元分配给航迹的阈值** — 用于将动态网格单元分配给航迹的阈值 `30`（默认值）| 正标量

将用于将动态网格单元分配给航迹的阈值指定为正标量。仅当动态网格单元到航迹的距离（由负对数似然表示）小于此参数的值时，该动态网格单元才能关联到该航迹。

- 如果某个动态单元未被分配给应分配给它的航迹，则增大该阈值。
- 如果某些动态单元被分配到了不应分配给它们的航迹，则减小该阈值。

**示例：** `18.1`

### **确认阈值 [M N]** — 航迹确认阈值 `[2 3]`（默认值）| 1×2 正整数向量

将航迹确认阈值指定为 1×2 正整数向量 `[M N]`。如果一条航迹在最近 `N` 次更新中的至少 `M` 次更新中被分配到动态网格单元，则该航迹被确认。

### **删除阈值 [P Q]** — 航迹删除阈值 `[5 5]`（默认值）| 1×2 正整数向量

将航迹删除阈值指定为 1×2 正整数向量 `[P Q]`。如果一条航迹在最近 `Q` 次更新中的至少 `P` 次更新中未被分配到任何动态网格单元，则该航迹被删除。

**示例：** `0.01`

## 描述

基于网格的多目标跟踪器，使用随机有限集方法

Grid-Based Multi Object Tracker 是一种跟踪器，能够在二维环境中处理来自多个传感器的多目标检测。该跟踪器使用高分辨率传感器数据（如点云和雷达检测）跟踪自主系统周围的动态目标。该跟踪器使用基于随机有限集 (RFS) 的方法，并结合 Dempster-Shafer 近似 [1]，来估计网格单元的动态特性。为了从网格中提取目标，该跟踪器使用单元到航迹关联方案 [2]。有关更多详细信息，请参阅 Algorithms。
