# Frequency Output

## 端口

### 输入

### **Frequency** — 输出波形的频率（可选）向量

波形发生器的频率设置。输入值的数据类型和范围取决于板卡的能力。

#### 依赖关系

当您将 **输出信号频率源** 设置为 `external` 时，此端口可见。

**数据类型：** `single` | `double` | `int8` | `uint8` | `int16` | `uint16` | `int32` | `uint32`

### **Duty Cycle** — 输出波形的占空比（可选）向量

波形发生器的占空比设置。输入值的数据类型和范围取决于板卡的能力。

#### 依赖关系

当您将 **输出信号占空比源** 设置为 `external` 时，此端口可见。

**数据类型：** `single` | `double` | `int8` | `uint8` | `int16` | `uint16` | `int32` | `uint32`

### 输出

### **Missed Ticks** — 错过的节拍计数（可选）double

在 **Connected IO** 模式下，返回模型落后实时内核的定时器节拍数。当模型落后超过 **最大错过节拍数** 时，软件会报告错误并停止仿真。

#### 依赖关系

当您选中 **显示 “Missed Ticks” 端口** 时，此端口可见。

**数据类型：** `double`

### **最大错过节拍数** — 模型可以落后内核的定时器节拍数 `10` (default) | integer

在 **Connected IO** 模式下，输入您的模型可以落后实时内核的定时器节拍数。当模型落后此数量或更少的定时器节拍时，软件假定该滞后是临时的。它允许模型追赶，即使模型错过了一些节拍。当模型落后超过此数量时，软件会报告错误并停止仿真。

在 **Run in Kernel** 模式下，软件忽略此值。

### **输出信号频率源** — 指定输出频率 (Hz) 的来源 `external` (default) | `internal`

选择指定要输出的频率（以 Hz 为单位）的来源。**输出信号频率源** 可以是以下之一：

- `internal` — 名为 **频率** 的可调参数指定频率。
- `external` (default) — 信号指定频率。输入端口 `Frequency` 出现在模块上以接受该信号。

  您可以为 **频率初始值** 和 **频率最终值** 指定附加设置。

#### 依赖关系

如果指定 `external`（默认值），则端口 `Frequency` 以及参数 **频率初始值** 和 **频率最终值** 可见。

如果指定 `internal`，**频率** 将替换 **频率初始值**，并且 **频率最终值** 被禁用。

|  |
| --- |
| **模块参数：** `FrequencySource` |

### **频率初始值** — 指定板卡在执行开始前生成的频率 标量

可选择指定初始频率，单位为 hertz。当您连接到目标机时，指定的频率生效。它会一直持续到仿真开始，此时频率信号的值生效。您可以使用此参数指定初始条件，并让它们有时间稳定。如果未出现值，则连接到目标机不会影响频率。

### **输出信号占空比源** — 指定输出信号占空比的来源 `internal` (default) | `external`

- `external` — 信号指定占空比。输入端口 `Duty Cycle` 出现在模块上以接受该信号。

### **占空比** — 指定输出信号为高电平的时间 `0.5` (default) | `0–1`

将占空比指定为从 `0` 到 `1`（含）的小数。它决定输出信号值为高电平 (`1`) 的时间量。例如，占空比 `0.7` 指定输出在 70% 的时间内为高电平，在 30% 的时间内为低电平。

两个占空比值具有特殊意义：

- `0` — 无论当前生效的频率设置如何，输出信号持续为低电平 (`0`)。
- `1` — 无论当前生效的频率设置如何，输出信号持续为高电平 (`1`)。

#### 依赖关系

要使此参数可见，请将 **输出信号占空比源** 设置为 `internal`。

#### 编程用法

|  |
| --- |
| **模块参数：** `Duty` |

### **占空比初始值** — 指定板卡在执行开始前的占空比 `0–1`

可选择指定初始占空比。当您连接到目标机时，指定的占空比生效。它会一直持续到仿真开始。如果未出现值，则连接到目标机不会影响占空比。您可以指定任何占空比。通常 **占空比初始值** 为 `0` 或 `1`，以强制初始输出信号持续为低电平或高电平。指定 `0` 或 `1` 会覆盖任何 **频率初始值** 设置。

#### 依赖关系

要使此参数可见，请将 **输出信号占空比源** 设置为 `external`。

#### 编程用法

|  |
| --- |
| **模块参数：** `Duty` |

### **占空比最终值** — 指定板卡在执行结束后的占空比 `0–1`

可选择指定最终占空比。当仿真完成时，指定的占空比生效并无限期持续。从目标机断开连接不会改变该占空比。如果未出现值，则仿真结束时生效的占空比将在之后无限期持续。您可以指定任何占空比。通常 **占空比最终值** 为 `0` 或 `1`，以强制初始输出信号持续为低电平或高电平。指定 `0` 或 `1` 会覆盖任何 **频率最终值** 设置。

#### 依赖关系

要使此参数可见，请将 **输出信号占空比源** 设置为 `external`。

## 描述

写入一个或多个频率或 PWM 输出通道

Frequency Output 模块生成脉宽调制方波并将其输出到模拟输出。

该方波在低电平 (`0`) 和高电平 (`1`) 之间以指定的频率和占空比交替。

您以 hertz (Hz) 为单位指定频率。

您将占空比指定为从 `0` 到 `1`（含）的小数。占空比决定输出信号值为高电平 (`1`) 的时间量。

将 Frequency Output 模块添加到模型后，双击 Frequency Output 模块以打开 模块参数：Frequency Output 对话框。
