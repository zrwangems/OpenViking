# Analog Input

## 端口

### 输出

### **Analog Data** — 从输入通道向量读取的模数转换器数据

模拟信号的 A/D 转换结果。输出值的数据类型和范围取决于板卡的能力。

**数据类型：** `double` | `single` | `int8` | `uint8` | `int16` | `uint16` | `int32` | `uint32`

### **Missed Ticks** — 遗漏节拍计数（可选）double

在 **Connected IO** 模式下，返回模型滞后实时内核的定时器节拍数。当模型滞后超过 **最大遗漏节拍** 时，软件会报告错误并停止仿真。

#### 依赖关系

当你选择 **显示 “Missed Ticks” 端口** 时，此端口可见。

**数据类型：** `double`

## 参数

### **安装新板卡** — 注册板卡 `< no board selected >`（默认）

当你点击 **安装新板卡** 时，软件会显示支持的板卡制造商列表。当你选择某个制造商时，软件会显示该制造商提供的板卡列表。当你选择某个板卡时，软件会将该板卡添加到已注册板卡列表中，并使该板卡成为当前板卡。

默认情况下，已注册板卡列表中的初始选择为 `< no board selected >`。

有关 I/O 板卡驱动支持的详细信息，请参阅 Simulink Desktop Real-Time 的硬件支持。

#### 依赖关系

当你在已注册板卡列表中选择某个板卡时，**删除当前板卡** 和 **板卡设置** 按钮可用。

### **采样时间** — 模块的采样时间 `0.1`（默认）| double

输入一个以秒为单位的值，表示你希望模块执行并与 I/O 硬件交互的频率。模块会按此采样率将模型与实时时钟同步。

如果使用固定步长求解器，请输入你在 **固定步长** 配置参数中输入的值，或该值的整数倍。

#### 编程用法

|  |
| --- |
| **模块参数：** `SampleTime` |

### **最大遗漏节拍** — 模型可滞后内核的定时器节拍数 `10`（默认）| integer

在 **Connected IO** 模式下，输入模型可滞后实时内核的定时器节拍数。当模型滞后此数量或更少的定时器节拍时，软件假定这种滞后是临时的。即使模型遗漏了一些节拍，软件也允许模型赶上。当模型滞后超过此数量时，软件会报告错误并停止仿真。

在 **Run in Kernel** 模式下，软件会忽略此值。

#### 编程用法

|  |
| --- |
| **模块参数：** `MaxMissedTicks` |

### **输入通道** — 选择模拟输入通道 `1`（默认）| vector

输入一个通道向量，用于选择你在此板卡上使用的模拟输入通道。该向量可以是任何有效的 MATLAB® 向量形式。例如，要选择八个连续的模拟输入通道，请输入：

```
[1,2,3,4,5,6,7,8]
```

或

```
[1:8]
```

要选择前三个模拟输入通道，请输入：

```
[1,2,3]
```

#### 编程用法

|  |
| --- |
| **模块参数：** `Channels` |

### **输入范围** — 模拟输入的输入范围，取决于板卡

从列表中，为你在 **输入通道** 参数中输入的模拟输入通道选择输入范围。例如，如果板卡的输入范围为 `±5 V`，请选择 `-5 to 5 V`。

如果你希望为不同的模拟通道设置不同的输入范围，请为每个不同的输入范围添加一个 I/O 模块。有效值取决于板卡的能力。

#### 编程用法

|  |
| --- |
| **模块参数：** `VoltRange` |

### **模块输出信号** — 模块返回的值类型 `Volts`（默认）| `Normalized bipolar` | `Normalized unipolar` | `Raw`

从列表中，选择以下选项之一：

- `Volts` — 返回等于模拟电压的值。
- `Normalized bipolar` — 无论输入电压范围如何，返回 -`1` 到 `+1` 的满量程值。
- `Normalized unipolar` — 无论输入电压范围如何，返回 `0` 到 `+1` 的满量程值。例如，`0` 伏到 `+5` 伏以及 `−5` 伏到 `+5` 伏的模拟输入范围都会转换为 `0` 到 `+1`。
- `Raw` — 返回 `0` 到 `2n -1` 的值。例如，12 位 A/D 转换器返回 `0` 到 `212 -1`（`0` 到 `4095`）的值。此方法的优势是返回值是整数，没有舍入误差。

#### 编程用法

|  |
| --- |
| **模块参数：** `RangeMode` |

## 描述

从一个或多个模拟输入通道读取

Analog Input 模块会连接并从你的 Simulink® 模型中的特定模拟输入通道读取。将 Analog Input 模块添加到模型后，可以为其 I/O 驱动输入参数。
