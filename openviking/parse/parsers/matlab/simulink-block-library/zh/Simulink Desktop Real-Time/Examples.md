# Simulink Desktop Real-Time

Simulink®
Desktop Real-Time™ provides a real-time kernel for Windows®, Linux®, and macOS. It includes drag-and-drop Simulink I/O driver blocks that enable closed-loop control of physical systems from
your desktop computer. The toolbox lets you connect to sensors, actuators, and other devices
to prototype and test control systems without requiring dedicated real-time test
equipment.

Simulink
Desktop Real-Time supports I/O devices such as DAQ boards, CAN devices, and USB webcams.
