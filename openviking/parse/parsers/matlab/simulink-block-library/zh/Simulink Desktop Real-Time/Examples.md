Simulink®
Desktop Real-Time™ 为 Windows®、Linux® 和 macOS 提供实时内核。它包含拖放式 Simulink I/O 驱动模块，可从桌面计算机对物理系统进行闭环控制。该工具箱允许您连接传感器、执行器和其他设备，无需专用实时测试设备即可对控制系统进行原型设计和测试。

Simulink
Desktop Real-Time 支持 DAQ 板、CAN 设备和 USB 网络摄像头等 I/O 设备。
