# Drive Cycle Source

## 端口

### 输入

### **VelFdbk** — 车辆纵向速度 `scalar`

纵向车辆速度。

#### 依赖项

要启用此端口，在**故障跟踪**选项卡上，选择 **启用故障跟踪**。将 **速度反馈单位, inUnit** 参数设置为 `VelFdbk` 输入端口信号单位。

### 输出

### **Info** — 总线信号 bus

包含这些模块计算的总线信号。

| 信号 | | 描述 |
| --- | --- | --- |
| `Reference Speed` | | 车辆参考速度 |
| `Reference Accel` | | 车辆参考加速度 |
| `Gear` | | 车辆挡位 |
| `Fault` | `UpprBnd` | 允许车辆速度范围的上限。 |
| `LowerBnd` | 允许车辆速度范围的下限。 |
| `Fault` | 表示故障条件的布尔值：  - 1 — 故障 - 0 — 无故障    如果车辆速度不在允许速度范围内，模块会设置故障条件。 |
| `FaultCnt` | 故障数。 |
| `CumFaultTime` | 处于故障条件的累计时间。 |
| `SnglFaultTime` | 单次故障所花费的时间。 |
| `Fail` | 表示故障失败的布尔值：  - 1 — 失败 - 0 — 无失败    如果故障条件超过最大故障次数、最大单次故障时间或最大总故障时间，模块会设置故障失败。 |

#### 依赖项

要启用此端口，在**故障跟踪**选项卡上，选择 **启用故障跟踪**。

### **RefSpd** — 车辆参考速度 `scalar`

车辆参考速度，单位由您指定。要指定单位，请使用 **输出速度单位** 参数。

### **RefAcc** — 车辆参考加速度 `scalar`

要计算加速度，模块使用具有三个样本点滤波器的二阶多项式实现 Savitzky-Golay 微分。

#### 依赖项

要创建输出加速度端口，请选择 **输出加速度**。选择 **输出加速度** 会启用 **输出加速度单位** 参数。

### **Gear** — 车辆挡位 `scalar`

#### 依赖项

要启用此端口：

1. 首先指定包含换挡计划的行驶循环。您可以使用：

   - 支持包来安装包含换挡计划的标准行驶循环，例如 `JC08` 和 `CUEDC`。
   - 工作区变量。
   - .`mat`、.`xls`、.`xlsx` 或 .`txt` 文件。
2. 选择 **输出换挡数据**。

## 参数

### 循环设置

#### 设置

### **驱动循环源** — 选择驱动循环源 `FTP75` (default) | `Wide Open Throttle (WOT)` | `Workspace variable` | `.mat, .xls, .xlsx or .txt file`

- `FTP75` — 从 .`mat` 文件将 FTP75 行驶循环加载到一维 Lookup Table 模块中。FTP75 表示一个城市行驶循环，您可以用它来确定乘用车的尾气排放和燃油经济性。

  要安装支持包中的其他行驶循环，请参阅 Support Package for Maneuver and Drive Cycle Data。
- `Wide Open Throttle (WOT)` — 使用 WOT 参数指定用于性能测试的行驶循环。
- `Workspace variable` — 将时间、速度以及可选的挡位数据指定为结构体、二维数组或时间序列对象。
- `.mat, .xls, .xlsx or .txt file` — 指定一个文件，其中包含按列格式排列的时间、速度以及可选的挡位数据。

安装其他循环后，您可以使用 `set_param` 设置行驶循环。例如，要使用行驶循环 `US06`：

```
set_param([gcs '/Drive Cycle Source'],'cycleVar','US06')
```

### **从工作区** — 工作区 `variable`

包含单调递增时间向量、速度向量以及可选的挡位数据向量的工作区变量。您可以使用结构体、二维数组或时间序列对象。在 **源速度单位** 参数字段中输入速度单位。

每个对应时间值都必须存在有效点。不能指定 `inf`、`empty` 或 `NaN`。

此表提供了使用工作区变量创建您自己的行驶循环的示例。

| 工作区变量 | 源速度单位 | 输出速度单位 | 行驶循环图 |
| --- | --- | --- | --- |
| 不带换挡计划的结构体，**从工作区** 设置为 `myCycleS`。  ``` t = 0:1:100; xdot = 5.*sin(t)+10; myCycleS.time = t'; myCycleS.signals.values = xdot'; ``` | `m/s` | `mph` | 显示正弦波的速度-时间图 |
| 带换挡计划的结构体，**从工作区** 设置为 `myCycleS`。  ``` gears=[0, 1, 2, 3, 3, 4, 4, 4, 4, 4, 4]; t=0:1:10; xdot=[0,5,10,15,20,25,30,30,30,30,30]; myCycleS.time=t'; myCycleS.signals.values=[xdot',gears']; ``` | `m/s` | `mph` | 显示速度在 0 秒时从 0 mph 线性增加到 6 秒时 70 mph 的速度-时间图。6 秒后，速度保持在 70 mph 不变。 |
| 不带换挡计划的二维数组，**从工作区** 设置为 `myCycleA`。  ``` t = 0:1:100; xdot = 5.*sin(t)+5; myCycleA = [t',xdot']; ``` | `m/s` | `mph` | 显示正弦波的速度-时间图 |
| 带换挡计划的二维数组，**从工作区** 设置为 `myCycleA`。  ``` gears=[0, 1, 2, 3, 4, 4, 4, 5, 5, 5, 5]; t=0:1:10; xdot=[0,5,10,15,20,25,30,40,50,60,60]; myCycleA=[t',xdot',gears']; ``` | `mph` | `mph` | 显示速度线性增加的速度-时间图：从 0 秒时 0 mph 到 6 秒时 30 mph，再到 9 秒时 60 mph。9 秒后，速度保持在 60 mph 不变。 |
| 不带换挡计划的时间序列对象，**从工作区** 设置为 `myCycleT`。  ``` myCycleT = timeseries; t = 0:1:100; xdot = 5.*sin(t)+20; myCycleT.Data = xdot'; myCycleT.Time = t'; ``` | `m/s` | `mph` | 显示正弦波的速度-时间图 |
| 不带换挡计划的时间序列对象，**从工作区** 设置为 `myCycleT`。  ``` myCycleT = timeseries; gears=[0, 1, 2, 3, 4, 4, 4, 5, 5, 5, 5]; t=0:1:10; xdot=[0,10,20,30,32,33,34,40,50,60,60]; myCycleT.Data = [xdot',gears']; myCycleT.Time = t'; ``` | `mph` | `mph` | 显示以 mph 为单位线性增加的速度-时间图。9 秒后，速度保持在 60 mph 不变。 |

#### 依赖项

要启用此参数，请从 **驱动循环源** 中选择 `Workspace variable`。

### **行驶循环源文件** — 文件名 `.mat, .xls, .xlsx or .txt`

包含单调递增时间数据、速度数据以及可选的按列或逗号分隔格式的挡位数据的文件。模块忽略文件中的单位。在 **源速度单位** 参数字段中输入源速度单位。

| 文件 | 源速度单位 | 输出速度单位 | 行驶循环图 |
| --- | --- | --- | --- |
| 一个 .`mat` 文件，包含与文件名同名的矩阵。该矩阵第 1 列包含时间，第 2 列包含速度。它可选地在第 3 列包含挡位选择。  ``` sampcyc =           0         0     0.5000    0.7000     1.0000    2.0000      1.5000    3.6000     2.0000    5.6000     2.5000    7.9000      3.0000   10.3000     3.5000   13.0000      4.0000   16.0000     4.5000   19.0000     5.0000   22.3000     5.5000   25.7000     6.0000   29.3000 ``` | `m/s` | `m/s` | 速度-时间图 |
| 一个 .`xls` 或 .`xlsx` 文件，A 列包含时间，B 列包含速度。11 行，A 列包含时间，B 列包含速度 | `mph` | `mph` | 速度-时间图 |
| 一个 .`xls` 或 .`xlsx` 文件，A 列包含时间，B 列包含速度，C 列包含挡位。模块： - 忽略文件中的表头和单位。 - 将挡位信息转换为整数： - N 到 0 - D 到 2 12 行，A 列包含以 sec 为单位的时间，B 列包含以 mph 为单位的速度，C 列包含挡位 | `mph` | `mph` | 速度-时间图 |
| 一个 .`txt`，第 1 列包含时间，第 2 列包含速度。模块忽略表头和单位信息。20 行，A 列包含以 sec 为单位的时间，B 列包含以 mph 为单位的速度 | `mph` | `mph` | 速度-时间图 |

您可以从外部源导入标准行驶循环文件。例如，您可以按照 WTMC 上的说明导入全球统一摩托车排放认证和测试规程 (WMTC) 循环。具体来说：

1. 下载换挡表和说明。
2. 按照说明根据您的输入计算换挡数据。
3. 速度单位是 `km/hr`。使用换算系数 1000/3600 将速度转换为 `m/s`。
4. 将数据复制并保存到新的 .`xls` 或 .`xlsx` 文件中，用作源文件。

如果您使用 **P**、**R**、**N**、**D**、**L**、**OD** 提供挡位计划，模块会将挡位映射为整数。

| 挡位 | 整数 |
| --- | --- |
| P | `80` |
| R | `-1` |
| N | `0` |
| L | `1` |
| D | `2` |
| OD | 最高指定挡位之后的下一个整数。 |

例如，模块将挡位计划 `P P N L D 3 4 5 6 5 4 5 6 7 OD 7` 转换为 `80 80 0 1 2 3 4 5 6 5 4 5 6 7 8 7`。

### **启用故障跟踪** — 启用故障跟踪 `off` (default) | `on`

### **速度容差, velBnd** — 行驶循环速度容差 `2.0` (default) | `scalar`

标准化测试指定要使用的速度容差。以下是两个示例：

- EPA 测功机行驶日程 — `2.0`
- WLTP 测试 — `2.0`

## 描述

标准或指定的纵向行驶循环

Drive Cycle Source 模块生成标准或用户指定的纵向行驶循环。模块输出是作为时间函数的车辆纵向参考速度，以及适用的换挡计划。您可以使用该行驶循环来：

- 预测车辆在给定换挡计划下跟随指定速度曲线所需的发动机扭矩和燃油消耗。
- 为车辆控制和被控对象模型的闭环加速和制动命令生成真实的速度和换挡计划。
- 研究、调整和优化车辆控制、系统性能以及系统在覆盖多个行驶循环时的鲁棒性。
- 识别超出标准化测试规定容差的故障。这些测试包括：

  - EPA 测功机行驶日程1
  - 全球统一轻型车辆测试程序 (WLTP) 实验室测试2

要生成行驶循环，您可以使用：

- 来自预定义来源的行驶循环。模块默认包含 `FTP–75` 行驶循环，并可从支持包加载其他循环。

  要从支持包安装其他行驶循环，请参阅 Support Package for Maneuver and Drive Cycle Data。某些行驶循环包括换挡计划，例如 `JC08` 和 `CUEDC`。
- 定义您自己的行驶循环的工作区变量。
- .`mat`、.`xls`、.`xlsx` 或 .`txt` 文件。这允许您加载其他标准行驶循环，或您已构建的循环。
- 节气门全开 (WOT) 参数。设置初始参考速度和标称参考速度，以产生参考速度的突然大幅变化，从而在车辆中引发 WOT 条件。

要实现此表中列出的目标，请使用指定的 Drive Cycle Source 模块参数选项。

| 目标 | 操作 |
| --- | --- |

### 故障和失效跟踪

在 **故障跟踪** 选项卡上，使用参数指定故障容差。如果车辆速度在给定参考时间处不在允许范围内，模块将设置故障条件。此处显示 EPA 和 WLTP 循环的示例：

| 参数 | 描述 | 设置 | |
| --- | --- | --- | --- |
| EPA Standard1 | WLTP Tests2 |
| **速度容差** | 在时间容差内，高于行驶循环速度轨迹最高点和低于最低点的速度容差。 | 2.0 mph | 2.0 km/h |
| **时间容差** | 模块用来确定允许速度范围的时间。 | 1.0 s | 1.0 s |
| **最大故障数** | 在行驶循环期间允许的最大故障数，且不会导致故障失效。 | *未指定* | 10 |
| **最大单次故障时间** | 允许的最大故障持续时间，且不会导致故障失效。 | 2.0 s | 1.0 s |
| **最大总故障时间** | 在故障条件下允许的最大累计时间，且不会导致故障失效。 | *未指定* | *未指定* |

模块使用时间容差来确定参考时间处的允许速度范围。在由参考时间 +/- 时间容差定义的时间跨度内，车辆速度必须处于参考速度范围 +/- 速度容差内，否则模块将设置故障条件。这些图说明了模块如何使用速度和时间容差来确定允许速度范围。
