**配置**

### **控制类型, cntrlType** — 纵向控制 `PI`（默认）| `Scheduled PI` | `Predictive`

纵向控制类型。

| 设置 | 模块实现 |
| --- | --- |
| `PI` | 带跟踪积分饱和和前馈增益的比例积分（PI）控制。 |
| `Scheduled PI` | 带跟踪积分饱和和前馈增益的 PI 控制，这些增益是车辆速度的函数。 |
| `Predictive` | 由 C. C. MacAdam1, 2, 3 开发的最优单点预瞄（前瞻）控制模型。该模型表示驾驶员在路径跟随和障碍物避让操作期间的转向控制行为。驾驶员预瞄（前瞻）以跟随预定义路径。为实现 MacAdam 模型，模块：  - 将动力学表示为线性单轨（自行车）车辆 - 在时间上提前 *T\** 秒的单点处最小化预瞄误差信号 - 考虑由感知和神经肌肉机制引起的驾驶员滞后 |

### **换挡类型, shftType** — 换挡类型 `None`（默认）| `Reverse, Neutral, Drive` | `Scheduled` | `External`

换挡类型。

| 设置 | 模块实现 |
| --- | --- |
| `None` | 无变速器。模块输出恒定挡位 1。使用此设置可最大程度减少生成加速和制动命令以跟踪前向车辆运动所需的参数数量。此设置不允许车辆反向运动。 |
| `Reverse, Neutral, Drive` | 模块使用 Stateflow 图对 Reverse、Neutral 和 Drive 挡换挡调度建模。使用此设置，通过简单的 Reverse、Neutral 和 Drive 挡换挡调度生成加速和制动命令，以跟踪前向和反向车辆运动。根据车辆状态和车辆速度反馈，模块使用初始挡位和换挡所需时间将车辆升挡至 Drive 或降挡至 Reverse 或 Neutral。对于 Neutral 挡，模块使用制动命令控制车辆速度。对于 Reverse 挡，模块使用加速命令生成扭矩，并使用制动命令降低车辆速度。 |
| `Scheduled` | 模块使用 Stateflow 图对 Reverse、Neutral、Park 和 N 速挡换挡调度建模。使用此设置，通过 Reverse、Neutral、Park 和 N 速挡换挡调度生成加速和制动命令，以跟踪前向和反向车辆运动。根据车辆状态和车辆速度反馈，模块使用这些参数确定：  - 初始挡位 - 升挡和降挡加速踏板位置 - 升挡和降挡速度 - 从 Neutral 换挡并接合前进挡和倒挡的时机  对于 Neutral 挡，模块使用制动命令控制车辆速度。对于 Reverse 挡，模块使用加速命令生成扭矩，并使用制动命令降低车辆速度。 |
| `External` | 模块使用输入挡位、车辆状态和速度反馈生成加速和制动命令，以跟踪前向和反向车辆运动。对于 Neutral 挡，模块使用制动命令控制车辆速度。对于 Reverse 挡，模块使用加速命令生成扭矩，并使用制动命令降低车辆速度。 |

### **参考和反馈单位, velUnits** — 速度单位 m/s（默认）

车辆速度参考和反馈单位。

#### 依赖项

如果将 **控制类型, cntrlType** 控制类型设置为 `Scheduled` 或 `Scheduled PI`，模块将 **参考和反馈单位, velUnits** 用于 **标称速度, vnom** 参数维度。

如果将 **换挡类型, shftType** 设置为 `Scheduled`，模块将 **纵向速度单位, velUnits** 用于这些参数维度：

- **升挡速度数据表, upShftTbl**
- **降挡速度数据表, dwnShftTbl**

## 描述

纵向速度跟踪控制器

Longitudinal Driver 模块实现纵向速度跟踪控制器。基于参考速度和反馈速度，该模块生成归一化加速和制动命令，其值可在 0 到 1 之间变化。您可以使用该模块来对驾驶员的动态响应建模，或生成跟踪纵向行驶循环所需的命令。

### 配置

使用 **外部动作** 参数创建输入端口，用于可禁用、保持或覆盖闭环加速或减速命令的信号。模块对输入命令使用以下优先级顺序：禁用（最高）、保持、覆盖。

**控制器**

使用 **控制类型, cntrlType** 参数指定以下控制选项之一。

| 设置 | 模块实现 |
| --- | --- |
| `PI` | 带跟踪抗积分饱和和前馈增益的比例积分（PI）控制。 |
| `Scheduled PI` | 带跟踪抗积分饱和和前馈增益的 PI 控制，这些增益是车辆速度的函数。 |
| `Predictive` | 由 C. C. MacAdam1, 2, 3 开发的最优单点预瞄（前视）控制模型。该模型表示路径跟随和避障操作期间的驾驶员转向控制行为。驾驶员通过预瞄（前视）来跟随预定义路径。为实现 MacAdam 模型，模块：  - 将动力学表示为线性单轨（自行车）车辆 - 最小化时间上前方 *T\** 秒处单点的预瞄误差信号 - 考虑由感知和神经肌肉机制导致的驾驶员滞后 |

**换挡**

使用 **换挡类型, shftType** 参数指定以下换挡选项之一。

| 设置 | 模块实现 |
| --- | --- |
| `None` | 无变速器。模块输出恒定的挡位 1。使用此设置可最小化跟踪车辆前进运动所需的生成加速和制动命令的参数数量。此设置不允许车辆倒车运动。 |
| `Reverse, Neutral, Drive` | 模块使用 Stateflow® 图对倒挡、空挡和前进挡换挡调度进行建模。使用此设置可通过简单的倒挡、空挡和前进挡换挡调度生成加速和制动命令，以跟踪车辆前进和倒车运动。根据车辆状态和车辆速度反馈，模块使用初始挡位和换挡所需时间将车辆升挡至前进挡，或降挡至倒挡或空挡。对于空挡，模块使用制动命令控制车辆速度。对于倒挡，模块使用加速命令生成扭矩，并使用制动命令降低车辆速度。 |
| `Scheduled` | 模块使用 Stateflow 图对倒挡、空挡、驻车挡和 N 速挡换挡调度进行建模。使用此设置可通过倒挡、空挡、驻车挡和 N 速挡换挡调度生成加速和制动命令，以跟踪车辆前进和倒车运动。根据车辆状态和车辆速度反馈，模块使用这些参数来确定：  - 初始挡位 - 升挡和降挡加速踏板位置 - 升挡和降挡速度 - 从空挡换挡和接合前进挡与倒挡的时机    对于空挡，模块使用制动命令控制车辆速度。对于倒挡，模块使用加速命令生成扭矩，并使用制动命令降低车辆速度。 |
| `External` | 模块使用输入挡位、车辆状态和速度反馈生成加速和制动命令，以跟踪车辆前进和倒车运动。对于空挡，模块使用制动命令控制车辆速度。对于倒挡，模块使用加速命令生成扭矩，并使用制动命令降低车辆速度。 |

### 控制器：预测速度跟踪

如果将 **控制类型, cntrlType** 参数设置为 `Predictive`，则模块实现由 C. C. MacAdam1, 2, 3 开发的最优单点预瞄（前视）控制模型。该模型表示路径跟随和避障操作期间的驾驶员转向控制行为。驾驶员通过预瞄（前视）来跟随预定义路径。为实现 MacAdam 模型，模块：

- 将动力学表示为线性单轨（自行车）车辆
- 最小化时间上前方 T\* 秒处单点的预瞄误差信号
- 考虑由感知和神经肌肉机制导致的驾驶员滞后

**驾驶员滞后**
