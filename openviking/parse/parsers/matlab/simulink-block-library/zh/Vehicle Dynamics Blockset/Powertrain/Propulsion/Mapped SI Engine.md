## 参数

#### 模块选项

### **包括涡轮增压器迟滞效应** — 增加时间常数 `off` (默认) | `on`

要对涡轮增压器迟滞建模，请选择 **包括涡轮增压器迟滞效应**。在节气门控制期间，时间常数对进气歧管填充和排空动态进行建模。当转矩请求需要涡轮增压器增压时，模块使用更大的时间常数来表示涡轮增压器迟滞。模块使用以下方程。

|  |  |
| --- | --- |
| 动态转矩 | dTbrakedt=1τeng(Tstdy−Tbrake) |
| 增压时间常数 | τbst={τbst,rising       when Tstdy>Tbrakeτbst,falling      when Tstdy≤Tbrake |
| 最终时间常数 | τeng={τthr       when Tbrake<fbst(N)τbst       when Tbrake≥fbst(N) |

这些方程使用以下变量。

|  |  |
| --- | --- |
| *Tbrake* | 制动转矩 |
| *Tstdy* | 稳态目标转矩 |
| *τbst* | 增压时间常数 |
| *τbst,rising*, *τbst,falling* | 增压上升和下降时间常数（分别） |
| *τeng* | 最终时间常数 |
| *τthr* | 节气门控制期间的时间常数 |
| *ƒbst(N)* | 增压转矩转速线 |
| *N* | 发动机转速 |

## 描述

使用查找表的火花点火发动机模型

Mapped SI Engine 模块使用功率、空气质量流量、燃料流量、排气温度、效率和排放性能查找表，实现映射火花点火 (SI) 发动机模型。可以将该模块用于：

- 硬件在环 (HIL) 发动机控制设计
- 车辆级燃油经济性和性能仿真

该模块允许您为这些发动机特性指定查找表。这些查找表使用 Model-Based Calibration Toolbox™ 开发，是命令扭矩 *Tcmd*、制动扭矩 *Tbrake* 和发动机转速 *N* 的函数。如果选择 **Input engine temperature**，这些表也是发动机温度 *TempEng* 的函数。

| 表 | **Input Engine Temperature** 参数设置 | |
| --- | --- | --- |
|  | `off` | `on` |
| 功率 | *ƒ(Tcmd,N)* | *ƒ(Tcmd,N,TempEng)* |
| 空气 | *ƒ(Tbrake,N)* | *ƒ(Tbrake,N,TempEng)* |
| 燃料 |
| 温度 |
| 效率 |
| HC |
| CO |
| NOx |
| CO2 |
| PM |

为限制 Mapped SI Engine 模块输出，该模块不会外推查找表数据。
