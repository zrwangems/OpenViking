## 描述

理想旋转齿轮箱

Gearbox 模块实现理想旋转齿轮箱。该模块使用齿轮惯量和阻尼来计算对基齿轮和从动齿轮对输入扭矩的速度响应。

在燃油经济性和动力总成效率研究中，您可以使用 Gearbox 模块对理想齿轮耦合以及常见传动系统元件（如变速器、发动机、离合器和差速器）之间的功率传递进行建模。

Gearbox 模块使用以下方程来近似传动系动力学。

ω˙BJB=ωBbB+ηNTFω˙FJF=ωFbF+ηTF

此约束方程将系统简化为单自由度系统。

ωB=NωF

为表示理想扭矩传递，该模块使用以下关系。

ηNTB+TF=0

### 功率核算

对于功率核算，该模块实现以下方程。

| 总线信号 | | | 描述 | 变量 | 方程 |
| --- | --- | --- | --- | --- | --- |
| `PwrInfo` | `PwrTrnsfrd` — 模块之间传递的功率  - 正信号表示流入模块 - 负信号表示流出模块 | `PwrBase` | 来自基轴的机械功率 | *PBase* | PBase= ηTBωB |
| `PwrFlwr` | 来自从动轴的机械功率 | *PFlwr* | PFlwr= ηTFωF |
| `PwrNotTrnsfrd` — 穿过模块边界但未传递的功率  - 正信号表示输入 - 负信号表示损耗 | `PwrMechLoss` | 总功率损耗 | *Png* | Png= −(Pt+Pd)+PsPt=ηTBωB+ηTFωF |
| `PwrDampLoss` | 阻尼导致的功率损耗 | *Pd* | Pd=−(bF|ωF|2+bB|ωB|2) |
| `PwrStored` — 存储能量变化率  - 正信号表示增加 - 负信号表示减少 | `PwrStoredShft` | 存储内部动能的变化率 | *Ps* | Ps=(ωBω˙BJB+ωFω˙FJF) |

这些方程使用以下变量。

|  |  |
| --- | --- |
| *TB* | 基齿轮输入扭矩 |
| *TF* | 从动齿轮输出扭矩 |
| *ωB* | 基齿轮角速度 |
| *ωF* | 从动齿轮角速度 |
| *JB* | 基齿轮转动惯量 |
| *JF* | 从动齿轮转动惯量 |
| *bB* | 基齿轮旋转粘性阻尼 |
| *bF* | 从动齿轮旋转粘性阻尼 |
| *N* | 扭矩传动齿轮比 |
| *η* | 齿轮效率 |
| *Pt* | 总功率 |
| *Pd* | 阻尼导致的功率损耗 |
| *Ps* | 存储内部动能的变化率 |
