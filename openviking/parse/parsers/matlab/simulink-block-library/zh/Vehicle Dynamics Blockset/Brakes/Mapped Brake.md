# Rotational Brake

## 端口

### 输入

### **BrkPrs** — 制动压力标量 | *N*×`1` 向量

制动压力，单位为 Pa。

向量为车轮数 *N* 乘 `1`。如果提供标量值，模块假定车轮数为 1。

#### 依赖关系

要启用此参数，请将 **制动类型** 设置为 `Disc`、`Drum` 或 `Mapped`。

### **Omega** — 车轮角速度标量 | *N*×`1` 向量

车轮角速度 *ω*，绕车轮固定 *y* 轴，单位为 rad/s。

向量为车轮数 *N* 乘 `1`。如果提供标量值，模块假定车轮数为 1。

#### 依赖关系

要启用此参数，请将 **旋转类型** 设置为 `No inertia`。

### **BrkTrqMax** — 最大制动转矩标量 | *N*×`1` 向量

最大制动转矩，单位为 N·m。此转矩表示最大可用阻力摩擦制动转矩，并相应地施加到旋转动力学。您无需考虑车轮方向。**BrkTrqMax** 与 **BrkTrq** 不同，**BrkTrq** 是由于摩擦产生的瞬时转矩，根据速度、施加的制动压力或其他摩擦制动特性计算得出。

向量为车轮数 *N* 乘 `1`。如果提供标量值，模块假定车轮数为 1。

#### 依赖关系

要启用此参数，请将 **制动类型** 设置为 `External Torque`。

### **AxlTrq** — 车桥转矩标量 | *N*×`1` 向量

车桥转矩 *Ta*，绕车轮旋转轴，单位为 N·m。

向量为车轮数 *N* 乘 `1`。如果提供标量值，模块假定车轮数为 1。

#### 依赖关系

要启用此参数，请将 **旋转类型** 设置为 `Rotational Inertia`。

### **WhlTrq** — 车轮转矩标量 | *N*×`1` 向量

车轮转矩，单位为 N·m。车轮转矩是来自轮胎模型的绕旋转轴的合力矩。此值包括投射到旋转轴平面上的牵引力矩和滚动阻力矩。

向量为车轮数 *N* 乘 `1`。如果提供标量值，模块假定车轮数为 1。

#### 依赖关系

要启用此参数，请将 **旋转类型** 设置为 `Rotational Inertia`。

## 描述

具有 disc、drum、mapped 或 external torque 模式的旋转制动器

Rotational Brake 模块实现旋转摩擦制动执行器。该制动实现类似于 Combined Slip Wheel 2DOF 模块。使用此模块指定外部最大制动扭矩，以与以下没有集成制动模型的轮胎模型之一交互：

- Combined Slip Wheel
  CPI model 或 Combined Slip Wheel
  STI model
- Simscape™
  Multibody™ model
- 第三方轮胎模型

### 制动器

**Disc**

如果将 **Brake Type** 参数指定为 `Disc`，则该模块实现盘式制动器。此图显示了盘式制动器的侧视图和前视图。

盘式制动器的前视图和侧视图，显示制动片、制动盘和卡钳

盘式制动器将来自制动缸的制动缸压力转换为力。盘式制动器在制动片平均半径处施加该力。

该模块使用以下方程计算盘式制动器的制动扭矩。

T={μPπBa2RmNpads4                当 N≠0μstaticPπBa2RmNpads4         当 N=0

Rm=Ro+Ri2

这些方程使用以下变量。

| 变量 | 值 |
| --- | --- |
| *T* | 制动扭矩 |
| *P* | 施加的制动压力 |
| *N* | 车轮速度 |
| *Npads* | 盘式制动器总成中的制动片数量 |
| *μstatic* | 制动片-制动盘静摩擦系数 |
| *μ* | 制动片-制动盘动摩擦系数 |
| *Ba* | 制动执行器缸径 |
| *Rm* | 制动片在制动盘上施加力的平均半径 |
| *Ro* | 制动片外半径 |
| *Ri* | 制动片内半径 |

**Drum**

如果将 **Brake Type** 参数指定为 `Drum`，则该模块实现静态（稳态）simplex 鼓式制动器。simplex 鼓式制动器由单个双侧液压执行器和两个制动蹄组成。制动蹄不共用同一铰接销。

simplex 鼓式制动器模型使用施加的力和制动器几何结构来计算每个制动蹄的净扭矩。鼓式制动器模型假定两侧的执行器和制动蹄几何结构对称，因此两个制动蹄可以使用同一组几何结构和摩擦参数。

该模块实现从 *Fundamentals of Machine Elements* 中的这些方程推导出的方程。

Trshoe=(πμcr(cosθ2−cosθ1)Ba22μ(2r(cosθ2−cosθ1)+a(cos2θ2−cos2θ1))+a(2θ1−2θ2+sin2θ2−sin2θ1))PTlshoe=(πμcr(cosθ2−cosθ1)Ba2−2μ(2r(cosθ2−cosθ1)+a(cos2θ2−cos2θ1))+a(2θ1−2θ2+sin2θ2−sin2θ1))P

T={Trshoe+Tlshoe                 当 N≠0(Trshoe+Tlshoe)μstaticμ   当 N=0

| 变量 | 值 |
| --- | --- |
| *T* | 制动扭矩 |
| *P* | 施加的制动压力 |
| *N* | 车轮速度 |
| *μstatic* | 制动片-制动盘静摩擦系数 |
| *μ* | 制动片-制动盘动摩擦系数 |

**Mapped**

如果将 **Brake Type** 参数指定为 `Mapped`，则该模块使用查找表确定制动扭矩。

T={fbrake(P,N)                   当 N≠0(μstaticμ)fbrake(P,N)    当 N=0

这些方程使用以下变量。

| 变量 | 值 |
| --- | --- |
| *T* | 制动扭矩 |
| fbrake(P,N) | 制动扭矩查找表 |
| *P* | 施加的制动压力 |
| *N* | 车轮速度 |
| *μstatic* | 静态条件下鼓式制动器衬片-摩擦面界面的摩擦系数 |
| *μ* | 盘式制动器衬片-制动盘界面的摩擦系数 |

制动扭矩 fbrake(P,N) 的查找表是施加的制动压力和车轮速度的函数，其中：

- *T* 是制动扭矩，单位为 N·m。
- *P* 是施加的制动压力，单位为 bar。
- *N* 是车轮速度，单位为 rpm。
