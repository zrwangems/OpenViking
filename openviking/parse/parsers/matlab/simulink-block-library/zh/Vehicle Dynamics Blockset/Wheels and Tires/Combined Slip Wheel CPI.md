# Combined Slip Wheel CPI

## 端口

### 输入

### **Omega** — 旋转速度 标量 | `N`-by-`1` 向量

轮胎绕车轮旋转轴的旋转速度，*ω*，单位为 rad/s。

向量为车轮数量，*N*，乘 `1`。如果提供标量值，模块假定车轮数量为一。

### **Vx** — 纵向速度 标量 | *N*-by-`1` 向量

沿轮胎固定 *x* 轴的车轴纵向速度，*Vx*，单位为 m/s。

向量为车轮数量，*N*，乘 `1`。如果提供标量值，模块假定车轮数量为一。

### **Vy** — 横向速度 标量 | *N*-by-`1` 向量

沿轮胎固定 *y* 轴的车轴横向速度，*Vy*，单位为 m/s。

向量为车轮数量，*N*，乘 `1`。如果提供标量值，模块假定车轮数量为一。

### **Camber** — 倾角 标量 | *N*-by-`1` 向量

外倾角，*ɣ*，或倾角，*ε*，单位为 rad。

向量为车轮数量，*N*，乘 `1`。如果提供标量值，模块假定车轮数量为一。

### **YawRate** — 轮胎角速度 标量 | *N*-by-`1` 向量

绕轮胎固定 *z* 轴的轮胎角速度，*r*（横摆角速度），单位为 rad/s。

向量为车轮数量，*N*，乘 `1`。如果提供标量值，模块假定车轮数量为一。

### **Fext** — 施加到轮胎的车轴力 标量 | *N*-by-`1` 向量

沿车辆固定 *z* 轴施加到轮胎的车轴力，*Fext*（正输入压缩轮胎），单位为 N。

向量为车轮数量，*N*，乘 `1`。如果提供标量值，模块假定车轮数量为一。

#### 依赖关系

要启用此参数，请将 **垂直运动** 设置为 `None`。

### **RadialDeflct** — 轮胎径向变形 标量 | *N*-by-`1` 向量

轮胎径向变形，*RadialDeflct*，单位为 m。此值将用于所有依赖变形的内部 Magic Formula 6.2 方程。

向量为车轮数量，*N*，乘 `1`。如果提供标量值，模块假定车轮数量为一。

#### 依赖关系

要启用此端口，请将 **垂直运动** 设置为 `External Deflection`。

### **ScaleFctrs** — 比例因子 `27`-by-`N` 数组

Magic Formula 6.2 比例因子数组。数组维度为 `27` 乘车轮数量，*N*。

Magic Formula 6.2 方程使用比例因子来考虑静态或仿真运行时变化。通常，大多数设置为 `1`。

| 数组元素 | 变量 | 比例因子 |
| --- | --- | --- |
| `ScaleFctrs(1,1)` | `lam_Fzo` | 额定载荷 |
| `ScaleFctrs(2,1)` | `lam_mux` | 纵向峰值摩擦系数 |
| `ScaleFctrs(3,1)` | `lam_muy` | 横向峰值摩擦系数 |
| `ScaleFctrs(4,1)` | `lam_muV` | 滑移速度，*Vs*，衰减摩擦 |
| `ScaleFctrs(5,1)` | `lam_Kxkappa` | 制动滑移刚度 |
| `ScaleFctrs(6,1)` | `lam_Kyalpha` | 侧偏刚度 |
| `ScaleFctrs(7,1)` | `lam_Cx` | 纵向形状因子 |
| `ScaleFctrs(8,1)` | `lam_Cy` | 横向形状因子 |
| `ScaleFctrs(9,1)` | `lam_Ex` | 纵向曲率因子 |
| `ScaleFctrs(10,1)` | `lam_Ey` | 横向曲率因子 |
| `ScaleFctrs(11,1)` | `lam_Hx` | 纵向水平偏移 |
| `ScaleFctrs(12,1)` | `lam_Hy` | 横向水平偏移 |
| `ScaleFctrs(13,1)` | `lam_Vx` | 纵向垂直偏移 |
| `ScaleFctrs(14,1)` | `lam_Vy` | 横向垂直偏移 |
| `ScaleFctrs(15,1)` | `lam_Kygamma` | 外倾力刚度 |
| `ScaleFctrs(16,1)` | `lam_Kzgamma` | 外倾力矩刚度 |
| `ScaleFctrs(17,1)` | `lam_t` | 气胎拖距（影响回正力矩刚度） |
| `ScaleFctrs(18,1)` | `lam_Mr` | 残余力矩 |
| `ScaleFctrs(19,1)` | `lam_xalpha` | Alpha 对 *Fx*（kappa）的影响 |
| `ScaleFctrs(20,1)` | `lam_ykappa` | Kappa 对 *Fy*（alpha）的影响 |
| `ScaleFctrs(21,1)` | `lam_Vykappa` | 诱导的胎体转向 *Fy* |
| `ScaleFctrs(22,1)` | `lam_s` | *Fx* 的力臂 |
| `ScaleFctrs(23,1)` | `lam_Cz` | 径向轮胎刚度 |
| `ScaleFctrs(24,1)` | `lam_Mx` | 翻转力偶刚度 |
| `ScaleFctrs(25,1)` | `lam_VMx` | 翻转力偶垂直偏移 |
| `ScaleFctrs(26,1)` | `lam_My` | 滚动阻力矩 |
| `ScaleFctrs(27,1)` | `lam_Mphi` | 驻车力矩 *Mz* |

### **Prs** — 轮胎充气压力 标量 | `N`-by-`1` 向量

轮胎充气压力，*pi*，单位为 Pa。

向量为车轮数量，*N*，乘 `1`。如果提供标量值，模块假定车轮数量为一。

#### 依赖关系

要创建此端口，请选择 **输入轮胎压力**。

向量为车轮数量，*N*，乘 `1`。如果提供标量值，模块假定车轮数量为一。

### **Fy** — 横向车轴力 标量 | *N*-by-`1` 向量

### **Fz** — 垂向车轴力 标量 | *N*-by-`1` 向量

### **胎体转向** — 包含胎体转向 `on` (default) | `off`

选择以在 Magic Formula 6.2 方程中包含胎体转向。

默认情况下，这些模块在 Magic Formula 6.2 方程中包含胎体转向和转向滑移。这些方程拟合到平带测试数据，并预测多种轮胎效应，包括胎体转向和转向滑移。如果符合以下情况，请考虑移除这些效应：

- 您的测试数据不包括胎体转向或转向滑移数据。
- 您的分析不需要胎体转向或转向滑移效应。

如果清除 **胎体转向**，模块会在内部将以下参数设置为 0：

- **翻转力矩垂直偏移, QSX1**
- **组合滑移 Fx 偏移因子减少, RHX1**
- **Efy 曲率常数外倾依赖性, PEY3**
- **FZNOM 处的 SHY 水平偏移, PHY1**
- **SHY 随载荷的变化, PHY2**
- **FZNOM 处的 Svy/Fz 垂直偏移, PVY1**
- **Svy/Fz 随载荷的变化, PVY2**
- **Fy 偏移随侧偏角的减少, RBY3**
- **FZNOM 处滑移率侧力 Svyk/Muy\*Fz, RVY1**
- **侧力 Svyk/Muy\*Fz 随载荷的变化, RVY2**
- **Bpt 斜率随外倾的变化, QBZ4**
- **Dpt 峰值拖距随外倾的变化, QDZ3**
- **Dmr 峰值残余力矩, QDZ6**
- **Dmr 峰值残余力矩随载荷的变化, QDZ7**
- **Ept 随 alpha-t 符号的变化, QEZ4**
- **FZNOM 处的 Sht 水平拖距偏移, QHZ1**
- **Sht 随载荷的变化, QHZ2**
- **s/R0 的标称值：Fx 对 Mz 的影响, SSZ1**

## 描述

符合 CPI Tydex 标准的组合滑移车轮

Combined Slip Wheel CPI 模块实现由 Magic Formula[1][2] 6.2 表征的车轮的纵向和横向行为，该公式符合 contact point interface (CPI) Tyre Data Exchange Format (TYDEX)[3] 标准。您可以导入自己的轮胎模型或使用内置轮胎模型。在需要低频轮胎-道路交互来确定车辆加速、制动和车轮滚动阻力的动力传动系统和车辆仿真中使用该模块。该模块适用于需要组合横向滑移的应用，例如横向运动和横摆稳定性研究。

基于车轮转动速度、纵向和横向速度、车轮外倾角和充气压力，该模块确定所有六个自由度 (DOF) 中的垂直运动、力和力矩。使用垂直自由度研究由道路轮廓或底盘运动引起的轮胎-悬架共振。

如果安装 Extended Tire Features for Vehicle Dynamics Blockset 支持包，则可以使用以下附加功能：

- 绘图生成 — 点击 **Plot steady state force, moment response** 按钮以生成以下绘图：

  - **Lateral force [N] vs Slip angle [rad]**
  - **Self-aligning moment [Nm] vs Slip angle [rad]**
  - **Longitudinal force [N] vs Longitudinal slip []**
  - **Longitudinal force [N] vs Lateral force [N]**
- 导入轮胎参数 — 使用 `tireModel.get` 方法将 Combined Slip Wheel CPI 模块中定义的轮胎参数值导入到 `tireModel` 对象。
- 导出轮胎参数 — 使用 `set` 方法将轮胎参数值从 `tireModel` 对象导出到 Combined Slip Wheel CPI 模块。
- 轮胎模型转换 — 使用 `convert` 方法将以下类型之一的轮胎模型转换为可导入 Combined Slip Wheel CPI 模块的 Magic Formula 6.2 轮胎模型：

  - Magic Formula 5.2
  - Fiala
  - Dugoff

使用 **Tire type** 参数选择轮胎数据的来源。

| 目标 | 操作 |
| --- | --- |
| 使用经验方程1, 2实现 Magic Formula 6.2。这些方程使用与模块参数对应的拟合系数。 | 使用文件中的拟合系数更新模块参数：  1. 将 **Tire type** 设置为 `External file`。 2. 在 **External tire source** 窗格上，点击 **Select file**。 3. 选择轮胎系数文件。 4. 点击 **Update mask values from file**。在提示您确认的对话框中，点击 **OK**。模块将更新参数。 5. 点击 **Apply**。 |

### 旋转车轮动力学

该模块计算车轮在以下作用下的惯性响应：

- 车轴损耗
- 轮胎滚动阻力
- 通过轮胎-道路界面的地面接触

为实现 Magic Formula 6.2，该模块使用所引用参考文献中的以下方程：

| 计算 | 方程 |
| --- | --- |
| 纵向力 | *Tire and Vehicle Dynamics*2 方程 4.E9 至 4.E57 |
| 侧向力 - 纯侧偏 | *Tire and Vehicle Dynamics*2 方程 4.E19 至 4.E30 |
| 侧向力 - 组合滑移 | *Tire and Vehicle Dynamics*2 方程 4.E58 至 4.E67 |
| 垂直动力学 | *Tire and Vehicle Dynamics*2 方程 4.E68、4.E1、4.E2a 和 4.E2b |
| 翻转力矩 | *Tire and Vehicle Dynamics*2 方程 4.E69 |
| 滚动阻力 | - *An improved Magic Formula/Swift tyre model that can handle inflation pressure changes*1 方程 6.1.2 - *Tire and Vehicle Dynamics*2 方程 4.E70 |
| 回正力矩 | *Tire and Vehicle Dynamics*2 方程 4.E31 至 4.E49 |
| 回正扭矩 - 组合滑移 | *Tire and Vehicle Dynamics*2 方程 4.E71 至 4.E78  如果清除 **Include turn slip**，则该模块将这些方程中的一些设置为 1。 |

### CPI 轮胎坐标系

该模块使用轮胎坐标系轴（*XT*、*YT*、*ZT*），这些轴固定在附着于轮胎的参考坐标系中。原点位于轮胎与地面的接触点。

CPI 轮胎坐标系以红色显示。

**注意**

CPI 轮胎坐标系（红色）等效于 TYDEX 车轮轴坐标系。

1

Z-Up 轮胎和车轮坐标系，显示车轮平面和道路平面

| 轴 | 描述 |
| --- | --- |
| *XT* | *XT* 和 *YT* 平行于道路平面。车轮平面与道路平面的交线定义 *XT* 轴的方向。 |
| *YT* | *YT* 是车轮旋转轴在地面上的投影。 |
| *ZT* | *ZT* 指向上方。 |
