# Vehicle Body 1DOF Longitudinal

## 端口

### 输入

### **FExt** — 车辆 CG 上的外部力 `array`

施加到车辆 CG 的外部力，
*Fxext*，
*Fyext*，
*Fzext*，在
车辆固定坐标系中，单位为 N。信号向量维度为
`[1x3]` 或 `[3x1]`。

#### 依赖关系

要启用此端口，请选择 **外部力**。

### **MExt** — 车辆 CG 上的外部力矩 `array`

施加到车辆 CG 的外部力矩，
*Mx*，
*My*，
*Mz*，在
车辆固定坐标系中，单位为 N·m。信号向量维度为
`[1x3]` 或 `[3x1]`。

#### 依赖关系

要启用此端口，请选择 **外部力矩**。

### **FwF** — 前轴上的总纵向力 `scalar`

沿车辆固定 `x` 轴作用在前轴上的纵向力，
*Fxf*，单位为 N。

### **FwR** — 后轴上的总纵向力 `scalar`

沿车辆固定 `x` 轴作用在后轴上的纵向力，
*FwR*，单位为 N。

### **Grade** — 道路坡度角 `scalar`

道路坡度角，γ，单位为 deg。

### **WindX** — 纵向风速 `scalar`

沿地球固定 `X` 轴的纵向风速，*Ww*，单位为 m/s。

#### 依赖关系

要启用此端口，请清除 **风 X,Y,Z 分量**。

### **WindXYZ** — 风速 `array`

沿惯性
*X*、*Y* 和
*Z* 轴的风速，*Ww*，
*WwY*，
*WwZ*，单位为 m/s。信号向量维度为
`[1x3]` 或 `[3x1]`。

#### 依赖关系

要启用此端口，请选择 **风 X,Y,Z 分量**。

### **AirTemp** — 环境空气温度 `scalar`

环境空气温度，
*Tair*，单位为 K。如果您想在运行时改变温度，请考虑此选项。

#### 依赖关系

要启用此端口，请选择 **空气温度**。

## 描述

前进和倒车运动中的双轴车辆

Vehicle Body 1DOF Longitudinal 模块实现一个具有恒定质量、进行纵向（即前进和倒车）运动的一自由度（1DOF）刚性车体。使用该模块：

- 在动力总成和燃油经济性研究中，当来自垂向和俯仰运动的重量转移可忽略时，用于表示车辆惯性载荷和阻力载荷。
- 用于确定车辆遵循指定驾驶循环所需的发动机扭矩和功率。

您可以选择模块选项，为外部力、力矩、空气温度和风速创建输入端口。

| 模块选项设置 | **外部输入端口** | 描述 |
| --- | --- | --- |
| **外部力** | `FExt` | 在车辆固定坐标系中施加到车辆 CG 的外部力。 |
| **外部力矩** | `MExt` | 在车辆固定坐标系中绕车辆 CG 的外部力矩。 |
| **空气温度** | `AirTemp` | 环境空气温度。如果您想在运行时改变温度，请考虑此选项。 |
| **风 X,Y,Z** | `WindXYZ` | 沿地球固定 *X*、*Y* 和 *Z* 轴的风速。如果您不选择此选项，模块实现输入端口 `WindX` — 沿地球固定 *X* 轴的纵向风速。 |

### Vehicle Body Model

车辆车轴平行并形成一个平面。纵向方向位于该平面内，并且垂直于车轴。如果车辆在倾斜坡道上行驶，法向方向不平行于重力，但始终垂直于车轴-纵向平面。

该模块使用作用在车辆上的所有力和力矩的净效应来确定车辆运动。纵向轮胎力推动车辆前进或后退。车辆的重力通过其重心 (CG) 作用。坡度角改变作用在车辆 CG 上的分解后重力的方向。类似地，该模块分解作用在车辆 CM 上的空气动力学阻力。

车辆自由体力图，显示作用在 CM 和轮胎上的力

Vehicle Body 1DOF Longitudinal 模块实现以下方程。

Fb=mx¨Fb=FxF+FxR−Fd,x+Fext,x−mgsinγ

零法向加速度和零俯仰力矩确定每个前轴和后轴上的法向力。

FzF=−Mext,y−Md,y+  b(Fd,z+Fext,z+ mgcosγ)−h(−Fext,x+Fd,x+ mgsinγ+mx¨)NF(a+b) FzR=Mext,y+Md,y+ a(Fd,z+Fext,z+ mgcosγ)+h(−Fext,x+Fd,x+ mgsinγ+mx¨)NR(a+b)

车轮法向力满足以下方程。

NFFzF+NRFzR−Fext,z=mgcosγ

### 风与阻力

该模块从车辆速度分量中减去风速，以获得净相对空速。为了计算作用在车辆上的阻力和力矩，该模块使用净相对空速。

Fd,x=12TRCdAfPabs(x˙−wx)2Fd,z=12TRClAfPabs(x˙−wx)2Md,y=12TRCpmAfPabs(x˙−wx)2(a+b)

默认情况下，为了计算沿车辆固定 *x* 轴的风速，该模块使用沿地面固定 *X* 轴的纵向风速。如果选择 **WindX,Y,Z**，则该模块使用沿地面固定 *X*、*Y*、*Z* 轴的风速。

### 功率核算

对于功率核算，该模块实现以下方程。

| 总线信号 | | | 描述 | 方程 |
| --- | --- | --- | --- | --- |
| `PwrInfo` | `PwrTrnsfrd` — 模块之间传输的功率  - 正值信号表示流入模块 - 负值信号表示流出模块 | `PwrFxExt` | 外部施加力的功率 | PFxExt=FxExtx˙ |
| `PwrFwFx` | 施加在前轴上的纵向力功率 | PFwFx=FwFx˙ |
| `PwrFwRx` | 施加在后轴上的纵向力功率 | PFwRx=FwRx˙ |
| `PwrNotTrnsfrd` — 功率跨越模块边界，但未传输  - 正值信号表示输入 - 负值信号表示损失 | `PwrFxDrag` | 阻力功率 | Pd=−0.5CdAfPabs(x˙2−wx)2287.058Tx˙ |
| `PwrStored` — 存储能量的变化率  - 正值信号表示增加 - 负值信号表示减少 | `wrStoredGrvty` | 重力势能的变化率 | Pg=−mgZ˙ |
| `PwrStoredxdot` | 纵向动能的变化率 | Px˙=mx¨x˙ |

这些方程使用以下变量。

|  |  |
| --- | --- |
| *Fxf*, *Fxr* | 分别在前、后地面接触点处每个车轮上的纵向力 |

| *FxExt*, *FwR* | 沿车辆固定 *x* 轴的外部力 |
| *Fd,x*, *Fd,z* | 作用在车辆 CG 上的纵向和法向阻力 |
| *Md,y* | 阻力作用在车辆上产生的绕车辆固定 *y* 轴的力矩 |
| *Fd* | 空气动力学阻力 |
| *Vx* | 车辆速度。当 *Vx* > 0 时，车辆向前运动。当 *Vx* < 0 时，车辆向后运动。 |
