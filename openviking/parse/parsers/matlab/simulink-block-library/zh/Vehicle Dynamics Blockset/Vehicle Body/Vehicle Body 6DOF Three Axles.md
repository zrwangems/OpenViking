# Vehicle Body 6DOF Three Axles

## 端口

### 输入

### **FSusp** — 作用在车辆上的悬架力 `3-by-6` 数组

在硬点位置处施加到车辆上的悬架纵向、横向和垂向悬架力，单位为 N，指定为 `3-by-6` 数组。

FSusp=[FFLxFFRxFMLxFMRxFRLxFRRxFFLyFFRyFMLyFMRyFRLyFRRyFFLzFFRzFMLzFMRzFRLzFRRz]

| 数组元素 | 车轴 | 轮侧 | 力轴 |
| --- | --- | --- | --- |
| `FSusp(1,1)` | 前 | 左 | 车辆固定 *x* 轴（纵向） |
| `FSusp(1,2)` | 前 | 右 |
| `FSusp(1,3)` | 中 | 左 |
| `FSusp(1,4)` | 中 | 右 |
| `FSusp(1,5)` | 后 | 左 |
| `FSusp(1,6)` | 后 | 右 |
| `FSusp(2,1)` | 前 | 左 | 车辆固定 *y* 轴（横向） |
| `FSusp(2,2)` | 前 | 右 |
| `FSusp(2,3)` | 中 | 左 |
| `FSusp(2,4)` | 中 | 右 |

| `FSusp(2,6)` | 后 | 右 |

### **FExt** — 作用在车辆上的外部力 `vector`

作用在车辆上的外部力，单位为 N，指定为 `1-by-3` 或 `3-by-1` 向量。

FExt=Fext=[FextxFextyFextz]or[FextxFextyFextz]

| 数组元素 | 力轴 |
| --- | --- |
| `FExt(1,1)` | 车辆固定 *x* 轴（纵向） |
| `FExt(1,2)` 或 `FExt(2,1)` | 车辆固定 *y* 轴（横向） |
| `FExt(1,3)` 或 `FExt(3,1)` | 车辆固定 *z* 轴（垂向） |

### **MExt** — 作用在车辆上的外部力矩 `vector`

作用在车辆上的外部力矩，单位为 N·m，指定为 `1-by-3` 或 `3-by-1` 向量。

MExt=Mext=[MextxMextyMextz]or[MextxMextyMextz]

| 数组元素 | 力轴 |
| --- | --- |
| `MExt(1,1)` | 车辆固定 *x* 轴（纵向） |
| `MExt(1,2)` 或 `MExt(2,1)` | 车辆固定 *y* 轴（横向） |
| `MExt(1,3)` 或 `MExt(3,1)` | 车辆固定 *z* 轴（垂向） |

### **Fh** — 作用在车体上的挂钩力 `array`

在挂钩位置处施加到车体上的挂钩力，*Fhx*、*Fhy*、*Fhz*，位于车辆固定坐标系中，单位为 N，指定为 `1-by-3` 或 `3-by-1` 数组。

#### 依赖关系

要启用此端口，请在 **输入信号** 下选择 **挂钩力**。

### **Mh** — 绕车体的挂钩力矩 `array`

在挂钩位置处、绕车辆固定坐标系的挂钩力矩，*Mhx*、*Mhy*、*Mhz*，单位为 N·m，指定为 `1-by-3` 或 `3-by-1` 数组。

#### 依赖关系

要启用此端口，请在 **输入信号** 下选择 **挂钩力矩**。

### **WindXYZ** — 风速 `array`

沿惯性 *X*、*Y* 和 *Z* 轴的风速，*Wx*、*Wy*、*Wz*，单位为 m/s，指定为 `1-by-3` 或 `3-by-1` 数组。

### **AirTemp** — 环境空气温度 `scalar`

环境空气温度，*Tair*，单位为 K，指定为标量。

#### 依赖关系

要启用此端口，请在 **环境** 下选择 **空气温度**。

## 描述

三轴车辆拖拉机车身，具有平移和旋转运动

Vehicle Body 6DOF Three Axles 模块实现一个六自由度（DOF）刚性三轴车辆车身模型，用于计算纵向、侧向、垂向、俯仰、侧倾和横摆运动。使用该模块对类似拖拉机的三轴车辆建模。该模块考虑车身质量、惯性、空气阻力、道路坡度以及由于悬架和外部力与力矩在各轴硬点位置之间的重量分布。使用 **惯性载荷** 参数分析不同载荷条件下的车辆动力学。

将该模块连接到虚拟传感器、悬架系统或外部系统，例如车身控制执行器。在平顺性和操纵性研究中使用 Vehicle Body 6DOF Three Axles 模块，对阻力、乘客载荷和悬架硬点位置的影响进行建模。

### 运动方程

为确定车辆运动，该模块实现刚体车辆动力学、风阻、惯性载荷和坐标变换的计算。车身固定坐标系和车辆固定坐标系相同。

该模块考虑车身固定坐标框架绕平坦地面固定惯性参考系的旋转。车身固定坐标框架的原点是车身车辆重心。

该模块使用此方程计算车身固定坐标框架的平移运动，其中施加的力 [*Fx Fy Fz*]T 位于车身固定框架中，并且假设车身质量 *m* 恒定。
