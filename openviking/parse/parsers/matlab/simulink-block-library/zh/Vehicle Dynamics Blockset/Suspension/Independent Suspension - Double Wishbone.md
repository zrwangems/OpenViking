# Independent Suspension - Double Wishbone

## 端口

### 输入

### **WhlPz** — 车轮 `z` 轴位移数组

车轮位移，*zw*，沿车轮固定的 *z* 轴，单位为 m。数组维度为 `1` 乘车辆上的车轮总数。

例如，对于两轴车辆，每轴两个车轮，`WhlPz`：

- 信号数组维度为 `[1x4]`。

  WhlPz=zw=[zw1,1zw1,2zw2,1zw2,2]

  | 车轮 | 数组元素 | 轴 | 车轮编号 |

  | 左后 | `WhlPz(1,3)` | `2` | `1` |
  | 右后 | `WhlPz(1,4)` | `2` | `2` |

### **StrgAng** — 转向角，可选数组

每个车轮的可选转向角，*δ*。输入数组维度为 `1` 乘转向车轮数。

例如，对于两轴车辆，每轴两个车轮，可以输入第一轴两个车轮的转向角。

- 要启用 **StrgAng** 端口，将 **Steered axle enable by axle, StrgEnByAxl** 设置为 `[1 0]`。输入信号数组维度为 `[1x2]`。
- `StrgAng` 信号包含两个转向角，分别对应其轴和车轮位置。

  StrgAng=δsteer=[δsteer1,1δsteer1,2]

  | 车轮 | 数组元素 | 轴 | 车轮编号 |
  | --- | --- | --- | --- |
  | 左前 | `StrgAng(1,1)` | `1` | `1` |
  | 右前 | `StrgAng(1,2)` | `1` | `2` |

#### 依赖关系

要启用端口 **StrgAng**，将 **Steered axle enable by axle, StrgEnByAxl** 向量的一个元素设置为 `1`。

### 悬架柔顺性和阻尼

该模块使用线性弹簧和阻尼器来建模悬架系统的垂向动态效应。利用车辆和车轮
支架的相对位置和速度，模块计算作用在车轮和车辆上的垂向悬架力。该
模块使用线性方程，将垂向阻尼和柔顺性与
悬架高度、悬架高度变化率以及转向角绝对值关联起来。

该模块实现此方程。

Fwza,t=Fz0a+kza(zva,t−zwa,t+mhsteera|δsteera,t|)+c(z˙va,t−z˙wa,t)+Fzhstopa,t+Fzaswya,t

阻尼系数，*c*，取决于 **启用主动阻尼** 参数设置。

| **启用主动阻尼** 设置 | 阻尼 |
| --- | --- |
| `off` | 常量，*c* = *cza* |
| `on` | 查找表，是主动阻尼器占空比和执行器速度的函数  c=f(duty,(z˙va,t−z˙wa,t)) |

该模块假设悬架元件没有质量。因此，施加到车辆的悬架力和力矩等于施加到车轮的悬架力和力矩。

Fvxa,t=Fwxa,tFvya,t=Fwya,tFvza,t=−Fwza,tMvxa,t=Mwxa,t+Fwya,t(Rewya,t+Ha,t)Mvya,t=Mwya,t+Fwxa,t(Rewxa,t+Ha,t)Mvza,t=Mwza,t

纵向位置和速度。

xwa,t=xva,tywa,t=yva,tx˙wa,t=x˙va,ty˙wa,t=y˙va,t

### 硬限位力

模块施加的硬限位反馈力，*Fzhstopa,t*，取决于悬架是在压缩还是伸张。模块施加该力的情况如下：

- 在压缩时，当悬架压缩量超过 **悬架最大高度, Hmax** 参数指定的最大距离时
- 在伸张时，当悬架伸张量大于 **悬架最大高度, Hmax** 参数指定的最大伸张量时

为计算该力，模块使用基于双曲正切和指数缩放的刚度。

### 转向角

可选地，使用 **Steered axle enable by axle, StrgEnByAxl** 参数来为车轮输入转向角。为了计算车轮的转向角，模块使用悬架高度的线性函数对输入转向角进行偏移。

δwhlsteera,t=δsteera,t+mhtoea(zwa,t−zva,t−mhsteera|δsteera,t|)+mtoesteera|δsteera,t|

该方程使用以下变量。

|  |  |
| --- | --- |
| *mtoesteera* | 车轴 `a` 的前束角相对于转向角的斜率 |
| *mhsteera* | 车轴 `a` 的转向角相对于垂向力的斜率 |
| *mhtoea* | 车轴 `a` 的前束角相对于悬架高度的斜率 |
| *δwhlsteera,t* | 车轴 `a`、车轮 `t` 的车轮转向角 |
| *δsteera,t* | 车轴 `a`、车轮 `t` 的转向角输入 |
| *zva,t* | 车轴 `a`、车轮 `t` 沿惯性固定 *z* 轴的车辆位移 |
| *zwa,t* | 车轴 `a`、车轮 `t` 沿惯性固定 *z* 轴的车轮位移 |

### 功率与能量

该模块为每个车轴 `a`、车轮 `t` 计算以下悬架特性。

| 计算 | 方程 |
| --- | --- |
| 耗散功率，*Psuspa,t* | Psuspa,t=Fwzlookupa(z˙va,t−z˙wa,t,z˙va,t−z˙wa,t,δsteera,t) |
| 吸收能量，*Esuspa,t* | Esuspa,t=Fwzlookupa(z˙va,t−z˙wa,t,z˙va,t−z˙wa,t,δsteera,t) |
| 悬架高度，*Ha,t* | Ha,t=−(zva,t−zwa,t+Fz0akza+mhsteera|δsteera,t|) |
| 从车轮托架中心到轮胎/道路界面的距离 | zwtra,t=Rewa,t+Ha,t |

这些方程使用以下变量。

|  |  |
| --- | --- |
| *mhsteera* | 对于车轴 `a` 上的车轮，施加在车轮托架处的转向角相对于垂向力的斜率 |
| *δsteera,t* | 车轴 `a`、车轮 `t` 的转向角输入 |
| *Rewa,t* | 车轴 `a`、车轮 `t` 从车轮托架中心到轮胎/道路界面的有效车轮半径 |
| *Fz0a* | 施加到车轴 `a` 上车轮的垂向悬架弹簧预紧力 |
| *zwtra,t* | 从车轮托架中心到轮胎/道路界面的距离，沿惯性固定 *z* 轴 |
| *zva,t*, *żva,t* | 车轴 `a`、车轮 `t` 沿惯性固定 *z* 轴的车辆位移和速度 |
| *zwa,t*, *żwa,t* | 车轴 `a`、车轮 `t` 沿惯性固定 *z* 轴的车轮位移和速度 |
