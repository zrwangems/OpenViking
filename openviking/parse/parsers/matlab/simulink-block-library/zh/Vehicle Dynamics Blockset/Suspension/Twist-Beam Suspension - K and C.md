# Twist-Beam Suspension - K and C

## 端口

### 输入

### **WhlPz** — 车轮 `z` 轴位移数组

车轮位移，*zw*，沿车轮固定的 *z* 轴，单位为 m。数组维度为 `1` 乘以车辆上的车轮总数。

例如，对于每轴两个车轮的两轴车辆，`WhlPz`：

- 信号数组维度为 `[1x4]`。

  WhlPz=zw=[zw1,1zw1,2zw2,1zw2,2]

  | 车轮 | 数组元素 | 车轴 | 车轮编号 |

  | 左前 | `WhlPz(1,1)` | `1` | `1` |
  | 右前 | `WhlPz(1,2)` | `1` | `2` |
  | 左后 | `WhlPz(1,3)` | `2` | `1` |
  | 右后 | `WhlPz(1,4)` | `2` | `2` |

### **WhlM** — 车轮上的悬架力矩数组

- `WhlM(1,...)` — 施加到车轮的绕惯性固定 *x* 轴的悬架力矩（纵向）
- `WhlM(2,...)` — 施加到车轮的绕惯性固定 *y* 轴的悬架力矩（横向）
- `WhlM(3,...)` — 施加到车轮的绕惯性固定 *z* 轴的悬架力矩（垂向）

例如，对于每轴两个车轮的两轴车辆，`WhlM`：

- 信号维度为 `[3x4]`。

  WhlM=Mw=[Mwx1,1Mwx1,2Mwx2,1Mwx2,2Mwy1,1Mwy1,2Mwy2,1Mwy2,2Mwz1,1Mwz1,2Mwz2,1Mwz2,2]

### **StrgAng** — 转向角，可选数组

每个车轮的可选转向角，*δ*。输入数组维度为 `1` 乘以转向车轮数。

例如，对于每轴两个车轮的两轴车辆，您可以为第一轴上的两个车轮输入转向角。

- 要启用 **StrgAng** 端口，请将 **按轴启用转向轴，StrgEnByAxl** 设置为 `[1 0]`。输入信号数组维度为 `[1x2]`。
- `StrgAng` 信号包含两个转向角，对应于其车轴和车轮位置。

  StrgAng=δsteer=[δsteer1,1δsteer1,2]

  | 车轮 | 数组元素 | 车轴 | 车轮编号 |
  | --- | --- | --- | --- |
  | 左前 | `StrgAng(1,1)` | `1` | `1` |
  | 右前 | `StrgAng(1,2)` | `1` | `2` |

#### 依赖关系

要启用端口 **StrgAng**，请将 **按轴启用转向轴，StrgEnByAxl** 向量中的某个元素设置为 `1`。

### **Anti-sway axle enable by axle, AntiSwayEnByAxl** — 用于启用车轴防倾杆的布尔向量 `[0 0]`（默认）| `vector`

为车轴 *a* 启用车轴防倾杆的布尔向量，无量纲。例如，`[1 0]` 启用前轴防倾杆并禁用后轴防倾杆。向量为 `1` 乘以车辆车轴数，*Na*。

如果在后轴上启用防倾杆，该模块使用以下方程计算扭转梁侧倾刚度。

TBrs=Srs−π[12WR∇TW2]180

该方程使用以下变量。

|  |  |
| --- | --- |
| *TBrs* | 扭转梁侧倾刚度 |
| *Srs* | 无扭转梁时的悬架侧倾刚度，**RollStiffNoTwstRear** 参数 |
| *WR∇* | 法向车轮刚度梯度，根据 **NrmlWhlRates** 参数和悬架位移计算 |
| *TW* | 轮距 |

如果未启用防倾杆，则刚度为 0。

## 描述

扭力梁运动学与柔度测试悬架

在 Vehicle Dynamics Blockset™ 库中，有两种类型的悬架模块，用于实现根据仿真或实际实验室悬架测试测得的运动学与柔度（K and C）测试悬架特性。

| 模块 | **Suspension type** 设置 | 实现 |
| --- | --- | --- |
| Twist-Beam Suspension - K and C  Twist-Beam Suspension - K and C | `Independent front and twist-beam rear` | 以下项的运动学与柔度影响：  - 前车轴上带两个车轮的独立悬架 - 后车轴上带两个车轮的扭力梁悬架 |
| Independent Suspension - K and C  Independent Suspension - K and C | `Independent front and rear` | 四个独立悬架对具有两个车轴且每轴两个车轮的车辆的运动学与柔度影响。  有关详细信息，请参阅 Independent Suspension - K and C。 |

### K and C 对悬架的影响

为了确定对车辆和车轮的整体悬架力和几何效应，模块将来自运动学（bounce、roll、steering）和柔度（纵向和侧向力、回正力矩）输入的各个效应相加。具体而言，模块将悬架几何状态乘以梯度或表值，以确定 K and C 对车轮方向和悬架力的影响。

车轮方向：

- 外倾、后倾和转向角
- 侧向车轮中心位移
- 纵向车轮中心位移

垂直悬架力：

- 防倾杆
- 减振器力
- 车轮刚度
- 接触印迹摆臂（CPSA）力
- 纵向侧视摆臂（SVSA）抗效应

**外倾、后倾和转向角**

模块使用这些参数来考虑 K and C 对外倾、后倾和转向角的影响。

- **Bounce test**–独立悬架
- **Roll test**–独立悬架
- **Steer test**
- **Longitudinal compliance test**
- **Lateral compliance-opposed test**
- **Aligning torque compliance-opposed test**

使用 **Static alignment settings** 参数设置悬架的初始状态。

**侧向车轮中心位移**

模块使用这些参数来考虑 K and C 对侧向车轮中心位移的影响。

- **Bounce test**
- **Longitudinal compliance test**
- **Lateral compliance-opposed test**

**纵向车轮中心位移**

模块使用这些参数来考虑 K and C 对纵向车轮中心位移的影响。

- **Bounce test**
- **Longitudinal compliance test**

**减振器力**

模块使用 **Shock force** 参数计算减振器力对垂直悬架力的影响。您可以指定基于表的参数值或常数值。

**车轮刚度**

模块使用 **Bounce test** 参数计算车轮刚度对垂直悬架力的影响。

**接触印迹摆臂**

模块使用以下方程计算接触印迹摆臂（CPSA）力对垂直悬架力的影响。

tan(θCPSA)=f(Zw)FzCPSA=Fytan(θCPSA)

在 CPSA 力计算中，模块还使用 **Static loaded radius of wheels** 参数。

这些方程使用以下变量。

|  |  |
| --- | --- |
| *ϴCPSA* | 接触印迹摆臂角 |
| *Fy* | 侧向悬架力 |
| *FzCPSA* | CPSA 对垂直悬架力的影响 |
| *zw* | 车轮位移 |

**纵向侧视摆臂抗效应**

模块使用以下方程计算加速和制动期间侧视摆臂（SVSA）力对垂直悬架力的影响。

tan(θSVSA)=f(Zw)FzSVSA=Fxtan(θSVSA)

使用 **Drivetrain type** 参数确保模块将加速抗效应应用于正确的车轮。

这些方程使用以下变量。

|  |  |
| --- | --- |
| *ϴSVSA* | 接触印迹摆臂角 |
| *Fx* | 纵向车轮力 |
| *FzSVSA* | SVSA 对垂直悬架力的影响 |
| *zw* | 车轮位移 |

### 防倾杆

可选地，使用 **Anti-sway axle enable by axle, AntiSwayEnByAxl** 参数按车轴实现防倾杆反作用力。

如果未启用防倾杆，则车轴侧倾刚度为 0。

**前车轴**

如果在前车轴上启用防倾杆，则防倾杆刚度为防倾杆扭矩参数 **Front suspension roll stiffness with anti-roll bar, RollStiffArbFrnt** 与在无防倾杆时测得的侧倾刚度参数 **Front suspension roll stiffness without anti-roll bar, RollStiffNoArbFrnt** 之差。

**后车轴**

如果在后车轴上启用防倾杆，模块使用以下方程计算扭力梁侧倾刚度。

TBrs=Srs−π[12WR∇TW2]180

该方程使用以下变量。

|  |  |
| --- | --- |
| *TBrs* | 扭力梁侧倾刚度 |
| *Srs* | 无扭力梁的悬架侧倾刚度，**RollStiffNoTwstRear** 参数 |
| *WR∇* | 法向车轮刚度梯度，根据 **NrmlWhlRates** 参数和悬架位移计算 |
| *TW* | 轮距 |
