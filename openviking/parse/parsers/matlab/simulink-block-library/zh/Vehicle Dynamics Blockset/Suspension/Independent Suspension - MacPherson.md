# Independent Suspension - MacPherson

## 端口

### 输入

### **WhlPz** — 车轮 `z` 轴位移数组

车轮沿车轮固定 *z* 轴的位移，*zw*，单位为 m。数组维度为 `1` 乘以车辆上的车轮总数。

例如，对于每轴两个车轮的两轴车辆，`WhlPz`：

- 信号数组维度为 `[1x4]`。

  WhlPz=zw=[zw1,1zw1,2zw2,1zw2,2]

  | 车轮 | 数组元素 | 车轴 | 车轮编号 |
  | --- | --- | --- | --- |
  | 前左 | `WhlPz(1,1)` | `1` | `1` |
  | 前右 | `WhlPz(1,2)` | `1` | `2` |
  | 后左 | `WhlPz(1,3)` | `2` | `1` |
  | 后右 | `WhlPz(1,4)` | `2` | `2` |

### **WhlM** — 车轮上的悬架力矩数组

- `WhlM(1,...)` — 绕惯性固定 *x* 轴施加到车轮的悬架力矩（纵向）
- `WhlM(2,...)` — 绕惯性固定 *y* 轴施加到车轮的悬架力矩（侧向）

### **StrgAng** — 转向角，可选数组

每个车轮的可选转向角，*δ*。输入数组维度为 `1` 乘以转向车轮数。

例如，对于每轴两个车轮的两轴车辆，可以为第一轴上的两个车轮输入转向角。

- 要启用 **StrgAng** 端口，请将 **Steered axle enable by axle, StrgEnByAxl** 设置为 `[1 0]`。输入信号数组维度为 `[1x2]`。
- `StrgAng` 信号包含根据其车轴和车轮位置的两个转向角。

  StrgAng=δsteer=[δsteer1,1δsteer1,2]

  | 车轮 | 数组元素 | 车轴 | 车轮编号 |
  | --- | --- | --- | --- |
  | 前左 | `StrgAng(1,1)` | `1` | `1` |
  | 前右 | `StrgAng(1,2)` | `1` | `2` |

#### 依赖项

要启用端口 **StrgAng**，请将 **Steered axle enable by axle, StrgEnByAxl** 向量中的某个元素设置为 `1`。

### 悬架柔度和阻尼

该模块使用线性弹簧和阻尼器来建模悬架系统的
垂向动态效应。利用车辆和轮架的相对位置与速度，
模块计算作用在车轮和车辆上的垂向悬架力。模块使用一个线性方程，将垂向阻尼和柔度与
悬架高度、悬架高度变化率以及转向角
绝对值相关联。

模块实现以下方程。

Fwza,t=Fz0a+kza(zva,t−zwa,t+mhsteera|δsteera,t|)+c(z˙va,t−z˙wa,t)+Fzhstopa,t+Fzaswya,t

阻尼系数 *c* 取决于 **启用主动
阻尼** 参数设置。

| **启用主动阻尼** 设置 | 阻尼 |
| --- | --- |
| `off` | 恒定，*c* = *cza* |
| `on` | 查找表，是主动阻尼器占空比和执行器速度的函数  c=f(duty,(z˙va,t−z˙wa,t)) |

该模块假定悬架元件无质量。因此，施加到车辆的悬架力和力矩等于施加到车轮的悬架力和力矩。

Fvxa,t=Fwxa,tFvya,t=Fwya,tFvza,t=−Fwza,tMvxa,t=Mwxa,t+Fwya,t(Rewya,t+Ha,t)Mvya,t=Mwya,t+Fwxa,t(Rewxa,t+Ha,t)Mvza,t=Mwza,t

模块将车轮位置和速度设置为等于车辆的横向和
纵向位置与速度。

xwa,t=xva,tywa,t=yva,tx˙wa,t=x˙va,ty˙wa,t=y˙va,t

### 硬限位力

模块施加的硬限位反馈力 *Fzhstopa,t* 取决于悬架是在压缩还是在伸张。模块在以下情况下施力：

- 在压缩时，当悬架压缩量超过 **悬架最大高度, Hmax**
  参数指定的最大距离
- 在伸张时，当悬架伸张量大于 **悬架最大高度, Hmax**
  参数指定的最大伸张量

为计算该力，模块使用基于双曲正切和指数缩放的刚度。

| *zwa,t* | 沿惯性固定 *z* 轴，轴 `a`、车轮 `t` 处的车轮位移 |

### 功率与能量

该模块为每个轴 `a`、车轮 `t` 计算以下悬架特性。

| 计算 | 方程 |
| --- | --- |
| 耗散功率，*Psuspa,t* | Psuspa,t=Fwzlookupa(z˙va,t−z˙wa,t,z˙va,t−z˙wa,t,δsteera,t) |
| 吸收能量，*Esuspa,t* | Esuspa,t=Fwzlookupa(z˙va,t−z˙wa,t,z˙va,t−z˙wa,t,δsteera,t) |
| 悬架高度，*Ha,t* | Ha,t=−(zva,t−zwa,t+Fz0akza+mhsteera|δsteera,t|) |
| 从轮架中心到轮胎/道路接触面的距离 | zwtra,t=Rewa,t+Ha,t |

这些方程使用以下变量。

|  |  |
| --- | --- |
| *mhsteera* | 施加在轴 `a` 上车轮轮架处的转向角对垂向力的斜率 |
| *δsteera,t* | 轴 `a`、车轮 `t` 的转向角输入 |
| *Rewa,t* | 轴 `a`、车轮 `t` 从轮架中心到轮胎/道路接触面的有效车轮半径 |
| *Fz0a* | 施加在轴 `a` 上车轮的垂向悬架弹簧预载力 |
| *zwtra,t* | 沿惯性固定 *z* 轴，从轮架中心到轮胎/道路接触面的距离 |
| *zva,t*, *żva,t* | 沿惯性固定 *z* 轴，轴 `a`、车轮 `t` 处的车辆位移和速度 |
| *zwa,t*, *żwa,t* | 沿惯性固定 *z* 轴，轴 `a`、车轮 `t` 处的车轮位移和速度 |
