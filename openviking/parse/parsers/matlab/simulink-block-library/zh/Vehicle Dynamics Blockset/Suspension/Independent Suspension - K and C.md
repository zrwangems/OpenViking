# Independent Suspension - K and C

## 端口

### 输入

### **WhlPz** — 车轮 `z` 轴位移数组

车轮位移 *zw*，沿车轮固定的 *z* 轴方向，单位为 m。数组维度为 `1` 乘以车辆上车轮总数。

例如，对于每轴两个车轮的两轴车辆，`WhlPz`：

- 信号数组维度为 `[1x4]`。

  WhlPz=zw=[zw1,1zw1,2zw2,1zw2,2]

  | 车轮 | 数组元素 | 轴 | 车轮编号 |

  | 后右 | `WhlPz(1,4)` | `2` | `2` |

### **WhlM** — 车轮阵列上的悬架力矩

- `WhlM(1,...)` — 施加于车轮的绕惯性固定 *x* 轴的悬架力矩（纵向）
- `WhlM(2,...)` — 施加于车轮的绕惯性固定 *y* 轴的悬架力矩（横向）

### **StrgAng** — 转向角，可选数组

每个车轮的可选转向角，*δ*。
输入数组维度为 `1` 乘以
转向车轮数。

例如，对于每轴两个车轮的两轴车辆，您可以输入第一轴上两个车轮的转向角。

- 要启用 **StrgAng** 端口，请将 **Steered axle enable by
  axle, StrgEnByAxl** 设置为 `[1 0]`。输入信号数组
  维度为 `[1x2]`。
- `StrgAng` 信号包含两个转向角，按其车轴和车轮位置排列。

  StrgAng=δsteer=[δsteer1,1δsteer1,2]

  | 左前 | `StrgAng(1,1)` | `1` | `1` |
  | 右前 | `StrgAng(1,2)` | `1` | `2` |

#### 依赖关系

要启用端口 **StrgAng**，请将 **Steered axle
enable by axle, StrgEnByAxl** 向量的一个元素设置为 `1`。

## 描述

独立运动学与柔度测试悬架

在 Vehicle Dynamics Blockset™ 库中，有两种类型的悬架模块，用于实现从仿真或实际实验室悬架测试中测得的运动学与柔度（K and C）测试悬架特性。

| 模块 | **Suspension type** 设置 | 实现 |
| --- | --- | --- |
| Twist-Beam Suspension - K and C  Twist-Beam Suspension - K and C | `Independent front and twist-beam rear` | 以下部件的运动学与柔度效应：  - 前轴上带两个车轮的独立悬架 - 后轴上带两个车轮的扭转梁悬架    有关详细信息，请参阅 Twist-Beam Suspension - K and C。 |
| Independent Suspension - K and C  Independent Suspension - K and C | `Independent front and rear` | 四独立悬架在具有两个车轴且每轴两个车轮的车辆上的运动学与柔度效应。 |

### K and C Effects on Suspension

为确定悬架对车辆和车轮的整体作用力及几何效应，该模块将来自运动学（跳动、侧倾、转向）和柔度（纵向力与侧向力、回正力矩）输入的各个效应相加。具体而言，该模块将悬架几何状态乘以梯度值或表格值，以确定 K 和 C 效应对车轮姿态及悬架力的影响。

车轮姿态：

- 外倾角、主销后倾角和转向角
- 车轮中心侧向位移
- 车轮中心纵向位移

垂直悬架力：

- 防倾杆
- 减振器力
- 车轮刚度
- 接地点摆臂（CPSA）力
- 纵向侧视摆臂（SVSA）抗效应

**外倾角、主销后倾角和转向角**

该模块使用以下参数来考虑 K 和 C 效应对外倾角、主销后倾角和转向角的影响。

- **跳动测试**– 独立悬架
- **侧倾测试**– 独立悬架
- **转向测试**
- **纵向柔度测试**
- **侧向柔度对置测试**
- **回正力矩柔度对置测试**

使用 **Static alignment settings** 参数设置悬架的初始状态。

**车轮中心侧向位移**

该模块使用以下参数来考虑 K 和 C 效应对车轮中心侧向位移的影响。

- **跳动测试**
- **纵向柔度测试**
- **侧向柔度对置测试**

**车轮中心纵向位移**

该模块使用以下参数来考虑 K 和 C 效应对车轮中心纵向位移的影响。

- **跳动测试**
- **纵向柔度测试**

**减振器力**

该模块使用 **Shock force** 参数计算减振器力对垂直悬架力的影响。您可以指定基于表格的参数值或常量参数值。

**车轮刚度**

该模块使用 **Bounce test** 参数计算车轮刚度对垂直悬架力的影响。

**接地点摆臂**

该模块使用以下方程计算接地点摆臂（CPSA）力对垂直悬架力的影响。

tan(θCPSA)=f(Zw)FzCPSA=Fytan(θCPSA)

该模块还在 CPSA 力计算中使用 **Static loaded radius of
wheels** 参数。

这些方程使用以下变量。

|  |  |
| --- | --- |
| *ϴCPSA* | 接地点摆臂角 |
| *Fy* | 侧向悬架力 |
| *FzCPSA* | CPSA 对垂直悬架力的影响 |
| *zw* | 车轮位移 |

**纵向侧视摆臂抗效应**

该模块使用以下方程计算加速和制动期间侧视摆臂（SVSA）力对垂直悬架力的影响。

tan(θSVSA)=f(Zw)FzSVSA=Fxtan(θSVSA)

使用 **Drivetrain type** 参数确保该模块将加速抗效应施加到正确的车轮。

这些方程使用以下变量。

|  |  |
| --- | --- |
| *ϴSVSA* | 接地点摆臂角 |
| *Fx* | 纵向车轮力 |
| *FzSVSA* | SVSA 对垂直悬架力的影响 |
| *zw* | 车轮位移 |

### Anti-Sway Bar

可选地，使用 **Anti-sway axle enable by axle,
AntiSwayEnByAxl** 参数按车轴实现防倾杆反作用力。

如果您在车轴上启用防倾杆，则防倾杆刚度为防倾杆力矩参数 **Suspension roll stiffness with anti-roll bar,
RollStiffArb** 与在无防倾杆情况下测得的侧倾刚度参数 **Suspension roll stiffness without anti-roll bar,
RollStiffNoArb** 之间的差值。

如果您未启用防倾杆，则侧倾刚度为 0。
