# Solid Axle Suspension - Mapped

## 端口

### 输入

### **WhlPz** — 车轮 `z` 轴位移数组

车轮位移 *zw*，沿车轮固定 *z* 轴方向，单位为 m。数组维度为 `1` 乘以车辆上车轮总数。

例如，对于每轴两个车轮的两轴车辆，`WhlPz`：

- 信号数组维度为 `[1x4]`。

  WhlPz=zw=[zw1,1zw1,2zw2,1zw2,2]

  | 车轮 | 数组元素 | 轴 | 车轮编号 |

### **WhlM** — 车轮阵列上的悬架力矩

- `WhlM(1,...)` — 施加于车轮的、绕惯性固定 *x* 轴的悬架力矩（纵向）
- `WhlM(2,...)` — 施加于车轮的、绕惯性固定 *y* 轴的悬架力矩（横向）

### **StrgAng** — 转向角，可选数组

每个车轮的可选转向角，*δ*。
输入数组维度为 `1` 乘以转向车轮数。

例如，对于每轴两个车轮的两轴车辆，您可以为第一轴上的两个车轮输入转向角。

- 要启用 **StrgAng** 端口，请将 **Steered axle enable by
  axle, StrgEnByAxl** 设置为 `[1 0]`。输入信号数组
  维度为 `[1x2]`。
- `StrgAng` 信号包含两个转向角，按其车轴和车轮位置排列。

  StrgAng=δsteer=[δsteer1,1δsteer1,2]

  | 车轮 | 数组元素 | 车轴 | 车轮编号 |
  | --- | --- | --- | --- |
  | 左前 | `StrgAng(1,1)` | `1` | `1` |
  | 右前 | `StrgAng(1,2)` | `1` | `2` |

#### 依赖关系

要启用端口 **StrgAng**，请将 **Steered axle
enable by axle, StrgEnByAxl** 向量的一个元素设置为 `1`。

## 描述

映射式整体桥悬架

Solid Axle Suspension - Mapped 模块为多轴、每轴多轮车辆实现映射式整体桥悬架。

该模块将悬架柔度、阻尼和几何效应建模为车轮位置和速度的函数，并使用各轴特定的柔度和阻尼参数。利用车轮位置和速度，该模块计算车轮垂向位置以及作用在车辆和车轮上的悬架力。该模块使用 *Z* 向下坐标系（定义于 SAE J670）和整体桥坐标系。整体桥坐标系与 *Z* 向下车辆坐标系对齐，其 *x* 轴指向车辆前进方向。

该模块使用一个查找表，将垂向阻尼和柔度与悬架高度、悬架高度变化率以及转向角关联起来。您可以校准车轮力查找表，使得转向角从标称中心位置变化时产生一个增加车辆高度的力。具体而言，该模块：

| 使用 | 用于计算 |
| --- | --- |
| - 车辆的纵向和横向位移与速度。 - 车轮的纵向和横向位移与速度。 - 施加在车辆上的垂向车轮力。 | - 施加在车轴中心的悬架力。 - 车辆和车轮的垂向位移与速度。 - 施加在车辆上的纵向、横向和垂向悬架力与力矩。 - 施加在车轮上的纵向、横向和垂向悬架力与力矩。 |

### Camber, Caster, and Toe Angles

为了计算外倾角、主销后倾角和前束角，该模块使用查找表 *Galookup*，它是悬架高度和转向角的函数。

[ξa,tηa,tζa,t]=Galookupf(zwa,t−zva,t,δsteera,t)

这些方程使用以下变量。

|  |  |
| --- | --- |
| *ξa,t* | 车轴 `a`、车轮 `t` 上车轮的外倾角 |
| *ηa,t* | 车轴 `a`、车轮 `t` 上车轮的主销后倾角 |
| *ζa,t* | 车轴 `a`、车轮 `t` 上车轮的前束角 |
| *δsteera,t* | 车轴 `a`、车轮 `t` 的转向角输入 |
| *zva,t* | 车轴 `a`、车轮 `t` 处车辆沿惯性固定 *z* 轴的位移 |
| *zwa,t* | 车轴 `a`、车轮 `t` 处车轮沿惯性固定 *z* 轴的位移 |

### Steering Angles

可选地，您可以输入车轮的转向角。为了计算车轮的转向角，该模块根据悬架高度对输入转向角进行偏移。对于该计算，该模块使用查找表 *Galookup*，它是悬架位置和转向角的函数。

δwhlsteera,t=δsteera,t+Galookupf(zwa,t−zva,t,δsteera,t)

该方程使用以下变量。

|  |  |
| --- | --- |
| *δwhlsteera,t* | 车轴 `a`、车轮 `t` 的车轮转向角 |
| *δsteera,t* | 车轴 `a`、车轮 `t` 的转向角输入 |
| *zva,t* | 车轴 `a`、车轮 `t` 处车辆沿惯性固定 *z* 轴的位移 |
| *zwa,t* | 车轴 `a`、车轮 `t` 处车轮沿惯性固定 *z* 轴的位移 |
