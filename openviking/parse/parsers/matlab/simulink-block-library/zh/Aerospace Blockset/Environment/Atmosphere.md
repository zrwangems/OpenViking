# Environment

Environment

模拟环境的不同方面，例如大气条件、重力、磁场、风

使用基于环境标准的参考模型来建模标准大气、重力和磁场剖面，并实现标准风条件。使用星历数据计算天体的位置和速度。

## Categories

- Atmosphere
  实现通用大气剖面，例如 ISA、COESA；非标准日模拟；递减率大气；压力高度
- Gravity
  计算地球上任意点的重力和磁场
- Wind
  实现与风相关的仿真，例如湍流、阵风、切变、水平风
- Celestial Phenomena
  计算天体的位置和速度
