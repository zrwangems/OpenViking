### 输出

### **Translation** — 多旋翼平移 `11`-by-`3` 数组

多旋翼的旋翼飞行器平移，返回为 `11`-by-`3` 数组。信号包含平移 [*X*, *Y*, *Z*]，以 meters 为单位，数组的每一行对应旋翼飞行器的一个骨骼。

该平移适用于 `Multirotor` 类型的以下骨骼。

| 骨骼 | 索引 |
| --- | --- |
| BODY | 1 |
| ROTOR1 | 2 |
| ROTOR2 | 3 |
| ROTOR3 | 4 |
| ROTOR4 | 5 |
| ROTOR5 | 6 |
| ROTOR6 | 7 |
| ROTOR7 | 8 |
| ROTOR8 | 9 |
| SENSOR1 | 10 |
| SENSOR2 | 11 |

### **Rotation** — 旋翼飞行器旋转 `11`-by-`3` 数组

多旋翼的旋翼飞行器旋转，返回为 `11`-by-`3` 数组：

该旋转适用于与 Translation 端口列出的相同骨骼。

信号包含旋转 [roll, pitch, yaw]，以 radians 为单位，数组的每一行对应旋翼飞行器的一个骨骼。

## 版本历史

**在 R2023b 中引入**

### R2025a：Simulation 3D Multirotor Pack 模块现在与 Simulation 3D Scene Configuration 模块同步坐标系

Simulation 3D Multirotor Pack 模块具有以下更改：

- **地理空间** 选项卡已重命名为 **输入** 选项卡。
- 在 **输入** 选项卡上，**选择输入坐标系** 窗格现在包含这些坐标系按钮：

  - **Fixed-frame** — Fixed-frame 坐标系。当您选择此坐标系时，注释 `Fixed-frame` 将出现在 pack 模块图标下方。
  - **ICRF** — International Celestial Reference Frame 坐标系。当您选择此坐标系时，注释 `ICRF` 将出现在 pack 模块图标下方。
  - **NED** — North-east-down 坐标系。当您选择此坐标系时，注释 `NED` 将出现在 pack 模块图标下方。

  如果模型包含 Simulation 3D pack 模块和关联的 Simulation 3D Scene Configuration 模块，则 Simulation 3D Multirotor Pack 的 **输入** 选项卡选项可能被禁用。在这种情况下，Simulation 3D Multirotor Pack 会与 Simulation 3D Scene Configuration 模块同步坐标系。
- 坐标系在模块下方显示为注释。
- **启用地理空间校正** 和 **x 轴方向（degrees，从北顺时针）** 参数已被移除。

### R2024a：Simulation 3D Multirotor Pack 模块现在支持 Earth-centered Earth-fixed (ECEF) 输入坐标系

为了为平移输入启用 ECEF 坐标系，Simulation 3D Multirotor Pack 模块已更新。将这些参数与 Simulation 3D Scene Configuration 模块中的 **使用地心作为原点 (ECEF)** 参数一起使用。

- **选择输入坐标系**

  - **ECEF** — ECEF 输入坐标系。当您选择此坐标系时，注释 `Origin: Earth center (ECEF)` 将出现在 pack 模块图标下方。
  - **NED** — NED 坐标系。在 R2024a 之前，NED 是唯一受支持的坐标系。
- **x 轴方向（degrees，从北顺时针）** — *x* 轴的方向。当您选中 **启用地理空间校正** 复选框时，此参数启用。

## 描述

为多旋翼飞行器生成平移和旋转信息

Simulation 3D Multirotor Pack 模块为 **类型** 设置为 `Multirotor` 的 Simulation 3D Rotorcraft 模块创建平移和旋转信息。使用 Simulation 3D Multirotor Pack 模块向 Simulation 3D Rotorcraft 模块的 **Translation** 和 **Rotation** 输入端口提供平移和旋转信息。
