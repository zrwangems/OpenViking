### 输出

### **Translation** — 多旋翼平移 `11`×`3` 数组

多旋翼的旋翼飞行器平移，以
`11`×`3` 数组形式返回。该信号包含平移
[*X*、*Y*、*Z*]，单位为米，
数组的每一行对应旋翼飞行器的一个骨骼。

该平移适用于
`Multirotor` 类型的以下骨骼。

| 骨骼 | 索引 |
| --- | --- |
| BODY | 1 |
| ROTOR1 | 2 |
| ROTOR2 | 3 |
| ROTOR3 | 4 |
| ROTOR4 | 5 |
| ROTOR5 | 6 |
| ROTOR6 | 7 |
| ROTOR7 | 8 |
| ROTOR8 | 9 |
| SENSOR1 | 10 |
| SENSOR2 | 11 |

### **Rotation** — 旋翼飞行器旋转 `11`×`3` 数组

多旋翼的旋翼飞行器旋转，以
`11`×`3` 数组形式返回：

该旋转适用于 Translation 端口所列出的相同骨骼。

该信号包含旋转 [roll、pitch、yaw]，单位为弧度，数组的每一行
对应旋翼飞行器的一个骨骼。

**Select input coordinate frame** 可能被禁用。有关
Simulation 3D Multirotor Pack 模块坐标系的详细信息，请参阅算法。

## 版本历史

**在 R2023b 中引入**

### R2025a：Simulation 3D Multirotor Pack 模块现在与 Simulation 3D Scene Configuration 模块同步坐标系

Simulation 3D Multirotor Pack 模块有以下变更：

- **Geospatial** 选项卡已重命名为 **Input** 选项卡。
- 在 **Input** 选项卡上，**Select input coordinate frame** 窗格现在包含以下坐标系按钮：

  - **Fixed-frame** — 固定坐标系。当
    您选择此坐标系时，注释
    `Fixed-frame` 会出现在 pack 模块
    图标下方。
  - **ICRF** — 国际天球参考系坐标系。当您选择此坐标系时，注释 `ICRF` 会出现在 pack 模块图标下方。
  - **NED** — 北-东-地坐标系。当您选择此坐标系时，注释 `NED` 会出现在 pack 模块图标下方。

  如果模型包含 Simulation 3D pack 模块和关联的 Simulation 3D Scene
  Configuration 模块，则
  Simulation 3D Multirotor Pack 的 **Input** 选项卡选项可能被禁用。在这种情况下，
  Simulation 3D Multirotor Pack 会与
  Simulation 3D Scene Configuration 模块同步坐标系。
- 坐标系显示为模块下方的注释。
- **Enable geospatial correction** 和 **Direction of x-axis (degrees clockwise from north)** 参数已被移除。

### R2024a：Simulation 3D Multirotor Pack 模块现在支持地心地球固定（ECEF）输入坐标系

为了支持用于平移输入的 ECEF 坐标系，Simulation 3D Multirotor Pack 模块
已更新。请将这些参数与 Simulation 3D Scene
Configuration 模块中的 **Use Earth center as origin
(ECEF)** 参数一起使用。

- **选择输入坐标系**

  - **ECEF** — ECEF 输入坐标系。当您选择此坐标系时，注释 `Origin: Earth center (ECEF)` 会出现在 pack 模块图标下方。
  - **NED** — NED 坐标系。在 R2024a 之前，NED 是唯一支持的坐标系。
- **Direction of x-axis (degrees clockwise from north)** — *x* 轴方向。当您选中 **Enable geospatial correction** 复选框时，此参数启用。

## 描述

为多旋翼旋翼飞行器生成平移和旋转信息

Simulation 3D Multirotor Pack 模块为 **Type** 设置为 `Multirotor` 的 Simulation 3D Rotorcraft 模块创建平移和旋转
信息。使用
Simulation 3D Multirotor Pack 模块向 Simulation 3D Rotorcraft 模块的 **Translation** 和 **Rotation** 输入
端口提供平移和旋转
信息。
