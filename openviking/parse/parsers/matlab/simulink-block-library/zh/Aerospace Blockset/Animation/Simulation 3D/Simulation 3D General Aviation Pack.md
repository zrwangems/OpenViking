### 输出

### **Translation** — 飞机平移 `15`-by-`3` 数组

General Aviation 飞机的平移，返回为 `15`-by-`3` 数组。该信号包含平移 [*X*, *Y*, *Z*]，以 meters 为单位，数组的每一行对应飞机的一个骨骼。

平移应用于 `General Aviation` 类型的以下骨骼。

| 骨骼 | 索引 |
| --- | --- |
| BODY | 1 |
| ENGINE1 | 2 |
| RUDDER | 3 |
| ELEVATOR | 4 |
| LEFT\_AILERON | 5 |
| RIGHT\_AILERON | 6 |
| FLAPS | 7 |
| LEFT\_SPOILER | 8 |
| RIGHT\_SPOILER | 9 |
| NOSE\_GEAR | 10 |
| NOSE\_WHEEL | 11 |
| LEFT\_GEAR | 12 |
| LEFT\_WHEEL | 13 |
| RIGHT\_GEAR | 14 |
| RIGHT\_WHEEL | 15 |

### **Rotation** — 飞机旋转 `15`-by-`3` 数组

General Aviation 飞机的旋转，返回为 `15`-by-`3` 数组：

旋转应用于与 Translation 端口列出的相同骨骼。

该信号包含旋转 [roll, pitch, yaw]，以 radians 为单位，数组的每一行对应飞机的一个骨骼。

## 版本历史

### R2025a：Simulation 3D General Aviation Pack 模块现在与 Simulation 3D Scene Configuration 模块同步坐标系

Simulation 3D General Aviation Pack 模块具有以下更改：

- **地理空间** 选项卡已重命名为 **输入** 选项卡。
- 在 **输入** 选项卡上，**选择输入坐标系** 窗格现在包含以下坐标系按钮：

  - **Fixed-frame** — Fixed-frame 坐标系。选择此坐标系时，注释 `Fixed-frame` 将显示在 pack 模块图标下方。
  - **ICRF** — 国际天球参考系坐标系。选择此坐标系时，注释 `ICRF` 将显示在 pack 模块图标下方。
  - **NED** — 北-东-地坐标系。选择此坐标系时，注释 `NED` 将显示在 pack 模块图标下方。

  如果模型包含 Simulation 3D pack 模块和关联的 Simulation 3D Scene Configuration 模块，则 Simulation 3D General Aviation Pack 的 **输入** 选项卡选项可能被禁用。在这种情况下，Simulation 3D General Aviation Pack 会与 Simulation 3D Scene Configuration 模块同步坐标系。
- 坐标系在模块下方显示为注释。
- **启用地理空间校正** 和 **x 轴方向（从北顺时针的度数）** 参数已被移除。

### R2024a：Simulation 3D General Aviation Pack 模块现在支持地心地固 (ECEF) 输入坐标系

为支持用于平移输入的 ECEF 坐标系，Simulation 3D General Aviation Pack 模块已更新。请将这些参数与 Simulation 3D Scene Configuration 模块中的 **使用地心作为原点 (ECEF)** 参数一起使用。

- **选择输入坐标系**

  - **ECEF** — ECEF 输入坐标系。选择此坐标系时，注释 `Origin: Earth center (ECEF)` 将显示在 pack 模块图标下方。
  - **NED** — NED 坐标系。在 R2024a 之前，NED 是唯一支持的坐标系。
- **x 轴方向（从北顺时针的度数）** — *x* 轴的方向。当您选择 **启用地理空间校正** 复选框时，此参数启用。

## 描述

为通用航空飞机生成平移和旋转信息

Simulation 3D General Aviation Pack 模块为 **类型** 设置为 `General aviation` 的 Simulation 3D Aircraft 模块创建平移和旋转信息。使用 Simulation 3D General Aviation Pack 模块向 Simulation 3D Aircraft 模块的 **Translation** 和 **Rotation** 输入端口提供平移和旋转信息。
