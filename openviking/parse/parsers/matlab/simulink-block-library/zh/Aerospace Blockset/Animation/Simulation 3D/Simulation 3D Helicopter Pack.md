### 输出

### **Translation** — 直升机平移 `19`-by-`3` 数组

直升机旋翼航空器的直升机平移，返回为 `19`-by-`3` 数组。该信号包含平移 [*X*, *Y*, *Z*]，以 meters 为单位，数组的每一行对应旋翼航空器的一个骨骼。

平移适用于 `Helicopter` 类型的以下骨骼。

| 骨骼 | 索引 |
| --- | --- |
| BODY | 1 |
| ENGINE1 | 2 |
| ENGINE2 | 3 |
| ROTOR1 | 4 |
| ROTOR2 | 5 |
| NOSE\_GEAR | 6 |
| NOSE\_WHEEL | 7 |
| NOSE\_GEAR\_DOOR1 | 8 |
| NOSE\_GEAR\_DOOR2 | 9 |
| LEFT\_GEAR | 10 |
| LEFT\_WHEEL | 11 |
| LEFT\_GEAR\_DOOR1 | 12 |
| LEFT\_GEAR\_DOOR2 | 13 |
| RIGHT\_GEAR | 14 |
| RIGHT\_WHEEL | 15 |
| RIGHT\_GEAR\_DOOR1 | 16 |
| RIGHT\_GEAR\_DOOR2 | 17 |
| SENSOR1 | 18 |
| SENSOR2 | 19 |

### **Rotation** — 旋翼航空器旋转 `19`-by-`3` 数组

直升机旋翼航空器的旋翼航空器旋转，返回为 `19`-by-`3` 数组。

该旋转适用于与 Translation 端口所列相同的骨骼。

该信号包含旋转 [roll, pitch, yaw]，以 radians 为单位，数组的每一行对应旋翼航空器的一个骨骼。

## 版本历史

**在 R2023b 中引入**

### R2025a：Simulation 3D Helicopter Pack 模块现在与 Simulation 3D Scene Configuration 模块同步坐标系

Simulation 3D Helicopter Pack 模块有以下更改：

- **地理空间** 选项卡已重命名为 **输入** 选项卡。
- 在 **输入** 选项卡上，**选择输入坐标系** 窗格现在包含这些坐标系按钮：

  - **Fixed-frame** — Fixed-frame 坐标系。选择此坐标系时，注释 `Fixed-frame` 会出现在 pack 模块图标下。
  - **ICRF** — 国际天球参考系坐标系。选择此坐标系时，注释 `ICRF` 会出现在 pack 模块图标下。
  - **NED** — 北-东-地坐标系。选择此坐标系时，注释 `NED` 会出现在 pack 模块图标下。

  如果模型包含 Simulation 3D pack 模块和关联的 Simulation 3D Scene Configuration 模块，则 Simulation 3D Helicopter Pack 的 **输入** 选项卡选项可能被禁用。在这种情况下，Simulation 3D Helicopter Pack 会与 Simulation 3D Scene Configuration 模块同步坐标系。
- 坐标系显示为模块下方的注释。
- **启用地理空间校正** 和 **x-axis 方向（从北顺时针的 degrees）** 参数已被移除。

### R2024a：Simulation 3D Helicopter Pack 模块现在支持 Earth-centered Earth-fixed (ECEF) 输入坐标系

要为平移输入启用 ECEF 坐标系，已更新 Simulation 3D Helicopter Pack 模块。将下列参数与 Simulation 3D Scene Configuration 模块中的 **Use Earth center as origin (ECEF)** 参数一起使用。

- **Select input coordinate frame**

  - **ECEF** — ECEF 输入坐标系。选择此坐标系时，注释 `Origin: Earth center (ECEF)` 会出现在 pack 模块图标下。
  - **NED** — NED 坐标系。在 R2024a 之前，NED 是唯一支持的坐标系。
- **Direction of x-axis (degrees clockwise from north)** — *x* 轴方向。选择 **Enable geospatial correction** 复选框时，将启用此参数。

## 描述

为直升机生成平移和旋转信息

Simulation 3D Helicopter Pack 模块为 **Type** 设置为 `Helicopter` 的 Simulation 3D Rotorcraft 模块创建平移和旋转信息。使用 Simulation 3D Helicopter Pack 模块将平移和旋转信息提供给 Simulation 3D Rotorcraft 模块的 **Translation** 和 **Rotation** 输入端口。
