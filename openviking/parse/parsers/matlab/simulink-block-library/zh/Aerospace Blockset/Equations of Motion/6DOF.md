# 6DOF Library

6DOF

在仿真中使用欧拉角和四元数表示实现六自由度运动方程

对固定质量或变质量大气飞行器的点质量和六自由度动力学进行建模与仿真。定义机体坐标系、风坐标系和地心固连（ECEF）坐标系中的运动方程表示。在坐标系之间进行变换并执行单位换算，以确保模型一致性。
