# Three-axis Inertial Measurement Unit

## 端口

### 输入

### **Ab** — 实际加速度三元素向量

机体轴系中的实际加速度，指定为三元素向量，单位由 **单位** 参数指定。

**数据类型：** `double`

### **ω** — 角速率三元素向量

机体轴系中的角速率，指定为三元素向量，单位为 radians per second。

**数据类型：** `double`

### **dω/dt** — 角加速度三元素向量

机体轴系中的角加速度，指定为三元素向量，单位为 radians per second squared。

**数据类型：** `double`

### **CG** — 重心位置三元素向量

重心位置，指定为三元素向量，单位由 **单位** 参数指定。

**数据类型：** `double`

### **g** — 重力三元素向量

机体轴系中的重力，指定为三元素向量，单位由 **单位** 参数指定。

**数据类型：** `double`

### 输出

### **Ameas** — 测量加速度三元素向量

来自加速度计的测量加速度，返回为三元素向量，单位由 **单位** 参数指定。

**数据类型：** `double`

### **ωmeas** — 测量角速率三元素向量

来自陀螺仪的测量角速率，返回为三元素向量，单位为 radians per second。

**数据类型：** `double`

## 参数

### **单位** — 单位 `Metric (MKS)` (默认) | `English`

输入和输出单位，指定为：

| 单位 | 加速度 | 长度 |
| --- | --- | --- |
| `Metric (MKS)` | Meters per second squared | Meters |
| `English` (British Imperial) | Feet per second squared | Feet |

#### 编程用法

|  |
| --- |
| **模块参数**: `units` |
| **类型**: character vector |
| **值**: `'Metric (MKS)'` | `'English'` |
| **默认**: `'Metric (MKS)'` |

### **IMU 位置** — IMU 位置 `[0 0 0]` (默认) | 三元素向量

IMU 的位置（也是加速度计组位置）是从零基准（通常为机头）向后、沿垂直中心线向右、并沿水平中心线向上测量的。此测量参考与重心输入相同。单位由 **单位** 参数指定。

#### 编程用法

|  |
| --- |
| **模块参数**: `imu` |
| **类型**: character vector |
| **值**: 三元素向量 |
| **默认**: `'[0 0 0]'` |

### **更新速率 (sec)** — 更新速率 `0` (默认) | 标量

加速度计和陀螺仪的更新速率，指定为 double 标量，单位为 seconds。更新速率为 0 会创建连续加速度计和连续陀螺仪。如果选中 **噪声开启** 复选框且更新速率为 0，则模块以 0.1 的速率更新噪声。

**提示**

如果：

- 将此参数值更新为 0（连续）
- 为模型配置固定步长求解器

则还必须选中 **求解器** 窗格中的 **自动处理数据传输的速率转换** 复选框。此复选框使软件能够正确处理速率转换。

## 描述

实现三轴惯性测量单元 (IMU)

Three-Axis Inertial Measurement Unit 模块实现包含三轴加速度计和三轴陀螺仪的惯性测量单元 (IMU)。

有关方程和误差应用的描述，请参阅 Three-axis Accelerometer 和 Three-axis Gyroscope。

Three-axis Inertial Measurement Unit 模块图标显示从 **单位** 参数选择的输入和输出单位。
