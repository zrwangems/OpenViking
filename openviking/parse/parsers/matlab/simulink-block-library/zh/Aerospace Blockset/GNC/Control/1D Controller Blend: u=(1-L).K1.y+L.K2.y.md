# 1D Controller Blend u=(1-L).K1.y+L.K2.y

## 端口

### 输入

### **y** — 飞行器测量向量

飞行器测量，指定为向量。

**数据类型：** `double`

### **v** — 调度变量向量

调度变量，指定为向量，且与状态空间矩阵的维度一致。

**数据类型：** `double`
### 输出

### **u** — 执行机构需求向量

执行机构需求，指定为向量。

**数据类型：** `double`

### **A 矩阵(v)** — 状态空间实现的 *A* 矩阵 `A1`（默认）| array

状态空间实现的 *A* 矩阵，指定为数组。在一维混合的情况下，*A* 矩阵应具有三个维度，最后一个维度对应于调度变量 *v*。例如，如果对应于 *v* 的第一个条目的 *A* 矩阵为单位矩阵，则 `A(:,:,1) = [1 0;0 1];`。

## 描述

通过线性插值状态空间控制器的输出，实现状态空间控制器的一维向量

1D Controller Blend u=(1-L).K1.y+L.K2.y 模块实现状态空间控制器设计的数组。模型并行运行这些控制器，并根据当前飞行条件或工作点对其输出进行插值。这种实现方法的优点是，各个控制器设计的状态空间矩阵 *A*、*B*、*C* 和 *D* 不需要从一个设计点到下一个设计点平滑变化。该模块的输出是执行机构需求，您可以将其输入到执行机构模块。
