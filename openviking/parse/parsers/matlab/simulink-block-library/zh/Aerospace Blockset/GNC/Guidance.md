# Guidance, Navigation, and Control (GNC)

Guidance, Navigation, and Control (GNC)

对制导、导航与控制（GNC）系统进行建模，包括控制器

使用制导模块计算两个飞行器之间的距离，使用控制器模块控制飞行器的运动，例如飞行器路径、位置和速度，以及作用在飞行器上的力。使用导航模块对每个三轴上的加速度计、陀螺仪和惯性测量单元（IMU）进行建模；IMU 包含一个三轴加速度计和一个三轴陀螺仪。实现 pilot crossover、precision 和 Tustin 模型。

## Categories

- Guidance
  计算两个飞行器之间的距离
- Navigation
  实现加速度、角速率、惯量的三轴测量
- Control
  仿真各种控制器，例如一维、二维、三维类型
- Actuators
  表示具有饱和和速率限制的线性与非线性执行机构
- Pilot Models
  实现 pilot 模型
- Flight Control Analysis
  分析航空航天飞行器的运动与动力学
- Flight Parameters
  计算航空航天参数，例如理想空速修正、Mach 数、动压
