# Three-axis Gyroscope

## 端口

### 输入

### **ω** — 角速率三元向量

在机体坐标系中的角速率，指定为三元向量，单位为弧度每秒。

**数据类型：** `double`

### **G's** — 加速度三元向量

在机体坐标系中的加速度，指定为三元向量，单位为 G。

**数据类型：** `double`
### 输出

### **ωmeas** — 测量角速率三元向量

陀螺仪输出的测量角速率，以三元向量形式返回，单位为弧度每秒。

**数据类型：** `double`

## 参数

### **Second order dynamics** — 二阶动力学 `on`（默认）| `off`

要对陀螺仪读数应用二阶动力学，请选中此复选框。

### **Update rate (sec)** — 更新速率 `0`（默认）| 标量

陀螺仪的更新速率，指定为双精度标量，单位为秒。更新速率为 0 时创建连续陀螺仪。如果选中 **Noise on** 复选框且更新速率为 0，则模块以 0.1 的速率更新噪声。

**提示**

如果您：

- 将此参数值更新为 0（连续）
- 为模型配置固定步长求解器

则还必须在 **Solver** 窗格中选中 **Automatically handle rate transition for data transfer** 复选框。此复选框使软件能够正确处理速率转换。

## 描述

实现三轴陀螺仪

Three-Axis Gyroscope 模块在三个轴的每一个上实现一个陀螺仪。有关测量机体角速率的详细信息，请参阅 Algorithms。

可选地，要对模块输入和动力学应用离散化以及测量机体角速率的非线性化，请使用 Saturation 模块。
