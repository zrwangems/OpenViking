# 2D Controller [A(v),B(v),C(v),D(v)]

## 端口
```yaml
ports:
- name: y
  summary: 飞行器测量向量
  direction: input
  data_types: double
- name: v1
  summary: 调度变量向量
  direction: input
  data_types: double
- name: v2
  summary: 调度变量向量
  direction: input
  data_types: double
- name: u
  summary: 作动器需求向量
  direction: output
  data_types: double
```

### 输入

### **y** — 飞行器测量向量

飞行器测量值，指定为向量。

**数据类型：** `double`

### **v1** — 调度变量向量

调度变量，指定为向量，其维度与状态空间矩阵的维度一致。

**数据类型：** `double`

### **v2** — 调度变量向量

调度变量，指定为向量，其维度与状态空间矩阵的维度一致。

**数据类型：** `double`
### 输出

### **u** — 作动器需求向量

作动器需求，指定为向量。

**数据类型：** `double`

### **A-matrix(v1,v2)** — 状态空间实现的 *A* 矩阵 A （默认） | 数组

状态空间实现的 *A* 矩阵。在二维调度的情况下，*A* 矩阵应具有四个维度，最后两个维度对应于调度变量 *v*1 和 *v*2。例如，如果对应于 *v*1 的第一个条目和 *v*2 的第一个条目的 *A* 矩阵为单位矩阵，则 `A(:,:,1,1) =
[1 0;0 1];`。

## 描述

实现依赖于两个调度参数的增益调度状态空间控制器

2D Controller [A(v),B(v),C(v),D(v)] 模块实现增益调度状态空间控制器，如算法中所述。

该模块的输出是作动器需求，您可以将其输入到作动器模块。
