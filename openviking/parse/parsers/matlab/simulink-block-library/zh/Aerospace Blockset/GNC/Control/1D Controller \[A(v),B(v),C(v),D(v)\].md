# 1D Controller [A(v),B(v),C(v),D(v)]

## 端口

### 输入

### **y** — 飞行器测量向量

飞行器测量值，指定为向量。

**数据类型：** `double`

### **v** — 调度变量向量

调度变量，指定为向量，其维度与状态空间矩阵的维度一致。

**数据类型：** `double`
### 输出

### **u** — 执行机构需求向量

执行机构需求，指定为向量。

**数据类型：** `double`

## 参数

### **A-matrix(v)** — 状态空间实现的 *A* 矩阵 `A1`（默认）| 数组

状态空间实现的 *A* 矩阵，指定为数组。在一维调度的情况下，*A* 矩阵应具有三个维度，最后一个维度对应调度变量 *v*。例如，如果 *v* 的第一个条目对应的 *A* 矩阵为单位矩阵，则 `A(:,:,1) = [1 0;0 1];`。

## 描述

实现依赖于一个调度参数的增益调度状态空间控制器

1D Controller [A(v),B(v),C(v),D(v)] 模块实现增益调度状态空间控制器，如算法中所述。

该模块的输出为执行机构需求，您可以将其输入到执行机构模块。
