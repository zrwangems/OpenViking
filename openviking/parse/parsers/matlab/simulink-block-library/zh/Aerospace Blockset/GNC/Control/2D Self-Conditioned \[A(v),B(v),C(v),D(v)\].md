# 2D Self-Conditioned [A(v),B(v),C(v),D(v)]

## 端口

### 输入

### **y** — 飞行器测量向量

飞行器测量值，指定为向量。

**数据类型：** `double`

### **v1** — 第一调度变量向量

第一调度变量，指定为向量，按照状态空间矩阵的维度排序。

**数据类型：** `double`

### **v2** — 第二调度变量向量

第二调度变量，指定为向量，按照状态空间矩阵的维度排序。

**数据类型：** `double`

### **u\_meas** — 测量的作动器位置向量

测量的作动器位置，指定为向量。

**数据类型：** `double`
### 输出

### **u\_dem** — 作动器指令向量

作动器指令，指定为向量。

**数据类型：** `double`

## 参数

### **A-matrix(v1,v2)** — 状态空间实现的 *A* 矩阵 `A`（默认）| 数组

状态空间实现的 *A* 矩阵。在二维调度的情况下，*A* 矩阵应具有四个维度，最后两个维度对应于调度变量 *v*1 和 *v*2。例如，如果对应于 *v*1 的第一个条目和 *v*2 的第一个条目的 *A* 矩阵为单位矩阵，则 `A(:,:,1,1) =
[1 0;0 1];`。

## 描述

根据两个调度参数以自条件形式实现增益调度状态空间控制器

2D Self-Conditioned [A(v),B(v),C(v),D(v)] 模块实现算法中定义的增益调度状态空间控制器。

该模块的输出是作动器指令，您可以将其输入到作动器模块。
