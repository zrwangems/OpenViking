# ClassificationSVM Predict

## 端口

### 输入

### **x** — 预测变量数据 行向量 | 列向量

预测变量数据，指定为一个观测的行向量或列向量。

**x** 中的变量必须与训练 **Select trained machine learning model** 所指定 SVM 模型的预测变量具有相同的顺序。

如果在训练 SVM 模型时在 `fitcsvm` 中设置 `'Standardize',true`，则 ClassificationSVM Predict 模块使用 SVM 模型的 `Mu` 和 `Sigma` 属性中的均值和标准差（分别）对 **x** 的值进行标准化。

**数据类型：** `single` | `double` | `half` | `int8` | `int16` | `int32` | `int64` | `uint8` | `uint16` | `uint32` | `uint64` | `Boolean` | `fixed point`
### 输出

### **label** — 预测的类别标签 标量

预测的类别标签，以标量形式返回。

- 对于单类学习，**label** 是表示正类的值。
- 对于两类学习，**label** 是产生最大得分或最大后验概率的类别。

**数据类型：** `single` | `double` | `half` | `int8` | `int16` | `int32` | `int64` | `uint8` | `uint16` | `uint32` | `uint64` | `Boolean` | `fixed point` | `enumerated`

### **score** — 预测的类别得分或后验概率 标量 | 1×2 向量

预测的类别得分或后验概率，对于单类学习以标量形式返回，对于两类学习以 1×2 向量形式返回。

- 对于单类学习，**score** 是正类的分类得分。对于单类学习，无法获得后验概率。
- 对于两类学习，**score** 是一个 1×2 向量。

  - **score** 的第一个和第二个元素分别对应于负类（`svmMdl.ClassNames(1)`）和正类（`svmMdl.ClassNames(2)`）的分类得分，其中 `svmMdl` 是 **Select trained machine learning model** 所指定的 SVM 模型。可以使用 `svmMdl` 的 `ClassNames` 属性来检查负类和正类的名称。
  - 如果使用 `fitPosterior` 或 `fitSVMPosterior` 拟合了最优的得分到后验概率变换函数，则 **score** 包含类别后验概率。否则，**score** 包含类别得分。

#### 依赖

要启用此端口，请在“模块参数”对话框的 **Main** 选项卡上选中 **Add output port for predicted class scores** 复选框。

**数据类型：** `single` | `double` | `half` | `int8` | `int16` | `int32` | `int64` | `uint8` | `uint16` | `uint32` | `uint64` | `Boolean` | `fixed point`

## 参数

### 主要参数

### **Select trained machine learning model** — SVM 分类模型 `svmMdl`（默认）| `ClassificationSVM` 对象 | `CompactClassificationSVM` 对象

指定包含 `ClassificationSVM` 对象或 `CompactClassificationSVM` 对象的工作区变量名称。

使用 `fitcsvm` 训练 SVM 模型时，以下限制适用：

- 预测变量数据不能包含分类预测变量（`logical`、`categorical`、`char`、`string` 或 `cell`）。如果以表格形式提供训练数据，则预测变量必须是数值型（`double` 或 `single`）。此外，不能使用 `CategoricalPredictors` 名称-值参数。要在模型中包含分类预测变量，请在拟合模型之前使用 `dummyvar` 对其进行预处理。
- `ScoreTransform` 名称-值参数的值不能为 `'invlogit'` 或匿名函数。对于根据新观测预测后验概率的模块，请将训练好的 SVM 模型传递给 `fitPosterior` 或 `fitSVMPosterior`。
- `KernelFunction` 名称-值参数的值必须为 `'gaussian'`（与 `'rbf'` 相同，单类学习的默认值）、`'linear'`（两类学习的默认值）或 `'polynomial'`。

#### 数据类型

### **Label data type** — 标签输出数据类型 `Inherit: Inherit via back propagation` | `Inherit: auto` | `double` | `single` | `half` | `int8` | `uint8` | `int16` | `uint16` | `int32` | `uint32` | `int64` | `uint64` | `boolean` | `fixdt(1,16,0)` | `fixdt(1,16,2^0,0)` | `Enum: <class name>` | `<data type expression>`

指定 **label** 输出的数据类型。该类型可以继承、指定为枚举数据类型，或表示为数据类型对象，例如 `Simulink.NumericType`。

支持的数据类型取决于 **Select trained machine learning model** 所指定模型中使用的标签。

- 如果模型使用数值或逻辑标签，支持的数据类型为 `Inherit: Inherit via back propagation`（默认）、`double`、`single`、`half`、`int8`、`uint8`、`int16`、`uint16`、`int32`、`uint32`、`int64`、`uint64`、`boolean`、定点以及数据类型对象。
- 如果模型使用非数值标签，支持的数据类型为 `Inherit: auto`（默认）、`Enum: <class name>` 以及数据类型对象。

当您选择继承选项时，软件的行为如下：

- `Inherit: Inherit via back propagation`（数值和逻辑标签的默认值）— Simulink® 在数据类型传播期间自动确定模块的 **Label data type**（请参阅 Data Type Propagation (Simulink)）。在这种情况下，模块使用下游模块或信号对象的数据类型。
- `Inherit: auto`（非数值标签的默认值）— 模块使用自动定义的枚举数据类型变量。例如，假设 **Select trained machine learning model** 指定的工作区变量名为 `myMdl`，类别标签为 `class 1` 和 `class 2`。那么，对应的 **label** 值为 `myMdl_enumLabels.class_1` 和 `myMdl_enumLabels.class_2`。模块使用 `matlab.lang.makeValidName` 函数将类别标签转换为有效的 MATLAB 标识符。

有关数据类型的详细信息，请参阅 Control Data Types of Signals (Simulink)。

点击 **Show data type assistant** 按钮 以显示 **Data Type Assistant**，它可帮助您设置数据类型属性。有关详细信息，请参阅 Specify Data Types Using Data Type Assistant (Simulink)。

## 版本历史

**在 R2020b 中引入**

### R2021a：对于数值和逻辑标签，**Label data type** 的默认值为 `Inherit: Inherit via back propagation`；对于非数值标签，默认值为 `Inherit: auto`

从 R2021a 开始，**Label data type** 参数的默认数据类型值和支持的数据类型取决于 **Select trained machine learning model** 所指定模型中使用的标签。对于数值和逻辑标签，默认值为 `Inherit: Inherit via back propagation`；对于非数值标签，默认值为 `Inherit: auto`。

如果您将 **Label data type** 指定为 `Inherit: Inherit via back propagation`（用于非数值标签）或 `Inherit: Inherit from 'Constant value'`，请将值更改为 `Inherit: auto`。

### R2021a：**Score data type** 和 **Raw score data type** 的默认值为 `Inherit: auto`

从 R2021a 开始，参数 **Score data type** 和 **Raw score data type** 的默认值为 `Inherit: auto`。

### R2021a：将 **Kernel data type** 指定为数据类型名称或数据类型对象

从 R2021a 开始，**Kernel data type** 参数不支持继承选项。您可以将 **Kernel data type** 指定为受支持的数据类型名称或数据类型对象。

## 描述

使用支持向量机 (SVM) 分类器对观测值进行单类分类和二分类

ClassificationSVM Predict 模块使用 SVM 分类对象（`ClassificationSVM` 或 `CompactClassificationSVM`）对观测值进行单类和二类（二分类）分类。

通过指定包含已训练 SVM 分类对象的工作区变量名称，将该对象导入模块。输入端口 **x** 接收观测值（预测变量数据），输出端口 **label** 返回该观测值的预测类标签。您可以添加可选的输出端口 **score**，它返回预测类分数或后验概率。
