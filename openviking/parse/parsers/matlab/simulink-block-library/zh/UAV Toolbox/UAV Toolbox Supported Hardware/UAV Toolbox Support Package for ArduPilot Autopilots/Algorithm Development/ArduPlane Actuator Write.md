# ArduPlane Actuator Write

## 端口

### 输入

### **Throttle** — 设置电机推力 `-1` | `1`

控制电机的推力输出。

值为 `-1` 会命令最小推力（如果支持，则为最大反向推力），`0` 将电机设置为怠速或无推力，而 `1` 会命令最大推力。

**数据类型：** `Single`

### **Aileron** — 设置副翼偏转 `[-1,1]`

控制副翼控制面的偏转。

值为 `-1` 命令最大向左偏转，`0` 使副翼居中（中性位置），而 `1` 命令最大向右偏转。

#### 依赖项

要启用这些端口，请从 **Motors** 参数中选择所需数量的电机 `(1-12)`。

**数据类型：** `single`

### **Elevator** — 设置升降舵偏转 `-1` | `1`

控制升降舵控制面的偏转。

值为 `-1` 命令最大低头偏转，`0` 使副翼居中（中性位置），而 `1` 命令最大向上偏转。

#### 依赖项

要启用这些端口，请从 **Servos** 参数中选择所需数量的舵机 `(1-8)`。

**数据类型：** `single`

### **Rudder** — 设置方向舵偏转 `-1` | `1`

控制方向舵控制面的偏转。

值为 `-1` 命令最大向左偏转，`0` 使方向舵居中（中性位置），而 `1` 命令最大向右偏转。

**数据类型：** `single`

### **Motor *`x`*** — 接受电机值 `[-1,1]` 的输入

将 Motor `x` 输入连接到表示 single 标量值的信号。

如果提供的输入大于 `1` 或小于 `-1`，模块会在内部将其分别截断为 `1` 和 `-1`。

#### 依赖项

要启用这些端口，请从 **Motors selection** 列表中添加所需数量的电机 `(1-12)`。

**数据类型：** `single`

### **TiltMotorsFront** — 设置前倾斜电机角度 `[-1,1]`

控制前倾斜电机的倾斜角度。

输入值为 `1` 命令电机达到最小倾斜角度，值为 `0` 将电机设置为中性或中间倾斜位置，而输入为 `-1` 命令电机达到最大倾斜角度。

#### 依赖项

要启用这些端口，请从 **Motors selection** 列表中添加该参数。

**数据类型：** `single`

### **ThrottleLeft** — 设置左侧电机推力 `[-1,1]`

### **Flap** — 设置襟翼检测 `-1` | `1`

控制襟翼控制面的偏转。

输入值为 `1` 表示最大向上偏转，值为 `0` 使襟翼居中（中性位置），而输入为 `-1` 表示最大向下偏转。

### **FlapAuto** — 设置自动襟翼检测 `[-1,1]`

控制襟翼控制面的自动偏转，通常由自动驾驶仪在特定飞行模式下管理。

输入值为 `1` 表示最大向上偏转，值为 `0` 使襟翼居中（中性位置），而输入为 `-1` 表示最大向下偏转。

#### 依赖项

要启用这些端口，请从 **Motors selection** 列表中添加该参数。

**数据类型：** `single`

### **Airbrakes** — 设置减速板展开 `[-1,1]`

控制减速板表面的展开。

输入值为 `1` 表示减速板完全收回，值为 `0` 将减速板设置为中性（未展开）位置，而输入为 `-1` 表示减速板完全展开 。

#### 依赖项

要启用这些端口，请从 **Motors selection** 列表中添加该参数。

**数据类型：** `single`

**注意**

以下选择为电机的输出可能无法按预期工作：

- Flap
- FlapAuto
- Airbrakes

这是因为，ArduPilot 会根据内部计算值管理这些飞行控制实体（Flap、FlapAuto、Airbrakes）。例如：

- Flap 和 FlapAuto 的值由 ArduPilot 根据当前 flight\_stage 和 control\_mode 设置，这些值决定使用手动还是自动襟翼输入。
- Airbrakes 由 ArduPilot 根据反向推力逻辑和/或手动 RC 通道输入进行控制。

因此，你为这些输出设置的任何值都可能被 ArduPilot 的内部重新计算覆盖。

## 参数

#### Motors selection

### **Motors function** — 要写入值到 Motor 编号的电机

添加要向其中发送 single 标量值的电机。模块上的电机输入端口数量取决于你在此参数中选择的电机数量。

点击 **Add** 添加新电机。要移除电机，请先选择所需电机，然后点击 **Delete**。

#### Servos selection

### **Servos function** — 要写入值到 Servo 编号的舵机

添加要向其中发送 single 标量值的舵机。模块上的舵机输入端口数量取决于你在此参数中选择的舵机数量。

点击 **Add** 添加新舵机。要移除舵机，请先选择所需舵机，然后点击 **Delete**。

**注意**

某些舵机功能在某些配置中可能无法按预期运行。例如，TiltMotor 功能可能在特定的 quadplane 配置（如 Bicopter 和 Tailsitter 配置）中无法工作，因为这些输出会被 ArduPilot 针对这些载具类型的内部逻辑覆盖。

## 描述

设置电机和舵机的执行机构值

ArduPlane Actuator Write 模块通过 PWM 和 UAVCAN 接口写入电机和舵机执行机构值。ArduPlane Actuator Write 模块接受 `-1` 到 `1` 之间的 single 标量值作为输入，并将这些值写入所选的电机或舵机。

输入值为 `1` 表示最大输出，值为 `0` 使舵机居中或将电机设置为其最低可能推力，而输入为 `-1` 表示最大输出但方向相反。但是，对于不支持反向操作的电机，任何小于零的值都会停止电机。

该模块接受 `-1` 到 `1` 之间的 single 标量值作为输入，并将这些值写入所选的 Motors/Servos。输入值为 `1` 表示最大输出，`0` 表示舵机居中或最小电机推力，而 `-1` 表示在支持的情况下沿相反方向的最大输出。
