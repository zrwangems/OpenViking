# Check Custom Bounds

## 端口

### 输入

### **Port\_1 (u)** — 要根据指定边界检查的信号 scalar | vector | matrix

要在仿真期间根据 **幅值** 和 **时间** 中指定的上下界检查的信号。

**数据类型：** `single` | `double` | `int8` | `int16` | `int32` | `int64` | `uint8` | `uint16` | `uint32` | `uint64` | `fixed point` | `enumerated` | `bus`

### 输出

### **Port\_1 (out)** — 输出断言信号 `1` | `0`

输出信号，用于指示输入信号是否在指定断言信号的边界内。在每个时间步，输出返回为以下之一：

- True (`1`)，如果断言成功，即信号满足所有边界
- False (`0`)，如果断言失败，即信号违反某个边界

输出信号的数据类型默认为 double。要将 Simulink 模型中所有生成逻辑信号的模块的输出数据类型设置为 Boolean，请在配置参数中选择 **将逻辑信号实现为布尔数据**。

#### 依赖关系

要启用此端口，请在 **断言** 选项卡上选择 **输出断言信号** 参数。

**数据类型：** `Boolean` | `double`

### 边界选项卡

### **时间** — 上界时间向量 `[0 5; 5 10]` (默认) | two-element vector | two-column matrix | cell array

一个或多个上界段的时间向量，以 seconds 为单位指定。

在 **幅值** 中指定对应的幅值。

- 要指定具有一个边的单个边界，请使用 two-element vector。该向量必须采用 [*Tstart* *Tend*] 形式，其中 *Tstart* 和 *Tend* 是正有限数，且 *Tstart* < *Tend*。

  例如，要在 0 到 10 seconds 的时间间隔内创建幅值为 1.2 的单个上界，请为 **时间** 指定 `[0 10]`，并为 **幅值** 指定 `[1.2 1.2]`。

  时间绘图上具有一个边的单个上界
- 要指定具有多个边的单个边界，请使用 two-column matrix。该矩阵必须采用 [*T1* *T2* ; *T2* *T3* ;…; *Tn* *Tn+1*] 形式，其中 *n* 是边界中的边数。具有多个边的单个边界是分段连续的，因此请指定这样的时间区间：下一个边开始的时间与前一个边结束的时间相同。

  例如，要创建一个具有两个边的单个边界，这两个边分别在 0–5 和 5–10 seconds，幅值分别为 1.2 和 1，请为 **时间** 指定 `[0 5;5 10]`，并为 **幅值** 指定 `[1.2 1.2;1 1]`。

  时间绘图上具有两个边的单个上界
- 要指定多个边界，请使用由 two-element vectors、two-column matrices 或两者组成的 cell array。也就是说，使用由多个单个边界组成的 cell array。

  例如，要创建两个边界，分别在 0–4 和 6–10 seconds，幅值分别为 1.2 和 1，请为 **时间** 指定 `{[0 4] [6 10]}`，并为 **幅值** 指定 `{[1.2 1.2] [1 1]}`。

  时间绘图上的两个上界

您可以从绘图窗口添加或修改开始和结束时间。

- 要添加新的时间向量，请右键单击绘图上的黄色区域，然后选择 **编辑**。单击 **插入** 向“编辑边界”对话框添加新行。在 **时间** 列中指定新边界段的开始和结束时间。在 **幅值** 列中指定对应的幅值。
- 要修改开始和结束时间，请拖动边界段。或者，右键单击该段，然后选择 **编辑**。在 **时间** 列中指定新的时间。

  在仿真模型之前，单击 **更新模块**。

要检查输入信号是否满足与上界时间向量对应的幅值，请同时选择 **在断言中包括上界** 和 **启用断言**。

### Assertion 选项卡

### **Enable assertion** — 启用或禁用检查 `on`（默认）| `off`

使该模块能够在仿真期间检查在 **Bounds** 选项卡上指定并包含用于断言的边界是否得到满足。如果边界未得到满足，则断言失败。MATLAB 提示符处会出现报告断言失败的警告。

如果断言失败，您可以选择指定该模块：

- 执行在 **Simulation callback when assertion fails (optional)** 中指定的 MATLAB 表达式。
- 通过选择 **Stop simulation when assertion fails** 停止仿真并返回错误消息。

禁用此参数后，该模块不再检查输入信号是否满足指定的边界。模块图标也会更新以指示断言已禁用。

### **Stop simulation when assertion fails** — 断言失败时停止仿真 `off`（默认）| `on`

### **Output assertion signal** — 创建输出信号 `off`（默认）| `on`

输出一个 Boolean 信号，该信号在每个时间步为：

- 如果断言成功，即输入信号满足所有边界，则为 True（`1`）
- 如果断言失败，即输入信号违反某个边界，则为 False（`0`）

默认情况下，输出信号的数据类型为 double。要将 Simulink 模型中所有生成逻辑信号的模块的输出数据类型设置为 Boolean，请在 Configuration Parameters 中选择 Implement logic signals as Boolean data。

选择此参数会向该模块添加一个输出端口，您可以将其连接到模型中的任何模块。

使用此参数设计复杂的断言逻辑。有关示例，请参阅 Verify Model Using Simulink Control Design and Simulink Verification Blocks (Simulink Control Design)。

#### 编程用法

|  |
| --- |
| **参数:** `export` |
| **类型:** character vector |
| **值:** `'on'` | `'off'` |
| **默认:** `'off'` |

## 描述

检查模型信号在仿真期间是否满足边界

检查信号在仿真期间是否满足指定的上界和下界。

- 如果信号满足所有边界，则该模块不执行任何操作。
- 如果信号不满足某个边界，MATLAB® 命令窗口中会出现警告消息。您还可以指定该模块：

  - 计算 MATLAB 表达式。
  - 停止仿真并返回错误消息。

在仿真期间，该模块还可以返回逻辑断言信号。

- 如果信号满足所有边界，则断言信号为 true（`1`）。
- 如果信号不满足某个边界，则断言信号为 false（`0`）。

使用该模块，您可以创建：

- 具有一个边沿的单个边界
- 具有多个边沿的单个边界
- 多个边界

您可以将 Check Custom Bounds 模块添加到多个信号，以检查它们是否满足边界。您还可以在时间图上绘制边界，以图形方式验证信号满足边界。

该模块和 Model Verification 库中的其他模块测试信号是否保持在指定的时域特性边界内。当模型未违反任何边界时，您可以通过清除断言选项来禁用该模块。如果修改了模型，您可以重新启用断言，以确保您的更改不会导致模型违反边界。

如果信号不满足边界，您可以优化模型参数以满足边界。如果您有 Simulink® Control Design™ 软件，可以添加频域边界，例如 Bode 幅值，并优化模型响应以满足时域和频域要求。

该模块可在所有仿真模式下用于信号监测，但仅在 `Normal` 或 `Accelerator` 仿真模式下用于响应优化。
