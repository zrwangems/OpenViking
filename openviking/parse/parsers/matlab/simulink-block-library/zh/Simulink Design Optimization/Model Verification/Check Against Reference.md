# Check Against Reference

## 端口

### 输入

### **Port\_1 (u)** — 要根据指定参考信号检查的信号 标量 | 向量 | 矩阵

在仿真期间，要根据 **幅值** 和 **时间** 中指定的参考信号检查的信号。

**数据类型：** `single` | `double` | `int8` | `int16` | `int32` | `int64` | `uint8` | `uint16` | `uint32` | `uint64` | `fixed point` | `enumerated` | `bus`
### 输出

### **Port\_1 (out)** — 输出断言信号 `1` | `0`

输出信号，指示输入信号是否在指定断言信号的边界内。在每个时间步，输出返回为以下之一：

- 如果断言成功，即输入信号满足所有边界，则为 True (`1`)
- 如果断言失败，即信号违反某个边界，则为 False (`0`)

输出信号的数据类型默认为 double。要将 Simulink 模型中生成逻辑信号的所有模块的输出数据类型设置为 Boolean，请在 Configuration Parameters 中选择 Implement logic signals as Boolean data。

#### 依赖项

要启用此端口，请在 **断言** 选项卡上选择 **输出断言信号** 参数。

**数据类型：** `Boolean` | `double`

### 边界选项卡

### **在断言中包含参考信号跟踪** — 检查信号是否跟踪参考信号 `on` (默认) | `off`

检查模块的输入信号在仿真期间是否跟踪在 **幅值** 和 **时间** 中指定的参考信号。如果信号不跟踪参考信号，软件将显示警告。

- 禁用此参数后，软件会停止检查输入信号在仿真期间是否跟踪参考信号。
- 要仅在绘图上查看参考信号，请禁用 **启用断言**。

如果选择 **显示绘图**，参考信号会显示在时间图上，如图所示。

### **绝对容差** — 信号的绝对容差 `eps^(1/3)` (默认) | 正实数标量

在输入信号接近参考信号时用于确定边界的绝对容差，指定为正实数标量。在仿真期间，信号必须保持在与参考信号对应的上限和下限范围内，其由下式给出

*y*u = (1 +
*RelTol*)*y*r
+ *AbsTol*

*y*l = (1 –
*RelTol*)*y*r
– *AbsTol*

其中：

- *y*r 是某一时刻参考信号的值。
- *y*u 是对应于该时间点的容差上限。
- *y*l 是对应于该时间点的容差下限。
- *RelTol* 设置每个时间步输入信号与参考信号幅值之间的相对容差。要设置 *RelTol*，请使用 **相对容差** 参数。
- *AbsTol* 设置每个时间步输入信号与参考信号幅值之间的绝对容差。要设置 *AbsTol*，请使用 **绝对容差** 参数。

如果信号违反这些限制，模块将进行断言。

| **参数：** `AbsTolerance` |
| **类型：** scalar |
| **值：** 正实数标量 |
| **默认：** `eps^(1/3)` |

### 断言选项卡

### **启用断言** — 启用或禁用检查 `on` (默认) | `off`

使模块能够在仿真期间检查 **边界** 选项卡上指定并包含用于断言的边界是否得到满足。如果某个边界未满足，断言将失败。报告断言失败的警告会出现在 MATLAB 命令提示符处。

如果断言失败，您可以选择指定模块：

- 执行在 **断言失败时的仿真回调（可选）** 中指定的 MATLAB 表达式。
- 通过选择 **断言失败时停止仿真**，停止仿真并返回错误消息。

如果您未指定任何边界，此参数不起作用。

禁用此参数后，模块不再检查输入信号是否满足指定的边界。模块图标也会更新以指示断言已禁用。

## 描述

检查模型信号在仿真期间是否跟踪参考信号

检查信号在仿真期间是否保持在参考信号的容差边界内。

- 如果信号满足所有边界，模块不执行任何操作。
- 如果信号不满足某个边界，MATLAB® 命令窗口中将出现警告消息。您还可以指定模块：

  - 计算 MATLAB 表达式。
  - 停止仿真并返回错误消息。

在仿真期间，模块还可以返回逻辑断言信号。

- 如果信号满足所有边界，断言信号为 true (`1`)。
- 如果信号不满足某个边界，断言信号为 false (`0`)。

您可以将 Check Against Reference 模块添加到多个信号，以检查它们是否跟踪参考信号。您还可以在时间图上绘制参考信号，以图形方式验证信号跟踪。

此模块以及 Model Verification 库中的其他模块用于测试信号是否保持在指定的时域特性边界内。当模型未违反任何边界时，您可以通过清除断言选项来禁用该模块。如果修改了模型，您可以重新启用断言，以确保您的更改不会导致模型违反边界。

如果信号不满足这些边界，您可以优化模型参数以满足这些边界。如果您有 Simulink® Control Design™ 软件，可以添加频域边界，例如 Bode 幅值，并优化模型响应，以满足时域和频域要求。

该模块可用于所有仿真模式进行信号监控，但仅在 `Normal` 或 `Accelerator` 仿真模式下用于响应优化。
