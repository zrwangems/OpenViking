# Inductor

## 端口

未在 R2025b 中记录。

## 参数

### **Inductance** — 电感值 `1e-9 H` (默认) | real number

电感值，指定为 real number。从对应的下拉菜单中指定电容的单位。

如果将此项参数设置为介于 `0` 和 `1e-18` `H` 之间的值，模块在仿真期间使用等于 `1e-18` `H` 的值。默认情况下，该值为 `1e-9` `H`。
