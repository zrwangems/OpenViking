### **噪声系数 (dB)** — 混频器的单边带 IEEE 噪声系数 0 `dB` (默认) | scalar

混频器的单边带噪声系数，根据 IEEE® 定义指定为标量。

要使用 Noise、Amplifier 或 Mixer 模块在电路包络模型中建模噪声，您必须在 Configuration 模块对话框中选中 **仿真噪声** 复选框。

IEEE SSB 定义假定混频器输入处的镜像带宽中的噪声被完美抑制，而混频器在镜像带宽和信号带宽中内部生成噪声。因此，混频器输出处的噪声是两个贡献之和：

Nout=NinGmix+2NmixerGmix,

其中：

- *N*out 是混频器输出处的噪声。
- *N*in 是混频器输入处的噪声（假设镜像带宽中的噪声被完美抑制）。
- *N*mixer 是混频器在信号和镜像带宽中内部生成的噪声。
- *G*mix 是混频器增益。

因此，根据 IEEE SSB 定义的噪声因子可以表示为

FSSB-IEEE=1+2Nmixer/Nin,

其与其他常用定义的关系为

FSSB=2+2Nmixer/Nin=1+FSSB-IEEE,FDSB=1+Nmixer/Nin=12(1+FSSB-IEEE).

在使用 Friis 公式进行链路预算分析时，您可以直接应用 IEEE SSB 定义来描述混频器级。使用其他定义则需要更改 Friis 公式。RF Blockset™ 中的 Mixer 模块和 RF Toolbox™ 中的 RF Budget Analyzer 应用都使用 IEEE 定义。

三种定义之间的解析关系允许您仿真混频器输出处的噪声水平。例如，

FSSB=4 dB⇒FSSB-IEEE=10log10(10FSSB/10−1)=1.79 dB,FDSB=4 dB⇒FSSB-IEEE=10log10(2×10FDSB/10−1)=6.04 dB.

如果您仿真 RF Blockset 混频器时不包含理想镜像抑制滤波器，则混频器输出处的噪声会大于噪声系数所预测的值，因为镜像带宽中的噪声实际上会折叠到输出信号上。

因此，在生成模型时，Modulator 和 Demodulator 模块都会自动插入理想镜像抑制滤波器。（您可以在模块掩码内删除该滤波。）

Noise Figure Testbench 模块测量 SSB 噪声系数，并使您能够验证仿真的噪声系数是否具有预期值。

- 如果您向模型添加理想镜像抑制滤波器，则有效噪声系数与解析值一致。
- 如果您移除镜像抑制滤波器，或使用具有部分抑制的滤波器，则测得的噪声系数大于解析值。

## 描述

在 RF 系统中对混频器建模

Mixer 模块执行信号频率转换和非线性放大。

对于给定的 RF 输入信号，*V*RF = *A*RFcos(*ω*RFt) 和 LO 输入信号 *V*LO = *A*cLOcos(*ω*LOt)，混频器将输入端口处的信号相乘：

VinVLO=Aincos(ωint)ALOcos(ωLOt)=AinALO2cos[(ωin+ωLO)t]+AinALO2cos[(ωin−ωLO)t]

这种混频将 RF 信号的频率转换为
*ωRF* + *ωLO*
和
*ωRF* – *ωLO*。
为使混频器正确执行此操作，您必须在 Configuration 模块计算的仿真频率中包含频率
*ωRF* + *ωLO*
或
*ωRF* – *ωLO*。

此模块的功率增益设定将单边带 (SSB) 的功率与输入关联起来。

在混合 RF 和 LO 信号后，Mixer 模块执行放大。为了对线性放大建模，混频器按系数 a1 缩放信号。使用多项式指定的 Voltage Controlled Voltage Source (VCVS) 实现非线性放大。该多项式自动包含饱和并产生额外的互调频率。
