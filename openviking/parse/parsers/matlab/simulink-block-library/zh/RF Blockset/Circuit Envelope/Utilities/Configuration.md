# Configuration

## 参数

#### 主要

### **自动选择基频和谐波阶数** — 自动选择基频和谐波阶数 `on`（默认）| `off`

选择此参数可在更新模型时自动选择 **基频** 和 **谐波阶数** 参数。自动选择并不总是返回尽可能小的仿真频率集。此方法使用保守数量的仿真频率来捕获系统的非线性行为。

要设置 **基频** 和 **谐波阶数**，请清除此参数。较小的仿真频率集可减少仿真时间并降低内存需求。但是，仿真频率减少可能会降低精度。

### **基频** — 仿真频率集的基频，以 Hz 为单位的正整数向量

仿真频率集的基频，指定为以 Hz 为单位的正整数向量。

#### 依赖关系

要启用此参数，请清除 **自动选择基频和谐波阶数**。

### **谐波阶数** — 每个基频的谐波阶数，正整数向量

每个基频的谐波阶数，指定为正整数向量。您也可以指定标量，此值将应用于每个 **基频**。

#### 依赖关系

要启用此参数，请清除 **自动选择基频和谐波阶数**。

### **总仿真频率：在仿真时计算** — 显示仿真频率数量的按钮

该模块根据基频及其各自的谐波阶数确定仿真频率。求解器在每个仿真频率处计算网络解，计算时间随仿真频率总数成比例变化。

基频的组合确定仿真频率集：[*m*\**f*1 + *n*\**f*2 + …]。在这种情况下，基频由 [*fs*1,*f*2,…] 表示，整数 *m* 和 *n* 是受相应 **谐波阶数** 约束的整数，|*m*| ≦*h*1，|*n*| ≦*h*2，等等。仅考虑正频率。

单击 **查看** 打开对话框，其中包含有关您系统中仿真频率的附加信息。`Configuration` 模块显示非线性模型的仿真频率数量。对于线性模型，实际频率数量会在仿真期间自动优化。

通过单击列出的仿真频率，您可以查看哪些基频的线性或多重组合表示该频率。在该对话框中，您还可以将仿真频率绘制在数轴上。

考虑单个基频 *f*1 = 2 GHz 和相应的谐波阶数 *h1* = 3。仿真频率集为：`[0, f1, 2f1, 3f1] = [0GHz, 2 GHz, 4 GHz, 6GHz]`。

考虑一个具有两个基频 `[f1 = 2 GHz, f2 = 50 MHz]` 和相应谐波阶数 `h1 = h2 = 1` 的电路。此设置产生五个仿真频率，值为：`[0, f2, f1-f2, f1, f1+f2]`。

考虑一个具有两个基频 `[f1 = 2 GHz, f2 = 3GHz]` 和相应谐波阶数 `h1 = 1` 以及 `h2 = 3` 的电路。此设置产生 11 个仿真频率，值为：`[0, f2, f1-f2, f1, f1+f2, -f1+2f2, 2f2, -f1+3f2, f1+2f2, 3f2, f1+3f2]`。

仿真频率集必须包括 RF Blockset 子系统中指定的所有载波频率，例如 Inport、Outport 和源模块内的载波频率。

#### 依赖关系

要启用此参数，请选择 **自动选择基频和谐波阶数**。如果清除 **自动选择基频和谐波阶数**，该选项将变为 **总仿真频率：N/A：基频未定义**。

### **步长** — 固定步长求解器配置的时间步长 `1e-6`（默认）| 以秒为单位的标量

固定步长求解器配置的时间步长，指定为以秒为单位的标量。时间步长的倒数决定以每个仿真频率为中心的信号包络的仿真带宽。

电路包络仿真的时间步长应与相对信号带宽相称，而不应与载波频率的绝对值相称。

默认值 (1e-6s) 足以对带宽高达 1/*h*（即 1MHz）的包络信号进行建模。接近最大带宽进行仿真时，仿真精度会降低。减小步长可对更大带宽的信号进行建模，或提高精度。

仿真速度与仿真步长成反比。较小的仿真步长对应较宽的包络带宽和较慢的仿真。

当仿真白噪声时，每个仿真频率的噪声带宽等于 1/*h*。

### **包络带宽** — 最大仿真包络带宽 `1 MHz`（默认）| 以 Hz 为单位的标量

最大仿真包络带宽，以 Hz 为单位的标量返回。Configuration 模块使用 **步长** 参数自动计算此值。使用的公式为：bandwidth=1(step  size)。

### **仿真噪声** — 全局启用或禁用噪声建模 `on`（默认）| `off`

选择此参数可在 RF Blockset 电路中全局启用噪声建模。选中此复选框时：

- Amplifier 和 Mixer 模块使用其各自的 **噪声系数 (dB)** 参数值。
- Amplifier 和 Mixer 模块使用 **温度** 参数指定的温度下的热噪声进行仿真。
- Resistor 模块使用 **温度** 参数对热噪声进行建模。
- Noise 模块将指定的噪声功率建模为电压源或电流源。

要全局禁用噪声建模，请清除此参数。

### **使用默认随机数生成器** — RF Blockset 源的默认伪随机噪声流 `on`（默认）| `off`

选择此参数可为 RF Blockset 源保留默认伪随机噪声流。清除此选项可为 RF Blockset 拓扑子系统指定独立的伪随机数流，并确定噪声流的种子。

#### 依赖关系

要显示此参数，请选择 **仿真噪声**。

### **噪声种子** — 独立伪随机数流的种子 `0`（默认）| 正标量整数

独立伪随机数流的种子，指定为正标量整数。

#### 依赖关系

要显示此参数，请清除 **使用默认随机数生成器**。

### **温度** — 全局噪声温度 `290.0``K` | 以开尔文为单位的标量整数

全局噪声温度，指定为以开尔文为单位的标量整数。

### **每帧采样数** — Inport 模块输入信号每个通道中的采样数 `1` | 正标量整数

Inport 模块输入信号每个通道中的采样数，指定为小于或等于 `1024` 的正标量整数。一个通道对应于 Inport 模块中的一个输入频率。

**注意**

为提高系统性能，建议的 **每帧采样数** 最大值为 `1024`。要处理更大的帧，请考虑以下方法之一：

- 使用 `rfsystem` System object™，它支持用于基于帧处理的向量输入，且没有任何帧大小限制。
- 在 Circuit Envelope Inport 和 Outport 模块之前和之后使用 Buffer (DSP System Toolbox) 模块。有关详细信息，请参阅 Buffering and Frame-Based Processing (DSP System Toolbox)。

### **归一化载波功率** — 归一化载波信号功率 `on`（默认）| `off`

选择此选项以归一化载波功率，使信号的平均功率为：

I2+  Q2

在这种情况下，方程给出 ω 处对应的通带信号：

sk(t)=I(t)2cos(2πfkt) − Q(t)2sin(2πfkt)

其中：

- *I*(*t*) 是载波信号的同相部分。
- *Q*(*t*) 是载波信号的正交部分。
- *fk* 是载波频率。

清除此选项，使载波信号的平均功率为：

I2 +  Q22

在这种情况下，ω 处对应的通带信号由以下方程表示：

sk(t)=I(t)cos(2πfkt) − Q(t)sin(2πfkt)

0 载波频率是一种特殊情况。其通带表示始终为 *I*，平均功率为 *I*2

### **启用输入插值滤波器** — 将较低速率基带信号自动插值到较高速率 RF 信号 on（默认）| off

选择此选项可启用输入插值滤波器，以对输入信号速率进行上采样，使其匹配 RF 求解器的采样率。现在，您可以直接在较宽频带电路中使用较低采样率的基带通信信号。此滤波器会在 RF 信号中引入延迟。**滤波器延迟（以采样为单位）** 显示仿真模型后引入的延迟。

**注意**

当您启用此滤波器时，

- RF 与基带的采样率之比必须为 2、4、6 或 8。
- RF Blockset 模型只能有一个 Inport 模块。

#### 高级

### **瞬态分析** — RF Blockset 环境的固定步长求解器 `Auto`（默认）| `NDF2` | `Trapezoidal Rule` | `Backward Euler`

RF Blockset 环境的固定步长求解器，指定为以下选项之一：

- `Auto`：当您不确定使用哪个求解器时，请将此参数设置为 `Auto`。
- `NDF2`：将此参数设置为 `NDF2`，以平衡窄带和宽带精度。此求解器适用于系统中信号的频率内容相对于 Nyquist 速率未知的情况。
- `Trapezoidal Rule`：对于窄带仿真，请将此参数设置为 `Trapezoidal Rule`。频率扭曲和缺少阻尼效应使此方法不适用于大多数宽带仿真。
- `Backward Euler`：将此参数设置为 `Backward Euler`，以仿真最大类别的系统和信号。阻尼效应使此求解器适用于宽带仿真，但总体精度较低。

RF Blockset 求解器是 Simscape™ 局部求解器的扩展。有关 Simscape 局部求解器的详细信息，请参阅 Solver Configuration 模块参考页。

### **将瞬态近似为小信号** — 为瞬态小信号分析选择小频率子集 off（默认）| on

选择此选项可为瞬态小信号分析选择较小的频率子集。

### **使用所有稳态仿真频率进行小信号分析** — 选择所有稳态仿真频率 on（默认）| off

选择此选项可选择所有稳态仿真频率。清除此选项可指定用于小信号瞬态仿真的频率。

#### 依赖关系

要显示此参数，请选中 **将瞬态近似为小信号**。

### **小信号频率** — 用于小信号瞬态仿真的频率 标量 | 向量

用于小信号瞬态仿真的频率，指定为标量或向量。指定的频率包含在由 **主要** 选项卡中的 **基频** 和 **谐波阶数** 确定的整个仿真频率集中。

此框中的默认值及相应单位不是常量。这些值取决于首次清除 **使用所有稳态仿真频率进行小信号分析** 时配置对话框的状态。

#### 依赖关系

要显示此参数，请清除 **使用所有稳态仿真频率进行小信号分析**。

### **填充频率** — 用于选择小信号瞬态频率的工具按钮

用于选择小信号瞬态频率以填充 **小信号频率** 的工具。所选频率是由 **主要** 选项卡中的 **基频** 和 **谐波阶数** 输入确定的仿真频率的子集。整个仿真频率集显示在对话框右侧的组合框中，所选频率会高亮显示。您可以通过直接在选择框中选择频率，或在 **小信号选择面板** 中选择所需的音调和谐波阶数，然后按 **选择** 来进行选择。组合框中的 **Tones(Hz)** 和 **谐波阶数** 值也使用 **主要** 选项卡中的 **基频** 和 **谐波阶数** 输入进行填充。

选择小信号频率窗口

#### 依赖关系

要显示此参数，请清除 **使用所有稳态仿真频率进行小信号分析**。

### **相对容差** — 系统变量的相对 Newton 容差 `1e-3`（默认）| 实正有限标量

系统变量的相对 Newton 容差，指定为实正有限标量。

### **绝对容差** — 系统变量的绝对 Newton 容差 `1e-6`（默认）| 实正有限标量

系统变量的绝对 Newton 容差，指定为实正有限标量。

### **最大迭代次数** — 收敛所需的迭代次数 `10`（默认）| 实正整数标量

收敛所需的迭代次数，指定为实正整数标量。

### **误差估计** — 检查系统变量收敛误差 `2-norm over all variables`（默认）| `Each variable separately`

检查系统变量收敛误差，指定为：

- `2-norm over all variables`：使用此选项计算所有状态变量的 2-范数，然后检查状态变量的收敛误差。
- `Each variable separately`：使用此选项分别检查每个变量的收敛误差。

### **恢复默认设置** — 将 Newton 求解器恢复为默认值的按钮

将 Newton 求解器恢复为默认值，指定为按钮。

## 描述

定义系统仿真设置

使用 Configuration 模块设置电路包络仿真的模型条件。模块参数定义 RF 和求解器属性。RF 属性包括仿真频率、谐波阶数、包络带宽和热噪声等属性。求解器属性包括瞬态分析类型、容差和小信号近似。

小信号瞬态仿真执行完整的非线性谐波平衡稳态求解，以确定后续线性瞬态分析的工作点。此选项允许您捕获受大恒定（载波上）信号影响的小信号的正确频谱行为。

将为每个拓扑上不同的 RF Blockset™ 子系统连接一个 Configuration 模块。每个 Configuration 模块定义所连接的 RF Blockset 子系统的参数。要查看模型中 Configuration 模块的示例，请在 MATLAB 命令窗口中输入 `RFNoiseExample`。

有关 RF 仿真的介绍，请参阅 Simulate High Frequency Components。

Configuration 模块封装图标是动态的，并显示所应用噪声参数的当前状态。此表显示了此模块上的图标如何根据模块上 **仿真噪声** 参数的状态而变化。
