# S-Parameter Testbench

## 端口

R2025b 中未记录。

## 参数

#### 主要

### **使用内部 Configuration 模块** — 使用测试台内部 Configuration 模块 on（默认）| off

选择以使用测试台内部 Configuration 模块。清除此参数以指定您自己的配置模块。清除此复选框会移除 **高级** 选项卡中的 **将瞬态近似为小信号** 选项。

**注意**

当使用您自己的配置模块时，诸如步长、基波音调、谐波阶数和仿真噪声等参数可能会影响测量结果。

### **输入功率幅度 (dBm)** — 输入到 DUT 的功率 `-30`（默认）| 实值标量

输入到被测设备 (DUT) 的功率，指定为以 dBm 为单位的实值标量。您可以通过在文本框中输入值或使用旋钮选择值来更改输入功率。指定的输入功率表示 DUT 输入端口处可用的功率。有效值为 `-90` 到 `60` dBm。

当在 **高级** 选项卡中选中 **将瞬态近似为小信号** 选项时，此参数在仿真运行期间处于禁用状态。

**数据类型：** `double`

### **端口数** — 测量端口数 `2`（默认）| 标量整数

测量端口数，指定为限制在 1:128 范围内的标量整数。更改端口数后，模块上会出现新端口。

**数据类型：** `double`

### **测量所有 S 参数** — 测量整个 S 参数矩阵 on（默认）| off

选择以测量整个 S 参数矩阵。此测量通过依次激励每个端口并测量所有端口的输出来完成。选中此复选框时，此参数下方会出现 **将测量结果保存到 .s2p** 按钮。在这种情况下，输出信号 S 参数的维度为 *N*×*N*×*F*。*N* 是端口数，*F* 是频率数。

清除此参数以手动指定 S 参数元素。在这种情况下，输出信号 S 参数的维度为 *M*×*F*。*M* 是 S 参数元素的总数，*F* 是频率数。

### **将测量结果导出到 sNp** — 将 S 参数数据保存到 Touchstone 文件 按钮

单击以将测得的 S 参数数据保存到 Touchstone 文件。此按钮会打开一个标准对话框，用于浏览和选择文件。建议的唯一文件类型是 `.sNp`，其中 *N* 是测量端口数。此按钮在首次仿真发生之前以及仿真运行或初始化期间处于禁用状态。它会捕获之前仿真的结果。`.sNp` 中的 *N* 值对应于先前测量的端口数。

#### 依赖项

要启用此参数，请选择 **测量所有 S 参数**。

### **S 参数元素** — 要测量的 S 参数元素 `[1 1]`（默认）| 两列矩阵

要测量的 S 参数元素，指定为两列矩阵。每行表示一个 S 参数元素。第一列表示入射波端口，第二列表示散射波端口。例如，`[[2 1];[1 1]]` 表示两个元素的测量：S21 和 S11。您可以从矩阵中按任意顺序选择任意元素，但元素必须唯一。

#### 依赖项

要启用此参数，请清除 **测量所有 S 参数**。

**数据类型：** `double`

### **工作区变量名** — 用于将测量数据存储在 MATLAB 工作区中的变量名 `'SparamObjOut'`（默认）| 字符向量

用于将测量数据存储在 MATLAB® 工作区中的变量名，指定为字符向量。数据存储为 RF Toolbox™ `sparameters` 对象。

**数据类型：** `char`

### **输入频率 (Hz)** — DUT 的载波频率 `2.1e9`（默认）| 标量

DUT 的载波频率，指定为以 Hz 为单位的标量。默认情况下，输出频率等于输入频率，因为测量 S 参数是为了量化线性系统。

对于在大的恒定外部信号上进行小信号测量，当选中 **针对稳态外部信号进行调整** 时，可以在 **高级** 选项卡中指定输出频率。

**数据类型：** `double`

### **基带带宽 (Hz)** — 输入信号的基带带宽 `10e6`（默认）| 正有限标量

输入信号的基带带宽，指定为以 Hz 为单位的正有限标量。测量频率位于输入载波频率周围的此频带上。默认情况下，此频带比求解器包络带宽窄，以使仿真伪影保持在测量结果之外。可以使用 **高级** 选项卡中的 **包络带宽与基带带宽之比** 来控制这两个频带之比。

**数据类型：** `double`

### **参考阻抗 (Ohm)** — 用于 S 参数测量的阻抗 `50`（默认）| 正有限标量

用于 S 参数测量的阻抗，指定为以欧姆为单位的正有限标量。所有端口都使用相同的参考阻抗进行测量。

**数据类型：** `double`

### **显示 S 参数频谱** — 在指定频率带宽上查看指定 S 参数的测量值 off（默认）| on

选择以使用频谱分析仪在指定频率带宽上查看指定 S 参数的测量值。您可以在图中查看两种类型的曲线：`Magnitude` 或 `Real & Imag`。`Magnitude` 图显示 S 参数数据幅度，单位为 dBm。`Real & Imag` 显示 S 参数的实部和虚部。S 参数的实部和虚部图没有单位。

**注意**

要使用 Spectrum Analyzer 查看 S 参数频谱，您需要 DSP System Toolbox™ 许可证。

### **接地并隐藏负端子** — 在内部接地并隐藏 RF 电路端子 on（默认）| off

选择以在内部接地并隐藏负端子。清除以暴露负端子。通过暴露这些端子，您可以将它们连接到模型的其他部分。

#### 高级

### **FFT 长度** — FFT 频点数 `128`（默认）| 2 的幂的标量整数

用于测量的 FFT 频点数，指定为 2 的幂的标量整数。该值必须是 2 的整数幂。此值控制指定带宽上测量的频谱分辨率。

### **测量时间** — 总时间长度 `12.8` μs（默认）| 标量整数

此参数为只读。

测量每个端口输出以获得频谱结果的总时间长度，指定为标量整数。该值是 **FFT 长度** 与 **主要** 选项卡中指定的 **基带带宽** 之比。它让您知道，超过此值的任何系统响应都不会包含在频谱结果中。此界限是频谱分辨率限制的结果。

### **等待时间与测量时间之比** — 顺序测量之间的间歇 `0`（默认）| 标量整数

端口激励变化的顺序测量之间的间歇，指定为 **测量时间** 实例的标量整数数量。与真实测量类似，DUT 无法重置以清除其内部状态。如果测量之间的切换太快，超出 **测量时间** 的输出可能会被收集到下一次测量中。此值有助于避免下一次测量受到污染。

### **包络带宽与基带带宽之比** — 内部求解器包络带宽与测量带宽之比 `8`（默认）| 2 的幂的标量整数

内部求解器包络带宽与测量带宽之比，指定为 2 的幂的标量整数。

### **针对稳态外部信号进行调整** — 针对大的稳态信号进行调整 off（默认）| on

选择以针对大的稳态外部信号进行调整，并且仅测量测试台注入的小信号激励对 DUT 的线性效应。这意味着 DUT 可以包含与在每个载波上包络时间内恒定的大的信号进行混频的元件。选中此参数时，您可以指定与输入频率不同的输出频率。

如果测试台外部没有信号注入到 DUT，请清除此项。

**注意**

DUT 不应包含在任何载波上包络随时间变化的外部信号。

### **输出频率 (Hz)** — 输出载波频率 `2.1e9`（默认）| 正有限标量

输出载波频率，指定为正有限标量。

#### 依赖项

要启用此参数，请选择 **针对稳态外部信号进行调整**。

### **将瞬态近似为小信号** — 为瞬态小信号分析选择频率的小子集 off（默认）| on

选择此选项以为瞬态小信号分析选择频率的小子集。使用此参数可加速测量大的非线性系统在由大的外部稳态信号指定的给定工作点附近的 S 参数。

### **使用所有稳态仿真频率进行小信号分析** — 使用为全谐波平衡非线性解自动选择的所有频率 on（默认）| off

选择此选项以使用为全谐波平衡非线性解自动选择的所有频率。清除以指定携带小信号瞬态的频率。

#### 依赖项

要启用此参数，请选中 **将瞬态近似为小信号**。

### **小信号频率 (Hz)** — 携带小信号瞬态的频率 `2.1e9`（默认）| 标量 | 向量

携带小信号瞬态的频率，指定为实数标量整数或向量。指定的频率应包含在仿真频率的整个集合中。如果某些频率未包含，则会出现警告消息。如果所有频率都未包含，则会出现错误消息。

#### 依赖项

要启用此参数，请清除 **使用所有稳态仿真频率进行小信号分析**。

### **填充频率** — 用于选择小信号瞬态频率的工具 按钮

打开该工具以选择小信号瞬态频率，以填充 **小信号频率**。所选频率是由仿真中使用的 **基波音调** 和 **谐波阶数** 确定的仿真频率的子集。整个仿真频率集合在对话框右侧的组合框中给出，所选频率会突出显示。您可以通过直接在选择框中选择频率，或在 **小信号选择面板** 中选择所需的音调和谐波阶数，然后单击 **选择** 来进行选择。组合框中的 **音调 (Hz)** 和 **谐波阶数** 值也会使用仿真中使用的 **基波音调** 和 **谐波阶数** 来填充。

选择小信号频率窗口

#### 依赖项

要显示此参数，请清除 **使用所有稳态仿真频率进行小信号分析**。

## 描述

测量系统的 S 参数

使用 S-Parameter Testbench 模块测量一般 RF 系统的 S 参数数据。S 参数测试台依次将激励信号注入每个端口，并测量所有端口的响应，以获得 RF 系统的散射矩阵。虽然激励应为小信号才能进行有意义的测量，但该测试台允许存在大的稳态外部信号。
