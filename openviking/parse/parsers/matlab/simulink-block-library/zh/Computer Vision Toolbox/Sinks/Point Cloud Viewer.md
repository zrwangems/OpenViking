# Point Cloud Viewer

## 端口

### 输入

### **Location** — 三维坐标空间中的点位置 矩阵 | 数组

三维坐标空间中的点的位置，指定为：

- 对于三维点云，为 *M*×3 矩阵或 *M*×*N*×3 数组。
- 对于三维点云序列，为 *M*×3×*T* 或 *M*×*N*×3×*T* 数组，其中 *T* 是点云序列中三维点云的总数。

每个数组指定点云中点的 *x*、*y* 和 *z* 坐标，但无组织点云和有组织点云的格式不同。

- 对于无组织点云，必须将 **Location** 指定为 *M*×3 或 *M*×3×*T* 数组，其中 *M* 是点的总数，每一行提供点的 *xyz* 坐标。
- 对于有组织点云，必须将 **Location** 指定为 *M*×*N*×3 或 *M*×*N*×3×*T* 数组，其中 *M*×*N* 是点的总数，数组的第三维提供对应点的 *x*、*y* 和 *z* 坐标。投影相机（例如 Kinect 或 lidar 传感器）将点存储为有组织点云。有组织点云布局为二维或三维点数组，类似于图像或视频结构。

**数据类型：** `single` | `double` | `uint8` | `uint16`

### **Color** — 点云颜色 `[]`（默认） | 矩阵 | 数组

点云颜色，指定为：

- 对于三维点云，为 *M*×3 矩阵或 *M*×*N*×3 数组。
- 对于三维点云序列，为 *M*×3×*T* 或 *M*×*N*×3×*T* 数组，其中 *T* 是点云序列中三维点云的总数。

对于无组织点云，指定为 *M*×3 矩阵或 *M*×3×*T* 数组时，每一行指定点云数据中一个点的 RGB 颜色三元组。对于有组织点云，指定为 *M*×*N*×3 或 *M*×*N*×3×*T* 数组时，第三维的每个通道指定点云数据中对应点的 RGB 颜色三元组。可以为所有点指定相同颜色，也可以为每个点指定不同颜色。

- 对于 `single` 或 `double` 数据类型，必须将 **Color** RGB 值指定在 [0, 1] 范围内。
- 对于 `uint8` 数据类型，必须将 **Color** RGB 值指定在 [0, 255] 范围内。
- 对于 `uint16` 数据类型，必须将 **Color** RGB 值指定在 [0, 65535] 范围内。

**注意**

**Color** 端口的输入必须与 **Location** 端口的输入具有相同的维度和数据类型。

#### 依赖关系

要启用此端口，请选择 **文件** >  **Location 和 Color 端口** 参数。

**数据类型：** `single` | `double` | `uint8` | `uint16`

### **Intensity** — 灰度强度 `[]`（默认） | 向量 | 矩阵 | 数组

*自 R2025a 起*

每个点的灰度强度，指定为：

- 对于无组织点云，为 *M*×1 向量；对于有组织点云，为 *M*×*N* 矩阵。
- 对于无组织点云序列，为 *M*×1×*T* 数组；对于有组织点云序列，为 *M*×*N*×*T* 数组。*T* 是点云序列中三维点云的总数。

**注意**

**Intensity** 端口的输入必须与 **Location** 端口的输入具有相同的数据类型。

#### 依赖关系

要启用此端口，请选择 **文件** >  **Location 和 Intensity 端口** 参数。

**数据类型：** `single` | `double` | `uint8` | `uint16`

## 参数

### 文件

### **在仿真开始时打开** — 在仿真开始时打开 Point Cloud Viewer 窗口 `on`（默认） | `off`

选择此参数可在仿真开始时显示 Point Cloud Viewer 窗口。清除此参数可防止 Point Cloud Viewer 窗口在仿真开始时打开。

### **Location 端口** — 启用点位置作为输入 `on`（默认） | `off`

选择此参数可启用 **Location** 端口，用于输入三维点云坐标。如果选择此参数，**Location 和 Color 端口** 和 **Location 和 Intensity 端口** 参数会自动清除。

### **Location 和 Color 端口** — 启用点位置和颜色作为输入 `off`（默认） | `on`

选择此参数可同时启用 **Location** 和 **Color** 输入端口。如果选择此参数，**Location 端口** 和 **Location 和 Intensity 端口** 参数会自动清除。

### **Location 和 Intensity 端口** — 启用点位置和强度作为输入 `off`（默认） | `on`

*自 R2025a 起*

选择此参数可同时启用 **Location** 和 **Intensity** 输入端口。如果选择此参数，**Location 端口** 和 **Location 和 Color 端口** 参数会自动清除。

### 文件 > 配置 > 编辑 > 核心

Point Cloud Viewer 配置对话框可用于更改图形用户界面 (GUI) 的行为和外观。

- 要打开配置对话框并编辑参数，请选择 **文件** > **配置**  > **编辑**。

配置对话框中的 **核心** 选项卡列出 GUI 的常规设置。

- 在 **核心** 选项卡中，选择 `General UI`，然后单击 **属性** 以打开 General UI 属性对话框。

### **显示完整路径** — 在标题栏中显示源数据的完整路径 `off`（默认） | `on`

选择此参数可在 Point Cloud Viewer 窗口的标题栏中显示模型名称和源数据的完整路径。如果清除此参数，窗口将显示缩短的名称。

### 工具 > 点云信息

点云信息对话框显示有关输入点云序列的信息。此信息包括 **源类型**、**源名称**、**帧大小**、**源数据类型** 和 **显示数据类型**。

### 视图

### **将所有 Point Cloud Viewer 窗口置于顶层** — 将所有 Point Cloud Viewer 窗口置于显示前端 `off`（默认） | `on`

选择此参数可将所有 Point Cloud Viewer 窗口向前置于所有其他打开的窗口之前。

### **仿真工具栏** — 显示仿真工具栏 `on`（默认） | `off`

选择此参数可在 Point Cloud Viewer 窗口上显示仿真工具栏。

仿真工具栏

要使用仿真工具栏执行相关操作，请按照表中所述选择相应功能。

| 功能 | 描述 |
| --- | --- |
| 运行 | 启动仿真，并查看点云序列。 |
| 单步前进 | 启动仿真，查看点云序列的一帧，然后暂停。 |
| 停止 | 停止仿真。 |
| 高亮 Simulink 模块 | 在 Simulink 模型中以蓝色背景高亮 Point Cloud Viewer 模块。 |
| 快照（冻结显示） | 冻结 Point Cloud Viewer 窗口，使您可以使用 **文件** 菜单中的 **打印** 或 **打印预览** 选项拍摄窗口快照。  **注意**  取消选择此选项可将 Point Cloud Viewer 窗口从冻结状态恢复为活动状态。 |
| 设置 | 启用 Point Cloud Viewer 窗口上的 **设置** 窗格。 |
| 颜色栏 *(自 R2025a 起)* | 在 Point Cloud Viewer 窗口中查看颜色栏。  默认情况下，Point Cloud Viewer 窗口不显示颜色栏。要查看颜色栏，请单击仿真工具栏上的 **颜色栏**。要隐藏颜色栏，请再次单击 **颜色栏**。  **依赖关系**  要启用此参数，请选择 **文件** >  **Location 端口** 或 **文件** >  **Location 和 Intensity 端口** 参数。 |

### **状态栏** — 显示状态栏 `on`（默认） | `off`

选择此参数可在 Point Cloud Viewer 窗口上显示状态栏。状态栏位于 Point Cloud Viewer 窗口底部，显示有关点云序列的以下信息。

- 维度
- 组织方式
- 仿真期间窗口的状态
- 当前帧的时间戳

### **高亮 Simulink 模块** — 高亮 Point Cloud Viewer 模块 `off`（默认） | `on`

在 Simulink 模型中以蓝色高亮 Point Cloud Viewer 模块。

### 仿真

要访问此参数，请在 Point Cloud Viewer 窗口中选择 **仿真** 菜单。

### **运行** — 查看整个点云序列 `off`（默认） | `on`

选择此参数可启动仿真，并连续查看从第一帧到最后一帧的点云序列。您也可以通过单击仿真工具栏上的 **运行** 来执行此操作。

### **继续** — 继续查看点云序列 `off`（默认） | `on`

选择此参数可继续查看点云序列直到最后一帧。要启用 **继续** 参数，请通过单击仿真工具栏上的 **单步前进** 来启动仿真。

### **停止** — 停止查看点云序列 `off`（默认） | `on`

选择此参数可停止显示点云序列。您也可以通过单击仿真工具栏上的 **停止** 来执行此操作。

### **丢帧以提高性能** — 降低输入点云序列的帧率 `on`（默认） | `off`

选择此参数可降低输入流式点云序列的帧率，以提高仿真性能。如果清除此参数，模块将在仿真期间显示输入点云序列信号中的每一帧。

## 描述

可视化流式点云数据序列

Point Cloud Viewer 模块创建一个 Point Cloud Viewer 窗口，用于显示从设备（例如 Microsoft® Kinect® 或 lidar 传感器）流式传输的三维点云数据序列。Point Cloud Viewer 模块还在 Point Cloud Viewer 窗口中提供仿真控制，以播放、暂停和单步调试流式点云数据序列。

Point Cloud Viewer 窗口

### Point Cloud Viewer 的功能

- 播放控制 — 使用 **运行**、**单步前进** 和 **停止** 按钮控制点云序列的流式播放。
- 设置坐标轴范围 — 通过设置 *x*、*y* 和 *z* 轴范围来限制三维点云数据的显示。
- 设置背景颜色 — 设置查看器窗口的背景颜色，用于显示点云数据。
- 垂直轴方向控制 — 将点云数据的垂直轴方向设置为向上为正或向下为正。
- 视图平面控制 — 设置视图平面以更改点云数据的视角。
- 分析点云数据 — 使用 Point Cloud Viewer 窗口的坐标轴工具栏上的 **数据提示** 选项检查点云数据。
- 查看颜色栏 — 使用仿真工具栏上的 **颜色栏** 按钮查看 Point Cloud Viewer 窗口中的颜色栏。
