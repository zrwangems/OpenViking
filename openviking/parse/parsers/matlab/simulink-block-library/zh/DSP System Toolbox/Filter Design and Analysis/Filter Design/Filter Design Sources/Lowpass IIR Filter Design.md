# Lowpass IIR Filter Design

## 端口

### 输入

### **N** — 滤波器阶数 正整数

将滤波器阶数指定为正整数。您可以在仿真期间更改通过此端口输入的滤波器阶数。

#### 依赖关系

要启用此端口，请选择 **从输入端口指定滤波器阶数** 参数。

**数据类型：** `single` | `double` | `int8` | `int16` | `int32` | `int64` | `uint8` | `uint16` | `uint32` | `uint64`

### **Fc** — 3-dB 截止频率 正标量 ≤ 1

以归一化频率单位将滤波器的 3-dB 截止频率指定为小于或等于 `1` 的正标量。您可以在仿真期间更改通过此端口输入的 3-dB 截止频率。

#### 依赖关系

要启用此端口，请选择 **从输入端口指定 3-dB 截止频率** 参数。

**数据类型：** `single` | `double`

### **Ap** — 通带波纹，以 dB 为单位 正标量

将 Chebyshev Type I 滤波器的通带波纹指定为以 dB 为单位的正标量。您可以在仿真期间更改通过此端口输入的通带波纹。

#### 依赖关系

要启用此端口：

- 将 **设计方法** 参数设置为 `Chebyshev Type I`。
- 选择 **从输入端口指定通带波纹** 参数。

**数据类型：** `single` | `double`

### **Ast** — 阻带衰减，以 dB 为单位 正标量

将 Chebyshev Type II 滤波器的阻带衰减指定为以 dB 为单位的正标量。您可以在仿真期间更改通过此端口输入的阻带衰减。

#### 依赖关系

要启用此端口：

- 将 **设计方法** 参数设置为 `Chebyshev Type II`。
- 选择 **从输入端口指定阻带衰减** 参数。

**数据类型：** `single` | `double`
### 输出

### **Num** — 分子系数 *P*×3 矩阵

分子系数，以 *P*×3 矩阵（SOS 形式）返回，其中 *P* 是滤波器节的最大数量。

b=[b01b11b21b02b12b22⋮⋮⋮b0Pb1Pb2P]

此方程以传递函数形式表示 SOS 滤波器。

H(z)=∏k=1PHk(z)=∏k=1Pb0k+b1kz−1+b2kz−2a0k+a1kz−1+a2kz−2,

其中

- **b** 是分子系数矩阵。
- **a** 是分母系数矩阵，模块在 **Den** 输出端口输出该矩阵。
- *k* 是行索引。

*P* 等于 `ceil`(*Nmax*/2)，其中 *Nmax* 是 **最大滤波器阶数** 参数的值。

当实际滤波器阶数 *N* 小于最大滤波器阶数 *Nmax* 时，最后 `ceil`(*Nmax*/2) − `ceil`(*N*/2) 个节是平凡的，其系数为 [*b*0, *b*1, *b*2] = [1, 0, 0]。

当实际滤波器阶数 *N* 为奇数时，最后一个非平凡滤波器节的系数为 [*b*0, *b*1, 0] = [1, 1, 0]。

此端口的数据类型取决于 **输出数据类型** 参数的值。

**数据类型：** `single` | `double`

### **Den** — 分母系数 *P*×3 矩阵

分母系数，以 *P*×3 矩阵（SOS 形式）返回，其中 *P* 是滤波器节的最大数量。

a=[a01a11a21a02a12a22⋮⋮⋮a0Pa1Pa2P]

此方程以传递函数形式表示 SOS 滤波器。

H(z)=∏k=1PHk(z)=∏k=1Pb0k+b1kz−1+b2kz−2a0k+a1kz−1+a2kz−2,

其中

- **a** 是分母系数矩阵，并且前导分母系数 *a*0 始终为 1。
- **b** 是分子系数矩阵，模块在 **Num** 端口输出该矩阵。
- *k* 是行索引。

*P* 等于 `ceil`(*Nmax*/2)，其中 *Nmax* 是 **最大滤波器阶数** 参数的值。

当实际滤波器阶数 *N* 小于最大滤波器阶数 *Nmax* 时，最后 `ceil`(*Nmax*/2) − `ceil`(*N*/2) 个节是平凡的，其系数为 [*a*0, *a*1, *a*2] = [1, 0, 0]。

当实际滤波器阶数 *N* 为奇数时，最后一个非平凡滤波器节的系数为 [1, *a*1, 0] = [1, 1, 0]。

此端口的数据类型取决于 **输出数据类型** 参数的值。

**数据类型：** `single` | `double`

### **g** — 每个二阶节的缩放值 向量

每个二阶节的缩放值，以包含 *P* + 1 个元素的向量形式返回，其中 *P* 是滤波器节的最大数量，等于 `ceil`(*Nmax*/2)，其中 *Nmax* 是 **最大滤波器阶数** 参数的值。

**可调：** 是

#### 依赖关系

要启用此端口，请选择 **设计具有缩放值** 参数。

**数据类型：** `single` | `double`

## 参数

### **平滑可调滤波器参数** — 平滑可调滤波器参数 `off`（默认）| `on`

*自 R2024a 起*

选择此复选框时，模块会通过使用参数的中间值反复设计滤波器，以逐渐更新可调滤波器参数（例如滤波器阶数、截止频率、通带波纹和阻带衰减），直到参数达到所需值。此过程称为参数平滑。有关更多信息，请参阅参数平滑。

清除此复选框时，模块会立即使用新参数值重新设计滤波器。

### **平滑因子** — 平滑因子 0.6（默认）| 小于 1 的非负标量

*自 R2024a 起*

将平滑因子 *α* 指定为小于 1 的非负标量。当 *α* = 0 时，不发生平滑。随着 *α* 接近 1，平滑操作次数以及由此导致的滤波器重新设计次数会增加。

**可调：** 是

#### 依赖关系

要启用此参数，请选择 **平滑可调滤波器参数** 参数。

### **设计方法** — 滤波器设计方法 `Butterworth`（默认）| `Chebyshev Type I` | `Chebyshev Type II`

将滤波器设计方法指定为以下之一：

- `Butterworth`
- `Chebyshev Type I`
- `Chebyshev Type II`

### **从输入端口指定滤波器阶数** — 用于从输入端口指定滤波器阶数的标志 `off`（默认）| `on`

选择此参数以从输入端口 **N** 指定滤波器阶数。清除此参数时，您可以使用 **滤波器阶数** 参数在模块对话框中指定滤波器阶数。

### **滤波器阶数** — 滤波器阶数 `6`（默认）| 正整数

将滤波器阶数指定为小于或等于 **最大滤波器阶数** 参数值的正整数。

**可调：** 是

#### 依赖关系

要启用此参数，请清除 **从输入端口指定滤波器阶数** 参数。

**数据类型：** `single` | `double` | `int8` | `int16` | `int32` | `int64` | `uint8` | `uint16` | `uint32` | `uint64`

### **最大滤波器阶数** — 滤波器的最大阶数 `10`（默认）| 正整数

将滤波器的最大阶数指定为正整数。在 **滤波器阶数** 参数中指定的值必须小于或等于在 **最大滤波器阶数** 参数中指定的值。

**数据类型：** `single` | `double` | `int8` | `int16` | `int32` | `int64` | `uint8` | `uint16` | `uint32` | `uint64`

### **设计具有缩放值** — 指定滤波器是否具有每个节的缩放值 `off`（默认）| `on`

指定滤波器是否具有每个节的缩放值。选择此参数时，模块通过 **g** 输出端口输出缩放值。

### **从输入端口指定 3-dB 截止频率** — 用于从输入端口指定 3-dB 截止频率的标志 `off`（默认）| `on`

选择此参数以从输入端口 **Fc** 指定 3-dB 滤波器截止频率。清除此参数时，您可以使用 **3-dB 截止频率** 参数在模块对话框中指定截止频率。

### **3-dB 截止频率** — 3-dB 截止频率 `0.25`（默认）| 正标量 ≤ 1

以归一化频率单位将滤波器的 3-dB 截止频率指定为小于或等于 `1` 的正标量。

**可调：** 是

#### 依赖关系

要启用此参数，请清除 **从输入端口指定 3-dB 截止频率** 参数。

**数据类型：** `single` | `double`

### **从输入端口指定通带波纹** — 用于从输入端口指定通带波纹的标志 `off`（默认）| `on`

选择此参数以从输入端口 **Ap** 指定通带波纹。清除此参数时，您可以使用 **通带波纹 (dB)** 参数在模块对话框中指定通带波纹。

#### 依赖关系

要启用此参数，请将 **设计方法** 参数设置为 `Chebyshev Type I`。

### **通带波纹 (dB)** — 通带波纹，以 dB 为单位 `1`（默认）| 正标量

将 Chebyshev Type I 滤波器的通带波纹指定为以 dB 为单位的正标量。

**可调：** 是

#### 依赖关系

- 将 **设计方法** 参数设置为 `Chebyshev Type I`。
- 清除 **从输入端口指定通带波纹** 参数。

**数据类型：** `single` | `double`

### **从输入端口指定阻带衰减** — 用于从输入端口指定阻带衰减的标志 `off`（默认）| `on`

选择此参数以从输入端口 **Ast** 指定阻带衰减。清除此参数时，您可以使用 **阻带衰减 (dB)** 参数在模块对话框中指定阻带衰减。

#### 依赖关系

要启用此参数，请将 **设计方法** 参数设置为 `Chebyshev Type II`。

### **阻带衰减 (dB)** — 阻带衰减，以 dB 为单位 `60`（默认）| 正标量

将 Chebyshev Type II 滤波器的阻带衰减指定为以 dB 为单位的正标量。

**可调：** 是

#### 依赖关系

要启用此参数：

- 清除 **从输入端口指定阻带衰减** 参数。

**数据类型：** `single` | `double`

### **采样时间** — 采样时间，以秒为单位 `-1`（默认）| 正标量 | `Inf`

将采样时间指定为 `-1`（继承）、`Inf`（常量采样时间）或正标量。此参数决定模块在仿真期间何时产生输出并更新其内部状态。有关更多详细信息，请参阅什么是采样时间？(Simulink)。

**数据类型：** `single` | `double`

### **输出数据类型** — 滤波器系数的数据类型 `double`（默认）| `single`

指定模块通过 **Num** 和 **Den** 端口输出的滤波器系数的数据类型。您可以将数据类型设置为 `double` 或 `single`。

### **仿真方式** — 要运行的仿真类型 `Interpreted execution`（默认）| `Code generation`

指定要运行的仿真类型。您可以将此参数设置为：

- `Interpreted execution` —— 使用 MATLAB® 解释器仿真模型。此选项可缩短启动时间。
- `Code generation` —— 使用生成的 C 代码仿真模型。第一次运行仿真时，Simulink® 会为该模块生成 C 代码。只要模型不改变，后续仿真将重用该 C 代码。此选项需要额外的启动时间，但可提供更快的后续仿真。

## 描述

设计具有可调滤波器规格的低通 IIR 滤波器

使用 Lowpass IIR Filter Design 模块，通过 Butterworth、Chebyshev Type I 和 Chebyshev Type II 设计方法设计低通 IIR 滤波器。您可以在仿真期间调整滤波器设计规格，例如滤波器阶数、3-dB 截止频率、通带波纹和阻带衰减。当这些参数的值发生变化时，模块会重新设计滤波器，并以二阶节 (SOS) 形式输出分子和分母系数。
