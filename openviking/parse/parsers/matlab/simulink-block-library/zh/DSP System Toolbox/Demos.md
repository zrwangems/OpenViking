DSP System Toolbox™ 提供算法、应用和示波器，用于在 MATLAB® 和 Simulink® 中设计、仿真和分析信号处理系统。您可以为通信、雷达、音频、医疗设备、IoT 及其他应用建模实时 DSP 系统。

使用 DSP System Toolbox，您可以设计和分析 FIR、IIR、多速率、多级和自适应滤波器。您可以从变量、数据文件和网络设备流式传输信号，用于系统开发和验证。Time Scope、Spectrum Analyzer 和 Logic Analyzer 让您可以动态可视化和测量流式信号。对于桌面原型设计和部署到嵌入式处理器（包括 ARM® Cortex® 架构），该工具箱支持 C/C++ 代码生成。它还支持位精确定点建模以及从滤波器、FFT、IFFT 和其他算法生成 HDL 代码。

算法以 MATLAB 函数、System object 和 Simulink 模块的形式提供。
