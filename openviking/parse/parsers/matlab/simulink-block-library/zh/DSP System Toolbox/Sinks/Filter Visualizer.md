# Filter Visualizer

## 端口

### 输入

### **Num** — 分子系数列向量 | 行向量 | *L*×3 矩阵 | *L*×5 矩阵

将滤波器的分子系数指定为行向量、列向量、对应于二阶节级联的 *L*×3 矩阵，或对应于四阶节级联的 *L*×5 矩阵，其中 *L* 是滤波器节数。

如果将 **Num Filters** 设置为大于 1 的值，则该模块为每个滤波器显示一个 **Num** 端口。

当将 **Filter Type** 设置为 `FIR` 时，所有 **Num** 端口上的输入必须为列向量或行向量。

**数据类型：** `single` | `double`

### **Den** — 分母系数列向量 | 行向量 | *L*×3 矩阵 | *L*×5 矩阵

将滤波器的分母系数指定为行向量、列向量、对应于二阶节级联的 *L*×3 矩阵，或对应于四阶节级联的 *L*×5 矩阵，其中 *L* 是滤波器节数。

如果将 **Num Filters** 设置为大于 1 的值，则该模块为每个滤波器显示一个 **Den** 端口。

#### 依赖关系

要启用此端口，请将 **Filter Type** 设置为 `IIR`。

**数据类型：** `single` | `double`

### **Filter Type** — 滤波器响应类型 `FIR`（默认） | `IIR`

将滤波器响应类型指定为以下选项之一：

- `FIR` –– 该模块为每个滤波器显示一个输入端口。通过端口输入滤波器的分子系数。
- `IIR` –– 该模块为每个滤波器显示两个输入端口。通过端口输入滤波器的分子和分母系数。

|  |

### **Legend** — 显示信号图例 `off`（默认） | `on`

可以使用图例控制示波器中哪些滤波器可见。单击图例中的滤波器名称可在示波器中隐藏该滤波器的频率响应。要显示滤波器响应，请再次单击该滤波器名称。要仅显示一个滤波器响应，请右键单击该滤波器名称，这将隐藏所有其他滤波器响应。要显示所有滤波器响应，请按 **Esc**。此设置等效于在 **Scope** 选项卡 > **Settings**（齿轮按钮）> **Color and Styling** 中更改 **Visible** 参数。

- `Stairs` –– 滤波器可视化器将滤波器响应（幅值、相位或两者）显示为阶梯图。阶梯图仅由水平线和垂直线组成。每条水平线表示某个频率值上的滤波器响应，并连接到两条垂直线。每条垂直线表示在某个频率处发生的值变化。

## 描述

显示时变数字滤波器的幅值和相位响应

Filter Visualizer 模块显示时变数字滤波器或时变滤波器系数的幅值响应和相位响应。使用此可视化器一次最多可可视化 20 个滤波器的频率响应。

可以使用可视化器配置绘图设置、查找峰值、启用游标测量，甚至将示波器显示复制到剪贴板。有关详细信息，请参阅 Configure Filter Visualizer。要以编程方式访问滤波器可视化器，请使用 `dsp.DynamicFilterVisualizer` 对象。

Filter Visualizer 显示工具条的 Measurements 选项卡。数据游标和峰值查找器已启用。
