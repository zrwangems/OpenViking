# Time Scope

## 端口

### 输入

### **Port\_1** — 要可视化的单个或多个信号 scalar | vector | matrix | array | bus | nonvirtual bus

连接要可视化的信号。最多可以有 96 个输入端口。输入信号可以具有以下特性：

- **类型** — 连续（基于采样）或离散（基于采样和基于帧）。
- **数据类型** — Simulink 支持的任何数据类型。请参阅 Simulink 支持的数据类型 (Simulink)。

  此模块接受定点输入，但会将其转换为 `double` 以进行显示。
- **维度** — 标量、一维（向量）、二维（矩阵）或多维（数组）。根据维度在一个信号中显示多个通道。请参阅信号维度 (Simulink) 和确定信号维度 (Simulink)。

#### 输入限制

- 当输入为常量信号时，示波器只绘制一个点。
- 当信号值为 `NaN` 时，示波器的显示中会出现间隙。
- 在示波器中可视化多个基于帧的信号时，帧大小为 1 的信号的某些采样可能不会显示。要可视化这些信号，请将帧大小为 1 的信号移至单独的示波器。

#### 总线支持

可以将非虚拟总线和总线信号数组连接到示波器。要显示总线信号，请使用普通或加速仿真模式。示波器按照各元素在总线中从上到下的出现顺序显示每个总线元素信号。嵌套总线元素会被展平。

要使用示波器记录非虚拟总线信号，请将**保存格式**参数设置为 `Dataset`。记录虚拟总线信号时，可以使用任意**保存格式**。

**数据类型：** `single` | `double` | `half` | `int8` | `int16` | `int32` | `int64` | `uint8` | `uint16` | `uint32` | `uint64` | `Boolean` | `fixed point` | `enumerated` | `bus`
**复数支持：** 是

### **输入处理** — 基于采样或基于帧的处理 `Elements as channels (sample based)`（Scope 的默认值） | `Columns as channels (frame based)`（Time Scope 的默认值）

指定模块执行基于采样还是基于帧的处理。

- `Elements as channels (sample based)` ––
  将输入的每个元素作为独立通道进行处理。
- `Columns as channels (frame based)` ––
  将输入的每一列作为独立通道进行处理。基于帧的处理仅适用于离散输入信号。

更改**输入处理**参数的设置时，示波器会清除信号数据和测量数据（如果有）。重新运行仿真，以使用新设置绘制信号数据。*（自 R2025a 起）*

**注意**

基于帧的处理需要 DSP System Toolbox 许可证。有关详细信息，请参阅基于采样和基于帧的概念。

#### 编程使用

请参阅 `FrameBasedProcessing` (Simulink)。

### **时间跨度** — 要显示的 *x* 轴长度 `Auto`（默认值） | `One frame period` | `<user-defined>`

将要显示的 *x* 轴长度指定为以下选项之一：

- `Auto` — 仿真开始时间与停止时间之差。

  模块使用**时间显示偏移量**和**时间跨度**参数计算时间范围的开始时间和结束时间。例如，如果将**时间显示偏移量**设置为 `10`，并将**时间跨度**设置为 `20`，则示波器会将时间范围设置为从 `10` 到 `30`。
- `One frame period` — 使用 Time Scope 模块输入信号的帧周期。仅当将**输入处理**参数设置为 `Columns as channels (frame based)` 时，此选项才可用。
- `<user-defined>` — 输入小于总仿真时间的任意值。

#### 编程使用

请参阅 `TimeSpan` (Simulink)。

### **溢出操作** — 显示超出可见 *x* 轴范围的数据 `Wrap`（默认值） | `Scroll`

指定如何显示超出可见 *x* 轴范围的数据。

仅当大型模型或较小步长导致绘图速度缓慢时，才能看到此选项的效果。

- `Wrap` — 从左到右绘制一整屏数据，清除屏幕，然后从左侧重新开始绘制数据。
- `Scroll` — 在右侧绘制新数据时，将数据向左移动。此模式需要进行大量图形处理，可能会影响运行时性能。

#### 编程使用

请参阅 `TimeSpanOverrunAction` (Simulink)。

### **Y 轴范围缩放** — *y* 轴缩放模式 `Manual`（默认值） | `Auto` | `After N Updates`

### **Y 轴数据范围 (%)** — 用于绘图的 *y* 轴百分比 `80`（默认值） | [1,100] 之间的整数

指定用于绘制数据的 *y* 轴范围百分比。如果将此参数设置为 `100`，则绘制的数据将使用整个 *y* 轴范围。

### **Y 轴对齐** — 沿 *y* 轴的对齐方式 `Center`（默认值） | `Top` | `Bottom`

#### 设置 > 记录

### **仅保留最后的数据点**、**仅保留最后的帧** — 限制缓冲的数据点或帧 `off`（默认值） | `on`

选择此属性可限制示波器内部保存的数据。当选择此属性并将**输入处理**参数设置为以下值时：

- `Elements as channels (sample based)` –– 示波器将最后 *n* 个数据点保存到**变量名**中指定的 MATLAB® 变量。在此设置下，此属性的名称为**仅保留最后的数据点**。
- `Columns as channels (frame based)` –– 示波器将最后 *n* 个数据帧保存到**变量名**中指定的 MATLAB 变量。在此设置下，此属性的名称为**仅保留最后的帧**。

*n* 是您在**最大点数**参数中指定的标量值。

选中此参数时，示波器绘制信号的时间范围可能小于整个仿真时间范围，例如采样时间较小时。如果示波器仅绘制信号的一部分，请考虑增加要保存的数据点数。

清除此属性时，示波器会保存所有数据。仿真结束后，可以在示波器中可视化全部数据。对于**停止时间**设置为 `inf` 的仿真，请考虑选择此属性。

**注意**

如果不选择此属性，并且采样率较高或仿真时间较长，则可能会遇到内存或系统性能问题。

#### 编程使用

请参阅 `DataLoggingLimitDataPoints` (Simulink)。

### **最大点数** — 要保存的最大数据点数 `5000` | 正整数

将要保存的最大数据点数 *n* 指定为正整数。示波器会将最后 *n* 个数据点保存到**变量名**中指定的 MATLAB 变量。

#### 依赖关系

要启用此参数，请选择**仅保留最后的数据点**或**仅保留最后的帧**参数。

#### 编程使用

请参阅 `DataLoggingMaxPoints` (Simulink)。

### **抽取**、**帧抽取** — 减少要显示和保存的示波器数据量 `off`（默认值） | `on`

选择此属性可每第 *N* 个数据点或帧绘制并记录（保存）一次示波器数据，其中 *N* 是您在**抽取值**参数中指定的抽取因子。

当选择此属性并在**抽取值**参数中指定标量值时，示波器会限制所绘制的数据值以及保存到**变量名**中指定的 MATLAB 变量的数据值。

将**输入处理**参数设置为以下值时：

- `Elements as channels (sample based)` –– 示波器每第 *N* 个数据点绘制并记录一次数据。此属性的名称为**抽取**。
- `Columns as channels (frame based)` –– 示波器每第 *N* 帧绘制并记录一次数据。此属性的名称为**帧抽取**。

清除此属性时，示波器会保存所有示波器数据。

#### 编程使用

请参阅 `DataLoggingDecimateData` (Simulink) 和 `DataLoggingDecimation` (Simulink)。

### **抽取值** — 抽取值 `2`（默认值） | 正整数

指定示波器每第 *N* 个数据点或帧保存或记录一次数据，其中 *N* 是您在此参数中指定的值。

值为 `1` 时会缓冲所有数据值。

#### 依赖关系

要启用此参数，请选择**抽取**或**帧抽取**。

#### 编程使用

请参阅 `DataLoggingDecimateData` (Simulink) 和 `DataLoggingDecimation` (Simulink)。

### **将数据记录到工作区** — 将数据保存到 MATLAB 工作区 `off`（默认值） | `on`

选中此参数可启用记录，并将记录的数据保存到 MATLAB 工作区。选中此参数时，示波器还会启用**变量名**和**保存格式**参数。此参数不适用于浮动示波器和示波器查看器。

有关使用 Scope 模块将信号保存到 MATLAB 工作区的示例，请参阅使用 Scope 模块保存仿真数据 (Simulink)。

指定用于将示波器数据保存到 MATLAB 工作区的变量名。此参数不适用于浮动示波器和示波器查看器。

### **保存格式** — MATLAB 变量格式 `Dataset`（默认）| `Structure With Time` | `Structure` | `Array`

#### 设置 > 坐标区样式

### **绘图类型** — 绘图类型 `Auto`（Scope 的默认值）| `Line`（Time Scope 的默认值）| `Stairs` | `Stem`

将绘图类型指定为以下类型之一：

- `Auto` –– 对于连续信号，绘图类型为线图；对于离散信号，为阶梯图；对于 Simulink 消息信号，为针状图。
- `Line` –– 线图。
- `Stairs` –– 阶梯图。阶梯图仅由水平线和垂直线组成。每条水平线表示一个离散采样周期内的信号值，并连接到两条垂直线。每条垂直线表示在特定采样时间发生的信号值变化。
- `Stem` –– 针状图，在输入值处显示圆圈，并用垂直线连接到 *x* 轴。

选择示波器显示窗口的背景颜色。

### **坐标区和网格** — 各个显示窗口的坐标区、网格和标签颜色 gray（默认）| 颜色

选择各个显示窗口的坐标区、网格和标签颜色。

### **示波器背景** — 示波器窗口的背景颜色 black（默认）| 颜色

选择示波器窗口的背景颜色。

### R2025a：改进的示波器和新的示波器容器，可将所有示波器停靠在一个窗口中

Simulink 中的 Simulink Scope (Simulink)、Time Scope 和 Floating Scope and Scope Viewer (Simulink) 模块提供了新的用户界面，您可以使用该界面访问示波器的设置和测量。示波器现在响应更迅速，性能也得到提升。使用新的示波器容器可将多个示波器窗口停靠到单个窗口中，并管理和组织示波器。示波器容器还使您能够在单个窗口中查看模型中的所有示波器。

Scope、Time Scope 和 Floating Scope and Scope Viewer 模块的主要改进包括：

- 精简的用户界面：通过新示波器工具条的 **Scope** 选项卡可轻松访问所有常规示波器设置，通过 **测量** 选项卡可轻松访问所有测量设置。
- 新的示波器容器：单个窗口为模型中的所有示波器显示窗口提供统一视图，使您能够在一个位置管理和组织多个示波器。
- 更新的设置面板：更新后的面板整合了示波器的所有常规和样式设置。要打开该面板，请点击工具条 **Scope** 选项卡中的 **设置**。

### R2025a：已移除通过 MATLAB Graphics API 访问 Time Scope 的功能

Time Scope 模块的底层图形已更改。您无法通过 MATLAB Graphics API 访问或修改 Time Scope 模块。

要在 MATLAB Graphics 窗口中显示示波器数据，请使用 Time Scope 模块工具条 **Scope** 选项卡中的 **打印到图窗** 功能。

### R2025a：已移除将示波器停靠到 MATLAB 桌面的功能

将 Simulink Scope (Simulink)、Time Scope 和 Floating Scope and Scope Viewer (Simulink) 停靠到 MATLAB 桌面的功能已移除。请改用新的示波器容器。有关详细信息，请参阅示波器窗口管理。

如果您有一个在 R2024b 或更早版本中创建且打开了四个或更多示波器的模型，并在 R2025a 中打开该模型，则已打开的示波器会自动停靠在示波器容器窗口中。

## 描述

显示并分析仿真过程中生成的信号，并将信号数据记录到 MATLAB 中

Simulink® Scope 模块和 DSP System Toolbox™ Time Scope 模块用于显示时域信号。

这两个模块的功能完全相同，但默认设置不同。Time Scope 针对离散时间处理进行了优化。Scope 针对一般时域仿真进行了优化。有关并排比较，请参阅 Simulink Scope Block Versus DSP System Toolbox Time Scope Block (Simulink)。

**Scope 选项卡**

此屏幕截图突出显示了示波器窗口的重要方面。

**Scope 显示功能：**

- 仿真控制——使用 **Run**、**Step Forward** 和 **Step Backward** 工具栏按钮，从 Scope 窗口运行和调试模型。
- 多个信号——使用多个输入端口，在同一显示画面中绘制多个信号。
- 多个显示画面——在多个子图中显示信号。所有子图的 *y* 轴都对应 *x* 轴上相同的时间范围。使用工具条 **Scope** 选项卡中的 **Display Grid** 参数控制子图的布局。
- 修改参数——在仿真前和仿真过程中修改示波器参数值。
- 坐标轴自动缩放——在仿真过程中或仿真结束时自动缩放坐标轴。在坐标轴的顶部和底部绘制边距。
- 仿真后显示数据——在仿真过程中保存示波器数据。如果在仿真开始时示波器处于关闭状态，则在仿真结束后打开示波器时，示波器会显示所连接输入信号的仿真结果。

  **注意**

  如果采样率较高或仿真时间较长，由于示波器会在内部保存数据，您可能会遇到内存或系统性能问题。要限制为示波器可视化保存的数据量，请使用 `Limit data points to last` 属性。
- 示波器窗口管理——示波器容器允许您将 Simulink 模型中的多个示波器停靠到单个窗口中。该容器提供了一个便捷的界面，您可以通过它实现信号可视化并管理各示波器的设置。
