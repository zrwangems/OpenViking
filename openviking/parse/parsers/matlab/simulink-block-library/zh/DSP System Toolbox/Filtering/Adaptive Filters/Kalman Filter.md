## 参数

**滤波器数量**
:   指定用于预测或估计当前值的滤波器数量。

**启用滤波器**
:   指定在每个时间步启用或禁用哪些滤波器。如果选择 `Always`，则始终启用滤波器。如果选择 `Specify via input port <Enable>`，模块上会出现 Enable 端口。

**在滤波器禁用时重置估计状态和估计误差协方差**
:   如果选中此复选框，与禁用的滤波器相对应的估计状态和预测状态以及估计误差协方差将重置为其初始值。如果在 **启用滤波器** 参数中选择 `Specify via input port <Enable>`，则此参数可见。

**估计状态的初始条件**
:   输入估计状态的初始条件。

**估计误差协方差的初始条件**
:   输入估计误差协方差的初始条件。

**状态转移矩阵**
:   输入状态转移矩阵。

**过程噪声协方差**
:   输入过程噪声协方差。

**测量矩阵源**
:   指定测量矩阵值的输入方式。如果选择 `Specify via dialog`，对话框中会出现 **测量矩阵** 参数。如果选择 `Input port <H>`，模块上会出现 H 端口。

**测量矩阵**
:   输入测量矩阵值。如果为 **测量矩阵源** 参数选择 `Specify via dialog`，则此参数可见。

**测量噪声协方差**
:   输入测量噪声协方差。

**输出估计的测量值 <Z\_est>**
:   如果希望模块输出估计的测量值，请选中此复选框。

**输出估计状态 <X\_est>**
:   如果希望模块输出估计状态，请选中此复选框。

**输出估计状态的均方误差 <MSE\_est>**
:   如果希望模块输出估计状态的均方误差，请选中此复选框。

**输出预测的测量值 <Z\_prd>**
:   如果希望模块输出预测的测量值，请选中此复选框。

**输出预测状态 <X\_prd>**
:   如果希望模块输出预测状态，请选中此复选框。

**输出预测状态的均方误差 <MSE\_prb>**
:   如果希望模块输出预测状态的均方误差，请选中此复选框。

## 描述

预测或估计动态系统的状态

使用 Kalman Filter 模块，根据一系列不完整和/或含噪声的测量值，预测或估计动态系统的状态。假设您有一个由以下方程定义的含噪线性系统：

xk=Axk−1+wk−1zk=Hxk+vk

该模块可以使用先前估计的状态 x^k−1 来预测时刻 *k* 的当前状态 xk−，如下面的方程所示：

xk−=Ax^k−1Pk−=AP^k−1AT+Q

该模块还可以使用当前测量值 zk 和预测状态 xk− 来估计时刻 *k* 的当前状态值 x^k，从而得到更精确的近似值：

Kk=Pk−HT(HPk−HT+R)−1x^k=xk−+Kk(zk−Hxk−)P^k=(I−KkH)Pk−

上述方程中的变量在下表中定义。

| 变量 | 定义 | 默认值或初始条件 |
| --- | --- | --- |
| *x* | 状态 | N/A |
| x^ | 估计状态 | `zeros([6, 1])` |
| x− | 预测状态 | N/A |
| *A* | 状态转移矩阵 | [101000010100001000000100000010000001] |
| *w* | 过程噪声 | N/A |
| *z* | 测量值 | N/A |
| *H* | 测量矩阵 | [100000010000000010000001] |
| *v* | 测量噪声 | N/A |
| P^ | 估计误差协方差 | `10*eye(6)` |
| *P-* | 预测误差协方差 | N/A |
| *Q* | 过程噪声协方差 | `0.05*eye(6)` |
| *K* | 卡尔曼增益 | N/A |
| *R* | 测量噪声协方差 | `eye(4)` |
| *I* | 单位矩阵 | N/A |

在上述方程中，*z* 是测量值向量。大多数情况下，该模块处理 Z，即一个 M×N 矩阵，其中 M 是测量值的数量，N 是滤波器的数量。

使用 **滤波器数量** 参数指定用于预测或估计当前值的滤波器数量。

使用 **启用滤波器** 参数指定在每个时间步启用或禁用哪些滤波器。如果选择 `Always`，则始终启用滤波器。如果选择 `Specify via input port <Enable>`，模块上会出现 Enable 端口。该端口的输入必须是由 1 和 0 组成的行向量，其长度等于滤波器的数量。例如，如果有 3 个滤波器，并且 Enable 端口的输入为 [1 0 1]，则在此时间步仅启用第一个和第三个滤波器。如果选中 **在滤波器禁用时重置估计状态和估计误差协方差** 复选框，与禁用的滤波器相对应的估计状态和预测状态以及估计误差协方差将重置为其初始值。

**注意**

所有滤波器都具有相同的状态转移矩阵、测量矩阵、初始条件和噪声协方差，但它们的状态、测量、启用和 MSE 信号均为各自独有。在状态、测量、启用和 MSE 信号中，每一列对应一个滤波器。

使用 **测量矩阵源** 参数指定测量矩阵值的输入方式。如果选择 `Specify via dialog`，对话框中会出现 **测量矩阵** 参数。如果选择 `Input port <H>`，模块上会出现 H 端口。使用此端口指定测量矩阵。
