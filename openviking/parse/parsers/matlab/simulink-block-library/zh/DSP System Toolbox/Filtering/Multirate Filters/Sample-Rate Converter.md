# Sample-Rate Converter

## 端口

### 输入

### **Port\_1** — 输入信号 标量 | 向量 | 矩阵

将输入信号指定为实数或复数值的标量、向量或矩阵。

该模块将二维输入信号的每一列视为单独通道。如果输入是二维信号，则第一个维度表示通道长度（或帧大小），第二个维度表示通道数。如果输入是一维信号，则该模块将该信号解释为具有单个通道。

当您输入可变大小信号（帧长度在仿真期间变化）时，信号的帧长度可以是任意的，也就是说，输入帧长度不必是抽取因子的倍数。当您输入固定大小信号（帧长度在仿真期间不变化）时，仅当您选择 **允许固定大小输入信号使用任意帧长度** 参数时，帧长度才可以是任意的。

要确定抽取因子，请点击模块对话框中的 **查看信息** 按钮。

**数据类型：** `single` | `double`
**复数支持：** Yes

### 输出

### **Port\_1** — 重采样信号 标量 | 向量 | 矩阵

Sample-Rate Converter 模块输出与输入信号具有相同数据类型和复数属性的信号。

输出信号维度取决于输入信号维度、采样率转换器各阶段的插值和抽取因子，以及您是否选择 **允许固定大小输入信号使用任意帧长度** 参数。您可以通过点击模块对话框中的 **查看信息** 按钮来确定各阶段的插值因子 *L* 和抽取因子 *M*。

此表提供了当您输入固定大小信号且模块在单级中实现滤波器时输出信号维度的更多详细信息。

**固定大小输入信号的单级滤波器**

| 输入信号 | 输出信号维度 |
| --- | --- |
| *P*×1 列向量，其中 *P* 是抽取因子 *M* 的倍数 | (*LP*/*M*)×1，其中 *L* 是插值因子 |
| *P*×1 列向量，其中 *P* 不是抽取因子 *M* 的倍数 | 当您选择 **允许固定大小输入信号使用任意帧长度** 时，为 `ceil`(*LP*/*M*)×1。如果您未选择 **允许固定大小输入信号使用任意帧长度**，则该模块会报错。 |
| *P*×*Q* 矩阵，其中 *P* 是抽取因子 *M* 的倍数 | (*LP*/*M*)×*Q* |
| *P*×*Q* 矩阵，其中 *P* 不是抽取因子 *M* 的倍数 | 当您选择 **允许固定大小输入信号使用任意帧长度** 时，为 `ceil`(*LP*/*M*)×*Q*。如果您未选择 **允许固定大小输入信号使用任意帧长度**，则该模块会报错。 |

此表给出了当您输入可变大小信号且模块在单级中实现滤波器时输出信号维度的更多详细信息。

当您输入可变大小信号（帧长度在仿真期间变化）时，**允许固定大小输入信号使用任意帧长度** 参数在模块对话框中可见，但不会对输入帧长度产生任何影响。即使您未选择 **允许固定大小输入信号使用任意帧长度** 参数，也可以输入任意帧长度的可变大小信号。

**可变大小输入信号的单级滤波器**

| 输入信号 | 输出信号维度 |
| --- | --- |
| *P*×*Q* | `ceil`(*LP*/*M*)×*Q* |

**多级滤波器实现**

当模块使用多个级实现滤波器时，模块的输出帧大小取决于输入帧大小 *P* 以及各个滤波器级的速率转换因子。有关这些滤波器级的更多信息，请点击模块对话框中的 **查看信息** 按钮。

**数据类型：** `single` | `double`
**复数支持：** Yes

## 参数

### **输入信号的采样率 (Hz)** — 输入信号的采样率，单位为 Hz `48e3`（默认值）| 正标量

将输入信号的采样率指定为以 Hz 为单位的正标量。输入采样率必须大于感兴趣的带宽。

### **输出信号的采样率 (Hz)** — 输出信号的采样率，单位为 Hz `96e3`（默认值）| 正标量

将输出信号的采样率指定为以 Hz 为单位的正标量。输出采样率必须大于感兴趣的带宽。

### **输出采样率的容差** — 输出采样率的最大容差 `0`（默认值）| 范围 [`0`,`0.5`] 内的正标量

将输出采样率的最大容差指定为范围 [`0`,`0.5`] 内的正标量。默认值为 `0`。

实际输出采样率会变化，但处于指定范围内。例如，如果您将 **输出采样率的容差** 设置为 0.01，则实际输出采样率处于输出信号采样率 ± 1% 的范围内。这种灵活性允许更简单的滤波器设计。

### **感兴趣的双边带宽 (Hz)** — 感兴趣的双边带宽，单位为 Hz `40e3`（默认值）| 正标量

将感兴趣的双边带宽（速率转换之后）指定为以 Hz 为单位的正标量。

### **阻带衰减 (dB)** — 混叠分量在阻带中的最小衰减，单位为 dB `80`（默认值）| 正标量

将阻带中混叠分量的最小衰减量指定为以 dB 为单位的正标量。此参数是模块对该过程中涉及的任何混叠进行衰减的最小量。

### **允许固定大小输入信号使用任意帧长度** — 允许固定大小输入信号使用任意帧长度 `off`（默认值）| `on`

*自 R2023a 起*

指定固定大小输入信号（其大小在仿真期间不变化）是否可以具有任意帧长度，其中帧长度不必是抽取因子的倍数。该模块仅对固定大小输入信号使用此参数，如果输入数据在仿真期间大小变化，则忽略此参数。

当输入信号是可变大小信号时，该信号可以具有任意帧长度，也就是说，帧长度不必是抽取因子的倍数。

对于固定大小输入信号，如果您：

- 选择 **允许固定大小输入信号使用任意帧长度** 参数，则信号的帧长度不必是抽取因子的倍数。如果输入不是抽取因子的倍数，则输出通常是可变大小信号。因此，为了支持任意输入大小，该模块还必须支持可变大小操作，您可以通过选择 **允许固定大小输入信号使用任意帧长度** 参数来启用该支持。
- 清除 **允许固定大小输入信号使用任意帧长度** 参数，则输入帧长度必须是抽取因子的倍数。

### **查看滤波器响应** — 查看滤波器响应 按钮

打开 Filter Visualization Tool FVTool 并显示 Sample-Rate Converter 的幅值/相位响应。该响应基于模块参数。当您更改参数时，FVTool 会更新。

要在 FVTool 运行时更新幅值响应，请修改对话框中的参数，然后点击 **应用**。

### **查看信息** — 显示有关滤波器的信息 按钮

点击 **查看信息** 按钮以显示 Sample-Rate Converter 模块的滤波器信息：

- `Overall Interpolation Factor`
- `Overall Decimation Factor`
- `Number of Filters`
- `Multiplication per Input Sample`
- `Number of Coefficients`
- `Filters`

该按钮将 `info` 函数的功能引入 Simulink® 环境。

### **仿真方式** — 要运行的仿真类型 `Interpreted execution`（默认值）| `Code generation`

指定要运行的仿真类型。您可以将此参数设置为：

- `Interpreted execution` —— 使用 MATLAB® 解释器仿真模型。此选项可缩短启动时间。
- `Code generation` —— 使用生成的 C 代码仿真模型。首次运行仿真时，Simulink 会为该模块生成 C 代码。只要模型不变，后续仿真会重用该 C 代码。此选项需要额外的启动时间，但可提供更快的后续仿真。

## 扩展功能

### C/C++ 代码生成 使用 Simulink® Coder™ 生成 C 和 C++ 代码。

Sample-Rate Converter 模块支持在以下条件下使用 Intel® AVX2 代码替换库进行 SIMD 代码生成：

- 对于上采样，输出采样率与输入采样率之比必须是整数。
- 对于下采样，输入采样率与输出采样率之比必须是整数。
- 输入信号的数据类型为 `single` 或 `double`。

SIMD 技术显著提高了生成代码的性能。有关详细信息，请参阅 SIMD 代码生成。要从此模块生成 SIMD 代码，请参阅使用 Intel AVX2 代码替换库从 Simulink 模块生成 SIMD 代码。

## 版本历史

**在 R2015b 中引入**

### R2024a：**仿真方式** 参数的默认值更改

**仿真方式** 参数的默认值现在为 `Interpreted execution`。通过此更改，该模块默认使用 MATLAB 解释器进行仿真。

### R2023a：支持任意输入帧长度

当满足以下条件时，此模块支持具有任意帧长度的输入信号：

- 输入信号是固定大小信号（帧长度在仿真期间不变化），并且您选择 **允许固定大小输入信号使用任意帧长度** 参数。
- 输入信号是可变大小信号（帧长度在仿真期间变化）。

当此模块支持具有任意帧长度的输入信号时，输入帧长度不必是抽取因子的倍数。

## 描述

多级采样率转换

Sample-Rate Converter 模块实现多级 FIR 采样率转换器。多级 FIR 转换器将输入信号每个通道的速率从输入采样率转换为输出采样率。多级实现通过首先降低输入信号的采样率来最小化采样率转换所需的计算量。接下来，该模块根据您在模块对话框中指定的参数确定抽取器和插值器的最佳数量。然后，该模块相应地在各个级中设计滤波器。

此模块支持 SIMD 代码生成。有关详细信息，请参阅代码生成。
