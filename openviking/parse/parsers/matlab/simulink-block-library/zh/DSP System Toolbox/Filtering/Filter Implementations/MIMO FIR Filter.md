# MIMO FIR Filter

## 端口

### 输入

### **x** — 数据输入向量 | 矩阵

将数据输入指定为大小为 *L*×*T* 的向量或矩阵。此模块支持可变大小输入信号，即您可以在仿真期间更改输入帧大小（行数）。但是，通道数（列数）必须保持不变。

在将**分子来源**设置为 `Input port` 之前，此端口未命名。

**数据类型：** `single` | `double`
**复数支持：** 是

### **Num** — 时域 FIR 滤波器系数行向量 | 矩阵

将时域 FIR 滤波器系数指定为行向量或矩阵输入。有关滤波器系数的详细信息，请参阅**分子**参数说明。

如果分子输入为行向量，则数据输入通道数必须为 1。

#### 依赖关系

要启用此端口，请将**分子来源**设置为 `Input port`。

**数据类型：** `single` | `double`
**复数支持：** 是
### 输出

### **y** — 滤波后的输出向量 | 矩阵 | 三维数组

滤波后的输出，以向量、矩阵或三维数组形式返回。

当滤波器数量 *F* 大于 1 且您：

- 选中**对所有输入通道的滤波输出贡献求和**参数时，模块将每个输入通道的滤波输出相加，生成 *L*×*R* 输出矩阵，其中 *L* 是输入帧大小（输入行数），*R* 是输出通道数。*R* 等于 *F*/(*T* × *P*)，其中 *F* 是滤波器数量，*T* 是输入通道数，*P* 是您在**传播路径数**参数中指定的值。
- 清除**对所有输入通道的滤波输出贡献求和**参数时，模块不会对所有输入通道的滤波输出贡献求和。输出为 *L*×*R*×*T* 数组。`y(:,j,k)` 表示第 *k* 个输入通道对第 *j* 个输出通道的输出。例如，`y(:,3,2)` 表示第二个输入通道在第三个输出通道上的输出。

有关模块如何计算输出的详细信息，请参阅 Modeling MIMO System with Multiple Propagation Paths。

输出的数据类型和复数性与输入信号相同。

**数据类型：** `single` | `double`
**复数支持：** 是

## 参数

要以交互方式编辑模块参数，请使用属性检查器。在 Simulink® 工具条的**仿真**选项卡中，在**准备**库中选择**属性检查器**。

### **分子来源** — FIR 滤波器系数的来源 `Property`（默认）| `Input port`

将 FIR 滤波器系数的来源指定为以下之一：

- `Property` –– 通过**分子**参数指定滤波器系数。
- `Input port` –– 通过 **Num** 输入端口指定滤波器系数。

### **分子** — 时域 FIR 滤波器系数 [`0.5 0.5`;`0.75 0.25`]（默认）| 行向量 | 矩阵

将时域 FIR 滤波器系数指定为大小为 *F*×*NumLen* 的行向量（单个滤波器）或矩阵（多个滤波器），其中 *F* 是滤波器数量，*NumLen* 是滤波器长度。如果 *F* 大于 1，则其值必须是输入通道数（列数）*T* 与您通过 `NumPaths` 属性指定的路径数 *P* 的乘积的倍数。乘法因子决定输出通道数 *R*，等于 *F*/(*T* × *P*)。

系数值可以在仿真期间更改，但分子的大小必须保持不变。

**可调：** 是

#### 依赖关系

要启用此参数，请将**分子来源**设置为 `Property`。

**数据类型：** `single` | `double`
**复数支持：** 是

### **传播路径数** — 每对输入和输出通道之间的传播路径数 `1`（默认）| 正整数

将每对输入和输出通道之间的传播路径数 *P* 指定为正整数。每条路径由一个唯一的滤波器表示。当您将路径数指定为大于 `1` 时，滤波器对多径传播进行建模。模块对每对输入和输出通道之间所有路径的滤波输出贡献求和。

有关示例，请参阅 Filter Input Signal Through Multiple Propagation Paths。

#### 依赖关系

要启用此参数，滤波器数量 *F* 必须大于 1。

**数据类型：** `single` | `double`

### **对所有输入通道的滤波输出贡献求和** — 对所有输入通道的滤波输出贡献求和的选项 `on`（默认）| `off`

选中此参数可对所有输入通道的滤波输出贡献求和。模块将每个输入通道的滤波输出相加，生成 *L*×*R* 输出矩阵，其中 *L* 是输入帧大小（输入行数），*R* 是输出通道数。*R* 等于 *F*/(*T* x *P*)，其中 *F* 是滤波器数量，*T* 是输入通道数，*P* 是您在**传播路径数**参数中指定的值。

当您清除此参数时，模块不会对所有输入通道的滤波输出贡献求和。输出为 *L*×*R*×*T* 数组。

有关模块如何根据此参数的值计算输出的详细信息，请参阅 Modeling MIMO System with Multiple Propagation Paths。

#### 依赖关系

要启用此参数，滤波器数量 *F* 必须大于 1。

**数据类型：** `Boolean`

### **查看滤波器响应** — 查看滤波器响应按钮

点击此按钮将打开滤波器可视化工具，并显示您在分子矩阵中指定的滤波器的幅值响应。响应基于您在模块对话框中选中的参数。要在滤波器可视化工具运行时更新幅值响应，请修改对话框中的参数并点击**应用**。

您可以从可视化工具界面配置绘图设置和信号测量。

在滤波器可视化工具工具条的**范围**选项卡上，**配置**部分允许您修改绘图设置。在**测量**选项卡上，您可以放置数据光标并显示所选信号的峰值。

有关滤波器可视化工具界面及其工具的更多详细信息，请参阅 Configure Filter Visualizer。

#### 依赖关系

要启用此按钮，请将**分子来源**设置为 `Property`。

### **仿真方式** — 要运行的仿真类型 `Interpreted execution`（默认）| `Code generation`

指定要运行的仿真类型。您可以将此参数设置为：

- `Interpreted execution` –– 使用 MATLAB® 解释器仿真模型。此选项可缩短启动时间。
- `Code generation` –– 使用生成的 C 代码仿真模型。首次运行仿真时，Simulink 会为模块生成 C 代码。只要模型不更改，C 代码将复用于后续仿真。此选项需要额外的启动时间，但可提供更快的后续仿真。

## 描述

通过多径 MIMO FIR 滤波器对输入信号进行滤波

MIMO FIR Filter 模块对包含多个时域 FIR 滤波器的多输入多输出（MIMO）系统进行建模。该模块执行时域滤波，其中滤波操作涉及输入通道与特定路径上的 FIR 滤波器之间的卷积。您可以使用**分子**参数直接指定多个滤波器的系数，或通过 **Num** 输入端口指定。

使用**传播路径数**参数，您可以指定每对输入和输出通道之间的路径数。每条路径包含一个长度相同的时域 FIR 滤波器。模块将每条路径的滤波输出相加。此外，根据**对所有输入通道的滤波输出贡献求和**参数的设置，模块对这些滤波输出贡献进行相加或拼接。有关详细信息，请参阅 Modeling MIMO System with Multiple Propagation Paths。

输出信号中的通道数取决于滤波器数量、每对输入和输出通道之间的路径数以及输入通道数。有关更多详细信息，请参阅 `y` 参数说明。

Frequency-Domain FIR Filter 模块也支持对 MIMO 和多径系统进行建模。该模块在频域中实现滤波。通常，时域滤波对较小的脉冲响应效率较高，而频域滤波对较长的脉冲响应效率较高。
