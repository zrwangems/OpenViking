# Binary File Reader

## 端口

### 输出

### **data** — 二进制文件数据 列向量 | 行向量 | 矩阵

读取器模块从 **文件名** 参数指定的文件中读取二进制数据。模块输出的数据维度为 **每帧采样数**×**通道数**。该模块可以读取浮点数据和整数数据。输入数据可以是实数或复数。当数据为复数时，模块将数据读取为交错的实部和虚部。读取器采用主机机器的默认字节序。

此端口在您选择 **输出文件结束指示符** 参数之前未命名。

**数据类型：** `single` | `double` | `int8` | `int16` | `int32` | `int64` | `uint8` | `uint16` | `uint32` | `uint64`
**复数支持：** Yes

### **EOF** — 文件结束指示符 布尔标量

当模块到达文件末尾时，该端口输出 `1`。否则，该端口输出 `0`。

此端口在您选择 **输出文件结束指示符** 参数之前未命名。

**数据类型：** `Boolean`

## 参数

### **文件名** — 文件的名称 `'Untitled.bin'`（默认）| 字符向量

模块从中读取数据的文件的名称。如果文件不在 MATLAB® 路径上，则指定该文件的完整路径。

### **文件头** — 文件头的大小 `struct([])`（默认）| 结构体

该结构体指定文件头的原型，即文件头的大小以及字段值的数据类型。该结构体可以包含任意数量的字段。结构体的每个字段必须是内置类型的实数矩阵。例如，如果 **文件头** 设置为 `struct('field1',1:10,'field2',single(1))`，则模块假定文件头由 10 个实数双精度值后跟 1 个单精度值组成。如果文件不包含文件头，则可以将此参数设置为空结构体 `struct([])`。

### **将文件头导出到基础工作区** — 检索文件头按钮

要检索文件头，请单击 **将文件头导出到基础工作区**。模块将文件头导出到基础工作区。

### **存储数据类型** — 文件中数据的存储类 `'double'`（默认）| `'single'` | `'int8'` | `'int16'` | `'int32'` | `'int64'` | `'uint8'` | `'uint16'` | `'uint32'` | `'uint64'`

文件中数据的存储类，指定为字符向量。此参数定义模块输出的矩阵的数据类型。

### **每帧采样数** — 每个输出帧的采样数 `1024`（默认）| 正整数

**每帧采样数** 指定模块输出的输出矩阵的行数。输出矩阵的维度为 **每帧采样数**×**通道数**。到达文件末尾后，模块返回指定数据类型、大小和复/实性的零值。

### **数据为复数** — 指定数据复/实性 off（默认）| on

当您选择此参数时，读取器将数据视为复数数据。模块将数据读取为交错的实部和虚部。将模块配置为将数据读取为 2×2 矩阵。模块将 `[1 5 2 6 3 7 4 8]` 读取为 `[1 2; 3 4]+1j*[5 6; 7 8]`。当您不选择此参数时，模块将数据读取为 `[1 5; 2 6]`。

### **通道数** — 通道数 `1`（默认）| 正整数

**通道数** 指定模块输出的输出矩阵的列数。此参数定义文件中为每个时间瞬间存储的连续交错数据样本的数量。数据大小为 **每帧采样数**×**通道数**。到达文件末尾后，如果输出矩阵未满，模块会用零填充矩阵以使其成为完整大小的矩阵。

### **输出文件结束指示符** — 文件结束指示符 off（默认）| on

当您选择此参数时，模块上会出现一个名为 **EOF** 的额外输出端口。当模块到达文件末尾时，该端口输出 `1`。否则，该端口输出 `0`。

### **采样时间 (s)** — 采样时间 1（默认）| 非负标量

**采样时间 (s)** 控制模块输出端口处的采样时间。此值表示 1/*Fs*，其中 *Fs* 是信号数据的采样率。输出端口处的 Simulink 采样时间为 **每帧采样数** × **采样时间 (s)**。

### **仿真方式** — 要运行的仿真类型 `Interpreted execution`（默认）| `Code generation`

指定要运行的仿真类型。您可以将此参数设置为：

- `Interpreted execution` –– 使用 MATLAB 解释器仿真模型。此选项可缩短启动时间。
- `Code generation` –– 使用生成的 C 代码仿真模型。第一次运行仿真时，Simulink 会为该模块生成 C 代码。只要模型不变，后续仿真将重用该 C 代码。此选项需要额外的启动时间，但可提供更快的后续仿真。

## 描述

从二进制文件读取数据

Binary File Reader 模块从二进制文件中读取多通道信号数据。该模块读取数据之前的文件头。**文件头** 参数指定文件头的结构。您可以通过模块参数指定数据的类型、大小和复/实性。您还可以通过单击 **将文件头导出到基础工作区** 按钮将文件头导出到基础工作区。

第一次读取文件时，读取器先读取文件头，然后读取数据。在后续调用中，读取器读取剩余数据。到达文件末尾后，读取器返回指定数据类型、大小和复/实性的零值。读取器可以从不是由 Binary File Writer 模块创建的二进制文件中读取信号数据。
