# Lane Keeping Assist System

## 端口

### 输入

### **Curvature** — 道路曲率 scalar | vector

道路曲率，指定为 1/*R*，其中 *R* 是弯道半径，单位为米。

道路曲率为：

- 当道路向全局坐标系的 Y 轴正方向弯曲时，为正值。
- 当道路向全局坐标系的 Y 轴负方向弯曲时，为负值。
- 对于直道，为零。

控制器将道路曲率建模为带预览的可测量扰动。您可以将曲率指定为：

- 标量信号 — 指定当前控制区间的曲率。控制器在整个预测时域内使用该曲率值。
- 长度小于或等于 **预测时域** 参数的向量信号 — 指定整个预测时域内的当前和预测曲率值。如果向量长度小于预测时域，则控制器在预测时域的剩余部分使用向量中的最终曲率值。

### **Longitudinal velocity** — 自车速度 nonnegative scalar

自车速度，单位为 m/s。

### **Lateral deviation** — 自车横向偏差 scalar

自车相对于车道中心线的横向偏差，单位为米。当自车位于中心线右侧时，横向偏差
*e*1 为正值；当自车位于中心线左侧时，为负值。

### **Relative yaw angle** — 相对于车道中心线的角度 scalar

自车纵轴相对于车道中心线的角度，单位为弧度，定义为：

e2=θe−θc

其中，*θe* 是自车角度，*θc* 是中心线角度，两个角度均在全局坐标系中定义。

### **Minimum steering angle** — 最小前轮转向角 scalar

最小前轮转向角约束，单位为弧度。当最小转向角在运行时变化时，使用此输入端口。

#### 依赖关系

要启用此端口，请选择对应的 **使用外部源** 参数。

### **Maximum steering angle** — 最大前轮转向角 scalar

最大前轮转向角约束，单位为弧度。当最大转向角在运行时变化时，使用此输入端口。

#### 依赖关系

要启用此端口，请选择对应的 **使用外部源** 参数。

### **Enable optimization** — 控制器优化启用信号 scalar

控制器优化启用信号。当此信号为：

- 非零时，控制器执行优化计算并生成 **Steering angle** 控制信号。
- 零时，控制器不执行优化计算。在这种情况下，**Steering
  angle** 输出信号保持优化禁用时的值。控制器继续更新其内部状态估计。

#### 依赖关系

要启用此端口，请选择 **使用外部信号启用或禁用优化** 参数。

### **External control signal** — 施加到自车的转向角 scalar

施加到自车的实际转向角，单位为弧度。控制器使用此信号估计自车模型状态。当施加到自车的控制信号与模型预测控制器计算的最优控制信号不匹配时，使用此输入端口。这种不匹配可能发生在以下情况，例如：

- Lane Keeping Assist System 不是活动控制器。当控制器未活动时保持准确的状态估计，可以防止控制器变为活动时控制信号出现突变。
- 转向执行器发生故障，未向自车提供正确的控制信号。

#### 依赖关系

要启用此端口，请选择 **使用外部控制信号在 PFC 和其他控制器之间实现无扰切换** 参数。

### **Vehicle dynamics matrix A** — 自车预测模型的状态矩阵 square matrix

自车预测模型的状态矩阵。状态矩阵的行数对应于预测模型中的状态数。此矩阵必须为方阵。

由 **Vehicle dynamics matrix
A**、**Vehicle dynamics matrix B** 和 **Vehicle
dynamics matrix C** 定义的自车预测模型必须是最小实现。

#### 依赖关系

要启用此端口，请选择 **使用车辆模型** 参数。

### **Vehicle dynamics matrix B** — 自车预测模型的输入到状态矩阵 column vector

自车预测模型的输入到状态矩阵。此信号的行数必须与 **Vehicle dynamics matrix A** 的行数匹配。

由 **Vehicle dynamics matrix A**、**Vehicle dynamics matrix B** 和 **Vehicle dynamics matrix C** 定义的自车预测模型必须是最小实现。

#### 依赖关系

要启用此端口，请选择 **使用车辆模型** 参数。

### **Vehicle dynamics matrix C** — 自车预测模型的状态到输出矩阵 matrix with two rows

自车预测模型的状态到输出矩阵。此信号的列数必须与 **Vehicle dynamics matrix A** 的行数匹配。

由 **Vehicle dynamics matrix A**、**Vehicle dynamics matrix B** 和 **Vehicle dynamics matrix C** 定义的自车预测模型必须是最小实现。

#### 依赖关系

要启用此端口，请选择 **使用车辆模型** 参数。

### 输出

### **Steering angle** — 前轮转向角控制信号 scalar

控制器生成的前轮转向角控制信号，单位为弧度。前轮转向角是前轮胎相对于车辆纵轴的角度。转向角朝向自车的正横向轴时为正值。

### 参数选项卡

#### 自车

### **使用车辆参数** — 使用车辆属性定义自车模型 `on` (default) | `off`

选择此参数可通过指定自车属性来定义 MPC 控制器使用的自车模型。自车模型是从前轮转向角到横向速度和横摆角速度的线性模型。有关更多信息，请参阅自车预测模型。

要定义车辆模型，请指定以下模块参数：

- **总质量**
- **横摆转动惯量**
- **从重心到前轮胎的纵向距离**
- **从重心到后轮胎的纵向距离**
- **前轮胎侧偏刚度**
- **后轮胎侧偏刚度**

有关自车模型的更多信息，请参阅自车预测模型。

选择此参数将清除 **使用车辆模型** 参数。

### **使用车辆模型** — 使用状态空间矩阵定义自车模型 `off` (default) | `on`

选择此参数可定义 MPC 控制器使用的自车模型的状态空间矩阵。此模型是从前轮转向角（单位为弧度）到横向速度（单位为米每秒）和横摆角速度（单位为弧度每秒）的线性模型。有关自车模型的更多信息，请参阅自车预测模型。

要定义初始内部模型，请指定 **A**、**B** 和 **C** 状态空间矩阵。内部模型必须是无直接馈通的最小实现，并且 **A**、**B** 和 **C** 的维度必须一致。

通常，自车转向模型依赖于速度，因此会随时间变化。要在运行时更新内部模型，请使用 **Vehicle dynamics A**、**Vehicle dynamics B** 和 **Vehicle dynamics C** 输入端口。

选择此参数将清除 **使用车辆参数** 参数。

## 描述

使用自适应模型预测控制器模拟车道保持辅助

Lane Keeping Assist System 模块模拟车道保持辅助 (LKA) 系统，该系统通过调整前轮转向角，使自车沿直道或弯道的中心行驶。控制器减小自车相对于车道中心线的横向偏差和相对横摆角。该模块使用自适应模型预测控制 (MPC) 计算最优控制动作，同时满足转向角约束。

要自定义控制器，例如使用高级 MPC 功能或修改控制器初始条件，请点击 **创建 LKA 子系统**。
