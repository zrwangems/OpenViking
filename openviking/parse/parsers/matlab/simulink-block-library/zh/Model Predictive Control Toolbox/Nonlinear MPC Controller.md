# Nonlinear MPC Controller

## 端口

### 输入

#### 必需输入

### **x** — 输入向量

当前预测模型状态，指定为长度为 *Nx* 的向量信号，其中 *Nx* 是预测模型状态的数量。由于非线性 MPC 控制器不执行状态估计，你必须在每个控制区间测量或估计当前预测模型状态。

### **ref** — 模型输出参考值行向量 | 矩阵

被控对象输出参考值，指定为行向量信号或矩阵信号。

若要在整个预测时域内使用相同的参考值，请将 **ref** 连接到具有 *Ny* 个元素的行向量信号，其中 *Ny* 是输出变量的数量。每个元素指定一个输出变量的参考值。

若要在预测时域内从时间 *k*+1 到时间 *k*+*p* 改变参考值（预览），请将 **ref** 连接到具有 *Ny* 列且最多 *p* 行的矩阵信号。这里，*k* 是当前时间，*p* 是预测时域。每一行包含一个预测时域步的参考值。如果指定的行数少于 *p*，则最后一行中的参考值用于预测时域的剩余步。

### **last\_mv** — 上一控制区间在被控对象中使用的控制信号向量

上一控制区间在被控对象中使用的控制信号，指定为长度为 *Nmv* 的向量信号，其中 *Nmv* 是操纵变量的数量。

**注意**

将 **last\_mv** 连接到上一控制区间实际施加到被控对象的 MV 信号。通常，这些 MV 信号是控制器生成的值，但并非总是如此。例如，如果你的控制器离线并运行在跟踪模式，即控制器输出不驱动被控对象，则将实际控制信号馈送给 **last\_mv** 有助于在控制器重新切换为在线时实现无扰切换。

#### 附加输入

### **md** — 输入行向量 | 矩阵

如果你的控制器预测模型具有测量扰动，你必须启用此端口，并向其连接行向量或矩阵信号。

若要在整个预测时域内使用相同的测量扰动值，请将 **md** 连接到具有 *Nmd* 个元素的行向量信号，其中 *Nmd* 是操纵变量的数量。每个元素指定一个测量扰动的值。

若要在预测时域内从时间 *k* 到时间 *k*+*p* 改变扰动（预览），请将 **md** 连接到具有 *Nmd* 列且最多 *p*+1 行的矩阵信号。这里，*k* 是当前时间，*p* 是预测时域。每一行包含一个预测时域步的扰动。如果指定的行数少于 *p*+1，则最后一行中的扰动值用于预测时域的剩余步。

#### 依赖项

要启用此端口，请选择 **Measured disturbances** 参数。

### **params** — 可选参数总线

如果你的控制器在其预测模型、自定义代价函数或自定义约束函数中使用可选参数，请启用此输入端口，并连接具有 *Np* 个元素的参数总线信号，其中 *Np* 是参数的数量。有关创建参数总线信号的更多信息，请参见 `createParameterBus`。控制器会将这些参数传递给其模型函数、代价函数、约束函数、passivity 函数和 Jacobian 函数。

如果你的控制器不使用可选参数，你必须禁用 **params**。

#### 依赖项

要启用此端口，请选择 **Model parameters** 参数。

### **mv.target** — 操纵变量目标向量

要指定操纵变量目标，请启用此输入端口，并连接向量信号。要使给定操纵变量跟踪其指定目标值，还必须为该操纵变量指定非零调节权重。

运行时提供的 **mv.target** 值应用于整个预测时域。

#### 依赖项

要启用此端口，请选择 **Targets for manipulated variables** 参数。

#### 在线调节权重

### **y.wt** — 输出变量调节权重行向量 | 矩阵

要指定运行时输出变量调节权重，请启用此输入端口。如果禁用此端口，模块将使用其控制器对象的 `Weights.OutputVariables` 属性中指定的调节权重。这些调节权重惩罚输出参考值的偏差。

如果 MPC 控制器对象在整个预测时域内使用恒定输出调节权重，则运行时只能指定恒定输出调节权重。类似地，如果 MPC 控制器对象使用随预测时域变化的输出调节权重，则运行时只能指定时变输出调节权重。

若要在整个预测时域内使用恒定调节权重，请将 **y.wt** 连接到具有 *Ny* 个元素的行向量信号，其中 *Ny* 是输出的数量。每个元素指定一个输出变量的非负调节权重。有关指定调节权重的更多信息，请参见 Tune Weights。

若要在预测时域内从时间 *k*+1 到时间 *k*+*p* 改变调节权重，请将 **y.wt** 连接到具有 *Ny* 列且最多 *p* 行的矩阵信号。这里，*k* 是当前时间，*p* 是预测时域。每一行包含一个预测时域步的调节权重。如果指定的行数少于 *p*，则最后一行的调节权重应用于预测时域的剩余部分。有关在预测时域内改变权重的更多信息，请参见 Setting Time-Varying Weights and Constraints with MPC Designer。

### 输出

#### 必需输出

### **mv** — 最优操纵变量控制作用 列向量

最优操纵变量控制作用，输出为长度为 *Nmv* 的列向量信号，其中 *Nmv* 是操纵变量的数量。

如果求解器收敛到局部最优解（**nlp.status** 为正），则 **mv** 包含最优解。

如果求解器达到最大迭代次数而未找到最优解（**nlp.status** 为零），并且控制器的 `Optimization.UseSuboptimalSolution` 属性为：

- `true`，则 **mv** 包含次优解
- `false`，则 **mv** 与 **last\_mv** 相同

如果求解器失败（**nlp.status** 为负），则 **mv** 与 **last\_mv** 相同。

#### 附加输出

### **cost** — 目标函数代价 非负标量

目标函数代价，输出为非负标量信号。该代价量化控制器达成其目标的程度。

仅当 **nlp.status** 输出为非负时，代价值才有意义。

#### 依赖关系

要启用此端口，请选择 **Optimal cost** 参数。

### **slack** — 松弛变量 0 | 非负标量

用于约束软化的松弛变量 ε，输出为 `0` 或正标量值。

- ε = 0 — 在整个预测时域内所有软约束均满足。
- ε > 0 — 至少有一个软约束被违反。当有多个约束被违反时，ε 表示最坏情况软约束违反（按每个约束的 ECR 值缩放）。

#### 依赖关系

要启用此端口，请选择 **Slack variable** 参数。

### **nlp.status** — 优化状态 标量

优化状态，输出为以下之一：

- 正整数 — 求解器收敛到最优解
- `0` — 达到最大迭代次数而未收敛到最优解
- 负整数 — 求解器失败

#### 依赖关系

要启用此端口，请选择 **Optimization status** 参数。

#### 最优序列

### **mv.seq** — 最优操纵变量序列 矩阵

最优操纵变量序列，返回为具有 *p*+1 行和 *Nmv* 列的矩阵信号，其中 *p* 是预测时域，*Nmv* 是操纵变量的数量。

**mv.seq** 的前 *p* 行包含从当前时间 *k* 到时间 *k*+*p*-1 计算出的最优操纵变量值。**mv.seq** 的第一行包含当前操纵变量值（输出 **mv**）。由于控制器不计算时间 *k*+*p* 的最优控制移动，**mv.seq** 的最后两行相同。

#### 依赖关系

要启用此端口，请选择 **Optimal control sequence** 参数。

### **x.seq** — 最优预测模型状态序列 矩阵

最优预测模型状态序列，返回为具有 *p*+1 行和 *Nx* 列的矩阵信号，其中 *p* 是预测时域，*Nx* 是状态的数量。

**x.seq** 的第一行包含当前估计状态值，这些值来自内置状态估计器或自定义状态估计模块输入 **x[k|k]**。**x.seq** 的接下来 *p* 行包含从时间 *k*+1 到时间 *k*+*p* 计算出的最优状态值。

#### 依赖关系

要启用此端口，请选择 **Optimal state sequence** 参数。

### **y.seq** — 最优输出变量序列 矩阵

最优输出变量序列，返回为具有 *p*+1 行和 *Ny* 列的矩阵信号，其中 *p* 是预测时域，*Ny* 是输出变量的数量。

**y.seq** 的前 *p* 行包含从当前时间 *k* 到时间 *k*+*p*-1 计算出的最优输出值。**y.seq** 的第一行基于当前估计状态和当前测量扰动（输入 **md** 的第一行）计算。由于控制器不计算时间 *k*+*p* 的最优输出值，**y.seq** 的最后两行相同。

#### 依赖关系

要启用此端口，请选择 **Optimal output sequence** 参数。

## 扩展功能

### C/C++ 代码生成 使用 Simulink® Coder™ 生成 C 和 C++ 代码。

用法说明和限制：

- Nonlinear MPC Controller 模块仅支持为使用默认 `fmincon` 求解器和 SQP 算法的非线性 MPC 控制器生成代码。
- 不支持 single-precision 或 fixed-point 计算的代码生成。
- 用于代码生成时，非线性 MPC 控制器不支持将预测模型函数、阶段代价函数或约束函数表示为匿名函数。
- 如果您的控制器使用可选参数，还必须为连接到 **params** 输入端口的 Bus Creator 模块生成代码。为此，请将 Nonlinear MPC Controller 和 Bus Creator 模块放在一个子系统内，并为该子系统生成代码。
- 在模型 **Configuration Parameters** 对话框下的 **Code Generation** 选项的 **Interface** 部分中，必须选中 **Support non-finite numbers** 复选框（默认选项）。
- 使用 Embedded Coder® 生成代码时，必须选中模型 **Configuration Parameters** 对话框下的 **Code Generation** 选项的 **Interface** 部分中的 **Support variable-size signals**。默认情况下，此复选框未选中，您必须在生成代码前选中它。

## 描述

仿真非线性模型预测控制器

Nonlinear MPC Controller 模块仿真非线性模型预测控制器。在每个控制区间，该模块通过求解非线性规划问题来计算最优控制移动。有关非线性 MPC 的详细信息，请参阅 Nonlinear MPC。

要使用此模块，必须先在 MATLAB® 工作区中创建一个 `nlmpc` 对象。
