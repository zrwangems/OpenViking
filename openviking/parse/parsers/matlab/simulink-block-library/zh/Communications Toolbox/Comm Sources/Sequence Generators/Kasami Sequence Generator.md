# Kasami Sequence Generator

## 端口

### 输入

### **oSiz** — 当前输出大小 标量 | 向量

当前输出大小，指定为标量或形式为 [*n*,1] 的向量，其中 *n* 是输出序列中的元素数。

**示例：** `[10 1]` 指定大小为 10×1 的当前输出列向量。

#### 依赖关系

要启用此端口，请将 **最大输出大小来源** 参数设置为 `Dialog parameter`。

**数据类型：** `double`

### **Ref** — 参考输入信号 标量 | 列向量

参考输入信号，指定为标量或列向量。

#### 依赖关系

要启用此端口，请将 **最大输出大小来源** 参数设置为 `Inherit from reference input`。

**数据类型：** `double`

### **Rst** — 重置信号 标量 | 向量

重置信号，根据输出大小指定为标量或向量。

- 当输出大小可变时，将此端口指定为标量。
- 否则，将此端口指定为标量或长度等于 **每帧样本数** 参数值的列向量。

对于非零 **Rst** 输入值，输出信号会重置。有关详细信息，请参阅重置行为。

#### 依赖关系

要启用此端口，请选择 **非零输入时重置** 参数。

**数据类型：** `double`
### 输出

### **Out** — 输出信号 向量

输出信号，返回为二值列向量。要使模块生成非零序列，**初始状态** 参数向量中至少有一个元素必须为非零。

**数据类型：** `double`

## 参数

要以交互方式编辑模块参数，请使用属性检查器。在 Simulink® 工具条的 **仿真** 选项卡上，在 **准备** 库中，选择 **属性检查器**。

### **生成多项式** — 生成多项式 `'z^6 + z + 1'` (默认) | 多项式字符向量 | 字符串标量 | 二值行向量 | 整数值行向量

指定生成多项式，其确定生成序列的移位寄存器中的连接，为下列选项之一。

- 包含数字 `1` 的多项式字符向量或字符串标量（例如 `'z^4 + z +
  1'`）。有关详细信息，请参阅 Communications Toolbox 中的多项式表示。
- 按降幂顺序列出多项式系数的二值行向量。第一个和最后一个条目必须为 `1`。此向量的长度必须比生成多项式的次数大一。
- 包含按降幂顺序排列的多项式非零项指数的整数值行向量。最后一个条目必须为 `0`。

例如，`'z^8 + z^2 + 1'`、`[1 0 0 0 0 0 1 0
1]` 和 `[8 2 0]` 表示同一个多项式 *p*(*z*) =
*z*8 +
*z*2 + 1。

### **初始状态** — 初始状态 `[0 0 0 0 0 1]` (默认) | 二值标量 | 二值行向量

移位寄存器的初始状态生成序列。如果指定二值行向量，则长度必须等于 **生成多项式** 参数指定的生成多项式的次数。如果指定二值标量，则模块会将该标量扩展为长度等于生成多项式次数的行向量。所得向量的所有条目都等于该标量。

### **序列索引** — 序列索引 `0` (默认) | 整数 | 形式为 [*k* *m*] 的向量

指定一个整数或形式为 [*k*
*m*] 的向量，以从可能的序列集合中选择感兴趣的 Kasami 序列。Kasami 序列存在两类：从小集合获得的序列和从大集合获得的序列。通过将此参数设置为范围 [0, 2*n*/2–2] 中的整数，可以从该小集合中选择 Kasami 序列。通过将此参数设置为形式为 [*k*
*m*] 的向量，可以从大集合中选择序列。*k* 必须为范围 [–2, 2*n*–2] 中的整数，*m* 必须为范围 [–1, 2*n*/2–2] 中的整数。有关详细信息，请参阅序列索引。

### **移位** — 序列相对于起始点的偏移 `0` (默认) | 整数

指定 Kasami 序列相对于初始时间的偏移。

通过选择 **非零输入时重置** 参数，可以使用外部信号将内部移位寄存器的值重置为初始状态。此选择会在此模块中为外部信号创建一个输入端口。模块重置内部移位寄存器的方式取决于其输出信号和重置信号是基于样本还是基于帧。有关示例，请参阅重置行为。

### **输出可变大小信号** — 输出可变长度信号的选项 `off` (默认) | `on`

选择此参数可在仿真期间启用可变长度输出序列。清除此参数时，模块输出固定长度序列。选择此参数时，模块可以输出可变长度序列。有关可变大小信号的信息，请参阅可变大小信号基础知识 (Simulink)。

### **最大输出大小来源** — 最大输出大小来源 `Dialog parameter` (默认) | `Inherit from reference port`

选择如何指定最大序列输出大小。

- `Dialog parameter` — 选择此值可将模块配置为使用 **最大输出大小** 参数设置作为允许的最大输出序列长度。**oSiz** 输入端口指定输出信号的当前大小，模块输出从输入信号继承采样时间。**oSiz** 的输入值必须小于或等于 **最大输出大小** 参数。
- `Inherit from reference port` — 选择此值可启用 **Ref** 输入端口，并将模块配置为从 **Ref** 输入端口处的可变大小信号继承采样时间、最大大小和当前输出大小。这些用于设置允许的最大输出序列长度。

#### 依赖关系

要启用此参数，请选择 **输出可变大小信号**。

### **最大输出大小** — 最大输出大小 `[10 1]` (默认) | 形式为 [*n* 1] 的向量

指定模块的最大输出大小。*n* 是正标量。

**示例：** `[10 1]` 指定输出信号的最大大小为 10×1。

#### 依赖关系

要启用此参数，请选择 **输出可变大小信号**，并将 **最大输出大小来源** 设置为 `Dialog parameter`。

### **采样时间** — 输出采样时间 `1` (默认) | `-1` | 正标量

正标量指定输出信号各样本之间的时间，以秒为单位。如果将采样时间设置为 `-1`，则输出信号从下游继承采样时间。有关 **采样时间** 和 **每帧样本数** 参数之间关系的信息，请参阅采样时序。

#### 依赖关系

要启用此参数，请清除 **输出可变大小信号**。

### **每帧样本数** — 每帧样本数 `1` (默认) | 正整数

指定输出数据一个通道中每帧的样本数。有关 **采样时间** 和 **每帧样本数** 参数之间关系的信息，请参阅采样时序。

### **非零输入时重置** — 重置输出信号的选项 `off` (默认) | `on`

选择此参数以启用 **Rst** 输入端口。使用该端口指定一个输入信号，该信号将内部移位寄存器重置为 **初始状态** 参数值的原始值。

### **输出数据类型** — 输出数据类型 `double` (默认) | `boolean`

指定模块的输出数据类型。

### R2020a: 现有模型自动将此模块更新为当前版本

从 R2020a 开始，Simulink 不再允许使用 R2015b 之前可用的 Kasami Sequence Generator 模块版本。

现有模型会自动更新，以加载在“源模块输出连续时间样本的帧，但不使用帧属性”中宣布的 Kasami Sequence Generator 模块版本。有关模块转发的详细信息，请参阅使用转发表维护库模块的兼容性 (Simulink)。

## 描述

从 Kasami 序列集合生成 Kasami 序列

Kasami Sequence Generator 模块从 Kasami 序列集合中生成序列。Kasami 序列是一组具有良好互相关特性的序列。有关详细信息，请参阅 Kasami 序列。

此模块可以输出在仿真期间长度变化的序列。有关可变大小信号的详细信息，请参阅可变大小信号基础知识 (Simulink)。
