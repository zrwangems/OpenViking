# Integer-Output RS Decoder

## 端口

### 输入

### **In** — Reed-Solomon 码字整数列向量

Reed-Solomon 码字，指定为 (*N*C×(*N* – *K* + *S* – *P*)-by-1 整数列向量。*N*C 是码字数量，*N* 是 **码字长度 N**，*K* 是 **消息长度 K**，*S* 是 **缩短消息长度 S**，*P* 是每个码字的打孔数。

有关详细信息，请参阅 RS 模块中的输入和输出信号长度。

**数据类型：** `single` | `double` | `integer`

### **Era** — 删除向量二进制列向量

删除向量，指定为与输入 Reed-Solomon 码字大小相同的二进制列向量输入信号。

删除值为 1 对应于码字中同一位置的已删除位。值为 0 对应于未删除的位。有关详细信息，请参阅打孔和删除。

#### 依赖关系

要启用此端口，请选择 **启用删除输入端口**。

**数据类型：** `double` | `Boolean`

### 输出

### **Out** — 解码消息整数列向量

解码消息，返回为以下之一：

- 当没有消息缩短时，为 (*N*C×*K*)-by-1 整数列向量。
- 当存在消息缩短时，为 (*N*C×*S*)-by-1 整数列向量。

*N*C 是消息字数量，*K* 是 **消息长度 K（符号）**，*S* 是 **缩短消息长度 S（符号）**。

**注意**

解码消息字的数量等于码字的数量。

有关详细信息，请参阅 RS 模块中的输入和输出信号长度。

### **Err** — 解码错误整数向量

符号解码错误，返回为包含 *N*C 个元素的整数向量，其中 *N*C 是码字数量。此端口指示在解码每个码字期间检测到的符号错误数量。负整数表示该模块检测到的错误数超过了使用指定编码方案所能纠正的数量。

**注意**

(*N*,*K*) Reed-Solomon 码最多可以纠正每个码字中 `floor((N-K)/2)` 个符号错误（不是位错误）。当接收到的码字包含超过 (*N*-*K*)/2 个符号错误时，会发生解码失败。

#### 依赖关系

要启用此端口，请选择 **输出已纠正符号错误数**。

**数据类型：** `double`

有关详细信息，请参阅支持的数据类型。

## 参数

要以交互方式编辑模块参数，请使用 Property Inspector。在 Simulink® 工具条的 **Simulation** 选项卡上的 **Prepare** 库中，选择 **Property Inspector**。

### **码字长度 N** — 码字长度 `7`（默认）| 整数

码字长度，指定为整数。

有关详细信息，请参阅 M 和码字长度 N 的限制以及 RS 模块中的输入和输出信号长度。

### **消息长度 K** — 消息字长度 `3`（默认）| 整数

消息字长度，指定为范围 [1, *N*–2] 内的整数，其中 *N* 是码字长度。

### **缩短消息长度 S** — 缩短消息字长度 `3`（默认）| 整数

缩短消息字长度，指定为整数，使得 *S* ≤ *K*。当 **缩短消息长度 S** < **消息长度 K** 时，Reed-Solomon 码被缩短。

您仍需为全长度 (*N*, *K*) 码指定 *N* 和 *K* 值，但解码会缩短为 (*N*–*K*+*S*, *S*) 码。

#### 依赖关系

要启用此参数，请选择 **指定缩短消息长度**。

### **生成多项式** — 生成多项式 `rsgenpoly(7, 3, [], [], 'double')`（默认）| 多项式字符向量 | 二进制行向量 | 二进制 Galois 行向量

生成多项式，其值在范围 [0, 2*M*–1] 内，按降幂顺序排列，指定为以下之一：

- 多项式字符向量。有关详细信息，请参阅 Communications Toolbox 中的多项式表示。
- 整数行向量，按降幂顺序表示生成多项式的系数。
- 整数 Galois 行向量，按降幂顺序表示生成多项式的系数。

每个系数都是由本原多项式定义的 Galois 域的元素。有关详细信息，请参阅指定生成多项式。

**示例：** `[1 3 1 2 3]`，等效于 `rsgenpoly(7,3)`

#### 依赖关系

要启用此参数，请选择 **指定生成多项式**。

### **本原多项式** — 本原多项式 `'X^3 + X + 1'`（默认）| 多项式字符向量 | 二进制行向量

本原多项式，按降幂顺序排列。此多项式的阶数为 *M*，并定义有限 Galois 域 GF(2M)，该域对应于构成消息字和码字的整数。将本原多项式指定为以下之一：

- 多项式字符向量。有关详细信息，请参阅 Communications Toolbox 中的多项式表示。
- 二进制行向量，表示生成多项式的系数。

有关详细信息，请参阅指定本原多项式。

**示例：** `'X^3 + X + 1'`，这是用于 (7,3) 码的本原多项式，`ppoly = primpoly(3,'nodisplay'); int2bit(ppoly,ceil(log2(max(ppoly))))'`

#### 依赖关系

要启用此参数，请选择 **指定本原多项式**。

### **打孔向量** — 打孔向量 `[ones(2,1); zeros(2,1)]`（默认）| 二进制列向量

打孔向量，指定为 (*N*–*K*)-by-1 二进制列向量。带有 `1` 的元素索引表示未经更改通过该模块的数据*符号*索引。带有 `0` 的元素索引表示从数据流中被打孔（即移除）的数据*符号*索引。有关详细信息，请参阅打孔和删除。

**注意**

如果编码器每帧处理多个码字，则相同的打孔模式适用于所有码字。

#### 依赖关系

要启用此参数，请选择 **打孔码**。

### **启用删除输入端口** — 启用删除输入端口 off（默认）| on

选中此复选框将启用删除端口 **Era**。有关详细信息，请参阅打孔和删除。

### **输出已纠正符号错误数** — 启用端口以输出已纠正符号错误数 off（默认）| on

选中此复选框将启用附加输出端口 **Err**，该端口指示该模块在输入码字中纠正的符号错误数量。

## 描述

解码 Reed-Solomon 码以恢复整数向量数据

Integer-Output RS Decoder 模块从 Reed-Solomon 码字向量中恢复消息向量。为了正确解码，此模块中的参数值必须与对应的 Integer-Input RS Encoder 模块中的参数值匹配。

Reed-Solomon 码的消息长度为 *K*，码字长度为 *N* – *打孔数*。您直接在模块对话框中指定 *N* 和 *K*。该码的符号是范围 [0, 2*M*-1] 内的整数，表示有限域 *GF*(2*M*) 的元素。有关 *M* 和 *N* 的限制，请参阅下文的 M 和码字长度 N 的限制。

此图标显示可选端口。

输入和输出是整数值信号，分别表示码字和消息。有关详细信息，请参阅 RS 模块中的输入和输出信号长度。该模块从输入数据类型继承输出数据类型。有关每个模块端口支持的数据类型的信息，请参阅支持的数据类型。

有关为 Reed-Solomon 码表示数据的详细信息，请参阅“整数格式（仅 Reed-Solomon）”一节。

如果解码器每帧处理多个码字，则相同的打孔模式适用于所有码字。

M 的默认值为 `ceil(log2(N+1))`，即大于或等于 log2(N+1) 的最小整数。您可以通过为 GF(2M) 指定本原多项式，将 M 的值从默认值更改，如下文指定本原多项式所述。

您还可以为 Reed-Solomon 码指定生成多项式，如指定生成多项式所述。

(*N*, *K*) Reed-Solomon 码最多可以纠正每个码字中 `floor((N-K)/2)` 个符号错误（*不是*位错误）。

如果解码失败，则解码器输入的消息部分将作为解码器输出原样返回。

输入和输出信号的采样时间相等。
