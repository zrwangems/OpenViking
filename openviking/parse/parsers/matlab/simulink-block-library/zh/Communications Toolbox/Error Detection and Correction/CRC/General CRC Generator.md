# General CRC Generator

## 端口

### 输入

### **In** — 输入信号二进制列向量

输入信号，指定为二进制列向量。输入帧的长度必须是 **每帧校验和** 参数的值的倍数。

**数据类型:** `double` | `Boolean`
### 输出

### **Out** — 输出码字帧二进制列向量

输出码字帧，返回为二进制列向量，其继承输入信号的数据类型。输出包含追加了 CRC 位序列的输入数据帧。

输出帧的长度为 *m* + *k* \* *r*，其中 *m* 是输入帧的大小，*k* 是每帧校验和的数量，*r* 是生成多项式的次数。

## 参数

要交互式编辑模块参数，请使用属性检查器。在 Simulink® Toolstrip 的 **仿真** 选项卡上的 **准备** 库中，选择 **属性检查器**。

### **生成多项式** — 生成多项式 `'z^16 + z^12 + z^5 + 1'` (默认) | 多项式字符向量 | 二进制行向量 | 整数行向量

CRC 算法的生成多项式，指定为以下之一：

- 多项式字符向量，例如 `'z^3 + z^2 +
  1'`。
- 二进制行向量，按降幂顺序表示生成多项式的系数。此向量的长度为 (*N*+1)，其中 *N* 是生成多项式的次数。例如，`[1
  1 0 1]` 表示多项式
  *x*3+
  *z*2+ 1。
- 整数行向量，按降序包含多项式中非零项的 *z* 的指数。例如，`[3 2 0]` 表示多项式 *z*3 +
  *z*2 + 1。

有关详细信息，请参阅 Communications Toolbox 中的多项式表示。

默认值为 CRC-16-CCITT 生成多项式。
下表列出了一些常用的生成多项式。

| CRC 名称 | 生成多项式 |
| --- | --- |
| CRC-32 | `'z^32 + z^26 + z^23 + z^22 + z^16 + z^12 + z^11 + z^10 + z^8 + z^7 + z^5 + z^4 + z^2 + z + 1'` |
| CRC-24 | `'z^24 + z^23 + z^14 + z^12 + z^8 + 1'` |
| CRC-16 | `'z^16 + z^15 + z^2 + 1'` |
| CRC-16-CCITT | `'z^16 + z^12 + z^5 + 1'` |
| Reversed CRC-16 | `'z^16 + z^14 + z + 1'` |
| CRC-8 | `'z^8 + z^7 + z^6 + z^4 + z^2 + 1'` |
| CRC-4 | `'z^4 + z^3 + z^2 + z + 1'` |

**示例：** `'z^7 + z^2 + 1'`、`[1 0 0 0 0 1 0
1]` 和 `[7 2 0]` 表示同一个多项式，*p*(*z*) =
*z*
7 + *z*
2 + 1。

### **初始状态** — 内部移位寄存器的初始状态 `0` (默认) | `1` | 二进制行向量

内部移位寄存器的初始状态，指定为二进制标量或长度等于生成多项式次数的二进制行向量。标量值会扩展为长度等于生成多项式次数的行向量。

### **直接方法** — 使用直接算法进行 CRC 校验和计算 `off` (默认) | `on`

选择以使用直接算法进行 CRC 校验和计算。清除时，模块使用非直接算法进行 CRC 校验和计算。

有关直接算法和非直接算法的详细信息，请参阅错误检测与校正。

### **反射输入字节** — 反射输入字节 `off` (默认) | `on`

选择以在将数据输入移位寄存器之前，按字节翻转输入数据。选中 **反射输入字节** 时，输入帧长度除以 **每帧校验和** 参数的值必须为整数且为 `8` 的倍数。清除 **反射输入字节** 时，模块不翻转输入数据。

### **在最终 XOR 前反射校验和** — 在最终 XOR 前反射校验和 `off` (默认) | `on`

选择以在输入数据完全通过移位寄存器后，围绕中心翻转 CRC 校验和。清除 **在最终 XOR 前反射校验和** 时，模块不翻转 CRC 校验和。

### **最终 XOR** — 最终 XOR `0` (默认) | `1` | 二进制行向量

最终 XOR，指定为二进制标量或长度等于生成多项式次数的二进制行向量。XOR 运算在将 CRC 追加到输入数据之前，使用 **最终 XOR** 参数的值对 CRC 校验和运行。标量值会扩展为长度等于生成多项式次数的行向量。设置为 `0` 等效于不执行 XOR 运算。

### **每帧校验和** — 为每帧计算的校验和数量 `1` (默认) | 正整数

为每帧计算的校验和数量，指定为正整数。

## 描述

根据生成多项式生成 CRC 码位，并将其追加到输入数据帧

General CRC Generator 模块为每个输入数据帧生成循环冗余校验 (CRC) 码位，并将其追加到该帧。有关详细信息，请参阅 CRC 生成器操作。
