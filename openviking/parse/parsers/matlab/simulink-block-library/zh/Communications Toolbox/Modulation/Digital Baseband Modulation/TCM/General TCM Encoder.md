# General TCM Encoder

## 端口

R2025b 中未提供文档。

## 参数

**网格结构**
:   包含卷积编码器网格描述的 MATLAB 结构体。

**操作模式**
:   在 `Continuous` 模式（默认设置）下，模块会在每帧结束时保留编码器状态，以供下一帧使用。

    在 `Truncated (reset every frame)` 模式下，模块会独立处理每一帧。也就是说，编码器状态会在每帧开始时重置为全零状态。

    在 `Terminate trellis by appending bits` 模式下，模块会独立处理每一帧。对于每个输入帧，模块会使用额外比特，在帧结束时将编码器状态设置为全零状态。输出长度由 y=n⋅(x+s)/k 给出，其中 *x* 是输入比特数，s=约束长度−1（或者，在存在多个约束长度的情况下，*s* =`sum(ConstraintLength(i)-1)`）。对于列向量输入信号，模块支持此模式。

    在 `Reset on nonzero input via port` 模式下，模块具有一个额外的输入端口，标签为 `Rst`。当 `Rst` 输入为非零值时，编码器会重置为全零状态。

**信号星座**
:   按集合划分顺序列出信号星座中各点的复向量。

**输出数据类型**
:   模块的输出类型可指定为 `single` 或 `double`。默认情况下，模块将其设置为 `double`。

## 描述

对二进制数据进行卷积编码，并使用任意星座进行映射

General TCM Encoder 模块通过对二进制输入信号进行卷积编码，并将结果映射到任意信号星座，来实现网格编码调制 (TCM)。**信号星座**参数按集合划分顺序列出信号星座点。此参数是一个复向量，其长度 *M* 等于卷积编码器可能输出符号的数量。（即，对于码率为 *k*/*n* 的卷积码，log2*M* 等于 n。）

### 输入信号和输出信号

如果卷积编码器表示码率为 *k*/*n* 的码，则 General TCM Encoder 模块的输入必须是长度为 *L*\**k* 的二进制列向量，其中 *L* 为某个正整数。

此模块接受二值输入信号。输出信号是长度为 *L* 的复列向量。有关此模块各端口支持的数据类型的信息，请参阅支持的数据类型。

### 指定编码器

要定义卷积编码器，请使用**网格结构**参数。此参数是一个 MATLAB® 结构体，其格式在卷积码的网格描述中进行了说明。可通过两种方式使用此参数字段：

- 如果要使用编码器的约束长度、生成多项式以及可能的反馈连接多项式来指定编码器，请在**网格结构**字段中使用 `poly2trellis` 命令。例如，要使用约束长度为 7、码生成多项式为 171 和 133（八进制数）、反馈连接为 171（八进制）的编码器，请将**网格结构**参数设置为

  `poly2trellis(7,[171 133],171)`
- 如果 MATLAB 工作区中有一个包含网格结构的变量，则将其名称输入为**网格结构**参数。这种方式更快，因为与上一项目符号中的用法相比，它会使 Simulink® 软件在每次仿真开始时更新框图所花费的时间更少。

编码器寄存器的初始状态为全零状态。您可以将编码器配置为在仿真过程中将其寄存器重置为全零状态。为此，请将 `Operation mode` 设置为 **Reset on nonzero input via port**。随后，模块会打开第二个输入端口，标签为 `Rst`。`Rst` 端口处的信号是标量信号。当该信号为非零值时，编码器会在处理第一个输入端口的数据之前重置。

### 信号星座

网格编码调制技术将星座划分为称为陪集的子集，以使每个陪集中点对之间的最小距离最大化。

**注意**

设置**信号星座**参数时，必须确保星座向量已按集合划分顺序排列。否则，模块可能会产生意外或次优的结果。

例如，下图显示了一种为 8-PSK 信号星座点确定集合划分顺序的方法。树顶部的图表示整个 8-PSK 信号星座，而树底部的八个图各包含一个星座点。树的每一层对应二进制序列 (b3,b2,b1) 中的一个不同比特，而树中给定层的每个分支对应该比特的一个特定值。按照树底部的序列列出星座点，可得到向量

```
exp(2*pi*j*[0 4 2 6 1 5 3 7]/8)
```

这是此模块**信号星座**参数的有效值。
