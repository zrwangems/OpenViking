# AXI4 Random Access Memory

## 端口

### 输入

### **wrData** — 写入器数据总线信号 标量 | 向量 | 矩阵

此信号包含要写入内存的数据。

**数据类型：** `single` | `double` | `int8` | `int16` | `int32` | `int64` | `uint8` | `uint16` | `uint32` | `uint64` | `Boolean` | `fixed point`

### **rdCtrlIn** — 读取器输入控制信号总线

此端口接受来自数据消费者模块的控制总线，指示消费者模块已准备好接受读取数据。此输入是来自读取器的读请求。要创建控制总线，请使用 SoC Bus Creator 模块。

**数据类型：** `ReadControlM2SBusObj`

### **wrCtrlIn** — 写入器输入控制信号总线

此端口接受来自数据生产者模块的控制总线，指示生产者模块已准备好发送数据。此输入是来自写入器的写请求。要创建控制总线，请使用 SoC Bus Creator 模块。

**数据类型：** `WriteControlM2SBusObj`
### 输出

### **rdData** — 输出到数据消费者的数据信号 标量 | 向量 | 矩阵

此信号包含从内存读取的数据。

**数据类型：** `single` | `double` | `int8` | `int16` | `int32` | `int64` | `uint8` | `uint16` | `uint32` | `uint64` | `Boolean` | `fixed point`

### **rdCtrlOut** — 从内存通道到数据消费者的读取器控制信号总线

此总线表示从内存通道到数据消费者的协议总线。要将信号与总线分离，请使用 SoC Bus Selector 模块。

**数据类型：** `ReadControlS2MBusObj`

### **wrCtrlOut** — 从内存通道到数据生产者的写入器控制信号总线

此总线表示从内存通道到数据生产者的协议总线。要将信号与总线分离，请使用 SoC Bus Selector 模块。

**数据类型：** `WriteControlS2MBusObj`

## 参数

### **内存仿真** — 设置仿真时序精度 `Burst accurate`（默认）| `Protocol accurate`

内存仿真提供两个级别的时序分辨率。请选择以下选项之一：

- **Burst accurate** — 仿真内存争用和高分辨率时序。
- **Protocol accurate** — 仿真 AXI4 协议握手序列和低分辨率时序。

### 主要

### **内存选择** — 在内存区域之间选择 `PS memory`（默认）| `PL memory`

在处理子系统 (PS) 或编程逻辑 (PL) 内存之间选择。

- 如果所选板卡仅支持 PL memory，则默认值为 `PL memory`。
- 如果所选板卡仅支持 PS memory 或仅支持 PL memory，则此参数为只读。
- 如果所选板卡不是受支持的 SoC 板卡，则此参数不可见。

### **区域大小 (bytes)** — 缓冲区大小，以 bytes 为单位 4096（默认）| 标量

指定内存缓冲区的大小（以 bytes 为单位）。

### **初始化内存内容** — 为仿真初始化内存 `off`（默认）| `on`

选择此参数以启用仿真前内存初始化。

### **初始值** — 初始内存值 0（默认）| 标量 | 向量

为内存仿真指定初始值，如下之一：

- 0–255 之间的整数标量值 — 该模块会复制此值并将其加载到所有内存位置。
- `uint8` 向量 — 该模块将向量的每个元素写入一个内存位置。

  - 如果向量小于内存区域，则用零填充该向量，使其与内存区域的大小匹配。
  - 如果向量大于内存区域，则截断该向量，使其与内存区域的大小匹配。

**示例：** `0` — 将所有内存位置初始化为零。

**示例：** `1:10` — 将前十个内存位置初始化为值 1–10，其他位置初始化为零。

#### 依赖关系

要启用此参数，请选择 **初始化内存**。

### **记录内存内容** — 记录内存内容 `off`（默认）| `on`

选择此参数以启用仿真后内存日志记录。

### **日志变量名称** — 内存日志的变量名称 字符串 | 字符向量

用于保存内存内容数据的变量名称，指定为字符串或字符向量。

**示例：** `'mem_content'`

#### 依赖关系

要启用此参数，请选择 **记录内存结束值**。

### 信号属性

#### 写数据信号

### **维度** — 输入数据信号的维度 标量 | 数组

**wrData** 可以是多维数组。将数组的维度指定为整数。

**示例：** 1 — 标量样本。

**示例：** [10 1] — 十个标量的向量。

**示例：** [1080 1920 3] — 一个 1080p 帧。该帧包含 1080 行，每行 1920 个像素，每个像素由三个值（分别对应红色、绿色和蓝色）表示。

### **数据类型** — 写入器数据的数据类型 uint32（默认）| double | single | int8 | int16 | int32 | int64 | uint8 | uint16 | uint64 | boolean | fixed point

指定 **wrData** 端口的数据类型。如需帮助，请点击 **...** 按钮并选择 **数据类型助手**。

### **采样时间** — 采样时间间隔 1（默认）| 正标量 | 向量

指定时间间隔（以 seconds 为单位），以定义模块的更新频率。

如果希望输出没有时间偏移，请将 **采样时间** 参数指定为标量。要为输出添加时间偏移，请将 **采样时间** 参数指定为 `1`-by-`2` 向量，其中第一个元素是采样周期，第二个元素是偏移量。有关 Simulink® 中采样时间的详细信息，请参阅 Specify Sample Time。

### **启用样本打包（最后一个信号维度作为通道）** — 在信号的最后一个维度上打包数据 `off`（默认）| `on`

选择此参数以启用沿信号最后一个维度的数据打包。AXI4-Random Access Memory 模块沿信号的最后一个维度打包数据。例如，如果通道数据类型为 `uint32`，维度为 `[1024 4]`。如果选择此样本打包参数，则内存通道会生成 1024 个 128 bits 的读或写事务。如果清除此样本打包参数，则内存通道会生成 4096 个 32 bits 的事务。

此图显示了数据类型为 `fixdt10[4x3]` 的信号的数据对齐方式。打包数据时，将三个 10-bit 字连接并扩展 2 bits，形成一个 32-bit 字。不打包数据时，每个 10-bit 字扩展为一个 16-bit 字。

顶行显示打包数据按 10、10、10 和 2 的样本对齐，以组成 32 bits。底行显示未打包数据按 10 和 6 的样本对齐，以组成 16 bits。

此图显示了数据类型为 `uint8[8x3]` 的信号的数据对齐方式。打包数据时，将三个 8-bit 字连接并扩展 8 bits，形成一个 32-bit 字。不打包数据时，每个 8-bit 字表示为 8-bit 样本。

顶行显示打包数据按 8、8、8 和 8 的样本对齐，以组成 32 bits。底行显示未打包数据按 8 bits 的样本对齐。

展平信号的总位宽不得超过 512 bits。

## 描述

通过外部内存对随机访问进行建模

AXI4 Random Access Memory 模块使用 MathWorks® 简化 AXI4 管理器协议，通过外部内存对两个硬件算法之间的连接进行建模。写入器和读取器都是管理器，通过该模块向内存发送读请求和写请求。外部内存是非托管的（没有逻辑缓冲区，没有循环缓冲区）。为确保数据完整性，读取器和写入器会在访问时协调时序。

此模块等效于一个连接到 Memory Controller 模块的 Memory Channel 模块，其 **通道类型** 参数设置为 `AXI4 Random Access`。

由于内存控制器对设计是隐式的，因此您可以实例化多个内存模块，这些模块通过内存控制器连接到同一内存单元。有效的模块包括：

- AXI4 Random Access
  Memory
- AXI4-Stream to
  Software
- Software to
  AXI4-Stream
- AXI4 Video Frame
  Buffer
- Memory Traffic
  Generator

一个模型中的管理器接口最大数量为 16。

连接到 Memory Controller 模块的 Memory Channel 模块，由 AXI4 Random Access Memory 模块替代

有关详细信息，请参阅简化 AXI4 Master 接口。
