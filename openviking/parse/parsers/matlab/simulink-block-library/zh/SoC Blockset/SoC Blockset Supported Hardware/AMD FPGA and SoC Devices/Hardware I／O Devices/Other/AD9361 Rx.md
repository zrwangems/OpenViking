# AD9361 Rx

## 端口

### 输入

### **rxDataIn** — 接收器数据复矩阵

在仿真中要通过该模块传递的接收器数据，指定为复矩阵。矩阵中的列数取决于使用的通道数。每一列对应于通过一个通道发送的一个通道的复数数据。在单通道模式下，列中的元素数必须为偶数。

此端口支持以下数据类型的复数值：

- 16-bit signed integers — 复数值是原始 16 位 I 和 Q 样本。来自 AD9361 RF 芯片 ADC 的 12 位值被符号扩展为 16 位。
- Single-precision floating point — 复数值缩放到 [–1, 1] 范围。该模块从符号扩展后的 16 位接收数据中推导出此值。
- Double-precision floating point — 复数值缩放到 [–1, 1] 范围。该模块从符号扩展后的 16 位接收数据中推导出此值。

#### 依赖项

要启用此端口，请将 **Simulation output** 参数设置为 `From input port`。

**数据类型：** `int16` | `single` | `double`
**复数支持：** Yes

### 输出

### **rxDataOut** — 接收器数据复矩阵

接收器数据，以复矩阵形式返回。矩阵中的列数取决于使用的通道数。每一列对应于在一个通道上接收的一个通道的复数数据。**Simulation output** 参数定义此数据的来源。

此端口支持以下数据类型的复数值：

- 16-bit signed integers — 复数值是来自板卡的原始 16 位 I 和 Q 样本。来自 AD9361 RF 芯片 ADC 的 12 位值被符号扩展为 16 位。
- Single-precision floating point — 复数值缩放到 [–1, 1] 范围。该模块从符号扩展后的 16 位接收数据中推导出此值。
- Double-precision floating point — 复数值缩放到 [–1, 1] 范围。该模块从符号扩展后的 16 位接收数据中推导出此值。

**数据类型：** `int16` | `single` | `double`
**复数支持：** Yes

## 参数

### **Enable channel 1** — 启用通道 1 的选项 `on` (默认) | `off`

选择此参数以启用接收通道 1。

### **Enable channel 2** — 启用通道 2 的选项 `off` (默认) | `on`

选择此参数以启用接收通道 2。

### **Simulation output** — 仿真行为 `Zeros` (默认) | `From recorded file` | `From input port`

仿真行为，指定为以下值之一：

- `Zeros` –– 返回零值数据。
- `From recorded file` –– 使用 **Dataset name** 和 **Source name** 参数从文件返回数据。
- `From input port` –– 从输入端口传递数据。

### **Dataset name** — 录制文件的名称 `rf_data_adsb.tgz` (默认) | 文件路径

录制文件的名称，指定为主机计算机上的文件路径，或在主机计算机上浏览并选择文件。此模块仅支持使用 SoC Blockset 数据记录 API 创建的 TGZ 文件。默认值是从 Packet-Based ADS-B Transceiver 示例记录的数据集。

#### 依赖项

要启用此参数，请将 **Simulation output** 设置为 `From recorded file`。

### **Source name** — 数据集的名称 `RF data Ch-1` (默认) | 字符向量

录制数据集文件中可用数据集的名称，指定为字符向量。该数据集必须存在于 **Dataset name** 参数指定的文件中。您可以在 **Source name** 框中键入名称，或点击 **Select** 查看录制数据文件中可用的源列表并检查其属性。默认值是从 Packet-Based ADS-B Transceiver 示例记录的数据集。

#### 依赖项

要启用此参数，请将 **Simulation output** 设置为 `From recorded file`。

### **Sample time** — 模块的采样时间 `1` (默认) | 正标量

模块的采样时间，指定为正标量。

**数据类型：** `double`

## 版本历史

**在 R2019a 中引入**

### R2024b: 不推荐

不建议使用此模块。请改用 AD936x Receiver。新的 AD936x Receiver 模块包含此模块的功能，但支持 SoC builder 工作流和 IP 核生成工作流。有关 SoC 工作流的详细信息，请参阅 SoC Generation Workflows。

### R2024a: 双通道支持

该模块现在支持两个接收通道。您可以通过从模块封装中选择 **Enable channel 1** 和 **Enable channel 2** 参数来启用双通道。

## 描述

将硬件逻辑连接到基于 AD9361 的 Zynq 接收器

AD9361 Rx 模块将您的硬件逻辑连接到 AD9361 接收器硬件。在仿真中，此模块从文件或输入端口返回数据。此模块不会在仿真中连接到无线电硬件。

该模块最多支持两个通道接收数据。
