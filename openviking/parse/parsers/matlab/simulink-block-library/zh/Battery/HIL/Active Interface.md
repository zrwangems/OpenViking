# Active Interface

## 端口

### 输入

### **Vcsc\_charge** — 来自电芯监控电路的充电电压，V 物理信号

来自电芯监控电路的充电电压，单位为 volt。

### **Icsc\_discharge** — 来自电芯监控电路的放电电流，A 物理信号

来自电芯监控电路的放电电流，单位为 ampere。

### **SOC** — 电池荷电状态，unitless 物理信号

电池的荷电状态，单位为 percent。

#### 依赖项

要启用此端口，请将 **暴露 SOC 输入端口** 参数设置为 `Yes`。

### 输出

### **Vbat** — 电池电压，V 物理信号

电池两端的电压，单位为 volt。

### **Icsc** — 电芯监控电路电流，A 物理信号

流经电芯监控电路的电流，单位为 ampere。

#### 依赖项

要启用此端口，请将 **暴露电芯监控电路电流测量端口** 参数设置为 `Yes`。

### **isCharging** — 充电状态，unitless 物理信号

物理信号输出端口，指示 BMS 正在为电池充电还是放电。如果此输出的值为 `1`，则 BMS 正在为电池充电。如果此输出的值为 `0`，则 BMS 正在为电池放电。

### **SOC** — 电池荷电状态，unitless 物理信号

电池的荷电状态，单位为 percent。

#### 依赖项

要启用此端口，请将 **暴露 SOC 输出端口** 参数设置为 `Yes`。

### **T** — 温度测量，K 物理信号

电池的温度，单位为 kelvin。

#### 依赖项

要启用此端口，请将 **暴露温度测量端口** 参数设置为 `Yes`。

### 守恒

### **+** — 正极端子电气

与接口正极端子关联的电气守恒端口。

### **-** — 负极端子电气

与接口负极端子关联的电气守恒端口。

### **H** — 热端口 thermal

热守恒端口。

#### 依赖项

要启用此端口，请将 **热端口** 参数设置为 `Model`。

## 参数

### **电芯监控电路电阻** — 电芯监控电路电阻 `1e-6` `Ohm` (默认)

电芯监控电路的代表性电阻，确保抽象方程中 **Vcsc\_discharge** 和 **Vbat** 端口的值之间存在小差异。此电压差确保充电和放电模式之间的平滑过渡。

### **暴露 SOC 输入端口** — SOC 输入端口可见性 `No` (默认) | `Yes`

用于暴露电池 SOC 输入端口的选项。

### **暴露 SOC 输出端口** — SOC 输出端口可见性 `Yes` (默认) | `No`

用于暴露电池 SOC 输出端口的选项。

#### 依赖项

要启用此参数，请将 **暴露 SOC 输入端口** 设置为 `Yes`。

### **热端口** — 热端口可见性 `Omit` (默认) | `Model`

对被动接口的热端口进行建模的选项。

### **暴露温度测量端口** — 温度测量端口可见性 `Yes` (默认) | `No`

用于暴露测量电池温度的端口的选项。

#### 依赖项

要启用此参数，请将 **热端口** 设置为 `Model`。

## 描述

电池与电芯监控电路之间的主动接口

Active Interface 模块提供电池与电芯监控电路之间的抽象主动接口。在桌面仿真和硬件在环电池仿真硬件中使用此模块。

电芯监控电路是一种电子电路，连接到电芯或并联组件。您可以使用此电路来规范化模块或电池包内部的电压或荷电状态 (SOC)。在实际应用中，您将此设备实现于电池和电池管理系统 (BMS) 控制之间。

在此图中，蓝色项表示实际设备、电压和电流。

为避免损坏电池并在标准运行条件和故障条件下测试电芯均衡算法，您可以使用硬件在环电池仿真硬件。抽象接口有助于将被动均衡 BMS 连接、设置和配置到仿真的电池。

在此图中：

- 蓝色表示实际设备、电压和电流。
- 绿色表示实际设备、电压和电流，以及仿真设备、电压和电流之间的接口。
- 橙色表示仿真设备、电压和电流。

Active Interface 模块提供电力电子设备的抽象表示，而无需对其进行详细建模。例如，如果您的电池包在其组成部分内具有不同水平的温度或电压，您可以使用此模块检查 BMS 在各种运行场景后是否正确均衡电池包。

如果输入信号 **Vcsc\_charge** 小于仿真电池电压 **Vbat**，则：

- 仿真电池正在放电。
- **IsCharging** 输出端口上的值为 `0` (`false`)。
- **Icsc\_discharge** 输入端口指定电芯监控电路中的电流。
- **Icsc** 输出端口上的值在数值上与 **Icsc\_discharge** 输入端口上的值相同。此输出是提供给电芯监控电路的电流的测量值。

如果输入信号 **Vcsc\_charge** 大于或等于 **Vbat**，则：

- 仿真电池正在充电。
- **IsCharging** 输出端口上的值为 `1` (`True`)。
- **Vcsc\_charge** 输入端口指定电池两端的电压减去电芯监控电路电阻上的电压降。
- 模块忽略 **Icsc\_discharge** 输入。
- **Icsc** 输出端口是提供给电芯监控电路的电流的测量值。因此，当 BMS 为电池充电时，此电流为负值。

### SOC 可选端口

使用 Active Interface 模块的可选 SOC 端口，以避免在 BMS 中实现 SOC 估计算法，对照仿真 SOC 验证和确认 SOC 估计算法，或表示实际电池。

- 如果您的模型中电池具有 SOC 输出端口，请暴露此模块的 SOC 输入端口并相应地连接端口。要暴露此模块的 SOC 输入端口，请将 **暴露 SOC 输入端口** 参数设置为 `Yes`。
- 要避免在 BMS 中实现 SOC 估计算法，或对照仿真 SOC 验证和确认 SOC 估计算法，请暴露此模块的 SOC 输出端口并将其连接到您的 BMS。要暴露此模块的 SOC 输出端口，请将 **暴露 SOC 输出端口** 参数设置为 `Yes`。
- 要表示实际电池，请勿暴露此模块的 SOC 端口。

### 热和温度可选端口

使用 Active Interface 模块的可选热和温度端口来表示带温度传感器的电池，或对照仿真温度验证和确认温度估计算法。

- 如果您的模型中电池具有温度传感器，请暴露此模块的热端口 **H** 并将其连接到热网络。要暴露此模块的热端口，请将 **热端口** 参数设置为 `Model`。
- 要对照仿真温度验证和确认温度估计算法，请同时暴露此模块的热端口 **H** 和温度测量端口 **T**，并分别将它们连接到热网络和您的 BMS。要暴露此模块的温度测量端口，请将 **暴露温度测量端口** 参数设置为 `Yes`。
- 如果您的模型中电池不包含热效应或没有温度传感器，请勿暴露此模块的热端口和温度端口。
