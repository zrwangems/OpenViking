# UDP Multicast Receive

## 端口

### 输出

### **Data** — 接收的数据向量

包含通过 UDP 网络接收的数据的 `uint8` 向量。如果未收到新数据包，则保持数据值。要确定是否收到新数据包，请使用 **Length** 输出端口。

**数据类型：** `uint8`

### **Length** — 接收的字节数 double

新接收到的数据包中的字节数，否则为 `0`。如果接收到的字节数超过可通过接收端口输出的字节数（其宽度由 **接收宽度** 定义），则多余的字节将被丢弃。

## 参数

### 通用参数

### **绑定地址** — 用于接收多播数据的绑定 IP 地址 `0.0.0.0`（默认）

**绑定地址** 可以是 `0.0.0.0` 或多播地址。当 **绑定地址** 设置为 `0.0.0.0` 时，模块绑定到 `INADDR_ANY`，这使套接字能够在所有接口上接收数据报。此设定会启用模块掩码上的 **组地址** 字段。当 **绑定地址** 设置为多播 IP 地址时，**组地址** 字段在模块掩码上隐藏。

如果 **绑定地址** 设置为 `0.0.0.0`，并且该模块配置在发送单播消息的组接口上，则该模块也可以接收单播消息。发生这种单播消息接收是因为地址 `0.0.0.0` 允许监听目标计算机所有接口上的任何消息。要避免这种单播消息接收操作，请将多播地址用作绑定地址。使用该设置时，模块仅接收多播消息，不接收单播消息。

### **本地端口** — 用于接收数据的目标 UDP 端口 `1–65535`

指定用于接收数据的 UDP 端口。

端口 `1` 到 `1023` 以及 `5500` 到 `5560` 保留用于 Simulink Real-Time 通信。

#### 编程使用

|  |
| --- |
| **模块参数：** `localPort` |

### **接收宽度** — `Data` 输出向量的宽度 `16`（默认） | `1–65504`

确定 `Data` 输出向量的宽度。如果此值小于所接收数据包中的字节数，则多余的字节将被丢弃。

#### 编程使用

|  |
| --- |
| **模块参数：** `rcvWidth` |

### **组地址** — 要加入的多播组 `{}`（默认） | `{'x.x.x.x'}` | 点分十进制字符向量

当绑定地址为多播地址时，此字段隐藏。以点分十进制字符向量形式输入有效的 IP 地址，例如 `{'224.0.0.0'}`。可以指定一个或多个组地址。

如果组 IP 地址不是 `224.0.0.0` 到 `239.255.255.255` 范围内的有效多播地址，则 UDP Multicast Receive 模块在模型更新时发出错误。

**示例：** `{'224.100.1.1'}`

**示例：** `{'224.100.1.1', '224.100.1.2'}`

#### 编程使用

|  |
| --- |
| **模块参数：** `multicastAddress` |

### **组接口** — 用于接收数据的本地 IP 接口 `{}`（默认） | `{'x.x.x.x'}` | 点分十进制字符向量

**组接口** IP 地址指定应通过哪些接口接收传入的多播消息。当绑定地址为 `0.0.0.0` 时，在 **组地址** 字段中指定的多播组通过指定的一个或多个组接口接收消息。当绑定地址为多播地址时，该地址通过指定的一个或多个组接口接收消息。以点分十进制字符向量形式输入有效的接口 IP 地址，例如 `{'192.168.7.5'}`。您还可以使用返回有效 IP 地址字符向量的 MATLAB 表达式。可以指定一个或多个组接口。

**示例：** `{'192.168.7.5'}`

**示例：** `{'192.168.7.5', '192.168.7.10'}`

## 描述

通过 UDP 网络从远程设备接收数据

UDP Multicast Receive 模块通过 UDP 网络从远程设备接收多播数据。它可以使用 MATLAB® 开发计算机和 Speedgoat® 目标计算机之间的连接来接收数据，也可以使用专用以太网卡来接收数据。如果使用专用以太网卡，请使用 Speedgoat 配置实用程序配置专用以太网板。

UDP Multicast Receive 模块在目标计算机上运行的实时应用程序中工作。该模块不在开发计算机上的模型仿真中工作。

最多可以加入 20 个多播组。此数量由模块掩码上的组地址和组接口字段的乘积确定。
