# CAN

CAN

使用 CAN 协议进行汽车硬件控制

要对汽车硬件进行建模，请使用 CAN 协议模块。这些模块连接到与标准总线架构（如 PCI）兼容的板卡。有关 CAN 标准的更多信息，请参阅 `www.can-cia.org`。

## 模块

|  |  |
| --- | --- |
| CAN Pack | 将各个信号打包为 CAN 报文 |
| CAN Unpack | 从 CAN 报文中解包各个信号 |
| CAN FD Pack | 将各个信号打包为 CAN FD 总线报文 |
| CAN FD Unpack | 从 CAN FD 报文中解包各个信号 |

## 相关信息

- **www.can-cia.org**
