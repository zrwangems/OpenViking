# FIFO Read

## 端口

### 输入

### **F** — 用于从中读取数据的 FIFO serialfifoptr

连接到包含从串行端口读取的数据的软件 FIFO。

### **MAX** — 要从 FIFO 读取的最大字节数 integer

该模块要返回的最大字节数。

#### 依赖关系

要使此端口可见，请设置参数 **最大和最小读取大小端口**。

### **MIN** — 要从 FIFO 读取的最小字节数 integer

该模块要返回的最小字节数。

#### 依赖关系

要使此端口可见，请设置参数 **最大和最小读取大小端口**。

### 输出

### **D** — 从 FIFO 读取的解析数据 vector

包含从 FIFO 读取的解析数据的向量。

#### 依赖关系

要确定此向量的数据类型，请设置参数 **输出向量类型**。

**数据类型：** `int8` | `uint8` | `int16` | `uint16` | `int32` | `uint32`

### **ENA** — 传递 `MAX` 的值 integer

将端口 `MAX` 的值传递给读取 `ENA` 端口的模块。

#### 依赖关系

要使此端口可见，请设置参数 **最大和最小读取大小端口** 和 **启用直通**。

## 参数

### **最大读取大小** — 模块返回的最大字符数 `1024` (默认) | integer

指定此模块要返回的最大字符数。生成的向量大小比此最大字符数多一。此模块通过将额外元素用作以下内容来指示正在返回的字符数：

- 对于 8 位数据类型，用作 null 终止符
- 对于 16 位和 32 位数据类型，用作字符计数

输入足够大的数字。如果此数字太小，该模块无法返回任何内容。例如，如果输入值 `10`，但在执行时 FIFO 包含 `11` 个字符加上 null 终止符，则该模块不返回任何字符。如果 FIFO 包含 `5`，则该模块返回 `5` 个字符加上 null 终止符。

如果选择参数 **最大和最小读取大小端口**，该模块会将端口 `MAX` 上输入的值解释为要返回的最大字符数。要返回的实际最大字符数是端口 `MAX` 上的值与模块参数中最大读取大小中的较小者。在未选中 **读取到分隔符** 复选框时，可在二进制模式下使用此值。

#### 编程用法

|  |
| --- |
| **模块参数：** `maxsize` |

### **最小读取大小** — 模块返回的最小字符数 `1` (默认) | integer

输入以字节为单位的最小读取大小。FIFO 必须至少包含此数量的元素，然后才能返回元素。

如果选择参数 **最大和最小读取大小端口**，则端口 `MIN` 的值将取代此值。

#### 编程用法

|  |
| --- |
| **模块参数：** `minsize` |

### **读取到分隔符** — 返回分隔的元素集 `on` (默认) | `off`

选中此复选框可启用返回以 **分隔符** 值终止的元素集。处理基于字符的元素时，请使用此参数。

#### 编程用法

|  |
| --- |
| **模块参数：** `usedelimiter` |

### **分隔符** — 分隔元素集的终止符值 `13` (默认) | `uint`

输入 8 位输入终止符的十进制值。此参数指定 FIFO 读取操作终止所依据的值。此值与 **读取到分隔符** 参数一起使用。默认情况下，此模块会查找回车符。仅当找到一个回车符时，它才返回字符。作为参考，回车符的十进制值为 `13`，换行符的十进制值为 `10`。

#### 编程用法

|  |
| --- |
| **模块参数：** `delimiter` |

### **输出向量类型** — 指定输出数据类型 `8 bit uint null terminated` (默认) | `count+32 bit int` | `count+32 bit uint` | `count+16 bit int` | `count+16 bit uint` | `8 bit int null terminated`

8 位数据类型在输出向量中生成以 NULL 终止的字符向量。对于 16 位和 32 位数据类型，第一个元素包含输出向量其余部分中预期元素的数量。

#### 编程用法

|  |
| --- |
| **模块参数：** `outputtype` |

### **最大和最小读取大小端口** — 启用最大和最小输入端口 `off` (默认) | `on`

选中此复选框时：

- 输入端口 `MAX` 的值是要从 FIFO 中移除的最大字符数。如果此数字超过 **最大读取大小** 的值，则该模块会忽略最大输入端口的值。它将 **最大读取大小** 的值作为要从 FIFO 中移除的最大字符数。
- 输入端口 `MIN` 的值是 FIFO 在可以返回元素之前必须包含的最小字符数。此值将取代用 **最小读取大小** 参数设置的值。

此设置使输入端口 `MAX` 和 `MIN` 可见。

#### 编程用法

|  |
| --- |
| **模块参数：** `enable` |

### **启用直通** — 启用 `MAX` 值的直通 `off` (默认) | `on`

选中此复选框可将输入端口 `MAX` 的值传递到输出端口 `ENA`。

#### 依赖关系

使输出端口 `ENA` 变为可见。

#### 编程用法

|  |
| --- |
| **模块参数：** `enableout` |

### **采样时间** — 模块的采样时间 `-1` (默认) | numeric

输入基本采样时间或基本采样时间的倍数。`-1` 表示继承采样时间。

#### 编程用法

`sampletime`

## 描述

读取简单数据流

FIFO Read 模块是 FIFO 读/写对的读取侧。您可以使用此模块来解析简单数据流。该模块以两种模式运行，可通过 **读取到分隔符** 复选框进行设置。

- 如果选中 **读取到分隔符** 复选框，则仅当指定的分隔符已写入 FIFO Write 模块时，该模块才会读取元素。如果找到该分隔符，则该模块会在输出向量中返回直到并包括该分隔符的元素。如果未找到该分隔符，则该模块会返回零长度向量，具体取决于数据类型。（如果得到零长度向量，您可以让模型执行特定操作或忽略该情况。）
- 如果清除 **读取到分隔符** 复选框，则该模块返回介于 **最小读取大小** 与 FIFO 中当前元素数量和 **最大读取大小** 两者中较小者之间的元素。

  执行 ASCII 读取时，选中 **读取到分隔符** 复选框。执行二进制读取时，清除此复选框。

以下是一些如何设置 FIFO Read 模块的示例：

- **中断服务例程的发送侧** — 如果中断原因不是 UART 上的硬件 FIFO 为空，则最大输入端口接收值 `0`。如果硬件 FIFO 为空，则它接收硬件 FIFO 的大小。最小输入端口接收常量值 `1`。
- **中断服务例程的接收侧** — 使用 ASCII 数据的典型情况会禁用最小和最大输入端口。选中 **读取到分隔符参数** 复选框，并且 **分隔符** 参数具有回车符或换行符的值。**最大读取大小** 参数的值很大（大约为 FIFO 大小的数量级），而 **最小读取大小** 参数的值为 1。在此形式下，驱动程序的作用类似于非阻塞读取行。

  对于定长二进制数据块的另一种接收侧配置，将 **最大读取大小** 和 **最小读取大小** 参数的值设置为该块的固定长度。不选中 **读取到分隔符** 参数。

对于复杂数据流，请考虑使用 FIFO Read HDRS 和 FIFO Read Binary 模块。有关何时使用这些模块的指南，请参阅 RS-232 FIFO Read Blocks。

有关详细信息，请参阅 RS-232 Serial Communication 和 RS-232 Legacy Drivers。
