## 描述

评估并验证在测系统的行为

以表格步骤序列定义测试评估。与 Test Sequence 模块类似，Test Assessment 模块使用 MATLAB® 作为动作语言。

双击 Test Assessment 模块以打开测试序列编辑器。默认情况下，Test Assessment 模块包含测试步骤“运行”，配置为“When 分解”序列。要将转移类型更改为标准转移，请右键点击顶层步骤并清除 **When 分解**。有关详细信息，请参阅测试序列编辑器。
