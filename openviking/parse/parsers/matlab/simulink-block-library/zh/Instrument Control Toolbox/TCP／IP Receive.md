# TCP/IP Receive

## 端口

### 输出

### **Data** — 接收的数据 向量 | 矩阵 | 数组

模块从远程地址接收的数据，以向量、矩阵或数组形式返回。

**数据类型：** `single` | `double` | `int8` | `int16` | `int32` | `int64` | `uint8` | `uint16` | `uint32` | `uint64`

### **Status** — 新数据可用 `0`（默认） | `1`

新数据可用状态，以逻辑值 `1`（`true`）或 `0`（`false`）返回。如果此端口返回 `1`，则表示有新数据可供读取。

#### 依赖关系

要启用此端口，请取消选中 **Enable blocking mode** 参数。

**数据类型：** `Boolean`

### **Terminator** — 终止符 `LF`（默认）| `CR` | `CR/LF` | `LF/CR` | `Custom terminator`

### **Byte order** — 字节顺序 `big-endian`（默认）| `little-endian`

在接收数据之前，请将字节顺序配置为与远程机器匹配的适当值。有关仪器存储字节顺序的信息，请参阅仪器文档。

### **Enable blocking mode** — 仿真在接收数据时等待 `on`（默认）| `off`

此参数使仿真在模块接收数据时等待。当新数据可用时，仿真从下一个时间步继续。如果您不希望读取操作导致仿真等待，请清除该复选框。

如果启用阻塞模式，仿真将等待请求的数据变为可用。在每个时间步，模型等待的时间最多为 **Timeout** 参数指定的时间。如果在此时间内未收到数据，模块输出值 `0`。

如果未启用阻塞模式，仿真将持续运行，并且模块有两个输出端口：**Status** 和 **Data**。**Data** 端口在每个时间步包含请求的数据集。**Status** 端口包含 0 或 1，取决于在给定时间步是否接收到新数据。

有关详细信息，请参阅 Enable Blocking Mode in Receive and Send Blocks。

## 描述

通过 TCP/IP 网络从指定的远程机器接收数据

TCP/IP Receive 模块使用 TCP/IP 协议配置并打开到指定远程地址的接口。配置和初始化在模型执行开始时进行一次。模块在模型运行期间以阻塞模式或非阻塞模式获取数据。使用 TCP/IP Receive 模块通过 TCP/IP 网络读取流数据。此模块仅作为 TCP/IP 客户端工作，不能用作 TCP/IP 服务器。

此模块没有输入端口。根据您选择阻塞模式还是非阻塞模式，它有一个或两个输出端口。如果您选择阻塞模式，模块有一个输出端口 **Data**，对应于它接收的数据。如果您不选择阻塞模式，模块有两个输出端口，**Data** 和 **Status**。

此模块使用先进先出（FIFO）缓冲区来接收数据。在每个时间步，**Data** 端口从缓冲区返回请求的值。在非阻塞模式下，**Status** 端口指示模块是否已接收到新数据。如果 **Status** 端口显示 `1`，则新数据可用；如果 **Status** 端口显示 `0`，则没有新数据可用。

### 其他支持的功能

- TCP/IP Receive 模块支持使用 Simulink® Accelerator 模式和 Rapid Accelerator。此功能可加速 Simulink 模型的执行。
- TCP/IP Receive 模块支持使用模型引用。此功能允许您的模型将其他 Simulink 模型作为模块化组件包含在内。
- TCP/IP Receive 模块支持 C/C++ 代码生成。此功能允许您使用 Simulink Coder™ 生成 C 和 C++ 代码。

有关这些功能的详细信息，请参阅 Simulink 文档。
