# UDP Receive

## 端口

### 输出

### **Data** — 接收的数据向量 | 矩阵 | 数组

模块从远程地址接收的数据，以向量、矩阵或数组形式返回。

**数据类型：** `single` | `double` | `int8` | `int16` | `int32` | `int64` | `uint8` | `uint16` | `uint32` | `uint64`

### **Status** — 新数据可用 `0`（默认） | `1`

新数据可用状态，以逻辑 `1`（`true`）或 `0`（`false`）返回。如果此端口返回 `1`，则新数据可供读取。

#### 依赖项

要启用此端口，请取消选择 **启用阻塞模式** 参数。

**数据类型：** `Boolean`

本地主机的主机名、点分十进制 IP 地址或 Web 服务器。此模块支持 IPV4 和 IPV6 地址格式。

启用本地端口共享的参数。如果要允许其他 UDP 套接字绑定到同一本地端口，请选择此参数。

UDP 端口可由其他应用程序共享，以允许多个应用程序侦听该端口上的 UDP 数据报。您可以将此模块绑定到特定的 **本地端口**，并在另一个应用程序中将 UDP 套接字绑定到相同的本地端口号，以便二者都可以接收 UDP 广播数据。

在接收数据之前，配置字节顺序以匹配远程机器的相应值。有关仪器存储字节顺序的信息，请参阅仪器文档。

### **启用阻塞模式** — 仿真在接收数据时等待 `on`（默认） | `off`

此参数使仿真在模块接收数据时等待。当新数据可用时，仿真从下一个时间步继续。如果不想让读取操作导致仿真等待，请取消选择此参数。

如果启用阻塞模式，仿真将等待所请求的数据可用。在每个时间步，模型等待的最长时间由 **超时** 参数指定。如果在此时间内未收到数据，模块输出值 `0`。

如果未启用阻塞模式，仿真将持续运行，并且模块有两个输出端口 **Status** 和 **Data**。**Data** 端口包含每个时间步请求的数据集。**Status** 端口包含 0 或 1，具体取决于在给定时间步是否收到新数据。

有关详细信息，请参阅接收和发送模块中的启用阻塞模式。

## 描述

通过 UDP 网络从指定的远程机器接收数据

UDP Receive 模块使用 UDP 协议配置并打开与指定远程地址的接口。配置和初始化在模型执行开始时进行一次。模块在模型运行期间以阻塞模式或非阻塞模式获取数据。

此模块没有输入端口。根据您选择阻塞模式还是非阻塞模式，它有一个或两个输出端口。如果选择阻塞模式，模块有一个输出端口 **Data**，对应于其接收的数据。如果未选择阻塞模式，模块有两个输出端口 **Data** 和 **Status**。

UDP Receive 模块非阻塞模式和阻塞模式

此模块使用先进先出 (FIFO) 缓冲区接收数据。在每个时间步，**Data** 端口从缓冲区返回请求的值。在非阻塞模式下，**Status** 端口指示模块是否已收到新数据。如果 **Status** 端口显示 `1`，则新数据可用；如果 **Status** 端口显示 `0`，则没有新数据可用。

**注意**

您必须同时拥有 Instrument Control Toolbox™ 和 Simulink® 的许可证才能使用此模块。

### 其他支持的功能

- UDP Receive 模块支持使用 Simulink 加速器和快速加速器模式。您可以使用这些模式加快 Simulink 模型的执行速度。有关这些仿真模式的详细信息，请参阅 Acceleration (Simulink)。
- UDP Receive 模块支持使用模型引用。此功能允许您的模型将其他 Simulink 模型作为模块化组件包含在内。

有关这些功能的详细信息，请参阅 Simulink 文档。
