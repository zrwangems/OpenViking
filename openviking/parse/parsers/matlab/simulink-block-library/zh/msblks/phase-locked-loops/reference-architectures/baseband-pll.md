# Baseband PLL

## 端口

### 输入

### **In** — 来自基带 VCO 的输入信号，标量

输入信号，指定为标量。该输入信号是相位域中基带 VCO 的输出。

**数据类型：** `double`
### 输出

### **Filt** — 环路滤波器输出，标量

相位域中环路滤波器的输出，以标量形式返回。

**数据类型：** `double`

### **PD** — 相位检测器输出，标量

相位域中相位检测器的输出，以标量形式返回。

**数据类型：** `double`

### **VCO** — VCO 输出，标量

相位域中 VCO 的输出，以标量形式返回。

**数据类型：** `double`

## 参数

要交互式编辑模块参数，请使用 Property Inspector。在 Simulink® 工具条中，在 **Simulation** 选项卡的 **Prepare** 库中，选择 **Property Inspector**。

### **环路滤波器类型** — 确定如何定义环路滤波器 `Transfer function`（默认） | `2nd order passive` | `3rd order passive` | `4th order passive`

确定如何定义环路滤波器。您可以定义二阶至四阶的无源环路滤波器，也可以使用传递函数表示环路滤波器。

如果要定义无源环路滤波器，则必须定义 PLL 系统的 **电荷泵电流 (A)**、**最小时钟分频值**、**环路带宽 (Hz)** 和 **相位裕度 (degrees)**。

#### 编程用法

|  |
| --- |
| **模块参数：** `Ftype` |
| **类型：** `double` |
| **取值：** `Transfer function` | `2nd order passive` | `3rd order passive` | `4th order passive` |
| **默认值：** `Transfer function` |

### **环路带宽 (Hz)** — 开环传递函数幅值变为 1 时的频率 `50e3`（默认） | 正实数标量

开环传递函数幅值变为 1 时的频率，指定为正实数标量，单位为 Hz。**环路带宽 (Hz)** 的值越低，相位噪声和参考杂散越低，但代价是锁定时间更长、相位裕度更小。

#### 依赖关系

要启用此参数，请将 **环路滤波器类型** 设置为 `2nd order passive`、`3rd order passive` 或 `4th order passive`。

### **开环分析** — 在仿真前绘制开环分析 on（默认） | off

选择此项可在仿真前绘制 PLL 系统的零极点图、环路带宽、阶跃响应和冲激响应。要绘制 PLL 系统的阶跃响应和冲激响应，您必须拥有 Control System Toolbox™ 许可证。默认情况下，选择此选项。

## 描述

PLL 的相位域模型

Baseband PLL 模块在相位域中对 PLL 建模。该模块接受实值相位偏移向量，并产生环路滤波器、相位检测器和 VCO 的输出。该模块用作反馈控制系统，自动调整本地生成信号的相位，以匹配输入信号的相位。
