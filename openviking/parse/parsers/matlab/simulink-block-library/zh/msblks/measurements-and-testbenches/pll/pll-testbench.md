# PLL Testbench

## 端口

### 输入

### **from pll** — 输入时钟信号标量

PLL Testbench 的输入时钟信号，指定为标量。**from pll** 端口连接到 PLL 系统的输出。

**数据类型：** `double`
### 输出

### **to pll** — 输出时钟信号标量

输出时钟信号，按照 **信号类型** 参数中的指定，以 sine 或 square 波形式返回。**to pll** 端口上的信号为 PLL 系统提供激励。

**数据类型：** `double`

## 参数

### **设置停止时间** — 将推荐的最小仿真停止时间设置为模型停止时间按钮

单击以将 PLL Testbench 模块报告的 **推荐的最小仿真停止时间 (s)** 设置为模型停止时间。

#### 依赖关系

仅当在 **设置** 选项卡中选择了 **相位噪声** 测量选项时，此按钮才可用。

### **绘制相位噪声曲线** — 绘制 PLL DUT 的相位噪声曲线按钮

仿真完成后，单击以绘制 PLL 设备 (DUT) 的相位噪声曲线，并将其与用户定义的相位噪声曲线进行比较。

#### 依赖关系

仅当在 **设置** 选项卡中选择了 **相位噪声** 测量选项时，此按钮才可用。

### **导出测量结果** — 仿真后导出测量结果按钮

仿真完成后，单击以将测量结果导出到 Excel 电子表格 (XLS) 或逗号分隔值 (CSV)。

### 激励

### **幅值 (V)** — PLL 输入处激励信号的最大值 `1` (默认) | 正实数标量

PLL 输入处激励信号的最大值，指定为正实数标量。

#### 编程使用

- 使用 `get_param(gcb,'InputAmplitude')` 查看 **幅值 (V)** 的当前值。
- 使用 `set_param(gcb,'InputAmplitude',value)` 将 **幅值 (V)** 设置为特定值。

### **频率 (Hz)** — PLL 输入处激励信号的频率 `30e6` (默认) | 正实数标量

PLL 输入处激励信号的频率，指定为正实数标量。

#### 编程使用

- 使用 `get_param(gcb,'Fo')` 查看 **频率 (Hz)** 的当前值。
- 使用 `set_param(gcb,'Fo',value)` 将 **频率 (Hz)** 设置为特定值。

### **添加相位噪声** — 添加作为频率函数的相位噪声 off (默认) | on

选择以引入作为频率函数的相位噪声。默认情况下，此选项未选中。

### **相位噪声频率偏移 (Hz)** — 相位噪声相对于载波频率的频率偏移 `[500 1e3 10e3 100e3]` (默认) | 实数值向量

相位噪声相对于载波频率的频率偏移，指定为以 Hz 为单位的实数值向量。

#### 依赖关系

要启用此参数，请在 **激励** 选项卡中选择 **添加相位噪声**。

实数值向量，指定在相对于载波的指定频率偏移处，以 1 Hz 带宽为中心的相位噪声功率。该值以 dBc/Hz 为单位指定。

| **值：** 实数值向量 |

### **估计相位噪声参数** — 自动估计相位噪声参数 on (默认) | off

### **周期抖动 (S)** — 周期抖动的标准差 `4.8666e-15` (默认) | 正实数标量

周期抖动的标准差，指定为以秒为单位的正实数标量。周期抖动是时钟信号周期时间相对于理想周期的偏差。

要启用此参数，请在 **激励** 选项卡中选择 **添加相位噪声**，并取消选择 **估计相位噪声参数**。

| **类型：** character vector |
| **值：** 正实数标量 |
| **默认：** `4.8666e-15` |

**数据类型：** `double`

### **闪烁拐角频率 (Hz)** — 闪烁噪声的拐角频率 `517103.8168` (默认) | 标量

闪烁噪声的拐角频率，指定为以赫兹为单位的标量。**闪烁拐角频率 (Hz)** 定义为由于闪烁噪声，相位噪声从 1/*f*2 过渡到 1/*f*3 的频率。在该频率下，周期抖动和闪烁噪声的频谱密度相等。

## 描述

通过测量工作频率、锁定时间和相位噪声来验证 PLL 系统

PLL Testbench 模块以时钟信号形式向锁相环 (PLL) 系统提供输入激励。该测试台还通过将工作频率、锁定时间和相位噪声与目标指标进行比较，来验证 PLL 系统的性能。

PLL Testbench 模块从 **激励** 选项卡生成用于驱动被测设备 (DUT) 的激励。用于验证 DUT 的设置参数在 **设置** 选项卡中定义，目标验证指标在 **目标指标** 选项卡中定义。
