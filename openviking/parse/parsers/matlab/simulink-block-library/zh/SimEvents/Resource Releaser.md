# Resource Releaser

## 端口

### 输入

### **Port\_1** — 输入实体 标量 | 向量 | 矩阵

用于进入模块的实体的输入实体端口。

**数据类型：** `single` | `double` | `int8` | `int16` | `int32` | `int64` | `uint8` | `uint16` | `uint32` | `uint64` | `Boolean` | `enumerated` | `bus` | `fixed point`
### 输出

### **Port\_1** — 输出实体 标量 | 向量 | 矩阵

用于离开模块的实体的输出实体端口。

**数据类型：** `single` | `double` | `int8` | `int16` | `int32` | `int64` | `uint8` | `uint16` | `uint32` | `uint64` | `Boolean` | `enumerated` | `bus` | `fixed point`

### **Port\_d** — 已离开模块的实体数量 标量

已离开模块的实体数量。

#### 依赖项

要启用此端口，请单击 **统计信息** 选项卡，然后选中标记为 **已离开的实体数量，d** 的框。

**数据类型：** `double`

### **Port\_n** — 尚未离开模块的实体数量 标量

尚未离开模块的实体数量。

#### 依赖项

要启用此端口，请单击 **统计信息** 选项卡，然后选中标记为 **模块中的实体数量，n** 的框。

**数据类型：** `double`

### **Port\_ex** — 提取的实体数量 标量

从此模块中拉出的实体数量。

#### 依赖项

要启用此端口，请单击 **统计信息** 选项卡，然后选中标记为 **提取的实体数量，ex** 的框。

**数据类型：** `double`

## 参数

### **要释放的资源** — 选择要释放的资源 `All` (默认) | `Selected`

选择要释放的资源。

- `All`

  为通过的实体释放所有资源的使用。
- `Selected`

  释放选定的资源。选择此选项将启用 **可用资源** 表。

#### 编程用法

|  |
| --- |
| **模块参数**：`ResourceToRelease` |
| **类型**：character vector |
| **值**：`'All'` | `'Selected'` |
| **默认值**：`'All'` |

### **事件操作** — 指定实体在特定事件下的行为 `Entry` (默认) | `Exit` | `Blocked`

在 **事件操作** 中定义行为。例如，当实体进入模块时，将调用 **Entry** 操作。

#### 编程用法

|  |
| --- |
| **模块参数**：`EntryAction, ExitAction, BlockedAction` |
| **类型**：character vector |

| **默认值**：`''` |

## 描述

释放实体资源

当实体进入模块时，Resource Releaser 模块会释放资源。该模块接受一个实体；只要下一个模块接受该实体或 Entity Find 模块提取该实体，该实体就会立即离开该模块。

您可以指定模块释放某些资源类型，或释放所有资源。

### 可用资源

使用 **可用资源** 控件可以：

- 从模型中所有 Resource Pool 模块定义的资源中选择资源。
- 将资源添加到选定的资源表中，您可以在该表中修改它们。

该列表显示模型中的所有资源。（如果没有资源，**可用资源** 列表为空。）

如果资源列表很长，可以在文本框中键入资源名称以筛选列表。

使用 **可用资源** 区域中的按钮可帮助构建资源表。这些按钮执行以下操作。

| 按钮 | 操作 |
| --- | --- |
| 带圆形绿色箭头符号的按钮 | 刷新 **可用资源** 列表。当模块对话框打开时，该列表会随您所做的任何上游模型更改而更新。 |
| 带指向右侧的蓝色箭头的按钮 | 将选定的资源添加到 **选定的资源** 表中。 |
| 带指向左侧的蓝色箭头的按钮 | 将选定的资源从 **选定的资源** 表移到 **可用资源** 列表。如果选定的资源是您手动添加的，此按钮将变暗。 |

可用资源列表下方的消息区域会显示有关资源的其他适用消息。

| 消息 | 含义 |
| --- | --- |
| `> Resource already selected` | 您已经将该资源添加到 **选定的资源** 表中。无法再次将该资源添加到表中。 |

### 选定的资源

使用 **选定的资源** 下的控件可构建和管理要释放的资源列表。每个资源在表中显示为一行。

使用这些控件，您可以：

- 手动添加资源。
- 修改您从 **可用资源** 列表添加到表中以进行释放的资源。
- 通过将 **数量来源** 参数设置为 `Dialog` 或 `Attribute` 来选择要释放的资源数量。

  - `Dialog` — 在 **数量** 列下指定要释放的资源数量。
  - `Attribute` — 指定定义要释放资源数量的属性的名称。

**选定的资源** 下的按钮执行以下操作。

| 按钮 | 操作 | 说明 |
| --- | --- | --- |
| 带绿色加号符号的按钮 | 向表中添加模板资源。 | 重命名该资源并指定其属性。 |
| 带重叠的相同纸张符号的按钮 | 将选定资源的副本添加到表中，以用作新资源的基础。 | 重命名副本。两个资源不能具有相同的名称。 |
| 带红色叉号符号的按钮 | 从 **选定的资源** 表中删除选定的资源。 | 以这种方式删除资源时，不会显示确认，并且无法撤消该操作。 |
| 带指向向上的蓝色箭头的按钮 | 在 **选定的资源** 表中将选定的资源按顺序上移。 | 不适用 |
| 带指向向下的蓝色箭头的按钮 | 在 **选定的资源** 表中将选定的资源按顺序下移。 | 不适用 |

**注意**

如果删除某一行并应用更改，则该删除可能会影响与其他属性对应的信号输出端口。例如，如果模块具有信号输出端口 **A2**，并且您删除了端口标记为 **A1** 的属性，则该模块会将 **A2** 重新标记为 **A1**。请验证连接到重新标记的端口的任何信号是否仍按预期连接。

| 属性 | 规范 | 用法 |
| --- | --- | --- |
| **名称** | 资源的名称。每个资源必须具有唯一的名称。 | 双击现有名称，然后键入新名称。 |
| **数量来源** | 实体请求的资源数量是来自对话框还是来自属性。 | 选择 `Dialog` 或 `Attribute`。如果选择 `Attribute`，则资源数量来源于实体的属性。此选项允许每个实体获取不同数量的资源。有关详细信息，请参阅 Set Resource Amount with Attributes。 |
| **数量** | 要分配给资源的值（当资源来自对话框时）。 | 双击该值，然后键入要分配的值。此值是每个实体释放的资源数量。例如，如果 **数量** 为三，则到达 Resource Releaser 模块的每个实体都必须释放 3 个资源，然后才能离开该模块。要释放的资源的粒度与 Resource Pool 模块中资源的粒度匹配。 |
