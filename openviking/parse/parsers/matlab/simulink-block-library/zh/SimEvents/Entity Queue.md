## 参数

### **如果队列已满，则覆盖最旧的元素** — 指定队列覆盖策略 on（Simulink® 的默认值） | off（SimEvents® 的默认值）

选中此复选框可在两种队列覆盖策略之间进行选择。

- 如果选中此复选框，则当队列已满时，传入消息会覆盖最旧的元素。

  此模式表示一个简单的消息缓冲区，可用于在 Simulink 组件和生产代码之间生成异步通信。
- 如果清除此复选框，则当队列已满时，该模块不接受新消息。

  在此模式下，可以使用事件动作操作实体数据并可视化统计信息。

  要自定义实体或消息进入、离开或被阻塞时的动作，请在 **事件动作** 选项卡的 `Entry action`、`Exit action` 或 `Blocked action` 字段中输入 MATLAB® 代码。有关详细信息，请参阅 Events and Event Actions。

  有关示例，请参阅 Manage Entities Using Event Actions。

### **优先级源** — 指定实体的哪个属性决定其优先级 字符向量 | `entitySys.priority`

例如，假设您在 Entity Generator 模块的实体类型选项卡中为实体添加了两个新属性，分别名为 `height` 和 `width`。这些属性会以字符向量形式显示为 **优先级源** 参数的选项。参数值决定实体优先级。

**注意**

## 描述

将消息和实体加入队列

此模块根据到达顺序或优先级将实体或消息存储在队列中。当下游模块准备好接收时，队列头部的每个元素离开。

可以指定队列的容量以及队列已满时的策略。该模块支持三种不同的消息或队列排序策略：先进先出 (FIFO)、后进先出 (LIFO) 和优先级。仅当清除 **如果队列已满，则覆盖最旧的元素** 复选框时，才能使用优先级队列。
