# Simscape Bus

## 端口

### 守恒

### **Bus** — Simscape Bus 端口总线

连接到 Simscape Bus 线的端口，该线表示一组守恒连接线。该捆绑包含连接到模块相反侧的所有线。

默认情况下，此相反侧没有端口。可通过将连接线拖到模块的该侧，或使用模块对话框来添加端口。从子级侧进入模块的元素可以是守恒连接线或 Simscape Bus 线。每当在子级侧添加一个端口时，相应连接就会添加到模块内部的连接列表中。

## 参数

### **连接类型** — 指定或删除刚性接口 `Inherit: auto`（默认） | `Bus: <object name>` | `CompositeConnection: <domain name>` | `ConnectionBus` 对象列表

通过从下拉列表中选择端口类型来指定刚性接口。该列表包含基础工作区或数据字典中存在的 `ConnectionBus` 对象的名称。如果将新的 `ConnectionBus` 对象添加到基础工作区或数据字典，请单击下拉列表中的 **刷新数据类型**，以使新对象可供选择。要创建或修改 `ConnectionBus` 对象，请单击下拉列表旁边的 **显示类型助手** 按钮以显示 **类型助手** 面板。有关详细信息，请参阅指定刚性接口。

要指定到复合域的刚性连接，请选择 `CompositeConnection: <domain name>`，然后单击下拉列表旁边的 **显示类型助手** 按钮。在 **类型助手** 面板中，将 **模式** 设置为 `Composite domain`，然后在 `<domain name>` 字段中键入现有复合域的名称。

要删除刚性接口规范，请将 **连接类型** 参数设置为 `Inherit: auto`。

### **模式** — 指定连接模式 `Inherit`（默认） | `Connection Bus object` | `Composite domain`

与 **连接类型** 参数一起使用，并提供用于指定刚性接口的附加选项：

- `Inherit` — 表示柔性接口。唯一可用的下拉选项是 `auto`。对应于 **连接类型** 参数设置 `Inherit: auto`。
- `Connection Bus object` — 指定刚性总线连接。在 `<object name>` 字段中键入现有 `ConnectionBus` 对象的名称，或使用 **编辑** 按钮打开类型编辑器并创建或修改 `ConnectionBus` 对象。对应于 **连接类型** 参数设置 `Bus: <object name>`。
- `Composite domain` — 指定到复合域的刚性连接。在 `<domain name>` 字段中键入现有复合域的名称。对应于 **连接类型** 参数设置 `CompositeConnection: <domain name>`。

## 描述

用于守恒连接线的总线

Simscape Bus 模块将守恒连接捆绑为一条 Simscape Bus 线。也可以使用此模块访问现有 Simscape Bus 线中的一个或多个连接。物理连接线是无方向性的，因此该模块可以同时充当 Bus Creator 和 Bus Selector。通常，模型会有两个彼此相对的 Simscape Bus 模块，并且它们的总线端口相连接。

但是，模型也可以包含 Simscape Bus 模块的层级结构。

捆绑到 Simscape Bus 线中的守恒连接可以属于不同的域。

该模块仅捆绑 Simscape™ 守恒连接，即 Simscape 守恒端口或 Simscape Multibody™ 端口之间的无方向性连接线。它不适用于其他类型的连接，例如物理信号线。有关守恒连接的详细信息，请参阅物理守恒端口。

Simscape Bus 模块的两侧可以有端口：

- 父级（捆绑）侧，由黑色条带指示。此侧包含单个总线端口，该端口捆绑从子级侧进入模块的所有连接。
- 子级（元素）侧，与父级侧相对。默认情况下，此侧没有任何端口。可通过将连接线拖到模块的该侧，或使用模块对话框来添加端口。从子级侧进入模块的元素可以是守恒连接线或 Simscape Bus 线。每当在子级侧添加一个端口时，相应连接就会添加到模块内部的连接列表中。

连接名称显示在模块图标上、子级侧相应端口旁边，以及模块对话框的 **层级字符串** 列表中。如果需要，可以在对话框中或直接在图标上编辑这些名称，方法是单击并键入新名称。

模块对话框包含以下按钮：

|  |  |
| --- | --- |
|  | 将新连接名称添加到 **层级字符串** 列表。默认连接名称是 `Connection1`、`Connection2`，依此类推。可以根据需要编辑这些名称：选择一行，然后再次单击并键入新名称。使用此按钮添加连接时，模块的子级侧会出现一个圆形守恒端口，类似于 Connection Port 模块的端口。将此守恒端口连接到另一个模块上的守恒端口后，便会定义其域类型。此后，只能将相同类型的端口连接到第二条总线上的相应连接。也可以直接在画布上添加连接，方法是将连接线从另一个模块上的守恒端口拖到 Simscape Bus 模块的子级侧。 |
|  | 从 **层级字符串** 列表中删除所选连接。对于未连接的端口，也可以直接在画布上删除它们或编辑其名称。 |
|  | 在画布上添加或删除连接后，刷新 **层级字符串** 列表。 |

### 使用模型画布上的模块

要向 Simscape Bus 模块添加连接：

1. 选择另一个模块上的守恒端口。或者，要创建 Simscape Bus 模块的层级结构，请选择另一个 Simscape Bus 模块父级侧的总线端口。
2. 将连接线从所选端口拖到第一个 Simscape Bus 模块的子级侧。
3. 具有默认名称的新连接会自动添加到模块连接列表。可以根据需要在上方蓝色字段中编辑连接名称。编辑完成后，选择下方蓝色字段中的连接名称以创建该连接。

**注意**

- 一个 Simscape Bus 模块不能有多个子级连接连接到同一个端口。换言之，不能将另一个模块上的守恒端口多次连接到同一个 Simscape Bus 模块。
- 可以通过将一个 Simscape Bus 模块父级侧的总线端口连接到另一个 Simscape Bus 模块的子级端口来创建 Simscape Bus 模块的层级结构，但禁止不同 Simscape Bus 模块之间的子级连接。换言之，不能将模块上的守恒端口连接到多个 Simscape Bus 模块。

删除连接线时，模块子级侧上的相应端口不会被删除。可以通过连接另一个模块来重用它。

要删除未使用的端口：

- 选择 Simscape Bus 模块子级侧上的圆形守恒端口。确保只选择该端口，而不是整个模块。
- 从省略号菜单中选择 **删除端口**。删除端口也会删除模块连接列表中的相应名称。

### 指定刚性接口

可以通过定义刚性接口规范来锁定 Simscape Bus 模块的连接类型。使用 `Simulink.ConnectionBus` 和 `Simulink.ConnectionElement` 对象，或通过声明复合域，为守恒连接设计刚性接口规范。将此类刚性规范应用于 Simscape Bus 模块后，模块端口将按该接口确定类型，并且不接受连接到不同域类型的连接。此功能可帮助确保模型架构中的连接类型正确。

使用 **连接类型** 参数应用刚性接口规范。有关详细信息，请参阅“将刚性接口规范应用于 Simscape Bus 模块”和“自定义复合域示例”。

将刚性接口规范应用于 Simscape Bus 模块时：

- 如果该模块之前在子级侧没有端口，则该模块会自动添加与接口定义对应的子级端口。对于嵌套总线定义，仅顶层总线的第一级中的子级端口会自动出现。
- 如果该模块在子级侧已有端口，则不会覆盖这些端口，并且新端口不会自动出现。相反，该模块会根据接口定义验证现有端口的名称和类型，并在发现连接错误时报告这些错误。

将刚性接口规范应用于 Simscape Bus 模块后，模块外观会更改以指示刚性总线。总线（父级）端口具有白色中心，模块图标在左下角有一个刷新标记。

模型图中刚性 Simscape Bus 模块的外观

应用刚性接口时，如果两个 Simscape Bus 模块都是刚性的并使用相同的接口定义，或者其中一个模块是使用 `ConnectionBus` 对象的刚性总线，而另一个是柔性的（其 **连接类型** 参数设置为 `Inherit: auto`），则可以连接这两个 Simscape Bus 模块的总线（父级）端口。在这两种情况下，连接线样式（双线）表示刚性总线连接。

两个刚性 Simscape Bus 模块之间的连接线

不能连接使用复合域接口的刚性总线和柔性总线的总线端口。

要删除刚性接口规范，请将 **连接类型** 参数设置为 `Inherit: auto`。
