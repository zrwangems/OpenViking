# Beamscan Spectrum

## 端口

### 输入

### **X** — 接收信号，*M*×*N* 复值矩阵

接收信号，指定为 *M*×*N* 复值矩阵。量 *M* 是信号的长度，即信号中包含的样本值数量。量 *N* 是阵列中的传感器阵元数量。

输入矩阵第一维的大小可以变化，以模拟变化的信号长度。例如，在具有可变脉冲重复频率的脉冲波形中，大小可能会发生变化。

**数据类型：** `double`
### 输出

### **Y** — Beamscan 二维空间谱，非负实值 *P*×*Q* 矩阵

估计的二维空间谱的幅度（2Magnitude），返回为非负的，返回为实值 *P*×*Q* 矩阵。每个条目表示估计的 MUSIC 空间谱的幅度。每个条目对应于由 **方位角扫描角度 (deg)** 和 **俯仰角扫描角度 (deg)** 参数指定的角度。*P* 等于 **方位角扫描角度 (deg)** 中指定的向量长度，*Q* 等于 **俯仰角扫描角度 (deg)** 中指定的向量长度。

**数据类型：** `double`

### **Ang** — 到达方向，非负实值 2×*L* 矩阵

信号的到达方向，返回为实值 2×*L* 矩阵。*L* 是由 **信号数量** 参数指定的信号数量。到达方向角由源相对于阵列局部坐标系的方位角和俯仰角定义。矩阵的第一行包含方位角，第二行包含俯仰角。如果对象无法识别频谱中的峰值，它将返回 `NaN`。角度单位为 deg。

#### 依赖关系

要启用此输出端口，请选中 **启用 DOA 输出** 复选框。

**数据类型：** `double`

## 参数

### **信号传播速度 (m/s)** — 信号传播速度 `physconst('LightSpeed')`（默认）| 实值正标量

信号传播速度，指定为实值正标量。光速的默认值是由 `physconst('LightSpeed')` 返回的值。单位为 m/s。

**示例：** `3e8`

**数据类型：** `double`

### **工作频率 (Hz)** — 系统工作频率 `3e8`（默认）| 正实标量

系统工作频率，指定为正标量。单位为 Hz。

### **移相器中的位数** — 移相器相位量化位数 `0`（默认）| 非负整数

用于量化波束形成器或导向矢量权重的相位偏移分量的位数。将位数指定为非负整数。值为零表示不执行量化。

### **前向-后向平均** — 启用前向-后向平均 off（默认）| on

选择此参数可使用前向-后向平均来估计具有共轭对称阵列流形结构的传感器阵列的协方差矩阵。

### **方位角扫描角度 (deg)** — 方位方向的扫描角度 `-180:180`（默认）| 实值向量

方位方向的扫描角度，指定为实值向量。角度必须介于 –180° 和 180° 之间（含端点）。必须按升序指定角度。单位为 deg。

**数据类型：** `double`

### **俯仰角扫描角度 (deg)** — 俯仰方向的扫描角度 `-90:90`（默认）| 实值向量

俯仰方向的扫描角度，指定为实值向量。角度必须介于 –90° 和 90° 之间（含端点）。必须按升序指定角度。单位为 deg。

**数据类型：** `double`

### **启用 DOA 输出** — 通过输出端口输出到达方向 off（默认）| on

选择此参数可通过 **Ang** 输出端口输出信号的到达方向 (DOA)。

### **信号数量** — 预期到达信号数量 `1`（默认）| 正整数

将 DOA 估计的预期信号数量指定为正标量整数。

#### 依赖关系

要启用此参数，请选中 **启用 DOA 输出** 复选框。

**数据类型：** `double`

#### 传感器阵列选项卡

### **指定传感器阵列方式** — 指定阵列的方法 `Array (no subarrays)`（默认）| `MATLAB expression`

指定阵列的方法，指定为 `Array (no subarrays)` 或 `MATLAB expression`。

- `Array (no subarrays)` — 使用模块参数指定阵列。
- `MATLAB expression` — 使用 MATLAB 表达式创建阵列。

### **表达式** — 用于创建阵列的 MATLAB 表达式 Phased Array System Toolbox™ 阵列 System object

用于创建阵列的 MATLAB 表达式，指定为有效的 Phased Array System Toolbox 阵列 System object。

**示例：** `phased.URA('Size',[5,3])`

#### 依赖关系

要启用此参数，请将 **指定传感器阵列方式** 设置为 `MATLAB expression`。

#### 阵列参数

### **几何结构** — 阵列几何结构 `ULA`（默认）| `URA` | `UCA` | `Conformal Array`

阵列几何结构，指定为下列之一

- `ULA` — 均匀线阵
- `URA` — 均匀矩形阵
- `UCA` — 均匀圆阵
- `Conformal Array` — 任意阵元位置

### **阵元数量** — 阵列阵元数量，对于 ULA 阵列为 `2`，对于 UCA 阵列为 `5`（默认）| 大于或等于 2 的整数

ULA 或 UCA 阵列的阵元数量，指定为大于或等于 2 的整数。

#### 依赖关系

要启用此参数，请将 **几何结构** 设置为 `ULA` 或 `UCA`。

### **阵元间距 (m)** — 阵元之间的间距，对于 ULA 阵列为 `0.5`，对于 URA 阵列为 `[0.5,0.5]`（默认）| 对于 ULA 或 URA 阵列，为正标量 | 对于 URA 阵列，为 2 元素正值向量

相邻阵元之间的间距：

- ULA — 将阵列中两个相邻阵元之间的间距指定为正标量。
- URA — 将间距指定为正标量或 1×2 正值向量。如果 **阵元间距 (m)** 是标量，则行间距和列间距相等。如果 **阵元间距 (m)** 是向量，则该向量的形式为 `[SpacingBetweenArrayRows,SpacingBetweenArrayColumns]`。

#### 依赖关系

要启用此参数，请将 **几何结构** 设置为 `ULA` 或 `URA`。

### **阵列轴** — ULA 的线性轴方向 `y`（默认）| `x` | `z`

ULA 的线性轴方向，指定为 `y`、`x` 或 `z`。所有 ULA 阵元在局部阵列坐标系中沿此轴均匀分布。

#### 依赖关系

- 要启用此参数，请将 **几何结构** 设置为 `ULA`。
- 当模块仅支持 ULA 阵列时，也会启用此参数。

### **阵列大小** — URA 阵列的维度 `[2,2]`（默认）| 正整数 | 1×2 正整数向量

URA 阵列的维度，指定为正整数或 1×2 正整数向量。

- 如果 **阵列大小** 是 1×2 向量，则该向量的形式为 `[NumberOfArrayRows,NumberOfArrayColumns]`。
- 如果 **阵列大小** 是整数，则阵列在每一行和每一列中具有相同数量的阵元。

对于 URA，阵元从最左侧阵列列的顶部到底部进行索引，然后从左到右继续到下一列。在此图中，**阵列大小** 值 `[3,2]` 会创建一个具有三行两列的阵列。

#### 依赖关系

要启用此参数，请将 **几何结构** 设置为 `URA`。

### **阵元栅格** — URA 阵元位置的栅格 `Rectangular`（默认）| `Triangular`

URA 阵元位置的栅格，指定为 `Rectangular` 或 `Triangular`。

- `Rectangular` — 在行和列方向上对齐所有阵元。
- `Triangular` — 将矩形栅格的偶数行阵元向正行轴方向偏移。位移为沿行维度的阵元间距的一半。

#### 依赖关系

要启用此参数，请将 **几何结构** 设置为 `URA`。

### **阵列法线** — 阵列法线方向，对于 URA 阵列为 `x`，对于 UCA 阵列为 `z`（默认）| `y`

阵列法线方向，指定为
`x`、
`y` 或
`z`。

平面阵列的阵元位于与所选阵列法线方向正交的平面内。阵元视轴方向指向阵列法线方向。

| 阵列法线参数值 | 阵元位置和视轴方向 |
| --- | --- |
| `x` | 阵元位于 *yz* 平面内。所有阵元视轴向量都沿 *x* 轴指向。 |
| `y` | 阵元位于 *zx* 平面内。所有阵元视轴向量都沿 *y* 轴指向。 |
| `z` | 阵元位于 *xy* 平面内。所有阵元视轴向量都沿 *z* 轴指向。 |

#### 依赖关系

要启用此参数，请将 **几何结构** 设置为 `URA` 或 `UCA`。

### **UCA 半径 (m)** — UCA 阵列半径 0.5（默认）| 正标量

UCA 阵列的半径，指定为正标量。

#### 依赖关系

要启用此参数，请将 **几何结构** 设置为 `UCA`。

### **阵元位置 (m)** — 共形阵列阵元的位置 `[0;0;0]`（默认）| 3×*N* 实值矩阵

共形阵列中阵元的位置，指定为 3×*N* 实值矩阵，其中 *N* 是共形阵列中的阵元数量。此矩阵的每一列表示阵列局部坐标系中一个阵元的位置 `[x;y;z]`。局部坐标系的原点是 *(0,0,0)*。单位为 m。

#### 依赖关系

要启用此参数，请将 **几何结构** 设置为 `Conformal Array`。

**数据类型：** `double`

### **阵元法线 (deg)** — 共形阵列阵元法向量的方向 `[0;0]` | 2×1 列向量 | 2×*N* 矩阵

共形阵列中阵元法向量的方向，指定为 2×1 列向量或 2×*N* 矩阵。*N* 表示阵列中的阵元数量。如果参数值是矩阵，则每一列以 `[azimuth;elevation]` 的形式指定对应阵元相对于局部坐标系的法线方向。局部坐标系将正 *x* 轴与共形阵列的法线方向对齐。如果参数值是 2×1 列向量，则所有阵元都使用相同的指向方向。

您可以使用 **阵元位置 (m)** 和 **阵元法线 (deg)** 参数来表示阵元对之间通过特定变换而不同的任何排列。这些变换可以组合平移、方位角旋转和俯仰角旋转。但是，不能使用需要绕法线方向旋转的变换。

要启用此参数，请将 **几何结构** 设置为 `Conformal Array`。

**数据类型：** `double`

### **锥化** — 阵元锥化 1（默认）| 复标量 | 复值行向量

将阵元锥化指定为复值标量或复值 1×*N* 行向量。在此向量中，*N* 表示阵列中的阵元数量。

锥化也称为*阵元权重*，它们乘以阵列阵元响应。锥化会修改响应的幅度和相位，以减少旁瓣或控制主响应轴的方向。

如果 **锥化** 是标量，则对每个阵元应用相同的权重。如果 **锥化** 是向量，则将向量中的一个权重应用于对应的传感器阵元。权重数量必须与阵列的阵元数量匹配。

**数据类型：** `double`

## 描述

Beamscan 空间谱估计器

Beamscan Spectrum 模块通过使用窄带常规波束形成器扫描一系列方位角和俯仰角，来估计传入窄带信号的二维空间谱。该模块可选地通过定位频谱峰值来计算指定数量信号的到达方向。
