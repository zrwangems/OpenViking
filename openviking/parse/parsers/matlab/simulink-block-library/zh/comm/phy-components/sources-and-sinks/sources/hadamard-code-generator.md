### R2020a: 现有模型自动将此模块更新为当前版本

从 R2020a 开始，Simulink® 不再允许使用 R2015b 之前可用的 Hadamard Code Generator 模块版本。

现有模型自动更新以加载在“源模块输出连续时间样本的帧，但不使用帧属性”中宣布的 Hadamard Code Generator 模块版本。有关模块转发的详细信息，请参阅使用转发表保持库模块的兼容性 (Simulink)。
