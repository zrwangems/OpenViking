# C2000 Absolute IQN

绝对值

此模块计算 IQ number 输入的绝对值。输出也是 IQ number。

**注意**

此模块的实现不会在代码生成期间调用对应的 Texas Instruments® 库函数。TI 函数使用全局 Q 设置，而此模块使用的 MathWorks® 代码会根据模块输入动态调整 Q format。有关详细信息，请参阅 Using the IQmath Library。
