## 描述

评估并验证被测系统的行为

在表格形式的一系列步骤中定义测试评估。与 Test Sequence 模块一样，Test Assessment 模块使用 MATLAB® 作为动作语言。

双击 Test Assessment 模块以打开 Test Sequence Editor。默认情况下，Test Assessment 模块包含一个测试步骤 Run，其配置为 When decomposition 序列。要将转移类型更改为标准转移，请右键单击顶层步骤并清除 **When decomposition**。有关详细信息，请参阅 Test Sequence Editor。
