### **使用推荐的仿真停止时间** — 将推荐的仿真停止时间设置为仿真停止时间 on（默认）| off

选择以直接将**推荐的仿真停止时间**设置为仿真停止时间。默认情况下，此选项处于选中状态。

**推荐的仿真停止时间**定义了仿真必须运行以获得有意义结果的最短时间。它通过将 Configuration 模块中的 **采样间隔** 与 **符号数量** 相乘计算得出。

### **波形创建方法** — 定义如何创建激励波形 `Random Symbols`（默认）| `Serial PRBS` | `Symbol Pattern` | `Binary Pattern` | `Symbol Voltage Pattern` | `Sampled Voltage` | `Parallel PRBS`

定义如何创建激励波形：

- `Random Symbols` — 直接从均匀分布随机生成符号。
- `Serial PRBS` — 定义二进制序列并映射到高阶调制符号。映射序列取决于 Configuration 模块中定义的调制方案。
- `Symbol Pattern` — 直接将符号模式定义为从 0 到（调制电平数 – 1）的整数。
- `Binary Pattern` — 直接定义二进制模式并映射到高阶调制符号。映射序列取决于 Configuration 模块中定义的调制方案。
- `Symbol Voltage Pattern` — 直接定义符号间隔模式的电压。
- `Sampled Voltage` — 直接定义以采样间隔为间隔的波形。
- `Parallel PRBS` — 利用多个 PRBS 流形成 PAM4、PAM8、PAM16 和 PAM32 符号。对于 PAM32，最多可以定义 5 个 PRBS 流。NRZ 调制方案使用单个 PRBS 流。其他调制方案使用随机符号波形创建方法。

## 描述

设置 SerDes 模型中的波形生成方法和要仿真的符号数

Stimulus 定义如何创建波形以及 SerDes Toolbox™ 模型中要仿真的符号数。您可以直接指定 PAMn 符号模式，或定义二进制到 PAMn 映射方案。

当您在 SerDes IBIS-AMI Manager 对话框中启用时钟转发时，可以使用 Stimulus 模块从外部时钟时间数组或波形生成时钟时间。
