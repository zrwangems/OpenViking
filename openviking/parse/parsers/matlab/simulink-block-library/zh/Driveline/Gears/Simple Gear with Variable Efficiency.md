# Simple Gear with Variable Efficiency

## 端口

### 输入

### **E** — 啮合效率物理信号

与齿轮啮合效率关联的物理信号输入端口。该模块接受范围 (0,1] 内的效率。

### 守恒

### **B** — 基础旋转机械

与基础轴关联的机械旋转守恒端口。

### **F** — 从动轴机械旋转

与从动轴关联的机械旋转守恒端口。

### **H** — 热流热

与热流关联的热守恒端口。热流会影响齿轮温度，因此影响动力传输效率。

#### 依赖关系

要启用此端口，请将 **热端口** 设置为 `Model`。

## 参数

### 主要

### **从动轮 (F) 与基础轮 (B) 的齿数比 (NF/NB)** — 齿轮比 `2`（默认） | 正标量

齿轮比。这是从动轮齿数与基础轮齿数的比值，NF/NB。该比值必须为正。

### **输出轴旋转** — 轴旋转方向 `In opposite direction to input shaft`（默认） | `In same direction as input shaft`

轴之间的相对旋转。这是输出轴相对于输入轴的旋转方向。您可以选择相同或相反的旋转方向。

### 啮合损失

### **最小效率** — 最小效率 `0.01`（默认） | 范围 (0,1] 内的正标量

齿轮允许的最小效率值。效率是输出轴与输入轴之间的功率比。物理信号输入保持在低于最小效率或高于 1 的值。该值必须为正。

### **从动轴功率阈值** — 低于该功率时应用数值平滑 `0.001` W（默认） | 正标量

从动轴功率高于此值时，完整效率因子生效。双曲正切函数在零（静止时）和效率设定点之间平滑效率因子。

### 黏性损失

### **基础轴 (B) 和从动轴 (F) 处的黏性摩擦系数** — 流体动力摩擦系数 `[0 0]` `N*m/(rad/s)`（默认） | 正二元素向量

由基础轴和从动轴处生效的黏性摩擦系数组成的二元素数组。默认数组对应于零黏性损失。

### 热端口

### **热端口** — 是否对热效应建模 `Omit`（默认） | `Model`

是否对热效应建模，并启用端口 **H** 以实现温度相关性能。

### **热质量** — 热质量 `50` J/K（默认） | 正标量

使组件温度变化一度所需的热能。热质量越大，组件对温度变化的抵抗能力越强。

#### 依赖关系

要启用此参数，请将 **热端口** 设置为 `Model`。

### **初始温度** — 初始温度 `300` K（默认） | 正标量

仿真开始时组件的温度。初始温度会根据您指定的效率向量改变组件效率，从而影响起始啮合损失或摩擦损失。

#### 依赖关系

要启用此参数，请将 **热端口** 设置为 `Model`。

## 描述

具有平行轴旋转和可变啮合效率的齿轮组

Simple Gear with Variable Efficiency 模块表示具有可变啮合效率的简单齿轮系。该齿轮系以指定传动比在平行配置布置的基础轴和从动轴之间传递扭矩。轴旋转可以沿相同或相反方向发生。齿轮损失是可选的。它们包括啮合损失和黏性轴承损失。为指定可变啮合效率，该模块包含一个物理信号端口，您可以使用该端口输入一般时变信号。忽略惯性和柔量效应。

### Simple Gear 模型

**理想齿轮约束和齿轮比**

Simple Gear 对两个连接的轴施加一个运动学约束：

|  |  |
| --- | --- |
| *r*F*ω*F = *r*B*ωB*. | **(1)** |

从动轴-基础轴齿轮比 *g*FB = *r*F/*r*B = *N*F/*N*B。*N* 是每个齿轮上的齿数。两个自由度简化为一个独立自由度。

扭矩传递为：

|  |  |
| --- | --- |
| *g*FB*τ*B + *τ*F – *τ*loss = 0, | **(2)** |

其中在理想情况下 *τ*loss = 0。

### 非理想齿轮约束和损失

在非理想情况下，*τ*loss ≠ 0。有关非理想齿轮建模的一般注意事项，请参阅“对带损失的齿轮建模”。

### 热模型

您可以通过启用可选热端口来对热流和温度变化的影响建模。要启用该端口，请将 **摩擦模型** 设置为 `Temperature-dependent efficiency`。

### 变量

在仿真前，使用 **变量** 设置来设置模块变量的优先级和初始目标值。有关详细信息，请参阅“为模块变量设置优先级和初始目标”。
