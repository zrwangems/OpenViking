# Nonlinear Rotational Spring

## 端口

`C`
:   旋转守恒端口

`R`
:   旋转守恒端口

## 参数

**参数化**
:   选择弹簧参数化方式。选项为 `By polynomial` 和 `By table lookup`。

     按多项式

    根据多项式系数指定非线性弹簧函数。

    **对称性**
    :   在对称和双侧多项式参数化之间进行选择。

        - `Symmetric` —
          指定一组多项式系数，用于确定拉伸和压缩状态下的弹簧扭矩。

          **弹簧系数向量**
          :   输入包含多项式弹簧系数的五元素向量。最高阶非零系数必须为正。物理单位适用于第一个系数。

              默认向量为 `[1 0 0.1 0 0.01]`。默认单位为 `N*m/rad`。
        - `Two-sided` —
          指定两组用于确定弹簧扭矩的多项式系数，一组用于正变形，另一组用于负变形。

          **弹簧拉伸系数向量**
          :   输入一个五元素向量，其中包含多项式弹簧 *拉伸* 函数的系数。最高阶非零系数必须为正。指定的物理单位是第一个多项式系数的单位。

          **弹簧压缩系数向量**
          :   输入一个五元素向量，其中包含多项式弹簧 *压缩* 函数的系数。最高阶非零系数必须为正。指定的物理单位是第一个多项式系数的单位。

     按表查找

    **变形向量**
    :   输入一个向量，其中包含表查找所用的变形值。根据插值方法，该向量必须包含最少数量的元素：`Linear` 为两个，`Smooth` 为三个。该向量包含的元素数还必须与扭矩向量相同。

    **扭矩向量**
    :   输入一个向量，其中包含与变形向量值对应的扭矩值。根据插值方法，该向量必须包含最少数量的元素：`Linear` 为两个，`Smooth` 为三个。该向量包含的元素数还必须与变形向量相同。如果向量中未包含该点，模块会自动在 (0,0) 变形–扭矩坐标处添加一个点。

    **插值方法**
    :   选择用于计算表查找数据点之间变形-扭矩值的方法。

        - `Linear` — 选择此选项可获得最佳性能。
        - `Smooth` — 选择此选项可生成连续曲线，且其一阶导数连续。

        有关插值算法的详细信息，请参阅 PS Lookup Table (1D) 模块参考页。

    **外推方法**
    :   选择用于计算表查找数据范围之外变形-扭矩值的方法。

        - `Linear` — 选择此选项可生成一条曲线，该曲线在外推区域以及外推区域与插值区域的边界处具有连续的一阶导数。
        - `Nearest` — 选择此选项可生成外推结果，使其不会高于数据中的最高点，也不会低于数据中的最低点。

        有关外推算法的详细信息，请参阅 PS Lookup Table (1D) 模块参考页。

## 描述

基于多项式或表查找参数化的扭转弹簧

该模块表示具有非线性扭矩-位移曲线的扭转弹簧。弹簧扭矩的大小是位移的一般函数，不必满足胡克定律。多项式和表查找参数化提供了两种指定扭矩-位移关系的方法。弹簧扭矩可以相对于零变形对称或非对称。

对称多项式参数化根据以下表达式定义弹簧扭矩：

T=k1θ+sign(θ)⋅k2θ2+k3θ3+sign(θ)⋅k4θ4+k5θ5,

其中：

- *T* — 弹簧力
- *k*1、*k*2、...、*k*5 — 弹簧系数
- *θ* — 端口 R 和 C 之间的相对位移，θ=θinit+θR−θC
- *θ*init — 弹簧初始变形
- *θ*R — 端口 R 的绝对角位置
- *θ*C — 端口 C 的绝对角位置

在仿真开始时 (t=0)，*θ*R 和 *θ*C 均为零，因此 *θ* 等于 *θ*init。

为避免会减慢仿真速度的过零现象，请指定奇次多项式 (*b*2,*b*4 = 0)，以从多项式表达式中去除 sign 函数。

双侧多项式参数化根据以下表达式定义弹簧扭矩：

T={k1tθ+k2tθ2+k3tθ3+k4tθ4+k5tθ5,θ≥0k1cθ−k2cθ2+k3cθ3−k4cθ4+k5cθ5,θ<0,

其中：

- *k*1t、*k*2t、...、*k*5t — 弹簧拉伸系数
- *k*1c、*k*2c、...、*k*5c — 弹簧压缩系数

两种多项式参数化均使用五阶多项式表达式。要使用较低阶多项式，请将不需要的较高阶系数设置为零。要使用较高阶多项式，请拟合为较低阶多项式，或者使用表查找参数化。

表查找参数化根据一组扭矩和角速度向量定义弹簧扭矩。如果未指定，模块会自动在原点（角速度为零且扭矩为零）添加一个数据点。

### 变量

要在仿真之前设置模块变量的优先级和初始目标值，请使用模块对话框或属性检查器中的 **初始目标** 部分。有关详细信息，请参阅“设置模块变量的优先级和初始目标”。

标称值提供了一种指定模型中变量预期大小的方法。使用基于标称值的系统缩放可提高仿真的稳健性。标称值可以来自不同来源，其中之一是模块对话框或属性检查器中的 **标称值** 部分。有关详细信息，请参阅“修改模块变量的标称值”。
