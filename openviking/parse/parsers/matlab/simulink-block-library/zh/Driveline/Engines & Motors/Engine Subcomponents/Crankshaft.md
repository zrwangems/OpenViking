# Crankshaft

## 端口

### 输入

### **CylPwr** — 气缸功率数组物理信号

当模块作为子组件运行时，与气缸功率相关联的物理信号输入。

#### 依赖关系

要启用此端口，请清除 **单独输入功率**。

### **CylPwr1** — 气缸 1 功率物理信号

与气缸 1 功率相关联的物理信号输入。

#### 依赖关系

要启用此端口，请选中 **单独输入功率**。

### **CylPwr2** — 气缸 2 功率物理信号

与气缸 2 功率相关联的物理信号输入。

#### 依赖关系

要启用此端口，请将 **气缸数** 设置为 `Two Cylinders`、`Three Cylinders` 或 `Four Cylinders`，并选中 **单独输入功率**。

### **CylPwr3** — 气缸 3 功率物理信号

与气缸 3 功率相关联的物理信号输入。

#### 依赖关系

要启用此端口，请将 **气缸数** 设置为 `Three Cylinders` 或 `Four Cylinders`，并选中 **单独输入功率**。

### **CylPwr4** — 气缸 4 功率物理信号

与气缸 4 功率相关联的物理信号输入。

#### 依赖关系

要启用此端口，请将 **气缸数** 设置为 `Four Cylinders`，并选中 **单独输入功率**。

### 输出

### **CrkPos** — 曲柄位置, deg 物理信号

与曲柄位置相关联的物理信号输出，单位为 deg。

### **Spd** — 发动机转速, rad/s 物理信号

与发动机转速相关联的物理信号输出，单位为 rad/s。

### **AvrSpd** — 循环平均曲柄速度, rad/s 物理信号

与循环平均曲柄速度相关联的物理信号输出，单位为 rad/s。

### **AvrTrq** — 循环平均净指示曲轴扭矩, N\*m 物理信号

与循环平均净指示曲轴扭矩相关联的物理信号输出，单位为 Nm。

### **Trq** — 瞬时净指示曲轴扭矩, N\*m 物理信号

与瞬时净指示曲轴扭矩相关联的物理信号输出，单位为 Nm。

### 守恒

### **F** — 曲轴机械旋转

与曲轴从动件相关联的机械旋转守恒端口。

## 参数

### 机械

### **初始曲柄位置, ca0 (0-720 CAdeg)** — 仿真开始时的曲柄位置 `0` `deg` (默认) | [0,720) 范围内的非负标量

初始曲柄位置。

火花点火气缸的数量。

### **单独输入功率** — 功率输入选项 `on` (默认) | `off`

是将功率作为数组输入，还是将每个燃烧气缸分配到其自己的端口。

### **火花角差** — 两缸发动机火花角相位 `270` `deg` (默认) | 正标量

两缸发动机的火花角差。此值可因发动机而异。

要启用此参数，请将 **气缸数** 设置为 `Two Cylinders`。

### **点火顺序** — 四缸发动机的点火顺序 `1-3-4-2` (默认) | `1-3-2-4`

四缸发动机的点火顺序。点火顺序因发动机而异，但您对该参数的选择不会影响模块性能。您可以将点火顺序信息用于控制器开发。

#### 依赖关系

要启用此参数，请将 **气缸数** 设置为 `Four Cylinders`。

是否输出循环平均速度。

### **循环平均净指示扭矩** — 输出循环平均净指示扭矩的选项 `on` (默认) | `off`

是否输出循环平均净指示扭矩。

### **瞬时净指示扭矩** — 输出瞬时净指示扭矩的选项 `on` (默认) | `off`

是否输出瞬时净指示扭矩。

## 描述

连接到一个或多个活塞的内燃机曲轴

Crankshaft 模块表示抽象内燃机的曲轴组件。将此模块连接到一个或多个 SI Combustion Cylinder 模块，以计算曲轴转角解析的瞬时扭矩。

### 方程

通用扭矩-转速-功率关系支配该模块，即

τ⋅ω=P,

其中

- *τ* 是扭矩。
- *ω* 是转速，模块假定其非负。
- *P* 是功率。

模块按如下方式计算功率

P=∑i=1NPi,

其中 *N* 是 **气缸数** 参数的值。模块将 *ω* 计算为曲柄位置 *θ* 的时间导数，即

ddtθ=ω.

常数 *ωc* 是 **避免除零的阈值** 参数。当 *ω* < *ωc* 时，模块应用 1/*ω* 线性化。

τ={PωP⋅(2ω−ωωc2)ω≥ωcω<ωc

**曲柄位置**

模块针对每个燃烧气缸，计算相对于上止点位置的曲柄位置，其中 0 ≤ *θi* ≤ 720 degrees。模块执行此计算的方式取决于 *N*。对于 *N* 的所有取值，*θ1* = *θ*。对于 *N* = 2，*θ2* = *θ1*+*Δ*，其中 *Δ* 是 **火花角差** 参数。此参数值特定于您要建模的发动机。它可以是诸如 270° 或 360° 的值。当 *N* = 3 时，模块假定气缸均匀定相，使得

θ2=θ1+(1⋅7203)θ3=θ1+(2⋅7203)

当 *N* = 4 时，模块假定气缸以 180° 均匀定相，并启用 **点火顺序** 参数。
