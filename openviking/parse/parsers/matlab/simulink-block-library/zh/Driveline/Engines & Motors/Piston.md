# Piston

## 端口

### 输入

### **T** — 归一化发动机节气门开度，无量纲物理信号

指定发动机节气门设置的物理信号输入端口。
### 输出

### **FC** — 燃料消耗，kg/s 物理信号

返回燃料消耗率的物理信号输出端口。

#### 依赖关系

要启用此端口，请将 **燃料消耗模型** 设置为以下之一。

- `Constant per revolution`
- `Fuel consumption by speed and torque`
- `Brake specific fuel consumption by speed and torque`
- `Brake specific fuel consumption by speed and brake mean effective pressure`
### 守恒

### **B** — 与活塞容器机械旋转关联的基础端口

与活塞容器关联的旋转机械守恒端口。

### **F** — 与曲轴扭矩机械旋转关联的从动端口

连接到发动机曲轴的旋转机械守恒端口。

## 参数

### 主要

### **气缸内径** — 活塞气缸壁的内径 `.10` `m`（默认）| 正标量

活塞气缸壁的内径。Piston 模块使用此测量值计算扭矩表。必须指定大于零的值。

### **活塞行程** — 活塞平移运动的长度 `.06` `m`（默认）| 正标量

从活塞完全缩回位置到完全伸出位置的距离。Piston 模块使用此测量值将活塞上的压力转换为扭矩值。必须指定大于零的值。

### **活塞杆长度** — 活塞到曲轴连杆的长度 `.1` `m`（默认）| 正标量

从活塞销孔中心到活塞杆中曲轴孔中心的距离。该模块使用此测量值将活塞上的压力转换为扭矩。必须指定大于零的值。

### **每循环冲程数** — 完成一个燃烧循环所需的活塞冲程数 `4`（默认）| 正偶数标量

进气、压缩、燃烧和排出燃烧气体所需的活塞阶段数。通常，发动机为二冲程或四冲程。必须使用二的倍数。

### **压力参数化** — 用于确定施加到活塞上的压力的方法 `By crank angle`（默认）| `By crank angle and throttle` | `By crank angle, throttle, and crank velocity`

希望模块用于参数化压力数据的参数组。

### **曲轴转角向量** — 不同的活塞曲轴转角 `[-360, -90, -30, 10, 30, 90, 160, 360]` `deg`（默认）| 向量

活塞曲轴转角，从大于或等于最小角度开始，到小于或等于最大角度结束。可以通过将冲程数分别乘以 -90 度或 90 度来计算最小或最大角度。必须至少指定两个值。

**曲轴转角向量** 中的每个元素对应于 **压力向量（表压）** 中的一个元素，或对应于 **压力矩阵（表压）** 的 *M* 行，或对应于每个 **压力三维矩阵（表压）** 矩阵。

### **节气门开度向量** — 不同的节气门位置 `[0, .3, .8, 1]`（默认）| 向量

与 **压力矩阵（表压）** 或 **压力三维矩阵（表压）** 参数中的压力对应的不同节气门位置。节气门位置必须保持在 [0,1] 范围内，其中 0 表示无节气门，1 表示全节气门。

**节气门开度向量** 中的每个元素对应于 **压力矩阵（表压）** 的 *N* 列，或对应于每个 **压力三维矩阵（表压）** 矩阵。

#### 依赖关系

要启用此参数，请将 **压力参数化** 设置为 `By crank angle and throttle` 或 `By crank angle, throttle, and crank velocity`。

### **曲轴速度向量** — 不同的角速度 `[0, 1000, 6000]` `rpm`（默认）| 向量

与 **压力三维矩阵（表压）** 中的压力对应的不同曲轴速度。

**曲轴速度向量** 中的每个元素对应于 **压力三维矩阵（表压）** 的一个 *O* 矩阵。

#### 依赖关系

要启用此参数，请将 **压力参数化** 设置为 `By crank angle, throttle, and crank velocity`。

### **压力向量（表压）** — 按曲轴转角参数化的压力 `[0, 3, 20, 50, 20, 10, 8, 0]` `bar`（默认）| 向量

与不同曲轴转角位置对应的压力值向量。

#### 依赖关系

要启用此参数，请将 **压力参数化** 设置为 `By crank angle`。

### **压力矩阵（表压）** — 按曲轴转角和节气门开度参数化的压力 *M*×*N* 矩阵（默认）| 矩阵

与不同曲轴转角和节气门开度组合对应的压力值矩阵。默认值为 `[0, 0, 0, 0; 0, .9, 2.4, 3; 0, 6, 16, 20; 0, 15, 40, 50; 0, 6, 16, 20; 0, 3, 8, 10; 0, 2.4, 6.4, 8; 0, 0, 0, 0]` `bar`。

**曲轴转角向量** 的元素对应于 **压力矩阵（表压）** 中的 *M* 行。**节气门开度向量** 的元素对应于 **压力矩阵（表压）** 中的 *N* 列。

#### 依赖关系

要启用此参数，请将 **压力参数化** 设置为 `By crank angle and throttle`。

### **压力三维矩阵（表压）** — 按曲轴转角、节气门开度和曲轴速度参数化的压力 *M*×*N*×*O* 矩阵（默认）| 三维矩阵

与各种曲轴转角、节气门开度和曲轴速度组合对应的压力值拼接矩阵。默认值为 `cat(3, [0, 0, 0, 0; 0, .9, 2.4, 3; 0, 6, 16, 20; 0, 15, 40, 50; 0, 6, 16, 20; 0, 3, 8, 10; 0, 2.4, 6.4, 8; 0, 0, 0, 0], [0, 0, 0, 0; 0, .9, 2.4, 3; 0, 6, 16, 20; 0, 15, 40, 50; 0, 6, 16, 20; 0, 3, 8, 10; 0, 2.4, 6.4, 8; 0, 0, 0, 0], [0, 0, 0, 0; 0, .9, 2.4, 3; 0, 6, 16, 20; 0, 15, 40, 50; 0, 6, 16, 20; 0, 3, 8, 10; 0, 2.4, 6.4, 8; 0, 0, 0, 0])` `bar`。

**曲轴转角向量** 的元素对应于 *M* 行。**节气门开度向量** 的元素对应于 *N* 列。**曲轴速度向量** 的元素对应于沿维度 *O* 拼接的矩阵。

默认情况下，*M* = 8，*N* = 4，*O* = 3。

#### 依赖关系

要启用此参数，请将 **压力参数化** 设置为 `By crank angle, throttle, and crank velocity`。

### **轴承粘性摩擦系数** — 主轴承和连杆轴承耗散功率的趋势 `.001` `N*m/(rad/s)`（默认）| 正标量

主轴承和连杆轴承的总粘性摩擦系数。该模块使用此参数计算基础轴与从动轴之间的粘性功率损耗。

### **偏移角** — 发动机循环中点与上止点之间的角度偏差 `0` `deg`（默认）| 标量

活塞到达上止点时在发动机循环中的点。发动机循环的角度范围为从 -*S*\*180 到 +*S*\*180 度，其中 *S* 是 **每循环冲程数** 参数的值。

### **初始曲轴转角** — 仿真开始时的曲轴转角 `90` `deg`（默认）| 标量

相对于上止点位置的时间零点的曲轴转角。

### 燃料消耗

### **燃料消耗模型** — 燃料消耗的参数化 `No fuel consumption`（默认）| `Constant per revolution` | `Fuel consumption by speed and torque` | `Brake specific fuel consumption by speed and torque` | `Brake specific fuel consumption by speed and brake mean effective pressure`

用于计算燃料消耗的模型。模型参数化与标准工业数据兼容。

选择除 `No fuel consumption` 以外的任何选项都会启用 **FC** 端口及相关参数。将 **燃料消耗模型** 设置为 `No fuel consumption` 时，该模块不计算燃料消耗。选择此选项可提高仿真速度。

### **每转燃料消耗** — 单个曲轴旋转期间消耗的燃料 `25` `mg/rev`（默认）| 标量

一个曲轴旋转中消耗的燃料量。

#### 依赖关系

要启用此参数，请将 **燃料消耗模型** 设置为 `Constant per revolution`。

### **速度向量** — 曲轴角速度 `[1000, 2000, 3000, 4000, 5000, 6000]` `rpm`（默认）| 向量

用于查找表参数化的发动机速度向量。向量长度必须与 **扭矩向量** 匹配。

#### 依赖关系

要启用此参数，请将 **燃料消耗模型** 设置为以下之一：

- `Fuel consumption by speed and torque`
- `Brake specific fuel consumption by speed and torque`
- `Brake specific fuel consumption by speed and brake mean effective pressure`

### **扭矩向量** — 给定速度下施加的扭矩 `[0, 80, 160, 200, 240, 320, 360, 400]` `N*m`（默认）| 向量

用于查找表参数化的发动机扭矩向量。向量长度必须与 **速度向量** 参数匹配。

#### 依赖关系

要启用此参数，请将 **燃料消耗模型** 设置为 `Fuel consumption by speed and torque` 或 `Brake specific fuel consumption by speed and torque`。

### **燃料消耗表** — 给定速度和扭矩组合下的燃料消耗率矩阵 *P*×*Q* 矩阵（默认）| 矩阵

与发动机速度和扭矩向量对应的燃料消耗率矩阵。行数 *P* 必须等于 **速度向量** 参数中的元素数。列数 *Q* 必须等于 **扭矩向量** 参数中的元素数。默认值为 `[.5, .9, 1.4, 1.6, 1.9, 2.7, 3.4, 4.4; 1, 1.7, 2.7, 3.1, 3.6, 5, 6, 7.4; 1.4, 2.7, 4, 4.8, 5.6, 7.5, 8.5, 10.5; 2, 3.6, 5.8, 6.7, 8, 10.4, 11.7, 13.3; 2.5, 4.8, 7.9, 9.4, 10.8, 14, 16.2, 18.6; 3.1, 6, 10.3, 11.9, 13.8, 18.4, 22, 26.5]` `g/s`。

#### 依赖关系

要启用此参数，请将 **燃料消耗模型** 设置为 `Fuel consumption by speed and torque` 或 `Brake specific fuel consumption by speed and torque`。

### **制动平均有效压力向量** — 产生给定扭矩所需的平均气缸压力 `[0, 250, 500, 625, 750, 1000, 1150, 1250]` `kPa`（默认）

制动平均有效压力（BMEP）值的向量。BMEP 满足表达式：

BMEP=T⋅(2π⋅ncVd),

其中：

- *T* 是输出扭矩。
- *nc* 是每转的循环数。
- *Vd* 是气缸排量。

#### 依赖关系

要启用此参数，请将 **燃料消耗模型** 设置为 `Fuel consumption by speed and torque` 或 `Brake specific fuel consumption by speed and brake mean effective pressure`。

### **制动比燃料消耗表** — 制动比燃料消耗率的燃料效率 *P*×*Q* 矩阵（默认）| 矩阵

制动比燃料消耗（BSFC）率矩阵。BSFC 是燃料消耗率与输出功率之比。行数 *P* 必须等于 **速度向量** 参数中的元素数。列数 *Q* 必须等于 **扭矩向量** 参数中的元素数。默认值为 `[410, 380, 300, 280, 270, 290, 320, 380; 410, 370, 290, 270, 260, 270, 285, 320; 415, 380, 290, 275, 265, 270, 270, 300; 420, 390, 310, 290, 285, 280, 280, 285; 430, 410, 340, 320, 310, 300, 310, 320; 450, 430, 370, 340, 330, 330, 350, 380]` `g/hr/kW`。

将 **燃料消耗模型** 设置为 `Brake specific fuel consumption by speed and torque` 时，请输入与发动机速度和扭矩向量对应的 BSFC 率矩阵。

将 **燃料消耗模型** 设置为 `Brake specific fuel consumption by speed and brake mean effective pressure` 时，请输入与发动机速度和制动平均有效压力（BMEP）向量对应的 BSFC 率矩阵。行数必须等于 **速度向量** 参数中的元素数。列数必须等于 **制动平均有效压力向量** 参数中的元素数。

#### 依赖关系

要启用此参数，请将 **燃料消耗模型** 设置为 `Brake specific fuel consumption by speed and torque` 或 `Brake specific fuel consumption by speed and brake mean effective pressure`。

### **插值方法** — 数据点之间的速度和扭矩行为 `Linear`（默认）| `Smooth`

用于计算中间速度和扭矩值处燃料消耗的插值方法。对于这两种方法，在数据范围之外，燃料消耗保持为查找表中给定的最后一个值不变。

#### 依赖关系

要启用此参数，请将 **燃料消耗模型** 设置为以下之一：

- `Fuel consumption by speed and torque`
- `Brake specific fuel consumption by speed and torque`
- `Brake specific fuel consumption by speed and brake mean effective pressure`

## 描述

往复式内燃机的活塞机构

Piston 模块表示往复式内燃机的活塞机构。Piston 模块考虑传递到发动机曲轴的瞬时扭矩，使您能够仿真由活塞旋转引起的传动系统振动。要对多活塞发动机建模，请使用 Piston Engine 模块。

端口 **B** 表示活塞容器，例如发动机缸体，端口 **F** 表示旋转曲轴。活塞力由气缸压力和横截面积得出。该模块从查找表获取燃烧压力，该查找表按曲轴转角参数化，并可选地按曲轴角速度和发动机节气门开度参数化。

曲轴扭矩由活塞力、曲轴转角、曲轴长度和连杆长度得出。根据这些输入，活塞力与曲轴扭矩的比值为

TFFB=−c(sin(θ)+sin(2θ)2(rc)2−sin2(θ)),

其中：

- *FB* 是与基础端口关联的瞬时活塞力。
- *TF* 是与从动端口关联的瞬时曲轴扭矩。
- *c* 是曲轴长度。
- *θ* 是瞬时曲轴转角。
- *r* 是连杆长度。

**活塞尺寸**

端口 **T** 允许您将发动机节气门开度指定为 0 到 1 之间的分数。该分数对应于生成的全功率百分比。每当模块属性检查器中的压力查找表仅按曲轴转角参数化时，该模块使用点 **T** 处的数据。
