# 4-Speed CR-CR

## 端口

### 输入

### **Gear** — 挡位标量的数值输入

指定 -1 表示倒挡，0 表示空挡，1–4 表示前进挡。

**数据类型：** `single` | `double`
### 守恒

### **B** — 基轴接口机械旋转

与基轴关联的守恒端口。

### **F** — 从动轴接口机械旋转

与从动轴关联的守恒端口。

## 参数

### **初始挡位** — 仿真开始时的挡位状态 `Neutral`（默认） | `4` | `3` | `2` | `1` | `Reverse`

使用离合器调度设置离合器的初始接合或分离。当变速器处于空挡时，从基轴到从动轴没有功率流。

## 描述

四速行星架-齿圈-行星架-齿圈变速器的离合器调度

4-Speed CR-CR 模块由两个行星齿轮组和五个盘式摩擦离合器组成。从动轴连接到输出行星齿轮的行星齿轮架，以及输入行星齿轮的齿圈。这些离合器配置为实现四个传动比、一个倒挡传动比和空挡。倒挡离合器和其中两个离合器确定基轴连接到哪些齿轮。另外两个离合器用作制动器，将行星齿轮组的各个齿轮接地到变速器壳体。

此图显示了一个四速行星架-齿圈-行星架-齿圈变速器。齿轮部件的标签叠加在输入和输出齿轮上。下表列出了图中标记的齿轮和离合器部件。

| 标签 | 部件 |
| --- | --- |
| I.P.G. | 输入行星齿轮 |
| O.P.G. | 输出行星齿轮 |
| R | 齿圈 |
| C | 行星齿轮架 |
| S | 太阳轮 |
| R | 倒挡离合器 |
| A–B | 控制功率流路径的前进挡离合器 |
| C–D | 前进挡、制动离合器 |

### 传动比、离合器调度和功率流

变速器输入轴与输出轴之间的传动比由为齿轮模块指定的基本齿轮比得出。基本齿轮比为

g1=NRINSI，

和

g2=NRONSO，

其中：

- *N*RI 是输入轴侧行星齿圈的齿数。
- *N*SI 是输入轴侧行星太阳轮的齿数。
- *N*RO 是输出轴侧行星齿圈的齿数。
- *N*SO 是输出轴侧行星太阳轮的齿数。

下表显示了 4-Speed CR-CR 模块各挡位的离合器调度、传动比表达式、传动比默认值和功率流图。

离合器调度列中的字母表示制动器和离合器。值 `1` 表示锁止状态，值 `0` 表示解锁状态。离合器调度根据 Gear 端口输入信号生成这些信号。这些信号通过 Gain 模块缩放，并用作离合器模块中的致动输入。
