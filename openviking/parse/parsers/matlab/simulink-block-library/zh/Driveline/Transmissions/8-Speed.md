# 8-Speed

## 端口

### 输入

### **Gear** — 挡位标量的数值输入

指定 -1 表示倒挡，0 表示空挡，1–8 表示前进挡。

**数据类型：** `single` | `double`
### 守恒

### **B** — 基座接口机械旋转

与基座轴关联的守恒端口。

### **F** — 从动接口机械旋转

与从动轴关联的守恒端口。

## 参数

### **Initial gear** — 仿真开始时的挡位状态 `Neutral`（默认）| `8` | `7` | `6` | `5` | `4` | `3` | `2` | `1` | `Reverse`

使用离合器调度表设置离合器的初始接合或分离状态。当变速器处于空挡时，从基座轴到从动轴没有功率流。

## 描述

八速变速器的离合器调度表

8-Speed 模块由四个行星齿轮组和五个离合器组成。基座轴连接到：

- 第二行星齿轮的行星齿轮架
- 通过三个离合器连接到其他齿轮，这些离合器决定功率流路径。

从动轴连接到第一和第四行星齿轮的行星齿轮架。另外两个离合器用作制动器，将第二和第三行星齿轮组的各个齿轮接地到变速器壳体。

此图显示了一个八速变速器。齿轮组件的标签叠加在输入和输出齿轮上。下表列出了图中标注的齿轮和离合器组件。

| P.G.1–P.G.4 | 行星齿轮，1–4 |
| R | 齿圈 |
| C | 行星齿轮架 |
| S | 太阳轮 |
| C–E | 控制功率流路径的前进离合器 |
| A–B | 前进制动离合器 |

### 传动比、离合器调度表和功率流

变速器输入轴和输出轴之间的传动比由齿轮模块指定的基本齿轮比决定。基本齿轮比为

gx=NRxNSx，

其中：

- *N*Rx
  是行星齿圈 x 的齿数，其中 x = 1、2、3 和 4。
- *N*Sx
  是行星太阳轮 x 的齿数，其中 x = 1、2、3 和 4。

下表显示了 8-Speed 模块每个挡位的离合器调度表、传动比表达式、传动比默认值和功率流图。调度表和齿轮比基于 GM 8L90 八速自动变速器的制造商数据。

离合器调度表列中的字母表示制动器和离合器。值为 `1` 表示锁定状态，值为 `0` 表示解锁状态。离合器调度表根据 Gear 端口输入信号生成这些信号。这些信号通过 Gain 模块进行缩放，并用作离合器模块中的致动输入。
