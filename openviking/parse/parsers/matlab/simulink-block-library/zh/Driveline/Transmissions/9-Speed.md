# 9-Speed

## 端口

### 输入

### **Gear** — 挡位标量的数值输入

为倒挡指定 -1，为空挡指定 0，为前进挡指定 1–9。

**数据类型：** `single` | `double`
### 守恒

### **B** — 基座接口机械旋转

与基轴关联的守恒端口。

### **F** — 从动接口机械旋转

与从动轴关联的守恒端口。

## 参数

### **Initial gear** — 仿真开始时的挡位状态 `Neutral`（默认）| `9` | `8` | `7` | `6` | `5` | `4` | `3` | `2` | `1` | `Reverse`

使用离合器排程设置离合器的初始接合或分离。当变速器处于空挡时，没有动力从基轴流向从动轴。

## 描述

九速变速器的离合器排程

9-Speed 模块由四个行星齿轮组和六个离合器组成。从动轴连接到第四行星齿轮的行星齿轮架。其中三个离合器确定基轴的动力流路径。另外三个离合器用作制动器，将行星齿轮组的各个齿轮接地到变速器壳体。

此图显示了一个九速变速器。齿轮组件的标签叠加在输入和输出齿轮上。下表列出了图中标注的齿轮和离合器组件。

| 标签 | 组件 |
| --- | --- |
| P.G.1–P.G.4 | 行星齿轮，1–4 |
| R | 齿圈 |
| C | 行星齿轮架 |
| S | 太阳轮 |
| A, B, E | 控制动力流路径的前进离合器 |
| C, D, F | 前进、制动离合器 |

### 传动比、离合器排程和动力流

变速器输入轴和输出轴之间的传动比由为齿轮模块指定的基本齿轮比得出。基本齿轮比为

gx=NRxNSx,

其中：

- *N*Rx
  是行星齿圈 x 的齿数，其中 x = 1、2、3 和 4。
- *N*Sx
  是行星太阳轮 x 的齿数，其中 x = 1、2、3 和 4。

下表显示了 9-Speed 模块每个挡位的离合器排程、传动比表达式、传动比默认值和动力流图。该排程和齿轮比基于 ZF 9HP 九速自动变速器的制造商数据。

离合器排程列中的字母表示制动器和离合器。值 `1` 表示锁定状态，值 `0` 表示解锁状态。离合器排程基于 Gear 端口输入信号生成这些信号。这些信号通过 Gain 模块进行缩放，并用作离合器模块中的致动输入。
