# Unidirectional Clutch

## 端口

### 守恒

### **H** — 轮毂速度 机械旋转

轮毂传动轴轴线的速度。

### **R** — 环速度 机械旋转

环传动轴轴线的速度。

## 参数

### **传动方向** — 相对旋转方向 `From hub to ring for positive rotation`（默认）| `From hub to ring for negative rotation`

离合器锁止并传递扭矩所对应的相对旋转方向。

### **初始状态** — 离合器初始状态 `Unlocked`（默认）| `Locked`

仿真开始时的离合器状态。离合器可以处于两种状态之一：锁止和未锁止。锁止的离合器约束基轴和从动轴以相同速度旋转，即作为一个整体旋转。未锁止的离合器允许两根轴以不同速度旋转，从而导致离合器片之间滑移。

## 描述

单向传递动力的离合器

Unidirectional Clutch 模块基于耦合的环-轮毂对理想单向离合器进行建模。当轮毂与环的相对速度变为正值或负值时，该模块传递扭矩，具体取决于您如何设置传动方向。有关模型详细信息，请参阅方程。

### 方程

图中显示了单向离合器的几何结构。表总结了单向离合器的变量。

如果锁止，离合器将扭矩从轮毂传递到环。如果未锁止，离合器不传递扭矩。离合器不存在未锁止但接合（传递扭矩）的状态。相对角速度（滑移），*ω*，是轮毂角速度 *ωH* 相对于环速度 *ωR* 的角速度，即 *ω*=*ωH* – *ωR*。

Unidirectional Clutch 模块实现单向离合器的理想模型，不包含任何内部动力学，例如滚子和弹簧。

**锁止条件**

传动方向决定锁止条件。

- 如果选择正向传动，则当 *ω* = *ω*H – *ω*R ≥ 0 且从正值变为零时，离合器锁止。随后滑移 *ω* 保持为零，并且离合器传递扭矩。

  如果传动系动力学随后在仿真中导致 *ω* < 0，则离合器会突然解锁并停止传递扭矩。
- 如果选择负向传动，则当 *ω* = *ω*H – *ω*R ≤ 0 且从负值变为零时，离合器锁止。随后滑移 *ω* 保持为零，并且离合器传递扭矩。

  如果传动系动力学随后在仿真中导致 *ω* > 0，则离合器会突然解锁并停止传递扭矩。

例如，正向锁止和扭矩传递如下。

- 当轮毂比环旋转得更快（*ω* > 0）时，轮毂和环之间预先设置的微小间隙被消除。弹簧加载的滚子楔入轮毂和环之间，使两者接触、锁止并一起旋转；*ω* 重置为零。（图中的旋转约定为顺时针。）
- 如果环比轮毂旋转得更快（*ω* < 0），则滚子被推离接触，离合器解锁。

有关离合器示意图，请参阅方程。

**离合器耗散的功率**

单向离合器是理想的，不耗散功率。离合器要么未锁止并且不施加动摩擦，要么锁止（无滑移）并且仅施加静摩擦。
