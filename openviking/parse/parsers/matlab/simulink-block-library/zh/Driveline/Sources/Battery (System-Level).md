# Battery (System-Level)

## 端口

### 守恒

### **+** — 正极端子电气

与电池正极端子关联的电气守恒端口。

### **-** — 负极端子电气

与电池负极端子关联的电气守恒端口。

### **H** — 传热热

与热传递关联的热守恒端口。

#### 依赖关系

要显示此端口，请将 **热端口** 设置为
`Model`。

## 参数

### 主要

### **额定电压，Vnom** — 电池完全充电时的输出电压 `12` `V`（默认）| 正标量

电池完全充电时其两端的空载电压。

### **内部电阻** — 电池内部电阻 `2` `Ohm`（默认）| 正标量

电池的内部连接电阻。

### **电池充电容量** — 用于模拟放电的选项 `Infinite`（默认）| `Finite`

用于模拟有限或无限电池充电容量的选项。

### **电池单体容量（Ah 额定值）** — 额定电池容量 `50` `A*hr`（默认）| 正标量

最大电池充电量。Ampere-hours 指电池能够以 1 Amp 放电的小时数。您可以将初始充电目标指定为变量。

#### 依赖关系

要启用此参数，请将 **电池充电容量** 设置为 `Finite`。

### **当充电量为 AH1 时的电压 V1** — 充电水平为 AH1 时的输出电压 `11.5` `V`（默认）| 正标量

当充电水平等于 **当空载电压为 V1 时的充电量 AH1** 时，电池的基本输出电压。

#### 依赖关系

要启用此参数，请将 **电池充电容量** 设置为 `Finite`。

### **当空载电压为 V1 时的充电量 AH1** — 空载输出电压为 V1 时的充电水平 `25` `A*hr`（默认）| 正标量

与您为 **当充电量为 AH1 时的电压 V1** 参数指定的空载输出电压对应的电池充电水平。

#### 依赖关系

要启用此参数，请将 **电池充电容量** 设置为 `Finite`。

### **自放电** — 用于模拟自放电电阻的选项 `Disabled`（默认）| `Enabled`

用于模拟自放电电阻的选项。该模块通过一个跨接电池端子的电阻来模拟此效应。

#### 依赖关系

要启用此参数，请将 **电池充电容量** 设置为 `Finite`。

### **自放电电阻** — 表示电池自放电的电阻 `2000` `Ohm`（默认）| 正标量

跨接电池端子、表示自放电的电阻。

#### 依赖关系

要启用此参数，请将 **电池充电容量** 设置为 `Finite`，并将 **自放电** 设置为 `Enabled`。

### 热端口

### **热端口** — 用于模拟热效应的选项 `Omit`（默认）| `Model`

用于显示热端口并在模型中包含热效应的选项。

### **热质量** — 电池的热质量 `30000` `J/K`（默认）

使组件温度变化一度所需的热能。热质量越大，组件对温度变化的抵抗能力越强。

## 描述

通用系统级电池

Battery (System-Level) 模块表示一个通用自放电电池。您可以使用该模块以中等保真度对混合动力和纯电动汽车驱动进行驱动循环分析。该模块是 Battery (Simscape Electrical) 模块的简化版本，并在适用时使用相同的参数。如有必要，这将有助于您过渡到更高保真度的模型。Battery (System-Level) 不支持电池衰减、老化、动态或温度相关特性。您可以使用 Battery (Simscape Electrical) 模块访问这些功能。

您可以选择模拟具有有限或无限充电量的电池。该模块还可以帮助您确定电压下降如何影响性能和控制要求。要详细了解如何观察电池性能，请参阅 Plot Basic Voltage-Charge Characteristics of Battery Blocks (Simscape Electrical)。

### 电池模型

当您将 **电池充电容量** 设置为 `Infinite` 时，该模块将电池视为一个电阻与一个恒定电压源串联。当您将 **电池充电容量** 设置为 `Finite` 时，该模块将电池视为一个电阻与一个取决于充电量的电压源串联。在这种情况下，电压是充电量的函数，并具有以下关系：

V=V0SOC1−β(1−SOC)

其中：

- `SOC`（荷电状态）是当前充电量与额定电池容量之比。
- *V*0 是电池完全充电且空载时的电压，由 **额定电压，Vnom** 参数定义。
- *β* 是一个常数，其计算方式是使充电量为 *AH1* 时电池电压为 *V1*。使用模块参数指定电压 *V1* 和安培小时额定值 *AH1*。*AH1* 是空载（开路）电压为 *V1* 时的充电量，并且 *V1* 小于额定电压。

该方程定义了电压与剩余充电量之间的近似关系。此近似可再现低充电量时电压下降速率的增加，并确保充电水平为零时电池电压为零。该模型的优点是所需参数很少，这些参数通常可在制造商数据表中获得。

### 变量

要在仿真之前设置模块变量的优先级和初始目标值，请使用模块对话框或属性检查器中的 **初始目标** 部分。有关详细信息，请参阅 Set Priority and Initial Target for Block Variables。

标称值提供了一种在模型中指定变量预期量级的方法。使用基于标称值的系统缩放可提高仿真稳健性。标称值可以来自不同来源，其中之一是模块对话框或属性检查器中的 **标称值** 部分。有关详细信息，请参阅 Modify Nominal Values for a Block Variable。

### 假设和限制

该模块假设自放电电阻不依赖于放电循环次数。
