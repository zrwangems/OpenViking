# Rotational Detent

## 端口

**R** 和 **C** 是分别与杆和壳体关联的旋转守恒端口。

## 参数

### 定位机构特性

**参数化方式**
:   选择如何指定定位机构特性。默认值为
    `By peak torque and notch width`。

    - `By peak torque and notch width` —
      通过峰值转矩和凹槽宽度指定定位机构特性。

       峰值转矩和凹槽宽度

      **峰值转矩**
      :   定位机构内部产生的峰值转矩。
          默认值为 `0.25`。

          从下拉列表中选择单位。
          默认单位为 newton-meters
          (`N*m`)。

      **凹槽宽度**
      :   产生转矩的区域宽度。默认值为
          `5`。

          从下拉列表中选择单位。
          默认单位为 degrees
          (`deg`)。
    - `By table lookup` — 根据滑块与壳体之间的相对位移，通过一维查表定义定位机构特性。如果选择此选项，面板将从默认选项切换。

       查表

      **相对旋转向量**
      :   指定与 **转矩向量** 中的值相对应的输入相对旋转向量。
          这两个向量必须具有相同的大小。
          角度必须按严格递增顺序指定。默认值为
          `[-5.0 -4.0 -3.0 -1.0 1.0 3.0 4.0 5.0]`。

          从下拉列表中选择单位。
          默认单位为 degrees
          (`deg`)。

      **转矩向量**
      :   指定所产生转矩的输入值向量，这些值与
          **相对旋转向量** 中的值相对应。
          默认值为 `[0 0 -0.25 -0.10 0.10 0.25 0 0]`。

          从下拉列表中选择单位。
          默认单位为 newton-meters
          (`N*m`)。

      **初始相对旋转**
      :   仿真开始时杆与壳体的相对角度。默认值为
          `0`。

          从下拉列表中选择单位。
          默认单位为 degrees
          (`deg`)。

      **插值方法**
      :   选择以下插值方法之一，用于在输入值位于两个连续网格点之间时近似计算输出值：

          - `Linear` —
            选择此默认选项可获得最佳性能。
          - `Smooth` —
            选择此选项可生成连续曲线，且其一阶导数连续。

          有关插值算法的详细信息，请参阅 PS Lookup
          Table (1D) 模块参考页。

### 间距

**定位机构间距**
:   选择如何指定定位机构间距。默认值为
    `Regularly spaced`。

    - `Regularly spaced` — 按固定间隔指定定位机构间距。

       固定间距

      **定位机构数量**
      :   指定相同且等间距的定位机构数量。
          必须大于或等于 1。默认值为 `1`。

          创建多个在 –180 到 +180 degrees 之间均匀分布的定位机构，其中一个定位机构的中心位于 0
          degrees。非整数值将四舍五入为最接近的整数。
    - `By angle vector` — 按自定义间隔指定定位机构间距。如果选择此选项，面板将从默认选项切换。

       自定义间隔

      **定位机构中心向量**
      :   以角度向量的形式指定相同定位机构中心的位置。
          这些值必须介于 –180 和 +180 degrees 之间。
          定位机构之间的最小间距必须大于
          **凹槽宽度** 参数。默认值为 `[-40 0 30 85]`。

          从下拉列表中选择单位。
          默认单位为 degrees
          (`deg`)。

### 摩擦

**粘性摩擦系数**
:   指定杆与壳体接触处的粘性摩擦系数。
    必须大于或等于 0。默认值为
    `0.1`。

    从下拉列表中选择单位。默认单位为
    newton-meters/(radians/second) (`N*m/(rad/s)`)。

**摩擦与峰值转矩之比**
:   指定杆与壳体接触处的动摩擦系数。
    必须大于或等于 0。默认值为
    `0.01`。

    动摩擦为该比率与峰值转矩的乘积。

**摩擦速度阈值**
:   指定定位机构中达到峰值动摩擦所需的相对角速度。
    必须大于 0。默认值为
    `10`。

    从下拉列表中选择单位。默认单位为
    revolutions/minute (`rpm`)。

## 描述

双侧弹簧加载式旋转定位机构

Rotational Detent 模块表示一个双侧弹簧加载式旋转定位机构。

定位杆相对于定位机构壳体旋转。壳体具有凹槽或磁体，杆旋转时，这些凹槽或磁体会在杆与壳体之间产生净相对转矩。使用该模块，可以通过峰值转矩和凹槽宽度或通过查表对旋转定位机构进行建模。该模型还包括杆与壳体之间的粘性阻尼和动摩擦。可以将摩擦设置为零。
