# TCP Receive

## 端口

### 输出

### **Data** — 输出数据向量

在每个时间步，该端口输出数据，其形式为在 **数据大小 (N)** 参数中指定大小的向量。有关详细信息，请参阅接收 TCP 数据。

**数据类型：** `int8` | `uint8` | `int16` | `uint16` | `int32` | `uint32` | `single` | `double` | `Boolean`

### **Status** — 在给定时间步接收到所请求的数据 `0` | `1`

在每个时间步，当接收到的数据长度大于或等于 **数据大小 (N)** 参数中指定的长度时，该端口输出 `0`。否则，它输出 `1`，表示没有接收到新数据。

有关详细信息，请参阅接收 TCP 数据。

**数据类型：** `uint16`

## 参数

#### 主要

### **连接模式** — 将模块设置为服务器或客户端 `Server`（默认）| `Client`

将该模块设置为 TCP/IP 服务器或客户端。

当将此参数设置为 `Server` 时，必须提供 **本地 IP 端口**。本地端口用作 TCP/IP 服务器的侦听端口。

当将此参数设置为 `Client` 时，必须提供要从中接收数据的 TCP/IP 服务器的 **远程 IP 地址** 和 **远程 IP 端口**。

### **本地 IP 端口** — 接收主机的 IP 端口，从该主机接收数据 `25001`（默认）| [1 到 65,535]

此本地端口号用作接收主机的侦听端口。将本地端口号与发送主机的远程端口号匹配。

### **远程 IP 地址** — 从中接收数据的服务器的远程 IP 地址 `192.168.1.2`（默认）| 任何有效 IP 地址

指定从中接收数据的服务器的 IP 地址。

#### 依赖关系

仅当将 **连接模式** 参数设置为 `Client` 时，此参数才会出现。

### **远程 IP 端口** — 从中接收数据的服务器的远程 IP 端口 `25000`（默认）| [1 到 65,535]

指定从中接收数据的服务器的端口号。

#### 依赖关系

仅当将 **连接模式** 设置为 `Client` 时，此参数才会出现。

### **数据类型** — 接收数据的类型 `uint8`（默认）| `double` | `single` | `int8` | `int16` | `uint16` | `int32` | `uint32` | `boolean`

指定该模块从发送主机接收的数据类型。每个元素的大小取决于其数据类型。

### **数据大小 (N)** — 接收数据中的字节数 `1`（默认）| 任何正整数

每个时间步要接收的字节数。

### **采样时间** — 模块从发送主机读取数据的时间间隔 `0.1`（默认）| 任何非负值

当将此参数设置为 `-1` 时，Simulink® 会根据模型中的模块上下文确定该模块的最佳采样时间。

#### 高级

### **等待直到接收到数据** — 等待直到所请求的数据可用 on（默认）| off

- 选择此选项时，读取操作以阻塞模式运行。在等待所请求的数据可用时，读取操作会被阻塞。读取时，如果数据不可用，该模块会等待 **超时时间（秒）** 参数中指定的时间。有关阻塞模式下输出端口值的详细信息，请参阅接收 TCP 数据。

  如果目标硬件在下一个读取操作计划开始时仍在等待数据可用，则会发生任务超限。

  要修复超限：

  - 使用 **采样时间** 参数增加时间步。
  - 使用 **数据大小 (N)** 参数减少所请求数据的长度。
- 清除此选项时，读取操作以非阻塞模式运行。在此模式下，该模块不会等待所请求的数据可用。有关非阻塞模式下输出端口值的详细信息，请参阅接收 TCP 数据。

### **超时时间（秒）** — 等待直到接收到数据的时间 `0.1`（默认）| `Inf` | 任何非负值

指定该模块在每个时间步等待数据可用的时间量。如果发生超时，读取操作将中止。

#### 依赖关系

仅当选择 **等待直到接收到数据** 参数时，此参数才可用。

### 接收 TCP 数据

本节说明在阻塞和非阻塞模式下输出端口的值，其中以下模块参数指定为：

| 模块参数 | 值 |
| --- | --- |
| **数据类型** | `uint8` |
| **数据大小 (N)** | `4` |

输出端口的值取决于接收到的数据长度是小于、大于还是等于所请求数据的长度。

- 接收到的数据长度 = 数据大小 (N)：**Data** 端口输出在 **数据大小 (N)** 参数中指定大小的数据向量。**Status** 端口输出 `0`，表示已接收到所请求的数据。

  假设接收到的数据长度为 4。在这种情况下，**Data** 端口输出大小为 4 且填充了接收数据字节的数据向量。**Status** 端口输出 `0`。
- 接收到的数据长度 < 数据大小 (N)：在阻塞模式下，该模块等待数据可用，持续时间为 **超时时间（秒）** 秒。如果数据在 **超时时间（秒）** 秒内变为可用，**Data** 端口输出在 **数据大小 (N)** 参数中指定大小的数据向量。**Status** 端口输出 `0`，表示接收到新数据。如果等待时间超过 **超时时间（秒）**，**Data** 端口输出在 **数据大小 (N)** 参数中指定大小且填充为零的数据向量。**Status** 端口输出 `1`，表示没有接收到新数据。

  在非阻塞模式下，该模块不会等待所请求的数据可用。**Data** 端口输出在 **数据大小 (N)** 参数中指定大小且填充为零的数据向量。**Status** 端口输出 `1`，表示没有接收到新数据。
- 接收到的数据长度 > 数据大小 (N)：**Data** 端口输出在 **数据大小 (N)** 参数中指定大小的数据向量。该向量仅包含数据中的前 *N* 个字节。其余字节将在下一个时间步与数据字节一起发出。**Status** 端口输出 `0`，表示已接收到所请求的数据。

  假设接收到的数据长度为 5 个字节。在这种情况下，**Data** 端口输出大小为 4 的数据向量。该向量仅包含接收数据中的前 4 个字节。第五个字节将在下一个时间步与数据字节一起发出。**Status** 端口输出 `0`。

## 描述

通过 TCP/IP 网络从远程主机接收数据

TCP Receive 模块通过有线网络从远程主机或其他目标硬件接收数据。当将 **连接模式** 设置为 `Server` 时，必须提供 **本地 IP 端口**。**本地 IP 端口** 用作 TCP/IP 服务器的侦听端口。当将 **连接模式** 设置为 `Client` 时，必须提供要从中接收数据的服务器的 **远程 IP 地址** 和 **远程 IP 端口**。

该模块有两个输出端口，**Data** 和 **Status**。在每个采样时间，**Data** 端口输出数据，其形式为在 **数据大小 (N)** 参数中指定大小的向量。

当接收到的数据长度大于或等于 **数据大小 (N)** 参数中指定的长度时，**Status** 端口输出 `0`。否则，它输出 `1`，表示没有新数据可用。

在没有硬件的仿真期间，该模块输出零。

**注意**

在某些情况下，防病毒软件或防火墙可能会阻止 TCP 流量。如果是这样，请配置防病毒软件或防火墙以允许特定 IP 端口号的流量。

该模块可以以阻塞模式或非阻塞模式接收数据。

在阻塞模式下，模型在等待所请求的数据可用时会阻塞执行。

阻塞模式

在时间步 1，该模块请求四个数据值，TCP/IP 接收缓冲区获得四个数据值。执行运行。

在时间步 2，该模块再次请求数据，但 TCP/IP 接收缓冲区只获得三个数据值。执行暂停，直到缓冲区收到第四个数据值或超时值耗尽。然后，执行恢复。

在时间步 3，该模块请求数据，缓冲区收到五个数据值。该模块返回前四个数据值，剩余的数据值将在下一个接收周期中使用。

在非阻塞模式下，模型连续运行。

非阻塞模式

在时间步 1，该模块请求数据，缓冲区获得四个数据值。该模块将 **Status** 端口值更改为 0，表示有新请求的数据可用。此时，**Data** 端口包含新接收的数据值。该模块将 **Data** 端口值重置为 0。

在时间步 2，该模块再次请求数据，但缓冲区只获得三个值。由于数据大小指定为 4，该模块无法返回 3 个值。因此，该模块将 **Status** 端口值设置为 1，表示没有新数据。**Data** 端口上的所有值变为 0。此时，缓冲区有三个数据值。但是，在此阶段，与阻塞模式不同，执行不会停止。

在时间步 3，缓冲区有五个数据值，该模块按接收顺序返回前四个数据值，并将 **Status** 端口值更改为 0。剩余的数据值将在下一个接收周期中使用。
