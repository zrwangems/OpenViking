## 参数

**车轮半径**
:   机器人车轮的半径。此参数不限定单位。

**轮距**
:   两个车轮之间的间距或车轴长度。此参数不限定单位。

**场地范围**
:   方形场地的边长。此参数不限定单位。

## 描述

查看两轮机器人的仿真速度值

在 XY 图中查看两轮机器人右轮和左轮的仿真速度值。该模块仅适用于仿真。这两个速度值以图形方式显示为机器人在矩形场地中移动的轨迹路径，并显示该场地的俯视图。

在代码生成期间，Field Simulator 模块会被忽略，并且不会影响生成的代码。
