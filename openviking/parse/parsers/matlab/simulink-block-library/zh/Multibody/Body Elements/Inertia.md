# Inertia

## 端口

### 坐标系

### **R** — 参考坐标系 frame

惯性元件的局部参考坐标系。连接到坐标系连线或坐标系端口，以定义惯性的相对位置和方向。

## 参数

### 惯性

### **Type** — 要使用的惯性参数化 `Point Mass`（默认） | `Custom`

要使用的惯性参数化。选择 `Point Mass` 表示无转动惯量的质量。选择 `Custom` 表示具有转动惯量的分布质量。

### **Mass** — 实体元件的总质量 `1 kg`（默认） | 具有质量单位的标量

要赋予实体元件的总质量。此参数可以为正或负。使用负值来捕获复合体（由多个实体和惯性组成）中的空隙或空腔效应，同时注意确保该体的总质量为正。

### **Custom: Center of Mass** — 质心坐标 `[0 0 0] m`（默认） | 具有长度单位的三元素向量

相对于模块参考坐标系的质心 [x y z] 坐标。仅在均匀引力场中，质心与重心重合。

### **Custom: Moments of Inertia** — 惯性张量的对角元素 `[1 1 1] kg*m^2`（默认） | 具有质量\*长度^2 单位的三元素向量

三元素向量，包含 [Ixx Iyy Izz] 转动惯量，相对于原点位于质心且轴平行于模块参考坐标系的坐标系指定。转动惯量是惯性张量的对角元素

(IxxIyyIzz),

其中：

- Ixx=∫m(y2+z2) dm
- Iyy=∫m(x2+z2) dm
- Izz=∫m(x2+y2) dm

### **Custom: Products of Inertia** — 惯性张量的非对角元素 `[0 0 0] kg*m^2`（默认） | 具有质量\*长度^2 单位的三元素向量

三元素向量，包含 [Iyz Izx Ixy] 惯性积，相对于原点位于质心且轴平行于模块参考坐标系的坐标系指定。惯性积是惯性张量的非对角元素

(IxyIzxIxyIyzIzxIyz),

其中：

- Iyz=−∫myz dm
- Izx=−∫mzx dm
- Ixy=−∫mxy dm

### 图形

### **Type** — 用于惯性可视化中的图形 `Marker`（默认） | `None`

用于惯性可视化的图形类型，指定为 `Marker` 或 `None`。将此参数设置为 `Marker` 可将惯性表示为标记，将此参数设置为 `None` 可在模型可视化中隐藏惯性。

### **Shape** — 用于表示惯性的标记形状 `Inertia Icon`（默认） | `Sphere` | `Cube` | `Frame`

标记的形状，指定为 `Inertia Icon`、`Sphere`、`Cube` 或 `Frame`。标记的运动反映惯性自身的运动。

#### 依赖关系

要启用此参数，请将 **Type** 设置为 `Marker`。

### **Size** — 标记的宽度（以像素为单位） 20 `pixels`（默认） | 标量

标记的宽度（以像素为单位），指定为标量。此宽度不随缩放级别缩放。请注意，标记的表观大小部分取决于屏幕分辨率，分辨率越高，每单位长度包含的像素越多，因此生成的图标越小。

#### 依赖关系

要启用此参数，请将 **Type** 设置为 `Marker`。

### **Visual Properties** — 颜色和不透明度的参数化 `Simple`（默认） | `Advanced`

用于指定视觉属性的参数化。选择 `Simple` 可指定 **Diffuse Color** 和 **Opacity**。选择 `Advanced` 可指定更多视觉属性，例如 **Specular Color**、**Ambient Color**、**Emissive Color** 和 **Shininess**。

#### 依赖关系

要启用此参数，请将 **Type** 设置为 `Marker`。

### **Diffuse Color** — 漫反射产生的光颜色 [0.5 0.5 0.5]（默认） | 值在 0 到 1 范围内的 3×1 或 1×3 向量 | 值在 0 到 1 范围内的 4×1 或 1×4 向量

漫反射产生的光颜色，指定为值在 0 到 1 范围内的 [R,G,B] 或 [R,G,B,A] 向量。该向量可以是行向量或列向量。可选的第四个元素指定颜色不透明度。省略不透明度元素等效于指定值 1。

#### 依赖关系

要启用此参数，请将 **Type** 设置为 `Marker`。

### **Opacity** — 图形不透明度 1.0（默认） | 0 到 1 范围内的标量

图形不透明度，指定为 0 到 1 范围内的标量。标量 0 对应完全透明，标量 1 对应完全不透明。

#### 依赖关系

要启用此参数，请设置：

1. 将 **Type** 设置为
   `Marker`
2. 将 **Visual Properties** 设置为
   `Simple`

### **Specular Color** — 镜面反射产生的光颜色 [0.5 0.5 0.5 1.0]（默认） | 值在 0 到 1 范围内的 3×1 或 1×3 向量 | 值在 0 到 1 范围内的 4×1 或 1×4 向量

镜面反射产生的光颜色，指定为值在 0 到 1 范围内的 [R,G,B] 或 [R,G,B,A] 向量。该向量可以是行向量或列向量。可选的第四个元素指定颜色不透明度。省略不透明度元素等效于指定值 1。

#### 依赖关系

要启用此参数，请设置：

1. 将 **Type** 设置为
   `Marker`
2. 将 **Visual Properties** 设置为
   `Advanced`

### **Ambient Color** — 环境光颜色 [0.15 0.15 0.15 1.0]（默认） | 值在 0 到 1 范围内的 3×1 或 1×3 向量 | 值在 0 到 1 范围内的 4×1 或 1×4 向量

环境光颜色，指定为值在 0 到 1 范围内的 [R,G,B] 或 [R,G,B,A] 向量。该向量可以是行向量或列向量。可选的第四个元素指定颜色不透明度。省略不透明度元素等效于指定值 1。

环境光指的是不直接来自光源的一般照明水平。环境光由经过多次反射和再反射、不再来自任何特定方向的光组成。

#### 依赖关系

要启用此参数，请设置：

1. 将 **Type** 设置为
   `Marker`
2. 将 **Visual Properties** 设置为
   `Advanced`

### **Emissive Color** — 自发光颜色 [0.0 0.0 0.0 1.0]（默认） | 值在 0 到 1 范围内的 3×1 或 1×3 向量

自发光产生的颜色，指定为值在 0 到 1 范围内的 [R,G,B] 或 [R,G,B,A] 向量。该向量可以是行向量或列向量。可选的第四个元素指定颜色不透明度。省略不透明度元素等效于指定值 1。

自发光颜色是不来自任何外部源的颜色，因此看起来是由标记自身发射的。当标记具有自发光颜色时，即使没有外部光源，也可以看到该标记。

#### 依赖关系

要启用此参数，请设置：

1. 将 **Type** 设置为
   `Marker`
2. 将 **Visual Properties** 设置为
   `Advanced`

### **Shininess** — 标记的光泽度 75（默认） | 1 到 128 范围内的标量

标记的光泽度，指定为 0 到 128 范围内的标量。此参数影响标记镜面反射的锐度。高光泽度的标记具有类似镜面的外观，低光泽度的标记具有更低光泽或缎面的外观。

#### 依赖关系

要启用此参数，请设置：

1. 将 **Type** 设置为
   `Marker`
2. 将 **Visual Properties** 设置为
   `Advanced`

## 描述

具有固定惯性属性的质量元件

Inertia 模块向连接的坐标系添加具有固定惯性属性的点质量或分布质量。质量类型（点质量或分布质量）取决于为模块选择的参数化。选择 `Point Mass` 假定质量集中在一点，因此没有转动惯量。选择 `Custom` 假定质量分布在空间中，使其可以具有非零转动惯量、惯性积和质心坐标（后者相对于模块的参考坐标系）。

选择标记提供了一种在模型可视化中识别惯性的方法。可视化在仿真开始时或图更新时（默认）在 Multibody Explorer 中打开。使用标记可相对于模型其余部分跟踪惯性的运动。有多种标记形状可用——惯性图标、球体、立方体、坐标系——每种形状都有可配置的尺寸。要从模型可视化中消除惯性（同时保留其对模型动力学的影响），该模块提供了 `None` 选项。
