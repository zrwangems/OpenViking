# File Solid

## 端口

### 坐标系

### **R** — 局部参考坐标系 坐标系

导入实体的局部参考坐标系。该坐标系相对于实体固定。将此坐标系连接到另一个模块以指定实体的位置和方向。
### 几何

### **CH** — 凸包表示 几何

表示实体几何的凸包。将此端口连接到 Spatial Contact Force 模块以在凸包上建模接触。

#### 依赖关系

要启用此端口，请在 **Geometry** 下展开 **Export** 并选择 **Convex Hull**。

## 参数

### 几何

### **File Name** — CAD 文件名或 CAD 文件路径 字符向量

CAD 文件名或 CAD 文件路径，指定为字符向量。如果文件名或路径不包含文件扩展名，模块假定文件类型为 STEP。该模块支持多种格式的 CAD 文件。有关支持的 CAD 文件格式列表，请参阅 Supported Software and File Formats。

根据 CAD 文件的位置，使用以下方法之一来指定 **File Name**。

| **位置** | 方法 |
| --- | --- |
| 文件位于当前工作文件夹或 MATLAB® 路径上 | 在文本框中输入文件名。 **示例：** `myShape.STEP` |
| 文件位于既不是当前文件夹也不在 MATLAB 路径上的文件夹中 | - 输入 CAD 文件的相对路径，即相对于当前文件夹的路径。 **示例：** `Geometries/myShape.STEP, 或 ../Geometries/myShape.STEP` - 单击 Browsing for CAD file 按钮并浏览到 CAD 文件。 - 输入 CAD 文件的完整路径。 **示例：** `C:/Users/Model/Geometries/myShape.STEP` |

**提示**

- 在多个平台上使用该模块或与他人共享模型时，请考虑使用文件名或相对路径。
- 正斜杠 (/) 在任何平台上都是有效的分隔符。反斜杠 (\\) 仅在 Microsoft Windows 平台上有效。

### **Unit Type** — 实体几何单位的来源 `From File`（默认）| `Custom`

实体几何单位的来源。选择 `From File` 以使用导入文件中指定的单位。选择 `Custom` 以指定自己的单位。

### **Unit** — 导入文件中指定几何坐标所用的长度单位 `m`（默认）| `cm` | `mm` | `km` | `in` | `ft`

用于解释几何文件中定义的几何的长度单位。更改单位会改变导入几何的比例。

### **Convex Hull** — 生成真实几何的凸包表示 `off`（默认）| `on`

选择 **Convex Hull** 以生成真实几何的凸包表示。选择此参数会启用端口 **CH**。

### 惯性

### **Type** — 要使用的惯性参数化方式 `Calculate from Geometry`（默认）| `Point Mass` | `Custom`

要使用的惯性参数化方式。选择 `Point Mass` 以对具有可忽略转动惯量的集中质量建模。选择 `Custom` 以对具有指定惯性矩和惯性积的分布质量建模。默认设置 `Calculate from Geometry` 使模块能够根据实体几何以及密度或质量自动计算转动惯性属性。

### **Based on** — 惯性计算中使用的参数 `Density from File`（默认）| `Custom Density` | `Custom Mass`

惯性计算中使用的参数。模块根据实体几何和所选参数计算惯性张量。

- `Density from File`：模块根据从 CAD 文件获得的密度计算物体的惯性。请注意，只有部分 CAD 格式包含密度数据。
- `Custom Density`：模块根据对话框中指定的密度计算物体的惯性。
- `Custom Mass`：模块根据对话框中指定的质量计算物体的惯性。

### **Density** — 材料单位体积质量 `1000 kg/m^3`（默认）

材料单位体积质量。质量密度可以取正值或负值。指定负质量密度以模拟实体中的空隙或空腔效应。

#### 依赖关系

要启用此参数，请设置：

1. **Type** 为 `Calculate from
   Geometry`
2. **Based on** 为 `Custom
   Density`

### **Mass** — 实体单元的总质量 `1 kg`（默认）| 带质量单位的标量

赋予实体单元的总质量。此参数可以为正值或负值。使用负值来捕捉复合体（由多个实体和惯量组成）中的空隙或空腔效应，同时注意确保整体上物体的质量为正值。

### **Center of Mass** — 质心坐标 `[0 0 0] m`（默认）| 带长度单位的三元素向量

相对于模块参考坐标系的质心 [*x*
*y*
*z*] 坐标。

#### 依赖关系

要启用此参数，请将 **Type** 设置为
`Custom`。

### **Moments of Inertia** — 惯性张量的对角元素 `[1 1 1] kg*m^2`（默认）| 带质量\*长度^2 单位的三元素向量

三元素向量，包含相对于原点位于质心且坐标轴平行于模块参考坐标系的坐标系的
[*Ixx*
*Iyy*
*Izz*] 惯性矩。惯性矩是惯性张量的对角元素

(IxxIyyIzz)，

其中：

- Ixx=∫m(y2+z2) dm
- Iyy=∫m(x2+z2) dm
- Izz=∫m(x2+y2) dm

#### 依赖关系

要启用此参数，请将 **Type** 设置为
`Custom`。

### **Products of Inertia** — 惯性张量的非对角元素 `[0 0 0] kg*m^2`（默认）| 带质量\*长度^2 单位的三元素向量

三元素向量，包含相对于原点位于质心且坐标轴平行于模块参考坐标系的坐标系的
[*Iyz*
*Izx*
*Ixy*] 惯性积。惯性积是惯性张量的非对角元素

(IxyIzxIxyIyzIzxIyz)，

其中：

- Iyz=−∫myz dm
- Izx=−∫mzx dm
- Ixy=−∫mxy dm

#### 依赖关系

要启用此参数，请将 **Type** 设置为
`Custom`。

### **Derived Values** — 惯性属性计算值的显示 按钮

显示实体惯性属性的计算值——质量、质心、惯性矩和惯性积。点击
**Update** 按钮以计算并显示实体的属性。在对模块参数进行任何更改后点击此按钮，以确保显示的值仍然是最新的。

质心在实体的局部参考坐标系中解析。惯性矩和惯性积分别在惯性解析坐标系中解析——该坐标系的坐标轴平行于参考坐标系的坐标轴，但原点与实体质心重合。

#### 依赖关系

要启用此参数，请将 **Type** 设置为
`Calculate from Geometry`。

镜面反射光的颜色，指定为值在 0 到 1 范围内的 [R,G,B] 或 [R,G,B,A] 向量。该向量可以是行向量或列向量。可选的第四个元素指定颜色不透明度。省略不透明度元素等同于指定值 1。此参数更改镜面高光的颜色，镜面高光是由于光源的光反射而在渲染实心体上出现的亮点。

### **Ambient Color** — 环境光颜色 [0.15 0.15 0.15 1.0]（默认）| 取值范围为 0 到 1 的 3×1 或 1×3 向量 | 取值范围为 0 到 1 的 4×1 或 1×4 向量

环境光颜色，指定为取值范围为 0 到 1 的 [R,G,B] 或 [R,G,B,A] 向量。该向量可以是行向量或列向量。可选的第四个元素指定颜色不透明度。省略不透明度元素等同于指定值为 1。

环境光是指并非直接来自光源的一般照明水平。环境光由经过多次反射和再反射、以至于不再来自任何特定方向的光组成。您可以调整此参数以更改所渲染实体的阴影颜色。

自发光颜色，指定为取值范围为 0 到 1 的 [R,G,B] 或 [R,G,B,A] 向量。该向量可以是行向量或列向量。可选的第四个元素指定颜色不透明度。省略不透明度元素等同于指定值为 1。

发射颜色是不来自任何外部光源的颜色，因此看起来是由实体自身发射的。当实体具有发射颜色时，即使没有外部光源，也可以看到该实体。

2. **Visual Properties** 为 `Advanced`

### **Show Port R** — 显示用于连接到其他模块的参考坐标系端口 on（默认）| off

### **New Frame** — 创建用于连接到其他模块按钮的自定义坐标系

单击创建按钮创建以打开用于创建新刚体附加坐标系的窗格。在此窗格中，您可以指定坐标系的名称、原点和方向。

- 要命名自定义坐标系，请单击 **Frame Name** 参数的文本字段。该名称标识刚体模块上以及 Multibody Explorer 的 **Model Tree** 窗格中的对应端口。
- 要选择自定义坐标系的 **Frame Origin**，请使用以下方法之一：

  - **At Reference Frame Origin**：使新坐标系原点与刚体参考坐标系的原点重合。
  - **At Center of Mass**：使新坐标系原点与刚体的质心重合。
  - **Based on Geometric Feature**：使新坐标系原点与所选特征的中心重合。有效特征包括曲面、线和点。从可视化窗格中选择一个特征，然后单击 **Use Selected Feature** 以确认原点的位置。原点位置的名称将出现在此选项下方的字段中。
- 要定义自定义坐标系的方向，请在 **Frame Axes** 部分下，选择自定义坐标系的 **Primary Axis** 和 **Secondary Axis**，然后指定它们的方向。

  使用以下方法选择用于指定主轴和次轴方向的向量。主轴平行于所选向量，并将其余两个轴约束在其法平面内。次轴平行于所选向量在法平面上的投影。

  - **Along Reference Frame Axis**：选择刚体参考坐标系的轴。
  - **Along Principal Inertia Axis**：选择刚体主惯性轴的轴。
  - **Based on Geometric Feature**：选择与刚体所选几何特征关联的向量。有效特征包括曲面和线。对应的向量在可视化窗格中由白色箭头指示。您可以从可视化窗格中选择一个特征，然后单击 **Use Selected Feature** 以确认选择。所选特征的名称将出现在此选项下方的字段中。

### 导入零件

File Solid 模块将导入的零件表示为刚体。该模块可以从 CAD 文件中读取惯量和颜色数据。或者，您可以为导入的零件显式指定这些属性。有关详细信息，请参阅惯量和图形。

File Solid 模块使用惯性坐标系（其原点与质心重合，各轴与参考坐标系的轴平行）来计算导入实体的惯量。计算惯性矩和惯性积所在的坐标系因 CAD 软件而异。有关如何指定惯量的详细信息，请参阅指定自定义惯量。

**计算惯量**

如果模块根据导入体的几何形状计算惯量，您可以在模块对话框中查看计算值。展开 **Inertia** 下的 **Derived Values** 节点，然后单击 **Update**。如果几何形状、密度或质量发生变化，请单击 **Update** 按钮重新计算惯量。所有计算值均采用 SI 单位。

**坐标系**

导入体通过坐标系进行连接。默认情况下，导入体具有一个由端口 **R** 表示的参考坐标系。CAD 文件指定参考坐标系的位置。

如果您需要在体的不同部位进行连接，或者需要在体上具有多个连接，则可以在体上创建额外的坐标系。每个坐标系都会为模块添加一个新的坐标系端口。有关创建自定义坐标系的详细信息，请参阅坐标系。

### 导入装配体

File Solid 模块使用 CAD 文件中指定的默认姿态将导入的装配体表示为单个刚体。该模块忽略 CAD 文件中的所有约束，并假定整个装配体具有一个密度。

如果您在 **Inertia** 下将 **Type** 指定为 `Calculate From Geometry`，并将 **Based On** 指定为 `Density`，则 File Solid 模块可以从 CAD 文件中读取密度数据。为确保模块成功读取密度，CAD 文件必须具有整个装配体的密度，并且所有零件的密度必须具有相同的值或未指定。否则，仿真将返回错误。

您可以手动指定导入装配体的密度、质量或惯量属性。该过程与单个零件的过程相同。有关详细信息，请参阅指定自定义惯量。

您可以导入具有由不同建模方法表示的零件的装配体，例如面片模型、多边形模型和 BRep 模型。但是，您只能在由 BRep 模型表示的零件上创建坐标系，因为它们具有必要的边界图元，例如点、边和面。

### 导出几何体

File Solid 模块可以在 Simscape Multibody 环境中生成导入 CAD 文件的凸包几何表示。您可以将导出的几何体用于空间接触。

如图所示，凸包几何体是真实几何体的近似。该模块根据其真实几何体计算物理属性，例如质量和惯量。
