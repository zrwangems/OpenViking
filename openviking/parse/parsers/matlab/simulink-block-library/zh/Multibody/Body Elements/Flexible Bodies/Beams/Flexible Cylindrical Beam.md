# Flexible Cylindrical Beam

## 端口

### Frame

### **A** — 连接坐标系 frame

用于在模型中连接梁的坐标系。在未变形配置中，此坐标系位于相对于局部参考坐标系原点沿 -*z* 方向半个梁长度处。

### **B** — 连接坐标系 frame

用于在模型中连接梁的坐标系。在未变形配置中，此坐标系位于相对于局部参考坐标系原点沿 +*z* 方向半个梁长度处。

### **R** — 参考坐标系 frame

表示柔性体整体刚体运动的虚拟未变形体的参考坐标系。**R** 坐标系并不物理地附着到柔性体。

**R** 端口不得与任何施加力或力矩或具有惯性的模块刚性连接。

## 参数

### 几何

### **Type** — 选择实心或空心横截面 `Solid`（默认）| `Hollow`

选择实心或空心横截面：

- 选择 `Solid` 对具有实心横截面的梁建模。
- 选择 `Hollow` 对具有空心横截面的梁建模。

### **Radius** — 中心轴与梁外表面之间的距离 0.5 `m`（默认）| positive scalar

中心轴与梁外表面之间的距离。

### **Thickness** — 空心横截面的壁厚 0.1 `m`（默认）| positive scalar

空心横截面的壁厚。此参数指定梁内表面与外表面之间的距离。

#### 依赖项

要启用此参数，请将 **Type** 设置为 `Hollow`。

### **Length** — 梁的拉伸长度 10 `m`（默认）| positive scalar

梁的拉伸长度。梁通过沿局部参考坐标系的 *z* 轴拉伸指定横截面来建模。拉伸关于 *xy* 平面对称，其中一半梁沿 *z* 轴负方向拉伸，另一半沿正方向拉伸。

### 刚度和惯性

### **Type** — 用于指定刚度和惯性属性的方法 `Calculate from Geometry`（默认）| `Custom`

用于指定刚度和惯性属性的方法，指定为 `Calculate from Geometry` 或 `Custom`。

当将该参数设置为 `Calculate from Geometry` 时，模块根据指定的密度、杨氏模量以及泊松比或剪切模量计算刚度和惯性属性。将参数设置为 `Custom` 以手动指定刚度和惯性属性。

### **Density** — 材料每单位体积的质量 2700 `kg/m^3`（默认）| positive scalar

材料每单位体积的质量——此处假定均匀分布在梁中。默认值对应于铝。

#### 依赖项

要启用此参数，请在 **刚度和惯性** 部分下，将 **Type** 参数设置为 `Calculate from Geometry`。

### **Specify** — 用于参数化梁的弹性属性 `Young's Modulus and Poisson's Ratio`（默认）| `Young's and Shear Modulus`

用于参数化梁的弹性属性。这些属性通常可从材料数据库获得。

#### 依赖项

要启用此参数，请在 **刚度和惯性** 部分下，将 **Type** 参数设置为 `Calculate from Geometry`。

### **Young's Modulus** — 轴向应力与轴向应变之比 70 `GPa`（默认）| positive scalar

梁的弹性杨氏模量。其值越大，对弯曲和轴向变形的抵抗力越强。默认值对应于铝。

#### 依赖项

要启用此参数，请在 **刚度和惯性** 部分下，将 **Type** 参数设置为 `Calculate from Geometry`。

### **Poisson's Ratio** — 横向应变与纵向应变之比 0.33（默认）| scalar in the range [0, 0.5)

梁的泊松比。指定值必须大于或等于 `0` 且小于 `0.5`。默认值对应于铝。

#### 依赖项

要启用此参数，请在 **刚度和惯性** 部分下，将 **Type** 参数设置为 `Calculate from Geometry`，并将 **Specify** 参数设置为 **Young's Modulus and Poisson's Ratio**。

### **Shear Modulus** — 剪应力与工程剪应变之比 26 `GPa`（默认）| positive scalar

梁的剪切模量（或刚性模量）。其值越大，对扭转变形的抵抗力越强。默认值对应于铝。

#### 依赖项

要启用此参数，请在 **刚度和惯性** 部分下，将 **Type** 参数设置为 `Calculate from Geometry`，并将 **Specify** 参数设置为 **Young's and Shear Modulus**。

### **Derived Values** — 质量和刚度截面属性的计算值 button

梁的质量和刚度截面属性的计算值。单击 **Update** 以计算并显示这些值。

提供的属性包括 **Centroid** 和 **Shear Center**。质心是轴向力使梁伸长（或收缩）而不弯曲的点。剪切中心是横向力必须通过以使梁弯曲而不扭转的点。

刚度截面属性计算如下：

- **Axial Rigidity**：*E**A*
- **Flexural Rigidity**：[*E**I*x,
  *E**I*y]
- **Cross Flexural Rigidity**：*E**I*xy
- **Torsional Rigidity**：*G**J*

质量截面属性计算如下：

- **Mass per Unit Length**：*ρ**A*
- **Mass Moment of Inertia Density**：[*ρ**I*x,
  *ρ**I*y]
- **Mass Product of Inertia Density**：*ρ**I*xy
- **Polar Mass Moment of Inertia Density**：*ρ**I*p

方程参数包括：

- *A* — 横截面积
- *ρ* — 密度
- *E* — 杨氏模量
- *G* — 剪切模量
- *J* — 扭转常数（由 Saint-Venant 翘曲偏微分方程的解获得）

剩余参数是梁的相关面积矩。这些量围绕质心坐标系的轴计算——该坐标系与局部参考坐标系对齐，但原点位于质心。面积矩为：

- *I*x,
  *I*y — 质心二次面积矩：

  [Ix,Iy]=[∫A(y−yc)2dA,∫A(x−xc)2dA],
- *I*xy — 质心惯性积面积矩：

  Ixy=∫A(x−xc)(y−yc)dA,
- *I*p — 质心极面积矩：

  IP=Ix+Iy,

其中 *x*c 和
*y*c 是质心的坐标。

### 阻尼

### **Type** — 阻尼方法类型 `Proportional`（默认）| `Uniform Modal` | `None`

应用于梁的阻尼方法：

- 选择 `None` 对无阻尼梁建模。
- 选择 `Proportional` 以应用比例（或 Rayleigh）阻尼方法。此方法将阻尼矩阵 [*C*] 定义为质量矩阵 [*M*] 和刚度矩阵 [*K*] 的线性组合：

  [C]=α[M]+β[K],

  其中 *α* 和 *β* 是 scalar 系数。
- 选择 `Uniform Modal` 以应用均匀模态阻尼方法。此方法对梁的所有振动模态应用单个阻尼比。该值越大，振动衰减越快。

  所选参考条件会影响阻尼比所适用的模态类型。有关参考条件的详细信息，请参见参考条件。当对柔性体使用模态降阶时，仅保留模态的子集。有关模态降阶的详细信息，请参见减少柔性体的自由度。

### **Mass Coefficient** — 质量矩阵系数 0 `1/s`（默认）| nonnegative scalar

质量矩阵的系数 *α*。此参数定义与质量矩阵 [*M*] 成比例的阻尼。

#### 依赖项

要启用此参数，请将 **Type** 设置为 `Proportional`。

### **Stiffness Coefficient** — 刚度矩阵系数 0.001 `s`（默认）| nonnegative scalar

刚度矩阵的系数 *β*。此参数定义与刚度矩阵 [*K*] 成比例的阻尼。

#### 依赖项

要启用此参数，请将 **Type** 设置为 `Proportional`。

### **Damping Ratio** — 均匀模态阻尼方法的阻尼比 0.01（默认）| unitless nonnegative scalar

阻尼比 *ζ*，应用于均匀模态阻尼模型中的所有梁振动模态。该值越大，梁振动衰减越快。

当 *ζ* = 0 时，梁无阻尼。如果施加到梁的边界条件与所选参考条件完全匹配，则 *ζ* < 1 产生欠阻尼模态衰减，*ζ* = 1 对应临界阻尼，*ζ* > 1 产生过阻尼耗散。当边界条件与参考条件不匹配时，所选阻尼比的效果会变化。有关参考条件的详细信息，请参见参考条件。

#### 依赖项

要启用此参数，请将 **Type** 设置为 `Uniform Modal`。

### 离散化

### **Number of Elements** — 梁有限元数量 1（默认）| positive integer

梁模型中的有限元数量。增加单元数量总会提高仿真精度。但实际上，在某个点之后，当单元很多时，精度的提高可忽略不计。此外，单元数量越多，计算成本越高，并会减慢仿真速度。

### 参考条件

### **Type** — 参考条件类型 `Linearized Mean Axes`（默认）| `Body-Fixed`

指定要应用的参考条件类型。有关详细信息，请参见参考条件。

- `Linearized Mean Axes`：体参考坐标系跟随瞬时质心，柔性体表现无约束的变形振动模态。
- `Body-Fixed`：选择固连于体的坐标系作为体参考坐标系。柔性体的变形表现自由振动模态振型，在体参考坐标系位置处具有零平移和旋转变形。

### **Frame** — 用于体固定参考条件的连接坐标系 frame name

输入要用作体参考坐标系的连接坐标系名称。坐标系名称区分大小写。确保所选坐标系在模块上暴露为端口。不能使用 **R** 坐标系，它是虚拟未变形体的参考坐标系。

#### 依赖项

要启用此参数，请将 **Type** 设置为 `Body-Fixed`。

### **Show Port R** — 显示参考坐标系端口 off（默认）| on

选择以暴露 **R** 端口，它表示虚拟未变形体的参考坐标系。请注意，**R** 坐标系并不物理地附着到柔性体。

**R** 端口不得与任何施加力或力矩或具有惯性的模块刚性连接。

### 保真度

### **Reduction** — 用于对柔性体建模的方法 `None`（默认）| `Modally Reduced`

用于对柔性体建模的方法，指定为 `None` 或 `Modally Reduced`。将参数设置为 `None` 以使用有限元法生成的完整节点弹性坐标，或将参数设置为 `Modally Reduced` 以使用模态变换方法减少体的弹性坐标。对于这两种设置，模块使用浮动参考坐标系公式 [1-2] 将体与其弹性变形耦合。

### **Number of Retained Modes** — 保留模态 1（默认）| nonnegative integer

保留模态，指定为范围 [0, *n*] 内的整数，其中 *n* 是体的弹性自由度数量。如果将数量设置为 0，则柔性体被视为刚体。

#### 依赖项

要启用此参数，请将 **Reduction** 设置为 `Modally Reduced`。

### 图形

### **类型** — 用于梁可视化的图形 `From Geometry`（默认） | `None`

梁的视觉表示类型，指定为 `From Geometry` 或 `None`。将参数设置为 `From Geometry` 以显示梁的视觉表示。将参数设置为 `None` 以在模型可视化中隐藏梁。

### **视觉属性** — 颜色和不透明度的参数化 `Simple`（默认） | `Advanced`

用于指定视觉属性的参数化。选择 `Simple` 以指定 **颜色** 和 **不透明度**。选择 `Advanced` 以指定更多视觉属性，例如 **镜面反射颜色**、**环境光颜色**、**自发光颜色** 和 **光泽度**。

#### 依赖项

要启用此参数，请将 **类型** 设置为 `From Geometry`。

图形不透明度，指定为 0 到 1 范围内的标量。标量 0 对应于完全透明，标量 1 对应于完全不透明。

### **漫反射颜色** — 漫反射所致光的颜色 [0.5 0.5 0.5]（默认） | 3×1 或 1×3 向量，值在 0 到 1 范围内 | 4×1 或 1×4 向量，值在 0 到 1 范围内

由于漫反射所致的光的颜色，指定为 [R,G,B] 或 [R,G,B,A] 向量，值在 0 到 1 范围内。该向量可以是行向量或列向量。可选的第四个元素指定颜色不透明度。省略不透明度元素等效于指定值 1。

### **镜面反射颜色** — 镜面反射所致光的颜色 [0.5 0.5 0.5 1.0]（默认） | 3×1 或 1×3 向量，值在 0 到 1 范围内 | 4×1 或 1×4 向量，值在 0 到 1 范围内

由于镜面反射所致的光的颜色，指定为 [R,G,B] 或 [R,G,B,A] 向量，值在 0 到 1 范围内。该向量可以是行向量或列向量。可选的第四个元素指定颜色不透明度。省略不透明度元素等效于指定值 1。此参数更改镜面高光的颜色，镜面高光是由于光源的光反射而在所渲染梁上出现的亮点。

### **环境光颜色** — 环境光的颜色 [0.15 0.15 0.15 1.0]（默认） | 3×1 或 1×3 向量，值在 0 到 1 范围内 | 4×1 或 1×4 向量，值在 0 到 1 范围内

环境光的颜色，指定为 [R,G,B] 或 [R,G,B,A] 向量，值在 0 到 1 范围内。该向量可以是行向量或列向量。可选的第四个元素指定颜色不透明度。省略不透明度元素等效于指定值 1。

环境光是指并非直接来自光源的一般照明水平。环境光是已经反射和再反射很多次以至于不再来自任何特定方向的光。您可以调整此参数以更改所渲染梁的阴影颜色。

#### 依赖项

要启用此参数，请设置：

1. **类型** 为 `From Geometry`
2. **视觉属性** 为 `Advanced`

### **自发光颜色** — 自发光颜色 [0.0 0.0 0.0 1.0]（默认） | 3×1 或 1×3 向量，值在 0 到 1 范围内

由于自发光而产生的颜色，指定为 [R,G,B] 或 [R,G,B,A] 向量，值在 0 到 1 范围内。该向量可以是行向量或列向量。可选的第四个元素指定颜色不透明度。省略不透明度元素等效于指定值 1。

发射颜色是不来自任何外部光源的颜色，因此看起来是由梁自身发射的。当梁具有发射颜色时，即使没有外部光源，也可以看到梁。

#### 依赖项

要启用此参数，请设置：

1. **类型** 为 `From Geometry`
2. **视觉属性** 为 `Advanced`

### **光泽度** — 高光锐度 75（默认） | 值限制在 0–128 的标量

镜面光反射的锐度，指定为 0–128 标度上的标量数字。增大光泽度值以获得更小但更锐利的高光。减小该值以获得更大但更平滑的高光。

#### 依赖项

要启用此参数，请设置：

1. **类型** 为 `From Geometry`
2. **视觉属性** 为 `Advanced`

### **新建坐标系** — 用于创建连接到其他模块的自定义坐标系 按钮

点击 Create 按钮 Create 以打开用于创建新附着于刚体的坐标系的窗格。在此窗格中，您可以指定该坐标系的名称、原点和方向。

- 要命名自定义坐标系，请点击 **坐标系名称** 参数的文本字段。该名称标识梁模块上的对应端口以及 Multibody Explorer 的树视图窗格中的端口。
- 要为自定义坐标系选择 **坐标系原点**，请使用以下方法之一：

  - **在参考坐标系原点**：使新坐标系原点与未变形梁的参考坐标系原点重合。
  - **基于几何特征**：使新坐标系原点与所选未变形几何特征的中心重合。有效特征包括曲面、线和点。从可视化窗格中选择一个特征，然后点击 **使用所选特征** 以确认原点的位置。原点位置的名称出现在此选项下方的字段中。
- 要定义自定义坐标系的方向，请在 **坐标系轴** 部分下，选择自定义坐标系的 **主轴** 和 **副轴**，然后指定它们的方向。

  使用以下方法选择用于指定主轴和副轴方向的向量。主轴平行于所选向量，并将其余两个轴约束到其法平面。副轴平行于所选向量在法平面上的投影。

  - **沿参考坐标系轴**：选择未变形梁的参考坐标系的一个轴。
  - **基于几何特征**：选择与未变形梁的所选几何特征相关联的向量。有效特征包括曲面和线。对应向量由可视化窗格中的白色箭头指示。您可以从可视化窗格中选择一个特征，然后点击 **使用所选特征** 以确认选择。所选特征的名称出现在此选项下方的字段中。

### **FrameN** — 编辑或删除现有自定义坐标系 坐标系名称

您已创建的坐标系。`N` 是每个自定义坐标系的唯一标识编号。

- 点击文本字段以编辑现有自定义坐标系的名称。

- 点击 Edit 按钮 Edit 以编辑自定义坐标系的其他方面，例如原点和轴。
- 点击 Delete 按钮 Delete 以删除自定义坐标系。

## 描述

具有用于变形的弹性特性的圆柱梁

Flexible Cylindrical Beam 模块对具有圆形横截面的细长梁进行建模，该梁可以是实心或空心。圆柱梁可以具有小的线性变形。这些变形包括拉伸、弯曲和扭转。该模块基于您指定的几何和材料属性计算梁的横截面属性，例如轴向、弯曲和扭转刚度。

圆柱梁的几何形状是其横截面的拉伸。梁的横截面定义在 *xy* 平面中，并沿 *z* 轴拉伸。要定义横截面，您可以在模块对话框的 **几何** 部分中指定其尺寸。图中显示了实心梁和空心梁。参考坐标系位于梁的形心处。

有关对柔性梁建模的详细信息，请参见柔性梁概述。
