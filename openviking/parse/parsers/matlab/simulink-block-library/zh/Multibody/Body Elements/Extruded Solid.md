# Extruded Solid

## 端口

### 参考系

### **R** — 参考系 frame

实体的局部参考系。此参考系相对于实体几何固定。将此端口连接到参考系实体——端口、线或结点——以解析参考系在模型中的放置。有关详细信息，请参阅 Working with Frames。

### 几何

### **G** — 几何 geometry

表示实体的几何。将此端口连接到 Spatial Contact Force 模块，以对实体上的接触进行建模。

#### 依赖关系

要启用此端口，请在 **几何** 下展开 **导出**，然后选择 **整个几何**。

## 参数

### 几何

### **挤出类型** — 要使用的形状参数化 `Regular`（默认）| `General`

要使用的形状参数化。选择 `Regular` 或 `General`。

- `Regular` — 正多边形横截面的平移扫掠，其几何中心与参考系原点重合，挤出轴与参考系 z 轴重合。
- `General` — 一般横截面的平移扫掠，其几何中心与横截面 XY 平面上的 [0 0] 坐标重合，挤出轴与参考系 z 轴重合。

### **规则挤出：边数** — 挤出横截面的边数 `3`（默认）| 单位为长度的标量

挤出横截面的边数。根据定义，横截面是正多边形——各边长度相等。指定的数字必须大于二。

### **规则挤出：外半径** — 挤出横截面的内切圆半径 `1 m`（默认）| 单位为长度的标量

完全内接挤出横截面的圆的半径。根据定义，横截面是正多边形——各边长度相等。

### **规则挤出：长度** — 挤出的扫掠长度 `1 m`（默认）| 单位为长度的标量

对指定挤出横截面进行扫掠的长度。挤出轴是实体参考系的 *z* 轴。横截面在正方向和负方向上以相等量进行扫掠。

### **常规挤出：横截面** — 在 XY 平面上指定的横截面坐标 `[1 1; -1 1; -1 -1; 1 -1]`（默认）| 单位为长度的两列矩阵

横截面形状指定为 [x,y] 坐标矩阵，其中每一行对应于横截面轮廓上的一个点。指定的坐标必须定义一个闭合环，且没有自相交段。

坐标的排列必须使从一个点到下一个点时，实体区域始终位于左侧。该模块沿 z 轴挤出指定的横截面形状，以获得挤出实体。

### **常规挤出：长度** — 挤出的扫掠长度 `1 m`（默认）| 单位为长度的标量

对指定挤出横截面进行扫掠的长度。挤出轴是实体参考系的 *z* 轴。横截面在正方向和负方向上以相等量进行扫掠。

### **整个几何** — 导出模块的真实几何 `off`（默认）| `on`

选择 **整个几何** 以导出 Extruded Solid 模块的真实几何，该几何可用于其他模块，例如 Spatial Contact Force 模块。

#### 依赖关系

要启用此选项，请将 **挤出类型** 设置为 `Regular`，并在 **导出** 下选择 **整个几何**。

### **凸包** — 生成真实几何的凸包表示 `off`（默认）| `on`

选择 **凸包** 以生成真实几何的凸包表示。通过连接 Spatial Contact Force 模块，可将此凸包用于接触。

#### 依赖关系

要启用此选项，请将 **挤出类型** 设置为 `General`，并在 **导出** 下选择 **凸包**。

### 惯性

### **类型** — 要使用的惯性参数化 `Calculate from Geometry`（默认）| `Point Mass` | `Custom`

要使用的惯性参数化。选择 `Point Mass` 可对具有可忽略转动惯量的集中质量进行建模。选择 `Custom` 可对具有指定惯性矩和惯性积的分布质量进行建模。默认设置 `Calculate from Geometry` 使该模块能够根据实体几何以及指定的质量或质量密度自动计算转动惯性属性。

### **基于** — 用于作为惯性计算基础的参数 `Density`（默认）| `Mass`

用于惯性计算的参数。该模块从实体几何和所选参数获得惯性张量。如果已知材料属性，请使用 `Density`。如果已知实体总质量，请使用 `Mass`。

### **密度** — 单位体积材料的质量 `1000 kg/m^3`（默认）

单位体积材料的质量。质量密度可取正值或负值。指定负的质量密度以对实体中空洞或空腔的影响进行建模。

### **质量** — 实体单元的总质量 `1 kg`（默认）| 单位为质量的标量

要赋予实体单元的总质量。此参数可以为正或负。使用负值可捕获复合体（由一个或多个实体和惯性组成）中空洞或空腔的影响，并注意确保该物体的质量总体为正。

### **自定义：质心** — 质心坐标 `[0 0 0] m`（默认）| 单位为长度的三元素向量

质心相对于模块参考系的 [x y z] 坐标。质心仅在均匀引力场中与重心重合。

### **自定义：惯性矩** — 惯性张量的对角元素 `[1 1 1] kg*m^2`（默认）| 单位为质量\*长度^2 的三元素向量

三元素向量，包含相对于以下参考系指定的 [Ixx Iyy Izz] 惯性矩：原点位于质心，各轴平行于模块参考系。惯性矩是惯性张量的对角元素

(IxxIyyIzz),

其中：

- Ixx=∫m(y2+z2) dm
- Iyy=∫m(x2+z2) dm
- Izz=∫m(x2+y2) dm

### **自定义：惯性积** — 惯性张量的非对角元素 `[0 0 0] kg*m^2`（默认）| 单位为质量\*长度^2 的三元素向量

三元素向量，包含相对于以下参考系指定的 [Iyz Izx Ixy] 惯性积：原点位于质心，各轴平行于模块参考系。惯性积是惯性张量的非对角元素

(IxyIzxIxyIyzIzxIyz),

其中：

- Iyz=−∫myz dm
- Izx=−∫mzx dm
- Ixy=−∫mxy dm

### **根据几何计算：派生值** — 显示计算出的质量属性值的按钮

显示计算出的实体质量属性值——质量、质心、惯性矩和惯性积。单击 **更新** 按钮以计算并显示实体的质量属性。在对模块参数进行任何更改后，单击此按钮以确保显示的值仍然是最新值。

质心在实体的局部参考系中解析。惯性矩和惯性积分别在惯性解析参考系中解析——该参考系的各轴平行于参考系的各轴，但原点与实体质心重合。

#### 依赖关系

当 **惯性** > **类型** 模块参数设置为 `Calculate from Geometry` 时，用于计算和显示质量属性的选项处于活动状态。

### 图形

### **类型** — 用于可视化的图形 `From Geometry`（默认）| `Marker` | `None`

实体的可视表示类型，指定为 `From Geometry`、`Marker` 或 `None`。将参数设置为 `From Geometry` 可显示实体的可视表示。将参数设置为 `Marker` 可将实体表示为标记。将参数设置为 `None` 可在模型可视化中隐藏实体。

### **视觉属性** — 颜色和不透明度的参数化 `Simple`（默认）| `Advanced`

用于指定视觉属性的参数化。选择 `Simple` 以指定 **漫反射颜色** 和 **不透明度**。选择 `Advanced` 以指定更多视觉属性，例如 **镜面反射颜色**、**环境光颜色**、**自发光颜色** 和 **光泽度**。

#### 依赖关系

要启用此参数，请将 **类型** 设置为 `From Geometry` 或 `Marker`。

### **形状** — 用于表示实体的标记形状 `Sphere`（默认）| `Cube` | `Frame`

用于可视化实体的标记形状。标记的运动反映实体本身的运动。

#### 依赖关系

要启用此参数，请将 **类型** 设置为 `Marker`。

### **大小** — 标记的宽度，以像素为单位 10 `pixels`（默认）| 标量

标记的宽度，以像素为单位。此宽度不随缩放级别缩放。请注意，标记的视觉大小部分取决于屏幕分辨率，较高分辨率每单位长度包含更多像素，因此会产生较小的图标。

#### 依赖关系

要启用此参数，请将 **类型** 设置为 `Marker`。

### **颜色** — 漫反射产生的光颜色 [0.5 0.5 0.5]（默认）| 值在 0 到 1 范围内的 3×1 或 1×3 向量 | 值在 0 到 1 范围内的 4×1 或 1×4 向量

直接白光下图形的颜色，指定为 0–1 范围内的 [R G B] 或 [R G B A] 向量。可选的第四个元素 (A) 指定 0–1 范围内的颜色不透明度。省略不透明度元素等效于指定值 1。

#### 依赖关系

要启用此参数，请设置：

1. **类型** 为 `From Geometry` 或 `Marker`
2. **视觉属性** 为 `Simple`

### **不透明度** — 图形不透明度 1.0（默认）| 0 到 1 范围内的标量

图形不透明度，指定为 0 到 1 范围内的标量。标量 0 对应于完全透明，标量 1 对应于完全不透明。

#### 依赖关系

要启用此参数，请设置：

1. **类型** 为 `From Geometry` 或 `Marker`
2. **视觉属性** 为 `Simple`

### **漫反射颜色** — 漫反射产生的光颜色 [0.5 0.5 0.5]（默认）| 值在 0 到 1 范围内的 3×1 或 1×3 向量 | 值在 0 到 1 范围内的 4×1 或 1×4 向量

漫反射产生的光颜色，指定为值在 0 到 1 范围内的 [R,G,B] 或 [R,G,B,A] 向量。该向量可以是行向量或列向量。可选的第四个元素指定颜色不透明度。省略不透明度元素等效于指定值 1。

漫反射颜色反映渲染实体的主颜色，并提供阴影，使渲染对象具有三维外观。

#### 依赖关系

要启用此参数，请设置：

1. **类型** 为 `From Geometry` 或 `Marker`
2. **视觉属性** 为 `Advanced`

### **镜面反射颜色** — 镜面反射产生的光颜色 [0.5 0.5 0.5 1.0]（默认）| 值在 0 到 1 范围内的 3×1 或 1×3 向量 | 值在 0 到 1 范围内的 4×1 或 1×4 向量

镜面反射产生的光颜色，指定为值在 0 到 1 范围内的 [R,G,B] 或 [R,G,B,A] 向量。该向量可以是行向量或列向量。可选的第四个元素指定颜色不透明度。省略不透明度元素等效于指定值 1。此参数更改镜面高光的颜色，镜面高光是渲染实体上因光源光线反射而产生的亮点。

#### 依赖关系

要启用此参数，请设置：

1. **类型** 为 `From Geometry` 或 `Marker`
2. **视觉属性** 为 `Advanced`

### **环境光颜色** — 环境光颜色 [0.15 0.15 0.15 1.0]（默认）| 值在 0 到 1 范围内的 3×1 或 1×3 向量 | 值在 0 到 1 范围内的 4×1 或 1×4 向量

环境光的颜色，指定为值在 0 到 1 范围内的 [R,G,B] 或 [R,G,B,A] 向量。该向量可以是行向量或列向量。可选的第四个元素指定颜色不透明度。省略不透明度元素等效于指定值 1。

环境光是指不直接来自光源的一般照明级别。环境光由已经反射和再反射很多次、以致不再来自任何特定方向的光组成。您可以调整此参数以更改渲染实体的阴影颜色。

#### 依赖关系

要启用此参数，请设置：

1. **类型** 为 `From Geometry` 或 `Marker`
2. **视觉属性** 为 `Advanced`

### **自发光颜色** — 自发光颜色 [0.0 0.0 0.0 1.0]（默认）| 值在 0 到 1 范围内的 3×1 或 1×3 向量

自发光产生的颜色，指定为 0 到 1 范围内的 [R,G,B] 或 [R,G,B,A] 向量。该向量可以是行向量或列向量。可选的第四个元素指定颜色不透明度。省略不透明度元素等效于指定值 1。

发射颜色是不来自任何外部源的颜色，因此看起来是由实体自身发射的。当实体具有自发光颜色时，即使没有外部光源也可以看到该实体。

#### 依赖关系

要启用此参数，请设置：

1. **类型** 为 `From Geometry` 或 `Marker`
2. **视觉属性** 为 `Advanced`

### **光泽度** — 高光锐度 75（默认）| 值限制在 0–128 范围内的标量

镜面光反射的锐度，指定为 0–128 范围内的标量数值。增大光泽度值可获得更小但更锐利的高光。减小该值可获得更大但更平滑的高光。

#### 依赖关系

要启用此参数，请设置：

1. **类型** 为 `From Geometry` 或 `Marker`
2. **视觉属性** 为 `Advanced`

### 参考系

### **显示端口 R** — 显示用于连接到其他模块的参考系端口 on（默认）| off

选择以公开 **R** 端口。

### **New Frame** — 为连接到其他模块创建自定义坐标系按钮

单击 Create 按钮 Create 以打开一个用于创建新附着于实体的坐标系的窗格。在此窗格中，你可以指定该坐标系的名称、原点和方向。

- 要命名自定义坐标系，请单击 **Frame Name** 参数的文本字段。该名称标识实体模块上以及 Multibody Explorer 树视图窗格中的对应端口。
- 要选择自定义坐标系的 **Frame Origin**，请使用以下方法之一：

  - **At Reference Frame Origin**：使新坐标系原点与实体的参考坐标系原点重合。
  - **At Center of Mass**：使新坐标系原点与实体的质心重合。
  - **Based on Geometric Feature**：使新坐标系原点与所选特征的中心重合。有效特征包括曲面、线和点。从可视化窗格中选择一个特征，然后单击 **Use Selected Feature** 以确认原点的位置。原点位置的名称显示在此选项下方的字段中。
- 要定义自定义坐标系的方向，请在 **Frame Axes** 部分下，选择自定义坐标系的 **Primary Axis** 和 **Secondary Axis**，然后指定其方向。

  使用以下方法选择用于指定主轴和次轴方向的向量。主轴平行于所选向量，并将其余两个轴约束到其法向平面。次轴平行于所选向量在法向平面上的投影。

  - **Along Reference Frame Axis**：选择实体参考坐标系的一个轴。
  - **Along Principal Inertia Axis**：选择实体主惯性轴的一个轴。
  - **Based on Geometric Feature**：选择与实体所选几何特征关联的向量。有效特征包括曲面和线。对应向量在可视化窗格中由白色箭头指示。你可以从可视化窗格中选择一个特征，然后单击 **Use Selected Feature** 以确认选择。所选特征的名称显示在此选项下方的字段中。

### **FrameN** — 编辑或删除现有自定义坐标系坐标系名称

你已创建的坐标系。`N` 是每个自定义坐标系的唯一标识编号。

- 单击文本字段以编辑现有自定义坐标系的名称。

- 单击 Edit 按钮 Edit 以编辑自定义坐标系的其他方面，例如原点和轴。
- 单击 Delete 按钮 Delete 以删除自定义坐标系。

#### 依赖关系

要启用此参数，请通过单击 **New Frame** 创建坐标系。

## 描述

具有几何、惯性和颜色的实体拉伸元素

Extruded Solid 模块向附着的坐标系添加一个具有几何、惯性和颜色的实体元素。该实体元素可以是简单刚体，也可以是复合刚体的一部分——复合刚体是一组刚性连接的实体，通常通过刚体变换在空间上分隔。将 Extruded Solid 和其他实体模块与 Rigid Transform 模块组合，以对复合刚体建模。

参考坐标系编码实体的位置和方向。在默认配置中，该模块仅提供参考坐标系。坐标系创建界面提供了基于实体几何特征定义附加坐标系的方法。你可以通过选择 **Frames** 可展开区域中的 Create 按钮来访问此界面。

### 导出几何属性

Extruded Solid 模块可以从拉伸实体生成凸包几何表示。此几何数据可用于对空间接触力建模。

如图所示，凸包几何是真实几何的近似。请注意，该模块基于真实几何计算物理属性，例如质量和惯性。

**L-shape sold**
