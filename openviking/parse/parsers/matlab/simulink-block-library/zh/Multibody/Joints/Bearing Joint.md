# Bearing Joint

## 端口

### 坐标系

### **B** — 基础坐标系 frame

关节模块的基础坐标系。

### **F** — 从动坐标系 frame

关节模块的从动坐标系。
### 输入

#### Z Prismatic Primitive (Pz)

### **fz** — 驱动力物理信号

物理信号输入端口，用于接受关节基元的驱动力。该模块沿基础坐标系的 *z* 轴，将大小相等、方向相反的力施加到关节的基础坐标系和从动坐标系上。

#### 依赖项

要启用此端口，请在 **Z Prismatic Primitive (Pz)** > **Actuation** 下，将 **Force** 设置为 `Provided by Input`。

### **pz** — 运动剖面物理信号

物理信号输入端口，用于接受关节基元的运动剖面。该模块使用此信号来确定从动坐标系相对于基础坐标系沿基础坐标系 *z* 轴的位移。该信号还必须包含位移的一阶和二阶导数。

#### 依赖项

要启用此端口，请在 **Z Prismatic Primitive (Pz)** > **Actuation** 下，将 **Motion** 设置为 `Provided by Input`。

#### X Revolute Primitive (Rx)

### **tx** — 驱动力矩物理信号

物理信号输入端口，用于接受关节基元的驱动力矩。该模块将大小相等、方向相反的力矩施加到关节基元的基础坐标系和从动坐标系上。该力矩绕基础坐标系的 *x* 轴。在仿真期间，从动坐标系和基础坐标系的 *x* 轴彼此对齐。

#### 依赖项

要启用此端口，请在 **X Revolute Primitive (Rx)** > **Actuation** 下，将 **Torque** 设置为 `Provided by Input`。

### **qx** — 运动剖面物理信号

物理信号输入端口，用于接受关节基元的运动剖面。该模块使用此信号来确定从动坐标系相对于基础坐标系绕基础坐标系 *x* 轴的旋转。该信号还必须包含旋转的一阶和二阶导数。

#### Mode Configuration

### **mode** — 关节模式控制物理信号

用于控制关节模式的输入端口。该信号必须是无量纲标量。当输入信号为 `0` 时，关节模式为 normal；当输入信号为 `-1` 时，关节模式为 disengaged；当输入信号为 `1` 时，关节模式为 locked。您可以在仿真期间的任意时刻更改模式。

该表显示了在模式之间转换期间关节位置和速度如何变化。

| 转换 | 位置 | 速度 |
| --- | --- | --- |
| Normal 到 Locked | 关节位置保留当前值，并在转换后保持不变。 | 关节速度变为零，并在转换后保持不变。 |
| Normal 到 Disengaged | 关节位置保留当前值，但转换后可以在任意方向变化。 | 关节速度保留当前值，但转换后可以在任意方向变化。 |
| Locked 到 Normal | 关节位置保留当前值，但转换后可以在与关节 DOFs 对齐的方向上变化。 | 关节速度保持为零，但转换后可以在与关节 DOFs 对齐的方向上变化。 |
| Locked 到 Disengaged | 关节位置保留当前值，但转换后可以在任意方向变化。 | 关节速度保持为零，但转换后可以在任意方向变化。 |
| Disengaged 到 Normal | 对于与关节 DOFs 对齐的方向，关节位置最初采用使用牛顿法计算的值，此后可以变化。在受约束方向，关节位置变为零，并在转换后保持不变。 | 对于与关节 DOFs 对齐的方向，关节速度最初采用使用牛顿法计算的值，此后可以变化。在受约束方向，关节速度变为零，并在转换后保持不变。 |
| Disengaged 到 Locked | 对于与关节 DOFs 对齐的方向，关节位置最初采用使用牛顿法计算的值，并在转换后保持不变。在受约束方向，关节位置变为零，并在转换后保持不变。 | 关节速度变为零，并在转换后保持不变。 |

#### 依赖项

要启用此端口，请在 **Mode Configuration** 下，将 **Mode** 设置为 `Provided by Input`。

### Z 移动副基元 (Pz)

从动坐标系首先沿基坐标系的 *z* 轴平移，然后绕从动坐标系的各轴旋转。第一次旋转绕 *x* 轴，第二次旋转绕第一次旋转后生成的从动坐标系的 *y* 轴，第三次旋转绕第二次旋转后生成的从动坐标系的 *z* 轴。

三维旋转在第二次旋转为正或负 90 degrees 的构型处具有运动学奇异。在这些构型中，第一和第三旋转轴对齐，关节失去一个自由度。

要指定关节基元初始状态的目标，请使用 **State Targets** 下的参数。目标在基坐标系中指定。还可以为这些目标设置优先级。如果关节无法满足所有状态目标，优先级将确定先满足哪些目标以及满足它们的接近程度。有关示例，请参阅 How Multibody Assembly Works 的 Guiding Assembly 部分。

要为关节基元对阻尼和弹簧行为建模，请使用 **Internal Mechanics** 下的参数。使用 **Damping Coefficient** 参数对能量耗散建模，使用 **Spring Stiffness** 参数对能量存储建模。关节弹簧尝试使关节基元离开其平衡位置，而关节阻尼器用作能量耗散元件。弹簧和阻尼器严格线性。

要指定关节基元的限值，请使用 **Limits** 下的参数。下限和上限定义自由区域的宽度。当位置超出边界时，模块施加力以将关节位置加速回自由区域。模块使用平滑弹簧-阻尼器方法计算该力。有关平滑弹簧-阻尼器方法的更多信息，请参阅 Spatial Contact Force 模块的“描述”部分。

**Actuation** 部分中的 **Force**、**Torque** 和 **Motion** 参数控制仿真期间关节基元的运动。有关更多信息，请参阅 Specifying Joint Actuation Inputs。此外，关节模块具有输出传感数据的端口，例如位置、速度、加速度、力和力矩，您可以使用这些数据对模型执行分析任务。有关更多信息，请参阅 Sensing 和 Force and Torque Sensing。

要指定关节模式配置，请使用 **Mode** 参数。有关更多详细信息，请参阅**端口**和**参数**部分下的 **Mode Configuration**。

### Faults

使用模式故障，您可以在仿真期间更改关节模式，而无需修改模型设计。故障注入会覆盖模式设置。例如，如果某个关节的 **Mode** 参数设置为 `Locked`，并且 **Fault behavior** 参数设置为 `Disengaged`，则该关节将变为 disengaged。

要向关节模块添加模式故障，请单击该关节模块，在 **Simscape Block** 选项卡和 **Faults** 部分中，单击 **Fault** > `Add Fault`。或者，您可以单击该关节模块，将鼠标悬停在省略号上以打开操作栏，然后单击 Add a fault on the block icon 按钮来添加故障。您可以向一个关节模块添加多个故障，但在仿真期间该关节模块只能有一个活动故障。

添加故障时，在 Property Inspector 中的 **Fault** 部分下，指定故障的行为和触发类型。要定义故障行为，请单击 **Fault Behavior** 旁边的链接。此关节支持 `Locked`、`Normal` 或 `Disengaged` 模式。关节模块支持以下触发类型：`Always on`、`Timed`、`Manual` 和 `Conditional`。有关这些触发类型的更多详细信息，请参阅 Set Fault Triggers。要触发条件故障，您可以使用 Simulink 信号、Simscape 语言模块和 MATLAB 工作区变量。要为模块设置活动故障，请使用 Fault Table。有关更多详细信息，请参阅 Access the Fault Table and Fault Dashboard。

要启用故障仿真，请在 **Simscape Block** 选项卡和 **Faults** 部分中，打开 **Fault Simulation** 按钮。当按钮为绿色且状态为 **on** 时，故障仿真处于开启状态。仿真会记录触发状态数据。要查看数据，请使用 Simulation Data Inspector。此外，您可以在 Fault Dashboard 中查看故障状态和已触发故障的摘要。要打开 Fault Dashboard，请在 **Simscape Block** 选项卡中单击 **Faults** > `Fault Dashboard`。

要创建和修改故障，您还可以使用 Simscape™ 和 Simulink® 故障函数。有关更多详细信息，请参阅 Simulink Fault Controls and Simscape Faults Interface 的函数部分。
