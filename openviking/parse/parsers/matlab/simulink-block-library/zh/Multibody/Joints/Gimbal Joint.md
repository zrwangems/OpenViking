# Gimbal Joint

## 端口

### 坐标系

### **B** — 基础坐标系 坐标系

关节模块的基础坐标系。

### **F** — 从动坐标系 坐标系

关节模块的从动坐标系。
### 输入

#### X 转动基元 (Rx)

### **tx** — 驱动力矩物理信号

物理信号输入端口，接受关节基元的驱动力矩。该模块将此力矩等值反向地施加到关节基元的基础坐标系和从动坐标系上。该力矩绕基础坐标系的 *x* 轴。在仿真过程中，从动坐标系和基础坐标系的 *x* 轴彼此对齐。

#### 依赖关系

要启用此端口，请在 **X 转动基元 (Rx)** > **驱动** 下，将 **力矩** 设置为 `Provided by Input`。

### **qx** — 运动轮廓物理信号

物理信号输入端口，接受关节基元的运动轮廓。该模块使用此信号来确定从动坐标系相对于基础坐标系绕基础坐标系 *x* 轴的旋转。该信号还必须包含旋转的一阶和二阶导数。

#### 依赖关系

要启用此端口，请在 **X 转动基元 (Rx)** > **驱动** 下，将 **运动** 设置为 `Provided by Input`。

#### 模式配置

### **mode** — 关节模式控制物理信号

用于控制关节模式的输入端口。该信号必须是无量纲标量。当输入信号为 `0` 时，关节模式为正常；当输入信号为 `-1` 时，关节模式为分离；当输入信号为 `1` 时，关节模式为锁定。你可以在仿真过程中的任意时刻更改模式。

下表显示了在模式之间切换时，关节的位置和速度如何变化。

| 切换 | 位置 | 速度 |
| --- | --- | --- |
| 正常到锁定 | 关节位置保留当前值，并在切换后保持不变。 | 关节速度变为零，并在切换后保持不变。 |
| 正常到分离 | 关节位置保留当前值，但在切换后可以沿任意方向变化。 | 关节速度保留当前值，但在切换后可以沿任意方向变化。 |
| 锁定到正常 | 关节位置保留当前值，但在切换后可以沿与关节自由度（DOF）对齐的方向变化。 | 关节速度保持为零，但在切换后可以沿与关节 DOF 对齐的方向变化。 |
| 锁定到分离 | 关节位置保留当前值，但在切换后可以沿任意方向变化。 | 关节速度保持为零，但在切换后可以沿任意方向变化。 |
| 分离到正常 | 对于与关节 DOF 对齐的方向，关节位置最初取通过使用牛顿法计算得到的值，此后可以变化。在受约束方向上，关节位置变为零，并在切换后保持不变。 | 对于与关节 DOF 对齐的方向，关节速度最初取通过使用牛顿法计算得到的值，此后可以变化。在受约束方向上，关节速度变为零，并在切换后保持不变。 |
| 分离到锁定 | 对于与关节 DOF 对齐的方向，关节位置最初取通过使用牛顿法计算得到的值，并在切换后保持不变。在受约束方向上，关节位置变为零，并在切换后保持不变。 | 关节速度变为零，并在切换后保持不变。 |

#### 依赖关系

要启用此端口，请在 **Mode Configuration** 下，将 **Mode** 设置为 `Provided by Input`。

## 描述

具有三个旋转基元的关节

Gimbal Joint 模块对具有三个旋转自由度的关节进行建模。该关节使从动坐标系能够相对于基座坐标系执行三维旋转。两个坐标系的原点重合。为实现三维旋转，万向关节具有三次顺序旋转，如图所示。

变换序列示意图

第一次旋转围绕从动坐标系的 *x* 轴，第二次旋转围绕第一次旋转后生成的从动坐标系的 *y* 轴，第三次旋转围绕第二次旋转后生成的从动坐标系的 *z* 轴。

万向关节在第二次旋转为正或负 90 度的构型下具有运动学奇异。在这些构型中，第一次和第三次旋转轴对齐，关节失去一个自由度。

要为关节基元指定初始状态的目标，请使用 **State Targets** 下的参数。目标在基座坐标系中指定。您还可以设置目标的优先级。如果关节无法满足所有状态目标，优先级决定先满足哪些目标以及满足的程度。有关示例，请参阅 How Multibody Assembly Works 的 Guiding Assembly 部分。

要为关节基元建模阻尼和弹簧行为，请使用 **Internal Mechanics** 下的参数。使用 **Damping Coefficient** 参数建模能量耗散，使用 **Spring Stiffness** 参数建模能量存储。关节弹簧试图将关节基元从其平衡位置移开，关节阻尼器充当能量耗散元件。弹簧和阻尼器严格线性。

要指定关节基元的限位，请使用 **Limits** 下的参数。下限和上限定义自由区域的宽度。当位置超出边界时，模块施加力以将关节位置加速回自由区域。模块使用平滑弹簧-阻尼方法计算力。有关平滑弹簧-阻尼方法的详细信息，请参阅 Spatial Contact Force 模块的描述部分。

**Actuation** 部分中的 **Force**、**Torque** 和 **Motion** 参数控制仿真期间关节基元的运动。有关详细信息，请参阅 Specifying Joint Actuation Inputs。此外，关节模块具有输出传感数据的端口，例如位置、速度、加速度、力和扭矩，您可以使用这些数据对模型执行分析任务。有关详细信息，请参阅 Sensing 和 Force and Torque Sensing。

要指定关节模式配置，请使用 **Mode** 参数。有关更多详细信息，请参阅 **Ports** 和 **Parameters** 部分下的 **Mode Configuration**。

### 故障

使用模式故障，您可以在仿真过程中更改关节模式，而无需修改模型设计。故障注入会覆盖模式设置。例如，如果一个关节的 **Mode** 参数设置为 `Locked`，并且 **Fault behavior** 参数设置为 `Disengaged`，则该关节变为分离状态。

要向关节模块添加模式故障，请点击关节模块，在 **Simscape Block** 选项卡中的 **Faults** 部分，点击 **Fault** > `Add Fault`。或者，您可以点击关节模块，将鼠标悬停在省略号上以打开操作栏，然后点击 Add a fault on the block icon Button 以用于添加故障。您可以向一个关节模块添加多个故障，但该关节模块在仿真期间只能有一个活动故障。

在添加故障时，在 Property Inspector 中的 **Fault** 部分下，指定故障的行为和触发类型。要定义故障行为，请点击 **Fault Behavior** 旁边的链接。此关节支持 `Locked`、`Normal` 或 `Disengaged` 模式。关节模块支持以下触发类型：`Always on`、`Timed`、`Manual` 和 `Conditional`。有关这些触发类型的更多详细信息，请参阅 Set Fault Triggers。要触发条件故障，您可以使用 Simulink 信号、Simscape 语言模块和 MATLAB 工作区变量。要为模块设置活动故障，请使用 Fault Table。有关更多详细信息，请参阅 Access the Fault Table and Fault Dashboard。

要启用故障仿真，请在 **Simscape Block** 选项卡中的 **Faults** 部分，打开 **Fault Simulation** 按钮。当按钮为绿色且状态为 **on** 时，故障仿真已开启。仿真会记录触发状态数据。要查看数据，请使用 Simulation Data Inspector。此外，您可以在 Fault Dashboard 中查看故障状态和已触发故障的摘要。要打开 Fault Dashboard，请在 **Simscape Block** 选项卡中，点击 **Faults** > `Fault Dashboard`。

要创建和修改故障，您还可以使用 Simscape™ 和 Simulink® 故障函数。有关更多详细信息，请参阅 Simulink Fault Controls 和 Simscape Faults Interface 的函数部分。
