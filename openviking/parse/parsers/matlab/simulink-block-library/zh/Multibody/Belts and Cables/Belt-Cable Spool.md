# Belt-Cable Spool

## 端口

### Frame

### **R** — 局部参考坐标系 frame

用于将卷筒连接到多体模型其余部分的参考坐标系。
### Belt-Cable

### **A** — 卷筒缆绳连接点 belt-cable

绳索中心线与卷筒节圆之间的切点。

## 参数

### **Pitch Radius** — 从卷筒中心到绳索中心线的距离 `10 cm`（默认）| 以长度单位为单位的正标量

从卷筒中心到绳索运行轴线的距离，在发生接触的弧线内测量。在复合滑轮系统中，节圆半径的差异通常决定了速度降低或扭矩增大的比率。

### **Sensing** — 选择要感测的运动学变量 `Unchecked`（默认）| Checked

选择要感测的运动学变量。选中复选框以公开对应变量的物理信号端口。可供感测的变量包括：

- **Spool Angle A** — 在参考坐标系的
  *xy* 平面内测量的角度，从局部 *x* 轴到坐标系原点与接触点 **A** 之间的连线。

  如果接触点位于
  *xz* 平面上方（在参考坐标系的 +*y* 区域内），则该角度为正。如果接触点位于 *xz* 平面下方，则该角度为负。当接触点恰好位于 *xz* 平面内时，该角度为零。

  该角度不是模运算的。它不会被限制在
  360 度范围内——即完成一圈后跳回范围起点——而是随着重复旋转连续变化。卷筒每转一圈，测量值就增加（或减少）2π。

  使用端口 **qpa** 进行此测量。
- **Fleet Angle A** — 从参考坐标系的
  *xy* 平面到接触点 **A** 处绳索的角度。*xy* 平面与卷筒的中心平面相同。

  如果绳索从
  *xy* 平面上方（在参考坐标系的 +*z* 区域内）接近接触点，则该角度为正。如果绳索从下方接近，则该角度为负。当绳索在卷筒中心平面内接近接触点时，该角度为零。

  该角度是模运算的，也就是说其值是有界的——此处介于 -π/2 到 +π/2 之间。该范围是开区间。测量值可以在 -π/2 和 +π/2 之间变化，但不能达到任一极限。

  请注意，如果 Belt-Cable Properties 模块的 **Drum Belt-Cable
  Alignment** 参数设置为
  `Monitored Planar`，则滑轮组件必须是平面的，因此偏角始终为零。要对非平面组件进行建模，请使用该参数的默认设置：
  `Unrestricted`。

  使用端口 **qfa** 进行此测量。

## 描述

滑轮系统中绳索的源和汇

Belt-Cable Spool 模块表示一个圆柱形卷筒，滑轮系统的绳索缠绕在该卷筒上（并从其上展开）。卷筒标记了绳索的一端，以及电机或其他动力源通常对负载施加拉力的位置。Belt-Cable End 模块通常标记绳索的另一端，负载本身通常连接在该端。根据是缠绕还是展开，卷筒可以表现为绳索的无限源或无限汇。

卷筒充当滑轮系统特有的带缆域与所有其他多体组件通用的坐标系域之间的接口。带缆端口（**A**）标识要缠绕在卷筒上的绳索末端，以及该末端在滑轮系统中的相对位置。坐标系端口（**R**）标识卷筒的参考坐标系及其在更广泛的多体模型中的位置。

卷筒的自由度是卷筒连接到其他组件所用关节的函数。通常由转动关节提供这些自由度；在这种情况下，它们简化为绕单一轴（卷筒的轴）的旋转。通过关节直接以力矩或运动信号形式指定的驱动输入用于驱动卷筒并缠绕（或展开）绳索。

绳索以与卷筒圆周相切的方式进入和离开卷筒。按照右手定则，缠绕方向为绕卷筒旋转轴的逆时针方向。该轴按定义为局部参考坐标系（**R**）的 *z* 轴。要反转缠绕方向，必须翻转局部参考坐标系，使 *z* 轴指向相反方向——例如，通过 Rigid Transform 模块施加坐标系旋转。

模型中不考虑卷筒表面（光滑或带槽）。此外，假设绳索以恒定半径（*节圆*半径）的圆形缠绕在卷筒上，并与绞车的横截面共面。忽略因缠绕引起的卷筒半径变化。

默认情况下，绳索可以与其中心平面成一定角度（图中为 *θ*）进入和离开卷筒。该角度在仿真过程中可以变化——例如，由于卷筒在移动关节上的平移。虽然接触点始终位于卷筒的中心平面内，但卷筒安装在关节上时可以移动。绳索也可以被约束为在其中心平面内进入和离开卷筒。是否强制执行此约束取决于 Belt-Cable Properties 模块的设置。

卷筒及缠绕在其上的绳索的惯性也被忽略。要捕获固定质量卷筒的惯性，请使用 Cylindrical Solid 或 Inertia 模块。如果实体几何在模型中很重要，请考虑使用 Cylindrical Solid 模块。要捕获绳索在卷筒上缠绕和展开时的可变质量特性，请使用 Variable Solids 库中的模块——例如 Variable Cylindrical Solid 或 General Variable Mass。
