# Belt-Cable Properties

## 端口

### Belt-Cable

### **P** — 带缆网络连接点 belt-cable

带缆网络的连接点，此模块旨在指定该网络的属性。

## 参数

### **Drum Belt-Cable Alignment** — 允许绳索与卷筒中心平面之间的对齐类型 `Unrestricted`（默认）| `Monitored Planar`

允许绳索与卷筒（无论是滑轮还是卷轴）中心平面之间的对齐类型。选择 `Unrestricted` 以允许绳索以一定角度进入和离开卷筒中心平面。在仿真过程中，进入和离开角度可以不同。选择 `Monitored Planar` 以要求绳索始终沿其中心平面方向进入和离开卷筒。如果在任何时候接触角不为零，仿真将停止并报错。

### **Type** — 可视化绳索的方式 `Pitch Line`（默认）| `None`

在模型可视化中显示绳索的方式。默认设置对应于一条节线，该节线以各自模块中指定的节圆半径围绕每个滑轮和卷轴呈弧形。在绳索与滑轮或卷轴之间的接触范围内，线段为圆弧形；在圆弧之间的距离内，线段为直线。

### **Visual Properties** — 颜色和不透明度的参数化方式 `Simple`（默认）| `Advanced`

用于指定视觉属性的参数化方式。选择 `Simple` 以指定 **Diffuse Color** 和 **Opacity**。选择 `Advanced` 以指定更多视觉属性，例如 **Specular Color**、**Ambient Color**、**Emissive Color** 和 **Shininess**。

#### 依赖关系

要启用此参数，请将 **Type** 设置为 `From Geometry` 或 `Marker`。

### **Color** — 漫反射光的颜色 [0.5 0.5 0.5]（默认）| 值在 0 到 1 范围内的 3×1 或 1×3 向量 | 值在 0 到 1 范围内的 4×1 或 1×4 向量

在直接白光下图形的颜色，指定为 0–1 范围内的 [R G B] 或 [R G B A] 向量。可选的第四个元素 (A) 指定颜色的不透明度，范围为 0–1。省略不透明度元素等同于指定值为 1。

#### 依赖关系

要启用此参数，请设置：

1. **Type** 为 `From Geometry` 或 `Marker`
2. **Visual Properties** 为 `Simple`

### **Opacity** — 图形不透明度 1.0（默认）| 0 到 1 范围内的标量

图形不透明度，指定为 0 到 1 范围内的标量。标量为 0 对应于完全透明，标量为 1 对应于完全不透明。

#### 依赖关系

要启用此参数，请设置：

1. **Type** 为 `From Geometry` 或 `Marker`
2. **Visual Properties** 为 `Simple`

### **Diffuse Color** — 漫反射光的颜色 [0.5 0.5 0.5]（默认）| 值在 0 到 1 范围内的 3×1 或 1×3 向量 | 值在 0 到 1 范围内的 4×1 或 1×4 向量

漫反射光的颜色，指定为值在 0 到 1 范围内的 [R,G,B] 或 [R,G,B,A] 向量。该向量可以是行向量或列向量。可选的第四个元素指定颜色的不透明度。省略不透明度元素等同于指定值为 1。

漫反射颜色反映渲染实体的主色，并提供着色，使渲染对象呈现三维外观。

#### 依赖关系

要启用此参数，请设置：

1. **Type** 为 `From Geometry` 或 `Marker`
2. **Visual Properties** 为 `Advanced`

### **Specular Color** — 由于镜面反射产生的光颜色 [0.5 0.5 0.5 1.0]（默认）| 取值范围为 0 到 1 的 3×1 或 1×3 向量 | 取值范围为 0 到 1 的 4×1 或 1×4 向量

由于镜面反射产生的光颜色，指定为取值范围为 0 到 1 的 [R,G,B] 或 [R,G,B,A] 向量。该向量可以是行向量或列向量。可选的第四个元素指定颜色不透明度。省略不透明度元素等效于指定值为 1。此参数会改变镜面高光的颜色，镜面高光是由于光源的光被反射而在渲染实体上形成的亮点。

#### 依赖关系

要启用此参数，请设置：

1. **Type** 为 `From Geometry` 或
   `Marker`
2. **Visual Properties** 为
   `Advanced`

### **Ambient Color** — 环境光颜色 [0.15 0.15 0.15 1.0]（默认）| 取值范围为 0 到 1 的 3×1 或 1×3 向量 | 取值范围为 0 到 1 的 4×1 或 1×4 向量

环境光颜色，指定为取值范围为 0 到 1 的 [R,G,B] 或 [R,G,B,A] 向量。该向量可以是行向量或列向量。可选的第四个元素指定颜色不透明度。省略不透明度元素等效于指定值为 1。

环境光是指并非直接来自光源的一般照明水平。环境光由已经被反射和再反射很多次、以至于不再来自任何特定方向的光组成。您可以调整此参数来改变渲染实体的阴影颜色。

#### 依赖关系

要启用此参数，请设置：

1. **Type** 为 `From Geometry` 或
   `Marker`
2. **Visual Properties** 为
   `Advanced`

### **Emissive Color** — 自发光颜色 [0.0 0.0 0.0 1.0]（默认）| 取值范围为 0 到 1 的 3×1 或 1×3 向量

由于自发光产生的颜色，指定为取值范围为 0 到 1 的 [R,G,B] 或 [R,G,B,A] 向量。该向量可以是行向量或列向量。可选的第四个元素指定颜色不透明度。省略不透明度元素等效于指定值为 1。

发射颜色是不来自任何外部光源的颜色，因此看起来是由实体自身发射的。当实体具有发射颜色时，即使没有外部光源，也可以看到该实体。

#### 依赖关系

要启用此参数，请设置：

1. **Type** 为 `From Geometry` 或
   `Marker`
2. **Visual Properties** 为
   `Advanced`

### **Shininess** — 高光锐度 75（默认）| 取值约束为 0–128 的标量

镜面光反射的锐度，指定为 0–128 范围内的标量数值。增大 shininess 值可获得更小但更锐利的高光。减小该值可获得更大但更平滑的高光。

#### 依赖关系

要启用此参数，请设置：

1. **Type** 为 `From Geometry` 或
   `Marker`
2. **Visual Properties** 为
   `Advanced`

## 描述

滑轮系统绳索的一般特性

Belt-Cable Properties 模块设置滑轮绳索的属性，包括其几何形状和颜色，以及其对齐约束。出于可视化目的，绳索被视为具有颜色和不透明度的一维线。圆弧段跨越滑轮，直线段连接各弧之间的距离。

默认情况下，绳索可以以与其中心平面成一定角度的方式进入和退出卷筒——滑轮或卷轴。该角度在仿真过程中可以变化——例如，由于卷筒在移动副上的平移。虽然接触点始终位于卷筒的中心平面内，但当卷筒安装在运动副上时，卷筒可以移动。使用此策略可以对例如绳索在卷轴上的缠绕及其偏角（图中记为 *θ*）进行建模。

绳索也可以被约束为在其中心平面内进入和退出卷筒。装配体仍然可以是三维的，不同的滑轮位于不同的平面上，但前提是各接触角均为零。将 **Drum Belt-Cable Alignment** 模块参数设置为 `Monitored Planar` 以强制执行此约束。（由于该约束是被监测的，如果接触角不为零，仿真将停止并报错。）

其他属性由建模假设和计算自动设置。这些假设包括绳索无质量、不可伸长且始终张紧。长度在装配时刻确定，此后固定不变。其值与绳索精确跨越初始配置中所布置的滑轮系统一致。

该配置取决于模型中各运动副的起始位置。在可行的情况下，这些位置与运动副模块中指定的状态目标相匹配。可以使用这些目标来设置绳索的长度并引导其端点的放置——例如，对卷轴施加初始旋转或对承载锚点施加初始平移。

皮带-绳索端口（**P**）标识由此模块表征的绳索。端口在皮带-绳索网络中连接的位置无关紧要。然而，重要的是模型中的每个皮带-绳索网络都包含此模块的一个实例。如果两个皮带-绳索网络之间没有皮带-绳索连接线，则它们是不同的网络。

绳索的可视化默认开启，但可以在模块中将其抑制。如果开启，您可以点击绳索上的任意点以高亮其整个长度。在树视图窗格中查找与所选绳索关联的 Belt-Cable Properties 模块的名称——模块名称会在那里标识。右键单击模块名称并选择 `Go To Block`（如有必要）以更新绳索可视化属性。
