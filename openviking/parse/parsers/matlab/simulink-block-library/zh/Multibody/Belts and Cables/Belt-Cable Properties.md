# Belt-Cable Properties

## 端口

### Belt-Cable

### **P** — Belt-cable 网络连接点 belt-cable

此模块旨在指定其属性的 belt-cable 网络的连接点。

## 参数

### **Drum Belt-Cable Alignment** — 缆绳与鼓轮中心平面之间允许的对齐类型 `Unrestricted`（默认） | `Monitored Planar`

缆绳与鼓轮（无论是滑轮还是卷筒）中心平面之间允许的对齐类型。选择 `Unrestricted` 可使缆绳以一定角度进入和离开鼓轮中心平面。在仿真期间，进入和离开角度可以不同。选择 `Monitored Planar` 要求缆绳始终与鼓轮中心平面成一直线进入和离开鼓轮。如果任何时候接触角不为零，仿真将停止并报错。

### **Type** — 可视化缆绳的方式 `Pitch Line`（默认） | `None`

在模型可视化中显示缆绳的方式。默认设置对应于一条节线，该节线以各自模块中指定的节圆半径围绕每个滑轮和卷筒形成弧形。在缆绳与滑轮或卷筒之间的接触范围内，线段是圆弧；在圆弧之间的距离处，线段是直线。

### **Visual Properties** — 颜色和不透明度的参数化设置 `Simple`（默认） | `Advanced`

用于指定视觉属性的参数化设置。选择 `Simple` 可指定 **Diffuse Color** 和 **Opacity**。选择 `Advanced` 可指定更多视觉属性，例如 **Specular Color**、**Ambient Color**、**Emissive Color** 和 **Shininess**。

#### 依赖关系

要启用此参数，请将 **Type** 设置为 `From Geometry` 或 `Marker`。

### **Color** — 漫反射光的颜色 [0.5 0.5 0.5]（默认） | 值在 0 到 1 范围内的 3×1 或 1×3 向量 | 值在 0 到 1 范围内的 4×1 或 1×4 向量

直接白光下图形的颜色，指定为 0–1 尺度上的 [R G B] 或 [R G B A] 向量。可选的第四个元素 (A) 指定 0–1 尺度上的颜色不透明度。省略不透明度元素等效于指定值 1。

#### 依赖关系

要启用此参数，请设置：

1. 将 **Type** 设置为 `From Geometry` 或
   `Marker`
2. 将 **Visual Properties** 设置为
   `Simple`

### **Opacity** — 图形不透明度 1.0（默认） | 0 到 1 范围内的标量

图形不透明度，指定为 0 到 1 范围内的标量。标量 0 对应完全透明，标量 1 对应完全不透明。

#### 依赖关系

要启用此参数，请设置：

1. 将 **Type** 设置为 `From Geometry` 或
   `Marker`
2. 将 **Visual Properties** 设置为
   `Simple`

### **Diffuse Color** — 漫反射光的颜色 [0.5 0.5 0.5]（默认） | 值在 0 到 1 范围内的 3×1 或 1×3 向量 | 值在 0 到 1 范围内的 4×1 或 1×4 向量

漫反射光的颜色，指定为值在 0 到 1 范围内的 [R,G,B] 或 [R,G,B,A] 向量。该向量可以是行向量或列向量。可选的第四个元素指定颜色不透明度。省略不透明度元素等效于指定值 1。

漫反射颜色反映渲染实体的主色，并提供使渲染对象呈现三维外观的明暗效果。

#### 依赖关系

要启用此参数，请设置：

1. 将 **Type** 设置为 `From Geometry` 或
   `Marker`
2. 将 **Visual Properties** 设置为
   `Advanced`

### **Specular Color** — 镜面反射光的颜色 [0.5 0.5 0.5 1.0]（默认） | 值在 0 到 1 范围内的 3×1 或 1×3 向量 | 值在 0 到 1 范围内的 4×1 或 1×4 向量

镜面反射光的颜色，指定为值在 0 到 1 范围内的 [R,G,B] 或 [R,G,B,A] 向量。该向量可以是行向量或列向量。可选的第四个元素指定颜色不透明度。省略不透明度元素等效于指定值 1。此参数更改镜面高光的颜色，即由于光源反射而在渲染实体上产生的亮点。

#### 依赖关系

要启用此参数，请设置：

1. 将 **Type** 设置为 `From Geometry` 或
   `Marker`
2. 将 **Visual Properties** 设置为
   `Advanced`

### **Ambient Color** — 环境光的颜色 [0.15 0.15 0.15 1.0]（默认） | 值在 0 到 1 范围内的 3×1 或 1×3 向量 | 值在 0 到 1 范围内的 4×1 或 1×4 向量

环境光的颜色，指定为值在 0 到 1 范围内的 [R,G,B] 或 [R,G,B,A] 向量。该向量可以是行向量或列向量。可选的第四个元素指定颜色不透明度。省略不透明度元素等效于指定值 1。

环境光指并非直接来自光源的一般照明水平。环境光由经过多次反射和再反射、不再来自任何特定方向的光组成。可以调整此参数以更改渲染实体的阴影颜色。

#### 依赖关系

要启用此参数，请设置：

1. 将 **Type** 设置为 `From Geometry` 或
   `Marker`
2. 将 **Visual Properties** 设置为
   `Advanced`

### **Emissive Color** — 自发光颜色 [0.0 0.0 0.0 1.0]（默认） | 值在 0 到 1 范围内的 3×1 或 1×3 向量

自发光产生的颜色，指定为 0 到 1 范围内的 [R,G,B] 或 [R,G,B,A] 向量。该向量可以是行向量或列向量。可选的第四个元素指定颜色不透明度。省略不透明度元素等效于指定值 1。

发射颜色是不来自任何外部源的颜色，因此似乎由实体自身发射。当实体具有自发光颜色时，即使没有外部光源也可以看到该实体。

#### 依赖关系

要启用此参数，请设置：

1. 将 **Type** 设置为 `From Geometry` 或
   `Marker`
2. 将 **Visual Properties** 设置为
   `Advanced`

### **Shininess** — 高光锐度 75（默认） | 取值约束在 0–128 的标量

镜面光反射的锐度，指定为 0–128 尺度上的标量数值。增大 shininess 值可获得更小但更锐利的高光。减小该值可获得更大但更平滑的高光。

#### 依赖关系

要启用此参数，请设置：

1. 将 **Type** 设置为 `From Geometry` 或
   `Marker`
2. 将 **Visual Properties** 设置为
   `Advanced`

## 描述

滑轮系统缆绳的一般特性

Belt-Cable Properties 模块设置滑轮缆绳的属性，其中包括其几何形状和颜色，以及其对齐约束。为了可视化目的，缆绳被视为具有颜色和不透明度的一维线。圆弧段跨越滑轮，直线段连接圆弧之间的距离。

默认情况下，缆绳可以以相对于鼓轮中心平面的角度进入和离开鼓轮——滑轮或卷筒。该角度可以在仿真期间变化——例如，由于鼓轮在移动副上的平移。虽然接触点始终位于鼓轮的中心平面内，但当鼓轮安装在关节上时，鼓轮可以移动。使用此策略可以例如对缆绳在卷筒上的缠绕及其偏角（图中用 *θ* 表示）进行建模。

还可以约束缆绳在鼓轮的中心平面内进入和离开该鼓轮。装配体仍然可以是三维的，不同滑轮位于不同平面，但前提是每个接触角均为零。将 **Drum Belt-Cable Alignment** 模块参数设置为 `Monitored Planar` 以强制执行此约束。（由于该约束是受监控的，如果接触角应不为零，仿真将停止并报错。）

其他属性由建模假设和计算自动设置。这些假设包括缆绳无质量、不可伸长且始终张紧。长度在装配时刻确定，此后固定。其值与缆绳在初始配置中精确跨越按排列布置的滑轮系统一致。

该配置取决于模型中各个关节的起始位置。在可行的情况下，这些位置与关节模块中指定的状态目标匹配。可以使用这些目标来设置缆绳的长度并引导其端部的位置——例如，向卷筒施加初始旋转或向承载锚点施加初始平移。

belt-cable 端口（**P**）标识由此模块表征的缆绳。端口在带缆网络中连接的位置并不重要。然而，重要的是模型中的每个带缆网络都包含此模块的一个实例。如果两个带缆网络之间没有 belt-cable 连接线，则它们彼此不同。

默认情况下，缆绳的可视化处于开启状态，但可以在模块中将其抑制。如果开启，可以单击缆绳上的任意点以高亮显示其整个长度。在树视图窗格中查找与所选缆绳关联的 Belt-Cable Properties 模块的名称——模块名称将在那里标识。如果需要更新缆绳可视化属性，请右键单击模块名称并选择 `Go To Block`。
