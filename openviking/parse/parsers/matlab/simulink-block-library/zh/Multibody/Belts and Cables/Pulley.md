# Pulley

## 端口

### Frame

### **R** — 局部参考坐标系 frame

用于将滑轮连接到多体模型的 frame 网络的参考坐标系。
### Belt-Cable

### **A** — 滑轮绳索切点 belt-cable

绳索中心线与滑轮节圆之间的切点。绳索从端口 **A** 到端口 **B** 逆时针缠绕在滑轮上。

### **B** — 滑轮绳索切点 belt-cable

绳索中心线与滑轮节圆之间的切点。绳索从端口 **A** 到端口 **B** 逆时针缠绕在滑轮上。

## 参数

### **节圆半径** — 从滑轮中心到绳索中心线的距离 `10 cm`（默认） | 以长度单位表示的正标量

从滑轮中心到任意接触点处绳索中心线的距离。在复合滑轮系统中，节圆半径的差异通常决定速度降低或扭矩增大的比率。

### **初始包角** — 仿真开始时滑轮的最小包角 `0.0 deg`（默认） | 以度表示的正标量

**下界** — 指定滑轮初始包角的下界。仿真开始时的包角大于或等于此指定值。

### **传感** — 选择要传感的运动学变量 `Unchecked`（默认） | Checked

选择要传感的运动学变量。选中复选框可公开对应变量的物理信号端口。可供传感的变量包括：

- **Wrap Angle** — 从与端口 **A** 关联的接触点到与端口 **B** 关联的接触点的角度。此角度在滑轮的 (*xy*) 中心平面内测量。它始终等于或大于零，并且对于绕局部 *z* 轴逆时针的每一圈，其值增加 `2π`。使用端口 **qwrp** 进行此测量。

  图中显示了接触点（滑轮的 **A** 和 **B**）之间的包角。局部参考坐标系指示滑轮的 *x* 轴（水平）和 *y* 轴（垂直）。
- **Pulley Angle A** — 从局部 *x* 轴到坐标系原点与接触点 **A** 之间连线、在参考坐标系 *xy* 平面中测量的角度。

  如果接触点位于 *xz* 平面之上（在参考坐标系的 +*y* 区域中），则角度为正。如果接触点位于 *xz* 平面之下，则角度为负。当接触点恰好位于 *xz* 平面内时，角度为零。

  该角度不是模数角度。测量值不受 360 度范围约束——不会在完成一圈后跳回范围起点——而是随着重复旋转连续变化。滚筒每转一圈，测量值增加（或减少）2π。

  使用端口 **qpa** 进行此测量。

  **Pulley Angles A and B**
- **Pulley Angle B** — 从局部 *x* 轴到坐标系原点与接触点 **B** 之间连线、在参考坐标系 *xy* 平面中测量的角度。

  如果接触点位于 *xz* 平面之上（在参考坐标系的 +*y* 区域中），则角度为正。如果接触点位于 *xz* 平面之下，则角度为负。当接触点恰好位于 *xz* 平面内时，角度为零。

  该角度不是模数角度。测量值不受 360 度范围约束——不会在完成一圈后跳回范围起点——而是随着重复旋转连续变化。滚筒每转一圈，测量值增加（或减少）2π。

  使用端口 **qpb** 进行此测量。
- **Fleet Angle A** — 从参考坐标系的 *xy* 平面到接触点 **A** 处绳索的角度。*xy* 平面与滚筒的中心平面相同。

  如果绳索从 *xy* 平面之上（在参考坐标系的 +*z* 区域中）接近接触点，则角度为正。如果绳索从下方接近，则角度为负。当绳索在滚筒的中心平面内接近接触点时，角度为零。

  该角度是模数角度，也就是说其值有界——在这里介于 -π/2 到 +π/2 之间。该范围是开区间。测量值可以在 -π/2 和 +π/2 之间变化，但不能达到任一极限。

  请注意，如果 Belt-Cable Properties 模块的 **Drum Belt-Cable Alignment** 参数设置为 `Monitored Planar`，则滑轮组件必须是平面的，因此偏转角始终为零。要对非平面组件建模，请使用该参数的默认设置：`Unrestricted`。

  使用端口 **qfa** 进行此测量。

  **Fleet Angle A**
- **Fleet Angle B** — 从参考坐标系的 *xy* 平面到接触点 **B** 处绳索的角度。*xy* 平面与滚筒的中心平面相同。

  如果绳索从 *xy* 平面之上（在参考坐标系的 +*z* 区域中）接近接触点，则角度为正。如果绳索从下方接近，则角度为负。当绳索在滚筒的中心平面内接近接触点时，角度为零。

  该角度是模数角度，也就是说其值有界——在这里介于 -π/2 到 +π/2 之间。该范围是开区间。测量值可以在 -π/2 和 +π/2 之间变化，但不能达到任一极限。

  请注意，如果 Belt-Cable Properties 模块的 **Drum Belt-Cable Alignment** 参数设置为 `Monitored Planar`，则滑轮组件必须是平面的，因此偏转角始终为零。要对非平面组件建模，请使用该参数的默认设置：`Unrestricted`。

  使用端口 **qfb** 进行此测量。

## 描述

用于传递扭矩和运动的缠绕有绳索的轮

Pulley 模块表示一个缠绕有绳索的带槽或带齿轮，这种装置常用于传递扭矩和运动，部分原因是其可提供的机械优势。滑轮（如果带齿则为链轮）是*理想*的：无质量且无摩擦，其表面与周围绳索之间不允许滑动，绳索本身也被理想化为绷紧且不可伸长。可单独使用滑轮，也可将其作为复合滑轮系统的一部分，例如起重机滑车组或汽车发动机的正时皮带。

滑轮有一个局部参考坐标系（frame 端口 **R**）和两个绳索切点（belt-cable 端口 **A** 和 **B**）。参考坐标系的原点置于滑轮中心，其 *z* 轴沿滑轮的旋转轴。绳索切点与绳索接触或离开滑轮的位置重合。这些位置在仿真期间可以变化。皮带或线缆从端口 **A** 到端口 **B** 缠绕在滑轮上，从而围绕 *z* 轴描绘出逆时针圆弧。

在两个滑轮的闭环系统中——例如皮带传动——belt-cable 端口的连接决定绳索几何形状是*交叉*还是*开口*。如下图所示，在 *z* 轴平行对齐的滑轮系统中，如果一个滑轮的端口 **A** 连接到另一个滑轮的端口 **A**，则绳索是交叉的；如果一个滑轮的端口 **A** 连接到另一个滑轮的端口 **B**，则绳索是开口的。如果不切换端口连接，而是翻转其中一个坐标系，使滑轮的 *z* 轴反平行，则效果相同。

滑轮的自由度完全取决于其连接的关节和约束（如果有）。通过旋转关节将滑轮连接到壳体，会赋予滑轮相对于壳体的一个旋转自由度；于是一个可相对于另一个自由旋转。通过直接连接、刚性变换或焊接关节将滑轮固定到另一个滑轮，会约束两者，使得如果一个旋转，则另一个也必须旋转。

默认情况下，绳索可以与其中心平面成一定角度进入和离开滑轮（图中为 *θ*）。该角度在仿真期间可以变化——例如，由于滑轮在移动关节上的平移。虽然接触点始终位于滑轮的中心平面内，但当安装在关节上时，滑轮可以移动。也可以约束绳索在滑轮的中心平面内进入和离开滑轮。是否强制实施此约束取决于 Belt-Cable Properties 模块的设置。

各滑轮必须保持在能够保持绳索自然长度的距离。该长度根据滑轮的初始布局计算，并且是固定的：绳索在仿真期间既不能拉伸也不能松弛。长度计算包括绳索绕滑轮的弧长。它们之间的接触被理想化为无滑动，绳索上的接触点始终以与其在滑轮上的对应点相同的瞬时速度运动。

请注意，frame 和 belt-cable 端口属于不同的多体域。通常，端口只连接到同类端口——frame 端口连接到其他 frame 端口，belt-cable 端口连接到其他 belt-cable 端口。belt-cable 域有特殊要求：每条网络或 belt-cable 连接线连接到一个（且不超过一个）Belt-Cable Properties 模块。通过该模块配置绳索的可视化，并在（模型图更新时）计算绳索的长度。

绳索的可视化采用节线的形式。绳索与滑轮在其圆周相切处接触和分离。绳索与滑轮之间的接触弧称为节弧。绳索的节线是不同滑轮之间的线段及其各自节弧之和。滑轮之间的线段显示为直线，这与不允许发生松弛的约束一致。

将 Pulley 模块与 Belt-Cable Spool 模块组合使用，以从绞盘收回额外长度的绳索，并将其返还给绞盘。一个示例应用是塔式起重机吊钩组的下降和上升。使用 Belt-Cable End 模块定义绳索的端点。该端点包含一个 frame，用于连接到载荷、固定装置或多体模型的其他部分。
