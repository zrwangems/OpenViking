# Pulley

## 端口
```yaml
ports:
- name: R
  summary: 局部参考坐标系 frame
  direction: unspecified
- name: A
  summary: 带轮绳索切点 belt-cable
  direction: unspecified
- name: B
  summary: 带轮绳索切点 belt-cable
  direction: unspecified
```

### Frame

### **R** — 局部参考坐标系 frame

用于将带轮连接到多体模型的机架网络的参考坐标系。
### Belt-Cable

### **A** — 带轮绳索切点 belt-cable

绳索中心线与带轮节圆之间的切点。绳索从端口 **A** 到端口 **B** 逆时针缠绕在带轮上。

### **B** — 带轮绳索切点 belt-cable

绳索中心线与带轮节圆之间的切点。绳索从端口 **A** 到端口 **B** 逆时针缠绕在带轮上。
## 参数
```yaml
parameters:
- name: Pitch Radius
  summary: 从带轮中心到绳索中心线的距离 10 cm（默认）| 以长度单位为单位的正标量
  group: ''
- name: Initial Wrap Angle
  summary: 仿真开始时带轮的最小包角 0.0 deg（默认）| 以度为单位的正标量
  group: ''
- name: Sensing
  summary: 选择要感测的运动学变量 Unchecked（默认）| Checked
  group: ''
```

### **Pitch Radius** — 从带轮中心到绳索中心线的距离 `10 cm`（默认）| 以长度单位为单位的正标量

从带轮中心到任意接触点处绳索中心线的距离。在复合带轮系统中，节圆半径的差异通常决定了速度降低或扭矩增大的比率。

### **Initial Wrap Angle** — 仿真开始时带轮的最小包角 `0.0 deg`（默认）| 以度为单位的正标量

**Lower Bound** — 指定带轮初始包角的下界。仿真开始时的包角大于或等于此指定值。

### **Sensing** — 选择要感测的运动学变量 `Unchecked`（默认）| `Checked`

选择要感测的运动学变量。选中某个复选框将为对应变量暴露一个物理信号端口。可用于感测的变量包括：

- **Wrap Angle** — 从与端口 **A** 相关联的接触点到与端口 **B** 相关联的接触点之间的角度。该角度在带轮的的中心（*xy*）平面内测量。它始终大于或等于零，其值在绕局部 *z* 轴逆时针每旋转一圈时增加 `2π`。使用端口 **qwrp** 进行此测量。

  该图显示了带轮的接触点（**A** 和 **B**）之间的包角。局部参考坐标系指示了带轮的 *x* 轴（水平）和 *y* 轴（垂直）。
- **Pulley Angle A** — 在参考坐标系的 *xy* 平面内测量的、从局部 *x* 轴到坐标系原点与接触点 **A** 之间连线的角度。

  如果接触点位于 *xz* 平面之上（在参考坐标系的 +*y* 区域中），则该角度为正。如果接触点位于 *xz* 平面之下，则该角度为负。当接触点恰好位于 *xz* 平面内时，该角度为零。

  该角度不是模量化的。它不会被限制在 360 度范围内——即完成一圈后不会跳回该范围的起点——而是会随着重复旋转而连续变化。滚筒每旋转一圈，测量值都会增加（或减少）2π。

  使用端口 **qpa** 进行此测量。

  **Pulley Angles A and B**
- **Pulley Angle B** — 在参考坐标系的 *xy* 平面内测量的、从局部 *x* 轴到坐标系原点与接触点 **B** 之间连线的角度。

  如果接触点位于 *xz* 平面之上（在参考坐标系的 +*y* 区域中），则该角度为正。如果接触点位于 *xz* 平面之下，则该角度为负。当接触点恰好位于 *xz* 平面内时，该角度为零。

  该角度不是模量化的。它不会被限制在 360 度范围内——即完成一圈后不会跳回该范围的起点——而是会随着重复旋转而连续变化。滚筒每旋转一圈，测量值都会增加（或减少）2π。

  使用端口 **qpb** 进行此测量。
- **Fleet Angle A** — 从参考坐标系的 *xy* 平面到接触点 **A** 处绳索的角度。*xy* 平面与滚筒的中心平面相同。

  如果绳索从 *xy* 平面之上（在参考坐标系的 +*z* 区域中）接近接触点，则该角度为正。如果绳索从下方接近，则该角度为负。当绳索在滚筒的中心平面内接近接触点时，该角度为零。

  该角度是模量化的，也就是说它的值是有界的——这里介于 -π/2 到 +π/2 之间。该范围是开区间。测量值可以在 -π/2 和 +π/2 之间变化，但不能达到任一极限。

  请注意，如果 Belt-Cable Properties 模块的 **Drum Belt-Cable Alignment** 参数设置为 `Monitored Planar`，则要求带轮组件为平面结构，因此偏角始终为零。要对非平面组件建模，请使用该参数的默认设置：`Unrestricted`。

  使用端口 **qfa** 进行此测量。

  **Fleet Angle A**
- **Fleet Angle B** — 从参考坐标系的 *xy* 平面到接触点 **B** 处绳索的角度。*xy* 平面与滚筒的中心平面相同。

如果绳索从 *xy* 平面上方（参考系的 +*z* 区域）接近接触点，则该角度为正。如果绳索从下方接近，则该角度为负。当绳索在卷筒的中心平面内接近接触点时，该角度为零。

该角度是模块化的，也就是说其取值是有界的——在此处，介于 -π/2 到 +π/2 之间。该范围是开区间。测量值可以在 -π/2 和 +π/2 之间变化，但不能达到任一极限。

请注意，如果 Belt-Cable Properties 模块的 **Drum Belt-Cable Alignment** 参数设置为 `Monitored Planar`，则滑轮组件必须是平面的，因此包角始终为零。要对非平面组件建模，请使用该参数的默认设置：`Unrestricted`。

使用端口 **qfb** 进行此测量。

## 描述

缠绕在绳索中用于传递扭矩和运动的轮

Pulley 模块表示一个缠绕在绳索中的带槽或带齿的轮，这种装置常用于传递扭矩和运动，部分原因在于它能提供机械优势。该滑轮（或带齿时的链轮）是*理想*的：无质量且无摩擦，其表面与周围绳索之间不允许打滑，绳索本身也被理想化为绷紧且不可伸长。可以单独使用该滑轮，也可以将其作为复合滑轮系统的一部分使用，例如起重机的滑轮组或汽车发动机的正时皮带。

该滑轮有一个局部参考坐标系（坐标系端口 **R**）和两个绳索切点（皮带-缆绳端口 **A** 和 **B**）。参考坐标系的原点位于滑轮中心，其 *z* 轴沿滑轮的旋转轴线方向。绳索切点与绳索接触或离开滑轮的位置重合。这些位置在仿真过程中可以发生变化。皮带或缆绳从端口 **A** 绕到端口 **B**，围绕滑轮沿 *z* 轴方向描绘出一条逆时针圆弧。

在两个滑轮组成的闭环系统中——例如皮带传动——皮带-缆绳端口的连接方式决定了绳索几何形状是*交叉*还是*开口*。如下图所示，在 *z* 轴平行对齐的滑轮系统中，如果一个滑轮的端口 **A** 连接到另一个滑轮的端口 **A**，则绳索为交叉式；如果一个滑轮的端口 **A** 连接到另一个滑轮的端口 **B**，则绳索为开口式。如果不切换端口连接，而是将其中一个坐标系翻转使滑轮的 *z* 轴反平行，效果相同。

滑轮的自由度完全取决于其所连接的关节和约束（如果有的话）。通过转动关节将滑轮连接到壳体上，赋予滑轮相对于壳体的一个旋转自由度；此时两者可以相对旋转。通过直接连接、刚性变换或焊接关节将滑轮固定到另一个滑轮上，则约束两者使得如果一个旋转，另一个也必须旋转。

默认情况下，绳索可以以与其中心平面成一定角度（图中为 *θ*）的方向进入和离开滑轮。该角度在仿真过程中可以变化——例如，由于滑轮在移动关节上的平移。虽然接触点始终位于滑轮的中心平面内，但当安装在关节上时，滑轮可以移动。绳索也可以被约束为在其中心平面内进入和离开滑轮。是否强制执行此约束取决于 Belt-Cable Properties 模块的设置。

各滑轮之间的距离必须保持绳索的自然长度不变。该长度由滑轮的初始位置计算得出，并且是固定的：绳索在仿真过程中既不能拉伸也不能松弛。长度计算包括绳索绕滑轮的弧长。它们之间的接触被理想化为无滑动，绳索上的接触点始终与其在滑轮上的对应点具有相同的瞬时速度。

请注意，坐标系端口和皮带-缆绳端口属于不同的多体域。通常，端口只连接到同类端口——坐标系端口连接到其他坐标系端口，皮带-缆绳端口连接到其他皮带-缆绳端口。皮带-缆绳域有一个特殊要求：每个网络或皮带-缆绳连接线连接到一个（且不超过一个）Belt-Cable Properties 模块。正是通过该模块配置绳索的可视化，并在（图更新时）计算绳索的长度。

绳缆的可视化形式为节线。绳缆与带轮在其圆周相切处接触和分离。绳缆与带轮之间的接触弧称为节弧。绳缆的节线是不同带轮之间的线段与各自节弧之和。带轮之间的线段显示为直线，这与不允许发生松弛的约束条件一致。

将 Pulley 模块与 Belt-Cable Spool 模块结合使用，以从绞盘收回绳缆并向其返回额外的绳缆长度。一个示例应用是塔式起重机吊钩组的下降和上升。使用 Belt-Cable End 模块为绳缆定义端点。该端点包含一个坐标系，用于连接到载荷、固定装置或多体模型的其他部分。
