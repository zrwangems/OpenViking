### **整数溢出时饱和** — 溢出操作的方法 `off`（默认） | `on`

指定整数溢出是饱和还是回绕。

- `on` — 溢出饱和到该数据类型可以表示的最小值或最大值。
- `off` — 溢出回绕到该数据类型可以表示的相应值。

例如，有符号 8 位整数 `int8` 可以表示的最大值为 127。任何大于该最大值的模块运算结果都会导致该 8 位整数溢出。

- 选中此参数时，模块输出在 127 处饱和。
  同样，模块输出在最小输出值 –128 处饱和。
- 清除此参数时，软件会将导致溢出的值解释为 `int8`，这可能会产生意外结果。
  例如，模块结果 130（二进制 1000 0010）表示为 `int8` 时为 –126。

#### 提示

- 当模型可能发生溢出，并且您希望在生成代码中提供显式饱和保护时，将此参数设置为 `on`。
- 要优化生成代码的效率，请为此参数保留默认的 `off` 设置。使用默认设置还有助于避免过度指定模块处理超出范围信号的方式。有关详细信息，请参阅 Troubleshoot Signal Range Errors (Simulink)。
- 选中此参数时，饱和会应用于模块上的每个内部运算，而不仅仅是输出或结果。
- 通常，代码生成过程可以检测何时不可能发生溢出。在这种情况下，代码生成器不会生成饱和代码。

## 描述

修正线性单元 (ReLU) 层

ReLU Layer 模块对层输入应用修正线性单元 (ReLU) 激活
运算。ReLU 激活执行非线性阈值操作，其中任何
小于零的输入值都设置为零。

此运算等效于：

ReLU(x)={x,x>00,x≤0

`exportNetworkToSimulink` 函数生成此模块以表示 `reluLayer` 对象。
由于它应用逐元素运算，此模块支持任意格式的输入数据，并
输出与输入具有相同维度和格式的数据。
