### **Saturate on integer overflow** — 溢出操作的方法 `off`（默认）| `on`

指定整数溢出是饱和还是回绕。

- `on` — 溢出饱和到数据类型可以表示的最小值或最大值。
- `off` — 溢出回绕到数据类型可以表示的相应值。

例如，有符号 8 位整数 `int8` 可以表示的最大值是 127。任何大于最大值的模块运算结果都会导致 8 位整数溢出。

- 选中此参数时，模块输出饱和于 127。类似地，模块输出饱和于最小输出值 –128。
- 清除此参数时，软件将导致溢出的值解释为 `int8`，这可能会产生意外结果。例如，模块结果 130（二进制 1000 0010）表示为 `int8` 时为 –126。

#### 提示

- 当您的模型可能存在溢出并且您希望在生成的代码中具有显式饱和保护时，请将此参数设置为 `on`。
- 要优化生成代码的效率，请保留此参数的默认设置 `off`。使用默认设置还有助于避免过度指定模块如何处理超出范围的信号。有关详细信息，请参阅 Troubleshoot Signal Range Errors (Simulink)。
- 当您选择此参数时，饱和适用于模块上的每个内部运算，而不仅仅是输出或结果。
- 通常，代码生成过程可以检测到不可能发生溢出的情况。在这种情况下，代码生成器不会生成饱和代码。

## 描述

一维最大池化层

Max Pooling 1D Layer 模块通过将输入划分为一维池化区域，然后计算每个区域的最大值来执行下采样。

层池化所沿的维度取决于层输入：

- 对于 `CT` 格式的时间序列和向量序列输入（两个维度按顺序分别对应于通道和时间步），层沿时间维度进行池化。
- 对于 `SC` 格式的一维图像输入（两个维度按顺序分别对应于空间像素和通道），层沿空间维度进行池化。

`exportNetworkToSimulink` 函数生成此模块以表示 `maxPooling1dLayer` 对象。
