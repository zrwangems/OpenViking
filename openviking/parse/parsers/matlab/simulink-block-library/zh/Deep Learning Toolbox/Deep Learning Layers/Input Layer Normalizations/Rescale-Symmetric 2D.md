# Rescale-Symmetric 2D

## 端口

### 输入

### **Port\_1** — 输入数据 三维数组

要归一化的输入数据。数据必须具有三个维度，依次对应两个空间维度和一个通道维度。

**数据类型：** `single` | `double` | `int8` | `int16` | `int32` | `int64` | `uint8` | `uint16` | `uint32` | `uint64` | `fixed point`
### 输出

### **Port\_1** — 归一化输出数据 三维数组

归一化输出数据。输出数据具有三个维度，依次对应两个空间维度和一个通道维度。

### **Output saturate on integer overflow** — 输出转换操作的溢出操作方式 `off`（默认）| `on`

指定由最终定点转换操作生成的模块输出值的整数溢出是饱和还是回绕。有关内部模块操作的溢出操作方式，请参阅 **Internal saturate on integer overflow**。

- `on` — 溢出饱和到数据类型可以表示的最小值或最大值。
- `off` — 溢出回绕到数据类型可以表示的相应值。

例如，有符号 8 位整数 `int8` 可以表示的最大值是 127。任何大于最大值的模块操作结果都会导致 8 位整数溢出。

- 选中此参数时，模块输出饱和于 127。类似地，模块输出饱和于最小输出值 –128。
- 清除此参数时，软件将导致溢出的值解释为 `int8`，这可能会产生意外结果。例如，模块结果 130（二进制 1000 0010）表示为 `int8` 时为 –126。

#### 提示

- 当您的模型可能发生溢出并且您希望在生成的代码中提供显式饱和保护时，请将此参数设置为 `on`。
- 为了优化生成代码的效率，请保留此参数的默认设置 `off`。使用默认设置还有助于避免过度指定模块如何处理超出范围的信号。有关详细信息，请参阅 Troubleshoot Signal Range Errors (Simulink)。
- 当您选择此参数时，饱和仅应用于输出或结果。
- 通常，代码生成过程可以检测到不可能发生溢出的情况。在这种情况下，代码生成器不会生成饱和代码。

## 描述

具有 rescale-symmetric 归一化的二维输入层

Rescale-Symmetric 2D 模块将二维图像数据（具有三个维度的数据，按顺序分别对应两个空间维度和一个通道维度）输入到神经网络，并将输入重新缩放到范围 [-1, 1]。

`exportNetworkToSimulink` 函数生成此模块，以表示一个 `imageInputLayer` 对象，该对象的 `Normalization` 属性设置为 `"rescale-symmetric"`。
