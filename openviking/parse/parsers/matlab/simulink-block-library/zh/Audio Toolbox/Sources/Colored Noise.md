# Colored Noise

## 端口

### 输出

### **Port\_1** — 有色噪声信号 标量 | 向量 | 矩阵

有色噪声输出信号。信号的大小和数据类型取决于 **输出通道数**、**每个输出通道的采样点数** 和 **输出数据类型** 参数的值。

**数据类型：** `single` | `double`

## 参数

### **噪声颜色** — 生成的噪声颜色 `pink` (默认) | `white` | `brown` | `blue` | `purple` | `custom`

模块生成的噪声颜色。您可以将此参数设置为：

- `pink` — 生成粉红噪声。此选项等效于将 **逆频率的幂** 设置为 `1`。
- `white` — 生成白噪声（平坦功率谱密度）。此选项等效于将 **逆频率的幂** 设置为 `0`。
- `brown` — 生成棕色噪声。也称为红色噪声或布朗噪声。此选项等效于将 **逆频率的幂** 设置为 `2`。
- `blue` — 生成蓝噪声。也称为天蓝噪声。此选项等效于将 **逆频率的幂** 设置为 `-1`。
- `purple` — 生成紫罗兰色（紫色）噪声。此选项等效于将 **逆频率的幂** 设置为 `-2`。
- `custom` — 使用 **逆频率的幂** 参数指定噪声的功率密度。

### **逆频率的幂** — 逆功率谱密度分量 `1` (默认) | `[-2 2]` 范围内的标量

逆功率谱密度分量 *α*，指定为区间 `[-2 2]` 内的实值标量。该逆指数将随机过程的功率谱密度定义为 1/|*f*|α。此属性的默认值为 `1`。当 **逆频率的幂** 大于 `0` 时，模块生成低通噪声，并在 *f*`= 0` 处存在奇点（极点）。这些过程表现出长记忆性。当 **逆频率的幂** 小于 `0` 时，模块生成具有负相关增量的高通噪声。这些过程称为反持续过程。在功率随频率变化的双对数图中，Colored Noise 模块生成的过程呈现近似线性关系，其斜率等于 *–α*。

#### 依赖关系

要启用此参数，请将 **噪声颜色** 设置为 `custom`。

### **保证输出有界 (+/-1)** — 将输出边界设置为 +1 和 −1 `off` (默认) | `on`

选中此参数可将输出限制在 +1 和 −1 之间。

选中此参数时，生成噪声的内部随机源服从均匀分布。如果 **噪声颜色** 设置为 `white`，则不会对随机源的输出应用着色滤波器。输出为振幅介于 +1 和 −1 之间的均匀噪声。如果 **噪声颜色** 设置为任何其他选项，则先对随机源的输出应用着色滤波器，然后施加增益，以确保输出的最大绝对值永不超过 `1`。

未选中此参数时，内部随机源服从高斯分布。输出无界。

### **输出通道数** — 输出通道数 `1` (默认) | 正整数

输出通道数，指定为正整数标量。此参数定义生成信号的列数。

### **输出数据类型** — 输出数据类型 `double` (默认) | `single`

输出的数据类型，指定为 `double` 或 `single`。

### **每个输出通道的采样点数** — 输出每帧的采样点数 `1024` (默认) | 正整数

输出信号每帧中的采样点数，指定为正整数标量。此参数定义生成信号的行数。

### **输出采样时间 (s)** — 输出的采样时间 `1` (默认) | 正标量

输出信号的采样时间，指定为正标量，单位为 s。

### **初始种子** — 随机数生成器的初始种子 `67` (默认) | 正整数

随机数生成器算法的初始种子，指定为实值正整数标量。

### **仿真方式** — 要运行的仿真类型 `Interpreted execution` (默认) | `Code generation`

指定要运行的仿真类型。您可以将此参数设置为：

- `Interpreted execution` –– 使用 MATLAB® 解释器仿真模型。此选项可缩短启动时间。
- `Code generation` –– 使用生成的 C 代码仿真模型。首次运行仿真时，Simulink® 会为模块生成 C 代码。只要模型不发生更改，后续仿真就会重用该 C 代码。此选项需要额外的启动时间，但可提高后续仿真的速度。

## 描述

生成有色噪声信号

Colored Noise 模块生成有色噪声信号，其功率谱密度在整个频率范围内为 1/|*f*|α。逆功率谱密度分量 *α* 可以是区间 `[-2 2]` 内的任意值。模块生成的有色噪声类型取决于您在模块对话框中选择的 **噪声颜色** 选项。当您将 **噪声颜色** 设置为 `custom` 时，可以通过 **逆频率的幂** 参数指定噪声的功率密度。
