# Graphic EQ

## 端口

### 输入

### **Port\_1** — 输入信号矩阵 | 一维向量

- 矩阵输入 —— 输入的每一列被视为一个独立通道。
- 一维向量输入 —— 输入被视为一个信号通道。

**数据类型：** `single` | `double`
### 输出

### **Port\_1** — 输出信号矩阵

Graphic EQ 模块输出的信号与输入信号具有相同的数据类型。输出的大小取决于输入的大小：

- 矩阵输入 —— 模块输出与输入信号大小和数据类型相同的矩阵。
- 一维向量输入 —— 模块输出一个 *N*×1 矩阵（列向量），其中 *N* 是一维向量输入中的元素个数。

**数据类型：** `single` | `double`

## 参数

如果某个参数被列为可调，则可以在仿真期间更改其值。

### **EQ Order** — 各均衡器频段的阶数 `2`（默认）| 正偶数

将各均衡器频段的阶数指定为正偶数。所有均衡器频段具有相同的阶数。

**可调：** 是

### **Bandwidth** — 滤波器带宽（倍频程） `1 octave`（默认）| `2/3 octave` | `1/3 octave`

将滤波器带宽指定为 `1 octave`、`2/3 octave` 或 `1/3 octave`。

ANSI S1.11-2004 标准定义了均衡器的中心频率和边缘频率。ISO 266:1997(E) 标准规定了用于标记目的的相应优选频率。

### **Structure** — 实现类型 `Cascade`（默认）| `Parallel`

将实现类型指定为 `Cascade` 或 `Parallel`。有关这些实现结构的信息，请参阅算法和图形均衡。

**可调：** 否

### **Gains** — 各倍频程或分数倍频程频段的增益（dB） `0` | 标量

以 dB 为单位指定各倍频程或分数倍频程频段的增益。图形均衡器中滤波器的数量和位置取决于 **Bandwidth** 参数。

**可调：** 是

### **Variable name** — 导出滤波器的变量名 `myFilt`（默认）| 有效变量名

导出滤波器时，基本工作区中用于存放该滤波器的变量名称。该名称必须是有效的 MATLAB® 变量名。

### **Overwrite variable if it already exists** — 如果变量已存在则覆盖 `on`（默认）| `off`

选中此参数时，如果 **Variable name** 参数指定的变量已存在于基本工作区中，导出滤波器将覆盖该变量。如果未选中此参数且指定的变量已存在于工作区中，导出滤波器将创建一个新变量，在变量名后附加下划线和数字。例如，如果变量名为 `var` 且已存在，则导出的变量将命名为 `var_1`。

### **Export filter to workspace** — 将滤波器导出到工作区按钮

将滤波器导出到基本工作区中由 **Variable name** 参数指定的变量中。

#### 提示

如果启用了 **Inherit sample rate from input** 参数且模型未运行，则无法导出滤波器。

### **Inherit sample rate from input** — 指定输入采样率的来源 off（默认）| on

选中此参数时，模块从输入信号继承其采样率。清除此参数时，在 **Input sample rate (Hz)** 中指定采样率。

**可调：** 否

### **Input sample rate (Hz)** — 输入采样率 `44100`（默认）| 标量

**可调：** 是

#### 依赖关系

要启用此参数，请清除 **Inherit sample rate from input** 参数。

### **Simulate using** — 指定要运行的仿真类型 `Code generation`（默认）| `Interpreted execution`

- `Interpreted execution` —— 使用 MATLAB 解释器仿真模型。此选项缩短启动时间，仿真速度与 `Code generation` 相当。在此模式下，可以调试模块的源代码。
- `Code generation` —— 使用生成的 C 代码仿真模型。首次运行仿真时，Simulink® 为模块生成 C 代码。只要模型不变，后续仿真将重用该 C 代码。此选项需要额外的启动时间，但后续仿真的速度快于 `Interpreted execution`。

**可调：** 否

## 描述

基于标准的图形均衡器

Graphic EQ 模块实现了一个图形均衡器，可以调节各倍频程或分数倍频程频段的增益。该模块使用滤波器规格随时间对每个输入通道的数据进行独立滤波。图形均衡器中各频段的中心频率基于 ANSI S1.11-2004 标准。
