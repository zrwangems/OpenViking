# Vertical Slider



使用具有可自定义外观的垂直滑块更改参数或变量值

## 库

Simulink / Dashboard / Customizable Blocks

## 说明

使用 Vertical Slider 模块在仿真期间调整变量或模块参数的值。您可以自定义 Vertical Slider 模块的外观，使其看起来像真实系统中的控件。您可以调整刻度范围和刻度值，以适合要调整的值的所需范围。将 Vertical Slider 模块与其他仪表板模块一起使用，创建交互式仪表板来控制您的模型。

要在仿真运行时调整值，请使用指针将手柄拖到要将连接的变量或模块参数设置为的刻度值。要在仿真未运行时调整值，请点击 Vertical Slider 模块以选择该模块，然后将手柄拖到要将连接的变量或模块参数设置为的刻度值。

**注意**

- 在仿真期间或点击已连接的 Vertical Slider 模块后，双击该模块不会打开模块参数对话框。要打开模块参数对话框，请按 **Shift**，然后双击该模块。
- 在仿真期间点击已连接的 Vertical Slider 模块会同时选择该模块并移动滑块手柄。要选择该模块而不移动滑块手柄，请按 **Shift**，然后点击该模块。

### 自定义 Vertical Slider 模块

将 Vertical Slider 模块添加到模型时，该模块会预配置为默认设计。您可以将该模块与默认设计一起使用，也可以自定义该模块的外观。

要自定义模块的外观，请使用设计模式。选择模块后，可以通过以下三种方式之一进入设计模式：

- 在 Simulink® 工具条上，在该模块特定的选项卡上，在 **Design** 下，点击 **Edit**。
- 在属性检查器中，在 **Design** 选项卡上，点击 **Edit**。
- 暂停在模块上方出现的省略号上，然后点击编辑自定义模块按钮 。

在设计模式中，可以使用模块上方的工具栏自定义圆形仪表。要访问其他自定义选项或输入设计设置的精确值，请使用属性检查器中的 **Design** 选项卡。

处于设计模式中的 Vertical Slider 模块，显示工具栏和属性检查器中的 Design 选项卡。

**设计模式操作**

| 操作 | 在工具栏中可用 | 在 **Design** 选项卡中可用 |
| --- | --- | --- |
| 上传手柄图像。 | Yes | Yes |
| 上传背景图像。 | Yes | Yes |
| 设置纯色背景颜色。 | No | Yes |
| 上传前景图像。 | No | Yes |
| 指定值条从其增长的原点的位置。 | No | Yes |
| 更改刻度线、刻度标签或值条的颜色和不透明度。 | Yes | Yes |
| 将刻度方向指定为从左到右或从右到左。 | No | Yes |
| 更改刻度和手柄的大小。 | No | Yes |
| 更改刻度和手柄的位置。 | No | Yes |

要使用工具栏更改刻度线、刻度标签或值条的颜色和不透明度，请在工具栏左起第二部分中，选择要更改其颜色的组件。要更改颜色，请点击色轮。要更改不透明度，请移动滑块。

除了使用工具栏和 **Design** 选项卡自定义模块设计外，您还可以在画布中交互式调整组件的大小和位置。

完成设计编辑后，要退出设计模式，请点击画布右上角的 **X**。

### 连接仪表板模块

仪表板模块不使用端口连接到模型元素。要连接仪表板模块，请使用连接模式。要在未连接的模块上进入连接模式，请暂停在要连接的模块上，然后点击连接按钮 。要在已连接的模块上进入连接模式，请选择该模块，暂停在出现的省略号 (…) 上，然后在展开的操作菜单中点击连接按钮。

要将控制模块连接到模型中的参数或更改控制模块的连接，请进入连接模式。选择要将其参数连接到的模块。在出现的列表中，选择要连接到的参数。然后，暂停在仪表板模块上，并点击完成连接按钮 。

在更新模型图之前，控制模块无法连接到由变量定义的参数。要连接到由变量定义的参数，或在仿真未运行时修改定义已连接参数值的变量值，请按 **Ctrl+D** 更新模型图。

您可以连接到具有标量值的参数，也可以连接到矩阵或结构体的元素。有关详细信息，请参阅将仪表板模块连接到 Simulink 模型。

您还可以将仪表板模块连接到 Stateflow® 图。有关详细信息，请参阅将仪表板模块连接到 Stateflow (Stateflow)。

此动画显示如何将 Vertical Slider 模块连接到您的模型。

未连接的 Vertical Slider 模块连接到 Constant 模块。

### 参数记录

连接到仪表板模块的可调参数会记录到仿真数据检查器中，您可以在其中查看参数值以及记录的信号数据。您可以通过使用 UI 或 `Simulink.sdi.exportRun` 函数从仿真数据检查器导出参数数据，从而在 MATLAB® 工作区中访问记录的参数数据。有关使用仿真数据检查器 UI 导出数据的详细信息，请参阅将数据导出到工作区或文件。参数数据存储在 `Simulink.SimulationData.Parameter` 对象中，可作为导出的 `Simulink.SimulationData.Dataset` 中的元素进行访问。

## 参数

使用属性检查器和模块参数对话框指定模块参数的值。要设置仪表板模块的核心参数，请使用模块参数对话框或属性检查器中的 **Parameters** 选项卡。要自定义模块，请使用属性检查器中的 **Design** 选项卡。要打开模块的模块参数对话框，请双击该模块。要打开属性检查器，请在 **Modeling** 选项卡上，在 **Design** 下，选择 **Property Inspector**。

## 参数

要设置仪表板模块的核心参数，请打开属性检查器并点击 **Parameters** 选项卡。

#### 连接

### **Connection** — 要连接的模块参数值 参数值连接选项

仪表板模块不使用端口连接到模型元素。要将仪表板模块连接到模型中的参数值，请使用连接模式、Simulink 工具条或模块参数对话框中的 **Connection** 表。要从属性检查器打开模块参数对话框，请在 **Connected to** 右侧点击 **Connect** 或 **Change**。您可以连接到具有标量值的参数，也可以连接到矩阵的元素。有关连接模式以及如何使用工具条进行连接的信息，请参阅将仪表板模块连接到 Simulink 模型。

要使用 **Connection** 表将控制模块连接到具有标量值的参数，或更改控制模块与具有标量值的参数的连接：

1. 选择模块。
2. 要连接模块，请在属性检查器的 **Parameters** 选项卡上点击 **Connect**。要更改模块的连接，请改为点击 **Change**。
3. 选择要将其参数值连接到的模块。
4. 在表中，选择要连接到的参数。
5. 点击 **Apply**。

在更新模型图之前，控制模块无法连接到由变量定义的参数。要连接到由变量定义的参数，或在仿真未运行时修改定义已连接参数值的变量值，请按 **Ctrl+D** 更新模型图。

您还可以将仪表板模块连接到 Stateflow 图。有关详细信息，请参阅将仪表板模块连接到 Stateflow (Stateflow)。

### **Lock Aspect Ratio** — 保持模块宽高比的选项 `on` (default) | `off`

选择此参数以在 Simulink 画布中调整模块大小时保持宽高比。

当宽高比锁定时，添加新背景图像会将模块的宽高比更改为与背景图像的宽高比匹配。当宽高比未锁定时，添加新背景图像不会更改模块的宽高比，而是会更改背景图像的宽高比以适合模块大小。

当宽高比锁定时，在调整模块大小时按 **Shift** 键会临时解锁宽高比。释放 **Shift** 键时，宽高比会锁定。当宽高比未锁定时，在调整模块大小时按 **Shift** 键会临时锁定宽高比。释放 **Shift** 键时，宽高比会解锁。

要使用纯色背景颜色，请选择 **Use Background Color** 参数。然后，从标准颜色调色板中选择背景颜色，或指定自定义颜色。

**提示**

您还可以在 Simulink 工具条的 **Format** 选项卡中指定 **Background Color**。

要指定模块文本的颜色，请使用 **Font Color** 参数。

#### 编程用法

将模块的 `BackgroundColor` 参数指定为 `1`×`3` `[r g b]` 向量，其值介于 `0` 和 `1` 之间，并格式化为字符串或字符向量。

|  |
| --- |
| **模块参数：** `BackgroundColor` |
| **类型：** string | character vector |
| **值：** `[r g b]` vector |

### **Opacity** — 模块背景不透明度 `1` (default) | scalar

将模块背景不透明度指定为 `0` 到 `1` 之间的标量值。

**示例：** `0.5`

### **Corner Radius** — 具有模块背景颜色的区域的圆角半径 scalar

指定模块背景颜色所覆盖区域的圆角半径，作为模块两个尺寸（宽度或高度）中较小者的一半的比例。

**示例：** `0.25`

#### 前景图像

### **X Offset** — 前景图像左边缘相对于模块左边缘的水平偏移量 scalar

指定图像左边缘相对于模块左边缘的水平偏移量，作为模块宽度的比例。相对于偏移量为 `0` 时图像的位置，负值偏移量会将图像向左移动，正值偏移量会将图像向右移动。

**示例：** `1`

### **Y Offset** — 前景图像上边缘相对于模块上边缘的垂直偏移量 scalar

指定图像上边缘相对于模块上边缘的垂直偏移量，作为模块高度的比例。相对于偏移量为 `0` 时图像的位置，负值偏移量会将图像向上移动，正值偏移量会将图像向下移动。

**示例：** `1`

### **Width** — 前景图像宽度 scalar

指定前景图像的宽度，作为模块宽度的比例。

**示例：** `0.5`

### **Height** — 前景图像高度 scalar

指定前景图像的高度，作为模块高度的比例。

**示例：** `0.5`

### **Lock Aspect Ratio** — 保持前景图像宽高比的选项 `on` (default) | `off`

选择此参数以在使用属性检查器调整图像大小时保持宽高比。

## 版本历史

**在 R2021a 中引入**

### R2025a：在仿真期间选择仪表板模块并打开模块参数对话框

当来自 Dashboard 或 Customizable Blocks 库的 Simulink 模块处于*活动*状态时，您可以与该模块所代表的控件交互。例如，您可以按下按钮或拨动开关。当模块处于非活动状态时，您只能与该模块交互。例如，您可以移动或调整该模块的大小。默认情况下，来自 Dashboard 和 Customizable Blocks 库的所有模块在仿真期间都处于活动状态。提升到仪表板面板的模块在该面板在自己的窗口中打开或停靠并解锁时也处于活动状态。对于 Callback Button 模块，只要按下按钮触发的至少一个回调具有非空值，这些模块就始终处于活动状态。要与非活动模块所代表的控件交互，您可以通过点击该模块临时激活它。取消选择该模块后，该模块会再次变为非活动状态。

点击活动的 Callback Button 模块或来自 Dashboard 或 Customizable Blocks 库且连接到参数或变量值的活动模块，会同时选择该模块并与该模块所代表的控件交互。例如，点击未选中的活动已连接 Push Button 模块会同时选择该模块并按下按钮。从 R2025a 开始，您可以通过按 **Shift** 然后点击该模块来选择该模块而不与控件交互。同样，您可以通过按 **Shift** 然后双击该模块来打开模块参数对话框。

### R2024b：使用键盘解锁仪表板模块宽高比

如果来自 Dashboard 库的模块的宽高比已锁定，您可以通过按 **Shift** 临时解锁宽高比。释放 **Shift** 键时，宽高比会锁定。

如果宽高比未锁定，按 **Shift** 会临时锁定宽高比。释放 **Shift** 键时，宽高比会解锁。

### R2024a：将仪表板面板部署为 Web 应用或独立桌面应用

借助 Simulink Compiler™ 许可证，您现在可以将与面板所连接的模型一起打包的仪表板面板部署为独立桌面应用或 Web 应用。您可以使用该应用操作控件并监控面板上的显示，而不依赖于 Simulink。

要了解如何部署面板，请参阅将仪表板面板部署为应用。

### R2024a：停靠仪表板面板

从 R2024a 开始，您可以将仪表板面板停靠到 Simulink Editor 窗口。您可以使用停靠的面板在仿真期间监控信号和控制参数，而不会遮盖画布中的模型图。

有关详细信息，请参阅停靠面板。

### R2023b：在新窗口中打开面板

从 R2023b 开始，您可以在新窗口中打开仪表板面板。为此，请选择该面板并暂停在出现的省略号上。在展开的操作菜单中，点击在新窗口中打开 。

您可以从模型窗口单独最小化和还原包含该面板的新窗口。从面板窗口中，您可以运行、暂停、停止和单步执行仿真。在面板窗口中，您可以编辑面板及其包含的模块。

要将面板返回到模型画布，请在面板窗口工具条中点击在画布中打开 。

有关在新窗口中打开面板的详细信息，请参阅在新窗口中打开面板。

### R2023a：Simulink 工具条中的持久 Panels 选项卡

将仪表板面板添加到模型时，**Panels** 选项卡会出现在 Simulink 工具条中，并显示用于管理和编辑面板的选项。

以前，**Panels** 选项卡仅在选择了面板时可见。从 R2023a 开始，当未选择面板时，**Panels** 选项卡会保持可见。

**Panels** 选项卡还包含以下新选项：

- 您可以添加空面板。
- 您可以重命名所选面板。
- 您可以隐藏所选面板。

### R2022b：面板中可自定义仪表板模块的撤销和重做支持

从 R2022b 开始，您可以撤销和重做对面板中可自定义仪表板模块所做的更改。

要撤销或重做更改：

1. 点击面板或面板中的模块。
2. 按 **Ctrl+Z** 撤销更改，或按 **Ctrl+Y** 重做更改。

**注意**

键盘快捷键基于 Windows®。在 Mac 上，请按 **command** (⌘) 而不是 **Ctrl**。

### R2022b：工具条对面板的支持

从 R2022b 开始，您可以使用 Simulink 工具条管理和编辑面板及其包含的仪表板模块。

当您点击面板中的仪表板模块时，该模块的工具条选项卡会出现。例如，当您点击 Circular Gauge 模块时，**Gauge** 选项卡会出现在工具条中。

当您点击面板时，**Panel** 选项卡会出现在工具条中。该选项卡提供以下选项：

- 管理模型中面板的可见性。
- 使所有未隐藏的面板适合当前视图。
- 折叠所选面板。
- 自定义面板的大小和内容。
- 为所选面板设置自定义背景图像。
- 向所选面板添加新选项卡。
