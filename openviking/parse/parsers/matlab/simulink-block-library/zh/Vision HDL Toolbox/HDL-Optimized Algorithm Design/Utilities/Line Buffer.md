# Line Buffer

## 端口

### 输入

### **pixel** — 输入像素流 标量 | 向量

此模块支持单像素流式传输或多像素流式传输。对于单像素流式传输，将单个输入像素指定为标量强度值。对于多像素流式传输，将两个、四个或八个像素强度值指定为向量。有关如何为多像素流式传输设置模型的详细信息，请参阅 Filter Multipixel Video Streams。

此模块不支持多分量流式传输。要处理多分量流，请为每个分量复制该模块。所有分量的 `pixelcontrol` 总线完全相同，因此您可以将单个总线连接到多个复制的模块。

从 R2025a 开始，软件支持 `single` 数据类型用于仿真和 HDL 代码生成。要在您的模型中为 `single` 数据类型启用 HDL 代码生成，请打开 **HDL Coder** 应用，转到 **Floating Point** 窗格，并选中 **Use Floating Point** 复选框。`double` 数据类型仅支持仿真，不支持 HDL 代码生成。

**数据类型：** `int` | `uint` | `fixed point` | `Boolean` | `double` | `single`

### **ctrl** — 与像素流关联的控制信号 `pixelcontrol` 总线

`pixelcontrol` 总线包含五个信号。这些信号描述像素的有效性及其在帧中的位置。有关更多信息，请参阅 Pixel Control Bus。

对于多像素流式传输，每个像素值向量都有一组控制信号。由于该向量只有一个 `valid` 信号，因此向量中的像素必须全部有效或全部无效。`hStart` 和 `vStart` 信号适用于向量中索引最低的像素。`hEnd` 和 `vEnd` 信号适用于向量中索引最高的像素。

**数据类型：** `bus`

### 输出

### **pixel** — 邻域列 列向量 | 矩阵

邻域像素值列，返回为 1×*H* 向量，其中 *H* 是垂直邻域维度。使用多像素流式传输时，该模块返回 *M*×*H* 矩阵，其中 *M* 是输入向量中的像素数。输出像素数据类型与输入像素的数据类型相同。

要为后续处理组成邻域，请使用 **shiftEnable** 信号将每个内核区域的输出列（包括填充）存储在移位寄存器中。对于多像素流式传输，使用移位寄存器构造 *M* 个区域，每个区域包含 *W*×*H* 个像素，其中 *W* 是水平内核维度。然后，并行执行内核操作 *M* 次。

**注意**

小矩阵支持 HDL 代码生成，但矩阵运算可能会影响硬件性能和资源使用。因此，请尽量减少您的设计直接对 *W*×*H* 邻域进行操作的次数。您可以：

- 将滤波器分为垂直和水平分量。
- 将邻域像素串联成 (*W*\**H*)×1 向量。
- 使用 For Each 子系统存储并操作每个像素行。

这些设计建议提供了在每个加法器或乘法器周围添加流水线的机会，以提高综合时钟速度并使设计适合 FPGA 上的 DSP 模块。

**数据类型：** `int` | `uint` | `fixed point` | `Boolean` | `double` | `single`

### **ctrl** — 伴随输出列的控制信号 `pixelcontrol` 总线

伴随输出列的控制信号，返回为包含五个信号的 `pixelcontrol` 总线。这些信号描述列中心像素的有效性，以及该像素在帧中的位置。请参阅 Pixel Control Bus。

仅包含填充像素的列不会置位 **ctrl**.`valid`。**shiftEnable** 信号对于填充列和有效列都会置位。

**注意**

对于帧的大部分区域，该模块返回随列底部像素到达的输入控制信号。但是，对于每帧最后的 `floor(H/2)` 行，列的底部像素是填充像素，因此该模块生成输出控制信号。该模块为每行中的有效像素生成连续置位的 **ctrl**.`valid` 信号。

对于多像素流式传输，每个像素值向量都有一组控制信号。由于该向量只有一个 `valid` 信号，因此向量中的像素要么全部有效，要么全部无效。`hStart` 和 `vStart` 信号适用于向量中索引最低的像素。`hEnd` 和 `vEnd` 信号适用于向量中索引最高的像素。

**数据类型：** `bus`

### **shiftEnable** — 邻域列的有效信号 标量

邻域列的有效信号，返回为 `Boolean` 标量。使用此信号控制移位寄存器，该寄存器根据输出列组成邻域。对于任何邻域列，此信号为 `true` (1)，表示该列包含有效图像像素，或该列是为边缘填充而添加的。

**数据类型：** `Boolean`

## 参数

### **邻域大小** — 输出邻域的大小 `[3 3]`（默认） | 2 元素整数维度行向量

要形成的输出邻域的大小，指定为 2 元素整数维度行向量 [*H* *W*]，其中 *H* 是垂直维度，*W* 是水平维度。该模块返回包含 *H* 个元素的列向量。*W* 维度用于确定填充。

### **填充方法** — 填充输入图像边界的方法 `Symmetric`（默认） | `Constant` | `Replicate` | `Reflection` | `None`

选择以下方法之一来填充输入图像的边界。有关这些方法的更多信息，请参阅 Edge Padding。

- `Constant` — 将图像帧外的像素解释为具有常量值。
- `Replicate` — 重复图像边缘处像素的值。
- `Symmetric` — 将填充像素的值设置为镜像图像边缘。
- `Reflection` — 将填充像素的值设置为围绕图像边缘处像素反射。
- `None` — 排除填充逻辑。该模块不会将图像帧外的像素设置为任何特定值。此选项可减少模块使用的硬件资源以及帧之间所需的消隐，但会影响帧边缘处输出像素的精度。为保持像素流时序，输出帧与输入帧大小相同。但是，为避免使用由未定义填充值计算出的像素，请屏蔽掉帧边缘周围 *KernelSize*/2 个像素以用于下游操作。有关详细信息，请参阅 Increase Throughput by Omitting Padding。

### **填充值** — 用于填充输入图像边界的值 `0`（默认） | integer

指定一个整数来填充输入图像的边界。该模块会将该值转换为与输入像素相同的数据类型。

#### 依赖关系

要启用此参数，请将 **填充方法** 参数设置为 `Constant`。

### **行缓冲区大小** — 行内存缓冲区的大小 `2048`（默认） | positive integer

行内存缓冲区的大小，指定为正整数。选择一个可容纳水平行中有效像素数的 2 的幂。如果指定的值不是 2 的幂，则缓冲区使用下一个更大的 2 的幂。

使用多像素输入时，此值必须容纳 (**每行有效像素数**)/(**像素数**) + 2。

## 版本历史

**在 R2017b 中引入**

### R2025a：支持用于 HDL 代码生成的 `single` 数据类型

此模块现在支持使用 `single` 数据类型像素输入的 HDL 代码生成。

### R2025a：在模块掩膜上显示算法延迟

此模块现在在模块掩膜上显示其延迟。延迟显示为行数和像素数。确切的时钟周期数取决于图像帧一行中的像素数以及输入像素有效模式。使用显示的延迟信息以及 `pixelcontrol` 总线信号来对齐设计中的并行数据路径。

### R2022a：每时钟两像素流式传输

此模块现在支持每时钟周期 2 像素的多像素流。

### R2021b：Reflection 填充

通过围绕边缘像素值进行反射来填充帧边缘。此填充方法有助于减少边缘对比度效应，并可在保持原始帧大小的同时改善机器学习的结果。

### R2020a：省略填充的选项

您现在可以将模块配置为不在活动帧边界周围添加填充。此选项可减少模块使用的硬件资源以及帧之间所需的消隐，但会影响帧边缘处输出像素的精度。要使用此选项，请将 **填充方法** 参数设置为 `None`。有关示例，请参阅 Increase Throughput by Omitting Padding。

### R2019b：多像素流式传输

Line Buffer 模块现在支持多像素流。HDL 实现会为每个像素并行复制算法。

对于多像素流式传输，该模块接受 4 或 8 个像素的输入向量，并返回 *KernelHeight*×*NumberOfPixels* 矩阵。**ctrl** 端口保持为标量，`pixelcontrol` 总线中的控制信号适用于向量中的所有像素。

### R2018b：改进的行缓冲区

行缓冲区现在处理突发数据，即一个像素行内的非连续有效信号。由于改进的填充逻辑以及对具有偶数行数的内核大小的原生支持，此实现使用的硬件资源更少。此更改会影响 Line Buffer 模块以及使用内部行缓冲区的模块。

对于某些配置，行缓冲区的延迟现在减少了几个周期。您可能需要重新平衡模型中的并行路径延迟。最佳实践是使用像素流控制信号来同步模型中的并行路径，而不是插入特定数量的延迟。

## 描述

存储视频行并返回邻域像素

Line Buffer 模块从流式图像数据中选择邻域像素。它处理视频控制信号和边缘填充，并针对高速视频设计进行了流水线化。该模块一次输出邻域的一列。要为后续处理组成邻域，请使用 **shiftEnable** 信号将输出列（包括填充）存储在移位寄存器中。当您的设计对同一邻域执行多个操作时，此模块允许您共享行缓冲区资源。

以下波形显示 Line Buffer 模块返回构成 5×5 邻域的 5×1 像素列。所示时间帧位于输入帧的开头（左上角）。该模块存储两行（`floor(M/2)`）并正在接收第三行的开头后，输出开始。**shiftEnable** 信号比输出 **ctrl**.`valid` 信号提前两个周期置位，这表示前两列（`floor(M/2)`）完全是填充像素。类似地，**shiftEnable** 在一行末尾额外保持高电平两个周期。
