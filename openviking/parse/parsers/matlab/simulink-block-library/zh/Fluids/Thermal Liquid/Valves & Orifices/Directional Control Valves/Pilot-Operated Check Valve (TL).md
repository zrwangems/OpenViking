# Pilot-Operated Check Valve (TL)

## 端口

### 守恒

### **A** — 阀入口热液体

正常工作期间（当先导机构禁用时），工作流体必须通过该开口进入阀门。仅当先导端口被加压到足够程度时，该端口才可用作出口。

### **B** — 阀入口热液体

正常工作期间（当先导机构禁用时），工作流体必须通过该开口离开阀门。

### **X** — 先导端口热液体

通过该开口（施加足够压力）致动先导机构，使阀门打开以实现反向流动。

## 参数

### **压力控制规格** — 选择用作阀门控制信号的压力测量 `Pressure difference of port X relative to port A`（默认）| `Pressure at port X`

选择用作先导控制信号的压力测量。该模块使用所选测量值计算阀门的控制压力。（计算参见模块描述。）

在默认设置 `Pressure difference of port X relative to port A` 下，控制压力是先导端口（**X**）到入口（**A**）的压降的函数。在替代设置 `Pressure at port X` 下，它是入口表压的函数。

### **开启压力差** — 阀门首次开启时的有效控制压力 `0.01 MPa`（默认）| 压力单位的正标量

阀门开始开启时的有效压力差。该差值——模块描述中的*控制压力*——是入口到出口的压降与先导压力乘先导比所得乘积之和。（所用先导压力取决于 **压力控制规格** 参数的设置。）

### **最大开启压力差** — 阀门完全开启时的有效控制压力 `0.02 MPa`（默认）| 压力单位的正标量

阀门完全开启时的有效压力差。该差值——模块描述中的*控制压力*——是入口到出口的压降与先导压力乘先导比所得乘积之和。（所用先导压力取决于 **压力控制规格** 参数的设置。）

### **先导比** — 先导端口面积与入口端口面积之比 `1`（默认）| 正的无量纲标量

先导端口面积与入口端口面积之比。

### **最大开启面积** — 由于密封不完善，全开位置时的开启面积 `1e-4 m^2`（默认）| 面积单位的正标量

阀门处于压力调节范围上限时，完全开启位置的开启面积。

### **泄漏面积** — 由于密封不完善，最大关闭位置时的开启面积 `1e-10 m^2`（默认）| 面积单位的正标量

阀门处于最大关闭位置、仅端口之间存在内部泄漏时的开启面积。该参数主要用于确保阀门关闭不会导致流体网络的某些部分被隔离（已知会在仿真中引起问题的状况）。此处指定的确切值不如其为一个大于零的（非常小）数值重要。

### **平滑因子** — 要应用于阀门开启面积函数的平滑量 `0`（默认）

要应用于阀门开启面积函数的平滑量。该参数确定要平滑的区域的宽度——一个位于完全开启位置，另一个位于完全关闭位置。

平滑会在开启面积函数的每个区域上叠加一个非线性段（一个三阶多项式函数，平滑由此产生）。此处指定的值越大，平滑程度越高，非线性段越宽。

在默认值 `0` 下，不应用平滑。此时向最大关闭和完全开启位置的过渡会引入不连续性（与零穿越相关），这往往会减慢仿真速度。

### **端口 A 和 B 的横截面积** — 阀门端口处垂直于流动路径的面积 `0.01 m^2`（默认）| 面积单位的正标量

阀门端口处垂直于流动路径的面积。假定这些端口尺寸相同。此处指定的流动面积最好与相邻组件的入口面积匹配。

### **流量系数** — 定义为实际质量流量与理想质量流量之比的经验因子 `0.64`（默认）| 正的无量纲标量

通过阀门的实际流量与其在理想阀门中会具有的理论值之比。该半经验参数衡量允许通过阀门的流量：其值越大，流量越大。如有阀门数据表，请查阅该参数。

### **临界雷诺数** — 层流与湍流流态之间边界处的雷诺数 `150`（默认）| 正的无量纲标量

假定流动在层流与湍流流态之间转换时的雷诺数。

## 描述

带控制端口的单向阀，用于实现反向流动

Pilot-Operated Check Valve (TL) 模块对带有超控机构的单向阀进行建模，该机构在被激活时允许回流。（单向阀本身则是一个带有单向开启机构的节流孔，安装该机构正是为了防止这种回流。）

超控机构为阀门增加第三个端口——*先导*端口。正常工作时，先导端口不活动，阀门的行为与任何其他单向阀相同。此时，仅当穿过其的压降从入口到出口下降时，其节流孔才开启。回流需要反向压力梯度，因此不会发生。此模式保护阀门上游组件免受压力浪涌、温度尖峰以及（在实际系统中）来自下游点的化学污染的损害。

当需要回流时，先导端口被加压，阀门的控制元件——通常是球或活塞——被推离其阀座。此时阀门双向开启，反向压降（从出口指向入口）足以驱动流体向上游流动。（阀座位于流动路径中，决定阀门是否开启。当它被球、活塞或其他控制元件覆盖时，流动被切断，阀门关闭。）

阀门逐渐开启，从开启压力开始，持续到其压力调节范围末端。开启压力给出初始阻力，该阻力由摩擦或弹簧力引起，阀门必须克服该阻力才能微开（或*开启*）。低于此阈值时，阀门关闭，仅泄漏流可以通过。超过压力调节范围末端后，阀门完全开启，流量达到最大值（由瞬时压力条件决定）。

开启压力在倒置安装的单向阀中起着重要作用。在这种情况下，开启元件（例如球或活塞）的重量以及流体的高程压头可能促使阀门开启。（在模型中，当入口上游的管道垂直或倾斜时，可能产生高程压头。）足够的开启压力可防止阀门即使以不利角度放置时也不经意开启。

### 控制压力

阀门的开启既取决于先导压力，也取决于从入口到出口的压降：

pCtl=kXpX+pA−pB,

其中 *p* 是表压，*k* 是先导比——先导开启面积（*S*X）与阀门开启面积（*S*R）的比例。下标 `X` 表示先导值，下标 `A` 和 `B` 分别表示入口和出口值。端口压力是在仿真期间（相对于绝对零）确定的变量。

先导压力可以是相对于入口（端口 **A**）的差值，也可以是表压值（相对于环境）。可使用 **压力控制规格** 下拉列表选择合适的设置——`Pressure difference of port X relative to port A` 或 `Pressure at port X`。如果选择 `Pressure at port X`，

pX=pX,Abs−pAtm,

其中下标 `Atm` 表示大气值（从模型的 Thermal Liquid Settings (TL) 或 Thermal Liquid Properties (TL) 模块获得）。下标 `X,Abs` 表示先导端口处的绝对值。如果选择 `Pressure difference of port X relative to port A`，

pX=pX,Abs−pA,Abs

其中下标 `A,Abs` 类似地表示阀门入口（端口 **A**）处的绝对值。先导压力差被约束为大于或等于零——如果其计算值为负，则在控制压力计算中假定为零。

### 控制压力超调

控制压力超过开启压力的程度决定阀门将开启多少。压力超调在此表示为压力调节范围（宽度）的分数：

p^=pCtl−PCrkPMax−PCrk.

控制压力 *pCtl*、开启压力 *pCrk* 和最大开启压力 *P*Max 对应于所选择的控制压力规格：`Pressure differential` 或 `Pressure at port A`。

该分数——技术上，即*归一化*超调——在完全关闭的阀门中取值为 `0`，在完全开启的阀门中取值为 `1`。如果计算返回超出这些界限的值，则改用两者中最近的值。（换句话说，该分数在 `0` 和 `1` 处*饱和*。）

### 开启参数化

阀门面积的线性参数化为

Avalve=p^(Amax−Aleak)+Aleak,

其中归一化压力 p^ 为

p^=pcontrol−pcrackingpmax−pcracking.

当阀门在线性参数化中处于接近开启或接近关闭位置时，可以通过调整 **平滑因子** 参数来保持仿真中的数值稳健性。如果 **平滑因子** 参数非零，模块会在 *pcracking* 和 *pmax* 之间平滑地饱和控制压力。有关详细信息，请参见数值平滑。

### 开启面积

阀门面积随平滑后的控制压力线性开启，

S=(SMax−SMin)p^+SMin,

其中 *SMax* 是最大阀门面积，*SMin* 是 **泄漏面积** 参数的值。

### 动量平衡

阀门通道中产生的那些压力损失的原因在模块中被忽略。无论其性质如何——突变面积变化、流道扭曲——仿真期间仅考虑其累积效应。该效应在模块中由流量系数捕获，流量系数衡量通过阀门的质量流量相对于其在理想阀门中会具有的理论值。将阀门中的动量平衡表示为流动中引起的压降：

pA−pB=m˙Avgm˙Avg2+m˙Crit22ρAvgCDS\*2[1−(S\*S)2]ξp,

其中 *ρ* 是密度，*C*D 是流量系数，*ξ*p 是压降比——衡量出口处压力恢复对阀门总压降贡献程度的量。下标 Avg 表示热液体端口处值的平均值。临界质量流量 m˙Crit 由临界雷诺数计算——即假定阀门中的流动从层流转变为湍流时的雷诺数：

m˙Crit=ReCritμAvgπ4S,

其中 *μ* 表示动力粘度。压降比计算如下：

ξp=1−(S\*S)2(1−CD2)−CDS\*S1−(S\*S)2(1−CD2)+CDS\*S.

### 质量平衡

阀门内部流体的体积，以及因此其质量，被假定为非常小，并且出于建模目的被忽略。因此，任何数量的流体都不能在那里累积。根据质量守恒原理，通过一个端口进入阀门的质量流量因此必须等于通过另一个端口离开阀门的质量流量：

m˙A+m˙B=0,

其中 m˙ 定义为通过端口 **A** 或 **B** *进入*阀门的质量流量。

### 能量平衡

阀门被建模为绝热组件。流体与其周围壁之间不能发生热交换。流体从入口到出口穿过时，既不对流体做功，也不由流体做功。基于这些假设，能量只能通过端口 **A** 和 **B** 以平流方式流动。根据能量守恒原理，端口能量流之和因此必须始终等于零：

ϕA+ϕB=0,

其中 *ϕ* 定义为通过其中一个端口（**A** 或 **B**）*进入*阀门的能量流率。
