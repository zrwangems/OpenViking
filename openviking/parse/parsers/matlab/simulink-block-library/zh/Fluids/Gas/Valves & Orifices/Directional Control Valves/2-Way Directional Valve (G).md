# 2-Way Directional Valve (G)

## 端口

### 输入

### **S** — 阀控制信号，`unitless` 物理信号

控制构件相对于其正常未致动位置的瞬时位移，指定为物理信号。该模块将位移针对控制构件完全打开节流孔所需的最大位置进行归一化。该信号是无量纲的，其瞬时值通常介于 `0` 和 `1` 之间。

### 守恒

### **A** — 阀开口气体

与开口关联的气体守恒端口，流动通过该开口进入或离开阀。

### **B** — 阀开口气体

与开口关联的气体守恒端口，流动通过该开口进入或离开阀。

## 参数

### **阀门参数化** — 用于指定节流孔流动特性的参数化方式 `Cv flow coefficient`（默认） | `Kv flow coefficient` | `Sonic conductance` | `Orifice area`

计算质量流量的方法。

- `Cv flow coefficient` — 流量系数 *C*v 决定模块参数化。
- `Kv flow coefficient` — 流量系数 *K*v（其中 Kv=0.865Cv）决定模块参数化。
- `Sonic conductance` — 稳态时阻力元件的声速流导决定模块参数化。
- `Orifice area` — 节流尺寸决定模块参数化。

### **开启特性** — 计算阀开启特性的方法 `Linear`（默认） | `Tabulated`

该模块用于计算阀开启面积的方法。线性设置将开启面积视为节流孔开启分数的线性函数。表格设置允许使用可以表格形式指定的一般非线性关系。

### **开启分数向量** — 用于指定表格化参数数据的控制信号值 `0 : 0.2 : 1`（默认） | 正数向量

用于指定所选流量能力度量的控制信号值向量：**声速流导向量**、**Cv 系数向量**、**Kv 系数向量** 或 **节流孔面积向量**。控制信号介于 `0` 和 `1` 之间，其中每个值对应阻力元件的一个开启分数。值越大，开口越大，流动越容易。

开启分数必须在向量中从左到右单调增加。该向量的大小必须与 **声速流导向量**、**Cv 系数向量**、**Kv 系数向量** 或 **节流孔面积向量** 参数相同。

## 描述

气体网络中的受控双端口阀

2-Way Directional Valve (G) 模块表示一个具有两个端口 **A** 和 **B** 以及一条流动路径 **A**–**B** 的阀。该路径穿过一个宽度可变的节流孔。在端口 **S** 处指定的输入信号控制阀芯的位置。当阀芯覆盖节流孔开口时，阀关闭。

流动可以是层流或湍流，并且可以达到声速。最大流速发生在阀的喉部，此处流动最窄且最快。当下游压力下降不再能提高流速时，流动阻塞且流速饱和。当背压比达到该阀特有的临界值时发生阻塞。该模块不捕获超声速流动。

### 阀位置

阀是连续可变的，并在一个常位和一个工作位之间平滑切换。

当端口 **S** 处阀芯的瞬时位移为零时，阀恢复到常位，此时它不再工作。除非阀芯台肩相对于阀节流口存在偏移，否则阀完全关闭。工作位是当阀芯从常位沿正方向达到最大位移时阀移动到的位置。此时节流口完全打开。

使阀处于工作位的阀芯位移取决于阀芯上台肩的偏移。**Valve opening fraction offset** 参数指定各端口阀芯位移对应的模块常量。

**节流口开度分数**

在阀位置之间，**A**–**B** 节流口的开度取决于阀芯台肩相对于边缘的位置。该距离是节流口开口，模块对该距离进行归一化，使其值为节流口完全打开时最大距离的一个分数。归一化变量是节流口开度分数。

节流口开度分数的范围可以从常位下的 `0` 到工作位下的 `1`。模块根据阀芯位移和开度分数偏移计算开度分数。位移和偏移是无量纲量，表示为最大台肩-节流口距离的分数。节流口开度分数为：

hAB=HAB+x,

其中：

- *h* 是 **A**–**B** 节流口的开度分数。如果计算结果返回超出 `0 - 1` 范围的值，模块使用最近的限值。
- *H* 是 **Valve opening fraction offset** 参数的值。为了允许不寻常的阀配置，模块不对其值施加限制，尽管通常这些值会介于 `-1` 和 `+1` 之间。
- *x* 是由端口 **S** 处的物理信号指定的阀芯归一化瞬时位移。为了补偿极端开度分数偏移，对信号值没有限制。该值通常介于 `0` 和 `+1` 之间。

**开度分数偏移**

默认情况下，当控制位移为零时，阀完全关闭。在此状态下，阀为零遮盖。

您可以偏移阀芯的台肩，以对负遮盖阀或正遮盖阀进行建模。负遮盖阀在常位部分打开。正遮盖阀在略超过常位时完全关闭。该图显示了节流口开度分数如何随阀芯瞬时位移变化：

- 图 **I**：零遮盖阀。开度分数偏移为零。当阀处于常位时，阀芯台肩完全覆盖节流口。
- 图 **II**：负遮盖阀。开度分数偏移为正。当阀处于常位时，阀芯台肩部分覆盖节流口。
- 图 **III**：正遮盖阀。开度分数偏移为负。阀芯台肩不仅在常位完全覆盖节流口，而且在常位周围的阀芯位移小范围内也完全覆盖节流口。

**零遮盖、负遮盖和正遮盖阀中的控制位置**

**泄漏流量**

泄漏流量确保流体网络的任何部分都不会被隔离。被隔离的流体段会降低模型的数值稳健性，减慢仿真速率，并在某些情况下导致仿真失败。**Leakage flow fraction** 参数将模块中的泄漏流面积表示为大于零的小数。

**复合结构**

该模块是一个复合组件，包含一个连接在端口 **A**、**B** 和 **S** 之间的单个 Orifice (G) 模块。有关阀参数化和模块计算的更多详细信息，请参阅 Orifice (G) 模块。

### 阀参数化

模块行为取决于 **Valve parametrization** 参数：

- `Cv flow coefficient` — 流量系数 *C*v 决定模块参数化。流量系数衡量气体在特定压差驱动下流动的难易程度。[2][3]
- `Kv flow coefficient` — 流量系数 *K*v（其中 Kv=0.865Cv）决定模块参数化。流量系数衡量气体在特定压差驱动下流动的难易程度。[2][3]
- `Sonic conductance` — 稳态下阻力元件的声速流导决定模块参数化。声速流导衡量气体在 *壅塞* 时流动的难易程度，*壅塞* 是流速达到当地声速的状态。当下游压力与上游压力之比达到称为 *临界压力比* 的临界值时，会发生壅塞。[1]
- `Orifice area` — 节流限制的尺寸决定模块参数化。[4]

### 开度特性

流量特性将阀的开度与产生该开度的输入（通常是阀芯行程）联系起来。根据 **Valve parameterization** 参数的设置，模块将开度表示为声速流导、流量系数或节流面积。控制输入是节流口开度分数，它是端口 **S** 处指定的阀芯位移的函数。

流量特性通常在稳态下给出，此时入口处于恒定且经过精细控制的压力下。流量特性仅取决于阀，并且可以是线性的或非线性的。为捕获流量特性，请使用 **Opening characteristic** 参数：

- `Linear` — 流量能力的度量是节流口开度分数的线性函数。当开度分数从 `0` 升至 `1` 时，流量能力的度量从指定的最小值按比例变化到指定的最大值。
- `Tabulated` — 流量能力的度量是节流口开度分数的一般函数，该函数可以是线性的或非线性的。该函数以表格形式指定，其中自变量由 **Opening fraction vector** 指定。

### 数值平滑

当 **Opening characteristic** 参数为 `Linear`，且 **Smoothing factor** 参数非零时，模块会对节流口开度分数应用数值平滑。启用平滑有助于在仿真中保持数值稳健性。

有关更多信息，请参阅数值平滑。

### 假设和限制

- **Valve parameterization** 参数的 `Sonic conductance` 设置适用于气动应用。如果将此设置用于空气以外的气体，您可能需要按比重的平方根对声速流导进行缩放。
- 对于远离理想气体的气体，`Orifice area based on geometry` 参数化的方程准确性较低。
- 该模块不对超声速流进行建模。
