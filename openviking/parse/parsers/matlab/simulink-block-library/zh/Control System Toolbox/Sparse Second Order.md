# Sparse Second Order

## 端口

### 输入

### **Input 1** — 输入信号 标量 | 向量

类型为 `double` 的实值输入向量，其大小等于 **B** 和 **D** 矩阵中的列数。

**数据类型：** `double`
### 输出

### **Output 1** — 输出向量 标量 | 向量

类型为 `double` 的实值输出向量，其大小等于 **F**、**G** 和 **D** 矩阵中的行数。

**数据类型：** `double`

## 描述

在 Simulink 中表示稀疏二阶模型

Sparse Second Order 模块允许您在 Simulink® 中表示二阶稀疏状态空间模型。此类稀疏模型来自有限元分析 (FEA)，在结构分析、流体流动、传热和电磁学等领域非常有用。此类建模得到的矩阵通常非常大，并具有稀疏模式。在连续时间中，二阶稀疏质量-弹簧-阻尼状态空间模型表示为以下形式：

M q¨(t)+C q˙(t)+K q(t) = B u(t)
y(t) = F q(t)+G q˙(t)+D u(t)

这里，完整状态向量由 [q,q˙] 给出，其中 q 和 q˙ 是位移向量和速度向量。`u` 和 `y` 分别表示输入和输出。`M`、`C` 和 `K` 分别表示质量矩阵、阻尼矩阵和刚度矩阵。`B` 是输入矩阵，而 `F` 和 `G` 是由状态向量的两个分量得到的输出矩阵。`D` 是输入到输出矩阵。
