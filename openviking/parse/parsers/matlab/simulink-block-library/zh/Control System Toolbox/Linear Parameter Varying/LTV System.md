# LTV System

## 端口

### 输入

### **u** — 输入信号 标量 | 向量

指定输入信号 *u*(*t*)。在多输入情况下，此端口接受维度与输入维度相同的信号。

### **IC** — 初始条件向量

*自 R2024b 起*

用于启动仿真的局部模型的初始条件，指定为长度等于模型状态数的向量。

#### 依赖项

要启用此端口，请将 **初始条件源** 设置为 `external`。

### 输出

### **y** — 模型输出 标量 | 向量

线性时变模型的响应。

### **x** — 状态值 标量 | 向量

模型状态的值

#### 依赖项

要启用此端口，请在模块参数的 **输出** 选项卡上选择 **输出状态**。

### **dx** — 状态导数值 标量 | 向量

状态导数的值。

#### 依赖项

要启用此端口，请在模块参数的 **输出** 选项卡上选择 **输出状态导数（连续时间）或更新（离散时间）**。

### **ss** — 局部状态空间模型总线

主要仿真时间步处的局部状态空间模型数据，以包含以下元素的总线信号形式返回。

- `A` — 状态矩阵
- `B` — 输入矩阵
- `C` — 输出矩阵
- `D` — 直通矩阵
- `InputDelay` — 输入延迟
- `OutputDelay` — 输出延迟
- `InternalDelay` — 模型中的内部延迟

#### 依赖项

要启用此端口，请在 **输出** 选项卡上选择 **输出插值状态空间数据**。

### **offset** — LPV 模型偏移总线

主要仿真时间步处的 LTV 模型偏移数据，以包含以下元素的总线信号形式返回。

- `InputOffset`
- `OutputOffset`
- `StateOffset`
- `StateDerivativeOffset`

#### 依赖项

要启用此端口，请在 **输出** 选项卡上选择 **输出插值偏移**。

当模块位于具有同步状态控制的模型中时（请参阅 State Control (HDL Coder) 模块），您必须指定离散时间模型数组。

### 固定项选项卡

在某些情况下，您的 LTV 模型可能包含变化很小的系数。使用此选项卡上的参数，您可以指定哪些模型矩阵是固定的及其标称值，以覆盖模型数据中的条目。在某些情况下，您可能希望将依赖于时间的矩阵（例如 *A*(*t*)）替换为固定值 *A\** 进行仿真。例如，*A\** 可以表示调度范围内的平均值。默认情况下，模块使用 **状态空间数组** 数据来决定哪些条目是固定的以及哪些条目是变化的（出于性能原因，模块仅对变化的条目进行插值）。

使用此选项卡，您可以覆盖此默认行为，例如尝试简化 LTV 模型。例如，您可以确定 *A* 的第三个条目变化不大，并希望将其固定为其平均值。逻辑数组指定哪些条目应被视为固定，而 **读取值来源** 指定这些固定条目要使用哪个值。`false` 对应于不覆盖 LTI 数组数据，即依赖数据来决定此条目是固定还是变化。

### **要固定的系数** — 状态空间矩阵的固定系数 `false` 或 `0` (默认) | `true` 或 `1` | 逻辑矩阵

将这些系数的位置指定为以下之一：

- 标量布尔值（`true` 或 `false`），如果矩阵的所有条目都以相同方式处理。

  对于状态空间矩阵和延迟向量，默认值为 `false`，这意味着它们被视为自由。
- 大小与相应矩阵大小兼容的逻辑矩阵：

  | 状态空间矩阵 | 固定条目矩阵的大小 |
  | --- | --- |
  | **A 矩阵** | *nx*×*nx* |
  | **B 矩阵** | *nx*×*nu* |
  | **C 矩阵** | *ny*×*nx* |
  | **D 矩阵** | *ny*×*nu* |
  | **输入延迟** | *nu*×1 |
  | **输出延迟** | *ny*×1 |
  | **内部延迟** | *ni*×1 |

  其中，*nu* 是输入数，*ny* 是输出数，*nx* 是状态数，*ni* 是内部延迟向量的长度。
- 用于指定固定条目位置的数值索引。有关如何为矩阵元素生成与给定下标 `(i,j)` 对应的数值索引的详细信息，请参阅 `sub2ind` 参考页。

指定位置后，使用 **读取值来源** 参数提供固定系数的值。

### **读取值来源** — 固定系数值的来源 `First model in state-space array` (默认) | `Custom state-space model`

提供固定系数值的状态空间模型，指定为以下之一：

- `First model in state-space array` — 状态空间数组中的第一个模型用于 LPV 模型的固定系数。在以下示例中，状态空间数组由对象 `sys` 指定，固定系数取自模型 `sys(:,:,1)`。

  ```
  % Specify a 4-by-5 array of state-space models.
  sys = rss(4,2,3,4,5);
  a = 1:4;
  b = 10:10:50;
  [av,bv] = ndgrid(a,b);
  % Use "alpha" and "beta" variables as scheduling parameters.
  sys.SamplingGrid = struct('alpha',av,'beta',bv);
  ```

  固定系数取自模型 `sysFixed = sys(:,:,1)`，它对应于 `[alpha=1, beta=10]`。如果强制固定 `A` 矩阵的 (2,1) 条目，则仿真期间使用的值为 `sysFixed.A(2,1)`。
- `Custom state-space model` — 为固定条目指定不同的状态空间模型。在 **自定义模型** 字段中为固定模型指定变量。固定模型必须使用与 LPV 模型中的状态空间数组相同的状态基。

### 调度选项卡

### **插值方法** — 插值方法 `Linear` (默认) | `Nearest` | `Flat`

插值方法。定义对于远离其网格位置的调度参数值，必须如何计算状态空间数据。

指定以下选项之一：

- `Flat` — 选择最接近但不超过当前点的网格点处的状态空间数据。*当前点* 是当前时间的调度参数值。
- `Nearest` — 选择调度空间中最接近的网格点处的状态空间数据。
- `Linear` — 通过对调度空间中最接近的 2d 个相邻点进行线性插值来获取状态空间数据，其中 d = 调度参数的数量。

对于调度参数值的规则网格，默认插值方案为 `Linear`。对于不规则网格，无论您做出何种选择，始终使用 `Nearest` 插值方案。要了解有关规则和不规则网格的更多信息，请参阅规则与不规则网格。

`Linear` 方法提供最高精度，但计算时间更长。`Flat` 和 `Nearest` 方法适用于具有模式切换动态的模型。

### **外推方法** — 外推方法 `Clip` (默认) | `Linear`

外推方法。定义对于落在已提供状态空间数组的范围之外（如 `SamplingGrid` 属性中所指定）的调度参数值，如何计算状态空间数据。

指定以下选项之一：

- `Clip` (默认) — 禁用外推，并返回对应于最接近当前点的最后一个可用调度网格点的数据。
- `Linear` — 为每个调度参数在第一个或最后一对值之间拟合一条线，具体取决于当前值是分别小于第一个网格点值还是大于最后一个网格点值。此方法返回该线上对应当前值的点。线性外推要求插值方案也必须是线性的。

当您在 Accelerator 模式下运行模型或构建模型时，请确保初始缓冲区大小足够大，以处理模型中预期的最大延迟。

## 描述

仿真线性时变 (LTV) 系统

*线性时变* (LTV) 系统是一种动态随时间变化的线性状态空间模型。在 MATLAB® 中，LTV 模型使用时变系数以状态空间形式表示。

在数学上，可以将 LTV 系统表示如下。

dx(t)=dx0(t)+A(t)(x(t)−x0(t))+B(t)(u(t)−u0(t))y(t)=y0(t)+C(t)(x(t)−x0(t))+D(t)(u(t)−u0(t))x(0)=xinit

其中，

- *u*(*t*) 是输入
- *y*(*t*) 是输出
- *x*(*t*) 是模型状态，初始值为 *xinit*
- dx(t) 是连续时间系统的状态导数向量 x˙，对于离散时间系统是状态更新向量 *x*[*k*+1]。这里，*k* 是整数索引，用于计数采样周期数 *Ts*。
- *A*(*t*)、*B*(*t*)、*C*(*t*) 和 *D*(*t*) 是依赖于时间 *t* 的状态空间矩阵。
- *dx*0(*t*)、*x*0(*t*)、*u*0(*t*) 和 *y*0(*t*) 是给定时间 *t* 下 dx(t)、*x*(*t*)、*u*(*t*) 和 *y*(*t*) 值的偏移。

  调用 `linearize` (Simulink Control Design) 或 `getIOTransfer` (Simulink Control Design) 等函数时，可以通过返回额外线性化信息来获取偏移。

该模块接受带有工作点信息的状态空间模型数组。该模块从 LTI 数组的 `SamplingGrid` 属性中提取时间依赖信息，并从此工作空间中选择局部动态。该模块使用此数组以及数据插值和外推技术进行仿真。

调用 `linearize` (Simulink Control Design) 或 `getIOTransfer` (Simulink Control Design) 等函数时，可以通过返回额外线性化信息来获取偏移。
