# Discrete Varying State Space

## 端口

### 输入

### **uk** — 系统输入 scalar | vector

系统输入信号。

### **A** — 状态矩阵 matrix

状态矩阵，维度为 *Nx*-by-*Nx*，其中 *Nx* 是系统状态的数量。

### **B** — 输入矩阵 matrix

输入矩阵，维度为 *Nx*-by-*Nu*，其中 *Nu* 是系统输入的数量。

### **C** — 输出矩阵 matrix

输出矩阵，维度为 *Ny*-by-*Nx*，其中 *Ny* 是系统输出的数量。

### **D** — 前馈矩阵 matrix

前馈矩阵，维度为 *Ny*-by-*Nu*。

对于零直通状态空间模型，取消选中 **启用前馈** 复选框。取消选中此复选框会禁用 **D** 输入端口。*（自 R2023a 起）*

### **dx0** — 状态导数偏移量 matrix

*自 R2024a 起*

状态导数偏移量，维度为 *Nx*-by-1，其中 *Nx* 是系统状态的数量。

#### 依赖关系

要启用此端口，请选择 **启用状态导数偏移量 dx0**。*（自 R2024a 起）*

### **x0** — 状态偏移量 matrix

*自 R2024a 起*

状态偏移量，维度为 *Nx*-by-1，其中 *Nx* 是系统状态的数量。

#### 依赖关系

要启用此端口，请选择 **启用状态偏移量 x0**。*（自 R2024a 起）*

### **u0** — 输入偏移量 matrix

*自 R2024a 起*

输入偏移量，维度为 *Nu*-by-1，其中 *Nu* 是系统输入的数量。

#### 依赖关系

要启用此端口，请选择 **启用输入偏移量 u0**。*（自 R2024a 起）*

### **y0** — 输出偏移量 matrix

*自 R2024a 起*

输出偏移量，维度为 *Ny*-by-1，其中 *Ny* 是系统输出的数量。

#### 依赖关系

要启用此端口，请选择 **启用输出偏移量 y0**。*（自 R2024a 起）*

### **IC** — 初始条件 vector

*自 R2024b 起*

开始仿真时局部模型所使用的初始条件，指定为长度等于模型状态数的 vector。

#### 依赖关系

要启用此端口，请将 **初始条件来源** 设置为 `external`。

### 输出

### **yk** — 系统输出 scalar | vector

系统输出信号。

### **xk** — 当前状态向量 vector

当前状态值。

#### 依赖关系

要启用此端口，请选择 **输出状态** 参数。

### **xk+1** — 下一状态向量 vector

下一时间步的状态值。

#### 依赖关系

要启用此端口，请选择 **输出状态更新** 参数。

## 描述

矩阵值可变的离散时间状态空间模型

使用此模块可实现矩阵可变的离散时间状态空间模型。将状态矩阵 *A*、输入矩阵 *B*、输出矩阵 *C* 和前馈矩阵 *D* 的瞬时值馈送到相应的输入端口。系统响应由以下方程给出：

xk+1=Axk+Bukyk=Cxk+Duk,

其中，*uk* 是系统输入，*yk* 是系统输出，*xk* 是当前系统状态，*x**k*+1 是下一时间步的系统状态。

该模块还允许您指定可变偏移量*（自 R2024a 起）*。此时，系统响应由以下方程给出：

xk+1=dx0k+A(xk−x0k)+B(uk−u0k)yk=y0k+C(xk−x0k)+D(uk−u0k),

其中，*u*0*k* 是输入偏移量，*y*0*k* 是输出偏移量，*x*0*k* 和 *dx*0*k* 分别是状态偏移量和状态导数偏移量。

使用此模块以及 Linear Parameter Varying 库中的其他模块，可实现具有可变参数或系数的常用控制元素。有关详细信息，请参阅“在 Simulink 中对增益调度控制系统建模”。

**注意**

避免使 **C** 和 **D** 矩阵依赖于系统输出 **yk**。如果存在这种依赖关系，则得到的状态空间方程 *yk* = *C*(*yk*)*xk* + *D*(*yk*)*uk* 会产生代数环，因为计算输出值 *yk* 需要知道输出值。这种代数环容易导致不稳定和发散。相反，请尝试使用时间 *t*、模块输入 **uk** 和状态输出 **xk** 来表示 **C** 和 **D**。

出于类似原因，避免使 **A** 和 **B** 依赖于 **xk+1** 输出。请注意，当 **yk** 是状态和输入的固定组合时（换言之，当 *yk* = *C**xk* + *D**uk*，其中 *C* 和 *D* 是常数矩阵时），**A** 和 **B** 可以安全地依赖于 **yk**。
