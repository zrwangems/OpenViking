# PS Three-Element Demux

## Ports

### Input

### **abc** — Three-element physical signal, unitless physical signal

Physical signal input port where the signal is a three-element row
vector.
### Output

### **a** — Scalar physical signal, unitless physical signal

Scalar physical signal output port.

### **b** — Scalar physical signal, unitless physical signal

Scalar physical signal output port.

### **c** — Scalar physical signal, unitless physical signal

Scalar physical signal output port.

## Version History

**Introduced in R2013b**

### R2023b: Block available in Foundation library

Prior to R2023b, this block was part of the Simscape™
Electrical™ product. It was called Three Element
Demux and was available only in the
Simscape/Electrical/Connectors & References library.

This change has no compatibility impact. The block functionality is unchanged. If
you open an existing model containing a Three Element
Demux block, it will be automatically updated to use the
PS Three-Element Demux block from the Foundation
library.

## Description

Convert three-element physical signal vector into scalar physical signals

The PS Three-Element Demux block splits a three-element
physical signal vector into three scalar physical signals.
