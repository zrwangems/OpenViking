# R2025b block-document reference storage

This directory stores deduplicated documents and legacy base-Simulink categories; **it is not the Library Browser root**. Use the [English Library Browser](../browser/en/index.md) for the installed product tree. `products/<product>/ref/` stores full documents; legacy categories such as `commonly-used-blocks` contain only the 341 base-Simulink reference entries.

See the [all-product catalog](../catalog/en/index.md) for the complete public catalog.
