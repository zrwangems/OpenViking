# Reference Frame

## Ports

### Frame

### **R** — Reference frame frame

Local reference frame represented by the block. Connect to a frame
line or frame port to define the relative position and orientation of
the reference frame.

## Description

Non-inertial reference frame

This block represents a reference frame with respect to which you can define other
frames. The reference frame is generally non-inertial. It can accelerate with respect to
the World frame. This block is optional in a model.
