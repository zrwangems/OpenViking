# 1D Controller [A(v),B(v),C(v),D(v)]

## Ports

### Input

### **y** — Aircraft measurements vector

Aircraft measurements, specified as a vector.

**Data Types:** `double`

### **v** — Scheduling variable vector

Scheduling variable, specified as a vector, that conforms to the dimensions of the
state-space matrices.

**Data Types:** `double`
### Output

### **u** — Actuator demands vector

Actuator demands, specified as a vector.

**Data Types:** `double`

## Parameters

### **A-matrix(v)** — *A* matrix of the state-space implementation `A1` (default) | array

*A*-matrix of the state-space implementation, specified as an array. In
the case of 1-D scheduling, the *A*-matrix should have
three dimensions, the last one corresponding to the scheduling variable
*v*. For example, if the *A*-matrix
corresponding to the first entry of *v* is the identity
matrix, then `A(:,:,1) = [1 0;0 1];`.

## Description

Implement gain-scheduled state-space controller depending on one scheduling parameter

The 1D Controller [A(v),B(v),C(v),D(v)] block implements a
gain-scheduled state-space controller, as described in Algorithms.

The output from this block is the actuator demand, which you can input to an actuator
block.
