## Description

Reference connection for mechanical rotational ports

The Mechanical Rotational Reference block represents a
reference point, or frame, for mechanical rotational ports. All rotational ports that are
rigidly clamped to the frame must be connected to a Mechanical Rotational
Reference block. For more information, see Grounding Rules.
