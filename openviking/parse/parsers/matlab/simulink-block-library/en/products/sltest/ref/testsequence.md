## Ports

Not documented in R2025b.

## Parameters

## Libraries

Simulink Test

## Block Characteristics

Not documented in R2025b.

## Extended Capabilities

### C/C++ Code Generation Generate C and C++ code using Simulink® Coder™.

### PLC Code Generation Generate Structured Text code using Simulink® PLC Coder™.

If you use Test Sequence Scenarios that contain `verify`
statements, you cannot generate Structured Text code.

## Version History

**Introduced in R2015a**

### R2025a: View `verify` results from only active scenarios

The Test Manager does not display results for `verify`
statements in inactive Test Sequence scenarios.

## Description

Create simulation testing scenarios, function calls, and assessments

Define a test sequence using a tabular series of steps. Like the Test
Assessment block, the Test Sequence block uses MATLAB® as the action language. Double-click the Test Sequence block icon to open
the Test Sequence editor.
