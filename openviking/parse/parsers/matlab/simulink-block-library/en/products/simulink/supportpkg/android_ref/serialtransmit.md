## Description

Send buffered data to the serial port

Send buffered data to the serial port.

The block input accepts vector or scalar data of data types, uint8, int8, uint16,
int16, uint32, int32, double, single, or boolean.

During simulations, this block does nothing.

**Note**

Only one Serial Transmit and one Serial Receive
blocks are allowed in a model.
