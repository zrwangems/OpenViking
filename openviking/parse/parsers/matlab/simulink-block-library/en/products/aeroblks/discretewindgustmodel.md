## Description

Generate discrete wind gust

The Discrete Wind Gust Model block implements a wind gust of
the standard “1-cosine” shape. This block implements the mathematical representation in
the Military Specification MIL-F-8785C [1]. The gust is applied to each axis
individually, or to all three axes at once. You specify the gust amplitude (the increase
in wind speed generated by the gust), the gust length (length, in meters, over which the
gust builds up) and the gust start time. For more information on the gust shape, see
Algorithms.

The Discrete Wind Gust Model block can represent the wind speed in units of
feet per second, meters per second, or knots.
