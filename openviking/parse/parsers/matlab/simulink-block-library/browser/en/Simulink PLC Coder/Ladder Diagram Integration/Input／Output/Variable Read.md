# Variable Read

## Ports

Not documented in R2025b.

## Parameters

### **Data Tag** — Data to be read A (default) | boolean

Specify the data to be read, specified in the format of `tags`. In
Ladder Diagrams, tags (variables) are used to represent inputs, outputs, and internal
memory with attributes such as `Data Type`, `Initial
Value`, and `size`. To change the attributes of the
`Data Tag`, open the **Program Variables** table
within the Ladder Diagram Program block.

#### Programmatic Use

|  |
| --- |
| **Block Parameter**: `PLCOperandTag` |
| **Type**: character vector |
| **Value**: character vector |
| **Default**: `'A'` |
