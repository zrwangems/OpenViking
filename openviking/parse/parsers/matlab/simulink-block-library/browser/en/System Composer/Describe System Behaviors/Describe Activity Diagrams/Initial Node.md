## Description

Dispatch control token at beginning of activity

An initial node is represented by a solid gray circle.

When an activity begins, a single control token is placed on an initial node. The control
token then flows to the node connected to the initial node. An activity can have multiple
initial nodes. All initial nodes have one output and no inputs.

### Create an Initial Node

You can create an initial node by dragging and dropping the Initial Node
block from the palette on the left to any location on the canvas.
