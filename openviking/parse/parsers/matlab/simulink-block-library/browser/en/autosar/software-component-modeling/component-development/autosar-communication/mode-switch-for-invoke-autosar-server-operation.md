# Mode Switch for Invoke AUTOSAR Server Operation

## Ports

Not documented in R2025b.

## Parameters

### **Configure the model for** — Client-server mode `code generation` (default) | `simulation`

Select the mode to configure for the client-server blocks:

- `code generation`
- `simulation`

## Libraries

AUTOSAR Blockset

## Block Characteristics

Not documented in R2025b.

## Extended Capabilities

### C/C++ Code Generation Generate C and C++ code using Simulink® Coder™.

## Version History

**Introduced in R2009b**

## Description

Toggle AUTOSAR client-server operation subsystem blocks between simulation and code-generation mode

You can add this switch block to your Simulink® model that contains client-server subsystem blocks. Double-click the switch
block to toggle client-server blocks between simulation and code-generation mode.
