## Description

Terminate one object or control flow

A flow final node is represented by a gray cross enclosed within a circle.

When a control token enters the Flow Final Node block, the corresponding
object or control flow is terminated, but the activity diagram as a whole is not terminated. A
flow final node does not have any outputs.

### Create a Flow Final Node

You can create a flow final node by dragging and dropping the Flow Final
Node block from the palette on the left to any location on the canvas.
