## Description

Terminate entire activity

An activity final node is represented by a solid gray circle enclosed in a white
circle.

When a control token enters the Activity Final Node block, the entire
activity diagram terminates. An activity final node does not have any output flows.

### Create an Activity Final Node

You can create an activity final node by dragging and dropping the Activity Final
Node block from the palette on the left to any location on the canvas.
