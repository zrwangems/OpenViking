# Independent Suspension - Air Spring

## 端口

### 输入

### **WhlPz** — 车轮 `z` 轴位移数组

车轮位移 *zw*，沿车轮固定的 *z* 轴，单位为 m。数组维度为 `1` × 车辆上的车轮总数。

例如，对于每轴两个车轮的两轴车辆，`WhlPz`：

- 信号数组维度为 `[1x4]`。

  WhlPz=zw=[zw1,1zw1,2zw2,1zw2,2]

  | 车轮 | 数组元素 | 车轴 | 车轮编号 |

### **WhlM** — 车轮上的悬架力矩数组

- `WhlM(1,...)` — 施加到车轮的、绕惯性固定 *x* 轴（纵向）的悬架力矩

### **StrgAng** — 转向角，可选数组

每个车轮的可选转向角 *δ*。输入数组维度为 `1` × 转向车轮数。

例如，对于每轴两个车轮的两轴车辆，可以输入第一轴上两个车轮的转向角。

- 要启用 **StrgAng** 端口，请将 **Steered axle enable by axle, StrgEnByAxl** 设置为 `[1 0]`。输入信号数组维度为 `[1x2]`。
- `StrgAng` 信号包含根据其车轴和车轮位置的两个转向角。

  StrgAng=δsteer=[δsteer1,1δsteer1,2]

  | 车轮 | 数组元素 | 车轴 | 车轮编号 |
  | --- | --- | --- | --- |
  | 前左 | `StrgAng(1,1)` | `1` | `1` |
  | 前右 | `StrgAng(1,2)` | `1` | `2` |

#### 依赖项

要启用端口 **StrgAng**，请将 **Steered axle enable by axle, StrgEnByAxl** 向量的某个元素设置为 `1`。

空气弹簧独立悬架

Independent Suspension - Air Spring 模块实现具有多轴且每轴多轮的空气弹簧独立悬架。您可以使用该模块根据测量或仿真的悬架响应数据对悬架几何、柔度和阻尼效应进行建模。

该模块将悬架柔度、阻尼和几何效应建模为车辆与车轮支架相对位置和速度的函数，并使用各轴特定的柔度和阻尼参数。该模块使用悬架柔度和阻尼计算作用在车辆和车轮上的悬架力。该模块使用 *Z*-down 坐标系（定义于 SAE J670）。下表描述了可为每个悬架元件指定的设置。

该模块包含储能弹簧元件和耗能阻尼器元件。它不包含储能质量元件。该模块假定连接到该模块的车辆（簧上）和车轮（簧下）模块存储与质量相关的悬架能量。

xwa,t=xva,tywa,t=yva,tx˙wa,t=x˙va,ty˙wa,t=y˙va,t

### 硬限位力

该模块施加的硬限位反馈力 *Fzhstopa,t* 取决于悬架是在压缩还是在伸张。该模块在以下情况施加力：

- 在压缩时，当悬架压缩量超过 **悬架最大高度, Hmax** 参数指定的最大距离时
- 在伸张时，当悬架伸张量大于 **悬架最大高度, Hmax** 参数指定的最大伸张量时

为计算力，该模块使用基于双曲正切和指数缩放的刚度。

| *ζa,t* | 车轴 `a`、车轮 `t` 上车轮的前束角 |
| *δsteera,t* | 车轴 `a`、车轮 `t` 的转向角输入 |
| *zva,t* | 沿惯性固定 *z* 轴，车轴 `a`、车轮 `t` 处的车辆位移 |
| *zwa,t* | 沿惯性固定 *z* 轴，车轴 `a`、车轮 `t` 处的车轮位移 |

### 转向角

可选地，您可以为车轮输入转向角。为了计算车轮的转向角，该模块根据悬架高度对输入转向角进行偏移。为进行计算，该模块使用查找表
*Galookup*，该表是悬架位置和转向角的函数。

δwhlsteera,t=δsteera,t+Galookupf(zwa,t−zva,t,δsteera,t)

该方程使用以下变量。

|  |  |
| --- | --- |
| *δwhlsteera,t* | 车轴 `a`、车轮 `t` 的车轮转向角 |
| *δsteera,t* | 车轴 `a`、车轮 `t` 的转向角输入 |
| *zva,t* | 沿惯性固定 *z* 轴，车轴 `a`、车轮 `t` 处的车辆位移 |
| *zwa,t* | 沿惯性固定 *z* 轴，车轴 `a`、车轮 `t` 处的车轮位移 |

### 功率和能量

| 计算 | 方程 |
