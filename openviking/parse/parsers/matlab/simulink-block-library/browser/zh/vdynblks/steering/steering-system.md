# Steering System

## 端口

### 输入

### **VehSpd** — 车辆速度标量

车辆速度，*v*，单位为 m/s，指定为标量。
这是车辆 CG 纵向速度向量的大小。

#### 依赖关系

要启用此参数，请选择 **Power assist** 模块选项。

### **CstrAng** — 车轮主销后倾角 1×2 向量

车轮主销后倾角，*τL*，单位为 radians，指定为 1×2 向量。第一个元素是左轮角度，第二个元素是右轮角度。

#### 依赖关系

要启用此端口，请清除 **Input signals** > **Kingpin moment**。

### **WhlAngFdk** — 车轮转向角反馈 1×2 向量

车轮转向角反馈，单位为 radians，指定为 1×2 向量。第一个元素是左轮的角度反馈，第二个元素是右轮的角度反馈：

- **AngLft**
- **AngRght**

您可以使用来自车辆被控对象模型的转向角响应或此模块的车轮角度输出来指定车轮转向角反馈。

#### 依赖关系

要启用此端口，请清除 **Input signals** > **Kingpin moment**。

### **AngIn** — 方向盘角度输入标量

来自驾驶员的方向盘角度输入，单位为 radians，指定为标量。

#### 依赖关系

要启用此端口，请选择 **Steering inputs** > **Angle**。

### **TrqIn** — 转向扭矩输入标量

来自驾驶员的方向盘扭矩输入，单位为 N\*m，指定为标量。

#### 依赖关系

要启用此端口，请选择 **Steering inputs** > **Torque**。

### **PwrAstTrq** — 动力辅助扭矩标量

转向轴上动力辅助的扭矩值，单位为 N\*m，指定为标量。该值从外部提供到此端口。

#### 依赖关系

要启用此端口，请选择 **Input signals** > **Power assist**。

### **PctAck** — 百分比 Ackermann 值标量

以百分比表示的 Ackermann 值，指定为标量。该值从外部提供到此端口。

#### 依赖关系

要启用此端口，请选择 **Input signals** > **Ackerman steering**。

### **TireFdk** — 轮胎力和力矩反馈 1×12 向量

来自右轮胎和左轮胎的轮胎力和力矩反馈，指定为 1×12 向量，其中包含下表中按指定顺序排列的值：

| 描述 | 单位 |
| --- | --- |
| *x* 方向力，左侧 | N |
| *x* 方向力，右侧 | N |
| *y* 方向力，左侧 | N |
| *y* 方向力，右侧 | N |
| *z* 方向力，左侧 | N |
| *z* 方向力，右侧 | N |
| *x* 方向力矩，左侧 | N\*m |
| *x* 方向力矩，右侧 | N\*m |
| *y* 方向力矩，左侧 | N\*m |
| *y* 方向力矩，右侧 | N\*m |
| *z* 方向力矩，左侧 | N\*m |
| *z* 方向力矩，右侧 | N\*m |

#### 依赖关系

要启用此端口，请清除 **Input signals** > **Kingpin moment**。

### **LftKpM** — 左主销力矩标量

左主销力矩，单位为 N\*m，指定为标量。

#### 依赖关系

要启用此端口，请选择 **Input signals** > **Kingpin moment**。

### **RghtKpM** — 右主销力矩标量

右主销力矩，单位为 N\*m，指定为标量。

#### 依赖关系

要启用此端口，请选择 **Input signals** > **Kingpin moment**。

### 输出

### **Info** — 车辆动力学信息总线

车辆动力学信息，返回为包含以下信号的总线信号：

| 信号 | 描述 | 单位 |
| --- | --- | --- |
| `StrWhlAngFdk` | 方向盘角度 | rad |
| `AstTrq` | 动力辅助施加的扭矩 | N·m |
| `AstPwr` | 动力辅助施加的功率 | W |
| `LftTieRodForce` | 左转向横拉杆中的轴向力 | N |
| `RghtTieRodForce` | 右转向横拉杆中的轴向力 | N |
| `LftKpM` | 左主销力矩 | N·m |
| `RghtKpM` | 右主销力矩 | N·m |
| `LftWhlAng` | 左轮转向角 | rad |
| `RghtWhlAng` | 右轮转向角 | rad |
| `LftWhlSpd` | 左轮转向角速度 | rad/s |
| `RghtWhlSpd` | 右轮转向角速度 | rad/s |
| `TrqIn` | 驾驶员施加在方向盘上的扭矩 | N·m |

### **AngLft** — 左轮转向角 `scalar`

左轮转向角，*δL*，单位为 radians，返回为标量。

### **AngRght** — 右轮转向角 `scalar`

右轮转向角，*δR*，单位为 radians，返回为标量。

## 描述

用于 Ackermann 和齿轮齿条转向机构的转向系统

Steering System 模块实现动态转向，以计算具有摩擦[4]、柔度以及 Ackermann 转向特性的齿轮齿条机构的车轮转向角。该模块使用方向盘输入角度或扭矩输入、车辆速度、后倾角以及右轮和左轮反馈来计算车轮转向角。该模块使用车辆坐标系。

如果选择 **Power assist** 参数，则可以指定一个扭矩助力查找表，该查找表是车辆速度和方向盘输入扭矩的函数。该模块使用方向盘输入扭矩和扭矩助力来计算转向动力学。如果选择 **Ackerman steering** 参数，则可以指定 Ackermann 百分比值的查找表以计算 Ackermann 转向效应，或指定一个恒定 Ackermann 百分比，其中 100% 表示理想 Ackermann 转向。

如果在 **Input signals** 部分选择 **Power assist**、**Ackerman steering** 或 **Kingpin moment**[5] 参数，则可以为外部助力扭矩、Ackermann 百分比值或主销力矩指定附加输入。

使用 **Steered axle** 参数指定转向的是前轴还是后轴。

| 设置 | 实现 |

| **Front** | 前轴转向  前轮转向右转的示意图 |
| **Rear** | 后轴转向  后轮转向右转的示意图 |

### 转向类型

**Rack-and-Pinion**

对于 Rack-and-Pinion 转向，小齿轮旋转导致齿条直线运动，齿条通过横拉杆和转向臂使车轮转向。

| *δR* | 右轮转向角 |

| *larm* | 转向臂长度 |

### 转向效应

**Ackerman**

对于理想 Ackerman 转向，车轮角度具有共同的转弯圆。

Ackerman 转向绕转弯圆右转的示意图

为计算理想车轮角度，模块使用以下方程。

cot(δL)−cot(δR)=TWWBδAck=δinγδL=tan−1(WBtan(δAck)WB+0.5TWtan(δAck))δR=tan−1(WBtan(δAck)WB−0.5TWtan(δAck))

在模块计算理想车轮角度后，它使用 Ackerman 百分比调整外侧车轮角度。

δo=δi−pAck(δi−δAck)

外侧车轮角度取决于转弯方向。

- 右转

  - 外侧角度 *δo* 为左轮角度 *δL*
  - 内侧角度 *δi* 为右轮角度 *δR*
- 左转

  - 外侧角度 *δo* 为右轮角度 *δR*
  - 内侧角度 *δi* 为左轮角度 *δL*
