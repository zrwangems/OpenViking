### **WhlPz** — 车轮 `z` 轴位移数组

沿车轮固定 *z* 轴的车轮位移，*zw*，单位为 m。数组维度为 `1` × 车辆上的车轮总数。

例如，对于每轴两个车轮的两轴车辆，`WhlPz`：

- 信号数组维度为 `[1x4]`。

  WhlPz=zw=[zw1,1zw1,2zw2,1zw2,2]

每个车轮的可选转向角，*δ*。输入数组维度为 `1` × 转向车轮数。

Solid Axle Suspension - Air Spring 模块实现具有多轴且每轴多轮空气弹簧整体桥悬架。

### 硬限位力

模块施加的硬限位反馈力 *Fzhstopa,t* 取决于悬架是在压缩还是在伸张。模块施加该力的条件：

- 在压缩时，当悬架压缩量超过 **Suspension maximum height, Hmax**
  参数指定的最大距离时
- 在伸张时，当悬架伸张量大于 **Suspension maximum height, Hmax**
  参数指定的最大伸张量时

为计算该力，模块使用基于双曲正切和指数缩放的刚度。

### 外倾角、主销后倾角和前束角

为了计算外倾角、主销后倾角和前束角，模块使用查找表 *Galookup*，该表是悬架高度和转向角的函数。

[ξa,tηa,tζa,t]=Galookupf(zwa,t−zva,t,δsteera,t)

方程使用以下变量。

|  |  |
| --- | --- |
| *ξa,t* | 轴 `a`、车轮 `t` 上车轮的外倾角 |
| *ηa,t* | 轴 `a`、车轮 `t` 上车轮的主销后倾角 |
| *ζa,t* | 轴 `a`、车轮 `t` 上车轮的前束角 |
| *δsteera,t* | 轴 `a`、车轮 `t` 的转向角输入 |
| *zva,t* | 轴 `a`、车轮 `t` 处、沿惯性固定 *z* 轴的车辆位移 |
| *zwa,t* | 轴 `a`、车轮 `t` 处、沿惯性固定 *z* 轴的车轮位移 |

### 转向角

可选地，您可以为车轮输入转向角。为了计算车轮的转向角，模块根据悬架高度对输入转向角进行偏移。为进行计算，模块使用查找表 *Galookup*，该表是悬架位置和转向角的函数。

δwhlsteera,t=δsteera,t+Galookupf(zwa,t−zva,t,δsteera,t)

方程使用以下变量。

|  |  |
| --- | --- |
| *δwhlsteera,t* | 轴 `a`、车轮 `t` 的车轮转向角 |
| *δsteera,t* | 轴 `a`、车轮 `t` 的转向角输入 |
| *zva,t* | 轴 `a`、车轮 `t` 处、沿惯性固定 *z* 轴的车辆位移 |
| *zwa,t* | 轴 `a`、车轮 `t` 处、沿惯性固定 *z* 轴的车轮位移 |

### 功率和能量
