## 参数

#### 模块选项

### **包含涡轮增压器滞后效应** — 增加时间常数 `off`（默认） | `on`

要对涡轮增压器滞后建模，请选择 **包含涡轮增压器滞后效应**。在节气门控制期间，时间常数对歧管充气和排空动态建模。当扭矩请求需要涡轮增压器增压时，模块使用更大的时间常数来表示涡轮增压器滞后。模块使用以下方程。

|  |  |
| --- | --- |
| 动态扭矩 | dTbrakedt=1τeng(Tstdy−Tbrake) |
| 增压时间常数 | τbst={τbst,rising       when Tstdy>Tbrakeτbst,falling      when Tstdy≤Tbrake |
| 最终时间常数 | τeng={τthr       when Tbrake<fbst(N)τbst       when Tbrake≥fbst(N) |

这些方程使用以下变量。

|  |  |
| --- | --- |
| *Tbrake* | 制动扭矩 |
| *Tstdy* | 稳态目标扭矩 |
| *τbst* | 增压时间常数 |
| *τbst,rising*, *τbst,falling* | 分别为增压上升和下降时间常数 |
| *τeng* | 最终时间常数 |
| *τthr* | 节气门控制期间的时间常数 |
| *ƒbst(N)* | 增压扭矩速度线 |
| *N* | 发动机转速 |

## 描述

使用查找表的火花点火发动机模型

Mapped SI Engine 模块使用功率、空气质量流量、燃料流量、排气温度、效率和排放性能查找表实现映射火花点火 (SI) 发动机模型。您可以将该模块用于：

- 硬件在环 (HIL) 发动机控制设计
- 车辆级燃油经济性和性能仿真

模块允许您为这些发动机特性指定查找表。这些查找表使用 Model-Based Calibration Toolbox™ 开发，是命令扭矩 *Tcmd*、制动扭矩 *Tbrake* 和发动机转速 *N* 的函数。如果选择 **输入发动机温度**，这些表还是发动机温度 *TempEng* 的函数。

| 表 | **输入发动机温度** 参数设置 | |
| --- | --- | --- |
| `off` | `on` |
| 功率 | *ƒ(Tcmd,N)* | *ƒ(Tcmd,N,TempEng)* |
| 空气 | *ƒ(Tbrake,N)* | *ƒ(Tbrake,N,TempEng)* |
| 燃料 |
| 温度 |
| 效率 |
| HC |
| CO |
| NOx |
| CO2 |
| PM |

为限制 Mapped SI Engine 模块输出，模块不会外推查找表数据。

MNom=PstdVdNcylRairTstdL=(60smin)Cps⋅m˙air(1000gKg)Ncyl⋅N⋅MNom

这些方程使用以下变量。

|  |  |
| --- | --- |
| *L* | 归一化气缸空气质量 |

### 涡轮增压器滞后

要对涡轮增压器滞后建模，请选择 **包含涡轮增压器滞后效应**。在节气门控制期间，时间常数对歧管充气和排空动态建模。当扭矩请求需要涡轮增压器增压时，模块使用更大的时间常数来表示涡轮增压器滞后。模块使用以下方程。

|  |  |
| --- | --- |
| 动态扭矩 | dTbrakedt=1τeng(Tstdy−Tbrake) |
| 增压时间常数 | τbst={τbst,rising       when Tstdy>Tbrakeτbst,falling      when Tstdy≤Tbrake |
| 最终时间常数 | τeng={τthr       when Tbrake<fbst(N)τbst       when Tbrake≥fbst(N) |

这些方程使用以下变量。

|  |  |
| --- | --- |
| *Tbrake* | 制动扭矩 |
| *Tstdy* | 稳态目标扭矩 |
| *τbst* | 增压时间常数 |
| *τbst,rising*, *τbst,falling* | 分别为增压上升和下降时间常数 |
