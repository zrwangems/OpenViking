# Flux-Based PM Controller

## 端口

### 输入

### **SpdReq** — 转子速度指令 `scalar`

转子速度指令，*ω\*m*，单位为 rad/s。

#### 依赖关系

要创建此端口，请为 **控制类型** 参数选择 `Speed Control`。

### **TrqCmd** — 转矩指令 `scalar`

转矩指令，*T\**，单位为 N·m。

#### 依赖关系

要创建此端口，请为 **控制类型** 参数选择 `Torque Control`。

### **BusVolt** — 直流总线电压 `scalar`

直流总线电压，*vbus*，单位为 V。

### **PhaseCurrA** — 电流 `scalar`

定子电流 a 相，*ia*，单位为 A。

### **PhaseCurrB** — 电流 `scalar`

定子电流 b 相，*ib*，单位为 A。

### **SpdFdbk** — 转子速度 `scalar`

转子速度，*ωm*，单位为 rad/s。

### **PosFdbk** — 转子电角度 `scalar`

转子电角度，*Θm*，单位为 rad。
### 输出

### **Info** — 总线信号 bus

总线信号，包含这些模块计算。

| 信号 | 描述 | 单位 |
| --- | --- | --- |
| `SrcPwr` | 源功率 | W |
| `LdPwr` | 负载功率 | W |
| `PwrLoss` | 功率损耗 | W |
| `MtrTrqEst` | 估计电机转矩 | N·m |

### **BusCurr** — 总线电流 `scalar`

估计直流总线电流，*ibus*，单位为 A。

### **PhaseVolt** — 定子端电压 `array`

定子端电压，*Va*、*Vb* 和 *Vc*，单位为 V。

#### 电气损耗

### **损耗参数化方式** — 选择类型 `Single efficiency measurement` (默认) | `Tabulated loss data` | `Tabulated efficiency data`

| 设置 | 模块实现 |
| --- | --- |
| `Single efficiency measurement` | 电气损耗使用逆变器效率的恒定值计算。 |
| `Tabulated loss data` | 电气损耗作为电机速度和负载转矩的函数计算。 |
| `Tabulated efficiency data` | 电气损耗使用作为电机速度和负载转矩函数的逆变器效率计算。    - 将您提供的效率值转换为损耗，并使用表格化损耗进行仿真。 - 忽略您为零速度或零转矩提供的效率值。当转矩或速度任一为零时，损耗假定为零。 - 使用线性插值确定损耗。根据需要为低速和低转矩提供表格化数据，以获得低功率条件下所需的精度水平。 - 对于超出表格范围的速度和转矩幅值，不外推损耗值。 |

为了在较低功率条件下获得所需精度水平，您可以为低速和低转矩提供表格化数据。

Flux Based PM Controller 模块为内置式永磁同步电机 (PMSM) 实现基于磁链的磁场定向控制器，并可选配外环速度控制器。内部转矩控制实现用于实现最大转矩每安培 (MTPA) 和弱磁的策略。您可以指定速度或转矩控制类型。

Flux Based PM Controller 实现速度控制、转矩确定、调节器、变换和电机的方程。

### 速度控制器

要实现速度控制器，请选择 **控制类型** 参数为 `Speed Control`。如果选择 **控制类型** 参数为 `Torque Control`，则模块不实现速度控制器。

速度控制器通过实现状态滤波器并计算前馈和反馈指令来确定转矩指令。如果不实现速度控制器，请向 Flux Based PM Controller 模块输入转矩指令。

示意图展示状态滤波器通过加速度和速度信号连接到指令前馈模块。状态滤波器还通过速度信号连接到状态反馈。

**状态滤波器**

状态滤波器是一种低通滤波器，它根据速度指令生成加速度指令。其特征方程的离散形式为：

z+KsfTsm−1

滤波器使用下式计算增益。

Ksf=1−exp(−Tsm2πEVsf)Tsm

方程使用以下变量。

|  |  |
| --- | --- |
| *EVsf* | 速度指令滤波器的带宽 |
| *Tsm* | 运动控制器采样时间 |
| *Ksf* | 速度调节器时间常数 |

**状态反馈**

为了生成状态反馈转矩，模块使用来自状态滤波器的滤波后速度误差信号。为了对速度进行滤波，模块使用比例积分 (PI) 控制器。

Tcmd=Kpω(ωm\*−ωm)+KiωzTsmz−1(ωm\*−ωm)

方程使用以下变量。

|  |  |
| --- | --- |
| *ωm* | 转子速度 |
| *ω\*m* | 转子速度指令 |
| *Tcmd* | 转矩指令 |
| *Kpω* | 速度调节器比例增益 |
| *Kiω* | 速度调节器积分增益 |
| *Tsm* | 速度调节器采样率 |

**指令前馈**

为了生成状态前馈转矩，模块使用来自状态滤波器的滤波后速度和加速度。此外，前馈转矩计算使用惯量、粘性阻尼和静摩擦。为了实现零跟踪误差，转矩指令是前馈和反馈转矩指令之和。

前馈转矩指令使用以下方程。

其中：

| --- | --- |

| *Tcmd\_ff* | 转矩指令前馈 |
| *Fs* | 静摩擦转矩常数 |
| *F*v** | 粘性摩擦转矩常数 |
| *Fs* | 静摩擦转矩常数 |
| *ωm* | 转子速度 |

**电流指令**

模块使用查找表确定 *d* 轴和 *q* 轴电流指令。查找表是机械速度和转矩的函数。为了确定查找表，您可以使用外部有限元分析 (FEA) 模型或测功机测试结果。

idref=f(|ωm|,|Tref|)iqref=sign(Tref)∗f(|ωm|,|Tref|)

| --- | --- |

| *Tref* | 转矩指令 |
| *idref*, *iqref* | 分别为 *d* 轴和 *q* 轴参考电流 |

### 变换

为了计算平衡三相 (*a*, *b*) 量、正交两相 (*α*, *β*) 量和旋转 (*d*, *q*) 参考坐标系中的电压和电流，模块使用 Clarke 和 Park 变换。

在变换方程中。

ωe=Pωmdθedt= ωe

| 变换 | 描述 | 方程 |
| --- | --- | --- |
| Clarke | 将平衡三相量 (*a*, *b*) 转换为平衡两相正交量 (*α*, *β*)。 | xα= 23xa− 13xb −13xcxβ= 32xb− 32xc |
| Park | 将平衡两相正交静止量 (*α*, *β*) 转换为正交旋转参考坐标系 (*d*, *q*)。 | xd= xαcosθe+ xβsinθexq= −xαsinθe+ xβcosθe |
| Inverse Clarke | 将平衡两相正交量 (*α*, *β*) 转换为平衡三相量 (*a*, *b*)。 | xa= xaxb= −12xα+ 32xβxc= −12xα− 32xβ |
| Inverse Park | 将正交旋转参考坐标系 (*d*, *q*) 转换为平衡两相正交静止量 (*α*, *β*)。 | xα= xdcosθe− xqsinθexβ= xdsinθe+ xqcosθe |

### 电气损耗

要指定电气损耗，请在 **电气损耗** 选项卡上的 **损耗参数化方式** 中，选择以下选项之一。

| 设置 | 模块实现 |
| --- | --- |
| `Single efficiency measurement` | 电气损耗使用逆变器效率的恒定值计算。 |
| `Tabulated loss data` | 电气损耗作为电机速度和负载转矩的函数计算。 |
| `Tabulated efficiency data` | 电气损耗使用作为电机速度和负载转矩函数的逆变器效率计算。    - 将您提供的效率值转换为损耗，并使用表格化损耗进行仿真。 - 忽略您为零速度或零转矩提供的效率值。当转矩或速度任一为零时，损耗假定为零。 - 使用线性插值确定损耗。根据需要为低速和低转矩提供表格化数据，以获得低功率条件下所需的精度水平。 - 对于超出表格范围的速度和转矩幅值，不外推损耗值。 |

最佳实践是使用 `Tabulated loss data` 而不是 `Tabulated efficiency data`：

- 在零速度或零转矩时，效率定义不明确。
- 您可以考虑在零速度或零转矩时仍然存在的固定损耗。
