# SOC Estimator (Kalman Filter, Variable Capacity)

## 端口

### 输入

### **Current** — 电池电流 标量 | 向量

电池电流，单位为 ampere，指定为标量（用于单个单体）或向量（用于多个单体）。要将此输入指定为单体电流向量，请选择 **将 Current 输入指定为单体电流** 参数。

### **CellVoltage** — 单体电压 标量 | 向量

单体电压，单位为 volt，指定为标量（用于单个单体）或向量（用于多个单体）。此输入端口的大小必须等于 **CellTemperature**、**CellAH** 和 **InitialSOC** 输入端口的大小。

### **CellTemperature** — 单体温度 标量 | 向量

单体温度，指定为标量（用于单个单体）或向量（用于多个单体）。此输入端口的大小必须等于 **CellVoltage**、**CellAH** 和 **InitialSOC** 输入端口的大小。

### **CellAH** — 单体温度 标量 | 向量

单体容量，单位为 ampere-hour，指定为标量（用于单个单体）或向量（用于多个单体）。该模块通过将累积电荷除以该值来计算 SOC。该模块通过对电池电流进行积分来计算累积电荷。

此输入端口的大小必须等于 **CellTemperature**、**CellVoltage** 和 **InitialSOC** 输入端口的大小。

### **InitialSOC** — 初始荷电状态 标量 | 向量

初始荷电状态，指定为范围 [0, 1] 内的标量或向量。此输入端口的大小必须等于 **CellVoltage**、**CellTemperature** 和 **CellAH** 输入端口的大小。

### 输出

### **SOC** — 荷电状态 标量 | 向量

电池的荷电状态，以标量或向量形式返回。此输出端口的大小等于 **CellVoltage**、**CellTemperature**、**CellAH** 和 **InitialSOC** 输入端口的大小。

## 描述

使用卡尔曼滤波器和可变容量的荷电状态估计器

SOC Estimator (Kalman Filter, Variable Capacity) 模块实现了一个估计器，该估计器使用卡尔曼滤波器算法计算电池的荷电状态 (SOC)。电池的单体容量是该模块的输入。

SOC 是释放容量 *C*releasable 与额定容量 *C*rated 之比。制造商提供每个电池的额定容量值，该值表示电池中的最大电荷量：

SOC=CreleasableCrated.

此模块支持单精度和双精度浮点仿真。

**注意**

要启用继承的单精度浮点仿真，所有输入和参数（**采样时间（-1 表示继承）** 参数除外）的数据类型必须是 `single`。

对于连续时间仿真，请将 **滤波器类型** 参数设置为 `Extended Kalman-Bucy filter` 或 `Unscented Kalman-Bucy filter`。

**注意**

此模块的连续时间实现仅在双精度浮点仿真中工作。如果您提供单精度浮点参数和输入，此模块会将其转换为双精度浮点值以防止错误。

对于离散时间仿真，请将 **滤波器类型** 参数设置为 `Extended Kalman filter` 或 `Unscented Kalman filter`，并将 **采样时间（-1 表示继承）** 参数设置为正值或 `-1`。

### 方程

这些图分别展示具有单时间常数动态和双时间常数动态的电池等效电路：

具有双时间常数动态的等效电路方程为：

dSOCdt=−i3600AHdV1dt=iC1(SOC,T)−V1R1(SOC,T)C1(SOC,T)dV2dt=iC2(SOC,T)−V2R2(SOC,T)C2(SOC,T)Vt=V0(SOC,T)−iR0−V1−V2

其中

- *SOC* 是荷电状态。
- *i* 是电流。
- *V*0 是空载电压。
- *V*t 是端电压。
- *AH* 是安时额定值。
- *R*1 是第一极化电阻。
- *C*1 是第一并联 RC 电容。
- *R*2 是第二极化电阻。
- *C*2 是第二并联 RC 电容。
- *T* 是温度。
- *V*1 是第一个 RC 网络上的极化电压。
- *V*2 是第二个 RC 网络上的极化电压。

第一并联部分的时间常数 *τ*1 通过关系 C1=τ1/R1 将第一极化电阻 *R*1 与第一并联 RC 电容 *C*1 关联。

第二并联部分的时间常数 *τ*2 通过关系 C2=τ2/R2 将第二极化电阻 *R*2 与第二并联 RC 电容 *C*2 关联。

对于卡尔曼滤波算法，该模块使用此状态以及这些过程函数和观测函数：

x=[SOCV1]Tf(x,i)=[−i3600AHiC1(SOC,T)−V1R1(SOC,T)C1(SOC,T)]h(x,i)=V0(SOC,T)−iR0−V1

如果将 **Charge dynamics** 参数设置为 `Two time-constant dynamics`，对于卡尔曼滤波算法，该模块使用此状态以及这些过程函数和观测函数：

x=[SOCV1V2]Tf(x,i)=[−i3600AHiC1(SOC,T)−V1R1(SOC,T)C1(SOC,T)iC2(SOC,T)−V2R2(SOC,T)C2(SOC,T)]h(x,i)=V0(SOC,T)−iR0−V1−V2

**扩展卡尔曼滤波器**

此图展示了扩展卡尔曼滤波器 (EKF) 的结构：

EKF 技术依赖每个时间步的线性化来近似非线性系统。为了在每个时间步对系统进行线性化，该算法在线计算这些雅可比矩阵：

F=∂f∂xH=∂h∂x

EKF 是一种离散时间算法。离散化后，用于电池 SOC 估计的雅可比矩阵为：

Fd=[100e−TSR1C1]Hd=[∂VOC∂SOC−1]

其中 *T*S 是采样时间，*V*OC 是开路电压。

EKF 算法包括这些阶段：

- **初始化**

  - x^(0|0)⁠— 使用时间步 0 的测量值在时间步 0 的状态估计。
  - P^(0|0)⁠— 使用时间步 0 的测量值在时间步 0 的状态估计误差协方差矩阵。
- **预测**

  - 将状态向前投影（*先验*）：

    x^(k+1|k)=f(x^(k|k),i)。
  - 将误差协方差向前投影：

    P^(k+1|k)=Fd(k)P^(k|k)FdT(k)+Q，

    其中 **Q** 是过程噪声的协方差。
- **校正**

  - 计算卡尔曼增益：

    K(k+1)=P^(k+1|k)HdT(k)(Hd(k)P^(k+1|k)HdT(k)+R)−1，

    其中 *R* 是测量噪声的协方差。
  - 使用测量值 *y(k)* 更新估计（*后验*）：

    x^(k+1|k+1)=x^(k+1|k)+K(k+1)(Vt(k)−h(x^(k|k),i))。
  - 更新误差协方差：

    P^(k+1|k+1)=(I−K(k+1)Hd)P^(k+1|k)。

**扩展卡尔曼-布西滤波器**

此图展示了扩展卡尔曼-布西滤波器 (EKBF) 的结构：

EKBF 是卡尔曼滤波器的连续时间变体。在连续时间中，预测步骤和校正步骤是耦合的。

- **初始化**

  - x^(t0)⁠— 在时间 *t*0 的状态估计。
  - P^(t0)⁠— 在时间 *t*0 的状态估计误差协方差矩阵。
- **预测-校正 EKBF 算法**

  K(t)=P(t)HT(t)R−1(t)dx^(t)dt=f(x^(t),i(t))+K(t)(Vt(t)−h(x^(t),i(t)))dP(t)dt=F(t)P(t)+P(t)FT(t)+Q(t)−K(t)H(t)P(t)

  其中：

  F(t)=∂f∂xH(t)=∂h∂x

**无迹卡尔曼滤波器**

此图展示了无迹卡尔曼滤波器 (UKF) 的结构：

EKF 通过仅使用 Taylor 展开的第一项，利用从 Taylor 展开获得的线性方程在局部近似非线性函数。在高度非线性系统中，这些解不太准确。

UKF 对一组 sigma 点使用非线性变换，该算法确定性地选择这些 sigma 点。该技术称为 *无迹变换*。变换后点的均值和协方差矩阵对于 Taylor 级数展开精确到二阶。

UKF 算法遵循这些步骤：

- **初始化**

  - x^(0|0)⁠— 使用时间步 0 的测量值在时间步 0 的状态估计。
  - P^(0|0)⁠— 使用时间步 0 的测量值在时间步 0 的状态估计误差协方差矩阵。
- 生成 sigma 点，并计算每个点的均值权重和协方差权重。

  - 选择 sigma 点 *x(i)(k|k)*
