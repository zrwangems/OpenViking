# Battery Cell Contact Monitoring

## 端口

### 输入

### **Voltage** — 并联组件电压，V 向量

并联组件的电压，以 V 为单位，指定为向量。
### 输出

### **CellConnectionError** — 接触丢失错误指示，无量纲向量

接触丢失错误的指示，返回为值可以为 `0` 或 `1` 的向量。等于 `1` 的元素对应于以下电芯或并联组件：其接触丢失症状持续的时间长于 **确认时间 (s)** 参数的值，这表示接触丢失故障。

此端口的大小等于 **Voltage** 输入端口的大小。

### **CellConnectionSymptom** — 接触丢失症状指示，无量纲向量

接触丢失症状的指示，返回为值可以为 `0` 或 `1` 的向量。等于 `1` 的元素对应于模块检测到接触问题的电芯或并联组件。

此端口的大小等于 **Voltage** 输入端口的大小。

## 描述

监测电池电芯接触

Battery Cell Contact Monitoring 模块监测电池电芯之间的接触状态。电芯接触监测算法对于电池系统的安全性、性能和可靠性至关重要，尤其是在包含许多电芯的电池包中。

此模块首先检查并联组件中的电芯接触丢失症状。如果模块检测到症状，并且此症状持续的时间长于 **确认时间 (s)** 参数的值，则模块将该症状报告为接触丢失错误。

您可以使用 **采样时间（-1 表示继承）** 参数在模块的连续和离散实现之间切换。要将模块配置为连续时间，请将该参数设置为 `0`。要将模块配置为离散时间，请将该参数设置为正的非零值，或设置为 `-1` 以从上游模块继承采样时间。

### 方程

在电芯之间的故障接触中，电压变化率可能非常小，并且噪声可能会对算法精度产生负面影响。模块使用对输出进行平滑的滤波导数来计算电压变化率，

Δvi=sTs+1vi,i=1,…,N;N>1,

其中：

- *T* 是平滑的时间常数。
- *vi* 是第 *i* 个电芯或并联组件的电压。
- *Δvi* 是第 *i* 个电芯或并联组件的平滑电压变化率。
- Δv=[Δv1,Δv2,…,ΔvN]T.
- v=[v1,v2,…,vN]T.

当并联组件中发生接触丢失故障时，电压变化率会增加。该增量的值与并联组件内部的电芯数量成反比。下图显示了正常并联组件和故障并联组件的电压随时间的变化。

模块假设并非所有并联组件都发生故障，并使用电压的平均变化率作为参考。为了检查故障症状，模块将累积误差的偏差直接与给定阈值进行比较，

ui={|Δvi|,when |Δvi|>ΔVthΔVth,when |Δvi|≤ΔVthuaverage=1NPA∑i=1NPAui

其中 *ΔVth* 是电压变化的检测阈值，用于消除电池处于空闲模式或接近空闲模式时的测量值，*N*PA 是并联组件的数量。

然后，模块在以下情况下检测到症状：

Symptom={0,when∫(u−(1+VoltageChangePar)uaverage)<eth1,when∫(u−(1+VoltageChangePar)uaverage)≥eth

其中 *eth* 是累积误差阈值，*VoltageChangePar* 是允许的峰均比。如果 *VoltageChangePar* 非常小，模块可能会检测到误报。如果 *VoltageChangePar* 太大，模块可能会检测到漏报。

### 假设与限制

- 模块不假设所有并联组件都发生故障。
- 模块不假设并联组件内的所有电芯都发生故障。
