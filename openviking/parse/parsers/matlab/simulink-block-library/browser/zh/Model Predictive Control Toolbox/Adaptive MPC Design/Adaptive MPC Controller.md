# Adaptive MPC Controller

## 端口

### 输入

#### 必需输入

### **model** — 更新的被控对象模型和标称工作点总线信号

更新的被控对象模型和标称工作点，指定为总线信号。将总线信号连接到 `model` 输入端口。在每个控制区间开始时，此信号会修改控制器对象 `Model.Plant` 和 `Model.Nominal` 属性。

Adaptive MPC Controller 要求被控对象模型为无延迟的 LTI 离散时间状态空间对象。以下命令提取构成此类模型的状态空间矩阵。

```
[A,B,C,D] = ssdata(mpcobj.Model.Plant)
```

`model` 输入的用途是用具有相同维度并代表相同控制区间的新矩阵替换这些矩阵。您还必须保留输入、输出和状态变量在控制器 `Model.Plant` 属性中出现的顺序。

当在以下模式下运行时：

- 自适应 MPC 模式，连接到 `model` 输入端口的总线必须包含以下信号，每个信号由指定名称标识：

  - `A` — *nx*×*nx* 矩阵信号，其中 *nx* 是被控对象模型状态数。
  - `B` — *nx*×*nu* 矩阵信号，其中 *nu* 是被控对象模型输入总数（即操纵变量、可测扰动和不可测扰动）。
  - `C` — *ny*×*nx* 矩阵信号，其中 *ny* 是被控对象模型输出数。
  - `D` — *ny*×*nu* 矩阵信号。
  - `X` — 长度为 *nx* 的向量信号，替换控制器 `Model.Nominal.X` 属性。
  - `Y` — 长度为 *ny* 的向量信号，替换控制器 `Model.Nominal.Y` 属性。
  - `U` — 长度为 *nu* 的向量信号，替换控制器 `Model.Nominal.U` 属性。
  - `DX` — 长度为 *nx* 的向量信号，替换控制器 `Model.Nominal.DX` 属性。它必须适合与假设控制区间的离散时间模型一起使用。有关详细信息，请参阅 Adaptive and Time-Varying MPC。

    要计算 `DX` 值，请使用您的模型的离散时间状态更新函数 (*f*)。这里，*uk* 和 *xk* 分别是当前时间步的输入值和状态值。

    DX=f(uk,xk)−xk
- 时变 MPC 模式，连接到 `model` 输入端口的总线必须包含以下三维总线信号：

  - `A` — *nx*×*nx*×(*p*+1) 矩阵信号
  - `B` — *nx*×*nu*×(*p*+1) 矩阵信号
  - `C` — *ny*×*nx*×(*p*+1)
  - `D` — *ny*×*nu*×(*p*+1) 矩阵信号
  - `X` — *nx*×(*p*+1) 矩阵信号
  - `Y` — *ny*×(*p*+1) 矩阵信号
  - `U` — *nu*×(*p*+1) 矩阵信号
  - `DX` — *nx*×(*p*+1) 矩阵信号

  这里，*p* 是控制器预测时域。对于每个信号，指定 *p*+1 个值，表示预测时域每一步的模型和标称条件。有关详细信息，请参阅 Time-Varying MPC。

构成该总线的一种方法是使用 Bus Creator (Simulink) 模块。

#### 依赖关系

**model** 中总线元素的维度取决于控制器的运行模式。要使控制器处于：

- 自适应 MPC 模式，请清除 **Linear Time-Varying (LTV) plants** 参数
- 时变 MPC 模式，请选中 **Linear Time-Varying (LTV) plants** 参数

### **ref** — 模型输出参考值 行向量 | 矩阵

被控对象输出参考值，指定为行向量信号或矩阵信号。

要在整个预测时域内使用相同的参考值，请将 **ref** 连接到具有 *Ny* 个元素的行向量信号，其中 *Ny* 是输出变量数。每个元素指定一个输出变量的参考值。

要使参考值在预测时域内（预览）从时间 *k*+1 到时间 *k*+*p* 变化，请将 **ref** 连接到具有 *Ny* 列且最多 *p* 行的矩阵信号。这里，*k* 是当前时间，*p* 是预测时域。每一行包含一个预测时域步的参考值。如果指定的行数少于 *p*，则最终参考值用于预测时域的剩余步。

### **mo** — 测量输出向量

测量输出，指定为向量信号。该模块使用测量到的被控对象输出来改进其状态估计。如果您的控制器使用默认状态估计，则必须将测量到的被控对象输出连接到 **mo** 输入端口。如果您的控制器使用自定义状态估计，则必须将估计的被控对象状态连接到 **x[k|k]** 输入端口。

#### 依赖关系

要启用此端口，请清除 **Use custom state estimation instead of using the built-in Kalman filter** 参数。

### **x[k|k]** — 自定义状态估计向量

自定义状态估计，指定为向量信号。该模块使用连接的状态估计，而不是使用内置估计器估计状态。如果您的控制器使用自定义状态估计，则必须将当前状态估计连接到 **x[k|k]** 输入端口。如果您的控制器使用默认状态估计，则必须将测量输出连接到 **mo** 输入端口。

即使噪声模型状态（如果有）不用于 MPC 优化，自定义状态向量也必须包含控制器的 `mpcstate` 对象中定义的所有状态，包括被控对象、扰动和噪声模型状态。

当替代估计技术被认为优于内置估计器时，或当状态完全可测时，请使用自定义状态估计。

#### 依赖关系

要启用此端口，请选中 **Use custom state estimation instead of using the built-in Kalman filter** 参数。

#### 附加输入

### **md** — 输入 行向量 | 矩阵

如果您的控制器预测模型具有可测扰动，则必须启用此端口，并向其连接行向量或矩阵信号。

要在整个预测时域内使用相同的可测扰动值，请将 **md** 连接到具有 *Nmd* 个元素的行向量信号，其中 *Nmd* 是操纵变量数。每个元素指定一个可测扰动的值。

要使扰动在预测时域内（预览）从时间 *k* 到时间 *k*+*p* 变化，请将 **md** 连接到具有 *Nmd* 列且最多 *p*+1 行的矩阵信号。这里，*k* 是当前时间，*p* 是预测时域。每一行包含一个预测时域步的扰动。如果指定的行数少于 *p*+1，则最终扰动用于预测时域的剩余步。

#### 依赖关系

要启用此端口，请选中 **Measured disturbances** 参数。

### **ext.mv** — 上一控制区间在被控对象中使用的控制信号向量

上一控制区间在被控对象中使用的控制信号，指定为长度为 *Nmv* 的向量信号，其中 *Nmv* 是操纵变量数。当以下情况时，使用此输入端口提高状态估计精度：

- 您知道您的控制器并非始终控制被控对象。
- 施加到被控对象的实际 MV 信号可能不同于控制器生成的值，例如在控制信号饱和时。

控制器状态估计假设 MV 为分段常数。因此，在时间 *tk*，**ext.mv** 值必须包含时间 *tk–1* 和时间 *tk* 之间的有效 MV。例如，如果 MV 实际上在此区间内变化，您可以提供在时间 *tk* 计算的时间平均值。

**注意**

- 将 **ext.mv** 连接到上一控制区间实际施加到被控对象的 MV 信号。通常，这些 MV 信号是控制器生成的值，但并非总是如此。例如，如果您的控制器离线并正在跟踪模式下运行（即控制器输出未驱动被控对象），则将实际控制信号馈送到 **ext.mv** 有助于在控制器重新切换到在线时实现无扰切换。
- 当控制器正在驱动被控对象时，插入 Memory 模块或 Unit Delay 模块，以反馈上一控制区间施加到被控对象的 MV 信号。这还避免了从 **ext.mv** 输入端口到 **mv** 输出端口的直接馈通，从而防止 Simulink® 模型中出现代数环。

有关使用外部操纵变量输入端口实现无扰切换的示例，请参阅 Switch Controller Online and Offline with Bumpless Transfer。

#### 依赖关系

要启用此端口，请选中 **External manipulated variable** 参数。

### **switch** — 启用或禁用优化的标量

要关闭控制器优化计算，请将 **switch** 连接到非零信号。

当不需要控制器输出时（例如系统手动运行或另一个控制器已接管时），禁用优化计算可减少计算量。但是，控制器会继续以通常方式更新其内部状态估计。因此，每当 **switch** 信号返回到零时，它都可以恢复优化计算。当控制器优化关闭时，该模块将当前 **ext.mv** 信号传递到控制器输出。如果未启用 **ext.mv** 输入端口，则控制器输出保持为禁用优化时的值。

有关使用外部操纵变量输入端口实现无扰切换的示例，请参阅 Switch Controller Online and Offline with Bumpless Transfer。

#### 依赖关系

要启用此端口，请选中 **Use external signal to enable or disable optimization** 参数。

### **mv.target** — 操纵变量目标向量

要指定操纵变量目标，请启用此输入端口，并连接向量信号。要使给定操纵变量跟踪其指定目标值，您还必须为该操纵变量指定非零整定权重。

运行时提供的 **mv.target** 值在整个预测时域内应用。

#### 依赖关系

要启用此端口，请选中 **Targets for manipulated variables** 参数。

#### 在线约束

### **ymin** — 最小输出变量约束 向量 | 矩阵

要指定运行时最小输出变量约束，请启用此输入端口。如果此端口禁用，则该模块使用其 `mpc` 控制器对象的 `OutputVariables.Min` 属性中指定的下界。如果某个输出变量在控制器对象中未指定下界，则在运行时该模块忽略对应的连接信号。

要使边界在预测时域内从时间 *k*+1 到时间 *k*+*p* 变化，请将 **ymin** 连接到具有 *Ny* 列且最多 *p* 行的矩阵信号。这里，*Ny* 是被控对象输出数，*k* 是当前时间，*p* 是预测时域。每一行包含一个预测时域步的边界。如果指定的行数少于 *p*，则最后一行中的边界应用于预测时域的剩余部分。如果只有一个输出变量，并且连接了不超过 *p* 个条目的向量信号，则这些条目在整个预测时域内使用。

**ymin** 信号的第 `i` 列对应于第 `i` 个被控对象输出，并在运行时替换 `mpc` 对象的 `OutputVariables(i).Max` 属性。替换行为取决于这两个变量的维度。

**`mpc` 对象中的标量 `OutputVariables(i).Min`（要应用于所有预测步的第 `i` 个被控对象输出的常数界）**

| **ymin** 维度 | 替换行为 |
| --- | --- |
| 标量 **ymin**（单输出，常数界） | **ymin** 替换 `OutputVariables(i).Min` 中定义的常数界。 |
| 列向量 **ymin**（单输出，时变界） | **ymin** 将 `OutputVariables(i).Min` 中定义的常数界替换为时变界。 |
| 行向量 **ymin**（多输出，常数界） | **ymin** 的第 `i` 个元素替换 `OutputVariables(i).Min` 中定义的常数界。 |
| 矩阵 **ymin**（多输出，时变界） | **ymin** 的第 `i` 列将 `OutputVariables(i).Min` 中定义的常数界替换为时变界。 |

**`mpc` 对象中的向量 `OutputVariables(i).Min`（针对第 `i` 个被控对象输出的时变界，在不同预测步具有不同值）**

| **ymin** 维度 | 替换行为 |
| --- | --- |
| 标量 **ymin**（单输出，常数界） | **ymin** 替换 `OutputVariables.Min` 中的第一个有限条目，并且 `OutputVariables.Min` 中的其余条目以相同位移量上移或下移，以保留原始 `OutputVariables.Min` 向量定义的曲线。 |
| 列向量 **ymin**（单输出，时变界） | **ymin** 替换 `OutputVariables(i).Min` 中定义的时变界，并丢弃原始边界曲线。 |
| 行向量 **ymin**（多输出，常数界） | **ymin** 的第 `i` 个元素替换 `OutputVariables(i).Min` 中的第一个有限条目，并且 `OutputVariables(i).Min` 中的其余条目以相同位移量上移或下移，以保留原始 `OutputVariables(i).Min` 向量定义的曲线。 |
| 矩阵 **ymin**（多输出，时变界）。 | **ymin** 的第 `i` 列替换 `OutputVariables(i).Min` 中定义的时变界，并丢弃原始边界曲线。 |

#### 依赖关系

要启用此端口，请选中 **Lower OV limits** 参数。

### 输出

#### 必需输出

### **mv** — 最优操纵变量控制作用列向量

最优操纵变量控制作用，输出为长度为 *Nmv* 的列向量信号，其中 *Nmv* 是操纵变量数量。

如果求解器收敛到局部最优解（**qp.status** 为正），则 **mv** 包含最优解。

如果求解器失败（**qp.status** 为负），则 **mv** 保持在其最近一次成功解；也就是说，控制器输出冻结。

如果求解器达到最大迭代次数仍未找到最优解（**qp.status** 为零），并且控制器的 `Optimization.UseSuboptimalSolution` 属性为：

- `true`，则 **mv** 包含次优解
- `false`，则 **mv** 保持在其最近一次成功解

#### 附加输出

### **cost** — 目标函数成本非负标量

目标函数成本，输出为非负标量信号。成本量化控制器实现其目标的程度。成本值使用缩放后的 MPC 成本函数计算，其中每一项都是无偏移且无量纲的。

仅当 **qp.status** 输出为非负时，成本值才有意义。

#### 依赖关系

要启用此端口，请选择 **Optimal cost** 参数。

### **qp.status** — 优化状态整数

优化状态，输出为整数信号。

如果控制器针对给定控制区间求解 QP 问题，则 **qp.status** 输出返回计算中使用的 QP 求解器迭代次数。该值是有限正整数，并与计算所需时间成比例。因此，较大的值意味着该时间区间内模块执行相对较慢。

QP 求解器可能由于以下原因无法找到最优解：

- **qp.status** = `0` — QP 求解器无法在 `mpc` 对象中指定的最大迭代次数内找到解。在这种情况下，如果控制器的 `Optimizer.UseSuboptimalSolution` 属性为 `false`，模块将其 **mv** 输出保持在最近一次成功解。否则，它使用最后一次求解器迭代中找到的次优解。
- **qp.status** = `-1` — QP 求解器检测到不可行的 QP 问题。有关大幅、持续扰动驱动输出变量超出其指定边界的示例，请参阅 Monitoring Optimization Status to Detect Controller Failures。在这种情况下，模块将其 **mv** 输出保持在最近一次成功解。
- **qp.status** = `-2` — QP 求解器在求解严重病态的 QP 问题时遇到数值困难。在这种情况下，模块将其 **mv** 输出保持在最近一次成功解。

在实时应用中，您可以使用 **qp.status** 设置警报或采取其他特殊操作。

#### 依赖关系

要启用此端口，请选择 **Optimization status** 参数。

## 参数

### **Adaptive MPC Controller** — 控制器对象 `mpc` 对象名称

指定一个 `mpc` 对象，该对象通过输入在模块标称工作点设计的 `mpc` 对象名称来定义 MPC 控制器。在运行时，控制器会在每个控制时刻用 **model** 输入端口指定的数据替换原始预测模型（`A`、`B`、`C` 和 `D`）和标称值（`U`、`Y`、`X` 和 `DX`）。

默认情况下，模块假定所有其他控制器对象属性（例如调节权重、约束）都是常量。您可以使用 **Online Features** 部分中的选项覆盖此假设。

以下限制适用于 `mpc` 控制器对象：

- 它必须存在于 MATLAB® 工作区中。
- 其预测模型必须是无延迟的 LTI 离散时间状态空间对象。使用 `absorbDelay` 命令将延迟转换为离散状态。预测中 `A`、`B`、`C` 和 `D` 矩阵的维度决定 `model` 输入端口信号所需的维度。

### **继承采样时间** — 从父子系统继承模块采样时间 `off`（默认）| `on`

**注意**

必须在控制器的采样率下执行 Function-Call Subsystem 或 Triggered Subsystem 模块。否则，由于以下两个原因，您可能会看到意外结果。

- MV 速率向量的第一个元素（即操纵变量的当前值与上一个值之间的差）通常会进行加权和约束，其假设是上一个 MV 值在过去以 MPC 对象中指定的采样时间出现；当模块以不同的采样率执行时，此假设不再成立。

如果清除此参数（默认），则模块的采样时间继承自控制器对象。

要查看模块的采样时间，请在 Simulink 模型窗口中，在 **Debug** 选项卡上的 **Information Overlays** 下，选择 **colors** 或 **Text**。有关详细信息，请参阅查看采样时间信息 (Simulink)。

### R2018b：MPC Simulink 模块 `mv.seq` 输出端口信号维度已更改

Adaptive MPC Controller 模块的 `mv.seq` 输出端口的信号维度已更改。以前，此信号是一个 *p*×*Nmv* 矩阵，其中 *p* 是预测时域，*Nmv* 是被操纵变量数。现在，`mv.seq` 是一个 (*p*+1)×*Nmv* 矩阵，其中第 *p*+1 行重复第 *p* 行。

## 描述

仿真自适应和时变模型预测控制器

Adaptive MPC Controller 模块使用以下输入信号：

- 测量到的被控对象输出（`mo`）
- 参考或设定点（`ref`）
- 测量到的被控对象扰动（`md`），如果有的话

此外，必需的 `model` 输入信号指定在计算最优被控对象操纵变量 `mv` 时要使用的预测模型。线性预测模型可以在每个控制区间根据运行时实际被控对象的变化而更改。预测模型可以表示用于所有预测步的单个 LTI 被控对象（自适应 MPC 模式），或表示用于不同预测步的 LTI 被控对象数组（时变 MPC 模式）。修改此模型的两种常见方法如下：

- 给定非线性被控对象模型，在当前工作点对其线性化。
- 使用被控对象数据估计经验线性时变 (LTV) 模型中的参数。

默认情况下，模块估计其预测模型状态。由于预测模型参数在运行时变化，MPC Controller 模块中使用的静态 Kalman 滤波器不适用。相反，Adaptive MPC Controller 模块使用线性时变 Kalman 滤波器 (LTVKF)。有关详细信息，请参阅自适应和时变 MPC。

在所有其他方面，Adaptive MPC Controller 模块模仿 MPC Controller 模块。由于自适应版本涉及额外开销，除非您需要在被控对象动态特性显著变化的大范围工作条件下控制非线性被控对象，否则请使用 MPC Controller 模块。

Adaptive MPC Controller 模块和 Multiple MPC Controllers 模块都使您的控制系统能够在运行时适应变化的工作条件。下表列出了使用每个模块的优点。

| 模块 | Adaptive MPC Controller | Multiple MPC Controllers |
| --- | --- | --- |
| **自适应方法** | 随着工作条件变化，为单个控制器更新预测模型 | 在为不同工作区域设计的多个控制器之间切换 |
| **优点** | - 只需离线设计一个控制器 - 运行时计算工作量更少，内存占用更小 - 对实际被控对象条件变化更具鲁棒性 | - 无需在线估计被控对象模型 - 控制器可以具有不同的采样时间、时域和权重 - 预测模型可以具有不同的阶次或时域 - 可以彻底测试有限的一组候选控制器 |
