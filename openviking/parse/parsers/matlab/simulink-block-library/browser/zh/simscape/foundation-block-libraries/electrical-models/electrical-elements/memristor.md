# Memristor

## 端口

### 守恒

### **+** — 正极端子电气

与忆阻器正极端子关联的电气守恒端口。

### **-** — 负极端子电气

与忆阻器负极端子关联的电气守恒端口。

## 参数

### **状态 A 的电阻** — 整个忆阻器处于状态 A `1 Ohm`（默认） | 正标量

如果整个忆阻器处于状态 A，即 *ξ* = 1 时的电阻。该值应大于 0。

### **状态 B 的电阻** — 整个忆阻器处于状态 B `100 Ohm`（默认） | 正标量

如果整个忆阻器处于状态 B，即 *ξ* = 0 时的电阻。该值应大于 0。

### **完成状态完全转换所需的总电荷** — 在状态之间完全转换所需的电荷 `10 mC`（默认） | 正标量

使忆阻器从完全处于一种状态转换到完全处于另一种状态所需的总电荷量。

### **t=0 时状态 A 所占比例** — 仿真开始时忆阻器中状态 A 所占比例 `0`（默认） | 最小值/最大值: (0,1)

*ξ* 在仿真开始时的初始条件。此参数在模块内设置高优先级变量目标。该值应大于或等于 0 且小于或等于 1。

### **窗口函数的指数** — 边界处的漂移控制 `2`（默认） | 正整数标量

窗口函数的指数 *p*，它使 *ξ* 的值保持在 0 和 1 之间。

## 描述

采用非线性掺杂剂漂移方法的理想忆阻器

此模块允许您使用非线性掺杂剂漂移方法对理想忆阻器建模。忆阻器的行为与电阻器类似，不同之处在于其电阻（也称为忆阻值）是已通过该器件的电流的函数。忆阻值由两种状态 A 和 B 定义，在给定时间，器件有一部分处于其中一种状态。

非线性掺杂剂漂移模型 [1] 由以下方程描述：

*V* =
*M*·*I*

*M* =
*ξ**·R*A+(1 –
*ξ*)*·R*B

dξdt=IQ0Fp(ξ)

其中

- *V* 是忆阻器两端的电压。
- *M* 是忆阻值。
- *I* 是流入 + 端子的电流。
- *R*A 和 *R*B 分别是状态 A 和状态 B 的电阻。
- *ξ* 是忆阻器处于状态 A 的比例。从 + 端子到 - 端子的正电流会增加 *ξ*。类似地，从 - 端子到 + 端子的正电流会减小 *ξ*。*ξ* 的值限制在 0 和 1 之间。
- *t* 是时间。
- *Q*0 是使忆阻器从完全处于一种状态转换到完全处于另一种状态所需的总电荷。
- *Fp(ξ)* 是一个“窗口”函数，它将 *ξ* 保持在 1 和 0 之间的窗口内，因此在器件边界处给出零漂移。

窗口函数为

*F*p(*ξ*) = 1 –
(2*ξ* –
1)2*p*

其中 *p* 是正整数。当 *ξ* 接近 0 或 1 时，会修改此函数，以提高数值稳定性。
