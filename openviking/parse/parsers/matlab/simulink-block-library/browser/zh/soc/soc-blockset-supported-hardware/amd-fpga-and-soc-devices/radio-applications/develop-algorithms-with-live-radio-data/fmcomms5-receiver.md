# FMCOMMS5 Receiver

## 端口

### 输入

### **center frequency** — 外部 RF 中心频率非负有限标量

外部 RF 中心频率，指定为非负有限标量。有效中心频率范围为 70 MHz 至 6 GHz。

#### 依赖关系

要启用此端口，请将 **中心频率源** 参数设置为 `Input port`。

**数据类型:** `double`

### **gain** — 外部增益数值标量 | 1×2 或 1×4 数值向量

外部增益，指定为数值标量，或 1×2 或 1×4 数值向量。有效增益范围为 –10 dB 至 73 dB，并且取决于中心频率。不兼容的增益和中心频率组合会从无线电硬件返回错误。对于每个中心频率可接受的最小和最大增益值，请查看制造商的规格。

根据 **通道映射** 参数配置设置增益。

- 对于单个通道，将增益指定为标量。
- 对于使用相同增益值的两个或四个通道，将增益指定为标量。模块通过标量扩展应用增益。
- 对于使用不同增益值的两个或四个通道，分别将增益指定为 1×2 或 1×4 向量。向量的第 `i` 个元素应用于由 **通道映射** 参数指定的第 `i` 个通道。

#### 依赖关系

要启用此端口，请将 **增益源** 参数设置为 `Input port`。

**数据类型:** `double`
### 输出

### **data** — 输出信号复矩阵

从无线电硬件接收的输出信号，返回为复矩阵。矩阵中的列数取决于正在使用的通道数，如 **通道映射** 参数所指定。每列对应于在一个通道上接收的复数据通道。

此端口支持这些数据类型的复数值：

- 16 位有符号整数 — 复数值是来自板的原始 16 位 I 和 Q 样本。来自 AD9361 RF 芯片 ADC 的 12 位值进行符号扩展至 16 位。
- 单精度浮点 — 复数值缩放至 [–1, 1] 范围。模块从板接收的符号扩展 16 位导出此值。
- 双精度浮点 — 复数值缩放至 [–1, 1] 范围。模块从板接收的符号扩展 16 位导出此值。

要指定数据类型，请使用 **输出数据类型** 参数。

要确认数据接收有效，请使用 **data valid** 端口。第一个有效数据帧可能包含瞬态值，从而导致包含未定义数据的数据包。

**数据类型:** `int16` | `single` | `double`
**支持复数:** 是

### **data valid** — 有效数据指示符 `1` | `0`

有效数据指示符，返回为以下值之一：

- `1` 表示模块已从无线电硬件接收到数据。
- `0` 表示模块尚未从无线电硬件接收到数据。

#### 依赖关系

要启用此端口，请在 **Advanced** 选项卡上，将 **数据超时 (sec)** 参数更新为 `Inf` 以外的值。

**数据类型:** `Boolean`

### **overflow** — 数据不连续性标志 `1` | `0`

数据不连续性标志，返回为以下值之一：

- `1` 表示存在导致非连续数据的溢出。
- `0` 表示无溢出。

您可以将此端口用作诊断工具，以确定 FMCOMMS5 Receiver 模块的实时运行情况。如果您的模型未实时运行，请增大帧大小以接近或实现实时性能。或者，您可以降低基带采样率。

#### 依赖关系

要启用此端口，请在 **Main** 选项卡上，选择 **启用 overflow 指示的输出端口** 参数。

**数据类型:** `Boolean`

## 参数

FMCOMMS5 Receiver 模块最多支持四个通道从 FMCOMMS5 Zynq 无线电硬件接收数据。使用 **通道映射** 参数指示使用单个通道还是多个通道。对于输出信号 **data** 中的每个通道，您可以独立设置 **增益 (dB)** 参数，也可以将相同设置应用于所有通道。所有其他参数值将应用于正在使用的每个通道。

要检查模块与无线电硬件之间的连接，并在它们之间同步无线电设置，请在 **Main** 选项卡上单击 **Info**。

设置模块参数值时，FMCOMMS5 Receiver 模块首先检查这些值是否具有正确的数据类型。如果这些值通过检查，这些值仍可能超出无线电硬件的范围。在这种情况下，无线电硬件会将实际值设置为尽可能接近指定值。当您下次通过单击 **Info** 将模块与无线电硬件同步时，对话框将显示实际值。

如果参数列为可调，则可以在仿真期间更改其值。

#### 主选项卡

### **无线电 IP 地址** — 无线电硬件的 IP 地址 `192.168.3.2` (默认) | 点分四段表达式

无线电硬件的 IP 地址，指定为点分四段表达式。

此参数必须与硬件设置期间分配的无线电硬件的物理 IP 地址匹配。有关更多信息，请参阅 Set Up AMD FPGA and SoC Devices。如果您使用非默认 IP 地址配置无线电硬件，请相应更新 **无线电 IP 地址**。

### **中心频率源** — 中心频率源 `Dialog` (默认) | `Input port`

中心频率源，指定为以下选项之一：

- `Dialog` — 使用 **中心频率 (Hz)** 参数设置中心频率。
- `Input port` — 使用 **center frequency** 输入端口设置中心频率。

### **中心频率 (Hz)** — RF 中心频率，以 Hz 为单位 `2.4e9` (默认) | 非负标量

RF 中心频率，以 Hz 为单位，指定为非负标量。中心频率的有效范围为 70 MHz 至 6 GHz。

**可调:** 是

#### 依赖关系

要启用此参数，请将 **中心频率源** 参数设置为 `Dialog`。

**数据类型:** `double`

### **增益源** — 增益源 `AGC Slow Attack` (默认) | `AGC Fast Attack` | `Dialog` | `Input port`

增益源，指定为以下值之一：

- `AGC Slow Attack` — 用于功率电平缓慢变化的信号。
- `AGC Fast Attack` — 用于功率电平快速变化的信号。
- `Dialog` — 使用 **增益 (dB)** 参数指定增益。
- `Input port` — 使用 **gain** 输入端口指定增益。

### **增益 (dB)** — 增益，以 dB 为单位 `10` (默认) | 数值标量 | 1×2 或 1×4 数值向量

增益，以 dB 为单位，指定为数值标量或 1×2 或 1×4 数值向量。有效增益范围为 –10 dB 至 73 dB，并且取决于中心频率。不兼容的增益和中心频率组合会从无线电硬件返回错误。对于每个中心频率可接受的最小和最大增益值，请查看制造商的规格。

根据 **通道映射** 参数配置设置增益。

- 对于单个通道，将增益指定为标量。
- 对于使用相同增益值的两个或四个通道，将增益指定为标量。模块通过标量扩展应用增益。
- 对于使用不同增益值的两个或四个通道，分别将增益指定为 1×2 或 1×4 向量。向量的第 `i` 个元素应用于由 **通道映射** 参数指定的第 `i` 个通道。

**可调:** 是

#### 依赖关系

要启用此参数，请将 **增益源** 参数设置为 `Dialog`。

**数据类型:** `double`

### **通道映射** — 通道输出映射 `1` (默认) | 整数 | `[N M]` | `[1 2 3 4]`

通道输出映射，指定为以下值之一：

- 从 1 到 4 的整数 — 该整数值指示正在使用哪个单个通道。
- `[N M]`，其中 *N* 和 *M* 是 1 到 4 的不同整数 — 通道 *N* 和 *M* 正在使用。
- `[1 2 3 4]` — 全部四个通道都在使用。

无线电硬件的 RF 芯片决定可用于接收数据的通道数。对于 FMCOMMS5，使用两个 AD9361 RF 芯片来提供对四个通道的支持。由 1 和 2 指定的通道位于第一个 AD9361 芯片上。由 3 和 4 指定的通道位于第二个 AD9361 芯片上。跨两个芯片使用多个通道有一定限制。有关更多信息，请参阅 Multiple Channel Synchronization for FMCOMMS5。

| 支持的无线电硬件 | RF 芯片 | 通道数 | 支持的 RF 端口 |
| --- | --- | --- | --- |
| ZC706 and FMCOMMS5 | 2 x AD9361 | 4 | - 对于 AD9361 Chip A：TX1A\_A, RX1A\_A, TX2A\_A, RX2A\_A - 对于 AD9361 Chip B：TX1A\_B, RX1A\_B, TX2A\_B, RX2A\_B |

### **基带采样率 (Hz)** — 基带采样率，以 Hz 为单位 `1e6` (默认) | 正标量

基带采样率，以 Hz 为单位，指定为正标量。此参数的有效范围为 520.834 kHz 至 61.44 MHz。

**注意**

要将模块与无线电硬件同步，请在 **Menu** 选项卡上单击 **Info**。如果指定速率与实际速率存在较小不匹配，请验证计算出的速率接近您实际想要的值。

**数据类型:** `double`

### **输出数据类型** — 输出信号的复数据类型 `int16` (默认) | `single` | `double`

选择输出数据类型为以下选项之一：

- `int16` — 整数值是来自板的原始 16 位 I 和 Q 样本。来自 AD9361 RF 芯片 ADC 的 12 位值进行符号扩展至 16 位。
- `single` — 单精度浮点值缩放至 [–1, 1] 范围。模块从板接收的符号扩展 16 位导出此值。
- `double` — 双精度浮点值缩放至 [–1, 1] 范围。模块从板接收的符号扩展 16 位导出此值。

### **每帧采样数** — 每帧的采样数 `20000` (默认) | 正整数

每帧的采样数，指定为正整数。在单通道模式下，每帧的采样数必须为偶数。向主机流式传输时，使用较大的帧大小可以提供更高效的性能。要确定对象的实时运行情况，请使用 **overflow** 输出端口。

### **启用 overflow 指示的输出端口** — 启用 overflow 控制信号 `on` (默认) | `off`

选择此参数可在主机-无线电硬件数据传输期间启用 **overflow** 输出端口。

### **启用突发模式** — 启用突发模式 `off` (默认) | `on`

当您选择此参数时，模块会生成一组连续帧。此设置可帮助仿真无法实时运行的模型。启用突发模式后，使用 **突发中的帧数** 参数指定连续数据量。有关如何使用此参数的更多信息，请参阅 Burst Mode。

### **突发中的帧数** — 连续突发中的帧数 `1` (默认) | 正整数

连续突发中的帧数，指定为正整数。

#### 依赖关系

要启用此参数，请选择 **启用突发模式** 参数。

**数据类型:** `double`

#### 滤波器选项卡

### **使用自定义滤波器** — 启用自定义滤波器 `off` (默认) | `on`

当您选择此参数时，滤波器链使用自定义滤波器设计而不是默认滤波器设计。例如，如果默认滤波器的增益或带宽特性不满足您的应用要求，您可以设计满足您特定要求的自定义滤波器。如果 FMCOMMS5 Receiver 模块尚未应用自定义滤波器设计，请单击 **Launch filter wizard** 以打开 ADI filter wizard。该向导使您能够基于 **基带采样率 (Hz)** 参数为 Analog Devices AD9361 RF 芯片设计自定义滤波器。您可以调整和优化用于计算模拟滤波器、插值和抽取滤波器以及 FIR 系数的设置。完成向导后，要将自定义滤波器设计应用于模块，请在模块掩码上单击 **Apply**。该设置将应用于两个 AD9361 芯片上正在使用的每个通道。

**注意**

通过使用 ADI filter wizard 将自定义滤波器应用于 FMCOMMS5 Receiver 模块时，**使用自定义滤波器** 会自动选中。要在默认滤波器设计和您的自定义滤波器设计之间切换，请分别清除或选择 **使用自定义滤波器**。然后在模块掩码上单击 **Apply**。

有关更多信息，请参阅 Baseband Sampling Rate and Filter Chains。

#### 高级选项卡

### **旁路用户逻辑** — 启用旁路用户逻辑 `off` (默认) | `on`

选择此参数可使无线电硬件数据路径旁路在 FPGA 目标定位或硬件-软件协同设计期间生成并编程的算法。有关更多信息，请参阅 FPGA Targeting Workflow and Hardware-Software Co-Design Workflow。

### **启用正交校正** — 正交校正 `on` (默认) | `off`

当您选择此参数时，模块会应用同相和正交 (IQ) 不平衡补偿。

### **启用 RF DC 校正** — RF DC 校正 `on` (默认) | `off`

当您选择此参数时，模块会应用 RF 直流 (DC) 阻断滤波器。

### **启用基带 DC 校正** — 基带 DC 校正 `on` (默认) | `off`

当您选择此参数时，模块会应用基带 DC 阻断滤波器。

### **覆盖自动采样时间** — 更改模块的采样时间 `off` (默认) | `on`

当您选择此参数时，您可以使用 **采样时间** 参数更改模块的采样时间。有关更多信息，请参阅 SDR Receiver Sample Times。

### **采样时间** — 模块的采样时间 `0.02` (默认) | 正标量

模块的采样时间，指定为正标量。默认值对应于 **每帧采样数** 除以 **基带采样率 (Hz)**。仅当部署硬件-软件协同设计实现时，才考虑更改默认值。

#### 依赖关系

要启用此参数，请选择 **覆盖自动采样时间** 参数。

**数据类型:** `double`

### **数据超时 (sec)** — I/O 操作超时，以秒为单位 `Inf` (默认) | 非负标量

I/O 操作超时，以秒为单位，指定为以下选项之一：

- `Inf` — 模块无限期等待完成 I/O 操作。
- 非负标量，*N* — 模块等待 *N* 秒以完成 I/O 操作。零秒对应于非阻塞设置。

**数据类型:** `double`

### **环回** — 内置自检 (BIST) 环回模式 `Disabled` (默认) | `Digital Tx -> Digital Rx` | `RF Rx -> RF Tx`

内置自检环回模式，指定为以下选项之一：

- `Disabled` — 禁用 BIST 环回。
- `Digital Tx -> Digital Rx` — 使数字信号在设备内环回。这些信号绕过 RF 级。
- `RF Rx -> RF Tx` — 使传入的接收器 RF 信号环回到 RF 发射器端口。这些信号绕过 FPGA。

### **测试信号注入** — BIST 信号注入模式 `Disabled` (默认) | `Tone Inject Tx` | `Tone Inject Rx`

BIST 信号注入模式，指定为以下值之一：

- `Disabled` — 禁用 BIST 信号注入。
- `Tone Inject Tx` — 启用向发射路径的 BIST 信号注入。
- `Tone Inject Rx` — 启用向接收路径的 BIST 信号注入。

当您启用 BIST 信号注入时，可以使用 **信号发生器模式** 参数设置 BIST 信号生成源。

### **Signal generator mode** — BIST 信号生成源 `PRBS`（默认） | `Tone`

BIST 信号生成源，指定为以下选项之一：

- `PRBS` — 使用板的伪随机二进制序列
  (PRBS) 生成器。

  设置单音频率和单音电平，请分别使用 **Tone frequency
  (Hz)** 和 **Tone level (dB)** 参数。

BIST 单音频率，指定为
`Fs/32`、`Fs/16`、

BIST 单音电平，指定为 `0`、
`-6`、`-12` 或

## 描述

从 FMCOMMS5 Zynq 无线电硬件接收数据

FMCOMMS5 Receiver 模块从 FMCOMMS5 Zynq® 无线电硬件接收数据。该模块支持带有 Analog Devices® FMCOMMS5 RF 卡的 Xilinx® ZC706 无线电硬件。

您可以使用 FMCOMMS5 Receiver 模块来仿真和开发各种软件定义无线电
(SDR) 应用。此图显示了使用 SoC Blockset™ Support Package for AMD FPGA and SoC Devices 在 Simulink® 中发射和接收
无线电信号的概念概览。Simulink 与 FMCOMMS5 Receiver 模块交互，以从无线电
硬件接收数据。

要通过空中发射无线电信号，将在 Simulink 中生成的信号传递给发射器模块。发射器模块将该信号转发到无线电硬件。要通过空中接收无线电信号，请使用接收器模块。接收器模块将从无线电硬件接收到的信号转发到 Simulink 中进行后处理。
