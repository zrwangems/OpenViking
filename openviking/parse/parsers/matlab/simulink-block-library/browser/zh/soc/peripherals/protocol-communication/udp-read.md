# UDP Read

## 端口

### 输入

### **msg** — UDP 数据包数值向量

此消息端口从连接的 IO Data Source 模块接收作为消息的 UDP 数据包。当 Task Manager 模块触发包含 UDP Read 模块的任务时，将处理这些消息。有关消息的详细信息，请参阅消息。

**注意**

此输入仅在仿真期间使用，在代码生成和外部模式仿真中不起作用。

**数据类型：** `SoCData`

### 输出

### **data** — 输出 UDP 数据包数值向量

从远程主机接收的输出 UDP 数据包，以数值向量形式返回。

**数据类型：** `single` | `double` | `int8` | `int16` | `int32` | `uint8` | `uint16` | `uint32`

### **length** — 接收到的 UDP 数据包长度非负标量

在输出 **data** 端口上返回的输出 UDP 数据包长度。

**数据类型：** `uint32`

## 参数

### **本地端口** — 本地主机的 IP 端口号 `25000`（默认）| 1 到 65,535 的整数

指定目标上要接收数据的应用程序的端口号。将本地 IP 端口号与远程主机的远程 IP 端口号匹配。

### **数据类型** — 接收数据的数据类型 uint8（默认）| single | double | int8 | int16 | int32 | uint16 | uint32

选择模块从发送主机接收的数据类型。将该数据类型与输入数据的数据类型匹配。

### **最大数据长度（元素）** — 输出 UDP 数据包的最大长度 `1`（默认）| 正整数

指定输出 **data** 端口在每个时间步可以生成的最大数据元素数。

### **接收缓冲区大小 (bytes)** — 接收数据中的数据字节数 `65535`（默认）| 1 到 65,535 的整数

指定模块在每个时间步可以接收的最大数据字节数。

### **启用基于事件的执行** — 启用或禁用基于事件的任务执行 `off`（默认）| `on`

要生成事件驱动代码，请选择此参数。要生成定时器驱动代码，请清除此参数。

当选择 **启用基于事件的执行** 时，无论采样时间如何，只要套接字缓冲区中接收到任何 UDP 数据，模块就会从套接字缓冲区读取数据。当清除 **启用基于事件的执行** 时，模块会在每个采样时间从套接字缓冲区读取可用的 UDP 数据。要设置模块可从套接字缓冲区读取的数据大小，请在 **接收缓冲区大小** 参数中指定大小。

### **采样时间** — 采样时间 `-1`（默认）| 非负标量

指定调度程序运行此模块的频率。如果此值为 `-1`（默认），则调度程序会为该模块分配采样时间。

## 描述

从远程主机接收 UDP 数据包

UDP Read 模块在目标上的应用程序中从远程主机接收 UDP（用户数据报协议）数据包。远程主机是您要从其接收 UDP 数据包的计算机或硬件。该模块从 UDP 套接字缓冲区读取 UDP 数据包，并将这些 UDP 数据包作为一维数组返回。
