# ECI Position to LLA

## 端口

### 输入

### **Xi** — 原始位置 3×1 元素向量

相对于 ECI 参考系的原始位置向量，指定为 3×1 元素向量。

**数据类型：** `double`

### **ΔUT1** — UTC 与 Universal Time 之间的差，标量

UTC 与 Universal Time (UT1) 之间的差，以 seconds 为单位，指定为标量，模块针对该差计算方向余弦或变换矩阵。

**示例：** `0.234`

#### 依赖关系

要启用此端口，请选中 **更高精度参数** 复选框。

**数据类型：** `double`

### **ΔAT** — 国际原子时与 UTC 之间的差，标量

国际原子时 (TAI) 与 UTC 之间的差，指定为标量，以 seconds 为单位，模块针对该差计算方向余弦或变换矩阵。

**示例：** `32`

#### 依赖关系

要启用此端口，请选中 **更高精度参数** 复选框。

**数据类型：** `double`

### **[xp,yp]** — 地球极位移 1×2 数组

地球极位移，指定为 1×2 数组，以 radians 为单位，由地壳运动沿 *x* 轴和 *y* 轴产生。

**示例：** `[-0.0682e-5 0.1616e-5]`

#### 依赖关系

要启用此端口，请选中 **更高精度参数** 复选框。

**数据类型：** `double`

### **Port\_5** — 基于归算方法的调整 1×2 数组

基于归算方法的调整，指定为 1×2 数组。端口名称取决于 **归算** 参数的设置：

- 如果归算方法为 `IAU-2000/2006`，此输入为对天球中间极 (CIP) 位置的调整，以 radians 为单位。此位置 ([d*X*,d*Y*]) 沿 *x* 轴和 *y* 轴，例如，`[-0.2530e-6 -0.0188e-6]`。
- 如果归算方法为 `IAU-76/FK5`，此输入为对经度的调整 ([Δδψ, Δδε])，以 radians 为单位。

有关历史值，请参见 International Earth Rotation and Reference Systems Service 网站 (`https://www.iers.org`)，并导航到 Earth Orientation Data Data/Products 页面。

**示例：** `[-0.2530e-6 -0.0188e-6]`

#### 依赖关系

要启用此端口，请选中 **更高精度参数**。

**数据类型：** `double`

### **Port\_6** — 时间增量源，标量

时间增量源，指定为标量，例如 Clock 模块。

#### 依赖关系

- 端口名称和时间增量取决于 **时间增量** 参数。

  | **时间增量** 值 | 端口名称 |
  | --- | --- |
  | `Day` | **day** |
  | `Hour` | **hour** |
  | `Min` | **min** |
  | `Sec` | **sec** |
  | `None` | 无端口 |
- 要禁用此端口，请将 **时间增量** 参数设置为 `None`。

**数据类型：** `double`
### 输出

### **μ l h** — 原始位置向量 3×1 元素向量

大地 LLA 坐标中的原始位置向量，以 3×1 元素向量形式返回，以 degrees 为单位。

**数据类型：** `double`

## 参数

### **归算** — 归算方法 `IAU-76/FK5` (默认) | `IAU-2000/2006`

用于转换坐标的归算方法。方法可以是以下之一：

- `IAU-76/FK5`

  使用国际天文学联合会 76/第五基本星表 (IAU-76/FK5) 参考系归算计算。如果用于转换的参考坐标系为 FK5，请选择此归算方法。

  **注意**

  此方法使用 IAU 1976 岁差模型和 IAU 1980 章动理论来归算计算。此模型和理论已不再现行，但软件为现有实现提供此归算方法。由于此归算方法使用极移近似，模块计算变换矩阵而不是方向余弦矩阵。
- `IAU-2000/2006`

  使用国际天文学联合会 2000/2006 参考系归算计算。如果用于转换的参考坐标系为 IAU-2000，请选择此归算方法。此归算方法使用 P03 岁差模型来归算计算。

#### 编程用法

| **值**: `'IAU-2000/2006'` | `'IAU-76/FK5'` |

## 描述

将地心惯性 (ECI) 坐标转换为大地纬度、经度、高度 (LLA) 坐标

ECI Position to LLA 模块基于指定的归算方法和协调世界时 (UTC)，针对指定时间和地球物理数据，将地心惯性 (ECI) 位置坐标转换为大地纬度、经度、高度 (LLA) 坐标。
