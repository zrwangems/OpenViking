# Lapse Rate Model

## 端口

### 输入

### **h (m)** — 位势高度 标量 | 数组

位势高度，指定为标量或数组。

**数据类型：** `double`
### 输出

### **T (K)** — 温度 标量 | 数组

温度，以 K 为单位返回为标量或数组。

**数据类型：** `double`

### **a (m/s)** — 声速 标量 | 数组

声速，以 m/s 为单位返回为标量或数组。

**数据类型：** `double`

### **P (Pa)** — 空气压力 标量 | 数组

空气压力，以 Pa 为单位返回为标量或数组。

**数据类型：** `double`

### **ρ (kg/m3)** — 空气密度 标量 | 数组

空气密度，以 kg/m3 为单位返回为标量或数组。

**数据类型：** `double`

### **ν (m2/s)** — 运动黏度 标量 | *m*-by-*n* 数组

运动黏度，以 m2/s 为单位返回为标量或 *m*-by-*n* 数组。

#### 依赖关系

选中 **输出运动黏度和动力黏度** 复选框会添加 **ν (m2/s)** 输出端口。

**数据类型：** `double`

### **μ (N s/m2)** — 动力黏度 标量 | *m*-by-*n* 数组

动力黏度，以 N s/m2 为单位返回为标量或 *m*-by-*n* 数组。

#### 依赖关系

选中 **输出运动黏度和动力黏度** 复选框会添加 **μ (N s/m2)** 输出端口。

**数据类型：** `double`

## 描述

实现大气递减率模型

Lapse Rate Model 模块针对输入位势高度实现环境温度、压力、密度和声速的递减率大气方程的数学表示。

Lapse Rate Model 和 ISA Atmosphere Model 模块是同一模块的替代配置。

Lapse Rate Model 模块具有以下实现：

- Lapse Rate Model — 递减率模型针对输入位势高度实现环境温度、压力、密度和声速的递减率大气方程的数学表示。您可以通过指定大气属性来自定义此大气模型。
- ISA Atmosphere Model — ISA 模型针对海平面 (0 m) 和对流层顶 (20000 m) 之间的输入位势高度，实现环境温度、压力、密度和声速的 ISA 值的数学表示。要从 Lapse Rate 实现转换为 ISA 实现，请清除 **更改大气参数** 参数。

Lapse Rate Model 模块图标以公制单位显示输入和输出端口标签。
