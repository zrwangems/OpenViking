### **输出整数溢出饱和** — 输出转换操作的溢出操作方法 `off`（默认） | `on`

指定由最终定点转换操作生成的模块输出值在整数溢出时是饱和还是回绕。有关内部模块操作的溢出操作方法，请参阅 **内部整数溢出饱和**。

- `on` — 溢出饱和到数据类型可以表示的最小值或最大值。
- `off` — 溢出回绕到数据类型可以表示的适当值。

例如，有符号 8 位整数 `int8` 可以表示的最大值为 127。任何大于该最大值的模块运算结果都会导致 8 位整数溢出。

- 选择此参数时，模块输出在 127 处饱和。类似地，模块输出在最小输出值 –128 处饱和。
- 清除此参数时，软件将导致溢出的值解释为 `int8`，这可能产生意外结果。例如，模块结果 130（二进制 1000 0010）表示为 `int8` 时为 –126。

#### 提示

- 当您的模型可能发生溢出，并且您希望在生成代码中获得显式饱和保护时，将此参数设置为 `on`。
- 要优化生成代码的效率，请保留此参数的默认 `off` 设置。使用默认设置还有助于避免过度指定模块处理超出范围信号的方式。有关详细信息，请参阅排查信号范围错误 (Simulink)。
- 选择此参数时，饱和仅应用于输出或结果。
- 通常，代码生成过程可以检测到不可能发生溢出的情况。在这种情况下，代码生成器不会生成饱和代码。

## 描述

一维平均池化层

Average Pooling 1D Layer 模块通过将输入划分为一维池化区域，然后计算每个区域的平均值来执行下采样。

该层池化所沿的维度取决于层输入：

- 对于采用 `CT` 格式的时间序列和向量序列输入（两个维度按顺序分别对应通道和时间步），该层沿时间维度进行池化。
- 对于采用 `SC` 格式的一维图像输入（两个维度按顺序分别对应空间像素和通道），该层沿空间维度进行池化。

`exportNetworkToSimulink` 函数生成此模块以表示 `averagePooling1dLayer` 对象。
