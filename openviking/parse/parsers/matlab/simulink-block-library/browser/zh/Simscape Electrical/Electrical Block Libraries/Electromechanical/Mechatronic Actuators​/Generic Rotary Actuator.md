# Generic Rotary Actuator

## 端口

### 守恒

### **+** — 正极端子电气

与执行器正极端子关联的电气守恒端口。

### **-** — 负极端子电气

与执行器负极端子关联的电气守恒端口。

### **C** — 壳体机械

与执行器壳体关联的机械旋转守恒端口。

### **R** — 转子机械

与转子关联的机械旋转守恒端口。

### **H** — 热端口 热

热端口。

#### 依赖关系

要启用此端口，请将 **建模选项** 设置为 `Show thermal port`。

## 参数

### **建模选项** — 是否启用热端口 `No thermal port`（默认） | `Show thermal port`

是否启用模块的热端口，并对将功率转换为热的损耗效应进行建模。

### 电气转矩

### **转速值** — 转速向量 `[-1500, -1000, -500, 0, 500, 1000, 1500, 2000, 2500, 3000]` `rpm`（默认）

为转矩-转速数据指定一个转速向量（包括其单位）。

### **转矩值** — 转矩向量 `[.04, .035, .03, .025, .02, .015, .01, .005, 0, -.005]` `Nm`（默认）

为转矩-转速数据指定一个转矩向量（包括其单位）。

### **额定电压** — 额定电压 `12` `V`（默认）

指明您所建模的设备的额定电压。

### **电机效率（百分比）** — 电机效率 `80`（默认）

模块用于计算与转矩相关的电气损耗的效率。

### **测量效率时的转速** — 测量效率时的转速 `2000` `rpm`（默认）

模块用于计算与转矩相关的电气损耗的转速。

### **与转矩无关的电气损耗** — 固定电气损耗 `0.1` `W`（默认）

当转矩为零时，与执行器关联的固定电气损耗。

### **仿真模式** — 仿真模式 `PWM`（默认） | `Averaged`

如果将 **仿真模式** 参数设置为 `PWM`，则向模块电气端子施加在零伏与额定电压之间切换的 PWM 波形。从电源汲取的电流等于输送机械功率并补偿电气损耗所需的量。如果施加的电压超过额定电压，则产生的转矩按比例缩放。但是，施加除额定电压以外的任何电压都可能提供不具代表性的结果。

如果将 **仿真模式** 参数设置为 `Averaged`，则响应施加电压 Vav 生成的转矩为

Vav/Vrated×T(ω)

其中 T(ω) 是转速 ω 处的转矩值。从电源汲取的电流使得电流与 Vav 的乘积等于消耗的平均功率。

### 机械

### **转子惯量** — 转子惯量 `0.0001` `kg*m^2`（默认）

转子对电机运动变化的阻力。该值可以为零。

### **转子阻尼** — 转子阻尼 `1e-8` `N*m/(rad/s)`（默认）

转子阻尼。该值可以为零。

### 温度依赖性

要启用这些参数，请将 **建模选项** 设置为 `Show thermal port`。

### **电阻温度系数** — 电阻温度系数 `3.93e-3` `1/K`（默认）

电阻温度系数。

### **测量温度** — 测量温度 `25` `degC`（默认）

定义执行器参数所对应的温度。

### 热端口

要启用此参数，请将 **建模选项** 设置为 `Show thermal port`。

### **热质量** — 热质量 `100` `J/K`（默认）

热质量是将温度升高一度所需的能量。

## 描述

由直流电压源或 PWM 驱动器驱动的通用旋转执行器

Generic Rotary Actuator 模块实现了一个通用旋转执行器模型，该执行器设计为由直流电压源或 PWM 驱动器驱动。您通过表格值定义转矩-转速特性，以在额定电压下驱动电机。此功能允许您在不参考等效电路的情况下对电机进行建模。

电机或执行器架构决定了电气损耗取决于转矩的方式。例如，直流电机的损耗与电流的平方成正比。由于转矩与电流成正比，损耗也与机械转矩成正比。大多数电机都有一个与机械转矩的平方成正比的电气损耗项。Generic Rotary Actuator 模块使用您提供的 **电机效率（百分比）** 和 **测量效率时的转速** 参数来计算此损耗项。

有些电机还有一个与转矩无关的损耗项。一个例子是并励电机，其中励磁绕组无论负载如何都汲取恒定电流。**与转矩无关的电气损耗** 参数用于考虑此效应。

电机效率是机械功率除以机械功率与两个电气损耗项之和。模块假定定义电机效率时的转速位于电动象限，因此为正。

您可以通过改变所施加电压的符号来使模块反向运行。例如，如果 REV 端口的电压大于 **反向阈值电压** 参数，则 H-Bridge 模块会反转电机方向。但是，如果您反向使用该模块，请指定正向运行的转矩-转速数据：

- 电动象限中的正转矩和正转速。
- 发电逆时针象限中的正转矩和负转速。
- 发电顺时针象限中的负转矩和正转速。

### 热效应建模

您可以公开热端口，以对将功率转换为热的损耗效应进行建模。要公开热端口，请将 **建模选项** 参数设置为以下任一值：

- `No thermal port` — 模块不包含热端口。
- `Show thermal port` — 模块包含一个热守恒端口。

有关在执行器模块中使用热端口的详细信息，请参阅《在旋转和平移执行器中模拟热效应》。
