# Phase Splitter

## 端口

### 守恒

### **~** — 可扩展三相端口 电气

可扩展复合 (**a2**,**b2**, **c2**) 三相端口

### **a,b,c** — 构成相 电气

扩展三相端口的构成相

## 描述

扩展或组合三个电气守恒端口

Phase Splitter 模块将一个复合三相端口扩展为其构成相。

扩展后的输出端口是电气守恒端口。
