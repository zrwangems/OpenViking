# Governor Type 1

## 端口

### 输入

### **speed\_pu** — 汽轮机速度标量

汽轮机的速度，以标幺值表示，指定为标量。

**数据类型：** `single` | `double`

### **Pref** — 速度参考偏置标量

速度负载参考的偏置，指定为标量。将此端口连接到汽轮机负载控制器模块（例如 Controller LCFB1 模块）的 **Pref** 输出端口。

**数据类型：** `single` | `double`
### 输出

### **Pmech(HP)** — 高压机械功率标量

高压机械功率，以标量形式返回。

**数据类型：** `single` | `double`

### **Pmech(LP)** — 低压机械功率标量

低压机械功率，以标量形式返回。

**数据类型：** `single` | `double`

### **初始转矩 (pu)** — 初始转矩 `0.45`（默认） | 标量

仿真开始时的标幺值初始转矩。

### **采样时间（-1 表示继承）** — 模块采样时间 `-1`（默认） | `0` | 正标量

连续模块执行之间的时间。执行期间，模块生成输出，并在适当情况下更新其内部状态。有关详细信息，请参阅 What Is Sample Time? 和 Specify Sample Time。

对于继承的离散时间操作，将此参数设置为 `-1`。对于离散时间操作，将此参数设置为正整数。对于连续时间操作，将此参数设置为 `0`。

如果此模块位于支持在连续操作和离散操作之间切换的掩码子系统或变体子系统中，请提升此参数，以确保在模块的连续实现和离散实现之间正确切换。有关详细信息，请参阅 Promote Block Parameters on a Mask。

## 描述

IEEE 类型 1 线性化调速汽轮机模型

Governor Type 1 模块对 IEEEG1 汽轮机-调速器模型进行建模。

此模块允许对交叉复式机组建模，并具有两组汽轮机功率分数：

- 用于低压 (LP) 的 **LP 功率分数，K\_2**、**LP 功率分数，K\_4**、**LP 功率分数，K\_6**、**LP 功率分数，K\_8**。
- 用于高压 (HP) 的 **HP 功率分数，K\_1**、**HP 功率分数，K\_3**、**HP 功率分数，K\_5**、**HP 功率分数，K\_7**。

可以使用 **采样时间（-1 表示继承）** 参数在模块的连续实现和离散实现之间切换。要将调速器配置为连续时间，请将 **采样时间（-1 表示继承）** 属性设置为 `0`。要将调速器配置为离散时间，请将 **采样时间（-1 表示继承）** 属性设置为正的非零值，或设置为 `-1` 以从上游模块继承采样时间。
