## 描述

在活动开始时发送控制令牌

初始节点用灰色实心圆圈表示。

活动开始时，会在初始节点上放置一个控制令牌。然后，控制令牌流向与初始节点相连的节点。一个活动可以有多个初始节点。所有初始节点都只有一个输出，没有输入。

### 创建 Initial Node

您可以将 Initial Node 模块从左边的调色板拖放到画布上的任意位置，从而创建初始节点。
