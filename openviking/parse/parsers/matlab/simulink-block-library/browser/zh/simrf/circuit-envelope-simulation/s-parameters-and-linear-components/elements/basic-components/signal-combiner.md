## 参数

### **接地并隐藏负端子** — 将 RF 电路端子接地 on (默认) | off

选择此参数可将负端子接地并隐藏。要暴露负端子，请清除此参数。通过暴露这些端子，您可以将它们连接到模型的其他部分。
