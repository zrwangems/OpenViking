# Vehicle Path Planner System

## 端口

### 输入

### **Pose** — 初始车辆位姿三元行向量

指定初始车辆位姿为向量信号
[*x*0
*y*0
*θ*0]，其中：

- (*x*0,
  *y*0) 是车辆后轴中心的初始位置。
- *θ*0 是初始车辆偏航角。

### **Target Pose** — 目标车辆位姿三元行向量

指定目标车辆位姿为向量信号
[*xt*
*yt*
*θt*]，其中：

- (*xt*,
  *yt*) 是车辆后轴中心的目标位置。
- *θt* 是初始车辆偏航角。

### **Enable** — 启用规划逻辑标量

要使用当前位姿、目标位姿和障碍物规划路径，将此信号设置为正值以启用路径规划器。

规划完成后，将启用信号设置为零，这会重置非线性 MPC 控制器。

路径规划器模块启用的时间必须：

- 长于规划器的最坏情况执行时间。为保证最坏情况执行时间，通过选择 **使用次优解** 参数，将规划控制器配置为在指定的最大迭代次数后应用次优解。
- 短于控制器的采样时间，采样时间使用 **采样时间** 参数指定。

### **Obstacles** — 障碍物列表五列矩阵

指定障碍物信息为具有 *N* 行的矩阵，其中 *N* 等于 **障碍物数量** 参数。每行按 [*X* *Y* *Φ* *L* *W*] 顺序包含障碍物的以下信息：

- (*X*, *Y*) — 位置，以 meters 为单位指定
- *Φ* — 偏航角，以 radians 为单位指定
- *L* — 长度，以 meters 为单位指定
- *W* — 宽度，以 meters 为单位指定

#### 依赖关系

要启用此端口，请选择对应的 **使用外部源** 参数。

### **Velocity range** — 速度范围二元向量

车辆速度范围，以 meters per second 为单位，指定为二元行向量 [*Vmin* *Vmax*]，其中：

- *Vmin* 是最小车辆速度。
- *Vmax* 是最大车辆速度。

#### 依赖关系

要启用此端口，请选择对应的 **使用外部源** 参数。

### **Steering angle range** — 前轮转向角范围二元向量

前轮转向角范围，以 radians 为单位，指定为二元行向量 [*ψmin* *ψmax*]，其中：

- *ψmin* 是最小转向角。
- *ψmax* 是最大转向角。

前轮转向角是前轮与车辆纵轴之间的角度。转向角朝向自车正横向轴时为正。

#### 依赖关系

要启用此端口，请选择对应的 **使用外部源** 参数。
### 输出

### **Path** — 规划车辆路径三列矩阵

规划车辆路径，输出为三列矩阵。每行包含车辆路径上的一个车辆位姿 [*x* *y* *θ*]，其中：

- (*x*, *y*) 是车辆后轴中心的位置。
- *θ* 是车辆偏航角。

### **Exitflag** — 优化状态整数

非线性 MPC 控制器的优化状态，输出为整数，如下所示：

- 正数 — 找到最优解
- `0` — 达到最大优化迭代次数，解可能不是最优的
- 负数 — 优化问题不可行

#### 依赖关系

要启用此端口，请选择 **优化状态** 参数。

## 描述

规划从初始位姿到目标位姿的无碰撞路径

Vehicle Path Planner System 模块模拟一个车辆路径规划器 (VPP) 系统，该系统使用多级非线性 MPC 控制器规划从初始位姿到目标位姿的无碰撞轨迹。您可以使用此模块为车辆规划路径，例如进入和驶出停车位的车辆，或在仓库中移动的机器人。

规划路径后，您可以让车辆使用路径跟随控制系统来跟踪该路径。

要自定义控制器，例如修改控制器成本函数或更改控制器初始条件，请点击 **创建 VPP 子系统**。
