# BMM150

## 端口

### 输出

### **Magnetic Field** — 由 BMM150 传感器测得的沿各轴的磁场强度向量

由连接到 NVIDIA 嵌入式板的 BMM150 传感器沿 X、Y 和 Z 轴测得的磁场强度，单位为 micro Tesla (µT)。该模块将磁场输出为 `1`-by-`3` 向量。

**数据类型：** `double`

### **Magnetic Field Status** — 磁场值的状态 `0` | `1`

磁场读数的状态。`0` 表示读取的数据是新的，`1` 表示读取的数据不是新的。

#### 依赖项

仅当选择 **状态** 参数时，此输出端口才会出现。

**数据类型：** `int8`

## 参数

### **I2C 模块** — 用于通信的模块 `empty`（默认）| 有效 I2C 模块编号

用于与 BMM150 传感器通信的 I2C 模块。不同 NVIDIA 嵌入式板支持的 I2C 模块数量不同。

#### 编程用法

|  |
| --- |
| **模块参数：** `I2CModule` |
| **类型：** 字符向量 |
| **值：** `''`|`positive integer` |
| **默认：**  `''` |

### **I2C 地址** — BMM150 传感器的 I2C 地址 `0x13`（默认）| `0x10` | `0x11` | `0x12`

BMM150 传感器与 NVIDIA 嵌入式板通信时使用的 I2C 地址。默认参数值（`0x13`）对应于 BOOSTXL-SENSORS BoosterPack™ Plug-in Module 使用的 I2C 地址。

#### 编程用法

|  |
| --- |
| **模块参数：** `I2CAddress` |
| **类型：** 字符向量 |
| **值：** `'0x10'`|`'0x11'`|`'0x12'`|`'0x13'` |
| **默认：**  `'0x13'` |

### **状态** — 设置用于获取磁场状态的输出端口 `on`（默认）| `off`

选择此参数可将 **Magnetic Field Status** 设置为其中一个输出端口。

#### 编程用法

|  |
| --- |
| **模块参数：** `Status` |
| **类型：** 字符向量 |
| **值：** `'on'` | `'off'` |
| **默认：** `'on'` |

### **预设值** — BMM150 传感器工作条件的预设值 `Low power`（默认）| `Regular` | `Enhanced` | `High accuracy`

指定读取数值时 BMM150 传感器工作条件的预设值。四个预设值之一的选择会影响电气特性（例如供电电流）以及相对于 ODR 和输出噪声所需的输出精度。

#### 编程用法

|  |
| --- |
| **模块参数：** `MagnetometerPreset` |
| **类型：** 字符向量 |
| **值：** `'Low power'`|`'Regular'`|`'Enhanced'`|`'High accuracy'` |
| **默认：**  `'Low power'` |

### **数据类型** — BMM150 传感器数值的输出数据类型 `single`（默认）| `double`

指定从 BMM150 传感器读取的数值的输出数据类型。NVIDIA 嵌入式板的默认数据类型为 `single`。如果需要，可使用此参数将数值更改为 `double`。

#### 编程用法

|  |
| --- |
| **模块参数：** `DataType` |
| **类型：** 字符向量 |
| **值：** `'single'`|`'double'` |
| **默认：**  `'single'` |

### **采样时间** — 读取数据的时间间隔 `-1`（默认）| scalar | `vector`

指定此模块从 BMM150 传感器读取数据的频率。将此参数设置为 -1 时，Simulink 会根据模型中的模块上下文确定该模块的最佳采样时间。

#### 编程用法

|  |
| --- |
| **模块参数：** `SampleTime` |
| **类型：** 字符向量 |
| **值：** scalar | vector |
| **默认：** `'0.1'` |
