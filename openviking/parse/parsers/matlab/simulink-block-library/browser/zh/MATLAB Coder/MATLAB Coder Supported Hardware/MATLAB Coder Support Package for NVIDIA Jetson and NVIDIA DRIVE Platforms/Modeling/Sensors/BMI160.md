# BMI160

## 端口

### 输出

### **Acceleration** — 由 BMI160 传感器测得的线性加速度向量

连接到 NVIDIA 嵌入式板的 BMI160 传感器沿 X、Y 和 Z 轴测得的线性加速度（以 m/s2 为单位）。该模块将线性加速度指定为 1-by-3 向量。

#### 依赖项

仅当选择 **Acceleration (m/s2)** 参数时，此输出端口才会出现。

**数据类型：** `double`

### **Angular Rate** — 由 BMI160 传感器测得的角速率向量

连接到 NVIDIA 嵌入式板的 BMI160 传感器沿 X、Y 和 Z 轴测得的角速率（以 rad/s 为单位）。该模块以 1-by-3 向量形式输出角速率。

#### 依赖项

仅当选择 **Angular rate (rad/s)** 参数时，此输出端口才会出现。

**数据类型：** `double`

### **Magnetic Field** — 由辅助 BMM150 传感器测得的磁场强度向量

连接到 NVIDIA 嵌入式板的 BMM150 传感器沿 X、Y 和 Z 轴测得的磁场强度，单位为 micro Tesla (µT)。该模块以 1-by-3 向量形式输出磁场。

#### 依赖项

仅当选择 **Magnetic Field (µT)** 参数时，此输出端口才会出现。

**数据类型：** `double`

### **Temperature** — 由 BMI160 传感器测得的温度标量

连接到 NVIDIA 嵌入式板的 BMI160 传感器测得的温度（以 ℃ 为单位）。

#### 依赖项

仅当选择 **Temperature (℃)** 参数时，此输出端口才会出现。

**数据类型：** `double`

### **Acceleration Status** — 加速度值状态 `0` | `1`

加速度测量的状态。`0` 表示读取的数据是新的，`1` 表示读取的数据不是新的。

#### 依赖项

仅当选择 **Acceleration Status** 参数时，此输出端口才会出现。

**数据类型：** `int8`

### **Angular Rate Status** — 角速率值状态 `0` | `1`

角速率测量的状态。`0` 表示读取的数据是新的，`1` 表示读取的数据不是新的。

#### 依赖项

仅当选择 **Angular Rate Status** 参数时，此输出端口才会出现。

**数据类型：** `int8`

### **Magnetic Field Status** — 磁场值状态 `0` | `1`

磁场读数的状态。`0` 表示读取的数据是新的，`1` 表示读取的数据不是新的。

#### 依赖项

仅当选择 **Magnetic Field Status** 参数时，此输出端口才会出现。

**数据类型：** `int8`

### **Interrupt Source** — 中断源状态 `0` | `1` | `-1`

Interrupt source 是一个 `1`-by-`7` 向量，表示 single tap、double tap、high-g detection、any-motion、slow-motion、flat detection 和 data ready 中断。

中断源的状态。`1` 表示中断已启用并且它是所生成中断的源。`0` 表示中断已启用但它不是所生成中断的源。`-1` 表示中断未启用。

#### 依赖项

仅当选择以下参数之一时，此输出端口才会出现。

- **Single tap**
- **Double tap**
- **High g detection**
- **Any motion**
- **Flat detection**
- **Data ready**

**数据类型：** `double`

### **Tap event Source** — 轻触事件源状态行向量

Tap event source 是一个 `1`-by-`4` 向量，表示 Single tap 或 Double tap 中断。前三个元素指示中断是否发生在 X、Y 和 Z 轴，第四个元素指示它位于轴的正方向还是负方向。对于方向，字节 `0` 表示负侧，`1` 表示正侧；对于其他字节，`1` 表示该轴是源，`0` 表示该轴不是源。

#### 依赖项

仅当选择 **Interrupt source** 参数时，此输出端口才会出现。

**数据类型：** `int8`

### **High g event Source** — 高 g 事件源状态行向量

High g event source 是一个 `1`-by-`4` 向量，表示 High g 中断。前三个元素指示中断是否发生在 X、Y 和 Z 轴，第四个元素指示它位于轴的正方向还是负方向。对于方向，字节 `0` 表示负侧，`1` 表示正侧；对于其他字节，`1` 表示该轴是源，`0` 表示该轴不是源。

#### 依赖项

仅当选择 **Interrupt source** 参数时，此输出端口才会出现。

**数据类型：** `int8`

### **Any motion event Source** — any-motion 事件源状态行向量

`Any motion event
Source` 是一个 `1`-by-`4` 向量，表示 any-motion 中断。前三个元素指示中断是否发生在 X、Y 和 Z 轴，第四个元素指示它位于轴的正方向还是负方向。对于方向，字节 `0` 表示负侧，`1` 表示正侧；对于其他字节，`1` 表示该轴是源，`0` 表示该轴不是源。

#### 依赖项

仅当选择 **Interrupt source** 参数时，此输出端口才会出现。

**数据类型：** `int8`

| `'±16g'` | `0.25g` | `15.75g` |

## 描述

测量来自 BMI160 传感器的线性加速度、角速率和温度

BMI160 模块输出连接到 NVIDIA® 嵌入式板的 BMI160 传感器沿 X、Y 和 Z 轴测得的线性加速度和角速率值。该模块还输出 BMI160 传感器读取的温度。如果将 BMM150 作为辅助传感器连接到 BMI160，则 BMI160 模块还输出 BMM150 传感器沿 X、Y 和 Z 轴测得的磁场。

该模块支持 single tap、double tap、high-g detection、any-motion、slow-motion、flat detection 和 data ready 中断。

Interrupt source 输出是一个 `1`-by-`7` 向量，其元素分别对应于 single tap、double tap、high-g detection、any-motion、slow-motion、flat detection 和 data ready 中断的源。`1` 表示它是源，`0` 表示它不是源，`-1` 表示中断未激活。

Tap source 输出是一个 `1`-by-`4` 向量，前三个元素指示 single tap/double tap 是否发生在 X、Y 和 Z 轴，第四个元素指示它位于轴的正方向还是负方向。High-g source 输出是一个 `1`-by-`4` 向量，前三个元素指示 high-g 中断是否发生在 X、Y 和 Z 轴，第四个元素指示它位于轴的正方向还是负方向。Any-motion source 输出是一个 `1`-by-`4` 向量，显示 any-motion 中断发生在 X、Y 和 Z 轴中的哪个轴，以及它位于轴的正方向还是负方向。第一个字节表示事件是否发生在 X 轴，第二个字节表示事件是否发生在 Y 轴，第三个字节表示事件是否发生在 Z 轴，第四个字节表示方向。对于方向，字节 `0` 表示负侧，`1` 表示正侧；对于其他字节，1 表示该轴是源，`0` 表示该轴不是源。

启用中断时，使用外部中断模块并开发相应的函数调用子系统。
