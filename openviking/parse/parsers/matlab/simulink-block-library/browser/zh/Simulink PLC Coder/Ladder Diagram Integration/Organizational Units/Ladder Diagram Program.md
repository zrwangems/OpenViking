## 描述

Ladder Diagram Program

Ladder Diagram 程序由逻辑的 Ladder Diagram 表示和程序变量组成。该程序从上到下、从左到右执行 Ladder Diagram 梯级。程序变量由本地和外部数据类型及其数据类型、初始值和大小组成。要了解 Rockwell IDE 中的程序结构与使用 Simulink PLC Coder™ 的 Program 结构之间的联系，请参阅
