## 描述

PLC Controller

在梯形图中，控制器是一个顶层组织单元，通常由任务和控制器标签组成。可以有一个任务或多个任务。控制器内的任务并行执行。Simulink® PLC Coder™ 中提供两种类型的控制器模块：

- PLC Controller Suite
- PLC Controller

PLC Controller Suite 是一个模块层级结构，用于对简单完整的梯形逻辑控制器结构进行建模，而 PLC Controller 模块包含梯形图逻辑语义。控制器标签存储全局变量的信息，例如 DataType、Mapping type、Port、Address 等。为梯形图定义的全局变量构成控制器的输入和输出端口。
