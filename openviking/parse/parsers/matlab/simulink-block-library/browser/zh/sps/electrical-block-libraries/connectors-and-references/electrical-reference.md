## 描述

连接到电气地

Electrical Reference 模块表示一个电气地。所有直接连接到地的模块的电气守恒端口都必须连接到 Electrical Reference 模块。包含电气元件的模型必须至少包含一个 Electrical Reference 模块。有关详细信息，请参阅接地规则。
