# SM ST2C

## 端口

### 输入

## 描述

离散时间或连续时间同步电机 ST2C 静态励磁系统，带有自动电压调节器

SM ST2C 模块实现符合 IEEE 421.5-2016[1] 的同步电机型 ST2C 静态励磁系统模型。

使用此模块对同步电机的励磁电压的控制和调节进行建模。

您可以使用 **采样时间（-1 表示继承）** 参数在模块的连续实现和离散实现之间切换。要为连续时间配置积分器，请将 **采样时间（-1 表示继承）** 属性设为 `0`。要为离散时间配置积分器，请将 **采样时间（-1 表示继承）** 属性设为正的非零值，或设为 `-1` 以从上游模块继承采样时间。

SM ST2C 模块包含四个主要组件：

- 电流补偿器根据机端电流修改测量的机端电压。
- 电压测量传感器使用低通滤波器模拟机端电压传感器的动态。
- 励磁控制元件组件将电压传感器输出与机端电压参考进行比较以产生电压误差。然后，该电压误差通过电压调节器以产生励磁电压。
- 当电源独立于机端电压时，电源对受控整流器的电源进行建模。

此图显示了 ST2C 励磁系统模型的总体结构：

- *VT* 和 *IT* 是同步电机的测量机端电压和电流。
- *VC1* 是电流补偿后的机端电压。
- *VC* 是滤波后的、电流补偿后的机端电压。

- *EFD* 和 *IFD* 分别是励磁电压和励磁电流。

以下各节详细描述模块的每个主要部分。

### 电流补偿器和电压测量传感器

电流补偿器建模为：

VC1=VT+ITRC2+XC2,

其中：

- *RC* 是负载补偿电阻。
- *XC* 是负载补偿电抗。

电压测量传感器实现为 Low-Pass Filter 模块，时间常数为 *TR*。有关离散和连续实现，请参阅 Low-Pass Filter 模块的文档。

### 励磁控制元件

此图展示了励磁控制元件的总体结构：

图中：

- Summation Point Logic 子系统为过励限制器（OEL）、欠励限制器（UEL）、定子电流限制器（SCL）和功率开关选择器 (V\_S) 电压建模求和点输入位置。有关将此模块与限制器一起使用的详细信息，请参阅励磁电流限制器。
- Take-over Logic 子系统为 OEL、UEL 和 SCL 电压建模接管点输入位置。有关将此模块与限制器一起使用的详细信息，请参阅励磁电流限制器。
- PI 子系统对 PI 控制器建模，该控制器用作自动电压调节器的控制结构，并允许表示采用现代数字控制器的设备改造。该模块的最小和最大抗积分饱和限值分别为 *VPImin* 和 *VPImax*。
- Low-Pass Filter 模块对电压调节器的主要动态进行建模。其中，*KA* 是调节器增益，*TA* 是调节器的主要时间常数。该模块的最小和最大抗积分饱和限值分别为 *VRmin* 和 *VRmax*。
- Filtered Derivative 模块对用于稳定励磁系统的速率反馈路径进行建模。其中，*KF* 和 *TF* 分别是该系统的增益和时间常数。有关精确的离散和连续实现，请参阅 Filtered Derivative 模块的文档。
- Integrator 模块通过受控饱和控制励磁机输出。参数 *EFDmax* 表示励磁机电压的限值。时间常数 *TE* 与控制绕组的电感相关。

### 励磁电流限制器

可以使用各种励磁电流限制器在不安全运行条件下修改电压调节器的输出：

- 使用过励限制器防止因励磁电流需求过大而导致磁场绕组过热。
- 使用欠励限制器在励磁过低时提升励磁，因为励磁过低可能导致失步。
- 使用定子电流限制器防止因电流过大而导致定子绕组过热。

将这些限制器中任一限制器的输出连接到以下某个点：

- 求和点，作为自动电压调节器（AVR）反馈回路的一部分
- 接管点，以覆盖 AVR 的通常行为

如果在求和点使用定子电流限制器，请使用单个输入 *VSCLsum*。如果在接管点使用定子电流限制器，请同时使用过励输入 *VSCLoel* 和欠励输入 *VSCLuel*。
