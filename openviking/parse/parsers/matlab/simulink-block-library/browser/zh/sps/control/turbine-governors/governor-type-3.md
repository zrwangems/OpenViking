# Governor Type 3

## 端口

### 输入

### **speed\_pu** — 水轮机速度标量

水轮机速度，以标幺值表示，指定为标量。

**数据类型：** `single` | `double`

### **Pref** — 速度参考偏置标量

速度负载参考的偏置，指定为标量。将此端口连接到水轮机负载控制器模块（例如 Controller LCFB1 模块）的 **Pref** 输出端口。

**数据类型：** `single` | `double`
### 输出

### **Pmech** — 机械功率标量

机械功率，以标量形式返回。

**数据类型：** `single` | `double`

连续模块执行之间的时间。在执行期间，模块生成输出，并在适当时更新其内部状态。有关详细信息，请参阅什么是采样时间？和指定采样时间。

如果此模块位于支持在连续操作和离散操作之间切换的掩码子系统或变体子系统中，请提升此参数，以确保在模块的连续实现和离散实现之间正确切换。有关详细信息，请参阅提升掩码上的模块参数。

## 描述

IEEE type 3 线性化速度调节水轮机模型

Governor Type 3 模块对带有压力管道动态特性的 IEEEG3 水轮机调速器模型进行建模。

与 Governor Type 1 模块相比，此模块具有更详细的调速器模型，并使用线性化的水轮机（或水）柱模型以及压力管道动态特性。

您可以使用 **采样时间（-1 表示继承）** 参数在模块的连续实现和离散实现之间切换。要将调速器配置为连续时间，请将 **采样时间（-1 表示继承）** 属性设置为 `0`。要将调速器配置为离散时间，请将 **采样时间（-1 表示继承）** 属性设置为正的非零值，或设置为 `-1`，以从上游模块继承采样时间。
