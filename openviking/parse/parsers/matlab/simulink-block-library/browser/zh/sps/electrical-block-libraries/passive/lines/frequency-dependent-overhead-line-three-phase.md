# Frequency-Dependent Overhead Line (Three-Phase)

## 端口

### 守恒

### **~1** — 三相交流电压 1 电气

与交流电压 1 相关联的可扩展电气守恒三相端口。

### **~2** — 三相交流电压 2 电气

与交流电压 2 相关联的可扩展电气守恒三相端口。

## 参数

### **建模选项** — 是否对复合或展开的三相端口建模 `Composite three-phase ports`（默认）| `Expanded three-phase ports`

是否对复合或展开的三相端口建模。

复合三相端口用单个模块端口表示三个独立的电气守恒端口。您可以使用复合三相端口来构建对应于三相电力系统单线图的模型。

展开的三相端口使用三个独立的电气守恒端口表示三相系统的各相。

### **线的 X 位置** — 水平线位置 `[-6, 0, 6]` `m`（默认）| 三元素向量

线在参考坐标系 *x* 轴上的位置。

### **线的 Y 位置** — 垂直线位置 `[16, 26, 16]` `m`（默认）| 三个正元素组成的向量

线在参考坐标系 *y* 轴上的位置。向量的元素必须大于 `0`。

### **导体电阻率** — 导体电阻率 `2.7e-8` `m*Ohm`（默认）| 正标量

导体电阻率。该值必须大于 `0`。

### **大地电阻率** — 大地回路电阻率 `100` `m*Ohm`（默认）| 正标量

大地回路电阻率。该值必须大于 `0`。

### **导体半径** — 导体半径 `0.017` `m`（默认）| 正标量

导体半径。该值必须大于 `0`。

### **线长度** — 线长度 `150e3` `m`（默认）| 范围 [1, 300000] 内的标量

频率相关架空线的长度。

### **接地配置** — 接地节点可访问性 `Internally grounded`（默认）| `Accessible ground nodes`

接地节点的配置。

## 描述

三相架空线，包含随频率变化的效应

Frequency-Dependent Overhead Line (Three-Phase) 模块表示高保真频率相关架空线，可提供从 0.01 Hz 到 100 kHz 的准确暂态响应仿真。

该模块计算频率相关阻抗矩阵和导纳矩阵。计算还取决于回路路径的损耗、电感和电容。

有关使用频率相关架空线（三相）的详细信息，请参阅工程应用。

### 方程

**线路模型**

多导体输电线路的电磁行为由电报方程描述。

−dVdx=ZI

−dIdx=YV

其中：

- *V* 是线路相电压向量。
- *I* 是相电流向量。
- *Z* 是单位长度的串联阻抗矩阵。
- *Y* 是单位长度的并联导纳矩阵。

这些是电流和电压向量的一般解。

|  |  |
| --- | --- |
| I(x)=e−ΨxC1+eΨxC2 | **(1)** |

|  |  |
| --- | --- |
| YcV(x)= e−ΨxC1−eΨxC2 | **(2)** |

其中 Ψ=YZ 是传播矩阵，Yc=(YZ)−1Y 是特性导纳。

现在考虑长度为 *x* = *l* 的输电线路段。在其一端的起始处，当 *x* = *0* 时，方程 1 和 2 计算如下。

|  |  |
| --- | --- |
| I1=C1+C2 | **(3)** |

|  |  |
| --- | --- |
| YcV1= C1−C2 | **(4)** |

积分常数向量 *C1* 和 *C2* 可以用 *I0* 和 *V0* 表示。

|  |  |
| --- | --- |
| C1=(I1+YcV1)2 | **(5)** |

|  |  |
| --- | --- |
| C2=(I1−YcV1)2 | **(6)** |

类似地，在 *x* = *l* 处，方程 1 和 2 计算如下。

|  |  |
| --- | --- |
| I2=e−ΨlC1+eΨlC2 | **(7)** |

|  |  |
| --- | --- |
| YcV2=e−ΨlC1−eΨlC2 | **(8)** |

为了获得输电线路模型的两个基本方程，首先使用方程 7 和 8 执行此计算。

|  |  |
| --- | --- |
| I2−YcV2=−2e−ΨlC1 | **(9)** |

然后将方程 5 代入方程 9。

|  |  |
| --- | --- |
| I2−YcV2=−H(I1+YcV1) | **(10)** |

其中 H=e−Ψl 是传播因子矩阵。方程 10 建立了多导体线路段端子处电压和电流之间的关系。

您可以获得一个伴随表达式，为 *x* = *0* 处的端子 1 提供模型。

|  |  |
| --- | --- |
| I1−YcV1=−H(I2+YcV2) | **(11)** |

定义：

- Ish,1=YcV1 — 由注入电压 *V1* 在端子 1 产生的并联电流向量
- Ish,2=YcV2 — 由注入电压 *V2* 在端子 2 产生的并联电流向量
- Irfl,1=12(I1+YcV1) — 端子 1 的反射电流
- Irfl,2=12(I2+YcV2) — 端子 2 的反射电流

最后将方程 10 和 11 重写如下：

I1=Ish,1−2HIrfl,2

I2=Ish,2−2HIrfl,1

这些方程构成了长度为 L 的线路段的行波线路模型。

特别是对于带大地回路的输电线路，参数高度依赖于频率。然后模型求解直接在相域中进行。该模块自动计算整个频率范围内的阻抗矩阵和特性导纳矩阵，并通过有理拟合执行近似。

该模型的有理拟合通过使用矢量拟合（VF）过程执行。有关相域线路模型和状态空间分析的详细信息，请参阅 *Wide-Band Line Model Implementation in Matlab for EMT Analysis* [1]。
