## 描述

永磁同步电机的直轴-交轴-零轴表示

PMSM (DQ0) 模块对具有三相定子的永磁同步电机 (PMSM) 的直轴-交轴-零轴 (dq0) 坐标系表示进行建模。使用此模块可为内置式永磁同步电机 (IPMSM)、表贴式永磁同步电机 (SPMSM)、横向磁通电机、轴向磁通（盘式）电机或 PMSM 伺服电机建模。

PMSM 具有永磁转子与绕线定子。您可在牵引应用（如电动汽车 (EV)）以及致动系统中使用这些电机。在致动系统中，PMSM 也称为 *brushless servomotors*。通常将 PMSM 设计为具有正弦反电动势 (EMF) 曲线。与具有梯形反电动势曲线的电机（如无刷直流 (BLDC) 电机）相比，此设计可减少不期望的高频机械谐波与电流谐波。

使用此模块为两种主要类型的 PMSM 建模：

- SPSM 或表贴式永磁 (SPM) 电机 — "S" 表示转子磁体为表贴式。*Ld* 与 *Lq* 相等。
- IPSM 或内置式永磁 (IPM) 电机 — "I" 表示转子磁体位于转子内部。*Ld* 与 *Lq* 不相等。

您还可以根据主磁通路径对 PMSM 进行分类。主磁通路径通常为径向，但也可为轴向，从而在相同电机物理尺寸下产生更高转矩。您可以使用 PMSM (DQ0) 模块为这两类 PMSM 建模。

**注意**

Simscape™ Electrical™ 包含若干模块，可为相同类型的电机或致动器建模。请选择对您需要回答的工程设计问题具有足够建模细节的模块。不要使用建模细节超过您需要的模块，因为更高保真度的模型会减慢仿真速度，并且更难以参数化。

像 PMSM (DQ0) 模块这样的模块使用简单等效电路为具有固定系数或参数相关系数的电机建模。这些模型具有中等保真度。使用此模块可在致动应用（如机器人和机电一体化）中设计控制器或系统，并在饱和与谐波仅微弱影响损耗时进行效率预测。有关选择合适模块以合适保真度级别为电机建模的详细信息，请参阅 Choose Blocks to Model Motors or Actuators。

### 方程

将 Park 变换应用于模块电气方程，可得到与转子角度无关的转矩表达式。

此方程定义 Park 变换：

P=2/3[cosθecos(θe−2π/3)cos(θe+2π/3)−sinθe−sin(θe−2π/3)−sin(θe+2π/3)0.50.50.5],

其中 *θe* 为电角度，等于 *Nθr*。*N* 为极对数。

模块对定子绕组电压和电流使用 Park 变换，将它们变换到与转子角度无关的 dq0 坐标系：

[vdvqv0]=P[vavbvc]

[idiqi0]=P[iaibic]

vd=Rsid+Lddiddt−NωiqLq

vq=Rsiq+Lqdiqdt+Nω(idLd+ψm)

v0=Rsi0+L0di0dt

T=32N(iq(idLd+ψm)−idiqLq)

其中：

- *Ld* = *Ls* + *Ms* + 3/2 *Lm*。*Ld* 为定子 *d* 轴电感。
- *Lq* = *Ls* + *Ms* − 3/2 *Lm*。*Lq* 为定子 *q* 轴电感。
- *L0* = *Ls* – 2*Ms*。*L0* 为定子零序电感。
- *ω* 为转子机械角速度。
- *N* 为转子永磁体极对数。
- *T* 为转子转矩。转矩从端口 **C**（表示电机壳体）流向端口 **R**（表示电机转子）。

PMSM (DQ0) 模块使用 Park 变换的原始非正交实现。如果尝试应用替代实现，dq0 电压和电流将得到不同结果。

### 替代磁链参数化

您可以使用 **Permanent magnet flux linkage** 参数通过反 EMF 或转矩常数对电机进行参数化。

反 EMF 常数是永磁体在各相标幺转速下感应的峰值电压。峰值永磁体磁链与反 EMF 之间的关系为：

ke=Nψm.

一相的反 EMF *eph* 为：

eph=keω.

转矩常数是各相标幺电流感应的峰值转矩。当两者均以 SI 单位表示时，转矩常数与反 EMF 常数在数值上相同：

kt=Nψm.

当 *Ld*=*Lq* 且所有三相电流平衡时，合成转矩 *T* 为：

T=32ktiq=32ktIpk,

其中 *Ipk* 为三个绕组中任一绕组的峰值电流。

因子 3/2 源于这是所有相转矩的稳态总和。因此，转矩常数 *kt* 也等于：

kt=23(TIpk),

其中 *T* 是在使用具有峰值线电压 *Ipk* 的平衡三相电流测试时测得的总转矩。RMS 线电流为：

kt=23Tiline,rms.

### 计算铁耗

铁耗由两项组成：一项表示主磁化路径，另一项表示在弱磁运行期间激活的跨齿尖路径。铁耗模型基于 [3]。

表示主磁化路径的项取决于感应的 RMS 定子线对中性点电压，Vmrms：

POC(Vmrms)=ahkVmrms+ajk2Vmrms2+aexk1.5Vmrms1.5.

此项在空载运行期间占主导。*k* 是关联 RMS 伏特每赫兹的反 EMF 常数。此项等于 k=Vmrms/f，其中 *f* 为电频率。右侧第一项为磁滞损耗，第二项为涡流损耗，第三项为附加损耗。模块根据您为开路磁滞、涡流和附加损耗指定的值推导分子上的三个系数。

表示跨齿尖路径的项在建立去磁场时相关，并且可通过有限元分析短路测试确定。此项取决于与跨齿尖磁通相关的 RMS EMF，Vdrms\*：

PSC(Vdrms\*)=bhkVdrms\*+bjk2Vdrms\*2+bexk1.5Vdrms\*1.5.

模块根据您为短路磁滞、涡流和附加损耗指定的值推导三个分子项。

### 模拟热效应

您可以暴露热端口，以模拟将功率转换为热量的损耗效应。要暴露热端口，请将 **Modeling option** 参数设置为以下值之一：

- `No thermal port` — 模块包含与定子 dq0 量相关的电守恒端口，但不包含热端口。
- `Show thermal port` — 模块包含与定子 dq0 量相关的电守恒端口，以及定子和转子的热守恒端口。

有关在致动器模块中使用热端口的详细信息，请参阅 Simulating Thermal Effects in Rotational and Translational Actuators。

### 变量

要在仿真前设置模块变量的优先级和初始目标值，请使用模块对话框或 Property Inspector 中的 **Initial Targets** 部分。有关详细信息，请参阅 Set Priority and Initial Target for Block Variables。

标称值提供了一种在模型中指定变量预期幅值的方法。使用基于标称值的系统缩放可提高仿真稳健性。您可以使用不同来源指定标称值，包括模块对话框或 Property Inspector 中的 **Nominal Values** 部分。有关详细信息，请参阅 System Scaling by Nominal Values。
