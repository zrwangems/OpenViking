# Induction Machine Field-Oriented Control

## 端口

### 输入

### **imRef** — 电流标量

标幺制下的励磁参考电流。

**数据类型：** `single` | `double`

### **wrRef** — 速度标量

标幺制下的转子参考速度。

**数据类型：** `single` | `double`

### **iabc** — 电流矢量

标幺制下测得的三相电流。

**数据类型：** `single` | `double`

### **wr** — 速度标量

标幺制下测得的角速度。

**数据类型：** `single` | `double`

### **Vdc** — 电压标量

测得的直流母线电压，单位为 V。

**数据类型：** `single` | `double`

### 输出

### **G** — 门极脉冲矢量 | `0` 或 `1`

逆变器门极脉冲。该模块不考虑任何死区时间。

**数据类型：** `single` | `double`

### **Visualization** — 可视化信号矢量

包含用于可视化的信号的总线。

**数据类型：** `single` | `double` | `bus`

## 描述

标幺制离散时间感应电机 FOC

Induction Machine Field-Oriented Controller 模块使用标幺制实现感应电机磁场定向控制 (FOC) 结构。为解耦转矩和磁通，FOC 使用转子 *d*-*q* 参考坐标系。该图显示了控制结构。

图中：

- *ωr* 是测得的角速度。
- *ωref* 是参考角速度。
- *id* 和 *iq* 是 *d* 轴和 *q* 轴定子电流。
- *ia*、*ib* 和 *ic* 是 *a*、*b* 和 *c* 相定子绕组电流。
- *imr\_ref* 是参考励磁电流。
- *imr* 是励磁电流。
- *vd* 和 *vq* 是 *d* 轴和 *q* 轴定子电压。
- *va*、*vb* 和 *vc* 是 *a*、*b* 和 *c* 相定子绕组电压。
- *θe* 是转子电角度。
- *GAH*、*GAL*、*GBH*、*GBL*、*GCH* 和 *GCL* 是 *a*、*b* 和 *c* 相高 (H) 和低 (L) 门极脉冲。

### 假设和限制

- 电机参数已知。
- 实现使用标幺制。
