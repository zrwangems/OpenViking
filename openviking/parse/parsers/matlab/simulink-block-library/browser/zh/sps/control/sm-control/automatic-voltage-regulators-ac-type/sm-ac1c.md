## 描述

离散时间或连续时间同步电机 AC1C 励磁系统，包括自动电压调节器和励磁机

SM AC1C 模块实现符合 IEEE 421.5-2016[1] 的同步电机 AC1C 型励磁系统模型。

使用此模块对使用交流旋转励磁机作为发电机运行的同步电机的励磁电压进行控制和调节建模。

您可以使用 **采样时间（-1 表示继承）** 参数在模块的连续实现和离散实现之间切换。要为连续时间配置积分器，请将 **采样时间（-1 表示继承）** 属性设置为 `0`。要为离散时间配置积分器，请将 **采样时间（-1 表示继承）** 属性设置为正的非零值，或设置为 `-1` 以从上游模块继承采样时间。

SM AC1C 模块由四个主要组件组成：

- 电流补偿器根据机端电流修改测量的机端电压。
- 电压测量传感器使用低通滤波器模拟机端电压传感器的动态。
- 励磁控制元件组件将电压传感器输出与机端电压参考值进行比较，以产生电压误差。然后，该电压误差经过电压调节器以产生励磁机励磁电压。
- 交流旋转励磁机对交流旋转励磁机建模，该励磁机产生励磁电压并将其施加到受控同步电机。该模块还将励磁机励磁电流（标准符号为 *VFE*）反馈回励磁系统。

以下各节详细描述模块的每个主要部分。

### 电流补偿器和电压测量传感器

电流补偿器建模为：

VC1=VT+ITRC2+XC2,

其中：

- *RC* 是负载补偿电阻。
- *XC* 是负载补偿电抗。

电压测量传感器实现为时间常数为 *TR* 的 Low-Pass Filter 模块。有关离散和连续实现，请参阅此模块的文档。

### 励磁控制元件

此图说明励磁控制元件的总体结构：

图中：

- SP 是过励限制器 (OEL)、欠励限制器 (UEL) 和定子电流限制器 (SCL) 电压的求和点输入位置。有关对此模块使用限制器的详细信息，请参阅励磁电流限制器。
- Lead-Lag 模块对与电压调节器相关的附加动态建模。这里，*TC* 是超前时间常数，*TB* 是滞后时间常数。有关离散和连续实现，请参阅 Lead-Lag 模块的文档。
- Low-Pass Filter 模块对电压调节器的主要动态建模。这里，*KA* 是调节器增益，*TA* 是调节器的主要时间常数。模块的最小和最大抗积分饱和限值分别为 *VAmin* 和 *VAmax*。
- TO 是 OEL、UEL 和 SCL 电压的接管点输入位置。有关对此模块使用限制器的详细信息，请参阅励磁电流限制器。
- Filtered Derivative 模块对用于稳定励磁系统的速率反馈路径建模。这里，*KF* 和 *TF* 分别是该系统的增益和时间常数。有关离散和连续实现，请参阅 Filtered Derivative 模块的文档。
- *EFEmin* 和 *EFEmax* 是输出励磁机励磁电压 *EFE* 的最小和最大饱和限值。

### 励磁电流限制器

您可以使用各种励磁电流限制器在不安全运行条件下修改电压调节器的输出：

- 使用过励限制器防止因励磁电流需求过大而导致励磁绕组过热。
- 使用欠励限制器在励磁过低（存在失步风险）时提升励磁。
- 使用定子电流限制器防止因电流过大而导致定子绕组过热。

将这些限制器中任意一个的输出连接到以下点之一：

- 求和点，作为自动电压调节器 (AVR) 反馈回路的一部分
- 接管点，以覆盖 AVR 的常规行为

如果在求和点使用定子电流限制器，请使用单个输入 *VSCLsum*。如果在接管点使用定子电流限制器，请同时使用过励输入 *VSCLoel* 和欠励输入 *VSCLuel*。
