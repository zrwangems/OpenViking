# Mode Switch for Invoke AUTOSAR Server Operation

## 端口

R2025b 官方文档未提供。

## 参数

### **为以下项配置模型** — 客户端-服务器模式 **代码生成** (默认) | **仿真**

选择要为客户端-服务器模块配置的模式：

- **代码生成**
- **仿真**

## 所属库

AUTOSAR Blockset

## 模块特性

R2025b 官方文档未提供。

## 扩展功能

### C/C++ 代码生成 使用 Simulink® Coder™ 生成 C 代码和 C++ 代码。

## 版本历史

**在 R2009b 中推出**

## 描述

在仿真和代码生成模式之间切换 AUTOSAR 客户端-服务器操作子系统模块

您可以将此开关模块添加到包含客户端-服务器子系统模块的 Simulink® 模型中。双击 Switch 模块可在仿真和代码生成模式之间切换客户端-服务器模块。
