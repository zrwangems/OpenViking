## 描述

机械旋转端口的参考连接

Mechanical Rotational Reference 模块表示机械旋转端口的一个参考点（也称为“坐标系”）。所有牢牢固定到坐标系的旋转端口都必须连接到一个 Mechanical Rotational Reference 模块。有关详细信息，请参阅Grounding Rules。
