# Temperature Source

## 端口

### 守恒

### **A** — 源出口 热

与源出口相关联的热守恒端口。

## 参数

### **温度** — 源出口处的绝对温度 293.15 K (默认)

源出口端口处恒定的绝对温度。

## 描述

恒定热能源，以温度为特征

Temperature Source 模块表示理想的热能源，无论系统消耗的热流多大，它都足以在其出口处维持指定的温度。

源产生恒定的绝对温度，由**温度**参数值定义。
