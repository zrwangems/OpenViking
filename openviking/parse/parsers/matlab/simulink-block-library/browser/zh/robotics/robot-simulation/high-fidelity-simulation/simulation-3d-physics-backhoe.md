# Simulation 3D Physics Backhoe

## 端口

### 输入

### **Velocity** — 使用速度输入移动车辆 `0`（默认） | 范围为 `[-7.5 ,7.5]` 的标量

用于移动反铲装载机车辆的速度输入，指定为范围 `[-7.5 , 7.5]` 内的标量。正值使车辆向前移动，而负值使方向反向。速度以米每秒 (m/s) 为单位指定。

为保持输入的反铲装载机速度稳定，系统使用 P 控制器内部估计所需加速度，并从当前反铲装载机速度获取反馈。

**数据类型：** `double`

### **Throttle** — 用于驱动反铲装载机的归一化输入 `0`（默认） | 范围为 `[-1 , 1]` 的标量

用于驱动反铲装载机的归一化输入，指定为范围 `[-1 , 1]` 内的标量。正值使车辆向前移动，而负值使方向反向。

确切的响应由车辆动力总成决定。模块支持的最大扭矩为 200 牛顿米 (Nm)，最大 RPM 为 6000。

#### 依赖关系

要启用此端口，请在 **反铲装载机输入** 下选择 **启用油门（禁用速度）输入信号** 参数。

**数据类型：** `double`

### **SteeringAngle** — 车辆方向输入 `0`（默认） | 范围为 `[-0.7854 , 0.7854]` 的标量

用于为反铲装载机车辆提供方向的转向角输入，指定为范围 `[-0.7854 , 0.7854]` 内的标量。转向角以弧度为单位指定。

由于 *z* 轴垂直向上，正输入值执行逆时针运动。

**数据类型：** `double`

### **FootBrake** — 归一化减速度扭矩输入 `0`（默认） | 范围为 `[0 , 1]` 的标量

用于降低车辆加速度的归一化减速度扭矩输入，指定为范围 `[0 , 1]` 内的标量。模块支持的最大强度为 200 牛顿米 (Nm)。

#### 依赖关系

要启用此端口，请在 **反铲装载机输入** 下选择 **启用脚制动输入信号** 参数。

**数据类型：** `double`

### **FrontBucketAngle** — 使用角度输入升高或降低前铲斗 `0`（默认） | 范围为 `[-0.6109, 1.5533]` 的标量

用于升高和降低前铲斗的前铲斗角度输入，指定为范围 `[-0.6109, 1.5533]` 内的标量。前铲斗角度以弧度为单位指定。

#### 依赖关系

要启用此端口，请在 **前铲斗输入** 下选择 **启用装载机机架和前铲斗角度输入信号** 参数。

**数据类型：** `double`

### **LoaderFrameAngle** — 使用角度输入升高或降低装载机机架 `0`（默认） | 范围为 `[-1.3963, 0]` 的标量

用于升高和降低前装载机机架的前装载机机架角度输入，指定为范围 `[-1.3963, 0]` 内的标量。装载机机架角度以弧度为单位指定。

#### 依赖关系

要启用此端口，请在 **前铲斗输入** 下选择 **启用装载机机架和前铲斗角度输入信号** 参数。

**数据类型：** `double`

### **RearBucketAngle** — 使用角度输入升高或降低后铲斗 `0`（默认） | 范围为 `[0, 1.5533]` 的标量

用于升高和降低后铲斗的后铲斗角度输入，指定为范围 `[0, 1.5533]` 内的标量。后铲斗角度以弧度为单位指定。

#### 依赖关系

要启用此端口，请在 **后铲斗输入** 下选择 **启用回转机架、动臂、斗杆和后铲斗角度输入信号** 参数。

**数据类型：** `double`

### **ArmAngle** — 使用角度输入升高或降低后斗杆 `0.0571`（默认） | 范围为 `[0.0571, 1.5533]` 的标量

用于升高和降低后铲斗的后斗杆角度输入，指定为范围 `[0.0571, 1.5533]` 内的标量。斗杆角度以弧度为单位指定。

#### 依赖关系

要启用此端口，请在 **后铲斗输入** 下选择 **启用回转机架、动臂、斗杆和后铲斗角度输入信号** 参数。

**数据类型：** `double`

### **BoomAngle** — 使用角度输入升高或降低后动臂 `0`（默认） | 范围为 `[-1.5533 , 0]` 的标量

用于升高和降低后动臂的后动臂角度输入，指定为范围 `[-1.5533 , 0]` 内的标量。动臂角度以弧度为单位指定。

#### 依赖关系

要启用此端口，请在 **后铲斗输入** 下选择 **启用回转机架、动臂、斗杆和后铲斗角度输入信号** 参数。

**数据类型：** `double`

### **SwingFrameAngle** — 使用角度输入左右移动后回转 `0`（默认） | 范围为 `[-1.2217, 1.2217]` 的标量

用于左右移动后回转的后回转角度输入，指定为范围 `[-1.2217, 1.2217]` 内的标量。回转机架角度以弧度为单位指定。

#### 依赖关系

要启用此端口，请在 **后铲斗输入** 下选择 **启用回转机架、动臂、斗杆和后铲斗角度输入信号** 参数。

**数据类型：** `double`

## 描述

3D 仿真环境中的反铲挖掘机物理模型

Simulation 3D Physics Backhoe 模块提供接口，用于在 Simulink® 3D 世界中实现反铲挖掘机车辆。

**注意**

使用 Simulation 3D Physics Backhoe 模块对模型进行仿真需要 Simulink 3D Animation™ 和 Robotics System Toolbox™ Offroad Autonomy Library 支持包。有关下载支持包的详细信息，请参阅安装 Robotics System Toolbox Offroad Autonomy Library 支持包。

要使用此模块，请确保模型中包含 Simulation 3D Scene Configuration 模块。如果将 Simulation 3D Physics Backhoe 模块的 **采样时间** 参数设置为 `-1`，该模块将继承 Simulation 3D Scene Configuration 模块中指定的采样时间。必须将 Simulation 3D Scene Configuration 模块中的采样时间设置为 0.01 或更小，以防止反铲挖掘机在 3D 可视化环境中抖动。

这些图示展示了反铲挖掘机资产参数相对于坐标轴的尺寸和位置，遵循 `yaw(z)`、`pitch(y)`、`roll(x)` 顺序。车辆布局遵循 Unreal Engine® 坐标系，该坐标系遵循左手定则世界坐标系。有关详细信息，请参阅 Robotics System Toolbox 中的 Unreal Engine 仿真坐标系。
