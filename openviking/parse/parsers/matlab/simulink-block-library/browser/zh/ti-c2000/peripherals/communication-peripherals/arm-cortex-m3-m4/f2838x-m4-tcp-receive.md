# F2838x-M4 TCP Receive

## 端口

### 输出

### **Data** — 输出数据向量

在每个时间步，该端口按 **数据大小 (N)** 参数指定的大小输出数据向量。

**Data Types:** `int8` | `uint8` | `int16` | `uint16` | `int32` | `uint32` | `single` | `double` | `Boolean`

### **Status** — 在给定时间步收到的请求数据标量

如果数据在给定时间步收到，则该端口输出 `0`。否则，它输出非零值，表示没有新数据可用。

**Data Types:** `uint8`

### **Length** — 接收数据长度标量

接收到的可变输出消息的长度

#### 依赖关系

要启用此端口，请选择 **启用可变长度** 参数。

**Data Types:** `uint32`

## 参数

### **连接模式** — 将模块设置为服务器或客户端 `Server` (默认) | `Client`

将模块设置为 TCP/IP 服务器或客户端。

当您将连接模式参数设置为 `Server` 时，请提供 **本地 IP 端口**。本地端口充当 TCP/IP 服务器上的侦听端口。

当您将连接模式参数设置为 `Client` 时，请提供要从中接收数据的 TCP/IP 服务器的 **服务器 IP 地址** 和 **服务器 IP 端口**。

### **本地 IP 端口** — 接收主机上用于接收数据的 IP 端口 `25000` (默认) | 范围 [1,65535] 内的正整数

此本地端口号充当 TCP/IP 服务器上的侦听端口。将本地端口号与发送主机的远程端口号匹配。

### **服务器 IP 地址** — 从中接收数据的服务器的远程 IP 地址 `192.168.1.10` (默认) | 任何有效的 IP 地址

指定从中接收数据的发送服务器的 IP 地址。

#### 依赖关系

仅当 **连接模式** 参数设置为 `Client` 时，此参数才会出现。

### **服务器 IP 端口** — 服务器上用于接收数据的远程 IP 端口 `25002` (默认) | 范围 [1,65535] 内的正整数

指定从中接收数据的发送服务器上的端口号。

#### 依赖关系

仅当 **连接模式** 设置为 `Client` 时，此参数才会出现。

### **数据类型** — 接收数据的数据类型 `uint8` (默认) | `double` | `single` | `int8` | `int16` | `uint16` | `int32` | `uint32` | `boolean`

选择模块接收的 TCP 数据中元素的数据类型。每个元素的大小取决于其数据类型。

### **启用可变长度** — 启用以接收可变数据长度 `off` (默认) | `on`

当您选择 **启用可变长度** 参数时，模块会配置一个输出端口 **Length**。

### **数据大小 (N)** — 接收数据中的数据字节数 `1` (默认) | 正整数

指定每个时间步要接收的数据字节数。

### **最大数据大小 (N)** — 数据的最大长度 `1` (默认) | 正整数

指定要接收的数据的最大长度。

#### 依赖关系

要启用此参数，请选择 **启用可变长度** 参数。

### **等待直到收到数据** — 等待直到请求的数据可用 `on` (默认) | `off`

- `on` — 当您选择此参数时，读取操作以阻塞模式运行。当模块等待请求的数据时，读取操作会被阻塞。如果数据可用，模块会输出数据。如果数据不可用，模块会等待数据。

  如果目标硬件在下一个读取操作开始时仍在等待数据，则会发生任务超限。

  要解决任务超限，请使用 **采样时间** 参数增大时间步。
- `off` — 当您清除此参数时，读取操作以非阻塞模式运行。读取数据时，如果数据不可用，模块会包含上一时间步收到的数据包（模块输出 0）。在此模式下，模块不会等待请求的数据可用。

### **采样时间** — 模块从发送主机读取数据的时间间隔 `0.1` (默认) | 非负值

指定模块应读取端口缓冲区的频率。输入大于 `0` 的值或 `-1`（用于继承采样时间）。

此值默认为 `0.1` seconds 的采样时间。较小的值要求处理器在更短的时间内完成相同数量的指令，这可能导致任务超限。

## 描述

通过 TCP/IP 网络从远程主机接收数据

TCP Receive 模块通过网络从远程主机或其他目标硬件接收数据。在将包含 TCP Receive 模块的模型部署到目标之前，服务器必须已启动并正在运行。

该模块以阻塞模式或非阻塞模式输出数据。在阻塞模式下，模型在等待请求的数据可用时阻塞执行。在非阻塞模式下，模型连续运行。要将模块设置为阻塞模式，请选择 **等待直到收到数据** 选项。

在每个时间步，**Data** 端口按 **数据大小 (N)** 参数指定的大小输出数据向量。**Status** 端口输出 0 或非零值，以指示是否收到新数据。**Status** 端口为 0 表示收到有效数据。

**注意**

- 您的防病毒软件或防火墙可能会阻止 TCP 流量。请配置该软件以允许来自特定 IP 端口号的流量。
- 由于 F2838x(ARM Cortex-M4) 上的 RAM 内存限制，此模块不支持将应用程序加载到 RAM。
- F2838x Arm Cortex-M 内核（Connectivity Manager）的 CPU Timer 2 为 lwIP 协议栈提供时基。它配置为每 1 ms 触发一次中断。如果模型中正在使用以太网模块，则不应重新配置此定时器。如果通过 Hardware Interrupt 模块使能相应中断，则它将每 `1` ms 运行一次中断处理程序。
- 在 TI C2000 与其他目标（如 Raspberry Pi）之间建立 TCP 通信时，请将 TCP Send 和 TCP Receive 模块配置为两者均为 client 或两者均为 server，以成功建立通信。不支持混合配置。
