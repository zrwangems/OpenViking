# Reference Frame

## 端口

### Frame

### **R** — 参考坐标系 frame

由该模块表示的局部参考坐标系。连接到坐标系连线或坐标系端口，以定义该参考坐标系的相对位置和方向。

## 描述

非惯性参考坐标系

该模块表示一个参考坐标系，您可以相对于该参考坐标系定义其他坐标系。该参考坐标系通常是非惯性的。它可以相对于 World frame 加速。该模块在模型中是可选的。
