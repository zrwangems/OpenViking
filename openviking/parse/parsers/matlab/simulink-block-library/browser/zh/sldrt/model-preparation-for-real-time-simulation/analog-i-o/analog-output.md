# Analog Output

## 端口

### 输入

### **Analog Data** — 要写入输出通道向量的数模转换器数据

作为 D/A 转换输入提供的源数据。输入值的数据类型和范围取决于板卡的能力。

**数据类型：** `single` | `double` | `int8` | `uint8` | `int16` | `uint16` | `int32` | `uint32`
### 输出

### **Missed Ticks** — 未命中 tick 计数（可选）double

在 **Connected IO** 模式下，返回模型落后于实时内核的定时器 tick 数。当模型落后超过 **最大未命中 tick 数** 时，软件报告错误并停止仿真。

#### 依赖

当您选择 **显示 “Missed Ticks” 端口** 时，此端口可见。

**数据类型：** `double`

## 参数

### **安装新板卡** — 注册板卡 `< no board selected >`（默认）

当您点击 **安装新板卡** 时，软件会显示受支持板卡的制造商列表。当您选择某个制造商时，软件会显示该制造商提供的板卡列表。当您选择某个板卡时，软件会将该板卡添加到已注册板卡列表中，并使该板卡成为当前板卡。

默认情况下，已注册板卡列表中的初始选择为 `< no board selected >`。

有关 I/O 板卡的驱动程序支持的详细信息，请参阅 Simulink Desktop Real-Time 的硬件支持。

#### 依赖

当您在已注册板卡列表中选择某个板卡时，**删除当前板卡** 和 **板卡设置** 按钮可用。

### **采样时间** — 模块的采样时间 `0.1`（默认）| double

输入一个以秒为单位的值，表示您希望模块执行并与 I/O 硬件交互的频率。模块按此采样率将模型与实时时钟同步。

如果您使用固定步长求解器，请输入您为 **固定步长** 配置参数输入的值，或该值的整数倍。

#### 程序化使用

|  |
| --- |
| **模块参数：** `SampleTime` |

### **最大未命中 tick 数** — 模型可以落后内核的定时器 tick 数 `10`（默认）| integer

在 **Connected IO** 模式下，输入模型可以落后于实时内核的定时器 tick 数。当模型落后的值小于或等于此定时器 tick 数时，软件假定该滞后是临时的。它允许模型追赶，即使模型错过了一些 tick。当模型落后的值超过此数量时，软件报告错误并停止仿真。

在 **Run in Kernel** 模式下，软件忽略此值。

#### 程序化使用

|  |
| --- |
| **模块参数：** `MaxMissedTicks` |

### **显示 “Missed Ticks” 端口** — 将未命中 tick 数发送到端口 `Missed Ticks` `'off'`（默认）| `'on'`

在 **Connected IO** 模式下，选中此复选框以将未命中 tick 数发送到输出端口 `Missed Ticks`。

在 **Run in Kernel** 模式下，`Missed Ticks` 端口为零。

#### 程序化使用

|  |
| --- |
| **模块参数：** `ShowMissedTicks` |

### **等待时让出 CPU** — 内核等待硬件时让出 CPU `'off'`（默认）| `'on'`

在 **Connected IO** 模式下，选中此复选框以在内核等待硬件响应时为其他程序授予更多 CPU 时间。

在 **Run in Kernel** 模式下，软件忽略此值。

#### 程序化使用

|  |
| --- |
| **模块参数：** `YieldWhenWaiting` |

### **输出通道** — 选择输出通道的通道向量 1（默认）| vector

输入一个通道向量，用于选择您在此板卡上使用的模拟输出通道。该向量可以是任何有效的 MATLAB® 向量形式。例如，要选择前两个模拟输出通道，请输入：

```
[1,2]
```

或

```
[1:2]
```

#### 程序化使用

|  |
| --- |
| **模块参数：** `Channels` |

### **输出范围** — 为模拟输出选择输出范围，取决于板卡

从列表中，为您为 **输出通道** 参数输入的模拟输出通道选择输出范围。例如，如果板卡的输出范围为 `±5 V`，请选择 `-5 to 5 V`。

如果您希望不同模拟通道具有不同的输出范围，请为每个不同的输出范围添加一个 I/O 模块。

#### 程序化使用

|  |
| --- |
| **模块参数：** `VoltRange` |

### **模块输入信号** — 发送到模块的值类型 `Volts`（默认）| `Normalized bipolar` | `Normalized unipolar` | `Raw`

从列表中，选择以下选项之一：

- `Volts` — 期望
  一个等于模拟输出电压的值。
- `Normalized bipolar` —
  期望一个介于 `-1` 和 `+1` 之间的值，无论
  输出电压范围如何，该值都会转换为输出电压的整个范围。
- `Normalized unipolar` —
  期望一个介于 `0` 和 `+1` 之间的值，无论
  输出电压范围如何，该值都会转换为输出电压的整个范围。例如，`0` 伏到 `+5` 伏以及 `−5` 伏到 `+5` 伏的模拟输出范围都会从 `0` 到 `+1` 之间的值进行转换。
- `Raw` — 期望一个
  从 `0` 到 `2n -1` 的值。例如，12 位 A/D 转换器期望一个介于 `0` 和 `212 -1`（`0` 到 `4095`）之间的值。此方法的优点是期望值是整数，没有舍入误差。

#### 程序化使用

|  |
| --- |
| **模块参数：** `RangeMode` |

### **初始值** — 输出通道向量的初始值

为您为 **输出通道** 参数输入的每个模拟输出通道输入初始值。例如，如果您输入了 `[1,2]`，并且您希望初始值为 `0` 伏，请输入 `[0,0]`。

#### 程序化使用

|  |
| --- |
| **模块参数：** `InitialValue` |

### **最终值** — 输出通道向量的最终值

为您为 **输出通道** 参数输入的每个模拟通道输入最终值。例如，如果您输入了 `[1,2]`，并且您希望最终值为 `0` 伏，请输入 `[0,0]`。

#### 程序化使用

|  |
| --- |
| **模块参数：** `FinalValue` |

## 描述

写入一个或多个模拟输出通道

Analog Output 模块从您的 Simulink® 模型连接并写入特定模拟输出通道。将 Analog Output 模块添加到模型后，您可以输入其 I/O 驱动程序的参数。
