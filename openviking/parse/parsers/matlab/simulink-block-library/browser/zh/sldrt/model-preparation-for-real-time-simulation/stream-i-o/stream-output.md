# Stream Output

## 端口

### 输入

### **Input Data** — 要写入通信通道的数据 numeric vector | string

作为 ASCII 数据发送到通信通道的数据值，根据 **格式字符串** 编码。
### 输出

### **Data Ready** — 数据就绪端口（可选） `1` | `0`

如果模块准备好接受新数据，此端口发出 `1`，否则发出 `0`。

#### 依赖关系

当您选择 **显示 “Data Ready” 端口** 时，此端口可见。

### **Data Error** — 数据错误端口（可选） `1` | `0`

如果发生数据错误，此端口发出 `1`，否则发出 `0`。

#### 依赖关系

当您选择 **显示 “Data Error” 端口** 时，此端口可见。

### **Missed Ticks** — 丢失节拍计数（可选） double

在 **Connected IO** 模式下，返回模型落后于实时内核的定时器节拍数。当模型落后超过 **最大丢失节拍数** 时，软件报告错误并停止仿真。

#### 依赖关系

当您选择 **显示 “Missed Ticks” 端口** 时，此端口可见。

**数据类型：** `double`

### **采样时间** — 模块的采样时间 `0.1`（默认） | double

如果您使用固定步长求解器，请输入您在 **固定步长** 配置参数中输入的值，或该值的整数倍。

### **最大丢失节拍数** — 模型可以落后内核的定时器节拍数 `10`（默认） | integer

在 **Connected IO** 模式下，输入模型可以落后实时内核的定时器节拍数。当模型落后该数量或更少的定时器节拍时，软件假定该滞后是暂时的。它允许模型赶上，即使模型丢失了一些节拍。当模型落后超过此数量时，软件报告错误并停止仿真。

在 **Run in Kernel** 模式下，软件忽略此值。

### **输入端口大小** — 指定端口数量和宽度 `1`（默认） | vector

输入一个端口宽度，或端口宽度向量。元素数量决定输入端口数量。每个端口具有由对应元素指定的宽度。例如，指定 `[3,1,2]` 表示模块有三个输入端口：一个宽度为 `3` 的向量、一个标量，以及一个宽度为 `2` 的向量，总共六个元素。您只需指定宽度。

#### 编程用法

|  |
| --- |
| **模块参数：** `PortSizes` |

### **格式字符串** — 写入流的数据项的格式 `'%g'`（默认） | character vector

输入与 C 库 I/O 例程（如 `printf`）所用格式相同的规范。格式字符串描述要发送的数据。格式字符串中的格式说明符数量必须与 **输入端口大小** 的元素总和相同。如果说明符为字符串的 `%s` 或 `%c`，则所创建的字符串类型输入端口仅接受字符串信号。此输入端口的 `Input port sizes` 参数值必须为 `"1"`，因为字符串只能是标量。

例如，假设 **输入端口大小** 为 `[3,1,2]`。那么 **格式字符串** 为 `'%d %d %d %f %d %d'` 会输出表示以下内容的 ASCII：

- 来自第一个输入端口上向量的三个整数
- 来自第二个输入端口上标量的一个 double
- 来自第三个输入端口上向量的两个整数

如果 **格式字符串** 中为某个值指定的数据类型与实际值的类型不同，则会发生类型转换。符合 **格式字符串** 的转换后数据将作为 ASCII 输出到设备。

## 描述

将格式化的 ASCII 数据写入通信通道

Stream Output 模块将格式化的 ASCII 数据写入端口或文件。在将 Stream Output 模块添加到模型后，双击 Stream Output 模块以打开模块参数：Stream Output 对话框。

驱动程序必须是以下之一：

- **标准设备** > **文件**
- **标准设备** > **串行端口**
- **标准设备** > **TCP 协议**
- **标准设备** > **UDP 协议**

当您安装 UDP 设备时，在标准设备 UDP 协议对话框中以十进制格式输入端口地址。

任何串行输出端口都可以发送采样率高达 500 Hz 的数据。要为某些输出串行端口启用高达 10 kHz 的更快采样率，请点击 **安装新板卡**，选择 **标准设备** > **串行端口**，然后选择 **直接端口访问**。

该模块并非对所有类型的串行输出硬件都支持此选项。
