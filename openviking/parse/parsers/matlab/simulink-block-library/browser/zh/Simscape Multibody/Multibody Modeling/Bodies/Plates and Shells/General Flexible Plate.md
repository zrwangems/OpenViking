# General Flexible Plate

## 端口

### 坐标系

### **FN** — 自定义坐标系 frame

自定义的附着于刚体的坐标系。使用 New Frame 参数指定端口名称。如果未指定自定义坐标系的名称，模块会将坐标系命名为 **FN**，其中 `N` 是标识编号。

#### 依赖关系

要启用自定义坐标系端口，请点击 **New Frame** 创建一个坐标系。

### **R** — 参考坐标系 frame

虚拟未变形体的参考坐标系，表示柔性体的整体刚体运动。**R** 坐标系并非物理上附着于柔性体。

**R** 端口不得与任何施加力/力矩或具有惯性的模块刚性连接。

## 参数

### 几何

### **Midsurface** — 板中面的坐标 [1 1; -1 1; -1 -1; 1 -1] `m` | *N*×2 矩阵 | 由 *N*×2 矩阵组成的 *M*×1 或 1×*M* cell array

用于在局部 *xy* 平面上指定板中面边界的坐标。您可以使用以下方式指定中面：

- 一个 *N*×2 的 *xy* 坐标矩阵来指定中面。每一行给出中面边界上一个点的 [*x*,*y*] 坐标。这些点按指定顺序连接以形成闭合折线。为确保折线闭合，模块会在最后一个点和第一个点之间插入一条线段。
- 一个 *M*×1 或 1×*M* 的 cell array（包含 *N*×2 的 *xy* 坐标矩阵）来指定带孔中面。数组中的第一个元素表示外边界，后续元素指定孔边界。

**注意**

确保任意两个边界不交叉、不重叠也不接触。

此外，每个单独边界必须：

- 没有重复顶点
- 没有自交
- 至少有三个不共线的点

### **Thickness** — 板厚度 0.1 `m`（默认）| 正标量

板的厚度。模块通过沿板的局部 *z* 轴拉伸指定的中面来对板建模。拉伸关于板的局部 *xy* 平面对称。为使板理论适用，厚度应远小于中面的整体尺寸。

### 刚度和惯性

### **Density** — 材料单位体积的质量 2700 `kg/m^3`（默认）| 正标量

材料的单位体积质量。默认值对应于铝。

### **Specify** — 用于参数化板的弹性属性 `Young's Modulus and Poisson's Ratio`（默认）| `Young's and Shear Modulus`

用于参数化板的弹性属性。您可以指定 `Young's Modulus and Poisson's Ratio` 或 `Young's and Shear Modulus`。这些属性通常可在材料数据库中获得。

### **Young's Modulus** — 轴向应力与轴向应变之比 70 `GPa`（默认）| 正标量

板的弹性杨氏模量。该参数值越大，对弯曲和面内法向变形的抵抗越强。默认值对应于铝。

### **Poisson's Ratio** — 横向应变与法向应变之比 0.33（默认）| 取值范围 [0, 0.5) 的标量

板的泊松比。指定值必须大于或等于 0 且小于 0.5。默认值对应于铝。

#### 依赖关系

要启用此参数，请将 **Specify** 设置为 `Young's Modulus and Poisson's Ratio`。

### **Shear Modulus** — 剪切应力与工程剪切应变之比 26 `GPa`（默认）| 正标量

板的剪切模量，也称为刚性模量。值越大，对剪切和扭转的抵抗越强。默认值对应于铝。

#### 依赖关系

要启用此参数，请将 **Specify** 设置为 `Young's and Shear Modulus`。

### 阻尼

### **Type** — 阻尼方法类型 `Proportional`（默认）| `Uniform Modal` | `None`

板的阻尼方法：

- 选择 `None` 对无阻尼板建模。
- 选择 `Proportional` 以应用比例（或 Rayleigh）阻尼方法。此方法将阻尼矩阵 [*C*] 定义为质量矩阵 [*M*] 和刚度矩阵 [*K*] 的线性组合：

  [C]=α[M]+β[K],

  其中 *α* 和 *β* 是标量系数。
- 选择 `Uniform Modal` 以应用均匀模态阻尼方法。此方法对板的所有振动模态应用单一阻尼比。值越大，振动衰减越快。

  所选择的参考条件会影响阻尼比适用的模态类型。有关参考条件的详细信息，请参阅参考条件。对柔性体使用模态降阶时，仅保留一部分模态。有关模态降阶的详细信息，请参阅减少柔性体的自由度。

### **Mass Coefficient** — 质量矩阵系数 0 `1/s`（默认）| 非负标量

质量矩阵的系数 *α*。此参数定义与质量矩阵 [*M*] 成比例的阻尼。

#### 依赖关系

要启用此参数，请将 **Type** 设置为 `Proportional`。

### **Stiffness Coefficient** — 刚度矩阵系数 0.001 `s`（默认）| 非负标量

刚度矩阵的系数 *β*。此参数定义与刚度矩阵 [*K*] 成比例的阻尼。

#### 依赖关系

要启用此参数，请将 **Type** 设置为 `Proportional`。

### **Damping Ratio** — 均匀模态阻尼方法的阻尼比 0.01（默认）| 无量纲非负标量

应用于板所有振动模态的阻尼比 *ζ*。值越大，振动衰减越快。如果应用于板的边界条件与所选择的参考条件完全匹配，*ζ* < 1 产生欠阻尼模态衰减，而 *ζ* > 1 产生过阻尼耗散。当边界条件与参考条件不匹配时，所选阻尼比的影响会变化。有关参考条件的详细信息，请参阅参考条件。

#### 依赖关系

要启用此参数，请将 **Type** 设置为 `Uniform Modal`。

**数据类型：** `double`

### 参考条件

### **Type** — 参考条件类型 `Linearized Mean Axes`（默认）| `Body-Fixed`

指定要应用的参考条件类型。有关详细信息，请参阅参考条件。

- `Linearized Mean Axes`：参考的体坐标系跟随瞬时质心，柔性体表现出无约束的变形振动模态。
- `Body-Fixed`：选择一个附着于刚体的坐标系作为参考体坐标系。柔性体的变形表现出自由振动模态振型，在参考体坐标系位置处具有零平动和转动变形。

### **Frame** — 用于 body-fixed 参考条件的连接坐标系 坐标系名称

输入要用作参考体坐标系的连接坐标系名称。坐标系名称区分大小写。确保所选坐标系在模块上作为端口公开。不能使用 **R** 坐标系，它是虚拟未变形体的参考坐标系。

#### 依赖关系

要启用此参数，请将 **Type** 设置为 `Body-Fixed`。

### **Show Port R** — 显示参考坐标系端口 `off`（默认）| `on`

选择以公开 **R** 端口，它表示虚拟未变形体的参考坐标系。请注意，**R** 坐标系并非物理上附着于柔性体。

**R** 端口不得与任何施加力/力矩或具有惯性的模块刚性连接。

### 保真度

### **Reduction** — 对柔性体建模的方法 `None`（默认）| `Modally Reduced`

用于对柔性体建模的方法，指定为 `None` 或 `Modally Reduced`。将参数设置为 `None`，以使用有限元方法生成的完整节点弹性坐标；或将参数设置为 `Modally Reduced`，以使用模态变换方法减少体的弹性坐标。对于这两种设置，模块都使用浮动参考坐标系公式 [5-6] 将体与其弹性变形耦合。

### **Number of Retained Modes** — 保留模态 1（默认）| 非负整数

保留模态，指定为范围 [0, *n*] 内的整数，其中 *n* 是体的弹性自由度数量。如果将数值设置为 0，则柔性体被视为刚体。

#### 依赖关系

要启用此参数，请将 **Reduction** 设置为 `Modally Reduced`。

### 图形

### **Type** — 用于板可视化的图形类型 `From Geometry`（默认）| `None`

板的视觉表示类型，指定为 `From Geometry` 或 `None`。将参数设置为 `From Geometry` 以显示板的视觉表示。将参数设置为 `None` 以在模型可视化中隐藏板。

### **Visual Properties** — 颜色和不透明度的参数化 `Simple`（默认）| `Advanced`

用于指定视觉属性的参数化。选择 `Simple` 以指定颜色和不透明度。选择 `Advanced` 以指定更多视觉属性，例如 **Specular Color**、**Ambient Color**、**Emissive Color** 和 **Shininess**。

#### 依赖关系

要启用此参数，请将 **Type** 设置为 `From Geometry`。

### **Color** — 漫反射导致的颜色 [0.5 0.5 0.5]（默认）| 取值范围为 0 到 1 的 3×1 或 1×3 向量 | 取值范围为 0 到 1 的 4×1 或 1×4 向量

在直射白光下图形的颜色，指定为 0–1 范围内的 [R G B] 或 [R G B A] 向量。可选的第四个元素 (A) 指定颜色不透明度，范围为 0–1。省略不透明度元素等效于指定值 1。

#### 依赖关系

要启用此参数，请设置：

1. **Type** 为 `From Geometry`
2. **Visual Properties** 为 `Simple`

### **Opacity** — 图形不透明度 1.0（默认）| 取值范围为 0 到 1 的标量

图形不透明度，指定为 0 到 1 范围内的标量。标量 0 对应于完全透明，标量 1 对应于完全不透明。

#### 依赖关系

要启用此参数，请设置：

1. **Type** 为 `From Geometry`
2. **Visual Properties** 为 `Simple`

### **Diffuse Color** — 图形颜色 [0.5 0.5 0.5]（默认）| 三元素向量 | 三元素向量

在直射白光下图形的颜色，指定为 0–1 范围内的 [R G B] 或 [R G B A] 向量。可选的第四个元素指定颜色不透明度，范围为 0–1。省略不透明度元素等效于指定值 1。

#### 依赖关系

要启用此参数，请设置：

1. **Type** 为 `From Geometry`
2. **Visual Properties** 为 `Advanced`

### **Specular Color** — 镜面反射导致的颜色 [0.5 0.5 0.5 1.0]（默认）| 取值范围为 0 到 1 的 3×1 或 1×3 向量 | 取值范围为 0 到 1 的 4×1 或 1×4 向量

镜面反射导致的颜色，指定为取值范围 0 到 1 的 [R,G,B] 或 [R,G,B,A] 向量。该向量可以是行向量或列向量。可选的第四个元素指定颜色不透明度。省略不透明度元素等效于指定值 1。此参数会改变镜面高光的颜色，即渲染梁上因光源光反射而产生的亮点。

#### 依赖关系

要启用此参数，请设置：

1. **Type** 为 `From Geometry`
2. **Visual Properties** 为 `Advanced`

### **Ambient Color** — 环境光颜色 [0.15 0.15 0.15 1.0]（默认）| 取值范围为 0 到 1 的 3×1 或 1×3 向量 | 取值范围为 0 到 1 的 4×1 或 1×4 向量

环境光颜色，指定为取值范围 0 到 1 的 [R,G,B] 或 [R,G,B,A] 向量。该向量可以是行向量或列向量。可选的第四个元素指定颜色不透明度。省略不透明度元素等效于指定值 1。

环境光指不直接来自光源的一般照明水平。环境光由已反射和再反射多次、不再来自任何特定方向的光组成。您可以调整此参数以改变渲染梁的阴影颜色。

#### 依赖关系

要启用此参数，请设置：

1. **Type** 为 `From Geometry`
2. **Visual Properties** 为 `Advanced`

### **Emissive Color** — 自发光颜色 [0.0 0.0 0.0 1.0]（默认）| 取值范围为 0 到 1 的 3×1 或 1×3 向量

自发光导致的颜色，指定为取值范围 0 到 1 的 [R,G,B] 或 [R,G,B,A] 向量。该向量可以是行向量或列向量。可选的第四个元素指定颜色不透明度。省略不透明度元素等效于指定值 1。

自发光颜色是不来自任何外部光源的颜色，因此看起来像是梁自身发出的。当梁具有自发光颜色时，即使没有外部光源也可以看到梁。

#### 依赖关系

要启用此参数，请设置：

1. **Type** 为 `From Geometry`
2. **Visual Properties** 为 `Advanced`

### **Shininess** — 高光锐度 75（默认）| 取值范围限定为 0–128 的标量

镜面光反射的锐度，指定为 0–128 范围内的标量数值。增大 shininess 值可获得更小但更锐利的高光。减小该值可获得更大但更平滑的高光。

#### 依赖关系

要启用此参数，请设置：

1. **Type** 为 `From Geometry`
2. **Visual Properties** 为 `Advanced`

### 坐标系

### **New Frame** — 创建用于连接到其他模块的自定义坐标系 按钮

点击 **Create** 按钮以打开用于创建新附着于刚体坐标系的面板。在此面板中，您可以指定坐标系名称、原点和方向。

- 要为自定义坐标系命名，请在 **Frame Name** 参数中输入名称。该名称标识模块上的端口以及 Multibody Explorer 树视图窗格中的端口。
- 在 **Frame Origin** 部分中选择坐标系原点：

  - **At Reference Frame Origin**：使新坐标系原点与未变形板的参考坐标系原点重合。
  - **Based on Geometric Feature**：使新坐标系原点与所选未变形几何特征的中心重合。有效特征包括曲面、线和点。从可视化窗格中选择一个特征，然后点击 **Use Selected Feature** 按钮以确认原点位置。原点位置的名称将出现在此选项下方的字段中。
- 要定义自定义坐标系的方向，请在 **Frame Axes** 部分下选择自定义坐标系的 **Primary Axis** 和 **Secondary Axis**，然后指定其方向。

  使用以下方法选择用于指定主轴和次轴方向的向量。主轴平行于所选向量，并将其余两个轴约束到其法平面。次轴平行于所选向量在法平面上的投影。

  - **Along Reference Frame Axis**：选择未变形板参考坐标系的轴。
  - **Based on Geometric Feature**：选择与未变形板所选几何特征相关联的向量。有效特征包括曲面和线。相应向量在可视化窗格中由白色箭头指示。您可以从可视化窗格中选择一个特征，然后点击 **Use Selected Feature** 按钮以确认选择。所选特征的名称将出现在此选项下方的字段中。

### **FrameN** — 编辑或删除现有自定义坐标系名称

您创建的坐标系。使用 New Frame 参数指定端口的名称。如果未指定自定义坐标系的名称，模块会将坐标系命名为 **FN**，其中 `N` 是标识编号。

- 单击文本字段以编辑现有自定义坐标系的名称。

- 单击 Edit 按钮 Edit 以编辑自定义坐标系的其他方面，例如原点和坐标轴。
- 单击 Delete 按钮 Delete 以删除自定义坐标系。

#### 依赖关系

要启用此参数，请通过单击 **New Frame** 创建坐标系。

## 描述

用于变形的具有弹性属性的薄板

General Flexible Plate 模块对能够发生弹性变形的薄而平坦的结构进行建模，包括拉伸、弯曲和剪切效应。该模块应用剪切变形 Mindlin 板理论 [1][2][3]，并使用有限元法 [4] 对其进行求解。您可以使用此模块对薄而平坦的结构（例如连杆机构和卫星太阳能电池板）进行建模。

General Flexible Plate

要指定板的几何形状，请使用 **Midsurface** 和 **Thickness** 参数。板的中面位于 *xy* 平面内，厚度沿 *z* 轴方向。厚度必须远小于板的宽度和长度，并且板关于中面对称。有关更多详细信息，请参阅几何形状部分。

该模块对由均质、各向同性且线弹性材料制成的柔性板进行建模。您可以在 **Stiffness and Inertia** 部分指定板的密度、杨氏模量以及泊松比或剪切模量。此外，该模块支持两种阻尼方法，以控制建模的性能。要向板添加自定义坐标系，请在 **Frames** 部分指定参数。
