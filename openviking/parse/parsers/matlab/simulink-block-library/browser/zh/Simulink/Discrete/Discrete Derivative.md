# Discrete Derivative

计算离散时间导数

## 所属库

Simulink / Discrete

## 描述

Discrete Derivative 模块计算有选择性缩放的离散时间导数，如下所示：

y(tn)=K(u(tn)−u(tn−1)Ts)

其中

- u(tn) 和 y(tn) 分别是模块在当前时间步的输入和输出。
- u(tn−1) 是在上一个时间步的模块输入。
- K 是可选的缩放因子，使用**增益值**参数指定。
- Ts 是仿真的离散步长（必须是固定值）。

**注意**

请勿在具有非周期性触发器的子系统（例如，非周期函数调用子系统）中使用此模块。此配置会产生不准确的结果。
