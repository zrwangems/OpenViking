# String Compare

比较两个输入字符串

## 所属库

Simulink / String

## 描述

String Compare 比较两个字符串。要查看两个字符串是否相同，请使用此模块。您可以指定匹配是否区分大小写以及要比较其中多少字符。

## 端口

### 输入

### **Port\_1** — 要比较的第一个字符串 标量

要比较的第一个字符串，指定为标量。

**数据类型:** `string`

### **Port\_2** — 要比较的第二个字符串 标量

要比较的第二个字符串，指定为标量。

**数据类型:** `string`
### 输出

### **Port\_1** — true 或 false 结果 标量

true 或 false 结果，指定为标量：

- `1` - 匹配。
- `0` - 不匹配。

**数据类型:** `Boolean`

## 参数

### **区分大小写** — 在字符串比较时区分大小写 on (默认) | off

字符串比较区分大小写：

on
:   比较字符串时考虑字符串的大小写。

off
:   比较字符串时不考虑字符串的大小写。

#### 编程用法

|  |
| --- |
| **模块参数**：`CaseSensitive` |
| **类型：**字符向量 |
| **值：**`'on'` | `'off'` |
| **默认值：**`'on'` |

### **比较选项** — 要比较的字符量 **整个字符串** (默认) | **前 N 个字符**

要比较的字符量：

- **整个字符串** - 比较整个字符串。
- **前 N 个字符** - 比较两个字符串的前 *`N`* 个字符。

#### 依赖关系

将此参数设置为**前 N 个字符**会启用**字符数**参数。

#### 编程用法

|  |
| --- |
| **模块参数**：`CompareOption` |
| **类型：**字符向量 |
| **值**：`'Entire string'` | `'First N characters'` |
| **默认值：**`'Entire string'` |

### **字符数** — 要比较的字符数 `1` (默认) | 标量

要比较的字符数

#### 依赖关系

当**比较选项**参数设置为**前 N 个字符**时，此参数将启用。

#### 编程用法

|  |
| --- |
| **模块参数**：`CompareOption` |
| **类型：**字符向量 |
| **值：**标量 |
| **默认值：**`'1'` |
