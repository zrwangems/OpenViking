# Barrier Certificate Enforcement

## 端口

### 输入

### **u0** — 控制动作 标量 | 向量

未修改的控制动作，指定为标量或向量。

如果 **动作数量** 参数为 `1`，则将 **u0** 连接到标量信号。否则，将 **u0** 连接到长度等于 **动作数量** 的向量信号。

### **fx** — 状态函数 标量 | 向量

以下被控对象动态方程中的状态函数 *f*(*x*)。

x˙=f(x)+g(x)u

将 **fx** 连接到 *Nx*-by-1 信号，其中 *Nx* 等于 **状态数** 参数。

### **gx** — 输入函数 标量 | 向量 | 矩阵

以下被控对象动态方程中的输入函数 *g*(*x*)。

x˙=f(x)+g(x)u

将 **gx** 连接到 *Nx*-by-*Nu* 信号，其中 *Nx* 等于 **状态数** 参数，*Nu* 等于 **动作数量** 参数。

### **hx** — 控制障碍函数 标量 | 向量

控制障碍函数，定义为被控对象状态的以下安全集。

{x:h(x)≥0}

将 **hx** 连接到 *Nc*-by-1 信号，其中 *Nc* 等于 **障碍证书数量** 参数。

### **qx** — 控制障碍函数的偏导数 标量 | 向量 | 矩阵

控制障碍函数关于被控对象状态的偏导数。

q(x)=∂h∂x

将 **qx** 连接到 *Nc*-by-*Nx* 信号，其中 *Nc* 等于 **障碍证书数量** 参数，*Nx* 等于 **状态数** 参数。

### **umax** — 动作信号上界 标量 | 向量

要为动作信号指定运行时上界，请启用此输入端口。如果禁用此端口，则模块不会对控制动作应用任何上界。

如果 **动作数量** 参数为 `1`，则将 **umax** 连接到标量信号。否则，将 **umax** 连接到长度等于 **动作数量** 的向量信号。

#### 依赖关系

要启用此输入端口，请选择 **使用外部源作为上界** 参数。

### **umin** — 动作信号下界 标量 | 向量

要为动作信号指定运行时下界，请启用此输入端口。如果禁用此端口，则模块不会对控制动作应用任何下界。

如果 **动作数量** 参数为 `1`，则将 **umin** 连接到标量信号。否则，将 **umin** 连接到长度等于 **动作数量** 的向量信号。

#### 依赖关系

要启用此输入端口，请选择 **使用外部源作为下界** 参数。

### 输出

### **u\*** — 修改后的控制动作 标量 | 向量

由 QP 求解器返回的修改后的控制动作。

如果求解器在达到最大迭代次数之前找到解，则 **u\*** 输出此最优解。

如果求解器达到最大迭代次数，优化停止，并且 **u\*** 输出次优解。

如果初始优化问题不可行，则返回的控制动作取决于模块是否配置为忽略约束或动作边界。有关更多信息，请参阅 **exitflag** 参数。

如果 **动作数量** 参数为 `1`，则 **u\*** 输出标量信号。否则，**u\*** 输出长度等于 **动作数量** 的向量信号。

### **exitflag** — 优化状态 `1` | `0` | 负整数

QP 求解器的优化状态。下表显示了可能的状态值。

| 退出标志 | 描述 |
| --- | --- |
| `1` | 求解器收敛到最优解，所有约束和边界均处于活动状态。在这种情况下，**u\*** 输出最优控制动作。 |
| `0` | 求解器达到最大迭代次数。**u\*** 中输出的控制动作可能是次优的。 |
| 负整数 | 初始优化问题不可行，并且适用以下场景之一。  - 在不使用动作边界的情况下重新运行优化，未产生可行解。 - 在不使用约束边界的情况下重新运行优化，未产生可行解。  在这种情况下，**u\*** 中输出的控制动作为零。 |

#### 依赖关系

要启用此输出端口，请选择 **优化状态** 参数。

## 描述

修改控制动作，以满足障碍证书约束和动作边界

Barrier Certificate Enforcement 模块计算在满足障碍证书约束和动作边界的情况下，与指定控制动作最接近的修改后的控制动作。

该模块使用二次规划 (QP) 求解器来寻找使函数 |u−u0|2 最小化的控制动作 *u*。其中，*u*0 是未修改的控制动作。

求解器对优化问题应用以下约束。

qxfx+qxgxu+γhxβ≥0umin≤u≤umax

其中：

- *f*x** 和
  *g*x** 是由被控对象动态 x˙=f(x)+g(x)u 定义的函数。
- *h*x** 是控制障碍函数。
- *q*x** 是控制障碍函数关于状态 *x* 的偏导数。
- *γ* 是约束因子。
- *β* 是约束幂。
- *u*min 是控制动作的下界。
- *u*max 是控制动作的上界。

Barrier Certificate Enforcement 模块需要 Optimization Toolbox™ 软件。

有关障碍证书执行的更多信息，请参阅 Barrier Certificate Enforcement for Control Design。
