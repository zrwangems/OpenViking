# Combined Slip Wheel STI

## 端口

### 输入

### **Xe** — 惯性参考系中的车轮位置，`N`-by-`3` 向量

沿惯性固定的 *X*、*Y*、*Z* 轴的车轮位置，单位分别为 m。

向量为车轮数量 *N* 乘 `3`。

### **DCM** — 方向余弦矩阵，`3`-by-`3` 向量

从车轮坐标系到地球固定惯性坐标系的变换矩阵。

### **Ang** — 轮辋的旋转角，`3`-by-`3` 向量

轮辋相对于车轮中心的旋转角，单位为 rad。

### **Ve** — 惯性参考系中的车轮速度，`N`-by-`3` 向量

沿惯性固定的 *X*、*Y*、*Z* 轴的车轮速度，单位分别为 m/s。

向量为车轮数量 *N* 乘 `3`。

### **Omega** — 旋转速度，`N`-by-`3` 向量

沿惯性固定的 *X*、*Y*、*Z* 轴的车轮旋转速度，单位分别为 rad/s。

向量为车轮数量 *N* 乘 `3`。

### **OmegaWc** — 轮辋旋转速度，`scalar`

轮辋绕车轮自转轴的旋转速度，*ω*，单位为 rad/s。

### **Road** — 车轮位置、旋转矩阵、速度，`1`-by-`18` 向量

包含车轮相对于地球固定惯性坐标系的位置、旋转和速度的向量。

| 向量元素 | 描述 |
| --- | --- |
| `Road(1,1)`  `Road(1,2)`  `Road(1,3)` | 沿惯性固定的 *X*、*Y*、*Z* 轴的车轮位置，单位分别为 m。 |
| `Road(1,4)`  `Road(1,5)`  `Road(1,6)`  `Road(1,7)`  `Road(1,8)`  `Road(1,9)`  `Road(1,10)`  `Road(1,11)`  `Road(1,12)` | 从车轮坐标系到地球固定惯性坐标系的变换矩阵。 |
| `Road(1,13)`  `Road(1,14)`  `Road(1,15)` | 沿惯性固定的 *X*、*Y*、*Z* 轴的车轮速度，单位分别为 m/s。 |
| `Road(1,16)`  `Road(1,17)`  `Road(1,18)` | 沿惯性固定的 *X*、*Y*、*Z* 轴的车轮角速度，单位分别为 rad/s。 |

### **ScaleFctrs** — 比例因子，`27`-by-`N` 数组

Magic Formula 6.2 比例因子数组。数组维度为 `27` 乘车轮数量 *N*。

Magic Formula 6.2 方程使用比例因子来考虑静态或仿真运行时变化。名义上，大多数设置为 `1`。

| 数组元素 | 变量 | 比例因子 |
| --- | --- | --- |
| `ScaleFctrs(1,1)` | `lam_Fzo` | 名义载荷 |
| `ScaleFctrs(2,1)` | `lam_mux` | 纵向峰值摩擦系数 |
| `ScaleFctrs(3,1)` | `lam_muy` | 横向峰值摩擦系数 |
| `ScaleFctrs(4,1)` | `lam_muV` | 滑移速度 *Vs*，衰减摩擦 |
| `ScaleFctrs(5,1)` | `lam_Kxkappa` | 制动滑移刚度 |
| `ScaleFctrs(6,1)` | `lam_Kyalpha` | 侧偏刚度 |
| `ScaleFctrs(7,1)` | `lam_Cx` | 纵向形状因子 |
| `ScaleFctrs(8,1)` | `lam_Cy` | 横向形状因子 |
| `ScaleFctrs(9,1)` | `lam_Ex` | 纵向曲率因子 |
| `ScaleFctrs(10,1)` | `lam_Ey` | 横向曲率因子 |
| `ScaleFctrs(11,1)` | `lam_Hx` | 纵向水平偏移 |
| `ScaleFctrs(12,1)` | `lam_Hy` | 横向水平偏移 |
| `ScaleFctrs(13,1)` | `lam_Vx` | 纵向垂直偏移 |
| `ScaleFctrs(14,1)` | `lam_Vy` | 横向垂直偏移 |
| `ScaleFctrs(15,1)` | `lam_Kygamma` | 外倾力刚度 |
| `ScaleFctrs(16,1)` | `lam_Kzgamma` | 外倾力矩刚度 |
| `ScaleFctrs(17,1)` | `lam_t` | 气胎拖距（影响回正力矩刚度） |
| `ScaleFctrs(18,1)` | `lam_Mr` | 残余力矩 |
| `ScaleFctrs(19,1)` | `lam_xalpha` | Alpha 对 *Fx* 的影响（kappa） |
| `ScaleFctrs(20,1)` | `lam_ykappa` | Kappa 对 *Fy* 的影响（alpha） |

| `ScaleFctrs(27,1)` | `lam_Mphi` | 驻车力矩 *Mz* |

### **Prs** — 轮胎充气压力，`scalar` | `N`-by-`1` 向量

轮胎充气压力，*pi*，单位为 Pa。

向量为车轮数量 *N* 乘 `1`。如果提供 `scalar` 值，模块假定车轮数量为 1。

#### 依赖关系

要创建此端口，请选择 **输入轮胎压力**。

### **帘布层转向** — 包含帘布层转向 `on` (默认) | `off`

选择以在 Magic Formula 6.2 方程中包含帘布层转向。

默认情况下，模块在 Magic Formula 6.2 方程中包含帘布层转向和转弯滑移。这些方程拟合到平带试验数据，并预测多种轮胎效应，包括帘布层转向和转弯滑移。如果符合以下情况，请考虑移除这些效应：

- 测试数据不包含帘布层转向或转弯滑移数据。
- 分析不需要帘布层转向或转弯滑移效应。

如果清除 **帘布层转向**，模块会在内部将以下参数设置为 0：

- **倾覆力矩垂直偏移, QSX1**
- **组合滑移 Fx 偏移因子减小, RHX1**
- **Efy 曲率常数外倾依赖, PEY3**
- **FZNOM 处的 SHY 水平偏移, PHY1**
- **SHY 随载荷变化, PHY2**
- **FZNOM 处的 Svy/Fz 垂直偏移, PVY1**
- **Svy/Fz 随载荷变化, PVY2**
- **Fy 偏移随侧偏角减小, RBY3**
- **FZNOM 处的滑移率侧向力 Svyk/Muy\*Fz, RVY1**
- **侧向力 Svyk/Muy\*Fz 随载荷变化, RVY2**
- **Bpt 斜率随外倾变化, QBZ4**
- **Dpt 峰值拖距随外倾变化, QDZ3**
- **Dmr 峰值残余力矩, QDZ6**
- **Dmr 峰值残余力矩随载荷变化, QDZ7**
- **Ept 随 alpha-t 符号变化, QEZ4**
- **FZNOM 处的 Sht 水平拖距偏移, QHZ1**
- **Sht 随载荷变化, QHZ2**
- **s/R0 的名义值：Fx 对 Mz 的影响, SSZ1**

## 描述

符合 STI Tydex 标准的组合滑移车轮

Combined Slip Wheel STI 模块实现车轮的纵向和侧向行为，该行为由符合标准轮胎接口 (STI) Tyre Data Exchange Format (TYDEX)[3] 标准的 Magic Formula[1][2] 6.2 表征。您可以导入自己的轮胎模型，或使用内置轮胎模型。在需要低频轮胎-道路相互作用以确定车辆加速度和车轮滚动阻力的传动系和车辆仿真中使用该模块。该模块适用于需要组合侧向滑移的应用，例如侧向运动和横摆稳定性研究。

基于车轮旋转速度、纵向和侧向速度、车轮外倾角以及充气压力，该模块确定所有六个自由度 (DOF) 的垂向运动、力和力矩。使用垂向 DOF 研究由道路剖面或底盘运动引起的轮胎-悬架共振。

如果您安装了 Extended Tire Features for Vehicle Dynamics Blockset 支持包，则可以使用以下附加功能：

- 绘图生成 — 点击 **Plot steady state force, moment response** 按钮生成以下图：

  - **侧向力 [N] 与滑移角 [rad]**
  - **回正力矩 [Nm] 与滑移角 [rad]**
  - **纵向力 [N] 与纵向滑移 []**
  - **纵向力 [N] 与侧向力 [N]**
- 导入轮胎参数 — 使用 `tireModel.get` 方法将 Combined Slip Wheel STI 模块中定义的轮胎参数值导入到 `tireModel` 对象。
- 导出轮胎参数 — 使用 `set` 方法将轮胎参数值从 `tireModel` 对象导出到 Combined Slip Wheel STI 模块。
- 轮胎模型转换 — 使用 `convert` 方法将以下类型之一的轮胎模型转换为可导入到 Combined Slip Wheel STI 模块的 Magic Formula 6.2 轮胎模型：

  - Magic Formula 5.2
  - Fiala
  - Dugoff

使用 **Tire type** 参数选择轮胎数据的来源。

| 目标 | 操作 |

### 车轮旋转动力学

该模块计算车轮在以下因素作用下的惯性响应：

- 车轴损耗
- 轮胎滚动阻力
- 通过轮胎-道路界面的地面接触

为实现 Magic Formula 6.2，该模块使用引用文献中的以下公式：

| 计算 | 公式 |
| --- | --- |
| 纵向力 | *Tire and Vehicle Dynamics*2 公式 4.E9 至 4.E57 |
| 侧向力 - 纯侧滑 | *Tire and Vehicle Dynamics*2 公式 4.E19 至 4.E30 |
| 侧向力 - 组合滑移 | *Tire and Vehicle Dynamics*2 公式 4.E58 至 4.E67 |
| 垂向动力学 | *Tire and Vehicle Dynamics*2 公式 4.E68、4.E1、4.E2a 和 4.E2b |
| 翻转力矩 | *Tire and Vehicle Dynamics*2 公式 4.E69 |
| 滚动阻力 | - *An improved Magic Formula/Swift tyre model that can handle inflation pressure changes*1 公式 6.1.2<br>- *Tire and Vehicle Dynamics*2 公式 4.E70 |
| 回正力矩 | *Tire and Vehicle Dynamics*2 公式 4.E31 至 4.E49 |
| 回正力矩 - 组合滑移 | *Tire and Vehicle Dynamics*2 公式 4.E71 至 4.E78<br>如果您清除 **Include turn slip**，该模块会将这些公式中的一些设置为 1。 |
