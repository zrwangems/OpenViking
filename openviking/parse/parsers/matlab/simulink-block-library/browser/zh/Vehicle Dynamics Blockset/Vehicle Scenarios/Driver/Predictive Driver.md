### **RefPose** — 参考位姿 [*Xref*, *Yref*, *φref*] vector

参考位姿，指定为
[*Xref*,
*Yref*,
*φref*] 向量。
*Xref* 和
*Yref* 的单位为 meters，
*φref* 的单位为 **角度单位, angUnits** 指定的单位。

*Xref* 和
*Yref* 指定要使车辆转向朝向的参考点。

*φref* 指定该参考点处路径的方位角，在顺时针方向上为正。

参考点是路径上最靠近车辆 CG 的点。可以使用 Z-up 或 Z-down 车辆坐标系，只要对模块输入和参数使用相同的坐标系（Z-up 或 Z-down）。

表示车辆路径上 x、y 和 psi 位置的图

#### 控制与换挡

### **纵向控制类型, cntrlType** — 纵向控制 `PI`（默认） | `Scheduled PI` | `Predictive`

纵向控制类型。

| 设置 | 模块实现 |
| --- | --- |
| `PI` | 带跟踪抗积分饱和和前馈增益的比例积分 (PI) 控制。 |
| `Scheduled PI` | 带跟踪抗积分饱和和前馈增益的 PI 控制，这些增益是车辆速度的函数。 |
| `Predictive` | 由 C. C. MacAdam1, 2, 3 开发的最优单点预瞄（前视）控制模型。该模型表示驾驶员在路径跟随和避障机动期间的转向控制行为。驾驶员进行预瞄（前视）以跟随预定义路径。为实现 MacAdam 模型，模块：  - 将动力学表示为线性单轨（自行车）车辆 - 最小化时间前方单点 *T\** 秒处的预瞄误差信号 - 考虑由感知和神经肌肉机制引起的驾驶员滞后 |

### **横向控制类型，controlTypeLat** — 控制器 `Predictive`（默认）| `Stanley`

使用 **横向控制类型，controlTypeLat** 参数指定横向控制类型。下表指定模块实现。

| 设置 | 模块实现 |
| --- | --- |
| `Predictive`（默认） | 由 C. C. MacAdam1, 2, 3 开发的最优单点预瞄（前视）控制模型。该模型表示驾驶员在路径跟随和障碍物避让操作中的转向控制行为。驾驶员通过预瞄（前视）来跟随预定义路径。 |
| `Stanley` | 控制器使用 Stanley4 方法最小化当前位置相对于参考位姿的位置误差和角度误差。 在**参考控制**窗格上，使用： - **位姿向量输入**参数来指定输入。  | 设置 | 实现 |   | --- | --- |   | `off`（默认） | 模块使用纵向、横向和横摆参考（`LongRef`、`LatRef`、`LatRef`）输入端口以及反馈（`LongFdbk`、`LatFdbk`、`LatFdbk`）输入端口作为参考位姿和反馈位姿。 |   | `on` | 模块分别使用输入端口 `RefPose` 和 `CurrPose` 作为参考位姿和反馈位姿。 | - **包含动力学**参数指定控制器要使用的模型类型。  | 设置 | 实现 |   | --- | --- |   | `off`（默认） | 控制器使用运动学自行车模型，适用于低速环境（如停车场）中的路径跟随，此时惯性效应最小。 |   | `on` | 控制器使用动力学自行车模型，适用于高速环境（如高速公路）中的路径跟随，此时惯性效应更明显。 | |

### **换挡类型，shftType** — 换挡类型 `None`（默认）| `Reverse, Neutral, Drive` | `Scheduled` | `External`

换挡类型。

| 设置 | 模块实现 |
| --- | --- |
| `None` | 无变速器。模块输出恒定挡位 1。使用此设置可最小化生成加速和制动命令以跟踪前方车辆运动所需的参数数量。此设置不允许车辆倒车。 |
| `Reverse, Neutral, Drive` | 模块使用 Stateflow 图对倒车、空挡和驱动挡换挡调度建模。使用此设置，通过简单的倒车、空挡和驱动挡换挡调度生成加速和制动命令，以跟踪前进和倒车车辆运动。根据车辆状态和车速反馈，模块使用初始挡位和换挡所需时间将车辆升挡至驱动挡或降挡至倒车挡或空挡。对于空挡，模块使用制动命令控制车速。对于倒车挡，模块使用加速命令生成扭矩，并使用制动命令降低车速。 |
| `Scheduled` | 模块使用 Stateflow 图对倒车、空挡、驻车和 N 速挡换挡调度建模。使用此设置，通过倒车、空挡、驻车和 N 速挡换挡调度生成加速和制动命令，以跟踪前进和倒车车辆运动。根据车辆状态和车速反馈，模块使用这些参数确定： - 初始挡位 - 升挡和降挡加速踏板位置 - 升挡和降挡车速 - 从空挡换入并接合前进挡和倒车挡的时机    对于空挡，模块使用制动命令控制车速。对于倒车挡，模块使用加速命令生成扭矩，并使用制动命令降低车速。 |

## 描述

用于跟踪纵向速度和横向路径的预测驾驶员控制器

Predictive Driver 模块实现一个控制器，该控制器生成归一化转向、加速和制动命令，以跟踪纵向速度和横向参考位移。归一化命令可以在 -1 到 1 之间变化。该控制器使用单轨（自行车）模型进行最优单点预瞄控制。

### 配置

**外部操作**

使用 **外部操作** 参数创建输入端口，用于模拟标准测试工况的信号。模块对输入命令使用以下优先级顺序：禁用（最高）、保持、覆盖。

下表汇总了外部操作参数。

| 目标 | 外部操作参数 | 输入端口 | 数据类型 |

| 用输入加速命令覆盖加速器命令。 | **加速器覆盖** | `EnablAccelOvr` | `Boolean` |
| `AccelOvrCmd` | `double` |
| 将加速命令保持在当前值。 | **加速器保持** | `AccelHld` | `Boolean` |
| 禁用加速命令。 | **加速器禁用** | `AccelZero` | `Boolean` |

### Controller: Stanley Lateral Path-Tracking

如果你将 **Lateral control type, controlTypeLat** 设置为 `Stanley`，则该模块实现 Stanley 方法4。为计算转向角指令，Stanley 控制器最小化当前位姿相对于参考位姿的位置误差和角度误差。车辆行驶方向决定这些误差值。

为计算转向角指令，控制器最小化当前位姿相对于参考位姿的位置误差和角度误差。

- *位置误差* 是从车辆重心（CG）到路径上参考点的横向距离。
- *角度误差* 是车辆相对于参考路径的角度。
