# BME280

## 端口

### 输出

### **Pressure** — 由 BME280 传感器测得的大气气压，标量

由连接到 NVIDIA 嵌入式板的 BME280 传感器测量的大气气压（单位为帕斯卡 (Pa)）。

#### 依赖项

仅当选择 **压力 (Pa)** 参数时，此输出端口才会出现。

**数据类型：** `double`

### **Temperature** — 由 BME280 传感器测得的温度，标量

由连接到 NVIDIA 嵌入式板的 BME280 传感器测量的温度（单位为 ℃）。

#### 依赖项

仅当选择 **温度 (℃)** 参数时，此输出端口才会出现。

**数据类型：** `double`

### **Humidity** — 由 BME280 传感器测得的相对湿度，标量

由连接到 NVIDIA 嵌入式板的 BME280 传感器测量的相对湿度（单位为 %）。

#### 依赖项

仅当选择 **湿度 (%)** 参数时，此输出端口才会出现。

**数据类型：** `double`

### **Status** — 读取值的状态 `0` | `1`

从 BME280 传感器读取的值的状态，用于指示读取的数据是否为新值。**Status** 值 `0` 表示读取的数据为新值，`1` 表示读取的数据不是新值。

#### 依赖项

仅当选择 **状态** 参数时，此输出端口才会出现。

**数据类型：** `uint8`

## 参数

### **I2C 模块** — 用于通信的模块 `empty`（默认）

用于与 BME280 传感器通信的 I2C 模块。不同 NVIDIA 嵌入式板支持的 I2C 模块数量不同。

#### 编程用法

|  |
| --- |
| **模块参数：** `I2CModule` |
| **类型：** character vector |
| **值：** `''`|`positive integer` |
| **默认值：**  `''` |

### **I2C 地址** — BME280 传感器的 I2C 地址 `0x77`（默认） | `0x76`

BME280 传感器与 NVIDIA 嵌入式板通信所使用的 I2C 地址。默认参数值（`0x77`）对应于 BOOSTXL-SENSORS BoosterPack™ Plug-in Module 使用的 I2C 地址。

#### 编程用法

|  |
| --- |
| **模块参数：** `I2CAddress` |
| **类型：** character vector |
| **值：** `'0x76'`|`'0x77'` |
| **默认值：**  `'0x76'` |

#### 高级设置

### **滤波器系数** — IIR 滤波器的滤波器系数 `0`（默认） | `2` | `4` | `8` | `16`

指定从 BME280 传感器读取压力和温度值时 IIR 滤波器的滤波器系数。为滤波器系数选择非零值有助于改善阶跃响应并消除测量值中的短期波动。

#### 编程用法

|  |
| --- |
| **模块参数**： `FilterMode` |
| **类型**： character vector |
| **值**： `'0'` | `'2'`| `'4'`| `'8'`| `'16'` |
| **默认值**： `'0'` |

### **待机时间** — 读取值的待机时间 `0.5 ms`（默认） | `10 ms` | `20 ms` | `62.5 ms` | `125 ms` | `250 ms` | `500 ms` | `1000 ms`

指定从 BME280 传感器读取值时处理器保持空闲（非活动持续时间）的待机时间（单位：ms）。此值的选择会影响总周期时间。

#### 编程用法

|  |
| --- |
| **模块参数**： `StandbyTime` |
| **类型**： character vector |
| **值**： `'0.5 ms'` | `'10 ms'`| `'20 ms'`| `'62.5 ms'`| `'125 ms'`| `'250 ms'`| `'500 ms'`|`'1000 ms'` |
| **默认值**： `'0.5 ms'` |

指定过采样因子以减少从 BME280 传感器读取的湿度值的噪声。此值是一个乘数因子，会影响测量速率和电流消耗。

指定过采样因子以减少从 BME280 传感器读取的温度值的噪声。此值是一个乘数因子，会影响测量速率和电流消耗。

## 描述

从 BME280 传感器测量大气气压、相对湿度和温度

BME280 模块输出由连接到 NVIDIA® 嵌入式板的 BME280 传感器测得的大气气压和相对湿度值。该模块还输出由 BME280 传感器读取的温度。
