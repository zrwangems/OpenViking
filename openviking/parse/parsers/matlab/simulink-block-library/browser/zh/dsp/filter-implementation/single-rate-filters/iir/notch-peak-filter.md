# Notch-Peak Filter

## 端口

### 输入

### **Input** — 输入信号向量 | 矩阵

将输入信号指定为向量或矩阵。输入信号的每一列视为一个单独通道。如果输入是二维信号，则第一个维度表示通道长度（或帧大小），第二个维度表示通道数。如果输入是一维信号，则将其解释为单通道。

此模块支持可变大小输入，使您能够在仿真期间更改通道长度。要启用可变大小输入，请清除 **从输入继承采样率** 复选框。通道数必须保持恒定。

**数据类型：** `single` | `double`
**复数支持：** Yes
### 输出

### **notch** — 陷波滤波器输出向量 | 矩阵

陷波滤波器输出，以向量或矩阵形式返回。

**数据类型：** `single` | `double`
**复数支持：** Yes

### **peak** — 峰值滤波器输出向量 | 矩阵

峰值滤波器输出，以向量或矩阵形式返回。

**数据类型：** `single` | `double`
**复数支持：** Yes

## 参数

### **滤波器规格** — 滤波器设计规格 `Bandwidth and center frequency`（默认）| `Coefficients` | `Quality factor and center frequency`

指定模块用于设计滤波器的参数或系数：

- `Bandwidth and center frequency`
  （默认）—— 使用 **3 dB 带宽** 和 **陷波或峰值中心频率** 设计滤波器。
- `Coefficients` —— 使用 **带宽系数** 和
  **中心频率系数** 设计滤波器。
- `Quality factor and center frequency`
  —— 使用 **品质因数** 和 **陷波或峰值中心频率** 设计滤波器。

### **从输入端口指定带宽** — 从输入端口指定 3 dB 带宽的选项 `off`（默认）| `on`

选中此复选框时，3 dB 带宽通过 **BW** 端口输入。清除此复选框时，3 dB 带宽通过 **3 dB 带宽** 参数在模块对话框中指定。

#### 依赖关系

要启用此参数，请将 **滤波器规格** 设置为 `Bandwidth and center frequency`。

### **3 dB 带宽** — 3 dB 带宽 `2205`（默认）| 正标量

将滤波器的 3 dB 带宽指定为正标量，单位为 Hz 或归一化频率单位 *（自 R2024a 起）*。

如果将 **采样率模式** 参数设置为：

- `Specify on dialog` 或
  `Inherit from input port` —— 3 dB 带宽的值以 Hz 为单位，且必须小于输入信号采样率的一半。
- `Use normalized frequency (0 to 1)`
  —— 3 dB 带宽的值以归一化频率单位表示。该值必须是小于 `1.0` 的正标量。

*（自 R2024a 起）*

**可调：** Yes

#### 依赖关系

要启用此参数，请将 **滤波器规格** 设置为 `Bandwidth and center frequency`，并清除 **从输入端口指定带宽** 参数。

### **从输入端口指定中心频率** — 从输入端口指定中心频率的选项 `off`（默认）| `on`

选中此复选框时，中心频率通过 **Fc** 端口输入。清除此复选框时，中心频率通过 **陷波或峰值中心频率** 参数在模块对话框中指定。

#### 依赖关系

要启用此参数，请将 **滤波器规格** 设置为 `Bandwidth and center frequency` 或 `Quality factor and center frequency`。

### **陷波或峰值中心频率** — 陷波或峰值中心频率 `11025`（默认）| 正标量

将滤波器的陷波和峰值中心频率指定为正数值标量，单位为 Hz 或归一化频率单位 *（自 R2024a 起）*。

如果将 **采样率模式** 参数设置为：

- `Specify on dialog` 或
  `Inherit from input port` —— 中心频率的值以 Hz 为单位，且必须小于输入信号采样率的一半。
- `Use normalized frequency (0 to 1)`
  —— 中心频率的值以归一化频率单位表示。该值必须是小于 `1.0` 的正标量。

*（自 R2024a 起）*

**可调：** Yes

#### 依赖关系

要启用此参数，请将 **滤波器规格** 设置为 `Bandwidth and center frequency` 或 `Quality factor and center frequency`，并清除 **从输入端口指定中心频率** 参数。

### **从输入端口指定带宽系数** — 从输入端口指定带宽系数的选项 `off`（默认）| `on`

选中此复选框时，带宽系数通过端口 **BWCoeff** 输入。清除此复选框时，带宽系数通过 **带宽系数** 参数在模块对话框中指定。

#### 依赖关系

要启用此参数，请将 **滤波器规格** 设置为
`Coefficients`。

### **带宽系数** — 带宽系数 `0.72654`（默认）| 范围 [−`1` `1`] 内的实标量

将决定滤波器 3 dB 带宽的系数指定为范围 [−`1`
`1`] 内的有限数值标量。

- `-1` 对应最大 3 dB 带宽（输入信号采样率的四分之一）。
- `1` 对应最小带宽（0 Hz，即全通滤波器）。

**可调：** Yes

#### 依赖关系

要启用此参数，请将 **滤波器规格** 设置为 `Coefficients`，
并清除 **从输入端口指定带宽系数** 参数。

### **从输入端口指定中心频率系数** — 从输入端口指定中心频率系数的选项 `off`（默认）| `on`

选中此复选框时，中心频率系数通过 **FcCoeff** 端口输入。清除此复选框时，中心频率系数通过 **中心频率系数** 参数在模块对话框中指定。

#### 依赖关系

要启用此参数，请将 **滤波器规格** 设置为
`Coefficients`。

### **中心频率系数** — 中心频率系数 `0`（默认）| 范围 [−`1` `1`] 内的实标量

将决定滤波器中心频率的系数指定为范围 [−`1`
`1`] 内的有限数值标量。

- `-1` 对应最小中心频率（`0` Hz）。
- `1` 对应最大中心频率（输入信号采样率的一半）。

默认值 `0` 对应输入信号采样率的四分之一。

**可调：** Yes

#### 依赖关系

要启用此参数，请将 **滤波器规格** 设置为 `Coefficients`，
并清除 **从输入端口指定中心频率系数** 参数。

### **从输入端口指定品质因数** — 从输入端口指定品质因数的选项 `off`（默认）| `on`

选中此复选框时，品质因数通过 **Q** 端口输入。清除此复选框时，品质因数通过 **品质因数** 参数在模块对话框中指定。

#### 依赖关系

要启用此参数，请将 **滤波器规格** 设置为 `Quality factor and center frequency`。

### **品质因数** — 陷波或峰值滤波器的品质因数 `5`（默认）| 正标量

将陷波和峰值滤波器的品质因数指定为实正标量。品质因数定义为 **陷波或峰值中心频率** / **3 dB 带宽**。品质因数越高，对应峰值或下陷越窄。

**可调：** Yes

#### 依赖关系

要启用此参数，请将 **滤波器规格** 设置为 `Quality factor and center frequency`，并清除 **从输入端口指定品质因数** 参数。

### **滤波器输出** — 要输出的滤波器响应 `Notch and Peak`（默认）| `Notch` | `Peak`

将要输出的响应指定为以下之一：

- `Notch and Peak` —— 模块输出滤波器的陷波和峰值响应。
- `Notch` —— 模块输出滤波器的陷波响应。
- `Peak` —— 模块输出滤波器的峰值响应。

### **采样率模式** — 指定输入采样率的模式 `Use normalized frequency (0 to 1)`（默认）| `Specify on dialog` | `Inherit from input port`

*自 R2024a 起*

使用以下选项之一指定输入采样率：

- `Use normalized frequency (0 to 1)`
  —— 以归一化频率单位 (0 到 1) 指定通带边缘和阻带边缘频率。
- `Specify on dialog` —— 使用 **输入采样率 (Hz)** 参数在模块对话框中指定输入采样率。
- `Inherit from input port` —— 模块从输入信号继承采样率。模块将采样率计算为
  *N*/*Ts*，其中
  *N* 是输入信号的帧大小，
  *Ts* 是输入信号的采样时间。

### **输入采样率 (Hz)** — 输入采样率 `44100`（默认）| 正标量

将输入信号的采样率指定为正标量值。

#### 依赖关系

要启用此参数，请设置：

- **滤波器规格** 为除 `Coefficients` 外的任何可接受值。
- **采样率模式** 为 `Specify on dialog`。*（自 R2024a 起）*

### **查看滤波器响应** — 查看滤波器响应按钮（默认）

单击此按钮会打开滤波器可视化工具，并显示陷波-峰值滤波器的幅值响应。该响应基于您在模块对话框中选择的参数。要在可视化工具运行时更新响应，请修改对话框中的参数，然后单击 **Apply**。

您可以从可视化工具界面配置绘图设置和频率响应测量。

在 **Scope** 选项卡上，您可以启用图例、指定同时绘制滤波器的幅值和相位响应、修改绘图设置、生成用于重新创建绘图的脚本，甚至保存或共享设置。在 **Measurements** 选项卡上，您可以启用数据游标，并显示滤波器响应的峰值。

有关滤波器可视化工具界面及其工具的更多详细信息，请参阅 Configure Filter Visualizer。

#### 依赖关系

要启用此按钮，请勿从输入端口指定任何滤波器规格。

### **仿真方式** — 要运行的仿真类型 `Interpreted execution`（默认）| `Code generation`

指定要运行的仿真类型。您可以将此参数设置为：

- `Interpreted execution` —— 使用 MATLAB® 解释器仿真模型。此选项可缩短启动时间。
- `Code generation` —— 使用生成的 C 代码仿真模型。首次运行仿真时，Simulink® 会为该模块生成 C 代码。只要模型不变，后续仿真会重用该 C 代码。此选项需要额外的启动时间，但可提供更快的后续仿真。

## 版本历史

**在 R2015a 中引入**

### R2024a：**仿真方式** 参数的默认值变更

**仿真方式** 参数的默认值现在为 `Interpreted execution`。通过此更改，模块默认使用 MATLAB 解释器进行仿真。

当您将 **采样率模式** 参数设置为 `Use normalized frequency (0 to 1)` 时，可以以归一化频率单位 (0 到 1) 指定 3 dB 带宽和中心频率。

## 描述

设计二阶可调陷波和峰值 IIR 滤波器

Notch-Peak Filter 模块使用指定的中心频率和 3 dB 带宽对输入信号的每个通道随时间进行滤波。此模块提供可调滤波器设计参数，使您能够在仿真运行时调整滤波器特性。该模块根据模块对话框中设置的滤波器参数设计滤波器。输出端口属性（如数据类型、复/实性和维度）与输入端口属性相同。
