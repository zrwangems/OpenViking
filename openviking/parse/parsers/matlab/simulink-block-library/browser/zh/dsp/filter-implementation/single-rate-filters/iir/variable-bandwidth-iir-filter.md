# Variable Bandwidth IIR Filter

## 端口

### 输入

### **x** — 数据输入 向量 | 矩阵

将数据输入指定为向量或矩阵。该模块将输入信号的每一列视为一个单独通道。如果输入是二维信号，第一维表示通道长度（或帧大小），第二维表示通道数。如果输入是一维信号，则该模块将其解释为具有单通道。

该模块接受可变大小输入信号，也就是说，您可以在仿真期间更改每个输入通道的大小，但不能更改通道数。

在选择以下参数之一之前，此端口未命名：

- **从输入端口指定通带频率**
- **从输入端口指定中心频率**
- **从输入端口指定带宽**

**数据类型：** `single` | `double`
**复数支持：** 是

### **Fp** — 滤波器通带频率 正标量

将 IIR 滤波器的通带频率指定为以 Hz 或以归一化频率单位表示的实正标量 *（自 R2023a 起）*。

#### 依赖关系

要启用此端口，请选择 **从输入端口指定通带频率** 参数。

**数据类型：** `single` | `double`

### **Fc** — 滤波器中心频率 正标量

将 IIR 滤波器的中心频率指定为以 Hz 或以归一化频率单位表示的实正标量 *（自 R2023a 起）*。

#### 依赖关系

要启用此端口，请选择 **从输入端口指定中心频率** 参数。

**数据类型：** `single` | `double`

### **BW** — 滤波器带宽 正标量

将 IIR 滤波器的带宽指定为以 Hz 或以归一化频率单位表示的实正标量 *（自 R2023a 起）*。

#### 依赖关系

要启用此端口，请选择 **从输入端口指定带宽** 参数。

**数据类型：** `single` | `double`
### 输出

### **Port\_1** — 滤波后输出 向量 | 矩阵

滤波后输出，以向量或矩阵形式返回。输出信号的大小、数据类型和复数性与输入信号匹配。

**数据类型：** `single` | `double`
**复数支持：** 是

## 参数

### **滤波器类型** — 滤波器类型 `Lowpass`（默认） | `Highpass` | `Bandpass` | `Bandstop`

指定 IIR 滤波器的类型。您可以将此参数设置为：

- `Lowpass`
- `Highpass`
- `Bandpass`
- `Bandstop`

### **IIR 滤波器阶数** — IIR 滤波器阶数 8（默认） | 正整数

将 IIR 滤波器的阶数指定为正整数。

### **从输入端口指定通带频率** — 从输入端口指定通带频率 `off`（默认） | `on`

选中此复选框时，请通过 **Fp** 端口指定滤波器通带频率。清除此复选框时，请在模块对话框中通过 **滤波器通带频率** 参数指定通带频率。

#### 依赖关系

要启用此参数，请将 **滤波器类型** 设置为 `Lowpass` 或 `Highpass`。

### **滤波器通带频率** — 滤波器通带频率 512（默认） | 正标量

将滤波器通带频率指定为以 Hz 或以归一化频率单位表示的实正标量 *（自 R2023a 起）*。

如果您将 **采样率模式** 参数设置为：

- `Specify on dialog` 或 `Inherit from input port` –– 滤波器通带频率的值以 Hz 为单位，并且必须小于输入采样率值的一半。
- `Use normalized frequency (0 to 1)` –– 滤波器通带频率的值以归一化频率单位表示。该值必须是小于 `1.0` 的正标量。

*（自 R2023a 起）*

**可调：** 是

#### 依赖关系

要启用此参数：

- 将 **滤波器类型** 设置为 `Lowpass` 或 `Highpass`。
- 清除 **从输入端口指定通带频率** 参数。

### **从输入端口指定中心频率** — 从输入端口指定中心频率 `off`（默认） | `on`

选中此复选框时，请通过 **Fc** 端口指定 IIR 滤波器的中心频率。清除此复选框时，请在模块对话框中通过 **滤波器中心频率** 参数指定中心频率。

#### 依赖关系

要启用此参数，请将 **滤波器类型** 设置为 `Bandpass` 或 `Bandstop`。

### **滤波器中心频率** — 滤波器中心频率 44100/4（默认） | 正标量

将滤波器中心频率指定为以 Hz 或以归一化频率单位表示的实正标量 *（自 R2023a 起）*。

如果您将 **采样率模式** 参数设置为：

*（自 R2023a 起）*

**可调：** 是

#### 依赖关系

要启用此参数：

- 将 **滤波器类型** 设置为 `Bandpass` 或 `Bandstop`。
- 清除 **从输入端口指定中心频率** 参数。

### **从输入端口指定带宽** — 从输入端口指定带宽 `off`（默认） | `on`

选中此复选框时，请通过 **BW** 端口指定 IIR 滤波器的带宽。清除此复选框时，请在模块对话框中通过 **滤波器带宽** 参数指定滤波器带宽。

将滤波器带宽指定为以 Hz 或以归一化频率单位表示的正标量 *（自 R2023a 起）*。

如果您将 **采样率模式** 参数设置为：

### **滤波器通带波纹 (dB)** — 滤波器通带波纹 1（默认） | 正标量

将滤波器通带波纹指定为实正标量。

### **滤波器阻带衰减 (dB)** — 滤波器阻带衰减 60（默认） | 正标量

将滤波器阻带衰减指定为实正标量。

### **采样率模式** — 用于指定输入采样率的模式 `Use normalized frequency (0 to 1)`（默认） | `Specify on dialog` | `Inherit from input port`

*自 R2023a 起*

使用以下选项之一指定输入采样率：

- `Use normalized frequency (0 to 1)` –– 以归一化频率单位 (0 到 1) 指定滤波器通带频率、中心频率和滤波器带宽。
- `Specify on dialog` –– 在模块对话框中通过 **输入采样率 (Hz)** 参数指定输入采样率。
- `Inherit from input port` –– 该模块从输入信号继承采样率，表示为 *N* / *Ts*，其中 *N* 是输入信号的帧大小，*Ts* 是输入信号的采样时间。

### **输入采样率 (Hz)** — 输入采样率 44100（默认） | 正标量

将输入信号的采样率指定为以 Hz 为单位的正标量。

#### 依赖关系

要启用此参数，请将 **采样率模式** 参数设置为 `Specify on dialog`。*（自 R2023a 起）*

### **查看滤波器响应** — 查看滤波器响应按钮

点击此按钮会打开滤波器可视化工具，并显示可变带宽 IIR 滤波器的幅值响应。该响应基于您在模块参数对话框中选择的参数。要在滤波器可视化工具运行时更新幅值响应，请修改对话框中的参数，然后单击 **应用**。

您可以从可视化工具界面配置绘图设置和信号测量。

在 **Scope** 选项卡上，**Configuration** 部分允许您修改绘图设置。在 **Measurements** 选项卡上，您可以测量信号统计量、放置数据光标，并显示所选信号的峰值。

有关滤波器可视化工具界面及其工具的更多详细信息，请参阅配置滤波器可视化工具。

#### 依赖关系

要启用此按钮，请勿从输入端口指定任何滤波器规格。

### **仿真使用** — 要运行的仿真类型 `Interpreted execution`（默认） | `Code generation`

指定要运行的仿真类型。您可以将此参数设置为：

- `Interpreted execution` –– 使用 MATLAB® 解释器仿真模型。此选项可缩短启动时间。
- `Code generation` –– 使用生成的 C 代码仿真模型。首次运行仿真时，Simulink® 会为该模块生成 C 代码。只要模型不变，后续仿真会重用该 C 代码。此选项需要额外的启动时间，但可提供更快的后续仿真。

## 描述

设计可调带宽 IIR 滤波器

Variable Bandwidth IIR Filter 模块使用 IIR 滤波器规格对输入信号的每个通道随时间进行滤波。该模块提供可调滤波器设计参数，使您能够在仿真运行时调整滤波器特性。

该模块根据模块对话框中设置的滤波器参数设计 IIR 滤波器。输出端口属性（如数据类型、复数性和维度）与输入端口属性相同。
