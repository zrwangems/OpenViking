### **对整数溢出进行饱和** — 溢出操作的方法 `off`（默认） | `on`

指定整数溢出是饱和还是回绕。

- `on` — 溢出饱和到数据类型可以表示的最小值或最大值。
- `off` — 溢出回绕到数据类型可以表示的相应值。

例如，有符号 8 位整数 `int8` 可以表示的最大值为 127。任何大于该最大值的模块运算结果都会导致 8 位整数溢出。

- 选择此参数时，模块输出在 127 处饱和。类似地，模块输出在最小输出值 –128 处饱和。
- 清除此参数时，软件将导致溢出的值解释为 `int8`，这可能会产生意外结果。例如，模块结果 130（二进制 1000 0010）表示为 `int8` 时是 –126。

#### 提示

- 当您的模型可能发生溢出，并且您希望在生成的代码中显式提供饱和保护时，请将此参数设置为 `on`。
- 要优化生成代码的效率，请保留此参数的默认 `off` 设置。使用默认设置还有助于避免过度指定模块如何处理越界信号。有关详细信息，请参阅 Troubleshoot Signal Range Errors (Simulink)。
- 选择此参数时，饱和会应用于模块上的每个内部运算，而不仅仅是输出或结果。
- 通常，代码生成过程可以检测到不可能发生溢出的情况。在这种情况下，代码生成器不会生成饱和代码。

## 描述

三维全局最大池化层

Global Max Pooling 3D Layer 模块通过计算输入的高度、宽度和深度维度上的最大值来执行下采样。此模块接受 `SSSC` 格式的 3-D 图像数据（四个维度，依次对应三个空间维度和一个通道维度），并在空间维度上进行池化。

`exportNetworkToSimulink` 函数生成此模块以表示 `globalMaxPooling3dLayer` 对象。
