## 描述

具有太阳轮、齿圈和行星架的理想行星齿轮

Planetary Gear 模块实现由刚性耦合的太阳轮、齿圈和行星架齿轮组成的理想行星齿轮耦合。该模块计算对太阳轮、行星架和齿圈输入转矩的动态响应。

在燃油经济性和动力总成研究中，可以将 Planetary Gear 模块作为功率分流装置，将其与常见传动系统元件（如变速器、发动机、离合器和差速器）耦合。

这些运动方程表示行星齿轮的动态响应。

ω˙sJs=ω˙sbs+Ts+Tpsω˙cJc=ω˙cbc+Tc+Tpcω˙sJr=ω˙rbr+Tr+Tprω˙pJp=ωpbp+Trp+Tsp+Tcp

为简化运动方程，该模块使用这些运动学和几何约束。

ωcrc=rsωs+rpωpωrrr=rcωc+rpωprc=rs+rprr=rc+rp

### 功率核算

对于功率核算，该模块实现以下方程。

| 总线信号 | | | 描述 | 方程 |
| --- | --- | --- | --- | --- |
| `PwrInfo` | `PwrTrnsfrd` — 模块之间传输的功率  - 正信号表示流入模块 - 负信号表示流出模块 | `PwrSun` | 太阳轮施加功率 | ωsTs |
| `PwrCarr` | 行星架施加功率 | W |
| `PwrRing` | 齿圈施加功率 | W |
| `PwrNotTrnsfrd` — 穿过模块边界但未传输的功率  - 正信号表示输入 - 负信号表示损失 | `PwrDampLoss` | 机械阻尼损失 | −(bsωs2+bcωc2+brωr2+bpωp2) |
| `PwrStored` — 存储能量变化率  - 正信号表示增加 - 负信号表示减少 | `PwrStoredPlntry` | 旋转动能变化率 | ω˙sωsJs+ ω˙cωcJc+ ω˙rωrJr+ ω˙pωpJp |

这些方程使用以下变量。

|  |  |
| --- | --- |
| *ωc*, *ωp*, *ωr*, *ωs* | 行星架、行星轮、齿圈和太阳轮角速度 |
| *rc*, *rp*, *rr*, *rs* | 行星架、行星轮、齿圈和太阳轮角半径 |
| *Jc*, *Jp*, *Jr*, *Js* | 行星架、行星轮、齿圈和太阳轮惯量 |
| *bc*, *bp*, *br*, *bs* | 行星架、行星轮、齿圈和太阳轮阻尼 |
| *Tc*, *Tp*, *Tr*, *Ts* | 施加的行星架、行星轮、齿圈和太阳轮转矩 |
| *Tps* | 行星轮施加在太阳轮上的转矩 |
| *Tpc* | 行星轮施加在行星架上的转矩 |
| *Tpr* | 行星轮施加在齿圈上的转矩 |
| *Trp* | 齿圈施加在行星轮上的转矩 |
| *Tsp* | 太阳轮施加在行星轮上的转矩 |
| *Tcp* | 行星架施加在行星轮上的转矩 |
