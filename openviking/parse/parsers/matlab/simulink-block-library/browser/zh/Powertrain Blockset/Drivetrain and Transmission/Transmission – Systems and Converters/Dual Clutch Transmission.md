# Dual Clutch Transmission

## 端口

### 输入

### **Gear** — 要接合的挡位编号 `scalar`

要接合的挡位编号的整数值。

### **CltchACmd** — 奇数挡命令 `scalar`

奇数挡的离合器压力命令，介于 `0` 和 `1` 之间。

#### 依赖关系

要创建此端口，请选择 **控制模式** 参数 `External control`。

### **CltchBCmd** — 偶数挡命令 `scalar`

偶数挡的离合器压力命令，介于 `0` 和 `1` 之间。

#### 依赖关系

要创建此端口，请选择 **控制模式** 参数 `External control`。

### **EngTrq** — 施加的扭矩 `scalar`

施加的输入扭矩，*Ti*，通常来自发动机曲轴或双质量飞轮减振器，单位为 N·m。

### **DiffTrq** — 施加的扭矩 `scalar`

施加的负载扭矩，*Td*，通常来自驱动轴，单位为 N·m。

### **Temp** — 油温 `scalar`

油温，单位为 K。为确定效率，模块使用 4D 查找表，该表是以下量的函数：

- 挡位
- 输入扭矩
- 输入速度
- 油温

#### 依赖关系

要创建此端口，请将 **效率因子** 设置为 `Gear, input torque, input speed, and temperature`。

## 参数

### **控制模式** — 指定控制模式 `External control`（默认） | `Ideal integrated controller`

DCT 通过控制两个离合器的压力信号来连续输出驱动轴扭矩。如果选择 **控制模式** 参数 `Ideal integrated controller`，模块会生成理想化的离合器压力信号。模块使用每个离合器的最大压力来近似可实现等效驱动轴扭矩的单离合器命令。要使用您自己的离合器控制信号，请选择 **控制模式** 参数 `External control`。

## 描述

向驱动轴施加扭矩的双离合器变速器

Dual Clutch Transmission 模块实现双离合器变速器 (DCT)。在 DCT 中，两个离合器向驱动轴施加机械扭矩。奇数挡接合一个离合器，而偶数挡接合第二个离合器。挡位数量通过整数向量指定，并带有对应的挡位速比、惯量、粘性阻尼和效率因子。离合器和同步器接合速率是线性且可调的。您可以提供外部离合器信号，或将模块配置为生成理想化的内部离合器信号。该模块以最少的参数化或计算成本实现变速器模型。

使用该模块对简化的自动手动变速器 (AMT) 进行建模，用于：

- 功率和扭矩容量选型
- 确定挡位速比对燃油经济性和性能的影响

为确定旋转驱动轴速度和反作用扭矩，Dual Clutch Transmission 模块计算：

- 离合器锁止和离合器摩擦
- 锁止旋转动力学
- 未锁止旋转动力学

要指定模块效率计算，请在 **效率因子** 中选择以下任一选项。

| 设置 | 模块实现 |
| --- | --- |
| `Gear only` | 效率由基于挡位的 1D 查找表确定。 |
| `Gear, input torque, input speed, and temperature` | 效率由 4D 查找表确定，该表是以下量的函数：

- 挡位
- 输入扭矩
- 输入速度
- 油温 |

### 离合器控制

DCT 通过控制两个离合器的压力信号来连续输出驱动轴扭矩。如果选择 **控制模式** 参数 `Ideal integrated controller`，模块会生成理想化的离合器压力信号。模块使用每个离合器的最大压力来近似可实现等效驱动轴扭矩的单离合器命令。要使用您自己的离合器控制信号，请选择 **控制模式** 参数 `External control`。
