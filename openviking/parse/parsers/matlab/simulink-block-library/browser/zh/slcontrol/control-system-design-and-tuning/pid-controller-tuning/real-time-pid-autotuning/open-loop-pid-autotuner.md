# Open-Loop PID Autotuner

## 端口

### 输入

### **u** — 来自控制器的信号 标量

将模块插入您的系统，使该端口接受来自源的控制信号。通常，该端口接受来自系统中 PID 控制器的信号。

**数据类型：** `single` | `double`

### **y** — 被控对象输出 标量

将此端口连接到被控对象输出。

**数据类型：** `single` | `double`

### **start/stop** — 启动和停止自整定实验 标量

要启动和停止自整定过程，请在 `start/stop` 端口提供信号。当信号的值从以下情况变化时：

- 负值或零变为正值时，实验启动
- 正值变为负值或零时，实验停止

当实验未运行时，模块将信号从 **u** 原样传递到 **u+Δu**。在此状态下，模块对被控对象或控制器行为没有影响。

通常，您可以使用从 0 变为 1 的信号来启动实验，并使用从 1 变为 0 的信号来停止实验。配置 **start/stop** 信号时需要考虑的一些要点包括：

- 当被控对象处于期望的平衡工作点时启动实验。使用初始控制器将被控对象驱动到该工作点。如果没有初始控制器（仅开环整定），您可以使用连接到 **u** 的源模块将被控对象驱动到该工作点。
- 在实验期间避免对被控对象施加任何负载扰动。负载扰动会使被控对象输出失真，并降低频率响应估计的精度。
- 让实验运行足够长时间，以便算法收集足够数据，在其探测的所有频率上获得良好估计。有两种方法可确定何时停止实验：

  - 提前确定实验持续时间。对于闭环整定，实验持续时间的保守估计为 200/*ωc*；对于开环整定，为 100/*ωc*，其中 *ωc* 是您的目标带宽。
  - 观察 `% conv` 输出处的信号，并在信号稳定在接近 100% 时停止实验。
- 当您停止实验时，模块会计算整定后的 PID 增益，并更新 `pid gains` 端口处的信号。

您可以配置适合您应用的任何逻辑来控制实验的启动和停止时间。

**数据类型：** `single` | `double`

### **bandwidth** — 用于整定的目标带宽 标量

为 `Target bandwidth (rad/sec)` 参数提供一个值。有关详细信息，请参阅该参数。

#### 依赖关系

要启用此端口，请在整定选项卡中，在 `Target bandwidth (rad/sec)` 旁边选择 **使用外部源**。

**数据类型：** `single` | `double`

### **target PM** — 用于整定的目标相位裕度 标量

为 `Target phase margin (degrees)` 参数提供一个值。有关详细信息，请参阅该参数。

#### 依赖关系

要启用此端口，请在整定选项卡中，在 `Target phase margin (degrees)` 旁边选择 **使用外部源**。

**数据类型：** `single` | `double`

### **sine Amp** — 注入正弦信号的幅值 标量 | 向量

为 `Sine Amplitudes` 参数提供一个值。有关详细信息，请参阅该参数。

#### 依赖关系

要启用此端口，请在实验选项卡中，在 `Sine Amplitudes` 旁边选择 **使用外部源**。

**数据类型：** `single` | `double`

### **step Amp** — 注入阶跃信号的幅值 标量

为 `Step Amplitude` 参数提供一个值。有关详细信息，请参阅该参数。

#### 依赖关系

要启用此端口，请在实验选项卡中，在 `Step Amplitudes` 旁边选择 **使用外部源**。

**数据类型：** `single` | `double`

### 输出

### **u+Δu** — 用于被控对象输入的信号 标量

将模块插入您的系统，使该端口将输入信号馈送到您的被控对象。

- 当实验正在运行（`start/stop` 为正）时，模块在该端口向被控对象注入测试信号。测试信号是实验开始时 u 处的值加上实验扰动。如果有任何保护被控对象的饱和或速率限制，请将来自 **u+Δu** 的信号馈入其中。
- 当实验未运行（`start/stop` 为零或负）时，模块将信号从 **u** 原样传递到 **u+Δu**。

**数据类型：** `single` | `double`

### **% conv** — 实验期间 FRD 估计的收敛性 标量

当实验正在运行（`start/stop` 为正）时，模块向被控对象注入测试信号，并在 `y` 处测量被控对象响应。它使用这些信号来估计被控对象在用于整定的目标带宽附近几个频率处的频率响应。`% conv` 指示被控对象频率响应估计的完成程度。通常，该值在实验开始后迅速上升到约 90%，然后逐渐收敛到更高的值。当其稳定在接近 100% 时停止实验。

**数据类型：** `single` | `double`

### **pid gains** — 整定后的 PID 系数 总线

此 4 元素总线信号包含整定后的 PID 增益 *P*、*I*、*D* 以及滤波器系数 *N*。这些值对应于 `Form` 参数中给出的表达式里的 `P`、`I`、`D` 和 `N` 参数。初始时，这些值分别为 0、0、0 和 100。模块在实验结束时更新这些值。此总线信号始终有四个元素，即使您整定的不是 PIDF 控制器。

如果您的模块关联了 PID 控制器，则可以在实验结束后使用这些值更新该控制器。为此，请在模块选项卡中点击 **更新 PID 模块**。

**数据类型：** `single` | `double`

### **estimated PM** — 使用整定后控制器的估计相位裕度 标量

此端口输出整定后控制器达到的估计相位裕度，以度为单位。模块在整定实验结束时更新此值。估计相位裕度根据 *G*(*jωc*)*C*(*jωc*) 的角度计算，其中 *G* 是估计的被控对象，*C* 是整定后的控制器，*ωc* 是穿越频率（带宽）。估计相位裕度可能与 `Target phase margin (degrees)` 参数指定的目标相位裕度不同。它是整定后系统所达到的鲁棒性和稳定性的指标。

- 通常，估计相位裕度接近目标相位裕度。一般而言，该值越大，整定后系统越鲁棒，超调越小。
- 负相位裕度表示闭环系统可能不稳定。

#### 依赖关系

要启用此端口，请在整定选项卡中选择 **输出整定后控制器达到的估计相位裕度**。

### **frd** — 估计的频率响应 向量

此端口输出实验估计的频率响应数据。初始时，`frd` 处的值为 [0, 0, 0, 0]。在实验期间，模块在频率 [1/3, 1, 3, 10]*ωc* 处注入信号，其中 *ωc* 是目标带宽。在实验期间的每个采样时间，模块使用分别包含这些频率处复频率响应的向量更新 `frd`。您可以使用响应的进展作为 `% conv` 的替代，以检查估计的收敛性。当实验停止时，模块使用用于计算 PID 增益的最终估计频率响应更新 `frd`。

#### 依赖关系

要启用此端口，请在实验选项卡中选择 **带宽附近的被控对象频率响应**。

### **dcgain** — 被控对象的估计 DC 增益 标量

如果在实验选项卡中选择 **使用阶跃信号估计 DC 增益**，模块会通过在注入的扰动中包含阶跃信号来估计被控对象的 DC 增益。当实验停止时，模块使用估计的 DC 增益值更新此端口。

#### 依赖关系

要启用此端口，请在实验选项卡中选择 **被控对象 DC 增益**。

### **nominal** — 标称工作点处的被控对象输入和输出 向量

此端口输出一个向量，其中包含实验开始时的被控对象输入（**u+Δu**）和被控对象输出（**y**）。这些值是模块执行实验时所处标称工作点处的被控对象输入和输出。

#### 依赖关系

要启用此端口，请在实验选项卡中选择 **被控对象标称输入和输出**。

## 参数

#### 整定选项卡

### **类型** — PID 控制器动作 `PI`（默认）| `PID` | `PIDF` | ...

指定您系统中 PID 控制器的类型。控制器类型指示控制器中存在的动作。以下控制器类型可用于 PID 自整定：

- `P` — 仅比例
- `I` — 仅积分
- `PI` — 比例和积分
- `PD` — 比例和微分
- `PDF` — 带微分滤波器的比例和微分
- `PID` — 比例、积分和微分
- `PIDF` — 带微分滤波器的比例、积分和微分

当您使用整定后的参数值更新 PID Controller 模块或自定义 PID 控制器时，请确保控制器类型匹配。

**可调：** Yes

#### 编程用法

|  |
| --- |
| **模块参数：** `PIDType` |
| **类型：** character vector |
| **值：** `'P'` | `'I'` | `'PI'` | `'PD'` | `'PDF'` | `'PID'` | `'PIDF'` |
| **默认值：** `'PI'` |

### **形式** — PID 控制器形式 `Parallel`（默认）| `Ideal`

指定控制器形式。控制器形式决定 PID 系数 *P*、*I*、*D* 和 *N* 的解释。

- `Parallel` — 在 `Parallel` 形式中，离散时间 PIDF 控制器的传递函数为：

  C=P+IFi(z)+D[N1+NFd(z)],

  其中 *Fi*(*z*) 和 *Fd*(*z*) 是积分器和滤波器公式（请参阅 `Integrator method` 和 `Filter method`）。连续时间并联形式 PIDF 控制器的传递函数为：

  C=P+I(1s)+D(Nss+N).

  其他控制器动作相当于将 *P*、*I* 或 *D* 设置为零。
- `Ideal` — 在 `Ideal` 形式中，离散时间 PIDF 控制器的传递函数为：

  C=P[1+IFi(z)+D(N1+NFd(z))].

  连续时间理想形式 PIDF 控制器的传递函数为：

  C=P[1+I(1s)+D(Nss+N)].

  其他控制器动作相当于将 *D* 设置为零，或将 *I* 设置为 `Inf`。（在理想形式中，控制器必须具有比例动作。）

当您使用整定后的参数值更新 PID Controller 模块或自定义 PID 控制器时，请确保控制器形式匹配。

|  |

| **模块参数：** `PIDForm` |
| **类型：** character vector |
| **值：** `'Parallel'` | `'Ideal'` |
| **默认值：** `'Parallel'` |

### **控制器采样时间 (sec)** — PID 控制器的采样时间 0.1（默认）| 正标量 | –1

指定 PID 控制器的采样时间，以秒为单位。此值还设置模块执行实验的采样时间。

要执行 PID 整定，模块会测量最高为目标带宽 10 倍的频率处的频率响应信息。为确保该频率小于 Nyquist 频率，目标带宽 *ωc* 必须满足 *ωc**Ts* ≤ 0.3，其中 *Ts* *ωc* 是您使用 **控制器采样时间 (sec)** 参数指定的控制器采样时间。

### **积分器方法** — 积分器项的离散积分公式 `Forward Euler`（默认）| `Backward Euler` | `Trapezoidal`

C=P+IFi(z)+D[N1+NFd(z)],

C=P[1+IFi(z)+D(N1+NFd(z))].

| 积分器方法 | *Fi* |
| --- | --- |
| `Forward Euler` | Tsz−1 |
| `Backward Euler` | Tszz−1 |
| `Trapezoidal` | Ts2z+1z−1 |

有关每种方法相对优势的详细信息，请参阅 Discrete PID Controller 模块参考页。

当您使用整定后的参数值更新 PID Controller 模块或自定义 PID 控制器时，请确保积分器方法匹配。

### **目标带宽 (rad/sec)** — 调优响应的目标穿越频率 1 (默认) | 正标量

目标带宽以 rad/sec 为单位指定，是调优后开环响应 *CP* 的 0 dB 增益穿越频率的目标值，其中 *P* 是被控对象响应，*C* 是控制器响应。该穿越频率大致设定控制带宽。对于上升时间 *τ* 秒，目标带宽的一个良好估计为 2/*τ* rad/sec。

为执行 PID 调优，autotuner 模块会测量最高达到目标带宽 10 倍频率的频率响应信息。为确保该频率低于奈奎斯特频率，目标带宽 *ωc* 必须满足 *ωc**Ts* ≤ 0.3，其中 *Ts* 是您使用 **控制器采样时间 (sec)** 参数指定的控制器采样时间。由于此条件，您可以为调优强制的最快上升时间约为 6.67*Ts*。如果该上升时间不满足您的设计目标，请考虑减小 *Ts*。

要通过输入端口提供目标带宽，请选择 **使用外部源**。

#### 实验选项卡

### **正弦幅值** — 正弦扰动的幅值 1 (默认) | 标量 | 长度为 4 的向量

在调优实验期间，模块会在频率 [1/3, 1, 3, 10]*ωc* 处向被控对象注入正弦信号，其中 *ωc* 是用于调优的目标带宽。使用 **正弦幅值** 指定每个注入信号的幅值。指定：

- 标量值，以在每个频率处注入相同幅值
- 长度为 4 的向量，以在 [1/3, 1, 3, 10]*ωc* 的每个频率处指定不同幅值

在具有典型目标带宽的典型被控对象中，实验频率处被控对象响应的幅值不会变化很大。在这种情况下，您可以使用标量值在所有频率处施加相同幅值的扰动。但是，如果您知道响应在该频率范围内急剧衰减，请考虑减小较低频率输入的幅值并增大较高频率输入的幅值。当所有被控对象响应具有可比幅值时，估计实验在数值上会更好。

扰动幅值必须：

- 足够大，以使扰动克服被控对象执行器中的任何死区，并生成高于噪声水平的响应
- 足够小，以使被控对象在标称工作点附近的近似线性区域内运行，并避免使被控对象输入或输出饱和

在实验中，正弦信号会叠加（对于开环调优，还会叠加阶跃扰动，如果有）。因此，扰动至少可能等于所有幅值之和。因此，为获得合适的幅值，请考虑：

- 执行器限制。确保最大可能扰动处于被控对象执行器的范围内。使执行器饱和可能会给估计的频率响应引入误差。
- 在用于调优的标称工作点处，被控对象响应针对给定执行器输入的变化量。例如，假设您正在调优用于发动机转速控制的 PID 控制器。您已确定，在目标带宽附近的频率处，节气门角度变化 1° 会导致发动机转速变化约 200 rpm。进一步假设为保持线性性能，转速偏离标称工作点不得超过 100 rpm。在这种情况下，选择幅值以确保扰动信号不大于 0.5（假设该值在执行器限制内）。

要通过输入端口提供正弦幅值，请选择 **使用外部源**。

**可调：** 是

### **减少内存并避免任务超限（仅外部模式）** — 仅部署调优算法 `off` (默认) | `on`

该模块包含两个模块，一个执行实时频率响应估计，另一个使用所得估计响应来调优 PID 增益。当您在外部仿真模式下运行包含该模块的 Simulink 模型时，默认情况下会部署这两个模块。您可以通过仅部署估计模块来节省目标硬件上的内存（请参阅 Control Real-Time PID Autotuning in Simulink）。在这种情况下，调优算法在 Simulink 主机计算机上运行，而不是在目标硬件上运行。选择此选项时，部署的算法使用的内存约为清除该选项时的三分之一。

PID 增益计算比频率响应估计要求更高的计算负载。对于快速控制器采样时间，某些硬件可能无法在一个执行周期内完成增益计算。因此，在使用计算能力有限的硬件时，选择此选项可让您调优具有快速采样时间的 PID 控制器。

此外，当您启用此选项时，从调优实验结束到新的 PID 增益到达 **pid gains** 输出端口之间可能会有数个采样周期的延迟。在将增益推送到控制器之前，请先在 **pid gains** 输出端口确认更改，而不是使用 **start/stop** 信号作为更新触发。

如果您打算部署该模块并在不使用外部仿真模式的情况下执行 PID 调优，请不要选择此选项。

- 在命令行中：使用 `set_param(mdl,'DefaultParameterBehavior','Tunable')`。

### **导出到 MATLAB** — 将实验和调优结果发送到 MATLAB 工作区 按钮

## 描述

基于实时开环实验估计的被控对象频率响应自动整定 PID 增益

Open-Loop PID Autotuner 模块允许您针对物理被控对象实时整定 PID 控制器。该模块可以整定 PID 控制器，以达到指定的带宽和相位裕度，而无需参数化被控对象模型或初始控制器设计。如果您有代码生成产品（例如 Simulink® Coder™），则可以生成在硬件上实现整定算法的代码，从而让您实时进行整定，无论是否使用 Simulink 管理自整定过程。

如果您在 Simulink 中有被控对象模型，也可以使用该模块获得初始 PID 设计。这样做可以让您预览被控对象响应，并在实时整定控制器之前调整 PID 自整定设置。

为实现无模型整定，Open-Loop PID Autotuner 模块：

1. 在标称工作点向被控对象注入测试信号，以采集被控对象输入输出数据并实时估计频率响应。测试信号是正弦和阶跃扰动信号的组合，叠加在实验开始时测得的标称被控对象输入之上。如果被控对象是反馈回路的一部分，则该模块在实验期间打开回路。
2. 在实验结束时，基于开环带宽附近估计的被控对象频率响应整定 PID 控制器参数。
3. 使用整定后的参数更新 PID Controller 模块或自定义 PID 控制器，使您能够实时验证闭环性能。

由于该模块执行开环估计实验，因此请勿将此模块用于不稳定被控对象或具有多个积分器的被控对象。

要使用该算法，不需要初始 PID 控制器设计。但是，您必须通过某种方式使被控对象达到用于频率响应估计实验的标称工作点。如果您有初始控制器设计，可以使用 Closed-Loop PID Autotuner。有关闭环和开环 PID 自整定的比较，请参阅何时使用 PID 自整定。

该模块支持使用 Simulink Coder、Embedded Coder® 和 Simulink PLC Coder™ 进行代码生成。它不支持使用 HDL Coder™ 进行代码生成。

有关使用 Open-Loop PID Autotuner 模块的详细信息，请参阅：

- 对 Simulink 中建模的被控对象进行 PID 自整定
- 实时 PID 自整定

有关 PID 自整定以及闭环和开环方法比较的更一般信息，请参阅何时使用 PID 自整定。
