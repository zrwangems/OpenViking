# 3D Controller [A(v),B(v),C(v),D(v)]

## 端口

### 输入

### **y** — 飞行器测量向量

飞行器测量，指定为向量。

**数据类型：** `double`

### **v1** — 第一调度变量向量

第一调度变量，指定为向量，其符合状态空间矩阵的维度。

**数据类型：** `double`

### **v2** — 第二调度变量向量

第二调度变量，指定为向量，其符合状态空间矩阵的维度。

**数据类型：** `double`

### **v3** — 第三调度变量向量

第三调度变量，指定为向量，其符合状态空间矩阵的维度。

**数据类型：** `double`

### 输出

### **u** — 作动器需求向量

作动器需求，指定为向量。

**数据类型：** `double`

## 参数

### **A-matrix(v1,v2,v3)** — 状态空间实现的 *A* 矩阵 `A`（默认）| array

状态空间实现的 *A* 矩阵。在三维调度的情况下，*A* 矩阵应具有五个维度，最后三个对应于调度变量 *v*1、*v*2 和 *v*3。例如，如果对应于 *v*1 的第一个元素、*v*2 的第一个元素和 *v*3 的第一个元素的 *A* 矩阵是单位矩阵，则 `A(:,:,1,1,1) = [1 0;0 1];`。

## 描述

实现取决于三个调度参数的增益调度状态空间控制器

3D Controller [A(v),B(v),C(v),D(v)] 模块实现如算法中所述的增益调度状态空间控制器。

此模块的输出是作动器需求，您可以将其输入到作动器模块。
