# 2D Observer Form [A(v),B(v),C(v),F(v),H(v)]

## 端口

### 输入

### **y-y\_dem** — 设定点误差向量

设定点误差，指定为向量。

**数据类型：** `double`

### **v1** — 第一调度变量向量

第一调度变量，指定为向量，其与状态空间矩阵的维度一致。

**数据类型：** `double`

### **v2** — 第二调度变量向量

第二调度变量，指定为向量，其与状态空间矩阵的维度一致。

**数据类型：** `double`

### **u\_meas** — 测得的执行器位置向量

测得的执行器位置，指定为向量。

**数据类型：** `double`

**数据类型：** `double`

## 参数

### **A 矩阵(v1,v2)** — 状态空间实现的 *A* 矩阵 `A`（默认） | 数组

状态空间实现的 *A* 矩阵。在 2-D 调度的情况下，*A* 矩阵应具有四个维度，最后两个维度对应于调度变量 *v*1 和 *v*2。例如，如果对应于 *v*1 的第一个条目和 *v*2 的第一个条目的 *A* 矩阵是单位矩阵，则 `A(:,:,1,1) = [1 0;0 1];`。

## 描述

根据两个调度参数，以观测器形式实现增益调度状态空间控制器

2D Observer Form [A(v),B(v),C(v),F(v),H(v)] 模块实现如算法中所定义的增益调度状态空间控制器。

该模块的输出是执行器需求，您可以将其输入到执行器模块。使用此模块可实现使用 H-infinity 回路成形设计的控制器，这是 Robust Control Toolbox 支持的设计方法之一。
