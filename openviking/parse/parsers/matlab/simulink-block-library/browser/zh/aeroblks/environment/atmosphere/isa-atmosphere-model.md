# ISA Atmosphere Model

## 端口

### 输入

### **h (m)** — 位势高度标量 | *m*-by-*n* 数组

位势高度，指定为标量或 *m*-by-*n* 数组。

**数据类型：** `double`
### 输出

### **T (K)** — 温度标量 | *m*-by-*n* 数组

温度，返回为标量或 *m*-by-*n* 数组，单位为 K。

**数据类型：** `double`

### **a (m/s)** — 声速标量 | *m*-by-*n* 数组

声速，返回为标量或 *m*-by-*n* 数组，单位为 m/s。

**数据类型：** `double`

### **P (Pa)** — 空气压力标量 | *m*-by-*n* 数组

空气压力，返回为标量或 *m*-by-*n* 数组，单位为 Pa。

**数据类型：** `double`

### **ρ (kg/m3)** — 密度标量 | *m*-by-*n* 数组

密度，返回为标量或 *m*-by-*n* 数组，单位为 kg/m3。

**数据类型：** `double`

### **ν (m2/s)** — 运动粘度标量 | *m*-by-*n* 数组

运动粘度，返回为标量或 *m*-by-*n* 数组，单位为 m2/s。

#### 依赖关系

选中 **输出运动粘度和动力粘度** 复选框会添加 **ν (m2/s)** 输出端口。

**数据类型：** `double`

### **μ (N s/m2)** — 动力粘度标量 | *m*-by-*n* 数组

动力粘度，返回为标量或 *m*-by-*n* 数组，单位为 N s/m2。

#### 依赖关系

选中 **输出运动粘度和动力粘度** 复选框会添加 **μ (N s/m2)** 输出端口。

**数据类型：** `double`

## 参数

### **使用扩展 ISA 模型** — 实现范围 `off` (默认) | `on`

国际标准大气模型的数学表示。

- 要实现输入位势高度介于海平面和对流层顶之间时环境温度、压力、密度和声速的 ISA 值的数学表示，请清除此复选框。对于超出限制的输入高度，输出值保持不变。
- 要实现输入位势高度介于 -5000 meters 和中间层顶之间时环境温度、压力、密度和声速的 ISA 值的数学表示，请选中此复选框。对于超出限制的输入高度，如果越界操作输入设置为 `None` 或 `Warning`，则输出值保持不变。

#### 依赖关系

选中此复选框会移除 **更改大气参数** 复选框。

ISA Atmosphere Model 模块现在支持介于并包括 -5000 meters 和中间层顶 84,852 meters 之间的位势高度输入。在之前的版本中，ISA Atmosphere Model 支持介于并包括海平面和对流层顶 20,000 meters 之间的位势高度。

- **使用扩展 ISA 模型** 参数：

  - 要实现输入位势高度介于 -5000 meters 和中间层顶之间时环境温度、压力、密度和声速的国际标准大气值的数学表示，请选中此复选框。
- **越界输入的操作** 参数，它允许你指定当选中 **使用扩展 ISA 模型** 复选框时对越界输入的操作。

  - 在 **ν** 输出端口中返回运动粘度的 *m*-by-*n* 个值的数值数组，单位为 m2/s。
  - 在 **μ** 输出端口中返回动力粘度的 *m*-by-*n* 个值的数值数组，单位为 N s/m2。

## 描述

实现国际标准大气 (ISA)

ISA Atmosphere Model 模块实现输入位势高度下环境温度、压力、密度和声速的国际标准大气 (ISA) 值的数学表示。

ISA Atmosphere Model 和 Lapse Rate Model 模块是同一模块的替代配置。

ISA Atmosphere Model 模块具有以下实现：

- ISA Atmosphere Model — 默认 ISA 模型实现环境温度、压力、密度和声速的 ISA 值的数学表示，适用于介于海平面 (0 m) 和对流层顶 (20000 m) 之间的输入位势高度。
- Lapse Rate Model — 递减率模型实现环境温度、压力、密度和声速的递减率大气方程的数学表示，适用于输入位势高度。要从 ISA 实现转换为 Lapse Rate 实现，请选择 **更改大气参数** 参数。你可以通过指定大气属性来自定义此大气模型。

要实现输入位势高度介于 -5000 m 和中间层顶 (84852 m) 之间时环境温度、压力、密度和声速的 ISA 值的数学表示，请选择 **使用扩展 ISA 模型** 参数。

ISA Atmosphere Model 模块图标以公制单位显示输入和输出端口标签。
