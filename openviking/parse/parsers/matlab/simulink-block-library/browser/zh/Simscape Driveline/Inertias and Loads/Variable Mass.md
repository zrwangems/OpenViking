# Variable Mass

## 端口

该模块有一个守恒平动端口和一个物理信号输入端口。
守恒平动端口用于标识质量随时间变化的传动系统组件。物理信号输入端口用于将质量指定为时间的函数。

## 参数

**最小质量**
:   可变质量在仿真过程中可取的最低值。物理信号输入在该值处饱和。如果输入低于最小质量，则将其设置为等于最小质量值。默认值为 `0.1`
    `kg`。

## 描述

指定为物理信号输入的时变质量

该模块对时变质量的影响进行建模。可变质量组件的示例包括燃料逐渐减少的燃料箱。在整个仿真过程中，物理信号输入端口提供每个时间步的瞬时质量。为了尽量减少求解器误差，请避免输入信号出现不连续和突变。

随着组件质量的变化，作用在该组件上的惯性力也会变化：

FI=mv˙,

其中：

- *F*I 为惯性力。
- *m* 为可变质量。
- *v* 为质量的速度。

物理信号输入在模块属性检查器中指定的最小质量处饱和。每当输入低于最小质量时，模块将改用最小质量进行计算。惯性力变为：

FI=mMinv˙,

其中：

- *m*Min 为允许的最小质量。

可变质量的线动量守恒。在没有外力的情况下，质量减小会导致线速度成比例增大。线动量保持不变，直到合外力使其发生变化。

### 变量

要在仿真前设置模块变量的优先级和初始目标值，请使用模块对话框或属性检查器中的**初始目标**部分。有关详细信息，请参阅“设置模块变量的优先级和初始目标”。

标称值提供了一种指定模型中变量预期量级的方法。使用基于标称值的系统缩放可提高仿真的鲁棒性。标称值可以来自不同来源，其中之一是模块对话框或属性检查器中的**标称值**部分。有关详细信息，请参阅“修改模块变量的标称值”。
