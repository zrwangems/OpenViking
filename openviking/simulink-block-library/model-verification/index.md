# Model Verification

| 块名称 | 官方文档摘要 |
| --- | --- |
| [Assertion](assertion.md) | Check whether signal is zero |
| [Check Discrete Gradient](check-discrete-gradient.md) | Check that absolute value of difference between successive samples of discrete signal is less than specified value |
| [Check Dynamic Gap](check-dynamic-gap.md) | Check that gap of possibly varying width occurs in range of signal's amplitudes |
| [Check Dynamic Lower Bound](check-dynamic-lower-bound.md) | Check that one signal is always less than another signal |
| [Check Dynamic Range](check-dynamic-range.md) | Check that signal falls inside range of amplitudes that varies from time step to time step |
| [Check Dynamic Upper Bound](check-dynamic-upper-bound.md) | Check that one signal is always greater than another signal |
| [Check Input Resolution](check-input-resolution.md) | Check that input signal has specified resolution |
| [Check Static Gap](check-static-gap.md) | Check that gap exists in signal's range of amplitudes |
| [Check Static Lower Bound](check-static-lower-bound.md) | Check that signal is greater than (or optionally equal to) static lower bound |
| [Check Static Range](check-static-range.md) | Check that signal falls inside fixed range of amplitudes |
| [Check Static Upper Bound](check-static-upper-bound.md) | Check that signal is less than (or optionally equal to) static upper bound |
